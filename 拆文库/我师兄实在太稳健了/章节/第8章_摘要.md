## 第8章 酒仙人上线

**概要**：酒玖在百凡殿审核弟子外出历练任务，见李长寿以化神九阶修为申请前往险地北俱芦洲乱瘴宝林，直言拒绝并让他改去东海打虾妖，还拿出长老身份玉片让他去找道藏阁长老取药草。李长寿坚持要去，酒玖无奈同意但安排元青和有琴玄雅照看他，还吐槽他入门一百多年还未到返虚境。李长寿退至一旁，检查了自己身上三重储物法器（手环、吊坠、大腿布袋）中的丹药、法器、灵石，都已分成三份存放。酒玖驾着大葫芦载五名弟子升空，布置防护法阵后向西北方向飞行。飞行途中酒玖想听曲解闷，李长寿却察觉后方云中有人跟踪，酒玖质问后一名自称洪林国殿前守将的魁梧汉子现身，声称是来护卫六公主，众人目光投向有琴玄雅，她冷淡拒绝护卫，李长寿嗅到了某种套路的味道。

**关键事件**：
1. 酒玖审核弟子外出任务，拒绝李长寿前往北俱芦洲的申请
2. 李长寿检查自己的三重储物法器，为外出历练做准备
3. 酒玖驾大葫芦载弟子飞行，途中发现跟踪者，揭露有琴玄雅是六公主身份

**逐章写法公式**：

- **情绪流向**：起：肃穆（审核任务） → 承：轻松调侃（飞行途中的互动） → 转：紧张（发现跟踪） → 合：悬念爆点（公主身份揭露）
- **节奏配比**：慢铺垫 35% / 快冲突 10% / 爽点爆发 0% / 悬念留白 55%
- **本章结构公式**：酒玖审核任务（拒绝李长寿申请） + 李长寿检查装备（三重储物法器） + 酒玖驾葫芦飞行（途中互动） + 发现跟踪者（揭露公主身份）
- **本章核心技巧**：用角色反差制造印象（酒玖的实力vs形象），用悬念收尾（公主身份+套路味道）
- **卡点与伏笔**：结尾卡点：有琴玄雅是六公主 + 殿前守将突然现身 + 李长寿嗅到套路味道；埋设/回收伏笔：李长寿的谨慎性格 → 三重储物法器 / 酒玖与李长寿师父的情分 → 拿出长老玉片
