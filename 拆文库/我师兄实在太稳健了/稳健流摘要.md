# 我师兄实在太稳健了 · 副对标摘要（稳健流）
> 副对标精简 · 补充主对标（凡流）的"稳健"维度 · 服务《我只想安稳修仙》

## 稳健流核心信条（李长寿 · 内容简介直引）
- 努力不沾因果，杀人必扬其灰
- 凡事谋而后动，从不轻易步入危险
- 藏底牌，修遁术，炼丹毒，掌神通
- 不动稳如老狗，一动石破天惊，动后悄声走人
- 躲在山中平安无事修行成仙（苟）

## 黄金三章稳健展现（第1-2章实证）
- **纸人替身**：床上放小纸人装自己在（防偷袭先手）
- **软仙香/防贼布置**：山门内还做防贼机关（连山门都不放心）
- **水遁修行**：练遁术（逃生手段常态化）
- **谋而后动**原话："弟子只是防患于未然"——把"稳健"说成"防患未然"
- **温润表象**：表面温和不急不缓，内里算计（藏拙的表演层）

## 稳健流 vs 凡流（差异/加码点）★
| 维度 | 凡流韩立 | 稳健流李长寿 |
|---|---|---|
| 稳健动因 | 被动（环境逼） | 主动（系统化布局） |
| 保命手段 | 藏拙+弱金手指 | 多重（替身/遁术/毒/后手） |
| 行动准则 | 谨慎隐忍 | 谋而后动（算尽才动） |
| 出手 | 被逼应战 | 不动如山/一动惊人/动后走人 |
| 处世 | 求生 | 不沾因果/扬灰灭迹 |
| 调性 | 沉重黑暗森林 | 带喜剧（纸人/师妹互动） |

## 对《我只想安稳修仙》主角映射（凡流 + 稳健流融合）
**凡流基底**（韩立）：资质平庸/外表普通/藏拙聪明/谨慎隐忍有家庭根/苦修慢热/朴素动机/弱金手指（小绿瓶类，催熟/加速辅助型）

**稳健流加码**（李长寿）：
1. 主动布局多重保命（不只藏拙，是真备后手：替身/遁术/解毒等）
2. 谋而后动——不算清楚不动，动前算尽后路
3. 不沾因果/扬灰灭迹——杀人留痕=找死，灭迹是本能
4. 不动如山、一动惊人、动后走人——平时苟成狗，出手必杀，干完消失
5. 温润表象藏算计——表面与世无争，内里步步为营
6. 适度喜剧——纸人替身/误会/反差萌（中和凡流沉重）

**区别于纯凡流**：主角更"主动稳健"（不只被动求生，主动布局安全），更"真有底牌"（藏拙是因为真有后手可藏），调性可带轻喜剧（稳健流的趣味）。

## 一句话定位
《我只想安稳修仙》= 凡人韩立的资质平庸苦修求生 × 我师兄李长寿的主动稳健底牌苟道，写一个**平庸修士靠极致稳健+弱法宝，在残酷修仙界苟成长生**的故事。
