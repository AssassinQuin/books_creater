# 我师兄实在太稳健了 · 剧情节奏（Stage 3 聚合）
> 主对标·稳健流节奏权威 · 服务《我只想安稳修仙》卷纲/细纲节奏

## 前30章节奏曲线（8段）
1. **黄金三章立人设(1-3)**：师妹入门 → 纸人替身亮相 → 入门审核 → 稳健教程
2. **师妹教学+生存哲学(4-5)**：残酷法则(躲避因果/保留底牌/三十六计走为上) + "活下去到顶点改写规则"
3. **时间跳+穿越者揭示(6)**：前世记忆/确立活下去目标/师妹十年后好感+约法三章
4. **历练大会选险地(7)**：五年一度 → 李长寿选最危险北俱芦洲(化神九阶压线)
5. **出发+三重储物+察觉跟踪(8-10)**：资源分三份/装过敏躲检查/将计就计装心魔
6. **进林+独走+摆脱监视(11-12)**：三层避瘴符/独选不同方向/隐踪+土遁摆脱
7. **★反杀高潮(13-17)**：纸人替身诱杀刺客+毁尸灭迹 → 救玄雅悄然离去 → 借力打力夺仙解草(纸人3→6张加码)
8. **善后+助师渡劫(18-30)**：师父们来援/坑跳不过/助师渡劫方案/饲养员/表象/夜会/渡劫二套/师徒

## 关键信息推进
- 1-3：李长寿人设(温润+算计+不沾因果) + 多底牌(纸人/软仙香/水遁) 定型
- 6：穿越者身份揭示(长线伏笔) + 活下去目标
- 7：化神九阶修为暴露(压线选险地)
- 13：★第一次反杀 + 元青背叛阴谋 + 纸人分身战斗应用定型
- 17：纸人加码(3→6张) + 借力打力高阶应用
- 22-30：助师渡劫(算计师父辈的高阶稳健——从自保升级到布局他人)

## 爽点/笑点循环（稳健流节奏特征）
- **爽点节奏**：每 2-3 章一个"多底牌兑现"小爽(看他料到了)；ch13/ch17 两个大爽(反杀/夺草)
- **笑点节奏**：性格喜剧穿插(装弱/吐槽/过度反应)，不密集，作调味
- **驱动方式**：稳健流不靠"危机密度"驱动，靠**"算计层层兑现"**驱动——读者期待"这次他又备了什么"

## 两个高潮结构（可迁移）
- **ch13 反杀（战斗化险）**：被动被盯 → 将计就计 → 纸人替身诱杀 → 多底牌并发 → 毁尸灭迹。爽在"敌人以为得手，他早备替身+反制"
- **ch22-30 助师渡劫（算计长辈）**：从自保升级到主动布局帮师父渡劫(多套方案)。爽在"算计层级升级"——对应陈安从"自保"到"主动布局"的成长节点

## 对《我只想安稳修仙》第一卷的节奏启示
- 凡流黄金三章(立人设/世界/金手指) + 稳健流加码(底牌雏形/谋定) 可叠加：陈安第1-3章立倒霉+平庸+藏拙，第10章前后炼器分身登场(对标李长寿纸人替身亮相)
- 第一卷大高潮：千层饼化险(对标ch13反杀)——多底牌并发+九死一生+智谋脱身
- 稳健流"算计层层兑现"驱动 → 陈安每2-3章一个"多方案兑现"小爽，避免靠危机密度硬撑
