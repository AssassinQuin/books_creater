# 我师兄实在太稳健了 · 概要（Stage 0 thin first-pass）
> thin first-pass；full plot-aware 500-1000 字版在 Stage 5 覆盖。
> 主对标 · 服务《我只想安稳修仙》稳健流维度（炼器分身金手指 / 多方案谨慎 / 苟道）

重生在封神大战之前的上古洪荒，李长寿成了度仙门一个普通炼气士。没有气运加身、不是天定劫子，只有一个长生梦。为在残酷洪荒安身立命，他努力不沾因果、杀人扬灰、凡事谋而后动，藏底牌、修遁术、炼丹毒、掌神通，纸人替身随身——不动稳如老狗，一动石破天惊，动后悄声走人。本想躲山中平安修仙，直到师父静极思动又收了个师妹回来，被一桩桩因果卷入局中。

**稳健流（苟道流）代表作**。核心爽点引擎 = 过度谨慎 / 多底牌（纸人替身+遁术+丹毒+神通）/ 谋定后动 / 不动如山一动惊人；轻喜感为调味（反差/误会/过度准备）。区别凡流：韩立是被动求生驱动谨慎，李长寿是**主动布局驱动稳健**——他的稳健本身就是笑点和爽点。

本拆解聚焦前 30 章（度仙门师门段 → 师妹到来 → 历练大会智斗反杀），稳健流套路最密集期，提炼稳健流情绪模块/节奏/文风/李长寿人设/纸人分身&多底牌机制，供《我只想安稳修仙》映射。
