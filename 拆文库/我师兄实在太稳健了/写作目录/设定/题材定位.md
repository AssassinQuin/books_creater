# 题材定位（反推）

## 一句话定位

洪荒流×稳健流：知局者在封神前的洪荒"求稳求生"，把苟道活成权谋，最终从棋子活成立法者。

## 题材配方表

| 成分 | 占比 | 说明 |
|---|---|---|
| 稳健苟道（人设驱动） | 30% | 底牌流/备战仪式/痕迹清除——每章可见的动作戏 |
| 智斗权谋（算计驱动） | 30% | 多底牌兑现/局中局/程序战（凌霄审灯） |
| 群像温情（关系驱动） | 20% | 师门/天庭/三教三层关系网 |
| 洪荒奇观（世界观驱动） | 15% | 圣人博弈/量劫史诗/秘辛揭晓 |
| 感情线（节点制） | 5% | 云霄线四高光章+灵娥温度线 |

## 核心情绪承诺（读者契约）

1. **算计兑现的爽**：读者期待"这次他又备了什么"——每 2-3 章一次小兑现，弧高潮大兑现。
2. **身份误读的喜**：稳健被大佬们过度解读（迪化误会），误会转化为人际资产。
3. **知局的优越感**：读者与主角共享封神知识，看着洪荒大佬们在"未来"面前裸奔——**但知识有保质期**。
4. **底层翻身的正剧感**：从炼气士到立法者，每一步都有代价记录（首败/灭门/师父之死）。

## 对标坐标

- **主对标**：自身（《我师兄实在太稳健了》，本书即拆解对象）
- **同人底盘**：《封神演义》叙事框架+洪荒流 canon（五大量劫/紫霄宫体系）
- **读者画像**：男频洪荒流+苟道流读者；对"权谋种田+群像"有偏好的长线读者

## 终局底牌与升级台阶（防写无可写设计）

- **终局底牌**：均衡之道（448-450 埋，753 再临，761 献祭兑现）——体系级翻盘的唯一授权。
- **升级台阶**（算计层级 L1-L7，见大纲§二）：每层台阶有明确的"毕业事件"（自保→布局长辈→势力→规则→天庭→大劫→天道）。
- **续航设计**：每卷一个"新棋盘"（南海→三教→天庭→大劫→封神→西游后传），棋盘不重复。

## 本书的市场教训（病根清单，仿写规避）

| 病根 | 正文证据 | 仿写对策 |
|---|---|---|
| 稳健悖论 | 谨慎必要性被消灭（主角后期战力/权力过剩，"稳"成空转口号） | 每卷至少一次"不稳就死"的实锤险局 |
| 隐藏金手指通胀 | 现代知识+算力无成本使用 | 现代思维限"方法论"层；每次使用付"知识失效"代价 |
| 反套路套路化 | 迪化误会模板复用至读者脱敏 | 同一套路 N 次变奏（换壳不换核），每变奏必须有增量 |
| 大纲失控 | ch480 官宣重编封神 | 开书前锁死终局卷细纲（尤其封神执行段） |
| meta 知识保质期 | 封神知识中后期失效后无替代引擎 | 中期完成"信息差→布局层"的引擎换挡（448 定道即换挡点） |
