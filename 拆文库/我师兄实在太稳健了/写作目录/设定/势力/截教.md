# 势力卡·截教（万仙来朝的义气行会）

**坐标**：碧游宫；通天教主门下。人数最多、管理层松散的行会（经济学身份）。
**核心人物**：通天（教主·"帮你劈了轮回塔"的护短底色）、多宝（大师兄·749 化身佛祖）、赵公明、三霄（云霄/琼霄/碧霄）、金灵圣母、龟灵圣母、无当、金光圣母（719 自刭谢罪）。
**大事记**：191-199 三霄入网→211-227 大婚之战结盟→513-526 红莲送碧游宫（截教之劫现形）→527-533 **万仙大会整风**（诛六亲传+九十六仙，多宝"无愧于心"）→656-659 围灵山→722-725 **弑圣战（大婚之后）→震杀准提**→739-741 紫霄宫大战·截教覆灭（通天托孤"带他们走"）→762 回五部洲重建碧游宫。
**暗病**：记名弟子明码标价贩售（529 揭）——整风弧的引子；红莲业障（525）=劫运燃料。
**功能位**：主角的挚友网+封神劫的悲剧主体。截教之劫是全书最大的"明知不可救而救之"主线。
**仿写要点**：大组织要有"病理"（贩售弟子/业障堆积），主角与它的关系=帮它治病而非当它的救世主。
