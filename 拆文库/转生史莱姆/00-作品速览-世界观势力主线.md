# 00 · 作品速览：世界观 / 势力 / 主线 / 伏笔

## 一、世界观分层

作品的世界不是单层平面，而是「洋葱式」结构——每一层剥开都是新的战力天花板。这是它后期膨胀的根源，也是可借鉴的「挖坑」手法。

| 层级 | 内容 | 在剧情中的作用 |
|------|------|----------------|
| 表层 | 朱拉大森林及周围人类诸国 | 建国主线舞台 |
| 中层 | 八星魔王议会、龙种、原初恶魔 | 世界顶层战力博弈 |
| 深层 | 天使居所、精神世界、多元宇宙 | 后期反派真正来源、究极技能天花板 |
| 底层 | 世界法则 / 创世神话（维鲁多拉等龙种的起源） | 终局伏笔 |

**机制要点**：表层用「政治 + 战斗」写细腻，深层用「设定堆叠」写宏大。问题是表层与深层调性断裂（见 04 避坑清单）。

## 二、势力图谱（含关系网）

```
                    【世界顶层】
              八星魔王议会（原十星）
              ├── 主角（觉醒魔王，后跻身）
              ├── 盟友系：金·克林姆兹、拉米莉丝、拉津等
              └── 对立/中立系：达格里尔、兽王戴斯塔等
                    │
        ┌───────────┼───────────┐
    【魔物侧】    【主角阵营】    【人类侧】
    各龙种      朱拉·特恩佩斯特    西方圣教会
    原初恶魔    联邦国（迷宫）     （圣骑士日向）
              ↑收编              法尔姆斯/英勇/东之帝国
    【隐藏幕后】
    天使系（费尔德维、米迦勒等远古存在）
```

**关系动态**：
- 主角阵营 = 魔物 + 人类共荣的「中立第三极」，靠外交 + 战力双线扩张
- 反派转盟友是常用手法（日向、部分魔王）——降低叙事成本，但稀释紧张感
- 隐藏幕后（天使系）跨超长卷埋伏笔，是「主线真正反派」

## 三、主线三段式

| 阶段 | 核心事件 | 成长性质 | 爽点取向 |
|------|----------|----------|----------|
| ① 转生→建国 | 从弱史莱姆靠吞噬成长为森林霸主，建国 | 物理 + 势力扩张 | 种田 + 收编 |
| ② 觉醒魔王 | 挚友之死→暴怒屠城→进化为真魔王 | 身份 + 战力双跃迁 | 复仇 + 碾压 |
| ③ 世界博弈 | 跻身八星，对抗东之帝国与天使系幕后 | 法则级对决 | 谋略 + 设定战 |

**节奏曲线**：① 蜜月上升期（最好看）→ ② 转折高潮（情绪顶点）→ ③ 膨胀期（设定堆叠，质量下滑）。

## 四、关键支线

| 支线 | 情感母题 | 工程价值 |
|------|----------|----------|
| 静（静江·伊泽） | 人类短暂寿命 vs 魔物永生 | 全篇最重要的催泪锚点；用「不可逆失去」给无敌主角注入脆弱性 |
| 维鲁多拉（暴风龙） | 跨越封印的伙伴情 | 最早盟友贯穿全篇，提供「老朋友」连续性 |
| 干部成长（红丸/紫苑/朱菜/迪亚波罗） | 各自独立成长弧 | 撑起配角群像，但造成战力断层（见 03） |
| 迷宫经营 | 副本经济 + 后备培养 | 极好用的「种田/养成」支线，产出资源与兵力 |

## 五、重要伏笔（含跨度）

| 伏笔 | 埋设 → 揭示跨度 | 类型 |
|------|----------------|------|
| 大贤者→智慧之王（拉斐尔）人格化 | 早 → 中后期 | 技能脱离掌控（隐患伏笔） |
| 捕食者→别西卜进化 | 早 → 中后期 | 能力最终形态 |
| 天使居所 / 精神世界 | 中 → 终局 | 世界观天花板 |
| 米迦勒/费尔德维的远古布局 | 中 → 终局 | 主线真正反派 |
| 维鲁多拉身世与创世 | 早 → 终局 | 神话底色 |

**伏笔手法借鉴**：用「技能会自主进化」暗示失控风险，是给无敌主角预设「内在反派」的聪明设计（可惜后期没兑现好，见 04）。
