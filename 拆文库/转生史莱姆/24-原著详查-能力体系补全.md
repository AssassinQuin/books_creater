## 一、魔法体系

### 召唤魔法（卷1 实证）
- 有**等级**之分，按魔法阵规模评定
- 卷1实证："從魔法陣的規模來看，是等級『B＋』以上的魔物"
- 静曾用召唤术召唤魔物（卷1，B+级）

### 咏唱机制（卷1 实证）
- 魔法通常需**詠唱**（咒文程序）
- 大贤者的**詠唱排除**功能可跳过咏唱直接发动
- 卷1："詠唱排除：行使魔法等技能時，無須咒文詠唱程序"

### 魔法种类（已知）
召唤魔法、精灵魔法、神圣魔法（教会系）等（精灵魔法/神圣魔法详规待补）。

## 二、等级评定体系（卷1 实证，详）

### 災害級魔物（定义）
> 戰鬥力相當於一整支軍隊，是如假包換的災害級魔物。

- 灾害级 = 战力等同一支军队（如龙）
- 三头蛇、有翼狮、龙等袭击城镇的魔物
- 灾害级入侵 → **国家级危机**，跨国支援体制（且支援只在事后，讨伐攸关国家威信须自理）

### 魔物等级（C/B/B+...）
| 等级 | 实例 |
|------|------|
| C級 | 滾刀哥布林、牙狼族（单体） |
| B級 | 孤刃虎、牙狼族（群集时） |
| B+級 | 召唤魔法可召唤的魔物 |

**机制**：
- 等级决定战力对比（"C級難敵B級"、"十個哥布林也贏不了一隻牙狼"）
- 群集可提升等级（牙狼单体C级→群集B级）
- 冒险者按等级承接任务

### 弱肉强食的社会（卷1 原文）
> 這個世界就是弱肉強食，弱者活該受到欺凌。
> 無市民權的人們……有能力的人會為了自保去當冒險者。貧富差距擴大。

- 等级体系背后是**阶级社会**（市民权/无市民权、贫富差距）
- 这与"体系压迫"主题直接焊接

## 四、究極技能详解（男主4个，卷5 实证）

### 智慧之王拉斐爾（大賢者＋異變者进化）
- 进化后"更容易實現創造者的願望"
- **人格化萌芽**："沒有喜怒哀樂，不該感到開心才對——但神奇的是，它感到很滿足"
- **可下令其他究极技能**："以『智慧之王拉斐爾』的名義下令"
- 作为"主人的代理人"行动（无自我意识时）

### 暴食之王別西卜（暴食者＋無心者进化）
- **吃光范围内所有魔素——不放過任何一絲靈魂**
- 可吞噬魔素 + 结界 + 灵魂
- 受智慧之王演算结果指挥

### 誓約之王烏列爾（無限牢獄进化）
- 基于**伙伴效忠的结晶**："對我宣誓效忠，這些人的心願化成結晶"
- 防御/誓约系（伙伴越多越强？）

### 暴風之王維爾德拉（捕食维鲁多拉残渣获得）
- 能力：**暴風龍召喚 / 暴風龍復原 / 暴風系魔法**
- 召唤维鲁多拉（一次一只，重复召唤前只消灭）
- 复原 = 复制维鲁多拉记忆到男主

**机制**：究极技能可由①獨有技整合进化 ②捕食强存在残渣获得 ③伙伴羁绊结晶。

## 六、抗性体系（卷5 实证）⭐ 含精彩叙事用法

### 男主觉醒后获得的抗性
- **痛覺無效** / **物理攻擊無效** / **自然影響無效** / **狀態異常無效** / **精神攻擊抗性** / **聖魔攻擊抗性**

### ⭐ 抗性的情感叙事用法（卷5 高光）
男主有"痛覺無效"，但面对亲友（静/紫苑等）死亡时：
> 「痛覺無效」算什麼。一點用都沒有。
> 仔細想想，這還是我第一次面對親友的死……伴隨劇烈的痛楚，疼痛難當。

**机制**：**抗性免疫肉体痛，不免疫情感痛**。原著用"痛觉无效却心痛"做极致情感反差——这是抗性体系的最高叙事用法。

### 省吾的痛覺無效（卷5，反向用例）
- 来自獨有技「生存者」："無論身體受多少重傷，他都不會吃痛"
- **但精神脆弱可被打垮**："沒辦法再造精神"→ 被盖德打到"心如死灰"

**机制**：痛觉无效 = 物理免疫，但精神是弱点。

## 七、对融合设计的详实意义

| 原著机制（细则） | 融合到你的项目 |
|------------------|----------------|
| 灾害级=一支军队 + 弱肉强食社会 | 你的底层魔物/人类阶级可直接用此标尺 + 强化体系压迫主题 |
| 究极技能3种获得方式（进化/捕食残渣/伙伴结晶） | 多元化获得路径，伙伴结晶式很适合"羁绊变力"的写实处理 |
| 智慧之王能下令其他究极 + 人格化萌芽 | 男主「睿音」进化后的人格化 = 内在反派伏笔（可兑现） |
| 誓约之王=伙伴效忠结晶 | 力量来源挂钩羁绊，写实且有情感重量 |
| **抗性免疫肉体不免疫情感** | ⭐ 直接借用：男主有抗性却心痛 = 写实笔法的天然抓手 |
| 觉醒一次获10固有技 | 进化节点的大爆发（但你的写实版要加代价） |
| 庆功宴（进化祝福伙伴） | 进化不只是个人，连带伙伴——可做群像高光 |
