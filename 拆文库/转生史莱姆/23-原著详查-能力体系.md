## 一、能量基础：魔素

### 魔素是什么（卷1 原文）
> 「魔素」是構成這個世界的要素。前世那邊沒有魔素，它在這個世界裡扮演重要角色。

- 魔素 = 这个世界的**基础构成要素**（现代世界没有）
- 魔素浓度决定魔物强弱、是否需进食、魔石/魔礦石分布

### ⭐ 反常识设定（卷1 原文）
> 這個世界有個特別之處，那就是**魔素愈淡的地方，史萊姆愈凶惡、愈強**。一般而言，魔素濃度較高的地方，魔物也會更強才對。

- 一般规律：魔素浓度高 → 魔物强
- **史莱姆反常识**：魔素淡 → 史莱姆更强（因为低魔素区要主动捕食补充魔素，逼出凶性）
- 朱拉大森林魔素极浓 → 史莱姆不需进食

### 史莱姆身体构造（卷1 原文）
> 史萊姆的身體全部是同一細胞的聚集體。每個細胞都是腦細胞、是神經，也是肌肉。因此，用來思考的演算細胞能交替休息，所以不需要睡眠。

- 单细胞聚合体，每个细胞兼具脑/神经/肌肉功能
- 演算细胞可交替休息 → **不需要睡眠**
- 记忆类似 RAID 阵列（分布式备份）

### 魔素 = 生命力（卷3 红丸说明）
> 魔素之於魔物，等同生物的生命力。

- 魔素消耗 = 生命力消耗（命名、大战、进化都耗魔素）

## 二、技能获得与进化机制（卷1 原文）

> 只有世界發生改變、獲得技能和技能進化時，「世界之聲」才會發聲。
> 當世界認可當事人有所成長時，才會很難得地獲得「技能」。至於「進化」，一般人根本連想都不用想。

**机制**：
- 技能/进化由**「世界之聲」**（世界法则）赋予，非个人努力可得
- 触发条件：**世界认可当事人成长** → 才"很难得"地获得技能
- 进化比获得技能更稀有（一般人想都不用想）
- 大贤者能"挪用部分世界之聲权限"来回答主角问题（卷1）

## 三、技能三层完整规则

### ① 固有技（Extra）—— 魔物特有技能（卷1 原文）
> 所謂的固有技，似乎是那隻魔物特有的技能。例如我的「融解」、「吸收」、「自動再生」就是固有技。不過，要使用固有技必須擬態成該魔物，否則好像無法發揮百分之百的功力。

- 固有技 = 某魔物种族特有技能
- **使用规则**：必须擬态成该魔物才能 100% 发挥（不擬态可部分活用，威力打折）
- 实例：男主捕食黑蛇后获得"毒噴霧""熱源感應"等固有技

### ② 獨有技（Unique）—— 世界法则级，执念赋予
- 性质：世界意志据执念/成长赋予（前述机制）
- 数量：每人极少数（主角核心 2 个：捕食者、大贤者）
- 详见下节主角獨有技拆解

### ③ 究極技能（Ultimate）—— 獨有技进化终极（卷5 起）
- 性质：獨有技进化后的终极形态
- 进化条件：见 §六

## 四、主角獨有技完整拆解 ⭐（核心）

### 捕食者（5 大子能力，卷1 原文系统说明）

| 子能力 | 原文定义 | 机制要点 |
|--------|----------|----------|
| **捕食** | 將對象物吸入體內。對象仍保有意識時，成功率將大幅減低。發動對象不限於有機物或無機物，**也包括技能及魔法** | 可吞一切（有机/无机/技能/魔法）；**对象有意识时成功率大降**（限制） |
| **解析** | 能解析、研究吸收對象。生成製作可能之道具。物質條件備齊時亦能複製。**成功解析術式後，有機會學習對象技能、魔法** | 解析后可复制道具、学习对方技能/魔法 |
| **胃袋** | 收納捕食對象。亦能保管解析後生成的物質。**收納進胃袋後將不受時間影響** | 异空间储存，时间静止 |
| **擬態** | 能重現吸收對象，行使同等能力。**只限成功解析情報的對象物** | 变形+获得对方能力（需先解析） |
| **隔離** | 收納無法解析的有害效果。將其淨化後還原成魔力 | 净化有害、转化魔力 |

**捕食者额外机制**：
- 默认自动收纳（吸进身体的物质自动进胃袋，可设置开关）
- 与大贤者的**並列演算可连结**（解析 + 演算协同，大幅提升解析力）
- 空间容量大（"使用量未滿百分之一"）
- 可隔离封印强存在（如封印暴风龙维鲁多拉 + 解除无限牢狱）

### 大賢者（5 大功能，卷1 原文系统说明）

| 功能 | 原文定义 |
|------|----------|
| **思考加速** | 將知覺速度提昇至千倍 |
| **解析鑑定** | 解析對象物，進行鑑定 |
| **並列演算** | 能將欲解析的事物與思考區隔開來進行演算 |
| **詠唱排除** | 行使魔法等技能時，無須咒文詠唱程序 |
| **森羅萬象** | 網羅這個世界未受屏蔽的現象 |

**大贤者的性质**（卷1）：
- **被动技，无自我意志**（"它是被動技，並沒有自我意志可言。不找它講話，它就不會主動問"）→ 后期进化为智慧之王后才有人格
- 呈现：**《》系统提示音 + YES/NO 选项 + 自动应答**，"像是電腦的自動語音那樣無機質"
- 与主角灵魂融合花了 90 天，之后才稳定可一问一答
- 挪用"世界之聲"权限来回答

### 擬態（捕食者子能力，但规则复杂，单列）
- 需先**捕食 + 解析**对象，才能擬态
- 擬态后可**行使同等能力**（含对方的固有技）
- **固有技需擬态才 100% 发挥**（不擬态威力打折）
- 擬态大体型魔物 → 主角体积增加
- 部分技能（如熱源感應）不擬态也能用

### 技能协同（卷1 实证）
> 「捕食者」的解析能跟「大賢者」的並列演算連結。

- 多獨有技可组合协同（解析 × 并列演算 = 精准夺取/学习）

## 六、进化体系（实证）

### 进化链
獨有技 →（整合 + 代价）→ 究極技能

### 进化的代价（卷5 原文，修正"无代价"误判）
大贤者→智慧之王：
> 獨有技「大賢者」挑戰進化……失敗。——ENDLESS——
> 獨有技「大賢者」整合「異變者」挑戰進化……成功。進化成「智慧之王拉斐爾」。
> 嘗試次數高達數億，「大賢者」不惜犧牲一切，持續挑戰。

**进化机制**：
1. **整合进化**：两个獨有技整合 → 究极（大贤者 + 異變者 → 智慧之王）
2. **代价由技能承担**：数亿次失败、牺牲一切
3. **技能有心愿**："想回應創造者的心願，渴求進化"（被动技却渴求进化 → 后期人格化伏笔）

### 觉醒魔王（顶级进化，卷5-6）
- 触发：大量人类死亡 + 强烈情感 / 魔王之"宴"（Walpurgis）
- 卷5"魔王誕生"、卷6"魔王盛宴/八星魔王"

## 八、命名机制（实证，详见 17）
- 命名魔物（Named Monster）：被冠名的魔物，进化变强
- **命名消耗命名者魔素（生命力）**——魔王级都不随便命名
- 命名建立主从忠诚

## 九、对融合设计的详实意义

| 原著机制（细则） | 融合到你的项目 |
|------------------|----------------|
| 捕食者5能力（捕食/解析/胃袋/擬態/隔離） | 男主「噬录」可照搬这套结构，但每项加写实代价 |
| 大贤者5功能 + 《》系统提示呈现 | 男主「睿音」借用：系统声 + YES/NO + 主角不信的张力 |
| 擬态需先解析、固有技需擬态才满发挥 | 给变形加限制（不能随便变，要先"理解"对象） |
| 技能协同（解析×演算） | 多能力组合产生新用法 |
| 进化代价（技能牺牲式） | **放大转移到主角**：主角为进化付不可逆代价 |
| 魔素=生命力，命名耗魔素 | 命名/进化的代价直接挂钩生命力 |
| 魔素浓度反常识（淡区史莱姆更强） | 可设计你的底层魔物在恶劣环境逼出强的反差 |
| 世界认可成长才给技能 | 技能获得挂"成长认可"，不是随便升级 |
