## 一、人类

| 类别 | 说明 |
|------|------|
| 普通人类 | 无先天能力，靠修炼魔法/武术变强 |
| 觉醒者/强者 | 修炼或神圣术成为圣骑士/勇者候选 |

| 种族 | 形态 | 备注 |
|------|------|------|
| 哥布林 / 矮人族 | 小型人型 | 常见底层魔物 |
| 牙狼族（岚牙） | 狼型 | 战力中坚 |
| 蜥蜴人 | 蜥蜴型 | 擅沼泽/战术 |

| 大鬼族 / 食人魔 | 高战力人型 | 红丸、紫苑、朱菜等（男主核心干部出身） |
| 巨人族 | 巨人型 | 达格里尔系 |
| 有翼族 / 天狗 | 飞行型 | — |

**底层魔物**（对应你故事里"妹妹是底层魔物"）：指哥布林、弱小亚人、未进化的小型魔物——被人类猎杀取晶、居于森林边缘的最底层。

## 三、龙种（真龙种）——世界顶层存在之一

近乎永生、战力极高，是世界秩序的基石。

| 龙种 | 属性 | 定位 |
|------|------|------|
| **维鲁多拉**（暴风龙） | 风/暴风 | 被封印在朱拉的龙，男主最早伙伴 |
| 维鲁莎（白雪姬） | 冰 | 强战力龙种 |
| 维鲁格林德（灼热龙） | 火 | 强战力龙种 |
| **维鲁达纳瓦**（星王龙） | 创世 | 最强龙种，世界创世者，已逝 |

龙种是「中深层」战力锚点。

## 七、种族关系（核心主题焊接点）

### 人魔仇恨循环 ⭐
> 人类猎杀魔物**取魔晶** → 魔物**报复**人类 → 双方失去至亲 → 仇恨加深 → 再猎杀再报复。
> **某些势力故意维持这个循环**（人类侧靠战争维持权力/资源，魔物主战派靠仇恨凝聚族群）。

这是：
- 转生史莱姆的核心种族主题
- 与《这次不一样了》"体系压迫/历史循环"的天然焊接处
- 男主"人魔共存"理想要打破的东西

### 命名进化
魔物被强者**赐名**可进化为更高种族（详见 08 能力体系）。

## 八、可融入要点（给改编）

1. **"妹妹 = 底层魔物"**：选哥布林/弱小亚人/未进化黏体型，处于被猎杀取晶的最底层
2. **"男主 = 史莱姆（胶质）"**：最弱魔物反差 hook，直接沿用
3. **人魔仇恨循环**作为全书主线主题，男主共存理想的对立面
4. 龙种/恶魔/天使作为中后期战力阶梯分层引入
