# 设定集拆解 08 · 能力体系（含金手指 / 命名 / 进化 / 魔法）

> 《转生史莱姆》能力体系详拆。这是全书最核心、最被借鉴的部分。
> 细节/数值建议核对原作。

---

## 一、能量基础

| 能量 | 说明 |
|------|------|
| **魔素** | 世界的能量介质，魔物/魔法的能量来源；魔素量决定魔物等级 |
| 灵子 | 更底层的粒子 |
| 神之核 / 神之怒 | 究极级能量，顶层战力介质 |

**魔素量**是衡量魔物战力的核心硬指标。

---

## 二、技能三层体系 ⭐（核心）

| 层级 | 性质 | 获得方式 | 拥有者 |
|------|------|----------|--------|
| **固有技能**（Extra） | 强力技能 | 修炼/天生 | 普通强者 |
| **独特技能**（Unique） | 世界法则级，近神授 | **世界意志据执念/愿望赋予** | 天选者 |
| **究极技能**（Ultimate） | 世界法则的具象 | 独特技能**进化**的终极形态 | 顶层战力 |

**关键规则**：
- 独特技能反映持有者的**核心执念**（如暴食、智慧、变化）
- 究极技能是独特技能的完成形态
- **执念/愿望越强，技能越强**——这是「挚友愿望召唤男主」可挂载的世界观逻辑

---

## 三、命名（赐名）机制 ⭐

| 规则 | 说明 |
|------|------|
| 赐名进化 | 强者给魔物「赐名」→魔物大幅进化 |
| 主从关系 | 被命名者效忠命名者，形成从属 |
| 命名代价 | 消耗命名者的魔素/力量 |
| 收编公式 | 男主靠命名把战败魔物收为部下并使其进化（一举三得：消威胁 + 增战力 + 得忠心） |

典型：男主给大鬼族红丸等赐名 → 他们进化为高战力干部。

---

## 四、魔物进化链 ⭐

```
弱小魔物 → 命名/积累 → 高位魔物 → 魔王种 → 觉醒魔王（真魔王）
```

### 觉醒魔王（顶级进化）的触发条件
| 条件 | 说明 |
|------|------|
| 大量人类死亡 + 强烈情感 | 男主的觉醒契机（暴怒屠猪头将军的猪）——全书最好的进化设计（有代价有情绪） |
| 魔王之「宴」 | 数位魔王齐聚引发连锁觉醒 |

进化伴随**能力飞跃**（获得究极技能）。

---

## 五、魔法体系

| 类型 | 说明 |
|------|------|
| 精灵魔法 | 借高位精灵之力 |
| 召唤魔术 | 召唤恶魔/精灵 |
| 神圣魔法 | 教会系，对魔物特攻 |
| 气息 / 斗气 | 武术能量 |
| 魔法咏唱 / 魔法阵 | 施法方式 |

---

## 六、战力评定（自由公会 rank 体系）

- 魔物威胁等级：**E / D / C / B / A / 特S**（及灾害级 S+）
- 冒险者 rank：对应任务等级
- 作用：给世界一个客观战力标尺，便于安排反派阶梯

---

## 七、男主金手指三件套 ⭐（详细）

| 技能 | 暂名（本项目） | 功能 | 进化形态（究极） |
|------|----------------|------|------------------|
| **大贤者** | 睿音 | 解析万物、自动解题、世界语言接口 | 智慧之王（拉斐尔） |
| **捕食者 / 暴食者** | 噬录 | 吞噬、解析、隔离、复刻目标能力 | 暴食之王（别西卜） |
| **变化师** | 拟态 | 拟态变形 | 变质家 |

### 世界语言（世界之声）
大贤者作为「世界语言」的接口，向男主播报信息（进化提示、状态解析等）——这是「系统提示」风味来源。

### 究极技能（后期）
男主集齐多个究极技能：智慧之王[拉斐尔]、暴食之王[别西卜]等。

---

## 八、可融入要点（给改编）

| 机制 | 融入方式 |
|------|----------|
| 技能三层 + 独特技能由执念赋予 | 直接用——**挚友的愿望召唤男主**就挂这个逻辑 |
| 命名收编公式 | 直接用——男主壮大势力的核心引擎 |
| 觉醒魔王（有代价版进化） | 用作男主进化节点，契机绑定妹妹相关重大失去 |
| 金手指三件套 | 专名重命名（睿音/噬录/拟态），**写实化处理**（见融合设计 §7） |
| 魔素/rank 体系 | 用作客观战力标尺 |
| 魔法体系 | 精灵/神圣/召唤可按需引入 |

### ⚠️ 必须重建代价（深拆 04 结论）
原作代价机制缺失（吞噬无反噬、大贤者全知、进化无代价）。融入时用写实笔法注入代价感，否则重蹈战力通胀坑。
