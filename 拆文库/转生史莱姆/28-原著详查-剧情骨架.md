# 原著详查 28 · 剧情骨架（详实版）

> 替代浅版 `20`。关键转折卷有原文实证，其余卷为章节标题级事件流（标注）。

---

## 卷1：转生 → 第一个朋友（实证）
- **三上悟，37岁**，"為了保護差點被隨機殺人魔拿刀刺的學弟，結果被捅了"——转生起因
- 死前听到世界之声（"被人左一句賢者右一句大賢者耍弄"）→ 转生为史莱姆 + 获獨有技（捕食者/大贤者/擬態）
- **遇暴风龙维鲁多拉**（被封印）→ 互相命名（坦派斯特/利姆路）= 平等灵魂羁绊
- **静（静江·伊泽）**：日本人穿越者，与男主同乡（"果然跟我來自同一個地方"），有请求托付男主
- 哥布林村救援 → 命名哥布林/牙狼 → 进化（哥布林→滾刀哥布林）

## 卷2：建国 → 大同盟（章节级 + 实证）
- 大鬼族（红丸等）命名收编 → 色彩干部群成型
- 猪头族来袭 → "絕對吞食者" → 朱拉森林大同盟建国

## 卷3：国名 → 魔王来袭（章节级）
- 国名"特恩佩斯特" → 蜜莉姆登场（龍魔人，远古魔王，为打发时间来玩）
- 暴风大妖渦（精神生命体，需肉体同化）→ 男主收服

## 卷4：交易 → 迷宫 → 被召唤的孩子（章节级）
- 兽王卡利翁交易、人类国度（布尔蒙）、迷宫大冒险
- **"被召唤的孩子"** = 穿越者孩子（静的遗愿相关）

## 卷5：魔王誕生 ⭐（实证 + 章节级）
- **"毀滅之日"**：克雷曼阴谋（用繆蘭监视、与法尔姆斯/圣教会勾结袭击男主国）
- **静之死**（关键情感引爆）→ 男主暴怒
- 觉醒魔王**需人类魂魄** → 男主屠戮袭击者（猪头大军?）→ 收集魂魄
- **觉醒真魔王** → 获得智慧之王/暴食之王/誓约之王/暴风之王四究极 + 10固有技 + 6抗性
- **复活**紫苑等（进化祝福连带伙伴）

## 卷6：魔王盛宴 → 八星魔王 ⭐（实证）
- **克雷曼召开 Walpurgis**（名目："朱拉新势力妄自以魔王自居"，时机：新月针对瓦倫泰）
- 目的：夺卡利翁领土、削减圣教会与男主
- 十大魔王名单揭晓（见 27）
- 男主跻身 → 八星魔王成型

## 卷7：圣魔激战（章节级）
- vs 日向（圣骑士团长，穿越者，现实主义）→ "聖魔激戰" → 卷8和解

## 卷8–10：建国 → 开国祭 → 迷宫运营（章节级）
- 各国建交、謁見典礼、开国祭 + 武斗大会、迷宫运营 + 评议会

## 卷11：勇者覺醒（实证片段）
- **格蘭貝爾・羅素**：前"七曜長老"之首、**前"光之勇者"**、与魯米納斯作战过 → 内贼
- **迪亞波羅**（原初恶魔）登场，效忠男主
- 勇者觉醒线 + 西方动乱

## 卷12–13：帝国大战 ⭐（章节级 + 实证）
- **东之帝国魯德拉**出动（纳卡统一帝国，神秘皇帝）
- 迷宫攻防战 → 完全胜利

## 卷14–15：帝都 → 皇帝真相 ⭐（实证）
- 紅蓮之肅清、**天上游戏**（天使介入）
- 卷15 **"皇帝的眞相"**：近藤中尉（皇帝近卫）、卡嘉莉进行仪式、維爾格琳守卫
- 灼热龙 vs 暴风龙

## 卷16–17：秩序崩坏（章节级）
- 秩序崩坏、背叛、**金·克林姆兹**终章、青色恶魔（迪亚波罗）

## 卷18：天帝與原勇者 ⭐（实证）
- **天帝艾爾梅西亞**（魔導王朝薩里昂）+ 替身希爾維亞（容貌相同交替扮演）
- **雷昂·克倫威爾 = 原勇者**（前人类→勇者→魔王）——"勇者真相"核心
- **金离开永久冻土**（大事件，魔王异动）
- 魔王宴会后势力重组

## 卷19：天使行动（章节级）
- **天使长行动、正义军团**：天使终局展开

## 卷20：莉姆露消失 ⭐（实证）
- **米迦勒死**（始原七天使，費爾德維的至交，"並列存在"却未复活）
- 米迦勒临终："朕的願望實現了"
- **費爾德維**（始原七天使之首）祈祷**維爾達納瓦（创世龙）复活**——天使终极目标
- 究极"正義之王"、神智核
- 莉姆露消失（主角终局）

## 对融合设计的详实意义（更新 05/12）

| 原著剧情节点 | 你的故事对应 |
|--------------|--------------|
| 卷1 三上悟护人被捅转生 | 男主转生契机（可借鉴"为他人牺牲"的动机） |
| 卷1 静=穿越者同乡+遗愿托付 | **挚友勇者=穿越者同乡+召唤愿望**的原始模板 |
| 卷5 静死→暴怒→觉醒（痛→爆） | 男主进化节点绑定妹妹相关重大失去 |
| 卷11/18 格蘭貝爾/雷昂=原勇者真相 | **勇者真相揭幕**——你的挚友勇者真相可借鉴这种多层揭幕 |
| 卷18 天帝替身（艾爾梅西亞/希爾維亞） | 身份替身机制可借鉴 |
| 卷20 天使复活创世龙維爾達納瓦 | 终局幕后目标参考（你的"维持人魔循环的幕后"终极目的） |
| 卷20 米迦勒=費爾德維至交却消失 | 反派间的情感（让反派有人性面） |
