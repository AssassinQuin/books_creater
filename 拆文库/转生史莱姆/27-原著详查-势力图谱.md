### 各魔王详解
- **金·克林姆兹**：恶魔族之首，原初恶魔之王，暗黑皇帝，议会核心

- **雷昂·克倫威爾**：白金剑王，**前人类**出身的魔王（人类→魔王的跨越）

## 二、Walpurgis 魔王盛宴机制（卷6 实证）

### 召开规则
- 魔王可借**名目**召开魔王盛宴（Walpurgis）
- 名目 = 借口（克雷曼用"朱拉有新势力妄自以魔王自居"为名）
- 时机选择有策略（克雷曼挑新月=瓦倫泰最弱日）

### 目的与权谋
- 借魔王盛宴**除掉对手/夺取领土**（克雷曼想夺卡利翁领土、削减圣教会与男主力量）
- "放敌人自相残杀"
- 觉醒魔王**需要人类魂魄**（"既然知道觉醒需要人类的魂魄，对弱者就用不着客气"）

### 议会性质
- 魔王间的政治博弈场所，非单纯武力对决
- 名目/时机/联盟 = 权谋要素

## 三、人类势力（详，实证）

### 西方聖教會
- 首要任务：**歼灭魔物**（"殲滅魔物才是首要之務"）
- 信仰：魯米納斯神（"魯米納斯神不容許世上出現任何魔物"）
- ⚠️ **巨大讽刺**：魯米納斯实际是**吸血鬼魔王**（羅伊·瓦倫泰或相关），圣教会信奉的神是魔物——**幕后真相式设计**

### 坂口日向（圣骑士团长）⭐
> 她居然是聖騎士團的首領──聖騎士團團長……「異界訪客」到這個世界會獲得特殊能力。她是否靠那股力量登上地表最強騎士團的頂點？

- **异界访客（穿越者）**——靠穿越获得的特殊能力成为最强
- **现实主义者**："追求合理性，只要有效，就会不择手段去做"
- 静的徒弟（"离开静小姐时已经够强"）
- 与男主对立（卷7 圣魔激战）

### 靜（静江·伊泽）
- 日向的**师傅**
- 有**遗愿**（保护被召唤的孩子，男主继承"靜小姐的遺願"）
- 勇者线核心，卷1登场，重要情感锚点

### 自由公会
- 与圣教会建在一起，**异界访客据点**（有玻璃门等现代元素）
- 冒险者/猎人组织，任务/等级评定

### 人类诸国
- 英格拉西亚王国（日向所在）、法尔姆斯、布尔蒙等
- "人类国家鲜少派兵攻打对方"（外部魔物威胁→人类内部相对和平）

## 七、对融合设计的详实意义（更新 09）

| 原著势力/机制 | 融合方式 |
|---------------|----------|
| **日向=异界访客穿越者→人类最强** | ⭐ **直接原型你的"挚友勇者"**——穿越者靠特殊能力成为人类阵营最强，与魔物男主对立 |
| 静-日向师徒 + 遗愿 | 勇者线可加师徒/遗愿传承层 |
| **魯米納斯=魔王被奉为神（讽刺）** | ⭐ 借鉴"幕后真相"——你的人类教会信奉的神可能是魔物/幕后（焊接体系压迫主题） |
| 十大魔王=各族代表+称号 | 魔王议会设计模板（种族多元+象征称号） |
| Walpurgis 权谋（名目/时机/联盟） | 魔王博弈可做政治戏，非纯武力 |
| 觉醒魔王需人类魂魄 | 进化代价的残酷绑定（你的写实版可强化） |
| 雷昂=前人类魔王 | 人魔跨越的可能（呼应你的"人魔共存"理想） |
| 东之帝国魯德拉（神秘皇帝） | 后期大国对手参考 |

### 给"挚友勇者"的详实原型（重要）
日向提供了完整模板：
- **穿越者**（异界访客）获特殊能力 → 成为人类最强
- 现实主义、不择手段（为目的）
- 与魔物男主对立（立场）
- 有师傅（静）+ 信仰/遗愿牵绊
- 后期可与男主和解（卷8和解协定）

你的挚友勇者可直接借鉴：穿越→人类最强→与男主（魔物）对立→召唤真相→和解/对决。
