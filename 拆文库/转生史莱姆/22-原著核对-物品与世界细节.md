## 一、魔素 → 魔石体系（卷1 实证，核心物品链）

原著对能量/物品体系有明确设定（卷1）：

> 「魔素」是構成這個世界的要素。前世那邊沒有魔素，它在這個世界裡扮演重要角色。
> 打倒魔物後，很罕見地會掉名為「魔石」的魔素結晶。魔石類似能量聚集物，會用在**精靈工學**──這個世界特有的發明物上，拿來當燃料。
> 高階魔物的核心魔石，比寶石還要美麗...用來當作各種產品的基核...讓使用者能力上升，追加附屬效果。
> 「魔礦石」...只能在高階魔物附近採到...生長在魔素濃度高的地方。

**物品链**：
```
魔素（世界基础能量）
  → 魔物（魔素构成/栖息于高魔素区）
    → 魔石（打倒魔物掉落的魔素结晶）/ 魔礦石（高魔素区矿石）
      → 精靈工學（以魔石为燃料的发明体系）/ 工艺基核（装饰/能力加成装备）
```

**关键**：魔石既是能量、又是经济、又是装备基核——**一件物品串起能量体系 + 经济 + 工艺 + 人魔关系**（猎杀魔物取石）。

---

## 二、精灵工学（世界特有发明体系）

- 以魔石为燃料的这个世界特有技术
- 发明物/机械/装置都依赖魔石
- 这给世界一个统一的"科技树"基底（魔石驱动）

---

## 三、迷宫（卷8 实证，副本经济）

- 拉米莉丝的迷宫，有管理角色（德蕾妮管理、贝瑞塔运营）
- 是实体设施，有运营、产出、试炼功能
- 卷8-13 迷宫戏份密集（迷宫攻防战等）

**机制**：迷宫 = 副本 + 资源产出 + 训练场 + 防御工事（多用途种田设施）。

---

## 四、命名物品 / 装备

- 被命名的装备/武器有特殊力量（命名机制延伸到物品）
- 黑兵衛（工匠）打造的武器（如给哥布达的武器承诺）
- 高阶魔石嵌入装备 = 能力上升 + 附属效果

## 六、对融合设计的意义（更新 14）

| 原著物品/细节 | 融合方式 |
|---------------|----------|
| 魔素→魔石→精灵工学链条 | 直接用：能量+经济+工艺+人魔仇恨一件物品四绑 |
| **魔石=猎杀魔物取得** | 人魔仇恨循环的实物根源（你的主题焊接点） |
| 精灵工学（魔石科技树） | 给你的世界一个统一技术基底 |
| 迷宫（副本经济） | 种田引擎直接移植 |
| 命名装备 | 命名机制延伸到物品 |
| 铜板/底层经济 | 用《这次不一样了》的精确经济写实 |

### 给"妹妹的病"的物品锚点（呼应 05 待确认项）
妹妹的病可以用**魔石/魔素相关设定**落地：
- 选项：魔素枯竭症（底层魔物缺魔素而衰）／需要高阶魔石续命（被垄断资源）／命名前的退化（未被命名=未进化的衰弱）
- 这让"治病"直接挂钩主线资源体系（魔石/命名/势力垄断），男主行动动机与世界运行绑定

**关键**：原著物品不是装饰，是"世界运行的零件"。你的每个物品都该参与世界运转（尤其魔石=人魔仇恨实物象征）。
