## 一、能量-物品完整链条（卷1 实证）⭐

```
魔素（世界基础要素）
  → 魔物（魔素构成/栖息高魔素区）
    ├→ 魔石（打倒魔物罕见掉落的魔素结晶）
    │   └→ 精靈工學燃料 / 工艺基核
    ├→ 高阶魔石（高阶魔物核心，比宝石美）
    │   └→ 装备基核（能力上升 + 附属效果）
    └→ 魔礦石（B级以上魔物附近，矿石吸魔素变质）
        └→ 魔鋼（提炼，仅3-5%）
            └→ 魔法武具材料（诱导魔力）
```

### 各物详解（卷1 原文）
| 物品 | 性质 | 用途 |
|------|------|------|
| **魔石** | 打倒魔物罕见掉落的魔素结晶，能量聚集物 | 精靈工學燃料 |
| **高阶魔石** | 高阶魔物核心，比宝石美，能量大 | 工艺品基核（能力上升/附属效果） |
| **魔礦石** | B级以上魔物附近采集（矿石吸魔素变质，"類似礦物突變"） | 提炼魔鋼原料 |
| **魔鋼** | 从魔礦石提炼，**仅3-5%产出** | 魔法武具核心材料 |

## 二、精靈工學（世界特有技术，卷1 实证）

- 以**魔石为燃料**的这个世界特有发明体系
- 发明物/机械/装置都依赖魔石驱动
- 给世界统一的"科技树"基底（魔石驱动一切）

## 三、经济体系（卷1 实证，详）

### 金本位（卷1 原文）
> 這世界還採用金本位制（每單位貨幣價值等同若干含重量的黃金）。

- **金币**为交易媒介（黄金值钱，各国通用基准）
- 物价实例：5个回复药 = 25金币（男主初交易被坑）

### 魔鋼的价值（卷1 原文）⭐
> 魔鋼塊的價值卻比等大金塊貴二十倍以上。
> 魔鋼會這麼貴不單只是它稀有。真正值錢的原因是──性質上很適合誘導魔力。

- 魔鋼价值 = 等大黄金的 **20倍以上**
- 值钱原因：**适合诱导魔力**（魔法装备核心材料）
- 稀有（魔礦石仅B+魔物区产，提炼仅3-5%）

### 经济循环
- 普通货币（金币）+ 稀有魔法材料（魔石/魔鋼）
- 冒险者打魔物 → 魔石/魔礦石 → 卖矮人/工匠 → 魔法武具/精灵工学产品

## 四、魔法武具 / 装备（卷1 实证）

### 武具规则
- **魔法武具**：乱碰会失去价值，需专业处理
- 哥布林无法用人类武具（太大 + 无金属加工技术）→ 卖矮人
- 硬皮鎧可分解利用；金属鎧难处理

### 打造体系
- **矮人**：金属加工工艺种族，矮人王国（洞窟），打造/配送金工品
- 黑兵衛（男主干部工匠）：打造武器
- 魔鋼 = 魔法武具核心（诱导魔力）

## 六、药与日常物品（卷1 实证）

### 希波庫特藥草（卷1 原文）
> 希波庫特藥草：傷藥的原料。只在魔素濃郁的地方生長。混合藥草汁液與魔素後會變成回復藥。將葉片搗爛，跟魔素混合後，能製成塗抹傷口的軟膏。

- 只长在魔素浓郁处
- 草汁 + 魔素 = 回復藥
- 叶捣烂 + 魔素 = 軟膏
- 男主用捕食者解析 + 大贤者并列演算，体内制药（连结后5分钟100个，不连结50分钟1个）

### 物品-技能协同实证
制药效率对比印证"技能协同"（解析×并列演算）的实际效用。

## 七、物品嵌入世界运行（四绑，总结）

| 维度 | 物品如何参与 |
|------|-------------|
| 能量 | 魔石=精灵工学燃料，驱动世界科技 |
| 经济 | 金本位 + 魔石/魔鋼（20倍金价）稀有材料市场 |
| 工艺 | 高阶魔石/魔鋼 = 装备/武具基核 |
| 冲突 | 魔石/魔礦石 = 猎杀魔物取得 → **人魔仇恨的实物根源** |

**一件物品（魔石）串起能量+经济+工艺+人魔仇恨四层**——这就是转生史莱姆物品设计的精髓。

### 给"妹妹的病"的详实落地（呼应 05 待确认项）
基于原著物品体系，妹妹的病有具体可落地的方案：
- **魔素枯竭症**：底层魔物在低魔素区衰弱（魔素=生命力，缺则衰）
- **需高阶魔石续命**：被垄断资源（魔石=猎杀魔物取得，底层得不到）→ 男主为妹必须打破垄断/猎杀/夺资源
- **需命名进化才能治**：命名前的退化衰弱（未被命名=未进化=衰）→ 男主命名妹妹可治，但命名耗魔素（男主的代价抉择）
- **魔鋼/精灵工学相关**：人造器官/魔力诱导体维持

这把妹妹的病直接挂到世界物品体系（魔石/命名/精灵工学），男主行动动机与世界运行深度绑定。
