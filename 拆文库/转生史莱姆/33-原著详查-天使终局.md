## 一、创世神话（卷16 实证）⭐

### 创世链条
```
星王龍 維爾達納瓦（创世神/龙种之首）
  → 创造天使族（无自我意识）
    → 七上位个体·熾天使 → 获赐名 → 始原七天使（近神存在）
      → 协助创造各族：
         ├─ 巨人族（大地化身，狂王=達格里爾）
         ├─ 妖精族（行星管理者，女王=拉米莉絲原名）
         ├─ 吸血鬼族（神祖，构筑文明=魯米納斯/瓦倫泰系）
         └─ 人类（通过"别次元并列世界"联动诞生）
```

> 為了幫助維爾達納瓦的作業而創造出來的沒有自我意識的天使族，其中的七個最上位個體熾天使...在得到維爾達納瓦賜予名字之後，成為了近乎於神一樣存在的『始原七天使』。

## 二、始原七天使（卷16 实证）

### 七天使之首：費爾德維
> 七天使之首正是之後成為妖魔族始祖的費爾德維。得到名字擁有自我意識後，費爾德維就向維爾達納瓦宣誓了效忠。

### 分化（卷16）
- **隨費爾德維去异界**（变异为**妖天族/妖魔族**）：費爾德維、札拉里奧、歐貝拉、克爾努
- **留維爾達納瓦身边**：3人
- **迪諾**（墮天族魔王/"幽眠支配者"）也是始原七天使之一！"其實，我也曾經是『始原』之一...監視地上的任務就落到了我頭上"——他是**地上监视者**，伪装成魔王议会的"累赘"

### 关键
- 始原七天使散布各方：妖魔王（費爾德維）、魔王议会（迪諾潜伏）等
- 都效忠維爾達納瓦，目标是复活他

## 三、龙种 / 圣灵体系（卷14 实证）⭐

> 比精靈更上位的是聖靈，聖靈也有八種。而在聖靈當中最上位的就是『龍種』，目前能確認到的，就只有四隻『龍種』。

### 四龙种（属性）
| 龙种 | 属性 |
|------|------|
| **星王龍 維爾達納瓦** | 空间+大地（星=更多属性可能）；创世神 |
| **白冰龍 維爾莎多** | 水 |
| **灼熱龍 維爾格琳** | 火 |
| **暴風龍 維爾德拉** | 水+风+空间 |

### ⭐ 蜜莉姆 = 維爾達納瓦之女
> 自蜜莉姆出生，『星王龍』維爾達納瓦消失後...

- 維爾達納瓦在蜜莉姆出生后消失
- 蜜莉姆=龍魔人（继承星王龙血脉），远古魔王
- 这解释了蜜莉姆"特S级/曾灭一国"的战力来源

## 四、金 vs 魯德拉：二千年斗争（卷14 实证）

> 帝國的皇帝魯德拉和金好像進行了二千年以上的鬥爭...自蜜莉姆出生、維爾達納瓦消失後，雙方就變得收斂了起來。

- 金与魯德拉斗争 **2000年以上**
- 維爾達納瓦消失后，双方收敛（不全开战，因对世界影响过大）
- 金"維持世界平衡，增加棋子，等魔物进化"
- 八星魔王中无人知金的真心（连蜜莉姆都不知金与魯德拉的游戏）

**金的目的**：维持世界平衡，对抗魯德拉（=米迦勒）的复活计划。

## 五、米迦勒夺舍 + 复活计划（卷15 实证，完整）⭐

### 夺舍真相
- 米迦勒（始原七天使）占据东之帝国皇帝魯德拉的身体
- 卷15 原文："我的敵人不是魯德拉，是米迦勒"
- 魯德拉身体里飞出物质（米迦勒的力量）

### 复活維爾達納瓦计划
> 維爾格琳的力量已成了朕的東西，魯德拉也消失了。接下來，只要再吸收維爾德拉和維爾莎多的力量，就能實現復活那位大人的願望了。

**步骤**：
1. ✅ 吸收維爾格琳（灼热龙，卷15）
2. ⏳ 吸收維爾德拉（暴风龙）——"麻煩的是維爾德拉"
3. ⏳ 吸收維爾莎多（白冰龙）——"對於維爾莎多，總會有辦法"
4. → 完全复活星王龍維爾達納瓦

### 手段
- **'王權發動'**：夺取目标精神意志（卷15 对维鲁多拉使用）
- **'神滅彈'**：伤龙种
- **'王宮城塞'**：绝对防御
- 米迦勒与魯德拉交换究极：米迦勒'正義之王' ↔ 魯德拉'誓約之王'

## 六、究极技能体系（天使系，卷15-16 实证）

| 究极 | 持有者 | 性质 |
|------|--------|------|
| **正義之王** | 米迦勒（原魯德拉处交换） | 绝对支配天使系究极 |
| **天使長的支配** | （正義之王对极） | 支配所有天使系技能持有者（无法反抗"兄长"維爾達納瓦构建的机制） |
| **救恤之王** | 維爾格琳 | 被正義之王通过"迴廊"支配 |
| **誓約之王烏列爾** | 魯德拉→男主 | 与正義之王成对 |
| **王權發動** | 米迦勒/魯德拉 | 夺取精神意志 |

**机制**：維爾達納瓦构建的天使系技能体系，所有天使系究极持有者**无法反抗正義之王**（兄长的绝对支配）。

## 七、卷15/20 终局（实证）

### 卷15：维鲁多拉危机
- 魯德拉（米迦勒）用'神滅彈'伤维鲁多拉 + '王權發動'欲夺其精神

## 八、对融合设计的意义（你的"远古幕后"原型）⭐

| 原著机制 | 融合方式 |
|----------|----------|
| **创世龙維爾達納瓦消失→天使谋复活** | 你的"远古存在/创世级力量消失→幕后谋复苏" |
| **米迦勒夺舍人类皇帝** | 你的幕后"夺舍人类高层"操控局势 |
| **吸收龙种/圣灵力量复活创世神** | 幕后收集特定力量复苏远古存在 |
| **始原七天使散布各方潜伏**（迪諾伪装魔王） | 你的幕后"潜伏多方势力" |
| **金 vs 魯德拉2000年斗争** | 守护方 vs 复活方的长期博弈 |
| **天使系究极的"绝对支配"机制** | 幕后力量的法则级控制 |
| **魂之迴廊（莉姆露-维鲁多拉，一活则不灭）** | 主角与强存在的灵魂绑定 |

### 给你的终局设计
- **幕后终极目的**：复活/复苏某个远古存在（对应人魔仇恨循环的根源——可能是某远古存在死后其"恨"化作循环）
- **幕后手段**：夺舍人类皇帝/教皇，操控人魔战争收集力量
- **守护方**：金的对应——一个维持平衡的远古存在/魔王
- **主角绑定**：与某强存在（维鲁多拉式）的灵魂绑定，是终局关键
