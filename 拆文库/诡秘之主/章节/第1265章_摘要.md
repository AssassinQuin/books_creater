**逐章写法公式**：

- **情绪流向**：起：净化痛苦 → 承：危机加剧（侵蚀脱离 + 阿蒙出现） → 转：意外转折（石板被偷） → 合：悲壮余波（科林消逝）
- **节奏配比**：慢铺垫 15% / 快冲突 55% / 爽点爆发 10% / 悬念留白 20%
- **本章结构公式**：净化收束（克莱恩承受痛苦） + 侵蚀危机（阴影巨手抓石板） + 阿蒙窃取（释放力量吸引石板） + 战士归途（科林消逝戴里克哀悼）
- **本章核心技巧**：危机一线多股势力同时切入，在主角无力阻止时完成关键事件的意外转折
- **卡点与伏笔**：结尾卡点：科林消逝的悲壮场景 + 戴里克的哀悼（戴里克未来的成长方向）；埋设/回收伏笔：阿蒙窃取亵渎石板的目的未知 → 后续阿蒙与克莱恩的对抗；克莱恩仅瞥见诡秘侍者配方 → 寻找其他途径获得配方
