**逐章写法公式**：

- **情绪流向**：起：准备进入巨人王居所的谨慎 → 承：无法看透的压抑 + 战场激战的紧张 → 转：天空异变的震撼 → 合：天变降临的震撼与悬念
- **节奏配比**：慢铺垫 40% / 快冲突 35% / 爽点爆发 15% / 悬念留白 10%
- **本章结构公式**：克莱恩治疗与观察（评估风险） + 对话确认无法召唤投影（做出决策） + 亲自进入深暗（行动） + 贝克兰德战场平行推进（危机升级） + 天空异变（震撼转折）
- **本章核心技巧**：双线并进+升级，巨人王居所线的"试探失败→被迫冒险"与战场线的"单人战斗→规模升级→天变降临"同步推进，用天空异象作为两线的交汇点
- **卡点与伏笔**：结尾卡点：天变降临，战场所有人沉眠，后续发展未知；埋设/回收伏笔：暗天使的深暗力量→历史投影无法进入，克莱恩必须亲自冒险
