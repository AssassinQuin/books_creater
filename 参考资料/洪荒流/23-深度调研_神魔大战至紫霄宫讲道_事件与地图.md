# 深度调研：神魔大战 → 紫霄宫讲道 事件时间线与洪荒地图

> 调研日期：2026-08-20。来源：知乎、百度百科、B站、起点/QQ阅读等全网公开资料（文末附来源清单）。
> 用途：为《我红云绝不赴死》设计"神魔大战期间→紫霄宫讲道"这段前史/卷间剧情提供事件骨架与地图参照。
>
> **最重要的前提**：洪荒流是网文同人体系，没有钦定正史。《佛本是道》（梦入神机，2006）是源头，此后《仙道厚黑录》《重生混元道》《悠悠洪荒》等不断叠加设定。**"小事可改，大势不可改"**是这一流派读者的默认契约——事件顺序的大框架有共识，但每个事件的细节几乎都有 2~4 个流行版本。本文以"主流共识 + 分歧标注"的方式整理。

---

## 一、时间单位体系（先立标尺，否则没法排事件）

洪荒流通行的时间单位（多部作品一致，出自邵雍《皇极经世》的元会运世体系）：

| 单位 | 换算 | 备注 |
|---|---|---|
| 一世 | 30 年 | |
| 一运 | 12 世 = 360 年 | |
| 一会 | 30 运 = 10,800 年 | |
| **一元会（一元）** | 12 会 = **129,600 年** | "一元复始之数"，洪荒叙事的基本单位 |
| 一量劫 | **五万元会 = 64.8 亿年** | 量劫=天道清算因果的周期，每逢量劫必有大劫 |
| 一无量量劫 | 4 亿 8 千万量劫 | 一方世界的生灭周期；圣人合道可渡 |
| 紫霄宫三讲节奏 | 一讲三千年，讲间三千年，前后约一万八千年 | 音荷师太版细节；鸿钧预告"一万八千年后身化天道" |

设计建议：写这段前史时**只需要用"元会"做单位**（"三族大战打了数十元会""红云在某某山闭关一元会"），量劫是跨度单位，中间的叙事粒度用元会最顺。

## 二、事件时间线（六大阶段）

### 总览（主流共识顺序）

```
混沌纪元 ──→ ①开天量劫(神魔大战) ──→ ②凶兽量劫 ──→ ③三族崛起·龙汉初劫
                                                        │
紫霄宫三讲·分宝·合道 ←── ⑤鸿钧成圣 ←── ④道魔之争(罗睺之乱)
```

⚠️ 两大顺序分歧，写作前必须先拍板：
1. **《佛本是道》原版顺序完全不同**：鸿钧先在混沌中紫霄宫讲道（收盘古、女娲、太一为大弟子）→ 分宝岩散宝 → 盘古奉法旨开天 → 三清/祖巫出世 → 巫妖。即"讲道在开天之前"。后世洪荒流绝大多数把开天挪到最前面，讲道挪到龙汉/道魔之后。
2. **道魔之争与龙汉初劫谁先谁后**：主流是"先龙汉、后道魔"（罗睺借三族大战的煞气修行，被鸿钧等围剿）；也有不少作品写罗睺先乱、三族后战，或两事交织（罗睺同时挑动三族+对抗鸿钧）。**"罗睺挑拨三族+道魔终局"交织版**戏剧性最强，被采用最多。

### 阶段〇：混沌纪元（前史背景）

- 混沌中孕育**三千混沌魔神**，每个魔神即一条大道法则的化身（时间、空间、因果、命运、造化、杀戮、毁灭、阴阳、五行……）。无需修炼，天生执掌一道，总数固定三千。
- **创世青莲（三十六品混沌青莲）**孕育**盘古**——力之魔神，三千魔神之首。
- 知名魔神（后世设定集中出现频率最高的名单）：时辰（时间）、杨眉/扬眉（空间，本体空心杨柳）、命运、因果、造化、杀戮、毁灭、阴阳、乾坤、五行、混沌魔猿，以及罗睺（毁灭/杀戮浊气版）、鸿钧（仙之魔神，一说本体蚯蚓/造化玉碟伴生）。
- 鸿钧在混沌中的角色两说：①只是潜心修炼的魔神之一；②大道显化，先开讲过一次"混沌讲道"（佛本是道原版）。

### 阶段①：开天量劫（=你说的"神魔大战"主体）

- 盘古欲"以力证道"，持开天斧劈混沌。三千魔神（受混沌意志蛊惑/为自保）群起阻道，爆发开天大战，持续数万年（一说数个衍纪）。
- 战况：盘古以力破万法，杀尽魔神；但残存的九位（或十余位）顶尖魔神合力最后一击，重创盘古本源——这为"盘古开天后必陨"和"魔神怨念留祸后世"埋下双种子。
- **盘古身化万物清单**（后世通行的标准分配表）：

| 部位 | 化为 |
|---|---|
| 左眼 | 太阳星 |
| 右眼 | 太阴星 |
| 元神（一气化三） | 三清：老子（太清）、元始（玉清）、通天（上清），降于昆仑山 |
| 十二滴精血（裹浊气） | 十二祖巫：帝江、烛九阴、玄冥、后土、共工、祝融、蓐收、句芒、天吴、强良、奢比尸、翕兹——落洪荒大地 |
| 脊梁 | **不周山**（天柱，立于洪荒中央） |
| 肚脐污血 | **幽冥血海**（后孕冥河老祖） |
| 毛发肌肤 | 草木山川、江河湖海 |
| 呼吸/声音 | 风、雷霆 |
| 开天斧（天道不容其存在而崩碎） | 斧刃→盘古幡、斧背→太极图、斧柄/斧魂→混沌钟 |
| 创世青莲（开花遭天道厌弃而碎） | 红花白藕青荷叶→扁拐/三宝玉如意/青萍剑（三清）；三枚未熟莲子→十二品功德金莲（接引）、十二品业火红莲（冥河）、十二品灭世黑莲（罗睺）；莲茎+天地煞气→弑神枪（罗睺）；土之祖源→九天息壤（女娲） |
| 开天功德 | 天地玄黄玲珑塔（太清伴生）等功德至宝；余者散落 |

- **幸存魔神**：扬眉（空间）、时辰（时间）、命运、乾坤、阴阳、罗睺等以残破元神逃入洪荒，日后化形——他们是下两个量劫的主角。魔神尸气、怨气、煞气沉积极北，成为凶兽量劫的根源。
- 太阳星上生**扶桑木**，太阴星上生**月桂**；先天灵根（人参果、黄中李、葫芦藤、蟠桃等）随开天散落各处。

### 阶段②：凶兽量劫（开天后第一劫，主流版）

- **起因**：三千魔神的怨念+开天残余煞气凝成"凶兽"，无灵智、只知吞噬破坏，席卷洪荒。
- **首领**：兽皇**神逆**——"逆"之道（倒退/逆转）的化身，手持**弑神枪**（一说弑神枪此时尚在罗睺手中，神逆持枪版本更常见）；麾下四大凶兽皇者：饕餮、混沌、梼杌、穷奇。
- **讨伐方**：第一批化形的先天生灵/幸存魔神——**鸿钧、罗睺、扬眉、乾坤、阴阳**等联手（此时鸿钧罗睺尚未反目），会猎于北方**兽神宫**/周山之巅，斩杀神逆。另有版本加入太初神圣、万族联军。
- **结局**：一皇四皇者陨落，亿万凶兽失去统领被围剿，残部遁入**十万大山**与极北。天道正式接管洪荒，降下大功德——这批功德催生了第一代先天神圣（三清、女娲伏羲、镇元子、冥河、东王公、西王母等在此前后陆续化形/出世）。
- 细节钩子：扶桑木化形出世的"扶桑道人"被神逆一击斩成两段、身死道消（残躯分落太阳星与蓬莱），是"凶兽量劫斩杀过先天神圣"的罕见案例——说明神逆的"逆道"克制一切常识性大道。

### 阶段③：三族崛起与龙汉初劫

- **三族起源**（通行两说）：①先天三族由天地元素交融孕生（水+王者之气→龙；火+涅槃之气→凤；土+天地元气→麒麟）；②盘古精血融入天地核心灵脉所化，故三族始祖皆有盘古血脉余泽。
- **分工格局**（战前三族共治）：龙族统鳞甲/水族、霸四海；凤族统飞禽/天空；麒麟统走兽/大地。三族镇压凶兽残患有功，天降功德，气运大涨——**这正是罗睺动手的窗口**。
- **罗睺的局**：他修杀戮魔道，需要以洪荒的无尽怨气、杀气、精血祭炼诛仙剑阵（诛仙、戮仙、陷仙、绝仙四剑+诛仙阵图）以求"以杀伐证圣"。手段：派人暗杀三族族人互相嫁祸、挑动资源与气运之争，把三族拖入全面战争。
- **大战**：万龙大阵对凤族麒麟族联军，主战场席卷洪荒中部（不周山下/中原），山川尽毁、灵脉大面积枯死。地点锚点：**落凤坡**（元凤泣血处）、**麒麟崖**（昆仑山巅，始麒麟葬身处）、东海海眼。
- **结局**（通行度最高的版本）：

| 始祖 | 结局 |
|---|---|
| 祖龙 | 撞毁西方祖脉（一说此即西方贫瘠的第一重原因），自身被永镇于**东海海眼**；元神化龙脉滋养大地，为龙族留一线生机 |
| 元凤 | 于落凤坡泣血哀鸣，立宏愿**永镇南方不死火山**；逃亡途中阴阳交合之气诞下孔雀蛋——即日后的**孔宣**（孔雀大明王）；另有版本再诞金翅大鹏 |
| 始麒麟 | 重伤于昆仑山巅**麒麟崖**身陨/化崖，向天道发愿"麒麟出没，必有祥瑞"为族赎罪；死前把嫡子**四不相（四不像）**托付元始天尊，后为元始坐骑 |

- 三族背负无量业力，几乎灭族，退出天地舞台。罗睺则借大战煞气把修为推到准圣极境（混元金仙巅峰）。
- **注意**：此劫又名"龙凤大劫""龙凤初劫"，名称借自道教"五劫"之首的**龙汉劫**（《度人经》体系：龙汉、赤明、上皇、开皇、延康），小说只是借名，不搬教义。

### 阶段④：道魔之争（罗睺之乱·须弥山之战）

- **性质**：天道要确立洪荒修炼体系的正统之争——仙道（鸿钧）vs 魔道（罗睺），谁赢谁做天道代言人。
- **阵容**：正方四人组——**鸿钧、扬眉、乾坤老祖、阴阳老祖**（皆幸存混沌魔神化形）；反方罗睺一人+诛仙剑阵+弑神枪（+魔道大军/域外天魔雏形）。
- **过程**（通行叙事）：会战于**须弥山**（西方，罗睺道场所在）。罗睺以诛仙剑阵困住扬眉、乾坤、阴阳三祖；乾坤、阴阳伤及本源、自爆破阵；鸿钧一念斩三尸（此战的标志性顿悟，也是他日后传"斩三尸证道"的底气），持造化玉碟残片与罗睺决战。
- **结局**：
  - 罗睺本源受损、成圣无望，遂引**西方祖脉自爆**——"西方灵脉就此贫瘠"，这是日后接引准提"化缘东土"、以及一切"西方因果"的总源头。
  - 罗睺身陨（残魂化域外天魔，永世伺机入侵——伏笔可用）；乾坤、阴阳陨落（悲情配角，网文里常留传承/遗府）；**扬眉重伤远走天外混沌**（他与鸿钧从此心存芥蒂——"扬眉有感鸿钧野心，远走天外"）。
  - 鸿钧获天道降下的至大功德+补全**造化玉碟**，就此成圣（天地间第一位圣人）。
- 部分版本把"鸿钧 vs 扬眉"的一战放在成圣之后（扬眉曾收走鸿钧全部法宝），可做彩蛋。

### 阶段⑤：鸿钧成圣 → 紫霄宫三讲（你问的终点事件）

**成圣宣言**（多部作品共享的画面）：紫气东来三万里，道音贯宇——"吾乃鸿钧，已证天道，成为洪荒圣人。一元之后，我将于混沌深处（三十三重天外）**玉京山·紫霄宫**中宣演大道，洪荒生灵与吾圣道有缘者，皆可前来聆听。"

**紫霄宫的位置**：三十三天之外的混沌之中（一说即混沌深处的玉京山）。非量劫不出，内含**分宝岩**。

**第一讲之前的蒲团之争**（全书派系格局的种子）：
- 鸿钧设**六个蒲团**（少数版本七个），先到先得；传音后百年内到达者有缘（"三千年一讲，讲间三千年"）。
- 主流座次版本：三清（1-3）→ 女娲（4）→ 红云（5）→ 鲲鹏或帝俊/太一（6）；伏羲自知无缘，让女娲独坐；**接引、准提自西方姗姗来迟**（路远+西方灵脉贫瘠赶路慢——又一重西方因果），无座。
- 让座事件通行版：准提当众卖惨痛哭，红云"老好人"发作起身让座，还连带劝（逼）鲲鹏也让——鲲鹏被挤下席位，与红云结下死仇；元始天尊看不起"披毛戴角之辈"也出言施压（版本细节）。
- 另一版本（后生仔版）六蒲团为三清、女娲、红云、太一，第七个无主蒲团归鲲鹏再被夺——总之"红云让座、鲲鹏背锅"是共识内核，座次细节各家自便。

**三千红尘客**：百年之期坐满三千听客，史称"紫霄宫三千客"。名单（各版本汇总）：镇元子、冥河老祖、鲲鹏、东王公、西王母、羲和、望舒（常羲）、十二祖巫（部分）、十大妖神、伏羲、燃灯道人（先天燃灯）、黎山老母、度厄真人、红云……凡洪荒成名大能几乎都在。

**三讲内容**：
1. **一讲大罗金仙之道**（讲毕收三清为亲传弟子，女娲/接引/准提为记名弟子）
2. **二讲准圣之道**（公布天道圣位之数；一说此时封**东王公为男仙之首、西王母为女仙之首**——第一代"仙庭"的种子）
3. **三讲成圣三法**：斩三尸证道、功德证道、以力证道——并分赐**七道鸿蒙紫气**（成圣凭证/权限）：三清、女娲、接引、准提各一；**第七道不收徒、单独赐给红云**（"红云心性纯良，此道紫气便予你吧"）。另有设定：鸿钧合道自占一道、遁去的一归变数——九道紫气说。

**分宝岩分宝**（第三讲之后）：
- 封神原著只留一句："当时有一分宝岩，吾师分宝镇压各方。"
- 佛本是道原版把分宝放在混沌讲道之后、开天之前（盘古得太极图/盘古幡、女娲得红绣球、太一得混沌钟、接引得青莲宝色旗、准提得加持神杵）。
- 主流洪荒流版（讲道后分宝，通行分配）：通天——**诛仙四剑+诛仙阵图**+青萍剑；元始——三宝玉如意（+盘古幡归属权）；老子——扁拐+风火蒲团（+天地玄黄玲珑塔+太极图）；女娲——红绣球、山河社稷图、缚妖索（+九天息壤）；接引——十二品功德金莲+青莲宝色旗；准提——七宝妙树+加持神杵。**剩余先天灵宝尽数散落洪荒**，"有缘者得之"——这是紫霄宫后整个"寻宝时代"的开端（燃灯捡乾坤尺/定海珠等传说的逻辑起点）。

**合道收尾**：三讲毕、分宝毕，鸿钧**以身合道**（身化天道，紫霄宫遁入混沌非量劫不出），从此"鸿钧即天道，天道非鸿钧"。洪荒进入后紫霄宫时代：诸圣争位、仙庭与妖庭交替、巫妖量劫酝酿。

## 三、洪荒地图（神魔大战→紫霄宫时期的地理）

### 3.1 总原则（写图前必须知道的三件事）

1. **此期洪荒大陆是完整一块**。"四大部洲"（东胜神洲、南赡部洲、西牛贺洲、北俱芦洲）是**巫妖量劫末期共工撞断不周山、"天倾西北、地陷东南"之后**才分裂出来的格局。写这个时期不能出现四洲。
2. **此期没有天庭**。第一代天庭（妖庭·帝俊太一）是紫霄宫讲道之后才建立的；此期天上只有日月星与鸿钧后来开辟的三十三重天（版本：三十三天为鸿钧成圣后所辟，妖庭借之立国）。
3. **西方经历了"富→贫"的断崖**：道魔之争罗睺自爆西方祖脉（+祖龙撞毁西方祖脉的版本）之前，西方灵脉与东方对等；之后灵气枯竭、大能东迁——接引准提的一切"苦大仇深"皆源于此。

### 3.2 垂直分层（从外到内）

```
混沌（外世界：地水火风狂暴，魔神栖息，扬眉隐居处）
 └─ 三十三重天之外：紫霄宫（玉京山；鸿钧道场；内含分宝岩）
     └─ 三十三重天（鸿钧所辟；后世天庭/三清天所在层）
         └─ 洪荒天穹：太阳星（扶桑木）· 太阴星（月桂）· 周天星辰
             └─ 洪荒大陆（完整一块，中央不周山天柱）
                 └─ 大地深处：九幽 → 幽冥血海（盘古脐血所化，冥河老祖）
```

### 3.3 水平布局（按方位，标注事件锚点）

**中央**
- **不周山**：盘古脊梁所化天柱，洪荒地理与气运的中枢；山顶有先天**葫芦藤**（结七葫芦：紫金红葫芦归红云一系——红云的九九散魄红葫芦出处锚点）；此期不周山完整矗立，是三族大战与后世巫妖大战的共同"背景板"。娲皇宫在不周山下（一说在太素天栗广之野，佛本是道版）。

**西方（此期地貌剧变区）**
- **昆仑山**：万山之祖、龙脉之源。盘古元神所化三清在此显化出世；山巅**麒麟崖**=始麒麟葬身处；玉虚宫（元始道场，阐教祖庭）、分宝岩一说也在昆仑（版本分歧：分宝岩在紫霄宫内 or 昆仑）。
- **须弥山**：西方极境，罗睺道场+道魔之争决战地，剑阵自爆的爆心；后世西方教/灵山在其废墟基础上兴起——"魔道圣地→佛门圣地"的因果转接点。
- **西方祖脉**：被罗睺自爆（或祖龙撞毁），从此西方贫瘠——地理级的因果伤疤。

**东方**
- **东海**：龙族大本营；**海眼**（祖龙永镇处）；**蓬莱、方丈、瀛洲**三岛（先天灵气凝成液态的顶级道场，东王公居蓬莱；扶桑残躯一段落于此——凶兽量劫遗案）；瀛洲等十洲三岛多为大能私有/无主机缘地。

**南方**
- **不死火山**：元凤立誓永镇处，凤族余脉聚居；衍生地点**落凤坡**（元凤泣血/诞孔雀蛋处）。
- **丹穴山**：山海经凤族祖地，常被用作凤族旧都。
- **凤栖山**：部分版本女娲、伏羲显化出世处（人首蛇身、天地间最早的妖族）。

**北方**
- **极北之地**：三千魔神尸骸怨气沉积最重之处——凶兽的发源地；兽皇神逆的**兽神宫**所在。
- **十万大山**：凶兽量劫后残部遁藏地，万族禁地。
- **北冥**：极北玄海，鲲鹏出身与潜修地（"北冥有鱼，其名为鲲"）。

**地下**
- **幽冥血海**：盘古肚脐污血所化，天地煞气与怨念的收纳池；血海不干、冥河不死；此期冥河老祖已在血海孕生（元屠、阿鼻双剑伴生），闭口修炼不问世事——紫霄宫三千客之一。

**天上**
- **太阳星**：扶桑木；帝俊、太一（三足金乌）在此孕育（此期尚未出世/尚在孕育，紫霄宫讲道时已是成名人选）；羲和浴日传说地。
- **太阴星**：月桂；羲和、望舒（常羲）执掌。
- **三十三重天**：鸿钧成圣后开辟（版本采纳与否自定），紫霄宫悬于其外。

**混沌**
- **玉京山·紫霄宫**：讲道圣地。
- 扬眉老祖隐居混沌深处（道魔之争后远走）。

## 五、剧情设计钩子（针对《我红云绝不赴死》）

1. **红云的出世时点天然落在这个窗口**：通行设定"天地初开后第一朵红云得道"，且有一派明确写他**龙凤大劫末期出世**（小狼《洪荒那些事儿》）。也就是说：凶兽量劫→三族大战→道魔之争这整段乱世，都是红云"睁眼看到的第一个世界"——一个至善祥云之道诞生在杀劫最浓的年代，人设反差本身就是书名《绝不赴死》的前史张力。
2. **红云的葫芦在不周山**：先天葫芦藤在不周山，红葫芦（九九散魄葫芦）归红云。可以写一段"凶兽量劫/三族大战期间上不周山取葫芦"的来历戏——不周山此期是天柱圣地，取宝=与天道中枢的第一次接触。
3. **镇元子是同期至交**：地仙之祖此期已出世（万寿山五庄观，人参果树），"云与地"的两个无门无派大能，可在三族战乱里结义。
4. **未被写滥的空窗事件**（差异化空间最大）：凶兽量劫的具体战役（神逆四凶的兽潮）、三族战后的大陆重建与遗孤流亡（孔宣的蛋、四不像、龙族残部）、道魔之争的前哨战（乾坤阴阳二祖的陨落可以写成完整悲情战役）、扬眉远走前的布局、紫霄宫开讲之前鸿钧的修行与成圣宣言、三千年一讲的"讲间空档"（两次讲道之间的洪荒权力真空期，神仙打架抢地盘的黄金时段）。
5. **因果链预埋**（大势不可改、小事可改的锚点）：
   - 罗睺自爆西方祖脉 → 西方贫瘠 → 接引准提迟到 → 卖惨求座 → 红云让座 → 鲲鹏结仇 → 围杀红云。这条链的**第一环在道魔之争**，写好它，后文紫霄宫的一切"巧合"才有制度性必然。
   - 诛仙四剑：罗睺的杀器 → 分宝岩归通天 → 封神诛仙阵。中转环节（谁从罗睺手里收缴、如何入分宝岩）是主流文本的模糊地带，可以自由发挥。
   - 三族遗孤（孔宣/四不相/龙族）与凶兽残部（十万大山）都是可长期回收的伏笔池。
6. **敌役梯队**：神逆（凶兽量劫Boss）→ 三族始祖（被罗睺操弄的悲剧强者，非纯反派）→ 罗睺（贯穿龙汉+道魔两劫的总Boss）→ 鸿钧（终局"棋手"形象的渐进黑化/非人化）。对一本"绝不赴死"的书来说，这套梯队正好逐级教会红云"善良在洪荒的生存成本"。
