## 一、洪荒流是什么：源流与定型

**定义**：以《封神演义》《西游记》等明清神魔小说设定为根基，吸收《山海经》《淮南子》等古籍文献衍生而成的网络小说题材。经典叙事框架：盘古开天 → 龙汉初劫（龙凤）→ 巫妖大战 → 封神之战（→佛道之争/西游）。

**三代源流**（本库一切引用的立论基础）：

| 阶段 | 作品 | 贡献 |
|---|---|---|
| **① 开山** | 《佛本是道》（梦入神机，起点中文网，2005-2006） | 确立洪荒叙事骨架：紫霄宫、圣位之争、量劫、巫妖、封神后传。**但原著细节与今日通说差异极大**（见下） |
| **② 定型** | 《重生混元道》（鱼泪满江）等 | 补充鸿钧合道、鸿蒙紫气、女娲造人成圣、三清二释立教成圣、混沌至宝（创世青莲）等，形成"紫霄宫六圣"通说体系（百度百科·洪荒小说词条） |
| **③ 繁衍** | 近二十年海量作品 | 层累出跟脚花开、禁制重数、功德气运经济、斩三尸细则等通行约定——**均无古典依据，也非开山作原文** |

**原著层与通说层的关键差异速览**（这是旧资料长期混淆、本次重构重点澄清的部分）：

| 议题 | 《佛本是道》原著层 | 后世通说层 |
|---|---|---|
| 鸿钧弟子结构 | 亲传＝盘古、太一、女娲 | 亲传三清、女娲关门、接引准提记名 |
| 三清来历 | 盘古元神所化，**开天同时即证混元** | 紫霄宫听道→分紫气→立教→成圣 |
| 鸿蒙紫气 | 无"七道紫气分赐"细节 | 七道紫气＝成圣凭证，第七道落红云 |
| 红云 | 混沌生灵；让出圣位；被鲲鹏-冥河逼到转世（转世身贺子博） | 第一朵红云得道；得第七道紫气被夺；转世云中子 |
| 斩仙飞刀 | 东皇第十子取夸父/后羿精气自炼于葫芦 | 先天葫芦藤黄葫芦所结 |

> 红云相关的完整分层考证见 **09-红云专题_中立权威考证.md**（本库红云唯一权威）；紫霄宫/成圣体系见 10。

**洪荒流没有钦定 canon**。所有"设定"都是版本谱系：原典层（古典文本）→ 原著层（开山作）→ 定型层（体系化作品）→ 通说层（综合惯例）→ 流变层（诸版本并列）。引用任何设定前先定层，是本库的基本纪律。

## 二、原典层对照速查：洪荒流从古典文本实际拿走了什么

> 旧版总纲缺失的维度。用途：分辨"古典依据"与"网文原创"，防止把后世设定当传统神话引用。

| 古典文本 | 实际提供的元素 | 洪荒流的改造 |
|---|---|---|
| 《封神演义》 | 鸿钧（84回"一道传三友"，唯一古典出处）；三清/阐截两教；诛仙阵/万仙阵；封神榜/打神鞭；三霄/赵公明/陆压/孔宣/云中子/燃灯；**火云洞三圣**（58/81回，伏羲/神农/轩辕，杨戬两次求药）；哪吒/杨戬/雷震子 | 抬升鸿钧为"合道天道"；将封神倒推为"量劫清算"；把鸿钧出场前的洪荒史（龙汉/巫妖）全部前置虚构；火云洞被另派给红云作道场（同名异物，易混淆） |
| 《西游记》 | 镇元子（24-26回，五庄观/人参果/"与世同君"/袖里乾坤）；太上老君与紫金红葫芦；蟠桃/兜率宫；奎木狼等星宿；六耳猕猴 | 镇元子被纳入"紫霄宫听道者+红云至交"谱系；紫金红葫芦编入"先天葫芦藤"谱系 |
| 《山海经》/《淮南子》 | 夸父逐日、共工触不周山、女娲补天/造人（淮南子）、烛龙、应龙、刑天、羲和常羲 | 全部纳入"巫妖量劫"因果链；祖巫体系以帝江等神名拼装 |
| 《庄子》 | 鲲鹏（逍遥游寓言意象） | 人格化为"妖师鲲鹏"，背负与红云的仇怨 |
| 道教文化 | 紫气东来（老子出关）；三尸神（斩三尸的概念原型）；三清尊神体系 | 衍生出鸿蒙紫气、斩三尸证道法、跟脚论等原创体系 |

**反向提醒**（常见误引）：红云老祖、冥河老祖、鸿蒙紫气、先天葫芦藤、跟脚花开、禁制重数、功德金光经济体系——**均无任何古典出处**，全部为网络小说原创或层累约定。网络词条（含百度百科部分内容）常把这些与古典元素混写，引用时按本表与 09 的分层归位。

## 三、世界观骨架（通说层概览）

> 本节只给骨架与入口，细节一律指向专项文件；所有"版本异"在专项文件中谱系并列，本库不设"统一钦定版"。

### 3.1 三层法则
大道（"大道五十，天衍四十九，遁去其一"）＞ 天道（鸿钧合道所掌，以量劫清算因果）＞ 人道（三皇/人族气运，部分作品设定独立于天道）＋ 地道（后土化轮回）。→ 详见 01

### 3.2 时间线八大事件
混沌 → 盘古开天 → 凶兽量劫/道魔之争（版本异）→ 龙凤初劫 → 紫霄宫讲道 → 巫妖量劫 → 三皇五帝 → 封神之战。→ 详见 02/07

### 3.3 境界体系
凡境（炼气→渡劫）→ 仙境（天仙→大罗金仙→准圣）→ 圣境（混元大罗金仙/圣人）→ 天道。跟脚"花开几品"为后起通行约定。→ 详见 01

### 3.4 法宝体系
混沌至宝（开天神斧/创世青莲/造化玉牒，均已碎损）→ 先天至宝 → 极品先天灵宝 → 先天灵宝 → 后天。禁制重数分级为后起通行约定（多版本冲突全存于 14）。→ 详见 08/14/19

### 3.5 功德/业力/气运
三位一体的能量守恒经济：功德抵业力、业力引量劫、气运随升降。洪荒三大功德：盘古开天＞女娲造人＞后土化轮回。→ 详见 15

### 3.6 圣位与鸿蒙紫气
通说：七道鸿蒙紫气＝成圣凭证（六圣＋红云第七道）；紫气体系为定型层产物，非开山作原文（见 10 §一）。→ 详见 10/11

### 3.7 量劫机制
通说"三根"：因果业力堆积／灵气枯竭／大道周期成住坏空。清算规则：因果债最重者应劫；劫后功德业力气运归零重分配。→ 详见 07/15

## 四、本库使用说明

**分层定义**（引用任何设定先定层）：
1. **原典层**——古典文本实际内容（见本文件第二节）
2. **原著层**——《佛本是道》原文（红云见 09；世界观见 09 §二）
3. **定型层**——《重生混元道》等体系化作品补出的设定
4. **通说层**——无明确出处、行业综合惯例（大多数设定在此层）
5. **流变层**——同一议题的诸版本谱系（09 §四、14、21）

**信源分级**（约定见 09 §六）：〔S〕起源作原文与逐字引文 ＞ 〔A〕权威词条 ＞ 〔B〕读者考据 ＞ 〔C〕内容农场（禁引）。

**版本冲突处理原则**：谱系并列、标注来源，**不强行统一**。旧版"统一版/本库叙述基准/每件法宝只允许一种描述"的做法是为具体小说服务的裁决行为，中立资料不做。

**专项文件入口**：01 世界规则/境界 → 02 时间线 → 03 人物档案 → 04 写作方法论 → 05 必死角色因果链 → 06 地理 → 07 量劫叙事 → 08 法宝详档 → **09 红云考证（红云唯一权威）** → **10 紫霄宫与成圣** → 11 成圣暗线 → 12/13 人物故事线 → 14 宝物机缘 → 15 功德系统 → 16-19 神通法宝详解 → 20 因果网络全景 → 21 读者讨论汇编（二手观点信源） → 22 圣人博弈 → 23 神魔大战考证 → 24 鸿钧与六圣档案。
