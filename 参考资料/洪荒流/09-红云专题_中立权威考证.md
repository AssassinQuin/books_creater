## 〇、一句话总结论

**红云老祖不出现在任何传统典籍与古典神魔小说中。** 该角色诞生于梦入神机《佛本是道》（起点中文网，2005-2006 连载，洪荒流开山之作），原著中他是"让出圣位、被鲲鹏-冥河逼到转世避劫"的悲情配角，转世身为人间的**贺子博**。今日大众熟知的"天地初开第一朵红云得道、第七道鸿蒙紫气、葫芦护元神转世云中子"等叙事，是《佛本是道》之后近二十年洪荒流作品层累定型的结果（体系化主要归功于《重生混元道》等后续作）。

**引用红云设定前必须先自问：用的是"原著层"还是"通说层"——两层差异极大（见第四节对照表）。**

## 一、原典考证层：传统文献中没有红云老祖

### 1.1 不存在性 〔A〕
- 《西游记》《封神演义》《山海经》《淮南子》及历代道教典籍、正史野史中**均无"红云老祖"其人**。
- 快懂百科·红云老祖词条明确标注："以下内容来源于《佛本是道》或其它洪荒小说，**不是宗教人物**"。
- "红云"二字在古籍中仅作天象与诗文意象使用，无神格、无故事。

### 1.2 同名异物与近源元素清单（易混淆，逐项对照）

| 元素 | 原典出处与内容 | 与红云的关系 |
|---|---|---|
| **火云洞/火云宫三圣** | 《封神演义》第58回（吕岳布瘟疫、杨戬首次上火云洞求药）、第81回（痘疹之灾、再求升麻药方）；即天皇伏羲、地皇神农、人皇轩辕，为圣人之尊 | **无任何关系**。洪荒流给红云安排道场"火云宫/火云洞"系后起设定，与三圣同名异物，是最常见的混淆点 |
| **云中子** | 《封神演义》第5回登场；终南山炼气士；进松木剑谏纣王除妲己；雷震子之师；十绝阵未参与、九曲黄河阵未被削三花——读者归纳为"福德之仙" | 后世"红云转世云中子"说正是对"福德之仙"标签的二次解释（见 4.1）。《佛本是道》原著中云中子是独立人物（炼器宗），与红云无涉 |
| **镇元子** | 《西游记》第24-26回；万寿山五庄观地仙之祖，别号"**与世同君**"，人参果树主人，袖里乾坤 | "红云至交"为洪荒流设定（通说层稳固），原典无此交情 |
| **鲲鹏** | 《庄子·逍遥运》"北冥有鱼……化而为鸟"的寓言意象 | "妖师鲲鹏"的人格、职位、与红云的仇怨均为《佛本是道》塑造 |
| **紫金红葫芦** | 《西游记》中太上老君"盛丹的葫芦"，被金银角童子盗用下界（第33-35回） | 洪荒流后起设定将各色葫芦统一编入"先天葫芦藤"谱系（见 10 号文件），与红云葫芦结成"同源"关系 |
| **鸿钧** | 《封神演义》第84回登场（"一道传三友"，三清之师）——古典小说中唯一出处 | 洪荒流将其抬升为"天道代言人/合道者"，红云故事的算计者形象由此而来 |
| **紫气** | 文化原型为老子出函谷关"紫气东来"（《列仙传》等） | "鸿蒙紫气"命名借用了这一意象，但概念本身为洪荒流原创，道教无此物 |

### 1.3 层结论
红云老祖的全部人物设定——本体、法宝、事迹、死亡、转世——均为网络小说原创，引用时不存在"古典依据"可依。

## 二、起源层：《佛本是道》原著中的红云 〔S〕

### 2.1 原著身份
- **本体**：混沌中的生灵（原著表述"红云老祖本是混沌中的生灵"）。〔注意：**不是**后世通说的"天地初开后第一朵红云得道"，此为定型层改动〕
- **修为**：准圣级（大罗金仙/准圣档）。
- **师承**：鸿钧座前听道（词条称"鸿钧老祖的挂名弟子、三十六门人之一"）。
- **功法**：悟得**九九红云混沌大法**。
- **法宝**：**九九红云散魄葫芦**——"三尺三寸，通体火红晶莹"，先天一点灵根长成的宝物，炼无穷岁月而成；喷出红沙可散人魂魄、伤人元神。

### 2.2 让座事件（原著版）
> 百度百科·佛本是道词条："鸿钧讲道，分发圣位，除三大亲传弟子盘古、太一，女娲外机缘不定。其中，**红云让座，准提道人打鲲鹏落位，与阿弥陀得到圣位，有了证道的机缘**。"

- 原著中鸿钧**亲传弟子是盘古、太一、女娲**——与后世通说"三清为亲传、女娲关门、接引准提记名"的结构完全不同。
- 原著中**三清是盘古元神所化、在开天辟地的同时即证混元**，根本不走"紫霄宫听道→分紫气→立教成圣"的路线（该路线为定型层产物）。
- 原著红云让出的是一个**听道位子/圣位机会**；原著叙述中未见"七道鸿蒙紫气分赐"细节，红云在原著中**并未持有鸿蒙紫气**。

### 2.3 陨落线（原著版）
> 知乎专栏《佛本是道 世界观 剧情简介 器物志》："（鲲鹏）派坐下两大妖神开明兽、陆吾追杀红云，最后使得红云不得不**转世避劫**。"
> 知乎"洪荒流索隐"引原著第三一四章："红云老祖因和妖族天师鲲鹏祖师在混沌之中有些间隙，两相在**首阳山**碰面，争斗起来，红云老祖不敌，被击成重伤，又被鲲鹏祖师下令妖神陆吾和座下大将开明兽追杀，遁进了幽冥之中，不想被冥河教祖遇到，双方又是言语不合，动起手来，被冥河教祖杀死……"

原著因果链：
```
紫霄宫让座（红云把位子让给准提）
→ 准提为接引打落鲲鹏、夺其位（鲲鹏记恨的真正源头）
→ 鲲鹏任妖师后，遣开明兽、陆吾追杀红云
→ 红云重伤遁入幽冥
→ 遇冥河教祖，言语不合被其打成残魂，九九红云散魄葫芦也被夺走
→ 颠倒天机、转入轮回，转世避劫
```
- 原著**没有**"鲲鹏半路偷袭夺鸿蒙紫气"情节（红云无紫气可夺）。
- 原著**没有**"葫芦护元神过幽冥、冥河拦截、祭葫芦得脱"的完整剧场（那是通说层加工；原著里葫芦恰恰被冥河夺走了）。

### 2.4 结局与转世
- 大结局彩蛋：**"反倒是转劫而来未修斩三尸之法的董永和红云躲过劫数，得自逍遥"**——转世红云在最终量劫中活到了最后，结局偏"因祸得福"。〔S：结局彩蛋引文，多源转述一致〕
- **转世身＝贺子博**：人间身份，后拜通天教主门下；曾在人间以两千块钱把**寂灭法轮**卖给主角周青——周青由此获得成道机缘的源头之一。〔B：知乎读者考据与 NGA 讨论交叉，称混沌钟钟锤本也是留给贺子博的机缘；建议逐章核对原文〕
- 原著中**云中子是独立人物**（炼器宗，周青初期承其传承），原著未言云中子与红云有任何关系。

### 2.5 原著角色功能小结
红云在《佛本是道》中的叙事功能：①洪荒序章的悲情注脚（好心让座→无辜被杀）；②主角机缘的因果源头（转世贺子博卖宝给周青）。他不是原著主角，戏份集中于回忆交代。

## 三、体系定型层：从《佛本是道》到"洪荒通说"

### 3.1 定型代表作 〔A〕
百度百科·洪荒小说词条："完善洪荒小说体系结构的是鱼泪满江的《重生混元道》，**补充了鸿钧合道、鸿蒙紫气、女娲造人成圣、三清二释立教成圣、混沌至宝（如创世青莲）等剧情和设定**。"
——即：今日通说的"紫霄宫六圣体系"，骨架出自《佛本是道》，血肉大半是《重生混元道》及其后二十年作品补的。

### 3.2 鸿蒙紫气考
- 道教典籍、正史野史均无此物；命名原型是"紫气东来"。
- 首创归属两说并存：〔B〕NGA 社区认为"紫霄宫抢蒲团/鸿蒙紫气成圣是神机（梦入神机）原创"；〔A〕百度百科·洪荒小说词条则把鸿蒙紫气体系归为《重生混元道》的补充完善。
- **保守结论**：圣位蒲团之争出自《佛本是道》；"七道鸿蒙紫气、有紫气方可成圣"的体系化细节是后续层累，确切首见文本待考。
- "大道五十，天衍四十九，遁去其一"（《易经》系辞＋道教化用）被通说借来解释"第七道紫气"的存在合法性——这是通说层的哲学包装，原著无此对应。

### 3.3 定型后的红云叙事全链（通说剧场版）
```
天地初开第一朵红云得道（先天祥云化身）
→ 紫霄宫听道，占蒲团
→ 准提接引来迟（哭诉西方贫瘠）
→ 红云好心让座
→ 鲲鹏被逼让座（元始斥"披毛带角、湿生卵化之辈"）
→ 鸿钧分七道鸿蒙紫气，第七道意外落红云（"遁去其一"的变数）
→ 出宫即遭鲲鹏偷袭，肉身被灭
→ 九九红云散魄葫芦护住元神
→ 元神入幽冥，又遭冥河拦截
→ 祭葫芦抵挡，乘隙入轮回转世
→ 号称"洪荒第一倒霉之人"
```

### 3.4 通说对原著的关键改动对照表

| 维度 | 《佛本是道》原著层 | 洪荒流通说层 |
|---|---|---|
| 本体 | 混沌中的生灵 | 天地初开第一朵红云得道（先天祥云化身） |
| 鸿钧弟子结构 | 亲传＝盘古/太一/女娲；三清开天即证混元 | 亲传三清、女娲关门、接引准提记名；三清也走紫霄宫成圣线 |
| 让座性质 | 让出听道位子/圣位机会（红云未得圣位） | 让座给准提后仍意外分得第七道鸿蒙紫气 |
| 死因 | 鲲鹏遣开明兽/陆吾追杀→重伤遁幽冥→冥河打成残魂 | 鲲鹏出宫半路偷袭灭其肉身；冥河在幽冥拦截补刀 |
| 葫芦归宿 | 被冥河夺走 | 护主元神过幽冥，随红云转世或下落不明 |
| 转世 | 贺子博（人间人，拜通天教主，卖寂灭法轮给周青） | 云中子（最流行）等，版本繁多（见 4.1） |
| 与镇元子 | 原著梳理未提至交（词条有载，起源待核） | 通说稳固设定："与世同君镇元子为其至交好友" |
| 结局色彩 | 转劫避祸、终局得逍遥（偏正面） | "洪荒第一倒霉之人"（悲情标签） |

### 4.2 词条混层警示 〔重要〕
百度百科"红云老祖"词条本身即混层样本：其叙述把"天地初开第一朵红云得道""获得鸿蒙紫气""转世后为福星云中子，后修成第二任青帝太乙救苦天尊"等通说层内容与《佛本是道》原著情节（混沌生灵、转世贺子博）糅在一起，且互相矛盾。
**引用任何百科词条时，须按本文件的分层重新归位后再使用。**

## 五、"红云流"子类型观察（客观市场现象）

红云已是洪荒流的常青配角＋独立主角亚类型。其"必死老好人"命格天然适配"穿越改命"母题：读者入场即知死局，冲突前置零成本。

- **常见改命路径**（各作品反复使用的开关）：不让座／拒紫气／转嫁祸水／反杀立威／执掌"劫"之权柄／情感线（娶后土、玄冥等变体）
- **样本作品**：《洪荒红云：紫霄争位只是开始》《洪荒：我为红云，开局圣位换老婆》《洪荒我为红云天命成圣》《洪荒之红云劫主》（完结，恶尸云中子设定）《洪荒封神：转世红云》《我在武侠世界当道祖》（红云转世云中子为主角）
- **通行张力点**：与鲲鹏的死因果／准提的"人情债"／与镇元子的友情／"鸿钧算计红云"阴谋论
