### ★ 三位混沌魔神详细能力补充（2026-08-09 Phase 5）
> 来源：百度百科·时间魔神 + 百度百科·乾坤鼎 + 百度百科·杨眉大仙 + 百度百科·三千魔神 + 知乎·洪荒道与魔

**阴阳道人**（阴阳法则掌握者，法则排名第9）：
- **身份**：混沌世界中一缕阴阳之气所化
- **伴生法宝**：**混沌阴阳镜**（混沌灵宝）
  - 镜分阴阳两面，可定人生死
  - 能颠倒阴阳、逆转造化
  - 具有镇压阴阳二气之威能
  - 属于魂系法宝，可攻击元神
- **法则能力**：调和天地阴阳二气；万物生死枯荣皆由阴阳驱动；可分化阴阳之力进行攻伐或防御

**乾坤道人**（乾坤法则掌握者）：
- **身份**：混沌三千魔神之一，执掌乾坤法则（涵盖天地运转、万物归元之力）
- **伴生法宝**：**乾坤鼎**（混沌灵宝/先天至宝）
  - 〔来源版本异〕一说为**混沌青莲的莲蓬**所化
  - 核心能力：**炼化万物、返本归元**——可将后天之物转化为先天
  - **提升法宝品质**——鼎中炼制之物可提高品级
  - **防御无双**——内含无穷乾坤之气，可作为顶级防御至宝
  - **扭转乾坤**——颠倒天地规则
- **其他法宝**：**乾坤尺**——形似尺子，用于投掷攻伐，蕴含乾坤法则之力
- **法则能力**：掌控天地乾坤运转；炼化万物归元；空间与力量的结合运用

**时辰道人**（时间法则掌握者，法则排名第2）：
- **身份**：混沌中时间法则的掌控者，乃时间之气的显化
- **法则排名**：时间法则在三千大道中排名**第二**（仅次于盘古的力量法则），有"**时间为尊**"之说
- **伴生法宝**：**时间轮盘**（时辰轮盘，混沌灵宝）
  - 辅助时辰道人更精准地操控时间法则
  - **禁锢时间、镇压空间**
  - 具有镇压混沌、颠倒时空的威力
  - 可炼化阴阳、扭转乾坤
- **法则能力**：**加速或减慢时间流逝** / **时间倒流** / **时间静止**；可与空间法则配合，形成时空封锁

## 六、关系网

### 师徒
- 鸿钧 →（紫霄宫讲道）→ **嫡传**：三清 + 女娲 + 接引 + 准提（记名弟子）
- 鸿钧 → **挂名/听道**：红云（三十六门人之一）、镇元子、帝俊、太一、鲲鹏、冥河、伏羲、后土等（紫霄宫三千客）
- 鸿钧 → **身边童子**：昊天（童子）+ 瑶池（童女）→巫妖后任天帝/王母

### 血缘
- 帝俊 ↔ 太一（兄弟）+ 羲和/常羲（妻妯娌）
- 女娲 ↔ 伏羲（兄妹，原为一体双生）

### 道魔之争（混沌纪末·龙凤初劫前）
- **鸿钧 + 杨眉大仙 + 阴阳道人 + 乾坤道人 + 时辰道人** vs **罗睺（+三千魔神部众）**
- 阴阳/乾坤自爆元神重创罗睺；时辰被罗睺斩首；杨眉牵制罗睺主力；鸿钧以诸天庆云护体未伤
- 战后：罗睺被灭→鸿钧融合三尸→成圣→合道；杨眉隐居混沌深处

### 挚友
- **红云 ↔ 镇元子**（洪荒名友谊，唯一真心护红云者）

### 因果敌对（红云相关核心网）
- **红云 →（让座致失机缘）→ 鲲鹏结怨**
- **红云 →（得紫气招祸）→ 冥河/鲲鹏围杀**

### 因果债（★多条暗线）

- 瑶池（王母娘娘）= 鸿钧身边童女 → 管蟠桃园/女仙之首
