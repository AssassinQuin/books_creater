## 一、洪荒流概述

**洪荒流** = 把《山海经》《封神演义》《西游记》+ 道教神话整合成的统一世界观。经典套路：**现代青年魂穿重生洪荒，通过历劫修行改变历史轨迹**。核心框架事件：**盘古开天 → 龙汉初劫（龙凤）→ 巫妖大战 → 封神之战 → 佛道之争**。

**天道与量劫**：洪荒由"天道"运转，气运/因果有守恒律；"量劫"是天道清算因果的周期性大劫（龙凤/巫妖/封神都是量劫）。量劫本质 = 众生因果积累到临界，需以大劫"清账"（大量生灵应劫身亡，偿还因果）。（量劫"清账"机制是洪荒流"改命"母题的核心约束。）

## 二、宇宙起源与法则

- **混沌**：天地未开，唯有混沌。
- **三千魔神（混沌魔神）**：混沌中诞生的三千个强者，**各掌一条法则**（时间/空间/毁灭/造化…）。盘古开天时斩杀三千魔神。〔主流版：魔神随开天陨落，法则散入洪荒〕
- **盘古开天**：盘古于混沌中开天辟地，与三千魔神大战，**力竭身亡，身化洪荒**：
  - 元神 → **三清**（老子/元始天尊/通天教主）
  - 十二滴精血 → **十二祖巫**
  - 左右眼 → **帝俊、东皇太一**（一说双眼化日月）
  - 身躯 → 山川万物

### 2.1 三重法则体系（详细）

| 法则层 | 本质 | 主导者 | 说明 |
|---|---|---|---|
| **大道**（最高） | 宇宙根本法则（"大道五十，天衍四十九，遁去其一"） | 大道本身（无人格化） | 超脱洪荒的至高法则。盘古"以力证道"即冲此层 |
| **天道** | 洪荒天地运转法则 | **鸿钧**（合道后天道化身） | 鸿钧合道后天道有了人格化意志。天道无私无情，以"量劫"清算因果 |
| **人道** | 人族气运/人心/人伦法则 | 三皇（火云洞） | 独立于天道的一层规则 |
| **地道** | 大地/轮回法则 | 后土（化轮回后） | 后土化六道轮回后融入地道（部分版本） |

### 2.2 因果律（详细机制）

| 法则 | 内容 |
|---|---|
| **因果不灭** | 种因必果，业力随身，**跨量劫不清零** |
| **因果守恒律** | 一笔命债/劫数不灭不消，**只流转**。救 A 免死，其死果不消失，只转移 |
| **量劫=天道调度因果** | 众生因果积累到临界，天道降下量劫，以大劫"清账" |
| **因果转移** | 因果债可被转移，但会留下"因果痕迹" |
| **杀不沾因果**（冥河双剑特例） | 元屠/阿鼻双剑杀人不积累业力=天道漏洞 |
| **功德抵业力（不消灭）** | 功德可延缓但不能阻止量劫清算 |

### 2.3 圣位与鸿蒙紫气

- **圣人（混元大罗金仙）**：合道/成圣者，超脱量劫、不死不灭，是洪荒顶层。成圣需鸿蒙紫气 + 立教功德（或证道）。
- **圣位分级**：
  - **天道圣人**（鸿钧独占）= 合道后的独特果位
  - **混元大罗金仙**（六圣）= 元神寄托天道虚空
  - **人道圣人**（三皇）= 元神寄托火云洞人道〔部分版本〕
  - **地道圣人**（后土）= 肉身化轮回〔部分版本〕
  - **亚圣**（龙凤麟族长化青龙/朱雀/麒麟崖）〔版本异〕
- **鸿蒙紫气**：成圣之基，鸿钧所赐。**数量版本异**：
  - 〔版本A · 主流·七道〕三清3+女娲1+接引1+准提1+**红云1**（招祸根源）
  - 〔版本B · 九圣说·八道〕"天道之下九为极，鸿钧占一尊，还剩七尊"+遁去其一
  - 〔版本C · 九道说〕尚有隐匿紫气流向（后土/孔宣/镇元子等伏笔）

### 2.4 量劫机制详细规则

> **量劫本质**（来源：知乎"周北辰"《末法量劫录》三根）：
> 1. **因果业力堆积**——万灵所行积累因果，超天道承载即崩溃
> 2. **灵气枯竭**——修士索取过度，先天灵气降为后天浊气
> 3. **大道周期**——大道如环，有成住坏空，量劫对应"坏与空"阶段

- **量劫（天地大劫）**：天道清算因果的周期，需大量生灵应劫。
- **量劫时间**：1量劫≈56亿年；1元会年=129600年

**量劫链条**：每个量劫都是上一个因果的清算 → 串成因果链。穿越改命类作品的主角凭前世记忆知道这些量劫的结局，可以设计改变导致结局的"因"——但结果变不变，取决于有没有圣人在背后推动那个结局（圣人的棋子，他们会出手维持结果不变；不是棋子的，改了就改了）。

## 五、★人物谱（按身份）

### 圣人层
- **鸿钧**：道祖，合天道，紫霄宫讲道者，三清/女娲/接引/准提之师。洪荒最高意志。
- **老子（太清）**：人教教主，三清之首，太极图。超然淡漠。
- **元始天尊（玉清）**：阐教教主，盘古幡。端方持重，封神主推。
- **通天教主（上清）**：截教教主，诛仙四剑。「有教无类」收妖/人/各类，**重情、刚烈**；万仙来朝；**封神被老子/元始/接引/准提四圣围殴，贬谪**。〔悲情，非死〕
- **女娲**：造人补天，妖族出身成圣，妖族最后的圣人。
- **接引/准提**：西方教二圣，立佛教。

### 妖族（巫妖战陨落组）
- **帝俊（妖皇）**：妖族天帝，河图洛书，妻羲和（十日之母）。巫妖战陨。
- **东皇太一**：帝俊之弟/或并称，**执混沌钟**（至高法宝），妻常羲（十二月之母）。巫妖战陨。〔顶级必死悲情〕
- **十大妖圣**：计蒙、英招、白泽、飞诞、飞廉、九婴、呲铁、商羊、钦原、鬼车。
- **鲲鹏（妖师）**：妖族军师，**因红云让座事件失圣位机缘，与红云结因果**；巫妖战背叛妖族（携河图洛书/或临阵脱逃）。〔与红云死因果相关〕

### 巫族（十二祖巫，盘古精血）

## 八、★大事件因果链拆解（因果调度机制的操作蓝图）

### 红云之死（主角线·最关键）
**完整因果链**：紫霄宫讲道 → 红云好心让座给准提 → 鲲鹏因此失圣位机缘（结怨）→ 鸿钧分紫气，红云意外得一道 → 紫气=成圣基，引众贪 → 冥河/鲲鹏等围杀夺气 → 红云身死道消（紫气被夺/转手）
- **可断点**：①不让座（不结鲲鹏怨）②拒接紫气（不招祸）③接了紫气但布局转嫁（让祸水引向该承之人）④与镇元子结盟共抗
- **守恒点**：紫气必须有人得（成圣机缘要落地）；红云不死则紫气祸转嫁谁？——这是主角「调度命债」的核心题

### 巫妖大战
**因果链**：妖族立天庭（帝俊太一）↔ 巫族争夺洪荒主导 → 夸父逐日/后羿射日（十日凌空，羲和之子被杀）激化 → 量劫至，两族决战 → 都天神魔大阵 vs 周天星斗大阵 → 两败俱伤，帝俊/太一/祖巫尽陨 → 后土已先化轮回 → 共工触不周山 → 天庭崩，鸿钧重立
- **可断点**：①解十日凌空（断夸父/后羿悲剧）②斡旋巫妖世仇③转移量劫应劫者

### 封神之战
**因果链**：天道量劫清算 → 阐教（元始）借机打压截教（通天）→ 商周更替为引 → 众仙应劫上榜 → 四圣围殴通天 → 截教败、通天贬 → 天庭补缺
- **可断点**：①截教弟子免惹因果②阐截和解③通天免被围

## 九、★斩三尸详细过程（canon核心机制）

> 来源：鸿钧紫霄宫二讲所传之法（知乎"太古宙古太古代"+ 多部洪荒流小说原文）。

### 三尸的本质（道教三尸神概念演化）

| 三尸 | 别称 | 居所 | 本质 |
|---|---|---|---|
| **上尸** | 青姑 | 居于云（脑） | **善念**·执善之念 |
| **中尸** | 白姑 | 居于身（胸） | **自我尸**·执我之念 |
| **下尸** | — | 居于土（腹） | **恶念**·执杀之念 |

### 斩尸流程

1. **大罗金仙圆满**：必须先至大罗巅峰，完成"三花聚顶、五气朝元"
2. **觅先天灵宝寄托**：三尸必须以**先天灵宝/先天灵根**等先天之物寄托（鸿钧原话："不入先天，皆不可斩尸"）
3. **依次斩出三尸**（自我尸最难，一般最后）：每斩一尸，道行增长；三尸有独立意识，可独立作战
4. **三尸合一**：历经无量量劫打磨 → 三尸与本尊归一 → 准圣圆满
5. **紫气+功德证道**：三尸合一时需鸿蒙紫气+功德 → 证道成圣

### 关键约束

- **无先天灵宝=不能斩尸=不能成准圣**——争先天灵宝激烈之根
- **自我尸最难斩**：需"无欲无求、不滞于物"的心性境界
- **三尸可能反噬**：三尸实力过强/契合度低可能背叛
- **斩尸+法则证道不可兼容**：一旦走斩尸路就无法转修法则证道
