## 一、洪荒流概述

**洪荒流** = 把《山海经》《封神演义》《西游记》+ 道教神话整合成的统一世界观。经典套路：**现代青年魂穿重生洪荒，通过历劫修行改变历史轨迹**。核心框架事件：**盘古开天 → 龙汉初劫（龙凤）→ 巫妖大战 → 封神之战 → 佛道之争**。

**天道与量劫**：洪荒由"天道"运转，气运/因果有守恒律；"量劫"是天道清算因果的周期性大劫（龙凤/巫妖/封神都是量劫）。量劫本质 = 众生因果积累到临界，需以大劫"清账"（大量生灵应劫身亡，偿还因果）。**★这是我们「因果守恒 + 因果调度」机制的天然土壤——量劫就是天道在调度因果。**

## 二、宇宙起源与法则

- **混沌**：天地未开，唯有混沌。
- **三千魔神（混沌魔神）**：混沌中诞生的三千个强者，**各掌一条法则**（时间/空间/毁灭/造化…）。盘古开天时斩杀三千魔神。〔主流版：魔神随开天陨落，法则散入洪荒〕
- **盘古开天**：盘古于混沌中开天辟地，与三千魔神大战，**力竭身亡，身化洪荒**：
  - 元神 → **三清**（老子/元始天尊/通天教主）
  - 十二滴精血 → **十二祖巫**
  - 左右眼 → **帝俊、东皇太一**（一说双眼化日月）
  - 身躯 → 山川万物
- **天道**：洪荒运转的根本法则。**鸿钧合道**后，鸿钧即天道化身（紫霄宫讲道，收三清/女娲/接引/准提为徒，赐鸿蒙紫气）。
- **圣人（混元大罗金仙）**：合道/成圣者，超脱量劫、不死不灭，是洪荒顶层。成圣需鸿蒙紫气 + 立教功德（或证道）。
- **鸿蒙紫气**：成圣之基，鸿钧所赐，数量极少（七道，分给三清/女娲/接引/准提，但红云意外得了一道——招祸根源）。
- **量劫（天地大劫）**：天道清算因果的周期，需大量生灵应劫。

| **鸿蒙纪** | 鸿钧紫霄宫讲道，收徒赐紫气 | 立圣人体系；**红云让座结因果、得紫气招祸伏笔** |

## 五、★人物谱（按身份）

### 圣人层
- **鸿钧**：道祖，合天道，紫霄宫讲道者，三清/女娲/接引/准提之师。洪荒最高意志。
- **老子（太清）**：人教教主，三清之首，太极图。超然淡漠。
- **元始天尊（玉清）**：阐教教主，盘古幡。端方持重，封神主推。
- **通天教主（上清）**：截教教主，诛仙四剑。「有教无类」收妖/人/各类，**重情、刚烈**；万仙来朝；**封神被老子/元始/接引/准提四圣围殴，贬谪**。〔悲情，非死〕
- **女娲**：造人补天，妖族出身成圣，妖族最后的圣人。
- **接引/准提**：西方教二圣，立佛教。

### 妖族（巫妖战陨落组）
- **帝俊（妖皇）**：妖族天帝，河图洛书，妻羲和（十日之母）。巫妖战陨。
- **东皇太一**：帝俊之弟/或并称，**执混沌钟**（至高法宝），妻常羲（十二月之母）。巫妖战陨。〔顶级必死悲情〕
- **十大妖圣**：计蒙、英招、白泽、飞诞、飞廉、九婴、呲铁、商羊、钦原、鬼车。
- **鲲鹏（妖师）**：妖族军师，**因红云让座事件失圣位机缘，与红云结因果**；巫妖战背叛妖族（携河图洛书/或临阵脱逃）。〔与红云死因果相关〕

### 巫族（十二祖巫，盘古精血）
- **后土**：祖巫之一，**以身化六道轮回**（给亡魂归处），牺牲。〔顶级必死悲情〕
- **共工**：怒触不周山（巫妖战末）。
- **祝融、帝江、句芒、蓐收、玄冥、后土、天吴、强良、翕兹、奢比尸、烛九阴** 等：巫妖战尽陨，仅玄冥（一说）存活。
- **夸父/后羿**：巫族阵营（或人族英雄），夸父逐日死、后羿射日后被逢蒙打死（妻嫦娥离去）。

### 散修大能（含主角团）
- **★红云老祖**：**洪荒第一朵红云得道**，先天祥云化身，异宝**九九散魂葫芦**，**性情温和善良，"洪荒老好人"**。紫霄宫让座给准提 → 与鲲鹏结因果 → 意外得鸿蒙紫气 → 成众矢之的 → **被围杀（冥河老祖等）身死道消**。挚友**镇元子**。〔主角转生目标，必死命格〕
- **镇元子**：地仙之祖，万寿山五庄观，人参果树，与世同君。红云挚友（网文常改编为救红云）。
- **冥河老祖**：血海之主，阿修罗教主，「血海不枯，冥河不死」，造阿修罗族。**追杀红云者之一**。
- **伏羲/女娲**：兄妹，人文始祖（伏羲演八卦），女娲后成圣。
- **孔宣**：元凤长子，世间第一只孔雀，**圣人之下第一人**，终沦为接引坐骑。〔悲情，非死但屈辱〕
- **元凤/祖龙/始麒麟**：龙凤劫三族首领，退场。
- **罗睺**：魔祖，龙凤劫时代争鸿钧，持诛仙剑阵，被鸿钧灭。

## 八、★大事件因果链拆解（因果调度机制的操作蓝图）

### 红云之死（主角线·最关键）
**完整因果链**：紫霄宫讲道 → 红云好心让座给准提 → 鲲鹏因此失圣位机缘（结怨）→ 鸿钧分紫气，红云意外得一道 → 紫气=成圣基，引众贪 → 冥河/鲲鹏等围杀夺气 → 红云身死道消（紫气被夺/转手）
- **可断点**：①不让座（不结鲲鹏怨）②拒接紫气（不招祸）③接了紫气但布局转嫁（让祸水引向该承之人）④与镇元子结盟共抗
- **守恒点**：紫气必须有人得（成圣机缘要落地）；红云不死则紫气祸转嫁谁？——这是主角「调度命债」的核心题

### 巫妖大战
**因果链**：妖族立天庭（帝俊太一）↔ 巫族争夺洪荒主导 → 夸父逐日/后羿射日（十日凌空，羲和之子被杀）激化 → 量劫至，两族决战 → 都天神魔大阵 vs 周天星斗大阵 → 两败俱伤，帝俊/太一/祖巫尽陨 → 后土已先化轮回 → 共工触不周山 → 天庭崩，鸿钧重立
- **可断点**：①解十日凌空（断夸父/后羿悲剧）②斡旋巫妖世仇③转移量劫应劫者

### 封神之战
**因果链**：天道量劫清算 → 阐教（元始）借机打压截教（通天）→ 商周更替为引 → 众仙应劫上榜 → 四圣围殴通天 → 截教败、通天贬 → 天庭补缺
- **可断点**：①截教弟子免惹因果②阐截和解③通天免被围
