### 两大核心功法详解

**九转玄功**（肉身修炼至高法门）：
- **出处**：源自《封神演义》中杨戬所修"八九玄功"的延伸设定，洪荒流网文中扩展为"九转玄功"
- **特点**：以肉身极致打磨为核心，通过庞大灵气改造肉体，达到"肉身成圣、超脱轮回"之境。**摒弃元神修炼**，拒绝神识推演、因果推算等高维能力，将全部进化压力施加于血肉之躯的物理极限
- **巫族修炼**：传说中十二祖巫修炼的是九转玄功的前八转，祖巫境界即为准圣修为
- **修成九转后**：泥丸宫内元神不灭则肉身不死，元神遁走可保无虞，肉身可无限复生，近乎不死不灭

**大品天仙诀**（元神/综合修炼法门）：
- **出处**：源自《西游记》中菩提祖师传授孙悟空的修炼功法，别称"显密圆通真妙诀"
- **特点**：融合儒、释、道三家精要，修炼后可超脱三界五行。核心在于对精、气、神的把控——谨固牢藏、休漏泄、屏除邪欲、得清凉、使六根清净体坚牢
- **属于"非常之道"**：夺天地之造化，修炼至极致可跳出三界外、不在五行中，达到大罗金仙级别
- **代价**：修炼者需每五百年经历**雷、火、风三灾**的考验

### 先天神祇的修炼（先天神祇）
先天神祇不走凡境修炼。他们天生带有先天灵力/法则亲和，修炼方式：
1. **吸收先天灵气**：天地灵气滋养本体
2. **感悟道韵**：领悟天地法则（鸿钧讲道=最大道韵来源）
3. **机缘催化**：灵宝/灵脉/功德/遗泽冲击修为瓶颈
4. **斩三尸**：准圣→圣人的关键跨越（斩善念/恶念/执念三尸→每尸以灵宝寄托→三尸合一→紫气+功德证道）
5. **功德证道**：做对天地有大功之事→天降功德→功德+紫气证道（最快但根基最弱）
6. **以力证道**：以自身为基，掌两道及以上圆满法则，法则共鸣强行打破境界壁垒（最强但最难，盘古差点成功但陨落）

## 二、各角色修炼·神通·法宝详解

### 红云（主角）

| 项目 | 内容 |
|---|---|
| **本体** | 洪荒第一朵红云得道（先天祥云化身）。〔来源：百度百科·红云老祖——"洪荒第一片红云得道"〕 |
| **本体特性·无形不灭** | "云之无形，无形乃不灭"——本体为云的特质使其难以被彻底消灭。肉身被灭后元神仍可借葫芦护持度入轮回 |
| **修炼** | 先天祥云蕴含准圣级先天灵力潜力（通说） |
| **修炼功法** | 先天神祇不走凡境修炼——以先天灵气滋养本体+感悟道韵+机缘催化。不走九转玄功（肉身流）也不走大品天仙诀（元神流），而是先天祥云本体的天赋修炼方式 |
| **本体神通=先天祥云之力** | ①**云体变化**：身体化为云雾（防御/逃遁/隐匿/变形）②**祥云护体**：云气凝成护罩（红霞威压=先天威能爆发·赤色霞光如穹顶压下）③**云行先天**：先天飞行之速（云之化身天生的高速移动）④**祥瑞气**：感知/安抚/探测（祥云的先天祥瑞之气可感知周围灵力波动/安抚心神/干扰凶兽感知） |
| **法宝=九九红云散魄葫芦** | 先天灵宝·来自不周山先天葫芦藤赤色葫芦。功能=**散人三魂七魄**（葫芦喷赤光→冲散目标魂魄）。有灵智，看心情触发+闹脾气。红云被灭时，元神正是靠此葫芦保护才得以入轮回 |
| **葫芦威能** | 先天灵宝级→能散准圣级以下目标的魂魄。圣人级无效（圣人元神不灭）。范围有限（一次对准一个目标）。葫芦有灵智=自主性（不是红云想用就能用好的） |
| **道场** | 火云洞 |
| **成长** | 金仙(卷一)→太乙金仙(卷二)→大罗金仙(卷三)→大罗巅峰(卷四)→准圣+人道=规则级(卷五) |
