## 八大事件框架（洪荒流主流骨架）

**主流序列**：
盘古开天 → 凶兽量劫 → 道魔之争 → 龙汉初劫（龙凤） → 巫妖量劫 → 三皇五帝（人族崛起） → 封神之战 → 西行取经（佛道之争）

**〔版本B · 扩展序列〕**（见知乎用户"半盏清茶煮春秋"《洪荒与同人》梳理，将分宝岩分宝、女娲造人、红云身死、老子化胡等独立事件单列）：
混沌 → 盘古诞生 → 鸿钧得鸿蒙紫气 → 盘古开天 → 龙凤麒麟三族之战 → 道魔之争 / 鸿钧成圣 → 巫妖崛起 → 紫霄宫争位（第一次讲道）→ 东王公西王母受封 → 二次讲道 → 羲和浴日 / 东王公身陨 → 第三次讲道 / 七分圣位 → 巫妖初战 / 妖管天巫管地 → 分宝岩分宝 / 鸿钧合天道 → 女娲造人 → 鲲鹏冥河杀红云 → 妖族炼屠巫剑 → 后土化轮回 / 冥河创阿修罗 → 十日凌空 / 夸父逐日 / 后羿射日 / 嫦娥奔月 → 巫妖决战 → 共工触不周山 → 女娲补天 → 三皇治世 / 五帝定伦 → 封神之战 → 化胡为佛 → 西游取经。

**权力更替总规律**：每个量劫 = 旧主角族应劫陨落 → 权力真空 → 新势力填真空崛起。**因果驱动**：争霸/业力积累 → 量劫清算 → 洗牌。

**量劫本质**（知乎"周北辰"《末法量劫录》归纳三根）：
1. **因果业力堆积**——万灵所行积累因果，超天道承载即崩溃；
2. **灵气枯竭**——修士索取过度，先天灵气降为后天浊气；
3. **大道周期**——大道如环，有成住坏空，量劫对应"坏与空"阶段。

## 各时期势力格局

### ① 盘古开天后（鸿蒙初）
- **盘古出身**：混沌中孕育三千魔神（虚数，各掌一道法则），盘古以力证道、开天辟地。盘古挥开天神斧大战三千魔神，力竭身亡，身化洪荒。
  - 元神 → 三清（老子/元始/通天）
  - 十二精血 → 十二祖巫（一说盘古浊气化）
  - 左眼 → 帝俊（太阳星扶桑树下金乌），右眼 → 太一〔版本异：或说日月〕
  - 脊梁 → 不周山（天柱），头与四肢 → 五岳
  - 毛发 → 草木，血液 → 江河
- **三千魔神**：战死后法则散入洪荒（完善三千大道）；少数真灵转世洪荒（鸿钧、扬眉、时辰、阴阳、乾坤、罗睺等皆为魔神残魂/精血重修或分身）。
- **主导**：无统一主导，群雄并起，散修大能游走。
- **凶兽起源**：魔神怨念煞气 + 开天余煞 → 化凶兽（无灵智，只知破坏）；亦有一说魔神残躯化为凶兽。
- **先天至宝分布**（开天所产，分宝岩分发前的初始归属）：
  - 造化玉牒 → 鸿钧（残缺，灭罗睺后补全）
  - 盘古幡 → 元始天尊
  - 太极图 → 老子
  - 诛仙四剑 + 阵图 → 通天（罗睺死后遗物）
  - 混沌钟（东皇钟） → 太一
  - 河图洛书 → 帝俊
  - 五行旗、天书（封神榜）、地书（镇元子）、冥书（生死薄）等各有所归
  - 九天息壤 → 女娲

### ② 凶兽量劫（开天第一劫）
- **格局**：凶兽肆虐洪荒，残杀先天生灵。
- **凶兽首领**：**兽皇神逆**（一称"吼"，由混沌魔神残念凝聚，执掌创世青莲莲茎所化九霄弑神枪）。
- **四大凶兽**（神逆麾下）：**混沌、穷奇、梼杌、饕餮**〔版本异：部分版本将相柳列入，替代穷奇或饕餮〕。
- **三方势力**：
  1. **凶兽方**：神逆 + 四大凶兽 + 亿万凶兽。
  2. **先天魔神方**：鸿钧、罗睺、扬眉、时辰、阴阳、乾坤等混沌魔神（已转世/分身）。
  3. **先天生灵方**：祖龙、元凤、始麒麟（天道以五行元素所育三大混沌神兽，统鳞甲/飞禽/走兽）+ 白虎一族（曾组万族联盟）等。
- **经过**：白虎一族先组万族联盟御凶兽，被神逆屠戮，弃西方祖地流散。天道降功德给斩凶兽者，三族联盟借功德突破境界，扭转战局。
- **关键战役**：
  - 祖龙斩饕餮于东方
  - 元凤斩混沌于南方
  - 始麒麟诛穷奇于中央
  - 鸿钧、扬眉、乾坤、阴阳四大魔神联手杀上北方兽神宫 → 斩神逆
- **结果**：
  - 凶兽败亡；四大凶兽或被斩杀、或封印。
  - 大道降功德：四分予龙凤全族，两分予魔神组，四分予洪荒大地与先天生灵。
  - **大道隐退，天道初现**——凶兽量劫是天道接替大道统治洪荒的转折点。
- **神逆遗物**：九霄弑神枪（后落入罗睺或他人之手，版本不一）。
- **因果链**：魔神怨念化凶兽 → 凶兽肆虐 → 先天魔神与三族联手斩凶兽 → 凶兽败亡、三族获功德 → 三族争霸种子种下（功德红利 → 龙汉初劫）。

### ③ 道魔之争（魔道之争）
- **格局**：凶兽量劫后，**魔祖罗睺**（毁灭魔神精血 + 另两位魔神所化，非混沌魔神转世本身）欲借凶兽量劫与龙汉初劫的杀煞之气证杀伐大道，以诛仙剑阵 + 弑神枪 + 十二品灭世黑莲对抗**鸿钧**。
- **罗睺阵营**：
  - 罗睺（魔祖，诛仙四剑 + 弑神枪 + 十二品灭世黑莲）
  - 天魔神·恶诛（灭世魔龙，后回命运长河）
  - 魔尊计都
  - 座下四大魔尊 / 无心无相无法无天（一说）
- **鸿钧阵营**：
  - 鸿钧（造化玉牒碎片 / 诸天庆云 / 斩三尸）
  - 扬眉大仙（空间大道，空心杨柳本体）
  - 时辰道人（时间大道，时间长河）
  - 乾坤老祖 / 阴阳老祖
- **战场**：西方洪荒祖脉——须弥山。
- **经过**（核心通行版本）：
  1. 罗睺摆**诛仙剑阵**（诛仙/戮仙/陷仙/绝仙四门）。
  2. 鸿钧主攻诛仙门，扬眉主攻戮仙门，阴阳主攻陷仙门，乾坤主攻绝仙门。
  3. 诛仙剑意无穷，**阴阳、乾坤被重创**（鸿钧有诸天庆云护体无损，扬眉防御见长）。
  4. 阴阳、乾坤**自爆本源**重伤罗睺（→ 时辰一说亦战死）。
  5. 鸿钧斩出善、恶、执**三尸**：诸天庆云镇诛仙门、善尸 + 乾坤鼎镇戮仙门、恶尸 + 太极图镇陷仙门、执尸 + 造化玉牒镇绝仙门。
  6. 扬眉逼退罗睺本体，鸿钧借机取下诛仙四剑 → 剑阵破。
  7. 罗睺**引西方祖脉自爆**，西方大地化为焦土、灵气枯竭 → 埋下"西方贫瘠 / 鸿钧欠西方因果"伏笔（接引准提立西方教、老子化胡皆此因果延续）。
- **结果**：
  - 罗睺肉身灭（一说残念逃入混沌化为"无天"；一说魔念三分——本源魔气遁混沌、诛仙四剑归鸿钧、弑神枪破空不知所踪）。
  - 鸿钧借大战功德 + 造化玉牒补全 → **以身合天道成圣**（洪荒第一位圣人）。
  - 扬眉大仙远走天外（感知鸿钧野心，不愿受制；一说后二人于混沌中再战，扬眉略胜）。
  - 时辰、乾坤、阴阳陨落或重伤退场。
- **因果链**：罗睺杀伐证道 → 道统之争 → 道胜魔败 → 鸿钧合道立天道秩序 → 为紫霄宫讲道铺路 → 西方祖脉毁 → 为佛教大兴埋伏笔。
- **诛仙剑阵归属**：罗睺死后 → 鸿钧 → 赐通天（封神之战通天摆此阵，需四圣方可破，正源于此）。

### ④ 鸿钧讲道（紫霄宫三讲）+ 道统确立
- **时间**：道魔之争后，鸿钧合天道前。
- **地点**：三十三重天外紫霄宫（鸿钧道场）。
- **三讲内容**（通行版本）：
  - **首讲**：大罗金仙境（花开几品、跟脚之说）
  - **二讲**：准圣境（斩三尸之法——善尸、恶尸、执尸）
  - **三讲**：圣人境（成圣三法——以力证道最强如盘古、斩三尸成圣次之如鸿钧、功德成圣最弱如三清女娲）
- **六蒲团位次**（三讲常驻前排）：三清占前三（老子/元始/通天），女娲居第四，接引、准提本无座。
- **红云让座事件**（关键转折）：红云老祖（洪荒第一朵红云）心生恻隐，将第五蒲团让给准提（或说接引）；鲲鹏老祖（本占第六）被迫一同让座。**因果**：西方二圣得位，鲲鹏失圣位机缘 → 鲲鹏怨红云入骨 → 后期巫妖战鲲鹏背叛妖族、追杀红云的因果根源。
- **分鸿蒙紫气**（七道，成圣之凭证）：
  - 六道各有其主：老子、元始、通天、女娲、接引、准提
  - **第七道**落红云之手（"天衍四十九，遁去其一"——遁去的变数即此紫气）
  - **"九圣说"**：天道本定九圣，鸿钧合道占一、遁去一、余七分赐（知乎"太古宙"版本）。
- **其他赐予**：
  - 鸿钧收三清为亲传、女娲为记名、接引准提为记名
  - 分宝岩分宝（各得先天灵宝）
  - 鸿钧**以身合天道**（合道后退居紫霄宫，不常显化）
- **东王公、西王母受封**：鸿钧讲道时封**东王公为男仙之首**、**西王母为女仙之首**，共管万仙。东王公、西王母遂立**第一代天庭（仙庭）**。
- **伏羲、女娲**：讲道期间伏羲、女娲（兄妹）初现，居中修炼。

### ⑤ 仙庭 → 妖庭 演变
- **第一代天庭（仙庭）**：东王公（盘古子嗣一说）+ 西王母（占西昆仑道场，蟠桃园为其所有）。镇洪荒百族，主管教化。
  - **职能**：龙凤劫后百废待兴，仙庭负责教化众生、引导入门，功德无量。
- **东王公身陨**：
  - 〔版本A〕被帝俊/太一挑战所杀（争夺天帝位）。
  - 〔版本B〕一缕魂魄被老子收走，后转世为吕洞宾。
- **第二代天庭（妖庭）**：
  - **帝俊**（天帝，执河图洛书，周天星斗大阵）+ **东皇太一**（执混沌钟/东皇钟）
  - 妖师**鲲鹏**（北冥道场，伪圣级强者）+ 十大妖圣（计蒙、英招、飞廉、九婴、商羊、钦原、呲铁、九凤、白泽、飞诞）+ 七十二妖神
  - 伏羲、女娲一度相助妖庭
  - 定都**帝都山**（一说不周山顶太阳宫）
- **妖族取代仙庭**：帝俊、太一不满东王公、西王母仙首地位，出兵攻打仙庭，东王公身陨、西王母退守西昆仑，妖庭正式成为洪荒主导。
- **巫族崛起**：盘古十二精血 → 十二祖巫（帝江、句芒、祝融、蓐收、共工、玄冥、后土、强良、烛九阴、天吴、翕兹、奢比尸）；巫族繁衍出**刑天、夸父、后羿、蚩尤**等大巫。巫族**不修元神、纯肉身成圣**，只认盘古父神，不服天庭。
- **妖管天、巫管地**：鸿钧出面调停，定下"妖管天、巫管地"格局。

### ⑥ 龙汉初劫（龙凤大劫） ★第一次无量量劫
- **格局**：**祖龙**（统鳞甲，水）、**元凤**（统飞禽，火）、**始麒麟**（统走兽，土）三族先天而育，各统海/空/陆，争霸洪荒主导权。三族繁衍极速、杀业日重。
- **起因**：三族本互不统属，初期分管水/空/陆。凶兽量劫后三族获功德红利，势力膨胀；**罗睺化身挑拨**（变龙入凤族、变凤入龙族等），激化三族矛盾，欲借三族杀业炼诛仙剑阵证道。
- **经过**：
  - 三族互相攻伐，洪荒初生种族大量灭绝，天地破碎。
  - 罗睺居中挑拨，吸收杀伐之气炼剑阵。
  - 龙族以**万龙大阵**硬刚凤族与麒麟族。
  - 三族元气大伤，始觉被利用。
- **结果**：
  - 三族**两败俱伤**，天道降下紫霄神雷天罚灭杀三族六成（一说）。
  - **祖龙**：元神破碎，身化龙脉护佑洪荒；首处化**祖龙崖**，烛龙、应龙沉睡。龙族退守四海（镇压海眼）。
  - **元凤**：重伤退入**不死火山**，诞下孔雀蛋（后孵化为**孔宣**/孔雀大明王；一说另诞大鹏），凤族镇压不死火山。
  - **始麒麟**：重伤于昆仑山巅化崖；死前托元始天尊保住麒麟子**四不像**（后为元始坐骑）。麒麟隐，沦为"祥瑞"传说，镇压大地龙脉。
  - **三族永世背负滔天业力，从天地主角退场** → **巫妖二族趁势填补权力真空，成为下一量劫主角**。
- **因果链**：三族争霸杀业积累 → 量劫清算 → 三族应劫退场 → 巫妖填真空。
- **关键人物**：鲲鹏、冥河等大能在此期崭露；伏羲、女娲、三清等持中立。

### ⑦ 巫妖量劫 ★第二次无量量劫
- **格局**：
  - **妖族天庭**：帝俊（妖皇，河图洛书）+ 东皇太一（混沌钟）+ 十大妖圣 + 妖师鲲鹏；**周天星斗大阵**（365妖神炼365星辰）、混元河洛大阵。立天庭，号令洪荒。
  - **巫族**：十二祖巫（盘古精血，肉身成圣，**十二都天神煞大阵**可唤盘古虚影，虚幻开天神斧有灭世威能）；不修元神、纯肉身。
  - 两族争洪荒主导权，世仇日深。
- **巫妖三次大战**（通行版本）：
  - **第一次**：周天星斗大阵初成 vs 十二都天神煞大阵。两阵交锋，僵持不下，空间崩裂。妖族退走（大阵不能持久）。鸿钧出面调停，定"妖管天、巫管地"千年之约。
  - **第二次**（激化期）：
    1. **祝融 vs 共工**（巫族内部，水火不容）→ 祝融胜，共工败。共工**怒触不周山** → 天柱折，天倾，天河倒灌，女娲补天。
    2. **帝俊十子（十日）恃权凌空** → 烤灼洪荒生灵。
    3. **夸父逐日**（巫族英雄追十日）→ 渴死（一说被十日联手晒死）。
    4. **后羿射日**（射落九日，皆羲和之子）→ 巫妖矛盾激化到顶点。第十金乌**陆压**逃脱（后入西方教成大日如来）。
    5. **妖族炼屠巫剑**（以人族冤魂为材，借人道之势斩巫族气血）→ 妖族屠戮人族。
    6. **后土以身化六道轮回**（祖巫剩十一，巫族实力受损；后土功德无量但被困轮回，称"后土皇地祇"/"平心至善娘娘"，为半圣/准圣级）。
    7. **冥河老祖创阿修罗族**（于血海）。
    8. **后羿被妖族设计所杀**（一说说被炼为斩仙飞刀）。
  - **第三次决战**：
    - 妖族：帝俊+太一催**周天星斗大阵**，十大妖圣+妖师鲲鹏+七十二妖神。
    - 巫族：十二祖巫（剩十一）催**十二都天神煞大阵**（可唤盘古虚影）。
    - 两阵碰撞，天崩地裂，**两败俱伤**。
    - **帝俊、东皇太一陨落**（一说东皇太一自爆与数位祖巫同归于尽，东皇钟下落不明）。
    - **祖巫几乎尽陨**（玄冥一说独存，一说与东皇太一同归于尽）。
    - **鲲鹏背叛**（携河图洛书/临阵脱逃——因红云让座怨+自保）。
- **结果**：
  - 妖族天庭崩毁；巫族近灭。
  - **女娲补天**（炼五色石补天穹，斩鳌足立四极）；元始天尊取三分之一不周山炼**番天印**（一说）。
  - 鸿钦定**重立天庭**（封神补缺的伏笔）。
  - **人族（三皇五帝）趁权力真空崛起**。
- **因果链**：巫妖争霸杀业 + 世仇 → 量劫清算 → 两族应劫陨落 → 人族填真空。
- **鲲鹏背叛因果**：龙汉初劫时红云让座事件，鲲鹏失圣位机缘（结怨红云）——此怨延续至巫妖，鲲鹏对妖族/红云皆无忠诚，终背叛。

### ⑧ 红云之死（量劫间关键事件）
- **时间**：巫妖量劫期间（一说讲道后不久）。
- **起因**：紫霄宫让座 → 鲲鹏失圣位机缘；红云独得第七道鸿蒙紫气 → 引觊觎。
- **经过**：**鲲鹏**联合**冥河老祖**（一说有帝俊、东皇太一参与）围杀红云。红云不敌，**自爆身亡**。
- **结果**：
  - 鸿蒙紫气破开空间遁走（一说化为三份入三皇之身，一说归天道）。
  - **红云元神逃脱转世** → **云中子**（阐教福德之仙）。
  - 红云与接引准提因果了结（西方教认红云让座恩）。
- **因果**：红云之死是紫霄宫让座事件的清算，也是巫妖量劫中的次级量劫事件。

### ⑨ 女娲造人 + 六圣立教成圣
- **女娲造人**：女娲于不周山下（娲皇宫），以**九天息壤** + **三光圣水** + **先天葫芦藤**抟土造人。功德成圣（鸿钧之后第一位圣人）。
- **人族诞生**：生而孱弱，无先天神通、无盘古血脉、无强横肉身，但**道体天成、灵智自开**，合大道，是天地之中心。
- **人族三祖**（女娲造人最先创造的三个）：**燧人氏**（钻木取火）、**有巢氏**（构木为巢）、**知生氏**（着兽皮）——皆为先天人族，大罗金仙乃至太乙金仙资质。
- **三清立教**：
  - **老子立人教**（玄都大法师为徒），功德成圣。
  - **元始立阐教**（十二金仙为徒：广成子、赤精子、黄龙真人、太乙真人、惧留孙、灵宝大法师、文殊广法天尊、普贤真人、慈航道人、玉鼎真人、道行天尊、清虚道德真君；记名弟子南极仙翁、云中子、姜子牙等）。
  - **通天立截教**（有教无类，万仙来朝。亲传：多宝道人、金灵圣母、无当圣母、龟灵圣母；外门：赵公明、三霄娘娘；随侍七仙）。
- **西方二圣立教**：接引、准提发**四十八大宏愿**立西方教，功德成圣。西方贫瘠（道魔之战祖脉毁），靠大宏愿借未来功德。
- **三清分家**：老子带玄都离昆仑，于**首阳山八景宫**立人教道场；通天去**东海金鳌岛碧游宫**立截教道场；元始独占**昆仑山玉虚宫**立阐教道场。

### ⑩ 三皇五帝（人族时代）
- **格局**：巫妖后，**人族崛起**。三皇治世，五帝定伦。
- **三皇**（通行版本）：
  - **天皇·伏羲**：女娲兄长，巫妖战陨后轮回入人族。创**先天八卦**（演先天数），造渔网，创音律（伏羲琴）。证天皇位，入**火云洞**镇压人族气运。
  - **地皇·神农**（炎帝）：**尝百草**、树五谷，发明医药（神农鼎）。使人族进入农耕时代。证地皇位，入火云洞。一说神农为巫族与人族混血（尝百草不死暗示巫族血脉）。
  - **人皇·轩辕·黄帝**：拜师**广成子**（元始十二金仙之首）。造舟车、制礼乐、定婚姻制度。**涿鹿之战**大败**蚩尤**（巫族大巫 / 三头六臂 / 铜头铁额，有风伯飞廉、雨师屏翳相助），得**九天玄女**授天书、**应龙**水法、**女魃**止雨，方胜。**蚩尤被应龙斩杀**（一说服诛，五马分尸，五岳镇压）。黄帝证人皇位，入火云洞。
- **五帝**（主流版本）：**少昊（白帝）/ 颛顼（玄帝）/ 帝喾 / 唐尧 / 虞舜**。
  - 少昊：黄帝长子，凤凰图腾。
  - 颛顼：黄帝之孙，与共工（炎帝后裔，即巫妖期触不周山的共工之位继承者）争帝，共工触不周山（不周山已折后再损）。
  - 帝喾、尧、舜治世，政治清明，禅让制。
  - **大禹治水**（禹为最后一位五帝）：铸**九鼎**，定九州。禹之子**启**建夏朝，"家天下"开始。
- **关键事件**：
  - **精卫填海**：神农之女女娃溺于东海，化为精卫。
  - **刑天舞干戚**：刑天（大巫）与天帝争，被斩首，以乳为目、以脐为口，挥干戚。
  - **绝地天通**（颛顼）：断绝天地通道，人神分离。
- **主导**：人族登台，但仍是圣人棋子（封神伏笔）。三皇入火云洞后，**以人族气运镇压不出**（除非人族有难方可现身）。

### ⑪ 封神之战 ★第三次无量量劫
- **背景**：
  - 第二代天庭（昊天 + 瑶池，鸿钧童子出身）兵将稀少，**昊天求贤**。
  - 〔版本A〕阐教十二金仙不敬昊天，身犯杀劫，昊天告鸿钧 → 鸿钧拟封神榜。
  - 〔版本B〕天道量劫清算，需众仙应劫上榜（**封神榜** = 天庭补缺名册；**打神鞭** = 执榜者神器）。
  - **商周易代**为引：商纣王（子受）题诗亵渎女娲 → 女娲召**三妖**（九尾狐妲己、雉鸡精胡喜媚、玉石琵琶精王贵人）惑商 → 西周伐商。
- **格局**：
  - **阐教**（元始，十二金仙，助周）
  - **人教**（老子，玄都大法师，助周）
  - **西方教**（接引准提，借机收徒，暗中助周）
  - **截教**（通天，万仙来朝，有教无类收妖/人，助商）
- **关键战役/事件**：
  - **哪吒闹海**、**姜子牙下山**、**比干剖心**
  - **九曲黄河阵**（三霄娘娘布，困十二金仙，削顶上三花）
  - **万仙阵**（通天集结截教万仙，被四圣破）
  - **诛仙阵决战**：通天摆**诛仙剑阵**（罗睺遗物），需四圣方可破。**老子 + 元始 + 接引 + 准提**四圣联手破阵，围殴通天。
  - 准提收**孔宣**（五色神光，孔雀大明王）为坐骑；接引收**多宝道人**（后为如来佛祖，一说说老子化胡时擒多宝）。
- **结果**：
  - **截教败落**：通天被鸿钧带回紫霄宫**贬谪**（服灭圣丹/陨圣丹，终生不出紫霄宫）；截教众仙大量上榜封神。
  - **天庭补缺成型**：封神榜诸神归位（李靖、哪吒、杨戬、韦护等肉身成圣不入榜；闻太师、赵公明、三霄等上榜）。
  - **西方教（佛教）大兴**：接引准提借机收截教残余、孔宣、坐骑等。
  - 阐教赢但十二金仙亦损因果；**燃灯道人、慈航道人、文殊广法天尊、惧留孙、普贤真人**等入西方教（佛门）。
- **因果链**：天道量劫清算 + 阐截道统之争 + 截教招业 → 量劫 → 截教应劫上榜 → 天庭补缺 + 佛教兴。

### ⑫ 化胡为佛（封神后过渡事件）
- **老子化胡**：老子西出函谷关（紫气东来三万里），以**多宝道人**（截教大弟子，封神被擒）转世为**如来佛祖**（释迦牟尼），创立佛教（西方教升级），压制西方二圣。
- 〔版本异〕多宝"叛变"成为如来，反助佛门壮大；老子无奈下凡收徒孔子，立儒道。
- **孔丘参悟浩然正气**成就圣人果位（非天道圣人，乃人道圣人）。

### ⑬ 西行取经（佛道之争）
- **背景**：
  - 封神后西方教（佛教）确立，佛教**东传**触怒道门。
  - 取经团队（**唐僧/孙悟空/猪八戒/沙僧/白龙马**）历劫。
  - 孙悟空为**石猴**（女娲补天遗石所化，一说东胜神洲花果山灵石）。
  - 大闹天宫 → 如来镇压（五行山五百年）→ 观音点化 → 唐僧（金蝉子十世轮回）西行。
- **格局**：佛道平衡；道门默认佛教东传，换取气运分配。
- **结果**：佛教确立，众角色再应劫；孙悟空成斗战胜佛。
- **深层博弈**：西行路是天道安排的"佛道分赃"——九九八十一难本质是各路妖魔（多为天上坐骑/童子下凡）的应劫舞台。
