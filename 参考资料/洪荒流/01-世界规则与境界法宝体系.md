# 01 · 世界规则 · 境界体系 · 法宝谱
> 洪荒流深度资料 · 世界运行的底层法则（我们「因果守恒+因果调度」机制的根基）

## 一、世界规则（底层法则）

### 1. 天道
洪荒最高运转法则。**鸿钧合道**后，鸿钧即天道化身（居紫霄宫）。天道无私无情，以"量劫"清算因果、平衡气运。天道之下，圣人亦受制约（封神即天道清算三教）。

### 2. ★因果（守恒律）—— 我们机制的原生土壤
- **因果不灭**：种因必果，业力随身，跨量劫不清零。
- **因果守恒**：一笔命债/业力不会凭空消失，只转移。**救 A 免死，则其死局因果转嫁给 B**——这正是我们「因果调度」的硬法则。
- **量劫 = 天道调度因果**：众生因果积累到临界，天道降下量劫，以大劫"清账"（大量生灵应劫身亡偿还因果）。
- → 主角的「因果调度」本质 = **抢在天道量劫之前，自己手动调度因果**（断链+转嫁+化解），改写必死结局。

### 3. 气运 / 功德 / 业力
- **气运**：命格/运势。气运旺者机缘多、化险；气运衰者倒霉/应劫。**可被夺/被转**（红云得紫气=气运暴涨→招祸）。
- **功德**：对天地有大功（女娲造人、后土化轮回、老子化胡）所获，可抵业力、助成圣。
- **业力**：杀业/恶因积累，招量劫清算。龙凤三族即背滔天业力退场。

### 4. 圣位 / 鸿蒙紫气
- **圣位**：成圣=混元大罗金仙，超脱量劫、不死不灭、与天道同寿。洪荒顶层。
- **鸿蒙紫气**：成圣之基（天道凭证），鸿钧所赐，**仅七道**（三清+女娲+接引+准提）。红云意外得一道→招祸根源。
- 成圣三法：① **斩三尸证道**（斩善/恶/自我三尸）② **功德证道**（立大功）③ **法力证道**（力破）——皆需鸿蒙紫气为基。

## 二、境界体系（修为等级，由低到高）

### 凡境（凡人修仙段）
炼气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫

### 仙境
| 境界 | 说明 |
|------|------|
| 散仙 | 渡劫失败/兵解重修，未受仙箓 |
| 地仙 | 受仙箓，未登天 |
| 天仙 | 正式登仙 |
| 真仙 | 肉身不朽、元神不灭 |
| 玄仙 | 领悟法则玄妙 |
| 金仙 | 法则初成，金口玉言 |
| 太乙金仙（太乙散/真/玄/金） | 仅次于大罗；截教四大弟子、阐教十二金仙多在此档 |
| 大罗金仙 | 超脱时间长河，万劫不磨（"大罗"=一切时空永恒逍遥） |
| 准圣（大罗金仙巅峰/斩一尸二尸） | 半步圣人 |

### 圣境/道境
| 境界 | 说明 |
|------|------|
| 混元大罗金仙（圣人） | 成圣，超脱量劫，不死不灭 |
| 天道（鸿钧） | 合道，即天道 |
| 大道 | 超脱天道（盘古未竟之境） |

> **洪荒流战力通胀警告**：洪荒是"金仙遍地走、大罗不如狗"的高战力世界。写凡境→金仙段是常规难度；太乙以上战力极难驾驭，新人作者易崩。**我们的书若从微末写，建议境界推进克制（凡境→天仙→金仙为主），把爽点放在算计/布局/因果调度，而非战力碾压。**

## 三、法宝谱（分级 + 主要法宝归属）

### 法宝等级（由高到低）
1. **混沌至宝**：开天前混沌中诞生（开天神斧残骸等），镇压混沌。
2. **先天至宝（开天三宝）**：开天神斧所化——**太极图、盘古幡、混沌钟**。可镇压大教气运、重定地水火风。
3. **先天灵宝**：先天地而生。分极品（定海珠、山河社稷图、十二品莲台）/ 普通。
4. **功德法宝**：以功德炼成（先天功德至宝等）。
5. **后天灵宝 / 后天法宝**：后炼制，威力递减。
