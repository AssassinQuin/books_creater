## 一、洪荒地理框架

### 1.1 洪荒大地结构
洪荒大地分**四大部洲**（+中央/天界/幽冥），源自佛教《阿含经》世界观 + 道教融合设定：
- **来源**：盘古身躯所化四大部洲（一说盘古倒下后躯体碎裂为四大部洲 + 三千小世界）。
- **天界（三十三重天）** 在上，**幽冥/地府**在下，**洪荒大地**居中。
- **四海**环绕洪荒大地（东海/南海/西海/北海），四海龙王各治其一。

### 1.2 四大部洲详解

| 部洲 | 位置 | 灵气特点 | 主要居民 | 关键地点 |
|------|------|---------|---------|---------|
| **东胜神洲** | 东 | 灵气最充沛，先天灵脉汇聚；修真圣地 | 三清道场邻近；仙修云集 | 花果山（西游）、金鳌岛碧游宫（截教）、蓬莱仙岛 |
| **南赡部洲** | 南 | 灵气中等；人族气运所在，人族气运鼎盛之地 | 人族主体（巫妖后人族崛起核心）；后期凡人王朝所在 | 牧野（封神战场）、长安、武夷山、五台山 |
| **西牛贺洲** | 西 | 灵气贫瘠（道魔之战毁西方祖脉）；佛教大兴后灵气复盛 | 佛教根基；后天灵山主 | 灵山/大雷音寺、须弥山（罗睺旧战场）、万寿山五庄观（一说在此） |
| **北俱芦洲** | 北 | 灵气杂乱、煞气重；蛮荒之地 | 妖族退守、凶兽余孽、蛮族；巫妖余波后巫族残余 | 妖族余脉据点、凶兽封印地 |

- 部洲归属在不同洪荒小说中差异大，如截教碧游宫在东胜神洲金鳌岛 / 东海金鳌岛 / 北海金鳌岛等版本皆有。
- "中神州"有时单列，有时合并入南赡部洲。

### 1.4 幽冥 / 地府

**幽冥界结构**（后土化六道轮回后立）：
- **幽冥海**（冥河老祖领地，血海相连）
- **血海**（冥河老祖老巢，阿修罗族所在）
- **地府 / 阴曹地府**（十殿阎罗所辖）
- **六道轮回**（天道、阿修罗道、人道、畜生道、饿鬼道、地狱道）—— 后土身化

**地府治理演变**：
- 巫妖后：巫族残余（蚩尤一说化阎王）入地府
- 封神后：阐教广成子下地府身化**十殿阎罗**（一说）；西方教**地藏王菩萨**于阴山大发宏愿"地狱不空，誓不成佛"
- 双方妥协：道教承认地藏入住，西方教未撼动道教三界主导

## 六、对我们主角的地理意义

- **主角起点**（若红云）：红云本体是"洪荒第一朵红云"，游走无定所（散修），可在任一部洲开局。**紫霄宫**（让座/得紫气）是核心因果节点。
- **因果调度场景**：每个必死角色的因果链分布在不同地点（太阳星/血海/不周山/碧游宫/须弥山/牧野...），主角改命需奔波介入。
- **地理即博弈盘**：
  - 西方贫瘠（道魔之战毁）→ 接引准提立教必发宏愿 → 截教残余被西方收 → 佛教东传 → 西游之因
  - 不周山（天柱）折断 → 女娲补天 → 遗石化孙悟空 → 封神/西游关联点
  - 血海（冥河不死）→ 冥河与红云因果 → 红云之死的关键参与者
  - 北俱芦洲（妖族退守）→ 妖族残余 → 后期妖族复兴伏笔
- **小而美 vs 宏大**：洪荒地理本宏大（四洲+天界+幽冥），但百万字不必走遍——聚焦 2-3 个部洲 + 关键圣地即可，其余作背景。
