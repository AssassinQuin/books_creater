## 一、十二祖巫（完整版）

> 来源：《佛本是道》及衍生洪荒流。形态出自《山海经》《淮南子》。
> 〔版本A〕盘古精血所化。不修元神、纯肉身成圣。天生可操纵自然法则。
> 〔版本B·《佛本是道》原著〕祖巫**有元神、先天不足**。
> 十二人合布**十二都天神魔大阵**（又名**十二都天神煞大阵**）可凝聚**盘古真身**（圣人级战力·需十二人齐聚）。
> 来源：[搜狗百科·十二祖巫](https://baike.sogou.com/v652986.htm)｜[百度百科·十二祖巫](https://baike.baidu.com/item/十二祖巫/10491270)

| 祖巫 | 法则/能力 | 形象 | 命运 |
|---|---|---|---|
| **帝江** | 空间法则（+速度·瞬移大师·一个念头穿越万里） | 如黄囊/赤如火/六足四翼/无面目/通晓歌舞 | **祖巫之首**。巫妖战遭仙道围攻而殒 |
| **烛九阴** | 时间法则（睁眼为昼/闭眼为夜/能操控时间流转甚至逆转时光） | 人面蛇身/赤 | 巫妖战陨（一说为护同伴耗尽本源，陷入永久沉睡） |
| **祝融** | 火法则（火爆脾气/天生火焰主宰/所到之处烈焰滔天） | 兽身人面/红鳞/耳盘火蛇/乘两龙 | 与共工不和→大战→**巫妖前已死** |
| **共工** | 水法则（蟒头人身/一怒引发洪水） | 蛇身红发/黑鳞覆体/缠青蟒/踏黑龙/乘两龙 | 与祝融战→怒触**不周山**→天柱折→天倾→天河倒灌→女娲补天。**巫妖末自毁** |
| **后土** | 土/大地法则（中央土之祖巫/人身蛇尾/七手/握腾蛇/掌控大地山川） | （详见文件12） | **化六道轮回**（被尊"后土娘娘"/"大地之母"） |
| **句芒** | 木/春法则（青竹身/鸟面人身/挥手催生万木） | 鸟身人面/乘两龙 | 巫妖战陨 |
| **蓐收** | 金/秋法则（人面虎身/金鳞/肩有翅/挥手召万千金戈） | 左耳有蛇/乘两龙 | 巫妖战陨 |
| **玄冥** | 冰/冬法则（呼风唤雨/冻结天地） | 人面鸟身/两耳悬蛇 | **修为最强**。巫妖战与太一**同归于尽**〔一说独存〕 |
| **天吴** | 风法则（虎身八尾/跑动掀起狂风） | 虎身十尾/人面 | 巫妖战陨 |
| **强良** | 雷法则（一声怒吼引发惊雷） | 虎头人身/马蹄/长手肘/嘴衔蛇/操蛇 | 巫妖战陨（强良胞妹=大巫九凤） |
| **奢比尸** | 天气法则（精准掌控阴晴冷暖） | 人面兽身/狗耳/两耳悬蛇 | 巫妖战陨 |
| **翕兹（弇兹）** | 电法则（挥手引出闪电/与强良的雷声构成雷暴） | 人面鸟身/两耳悬蛇/手拿红蛇 | 巫妖战陨 |

> **本书应用**：后土是核心角色（已详述）。其余祖巫为群像（巫妖战背景）。祝融共工大战→不周山断→天倾→女娲补天是巫妖量劫末尾重大事件。
> **巫妖战前削弱链**：祝融共工大战→双双身殒→祖巫剩十→后土化轮回→祖巫剩九→决战时祖巫不足十二→都天神魔大阵无法凝聚完整盘古真身→战败加速。

## 三、截教核心弟子（封神主线相关）

### 多宝道人
- 截教**大弟子**。通天首徒。实力在截教众仙中第一
- 封神中：代师出手→被老子生擒→后归西方教→**多宝如来**（佛教）
- 名字含义："多宝"=拥有很多法宝

### 金灵圣母
- 截教**二弟子**。通天倚重。万仙阵中代通天指挥
- 法宝：龙虎玉如意/四象塔/金霞冠
- 封神中：万仙阵被燃灯用定海珠偷袭→陨落→封神为**斗姆元君**（星宿之母）

### 无当圣母
- 截教弟子。**万仙阵后唯一逃出**的截教核心（"道行未失"）
- 传说后归隐/或入佛教。象征截教最后的火种

### 赵公明
- 截教外围弟子（三霄结义兄长）。**财神爷**
- 法宝：**定海珠**（二十四颗/打人无往不利）+缚龙索
- 封神中：定海珠大杀阐教→被陆压**钉头七箭书**暗算→七日而死
- 封神后封为**金龙如意正一龙虎玄坛真君**（财神）

### 三霄娘娘（云霄/琼霄/碧霄）
- 赵公明结义妹妹。截教弟子
- 法宝：**混元金斗**（收仙收人/削三花废修为）+**金蛟剪**（两条蛟龙化剪/可斩仙）
- **九曲黄河阵**：以混元金斗为核心→削去阐教**十二金仙顶上三花/胸中五气**（废修为）→需老子亲自出手才破
- 故事线：赵公明被陆压暗杀→三霄下山报仇→摆黄河阵废十二金仙→老子/元始出手破阵→三霄身死→封神为**感应随世仙姑**（执掌混元金斗/管转劫生育）
- **本书应用**：卷五金蝉脱壳的**黄河阵引爆身份**事件。云中子在黄河阵中福报面激活→与红云本体共振→独立成道。三霄的黄河阵是引爆场地。

## 五、三皇五帝（人族时代·卷四核心）

> 巫妖量劫后，人族趁权力真空崛起。三皇五帝治世。
> 来源：[B站·最详细总结洪荒神话体系](https://www.bilibili.com/read/cv4680920/)｜[搜狗百科·洪荒时代](https://baike.sogou.com/v561701.htm)

### 三皇（版本异，主流洪荒版）

| 三皇 | 贡献 | 洪荒设定 |
|---|---|---|
| **燧人氏（天皇·版本B）** | 钻木取火→人族脱离茹毛饮血 | 一说先天神圣转世/一说纯人族英杰 |
| **伏羲氏（太昊/天皇·版本A）** | 演八卦/造书契/教渔猎/定嫁娶 | **先天神祇伏羲陨落后转世人族**→以人族之身演八卦→人文始祖（与女娲兄长伏羲同一人） |
| **神农氏（炎帝/地皇）** | 尝百草/教农耕/立医药 | 人族英杰/一说炎帝部落首领 |
| **黄帝（轩辕/人皇·版本B）** | 阪泉之战败炎帝/逐鹿之战败蚩尤 | 广成子弟子→被尊**人皇**（有时列入三皇有时列入五帝） |

> **版本差异**：三皇具体名单在不同典籍和小说中版本极多。洪荒流主流采用"**伏羲/神农/黄帝**"或"**燧人/伏羲/神农**"。

### 五帝
| 五帝 | 事迹 |
|---|---|
| **黄帝（轩辕）** | 广成子弟子→阪泉之战败炎帝（炎帝归顺）→**逐鹿之战败蚩尤**（昊天派九天玄女赠天书支援）→被尊**人皇** |
| **颛顼** | 暗算大巫九凤（九凤逃入洪荒星空炼化三星辰=七杀/破军/贪狼）。绝地天通（切断天地通道） |
| **帝喾** | 黄帝曾孙 |
| **尧** | 圣贤之王/选贤任能/禅让于舜 |

> **另版本五帝**：少昊/颛顼/帝喾/尧/舜（不含黄帝，因黄帝列入三皇）。

### 火云洞
- **三皇隐居之所**=人族圣地
- 洪荒设定：火云洞是人族气运核心，三皇在此守护人族气运
- 三皇不出世但任何敢动火云洞的人都会被人族气运反噬
- **本书关键**：火云洞/古老洞天与人道规则的关联（本书魔改：古老洞天蕴人道规则/崆峒印）

### 蚩尤/刑天/九凤（大巫·人族时代残余）
| 角色 | 事迹 |
|---|---|
| **蚩尤** | 大巫/铜头铁额/率九黎部落→以巫族秘术造十二都天神煞大阵（欲聚祖巫之灵）→与炎黄战→逐鹿之战败→被杀→传说阎王=蚩尤所化 |
| **刑天** | 大巫/助炎帝→逐鹿之战后一怒欲伐天庭→被昊天斩首→以乳为目以脐为口/操干戚舞（"刑天舞干戚，猛志固常在"）→怨念吓跑昊天 |
| **九凤** | 大巫之首（强良胞妹）/主张人巫和谐→被颛顼偷袭算计→中轩辕剑→重伤逃入星空→炼化七杀/破军/贪狼三星→图复仇 |

> **本书应用**：卷四三皇五帝时代实质内容。红云见证人族崛起的具体故事（燧人取火/伏羲演八卦/神农尝百草/黄帝战蚩尤）。火云洞=人族圣地=古老洞天人道规则锚点。

## 六、罗睺（魔祖·龙凤初劫大反派）

| 阶段 | 事件 |
|---|---|
| **身份** | 混沌三千魔神之一（杀之大道/魔道法则）。洪荒流中"魔祖"形象最早由网络作家李色佛在2008年小说《洪荒玄松道》中编撰成形，原型取自印度神话中的星神 |
| **起源** | 〔版本A〕盘古开天时被重创，残魂遁入洪荒转生。〔版本B〕混沌魔神残魂融合混沌杀伐浊气诞生。〔版本C〕洪荒开辟之初由混沌魔神怨念与先天煞气汇聚而成的先天魔主 |
| **法宝** | **诛仙四剑+诛仙剑阵图**（出世时伴随四把剑胚和阵图·"诛仙剑阵，戮仙弑神"·以杀证道）+ **弑神枪**（混沌至宝·混沌青莲根茎所化·攻伐之力超强·罗睺在洪荒西方养伤时与之产生先天感应）+ **十二品灭世黑莲**（混沌青莲所化·防御至宝·后被蚊道人食去三品） |
| **龙凤初劫** | 暗中挑拨三族（祖龙/元凤/始麒麟）相争→吸收杀伐之气→以三族精血怨气强行打开盘古封印→得诛仙四剑→布诛仙剑阵→欲以杀伐证道→重塑混沌 |
| **道魔之争** | 鸿钧联合**杨眉大仙+阴阳道人+乾坤道人+时辰道人**等大能共破诛仙阵。阴阳/乾坤自爆元神重创罗睺；时辰被罗睺斩首；杨眉牵制罗睺主力；鸿钧以诸天庆云护体 |
| **被灭** | 诛仙剑阵虽强但被破→**罗睺被鸿钧所灭**（一说自爆而亡）→魔道退场。残留魔念化作心魔，永世纠缠诸天修士 |
| **遗泽** | 诛仙四剑被鸿钧收回→分宝岩分给通天→通天借此领悟诛仙剑阵。弑神枪下落不明。十二品灭世黑莲下落不明。鸿钧将罗睺手下三千魔神元神炼化成诛仙剑（部分版本） |
| **本书应用** | 卷一龙凤初劫背景大反派。红云不直接参与罗睺vs鸿钧（顶层对决），但龙凤初劫的余波影响他的世界 |

> **来源**：[百度百科·罗睺（洪荒魔祖）](https://baike.baidu.com/item/罗睺/20425543)

### Canon（封神演义原设）

### 洪荒流设定（红云转世）
- 洪荒流：云中子=**红云老祖转世**→所以天生是"福德之仙"（红云的善因转化）
- 红云被杀后葫芦护元神度入轮回→转世成云中子→以人族之身重新修行

### 本书魔改
- **不是转世，是命数分裂**：红云被救时代价=一段命数溢出化成独立灵魂（云中子=福报面）。红云本体残存（劫数面）
- 云中子是**独立的人**，非红云分身/工具
- **canon呼应**：本书的"命数分裂"与canon的"转世"呼应——红云的善因/福报化为云中子，与canon转世逻辑一致
- 卷二诞生→卷四进阐教显福德之仙→卷五黄河阵引爆身份→独立成道

## 补充：巫妖大战后的世界格局变化

> 来源：[搜狗百科·洪荒时代](https://baike.sogou.com/v561701.htm)｜[百度百科·巫妖大战](https://baike.baidu.com/item/巫妖大战/10331701)

1. **天庭新秩序**：三清推举鸿钧身边童子（昊天）为天帝、童女（瑶池）为王母
2. **六道轮回归天庭**：后土化轮回后，六道轮回不归巫族掌握，归天庭管辖，即建立地府
3. **三卷天书流传**：封神榜（元始）、生死簿、地书（镇元子）——其中地书最为神秘，为天地胎膜
4. **阐截兴起**：阐教（元始/十二金仙/云中子）、截教（多宝/无当/金灵/三霄/赵公明等）兴起
5. **西方教演化为佛教**：接引=阿弥陀佛/准提=菩提祖师。渡化截教残余+阐教叛将入佛教
6. **帝俊第十子**化身为陆压道人，以斩仙飞刀在封神大战中大放异彩
7. **人教大兴**：人族从被妖族屠戮、巫族漠视的弱小种族→三皇五帝治世→洪荒主角
8. **地仙界迁移**：地球被打小，人间界灵气日益稀薄→有神通者都去了地仙界，只在地球留下了道统
