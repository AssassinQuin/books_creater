# Phase 2 · 框架提炼综合（SKILL.md 蓝图）

> 本文是 plot-methodology skill 的直接构建蓝图，基于 01-05 调研文件综合提炼。
> 提炼者：主 agent（战略层）。调研截止：2026-07-27。
> 三重验证标准：跨域复现（≥2 场景）/ 生成力（能指导新问题）/ 排他性（非通用道理）。

---

## 一、心智模型 M1-M6（情节方法论镜片）

### M1 · 悬念第一性（The Suspense Prime）
- **一句话**：情节的引擎不是结构骨架、不是人物弧线，而是「读者想知道接下来」；悬念=创造和延长预期。
- **来源证据**：① 全书副标题把悬念与人物、冲突并列；② Ch5「只要有悬念，读者通常就会坚持看完作品」；③ agent3 定位——卢克曼是唯一把「读者想知道接下来」作为情节第一性原理的理论家，与麦基鸿沟最近邻但回答「如何让读者一直看下一拍」。
- **应用方式**：每章/每场景自检「读者此刻在期待什么？这个期待是被制造还是被消耗？」
- **局限**：悬念不能空转——「为悬念而悬念」（猫跳出来）会被读者埋怨；悬念必须是经历的附属品。
- **网文适配**：✅ 高度契合。直接对接网文「章末钩子」「追读率」逻辑。短钩子（每章）+ 长主线（贯穿卷）双层设计。

### M2 · 冲突心理学化（Conflict as Internal Compensation）
- **一句话**：外部冲突是内心冲突的代偿；冲突的最高形式是内心冲突（外部可解决、避免、忽略，内心不能）。
- **来源证据**：① Ch6「我们经常渴望甚至制造外部冲突，以便不去思考内心冲突」；② Ch6 题词「一切冲突都是与自我的战斗」；③ 「冲突的可能性 > 冲突的现实」——即使不爆发也维持悬念。
- **应用方式**：设计冲突时先问「主角的内心冲突是什么？」，外部冲突作为其外化与代偿。
- **局限**：纯粹的内心冲突在快节奏类型小说里会拖；需外化为可见行动。
- **网文适配**：⚠️ 改造。网文「爽文学观」下冲突功能是「释放情绪」而非「勘探现实」。但「内心冲突外化为打脸/逆袭」依然成立——把卢克曼的「内心冲突」翻译成「主角的核心执念/不甘」，外部冲突（反派打压）作为其代偿爆发点。

### M3 · 经历三层深度（Three Depths of Experience）
- **一句话**：人物弧线深度分三级——认识他人 → 认识自我 → 在认识基础上行动（最深刻，人物「完全变成另一个人」）。
- **来源证据**：① Ch4 三种深度经历递进；② 「在认识基础上采取行动是所有经历中最深刻的」；③ 表面经历（恋爱/物质/友谊等 7 类）vs 深度经历的二分。
- **应用方式**：评估人物弧线时定级——只在第 1 层（认识他人）= 浅；到第 3 层（行动改变）= 深。
- **局限**：不是所有类型都需要第 3 层（喜剧/爽文可在第 1-2 层循环）。
- **网文适配**：⚠️ 部分舍弃。网文主角弧线以「目标达成+实力升级」为主，深度经历第 3 层「变成另一个人」常被弱化。但卷高潮可用第 2 层（认识自我执念）放大共鸣。skill 提供「深度档位」参数：快节奏爽文锁 L1-L2，文青向可冲 L3。

### M4 · 行动显现论（Action Over Thought）
- **一句话**：人物的真实本质只能通过环境和行动显现，不能通过内心独白——「200 页思考爱，然后举枪杀友，这书讲的是杀人不是讲爱」。
- **来源证据**：① Ch3「只有通过环境我们才能看到人物如何行动」；② Ch4 深度经历第 3 层=行动；③ agent1 标为全书最重要的反「内心独白至上」宣言。
- **应用方式**：写人物时先问「他做了什么」而非「他想了什么」；用「通过别人的眼睛」（indirect characterization）替代作者旁白。
- **局限**：关键节点的内心戏仍有价值（放大爽点/共鸣），不是完全禁用。
- **网文适配**：✅ 高度契合且强化。网文铁律「行动展示内心，不用旁白介绍」正是此原则。网文更极端——大段心理直接掉追读。

### M5 · 上下文宏观评判（Context as Macro Judgment）
- **一句话**：一切元素都是相对的，必须在整体中被评判；人物由上下文塑造（一个主要人物只有相对其他人物才是主要的）。
- **来源证据**：① Ch7「写作是一支交响乐，没有什么是独立存在的」；② 「人物是由上下文来塑造的」；③ 上下文头号敌人=重复；④ 节奏/进展/意义都是相对的（对比满足原理）。
- **应用方式**：编辑视角俯瞰——篇幅分配、场景移植、重复清单、人物移植。
- **局限**：上下文充分铺垫在快节奏类型里会让位给「边走边带」。
- **网文适配**：⚠️ 改造。网文不能预先铺背景，但「上下文塑造人物」（用配角衬托主角光环）、「对比满足」（虐后爽的对比）、「重复是头号敌人」依然高度适用。skill 保留「俯瞰自检」工具，改造「铺垫方式」。

### M6 · 阅读心理曲线（The Reading Psychology Curve）
- **一句话**：读者卷入度分四级——好奇 → 兴趣 → 需要 → 行动；好作品要把读者推向更高阶。
- **来源证据**：① Ch8 四阶段模型；② 每阶段达成作品比例递减（好奇=所有，行动=极少）。
- **应用方式**：作为读者卷入度的评估标尺，定位「你的作品把读者停在哪一阶」。
- **局限**：分级偏主观；「行动」阶在商业类型里少见。
- **网文适配**：✅ 直接对接网文留存率。好奇=点击率，兴趣=追读率，需要=加书架/打赏，行动=安利/二创。这是卢克曼与网文最天然的桥梁之一。

## 二、元方法（贯穿性工作骨架，不单列为镜片）

### 元方法 A · 递进管线（Pipeline）
人物（基石 Ch1-3）→ 经历（必须变化 Ch4）→ 悬念+冲突（经历的质地肌理 Ch5-6）→ 上下文（宏观定型 Ch7）→ 超越（Ch8）。
**用途**：作为 skill 的主工作流骨架——按这个顺序诊断/构建情节。

### 元方法 B · 经纪人诊断式（Diagnostic over Heuristic）
来源：agent2 发现——卢克曼是写作教程领域极少数从经纪人位置写书的作者。结构 DNA = **诊断 → 修复 → 练习**，从明显到微妙。
**用途**：skill 的每个工具都按「问题症状 → 根因 → 修复动作 → 自检」组织，而非空泛启发。这正好补上原书被批评的「What 不教 How」断层（agent5）。

## 三、决策启发式（10 条「如果 X 则 Y」）

1. **如果读者不知道人物想要什么** → 没有目标就没有悬念 → 先立目标（M1）
2. **如果冲突依赖极端环境而非人物** → 警告：人物先行，环境从人物生长（M2）
3. **如果悬念场景只让猫跳出来** → 失败：延长悬念必须有实质，否则读者埋怨（M1）
4. **如果人物 200 页都在想** → 提醒：思想不算数，让他行动（M4）
5. **如果两个角色没有冲突可能性** → 即使不爆发，也要保留可能性（制造悬念层）（M2）
6. **如果每个场景都很紧张** → 反效果：上下文需要喘息，对比才有效（M5）
7. **如果开头太精彩** → 警告：提高门槛后难以为继，均衡开始按部就班（M5）
8. **如果想埋长线伏笔** → 「冲突的可能性」比「冲突的现实」更维持追读（M2）
9. **如果情节靠「伟大的创意」** → 反目标：创意需人物+悬念+冲突支撑（反模式）
10. **如果用大段内心独白** → 网文直接掉追读，改为行动展示/关键节点 200-500 字（M4+网文）

## 四、网文适配映射（skill 核心价值）

| 卢克曼原则 | 处理 | 网文做法 |
|---|---|---|
| 因果链纪律 | ✅ 保留 | 伏笔-回收严格因果，金手指不能临时加 |
| 张弛节奏 | ✅ 保留（天然桥梁） | 每章一小爽/3-5 章一中爽/每卷一大爽，平路≤3 章 |
| 四幕结构 | ✅ 保留 | 单卷内严格四幕 |
| 反转伏笔回收 | ✅ 保留 | 反转=多伏笔回收=卷高潮核心爽感 |
| 人物驱动 | ⚠️ 改造 | 目标+金手指+阻碍 三件套替代纯心理驱动 |
| 内心生活 | ⚠️ 重度改造 | 行动展示为主，仅卷高潮用 200-500 字内心戏 |
| 上下文铺垫 | ⚠️ 改造 | 开篇即冲突，语境「边走边带」 |
| 悬念 | ⚠️ 核心改造 | 短钩子密布（六式）+ 长主线兜底 |
| 多维视角 | ⚠️ 改造 | 默认主角单视角，卷高潮可切≤10-15% |
| 复杂心理深度 | ❌ 舍弃 | 大段内心戏直接掉追读 |
| 现实质感冲突 | ❌ 舍弃 | 接受套路化（打脸/装逼/升级）但给「功能性真实」 |
| 主题渐显 | ❌ 舍弃 | 主题在简介+金手指明示 |
| 象征隐喻 | ❌ 舍弃 | 罕用；如需深层走「情怀」路径 |
| **金手指**（网文独有） | ➕ 叠加 | 与情绪高点一一对应，主角被压到极限时给逆转能力 |
| **爽点密度模型**（网文独有） | ➕ 叠加 | 三级爽点（小/中/大）+ 六种手法 |
| **章末钩子六式**（网文独有） | ➕ 叠加 | 怪物睁眼/危机/身份揭露/反转/情绪炸弹/信息投放 |
| **平台节奏差异**（网文独有） | ➕ 叠加 | 8 平台对照（番茄/七猫/起点/晋江/飞卢…） |

## 五、价值观与反模式

### 核心价值观（卢克曼）
1. **人物自治**：充分发展的人物会接手故事
2. **真实+爱**：写作伦理的最高原则
3. **反公式**：没有规则、没有公式、没有步骤
4. **行动>思想**
5. **经纪人务实**：可证伪的具体性（每个论断落到可验证文本特征）

### 反模式（卢克曼反对）
- 伟大的创意决定论
- 公式写作 / 「20 种基本情节」模板
- 现实主义至上
- 为深刻而深刻
- 大段内心独白至上
- 依赖极端环境制造冲突
- 为悬念而悬念（无实质的延长）

### 网文语境下的价值观补充
- **套路合法性**：套路是市场检验过的「读者欲望模板」，与卢克曼反公式立场需调和
- **快感投放优先**：爽文学观下，意义伴随快感产生（颠倒卢克曼的「情节服务意义」）

## 六、核心张力（skill 的灵魂，必须诚实声明）

> **卢克曼「文学性优先」（意义、深度、上下文铺垫、人物自治）⟷ 网文「爽文学观」（快感投放、即时满足、套路合法性、目标驱动）**

这不是缺陷，而是 skill 存在的理由：**做文学理论→网文实践的适配翻译**。
- agent1 把上下文/心理深度当卢克曼**优势**
- agent4 指出这些在网文要**舍弃/改造**
- agent5 揭示原书**隐性反对套路、对网文零验证**
→ skill 必须明确告诉用户：哪些原则在网文成立且提升质量，哪些需改造，哪些必须舍弃。

## 七、智识谱系与坐标

- **站在肩上**：亚里士多德（净化）→ 希区柯克（悬念预期论）→ 斯坦尼斯拉夫斯基（体验派冲突练习）→ 尼采（骆驼→狮子）→ 罗宾斯/佛教（预期心理学）
- **对比坐标**（agent3）：与麦基「鸿沟」最近邻——麦基解释「为什么这一拍爆」，卢克曼解释「如何让读者一直想看下一拍」；与特鲁比同属人物驱动阵营但卢克曼以悬念为引擎；与救猫咪互补（救猫咪给节拍位置，卢克曼给人物-悬念填充）
- **独特位置**：唯一把「读者想知道接下来」作为情节第一性原理 → 为商业连载小说（网文/类型小说）提供经典理论未直接回答的可操作路径

## 八、诚实边界（skill 必须前置声明）

1. **文学 vs 网文错位**：原书隐性假设文学性优先，对网文/爽文/类型小说零验证、隐性反对套路。skill 是「翻译」而非原貌复述。
2. **What 不教 How 断层**：原书被批评只讲做什么不讲怎么做（agent5）。skill 通过「诊断→修复→练习」结构补上，这是 skill 的增量价值。
3. **电影举例多过小说**：原书大量用电影案例（因电影是纯情节媒介）。skill 在网文场景需重新举例。
4. **2002 年成书**：例子陈旧，网文生态未覆盖。skill 已用 2026 网文资料更新。
5. **Goodreads 3.8 同类中位偏下**：非公认最顶级教程（不及 King/McKee/Snyder）。取其独特价值（悬念第一性 + 经纪人诊断视角），结构骨架补救猫咪。
6. **方法论是检查工具，不是生成模板**：卢克曼本人反公式。skill 提供深度检查工具，不提供「照着填就出情节」的模板。
7. **不能替代实操与阅读**：方法论降低试错，不替代大量读写训练。
8. **调研截止 2026-07-27**；网文平台规则与算法持续变化。
