# 经历深度诊断 (Experience Depth)

## R — 原文 (Reading)

> "深度经历1：认识他人……深度经历2：认识自我……深度经历3：在认识的基础上采取行动……在认识的基础上采取行动是所有经历中最深刻的。在这种经历结束时，人物彻头彻尾地变成了另一个人，完全认不出来了。"
>
> — 诺亚·卢克曼, 第4章 经历

---

## I — 方法论骨架 (Interpretation)

诊断人物"真变了还是表面变了"的四条标尺：

① **旅程 > 目的地**。满足感来自信息传播的过程，不是信息本身；作家首要决策是"保留什么"，而非"透露什么"。

② **深度经历三层递进**：认识他人 → 认识自我 → 在认识上行动。每上一层更深但也更难；停在第一层是最常见的困境——"觉醒了却重复旧模式"，看清真相但治标不治本。

③ **表面经历7类只是入口**：恋爱/物质/身体状况/友谊/知识/名望/家庭。它们易得、可见、社会普遍认可，常被误当深度经历；最大价值是作为引导入口——尤其消极的"失去"类（失去地位/破产/家庭破裂）更容易激发自我认识的深度经历。

④ **多段经历的编织关系决定故事质地**：相辅相成（接力棒）/ 相互冲突（最强，能强制开启深度经历）/ 平行滋养（交汇于同一终点）/ 开启新纪元（续集逻辑）。相互依存的经历 > 单一经历；冲突的经历 > 和谐的经历。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 《洛奇》——三段经历相互依存（c19）

- **问题**: 一个拳击励志片如何不止于"打赢比赛"这一单一目标，而让人物变化有重量？
- **方法论的使用**: 用 **经历编织术**——把身体训练、心理复健、爱情三段经历交织。当洛奇心灰意冷停止训练时，第二段（心理复健）反向影响第一段（身体训练）；最终是第三段（爱情）让前两段回心转意。三段经历像接力赛选手交接棒，一段卡住时另一段从其停止处续接。
- **结论**: 多段相互依存的经历 > 单一经历；爱情线（深度经历）反向推动体育线（表面经历），打破单一经历的扁平。
- **结果**: 影片最终镜头是洛奇呼唤女友——"《洛奇》归根结底是个爱情故事"。体育片因深度经历层获得跨类型共鸣，成为经典，并衍生出成功续集。

### 案例 2: 《教父》《洛奇》《星球大战》首集——开启新纪元的经历（c21）

- **问题**: 首集如何在自身令人满意的同时，又为续集留出空间？
- **方法论的使用**: 用 **经历编织术第④种"开启新纪元"**——结尾既圆满解决 95%，又留 5% 悬而未决，让此刻的经历终点自然成为下一段经历的起点。
- **结论**: 作者称之为"写作中最难实现的目标之一"——"看着路的同时还要向上看"。完成当下经历与开启新经历必须同时发生。
- **结果**: 三部首集都衍生出成功续集，证明"开启新纪元"的结构设计本身具有 IP 延展力。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **读者/审稿反馈"那又怎样"**——主角结尾当上 CEO / 暴富 / 恋爱成功，读者却无代入感
2. **人物弧线平淡**——升级流却无代入感，越读越觉得主角是个工具人
3. **"人物没成长"的直觉**——堆了很多事件，但内核信念从未被挑战
4. **审查"扁平人物"**——判断是人物塑造问题，还是经历深度不足

### 语言信号 (用户的话里出现这些就应激活)

- "人物没成长" / "主角没变化"
- "弧线平淡" / "弧线太薄"
- "那又怎样" / "so what"
- "character arc flat" / "stagnant" / "no growth"
- "主角就是个工具人" / "读不出他想要什么"

### 与相邻 skill 的区分

- 与 `inner-conflict` 的区别: 本 skill 诊断**变化是否发生、变化多深**（人物弧线的纵向深度）；inner-conflict 制造**当下"知道该做却做不到"的内心张力**（横向紧张感）。一个问"变了没"，一个问"卡在哪"。
- 与 `reading-psychology-curve` 的区别: 本 skill 在**人物层**（角色变化深度）；后者在**受众层**（读者投入到了好奇/兴趣/需要/行动的哪一阶段）。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **盘点人物的经历清单，区分表面 vs 深度**
   - 列出主角遭遇的所有经历，逐条标注："表面（7类之一：恋爱/物质/身体状况/友谊/知识/名望/家庭）" 还是 "深度（三层之一：认识他人/认识自我/在认识上行动）"。
   - 完成标准: 清单完整且每条有标注。若清单全是表面经历、无任何深度层 → 已定位问题，进入步骤 3。

2. **检查三层认识是否发生**
   - 对每一层逐一问: ①主角是否认识了某个重要他人的真相（不再自欺）？②是否由此认识了自己的某个内核信念/恐惧/渴望？③是否在认识基础上采取了与过去截然不同的行动？
   - 完成标准: 三层都有明确"是/否"判定并附文本证据。
   - 判停条件: 若 ①②③ 全否 → 跳到步骤 3 设计触发；若 ③ 已发生 → 人物已"真变了"，问题不在经历深度，停止本 skill。

3. **若只有表面经历 → 设计一个"失去"或挑战触发深度经历**
   - 选一个已有表面经历，反转成"失去"（失去地位/家庭/信念支撑），让人物被迫从"认识他人"进入"认识自我"。确保"失去"击中的是**内核信念**，而非又一次表面波动。
   - 若多段经历并行 → 检查是否能用"相互冲突"或"相辅相成"关系编织，让一段经历卡住时另一段接力。
   - 完成标准: 产出一个具体的深度经历设计（触发事件 + 击中的内核信念 + 人物将采取的非常规行动）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **单元剧主角（柯南/福尔摩斯/波洛）**——主角"不变的标杆"本身是读者锚点，刻意不变是设计目标不是缺陷。强行加深度反而破坏系列结构。
- **无敌流 / 纯粹爽文逆袭流**——读者要的就是表面经历（暴富/升职/打脸/装逼）的即时爽感，强行加"认识自我"层会拖慢爽点节奏、破坏类型契约。

### 作者在书中警告的失败模式

- **ce10 表面经历误当深度经历（人类最大悲剧）**: 人物结尾获得财富/地位/爱情，但读者"那又怎样"——因为内核信念从未被挑战，外表翻天覆地、内核丝毫未变。这是本 skill 要诊断的头号病症。
- **ce11 知识/教育误当启迪**: 给人物堆砌学位、技能、行话、调研细节，以为这就是"成长"。人物无所不知却对自己一无所知——知识是外部累积（加法），认识是内部转变（转向），两者方向不同。

### 作者的盲点 / 时代局限

- **"深度 > 表面"是文学审美等级排序，不是读者心理学或市场标准**。作者出身文学经纪人，价值观 = "经久不衰的杰出文学"。商业上表面经历（升职/暴富/恋爱/逆袭）往往更卖座——网文逆袭流/种田流/系统流恰恰靠表面经历获得百万级粘性，不可硬套"必须有深度层"。
- **2002 年好莱坞 + 纸质书时代**。未涉及网文连载的日更节奏/章末钩子/爽点密度——在长篇连载中，"觉醒了却重复旧模式"可能恰是延长期的结构需要，而非缺陷。
- **"一口气读完找重复"的隐含假设**在边写边发的连载模式下不成立。

### 容易混淆的邻近方法论

- 与 `inner-conflict`: 本 skill 问"变了没、变多深"（纵向），inner-conflict 问"当下卡在哪"（横向）。
- 与 `reading-psychology-curve`: 本 skill 在人物层，后者在受众层。

## 相关 skills

- **composes-with `inner-conflict`**: 深度经历第三层"在认识上行动"引出 inner-conflict 的知行矛盾——本 skill 诊断"真变了还是表面变"（纵向弧线），inner-conflict 制造"知道该做却做不到"的横向张力，二者一纵一横共同支撑人物深度。
- **contrasts-with `reading-psychology-curve`**: 本 skill 在人物层诊断变化深度（角色弧线的纵向），reading-psychology-curve 在受众层诊断投入阶段（读者停在哪一层）。一个看作品侧的人物，一个看受众侧的读者。
