# 阅读心理曲线诊断 (Reading Psychology Curve)

## R — 原文 (Reading)

> "理想的作品可以让读者经历四个阶段: 好奇→兴趣→需要→行动……你能唤起读者的最高层次就是让他们因为作品而感动, 仅仅读完这本书或看完这部电影还不够; 你能够把一种将他们读到或看到的东西付诸行动的热望植入他们心中。"
>
> — Noah Lukeman, 第8章 超越

---

## I — 方法论骨架 (Interpretation)

作品(或任何传达)的影响力分 4 个递进阶段, 越后越难达到:

1. **好奇**: 最易达成, 营销/标题/封面就能做到; 标志是"陌生人愿意给你 2 小时试看"。
2. **兴趣**: 被吸引不想离开, 但还没决定看完; 停留时间长, 随时可放下。
3. **需要**: 全方位需要, 不是短期"想知道结局"; 判定标志有两个——**①足够强的代入感**(受众把自己投射进去), **②未解问题**(受众把作品的问题当成自己的问题急需解决)。缺一不可。
4. **行动**: 改变实际行为(给国会写信、发动暴乱、改变职业决定), 是作品的终极力量。

关键诊断原则:
- 后阶段必须建立在前阶段上, 不能跳级。
- **大多数作品停在好奇/兴趣层**——这是影响力天花板过低的常见病灶。
- 自检: 作品激发受众到了哪一层? 1-10 打几分?

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 《刺杀肯尼迪》——激发读者给国会写信(第 4 阶段: 行动)

- **问题**: 作品能达到的最高影响力是什么? 卢克曼需要一个第 4 阶段的实证。
- **方法论的使用**: 奥利弗·斯通《刺杀肯尼迪》被作为 4 阶段模型的最高层证据——作品不仅激发了好奇/兴趣/需要, 还直接激发了集体行动。
- **结论**: "成千上万人给国会写信, 最终秘密档案被解禁"——作品跨过了"读完/看完"的边界, 把受众的感动转化成了付诸行动的热望。
- **结果**: 卢克曼将此称为"你作为作家能够行使的终极力量", 以此论证第 4 阶段是衡量作品影响力的最高标尺。

### 案例 2: "需要层"判定标志的应用 [方法论应用]

- **问题**: 一部作品停留时间很长, 算不算到了"需要层?
- **方法论的使用**: 按 4 阶段模型, 用两个判定信号交叉验证——代入感是否足够强? 是否存在受众自己急需解决的未解问题? 卢克曼论证, "需要"层的核心不是短期"想知道结局"(那仍只是兴趣层), 而是全方位的、个人化的需要。
- **结论**: 停留时间长 ≠ 需要层。若受众虽被吸引却没有代入、没有把作品的未解问题内化为自己的问题, 就仍卡在兴趣层。
- **结果**: 该判定标志成为 V2 跨域诊断的基础(如"产品 demo 能让投资人看完但没人投钱"→ 停在兴趣层, 缺未解问题与代入)。

> 注: 原书第 8 章本单元的具体作品案例较少, c41 是唯一锚定到具体作品的实证; 案例 2 是作者对"需要层"机制论证的应用, 非单一作品案例。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 追读数据持续下降, 不知问题出在哪一层——是好奇层没勾住, 还是兴趣层断裂, 还是需要层缺失?
2. 读者反馈"看不下去"或"看完就忘"——诊断是兴趣层断裂(节奏/张力问题)还是需要层缺失(无代入/无未解问题)。
3. 产品 demo / 内容营销转化率低——用户停留但不掏钱/不注册。
4. 演讲或汇报后, 听众"点头但不行动"——卡在需要→行动的跨越。
5. 评价一部作品或产品的"影响力天花板"——它最高能达到第几层?

### 语言信号(用户的话里出现这些就应激活)

- "追读下降" / "读者弃书" / "drop-off 严重" / "churn 高"
- "没代入感" / "看完就忘" / "没共鸣"
- "engagement 低" / "转化率低" / "没人动手"
- "影响力弱" / "受众停在哪儿" / "为什么打动不了人"

### 与相邻 skill 的区分

- 与 `experience-depth` 的区别: 本 skill = **受众投入层**诊断(受众侧的投入阶梯, 问"读者停在哪层"); experience-depth = **人物变化层**诊断(作品侧的人物弧线深度, 问"人物真的变了吗")。一个看受众, 一个看人物。
- 与 `suspense-designer` 的区别: 本 skill = **诊断标尺**(告诉你卡在哪一层); suspense-designer = **注入张力的操作**(告诉你怎么从好奇升到兴趣/需要)。二者常配合: 本 skill 定位卡点, suspense-designer 补足张力。
- 与 `allocation-audit` 的区别: 本 skill = 影响力分层诊断; allocation-audit = 用篇幅/时间分配反推真实主题。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **判断当前停在哪个阶段(1-10 打分)**
   - 好奇层信号: 看完简介/封面/标题就走了, 不点开正文。
   - 兴趣层信号: 看了几页/几分钟, 但随时可放下, 不会主动找下文。
   - 需要层信号: 主动追更/主动推荐/反复回想/把作品的问题当成自己的问题。
   - 行动层信号: 因作品改变实际行为(写信、转发行动、改变决定)。
   - 完成标准: 给出 1-10 分及对应阶段, 并附判定依据。

2. **诊断卡点(为什么升不到下一层)**
   - 好奇→兴趣卡点: 内容未兑现承诺 / 节奏拖沓 / 开场无张力。
   - 兴趣→需要卡点: **缺代入感**(受众无法把自己投射进去)或**缺未解问题**(受众没有"自己急需回答的问题")。
   - 需要→行动卡点: 作品未提供可行动的出口 / 受众不知"我该做什么"。
   - 完成标准: 定位具体的卡点位置(哪一层→哪一层之间), 而非笼统说"不够好"。
   - 判停条件: 若作品类型本就不追求第 4 阶段(如纯娱乐/爽文), 跳到步骤 3 的"按类型定目标层"。

3. **补足该阶段所需元素**
   - 好奇层补: 钩子 / 标题 / 承诺的清晰化。
   - 兴趣层补: 张力 / 冲突 / 节奏(调用 `suspense-designer` / `conflict-designer`)。
   - 需要层补: 代入感(见 `experience-depth` 强化人物代入) + 未解问题(见 `suspense-designer` 的悬而未决/秘密)。
   - 行动层补: 明确的行动出口 / 感染力机制(把"感动"翻译成"具体可做的事")。
   - **按类型定目标层**: 工具书/参考书目标层=好奇; 商业娱乐作品目标层=兴趣/需要; 议题/影响力作品目标层=需要/行动。不要对纯娱乐作品强求第 4 阶段。
   - 完成标准: 列出具体修复点 + 对应的可调用 skill。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **纯工具书/参考书/技术手册**: 受众要的是检索效率, 不追求投入曲线; 用"行动层"标尺去衡量是误诊。
- **已经过市场或时间验证的经典作品**: 无需用此诊断标尺, 它们早已证明能穿透到需要/行动层。
- **网文爽文爽点密度诊断**: 见下"作者盲点", 4 阶段是文学影响力模型, 与网文爽点机制根本不同; 追读数据高 ≠ 达到需要/行动层, 应走专用爽点扫描。

### 作者在书中警告的失败模式

- **大多数作品停在好奇/兴趣层**: 作者明确指出这是影响力天花板过低的常见病灶, 不是个别现象。
- **"需要层"标志缺失**: 没有代入感或没有未解问题, 受众停留时间再长也只是兴趣层——停留时长是误导性指标。

### 作者的盲点 / 时代局限

- **4 阶段是文学影响力模型, 对娱乐作品不完全适用**: 网文"追读"有自己的爽点密度机制(即时满足、章末钩子、装逼打脸、金手指快感), 追读高不等于达到了"需要/行动层"; 网文读者要的是即时爽感而非"全方位需要"。直接套用 4 阶段会误判网文。
- **"行动层"在娱乐作品里基本不适用**: 小说/电影很难直接激发集体行动, 除非是议题作品(如《刺杀肯尼迪》); 把"行动"当通用最高标准, 会把绝大多数娱乐作品误判为"失败"。
- **"需要层"假设受众寻求代入/未解问题**: 但大量受众寻求的是逃避现实、情绪按摩、爽感, 不要求深度代入或解决问题——他们的"需要"是即时情绪补给, 不是卢克曼定义的"全方位需要"。
- **立场盲点**: 文学经纪人出身, 价值观 = "经久不衰的杰出文学", 以"世代流传""永恒""教益"为最高标准, 对"快餐但高粘性的商业类型文"潜在低估——而后者恰恰证明了即时情绪满足的市场力量。

### 容易混淆的邻近方法论

- **"代入感" / "未解问题"** 看起来像悬念技法或经历深度, 但本 skill 只把它们作为"需要层"的**判定信号**使用, 不展开具体技法(见 `suspense-designer` / `experience-depth`)。
- **"影响力" / "传播力"** 在营销语境里有自己的漏斗模型(AARRR/AIDA), 本 skill 是作品侧的心理投入阶梯, 不等同于营销转化漏斗。

## 相关 skills

- **contrasts-with `suspense-designer`**: 本 skill 是诊断标尺（量受众停在好奇/兴趣/需要/行动哪一层），suspense-designer 是注入张力的操作（向场景注入悬念技法）。诊断标尺 vs 注入操作——但 reading 的"需要层"判定依赖 suspense 的未解问题作为两大信号之一。
- **contrasts-with `experience-depth`**: 本 skill 在受众层诊断投入阶段（读者侧），experience-depth 在人物层诊断变化深度（角色侧）。受众层 vs 人物层，一个看读者一个看人物。
