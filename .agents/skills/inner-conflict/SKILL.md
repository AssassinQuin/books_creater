# inner-conflict — 内心冲突与知行矛盾

## R — 原文 (Reading)

> "冲突的最高形式通常来自内心。外部冲突至少是可以言说的，可以被解决、避免和忽略；内心冲突却不容易贴上标签，从来不能避免，有时候永远不能解决……我们经常渴望——甚至制造——外部冲突，以便不去思考内心冲突的问题。"
>
> — Noah Lukeman, 第6章 冲突

---

## I — 方法论骨架 (Interpretation)

本 skill 围绕三条互相咬合的论断制造内心张力：

1. **内心冲突 > 外部冲突（最高形式论）**：外部冲突可被言说、解决、避免、忽略；内心冲突不可贴标签、不可避、有时永远不可解。所以最深刻的张力来自内心。
2. **投射论（反直觉诊断法）**：人无意识地制造外部冲突，以逃避内心冲突。观察一个人物反复卷入的外部冲突模式，就能反推他未解决的内心议题——"外部冲突模式 = 内心议题的指纹"。内心冲突越激烈，他制造的外部冲突越严重（成瘾、吵架狂、危机依赖者）。
3. **认识-行动矛盾（最深刻的紧张器）**：人物"知道正确做法却做不到"时，不要急于解决这个矛盾，要利用并延长它。延长会创造最深刻的紧张感，并衍生三种形态——神经官能症（心理投射/偏执/生理症状）、道德困境（救家人还是杀外人）、悲剧（决定行动却已太晚）。

一句话：把外部冲突当症状，把内心冲突当病因；把"知行不一"当引擎，别急着熄火。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《罪与罚》拉斯柯尔尼科夫——把内心冲突置于外部罪行之上

- **问题**: 一部以谋杀为核心的作品，真正的重心应该放在哪里？是罪行、追凶，还是别的？
- **方法论的使用**: 用"内心冲突最高形式论"诊断——作品的核心不在外部的谋杀与刑罚，而在拉斯柯尔尼科夫是否完成"自我认识"的心路历程。卢克曼据此断言："悔恨本身并不重要，自我认识的历程才重要。"外部冲突（罪行、审判）只是放大器，内心冲突（他是否能认识自己）才是不可避、不可解的最高形式。
- **结论**: 把内心冲突置于外部冲突之上，作品的核心从"谋杀案"重定为"自我认识的历程"。
- **结果**: 许多宗教与文化把救赎寄于此历程；《罪与罚》成为"深度经历 2：认识自我"的典范，并支持"认识是深度，在认识上行动才是最深刻"的递进。

### 案例 2: 弗兰纳里·奥康纳《汇流》——刻意延长认识-行动矛盾至悲剧

- **问题**: 如何让"知道该做却做不到"产生最深刻的效果？
- **方法论的使用**: 用"认识-行动矛盾紧张器"——固执的儿子终于意识到自己让母亲多么难过，他到母亲家去道歉，却发现母亲已经去世。人物完成了"认识→决定行动→开始行动"的全部内在历程，但行动注定无法达成。作者刻意延长矛盾、不急于解决，而是让解决永远差一步。
- **结论**: "行动太晚的悲剧"——内在完成但外在落空——依然能给读者"某种解决，好像他已经采取了行动一样"的满足感。延长矛盾比解决矛盾更有力。
- **结果**: 这一手法在悲剧中取得最强烈效果，与《罗密欧与朱丽叶》一起被卢克曼援引为"行动太晚"悲剧技法的核心例证。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **人物动机单薄/扁平**：感觉角色"只是工具人"，行为靠剧情需要驱动，缺乏内在张力。
2. **反派过于扁平**：邪恶但没有深度，需要赋予真实的心理逻辑（注意 ce12 约束——不是让反派忏悔）。
3. **需要道德两难**：想让读者纠结、选边站，而不是一边倒。
4. **角色反复陷入同种外部冲突**：主角又跟权威吵架、又跟恋人闹翻、又跟同事撕——需要诊断这背后指向什么未解决的内心议题。

### 语言信号 (用户的话里出现这些就应激活)

- "人物太扁""角色没有深度""反派太单薄/太脸谱化"
- "道德困境""知行不一""他为什么就是不行动"
- "主角为什么老是陷入同一种冲突"
- "inner conflict""character motivation flat""villain too one-note"

### 与相邻 skill 的区分

- 与 `conflict-designer` 的区别：`conflict-designer` 负责**生成外部对抗**（13 式冲突生成器：人物/群体/权力斗争/时间…）；本 skill 负责**诊断外部冲突背后的内心议题**，或直接**制造内心张力**。一个管"外"，一个管"内"——当用户说"冲突太浅""反派没深度"走本 skill；当用户说"这场戏不够对抗""需要加点阻力"走 `conflict-designer`。
- 与 `experience-depth` 的区别：`experience-depth` 诊断人物**变化深度**的层级（表面 7 种 vs 深度 3 层：认识他人→认识自我→在认识上行动），判定"真的变了还是只是看清了"；本 skill 制造**变化背后的紧张感引擎**（认识-行动矛盾/投射），是驱动变化迟迟不发生的张力本身。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **从人物反复的外部冲突反推内心议题（投射论诊断）**
   - 列出该人物反复卷入的外部冲突模式（跟谁吵？什么情境下触发？模式是否重复？）。
   - 完成标准：写出一句话"内心议题假设"——例如"他用与权威的冲突，逃避'我其实渴望被权威认可'的内心议题"。

2. **设计认识-行动矛盾并刻意延长不解决**
   - 明确人物"知道正确做法是什么"的具体内容。
   - 设计他"做不到/不愿做/迟疑"的具体障碍，选定延长策略（犹豫、合理化、逃避、转移、投射）。
   - 完成标准：一个"他知道却做不到"的具体场景已写出，且矛盾未被当场解决。
   - 判停条件：若人物是真正犯下重罪的反派/杀手，跳到步骤 3 的 ce12 检查——"拒绝认识"本身可能是该人物的心理自保，不应强加认识。

3. **按需衍生道德困境/神经官能症/悲剧**
   - 从三种衍生形态中选一种嵌入情节：
     - 神经官能症（心理投射/偏执/生理症状）
     - 道德困境（两个"正确"互斥，如救家人还是救陌生人）
     - 悲剧（行动太晚——内在完成但外在永远落空）
   - **ce12 校验**：若是反派/作恶者，检查是否违反"拒绝认识=心理自保"——一旦认识闯入会被重负压垮，所以他们会用合理化/否认/投射阻止认识发生。给反派强加"幡然悔悟"的救赎弧线 = 假的。
   - 完成标准：选定形态并嵌入情节；对反派已确认是否适用 ce12 例外。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **动作驱动型故事**（追车/打斗/闯关/升级流战斗）：外部即时冲突是节奏引擎，深挖内心会拖慢爽点循环。
- **轻喜剧/单元剧**：内心议题的沉重感会破坏类型期待；喜剧更依赖外部误解与错位。
- **一次性工具人/龙套**：不是所有角色都需要内心议题，给过场人物强加内心冲突=注水。

### 作者在书中警告的失败模式

- **ce12 — 反派不允许自己认识错误（一旦认识会被重负压垮）**：写作真正邪恶的人物时，让他们轻易"认识到错误并忏悔"是假的。卢克曼明言："这就是为什么杀手、纳粹分子和其他同样类型的人不允许自己看到他们行为中的错误。一旦这种认识闯进他们的头脑，他们很快就会被自己行为造成的重负压垮。"给反派强行加"幡然悔悟"的弧线，违反了人物的心理自保机制，变成道德故事的附庸。认识-行动矛盾的正确用法是**延长**矛盾，不是让所有人物都走向认识。

### 作者的盲点 / 时代局限

- **文学性"内心>外部" vs 网文爽文"外部即时冲突"的张力**：卢克曼的"内心冲突是最高形式"是 2002 年好莱坞/西方经典文学传统（莎士比亚、陀思妥耶夫斯基、奥康纳）。网文爽文（日更/追读/章末钩子/黄金三章/爽点密度）更依赖外部即时冲突驱动节奏，深度内心戏（延长认识-行动矛盾）可能拖慢日更节奏，在断更连载、读者每天读 15 分钟的模式下未必有耐心。
- **"一口气读完作品"的隐含假设**：投射论诊断法（反复外部冲突→内心议题指纹）需要全局俯瞰人物的冲突模式；网文连载作者常边写边发，未必有全局设计机会。
- **案例全是西方经典**：无东方叙事传统对照（中国章回体、物哀、循环结构）。

### 容易混淆的邻近方法论

- `conflict-designer`：外部对抗生成（管"外"）。
- `experience-depth`：变化深度层级诊断（管"变了没"）。
- 本 skill：内心议题诊断 + 内心张力制造（管"内心病因"与"知行不一引擎"）。
