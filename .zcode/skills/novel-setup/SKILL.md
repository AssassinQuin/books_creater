# 小说项目基建（novel-setup）

> 源自 2026-05-02 达尔文优化版（5bf3268），移植到 ZCode 文件流。共享铁律见 `.zcode/knowledge/legacy/novel-writer/references/shared-conventions.md`（数据分层已改为文件树：novel-db/Memory 全部由 story-flow MCP + `novels/{书名}/` 文件树替代）。

## 强制流程

```
A1启动: 建项目目录 → 头脑风暴(逐问) → 🔒输出决策卡 → 用户选定 → commit
A2世界观: 读模板 → 逐维度建立(每维🔒确认) → 交叉验证 → commit → 建议下一步
```

每个阶段有 🔒 检查点。用户说"改一下"→ 回退修改；说无关问题 → 简短回答后回到当前步骤。

## ZCode 编排

- **主力子 agent**：`setup-architect`（简报 `.zcode/agents/setup-architect.md`），A1/A2 的引导、生成、交叉验证都 spawn 它执行；主流程只做 🔒 检查点交互与 commit
- **spawn 前**：`ref_route` 取权威文件清单（头脑风暴 / 世界观设定）贴进任务提示
- 断点续传：`book_status` + `novels/{书名}/选题决策.md` 是否存在判断停在哪一步

## A1: 项目启动

触发: "头脑风暴"/"灵感"/"我有个想法"/"开书"

1. 确认小说名 → `book_use(书名)`（不存在则创建 `novels/{书名}/` 目录树：设定/大纲/正文/追踪）
2. 读 `.zcode/knowledge/legacy/novel-writer/references/brainstorm-guide.md`，**一次只问一个问题**：
   - 画面感 → 主角特质 → 读者情绪(爽/虐/燃/感动/紧张) → 对立面 → 独特规则
   - 用户提到"群像"→ 追问每个核心角色的独立线和交汇点
3. 每个回答落 `novels/{书名}/灵感/`（一个要点一个小文件）
4. 🔒**输出决策卡** → 写 `novels/{书名}/选题决策.md`：

   ```
   项目: {小说名}
   核心冲突: {1-3个候选}
   主线方向: {2-3个候选}
   读者情绪: {主情绪}
   亮点场景: {列表}
   建议品类: {参考 genre-profiles.md}
   建议节奏: {快/中/慢}
   ```

5. 用户选定 → 补写选题决策.md 的「已选定」段
6. `git commit -m "A1: 项目启动 - {小说名}"`

完成后建议：`/novel-setup` 建世界观，或 `/novel-character` 设计人物。

## A2: 世界观建模

触发: "建世界观"/"世界观"/"设定" | 前置: A1 完成（选题决策.md 存在）

**已有世界观检测**：扫描 `novels/{书名}/设定/世界观/*.md`。
- 已有维度 → "你已建了{N}个维度（{列表}），要修改哪个？还是继续新建？"
- 修改模式：改对应维度文件（整体重写，不打补丁）→ 🔒确认
- 空白 → 进入逐维度建立

### 模式选择

| 用户意图 | 模式 | 流程 |
|---------|------|------|
| "帮我设计一个完整世界" | **引导模式** | 逐维度问答（默认） |
| "给我一个标准{品类}世界" | **快速模式** | 基于模板+genre-profiles 自动生成6维初稿 → 用户审阅修改 |
| "改一下{某维度}" | **修改模式** | 读当前维度文件 → 整体重写 → 🔒确认 |

### 引导模式（默认）

1. 读 `.zcode/knowledge/legacy/novel-writer/references/worldbuilding-template.md`
2. 逐维度建立，**一次一个维度**：种族→势力→地理→能力→经济→日常
   - 每维度落一个文件：`novels/{书名}/设定/世界观/{维度}.md`
   - 用户说"跳过这个" → 记录，后续标注缺失，不强制补全
3. 每维度完成 → 🔒**向用户确认该维度**再进入下一个

### 交叉验证（两种模式都必须执行）

spawn `setup-architect` 逐项检查，不合理解释原因并建议修改：

| 检查项 | 验证方法 | 异常标准 |
|--------|---------|---------|
| 种族×地理 | 各种族分布与地理是否匹配 | 有种族无分布区域 |
| 势力×地理 | 势力地盘与区域对应 | 势力无明确地盘 |
| 势力×经济 | 势力财力支撑其行为 | 穷势力养大军/富势力不做贸易 |
| 能力×种族 | 先天能力差异自洽 | 弱种族突然有超强能力无解释 |
| 经济×日常 | 物价与生活水平匹配 | 一顿饭=普通人一年收入 |
| 时间×距离 | 出行时间与距离合理 | 步行1小时跨大陆 |

验证通过 → `git commit -m "A2: 世界观完成 - {小说名}"` → 建议下一步：`/novel-character`
