# 我师兄实在太稳健了 · 剧情情绪模块（Stage 3 聚合）
> 主对标·稳健流权威 · 服务《我只想安稳修仙》金手指(炼器分身)/人设/爽点设计

## 读者需求
看一个**没有气运加身、不是天定劫子**的炼气士，在残酷洪荒靠**过度谨慎 + 多底牌 + 谋而后动**，主动布局活下去、求长生。代入来自"他比我想得远十步"，爽感来自"他又料到了/又备好了"，笑点来自"准备得过头"。

## 稳健流情绪引擎（★区别凡流"求生紧张"）
- **核心情绪 = 过度准备的掌控感**：李长寿永远比场景需要的多备一手。爽在"看他把所有后手铺满"的掌控感，笑在"这也防/那也防"的夸张。
- 不是"差点死了才活下来"的劫后爽（凡流九死一生），是"根本不让自己进死地"的算计爽——敌人以为得手，他早备了替身/反制。
- **与凡流互补**：凡流=被动求生驱动谨慎；稳健流=主动布局驱动稳健。陈安 = 凡流底色(倒霉逼出谨慎) + 稳健流加码(主动多底牌)。

## 可复现模块卡（★陈安炼器分身映射母题库）

### M1 纸人替身/分身模块（核心金手指母题）
- 触发：独处/赴险/战斗
- 动作：放纸人代其在场(防偷袭) / 纸人替死 / 多纸人锁魂攻击
- 成长曲线：ch1 一只代场 → ch13 三纸人锁魂+替死诱杀 → ch17 纸人从3张加到6张
- → **陈安炼器分身直接母题**：炼器造的物理分身(代场/替死/多分身协同)，随修为提升分身数/强度/功能

### M2 多底牌并发模块
- 触发：任何行动前
- 动作：同时铺开多个后手(替身+毒+遁术+探测+储物分份)，不靠单底牌
- 实证：ch8 三重储物(丹药/法器/灵石分三份存放) / ch13 反杀(替身+软仙散+换天宝伞+三纸人+焚尸+弩)
- → 陈安：炼器分身+防御器具+逃生遁具+探测法器 同时布设

### M3 一击必杀 + 毁尸灭迹模块（不动如山一动惊人）
- 触发：被盯上/必须出手
- 动作：设伏 → 一击致命 → 扬灰灭迹(白火焚尸/超度亡魂/清理战场)
- 实证：ch13 反杀刺鸠
- → 陈安：炼器手段(毒/阵/弩/分身)一击 + 灭迹

### M4 借力打力模块
- 触发：强敌/守护者在场
- 动作：引第三方(追杀者/毒蛇)对付目标，自己渔利
- 实证：ch17 引追杀者引毒蛇夺仙解草
- → 陈安：用分身/器具借局

### M5 安全审查 / 不轻信模块
- 触发：新人/新物靠近
- 动作：先排查(入门审核查魂/查魔；察觉监视；将计就计)
- 实证：ch2 入门审核 / ch12 察觉监视 / ch13 将计就计设伏
- → 陈安：炼器探测法器/分身试探 排查一切靠近的人/物

### M6 降低存在感 / 隐踪模块
- 触发：日常/潜行
- 动作：隐匿气息/隐踪符/遁术/装弱(装过敏/装抽搐/装心魔)
- 实证：ch3 隐身道术 / ch12 隐踪符+土遁 / ch9 装抽搐躲检查
- → 陈安：炼器隐匿器具 + 倒霉反差的装弱

### M7 防患未然 / 谋而后动模块（话术包装）
- 触发：任何决策
- 动作：把稳健说成"防患未然"/"活下去到顶点再改写规则"，话术化传递
- 实证：ch2 防患未然 / ch5 活下去到顶点改写规则
- → 陈安：稳健信条的话术表达（倒霉体质让他更理直气壮地"防患未然"）

### M8 务实经营弱脉模块
- 触发：资源/人际
- 动作：灵鱼资产/送礼经营/把师妹变劳动力/卖手艺换资源
- 实证：ch3 送礼+师妹园丁
- → 陈安：炼器卖器换资源 + 经营伏笔人脉网（弱连接人脉）

## 喜剧分寸（★"轻底色搞笑"参照·性格喜剧五源）
1. **限知视角信息差**（师妹听不懂现代词，读者懂）
2. **过度反应夸张**（杀人灭口/千字誓言）
3. **表里反差**（温润嗓音说算计）
4. **装弱装病**（过敏/抽搐/心魔）
5. **内心吐槽**（人品气质差距/"有毒玄雅"）
→ **陈安"轻底色"**：倒霉反差(越谨慎越被倒霉拆台) + 过度准备夸张 + 内心吐槽。性格喜剧，非段子/闹剧。
