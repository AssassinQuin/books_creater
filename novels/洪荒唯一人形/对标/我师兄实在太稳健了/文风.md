# 我师兄实在太稳健了 · 文风（Stage 6）
> 主对标·稳健流文风 · 与《凡人修仙传》文风(凡流白描基)配合使用
> 服务《我只想安稳修仙》：陈安 = 凡流白描底色 + 稳健流性格喜剧调味

## 核心特征
**古典仙侠白描为骨 + 穿越者现代视角穿插(内心吐槽/现代词) + 性格喜剧笔法**。比凡人更"轻"、更"暖"、带喜感；凡人偏冷峻写实，我师兄偏轻松仙侠。

## 维度

### 句长
中短句为主，长短交替。叙述用中句，动作/紧张处用短句。仙气场景偶用四六句式（"钟声在云间飘荡/翠峰琉璃碗大阵"）增古典味。

### 视角（稳健流特色·双限知）
- **主角限知**：李长寿内心算计展开（读者看他怎么算的，"果然还是要杀人灭口吧"）
- **配角限知（师妹视角）**：师妹崇拜滤镜 + 听不懂现代词 → 信息差笑点的载体
- 关键算计用主角内心独白铺；喜剧段用师妹限知视角

### 场景白描
古典仙侠画卷式（钟声/白云/翠峰/琉璃大阵/灵气肉眼可见），仙气飘飘。比凡人"茅草屋顶"式贫寒白描更仙侠、更轻。

### 心理处理
- 动作/身体反应替代直述情绪（凡流同）
- **大量内心吐槽**（穿越者视角）："人品气质差距""有毒玄雅""果然还是要杀人灭口"——吐槽是性格喜剧的主要载体

### 对话
功能型（推进 + 暴露性格）。李长寿温润不急不缓（表象层）；师傅齐源慈祥爱面子；酒玖豪放；师妹天真懵懂（限知）。对话带身份印记。

### 喜剧笔法（★稳健流文风标志）
- 画面反差（师傅褶皱凑成"严肃"两字 / 纸人替身 / 湿身登场）
- 装弱装病的肢体细节（装抽搐/装过敏）
- 内心吐槽穿插
- **不靠段子/网络梗堆砌**——靠性格与情境

### 比喻
克制，偶有生活化/角色化比喻，不堆叠。

## 对《我只想安稳修仙》文风启示
- **凡人白描**（茅草屋顶式贫寒真实）= 陈安的凡流底色基（陈安凡人底层出身，世界更偏写实残酷）
- **我师兄的"内心吐槽 + 性格喜剧笔法"** = 陈安稳健流加码（倒霉反差吐槽、过度准备的夸张描写）
- 陈安整体**更偏凡流**（底色重/白描实/少仙气/多残酷），稳健流喜感作**轻调味**（倒霉反差/过度准备，不喧宾夺主）
- **现代词**：陈安是本土凡人（非穿越者），**不用现代词穿插**——喜感靠"倒霉反差 × 过度准备"，不靠现代词信息差（这是我师兄穿越者设定的专属，陈安不继承）
