## 设计原则（plot-methodology + v3）

1. **多功能**：每条支线同时展开世界/丰富角色/制造悬念/服务主线/活跃氛围
2. **差异化**：势力博弈/悬疑反转/迪化喜剧/成长弧/世界展开/见证记录——不同模式，不统一套路
3. **爆炸分散**：V1-V8 + 终幕错落，不全堆 V8
4. **围绕男主但有自己生命**：支线角色有自己的伤口/欲望/议程，不全绑治愈主题
5. **势力交织**：支线之间 + 与主线涟漪；多条支线指向天庭操盘（终极暗线）

## 各支线详细设计

### 支线 1·太一宗内斗（人·教权·成长+伪善裂缝）
- **势力**：太一宗（正道第一宗门）·激进派(玄冥长老) vs 温和派
- **钩子**：玄冥真信"灭妖救世"，信念 V2-V8 渐进塌陷；V8 男主打破循环涟漪让他感应"天道异常"自查发现"天道=神族"(F16)，信念崩塌
- **节奏**：V2-V3 坚定(围剿和邦·锤伯死上级) → V5 动摇(信念辩论) → V8 崩塌(发现天道=神族) → 终幕隐居(不洗白)
- **交织**：主线 F16；异端审问官体系(支线5)；薛恒仙化(支线2)

### 支线 2·正道诸国王权与仙化（人·王权·悬疑）
- **势力**：正道诸国联盟（皇朝）·盟主被仙化夺舍/近卫军长薛恒被仙化
- **钩子**：王权沦为天庭傀儡；薛恒表面人格保留实为天庭执行者
- **节奏**：V2-V3 暗示 → V4-V5 薛恒暴露天庭执行者身份 → 终幕薛恒结局
- **交织**：天庭操盘(主线终极)；太一宗(支线1·教权vs王权)

### 支线 3·商修灵石暗战（人·商权·势力博弈+世界展开）⭐
- **势力**：跨界商修网络（陆离/商离）·灵石=货币+修炼资源
- **钩子**：各方(人族正道/妖族/天庭)争夺灵石控制权；陆离在和邦搞"灵石公平贸易"触动多方利益
- **节奏**：V1-V2 陆离登场(商修智囊) → V3-V5 公平贸易触多方 → V6-V8 灵石暗战升级 → 终幕商修网络归和邦
- **交织**：妖族(妖灵密林灵石矿·支线7)/人族(正道垄断)/天庭(暗中控制)；陆离同病镜子(主线治愈)
- **多功能**：展开商修世界规则+势力博弈+陆离成长+迪化(男主种田被误读)

### 支线 4·散修联盟处境（人·底层·世界展开+迪化）
- **势力**：散修联盟（无门派修士）·底层被各方挤压
- **钩子**：散修无资源无靠山，被宗门/正道/妖族挤压；某散修误读男主(迪化喜剧)
- **节奏**：分散各卷(底层修士的日常+误读男主)
- **交织**：邵半仙线(支线15·同为底层误读者)；温故(人族散修·善种)

### 支线 5·异端审问官黑幕（人·执法·悬疑反转）
- **势力**：异端审问官体系（正道执法）·深层黑幕
- **钩子**：异端审问官的黑幕——地灵族匠心真元交易/伪善领主伪造妖族作案(制造人妖仇恨)
- **节奏**：V2-V3 围剿和邦(锤伯死) → V6 莘奴线拼图 → V8 反派自爆(异端审问官说漏嘴)
- **交织**：锤伯灭族(主线 F21)/莘奴(灭妖者转化)/天庭操盘

### 支线 6·八妖王博弈（妖·会盟·势力博弈+迪化）⭐
- **势力**：妖王会盟（八妖王）·金式(平衡)/昼(平衡)/厄枭(野心·主线)/戌迦(潜伏·主线)/其他妖王
- **钩子**：八妖王各有领地/算计；男主崛起被迪化为"深谋远虑新妖王"，各方反应
- **节奏**：V4 注意男主 → V5 妖王盛宴(虚名最高·博弈) → V6-V8 分裂(昼支持/戌迦暴露)
- **交织**：主线虚名/迪化；男主妖族身份；金式昼(世界肌理·平衡者)

### 支线 7·妖灵密林诸部求存（妖·部族·成长+世界展开）
- **势力**：妖灵密林诸部（灵狸/大鬼/牙狼/蜥人/猪头等部族）
- **钩子**：诸部被人族猎杀取灵石(人妖仇恨循环)求存；男主收编建国(和邦雏形)
- **节奏**：V1 男主起家收编 → V2-V3 和邦扩张 → 分散(各部族的故事)
- **交织**：商修灵石(支线3·灵石矿)/人妖仇恨(主线)/小牙(灵狸族·弟系)

### 支线 8·妖修文明冲突（妖·世界展开）
- **势力**：妖修（修仙的妖）vs 部族妖
- **钩子**：修仙的妖(走人族修仙路)与部族妖(血脉天赋)的文明冲突；某妖修立场撕裂
- **节奏**：分散(世界展开·妖族内部的多元)
- **交织**：妖王会盟(支线6)/男主(妖族修仙+血脉·两种路)

### 支线 9·魔宫割据内战（魔·势力博弈）
- **势力**：魔宫割据（多魔尊·厄枭/江烬/其他）·魔尊割据内战
- **钩子**：魔界崇尚力量·魔尊割据内战·业力累积(天劫首当其冲)
- **节奏**：V4-V5 厄枭(主线反派) → V6 江烬登场(堕落魔尊) → V6-V8 魔宫内战
- **交织**：江烬堕落(主线镜像)/天庭陷害人族强者(支线5同类·天庭操盘)

### 支线 10·魔族流亡第三条路（魔·成长）
- **势力**：魔族流亡者（阿檀等）·寻"第三条路"
- **钩子**：魔族流亡者拒绝割据内战，寻"第三条路"(和邦共存)；投和邦
- **节奏**：V3-V4 阿檀流亡 → V4 投和邦 → 终幕魔族代表
- **交织**：江烬(堕落vs第三条路)/和邦(五族共存)

### 支线 11·仙宗飞升失踪（仙·悬疑反转）⭐
- **势力**：仙宗联盟（正统仙修）·飞升失踪
- **钩子**：最近飞升的仙修越来越少/失踪；砚青/沈砚调查发现飞升被天庭操纵(飞升者被吸收用于复活仪式)
- **节奏**：V5-V6 暗示(飞升减少) → 穿插仙界卷(调查+揭一层) → 终幕揭穿(天庭吸收仙修)
- **交织**：天庭复活仪式(主线终极)/砚青沈砚(仙界见证者)
- **多功能**：展开仙界+天庭更大阴谋+悬疑反转

### 支线 12·灵族 800 年记录（仙·见证记录+世界展开）
- **势力**：灵族（砚青所在·记录者）·800 年见证循环
- **钩子**：砚青 800 年记录六界大战循环；灵族中立观察；男主是"800 年第一次想干预的存在"
- **节奏**：V1-V2 暗线(记录) → V3 加入(想干预) → 终幕"翻开新的一页"
- **交织**：主线见证/飞升失踪(支线11)

### 支线 13·冥府亡魂账篡改（冥·悬疑+世界展开）⭐
- **势力**：冥府（判官秩序·冥）·亡魂账被篡改
- **钩子**：天庭强征亡魂(复活仪式需要)+篡改生死账(制造死亡累积业力)；铁岚/冥调查发现"某些死亡不是天灾是天庭制造"
- **节奏**：V5-V6 冥府被威胁(强征亡魂) → 穿插冥界卷(调查+揭一层) → 终幕冥府加入和邦
- **交织**：天庭复活仪式(主线终极)/铁岚(冥界线)/锤伯本源(冥府察觉异常)
- **多功能**：展开冥府秩序+天庭阴谋(制造死亡)+悬疑

### 支线 14·鬼族幽冥秩序（冥·世界展开）
- **势力**：鬼族部族（铁岚幽冥族）·幽冥秩序
- **钩子**：鬼族部族处境/铁岚弑主背景(厄枭前副官)；幽冥族的秩序
- **节奏**：V2-V3 铁岚加入(弑主背景) → 分散(鬼族世界展开)
- **交织**：铁岚线(主线考验效忠)/厄枭(支线9)

### 支线 15·邵半仙乌鸦嘴游方（跨界·迪化喜剧+伏笔载体）⭐
- **势力**：游方说书人（邵半仙）·贯穿各卷
- **钩子**：邵半仙说书误读男主(迪化传播者)+离谱预测都成真(乌鸦嘴·迪化具现)；埋深/浅/假伏笔(红鲱鱼)
- **节奏**：贯穿各卷(每到一个新卷世界先出场，用离谱说书定调"世界对男主的误读")
- **交织**：所有迪化线(他是迪化发动机)/散修(支线4)/伏笔分层载体
- **多功能**：迪化喜剧+迪化传播+伏笔分层+活跃氛围；**完全不碰治愈主题**

## 势力交织网（多条支线指向天庭操盘）

```
【天庭·昊玄殁殃】操盘六界（终极暗线·复活仪式）
     │
     ├─ 支线2 正道诸国仙化（盟主/薛恒）
     ├─ 支线5 异端审问官黑幕（伪造人妖仇恨·累积业力）
     ├─ 支线9 魔宫割据（天庭陷害人族强者·江烬样本）
     ├─ 支线11 仙宗飞升失踪（吸收仙修·复活仪式）
     ├─ 支线13 冥府亡魂账篡改（强征亡魂·制造死亡·累积业力）
     └─ 支线3 商修灵石暗战（天庭暗中控制灵石）

【主线双救引擎】周临必死局（天庭操盘）= 支线2/5/9 的当代样本
```

**关键**：5+ 条支线都指向天庭操盘（主线终极），支线交织成"天庭如何操盘六界失衡→大战"的宏观网——世界因此**混乱真实**。
