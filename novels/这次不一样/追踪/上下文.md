## 三、仙侠原生机制（关键约束 · 写作红线）

- **灵气 = 生命力**；灵气消耗 = 生命力消耗；灵石 = 灵气结晶（货币 + 修炼资源）
- **天道 = 规则意志显化 · 非人格神**；不主动"赐"力量；道鸣 = 感应非赋予；通过因果/天劫/血脉运转
- **因果循环**：善恶有报；妄造杀业引天劫
- **境界十层**：凡 → 练气 → 筑基 → 金丹 → 元婴 → 化神 → 大乘 → … → 仙/金仙
- **男主能力全战斗向**（通灵玉鉴：鉴映/鉴纹/鉴纳/鉴纹暴起/通灵鉴域），治愈靠剧情不靠能力属性
- **进化触发全仙侠原生**：修炼 / 师徒传承 / 血脉觉醒 / 悟道 / 渡大天劫
