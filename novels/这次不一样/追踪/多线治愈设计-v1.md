# 多线治愈设计 v1（V10-V11 方向框架 · 私因驱动 · 待下次展开）

> 🔧 **2026-07-29 方向修正**：旧版（同日早些时候）犯了根本错误——用**设定文档的元概念**（治愈路线/系统对抗/打破循环/强大=燃料）当故事因果。这些是游戏机制语言·不是小说里人物的因果。本版确立正确方向·记录框架·**待下次展开完整设计**。
>
> **设计核心（一句话）**：男主 V10 遭遇具体事件打击 + 前世创伤放大 → 自责·觉得善意白费·差点回到前世"我尽力了" → 身边人基于**各自的私人理由和弧线闭环**拉回他（不是为宏大目标·是私人的执念/羁绊）→ 男主发现自己对他们做的事没有白费 → 重新站起来。

---

## 一、旧版的错误（避免重犯）

| 错误 | 为什么错 |
|------|---------|
| "治愈路线 vs 复活仪式系统" | 故事里没人会说"我用治愈路线对抗你的系统"——游戏机制·非小说因果 |
| "男主强大=燃料" | 设定层的数值逻辑·非人物经历 |
| "角色为了打破循环而行动" | **没有角色会为"打破循环"这种宏大目标行动**——这不是人的动机 |
| "能力指向错位/系统级对抗" | 元概念·非故事语言 |

**教训**：设定文档可以写"系统/路线/燃料"这些分析语言·但**故事里的因果必须是人物经历的**——人物做了什么·经历什么·因此怎么想·怎么选择。

## 二、正确方向（skill 方法论 + 参考小说）

### skill 核心方法应用

1. **先定情绪·再定故事**（skill §核心方法）：V10-V11 情绪 = 男主低谷（自责/无力/差点放弃）→ 被身边人**私人羁绊**拉回 → 重新站起来。感动点 = "你以为善意白费了·但对他们来说·你改变了一切"。
2. **从验证过的模式出发**（skill §核心方法）：找同类情境的参考小说·看他们怎么写。
3. **用模块组装**（skill §核心方法）：男主低谷模块 + 群像拉回模块 + 真相揭示模块 + 重新站起模块。

### 参考小说的同类情境（男主低谷 + 群像拉回）

| 小说 | 低谷情境 | 群像帮忙的理由（全是私人的·非宏大目标） |
|------|---------|---------------------------------------|
| **诛仙** | 碧瑶死后·鬼厉堕落 | 陆雪琪"我不放弃你"（私人执念）/ 田不易"逆徒也是我徒弟"（师徒情）|
| **将夜** | 书院被围·桑桑被抓 | 桑祠是本命 / 莫山山认同他的不屈服 / 夫子就是夫子 |
| **大奉打更人** | 魏渊牺牲·许七安被联合打压 | 临安因为爱 / 金莲认可他的为人 / 魏渊自己的使命 |
| **诡秘之主** | 克莱恩"死" | 塔罗会每人记得他对自己做的**具体的事** |

### 提炼出的正确模式

1. **每个角色帮主角的理由是私人的**——爱/认可/执念/归属/师徒情。**没有任何人是为了"打破循环"**。
2. **理由来自男主对他做的具体的事**——V1-V9 的种子·自然长出果实。
3. **理由是角色自己弧线的闭环**——他的成长让他做出这个选择·不是男主赋予的使命。
4. **男主低谷的因果是事件+性格**——具体失去/错误选择/守护不了 + 前世创伤放大·不是"设定驱动"。

### 正确的因果链（种子→果实·不是系统→对抗）

```
旧版（错误）：角色是循环受害者 → 选择打破循环 → 帮男主

正确版（参考）：男主V1-V9对角色做了具体的事（种子）
                  → 角色因此成长/改变（他自己的弧线）
                  → V10男主摔跟头
                  → 角色基于自己的成长+对男主的私人羁绊 → 选择帮他（果实）
```

## 三、男主摔跟头的因果（事件+性格·非设定驱动）·待展开

> 方向·下次展开具体事件

**不用设定驱动（"强大=燃料"）·用事件+性格**：

- **具体事件打击**：男主遭遇了什么具体的挫折（和邦被围/伙伴受伤或死亡/他做了一个代价巨大的选择/他发现有些东西他守护不了）——待下次设计具体事件
- **性格放大**：他的性格（前世创伤——付出善意被辜负的恐惧）把这些打击放大成自责
- **"善意白费"的边缘**：他到了"也许我的善意也白费了"的边缘——呼应前世"我尽力了"·差点回到前世的放弃状态

**男主自责的核心**（不是"我是燃料/我指向错位"这种设定语言·是人物的内心）：
- "我拼命守护·还是护不住"
- "也许我的善意和前世一样·终归是被辜负的"
- "我尽力了……也许这次也一样"
- 差点封闭·差点放弃——呼应前世跳桥前"我尽力了"

## 五、和反派/危机的联系（私人恩怨·非系统对抗）·待展开

> 方向·下次展开

**不是"系统对抗"·是私人恩怨/守护欲**：
- 反派（天庭/江烬）做了什么**具体的事**伤害了他们/男主
- 他们因此有**私人的**理由行动（守护/复仇/不屈服）
- 推动剧情向正确方向发展·但是因为他们自己的选择·不是因为他们"看破了系统"

**待设计**：反派的哪些具体行动·构成每个角色的私人恩怨/守护对象。

## 六、男主发现"没有白费"的真相（待展开）

> 方向·下次展开

男主在自责中·被身边人的私人理由一层层冲击·逐渐发现：
- 他以为自己拼命守护是白费（护不住所有）
- 但对他们每个人来说·他做的事改变了一切（具体的种子·长出具体的果实）
- "没有白费"——不是"系统对抗胜利"·是"他对每个具体的人做的事·都没有白费"

**揭示方式**（emotional-methods 余韵钝痛 + 物件触发）：不用对话说教·用具体物件（如温故灵石袋）+ 每个角色的具体行动·让男主自己拼出真相。

## 七、情绪弧线（先定情绪·skill 方法论）

```
V10 摔跟头（具体事件打击·痛）
  ↓
自责萌芽（"我护不住"·性格放大）
  ↓
自责加深到饱和（"也许善意白费了"·差点回到前世"我尽力了"）
  ↓

  ↓
真相揭示（"没有白费"·他对每个人做的事都结了果实）
  ↓
重新站起来（主动选·不是被动被救）
  ↓
余韵（安静细节收束）
```

## 九、防跑偏红线（避免重犯旧版错误）

1. **不用元概念**——禁"治愈路线/系统对抗/打破循环/强大=燃料/能力指向错位"等设定文档语言。故事因果必须是人物经历的。
2. **每个角色的理由是私人的**——爱/认可/执念/归属/师徒情·不是宏大目标。任何角色"为了打破循环"而行动 = 跑偏。
3. **男主摔跟头是事件+性格**——具体事件打击 + 前世创伤放大·不是"设定驱动"。任何"他的强大反成燃料"式写法 = 跑偏。
4. **因果是种子→果实**——男主V1-V9做的具体的事 → 角色自己的成长 → 基于私人理由行动。不是"系统→对抗"。
5. **参考小说验证**——每个设计点对照诛仙/将夜/大奉/诡秘的同类情境·确认是"私人理由"而非"宏大目标"。
