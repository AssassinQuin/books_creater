## 一、网文定位（三层 · 治愈只是内核不是全部）

这是**迪化喜剧外壳 + 治愈内核 + 诡秘式螺旋剧情**的网文。

- **外层·迪化喜剧**（最多）：男主被六界误读神化，爽+笑
- **中层·世界丰富**（多）：六界各有特色/角色/风物，世界活
- **内层·治愈主线**（少）：男主被善治愈→给世界善

**核心纪律**：治愈只占少数核心角色。大部分角色服务迪化喜剧和世界丰富，**不全为主题服务**。多样性 > 主题统一。

## 二、剧情结构原则（诡秘之主式 · 写作手法权威）⭐

1. **螺旋剧情，非线性**——事件牵出更大事件，层层深入，读者猜不到结局。每个"真相"背后还有更深的层（锤伯灭族→厄枭→天庭操盘→循环→天道化身）。拒绝"一卷一boss通关"的线性。
2. **信息突然爆发（分散·不全堆最后）**——平时碎片埋线（日记/传闻/邵半仙说书/小细节），某章集中爆发颠覆认知。**爆发点分散在各卷，不全堆在结局**：设计得好的卷可以**提前给出部分**真相（让读者尝到甜头+层层深入），最后大爆发（V8 摔跟头/第三幕/终局）做总颠覆。螺旋深入 = 各卷小爆发 + 终局大爆发。
3. **不要工整，要自然**——拒绝机械对称（每卷一boss/每卷一进化/伏笔均匀分布这种模板）。剧情像有机体生长，有些线松有些线紧，有些角色戏多有些戏少，**不刻意平衡**。
4. **松紧有致**——紧张（悬疑/战斗/真相爆发）与松弛（迪化喜剧/种田/群像日常/邵半仙乌鸦嘴）交替。松弛段是迪化喜剧和世界氛围的主场，不是凑字数。
5. **线索/故事多功能**——一条线索同时承载多种功能：丰富角色 / 前因后果 / 主线 / 展开世界 / 活跃氛围。**拒绝单功能线索**（一条线只为一件事服务是浪费）。

> 这五条是 V1 细纲及所有正文写作的手法红线。

## 三、角色原则（多功能类型 · 取代"全绑三核心"）

角色分 4 类功能，**不是全部绑治愈主题**：

- **主题承载型**（少数）：男主 / 锤伯 / 周临 / 江烬——只有这 4 个承载治愈/双救主线
- **迪化喜剧型**（大量）：误读男主的配角（邵半仙/妖王们/正道修士/商修/民间）——爽笑来源，**不为主题服务**
- **世界肌理型**（大量）：六界各界特色人物/怪咖/风物——让世界活
- **反派型**（中等）：各种动机的对立（厄枭纯粹恶/玄冥伪善/昊玄循环），不一定和治愈有关

群像（小牙/陆离/铁岚/小曜/砚青）是治愈累积圈但**有自己生命**，不全绑主题。**群像各有自己的支线 + 相互之间横向涟漪关联（旧识/仇敌/师承/同门/血仇）+ 每条支线/关系有前因后果**——群像不是主线工具，他们有自己的故事，故事之间互相影响（如锤伯灭族↔铁岚弑主同源厄枭；陆离↔商离旧合伙人；小牙↔周临血仇）。

角色从"是谁"长（人生/伤口/欲望），有自己的议程，不是主题工具。

## 五、迪化机制（后置 + 伏笔分层 + 乌鸦嘴）⭐

1. **迪化后置性**：误读滚雪球越滚越大（护人→奴印→操控强者→妖族帝国…），真相后置闪现/揭晓，**不轻易给**。爽感来自差距累积。
2. **伏笔分层**（不要全一种深度）：
   - **深伏笔**：贯穿全书（穿越即双救/周临身份/天道化身/灵犀人格化）
   - **浅伏笔**：1-3 卷回收（每卷的小谜/小预测/小悬念）
   - **假伏笔（红鲱鱼）**：误导读者猜错，后期揭示是假（某角色像叛徒实际不是 / 邵半仙某次"预测"是假误导）
3. **乌鸦嘴角色·邵半仙**（游方说书人/散修 · 工作名）：
   - 江湖骗子外表，四处游方说书（**天然贯穿各卷世界**）
   - **乌鸦嘴**：随口吐槽/预测的离谱话都因男主迪化因果成真——自己怕自己的嘴（"别说了别说了！"成梗）
   - **迪化传播者**：四处说书传播男主传说，越传越离谱
   - **伏笔载体**：预测多数成真（深/浅伏笔），**偶尔一个是假的（红鲱鱼）**
   - 迪化喜剧型，**完全不碰治愈主题**；每到一个新卷世界先出场，用离谱说书给"世界对男主的误读"定调
