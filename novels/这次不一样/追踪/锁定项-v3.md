## 一、世界观根基（最稳·底层不变）

- **灵气**：天地修仙根基能量；灵气=生命力；灵石=灵气结晶（货币+修炼资源）
- **天道**：规则意志显化；**非人格神·只按规则运转**（不做灵活归属判断）；通过因果/天劫/血脉运转；**不主动"赐"力量**
- **因果**：业力循环；善恶有报；妄造杀业引天劫
- **道鸣**：修士悟道/渡劫/血脉觉醒时天地有鸣（**感应而非赋予**）
- **境界十层**：凡→练气→筑基→金丹→元婴→化神→大乘→仙→金仙→大罗
- **六族 + 六界**：神/魔/仙/妖/人/鬼；分界=立场+界域（非生理善恶）；和邦=五族共和（神族除外）
- **天劫三劫**：心境之劫 + 业力之劫 + 血脉之劫（大境界突破·九死一生）
- **师徒传承机制**：仙侠原生核心（锤伯传匠心真元给男主）

## 二、能力体系（男主 · 全战斗向）

- **5 神通**：鉴映（天赋）/ 鉴纹（师徒传承+血脉觉醒）/ 鉴纳（修炼凝聚+悟道）/ 鉴纹暴起（血脉·情感激荡）/ 通灵鉴域（悟道+渡大天劫·法则级）
- **觉醒法则全仙侠原生**：修炼 / 师徒传承 / 血脉觉醒 / 悟道 / 渡劫（非系统文）
- **7 阶段进化链 + 第十二卷妖圣**：幼妖→成妖→凝脉妖→大妖→妖王→妖神→妖圣（与境界+卷骨架咬合）
- **双驱动成长**：治愈心境 + 主动修炼（缺一不可）
- **能力全战斗向·反差在用途不在本质**：强大战斗神通只用于护人/建国/种田；治愈交剧情层（能力本身无治愈属性）
- **迪化**：每次进化被外人误读为"新妖王崛起/妖神降临"——信息差爽点

## 三、核心机制（v3 新增·Phase 2 定义·锁定）

- **错位道鸣**（双救引擎物理基础·F3）：穿越级大道鸣在因果层造成一次微小扰动→远方必杀轨迹偏移寸许；不可重复/不可主动触发（"这次不一样"=天道例外）
- **天庭必死局操盘**（F4/F5）：天庭不能直接下界，靠仙化夺舍人族顶层+戌迦调妖族围攻，陷害触及循环真相的人族强者（江烬上代+周临当代）
- **仙化夺舍条件**：需目标有"信念裂痕"（荣誉感/坚定信念被利用）——非无差别夺舍，保留被夺舍者的悲剧性
- **F18 两条线分工**：陷害人族强者=维持循环；吸收妖/魔/仙至强力量=复活天道化身仪式力量源
- **业力规则**：男主渡大天劫本无业力之劫（未造杀业·天道规则自然结果，非"算别人头上"）

## 四、角色主体（已 v3 合规·锁定）

- **男主·林悟**：前世轻生→妖族幼体→被治愈→妖圣（5 神通全战斗向）
- **挚友·周临**：人族最强剑修（**非勇者·非天选·凭本事**）·双救另一端·**平行 POV 全程 + 中后期相遇 + 周临察觉→冲突→终局确认（修订 1·取代旧"全书不交手"）**·终局接住男主一次（earned·有中后期弧铺垫）
- **锤伯**：地灵族老灵匠·主题承载型·第一卷末师徒传承+第二卷末护阵牺牲
- **群像核心 6**：小牙（灵狸族·弟系）/ 陆离（人族商修·同病镜子）/ 铁岚（幽冥族女将·前厄枭副官·军事长）/ 小曜（龙族幼龙·最强单体）/ 砚青（灵族·800年记录者·史官）+ **邵半仙**（乌鸦嘴说书人·迪化喜剧型·**完全不碰治愈主题**·伏笔分层载体）
- **反派双核**：外部 始原仙神 **昊玄+殁殃**（维持循环）/ 内在 **鉴映失控**（F10·前世创伤反扑）
- **江烬**：上代人族顶尖剑修堕落（**非前代勇者**·天庭陷害上代样本·男主暗黑镜像）
- **中文化锁定**：昊玄（原赫列维斯）/ 殁殃（原撒弗）——**无外国名**

## 五、结构与剧情机制（锁定）

- **六界全活格局** + **战力失衡六维**（妖界无统一顶级/魔界割据/仙界飞升失踪/冥府被强征/人界周临一人苦撑/神界操盘）→ 六界大战
- **三层架构**：外层迪化喜剧（最多）/ 中层世界丰富（六界）/ 内层治愈主线（少）——大部分角色不全绑主题
- **双救引擎**：穿越即双救（错位道鸣·序章上帝碎片·**中后期相遇+第十二卷确认**·书名点题）【⚠️ 修订 1 同步：旧"终局相认"已被取代·改为平行 POV 全程 + 第七卷-第八卷中后期相遇 + 周临察觉→冲突→第十二卷确认·详 §四】
- **迪化流**：后置 + 滚雪球（真相不轻易给·爽感来自差距累积）
- **伏笔分层**：深（贯穿）/ 浅（1-3卷）/ 假（红鲱鱼·误导）
- **15 支线 + 爆炸时机分散**（各卷小爆发+终局大爆发·不全堆结局）
- **螺旋剧情 5 原则**：非线性 / 信息爆发分散 / 自然非工整 / 松紧有致 / 线索多功能
- **题材定位**：仙侠·妖族幼体·迪化+种田+共和+治愈内核
