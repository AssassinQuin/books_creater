# 剧情结构原则（V1 细纲 / 正文写作红线 checklist）

> 权威：`追踪/重构总纲-v3.md` §一/§二/§五/§六。本文件是写作手法 checklist，V1 细纲与正文写作时逐条对照。
> 性质：这是**怎么写**的手法红线（区别于设定文件的**是什么**）。

---

## 一、三层架构（每章/每卷要 balance）

- [ ] **外层·迪化喜剧**（爽笑·占比最多）：男主被六界误读神化
- [ ] **中层·世界丰富**（六界·占比多）：各界特色/角色/风物
- [ ] **内层·治愈主线**（占比少）：男主被善治愈→给世界善
- **纪律**：大部分内容**不全为主题服务**——治愈只占核心圈少数角色

---

## 二、螺旋剧情 5 原则（诡秘之主式 · 每卷写作红线）⭐

1. **螺旋非线性**：事件牵出更大事件，层层深入，读者猜不到结局；拒绝"一卷一 boss 通关"线性
2. **信息爆发分散**（不全堆结局）：各卷小爆发（设计好的卷提前给部分真相）+ 终局大爆发（总颠覆）
3. **不要工整，要自然**：拒绝机械对称（每卷一 boss/每卷一进化/伏笔均匀分布）；剧情像有机体生长，有松有紧
4. **松紧有致**：紧张（悬疑/战斗/真相爆发）+ 松弛（迪化喜剧/种田/群像日常/邵半仙乌鸦嘴）交替
5. **线索多功能**：一条线索同时承载——丰富角色 / 前因后果 / 主线 / 展开世界 / 活跃氛围；拒绝单功能线索

---

## 三、迪化机制

- [ ] **后置性**：误读滚雪球越滚越大，真相后置闪现/揭晓，**不轻易给**；爽感来自差距累积
- [ ] **伏笔分层**（不要全一种深度）：
  - 深伏笔（贯穿全书）/ 浅伏笔（1-3 卷回收）/ **假伏笔（红鲱鱼·误导读者猜错）**
- [ ] **邵半仙**（乌鸦嘴说书人）：离谱预测都成真（迪化具现）；迪化传播者；伏笔分层载体；贯穿各卷串场；**不碰治愈主题**

---

## 四、卷级世界（混合方案 · 不打怪升级）

- [ ] **主线每 V 独立舞台**（可跨界·不机械对应界）：V1 妖灵密林 / V2 人妖边城 / V3 和邦 / V4 妖王会盟 / V5 妖王盛宴 / V6 魔宫 / V7 人界前线 / V8 和邦被围 / 第三幕 六界交汇 / 终幕 神界
- [ ] **穿插仙冥专属卷**：仙界卷（追查天庭线索）/ 冥界卷（生死因果）——六界全展开
- [ ] **卷间涟漪·前因后果**：每卷事件牵动其他卷/界
- [ ] **每卷地图有内在价值**（世界观展开+跨卷纠葛），不是刷怪场

---

## 五、角色多功能类型（不全绑主题）

- [ ] **主题承载型**（少数·仅 4 个）：男主 / 锤伯 / 周临 / 江烬
- [ ] **迪化喜剧型**（大量）：邵半仙 / 妖王们 / 正道修士 / 商修 / 民间——**不为主题服务**
- [ ] **世界肌理型**（大量）：六界各界特色人物/怪咖
- [ ] **反派型**（中等）：各种动机对立（不一定和治愈有关）
- **群像各有支线 + 横向涟漪 + 前因后果**（不是主线工具）

---

## 六、写作禁忌（红线）

- ❌ **AI 腔**：章末升华 / "他感到"直述情绪 / 万能比喻 / 角色语气统一
- ❌ **勇者 / 召唤愿望 / 前代勇者**（已随召唤体系拆除）
- ❌ **外国名**（赫列维斯/撒弗/蜜莉姆式等·全部中文化：昊玄/殁殃/八妖王待中文化命名）
- ❌ **工整对称**（每卷一 boss/每卷一进化/伏笔均匀）
- ❌ **全为主题服务**（所有角色/线索都绑治愈主题）
- ❌ **打怪升级换地图**（地图只是刷怪场）
- ❌ **信息全堆结局**（不分散爆发）
