## 〇、设计总则（先立规矩）

1. **中国仙侠质感优先**：空间用"层叠 + 中界水平"（须弥式），不用西式"平行宇宙 / 多维空间"；灵气用"清/浊/阴/魔"四气流转，不用"能量场 / 频率"；天劫用"业力累积→雷霆清洗"，不用"系统判定 / 评分"。语汇一律仙侠原生。
2. **物理具现优先**：所有机理必须能写出画面——"业力怎么累积"要具象到"妄造杀业→血气凝滞不散→天道感应降雷霆"，不写"业力增加"四个字了事。
3. **咬合剧情骨优先**：每条机理最后都过一遍剧情骨（妖灵密林交汇 / 跨界商修陆离 / 双救周临远方人界 / 六界大战 / 飞升 / 锤伯师徒传承 / 共和）——机理服务于故事，不是炫设定。
4. **可执行优先**：每条机理给"规则 + 限制 + 代价 + 写作用法"——读者看得到、作者写得来、反派能利用、男主能突破。

## 一、六界空间结构（方案 C · 层叠 + 中界广袤 + 裂隙网络）

> **现状约束**（不可推翻）：六界=六个相通位面；妖灵密林是妖界↔人界交汇地；周临在远方人界；仙界云海之上；冥界黄泉之下；神界天外遗址。

### 结构核心

1. **垂直三层**：上界（神/仙）/ 中界（人/妖/魔三界水平相接）/ 下界（冥）——中国仙侠传统的"仙在上/冥在下/凡在中"。
2. **中界是主舞台**：人/妖/魔三界是一片广袤大陆（**玄黄大陆**）的三个地理区域，**无界膜**，靠天然天堑（妖灵密林/魔界裂空带）隔开——可徒步/飞舟/商道跨界。**陆离的跨界商修网络就在中界水平流动**。
3. **垂直通道**：
   - **飞升通道**（中界↔仙界）：修士渡劫后上冲突破"层膜"到仙界
   - **冥府渡口**（中界↔冥界）：黄泉路下沉，鬼修出入
   - **天外通道**（仙界↔神界）：神族潜伏/天庭先锋下界的路径，凡人极难涉足
4. **裂隙网络**（补充通道）：除了主要垂直通道，各界间散落**虚空裂隙**（天然/远古大战遗留/大能开辟），是冒险者/逃亡者的捷径，也是六界大战的传统战场。

### 妖灵密林解释（咬合剧情）

- 中界玄黄大陆上，人界（东方）与妖界（中部）之间的**原始密林带**——大陆天然过渡区
- 灵气浓郁成雾（两界灵气在此交汇激荡）
- 多族混居（人族商修/猎师从东来，妖族诸部从西来，混处缓冲）
- 是六界大战的传统战场之一（边缘地带·四战之地）
- **男主转生此地 = 转生在"世界的伤口"上**（F12 强化）

| 剧情骨要求 | 方案 C 如何咬合 |

## 二、中界地理细化（玄黄大陆 · V1-V3 细纲地基）⭐ 核心

> 本节是方案 C 落地到正文的**地图层**——V1-V3 细纲从这里取场景/路线/方位。
> 中界 = **玄黄大陆**（玄为天色·黄为地色·取"天地玄黄"古意），一片广袤大陆，三界水平相接。

### 1. 三界方位布局（东 ◀ 中 ▶ 西）

```
东海岸                                                    西极荒
  ●─────────────●───────────●──────────────●───────────●
  │ 人界诸国      │           │              │           │
  │ （东方·广袤）  │  妖灵密林  │  妖界（中部）  │ 魔界裂空带 │ 魔界（西方）
  │ 太一宗/正道   │ （人妖    │  妖王会盟     │ （妖魔    │  魔宫割据
  │ 前线/边城    │  天堑）    │  八妖王领地   │  天堑）   │  山河
  ●─────────────●───────────●──────────────●───────────●
       ↑                              ↑
   周临远方前线                  厄枭跨界东扩
   （正道诸国前线·远端）         （自魔界入妖界）
```

**方位逻辑**：
- **人界居东**：广袤诸国，东临沧海，西抵妖灵密林——人族繁衍之地，皇朝+宗门林立。
- **妖界居中**：密林深处，妖王会盟所在，八妖王水平各占一地。
- **魔界居西**：山河割据，魔宫林立，西极荒寒。
- **两道天堑**：妖灵密林（人妖过渡）/ 魔界裂空带（妖魔过渡）——天然隔开三界，但非绝境，可强渡。

| **正道诸国联盟** | 人族修士宗门+皇朝+商会联盟 | 第二卷-第三卷反派（异端审问官围剿）/ 外交对象 |

### 5. 妖灵密林具体地理（男主转生 + 建国地 · V1 舞台）⭐

> 妖灵密林是全书起点和建国地，需要最具体的地理。

**位置**：玄黄大陆中部偏东，人界（东方）与妖界（中部）之间的原始密林过渡带。水平延伸千里，纵深数百里。

**地形结构**（从东到西）：

```
东缘（人界侧）          腹地（男主舞台）              西缘（妖界侧）
─────────────────────────────────────────────────────────────
人妖边城               锤伯炼器铺                   灵狸族聚居
商修驿站               地灵族遗址（流落地）            妖族诸小部
猎师前哨               和邦（男主建国地·V2-V3 起）    妖王会盟外围市集
正道前哨               男主转生地（密林深处）
```

**灵气特征**：人妖两界灵气在此交汇激荡，灵气浓郁成雾，灵脉密集（地灵族在此立身的原因）。

**"世界的伤口"**：
- 六界大战传统战场·边缘地带·四战之地
- 多族混居的混乱地带：人族商修/猎师/正道从东来，妖族诸部从西来，地灵族/流亡者居中
- 男主转生此地 = 转生在"世界的伤口"上（F12 强化）
- **男主在此建和邦 = 在世界的伤口上种善意之国**（循环打破的物理具现）

**生态**：古树通灵，兽踪遍地，妖兽密集（凡人过不了），灵气雾障（练气期修士需结伴+向导，筑基期以上可单走）。

### 6. 魔界裂空带（妖魔天堑）

**位置**：玄黄大陆中部偏西，妖界（中部）与魔界（西方）之间的过渡带。

**特征**：
- 天空常裂——虚空裂隙密布，天劫随机劈下（业力浓重之地）
- 魔气弥漫（妖界灵气在此被魔界业力污染）
- 妖魔两族的天然隔离带，但比妖灵密林更险恶

**穿越难度**：化神期以上才能强渡（低阶进=灰飞烟灭）；商修走的是裂空带的"稳定窗口"（特定时节/特定路径）。

**故事功能**：
- 男主 V4-V5 追查锤伯灭族（深入妖界→过裂空带→入魔界）
- 厄枭跨界东扩的来路（从魔界过裂空带入妖界）
- 六界大战时妖魔两族的绞肉机

### 7. 商道路线（陆离跨界商修网络）

> 陆离的商修网络是和邦的商务脊梁，也是 V1-V3 男主起家的经济纽带。

**主商道**（中界水平流动·陆离网络覆盖）：

```
【人界】商会总会 → 人妖边城 → 【妖灵密林】腹地市集（和邦中转·V2-V3 起）
   → 【妖界】诸部市集/妖王会盟外围 → 【魔界裂空带】稳定窗口 → 【魔界】魔宫外围交易点
```

**节点**：
- **人界起点**：商会总会（人界中部）
- **密林中转**：人妖边城 + 锤伯炼器铺（V1）+ 和邦（V2-V3 起·男主建国后卡在商道咽喉）
- **妖界深处**：妖王会盟外围市集
- **魔界**：魔宫外围交易点（需过裂空带稳定窗口）

**商修类型**：
- **商会总会**（中立·大宗交易·陆离原属）
- **自由商会**（倾向男主·陆离后期另立）
- **散商/游商**（跨界小批量·风险高）

**货物**：灵石（货币）/ 灵材 / 法宝 / 妖族特产（妖丹/妖兽材料）/ 人族丹药符箓 / 情报。

**和邦的商务命脉**：男主建国后，和邦正好卡在商道中转节点（妖灵密林腹地）——陆离的跨界商修网络成为和邦五族共和的经济纽带。

### 8. 天然天堑总结

| 天堑 | 位置 | 隔开 | 穿越门槛 | 故事功能 |
|------|------|------|---------|---------|
| **妖灵密林** | 人妖边缘 | 人界↔妖界 | 练气期需结伴+向导/筑基期可单走/凡人过不了 | 男主转生+建国地·世界的伤口 |
| **魔界裂空带** | 妖魔边缘 | 妖界↔魔界 | 化神期以上强渡/商修走"稳定窗口" | 男主 V4-V5 复仇线·厄枭东扩来路 |

两道天堑是中界三界（人/妖/魔）的天然边界，但不是绝境——正是这种"可通而难通"的半透性，造就了六界大战的混战格局（打得过来·退得回去）和商修网络的存在空间（有差才有商）。

## 三、交通/跨界机制（空间结构落地 · 6 种分层）

> 跨界有六套机制——按"难度 / 成本 / 谁能用"分层。读者一看就懂"这次跨界多难"。

### 1. 中界内三界地理相通（人↔妖↔魔）⭐ 最常用

- **方式**：徒步 / 飞舟 / 商队 / 传送阵（高阶）
- **路径**：
  - 人界 → 妖灵密林（人妖边缘·天然过渡带）→ 妖界
  - 妖界 → 魔界裂空带（妖魔边缘·天空常裂）→ 魔界
- **限制**：
  - 凡人过不了妖灵密林（灵气浓郁+妖兽密集）
  - 练气期修士需结伴+商修向导（陆离的网络就在这）
  - 筑基期以上可单走
- **成本**：时间（徒步数月）/ 灵石（飞舟/传送阵）/ 风险（妖兽/天劫裂空/魔气侵蚀）
- **谁能用**：商修（陆离）/ 散修 / 流亡者 / 男主和邦众人

### 2. 飞升通道（中界↔仙界 · 垂直上冲）

- **方式**：修士渡大天劫后·飞升通道打开·冲破"层膜"到仙界
- **路径**：飞升台（仙界的入口·实为天庭陷阱 F18）
- **限制**：
  - 唯一通道·只渡大天劫成功后打开
  - 一次性的·不可往返（飞升后回不来·除非金仙大能破界）
  - 飞升台守者审查（仙宗联盟+暗中天庭操纵）
- **成本**：渡劫失败=灰飞烟灭 / 飞升失踪（F18·被天庭吸收用于复活仪式）
- **谁能用**：人修大乘期渡劫成功者（极罕见·几百年一两个）

### 3. 冥府渡口（中界↔冥界 · 垂直下沉）

- **方式**：黄泉路下沉·渡口出入·鬼修引路
- **路径**：冥府渡口（冥界入口）/ 各地散落的"阴泉眼"（小渡口）
- **限制**：
  - 活人下冥界需鬼修引路+护魂法宝（否则魂魄被阴气侵蚀）
  - 亡魂只能走黄泉路（不可逆·除非执念极深成鬼修）
  - 冥府被动中立·不轻易放活人进
- **成本**：寿元损耗（活人在冥界一日=阳间一月）/ 阴气侵魂
- **谁能用**：鬼修（铁岚一脉）/ 寻亲的修士（极罕见）/ 亡魂（强制）

### 4. 虚空裂隙（补充通道 · 冒险者捷径）

- **来源**：远古大战遗留 / 天地法则自然破损 / 大能强开
- **分布**：六界散落·不可预测·时隐时现（魔界裂空带是最密集区）
- **特点**：
  - 捷径（裂隙两端可能直通跨界·如人界→仙界/妖界→冥界）
  - 危险（虚空乱流/异兽/法则紊乱）
  - 不稳定（随时可能闭合）
- **限制**：境界门槛（化神期以上才能进·低阶进=灰飞烟灭）
- **成本**：生命力（虚空乱流伤神）/ 迷失（裂隙内时空紊乱）
- **谁能用**：高阶冒险者 / 逃亡者（戌迦等潜伏者用裂隙跨界）/ 男主后期

### 5. 大能破界（极端方式 · 反派专用）

- **方式**：金仙/妖圣/魔尊级别强行撕裂层膜跨界
- **限制**：会引来天劫（强改因果）/ 极耗真元
- **成本**：天劫劈+业力累积
- **谁能用**：天庭先锋（神族代理人·仙化夺舍后下界）/ 昊玄殁殃（受天道规则约束不能亲临下界·靠代理人）

### 6. 界门（人工通道 · 大宗门/大势力的固定跨界口）

- **方式**：上古阵法开辟的固定界门·需灵石维持
- **分布**：太一宗山门有界门（人界↔仙界）/ 仙宗联盟有界门 / 妖王会盟议事场有界门（妖界内部·非跨界）
- **限制**：境界门槛+宗门许可+灵石消耗
- **成本**：每次开启耗极品灵石数枚
- **谁能用**：宗门弟子（公务）/ 高阶商修（特许）/ 男主后期（和邦建好后开设界门）

### 写作用法（直接套）

| 剧情需要 | 用哪种跨界 |
|---------|----------|
| 陆离做生意 | 中界三界地理相通·商道 |
| 男主 V1 在妖灵密林 | 中界内·人妖边缘·天然交汇 |
| 周临前线远方人界 | 中界内·人界广袤·远离密林 |
| 鬼族铁岚上界 | 冥府渡口·中界↔冥界 |
| 神族天庭先锋下界 | 大能破界+仙化夺舍代理人 |
| 仙界飞升失踪 F18 | 飞升通道·实为陷阱 |
| 男主终幕上天外决战 | 飞升通道+虚空裂隙+大能破界（多种结合） |
| 男主追查锤伯灭族（V4-V5 跨妖魔界） | 中界内·妖界→魔界裂空带→魔界 |

## 四、灵气循环物理机制（来源 / 循环 / 各界差异 / 灵脉 / 灵石）

> **现状继承**：灵气=天地根基能量；体内灵气=生命力储备（外部灵气为中性能量·纳入体内后才转化为生命力）（消耗灵气=消耗寿命/真元）；灵石=灵气结晶。
> 本节深化：灵气**从哪来/怎么流/各界差异/灵脉分布/灵石怎么生**。

### 1. 灵气来源（天道运转的副产物 · 物理具现）

- **天道运转生灵气**：天道是规则意志·按因果/天劫/血脉规则运转——运转本身**生灵气**（规则运转的副产物）
- **类比**（仙侠化）：如天地呼吸·一吐一纳皆是灵气；天道运转不息·灵气绵绵不绝
- **不增不减**：灵气总量恒定（天道规则封闭）·只在各界流转·不创造不消灭
- **物理具现**：灵气是无色无味的微茫之气·浓郁处成雾（妖灵密林）/ 清冽处如泉（仙界）/ 沉滞处凝阴（冥界）

### 2. 灵气循环（垂直流转 + 中界水平流动）

```
【神界】法则碎片（非灵气·是规则本身的碎片·不可直接修炼·神族天律执行所需）
   ↓ 天道运转生灵气·下沉
【仙界】仙气（清冽·法则感强·飞升者修仙格所需）
   ↓ 飞升通道+层膜渗透·下沉
【中界】灵气（凡灵气·修士引气入体所需）
   └─ 人界：灵气中性·灵脉汇聚处建宗门
   └─ 妖界：灵气浓郁成雾·自然灵气·血脉丰厚
   └─ 魔界：魔气=灵气被业力污染·速成但反噬
   ↓ 中界三界水平流动（妖灵密林/魔界裂空带是流动枢纽）
【冥界】阴气（死气·亡魂食粮·鬼修魂火所需）
   ↓ 阴气下沉·最深处
【轮回井】阴气净化·转生回中界（轮回机制）
```

### 3. 各界灵气差异（写作画面化）

| 界 | 灵气形态 | 性质 | 修炼用法 | 画面感 |
|---|--------|------|---------|------|
| **神界** | 法则碎片 | 规则本身·非灵气 | 神族不修炼·只执行天律·法则碎片是天律运转的"燃料" | 天外废墟·星序缓慢流转·每颗星是一个沉睡的仙神·法则阵纹半毁 |
| **仙界** | 仙气 | 清冽·法则感强 | 飞升者引仙气入体凝仙格 | 云海苍茫·仙宗山门隐于云中·仙气如清泉入喉 |
| **人界** | 灵气（中性） | 凡灵气·温和 | 修士引气入体·筑基结丹 | 山川灵秀·灵脉汇聚处建宗门·灵气淡处为凡俗 |
| **妖界** | 灵气（浓郁） | 自然灵气·血肉丰厚 | 妖族血脉觉醒+妖丹淬炼 | 灵气浓郁成雾·古树通灵·密林深处妖兽出没 |
| **魔界** | 魔气 | 灵气被业力污染 | 魔修速成逆修+血祭 | 天空常裂（天劫随机劈）·魔气弥漫如血雾·山河割据 |
| **冥界** | 阴气 | 死气·沉滞 | 鬼修魂火+执念+判官秩序 | 幽暗肃穆·黄泉路无尽·亡魂排队·执念狱阴气最重 |

### 4. 灵脉（灵气汇聚的地下脉络）

- **定义**：灵气在地底汇聚成脉·如水成河·是灵气的"地下河"
- **分布**：
  - **人界**：灵脉多被大宗门占据（太一宗/正道诸国）·灵脉枯竭处为凡俗
  - **妖界**：灵脉自然分布·密林深处灵脉密集（妖灵密林灵气浓郁原因·**地灵族靠此立身**）
  - **魔界**：灵脉被魔气污染·成"魔脉"·魔宫割据山头都建在魔脉上
  - **仙界**：灵脉清冽·仙宗山门所在
  - **冥界**：无灵脉·有"阴脉"（阴气汇聚）·判官衙门/执念狱所在
- **灵矿**：灵脉节点处的灵气结晶矿·产灵石（**地灵族是天生采灵矿的种族·锤伯种族特性**）
- **争夺**：灵脉是势力争夺核心资源（人族猎妖取灵石=抢妖界灵脉）

### 5. 灵石（灵气结晶 · 货币 + 修炼资源）

- **来源**：灵矿开采+高阶妖族死后罕见掉落（妖丹结晶）
- **分级**：下品 / 中品 / 上品 / 极品（灵气浓度递增·极品罕见）
- **用途**：
  - **货币**：修士界通用（凡俗仍用金银）
  - **修炼**：吸收灵石灵气加速修炼（但不如自然灵气纯粹）
  - **工艺基核**：法宝燃料 / 阵法能源 / 炼器辅料 / 界门开启
- **物理具现**：灵石是半透明晶体·内含微茫灵光·品级越高灵光越亮
- **人妖仇恨的实物根源**：人族猎杀妖族取妖丹结晶=灵石（**主线资源体系·锤伯灭族的深层经济动因**——地灵族是采灵矿的·被厄枭盯上灭族抢矿）

### 写作用法（直接套）

| 剧情需要 | 灵气/灵脉/灵石怎么用 |
|---------|--------------------|
| 妖灵密林灵气浓郁成雾 | 妖界灵气自然浓郁+人界灵气在此交汇激荡 |
| 陆离跨界商修 | 倒卖灵石/灵材/法宝（灵石=货币） |
| 锤伯地灵族炼器 | 地灵族天生能感应灵脉·采灵矿炼器 |
| 锤伯灭族 | 厄枭抢地灵族灵矿（经济动因+血脉论歧视） |
| 魔修速成反噬 | 魔气=灵气被业力污染·速成但业力累积招天劫 |
| 仙修清修 | 仙气清冽·需清修感悟法则 |
| 鬼修执念 | 阴气沉滞·鬼修靠执念维持魂火 |
| 男主灵觉感知万物 | 灵觉敏锐能感知灵气流动·看穿灵脉/灵石真伪/法宝结构 |

## 五、各界修炼体系细化（6 界 · 方法 / 过程 / 代价 / 局限）

> **现状继承**：`男主能力进化体系.md` §二已给六界修炼核心表（核心器官+能力风格）。本节在该表上深化出**可执行的修炼过程**——读者看得见修士怎么修、怎么进阶、付什么代价、卡在哪儿。
> 男主（妖修）的详细进化见 `男主能力进化体系.md`（灵觉敏锐）·本节只补其他五界+妖修的过程细节。

### 1. 妖修（血脉 + 妖丹 · 男主种族）

| 阶段 | 妖族形态 | 修炼过程（怎么修） | 代价 | 局限 |
|------|---------|----------------|------|------|
| 幼妖（凡） | 初生妖族·血脉潜伏 | 本能吸纳灵气入妖丹初基·血脉天赋未醒 | 寿命短（凡兽寿命） | 知性未开·凭本能 |

| 大妖（金丹） | 妖丹成相·妖相初成 | 妖丹淬炼到极致凝出"妖丹之相"·多血脉融合 | 妖丹之相凝失败=妖丹毁·血脉紊乱 | 妖丹之相是高阶妖族标志·罕见 |

**妖修核心机制**：
- **三柱**：血脉觉醒 / 妖丹淬炼 / 化形渡劫
- **血脉觉醒**：特定条件触发（情感激荡 / 师徒传承 / 渡劫）·血脉浓度瞬时飙升·解放血脉天赋
- **妖丹淬炼**：引灵气入妖丹·日积月累淬炼·是妖修的"日常功课"
- **化形渡劫**：妖王级渡"化形劫"（化人形/化神形）·失败成妖兽
- **男主独特**：唯一特别的是灵觉敏锐（血脉天赋正常变异·非外挂）；妖丹淬炼按妖修正常路径（男主能力进化体系.md §二）

- **借外物修自身**：法宝 / 符箓 / 阵法 / 丹药——人修是"加法积累"·借外物强化自身

- **陆离**：跨界商修·修为不是最强但人脉+情报+商业网络

### 3. 魔修（魔心 + 业火 · 厄枭/江烬一脉）

| 阶段 | 修炼过程 | 代价 | 局限 |
|------|---------|------|------|
| 入魔 | 掠夺/杀伐/血祭·魔气入体·凝魔心初基 | 业力累积·天劫首劈 | 寿命短（业力反噬） |

| 魔尊 | 魔心凝业火大成·割据一方 | 天劫累积·随时劈下 | 天劫劈死者众·魔尊活得焦虑 |

## 六、天劫 / 渡劫 / 飞升机制

> **现状继承**：天劫三劫（心境/业力/血脉）+ 化神→大乘渡大天劫 + 男主渡劫三劫具现（基底.md §二）。
> 本节深化：天劫**怎么来 / 怎么劈 / 怎么过 / 不过怎么样 / 飞升去哪**。

### 1. 天劫触发（业力累积 + 境界突破）

**触发方式**：
- **境界突破时**（主动）：修士突破大境界时（练气→筑基 / 筑基→金丹 / 金丹→元婴 / 元婴→化神 / 化神→大乘）·天道感应·降天劫考验
- **业力累积到阈值**（被动）：妄造杀业→业力累积→达到阈值·天道降天劫清洗（**六界大战的根本机制·神族利用这条维持循环**）

**天劫类型**（三劫·已有·深化）：
- **心境之劫**：问心境是否到位——执念/信念/放下的考验（心境不到=心魔入侵/走火入魔）
- **业力之劫**：问业力是否扛得住——杀业重的修士天劫更猛（业力越重天劫越烈）
- **血脉之劫**（妖族专属）：血脉觉醒需渡血脉之劫（血脉浓度瞬时飙升的考验·失败=血脉紊乱）

### 2. 渡劫过程（物理具现）

**天劫形态**：
- **雷霆**（最常见）：九霄神雷劈下·按境界分一重到九重（大乘渡劫=九重雷劫）
- **业火**（业力重者）：天劫降业火焚身（魔修常遭业火劫）
- **心魔**（心境之劫）：心境具现为心魔·修士需在心境内战胜执念
- **法则碾压**（高阶天劫）：化神以上天劫含法则碾压·修士需触碰法则才能过

**渡劫过程**（写作画面）：
1. **天象异变**：劫云聚拢·天地变色·灵气紊乱
2. **天劫降临**：雷霆/业火/心魔/法则具现·按境界分几重
3. **修士应对**：硬抗（法宝/丹药）/ 借势（悟道突破）/ 化解（法则反制）
4. **天劫结束**：渡过=突破成功·失败=重伤/兵解/灰飞烟灭/堕魔

### 3. 渡劫失败后果（分档）

| 后果等级 | 描述 | 触发条件 |
|---------|------|---------|
| **重伤** | 渡劫失败但保住命·修为暴跌 | 轻度失败（如硬抗过天劫第一重但扛不住第二重） |
| **兵解** | 肉身被天劫毁·元神逃出·修为跌落（人修可重修/妖族难） | 中度失败（肉身毁但元神/妖丹保住） |
| **灰飞烟灭** | 肉身+元神俱灭·彻底死透 | 重度失败（天劫直接劈碎） |
| **堕魔** | 心境之劫失败·心魔入侵·堕魔（如江烬） | 心境之劫失败特定情况 |
| **化妖兽**（妖族） | 化形渡劫失败·失去知性·化妖兽 | 妖族化形劫失败 |

### 4. 飞升机制（人→仙 · 去哪）

**飞升路径**：
1. **人修大乘圆满**：修为大乘巅峰·感悟法则到一定深度
2. **引动大天劫**：天道感应·降大天劫（九重雷劫+心境+业力+法则碾压）
3. **渡过大天劫**：成功渡劫·修为质变·仙灵之体初显
4. **飞升通道打开**：天地感应·飞升通道（光柱/天门）出现
5. **冲破层膜到仙界**：修士冲入飞升通道·突破中界↔仙界层膜·抵达仙界飞升台
6. **仙气入体凝仙格**：飞升者引仙气入体·凝仙格初基·正式成仙修

**飞升限制**：
- **一次性·不可往返**：飞升后回不来·除非金仙大能破界
- **飞升失踪**（F18·核心反转）：飞升者抵达飞升台后·部分被天庭吸收用于复活仪式·对外宣称"飞升失踪"
- **飞升台守者**：仙宗联盟+暗中天庭操纵·审查飞升者

**妖族飞升**（极罕见）：
- 妖圣渡劫飞升——妖族几千年一个·男主终幕形态
- 男主飞升通道与神界天外通道交汇（终幕决战之地）

### 5. 男主渡大天劫（V11 · 三劫具现 · 已有 · 深化）

- **心境之劫**：目睹天庭先锋之祸的杀业·选择"不以杀止杀"（心境到位=被群像治愈）
- **业力之劫**：男主不杀生灵·本无业力之劫（业力归神族）——但天庭先锋制造的杀业累积在战场·男主需以迪化第四阶段·法则级化解
- **血脉之劫**：前世灵魂强+被群像治愈→血脉觉醒到极致（迪化信仰扭曲现实的具现·信仰强度到法则级）
- **渡劫结果**：渡过大天劫·妖神突破·迪化第四阶段·法则级觉醒

## 七、天道运转规则（因果 / 业力 / 血脉 / 道鸣 / 循环 · 物理具现）

> **现状继承**：天道非人格神·是规则意志；通过因果/天劫/血脉规则运转；不主动"赐"力量；道鸣是规则感应非赋予。
> 本节深化：天道**怎么运转**——因果/业力/循环怎么物理具现？道鸣是什么物理现象？

### 1. 天道的本质（物理具现 · 非人格神）

- **天道=规则意志**：天道是因果/天劫/血脉三大规则的运转总和·不是有情绪的神
- **物理具现**：天道没有肉身·没有神格·没有居所——它**就是规则本身**·规则运转即天道运转
- **类比**（仙侠化）：天道如天地之"道"·无形无相·只在规则运转时显化（因果报应/天劫降下/血脉觉醒时·是天道在"运转"）
- **不主动"赐"力量**：天道不问善恶·只按规则运转——修士修炼/悟道/血脉觉醒/渡劫时天道有感应（道鸣）·但力量是修士自己修出来的

### 2. 因果循环（物理具现 · 业力累积）

**因果规则**：
- **妄造杀业 → 业力累积**：杀生灵（尤其无辜者）=造杀业=血气凝滞不散=业力累积
- **业力累积 → 天劫清洗**：业力达到阈值·天道降天劫清洗（**六界大战的根本机制**）
- **善因累积 → 业力消解**：种善因（救人性命/建善意之国）=善业累积=消解业力

**业力的物理具现**（写作画面）：
- **杀业重者**：周身血气凝滞不散·天劫感应强·雷霆常瞄着他劈
- **业力累积地**：战场/屠戮之地·血气渗透地底·成"业力场"·天劫常降
- **善业累积地**：男主和邦所在·善业消解业力·天劫不降（**男主建国打破循环的物理具现**）

**业力反噬的物理具现**：
- **造业者反噬**：业力归造业者（神族制造杀业=业力归神族·终幕昊玄殁殃被天劫反噬）
- **男主不杀生灵**：男主未造杀业·天道规则下他本就不欠业力之劫（**非"业力算别人头上"的特殊判定**·天道非人格神只按规则运转·不做灵活归属判断）

### 3. 血脉规则（物理具现 · 血脉浓度）

**血脉规则**：
- **血脉浓度=真实能量**：妖族血脉浓度是可量化（灵觉感知可见）的真实能量·决定妖族天赋上限
- **血脉觉醒**：特定条件触发（情感激荡/师徒传承/渡劫）·血脉浓度瞬时飙升·解放血脉天赋
- **血脉纯粹/杂血**：血脉纯粹=天赋强/上限高；杂血/凡身=天赋弱/上限低（**男主凡身最弱=血脉论最底层·最大反差**）

**血脉浓度的物理具现**：
- **高血脉浓度**：妖族气血充沛·血脉天赋可用·妖相威严
- **血脉觉醒时**：血脉浓度瞬时飙升·妖纹显现（男主第一道妖纹=锤伯师徒传承触发）·战力跃阶
- **迪化合力**（男主护短·被动）：护短时配角脑补深意+自发行动·战力瞬时跃阶碾杀·男主被动受益（**F14 迪化合力之谜**）

### 4. 道鸣（物理现象 · 规则感应）

**道鸣是什么**：
- **道鸣=规则感应的具现**：修士悟道/渡劫/血脉觉醒时·天地法则产生共鸣·具现为鸣响/异象
- **物理表现**：
  - **悟道道鸣**：修士感悟法则时·天地法则共鸣·具现为钟鸣/磬响/花开/云起等异象
  - **渡劫道鸣**：天劫降临时·劫云中隐约的轰鸣·是天道在"宣告"
  - **血脉觉醒道鸣**：妖族血脉觉醒时·血脉浓度飙升引发天地感应·具现为妖纹光芒/妖气激荡
- **感应非赋予**：道鸣是规则运转的副产物（感应）·不是天道"给"力量——力量是修士自己修出来的

**错位道鸣（F3 · 双救引擎的物理基础）**：
- **触发**：男主穿越=人类灵魂跨世界+与妖族血脉融合·是天地间非自然事件·量级等同"非自然渡劫"→触发一次大范围道鸣
- **跨界传导**：道鸣沿天道感应网（因果层）传导·从妖界边缘荡到远方人界前线周临战场
- **因果干预**：穿越级大道鸣在因果层造成**一次微小扰动**——让远方一次必杀攻击的轨迹偏移寸许·周临奇迹活
- **一次性·不可重复**：错位道鸣是穿越瞬间的一次性事件·"这次不一样"=天道这次出了个例外

### 5. 六界大战循环（物理具现 · 业力恶性循环）

**循环机制**（已有·物理具现化）：
1. **业力累积**：六界众生妄造杀业（人妖仇恨/魔族掠夺/神族操盘）→ 业力累积在天地间
2. **业力达到阈值**：每隔几百年·业力累积到天道阈值
3. **天劫清洗**：天道降大天劫清洗·具现为六界大战（多方混战·生灵大量死亡）
4. **生灵死亡 → 业力再累积**：大战制造的杀业再累积业力（恶性循环）
5. **神族利用循环**：神族（昊玄+殁殃）主动维持循环——制造大量生灵死亡=收集"复活天道化身仪式"所需的业力/力量

**循环的本质**（伏笔 F11/F18）：
- **表层**：天道定期清洗业力（这是天道规则）
- **深层**：神族利用天劫规则·主动维持六界大战循环·企图复活天道化身

### 6. 循环打破（男主建国的物理具现）

**循环被打破的物理具现**：
- **善因累积消解业力**：男主建和邦·人妖鬼魔仙五族共存·种善因累积善业→消解业力
- **业力不再达阈值**：善业消解业力→业力不再达天劫阈值→天劫不再降→六界大战循环被打破
- **天庭先锋被化解**：男主终幕用迪化第四阶段·法则级化解天庭先锋军（信仰扭曲现实·非杀戮·能量循环转化）→ 不制造新杀业→ 不累积新业力
- **周临相认象征循环打破**：人族最强剑修接纳妖圣男主=人妖必敌刻板信仰的终极打破=循环（六界互杀）被打破的象征

**这是治愈内核对世界的终极兑现**——男主战胜外部世界几百年的伤口。
