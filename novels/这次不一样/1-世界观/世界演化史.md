# 世界演化史（纵向切片 · 循环 = 伤痕累积引擎）

> **本文件是六界历史的纵向时间切片，与 `六界志.md`（横向界域切片）互补。**
> 六界志回答"现在各界是什么样"；本文件回答"怎么走到现在、上代余波还压着谁"。

## 〇、设计总则（先立规矩）

### 本文件的定位
- **写作查询点，不是编年史。** 写到某章需要"五百年前那场仗现在还压着谁"时能查到，不是流水年表。
- **传说式密度。** 学传统网文"帝血染星空"的密度，不学"公元前 XXX 年第 N 次大战"的流水账。
- **梳理已知设定的历史脉络，不新增设定。** 历史细节以 `仙侠世界观基底.md` §五/§九、`伏笔.md`、各角色档案为准。

### 核心论点：循环 = 伤痕累积引擎（非重置）
> 六界大战循环**清洗的是业力，不是社会。** 每次大战清洗业力，但留下**不可逆的伤痕**——世界不是重置，是越来越沉。

每次大战留下 **4 类不可逆遗留**：
1. **物理遗址**（天庭遗址、古战场、沉没的宗门）
2. **知识断层**（失传的功法/古法/历史记忆）
3. **代际创伤**（某族被屠的仇恨还在流传、群体的恐惧印记）
4. **潜伏残党**（上代败者的残兵潜伏下来、神族万年眼线）

外加跨循环累积的 **冥界执念**（战死者亡魂层层叠加，越滚越大）。

> 这 4+1 类伤痕，就是本作"历史厚重感"的物理来源。也是男主"治愈世界累积创伤"的治疗对象——世界观与治愈内核在根部咬合。

### 与治愈内核的咬合
- 神族（昊玄+殁殃）= 让世界**永远在痛中循环**（伤痕只增不减）
- 男主 = 治愈世界几千年累积的伤痕（打破循环 = 停止叠加新伤 + 善因消解旧伤）
- 同一个伤口，两条路：神族选毁灭，男主选治愈（详 `仙侠世界观基底.md` §九）

## 一、远古纪元（创世 → 失衡 → 循环启动）

> 所有矛盾的根在这一层。这是"创世神话"层，交代秩序怎么来的、为什么会坏。

### 创世
- **天道化身**（创世级至高存在）创造六界，并创造**远古仙神**（始原仙神）维护六界秩序。
- 远古仙神之首 = **昊玄**；武力统帅 = **殁殃**。他们为天道化身创造六界、维护秩序——这是他们的存在意义。

### 失衡（第一次伤口）
- **天道化身消失于远古**（原因待定·终幕可揭）。
- 远古仙神失去创造者 = **被舍弃**。他们为天道化身付出一切，天道化身一走，他们失去存在意义。
- 昊玄形成执念：**"复活天道化身 = 完成被中断的创世使命"**——这是他被舍弃的付出的具现，也是六界一切循环之痛的起点。
- 殁殃更激进：**"六界必须为舍弃天道化身付出代价"**。

### 循环启动
- 昊玄+殁殃确立复活仪式（F18）：**吸收六界至强力量 + 收集六界大战业力 → 复活天道化身**。
- 为持续收集业力，他们**主动维持六界大战循环**——每隔几百年推动一次六界大战（F11）。
- 天庭遗址（神界）成为潜伏之地；受天道规则约束，始原仙神**不能亲临下界**，靠**代理人操盘**（仙化夺舍人族顶层 + 万年眼线潜伏）。

> **远古纪元建立的因果链**：被舍弃 → 执念复活 → 需要业力 → 推动循环 → 世界永远在痛。
> 男主后来打破循环，断的就是这条因果链（用善因消解旧业力 + 不造新业力，让复活仪式永远凑不齐）。

## 二、循环纪元（多次六界大战 · 伤痕叠加）

> 不写死具体循环次数（留弹性·后续卷纲可按需补锚点）。这里给的是**每次循环的通用结构与累积规律**。

### 循环机制（每次大战怎么发生）
- **表层**：天道定期降下大天劫，清洗累积业力——六界多方混战是其具现。
- **深层**：昊玄+殁殃利用天劫规则，**主动维持循环**，借大战收集死亡业力（复活仪式燃料）。
- **天庭先锋**：每次大战，神族派天庭先锋下界执行（名义"代天道清洗"，实为"维持循环让世界永远在痛"）。

### 每次大战的矛盾矩阵（谁打谁·为什么）
| 参与方 | 立场 | 真实处境 |
|---|---|---|
| 神界（天庭） | 借"天道意志"清洗妖魔，名义维持秩序 | 实为收集业力·维持循环 |
| 魔界 | 反扑，魔尊野心扩张 | 加深仇恨·被利用 |
| 妖界 | 遭殃（被神/仙/人正统视为"待清洗"） | 循环最大受害者 |
| 人界正道 | 借机立功（斩妖除魔消业） | 实为加深仇恨·被神族渗透操盘 |
| 仙界 | 部分协助神界·部分中立 | 摇摆 |
| 冥界 | 吸收战死者亡魂，积攒执念 | 被动承受·执念跨循环累积 |

### 每次大战留下的 4+1 类伤痕（累积·不可逆）
1. **物理遗址**：古战场、沉没宗门、破碎天庭遗迹——散落五界，成为后世探秘/潜伏之地。
2. **知识断层**：每代强者战死，功法/古法/历史记忆失传——后世只知传说不知真相（服务"真相被掩盖"叙事）。
3. **代际创伤**：某族被屠的仇恨在民间流传、群体性恐惧印记——成为后世"内部矛盾"的情绪燃料。
4. **潜伏残党**：上代败者残兵潜伏下来，神族万年眼线（戌迦等）跨循环监视——成为当代格局里的暗桩。
5. **冥界执念滚雪球**：战死者亡魂层层叠加，冥府执念越积越深——冥界越来越沉重（铁岚幽冥族的源头背景）。

> **关键**：循环清洗业力（量），但 4+1 类伤痕只增不减（质）。世界每一次循环都更沉、更痛、更难治愈。这就是"历史厚重感"的内生来源——不是外加的历史层，是循环本身的累积性。

## 三、上代大战（约 500 年前 · 当代格局的直接源头）

> 离当代最近的一次六界大战，当代大多数势力/恩怨/角色都能追到这一仗。**写作查询频率最高的一节。**

### 战死者与余识
- **小曜**：上代天劫战死者，**余识重生**（详 `2-角色/小曜.md`）。上代大战最直接的"活余波"。

### 被天庭陷害的人族顶尖（F17/F5 样本）
- **江烬**：上代人族顶尖剑修，抱"拯救世界"信念参战，被天庭操盘多次失败，看透"人族比妖族更恶"后**堕魔**。男主"凭什么不一样"的镜像（第七卷-第十卷反派）。
- 江烬的堕落 = 天庭陷害人族强者的**上代样本**（周临是当代样本·F5′）。

### 潜伏暗桩（跨循环·延续到当代）
- **戌迦**：神族**万年眼线**，潜伏妖王会盟（跨多个循环·远早于上代大战），表面八妖王之一，实为监视妖族。当代仍在位。

### 灭族事件（时间待定）
- **锤伯灭族**：野心魔尊**厄枭**（妖死族背景·曾被正道炼成傀儡兵器百年·挣脱后堕魔）灭锤伯（地灵族）一族。
  - ⚠️ 灭族时间未在现有设定写死——可能是上代大战余波，也可能是更近的独立事件。**待 第一卷/第二卷细纲确认。** 锤伯是男主师徒传承来源（F20/F13），灭族时间影响男主复仇线起点，需锁定。

### 上代大战留下的当代遗产
- **残党潜伏**：各界败者残兵进入蛰伏期，等待下一轮循环。
- **断层加深**：上代真相被进一步掩埋，当代只流传失真的传说。
- **人族顶尖真空**：江烬堕魔后，人族正道顶层被神族渗透加剧（为当代薛恒被仙化夺舍铺路）。

## 四、当代格局（从上代余波里长出来的世界）

> 当代六界主要势力（咬合 `仙侠世界观基底.md` §七）。每个势力标注**历史来源**——这是本文件的价值：让当代格局"有根"。

| 界 | 主要势力 | 历史来源（从哪长出来） | 与男主关系 |
|---|---|---|---|
| 神界 | **天庭**（昊玄+殁殃） | 远古始原仙神·跨所有循环的幕后 | 主反派A（终局）·F18 |
| 神界 | **天庭先锋军** | 每次循环下界·当代由薛恒率领 | 第三幕高潮·第十一卷 |
| 仙界 | **仙宗联盟**（太一宗为魁首） | 飞升者累积·与天庭关系复杂（历史摇摆） | 可争取中立·砚青所在 |
| 人界 | **正道诸国联盟** | 历代"灭妖除魔"正道传承·深层被神族渗透 | 第二三卷反派/外交 |
| 人界 | **太一宗** | 正道第一宗·**信奉的"天道"实为神族**（F16·讽刺结构） | 周临出身·F16 |
| 人界 | **跨界商修网络** | 跨界贸易累积·相对超脱 | 陆离所属·和邦商务 |
| 妖界 | **妖王会盟**（八妖王） | 妖族大能议会·**含神族眼线戌迦** | 第四五卷·男主虚名高点 |
| 魔界 | **魔宫割据** | 上代败者/堕落者累积（江烬/厄枭等） | 第四-十卷反派梯度 |
| 冥界 | **冥府** | 跨循环执念累积·越来越沉 | 铁岚出身 |
| 多界 | **神族潜伏者**（堕神眼线） | 仙化夺舍人族顶层 + 妖王会盟眼线 | 暗桩·伏笔层 |

### 当代矛盾的根源（哪些是历史遗留的爆发）
- **人妖对立**：历代循环"神界清洗妖魔"的累积创伤 → 当代人界正道信奉"灭妖除魔是天道"（F16 真相：那套天道是神族）。
- **男主被天庭盯上**：男主穿越触发错位道鸣（F3·双救因果）+ 触及循环真相 → 天庭必死局操盘（F4/F5）。
- **江烬的恨**：上代被天庭操盘失败的累积幻灭 → 当代"人族比妖族更恶"的堕魔执念。
- **厄枭的怕**：曾被正道炼成傀儡的累积恐惧 → "先支配所有人以防再被支配"。
- **锤伯的痛**：灭族后的累积孤独 → 把匠心传给男主（F13/F20·代价是失去生命意义）。

> **每一个当代矛盾，都能追到一条累积的历史伤口。** 这就是演化史要保证的——让当代"有根"，让读者感到这个世界是"长出来的"，不是"摆出来的"。

> 写到某章卡住时，来这里查"这件事的历史背景是什么"。
