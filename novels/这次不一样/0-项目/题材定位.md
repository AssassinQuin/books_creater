# 题材定位

## 基本信息
- **书名**：《这次不一样》（暂定）
- **题材/类型**：仙侠 · 妖族幼体（凡身最弱开局） · **迪化流** · **种田流**（六界共和）
- **目标平台**：起点/番茄（男频长篇）
- **预计字数**：200 万字+
- **目标读者**：喜欢"Q 萌幼妖 ↔ 碾压级战斗神通"反差、人妖鬼魔仙五族共和、迪化流误解爽、种田建国流的读者

## 一句话梗概
前世付出善意被身边人辜负、走投无路轻生的人类灵魂林悟，被天道感应转生为**妖族幼体（小妖·凡身最弱）**，在妖界与人界边缘的妖灵密林靠**灵觉敏锐（血脉天赋变异·非金手指）+前世智慧+师徒传承+血脉觉醒+悟道+渡劫进化**+**被各方"迪化"（误解神化）**，一个个反转收编人/妖/鬼/魔/仙五族伙伴，从底层建起**和邦**（五族共和的善意之国，神族除外），打破六界大战循环，终成妖圣。

## 核心梗（三分法）
1. **迪化流**：男主无意言行被过度解读/神化，对方自我攻略，一个个反转爽（误解→真相→新误解）
2. **种田流**：从零建国、师徒传承+伙伴加入、经营发展、万邦来朝
3. **中国式共和**：人妖鬼魔仙五族共和 = 天下共和/和而不同（非日式联邦、非美式）

## 对标分析
| 对标 | 借鉴 |
|------|------|
| 迪化流网文 | 误解/脑补/神化的反转爽感机制 |
| 仙侠网文 | 灵气/境界（凡→练气→筑基→金丹→元婴→化神→大乘→仙→金仙→大罗）/渡劫/血脉觉醒/悟道/天道/因果/六界/灵石 |
| 种田建国流 | 据点由小到大、伙伴一个个加入、万邦来朝 |
| 共和/和而不同 | 中国式"和邦"治理（非西式联邦、非日式联合） |

## 差异化卖点
1. **仙侠+迪化+种田的中国风共和版**（市面少见）
2. 男主魅力驱动收编+迪化神化（种族为妖族幼体·原创仙侠非西幻）
3. 中国文化底色（和邦/万邦共和/和而不同），非日式非美式
4. **治愈内核（剧情层）+ 迪化被动变强（设定层）的反差**：男主本是普通妖族幼体（灵觉敏锐·血脉天赋变异·非金手指），因被各方"迪化"（误解神化）而被动获得超出自身实力的战力——碾压级场面多来自群像脑补+自发行动的迪化合力，而非主动外挂神通（强↔善的反差在被动承受，不在主动神通）
5. **进化触发机制全仙侠原生**：师徒传承（锤伯 V1 末传匠心本源）+ 血脉觉醒 + 悟道 + 渡劫
6. 有趣+反转+爽（非写实悲剧）

## 调性约束
- **有趣、反转、爽**为主（迪化误解爽 + 种田成就爽 + 碾压战斗爽）
- 不走写实悲剧/循环暗黑/暖中带冷
- 主角**魅力驱动**（非去主角中心）；多方势力作为"迪化对象"存在（被男主魅力折服/误解）
- 多方博弈保留，但基调是**建设感+反转爽**，非暗黑撕裂

## 核心约束
- 无后宫、无单一女主、无感情戏
- 迪化要有"反转逻辑"（误解要有合理基础，不能硬凹）
- 男主能力=灵觉敏锐（血脉天赋变异·非金手指）+迪化被动变强（详见 `1-世界观/男主能力进化体系.md`）
- 治愈交给剧情（锤伯师徒传承+V2 末护阵牺牲 / 群像善意累积 / 挚友线），能力本身无治愈属性
- 严守仙侠规则：神通觉醒靠"修炼/师徒传承/血脉觉醒/悟道/渡劫"
- 原创仙侠，世界观与人物全部原创，不抄任何已有作品
- 严守 `.claude/rules/story-consistency.md` 一致性规则
