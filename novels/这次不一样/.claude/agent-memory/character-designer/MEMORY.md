# Memory Index — character-designer (这次不一样)

## 项目方向

- 仙侠 · 男主转生妖族幼体 · 迪化流 · 种田流（六界共和）
- 治愈内核（剧情层）：男主前世轻生→转生妖族幼体→被群像善意累积治愈→真觉醒→建和邦
- 能力全战斗向（通灵玉鉴：鉴映/鉴纹/鉴纳/鉴纹暴起/通灵鉴域）；治愈交给剧情（锤伯师徒传承+V2末护阵牺牲 / 群像累积 / 挚友线）
- 进化触发机制全仙侠原生：修炼 / 师徒传承 / 血脉觉醒 / 悟道 / 渡大天劫

## 设计铁律

1. **从"是谁"长，不从功能位+怪癖拼贴**——先想角色的人生/伤口/欲望，怪癖自然流露
2. **原创**——人物原创，不抄任何已有作品角色
3. **多种族覆盖**——仙侠六族（人/地灵族·人族亚种/妖/鬼·幽冥/龙/仙·灵）+ 神族（外部主反派）
4. **无女主、无感情戏**——治愈靠群像累积+关键牺牲（锤伯 V2 末护阵），不靠单一女主拯救
5. **每个角色独立人生**——把男主从故事里抽走，角色的人生仍成立
6. **每个角色有行为重复点**——维持长篇一致性（如锤伯=叨叨念+捏料手法；小牙=露牙+学锤伯说话；陆离=我试试+契约精神）
7. **能力全战斗向**——男主金手指（通灵玉鉴：鉴映/鉴纹/鉴纳/鉴纹暴起/通灵鉴域）无治愈功能，反差在用途（强大战力用于护人/建国），不在能力本质
