## 四、人物弧线（本卷）

### 男主·林悟（Tier-1 深度型 · 反弧线起点 · 灵觉迟钝初现）

- **成长弧**：追查决心 → 镜像震撼（被江烬看穿）→ **灵觉迟钝初现**（线 3 V7 节点·"眼"首次发虚）→ 堕落真相沉重（"我差点就是江烬"）→ **自我怀疑开始**（"凭什么我不堕落"扎进心里·反弧线第一道缝·V10 才真摔跟头）→ 锁定"当代样本"（暗线推进·宿命感）。**反弧线起点**——V5 虚名最高 → V7 镜像扎心+灵觉迟钝初现 → V10 摔跟头（痛）→ V11 真觉醒。本卷是反弧线**第一道缝**，不能突变（V10 才真摔跟头）。
- **命运层（深度）·灵觉迟钝初现**：
  - **灵觉迟钝 = 认识自我动摇**（experience 深度）：江烬"凭什么不一样"灵魂之问触发男主前世创伤共鸣（前世被辜负·"不要相信任何人"的旧伤）·灵觉敏锐度首次明显下降——感知失准·善恶轮廓模糊·灵气浓度感应发虚。**这不是外挂失灵，是男主自我（敏锐感知）首次动摇**——比"外挂被破解"更内在、更宿命。男主第一次意识到"敏锐不是理所当然"（为 V10 灵觉暴跌埋第 3 粒）。
  - **江烬镜像 = 他"如果没被治愈"的 if 线**（深度层）：江烬是男主"如果失败堕落"的暗黑镜像（**他差点就是江烬**·这次不一样的重量第一次压在他身上）。
  - **三人同源三命运揭一层 = 他第一次意识到自己被治愈不是理所当然**（双救暗线的远方回声·"远方那道灵气"开始有形状·他隐约感到自己穿越可能与某人有关）。
  - **锁定"当代样本" = 他的朴素动机（护身边人）开始承载宏大命运**（他追的人是前世挚友·他还不知）。
- **反弧线种子**：自我怀疑开始（V10 摔跟头的种子·本卷就埋）+ 灵觉迟钝的失控感（V10 灵觉暴跌的前奏·线 3 第 3 节点）+ 迪化"亏成首富式反讽"让他首次感到"掌控不了外界解读"（修订 3 落实·失控感种子）。
- **大禹治水内核初现**：男主面对江烬不是"打败"是"看见自己的可能"——这是大禹治水"疏导非堵塞"的初阶形态（男主治愈方法论的镜像卷预演：不靠力量征服·靠理解善被打碎的伤口）。但 V7 压力下疏导首次力不从心（江烬的贪毒闭环太深·男主只能"看见"不能"化解"·为 V10 镜像考验终极一击+终幕迪化法则级化解蓄势）。

### 江烬（堕落魔尊 · 上代人族剑修 · Tier-1 深度型·多层镜像）⭐ 本卷旗舰 · 四层镜像

> **四层镜像设计**：① 三人同源三命运（最深的镜像）② 延长知行矛盾（贪毒闭环具现）③ 墨渊师徒情锚（情感锚）④ 江烬道心弧线。经典内核装入：麦克白+浮士德+夸父追日+三毒·贪。

- **第一层·三人同源三命运（F15 揭一层·最深的镜像）**：
  - **同一起点**：三个"想治愈世界的善意者"（上代/当代/穿越·都是人族顶尖剑修/妖修·都被天道陷害）
  - **江烬**（上代·**没被救**·善意被打碎→堕落）：上代人族顶尖剑修·被天庭陷害陷入必死局·**没有错位道鸣救他**（双救是周临当代才有的例外）·侥幸活·同袍被屠·被当叛徒追杀·多次试图重返正道被拒→被打碎堕落
  - **周临**（当代·**被男主错位道鸣救**·没堕落但被天庭追）：天庭陷害当代样本·男主穿越错位道鸣救了他→他没堕落·但被天庭持续追杀
  - **男主**（穿越·**被治愈**·选不堕落）：被锤伯/群像治愈·没被打碎→建和邦
  - → "表面是个人选择，其实是命运分叉"。**江烬是男主"如果没被治愈/如果失败堕落"的暗黑镜像**。
- **第二层·延长知行矛盾（inner-conflict · 贪毒闭环具现）**：
  - **江烬不是一次性嘴炮**，而是**持续的知行矛盾**——他知道堕落错了却停不下。
  - **贪毒闭环**（中国三毒·贪·总纲 §五江烬行·骨牌链 3 出处）：贪力量（怕被支配）→修魔速成→业力累积→天劫首劈→恐惧→贪更多力量（避免被天劫劈死）→业力更重→天劫更猛……**这是佛家"贪造业，业生苦，苦生贪"的闭环具现**。
  - 江烬的悲剧深度在此：**他不是"选恶"**，是**"知道善被打碎错了，但贪毒闭环驱动他停不下"**——知（善被打碎是错的）与行（继续修魔堕落）的矛盾延长不解决（inner-conflict 铁律：刻意延长不解决）。
  - **男主面对他不是"打败"是"看见自己的可能"**（大禹治水疏导初阶）：男主在江烬身上看见"如果前世没被治愈/如果放弃信念"的自己——这是镜像卷的真正深度（不是武力对决·是命运认知的碰撞）。
- **第三层·墨渊师徒情锚（情感锚·江烬线不只是理念对抗）**：
  - 墨渊（江烬徒弟·视江烬为父）作为情感锚·让江烬线不只是理念对抗·有**具体的人的牵挂**。
  - 江烬对墨渊的态度 = 他"被打碎的善"的最后火种（他教墨渊剑·教墨渊活下去·但他自己停不下堕落·墨渊是他若救赎的载体）。
  - **墨渊的孝心 = 江烬 if 线救赎的可能**（终幕继承善——江烬的善没白打碎·在墨渊身上有火种·V10 看清师父被天庭利用·终幕转化加入和邦）。
- **第四层·江烬道心弧线（v10 道心 4 维度·本卷起埋）**：
  - **执念维度**：证明"善被打碎"（上代剑修的堕落执念）
  - **孝心维度**：对墨渊的复杂情感（他视墨渊如子·但他自己被打碎的善不敢直面）
  - **镜像维度**：与男主的镜像（"凭什么你不堕落"的灵魂之问·问命运·非挑衅）
  - **道心维度**（弧线去向）：从"善被打碎"执念 → 去向"善可以被理解"（**V7 只埋种子·终幕才化解**·本卷不洗白不化解）
- **经典内核装入**（总纲 §五江烬行）：
  - **麦克白**（西方并存）：江烬 = 善被点燃后不可逆堕落（上代剑修的善被天庭陷害点燃→滑落·野心/执念被点燃后的不可逆）。"凭什么不一样"= 麦克白式压迫感（被命运逼到墙角的人·逼问命运为何放过别人）。
  - **浮士德**（西方并存）：江烬 = 为"更多"（证明善被打碎·证明自己的堕落是对的）而堕落——浮士德式"为更多出卖灵魂"的变体（江烬出卖灵魂不是为了青春/知识·是为了证明善不存在）。
  - **夸父追日**（中国·主框架）：江烬的执念 = 理想主义者的悲剧（**明知不可为而为之**——明知"证明善被打碎"是绝望的执念·仍然追·直到渴死）。夸父追日化为邓林·江烬堕魔化为魔尊·都是"追不到但仍然追"的理想主义者悲剧。
