# 剧情线 · 支线-陆离同病（男主同病的镜子 · V8 治愈反弹承载者）

> 一句话：陆离和男主**同病**——前世都付出善意被背叛——但男主选了轻生，他选了流浪逃避。他是男主的"另一种结局"，男主治愈他=治愈前世自己（剧情层）。
> 类型：**角色支线**（治愈累积圈·事件推动者②·V8 治愈反弹核弹承载者）
> 主导者：陆离（人族跨界商修·异界穿越者）
> 角色档案：`2-角色/陆离.md`
> 严咬合：`0-项目/上下文.md` / `6-方法论/剧情线设计规范.md` / `5-追踪/伏笔.md`（F22 陆离原世界之谜）/ `6-方法论/迪化机制底层重构-v4.md`（战略式迪化）

## 一、线定义

- **核心驱动**：陆离前世（现代世界）合伙人背叛+妻子离开+朋友圈站对面→精神死了→穿越异世界做流浪商修（契约感知天赋·伤口的具现）→从不长久停留从不建立羁绊。男主是 he 同病·但男主选轻生他选逃避。男主治愈他=治愈前世自己的另一种可能（剧情层）
- **起点**：V1-V2·男主在某次冲突中无意间为陆离解围（其实是摆烂+夜遁避战·被陆离误读为"远见之主"）
- **终点**：终局·陆离是和邦商务长·终于找到"不被辜负的地方"·把锤伯打的精密天平捐给和邦市集
- **线功能**：
  - **治愈弧的"同病镜子"**（男主治愈陆离=治愈前世自己）
  - **V8 治愈反弹核弹承载者**（"为什么你没变"——陆离的动摇是男主"治愈拉锯"的具现）
  - **战略式迪化范例**（契约感知对男主失灵·善不在契约框架内）

## 二、Beat 序列

### Beat-离1 · 迪化收编 · V1-V2（契约失灵·战略式迪化）

**时序**：V1-V2（跨 Arc）
**地点**：妖灵密林边缘 / 人妖边城
**相关人物**：陆离（主导）·男主（被迪化者）·锤伯（旧识·信任锚）

**开端**：陆离前世合伙人背叛+妻子离开+朋友圈站对面→精神死了→穿越异世界做流浪商修（契约感知天赋·伤口具现）→从不在一个城镇超过 3 天·从不建立羁绊。流浪到密林边缘时·锤伯给他打过一套商队用精密天平（用过好几年·这是他在异世界唯一保留的"长期物品"）。

**发展**：V1-V2 男主在某次冲突中无意间为陆离解围——其实是男主摆烂+夜遁避战（真实种子）·陆离基于"前世合伙人背叛的伤口+商人因果思维（巧合→预判）+锤伯给他打的天平旧情（信锤伯的'人鉴'）"（道心依据）·误读男主为"深谋远虑的远见之主"（放大方向）。**陆离的契约感知第一次失灵**——男主的"善"不在契约框架内（男主是真心·不是契约）。陆离震惊："这个人不和我谈条件？"

**高潮**：陆离得知男主是"锤伯的人"——对锤伯的"匠人认可"有信任（锤伯不打没价值的料）——这**加速了他的迪化**。陆离开始跟随男主（智囊+外交角色）。

**结果**：陆离迪化收编（战略式迪化·Beat-迪2 同步）。但他的契约感知总在工作·他下意识评估每个对话的"契约条件"——他还在等男主变成"另一个自己"。

**对剧情推动**：
- **本线推进**：从"流浪逃避"到"迪化收编（契约失灵）"
- **主线贡献（迪化弧）**：战略式迪化范例（契约感知失灵·善不在契约框架）
- **主线贡献（治愈弧）**：陆离=男主同病·治愈他=治愈前世自己（剧情层起点）
- **影响其他线**：锤伯师徒传承线（陆离的信任锚·锤伯天平）/ 商离投资线（旧情人·V3 重逢）

**伏笔与 callback**：
- **埋下 F22**（陆离原世界之谜·契约感知天赋人族跨界商修·穿越者·随身带锤伯打的精密天平）
- **埋下**：陆离"等男主变另一个自己"（V8 治愈反弹核弹的种子）

**关键物品 / 设定**：锤伯打的精密天平（陆离唯一的"长期物品"·信任锚·契约感知的具现）/ 契约感知（商修天赋·伤口的具现·对男主失灵）

**跨章数估算**：V1-V2 跨 Arc（迪化收编穿插主线）

### Beat-离2 · 锤伯死动摇 · V2 末（"善良被辜负"）

**时序**：V2 末（锤伯护阵牺牲）
**地点**：和邦雏形
**相关人物**：陆离·男主·锤伯（死）·异端审问官（直接死因）

**开端**：V2 末太一宗异端审问官围剿和邦雏形。锤伯护阵牺牲（Beat-锤3/治3 同步）。

**发展**：陆离目睹锤伯死——他的"前世合伙人背叛"伤口被触发："看吧·善良会被辜负。"他动摇（这是他一直等待的"男主变另一个自己"的时刻）。

**高潮**：**但男主没崩**——男主给锤伯加护体灵觉+镇魂印·让锤伯无憾而走（第一次"痛着信"的选择）。陆离震惊："为什么你没崩？"男主没回答（他还在自己的撕裂里）。

**结果**：陆离的动摇暂时平息·但种子已种——他还在等（如果下次男主崩了·他的"世界不值得信"就验证了）。

**对剧情推动**：
- **本线推进**：从"迪化收编"到"锤伯死动摇（但男主没崩·震惊）"
- **主线贡献（治愈弧）**：陆离的动摇是治愈拉锯的具现（Beat-治3 同步）
- **影响其他线**：锤伯师徒传承线（陆离是锤伯旧识·锤伯死触发他动摇）

**伏笔与 callback**：
- **兑现 callback**：Beat-离1（陆离"等男主变另一个自己"）在锤伯死时第一次动摇
- **埋下**：陆离还在等（V8 治愈反弹核弹的远端伏笔）

**关键物品 / 设定**：锤伯死（触发陆离"善良被辜负"伤口）

**跨章数估算**：V2 末 1-2 场（穿插锤伯牺牲主线）

### Beat-离3 · 建国 · V3（商务长·天平捐市集·愿意停留）

**时序**：V3（和邦建成）
**地点**：和邦
**相关人物**：陆离·男主·商离（V3 重逢·旧情人）

**开端**：V3 和邦建成。陆离作为智囊+外交·帮助建国（用商人经验）。

**发展**：陆离用契约感知做"群像迪化网络的违约预警"（成员背叛预警）——他的伤口（契约感知）成为和邦的功能。**商离 V3 重逢**（旧情人/前合伙人）——陆离的旧伤被触动（自保沉默伤过商离的前科）。

**高潮**：陆离做了一个他从未做过的事——**把锤伯打的精密天平捐给和邦市集**（象征他终于愿意停留·不再流浪逃避）。这是他从"精神死了"到"愿意建立羁绊"的转折。

**结果**：陆离在和邦找到"不被辜负的地方"的雏形。但他仍在等（男主会不会变）。

**对剧情推动**：
- **本线推进**：从"锤伯死动摇"到"建国（愿意停留·天平捐市集）"
- **主线贡献（共存弧）**：和邦商务长·群像迪化网络违约预警（Beat-共2 同步）
- **影响其他线**：商离投资线（V3 重逢·旧情人·旧伤）/ 锤伯师徒传承线（天平捐市集·锤伯遗物的延续）

**伏笔与 callback**：
- **兑现 callback**：Beat-离1（锤伯天平·唯一长期物品）在 V3 捐出·象征愿意停留
- **埋下**：陆离与商离的旧伤（V5/V8 和解的种子）

**关键物品 / 设定**：精密天平（捐市集·愿意停留的象征）/ 契约感知（违约预警功能）

**跨章数估算**：V3 中 1-2 场（建国主线穿插）

### Beat-离4 · 持续试探 · V4-V7（等男主变另一个自己）

**时序**：V4-V7（跨卷·和邦扩展→魔宫）
**地点**：和邦 / 妖王会盟 / 魔宫
**相关人物**：陆离·男主·商离（V5 真心追随·与陆离旧伤和解）

**开端**：V4-V5 男主虚名最高（迪化弧 Beat-迪3）。陆离作为商务长随男主。

**发展**：陆离**多次试探男主**——"你这么善·迟早被辜负。"他在等男主变成"另一个自己"（他的伤口让他无法相信无私善意）。**商离 V5 真心追随男主**（商离的迪化链：男主救她→"妖族真的护人"→与陆离旧伤和解）——商离的转变是陆离"同病镜子"的另一面（商离选择了相信·陆离还在等）。

**高潮**：V6-V7 江烬登场（嫉妒式迪化）——江烬"凭什么你不堕落"也是陆离想问的（陆离的"善良被辜负"伤口与江烬的"被打碎"共振）。但男主没堕落（有群像治愈）。

**结果**：陆离的"等"持续·但越来越松动（男主一次次没变·他的伤口越来越难维持"世界不值得信"）。

**对剧情推动**：
- **本线推进**：从"建国（愿意停留）"到"持续试探（等男主变·但越来越松动）"
- **主线贡献（治愈弧）**：陆离的试探是治愈拉锯的持续（Beat-治6 镜像验证同步）
- **影响其他线**：商离投资线（V5 真心追随·与陆离旧伤和解）/ 江烬堕落施压线（V6-V7 共振）

**伏笔与 callback**：
- **兑现 callback**：Beat-离2（陆离"等男主变"）在 V4-V7 持续·但松动
- **埋下**：V8 治愈反弹核弹的临界（陆离的"等"即将崩塌）

**关键物品 / 设定**：陆离的"我试试"口癖（不承诺·但一旦说"我答应你"必达）

**跨章数估算**：V4-V7 跨卷（穿插各卷主线）

### Beat-离5 · 治愈反弹核弹 · V8 ⭐⭐（"为什么你没变"）

**时序**：V8（人界前线·男主与周临真正相遇）
**地点**：人界前线
**相关人物**：陆离（崩溃）·男主（没变）·温故（拿出当年信物·治愈反弹触发器）·铁岚（第一次叫"林悟"）

**开端**：V8 男主虚名最高时的预兆（V10 摔跟头前奏）。**关键时刻**：温故拿出当年救男主时的信物护男主——"连温故都没走"（Beat-治7 同步）。

**发展**：陆离再次动摇——"看吧·全人族喊杀你·你的善终于被辜负了。"他等待的"男主变另一个自己"的时刻似乎到了（虚名即将破灭）。**但男主仍然没崩**（被群像治愈·剧情层）。

**高潮**：**陆离崩溃**——"**为什么你没变？**"（他的"付出善意被辜负"伤口让他一生等男主变成"另一个自己"·但男主从头到尾没变）。男主："**因为有锤伯·有小牙·有你。**"陆离的"世界不值得信"被彻底击碎——男主没变是因为有群像·陆离自己也是群像之一。**铁岚第一次叫男主本名"林悟"**（认主升华·骨牌链2 第3张）。

**结果**：陆离从"等男主变"转为"重新选择相信"——他终于不再等了。这是 V8 治愈反弹核弹（Beat-治7 的承载者）。

**对剧情推动**：
- **本线推进**：从"持续试探（等男主变）"到"治愈反弹核弹（崩溃→重新选择相信）"·陆离线转折点
- **主线贡献（治愈弧）**：V8 治愈反弹核弹（Beat-治7·陆离是承载者）
- **主线贡献（迪化弧）**：陆离的战略式迪化完成（从"契约失灵"到"真信仰"）
- **影响其他线**：温故善种线（V8 信物治愈反弹触发器）/ 铁岚认主线（V8 第一次叫"林悟"·骨牌链2）/ 商离投资线（V5 已和解·V8 陆离终于跟上）

**伏笔与 callback**：
- **兑现 callback**：Beat-离1（陆离"等男主变另一个自己"）在 V8 崩塌
- **兑现 callback**：Beat-离2（锤伯死动摇）在 V8 得到回答"男主没变是因为有群像"
- **埋下**：V10 摔跟头时"群像没散"（Beat-治8·陆离是"没散"的群像之一·V8 重新选择相信的回响）

**关键物品 / 设定**：温故的当年信物（治愈反弹触发器）/ 铁岚第一次叫"林悟"（认主升华）

**跨章数估算**：V8 关键卷约 2-3 章（治愈反弹核弹核心场景）

### Beat-离6 · 终局 · 不被辜负的地方（和邦商务长）

**时序**：V10-V12+终幕
**地点**：和邦（被围→化解循环） / 终幕和邦市集
**相关人物**：陆离·男主·群像（没散）

**开端**：V10 和邦被围（Beat-邦5/治8 同步）。陆离是"群像没散"的一员（V8 重新选择相信的回响）。

**发展**：V11 真治愈·V12 打破循环。陆离全程作为商务长支撑和邦后勤（粮草管理·Beat-邦2 粮草预言的承载者）。

**高潮**：终幕·陆离是和邦的"商务长"——他**终于找到了"不被辜负的地方"**。和邦市集里那架锤伯打的精密天平还在（Beat-离3 捐出的）——它成为和邦的象征之一（"不被辜负"的具现）。

**结果**：陆离线收束——从"精神死了·流浪逃避"到"找到不被辜负的地方·愿意停留"。男主治愈他=治愈前世自己的另一种可能（剧情层闭环）。

**对剧情推动**：
- **本线推进**：从"治愈反弹核弹（重新选择相信）"到"找到不被辜负的地方"·陆离线终点
- **主线贡献（治愈弧）**：治愈弧的"同病镜子"收束（治愈陆离=治愈前世自己）
- **主线贡献（共存弧）**：和邦商务长·"不被辜负的地方"的具现
- **影响其他线**：锤伯师徒传承线（天平捐市集·锤伯遗物归位）/ 商离投资线（终局和邦商务+情报枢纽）

**伏笔与 callback**：
- **回收 F22**（陆离原世界之谜·穿越者·终局找到"不被辜负的地方")
- **兑现 callback**：Beat-离3（天平捐市集·愿意停留）在终幕成为和邦象征

**关键物品 / 设定**：精密天平（和邦市集·"不被辜负"的具现·锤伯遗物归位）

**跨章数估算**：终幕收束段（1-2 章）
