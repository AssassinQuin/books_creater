# 剧情线 · 主线-共存弧（全书四大主线之一）

> 一句话：男主转生妖族（站妖边获信任）→ 被治愈 → 建「和邦」（五族共和·人/妖/魔/鬼/仙 共存·神族除外）→ 共存从一城到五族到打破六界大战循环→终幕研墨锤作为"建国之锤"归位。
> 类型：**主线**（四大主线之一·全书**世界层**脉络）
> 核心母题：**共存是治愈弧给世界的具现**——治愈弧（内层·少数核心圈）→ 共存弧（世界层·把治愈扩散到六界）。治愈弧回答"男主如何被治愈"，共存弧回答"被治愈的男主给世界什么"。
> 与其他主线：治愈弧（内层·情感核）/ 迪化弧（喜剧外壳·发生机制）/ 双救弧（命运层·跨越生死）—— 共存弧是**外层世界结构**，承载"这次不一样"在世界层面的落地。
> 严咬合：`0-项目/上下文.md` §五创作内核 / `6-方法论/剧情线设计规范.md` / `5-追踪/伏笔.md` / `大纲/重构总纲-v4.md`（§二能力极简·§四跨卷修复·§五经典内核·§九纪律）/ 各卷纲（V1-V12）的"共存里程碑"段
> 共存引擎（v4 总纲权威）：男主转生妖族（站妖边获信任）+ 灵觉感知个体非血脉 + 各族按自己道心汇聚（非被带动·水浒汇聚实质）

## 一、线定义

- **核心驱动**：男主前世"付出善意被人族辜负"→ 今世转生妖族（站妖边）→ 被各族善意治愈 → 把治愈的善意给世界（共建非支配）→ 共存从一城一族扩到五族，最后打破六界大战循环
- **起点**：V1 Arc1 · 男主转生妖族幼体 + 锤伯"不分血脉认材料"的地灵族师徒传承式共和雏形 + 温故（人族散修·不杀妖的人族）打破"人妖必敌"第一道口子
- **终点**：终幕 · 和邦五族共和完成（神族除外通过昊玄选盘古式牺牲完成）+ 六界大战循环打破 + 研墨锤作为"建国之锤"归位（化翅膀灵纹印记·F20 终极回收）
- **主导者**：男主（建和邦者·共建非支配的国父/精神领袖·不称帝但权力 100%）
- **线功能**：
  - **对治愈弧**：治愈弧"给世界"的具现（治愈的扩散载体）
  - **对迪化弧**：共和被外解读为"帝国扩张"是迪化喜剧引擎；虚名最高背后是和邦脆弱暗涌（线1）
  - **对双救弧**：周临相认=循环打破 KEY（人族最强剑修接纳妖圣=嗔毒被疏导的象征）
  - **对全书**：六界大战循环的**化解**主线（非杀戮·大禹治水疏导式）

### 共存弧的纪律（区别于治愈弧/迪化弧）

- **共和 Show 不 Tell**（修订4·读者毒点·最高纪律）：**绝不写议会辩论/制度建设长戏**。通过阿檀"找到第三条路"/各族互动/经济/结果/一句话定乾坤 show。男主国父/精神领袖地位通过群像态度与日常决策展示，不写议会戏不写制度戏。
- **共非帝国**（共和精神）：男主拒绝支配捷径（V4 拒绝厄枭操偶术·"我不需要支配来护人·这次不一样"）；国父/精神领袖·不称帝但权力 100%；各族按自己道心汇聚（水浒式·非被带动·非"主角光环收小弟"）。
- **中性词纪律**：用"大家/朋友/一起走/共和/共建"中性词；**禁政治特色词**（群众/集体/解放/为民/同志/阶级等）——这是仙侠世界的五族共和，不是近现代政治叙事。
- **神族除外**：五族共和指人/妖/魔/鬼/仙，**神族除外**（戌迦潜伏→V10 揭穿→神界操盘链条暴露·循环操盘者不可共存只能被化解）；终幕通过昊玄选盘古式牺牲（顺道·回归道）完成"神族道与器的分裂"的化解，非洗白。
- **边建边漏**（v4 重构总纲§四·线1·最高严重度）：和邦不是单边上升，是从 V3 起一路"边建边漏"——边境摩擦/粮草预言/天庭征调令/围城预演→V10 总爆发。共存的脆弱性是这条线的张力来源。

## 二、Beat 序列 ★核心

### Beat-共1 · 共存种子 · V1 Arc1/Arc4

**时序**：V1 Arc1（男主转生第一天）+ V1 Arc4（锤伯灭族暗线浮起·地灵族古法展开）
**地点**：妖灵密林边缘·锤伯炼器铺
**相关人物**：男主（幼妖·转生站妖边）·锤伯（地灵族老灵匠·共和雏形承载者）·温故（人族散修·人族善种）·小牙（灵狸族·同期同伴）

**开端**：男主转生为幼妖（凡身最弱·血脉天赋变异灵觉敏锐），前世"付出善意被人族辜负"的伤口让他本能封锁。按血脉天命论，他是"最弱的妖"——所有判断应来自血脉。

**发展**：
- **锤伯"不分血脉认材料"**（地灵族古法·万物皆料的匠人哲学）：锤伯用鉴定灵矿的手法捏起男主——"这么纯的妖气"。**男主灵觉第一次失灵**：锤伯没有"人/妖/血脉"判断，只有"匠人对料"的痴迷。这是地灵族师徒传承式共和的**道心根基**——认料不认血脉。
- **温故救男主一次**（人族善种）：温故（太一宗外门被逐的良心·"不杀妖的人族"）在灭妖队危机中救男主。**人族善种打破"人妖必敌"第一道口子**——人族不是整体，妖族也不是。
- **灵觉感知善意恶意**（破血脉论开端）：男主的灵觉敏锐（血脉天赋变异）首次让他感知到"个体差异"——同族有害他的（妖灵密林掠食者），异族有善意的（锤伯/温故）。**血脉不决定善恶，个体才决定**——这是共存引擎的认识论根基。

**高潮**：锤伯给男主打微型护甲，叨念"你这妖气太纯，没壳子装"。男主第一次哭（转生后第一次）。**"也许这次不一样"**（全书母题第一次冒头）——共存的种子在此萌动：这一次，他不是被人族辜负，而是被一个地灵族 + 一个人族散修同时以善对待。

**结果**：
- 共存种子种下：地灵族师徒传承式共和雏形（锤伯→男主·不分血脉认材料/认人）+ 人族善种（温故）+ 男主灵觉破血脉论认识论
- 男主第一次想"也许这次不一样"——治愈弧与共存弧的**共同起点**（两弧在此交汇）
- 温故留下灵石袋（V10 道具回响·线4种子）——"不杀妖的人族"的具现物

**对剧情推动**：
- **本线推进**：从"无共存（前世伤口·人妖必敌刻板印象）"到"共存种子萌动（地灵族师徒传承式 + 人族善种 + 灵觉破血脉论）"
- **主线贡献（治愈弧）**：共存种子与治愈种子同根（被各族善意击中→想给世界）
- **影响其他线**：治愈弧（同起点）/ 迪化弧（锤伯迪化真实种子·"好料"被脑补为"深意"）/ 温故善种线（人族口子起点·V10 信物治愈反弹触发器远端伏笔）/ 锤伯师徒传承线（共和雏形起点）

**伏笔与 callback**：
- **兑现 callback**：序章 F1（前世"付出善意被人族辜负"）→ 此刻异族有善意的可能性首次具现
- **埋下**：地灵族师徒传承式共和雏形（V3 扩展为多族共和·建国制度根基）
- **埋下**：温故灵石袋（V10 信物治愈反弹触发器·线4种子）

**关键物品 / 设定**：锤伯的微型护甲（边角料·绝作级工艺·地灵族认料哲学的具现）/ 灵觉首次失灵（锤伯绕过血脉判断）/ 地灵族古法（万物皆料的匠人哲学·道器合一·中国"格物致知"+庄子"庖丁解牛"）

**跨章数估算**：V1 黄金三章中的 2-3 章 + Arc4 锤伯灭族暗线浮起段

### Beat-共2 · 和邦建成 · V2 末-V3（五族雏形显形·第一次重击不倒退）⭐

**时序**：跨 V2 末-V3（V2 末锤伯死·共存第一次流血；V3 建国·五族雏形显形）
**地点**：人妖边城（V2）→ 和邦（V3·妖灵密林边缘正式建国）
**相关人物**：男主·锤伯（V2 末死·遗志落地）·陆离（V2 加入·人族商修·同病镜子）·温故（V2 深化·"不杀妖的人族"具体兑现）·小牙（继承师傅护甲图纸）·铁岚（V3 加入·鬼族·军事长）·商离（V3 投资·自由商会·和邦经济维度）·砚青（V3 远观破原则迹象·仙族加入前奏）·玄冥（V2 异端审问官督战·人族伪善伤口具现）

**开端**：V1 末锤伯传承后失炼器力，暗决为男主拼最后一次。V2 男主踏进人妖边城——共存引擎从"妖族内部共和雏形"扩到"人妖共存"第一步，立刻遇阻（异端审问官灭妖令抵达·"人妖必敌"刻板信仰的具象）。**陆离登场**（人族商修·契约感知天赋=伤口具现·前世合伙人卷款背叛）——人族善种代表 +1（继温故之后第二个人族善种·共存引擎人族口子扩张）。

**发展**：
- **V2 末·锤伯护阵牺牲**（共存第一次流血代价）：异端审问官玄冥督战围剿和邦雏形，锤伯燃本源布"地灵护阵"护男主而死。**共存第一次失去关键人物**。但**陆离在锤伯死时挡在男主身前**——人族善种在最重要的时刻证明"人族也可以为妖族拼命"。
- **男主"痛着信"不封闭**（共存信念经打击不崩）：男主撕裂（灵觉过载反扑首现·线3）但选"痛着信"——比 V1 传承更难的治愈。**反弧线预演但没倒退**（V10 才真倒退）。锤伯遗志："和邦要立"。
- **V3·建国真行动**（地灵族师徒传承式扩展为多族共和）：男主"痛着信"后立和邦——锤伯遗志兑现。**扩展逻辑**：地灵族认死理"万物皆料"的师徒传承模式（不分血脉认材料/认人）→ 制度化外推为多族共和（妖的部族+人的商修+鬼的判官+部分仙的记录者）。**水浒式各自汇聚**（非男主带动·每个角色基于私人道心汇聚）：铁岚找"不变形的主君"/小曜托付上代见证/陆离找值得停留的地方/商离商会独立/温故守护不该死的人/砚青见证者的觉醒。
- **大禹治水疏导建国**（v10 中国根基内核）：共和是疏导的具现——让各族有"化解的出口"，不是压制世仇。边境摩擦用疏导应对（不硬灭试探势力·让试探找不到"妖族威胁"的口实·让嗔毒没有对象）。
- **五族雏形显形**：鬼族（铁岚）加入破"鬼族不介入" + 部分仙（砚青首次破原则迹象·800年记录者）→ **妖 + 人 + 鬼 + 部分仙**（五族雏形）。
- **★ 边境摩擦第 1 粒埋**（线1·最高严重度·解决 V10 空降）：建国后立即埋和邦军事脆弱性——人妖势力试探和邦初立的脆弱（人族正道宗门玄冥势力触角 + 妖界厄枭外围 + 其他妖王部下试探被迪化为妖圣的男主）。意象：一道修了又裂的边界痕。**大禹治水式疏导应对**（不硬灭·疏导让试探势力找不到"妖族威胁"口实）。

**高潮**：**大迪化爆发·建国五族雏形立起**（中迪化卷高潮·V3 Arc5）——建国真行动（真实种子）被脑补放大为"妖族殖民/王者之气/妖圣转世"。男主苦笑 + 不配得感深化（"我只是想给被治愈的人一个安身处，怎么就成妖王了"·迪化底层第3层）。**第一次愿意主动信非锤伯的人**（灵觉深化质变·锤伯传匠心本源进一步兑现）——男主的"眼"成为建国选人/识破渗透/共和治理的内功。**与共和制度同构**（共和是战果非妥协·大禹治水疏导建国的具现）。

**结果**：
- 和邦正式建国·五族雏形显形（妖+人+鬼+部分仙）
- 地灵族师徒传承式共和雏形（V1）→ 扩展为多族共和制度（V3·背景结构·show 不 tell）
- 边境摩擦第1粒埋下（V10 兵临城下的远端种子）
- 男主"痛着信"不封闭 + 群像没散治愈反弹预演（V10 真低谷的预演）
- 阿檀魔族流亡前奏（V3 Arc6 暗线一触·V4 投和邦·大事件5启下魔族加入）

**对剧情推动**：
- **本线推进**：从"共存种子"到"和邦建成·五族雏形显形"——共存弧第一个大节点
- **主线贡献（治愈弧）**：治愈扩散到群像（V3 各角色治愈点穿插·暖累积）
- **主线贡献（迪化弧）**：迪化二阶段·崇拜追随起（建国真行动被脑补为王者之气）
- **影响其他线**：锤伯师徒传承线（V2 末 struct 收束·V3 遗志落地）/ 灵觉过载线（V2 末首冒→V3 预演节点）/ 温故善种线（V2 边城深化）/ 陆离同病线（V2 加入·V3 鉴连触媒）/ 铁岚认主线（V3 效忠·骨牌链2第3张）/ 各角色支线治愈点（V3）/ 线索-和邦军事脆弱性（V3 起点）

**伏笔与 callback**：
- **兑现 callback**：Beat-共1（地灵族师徒传承雏形 + 人族善种 + 灵觉破血脉论）→ 此刻扩展为多族共和制度 + 鬼族加入 + 五族雏形
- **埋下**：边境摩擦第1粒（线1·V10 总爆发回收）
- **埋下**：阿檀魔族流亡前奏（V4 投和邦·共存推到魔族门槛）
- **埋下**：砚青首次破原则迹象（V6 仙族加入前奏）
- **埋下**：商离自由商会（和邦经济维度·show 载体）

**关键物品 / 设定**：研墨锤（V2 末锤伯遗物转交男主·地灵族师徒传承式共和的具现物·建国之锤雏形）/ 锤伯的护阵古法（V2 末燃本源·地灵族古法） / 温故灵石袋（V2 边城深化·V10 道具回响）/ 商离自由商会（和邦经济维度·show 载体） / 冥的判官秩序（V3 新增司法维度·背景设定·不写长制度戏）

### Beat-共3 · 共和选择 · V4-V5（拒绝支配捷径·共非帝国的主动具现）⭐

**时序**：跨 V4-V5（V4 妖王会盟·厄枭招揽→男主拒绝；V5 妖王盛宴·昼带平衡派归附·五族共和具体落地）
**地点**：妖王会盟议事场（V4）→ 妖王盛宴 / 地灵族遗址（V5·锤伯灭族现场·复仇地）
**相关人物**：男主·厄枭（诱惑者·纯粹恶·操偶术·饕餮维度）·昼（平衡派妖王·共和落地的关键人物）·阿檀（认出厄枭=锤伯灭族仇敌·F21 揭·魔族加入前奏）·戌迦（神族眼线·八妖王之一·潜伏）·紫蘅（投机派妖王·血脉天命创口）·薛恒（天庭执行者·V5 暴露）

**开端**：V3 男主虚名（和邦建成后）传到妖王会盟。**水浒汇聚式群像登场**（八妖王各自故事汇聚·非男主带动·邵半仙被请去说书虚名传播具现）。男主进入妖界最深的博弈场——会盟议事场（不是朝廷是议会·共和的文化前身·妖族部族议事传统）。**迪化第二阶段·崇拜追随**（被妖王们迪化为"深不可测的大妖"·他按"被脑补的深意"行动——实为前世智慧+灵觉敏锐+摆烂躲事本能——竟成事·被动变强）。

**发展**：
