## 四、人物弧线（本卷·深度节点）

### 男主·林悟（Tier-1 深度型 · 旗舰 · 灵觉应用深化+中迪化爆点）

- **成长弧**：V2 站在路口没走的延续 → 群像因他没走而愿意共在 → 争取陆离信任 → **第一次愿意主动信非锤伯的人**（灵觉深化质变·卷高潮）。**渐进不突变**——拉锯贯穿 Arc1-4，到 Arc5 卷高潮才"主动释放信任"。
- **能力深化（灵觉应用深化）**：
  - **V1-V2 灵觉是感知层**（感知危险/灵气浓度/善意恶意模糊感·V1 锤伯传匠心本源开启"感知万物本质"）
  - **V3 深化到应用层**：从"模糊善恶感"→"精准分辨人心真伪"。用于：
    - **建国选人**：识别谁是真心投奔、谁是投机、谁是渗透（边境摩擦时辨别间谍·识破人族正道斥候/妖王部下眼线）
    - **共和治理**：各族世仇调解时，感知仇恨的真实深度，找到疏导口（大禹治水式疏导·不是压制世仇）
    - **信任决策**：陆离契约→真心拉锯中，灵觉作为男主判断陆离是否可信的**内在依据**（非外挂·真本事有局限——会过载·线 3 V3 反扑预演节点）
  - **关键写法**：灵觉应用深化是 V1 锤伯传匠心本源的进一步兑现（"感知万物本质"从材料扩展到人心）·非外挂叠加·有局限（过载反扑一次·线 3 V3 节点）
- **命运层（深度）**：
  - "第一次愿意主动信"是 V1"走开不救灵狸幼崽"的反向回响——**伤口被治愈到能反过来主动信人**（**早期选择→必然结局的宿命链条·V1 伤口在 V3 收拢**·宿命感）
  - **中迪化爆点**（迪化底层第 3 层·内心拉扯）：建国真行动（真实种子）被脑补为"妖族殖民/王者之气"（放大）——男主苦笑+不配得感深化（"我只是想给被治愈的人一个安身处，怎么就成妖王了"·**他知道是误会·怕被拆穿·拆穿=失去一切：和邦/追随者/治愈的种子**·迪化底层文档第 3 层）
  - **迪化塑造本体种子**（迪化底层·核心反转）：男主发现"被迪化推着成为的样子"——善良、守护、深谋——其实是他**真正想成为的人**。V3 是这个反转的种子（男主开始隐约感到"被推着成为的善的守护者不坏"·非主动接纳·留给 V7-V10 深化）
  - 建国是锤伯遗志的执行——锤伯虽死仍是男主行动的隐形驱动（**死者对生者命运的牵引**）
- **反弧线种子**：虚名累积的隐性代价（V3 卷高潮后虚名传开·V10 摔跟头的种子·本卷就埋）+ **灵觉过载反扑预演**（线 3 V3 节点·灵觉深化后的反噬·为 V10 暴跌埋因·线 3 六节点第 2 节点）

### 铁岚（幽冥族女将 · 前厄枭副官 · 弑主流浪 · 简练型 + 横向涟漪）

- 弑主后流浪求存 → 撞上和邦 → 考验男主"不会变的主君" → 效忠（和邦军事长）
- **关键写法**：考验不突变——她对主君的失望是 200 年累积（弑主后的创伤），男主要通过**具体事件**证明自己不会变形（不是一句话承诺）。**灵觉应用深化作为考验的内功**：男主用灵觉精准感知铁岚 200 年创伤的真实深度（不是表面敌意·是怕再认一个会变形的主君），找到疏导口（大禹治水·给她的认主本能一个不会被辜负的落点）。
- **横向涟漪（跨卷联系网·地灵+幽冥共同伤口）**：她弑主的厄枭 = 锤伯灭族的厄枭——**地灵族与幽冥族被同一敌人伤过**（V3 揭横向涟漪·V4-V5 复仇兑现·大事件 3 兑现节点）

### 小曜（龙族幼龙 · 循环梦 · 上代见证者 · 简练型）

- 被男主用**灵觉+锤伯传匠心本源+前世杂学**破解龙潭古阵释放（能力极简后的释放方式：男主灵觉感知到龙潭深处"沉睡气息"的古老阵法结构·用匠心本源解读阵法机理·用前世杂学（书店老板的杂学）补全阵法知识·非外挂·真本事+真传承）→ 循环梦残片断续浮出（上代六界大战见证）→ "这次不一样吗"（上代见证者对男主的辨认）→ 托付男主
- **关键写法**：循环梦不是一次性 dump 历史——是断续碎片，每片带出一点天道化身/始原仙神传说（**螺旋揭示·不全堆**）
- **功能**：历史揭示窗口 + 最强单体战力加入 + "这次不一样吗"的主题回声（书名钩子）

### 砚青（仙族 · 灵族 800 年记录者 · 简练型 + 暗线浮现 · 首次破原则迹象）

- V3 不正式登场——只作**首次破原则迹象**（800 年首次干预的前兆·留白炸弹·不现身）
- **关键写法**：留白炸弹——读者知道"有人在 800 年高度看男主这个例外"，但砚青不现身（**留白比登场更有重量·负空间手法**）。男主**灵觉应用深化的延伸**（从感知人心扩展到感知"被注视"）：某次建国关键决策时，男主灵觉突然感知到一股"非常远非常淡的注视"——像有人在 800 年高度看他·他分辨不出善恶（砚青的记录者视角·非敌非友·超越灵觉的分辨范围·为 V10/V11 砚青正式登场埋因）。
- **功能**：仙界不介入的裂缝 + 世界观揭示视角（800 年记录者怎么看男主）+ **灵觉应用深化的边界测试**（有东西超越灵觉分辨范围·男主的"眼"不是万能·线 3 局限伏笔的延伸）
