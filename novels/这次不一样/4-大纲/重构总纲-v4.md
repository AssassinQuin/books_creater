## 二、能力体系重设（灵觉极简版）★ 本次最大变更

### 男主能力一句话
> 男主就是普通妖族幼体，唯一特别的是灵觉敏锐（比同阶感知大一圈、能模糊感知识别善意恶意/灵气浓度）。**没有金手指外挂**。他的"强"完全来自 5 个被动来源。

### 5 个力量来源（无主动外挂）
1. 前世现代人智慧（30 岁灵魂 + 书店老板杂学 + 开阔眼界）
2. 灵觉敏锐的小天赋（血脉正常变异）
3. 师徒传承（锤伯 V1 末传匠心本源 → 感知万物本质的敏锐度质变）
4. 修炼积累（按妖修正常路径：幼妖→成妖→化形妖→大妖→妖王→妖神→妖圣）
5. **被迪化的"自我实现预言"**（核心）：别人觉得他强 → 照"深意"行动 → 竟成好事 → 他被动受益（声望+资源+追随者）→ 他真变强了 → 更被坚信。**结构性迪化，不是装的。**

### 迪化四阶段（能力极简后，这是男主"变强"的主引擎）
| 阶段 | 卷 | 类型 | 表现 |
|---|---|---|---|
| 一 | V1-V3 | 脑补误会 | 随口话被脑补为圣人之言；害怕撤退被脑补为战略撤退；收编败将被脑补为王者之气 |
| 二 | V4-V6 | 崇拜追随 | 正常突破被脑补为天纵之才；前世常识被脑补为道法通天；犯错被脑补为考验 |
| 三 | V7-V9 | 信仰献祭 | 被多方奉为妖圣转世；配角主动做事不求回报；男主完全不知自己被信仰 |
| 四 | V10-V12 | 法则扭曲 | 别人信"男主能化解天劫"→天劫真没来；信"男主是循环终结者"→循环真崩塌；**信仰扭曲天道**（道家心想事成+佛家愿力+民俗信则有）|

### V10 摔跟头机制重设（替代"鉴纹暴起碾压不动"）
- **灵觉迟钝**：前世创伤反扑 → 灵觉敏锐度暴跌（感知失灵，等于摘了男主唯一的"眼"）
- **迪化信仰崩塌**：虚名破灭（异端审问官自爆）→ 建立"男主不可战胜"的迪化基础动摇 → 配角动摇 → 男主失去"被动变强"的来源
- **三条件保留**（Decision ②）：因果锚（灵觉迟钝+江烬灵魂之问+虚名破灭+天庭阴谋塌陷）/ 持续行动（暗中建和邦留后手）/ 为他人主动承受

### 终幕法则化解重设（替代"通灵鉴域"）
- **迪化第四阶段法则级 = 循环打破机制**：六界众生信"男主是循环终结者" → 信仰扭曲天道 → 循环真的崩塌（非男主主动释放法则技能）
- 周临相认 = KEY：人族最强剑修接纳妖圣 = "人族嗔毒被疏导"的象征 → 嗔毒瓦解触发连锁 → 六界创口同步收敛
- 法则只是载体，**情感撑主题**（interpretive-space：避免设定赢的"虚"）

### "鉴连网络"重新解释（去外挂）
原"鉴连网络"（男主外挂共鸣借力）→ **重新解释为"迪化塑造本体"的具现**：群像因迪化男主而形成联结网络，他们的信仰+自发行动交织成网，男主被动处于网络中心受益。**不是男主主动建立的外挂**，是迪化的副产品。

### 群像能力也极简
所有角色按种族正常修炼路径，差异化靠**性格 + 剧情功能 + 人际关系 + 道心**，不靠能力体系。

## 九、v4 重构纪律（用户 2026-07-31 明确 · 贯穿所有卷纲）★

> 这条纪律优先级最高，覆盖前面的具体指引。

1. **独立设计，禁止打补丁**（refactor-over-patch）：v4 卷纲从本总纲 + v10 中国根基**独立设计**。v3 卷纲仅作素材参考（提取有效细节），**绝不照搬 v3 结构 / 不写"v4 vs v3 变更日志" / 不标"保留"标记**。该删的删，该重构的重构——旧内容不绑架后续生成。
2. **禁止锁章节数 / 字数**（design-philosophy：不限字数只到卷级）：卷纲只到**卷级**（本卷目标 / 主线骨架 / 情绪弧 / 人物弧 / 伏笔 / 爽点节奏密度）。节奏密度描述（如"爽点偏密 / 偏稀 / 紧张段让位"）允许，**硬约束（"共 X 章 / 约 X 万字 / 16 章"）禁止**——让正文写作由内容驱动，不被卷纲锁死。
3. **已完成卷纲若含补丁痕迹（变更索引段 / 保留标记 / 章节锚点 / 明确章数字数），一律清理回炉。**
