## 一、本卷目标

- **剧情完成**：男主虚名（V3 鉴连觉醒后）传到妖王会盟 → 八妖王博弈四派登场 → 男主被迪化为"新妖王"（修订 3·迪化事与愿违·越想低调越被深不可测）→ 厄枭（野心魔尊·锤伯灭族仇敌）派使者招揽（支配捷径）→ **男主主动拒绝（治愈后选择·不走江烬旧路·镜像反面）** → 阿檀（魔族流亡）认出厄枭=锤伯灭族仇敌·**F21 揭** → 厄枭借妖王会盟议事陷害 → 男主识破+再次拒绝支配 → 卷尾阿檀投和邦（魔族加入前奏）·厄枭结怨召开盛宴（→ V5）
- **男主状态变化**：维持**凝脉妖**（不进化·V4 是选择卷不是进化卷）；鉴连网络首次跨出和邦触达妖王会盟边缘（虚名载体）；**修订 4**：男主虚名最高但坚持"建共和·非支配"——和邦以地灵族师徒传承式共和扩展（背景结构·不写议会戏）
- **心境变化**：治愈深化（V3"愿意信"→V4"不走捷径"）→ 拉锯（明知有捷径偏不走·修订 3 知情后想低调反被神化的反讽）→ 主动拒绝（**这次不一样**的主动选择·vs 江烬当年可能走的路）→ 知仇（为 V5 复仇铺垫）
- **共存里程碑**（V4 在共存引擎的位置）：妖王会盟纳入前奏——男主虚名最高但**建共和（非支配·拒绝捷径）**；妖王会盟开始重新评估这个"新妖王"；阿檀魔族流亡预示**魔族加入前奏**（共存引擎推到魔族门槛）；本卷是**修订 4 共和制度**的"主动选择"节点（拒绝支配捷径=共和非帝国的具现）

## 三、情绪弧线

**虚名入会盟（被动） → 迪化事与愿违的无奈反讽（修订 3·想低调反被神化） → 八妖王博弈世界感 → 诱惑拉锯（厄枭捷径·明知有捷径） → 拒绝后的清亮（这次不一样·不走江烬旧路） → 灭族真相沉重（F21 揭·锤伯仇确认） → 远方周临牵挂（读者上帝视角） → 陷害识破的紧绷 → 阿檀投和邦的微光（魔族前奏） → 卷尾结怨的隐忧（V5 盛宴威胁）**

> 与 V3（建国·愿意信·扩散到伙伴）差异化：V3 是治愈**扩散**（暖），V4 是治愈**选择**（重）——主动拒绝支配捷径是"明知有捷径偏不走"的重量，不是又一次暖的释放。
> 与 V5（虚名膨胀→愿拼命）差异化：V5 情绪向上膨胀（虚名最高·拉锯最烈·为 V10 摔跟头蓄势）；V4 情绪是**清醒的拉锯**（拒绝+知仇·不膨胀·给 V5 蓄势留空间）。

## 四、人物弧线（本卷）

### 男主·林悟（Tier-1 深度型·旗舰）
- **成长弧**：治愈扩散到伙伴（V3 末态）→ 虚名入会盟视野（被动）→ 修订 3 知情后想管理迪化（主动但事与愿违·亏成首富式反讽）→ 拒绝支配捷径（**主动选择·不走江烬旧路·成长弧关键节点**）→ 知锤伯仇（为 V5 复仇蓄势·情感驱动）
- **命运层（深度）**：
  - 拒绝支配 = 他"付出善意被辜负"的伤口没让他选支配（**伤口没决定命运·反-write 弧**·与江烬堕落路径的分叉）
  - 修订 3 迪化知情后越管越大 = 他的"主动掌控"愿望被命运反讽（亏成首富引擎·喜剧外壳包裹宿命感）
  - 阿檀认出厄枭 = 锤伯之死的"被舍弃的付出"在他面前具现（与昊玄/殁殃"被舍弃的付出"的远端呼应·男主终局镜像预演）
- **反弧线种子（V10 摔跟头·本卷埋）**：虚名累积的隐性代价——他拒绝支配但虚名仍在滚大（V5 虚名最高·V10 摔跟头时越痛）；修订 3 反讽越喜剧，V10 反弹越痛
- **内心 OS 密集**（修订 3 落地）：男主察觉迪化后的内心吐槽（"我又不想当什么新妖王"·修真聊天群宋书航式·亏成首富式反讽喜剧）

### 厄枭（纯粹恶对照·V4-V5 反派·锤伯灭族仇敌·简练型）
- Arc2 派使者招揽（支配捷径·"投我可保和邦·可复仇"）→ Arc3 男主拒绝 → Arc5 借议事陷害 → V5 卷首召开盛宴复仇
- **关键写法**：厄枭**不能被 redeemed**（深度型反派的"被命运推"需要这个对照·故意留作纯粹恶）——但他的"野心"有自己的逻辑（怕被支配所以先支配·魔族焦虑·魔族"只信力量"的伤口产物）。读者要能理解他的逻辑但不同情他的选择

### 戌迦（万年潜伏的眼线·戏假情真·Tier-1 深度型·V4 裂痕起）
- Arc2-Arc5 推波助澜（执行天庭监视任务·站厄枭边）→ **Arc5 某一瞬"手下留情"留下情感裂痕伏笔**（深度节点·只埋不揭·终幕灰色收束）
- **关键写法**：戌迦裂痕**只埋不揭**——读者隐约感到他对某妖王/某场景有真情感（任务 vs 万年共处情感·深度型"戏假情真"的撕裂），但**不揭穿**；邵半仙乌鸦嘴"某妖王是叛徒"红鲱鱼反而误导读者**先猜戌迦**（但戌迦暴露留到 V10·昼揭穿）

### 阿檀（魔族流亡·铁岚旧同盟·魔族第三条路·简练型）
- Arc1 在场采药被卷入场（V3 已铺垫）→ Arc4 认出厄枭=锤伯灭族仇敌·F21 揭 → Arc6 带魔宫情报投和邦前奏
- **关键写法**：阿檀是**地灵+魔族共同伤口支线**的魔族端——锤伯灭族↔阿檀流亡同源厄枭（横向涟漪·两个被厄枭伤过的种族）；她的"第三条路"（不野心不堕落·共建）是 V6 江烬镜像的预演（"魔族也有第三条路"的存在证明）

### 昼（白虎族老牌妖王·平衡派·简练型·V4 是"关注"不是"认可"）
- Arc2 暗中观察男主（**V4 是关注·V5 才认可**）→ 平衡信念与男主共和的碰撞（为 V5 认可铺垫）
- **关键写法**：V4 不让昼"认可男主"——V5 的认可是 earned 的（要有 V4 的观察拉锯做前提）；昼的"察觉戌迦不像妖族"在 V4 只埋（V6-V7 调查·V10 揭穿）

### 紫蘅（九尾狐族投机派·简练型·V4 出场·V5 出卖）
- Arc2 拉拢打探男主（投机·弱族生存逻辑·"新妖王崛起"的价值评估）→ Arc5 陷害中观望（V5 出卖前奏·"两边都不得罪"）
- **关键写法**：紫蘅 V4 不出卖男主（V5 才被厄枭威逼利诱出卖）——V4 是她的"投机评估期"，让她 V5 出卖有 V4 铺垫才不突兀

### 周临（Tier-1 深度型·远方 POV·修订 1·1 章）
- Arc4 1 章远方 POV（人界前线苦撑·不知男主存在·"替林悟活"的执念基底）
- **关键写法**：周临**绝不出现**在男主线（修订 1·远方平行 POV·互不知情）；POV 章让读者**持续牵挂**（修真聊天群/诡秘塔罗会验证·远方成员有 POV 才"人均主角"）；可融入双救暗线弱回声（远方灵气共鸣·读者上帝视角牵挂）

### 邵半仙（迪化喜剧型·V4 被请去妖王会盟说书）
- Arc1 妖王们请他说书（虚名传播具现）→ Arc1-Arc2 乌鸦嘴首爆·**红鲱鱼预测"某妖王是叛徒"**（误导读者猜戌迦）→ Arc5 陷害期再次乌鸦嘴（迪化滚雪球）
- **关键写法**：邵半仙**完全不碰治愈主题**（喜剧型·只负责迪化传播+伏笔分层）；他的乌鸦嘴预测在 V4 是红鲱鱼高潮（读者跟着猜叛徒·实际答案留到 V10 昼揭穿戌迦）

## 六、剧情推进顺序（6 Arc · 顺序推进 · 不限定章数）

> ⚠️ **只给 arc 顺序与 arc 内事件顺序，不限定章数**——每个 arc 多少章由内容自然决定。细纲/正文不得为凑章数注水或压缩。**章数编号是相对位置·非绝对章号**。

### Arc 1 · 虚名入会盟视野 · 邵半仙说书 · 迪化反讽起
- **目标**：男主虚名（V3 鉴连觉醒后）传到妖王会盟；妖王们请邵半仙说书（虚名传播具现）；邵半仙乌鸦嘴首爆"某妖王是叛徒"红鲱鱼；男主被告知"被新妖王提名"·**修订 3 反讽喜剧起**（男主想消解迪化反被神化更深·亏成首富式）
- **爽点**：虚名入会盟迪化（反讽喜剧）/ 邵半仙乌鸦嘴首爆（红鲱鱼+伏笔分层）
- **情绪**：被动入局 → 修订 3 反讽无奈（想低调越深不可测） → 喜剧外壳下的隐忧（"我没想当妖王"）
- **支线**：邵半仙迪化传播 / 妖王会盟议事制 / 异常妖气（戌迦监视·V1 埋的戌迦暗线在此升级为"被妖王们察觉异常"）
- **妖界文化展开**：妖王会盟议事制（议而不决）/ 八妖王各领地（白虎雪原/九尾狐幻境等）/ 血脉论在会盟的体现（男主凡身 vs "新妖王"虚名的最大反差）
- **深度节点（男主·修订 3）**：男主知情迪化后想消解——主动澄清"我不是妖王"/想低调装弱——结果每次动作都意外让迪化更大（亏成首富引擎·越想消解越深不可测·喜剧外壳包裹宿命感）
- **迪化**：男主想澄清反被神化"深不可测"/想装弱反被神化"扮猪吃虎·妖王谦逊"/想低调避开议事反被神化"妖王巡视不在场·更是深不可测"
