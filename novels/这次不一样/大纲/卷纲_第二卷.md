## 一、本卷目标

- **剧情完成**：和邦雏形（锤伯/小牙/男主）接触人妖边城 → 异端审问官围剿（玄冥派·锤伯死上级·F16 前兆） → 陆离加入（人族商修·同病镜子·契约试探→真心追随） → **V2 末锤伯护阵牺牲（燃本源战死·治愈撕裂·暖被暴力夺走）** → 男主选"痛着信"不封闭
- **男主状态变化**：维持成妖（练气·**V2 不进化**——这是撕裂卷不是进化卷）；鉴纹在但不能逆天；新增"迪化知情者"身份（修订3 落地）
- **心境变化**：边城新奇（人妖交汇的世界展开）→ 迪化察觉反讽（亏成首富式·越想低调越显赫）→ 异端审问官压力 → 鉴映失控首次具现（前世创伤反扑·克制冒头）→ **锤伯牺牲的暖被夺撕裂** → 选"痛着信"（不封闭·治愈经打击不倒退·反弧线预演但没倒退·V10 才真倒退）
- **共存里程碑**（V2 在共存引擎的位置）：**人妖共存经第一次重击·男主"痛着信"不封闭**
  - ① 陆离（人族商修·同病镜子·付出善意被辜负者）加入 = 人族善种代表 +1（继温故之后第二个人族善种·共存引擎人族口子扩张）
  - ② 温故线推进（V1 灵石袋道具埋因→V2 在边城具体兑现"不杀妖的人族"的存在）= 人族善种从"个别"到"网络"（自由商会倾向男主）
  - ③ 异端审问官玄冥围剿 = 人族伪善伤口的具体化（"灭妖是天道"信仰被利用·F16 前兆·人族被当枪使）
  - ④ 锤伯被异端审问官逼死 = 共存第一次"流血代价"——但男主没倒退（"痛着信"是共存信念经打击不崩的证明·比 V1 传承更难的治愈）
  - ⑤ 男主"看个体"逻辑扩到人族（陆离·玄冥·温故三方对照）：血脉/种族不重要，你是谁才重要

## 三、情绪弧线

**边城新奇 → 迪化察觉（反讽喜剧调）→ 拉锯（试探/商战/审问官阴影）→ 异端审问官压力紧绷 → 护短暴发震撼 → 自责 → 鉴映失控反扑（"不要相信"）→ 锤伯牺牲（暖被暴力夺走·撕裂）→ 痛着信（不封闭·治愈反弹预演）→ 钩子（建国遗志）**

> **与 V1 情绪差异化（强制·防同形）**：
> - V1 传承 = **暖的代价**（锤伯活着但失意义·一种"代价"·暖还在）
> - V2 牺牲 = **暖被暴力夺走**（锤伯死了·暖被强行夺·一种"失去"·暖没了）
> - V1 高情绪是"暖+痛"；V2 高情绪是"撕+空+选信"。**两个高情感不能同形·否则读者麻木**。
> - V1 男主是"接受善意"的弧；V2 男主是"善意被夺后还要不要继续善"的弧。

## 四、人物弧线（本卷）

### 男主·林悟（Tier-1 深度型 · 旗舰）
- **成长弧**：边城接触 → 察觉迪化（修订3 落地）→ 主动管理但事与愿违 → 异端审问官压力 → 锤伯死撕裂 → 鉴映反扑 → **选"痛着信"**（V2 关键节点·反弧线预演·但没倒退）
- **命运层（深度·本卷深化）**：
  - 他察觉迪化但消解不了 = **他的存在本身在改变世界**（他越想低调越显赫·亏成首富式宿命·命运不让他隐身）
  - 锤伯死 = 他"付出善就引来更大的恶"（前世创伤在 V2 重演·F1 程哲碎片触发·"被信任的人背叛"反扑）
  - 鉴映失控首次具现 = 他的天赋里藏着前世创伤（**力量=伤口**·F10 首现·他的最强能力（看真心）正在被创伤扭曲成"不要相信"）
  - 他选"痛着信" = 他对抗自己的命运层（前世他选择"不再付出"·这一世他选继续·但付出了代价）
- **反弧线种子（V10 摔跟头的种子·V2 就埋）**：
  - 护短执念过度依赖（V2 护短暴走后自责·为 V10 碾压不动蓄势）
  - 鉴映失控渐进反扑（V2 冒头·V10 最强反扑·第三幕爆发）
  - 虚名累积的隐性代价（V2 边城迪化滚雪球·为 V10 虚名破灭蓄势）
- **修订3 落地（迪化事与愿违·核心）**：
  - 男主从 V1 的"完全不知"转为 V2 的"知情者"
  - 内心 OS 密集（"我又不是什么妖王""我只想活着""为什么我越躲越红"·修真聊天群宋书航式）
  - 主动想管理/消解迪化（装低调/澄清/选择性装逼），但每次动作都意外让迪化更大（亏成首富引擎·反讽喜剧）
  - **内核仍真诚**：迪化是外壳，他真心护陆离/锤伯/小牙，治愈内核不变（不能因反讽喜剧 OOC 成犬儒）

### 锤伯（地灵族老灵匠 · 主题承载 · 简练型 · V2 完成 struct）
- **完成弧**：V1 末传承（失炼器力·"绝作完成后的释然"）→ V2 边城日常（释然但生命意义已失·"等死"状态）→ 异端审问官围剿察觉"地灵护阵"古法预感 → V2 末主动燃仅剩本源护阵战死
- **关键写法（与 V1 传承差异化）**：
  - V1 传承是"他活着但失意义"——代价型
  - V2 牺牲是"他主动选死·因为活着的意义（打磨好料/护徒弟）已彻底完成·护阵是他最后的绝作"
  - **不能写成男主没救他的愧疚驱动**（防跑偏红线）——锤伯是**主动选**："我的绝作完成了·该走了·这次换我护你"
  - 他的死有尊严（地灵族匠人的最后一件作品 = 护阵·不是被拉去死的悲剧角色）
- **跨卷大事件 3（锤伯链 V2 兑现）**：传承→牺牲的 struct 完成；本源入冥府（F20 收·冥府线启动）

### 小牙（灵狸族少年 · 锤伯徒弟 · 成长弧型 · V2 加重）
- 恨人族（V1 已埋）→ V2 边城被异端审问官直接伤害（人族伪善伤口具体化）→ V2 末锤伯死→小牙陷入"师兄是人形妖族·师傅被人族逼死"的撕扯 → **他的恨意升级但被男主"痛着信"拉住**（V2 关键情感节点·小牙的"反弧线预演"·为 V7 对周临血仇拉扯蓄势）
- **血仇种子（V7 兑现）**：V2 异端审问官围剿中，小牙可能远远"感知"到某个腥味（周临留下的痕迹·不点名·不亮身份·远方回声埋因）——埋 V7 男主锁定周临时小牙的血仇拉扯

### 陆离（人族商修 · 同病镜子 · 契约感知天赋 · 智囊型 · V2 加入）
- **加入弧**：契约试探（探男主实力/底细·商业筹码）→ 拉锯（同病镜子被男主"看真心"照见）→ 真心追随（V2 末锤伯死时陆离挡在男主身前·契约转追随）
- **同病镜子**：陆离也是"付出善意被辜负"者（具体伤口·V2 揭一层·留 F22 完整原世界之谜给后续）——他的契约感知天赋（F22·V2 埋·V3 回收）让他能"读"出男主的善意，但他一开始不信（前世创伤），慢慢被治愈
- **关键写法**：陆离别工具化——契约试探要有他自己的伤口驱动（同病镜子要真），追随不是被男主光环收服，是被治愈（V2 加入节奏的非工整·与铁岚 V3 考验效忠差异化·不模板）
- **多功能编织**：人族善种代表 +1（共存引擎）+ 商修网络展开（和邦经济维度）+ F22 鉴连触媒（V3 鉴连觉醒的道具）+ 与商离旧情伏笔（V5 重逢埋因·跨卷结构网三）

### 玄冥（异端审问官首长 · 太一宗激进派 · 锤伯死上级 · 深度型 Tier-1 · V2 首出场）
- **表面（他以为）**：信奉"灭妖除魔是天道"——下灭妖令围剿和邦·他一生最坚定的信念
- **其实（能动性错觉·读者层·V2 只埋不揭）**：他信的"天道"实为神族意志（F16）——他派的异端审问官、下的灭妖令，实为神族借他的手除异己。**V2 不揭·V10 塌陷时回看 V2 才知道**
- **命运层**：他是周临的老师（跨卷结构网三·同门：温故被逐/周临留下/玄冥授业）——他亲手教出的最强学生（周临）正是他信仰体系要清除的"变数"（师徒命运错位·V2 暗触不展开·V7-V10 兑现）
- **V2 落地场景方向**：他下令围剿和邦——表面是反派行径，命运层是他"忠于信仰"的悲剧（他越忠，错的越深·锤伯死在他手里的因果）
- **关键写法（防脸谱化）**：
  - 他是**信念坚定的悲剧**不是脸谱反派——读者要能理解他（他信的不是错的是天道，是他不知道天道是什么）
  - 他对锤伯的"死上级"关系不是私人恩怨——是体制（异端审问官体系·太一宗激进派）的必然
  - 他不 V2 塌陷——V10 才塌（深度型·螺旋揭·不全堆 V2）
  - 他与温故是太一宗同门两路（激进伪善 vs 良心被逐·跨卷结构网三镜像）—— V2 暗触，V10 兑现
