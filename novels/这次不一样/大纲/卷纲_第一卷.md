## 一、本卷目标

- **剧情完成**：男主转生妖族幼体（凡身 E-）→ 遇锤伯（治愈种子）→ 摆烂拉锯 → 修炼苦挣 → 首次护短暴走（鉴纹暴起首现）→ V1 末师徒传承（鉴纳初醒+第一道妖纹）→ **成妖（凡→练气）**
- **男主状态变化**：幼妖（凡身最弱）→ 成妖（练气）+ 鉴纳初醒+第一道妖纹（鉴纳累积的标记·护体妖纹）+ 道号（F13）
- **心境变化**：麻木摆烂（想死）→ 治愈种子萌动（"也许这次不一样"）→ 第一次想"回馈" → 愿意为锤伯/小牙拼命（护短）→ 接受传承（第一次被以善对待·不知如何回应）
- **共存里程碑**（V1 在共存引擎的位置）：**种下妖+人共存的种子**——①男主转生妖族（站妖边·获信任前提）②鉴映看个体破"血脉论"开端 ③温故（人族善种）打破"人妖必敌"第一道口子 ④地灵族师徒传承式共和雏形（锤伯→男主·不分血脉认材料/认人）

## 三、情绪弧线

**摆烂麻木 → 警觉困惑 → 治愈种子萌动 → 考验拉锯 → 部族世界新奇/被辱 → 护短爆发震撼 → 自责 → 暗线沉重 → 传承预感 → 抗拒拉锯 → 传承震撼（暖+痛）→ 成妖蜕变 → 释然+钩子**

> 与 V2（牺牲·痛被夺）情绪差异化：V1 传承是"暖的代价"（活着但锤伯失意义），V2 牺牲是"暖被暴力夺走"——两卷高情绪不能同形。

## 四、人物弧线（本卷）

### 男主·林悟（Tier-1 深度型 · 旗舰）
- **成长弧**：想死/摆烂 → 治愈种子 → 第一次想回馈 → 护短（为身边人）→ 接受传承。**渐进不突变**——摆烂拉锯贯穿 Arc1-3，到 Arc3 护短才第一次"主动为别人"，Arc6 才"接受别人为自己付出"
- **命运层（深度）**：
  - "走开"不救灵狸幼崽 = 前世创伤在替他做选择（**伤口写命运**）
  - 鉴映第一次失灵（锤伯）= 遇到第一个"绕过他所有警惕触发"的人
  - 鉴纹暴起首现 = 他的最强战力来自前世"付出善意被辜负"的怒火（**力量=伤口**）
  - 穿越即双救（远方灵气共鸣）= 他不知道自己救了周临（**宏大命运 vs 朴素动机**）
- **反弧线种子**：护短执念过度依赖（V10 摔跟头的种子·本卷就埋）

### 锤伯（地灵族老灵匠 · 主题承载 · 简练型）
- 匠人纯粹认可（认死理"料不能浪费"）→ 警觉男主凡身瓶颈 → 暗决传承 → V1 末耗本源·失炼器力（"绝作完成后的释然"）
- **关键写法**：传承后他**活着但失去生命意义**（族灭后靠"打磨好料"活着，现在意义被剥夺）——这个代价要写足，是 V1 最重的情感

### 小牙（灵狸族少年 · 锤伯徒弟 · 成长弧型）
- 恨人族（父亲被人族猎杀）+ 护师傅 → 考验男主 → V1 末接纳"师兄"
- **血仇种子**：对周临的血仇（周临杀过灵狸族）·V1 不展开，埋暗线

### 邵半仙（迪化喜剧型 · v3 新增 · 首出场）
- Arc2 入妖灵密林，游方说书定调迪化，乌鸦嘴埋**红鲱鱼假伏笔**（某离谱预测误导读者）
- 完全不碰治愈主题；给自己埋一条"怕自己乌鸦嘴"的小暗线

### 温故（人族散修 · 人族善种 · 共存引擎人族口子）
- Arc1 ch5 救男主（V10 治愈反弹道具埋因）→ Arc4 线深化（"不杀妖的人族"代表）→ 打破"人妖必敌"

### 莘奴（人族灭妖队队长 · V1 小反派 → V10 转化）
- Arc1 ch5 灭妖队围剿男主 → Arc3-4 持续压力 → V1 埋"灭妖者"形象（V10 反向护妖的反转铺垫）

## 六、剧情推进顺序（6 Arc · 顺序推进 · 不限定章数）

### Arc 1 · 黄金三章 + 起手 ✅ 已有细纲（ch1-5）
- **目标**：转生鉴映本能亮相 + 摆烂执念外化 + 遇锤伯治愈种子 + 小牙考验 + 灭妖队危机/温故相救

- **情绪**：麻木→警觉→种子萌动→考验拉锯→意外被救

- **深度节点**：男主"走开"=伤口写命运；鉴映失灵(锤伯)

### Arc 2 · 摆烂拉锯 · 迪化起势 · 修炼苦挣
- **目标**：男主被迫留炼器铺（锤伯认死理）+摆烂vs治愈拉锯；邵半仙首出场定调迪化；修炼苦挣+瓶颈初现；散修误读滚雪球
- **爽点**：迪化喜感（邵半仙说书+散修误读）/ 修炼小突破（鉴映精进·扮猪吃虎）
- **情绪**：拉锯（摆烂vs治愈）→ 警惕松动 → 苦挣
- **支线**：邵半仙乌鸦嘴+红鲱鱼 / 小牙恨人族伤口（灵狸族与人族冲突）/ 温故灵石袋深化
- **妖界文化展开**：地灵族炼器铺日常 / 妖灵密林边缘风物 / 妖族认死理性格
- **深度节点**：男主被动修炼（不积极·摆烂拉拽）；邵半仙"怕自己乌鸦嘴"暗线起

### Arc 3 · 妖灵密林诸部 · 血脉论 · 首次护短暴走 ⭐
- **目标**：诸部登场+妖界文化（血脉论/部族共生）；男主凡身被辱（血脉论反差）；危机升级；**首次护短暴走（鉴纹暴起首现）**；暴走后果
- **爽点**：⭐护短暴走首现（核弹·碾压级·读者等了十几章）
- **情绪**：部族世界新奇 → 被嘲侮辱 → 护短爆发 → 自责
- **支线**：诸部世界展开 / 血脉论歧视 / 戌迦察觉异常升级
- **妖界文化展开**：血脉崇拜+部族共生 / 八妖王割据背景 / 凡身=血脉论最底层的反差
- **共存引擎节点**：男主鉴映看个体（绕过血脉论）——"血脉不重要，你是谁才重要"的种子
- **深度节点（男主命运层）**：鉴纹暴起=前世创伤具现（力量来自伤口）；F10 鉴映失控首次冒头（暴走后·克制）；F19 护短极限种子
- **迪化**：暴走被神化"妖王现世/妖神降临"——迪化滚雪球升级

### Arc 4 · 锤伯灭族暗线 · 地灵族古法 · 人族压力
- **目标**：锤伯灭族之谜浮起（F21）；地灵族古法/师徒传承展开（为 V1 末传承铺垫）；人族猎师团/灭妖队持续压力；男主收编第一只弱族部下（和邦雏形）；温故线回收
- **爽点**：收编（种田/建国爽点·和邦共和雏形）/ 锤伯灭族之谜悬念
- **情绪**：暗线沉重 → 古法敬畏 → 人妖压力 → 收编希望
- **支线**：锤伯灭族之谜（厄枭阴影）/ 地灵族古法传承 / 温故人族善种线 / 莘奴灭妖队压力
- **妖界文化展开**：地灵族匠心真元/传承代价/族灭历史 / 人妖仇恨伤口
- **共存引擎节点**：男主"不看血脉看个体"收编杂血弱族 = 地灵族师徒传承式共和雏形；温故打破"人妖必敌"
- **深度节点**：锤伯伤口展开（主题承载型深度）

### Arc 5 · 修炼瓶颈 · 传承铺垫 · 男主抗拒
- **目标**：男主修炼到瓶颈（凡身承不住·需匠心本源）；锤伯暗决传承；男主抗拒（不想锤伯付代价）；邵半仙乌鸦嘴预告

### Arc 6 · V1 末高潮 · 师徒传承 · 鉴纹觉醒 · 成妖 ⭐
- **目标**：危机触发传承（大事件围攻）；师徒传承（锤伯耗本源·失炼器力·男主濒死承本源）；鉴纹觉醒+成妖；道号（F13）；卷尾钩子→V2

## 八、防跑偏红线（本卷写作底线）

1. **男主摆烂贯穿 Arc1-3**：不能让他主动修炼太积极/主动建和邦——V1 他还在摆烂拉锯，修炼是被锤伯带动/被护短触发，收编是"被推着"不是"要当领袖"
2. **周临 V1 绝不出现**：只作"远方灵气共鸣"（序章上帝碎片），**不点名·不出场·不交手**
3. **灵狸幼崽（ch1）= 小牙同族伏笔**：男主 V1 要"走开"（摆烂执念），不能 V1 就救了她
4. **迪化后置**：男主越躲越被神化，**不能让男主主动利用迪化**；紧张段（护短暴走/传承）迪化让位
5. **鉴纹暴起首暴要狠但不能无敌感固化**：暴走后要有"难收/自责"代价（F19 种），为 V10 摔跟头蓄势
6. **传承是暖的代价不是痛的撕裂**：锤伯活着但失意义——与 V2 牺牲情绪差异化
7. **鉴映失控只冒头不爆发**：V1 ch18 首次冒头（克制），爆发留第三幕

## 九、本卷自省（精彩/问题/可加）

### 精彩点（要打狠）
- 护短暴走首现是 V1 最大爽点——读者等了十几章的碾压级释放，要写足反差（最弱幼妖 vs 碾压级）
- 传承是 V1 最重情感——暖中带痛，锤伯"活着但失意义"要写出重量

### 人物问题（防跑偏）
- 小牙考验线别拖（Arc1 内 2 章解决，否则节奏垮）
- 摆烂拉锯别太长——Arc2-3 必须有"种子萌动"的渐进，否则读者烦男主不成长
- 邵半仙别成功能点缀——给他"怕自己乌鸦嘴"的小暗线（一个怕自己说中命运的人）

### 剧情问题（跑偏风险）
- 序章上帝碎片不能太隐（读者要隐约感知"穿越救了人"，否则终局相认落空）
- 锤伯灭族之谜（Arc4）别抢主线——是暗线铺垫，不是 V1 主事件
