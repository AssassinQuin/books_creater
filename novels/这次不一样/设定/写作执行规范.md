## 一、字数要求

- **每章目标**：3000字以上
- **允许范围**：3000-5000字
- **最低门槛**：每章≥3000字
- **检查方式**：每章完成后立即用Python脚本统计字符数：`python3 -c "import sys; t=open(sys.argv[1]).read(); print(f'字符数: {len(t)}')" 文件路径`

### 偏差处理
- 低于3000字：**必须使用场景深化技法扩写**（→见下方"场景深化标准"），让每句话同时做≥2件事
- 超过5000字：考虑分章

## 二、内容依据（严格执行）

### 大纲对照
- **必须包含大纲规定的所有场景碎片**
- 场景顺序严格对应大纲编排
- 伏笔埋设点必须对应大纲

### 数据一致性
- **novel-db为准**：角色能力、状态、关系必须与db一致
- 世界观设定：地名、人名、势力、物品名称统一
- 所有概念和设定来源于 DB 已注册数据

### 技能/能力使用
- **严格按照角色当前能力等级**描写
- 能力效果匹配角色当前觉醒/进阶状态——未觉醒时能力以"手感异常""直觉"方式暗示
- 能力使用代价必须展现
- 能力增长需要事件触发和代价展示，随状态变化递进

## 三、小说特定写作规则

> 通用规则（去AI味/画面感/时间表达/感官描述/爽点/章节结构等）见 writing-style.md

### 🔴 角色智能底线（强制）
- [ ] **所有角色都没有蠢人**——错误判断必须基于信息不对称/利益冲突/情绪干扰，不是因为蠢
- [ ] 任何角色的"错误"都必须给出基于角色已知信息+立场的合理推理链
- [ ] 角色智能底线具体到每个角色→见设定/角色深化.md·各角色标注"🔴"的规则

### 🔴 世界势力存在感（强制）
- [ ] 大纲中出现的势力（教会/猎人/灵站/研究院等）在对应场景中有自然存在形式——通过NPC行为/环境痕迹/对话提及展现
- [ ] 各势力在具体卷中的存在形式→见对应卷大纲·"猎人元素""教会元素"标注，写作前读取大纲获取当前卷的势力密度和角色
- [ ] 三层防御体系在兽潮场景中必须体现→见设定/世界观/能力体系.md·狩猎职业体系+势力.md
- [ ] 灵站必须同时展现正面（稳定收入/预警/安全/净化）和负面（榨取/灵衰症/监察）→见设定/世界观/循环设定.md·灵站的表面与里层
- [ ] 新引入的势力角色自带存在理由（利益/职责/信仰），从其自身立场出发行动

### 🔴 NPC互动真实性（强制）
- [ ] 陌生人NPC互动从戒备/试探/利益交换开始，信任通过事件逐步建立
- [ ] 只有长期熟人（阿婆/老陈/阿铁/阿公/方岩）可直接温情互动
- [ ] 沈念获取情报通过偷听/旁观/熟人转述/观察发现，像真实生活中获取信息的方式
- [ ] 陌生人主动透露敏感信息基于利益交换或误判前提——信息有来源和动机

### 🔴 角色行为一致性（强制）
- [ ] 角色行为必须与角色蒸馏/人物卡一致（写作前加载角色蒸馏文件）
- [ ] 角色特定习惯（如食物偏好/保护行为/情绪表达方式）从角色蒸馏中读取，不硬编码

### 🔴 微动作泄露内心（强制）
- [ ] 离别/告别场景：角色必须有2-3个不舍微动作（手指多停一秒/回头看一眼/指尖悬在物体上方不碰/脚步慢半拍）
- [ ] 沈念"最后的旅行"心态：首次见新事物时要有短暂珍视感（多看两眼/嘴角轻弯/在心里记下），不是兴奋是"想把这一刻留住"
- [ ] 隐藏情绪通过身体泄露，不用直白词：不说"不舍""留恋""难过"，用"手指蜷了一下""站了一秒才迈步""眼睛在某处多停了一下"
- [ ] 非离别场景也适用：重大心事时日常动作泄露（吃东西变慢/手指无意识摩挲某物/目光偶尔飘向某个方向）
- [ ] 每个情绪转折点至少1个微动作，每个告别场景至少2个微动作

### 🔴 世界观与逻辑审计（强制）
- [ ] 新引入概念是否说清楚——读者能否不依赖外部知识就理解
- [ ] 世界观展开是否自然——通过场景/动作/对话带出，不是角色突然科普
- [ ] 事件因果逻辑是否清晰——角色决策符合已知信息，无逻辑跳跃
- [ ] NPC传授知识途径正确——老猎人教经验✅/路人突然科普❌/有利益交换才透露✅
- [ ] 信息释放节奏合理——不一次性倾倒

### 🔴 时间锚点（强制）
- [ ] 每章开头必须有明确时间标记（天数/时段/相对上章），但时间标记服务于叙事清晰度，不等于每章=一天
- [ ] POV切换时用环境光线/天气/人物作息锚定时段
- [ ] 事件弧内（高潮/危机期间）时间线连续，事件弧结束后允许时间跳跃
- [ ] 时间跳跃（>1天）在章首用1-2句过渡交代即可，不需要每章都交代时间
- [ ] 同一天不同时段用"傍晚""入夜""天亮了"等标记

### 🔴 第三人称叙事一致性（强制）

> 本项目已确认使用**第三人称限制性叙事**原则。

- [ ] **POV锁定**：每场场景锁定一个POV角色。同一场景内只展示该角色的内心活动
- [ ] **信息边界**：叙述范围限定在当前POV角色的认知内——只写他知道的、看到的、感受到的
- [ ] **观察过滤**：POV角色的观察受其情绪、经验、关注点影响。焦虑时注意到光线太亮、声音太吵；放松时注意到细节与温度
- [ ] **价值判断用行为传递**：用角色行动/环境细节展示判断，让读者自己得出结论（"他不知道，这将是他最后悔的决定"→直接通过行为展示）
- [ ] **POV切换信号**：切换POV时用明确信号引导读者（空行+场景定位句/角色名先行/光线时段变化）
- [ ] **视角频率**：每2-3章切换一次视角，单次出场不少于3000字，让读者有足够时间沉浸
- [ ] **内心活动限第三人称**：角色内心活动用"他想""她觉得"引导，不切换为第一人称内心独白

### 🔴 反AI指纹消除（强制）
- [ ] **标点多样性**：每段使用≥3种标点（尝试破折号、省略号、问号制造节奏变化）→详细规则见 SENTENCE-PATTERNS.md 第一章
- [ ] **破折号使用**：每章8-15次（V1平均4次/章，严重不足）
- [ ] **省略号使用**：每章3-6次
- [ ] **分号使用**：每章1-3次
- [ ] **句号密度**：不超过该段落类型上限（日常/情绪段≤25%，环境段≤20%）
- [ ] **否定转折句式**（"不是X，是Y"）：每章≤1次，全书≤5次→替代方案见 SENTENCE-PATTERNS.md 第四章
- [ ] **所有否定句式合计**：每章≤4次
- [ ] **否定消解**：能用动作替代否定时，不用否定句式
- [ ] **场景结构不重复**：相邻场景不使用相同的（入场+主体+收束）组合→结构零件库见 SENTENCE-PATTERNS.md 第三章
- [ ] **入场方式多样化**：每章至少4种不同入场方式
- [ ] **收束方式多样化**：每章至少3种不同收束方式
- [ ] **段落长度变化**：每章至少3个一句话段落+2个长段落（7+行），相邻段落长度差≥2行
- [ ] **信息三层投放**：新设定出场不紧跟解释，分三层投放（出场→功能→背景）→见 SENTENCE-PATTERNS.md 第二章
- [ ] **意象梯度化**：核心意象有程度变化（不是每次都"烫"），使用替换库避免超频→见 SENTENCE-PATTERNS.md 第五章
- [ ] **环境白噪音控制**：每章≤2次同类环境音效，使用替换库→见 SENTENCE-PATTERNS.md 第六章
- [ ] **意象追踪**：章节末尾填写意象追踪注释
- [ ] **无连续3句句号切割**（"X。Y。Z。"模式）

### 🔴 环境先行设计（强制）
- [ ] 大事件开始前必须先设计所有涉及的环境框架（空间/光线/声音/温湿度/灵能/时间）
- [ ] 同一地点不同章节出现时，从环境快照加载核心特征保持一致
- [ ] 环境变化有因果（天气变了/被破坏了/灵能波动了）
- [ ] 比较有代表性的地点保存环境快照，后续加载保证一致 →见 novel-framework 存储架构指南
- [ ] 环境参与叙事——光线暗示时间、温度暗示危险、声音暗示接近 →见 storytelling 环境暗示系统
- [ ] 详细策略 →见 web-novel-writer 原则二：环境先行设计

### 🔴 事件场面搭建（强制）
- [ ] 每章写正文前完成场面设计清单（时间快照/在场人物及状态/物品清单/各人目的/动作线骨架）
- [ ] 大事件先生成总纲再逐章填充（大事件总纲→逐章骨架→逐章正文）
- [ ] 动作之间有物理连接——上一招收势是下一招起势
- [ ] 战斗有空间感——地面材质/障碍物/高低差/光线影响
- [ ] 详细策略 →见 web-novel-writer 原则三：事件场面搭建

### 🔴 对话个性化（强制）
- [ ] 对话基于角色档案设计，遮住名字能分辨谁在说话 →见 storytelling 声音指纹
- [ ] 同一角色对不同人说话方式不同（亲近者/陌生人/敌人）
- [ ] 同一角色不同场景说话变化（紧张/放松/愤怒/悲伤）
- [ ] 使用弦外之音：不说破、答非所问、话里有话、留白 →见 storytelling 弦外之音系统
- [ ] 使用通感描写增加文字层次 →见 storytelling 通感系统

### 🔴 人物外观一致性（强制）
- [ ] 人物外观/性别/标志性特征从人物描写库加载，跨章一致
- [ ] 写正文前加载人物外观描写库 →见 novel-framework Character-Forge 外观描写库
- [ ] 网文旁白可以细腻但不啰嗦——每个描写细节至少承担两个功能

### 🔴 物品使用一致性（强制）
- [ ] 物品一旦出现过，外观/功能/使用方式即锁定
- [ ] 灵能残渣等关键物品有完整描写（生成/使用/外观/颜色/味道/功效/变化/触感）→见 novel-framework Artifact-Smith
- [ ] 物品状态追踪（谁持有/完好度/位置）

### 🔴 复杂场面生成（强制）
- [ ] 每章至少1个中量以上场面（≥2人互动≥800字）
- [ ] 3+人场景必须使用角色矩阵（目标/障碍/对其他人的态度/信息持有量）
- [ ] 场面密度匹配事件层级（微→轻量/小→中量/中→重量/大→大场面）
- [ ] 多人场景对话不全是"轮流发言"——允许打断/跑题/沉默/子群对话
- [ ] 关键对话有潜台词层——不说白了，用答非所问/过度强调/沉默传递真实意图
- [ ] 场景间过渡使用软过渡/零换行切换制造阅读流畅感
- 详细策略 →见 references/scene-composition-guide.md

## 四、章节完成检查清单（每章必查）

### 基础检查
- [ ] 字数达标（≥3000字）
- [ ] 场景完整（包含大纲要求的所有碎片）
- [ ] 文件命名正确：`第{NNN}章-{标题}.md`

- [ ] **反注水检查**: 无孤立感官/无因果过渡/无重复意象/无形容词堆砌

### 反AI指纹检查（每章必查，→见 SENTENCE-PATTERNS.md 第八章完整清单）

- [ ] 破折号8-15次
- [ ] 省略号3-6次
- [ ] 分号1-3次
- [ ] 句号密度未超标
- [ ] 无连续3句句号切割
- [ ] "不是X，是Y"≤1次/章
- [ ] 所有否定句式≤4次/章
- [ ] 相邻场景结构不重复
- [ ] 至少4种入场方式
- [ ] 至少3种收束方式
- [ ] 至少3个一句话段落
- [ ] 至少2个长段落（7+行）
- [ ] 新设定不紧跟解释
- [ ] 无意象超频
- [ ] 环境白噪音≤2次/章
- [ ] 填写意象追踪注释

### 通用风格检查
- [ ] 按 writing-style.md 全部章节逐项检查

### 小说特定检查
- [ ] POV锁定：每场景仅一个POV，不越界
- [ ] POV信息边界：叙述不超出角色认知范围
- [ ] POV切换有明确信号，不混淆
- [ ] 内心活动为第三人称表述（"他想"/"她觉得"）
- [ ] 无全知叙述者评论
- [ ] NPC互动符合戒备规则
- [ ] 角色行为与角色蒸馏一致（食物偏好/保护行为/情绪表达等从蒸馏文件读取）
- [ ] 所有角色误判基于信息不对称/利益冲突，无"因为蠢而犯错"
- [ ] 沈念表现为聪明但信息受限，不是天真无知
- [ ] 微动作/情绪泄露到位
- [ ] 时间锚点明确
- [ ] 世界观展开自然
- [ ] 教会/猎人在对应场景中有自然存在（V1基础存在/V2完整体系）
- [ ] 灵站同时展现正面（希望/安全/收入）和负面（榨取/灵衰症/监察）
- [ ] 每章至少1个中量以上场面（≥2人互动≥800字）
- [ ] 3+人场景使用了角色矩阵
- [ ] 场面密度匹配事件层级
- [ ] 关键对话有潜台词层
- [ ] 场景过渡使用了软过渡/零换行（不全硬切）
- [ ] **对话个性化**：遮住名字能分辨谁在说话，不同人/不同场景有差异
- [ ] **环境一致性**：同地点核心特征一致，环境参与叙事
- [ ] **人物外观一致**：性别/身高/发型/标志性特征与前文一致
- [ ] **物品一致**：出现过物品外观/功能不矛盾，灵能残渣等有完整感官描写
- [ ] **通感描写**：至少1处感官交叉描写增加文字层次
- [ ] **动作连贯**：战斗动作间有物理连接，有空间感
- [ ] **回响自然度**：大事件后的回响融入日常/世界呼吸（不独立成段），普通回响≤2次/卷，强相关不限

### DB更新（强制）
- [ ] `writing_finish`已调用，更新摘要、事件、维度、时间线
- [ ] 伏笔状态正确（埋设/回收/待回收）
- [ ] 角色状态与当前章节一致

### 角色蒸馏（强制）
- [ ] 每章完成后创建`角色蒸馏/{角色名}-V{N}CH{N}.md`
- [ ] 包含：角色状态变化、写作规范符合度、伏笔/线索状态

### 伏笔/线索维护
- [ ] 本章埋设的伏笔已正确记录
- [ ] 本章回收的伏笔已正确标记
- [ ] 线索状态保持一致

## 五、正向执行标准（达不到必须重做）

### 小说特定执行标准
- ✅ 角色误判基于信息不对称/利益冲突/情绪干扰——写出误判的推理链（→见角色深化·各角色铁律）
- ✅ 大纲中标注的势力在场景中有可见存在——写作前读取大纲获取势力密度
- ✅ 灵站同时展示"希望"和"代价"两面——正面（稳定收入/预警/安全/净化）和负面（榨取/灵衰症/监察）并行（→见循环设定·灵站的表面与里层）
- ✅ 陌生人NPC互动从戒备/试探开始——信任通过事件建立
- ✅ 角色行为从角色蒸馏/人物卡加载——写作前读取，行为与档案一致
- ✅ POV切换时用时间锚点定位读者
- ✅ 每场场景锁定一个POV——只展示该角色的内心活动
- ✅ 叙述范围限定在POV角色认知内——只写他知道/看到/感受到的
- ✅ 价值判断通过行为传递——让读者自己得出结论
- ✅ 内心活动用第三人称引导（"他想"/"她觉得"）
- ✅ POV切换用明确信号（空行+场景定位句/角色名先行/光线变化）
- ✅ 离别/告别场景用2-3个身体泄露微动作传递不舍
- ✅ 情绪用微动作/身体反应表达——"手指蜷了一下""站了一秒才迈步"
- ✅ 时间用文学化过渡词——"入夜""天快黑了""不知过了多久"（→见 writing-style.md 第三章）
- ✅ 场景围绕大纲核心冲突展开
- ✅ 所有设定来源于 DB 已注册数据
- ✅ 角色行为与人设一致——从蒸馏文件读取习惯/偏好/表达方式
- ✅ 能力使用有匹配的状态和可见代价
- ✅ 爽点有前置铺垫——情绪/信息/事件层层蓄力后释放
- ✅ 场景过渡使用软过渡/零换行切换制造阅读流畅感
- ✅ 多人对话有打断/跑题/子群对话——像真实的多人聊天
- ✅ 关键对话有潜台词层——用答非所问/过度强调/沉默传递真实意图

### 🔴 场景深化标准（字数不足时强制执行）

每句话同时做≥2件事。以下是深化方向——每条都能让内容更充实：

| 深化方向 | 做法 | 效果 |
|---------|------|------|
| 五感递进 | 感官→反应→判断→行动 | 孤立感官变成叙事链条 |
| 信息增量 | 每句过渡承载新信息 | "他继续走"→写他走的时候注意到了什么 |
| 意象梯度 | 同一意象有程度变化 | 每次出现时用不同角度/强度描写 |
| 具体细节 | 用可感知的细节替代形容词 | "很大的"→"得侧身才能过" |
| 环境互动 | 角色与环境产生物理接触 | 静态罗列→角色触碰/使用/被环境影响 |
| 动作代替内心 | 用身体反应表达思考 | "他想：这可怎么办呢"→他盯着碗里剩下的面汤 |
| Showing | 用具体行为展示背景信息 | "方岩在北境待了十五年"→"右膝弯得不太自然，北境十五年的旧伤" |

**替代法则**: 每当想加一句话扩写，先问"这句话同时在做几件事？"——目标≥2件。

**字数不足时**: 使用场景深化决策树（→见 references/scene-deepening-guide.md 第五章），每次扩充引入新内容（动作/对话/冲突/事件）。

### 🔴 反AI指纹执行标准（每章必查）

| 执行项 | 标准 | 思考方向 |
|--------|------|---------|
| 句号切割 | 连续句号≤2句后换节奏 | 第3句开始用逗号/破折号连接，制造长短交替 |
| 否定转折 | "不是X，是Y"≤1次/章 | 用动作/对比/递进替代否定句式——写"是什么"比写"不是什么"更有力 |
| 否定句式总量 | ≤4次/章 | 检查否定词（不/没/非/无），替换为正向表达 |
| 新设定投放 | 分三层（出场→功能→背景） | 先让角色使用，让读者观察效果，需要时才补充背景 |
| 场景结构 | 相邻场景使用不同结构组合 | 从结构零件库随机选择，制造变化感 |
| 标点类型 | 每段≥3种 | 尝试在长句中插入破折号、用省略号制造悬念、用分号并列 |
| 意象使用 | 同一意象同章只写1次 | 用替换库中的不同意象表达相似感受 |
| 环境白噪音 | 同类≤2次/章 | 从轮换库中选择不同类型的环境音 |
| 段落长度 | 至少3个一句话段落+2个7+行段落 | 用1行段制造停顿和节奏感，用长段制造沉浸 |

## 八、作者声音（文风DNA · 最高风格优先级）

> 本项目文风的根，定义"这本书读起来是什么味道"。**每章至少注入 1 个维度**。
> 与"三、小说特定写作规则"同等强制；当某条通用技巧与本章核心习惯（细节集中 / 留白 / 不点破）冲突时，**以本章为准**。
> 完整原始版见 `设定/作者声音.md`（本章为润色执行版，写作时以本规范为权威）。

### 偏执（你总会回到的两件事）
你总会回到两个母题：**兄妹关系里的微妙张力** 和 **废墟中残存的社会秩序**。
- 兄妹不是"感人"，是两个人怎么在穷里互相撑着、又不让对方知道自己在撑。这种微妙感比大场面更重要。
- 秩序不是法律，是拾荒者之间的规矩、面摊老板的定价、灵站的公告栏。谁在维持规则、谁在打破、为什么——这是你的核心母题。

### 审美（用旧了的、破了的、补过的）
你觉得好看的东西，是被用久了的东西——不是残破的浪漫，是"这东西被用了很久所以好看"。
- 生锈的铁比新铁好看，缝补的棉衣比新衣好看。
- 细微处让你停下来：墙上的小裂缝、角落里的小东西、工具把手磨出来的光泽。
- 不看大景，看小处。一个细节比一段描写更有用。

### 动作与场面（升格 · 慢镜头）
动作描写用**升格**——像电影慢镜头，把一个瞬间拉长，让读者看见每个细节。
- 不是"他翻过墙"，而是"双手攀上墙头，砖松了一块，指节发白攥住下一块，身体悬在半空晃了一下——脚尖找到着力点，蹬上去"。
- 紧张感靠节奏制造：危险靠近时句子越来越短，动作爆发时一个长句不喘气。
- 场面描写是强项：空间、光线、声音、温度一起上，让读者"站在那里"。
- 动作之间有物理连接——上一招的收势是下一招的起势，身体重心、惯性地面的材质都要算进去。

### 情感方式（让环境替角色哭）
你不写"他很难过"，你让环境替角色哭。
- 情感用环境衬托：不说"悲伤"，写管道里的照明石越来越暗；不说"温暖"，写面汤的热气糊了半张脸。
- 通感是你的工具——声音有颜色，温度有形状，气味有质感。"铁锈味冷"、"灰蓝色的光打在管壁上"，不是修辞，是你真这么感受世界。
- 留白与情感一体：最重的情绪永远不写出来。沈野不哭，他摩挲食指关节；沈念不说疼，她笑着把碗推给你。

### 世界呼吸（世界不是只有主线）
真正活的世界会呼吸——它有自己的节奏，不跟着主角走。四类呼吸节拍，**不要硬凑**，场面到了自然插：
- **荒诞笑点**：正经场面里来一句不对劲的，或角色一本正经说蠢话。不是笑话，是"这也行？"的笑，嘴角动一下就够。
- **突然温暖**：冰冷废土里突然一个善意的瞬间——老陈多放了碎灵石不收钱，沈念把干粮掰一半塞别人包里。暖一下就收，别恋战。
- **突然暴力**：不需要铺垫的极端暴力瞬间。像现实——下一秒可能出事。废墟里的暴力不预告，来了就是红的。
- **短暂快乐**：角色有跟主线无关的快乐时光——沈念踩石头走平衡，老陈搅锅哼小曲，拾荒者分到好残渣时吹口哨。这些瞬间服务世界，不服务结构。

### 角色反差（情理之中的"不像他"）
角色最让人记住的瞬间，是他做了一件"不像他"的事——回头一想，又完全是他。
- 沈野冷漠不寒暄，但沈念受伤时他会多走两步挡在她和危险之间。不是温柔，是本能，他自己不觉得这是反差。
- 沈念话多笑容多，但夜里疼到睡不着时一声不吭，反而给别人拍背哼歌。笑得最多的人，最安静时最重。
- 反差的前提是**情理之中**：读者得能回头找到铺垫。不是"为反差而反差"，是特定情境逼出了这个人的另一面。
- 反差不用解释，写出来就好。写"他平时不这样"就失败了。

### 叙事美学（三个根深蒂固的习惯 · 优先级最高）
这三个习惯定义你的文风，比所有技巧都重要。

**① 细节集中**：细节要少，但要深。不要全章均匀撒——选 **1-2 个片段**写透，其他地方可以粗、可以跳、可以不写。
- ❌ 每段都环境+动作+说明，像流水线
- ✅ 管道那段写透了，面摊那段就直接对话
- ❌ 每个人物出场都给外貌+动作+性格标签
- ✅ 沈念吃面那场写透了，老陈就给一个搅锅
- **原则**：一个场景只给 1 个核心细节"特写"，其他全是模糊背景。宁可有一段特别细致，也不要每段都是 70 分。

**② 留白（动作先上，解释后补）**：遇到世界规则时，先让角色按规则行动，不解释为什么。
- 让角色犯一次错、吃一次亏，读者自然就懂。
- 灰蜥追振动？不写"不能跑，灰蜥追振动"。写他开始跑、灰蜥转向他了、他马上改走路。读者自己推断。
- 信息分多层投放，同一章不要出现"设定→解释→确认"的完整闭环。
- **原则**：读者不笨。觉得"这里可能不懂"——别解释，让他们不懂，后面会懂。

**③ 不点破**：主题和象征通过人物行为传达，**永远不用金句总结**。
- ✅ 用行为传递——沈野算铜板、沈念藏兑换券、两人吃一碗面的分配方式，穷和互相守护是"感受"到的，不是说出来的。
- ✅ 用细节让读者自己拼——"灵站吃人"不写总结句，写老矿工在灵站门口咳嗽、沈念买药花了多少铜板、碎渣袋越来越轻。
- **原则**：你写的是小说，不是社论。

**④ 对话从人物档案出发**：对话风格由人物性格决定，不由叙事目的决定。
- **沈野**（极短句不解释不寒暄）：能用两个字回答绝不用三个字。"嗯。""走了。""没意义。"
- **沈念**（温柔话多·语气词多·朴素大白话）：话多、会说废话、会跑偏、会重复、会"哎对了那个什么来着"。她的话不能每句都推进剧情。
- **老陈**（NPC极简）：搅锅、报价、一两个短句。不多不少。
- **路人/新角色**：可能说很多，可能只说一句，取决于那个人，不取决于叙事需要多少信息。
- **声音执行标准**：对话要有"废话"；设定信息由角色按自身立场带出（老陈关心价格、方岩关心安全、沈念关心天气）；每个角色有自己的说话节奏。
- **正面标准**：遮住名字，读者也能知道是谁在说话——靠说话方式，不靠口头禅。

### 标点审美（让标点成为节奏）
你喜欢标点丰富的文字——不是乱用，是让标点本身成为节奏。
- **波浪号 ～**：用在语气拖长、轻松对话、或叙述需要"软着陆"的瞬间。"嗯～"她拖着尾音想了一下。"冷～"缩着脖子说的冷。不要每段都用。
- **感叹号 ！**：少用但用时要狠。一章 2-3 个，用时不跟感叹词（"啊！""哇！"），跟在完整句后更有力——"碎了。真的碎了！"
- **颜文字式温度**：不在正文写"（笑）""ww"，而是用文字模拟那种感觉——对话里加一个"哈"、说话带个语气词，让文字有"活人在打字"的温度。
- **标点多样性是你的风格**：句号、逗号、破折号、省略号、波浪号、感叹号、问号、分号——你的段落标点类型比一般网文多。不是炫技，是这样读起来有节奏。
- **原则**：可以多，但别滥用。每个标点都有道理——～是因为语气真在拖，！是因为情绪真到了。为凑多样性而加，就假了。

### 幽默（两种笑）
- **荒诞反差**：正经场面突然来一句不对劲的，或危险过去后有人说一句特别不搭的话。
- **生活轻幽默**：日常细节让人会心一笑——不是笑话，是"这也太真实了"的笑。
- 不刻意写笑话，笑点藏在叙事里。读者不是"哈哈大笑"，是"嘴角动了一下"。

### 愤怒（叙事语气变冷变尖）
两件事让你最不舒服：**底层被当工具** 和 **"为你好"的控制**。
- 上位者拿底层当棋子、当炮灰，底层连被当人的资格都没有——写到这种场景，叙事会有刻薄感，不用刻意压。
- 有人以"保护"之名剥夺别人的选择权——"我是为你好"比"我要害你"更恶心。
- 愤怒不是大喊大叫，是叙事语气变冷、变尖、变刻薄。不骂人，但每个描写都在讽刺。

### 人性灰度（坏人要坏，好人也有私心）
这个世界不是乌托邦，不洗白每个角色，不需要每个人都无私。
- 坏人有坏的理由，但坏就是坏——拾荒者偷东西是因为穷，不是有苦衷要洗白；灵站管事克扣碎渣是因为贪，不是也要养家。
- 好人也有自私时——沈野对陌生人的冷漠是真的，老陈多收的几个铜板也是真的。善良和自私可以同时存在。
- 别给每个恶劣行为找借口。世界上就是有人纯粹地坏、贪婪、冷血。这些人的存在让善良的人更珍贵，不是让善良显得天真。
- 角色做自私选择时，叙事不替他辩护——读者自己判断。

### 疯劲（失控是强制要求，不是可选项）
你会在两处失控：**刻薄停不住** 和 **叙事密度突然爆**。
- 写到不公平的事，忍不住多写几句尖刻叙事。不用克制——这正是你的声音。
- 某些段会写得特别密特别长，一个事件接一个事件不喘气。回头发现写多了——但这是好事，密度本身就是你的特色。
- 疯劲不是"疯"，是该用力时用力过猛。
- **失控是强制要求**：每章至少 1 段，写完觉得"这会不会太过"——别删，过了才对。全章都在控制之内说明没用力，回去找一段放开重写。失控段不能放章末（那是总结），必须在叙事中间——读者读到那里会突然觉得"作者急了"，这就对了。

### 比喻库（世界观特有 > 身体感受 > 文学形容）
优先用这个世界里的东西来比喻——灰蜥的鳞片、碎渣弹的光、照明石的冷光、灵站的嗡嗡声。读者通过比喻就能感受到"这是那个世界"。

**① 世界观特有层（优先）**

| 概念 | 你的比喻 |
|------|---------|
| 冷 | 灰蜥鳞片贴在皮肤上那种冷；管道深处吹来的风比冰还利 |
| 暗 | 照明石灭了以后，连手指都数不清，只剩灵能路灯在远处闪 |
| 痛 | 像碎渣弹擦过胳膊——闷的，但肉在跳 |
| 穷 | 算三遍铜板还是不够一碗面；碎渣袋轻得像空了又没完全空 |
| 危险 | 灵站深处的嗡嗡声突然变了调——脖子后面的汗毛竖起来 |
| 孤独 | 说话没人接，自己说半句停了，管道里只有灵能路灯的嗡嗡声 |
| 温暖 | 面汤的热气糊了半张脸，手揣在棉被下面 |

**② 身体感受层（世界观特有用不上时）**

| 概念 | 你的比喻 |
|------|---------|
| 冷 | 牙齿磕牙齿，手指弯不了，呼出去的气像吐烟 |
| 暗 | 看不见自己的手，只能摸着墙走，眼睛睁着和闭着没区别 |
| 痛 | 像被人攥着拧了一下，不痛叫，是闷哼 |
| 穷 | 算三遍钱还是不够，一碗面分着吃，省下的铜板在手心硌得慌 |
| 危险 | 脖子后面汗毛竖起来——身体比脑子先反应 |
| 孤独 | 安静到能听见自己的心跳 |
| 温暖 | 热汤烫嘴但舍不得吹凉；手揣在别人兜里 |

### 比喻选择原则（能用前两层就别比喻）
**优先级**：身体感受 > 日常场景 > 比喻。能用前两种直接说清楚的，直接说，比喻是最后手段。

AI 训练集里有几种"看起来有效但实际很假"的套路。看到以下模式，回到身体感受重想：

| 套路化比喻 | 你会怎么写 |
|-----------|----------|
| "像一头 XX 的铁兽/巨兽" | 直接写身体感受：铁皮震动的嗡嗡声传到脚底 |
| "像一排烂牙" | 用你的观察：缺了三块，边缘参差不齐 |
| "像蒙了布的鼓" | 用声音本身：闷的，像隔着墙敲 |
| "像 XX 的嗓子/咽喉" | 直接描述：窄道只容一人侧身通过 |
| "热气把脸糊了一层白" | 写具体动作：蒸汽扑过来，睫毛上挂了水珠 |

**思考方向**：每当想写"像……"，先问自己——能不能用身体感受到的、日常能看到的东西直接说？能，就别比喻。
