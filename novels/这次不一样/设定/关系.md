## 一、总原则

- **三层架构**：外层迪化喜剧（最多）/ 中层世界丰富（六界）/ 内层治愈主线（少）。**治愈只占核心圈少数角色**，大部分角色服务迪化喜剧和世界丰富，不全为主题服务。
- **角色围绕男主但有自己生命**：男主是网文代入中心，但角色有自己的伤口/欲望/支线，不是主题工具。
- **多功能类型**：主题承载型 / 迪化喜剧型 / 世界肌理型 / 反派型。
- **螺旋剧情·自然非工整**：关系动态有松有紧，线索多功能，信息爆发分散（不全堆结局）。

## 六、迪化机制（后置 + 伏笔分层 + 邵半仙）

1. **后置性**：误读滚雪球越滚越大（护人→奴印→操控强者→妖族帝国…），真相后置闪现/揭晓，**不轻易给**。爽感来自差距累积。
2. **伏笔分层**（不要全一种深度）：
   - **深伏笔**：贯穿全书（穿越即双救 / 周临身份 / 天道化身 / 鉴映失控）
   - **浅伏笔**：1-3 卷回收（每卷的小谜）
   - **假伏笔（红鲱鱼）**：误导读者猜错，后期揭示是假
3. **邵半仙**（乌鸦嘴说书人·迪化喜剧型·不碰主题）：游方说书，离谱预测都因男主迪化因果成真；迪化传播者；伏笔分层载体（深/浅/假都有）；贯穿各卷世界串场。
