## 核心内核 ⭐

**一句话**：一个前世被善伤透、走投无路轻生的人，转生妖族幼体，被身边人的善意治愈，长成了建和邦、打破六界大战循环的妖圣。

- **前世**：付出善意被四类人辜负（程哲/小沈/苏绾+碰瓷者，挚友周临缺席），雨夜桥上跳下"我尽力了"
- **转生后**：摆烂等死（"又活过来了，真烦"）
- **遇到锤伯**：被锤伯的"匠人对材料的纯粹认可"治愈（绕过"人对人"的警惕）
- **真觉醒**：从"想死 / 摆烂 / 提防"→"想为锤伯、为身边不背叛他的人拼命"
- **给世界**：建五族共和（人/妖/鬼/魔/仙）的善意之国（和邦），打破六界大战循环

## 设计原点（"这次不一样"在哪）

- **形态反差**：Q 版萌幼妖（前世三十岁糙汉）↔ 碾压级战斗神通（护短暴走+法则级反弹）
- **能力全战斗向 · 反差在用途**：男主强大战斗神通（灵犀/铭锋/同源/逆鳞/万象归元）只用于护人/建国/种田——**强↔善的反差在用途，不在能力本质**（治愈交给剧情，能力无治愈属性）
- **进化触发机制全仙侠原生**：修炼 / 师徒传承（锤伯 V1 末传匠心本源） / 血脉觉醒 / 悟道 / 渡大天劫
- **迪化**：妖族因善进化+护短 = 世界未见，每次进化被误读为"新妖王搞事""妖神降临要发动战争"

## 核心特质
- 务实、冷漠、提防（前世伤口：付出善意会被辜负）
- 摆烂表象 vs 内心挣扎（被治愈的过程拉锯）
- 前世记忆碎片化（生死/情感关头浮出，犹抱琵琶式揭）
- 治愈后：柔软、愿意相信、愿意为身边人拼命

## 弱点 / 缺陷（写实化）
- 前世记忆不全（避免开挂）
- 转生妖族幼体（凡身最弱 · 肉体孱弱）
- 灵气消耗 = 生命力消耗（仙侠原生规则）
- 灵犀人格化失控风险（内在反派伏笔 F10）
- 共情过载（同源网络联结深了能感受他人痛苦）
- **核心软肋**：身边人（锤伯、群像伙伴）——他治愈后愿意为他们拼命，可被利用

## 核心动机（治愈内核 + 战斗向能力版）
1. **想死 → 想活**：从摆烂等死 → 被治愈 → 想为锤伯/身边人活下去
2. **建国（和邦）**：被治愈 → 给世界一个善意的国（治愈的果实）
3. **打破六界大战循环**：用联结（非杀伐）打破战争循环（"这次不一样"点题）
4. **回原世界新生**：使命完成 → 带治愈回去，学会活下去（治愈闭环）

## 成长弧线（与大纲 V1-V8 + 第三幕 + 终幕咬合）
- **V1**：摆烂的幼妖 + 前世碎片 + 遇锤伯（治愈种子）+ V1 末师徒传承（进化+铭锋觉醒）+ 迪化起家
- **V2**：种田建国雏形 + V2 末锤伯护阵牺牲（治愈撕裂·灵犀人格化第一次具现）
- **V3-V5**：迪化滚雪球 → 虚名最高点 + 种田建国 + 治愈拉锯 + 挚友线暗涌
- **V6-V8**：镜像考验（江烬+周临）→ V8 摔跟头 + 群像没散
- **第三幕**：六界大战前奏 + 治愈核弹 → 真觉醒 → 渡大天劫 → 妖神
- **终幕**：建和邦 + 打破六界大战循环 + 周临相认 + 回原世界新生 → 妖圣

## 男主"不一样"的关键
- 历代试图救世的强者（如上代人族剑修江烬）都困在战争/杀伐的旧路 → 都失败
- 男主转生成**妖族**（小妖）→ 站在另一边 → 跳出二元对立 → 打破循环的关键
- **这次不一样**的核心：旧路用战争应对循环失败，男主用善意 / 联结打破
