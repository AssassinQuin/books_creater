# 试写样本 · 脊堡敢死营的早晨

> P1-3 检验样本——主角不存在时，敢死营普通一天的开始。
> 目的：检验 P0-1（参照分工）/ P0-2（六准则现象化）/ P0-3（高阶异变代价）是否在世界感层面成立。

---

号角响在天还没亮透的时候。比正规军的晚半刻。这是规矩——敢死营的号总是慢半拍，没人改过。也没人闹。闹的人去年被扒了军装扔回死牢，第三天就喊不出声了。

灰指睁眼。营房顶上的以太灯还亮着，蓝白色。皮肤上那层"温水流过"的感觉淡了——黎明前浓度最低，老猎人都能感觉到，皮肤不刺了，骨头缝也不痒了。这意味着今天裂谷三层以上是安全的。三层以下不知道。

"灰指"是外号。火亲和控温派，指甲干净，手指却粗得不像控温的。他把铜壶搁到火盆上，火盆里的炭自己亮了一下——火亲和靠近火时的本能反应，他自己没察觉，但半耳看见了。

半耳是去年补进来的。征召逃兵，半只耳朵冻掉。风亲和，夏天也口渴，腰里挂着水囊。他蹲在火盆边，手伸出来，灰指没看他，把铜壶往他那边推了半个手位。半耳的手腕是凉的。

"灰指，"半耳说，"今天将军查营吗？"

"不知道。"

"要是查营——"

"不知道。"

哑巴靠墙坐着。土亲和。三年没说过话。皮肤像树皮，关节处裂口子。他不靠近火盆——土亲和不需要热，他需要地。

外面号角又响了一声。这次是换班。空气里的"温水感"开始回来，皮肤起鸡皮疙瘩。浓度在升。三层以下要不安生了。

灰指把硬面包掰开，泡进热麦酒。半耳盯着面包发软。"今天三层以下，"灰指说，"魔潮可能要来了。"

半耳没接话。

门口的兵一起让开了。

没人喊立正，没人喊将军。让开是身体的反应——腿先动，脑子后知道。铸域级走过的时候，空气会变形，看一会儿眼睛发酸。这是铸域的规矩。

是脊堡七将之一。土亲和。披着灰斗篷，没戴手套。灰指瞥了一眼他的手——指节上隐约的纹路，像树根，从袖口一直爬到手背。

"灰指，"半耳低声问，"将军今天怎么没戴手套？"

灰指收回目光。

"他不用手套了。"

号角再响。敢死营的早操开始。

## 自检（用乌贼三问 + 现象化校验）

### 1. 世界感：这个世界不依赖主角也存在吗？
✅ 通过——4 个 NPC（灰指/半耳/哑巴/将军）各有来历、各有逻辑、各有体温，没有一个是为剧情临时拉来的。号角/换班/早操是世界的节律，主角来不来都照常。

### 2. 六准则是否用现象呈现（不写法则名）？
| 准则 | 文中现象呈现 |
|------|-------------|
| 感受法则 | "皮肤上那层'温水流过'的感觉淡了——黎明前浓度最低" |
| 浓度法则 | "空气里的'温水感'开始回来，皮肤起鸡皮疙瘩" |
| 元素法则 | 火亲和"炭自己亮了一下"；风亲和"夏天也口渴，腰里挂着水囊"；土亲和"皮肤像树皮，关节处裂口子"、"不需要热，需要地" |
| 趋异法则 | 灰指是火亲和控温派——"指甲干净，手指却粗得不像控温的" |
| 强者法则 | "腿先动，脑子后知道" / "空气会变形，看一会儿眼睛发酸" |
| 代价法则 | 没出现社会代价（场景不需要），但将军的"高阶异变"代替了 |

### 3. 高阶异变代价是否落地？
✅ 通过——"他不用手套了"一句承载铸域级异变：
- 身体染色：土亲和将军"指节上隐约的纹路，像树根，从袖口一直爬到手背"
- 人际隔离：兵们"让开是身体的反应"，没人靠近，没人对话
- 神格化前兆：连手套都不需要——他已经"不是普通人"了

### 4. 参照分工是否串味？
✅ 通过——
- 视觉：号角/铜壶/火盆/热麦酒/灰斗篷/手套（欧洲中世纪）
- 结构：敢死营=最底层耗材/七将军议会/征召逃兵（多极博弈下的军事机器）
- 叙事：未涉及（主角不存在）

无东方术语（灵气/修炼/经脉/灵石都没出现）；无 AI 禁用词（默默/淡淡/微微/嘴角/眼中 都没出现）。

### 5. 脊堡基调是否到位？
✅ 通过——
- 短句写军事（"灰指睁眼。" "半耳没接话。"）
- 冷硬温情（灰指把铜壶往半耳那边推半个手位——不说话的暖）
- 疲惫不写阴谋（"闹的人去年被扒了军装扔回死牢，第三天就喊不出声了"——陈述事实，不解释黑幕）

## 暴露的待办

1. **脊堡将军的具体姓名未定**——文中绕开了（"脊堡七将之一"）。后续需要给七将军起名（建议欧洲化姓氏）
2. **"哑巴"是临时外号**——后续如果这个角色要出现多次，需要给他真名（即使他不说话）
3. **裂谷"三层"的具体定义**——文中"三层以上安全"是隐含设定，需要在世界观里明确"裂谷分七层"之外的分层规则（浓度/魔物强度）
