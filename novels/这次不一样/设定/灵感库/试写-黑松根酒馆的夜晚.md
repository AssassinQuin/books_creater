# 试写样本 · 黑松根酒馆的夜晚

> 势力命名重构后的检验样本——新势力名在正文里跑一圈
> 目的：检验"白廷/脊堡联盟/三港/窖众"在对白与叙述里是否自然；俗称与正式名切换是否成立
> 场景：黑松镇"黑松根"酒馆，某个初一的夜晚

---

黑松根酒馆的灯亮起来时，外面的雪冻上了。屋檐的旧雪结成冰壳，风一吹，掉下来砸在门廊上碎成粉。

格特鲁德把吧台擦了第三遍。墙上挂着那顶旧军帽——今天已经擦过了。克劳斯在角落，背靠墙，面前一杯酒，左手背朝下扣着——那块疤不让人看见。火盆的光照不到他那个角落。他选的。

门推开，冷风灌进来。

"关门。"格特鲁德没抬头。

奥托踉跄进来——脊堡联盟驻黑松镇的征召官，军装没扣好，领口歪着。他在吧台坐下。

"两杯。"

"你今晚喝两杯，明早就醒不了。"

"两杯。"

格特鲁德倒了。第一杯推过去，第二杯放旁边。奥托看着酒面发呆。

"今天几个？"格特鲁德边擦杯子边问。

"两个。"

"哪家？"

奥托没答。他把第一杯酒喝了，呛了一下。格特鲁德把一碗汤推过去——昨天的剩汤热过，不收钱。

门又响。推门的比奥托矮半头、胖一圈，进门先抖丝绸外袍上的雪。丝绸在黑松镇是稀罕东西，这里的人都穿粗麻。

"老板娘，"洛伦佐用三港腔喊，"老规矩。"

"老规矩是什么？"

"最好的酒，倒满，我不喝完。"

格特鲁德笑了，从柜子下拿出一瓶碎月港的葡萄酒。奥托和 洛伦佐没打招呼——他们互相认识，但不在酒馆打招呼。这是规矩。洛伦佐走到吧台另一头，离奥托隔两个位置。

"老板娘，"洛伦佐压低声音，"初一的东西带了。"

格特鲁德从吧台下拿出一个小铜壶递过去——铜壶是克劳斯的，但洛伦佐不知道。洛伦佐把铜壶收进外袍，摸出一个小布包放在吧台上。布包里是钱和一张折好的纸。

格特鲁德把布包收了，纸没看——等会儿再看。

"那个少年，"格特鲁德突然说，"今天被征召的两个里，有没有姓哈特的？"

洛伦佐想了一下。"我下午听人说过。好像有一个。"

格特鲁德没再说话。她转身去灶台热汤。奥托还在喝第二杯酒，他没听见这段对话。

门第三次响。

进来的是白袍。本尼狄克走进时所有人安静了半口气，然后该喝酒的喝酒。本尼狄克习惯了这种安静。他坐到吧台最角落。

"一杯麦酒，半量。"

"教规允许？"

"每月初一允许半量。"

格特鲁德倒了半杯。本尼狄克先在胸前划了个手势——白廷的祈祷手势——然后才端起杯子。

洛伦佐看了本尼狄克一眼，没说话。三港的商人不喜欢白袍。去年白廷下了禁令，洛伦佐的两条船不能在某些港口靠岸，理由是"教义冲突"，他多花了一倍成本绕远路。

本尼狄克也没看洛伦佐。他在看角落里的克劳斯。

"那个人，"本尼狄克低声对格特鲁德说，"还在？"

"克劳斯？"

"他今天初一。"

格特鲁德停下擦杯子的手，看着本尼狄克。两人都知道对方知道什么。

"他今天不出去。"格特鲁德说，"今天他不想出门。"

本尼狄克点头，没追问。这是黑松镇的规矩——有些事知道就好，不说出来。

奥托喝完第二杯站起来，踉跄了一下。他把钱放在吧台上——比酒钱多一倍。格特鲁德没收。

"汤钱。"

"我说了不收。"

奥托把钱收回口袋。走到门口时他回头看了一眼角落——克劳斯还在那里，背靠墙，没动。奥托想说什么，最终没说。他推开门，冷风把他卷出去。

本尼狄克也站起来了。走出酒馆时经过克劳斯的角落，两人目光碰了一下——本尼狄克的眼神里有嫉妒，克劳斯的眼神里什么都没有。雪在本尼狄克身后合上。

洛伦佐最后走。他把没喝完的葡萄酒推回给格特鲁德。

"下个月见。"

"下个月见。"

酒馆空了。格特鲁德收拾吧台，把葡萄酒倒回瓶里——这酒她明天给克劳斯热一杯，克劳斯不喝麦酒，只喝热的葡萄酒。她把旧军帽从墙上取下来擦了擦，又挂回去。

克劳斯还在角落，杯子空了。

"克劳斯，"格特鲁德没回头，"今天初一，你不出去？"

"不想去。"

"为什么？"

克劳斯没答。他看着墙上的裂痕。裂痕在那里很久了——比克劳斯还久。

"今天那个被征召的少年，"克劳斯突然说，"姓哈特？"

格特鲁德转身。

"你怎么知道？"

克劳斯没答。他把空杯子推到桌边——这是让格特鲁德再倒一杯的意思。格特鲁德给他倒了热葡萄酒，多倒半指。

格特鲁德关了灯。酒馆黑下来，只剩火盆的红光。

克劳斯的左手背朝下扣着，那块疤不让人看见。但红光照到了他的袖口——袖口有一圈淡淡的灰，窖里带出来的，洗不掉。

## 自检 · 势力名在正文中的运行

### 1. 势力名植入清单

| 势力 | 正式名（叙述用） | 俗称（人物嘴里） | 出现位置 |
|------|---------------|---------------|---------|
| 脊堡联盟 | "脊堡联盟驻黑松镇的征召官" | （未用俗称——奥托是军官，叙述视角用正式名） | 奥托进场 |
| 三港 | "三港腔""三港的商人" | "碎月港的葡萄酒"（地理性俗称） | 洛伦佐进场 |
| 白廷 | "白廷的祈祷手势""白廷下了禁令" | "白袍"（镇民视角的俗称） | 本尼狄克进场 |
| 窖众 | （未直说） | "窖里带出来的"（双关：地窖/窖众） | 收尾克劳斯袖口的灰 |
| 灰书会 | 不出现 | 不出现 | 暗线暂不暴露 |
| 赛瑞斯 | 不出现 | 不出现 | 暗线暂不暴露（洛伦佐-格特鲁德铜壶交接是钩子） |

### 2. 和谐感自检

把场景里的势力名并排读：
- **脊堡联盟**驻黑松镇的征召官
- **三港**腔 / **三港**的商人
- **白袍**（镇民叫法） / **白廷**的祈祷手势 / **白廷**下了禁令
- **窖里**带出来的

读起来像**同一个世界**——四个名字风格统一，不像不同小说里的势力 ✓

### 3. 俗称与正式名切换

- **白廷**：叙述用"白廷"（白廷的祈祷手势 / 白廷下了禁令），镇民视角用"白袍"（"进来的是白袍"）——切换自然 ✓
- **脊堡联盟**：叙述用"脊堡联盟驻黑松镇的征召官"，未用俗称（因为奥托是军官，不是镇民随口提及） ✓
- **三港**：叙述用"三港腔""三港的商人"，洛伦佐自己不提势力名（他只说"碎月港"具体地名） ✓
- **窖众**：未直说，用"窖里"双关（地窖 / 窖众）——暗线钩子 ✓

### 4. AI 味检查

- 无"默默/淡淡/微微/嘴角/眼中/心头一震/深吸一口气" ✓
- 短句写日常（"两个。""关门。""两杯。"） ✓
- 用感官传递（雪冻上/冰壳碎/丝绸外袍/旧军帽/火盆红光） ✓
- 不解释情绪（"奥托想说什么，最终没说"——不解释为什么不说） ✓

### 5. 暗线钩子（读者第一次读会忘的细节）

1. **赛瑞斯暗线**：洛伦佐给 格特鲁德的小铜壶 + 布包（钱+纸）——赛瑞斯的情报交接。读者第一次读以为是普通商业交易
2. **窖众暗线**：克劳斯"今天初一不出去" + 袖口的灰——窖众耳目身份。本尼狄克知道但不说破
3. **白廷 vs 三港矛盾**：本尼狄克和 洛伦佐的相互无视——白廷的禁令让三港商人绕远路（"教义冲突"）
4. **格特鲁德找儿子**：旧军帽 + 问"姓哈特的少年"——她在找儿子的下落
5. **克劳斯的信息网**：克劳斯怎么知道"被征召的少年姓哈特"？——窖众的情报网（后面回收）

### 6. 暴露的待办

1. **"脊堡联盟"在对白里没出现过**——因为场景里没有镇民随口提"北军"。下次试写可以加一句镇民闲聊："听说北军今天又来征召了"，检验俗称"北军"是否自然
2. **"窖众"从未直说**——只有"窖里"双关。这是有意为之（暗线），但后续需要一场戏让主角团第一次听到"窖众"这个词
3. **洛伦佐的姓氏未提**——场景里只叫"老板娘""洛伦佐"，没用全名。下次试写可植入"洛伦佐·马尔基"或"洛伦佐·马尔维兹"
