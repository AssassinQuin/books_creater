## 一、总体：埃瑟利亚日常生活

### 日常节律

- 日出而作，日落而息。没有电灯，照明靠油灯/以太灯（富人）
- 食物保存：腌制、风干、地窖储存。新鲜蔬果是奢侈品
- 水源：井水、河水、雨水收集。贵族有引水渠
- 垃圾处理：贫民区街道污秽，贵族区有下水道（帝国和里萨兰提亚）
- 季节：冬季漫长，北方几乎无法外出。夏季是贸易和战争的季节
- 社交空间：酒馆、市场、教堂/神殿、铁匠铺、码头
- 信息流动：告示栏、吟游诗人、商人传闻、教会布道

> **写作指南**：写日常生活时写其具体、感官、不解释——读者通过角色的日常感知世界，不需要旁白说明。

## 二、各地区日常生活

### 1. 瓦尔德帝国

| 维度 | 内容 |
|------|------|
| **城市布局** | 皇城-贵族区-商人区-贫民区-城墙外（流民） |
| **住房** | 贵族：石砌城堡/庄园。商人：木石混合楼房。贫民：木屋/茅草屋/城墙外帐篷 |
| **食物** | 贵族：多道菜肴、香料、进口酒。平民：黑面包、腌肉、豆类汤、淡啤酒 |
| **服饰** | 贵族：丝绸、毛皮、珠宝。平民：粗麻布、羊毛。颜色受法律限制（紫色仅限皇室） |
| **职业** | 农民（70%）、手工业者、商人、士兵、仆人、觉醒者（特权阶层） |
| **休闲** | 贵族：狩猎、宴会、决斗。平民：酒馆、教堂、季节性集市 |
| **税负** | 什一税+人头税+战争特别征召。农民常以劳役代税 |
| **魔法在日常** | 富人用魔法物品照明、取暖、保鲜。穷人用不起，靠火和冰窖 |
| **街景** | 马车与行人争道，士兵巡逻，告示栏贴满征兵令和通缉令 |

> **写作指南**：写帝国日常时写其等级森严——同样一条街，贵族走中间，商人走两边，贫民走 gutter。觉醒者过街，所有人低头。

### 2. 里萨兰提亚

| 维度 | 内容 |
|------|------|
| **城市布局** | 港口-市场-行会区-居民区-城墙 |
| **住房** | 密集楼房，上层住人，下层开店。码头有吊脚楼 |
| **食物** | 海鲜为主，进口粮食为辅。香料贸易让富人吃得很好，穷人吃臭鱼 |
| **服饰** | 实用为主，但商人爱炫耀。异国服饰常见（精灵丝绸、矮人金属饰品） |
| **职业** | 水手、商人、工匠、码头工人、佣兵、鉴定师（觉醒者相关） |
| **休闲** | 酒馆（水手歌）、赌场、斗兽场（魔兽搏斗，非法但公开）、行会聚会 |
| **市场** | 早市鱼腥味、午市香料味、晚市酒精味。不同语言叫骂声 |
| **魔法在日常** | 魔法物品更常见，但价格高昂。黑市有便宜货（可能是逆流兄弟会制造） |
| **港口** | 各国船只、走私、海盗、冷壁炉商会的代理人 |
