# 日常生活

> 完整设计见 DB `daily_life` 分类。本文档为汇总指针。
> 核心原则：日常即世界观——用摊贩闲聊、告示栏排名、酒馆物价展示世界，不用设定说明文。

---

## 一、总体：埃瑟利亚日常生活

### 日常节律

- 日出而作，日落而息。没有电灯，照明靠油灯/以太灯（富人）
- 食物保存：腌制、风干、地窖储存。新鲜蔬果是奢侈品
- 水源：井水、河水、雨水收集。贵族有引水渠
- 垃圾处理：贫民区街道污秽，贵族区有下水道（帝国和里萨兰提亚）
- 季节：冬季漫长，北方几乎无法外出。夏季是贸易和战争的季节
- 社交空间：酒馆、市场、教堂/神殿、铁匠铺、码头
- 信息流动：告示栏、吟游诗人、商人传闻、教会布道

> **写作指南**：写日常生活时写其具体、感官、不解释——读者通过角色的日常感知世界，不需要旁白说明。

## 二、各地区日常生活

### 1. 瓦尔德帝国

| 维度 | 内容 |
|------|------|
| **城市布局** | 皇城-贵族区-商人区-贫民区-城墙外（流民） |
| **住房** | 贵族：石砌城堡/庄园。商人：木石混合楼房。贫民：木屋/茅草屋/城墙外帐篷 |
| **食物** | 贵族：多道菜肴、香料、进口酒。平民：黑面包、腌肉、豆类汤、淡啤酒 |
| **服饰** | 贵族：丝绸、毛皮、珠宝。平民：粗麻布、羊毛。颜色受法律限制（紫色仅限皇室） |
| **职业** | 农民（70%）、手工业者、商人、士兵、仆人、觉醒者（特权阶层） |
| **休闲** | 贵族：狩猎、宴会、决斗。平民：酒馆、教堂、季节性集市 |
| **税负** | 什一税+人头税+战争特别征召。农民常以劳役代税 |
| **魔法在日常** | 富人用魔法物品照明、取暖、保鲜。穷人用不起，靠火和冰窖 |
| **街景** | 马车与行人争道，士兵巡逻，告示栏贴满征兵令和通缉令 |

> **写作指南**：写帝国日常时写其等级森严——同样一条街，贵族走中间，商人走两边，贫民走 gutter。觉醒者过街，所有人低头。

### 2. 里萨兰提亚

| 维度 | 内容 |
|------|------|
| **城市布局** | 港口-市场-行会区-居民区-城墙 |
| **住房** | 密集楼房，上层住人，下层开店。码头有吊脚楼 |
| **食物** | 海鲜为主，进口粮食为辅。香料贸易让富人吃得很好，穷人吃臭鱼 |
| **服饰** | 实用为主，但商人爱炫耀。异国服饰常见（精灵丝绸、矮人金属饰品） |
| **职业** | 水手、商人、工匠、码头工人、佣兵、鉴定师（觉醒者相关） |
| **休闲** | 酒馆（水手歌）、赌场、斗兽场（魔兽搏斗，非法但公开）、行会聚会 |
| **市场** | 早市鱼腥味、午市香料味、晚市酒精味。不同语言叫骂声 |
| **魔法在日常** | 魔法物品更常见，但价格高昂。黑市有便宜货（可能是逆流兄弟会制造） |
| **港口** | 各国船只、走私、海盗、冷壁炉商会的代理人 |

> **写作指南**：写里萨兰提亚日常时写其混乱活力——五种语言同时叫骂，三种货币同时流通，两种法律同时执行。

### 3. 斯卡迪亚

| 维度 | 内容 |
|------|------|
| **城市布局** | 以霜墙要塞为中心，向外辐射少量村庄 |
| **住房** | 石砌为主（抗寒），屋顶陡峭（排雪），窗户小（保温） |
| **食物** | 腌肉、根茎类蔬菜、发酵奶制品。新鲜蔬果几乎绝迹 |
| **服饰** | 厚重毛皮、羊毛层叠。外出需全副武装防寒 |
| **职业** | 士兵、猎人、矿工、走私者、军医 |
| **休闲** | 几乎没有。冬季围炉讲故事、赌博、酗酒。夏季短暂集市 |
| **社会动态** | 军民不分——士兵的家属就是村民，村民的儿子就是士兵 |
| **魔法在日常** | 稀少。觉醒者被帝国征召走，留下的都是未觉醒者靠体力 |
| **前线氛围** | 随时可能听到魔潮警报。孩子从小学习辨认警报声 |
| **腐败** | 军官家属住暖房，士兵家属住冷屋。走私结晶是公开秘密 |

> **写作指南**：写斯卡迪亚日常时写其寒冷中的坚韧——不是悲壮，是习惯。人们不谈论魔潮，因为谈论没用。

### 4. 卡兹·杜姆

| 维度 | 内容 |
|------|------|
| **环境** | 地下，无自然光，靠以太灯和火把照明。空气闷热，金属味和矿石粉尘 |
| **住房** | 开凿于岩壁的洞穴，按家族分配。富裕家庭有独立通风口 |
| **食物** | 进口粮食为主，地下种植蘑菇和苔藓。肉类是奢侈品 |
| **服饰** | 实用，耐磨，多层（地下温差大）。金属饰品显示地位 |
| **职业** | 矿工、锻造师、工程师、商人（与地面交易）、医师（治硅肺病） |
| **休闲** | 地下竞技（摔跤、锻造比赛）、家族宴会、讲故事（地面世界的故事是童话） |
| **社会结构** | 家族>个人。背叛家族=被驱逐到地面=死刑 |
| **时间感** | 没有日夜，靠钟声和班次划分时间。矿工三班倒 |
| **健康危害** | 硅肺病、以太辐射病、塌方。平均寿命比地面短20年 |
| **与地面关系** | 矮人地面行走需戴护目镜（不适应强光）。与地面人类交易时谨慎但务实 |

> **写作指南**：写卡兹·杜姆日常时写其地下世界的独特节奏——没有太阳，但有钟声。没有天空，但有岩壁上的家族图腾。

### 5. 莫尔登

| 维度 | 内容 |
|------|------|
| **环境** | 沼泽、湿地、雾气。建筑架空或漂浮 |
| **住房** | 高脚屋、船屋、半地下掩体。防潮是首要问题 |
| **食物** | 鱼类、两栖类、水生植物。发酵食品（保存） |
| **服饰** | 防水材料（油布、处理过的皮革）。短打为主（便于涉水） |
| **职业** | 渔民、走私者、草药师、治疗师（沼泽疫病多） |
| **休闲** | 水上集市、篝火故事、草药占卜 |
| **社会动态** | 王室想靠拢帝国，民间支持逆流兄弟会。城乡分裂严重 |
| **疾病** | 沼泽热、寄生虫、以太污染水。治疗师比法师更受欢迎 |
| **魔法在日常** | 混乱。帝国法律管不到，民间自行其是 |
| **隐藏活动** | 逆流兄弟会的地下工坊、走私码头、黑市治疗 |

> **写作指南**：写莫尔登日常时写其潮湿、被遗忘、但顽强——帝国地图上可能找不到这个村庄，但这里的人照样活着。

### 6. 艾洛萨恩（精灵领地）

| 维度 | 内容 |
|------|------|
| **环境** | 古老森林，树木巨大，光线昏暗。时间感不同（一天像地面半天） |
| **住房** | 树屋、洞穴、与树木共生的建筑。不使用金属钉（伤害树木） |
| **食物** | 果实、根茎、狩猎（有节制的）。不种植，只采集 |
| **服饰** | 植物纤维、皮革、羽毛。颜色与森林融合 |
| **职业** | 守护者、歌者、记忆传承者、医者、少数与外界交流的使者 |
| **休闲** | 歌唱（历史以歌谣形式传承）、冥想、与树木"交谈" |

> **写作指南**：写艾洛萨恩日常时写其缓慢、古老、悲伤——精灵不是在生活，是在等待。等待循环结束，或等待自己消亡。

## 三、魔法物品与平民生活

### 魔法物品分级

| 层级 | 说明 |
|------|------|
| **奢侈品** | 照明、保鲜、取暖、通讯。富人专属 |
| **标准品** | 一次性防护符、简易工具强化。中产偶尔用 |
| **黑市货** | 不稳定、有副作用、便宜。贫民区流通 |
| **违禁品** | 逆流兄弟会制造的未登记物品。效果好但违法 |

### 日常应用

| 用途 | 富人 | 平民 |
|------|------|------|
| 照明 | 以太灯 | 油灯 |
| 取暖 | 恒温符 | 火盆 |
| 食物保鲜 | 保鲜符 | 冰窖 |
| 通讯 | 传讯符 | 信鸽 |
| 交通 | 马车 | 步行 |

### 社会分层标志

能用魔法物品 = 有地位。不能用 = 底层。这种区分比血统更刺眼。

> **写作指南**：写魔法物品时写其作为阶级标志的残酷——一个母亲买不起防护符给孩子，不是因为她不努力，是因为世界这样设计的。

## 四、物价与货币

### 货币系统

| 货币 | 说明 |
|------|------|
| 帝国铸币 | 瓦尔德帝国铸币，名义上通用，但边境贬值 |
| 城邦铸币 | 里萨兰提亚铸币，更稳定 |
| 以太结晶 | 真正硬通货，按属性/纯度分级 |
| 以物易物 | 边境和底层普遍 |

### 参考物价

| 商品 | 价格 |
|------|------|
| 一条黑面包 | 1帝国铜币（工人半天工资） |
| 一磅盐 | 5铜币 |
| 酒馆住一晚（含淡啤酒） | 3铜币 |
| 魔法照明符 | 1小颗火属性结晶（工人一个月工资） |
| 治疗药水 | 3颗光属性结晶（只有贵族和士兵用得起） |
| 一匹马 | 20银币（商人半年积蓄） |
| 贫民房租（每月） | 2银币（占收入一半） |

### 收入水平

| 职业 | 日/月收入 |
|------|----------|
| 农场工人 | 每天2-3铜币 |
| 熟练工匠 | 每天5-8铜币 |
| 士兵 | 每月1银币（含食宿） |
| 商人职员 | 每月3-5银币 |
| 小贵族 | 每年50-200金币（来自领地税收） |

> **写作指南**：写物价时写其具体——不是"很贵"，是"一个工人三个月不吃不喝才能买一颗最小号的防护结晶"。
