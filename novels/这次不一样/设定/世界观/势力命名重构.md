## 一、重构原则

### 1. 同一文化母体：神圣罗马帝国

神圣罗马帝国（962-1806）——"破碎主权 + 教权博弈 + 自由市 + 联盟制"完美对应本书的"多极均势 + 白廷教权 + 三港商业城邦 + 脊堡军事联盟"。

**母体语言分工**（命名时的词根选择依据）：
- 拉丁语：宗教 / 学术 → 白廷、灰书会
- 德语：世俗 / 政治 → 脊堡联盟、窖众
- 意大利语：自由市商业 → 三港同盟
- 凯尔特 / 萨克森：边缘抵抗 → 窖众边缘派
- 拜占庭希腊：古老贵族 → 赛瑞斯

### 2. 统一结构

正式名 = [核心意象] + [政治体后缀]

| 后缀 | 含义 | 用于 |
|------|------|------|
| 廷 | 宫廷 / 教廷 | 白廷 |
| 联盟 | 联邦 / 军事同盟 | 脊堡联盟 |
| 同盟 | 商业同盟 | 三港同盟 |
| 众 | 人民 / 族群 | 窖众 |
| 会 | 修会 / 学会 | 灰书会 |
| 无后缀 | 家族即势力 | 赛瑞斯 |

### 3. 俗称 vs 正式名

- **正式名**：势力自称 + 设定文档使用
- **俗称**：老百姓嘴里 + 章节正文使用
- **俗称不保留任何旧名**

## 四、每个名字的理由

### 白廷（替代"圣域"）
"圣域"太抽象，像东方修仙。"白廷"= 白（视觉，呼应白袍巡礼者）+ 廷（政治体，政教合一）。白廷二字日耳曼语感，既视觉又政治。

### 脊堡联盟（替代"铁脊"）
"铁脊"太功能性。"脊堡联盟"= 脊（脊骨裂谷）+ 堡（要塞）+ 联盟（七将军议会的联邦制）。完美对应汉萨同盟式的商业军事联邦。

### 三港同盟（替代"银港同盟"）
"银港同盟"是三词堆砌。"三港同盟"= 三（三泉城 + 白浪港 + 碎月港）+ 港 + 同盟。对应伦巴第联盟式的自由市联合。

### 窖众（替代"灰烬"）
"灰烬"太抽象（像末日组织）。"窖众"= 窖（地下避难所）+ 众（人民）。"众"字强调人民共同体，区别于"网络""组织"的冷感。

### 灰书会（替代"影子组织"）
"影子组织"是纯描述（最弱的命名）。"灰书会"= 灰（灰袍 + 古籍残页）+ 书（守秘者传承）+ 会。对应本笃会式的隐修传统。

### 赛瑞斯（替代"赛瑞斯家族"）
去掉"家族"二字，让"赛瑞斯"独立成势力名（而不是"某某家族"的从属感）。神圣罗马帝国的贵族家族（如哈布斯堡）都是"家族即势力"，赛瑞斯沿用这种逻辑——家族名就是势力名。

## 五、命名风格指南

### 5.1 贵族前置词规则

| 前置词 | 语源 | 使用范围 |
|-------|------|---------|
| 冯 | 日耳曼 | 脊堡联盟 + 白廷世俗贵族 |
| 麦克 | 凯尔特 | 窖众（边缘文化） |
| 无 | - | 三港同盟 + 灰书会 + 赛瑞斯 |

**禁止使用**：法语、意大利语、其他语源的前置词

### 5.2 姓氏规则

- **禁止意译姓**：如"雾步"这种游戏式姓氏禁用（不像真姓）
- **用音译或半音译**：如阿舍（灰烬的音译姓，双关窖众暗线）/ 马尔维兹（新造意大利音韵）
- **可用经典姓**：如施泰恩（日耳曼经典姓）/ 塞维鲁（拉丁经典姓）/ 卡西乌（罗马经典姓）

### 5.3 称谓规则

| 身份 | 称谓方式 | 示例 |
|------|---------|------|
| 白廷教士 | [教名] 兄弟 | 本尼狄克兄弟 / 奥古斯丁兄弟 |
| 脊堡军官 | 冯 + [地名] | 奥托·冯·斯泰内克 |
| 三港商人 | [名] + [姓] | 洛伦佐·马尔基 |
