# 灵基体系

> **条目名**：灵基体系

## 概览

- **region**: 全域
- **writing_guide**: 写灵基不是写游戏面板。灵基是人的一部分，不是装备。写能力开发要写出"他是怎么想到的"，不是"他升级了"。元素亲和是天生的，但衍化靠人。

## 详细设定

### 概述

觉醒不是获得力量，是灵在你身上找到了共鸣的形状。每个人天生对灵有不同的亲和——你是什么性格、什么经历、什么执念，灵就在你身上烧出什么颜色的火。这个共鸣方向，叫做灵基。

灵基决定能力的方向，不决定上限。能走多远、能衍化出多少用法，靠顿悟、靠实战、靠想象力。

### 四大亲和类型

灵本身没有属性。但灵与不同的人共鸣时，会呈现不同的元素倾向。这种倾向是天生的，不是选择的——你可能天生对火有亲和，就像有人天生对音乐敏感。

灵基亲和按性质分为四大类型。这不是人类发明的分类法，是灵在无数觉醒者身上留下的规律——你不需要知道这些类型，你的灵基自己会告诉你它属于什么。

同一个人可能同时对多个元素有亲和，但大多数觉醒者只有一个灵基。觉醒几个灵基，取决于灵在你身上找到了几种共鸣形状。

#### 元素亲和

最直观的共鸣。灵在觉醒者身上呈现自然元素的形态。觉醒者中七成以上属于元素亲和。

- **火** — 灵呈现燃烧、高温、爆发。性子烈的人容易觉醒。核心是"释放"——攻击力最强的亲和之一，但用法天差地别：有人只会放火球，有人把火压缩成刃，有人用温差控制气流飞行。
- **水** — 灵呈现流动、渗透、溶解。性格柔韧或深沉的人容易觉醒。核心是"适应"——最灵活的亲和，单点爆发不如火系，但几乎没有死角。高级水系能操控流体、改变物质状态。
- **风** — 灵呈现气流、速度、切割。追求自由或正在逃避什么的人容易觉醒。核心是"流动"——速度、侦测、远程攻击。近身战是弱点。
- **土** — 灵呈现坚固、厚重、承载。沉稳或固执的人容易觉醒。核心是"坚守"——防御、地形改造、束缚。攻击性弱，但极难被杀死。土系觉醒者活得最久。
- **雷** — 灵呈现电弧、穿透、极速。急性子或走极端的人容易觉醒。核心是"穿透"——单体最强爆发，范围小但破坏集中。持续战是弱点，雷系打不了一整天。雷系在元素亲和中最稀有，觉醒概率约为千分之一。
- **冰** — 灵呈现凝固、降温、静止。冰系未必冷漠，但往往有控制欲或被深深伤害过。核心是"控制"——减速、封锁、保存。冰系是水系的分支，但走了完全不同的路。一个水系觉醒者可能在某个时刻"冻住"了，从此变成冰系。

元素亲和内部稀有度：雷 < 冰 < 火 < 水 ≈ 风 ≈ 土。雷系的千分之一觉醒率让它成为元素中的异类——每个雷系觉醒者都会被势力盯上。

#### 玄变亲和

灵呈现的形态不再是肉眼可见的自然元素，而是更抽象的力量——光暗、震动、金属。玄变亲和比元素稀有，觉醒者约占两成。

- **光** — 灵呈现明亮、穿透、揭示。核心是"真相"——照明、幻象破除、治疗。光系的直接战斗能力不如火系雷系，但在暗系和幻术使用者眼中，光系是最危险的存在。光系觉醒者在灵衰严重的地区格外受欢迎——他们能缓解灵衰症状，虽然不能根治。
- **暗** — 灵呈现遮蔽、腐蚀、潜伏。暗系未必邪恶，但往往有不想被人看到的部分。核心是"隐藏"——潜行、毒素、精神侵蚀。战场上不如火系显眼，但统计下来，暗系杀死的人更多。暗系和光系不是对立面，是同一枚硬币的两面——一个揭示真相，一个保守秘密。
- **声** — 灵呈现震动、回响、共鸣。操控声波、感知震动、干扰灵的流动。声系觉醒者极罕见，归类在玄变是因为声的本质是震动——看不见摸不着，但无处不在。渊级异兽"沉鸣"就是声系走到极致——存在本身即声波，经过处方圆十里灵被震散。
- **金** — 灵呈现锐利、塑形、共振。操控金属、强化武器、锻造灵纹器物。金系觉醒者是天生的匠人和战场上最麻烦的对手——别人要找武器，他随手捏一把。金系之所以归入玄变而非元素，因为金的本质不是"创造金属"，是"赋予灵以形状"——和声系操控震动、光系操控明暗一样，金系操控的是结构。

#### 生灭亲和

灵呈现的形态与生命本身相关——生长、蜕变、支配。生灭亲和的觉醒者数量少，但每一个都让人不安。河洛对生灭亲和的监控比玄变更严格。

- **木** — 灵呈现生长、寄生、蜕变。操控植物、加速生长、释放毒素。木系觉醒者少，但每一个都难对付——你砍了他地上的茎，杀不死他地下的根。木系的"生"是双刃剑：能让枯木逢春，也能让寄生菌一夜吞噬一具尸体。
- **血** — 灵呈现侵蚀、同化、支配。操控自身或他人的血液与生命力。血系的核心是"支配生命"，与灵衰形成最尖锐的冲突——灵衰是生命的枯萎，血系是在枯萎的方向上走得更远。血系觉醒者历史上大多被河洛秘密处决或收编。活下来的那些，没有一个敢公开身份。

生灭亲和的两个方向——木给生命，血夺生命——在理论上可以共存。历史上出现过双灵基（木+血）的觉醒者，无一例外都是灾难级的存在。木和血不是两种能力，是同一种对生命的理解的两端。站在中间的人，既能催生也能收割。

#### 禁忌亲和

灵直接改写现实规则，跳过所有中间过程。禁忌亲和不是"更强的元素"，是完全不同的运作方式——其他亲和是灵通过元素产生效果，禁忌亲和是灵直接作用于灵。

四百年来有记录的禁忌亲和觉醒者不超过十人。每一个的出现都改写了时代。

- **灵** — 不通过元素中转，直接操纵灵的流动、浓度、凝结。理论上是最强亲和，实践中灵系觉醒者极难存活——灵对自身的操控容易失控，觉醒时灵压暴走的概率比其他亲和高数倍。灵系觉醒者是天然的阵法媒介，也天然被河洛觊觎。河洛之所以能建立灵晶阵法体系，最初就是靠一个灵系觉醒者的研究成果。
- **空** — 灵呈现空间扭曲、折叠、割裂。传送、空间封锁、空间切割。空系觉醒者四百年内有记录的不超过五人，每一次出现都改写了战局。空系的代价是身体——每一次扭曲空间，自己的骨骼都在抗议。最长寿的空系觉醒者活到四十三岁，死时全身骨骼碎裂。

禁忌亲和的觉醒不是运气好，更像是运气太好了——好到灵在你身上打开了一扇不该打开的门。门后面的东西，大多数人的身体承受不住。

### 多灵基

绝大多数觉醒者一辈子只有一个灵基。没有第二颗种子，没有境界突破送的新灵基。一个灵基走到底，能衍化出多少枝干，全看你自己。

多灵基只通过极端途径获得，每一个都是赌命：

- **灵潮中二次共鸣**：灵压把第二个印记砸进身体。大概率死，小概率活。
- **吸收异兽灵核**：角级以上异兽的灵核中含有其灵基的残留。吞下去，赌能不能融合。赌赢了多一个灵基，赌输了人废。
- **极端情境的二次觉醒**：极少数人在生死关头触发了类似觉醒的共鸣，获得第二个灵基。和灵潮类似，但不是灵压砸进来的，是绝境逼出来的。

四百年来有记录的多灵基觉醒者不超过二十人。其中活过三年的不到一半。

#### 化学反应

两个灵基不会各干各的。当它们共存于一个身体时，会自然产生化学反应——不是1+1=2，是生成全新的东西。

- **火+风**：不是"既能放火又能吹风"，是爆燃推进、烬域（火借风势烧尽方圆空气中的灵，制造局部真空）。
- **雷+水**：不是"闪电和水流"，是感电场域——水中雷弧扩散，一击覆盖整片水域。
- **光+暗**：理论上是最矛盾的组合。光揭示真相，暗保守秘密。一个光暗双灵基的觉醒者，历史上只出现过一次——他能制造"绝对矛盾区"，区域内的一切既被照亮又被遮蔽，进入的人会丧失方向感和自我认知。

化学反应不是自动产生的。需要觉醒者同时理解两个灵基的本质，并在实战中找到交汇点。这是悟的一种——不是悟单个灵基的本质，是悟两个灵基之间的关系。

#### 排斥风险

两个灵基也可能互相排斥。火+水是最常见的排斥组合——觉醒者的身体成为战场，一个烧一个灭，内耗到死。排斥没有规律，同一种组合在不同人身上可能融合也可能排斥。

多灵基是最不稳定的变量——最强的可能从这里诞生，最惨的也死在这里。

### 衍化机制

灵基是种子，衍化是让它长出枝干。同一个灵基，十个人能长出十种完全不同的树。

#### 三条路

- **磨** — 反复使用中发现新用法。火系先只会点燃，练了一千次发现能控形状，再练一千次发现能精确控温。磨出来的衍化稳定可靠，但慢。大多数引灵境觉醒者靠磨。
- **逼** — 绝境中逼出来的用法。不是想出来的，是必须活下来才找到的。逼出来的衍化往往不稳定、代价大，但威力惊人，而且独属于你——因为没有人经历过和你一样的绝境。
- **悟** — 照见级别的顿悟。突然理解灵基的本质不只是你以为的那样。火系不一定是"烧"，可能是"能量释放"——理解到这一层，衍化方向完全打开。悟出来的衍化最不可控，但最接近规则系。

大多数觉醒者一辈子只靠磨。逼需要命硬，悟需要灵性。

#### 衍化与境界

- **感脉境**：灵基初现，能力粗糙。火系可能只会手掌着火。谈不上衍化。
- **引灵境**：灵基成型，可持续战斗。通过磨可以开发出多个基础衍生能力。这个阶段最能看出觉醒者的想象力和实战天赋——同样的火系，有人只会抡火拳，有人已经学会用热气流加速移动。
- **照见境**：灵纹成形，灵基质变。悟的速度和深度暴增，衍化方向打开。这是大多数觉醒者能力真正"个人化"的分水岭。照见之前，你的火和别人差别不大；照见之后，你的火只属于你。
- **同潮境**：灵基接近规则系。能力不再是"使用灵做什么"，而是"你就是这个元素的一部分"。
- **归流境**：灵即你，你即灵。灵基的终极形态——你就是那个元素本身。

灵晶能加速单个灵基的熟练度——从感脉到引灵，从粗糙到成型。但灵晶买不来顿悟，也买不来新灵基的觉醒。灵晶是肥料，种子要自己长。

### 规则系

灵基衍化的终极方向。从具体走向抽象。

> 火系的路径：点火 → 控温 → 控热力学 → "这片区域的热力学由我定义"
> 暗系的路径：隐身 → 操控阴影 → 定义"看不见"这个概念本身
> 声系的路径：声波 → 震动控制 → 万物皆有频率，我改频率——沉鸣

规则系不是境界的问题，是对灵基本质的完全理解。理论上任何灵基都能走向规则系。实践中，大多数人在照见境才能触摸到边缘，同潮境才有可能触及核心。而渊级异兽——它们用亿万年的进化本能，走了另一条到达规则系的路。

### 全生物适用

灵对所有生命一视同仁。灵基不是人类的专利。

- **异兽**：灵基通过本能衍化。没有"悟"，但进化提供了另一种路径——亿万年的筛选，让最合适的变异活下来。角级异兽的灵基已高度成熟，每只独有能力。渊级异兽的灵基已走到规则系，存在本身改写局部规则。
- **植物**：灵基以生长和适应的形式表现。灵草是植物灵基的初级产物，灵木是高级产物。伐木工知道，灵木砍下去的断面会流血。不是血，是灵——灵木的灵基在挣扎。
- **灵本身**：灵有没有灵基？归流境的觉醒者"自身即灵"，那灵本身有没有"觉醒"的时刻？裂口出现的那一天，灵表现出了从未有过的行为。没人敢说那是灵的"觉醒"。但也没人敢说不是。

### 与现有体系的关联

灵基体系不替代境界体系，是它的补充。境界描述灵与人的关系深度（量变到质变），灵基描述灵在人身上的具体表现（方向与衍化）。

| | 感脉 | 引灵 | 照见 | 同潮 | 归流 |
|---|---|---|---|---|---|
| **灵基** | 觉醒 | 成型可战 | 质变 | 接近规则系 | 即元素本身 |
| **衍化** | 无 | 磨为主 | 磨+逼+悟 | 悟为主 | 不需要衍化 |
| **灵晶作用** | 无 | 加速熟练 | 无法替代顿悟 | 无法替代顿悟 | 无意义 |

核心公式：**境界决定深度，灵基决定方向，顿悟决定突破，想象力决定广度。**

世家垄断的不是觉醒——觉醒是随机的。世家垄断的是灵晶资源、多灵基的存活率、以及顿悟前的高强度实战机会（矿洞、灵潮前线、异兽猎杀）。穷人家的火系觉醒者和世家的火系觉醒者，起点相同，但世家的火系在照见之前就已经经历了一百场生死战，穷人家的火系在矿洞里当了十年媒介。
