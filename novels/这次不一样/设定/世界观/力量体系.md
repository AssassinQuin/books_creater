# 力量体系（仙侠 · 简明版）

> 本文件是世界观力量规则的简明版。**男主能力/进化/神通的详细机制**见 `设定/世界观/男主能力进化体系.md`（权威 · 全战斗向）。
> 世界观基底：`设定/世界观/仙侠世界观基底.md`（六界大战版权威）。

## 一、能量基础：灵气

- **灵气**=天地修仙根基能量（弥漫天地）；修士/妖族/魔族/鬼族/灵族/龙族都靠灵气修炼
- 灵气浓度决定强弱、是否需进食、灵石分布
- **灵气=生命力**（消耗灵气=消耗生命力）
- **灵石**=灵气结晶（货币+修炼资源+工艺基核）
- 反常识：灵气淡区低阶妖族更凶悍（逼出凶性）

## 二、神通三层体系（仙侠原生）

| 层 | 性质 | 获得 |
|----|------|------|
| **天赋神通** | 妖族血脉天生 | 天生 + 血脉觉醒时彻底解放 |
| **本源神通**（本作核心） | 修士本源凝聚 / 师徒传承 | 师徒传承（锤伯传匠心本源给男主）+ 自身修炼凝聚本源 |
| **法则神通**（究极） | 法则具象 | 悟道（修士感悟天地法则自然获得，不是天道"赋予"） |

**神通觉醒法则**：
- 修士通过**修炼/悟道/血脉觉醒**获得神通——**不是天道"认可后赋予"**
- **道鸣**：修士悟道/渡劫/血脉觉醒时，天地有鸣（道鸣），是规则运转的具现（**感应**而非**赋予**）
- **三种觉醒路径**：修炼凝聚 / 悟道 / 血脉觉醒
- **天道非"赋予者"**：天道只是规则运转，修士修到/悟到/觉醒到，力量自然显现

## 四、师徒传承机制⭐ 仙侠原生核心

- **传承机制**：地灵族灵匠到暮年，可将毕生凝聚的"匠心真元"（与器道合一的生命精华）**传承给弟子**——地灵族古法，相当于人族修士的"衣钵传承"
- **传承代价（独特 · 比死更深刻）**：
  - 地灵族传承不像人族那样直接耗寿命，而是**消耗地灵族一生积累的"匠心真元"**
  - 锤伯传承后**失去炼器能力**——他的"匠心真元"被掏空，他再也炼不出任何器
  - **比死更深刻的代价**：活着但失去生命意义（族灭后他靠"打磨好料"活着，现在这个意义被剥夺）
- **触发男主进化**：锤伯的匠心本源灌入男主 → 男主体内妖族血脉被外力激发 → **血脉觉醒** → 男主进化（幼妖→成妖）+ 本源神通「铭锋」觉醒
- **道号作为师徒名分（情感意义，不触发进化）**：锤伯在传承仪式上给男主取一个道号——纯情感/师徒名分，**道号本身不触发进化**（触发改的是传承匠心本源+男主血脉觉醒）
- **V1 末传承 / V2 末护阵**（剧情骨全保留）：
  - **V1 末·师徒传承**：锤伯把毕生匠心真元传给男主，耗掉大部分本源，失去锻造能力
  - **V2 末·地灵护阵**：锤伯把仅剩的本源燃尽，布下"地灵护阵"护男主（地灵族古法·护阵燃本源），战死

## 五、妖族进化链（男主专属）

```
幼妖 → 师徒传承/积累 → 成妖 → 凝脉妖 → 大妖 → 妖王 → 妖神 → 妖圣（终幕形态）
（凡）（练气）        （筑基）（金丹）（元婴）（化神）（大乘）（仙/金仙）
```

- **进化触发**：修炼突破 / 师徒传承 / 血脉觉醒 / 悟道 / 渡劫
- **大境界突破需渡天劫**：化神→大乘需渡大天劫（心境之劫+业力之劫+血脉之劫·九死一生）
  - 男主渡劫的三劫具现：心境之劫（被群像治愈→心境到位）/ 业力之劫（天庭先锋之祸的死亡业力·算在神族头上，男主不杀生灵）/ 血脉之劫（前世灵魂强+被治愈→血脉觉醒）
- **抗性**：免疫肉体不免疫情感（痛觉无效却心痛——写实高光）

## 六、能量-物品链条

```
灵气 → 妖族/修士/灵兽 → 灵石（打倒高阶妖族罕见掉落）/ 灵礦石（高灵气区采）
  → 法器燃料 / 工艺基核 / 灵鋼（稀有金属，诱导灵气）
```

- **灵石=人妖仇恨实物根源**（人族猎杀妖族取灵石）—— 主线资源体系
- 金本位经济 + 灵石/灵鋼稀有材料市场
