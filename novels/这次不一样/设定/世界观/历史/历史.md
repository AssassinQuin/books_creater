# 历史

> **条目名**：埃瑟利亚历史
> **region**: 全域
> **writing_guide**: 历史不是背景，是活的力量。写历史不写编年表，写碎片：深掘者矿灯上的刻痕、圣廷古籍中被撕掉的那一页、老水手唱的歌。真相由多方拼凑，不是主角一人发现。知道历史的人能改变现在。

---

## 一、核心原则

1. **渐进发现**：历史不是一次性揭示，是跨越全书的渐进发现
2. **多方拼凑**：真相由多方势力共同拼凑，不是主角一人发现
3. **历史有力量**：知道历史的人能改变现在

---

## 二、已知的历史（模糊）

### 2.1 大崩解

很久以前，有个厉害的文明。然后他们把自己打没了。

怎么没的？不知道。有人说打仗，有人说天灾，有人说他们自己疯了。

### 2.2 断层

大崩解之后，有一段黑暗的时间。没人知道持续了多久。只知道后来有人重新聚集起来，建立了现在的王国和城邦。

### 2.3 当前的变化

觉醒率在上升。魔潮在变强。古代魔法物品在"醒来"。

为什么？不知道。

## 三、各方势力的历史碎片

| 势力 | 知道的 | 不知道的 |
|------|--------|---------|
| **赫斯珀里迪斯** | 有一些古代文献，提到"以前的人很厉害，然后他们把自己打没了" | 怎么没的、为什么觉醒率在上升、这和现在有什么关系 |
| **圣廷** | 宗教经典中提到"原初者"和"大审判" | 原初者是谁、大审判是什么、是不是还会再来 |
| **帝国** | 军事档案中记载了"古代战争"和"某种武器" | 战争为什么发生、武器是什么、谁赢了 |
| **深掘者** | 矿脉深处挖出过古代工具，上面有字，看不懂 | 那是什么字、谁写的、写了什么 |
| **逆流兄弟会** | 收集了一些古代图纸和技术碎片 | 这些技术怎么用、为什么被丢弃、用了会怎样 |
| **灰烬** | 老人们的传说："以前的人能飞，然后他们开始打架" | 一切细节 |

---

## 四、历史的发现方式

### 4.1 渐进发现

历史不是一次性揭示的。旅行者在旅途中，每到一个地方，发现一点碎片。

| 阶段 | 发现 | 来源 |
|------|------|------|
| 早期 | 深掘者矿灯上的刻痕 | 北方冻土的矿脉 |
| 早期 | 圣廷古籍中被撕掉的一页 | 圣廷城邦的图书馆 |
| 中期 | 老水手的歌 | 里萨兰提亚的码头 |
| 中期 | 古代魔法物品上的铭文 | 某个战场遗址 |
| 后期 | 赫斯珀里迪斯的秘密档案 | 潜入或合作 |

### 4.2 多方拼凑

不同势力发现的碎片，互相印证或矛盾。

- 旅行者发现矿灯刻痕 → 深掘者说"我们也有类似的" → 但深掘者不知道意思
- 旅行者发现古籍缺页 → 圣廷说"那一页被异端烧掉了" → 但灰烬老人说"我爷爷记得那一页的内容"
- 旅行者发现古代铭文 → 逆流兄弟会说"我们也有类似的图纸" → 但图纸和铭文对不上

**真相在拼凑中浮现，但永远不会完整。**

### 4.3 历史有力量

知道历史的人，能做出不同的选择。

- 帝国不知道历史 → 加强控制 → 重复可能的错误
- 圣廷不知道历史 → 强化信仰 → 用错误的方式应对
- 赫斯珀里迪斯知道部分历史 → 秘密行动 → 但不知道全部，行动有风险
- **知道更多历史的人 → 能做出不同选择 → 改变现在**

## 六、写作检查清单

1. **历史是否渐进发现？** 不是一次性揭示，是跨越全书的碎片积累
2. **是否多方拼凑？** 主角团发现的碎片，和其他势力的碎片互相印证或矛盾
3. **历史是否有力量？** 知道历史的人能做出不同选择，改变现在
4. **是否保持模糊？** 没有标准答案，真相开放
