## 〇、核心设计（一句话）

**男主就是个普通妖族幼体，按妖修正常路径修炼，唯一特别的是有一个小天赋——灵觉敏锐（比同阶感知大一圈、能模糊感知识别善意恶意/灵气浓度）。没有金手指外挂。他的"强"完全来自 5 个被动来源。**

1. **形态**：妖族幼体（Q 萌反差：前世糙汉 ↔ 萌妖）·转生妖界↔人界边缘"妖灵密林"
2. **能力风格**：被动+迪化驱动；**全战斗向能力极简化**（治愈交剧情，能力无治愈属性）
3. **金手指**：**没有**——唯一特别的是灵觉敏锐（血脉天赋正常变异，**非外挂**，就像有人天生眼力好/耳力好）
4. **力量来源**：5 个被动来源（前世智慧 / 灵觉 / 师徒传承 / 修炼积累 / 被迪化的自我实现预言）
5. **修炼路径**：幼妖→成妖→化形妖→大妖→妖王→妖神→妖圣（妖修正常路径，**零外来元素**）
6. **变强主引擎**：迪化四阶段（脑补误会→崇拜追随→信仰献祭→法则扭曲）
7. **护短爆发**：**迪化合力**（配角脑补深意+自发行动，男主被动受益）/ 群像合力
8. **非系统流**：修仙法则驱动（修炼/师徒传承/血脉觉醒/悟道/渡劫），无系统面板、无演化树、无收集图鉴

> **治愈内核与能力的关系**：治愈交给剧情（锤伯牺牲/群像善意累积/挚友线）；能力纯战斗向；治愈推进是进化的**触发器**（被治愈→心境到→修炼/悟道/血脉觉醒→进化），不是能力属性。
> **男主看不见自己被迪化**：他始终觉得自己是普通妖修（自盲的结构性基础）——这是迪化能持续升级的根。

## 二、六界修炼体系区分（金手指不突兀的地基）

> 六界是**六种修炼道**，每界修的根本不同。男主就是妖修体系里的一个普通修士，按妖修正常路径修炼，**没有任何特殊机制**。

| 界 | 修炼核心 | 核心器官 | 能力风格 |
|---|---|---|---|
| **妖族**（男主）| 血脉+妖丹（血脉觉醒+妖丹淬炼+化形渡劫）| **妖丹** | 血脉天赋神通+化形质变 |
| 人族 | 灵根+丹田（引气+金丹/元婴+法宝符箓阵法丹药）| 丹田 | 借外物修自身·加法积累 |
| 魔族 | 魔气+魔心（速成逆修+血祭+业力代价）| 魔心（业火）| 速成+逆修+天劫首劈 |
| 鬼族（冥）| 魂魄+魂火（执念+阴气+判官秩序）| 魂火 | 魂魄强度+审亡魂+认主 |
| 仙族 | 仙气+仙格（飞升后修法则+清修记录）| 仙格 | 法则+清高+记录者 |
| 神族（天庭）| 神格+天律（永恒不死+维护天道·只执行不修炼）| 神格 | 法则维护+永恒+仙化夺舍 |

> **妖修三柱**：血脉觉醒 / 妖丹淬炼 / 化形渡劫。男主就是普通妖修，按这套路径修炼，**妖丹按妖修正常路径淬炼**（血脉天赋在妖丹淬炼中稳定成型）。
> **群像能力也极简**：所有角色按种族正常修炼路径，差异化靠**性格+剧情功能+人际关系+道心**，不靠能力体系。

## 三、核心内核：灵觉敏锐（血脉天赋正常变异）

### 3.1 灵觉敏锐的具体表现

- **感知范围**：比同阶妖族感知范围大一圈（早察觉危险/机会）
- **善意恶意感知**：能模糊感知他人善意/恶意（不是读心，是直觉）
- **灵气浓度感知**：能模糊感知灵气浓度变化（找灵脉/灵物有优势）
- **锤伯传承后的延伸**：V1 末锤伯传匠心本源后，灵觉敏锐的"感知万物本质"获得质变（匠人鉴料的敏锐度延伸——对器物/材料的敏感，仍是感知侧，非外挂）

### 3.2 灵觉敏锐的天然边界（不是外加局限·是天赋本身的边界）

- **只能模糊感知**，不能读心/预知/精确定位
- **境界压制**：对方境界高过男主太多，灵觉被压制无法感知
- **过载失灵**：强情绪过载/创伤反扑会让灵觉失灵（**F10 灵觉过载/创伤反扑**·内在反派伏笔·V2 首现→V7 迟钝初现→V10 暴跌→V11 接纳消解）
- **对方真心敞开心扉时**：灵觉"映不出"对方的恶意（因为没有了）——这是治愈推进的剧情标记，不是 bug

> **注意**：灵觉敏锐就是天赋，边界天然透明——同阶感知范围、境界压制、过载失灵（见 3.2），都是天赋本身的自然尺度。男主就是普通妖修，同境界打不过强者，天然有张力，简单自洽。

## 四、5 个力量来源（无主动外挂）

> 男主的"强"完全来自这 5 个被动来源。没有一个是主动外挂。

### 来源一：前世现代人智慧
- 30 岁灵魂 + 书店老板杂学 + 开阔眼界
- 现代常识差（洗手防病/分工协作/契约精神）在本世界的"见识差"应用
- **边界**：现代常识在本世界不全适用（"洗手防病"有用，"民主选举"未必）

### 来源二：灵觉敏锐的小天赋
- 血脉天赋正常变异（非金手指）
- 提供迪化的"预言感"基础（随口一句话被脑补为"未卜先知"）

### 来源三：师徒传承
- 锤伯 V1 末传匠心本源 → 感知万物本质的敏锐度质变
- **这是师徒传承触发血脉觉醒的纯仙侠机制**，按妖修正常路径
- 锤伯核心手艺"鉴料"（鉴定矿石灵材）→ 灌匠心本源 → 男主"感知万物本质"的敏锐度质变（匠人鉴料→男主感知万物·一脉相承，**仍是感知侧天赋延伸，非外挂**）

### 来源四：修炼积累
- 按妖修正常路径：幼妖→成妖→化形妖→大妖→妖王→妖神→妖圣
- 进化触发：修炼积累 + 师徒传承 + 血脉觉醒 + 悟道 + 渡劫（纯仙侠原生）
- **没有任何特殊机制**，就是普通妖修

### 来源五：被迪化的"自我实现预言"（核心·男主"变强"的真引擎）
- 别人觉得他强 → 照"深意"行动 → 竟成好事 → 他被动受益（声望+资源+追随者）→ 他真变强了 → 更被坚信
- **结构性迪化，不是装的**——男主自己看不见这个循环（自盲基础）
- 这是能力极简后，男主"变强"的主引擎（详见 §五 迪化四阶段）

## 五、迪化四阶段（男主"变强"主引擎）⭐ 核心

> 能力极简后，**迪化是男主"变强"的主引擎**。迪化本质 = 误解 → 行动（按误解）→ 竟然成真/更好 → 反转爽 + 喜剧。

### 5.1 四阶段表（真实种子 → 迪化放大 → 内心变化）

> 迪化不是"男主懵圈+配角脑补+被动受益"的扁平喜剧。每个阶段都必须同时具备**三列**：真实种子（男主真做了什么善意/能力判断）、迪化放大（配角基于自身道心误读）、内心变化（第 3 层 inner-conflict）。**缺真实种子=硬凹，缺内心变化=工具人**——这是迪化能不能"经典"的关键。

| 阶段 | 卷 | 真实种子（男主真做了什么） | 迪化放大（配角怎么误读） | 男主内心变化（第 3 层） |
|---|---|---|---|---|
| 一·脑补误会 | V1-V3 | 灵觉察觉危险提醒换路 / 前世常识洗手防疫 / 收编败将给口饭 | 随口话被脑补为圣人之言；害怕撤退被脑补为战略撤退；收编被脑补为王者之气 | 苦笑+不解释（享受便利）+ **不配得感种子**（"他们信的是假的我"） |
| 二·崇拜追随 | V4-V6 | 拒绝支配捷径（真选择）/ 正常突破（真修炼）/ 看穿一次阴谋（灵觉+智慧） | 正常突破被脑补为天纵之才；前世常识被脑补为道法通天；犯错被脑补为考验 | **怕拆穿的焦虑** + 开始**被期待绑架**（"我必须维持这个形象"）|
| 三·信仰献祭 | V7-V9 | 主动为身边人拼命（真善良）/ 建和邦庇护五族（真行动） | 被多方奉为妖圣转世；配角主动做事不求回报 | **深度内心冲突**（我是谁？真实的我 vs 被神化的我）→ **主动选择成为**（发现被推着的形象真能帮人，从被动转主动）|
| 四·法则扭曲 | V10-V12 | 接纳"被神化的自己=真实的自己"，用一生兑现信仰 | 信"男主能化解天劫"→天劫真没来；信"男主是循环终结者"→循环真崩塌；**信仰扭曲天道**（道家心想事成+佛家愿力+民俗信则有）| **和解**（不再纠结配不配）+ **迪化塑造本体完成**（虚构形象被男主用行动兑现成真）|

> **四阶段 = 男主深度经历三层（experience-depth）**：V1-V6 认识他人（看清配角道心与伤口→理解他们为什么误读自己）→ V7-V9 认识自我（面对"真实的我 vs 被神化的我"的知行矛盾）→ V10-V12 在认识上行动（主动选择成为众人信仰的善的化身，用行动把虚构变成真实——这是最深刻的经历）。
>
> **"能力自盲"不等于"对神化无觉察"**：男主始终觉得自己"能力普通"（灵觉只是小天赋，不觉得自己强）——这是能力侧自盲，**不会动摇**；但他对"众人正在神化我"是逐步觉察的（V1-V3 苦笑→V4-V6 怕拆穿→V7-V9 挣扎→V10-V12 接纳）。两层并行不悖：他越觉察"被神化"，越能在"我到底是不是那个人"的拉扯中做出选择。

### 5.2 迪化的三大合理基础（避免硬凹）

男主虽然能力简单，但迪化必须有合理基础——不能凭空脑补。基础来自：

1. **灵觉敏锐的"预言感"**：男主灵觉比同阶敏锐，随口一句"今天别往东走"（灵觉感到异样）→ 配角脑补"师父已算到东边有劫"→ 东边果然出事 → 被神化
2. **前世现代人的"见识差"**：随口说"大家洗手再吃饭"（前世习惯）→ 配角脑补"师父已悟净身之道"→ 部落瘟疫减少 → 被神化
3. **被迪化的"自我实现预言"**：被迪化为"大妖"→ 配角死心塌地追随 → 照"深意"行动 → 真成事 → 男主被动受益（声望+资源+追随者）→ 真变强 → 更被坚信

### 5.3 迪化的反转爽点公式

- **公式一·事与愿违闭环**：男主想低调/澄清 → 反而引发更大神迹/崇拜 → 越挣扎越被神化
- **公式二·信息差双线叙事**：读者全知（看见男主的无意识+配角的脑补）+ 双方互不知 → 优越感+喜感
- **公式三·阶段性揭晓**：V1-V3 锤伯部分知情（不说破）→ V4-V6 核心圈部分知情 → V7-V9 核心圈全员知情但配合演戏 → V10-V12 男主接纳"被神化的自己"，主动兑现成真

### 5.4 内心拉扯层（迪化的深度核心 · inner-conflict）

> 旧设计只有"被动受益"的喜剧表层，没有内心层——这是迪化扁平、男主工具化的根。本层是迪化能不能"经典"的关键，**V4-V10 要逐步累积，V7/V10 爆发**。

**① 不配得感（V1-V6 种子→V7-V9 高潮）**：男主知道自己没那么强、没那么"深谋"（只是灵觉+小聪明+善良），众人把他当神。他怕被拆穿——拆穿=失去一切（和邦/追随者/治愈的种子）。**前世书店老板的他，最懂"名不副实"的羞耻感**：前世付出善意被嘲笑"老好人傻"，这次反过来，他没付出多少却被捧上神坛，羞耻感以另一种形式回来。

**② 被期待绑架（V4-V9 累积）**：他开始被推着成为众人期待的样子。每次他想澄清/退缩，配角已经按"深意"行动了，他只能跟上。**知行矛盾**（inner-conflict）：他"知道自己不配"（知），但众人需要他"是"（行）——他只能装作是，装着装着，发现"装成的样子"真的帮到了人。这是全书最深刻的紧张感，**不要急于解决**：拉扯要延长到 V10 摔跟头一并爆发。

**③ 迪化塑造本体（核心反转 · V7-V12 完成）**：渐渐地，男主发现"被迪化推着成为的样子"——善良、守护、深谋——其实就是他**真正想成为的人**（那个前世想当的好人）。他开始**主动**按"被期待的样子"行动（不是被动，是选择），因为他发现这样真能帮到人。**虚构形象被男主用行动兑现成真**——这是迪化从"喜剧噱头"升华为"人物弧线"的核心反转：他不是"被误会成神"，他是"被误会推着，真的活成了神的样子"。

> **落地要求**：每次写迪化场景，除了写配角的脑补+喜剧反差，必须留一笔男主的内心戏（不配得感的苦笑/被期待绑架的窒息/主动选择成为的决心）。纯被动受益的描写=扁平，必须删。

### 5.5 战斗主体性原则（男主是大脑+致命一击，不是工具人）

> 旧设计"合力围剿=配角脑补合力，男主OS什么都没干"= 爽感错位（experience-depth 不通过 + 读者看配角打赢）。**男主全程懵圈=工具人，禁止**。

1. **男主是大脑+致命一击**：灵觉看准弱点/关键时机/破绽，前世智慧做关键决策，男主**亲自执行致命点**。配角合力是**外围执行**（手脚），不是主导。
2. **迪化在战斗中的放大**：男主的真本事（看准+果断）→ 配角把他的果断脑补为"深谋"→ 配角按"深谋"放大执行（超额完成男主意图）。**男主是发起者+关键点，迪化是放大器**——不是迪化替代男主打赢。
3. **爽点双层**：第一层=男主真本事的爽（灵觉看准、果断一击）；第二层=迪化放大的爽（意图被超额实现、喜剧反差）。**缺一不可**——只写迪化不写真本事=男主工具化。
4. **示范场景（V5 合力围剿厄枭）**：男主灵觉看准厄枭命门 → 果断指挥+亲自致命一击 → 配角把"果断"脑补为"师父深谋"→ 超额放大围剿 → 厄枭死在男主手里，不是死在配角围攻里。读者爽的是"男主真本事+迪化超额"双层叠加。

### 5.6 与前世创伤的呼应（错位的二次发生 · 主题咬合）

> 迪化不是孤立的喜剧机制，它与男主的前世创伤形成**主题级呼应**——这是迪化承载全书主题"这次不一样"的底层。

- **前世**：林悟付出真善意 → 被程哲/小沈/苏绾/碰瓷者一次次**辜负**（善意→无回报的错位）→ 封闭绝望轻生。
- **这次**：林悟付出小善意 → 被六界**过度回报**（善意→基于误会的超额回报的错位）。
- **两次都是"善意与回报的错位"**——这是全书主题"这次不一样"的**发生机制**：迪化=错位的二次发生。
- **男主的治愈=不再纠结"配不配"**：前世他纠结"我付出这么多凭什么被辜负"，这次他纠结"我没付出这么多凭什么被捧上神坛"。两次纠结的本质都是"把善意当交易"。V10-V12 的和解=他终于放下交易思维："既然众人因我而信善，我就真的去做那个善的化身"——**善意不是为回报，善意本身就是答案**。
- **终幕法则级咬合**：打破六界循环的不是法则技能，是**男主真的成为了众人信仰的那个守护者**——信仰扭曲现实的本质，是男主用一生兑现了虚构形象，让"信仰"有了真实承载。循环因"被相信的善"而崩塌。**迪化=这次不一样的机制**，在此闭环。

## 七、迪化合力（替代"鉴纹暴起"的爽点引擎）

> **旧"鉴纹暴起"已删除**（外挂型主动爆发·不符合极简）。替代为**迪化合力**——男主被动受益，非主动外挂。

### 7.1 迪化合力机制

- **触发**：男主或身边人受威胁 / 见"付出善意被辜负"场景（戳前世伤口）
- **效果**：男主灵觉看准+果断决策（大脑+致命一击） → 配角把果断脑补为"师父的深意" → 配角按各自强项+道心**放大执行**（手脚） → 合力战力跃阶 → 男主亲自完成致命点，配角超额清扫外围
- **画面（战斗主体性示范）**：男主灵觉定位敌方命门 → 一句话/一个手势指明破绽 → 配角各自脑补"师父的深意是……"→ 各自放大出击 → 合力绞杀外围 → **男主亲自执行致命一击**（不是懵圈等配角打赢）→ 敌人死在男主手里，迪化让配角超额完成意图
- **男主内心的双线**：表层=果断指挥+致命一击（真本事）；内心=不配得感的苦笑（"他们又把我的一拳脑补成圣人之击了"+被期待绑架的窒息）。**纯"男主全程懵圈OS我什么都没干"的扁平描写=工具人，禁止**。
- **与群像合力的区别**：群像合力是真实的并肩作战（每人各自战力+配合，剧情层）；迪化合力是配角脑补+放大执行（男主是发起者+致命点，迪化是放大器，迪化层）。两者常叠加。

### 7.2 男主本人的战斗（按境界正常战力）

- **幼妖期**：靠前世智慧+灵觉+本能自保（完整的扮猪吃虎）
- **成妖期**：师徒传承后初醒，战力刚起步
- **化形妖-大妖期**：正常妖修战力，靠策略+护短
- **妖王期**：群像联结的合力（真实并肩作战，非 buff）
- **妖神-妖圣期**：靠心境+群像+迪化信仰强度，不是数值碾压

### 7.3 战斗用法（无外挂 buff · 男主主体性）

- **灵觉敏锐提供战场预警+命门定位**（敌方位置/恶意/灵气波动/破绽）——**男主是大脑**
- **前世智慧提供关键决策**（现代战术/分工/心理博弈/果断时机）——**男主是大脑**
- **男主亲自执行致命一击**（看准命门后果断出手，不是配角代劳）
- 群像各自战力+配合（剧情层并肩作战，外围清扫）
- 迪化合力（配角脑补"深意"+放大执行，超额完成男主意图）——**迪化是放大器，不是替代男主打赢**
- 男主的战斗全靠以上五项（灵觉预警+前世智慧+亲自致命一击+群像配合+迪化放大），简单透明可复现
