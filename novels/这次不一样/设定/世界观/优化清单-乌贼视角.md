# 世界观优化清单 · 乌贼视角

> 基于 wuzhei-perspective skill 分析 · 2026-06-12
> 核心诊断：世界很完整但缺"世界感"——档案 vs 真实运转的地方

## 三大根因（顺序决定优化优先级）

1. **现实参照不统一**——暗黑奇幻/公路文/春秋战国三种视觉联想互相打架
2. **核心机制太抽象**——以太六准则是哲学命题，不是读者可见的现象
3. **缺少世界感细节**——文档像 DND 怪物手册，不像主角不存在也在运转的真实地方

---

## P0 必修（决定世界感能否立住）

### P0-1 现实参照做减法，定一个主锚

- **现状**：「暗黑奇幻 + 公路文 + 春秋战国式割据」三种参照并存，视觉/术语联想冲突
- **动作**：
  1. 选一个主参照（建议春秋战国，因为已经写在核心锚点里）
  2. 视觉层全部收敛到主参照——圣骑士团→虎贲/武士团；教堂→祠庙/祖殿；葡萄酒→米酒/茶
  3. 暗黑奇幻降级为"基调"（残酷、压迫）而非"视觉来源"
  4. 公路文降级为"叙事结构"（主角团移动）而非"世界观来源"
- **落到**：`核心设定/世界基石.md`（核心锚点改写）+ 全术语扫描替换
- **验收**：随便抽 10 个术语（地名/职位/物品），9 个以上能对应到同一个文化参照系

### P0-2 把"以太六准则"现象化

- **现状**：感受/浓度/元素/趋异/代价/强者——六条全是抽象规则，读者能复述但想象不出画面
- **动作**：每条准则配 2-3 个**读者可见的现象**：
  - 感受法则 → 觉醒者接触以太的体感（皮肤刺痛？耳朵嗡鸣？嘴角金属味？）
  - 浓度法则 → 浓度变化的可观测信号（黑月亮度？魔潮频率？作物变异？酒疯子变多？）
  - 元素法则 → 元素亲和在身体上的可见痕迹（火亲和体温偏高？水亲和皮肤湿润？）
  - 趋异法则 → 高阶觉醒者怎么"不像人"了（瞳孔变色？声音多了一层回响？）
  - 代价法则 → 用过度的具体表现（指甲结晶化？记忆错乱？情绪钝化？）
  - 强者法则 → 高阶者之间的相互感知（气场压迫？空间扭曲？普通人站不稳？）
- **落到**：`能力体系/能力体系总纲.md` 在"六准则"section 每条下面加"现象表现"小节
- **验收**：每条准则能让读者立刻说出"在故事里这看起来是 ___"

### P0-3 给代价法则加"内在代价"层

- **现状**：代价只有社会维度（执照/魔力税/征召/歧视/地位绑定），使用力量本身无代价 → 觉醒显得"安全"
- **动作**：在背景大纲"三、代价"section 加 1-2 条**内在代价**：
  - 候选 A：结晶化侵蚀——以太用过度，身体组织慢慢结晶（皮肤下有晶簇、关节僵硬）
  - 候选 B：情绪钝化——高阶觉醒者情绪反应越来越弱，"强大"和"非人"成正比
  - 候选 C：元素反向同化——亲和某元素久了，被元素"染色"（火亲和暴躁、水亲和冷漠）
  - 任选 1-2 个，写到背景大纲 + 进阶五境的"代价"项下
- **落到**：`背景.md` 三、代价 + `能力体系/能力体系总纲.md` 进阶五境每境加"代价"字段
- **验收**：进阶每一境都有明确的"使用过度会 ___"，读者能预判角色的代价

## P1 重要（影响阅读体验）

### P1-1 设计"制度化场景"作为多势力收束

- **现状**：9 个力量中心（7 势力 + 灰书会 + 赛瑞斯），群像爆炸风险
- **动作**：设计 1-2 个**固定发生的制度化场景**，让多势力人物自然相遇：
  - 候选 A：冒险者公会大厅的"任务发布日"（每周固定，所有势力派代表）
  - 候选 B：某个跨势力宗教节日（白廷主持，所有城邦参加）
  - 候选 C：某个中立酒馆的"信息黑市"（地下情报交易，窖众/拾荒者/各势力暗探）
- **落到**：`势力/势力总纲.md` 新增"制度化相遇场景"section
- **验收**：主角团可以在不"硬凑"的情况下，在一个固定场景里同时遇到 3+ 势力的人

### P1-2 地理具体化到能画地图

- **现状**：`地图/大陆概览.md` 只有"一超多强 + 真空地带"的结构性描述，没有具体地名
- **动作**：补全 8-12 个具体地点：
  - 每个势力首府的名字 + 一句话特征（白廷首府 / 三港主城 / 脊堡联盟要塞 / ...）
  - 主角团起点的具体小镇/村落（CLAUDE.md 提到"从北到南"方向）
  - 2-3 个"真空地带"的名字 + 长什么样的描述
  - 关键地理障碍（深裂/脊骨裂谷/东岸/南境 这些命名优化后的地标）
- **落到**：`地图/大陆概览.md` 详细设定 section 扩写 + 可选画一张示意图
- **验收**：读者读完地理文档能在脑子里画出一张粗略地图，知道主角从哪到哪要经过什么

### P1-3 加"主角不存在的一天"试写段

- **现状**：所有写作铁律都是"写感官不写说明"，但世界观文档本身全是说明
- **动作**：选 2-3 个势力，各写一段 500-800 字的「主角不存在时，这里普通一天发生了什么」：
  - 脊堡敢死营的早晨（号角几点响 / 早饭 / 训练 / 谁今天没回来）
  - 三港码头的换班（船到 / 卸货 / 分账 / 拾荒者等在码头外）
  - 窖众窖口的分食（一锅炖菜 / 谁先盛 / 老匠人仿刻铭牌 / 吹口哨）
- **落到**：`设定/灵感库/世界日常-试写.md`（新建，作为参考样本）
- **验收**：试写段完成后能立刻看出哪些设定立住了、哪些是档案在撑

## P2 优化（锦上添花）

### P2-1 暗线的"可观测性"补强

- **现状**：CLAUDE.md 提到三条暗线（灰病/历史/战争），但世界观文档里看不到暗线如何被普通人感知
- **动作**：每条暗线设计 2-3 个"普通人可见的边缘信号"——读者后来才发现"原来那是暗线"
- **落到**：`设定/大纲/线索/` 下各暗线文件加"可观测信号"section
- **验收**：每条暗线在卷一就能埋下 1-2 个"读者会忘的细节"作为伏笔

### P2-2 觉醒者社会歧视的具体场景化

- **现状**：背景大纲提到"觉醒者勿入"的牌子、聚居区是贫民窟——这些是说明
- **动作**：把歧视落到具体日常场景——酒馆老板怎么"礼貌地"赶人、孩子被邻居怎么排挤、老板怎么"客气地"不雇觉醒者
- **落到**：`社会与文化总纲.md` 文化体系 section 扩写
- **验收**：场景化的歧视描写可以直接进入章节正文，不用再"解释"

### P2-3 术语可视化词典

- **现状**：术语统一做过（法师→觉醒者、泉眼→清除），但没有"读者第一次看到这个词脑子里出现什么画面"的对照
- **动作**：建一个术语小词典——每个核心术语配一张"画面描述"（不是图，是一段文字让读者想象）
- **落到**：`设定/世界观/术语词典.md`（新建）
- **验收**：新读者第一次读到"以太结晶"能在脑子里看到画面

## 执行顺序建议

```
Week 1: P0-1 现实参照做减法（决定后续所有改动的方向，必须先做）
Week 1: P0-2 六准则现象化（独立任务，可与 P0-1 并行）
Week 2: P0-3 内在代价（基于 P0-2 现象化的结果）
Week 2: P1-3 主角不存在的一天（试写——立即检验 P0 是否到位）
Week 3: P1-1 制度化场景 + P1-2 地理具体化
Week 4: P2 系列（在主线写作开始前作为锦上添花）
```

**关键节点**：P1-3（试写）是检验 P0 改动是否到位的"考试"——如果试写顺畅，P0 改对了；如果试写卡壳，回去查 P0 哪一项没做透。

---

## 整体验收标准

修订完成后，跑一次"乌贼三问"自检：

1. **「这个世界不依赖主角也存在吗？」**——能答出 3+ 个不依赖主角发生的日常事件
2. **「六准则在故事里长什么样？」**——能立刻说出每条准则的可见现象
3. **「主角团移动时经过哪些地方？」**——能画出/说出一张粗略地图

三问全 pass = 世界感立住了，可以进入 Phase B 大纲规划。
任一卡壳 = 回去查对应 P 项。
