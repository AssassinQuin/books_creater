# 社会分层

> **条目名**：埃瑟利亚社会分层
> **region**: 全域
> **writing_guide**: 纯人类世界，社会分层基于觉醒状态、阶级、职业。不写外貌差异，写日常差异——他们怎么吃饭、怎么工作、怎么被对待。

---

## 一、核心原则

### 社会分层设计铁律

| 原则 | 说明 |
|------|------|
| **纯人类世界** | 无精灵、兽血者、矮人等非人类智慧生物 |
| **分层基于觉醒状态** | 觉醒者 vs 未觉醒者是核心鸿沟 |
| **分层基于阶级** | 贵族/商人/平民/拾荒者的经济鸿沟 |
| **分层基于地域** | 城邦公民 vs 城墙外流民 vs 荒野拾荒者 |
| **不写外貌，写日常** | 不是"尖耳朵"，是"觉醒者的手心偏热、拾荒者的靴底磨穿" |
| **信息差是真正的边界** | 知道历史的人vs不知道的人，才是真正的阶层边界 |

---

## 二、四大社会阶层

### 1. 贵族与统治阶级

> **region**: 全域
> **占比**: 约占总人口1%
> **核心特征**: 掌握政治权力、以太泉控制权、觉醒者登记制度

#### 权力来源

| 方面 | 说明 |
|------|------|
| **政治权力** | 世袭或军事功勋获得贵族身份，控制城邦议会 |
| **经济垄断** | 控制以太泉开采权、结晶贸易、土地所有权 |
| **觉醒者垄断** | 通过仪式觉醒（昂贵）确保家族觉醒者比例远高于平民 |
| **知识垄断** | 控制觉醒者学院、古代文献、技术图纸 |

#### 内部差异

- **帝国贵族**：十二家族世袭，血统即权力
- **城邦寡头**：里萨兰提亚的十二贸易家族，财富即权力
- **将军议会**：斯卡迪亚的七将军，战功即权力
- **神职高层**：圣廷的大主教和神殿议会，信仰即权力

---

### 2. 商人、工匠与执照觉醒者

> **region**: 城邦内部
> **占比**: 约占总人口15%
> **核心特征**: 有技能、有执照、有城邦公民权，但无政治权力

#### 构成

| 群体 | 说明 |
|------|------|
| **商人** | 控制贸易网络，但受贵族/寡头盘剥。里萨兰提亚的商人最自由，帝国的商人最受限 |
| **工匠** | 铁匠、木匠、以太设备维修师。深掘者行会的工匠地位最高 |
| **执照觉醒者** | 在帝国/圣廷/城邦登记注册的觉醒者。有义务服役，有权利受保护 |
| **公会冒险者** | 在冒险者公会注册的觉醒者，靠完成任务谋生 |

#### 核心矛盾

- 商人想扩大贸易自由，贵族想维持垄断
- 工匠想提升技术地位，但技术被贵族控制
- 执照觉醒者想获得更多自主权，但登记制度束缚他们

---

### 3. 平民与未觉醒劳工

> **region**: 城邦内部和周边
> **占比**: 约占总人口60%
> **核心特征**: 未觉醒，从事农业、矿业、码头劳动，是社会基石但无话语权

#### 构成

| 群体 | 说明 |
|------|------|
| **农民** | 帝国平原的粮食生产者，占人口最大比例。受贵族地主盘剥 |
| **矿工** | 脊骨裂谷的结晶开采者，危险但收入相对较高。深掘者行会保护其权益 |
| **码头工人** | 里萨兰提亚的底层劳动力，日结工资，无保障 |
| **手工业者** | 小作坊主、学徒，靠手艺谋生 |

#### 生存状态

- 未觉醒者占人口80%，但掌握的资源不到10%
- 以太结晶对他们来说是工具（照明/供暖/治疗药剂），不是力量源泉
- 精锐的未觉醒骑士团能打赢觉醒者民兵——数量和组织有时能弥补个体差距

---

### 4. 城墙外流民、拾荒者与灰烬成员

> **region**: 城墙外、荒野、地下
> **占比**: 约占总人口24%
> **核心特征**: 无公民权、无固定居所、无社会保护，在缝隙中求生

#### 构成

| 群体 | 说明 |
|------|------|
| **城墙外流民** | 帝国皇城外的临时聚落。法律上不是公民，无权利无保护 |
| **拾荒者** | 荒野中收集结晶碎片、魔物素材的流浪者。危险但自由 |
| **无照觉醒者** | 觉醒了但没登记的人——帝国视其为罪犯，圣廷视其为异端 |
| **灰烬成员** | 地下网络的参与者。伪造执照、走私结晶、藏匿逃亡者 |
| **逃亡者** | 逃离征召/奴役/审判的人，靠灰烬网络生存 |

#### 生存逻辑

- 不是"可怜"，是"活着"。写底层不写可怜，写活着
- 拾荒者的靴底磨得只剩一层皮，踩在冻土上能感觉到石子硌脚心
- 无照觉醒者是定时炸弹——觉醒了但没资源、没训练、没保护

## 三、觉醒状态与社会地位

### 觉醒者 vs 未觉醒者

| 维度 | 觉醒者 | 未觉醒者 |
|------|--------|---------|
| **人口占比** | 约20% | 约80% |
| **社会地位** | 登记后有特权，无照则被追捕 | 无特权，但也不是底层——精锐骑士团一样是力量 |
| **经济能力** | 可从事高价值工作（法师/护卫/探索者） | 从事体力劳动，收入低但稳定 |
| **政治权利** | 帝国：登记觉醒者可担任军官；圣廷：注册为"圣恩者" | 无政治权利，但城邦公民有基本保护 |
| **生存风险** | 被征召、被猎杀取核、被异端审判 | 被贵族征召为炮灰、被魔潮吞没、被疾病带走 |

### 觉醒者的内部分层

| 层级 | 说明 |
|------|------|
| **高阶觉醒者** | 洞见以上境界。被势力争夺，享有特权，但也被束缚 |
| **中阶觉醒者** | 洞见境界。军队主力、公会中坚、商会护卫 |
| **低阶觉醒者** | 刚觉醒。最危险的群体——有力量但无经验，容易被利用或猎杀 |
| **无照觉醒者** | 未登记。帝国和圣廷的追捕对象，灰烬网络的保护对象 |

## 四、社会流动性

### 上升通道（极少）

| 通道 | 说明 |
|------|------|
| **军功** | 斯卡迪亚唯一真实的上升通道。不论出身，只看战功 |
| **觉醒** | 随机事件。一个矿工在矿洞里觉醒，命运改变——但多数觉醒者仍被势力控制 |
| **商业成功** | 里萨兰提亚的商人可通过财富获得影响力，但无法获得贵族身份 |
| **技术垄断** | 掌握古代图纸或独特技术的工匠，可提升地位——但会被势力觊觎 |

### 下降通道（常见）

| 通道 | 说明 |
|------|------|
| **破产** | 商人失败→沦为平民→沦为流民 |
| **觉醒失控** | 觉醒后无法控制力量→被异端审判→失去一切 |
| **政治失势** | 贵族家族衰落→成员沦为平民或流亡 |
| **魔潮** | 边境村庄被魔潮摧毁→幸存者成为拾荒者 |

## 五、写作检查清单

每章涉及社会分层时自检：

1. **阶层差异是否写日常？** 不是"贵族很富有"，是"贵族走街道中央，商人走两边，贫民走 gutter"
2. **觉醒者是否写选择？** 不是"他很强大"，是"他选择了站出来，还是选择了独善其身"
3. **底层是否写活着？** 不是"底层人民很可怜"，是"拾荒者的靴底磨穿了，用草绳绑着继续走"
4. **阶层冲突是否写结构？** 不是"贵族恨平民"，是"贵族看不见平民——一个法官可能一辈子没踏足过城墙外"
5. **是否有纯善纯恶的阶层？** 每个阶层有自己的逻辑，没有纯善纯恶
