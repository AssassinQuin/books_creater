# 种族

> **条目名**：埃瑟利亚大陆种族
> **region**: 全域
> **writing_guide**: 种族不是"异类"，是"被结构伤害的群体"。不写外貌特征（尖耳朵/蓝皮肤），写日常差异——他们怎么吃饭、怎么工作、怎么被对待。每个种族有自己的逻辑，没有纯善纯恶。

---

## 一、核心原则

### 种族设计铁律

| 原则 | 说明 |
|------|------|
| **封印让所有种族关于以太的记忆都断绝** | 经历几千年，都没有以太记忆，处于原始、冲突状态 |
| **生活仅凭种族天赋特点** | 各族不知道以太的存在，但天生有某些能力 |
| **以太增强种族天赋** | 有以太时，各族天赋被放大；无以太时，天赋处于"休眠"状态 |
| **人类必须觉醒学习** | 人类天生无法感知以太，必须通过觉醒事件才能使用 |
| **人类可天生适应某些以太** | 某些人类血统对特定元素有亲和力，觉醒后更容易掌握 |
| **不写外貌，写日常** | 不是"尖耳朵"，是"精灵丝绸不皱、兽血者体温偏高" |
| **种族是信息差的载体** | 知道历史的人vs不知道的人，才是真正的种族边界 |

## 二、五大种族

### 1. 人类（Human）

> **region**: 全域
> **population**: 大陆主体，约占总人口70%
> **核心特征**: 必须觉醒才能使用以太，但天生能适应某些以太属性

#### 种族天赋：适应者

| 方面 | 说明 |
|------|------|
| **以太使用方式** | 必须通过"觉醒"事件才能感知和操控以太。觉醒后需要学习和练习 |
| **觉醒率** | 约20%，自然觉醒（随机）+ 仪式觉醒（可控但昂贵） |
| **天生适应** | 某些人类血统对特定元素有亲和力（如北方人多火系亲和，沿海人多水系亲和） |
| **优势** | 可塑性强，同元素不同开发方向；可学习多种魔法 |
| **劣势** | 觉醒前完全无法感知以太；觉醒后需要长期训练 |
| **社会结构** | 觉醒者vs普通人的鸿沟是核心矛盾。觉醒者垄断权力和资源 |

#### 历史状态（封印时期）

- **封印初期**：人类与其他种族一样，失去了所有以太记忆
- **封印中期**：人类建立了无魔法的世俗社会，依靠农业和手工业生存
- **封印后期**：人类成为大陆最繁荣的种族（因为不依赖以太）
- **当前（复苏期）**：觉醒率回升，但社会结构还停留在"无魔法"时代，导致剧烈冲突

#### 与其他种族关系

| 种族 | 关系 | 说明 |
|------|------|------|
| 兽血者 | **歧视+利用** | 视兽血者为"半魔物"，但利用其战斗力（敢死营） |
| 精灵 | **忌惮+利用** | 忌惮精灵的敏锐感知，但利用其工艺和情报 |
| 矮人 | **商业合作** | 签契约做生意，但不信任 |
| 裂谷族 | **否认存在** | 官方不承认裂谷族的存在 |

---

### 2. 兽血者（Beastblood）

> **region**: 北境、大陆中心
> **population**: 约占总人口8%
> **核心特征**: 人类与魔物的混血，身体天生强壮，有以太时进入血怒状态

#### 种族天赋：血怒

| 方面 | 说明 |
|------|------|
| **以太使用方式** | 不需要"觉醒"——身体天生就是以太容器。情绪激发时身体自动吸收以太，强化肉体能力 |
| **触发条件** | 极端情绪（愤怒、恐惧、绝望）触发"血怒"状态 |
| **无以太状态** | 身体强壮，但无血怒能力，只是比普通人类更强壮 |
| **有以太状态** | 情绪激发时进入血怒，力量、速度、反应大幅提升 |
| **优势** | 无需训练即可战斗；肉体强度远超人类；对魔物有天然威慑 |
| **劣势** | 血怒状态不可控，可能误伤友军；情绪平复后极度虚弱；被人类视为"不稳定武器" |
| **社会结构** | 无独立社会，分散在人类社会中，被帝国征召为"敢死营" |

#### 血怒的物理机制

> 兽血者的血液中混有魔物的以太残留。情绪激发时，血液中的以太活性化，流入肌肉和组织，产生强化效果。这不是"魔法"——是**生理反应**。

| 血怒阶段 | 表现 | 代价 |
|---------|------|------|
| **初怒** | 瞳孔变红，力量提升30% | 事后疲劳 |
| **深怒** | 皮肤表面出现魔纹，力量提升100% | 事后卧床数日 |
| **狂怒** | 完全失去理智，力量提升300% | 可能永久性损伤，甚至死亡 |

#### 历史状态（封印时期）

- **起源**：封印时期魔物泛滥，人类与魔物的接触导致混血后代
- **封印初期**：被视为"诅咒"，大量屠杀
- **封印中期**：帝国发现其战斗力，开始"驯化"——征召为敢死营
- **当前**：制度化歧视——兽血者不能拥有财产、不能担任官职、只能从事军事和体力劳动

#### 与其他种族关系

| 种族 | 关系 | 说明 |
|------|------|------|
| 人类 | **被压迫+复杂情感** | 恨人类的歧视，但也需要人类的庇护（没有独立社会） |
| 精灵 | **疏远** | 精灵对兽血者既不同情也不歧视——只是"又一种短寿的生物" |
| 矮人 | **尊重** | 矮人尊重兽血者的战斗力，签契约时会优先考虑 |

### 3. 精灵（Elf）

> **region**: 南方密林（艾洛萨恩）
> **population**: 约占总人口5%，持续衰退中
> **核心特征**: 感知敏锐，有以太时寿命延长，可共鸣以太流动

#### 种族天赋：共鸣

| 方面 | 说明 |
|------|------|
| **以太使用方式** | 天生感知以太流动，不需要"觉醒"。但精灵的"魔法"不是操控，是**共鸣**——与以太的自然流动协调 |
| **无以太状态** | 寿命约200岁，感知敏锐，反应快，但无法使用任何以太能力 |
| **有以太状态** | 寿命延长（可达500岁以上），可共鸣以太流动，增强或减弱自然效果 |
| **优势** | 无需觉醒；对以太的感知精度远超人类；积累深厚知识 |
| **劣势** | 可塑性差——精灵只能"共鸣"，不能"操控"，无法开发新能力；生育率极低 |
| **社会结构** | 氏族自治，无统一政府。封闭派vs参与派的永恒争论 |

#### 共鸣的物理机制

> 精灵不是"施法"——是**成为以太流动的一部分**。人类法师像"划船"（主动操控），精灵像"顺流而下"（被动共鸣）。精灵可以感知以太的细微变化，但不能改变流向。

| 共鸣层次 | 表现 |
|---------|------|
| **感知** | 感知周围以太浓度和流动方向 |
| **协调** | 与以太流动协调，增强或减弱自然效果（如让火焰更旺，或让水流更缓） |
| **预言** | 极少数精灵能感知以太的"趋势"——不是看见未来，是感知"水流的方向" |

#### 历史状态（封印时期）

- **封印初期**：与其他种族一样，失去了所有以太记忆
- **封印中期**：精灵的敏锐感知让他们在狩猎和生存中有优势，建立了密林中的氏族社会
- **封印后期**：精灵的寿命（约200岁）让他们积累了大量知识，但知识以歌谣和禁忌形式保存
- **当前（复苏期）**：精灵开始感知到以太的回归，但不知道这是什么，以为是"神迹"或"自然变化"

#### 与其他种族关系

| 种族 | 关系 | 说明 |
|------|------|------|
| 人类 | **警惕+利用** | 需要人类的商业网络，但警惕其扩张 |
| 兽血者 | **疏远** | 不同情也不歧视——"又一种短寿的生物" |
| 矮人 | **尊重** | 尊重矮人的工艺，但认为矮人"太执着于物质" |

---

### 4. 矮人（Dwarf）

> **region**: 西境高原地下（卡兹·杜姆）
> **population**: 约占总人口10%
> **核心特征**: 地质直觉强，擅长锻造，有以太时可感知结晶品质

#### 种族天赋：深掘

| 方面 | 说明 |
|------|------|
| **以太使用方式** | 矮人不能"施法"——但他们是**以太结晶的专家**。能感知结晶的品质、纯度、稳定性 |
| **无以太状态** | 地质直觉强，擅长锻造和采矿，但不知道什么是"以太结晶"，只当是"特殊的石头" |
| **有以太状态** | 可感知结晶的品质和纯度，能加工以太设备，制造魔法物品 |
| **优势** | 结晶开采和加工能力大陆第一；对以太设备的制造有天然直觉；寿命约150年 |
| **劣势** | 完全无法操控以太（不能施法）；依赖地面贸易获取食物 |
| **社会结构** | 各城邦独立，契约联结。传统派（封闭）vs开放派（与人类贸易） |

#### 深掘的物理机制

> 矮人的"天赋"不是魔法——是**地质直觉**。他们能感知地脉的走向、结晶的形成过程、矿脉的品质。这种直觉让他们成为最好的矿工和工匠。

| 深掘层次 | 表现 |
|---------|------|
| **探矿** | 感知地下矿脉的位置和品质 |
| **加工** | 将 raw 结晶加工成稳定的能源核心 |
| **锻造** | 将结晶核心融入金属，制造魔法物品 |

#### 历史状态（封印时期）

- **封印初期**：与其他种族一样，失去了所有以太记忆
- **封印中期**：矮人凭借地质直觉和锻造技术，在地下建立了繁荣的城邦
- **封印后期**：与人类建立贸易关系，用金属制品换取食物和物资
- **当前**：卡兹·杜姆是大陆最重要的矿产产地，矮人的经济地位上升，但政治地位仍受制于地面势力

#### 与其他种族关系

| 种族 | 关系 | 说明 |
|------|------|------|
| 人类 | **商业合作** | 签契约做生意，但不信任人类的政治承诺 |
| 精灵 | **尊重+疏远** | 尊重精灵的知识，但认为精灵"太抽象" |
| 兽血者 | **尊重** | 尊重兽血者的战斗力，签契约时会优先考虑 |

## 三、种族与以太使用方式对比

| 种族 | 使用方式 | 需要觉醒？ | 可塑性 | 无以太状态 | 有以太状态 |
|------|---------|-----------|--------|-----------|-----------|
| **人类** | 操控（主动施法） | **必须觉醒** | 高 | 完全无感知 | 觉醒后可操控以太 |
| **兽血者** | 血怒（生理反应） | 不需要 | 低 | 身体强壮 | 情绪激发进入血怒 |
| **精灵** | 共鸣（被动协调） | 不需要 | 低 | 寿命约200岁，感知敏锐 | 寿命延长，可共鸣以太 |
| **矮人** | 深掘（结晶加工） | 不需要 | 中 | 地质直觉强，擅长锻造 | 可感知结晶品质 |

## 四、写作检查清单

每章涉及种族时自检：

1. **种族天赋是否影响日常？** 精灵的丝绸不皱、兽血者的体温偏高、矮人的手掌有结晶粉尘
2. **种族关系是否写结构不写情绪？** 不是"精灵讨厌人类"，是"精灵需要人类的商业网络，但警惕其扩张"
3. **种族历史是否影响当前行为？** 兽血者的顺从不是因为懦弱，是因为没有独立社会
4. **种族差异是否写信息差？** 精灵知道封印的真相，但用歌谣形式保存，连精灵自己都不完全懂
5. **是否有纯善纯恶的种族？** 每个种族有自己的逻辑，没有纯善纯恶
