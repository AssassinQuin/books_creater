# 魔物体系


> **条目名**：魔物体系

## 概览

- **region**: 全域
- **writing_guide**: 魔物是野生动物不是副本怪。写豸像写鼠群——恶心但不太危险。写牙像写虎——强但可以对付。写角像写另一群人——聪明、有计划、不好惹。写鳞写它改变一整片区域的能力。写厄只存在于传说和恐惧中。不写等级数字，写它对周围的影响——空气变热、地面结霜、低阶兽臣服。读者通过感受理解威胁级别。术语用'觉醒者'不用'法师'。

## 详细设定

### 定义

魔物是以太生态的一部分。它们栖息在高浓度区，消耗以太维生，死后凝结出魔核（低品质结晶）。不是异界入侵者——是本土生态链的一环。像野兽一样——有领地、有食性、有行为模式。不是怪物=邪恶。

### 核心逻辑

豸被动吸收→牙主动摄取→角以太循环→鳞晶体即本体→厄它就是以太。觉醒者靠悟驾驭以太，魔物靠肉体和本能吞噬以太。同一源头，殊途。

### 分阶

#### 豸（原尘级）

虫鼠蛇蝎大小的低等魔物。单个不危险但成群致命。城镇下水道和矿洞里常见。公会的'清理委托'主要对象。

| 维度 | 表现 |
|------|------|
| aether | 被动吸收，像呼吸一样自然摄入微量以太 |
| aether_change | 晶芽在体内萌芽，元素微弱溢出体表——火豸体温偏高，冰豸爬过留霜痕 |
| magic_use | 不会施法。元素溢出是被动现象不是主动使用。咬和抓还是物理攻击 |
| innate | 繁殖快，对以太浓度敏感——浓度一升就疯狂繁殖。单只弱，数量一多比牙还危险 |
| 威胁等级 | 巡逻日常清理 |

#### 牙（原铁级）

狼/熊/大型爬行类大小的中型魔物。有领地意识，会主动攻击入侵者。荒野和荒野外围常见。低级冒险者的主要目标。

| 维度 | 表现 |
|------|------|
| aether | 主动摄取，会寻找以太浓度高的区域进食和栖息 |
| aether_change | 晶核成形，元素渗透进攻击器官——獠牙带火、利爪附冰、尾部蓄雷 |
| magic_use | 本能释放元素。不是施法，是把元素集中在攻击部位打出去——一次撕咬就是一次元素爆发 |
| innate | 狩猎智能——伏击、包抄、诱敌。能感知觉醒者的以太波动并针对性回避或进攻 |
| 威胁等级 | 需要驻防觉醒者，城墙有意义 |

#### 角（原渊级）

人形或更大的高等魔物。有明确智力——能使用策略、设陷阱、指挥低等魔物。裂谷深处和高浓度核心区才有。不是'boss'——是这片区域的顶级掠食者。铁脊敢死营的主要死因。

| 维度 | 表现 |
|------|------|
| aether | 晶核与外部以太开始共振，形成以太循环——吸收→晶体→释放→再吸收 |
| aether_change | 元素渗透全身——皮肤骨骼血液都含元素。体型剧增，角/甲/壳是晶体外化的标志 |
| magic_use | 能主动操控周围元素——不只是打出去，能在范围内调动。火系角兽让周围空气燃烧，冰系让地面结霜蔓延 |
| innate | 领域本能——占据地盘后改变当地以太分布，让领域内适合自己不适合其他。低阶兽自动臣服或逃离 |
| 威胁等级 | 整片区域变成无人区 |

#### 鳞（原灾级）

极端稀有的超大型魔物。传说级存在——鳞级出现意味着整个区域要撤离。上一次封印前鳞级遍地走，现在几乎绝迹——但复苏可能唤醒沉睡的鳞级。

| 维度 | 表现 |
|------|------|
| aether | 晶体主导身体，不再是兽体内有晶而是晶体长成了兽。两者难以区分 |
| aether_change | 全身覆盖元素结晶化的鳞甲。呼吸、移动、存在本身都在释放元素能量。周围以太被它牵引 |
| magic_use | 没有施法的概念了。每一个动作都是魔法——跺脚地震，呼吸烈焰，目光所及冰封 |
| innate | 统御低阶兽——通过以太共振控制范围内的豸、牙、甚至角。兽群的指挥中枢，驱赶迁徙就是魔潮 |
| 威胁等级 | 城市级威胁，觉醒者军出动 |

#### 厄

它就是以太。现代人只存在于传说和恐惧中——封印前的厄兽是古人应对以太的原因之一。

| 维度 | 表现 |
|------|------|
| aether | 它就是以太。晶体=本体=以太的凝结态生命。周围以太因它的存在而改变分布 |
| aether_change | 不是以太改变了它，是它的存在改变了以太本身。所在之处以太浓度暴涨或扭曲，规则被本能重写 |
| magic_use | 没有使用的概念。它存在，世界就变形。它苏醒，方圆百里改写 |
| innate | 一切。它的本能就是法则 |
| 威胁等级 | 传说，现代人无法应对 |

### 生长阶段

每个级别内有生长阶段：幼生→成长→成熟→巅峰

### 元素独立

元素属性独立于级别。火系豸和冰系角是完全不同维度的威胁。

### 魔潮

潮兽（鳞级）驱赶兽群→大量牙和角被裹挟迁徙→形成魔潮。厄兽苏醒直接引发超级魔潮。魔潮不是自然灾害，是高阶魔物的行为后果。

### 魔物素材

魔物死后体内的以太凝结为魔核（品质低于天然结晶但有用途）。魔物素材是重要的经济来源：皮甲/骨骼/毒液/内脏各有用途。经验丰富的工匠擅长加工魔物素材。

### 荒野生态

裂谷不是空的洞穴——是有生态的地下世界。豸在最外层吃残渣，牙在中层捕猎，角在深层称王。食物链清晰。裂谷越深以太浓度越高→魔物越强→产出越好→风险越大。这是冒险者公会的整个商业模式的基础。

### 写作铁律

- 写魔物像写野生动物不写游戏怪物
- 豸级写数量和恶心
- 牙级写力量和速度
- 角级写智慧和压迫感
- 鳞级写它改变一整片区域的能力
- 厄级不存在于当下故事里——只存在于传说和恐惧中
- 写魔物战斗写血肉和恐惧，不写'对XX造成YY点伤害'
