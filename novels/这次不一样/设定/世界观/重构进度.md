### Step 2：创作宪法（5条铁律）✅ → DB:世界原则

1. **力量导致毁灭，毁灭催生控制**：史前高阶法师零和博弈→一致封印以太
2. **控制是理想主义的异化**：他们是一群理想者，以平衡为名维持脆弱和平
3. **循环是结构，不是命运**：封印→复苏→混乱→再封印，但这次可以不一样
4. **觉醒是运气，但选择是人做的**：不是天赋异禀成为英雄，是选择了站出来
5. **底层是缓冲垫，也是改变的力量**：写活着的日常不写可怜，写冷漠不写邪恶

### Step 4：氛围DNA ✅ → DB:三层

#### Layer 1 道德层 ✅

- 暗黑：世界不安全，魔潮随时吞没镇子
- 残酷：法师和平民两个世界，不是恶意是无视
- 含蓄：不直接说教，用灰雪、灯光、拾荒者的手指传递
- 历史厚重：几千年不是数字，是冻土下的骨骼

#### Layer 2 感官层 ✅

- 关键词：冷、荒、奇幻宏大、魔潮危险、法师蔑视
- 核心理念：只给感官不给答案，世界在运转没人讲解
- 多种族活在日常，神秘的不是设定是这世界本就没人懂
- 荒不是形容词，是几百里冻土、不回来的路、绕回原地的光

#### Layer 3 禁忌+词汇 ✅

- 解释藏在日常里，时候不到不点破
- 禁止东方修仙词（灵力/修炼/丹药/经脉）
- 禁止AI味（默默/不禁/嘴角微扬/眼中闪过）
- 世界词汇锚定：以太/觉醒/法师/魔潮/以太结晶/拾荒者/塔/灯

### Step 5：能力体系 ✅ → DB:ability

#### 核心驱动：以太

以太弥漫世界，浓度不均，决定一切。

#### 觉醒

- **完全随机**。能感受到不同以太，自己能够操控，形成自己的能力。
- 觉醒率：史前70-80% → 封印后<5% → 当前**20%（临界点，冲突最大化）** → 复苏中逐年上升
- 高浓度区域+特殊条件可以提高概率（花钱买运气）

#### 元素亲和

- 全职法师框架：元素系 + 白魔法 + 黑魔法 + 次元系
- 同元素不同开发方向（参考海贼王）
- 觉醒时可感知对应属性以太

#### 学习

- 可教：有学院、师傅、教材（参考无职转生）
- 进阶走多远 → **天赋**强相关（参考将夜）
- 同阶级内实力强弱 → **天赋+努力**

#### 进阶

- 积累+悟（参考将夜）。不是等级，是理解深度。
- 二次觉醒：环境+天赋随机触发，可能获得第二种亲和。

#### 限制

- 施法消耗精神力+以太
- 体内以太总量有上限
- 被打断就失败

#### 没有

- 无法力值/MP，无技能树，无等级系统，无升级动画，无禁咒概念，无走火入魔

#### 以太结晶

- 所有觉醒生物体内都有（法师、魔兽、其他觉醒种族）
- 按元素属性分类
- 功能：修炼资源、回复以太消耗、硬通货、材料/能源
- 阶级越高品质越好，法师死后留存——强者可能被猎杀取结晶

### Step 5：魔法质感-施法与进阶 ✅ → DB:core_setting

#### 核心模型：将夜式理解深度 + 诡秘式存在跃迁 + 全职法师元素体系

| 维度 | 设定 |
|------|------|
| **魔法来源** | 体内以太核心（胸腔器官，觉醒时形成）+ 对外界以太的感知 |
| **施法方式** | 冥修积累 → 理解元素本质 → 以意驭能 → 释放 |
| **进阶机制** | 不是等级，是理解深度。从人到非人的存在跃迁 |
| **以太浓度** | 只影响天花板（能修炼到的最高层次），不影响日常施法 |
| **可逆性** | 可逆。重伤、超负荷、核心受损可导致境界跌落 |

#### 境界名称（西幻+从人到神）

| 境界 | 英文 | 核心变化 |
|------|------|---------|
| **觉醒** | Awakening | 形成以太核心，感知对应元素 |
| **洞见** | Insight | 理解元素本质，施法效率质变 |
| **精通** | Mastery | 自如操控，可驱动异属性以太 |
| **超凡** | Transcendence | 存在方式改变，看到以太流动如实体 |
| **升华** | Ascension | 触及规则，可改变局部以太浓度。**非人** |

#### 跨元素能力

精通以上可驱动外界异属性以太，实现跨元素能力。不是"学会了水魔法"，是"理解了能量本质，知道如何让水以太响应"。

#### 跌落的质感

> "他曾经'看到'以太流动如河流。现在，他只能'感受'到模糊的温暖。他知道河流还在那里，但他看不到了。这种失落，像色盲者曾经看过颜色。"
