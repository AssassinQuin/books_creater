### Step 2：创作宪法（5条铁律）→ [世界原则.md](核心设定/世界原则.md) v2.0

> 已根据后续势力/经济/能力体系精确校准。每条原则新增：叙事线对应、势力张力矩阵、写作检查清单。

1. **力量导致毁灭，毁灭催生控制**：史前觉醒率70-80%，升华者战斗是行走的天灾→零和博弈→封印以太。帝国登记制、赫斯珀里迪斯维护封印，都源于对毁灭的恐惧。
2. **控制是理想主义的异化**：赫斯珀里迪斯创始人从古籍残片中拼凑出循环真相，以"平衡"之名管理世界。他们不是传承自史前文明——是自己在黑暗中摸索出来的。
3. **循环是结构，不是命运——但结构可以被打破**：封印→复苏→混乱→再封印已发生多次，每次代价是一个文明的毁灭。主角团推动魔法技术民主化，是比"推翻"更根本的改变。
4. **觉醒是运气，但选择是人做的**：觉醒率20%完全随机，但觉醒只是起点——有人效忠帝国，有人加入逆流兄弟会，有人隐藏能力做普通人。男二的感染力在于"做了选择"。
5. **底层是缓冲垫，也是改变的力量**：帝国征召制把平民当炮灰，拾荒者是城墙外的"缓冲垫"。改变来自技术扩散：当普通人也能用魔法物品，缓冲垫就有了牙齿。

### Step 4：氛围DNA → [氛围DNA.md](核心设定/氛围DNA.md) v2.0

> 已根据势力/经济/日常生活精确校准。感官层按地区分化，新增势力对应设定注释。

**Layer 1 道德层**
- 暗黑：世界不安全。帝国北方贵族区有塔灯预警，平民区没有——等平民看到魔潮时已经跑不掉了。
- 残酷：贵族不是恨平民，是看不见。一个帝国法官可能一辈子没踏足过城墙外的拾荒者营地。
- 含蓄：男二挡在魔潮前，不写"他眼中燃烧着正义之火"，写"他挡在那里，因为后面的人还没跑完"。
- 历史厚重：黑林子的树没人知道为什么叶子是黑的。赫斯珀里迪斯的古籍残片没人能完全读懂。

**Layer 2 感官层（按地区分化）**
- 瓦尔德帝国：等级、秩序、压抑——紫色丝绸、石板路马蹄声、觉醒者过街时低头的行人
- 里萨兰提亚：混乱、活力、盐味——五种语言叫骂、三种货币流通、鱼腥味混着香料味
- 斯卡迪亚：冷、荒、寂静——灰雪不化、地行蜥车辙、黑林子叶子不落
- 卡兹·杜姆：金属、火焰、地下——锤声回荡、结晶矿脉幽光、矮人拒收帝国钱币（"以太味儿脏"）
- 艾洛萨恩：古老、疏离、完美——精灵丝绸不皱、精灵文招牌让人突然失忆、精灵不来人类镇子
- 城墙外：脏、活、危险——炊烟混着腐烂味、魔兽骨头交易、没有塔灯预警的黑暗

**Layer 3 禁忌+词汇（精确版）**
- 叙事禁忌：不写设定说明文、不美化苦难、不统一善恶、不用"世界"做主语
- 禁止词：东方修仙词（灵力/修炼/丹药/经脉）、游戏化（蓝条/buff）、AI味（默默/嘴角微扬）
- 世界词汇锚定：以太/觉醒/法师/魔潮/以太结晶/拾荒者/塔灯/以意驭能/理解深度

## 二、能力体系（已完成）→ [能力体系.md](能力体系/能力体系.md)

### 核心驱动：以太

以太弥漫世界，浓度不均，决定一切。

**觉醒**
- **完全随机**。能感受到不同以太，自己能够操控，形成自己的能力。
- 觉醒率：史前70-80% → 封印后<5% → 当前**20%（临界点，冲突最大化）** → 复苏中逐年上升
- 高浓度区域+特殊条件可以提高概率（花钱买运气）

**元素亲和**
- 全职法师框架：元素系 + 白魔法 + 黑魔法 + 次元系
- 同元素不同开发方向（参考海贼王）
- 觉醒时可感知对应属性以太

**学习**
- 可教：有学院、师傅、教材（参考无职转生）
- 进阶走多远 → **天赋**强相关（参考将夜）
- 同阶级内实力强弱 → **天赋+努力**

**限制**
- 施法消耗精神力+以太
- 体内以太总量有上限
- 被打断就失败

**没有**：法力值/MP，技能树，等级系统，升级动画，禁咒概念，走火入魔

**以太结晶**
- 所有觉醒生物体内都有（法师、魔兽、其他觉醒种族）
- 按元素属性分类；功能：修炼资源、回复以太消耗、硬通货、材料/能源
- 阶级越高品质越好，法师死后留存——强者可能被猎杀取结晶

### 魔法质感-施法与进阶

**核心模型**：将夜式理解深度 + 诡秘式存在跃迁 + 全职法师元素体系

| 维度 | 设定 |
|------|------|
| **魔法来源** | 体内以太核心（胸腔器官，觉醒时形成）+ 对外界以太的感知 |
| **施法方式** | 冥修积累 → 理解元素本质 → 以意驭能 → 释放 |
| **进阶机制** | 不是等级，是理解深度。从人到非人的存在跃迁 |
| **以太浓度** | 只影响天花板（能修炼到的最高层次），不影响日常施法 |
| **可逆性** | 可逆。重伤、超负荷、核心受损可导致境界跌落 |

**境界名称（西幻+从人到神）**

| 境界 | 英文 | 核心变化 |
|------|------|---------|
| **觉醒** | Awakening | 形成以太核心，感知对应元素 |
| **洞见** | Insight | 理解元素本质，施法效率质变 |
| **精通** | Mastery | 自如操控，可驱动异属性以太 |
| **超凡** | Transcendence | 存在方式改变，看到以太流动如实体 |
| **升华** | Ascension | 触及规则，可改变局部以太浓度。**非人** |

**跨元素能力**：精通以上可驱动外界异属性以太，不是"学会了水魔法"，是"理解了能量本质，知道如何让水以太响应"。

**跌落的质感**："他曾经'看到'以太流动如河流。现在，他只能'感受'到模糊的温暖。他知道河流还在那里，但他看不到了。这种失落，像色盲者曾经看过颜色。"
