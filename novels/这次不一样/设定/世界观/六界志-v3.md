# 六界志 v3（世界观细化 + 和谐共存引擎）

> 用户方向（2026-07-28）：六界内容太薄、世界感差、各界文化应不同、男主如何让六界和谐共存没展示。本文件补这块地基——每界深做 + 共存引擎。
> 严咬合：`重构总纲-v3.md` §四（六界全活）/ `仙侠世界观基底.md`（天道/灵气/六族/境界）/ `势力/总览.md`（势力格局）/ `深度人物设计.md`。
> 用途：卷级总纲/细纲的**世界素材库 + 共存进度脊梁**——几百章的支线/场景/文化都从这里长。

---

## 〇、设计总则

1. **六界各活·各有性格**：不是六个刷怪场，是六种文明——各有文化基调/社会结构/价值观/内部矛盾/美学。男主闯进去是变量，不是它们的"目的"。
2. **每界一个"共存障碍"（伤口）**：六界不能共存，是因为每界都有一个具体的伤口（血脉论/灭妖信仰/不介入/唯力/盲从/操盘循环）。**男主建和邦的过程 = 逐界治愈这些伤口**。
3. **共存引擎 = 治愈模型的外推**：男主不靠力量征服，靠"被治愈的经历+灵觉感知(看真心)+迪化塑造本体的具现(联结)"解开每界的伤口。**建国是治愈的果实**（v3 内核）。
4. **和邦 = 五族共和（神族除外）**：神界是循环操盘者，不被吸纳，是被"化解"（终幕）。其余五界（妖/人/鬼/魔/仙）逐卷加入和邦。

> ⚙️ **中界地理详写**（玄黄大陆三界方位布局 / 人界诸国+太一宗+周临前线 / 妖界妖王会盟+八妖王领地水平分布+地灵族遗址 / 魔界魔宫割据 / 妖灵密林内部结构 / 魔界裂空带 / 陆离跨界商道主路线 / 天然天堑）：见 `设定/世界观/世界运转机理.md` §二。本文件保留各界**文化基调 + 共存引擎**（各界风物地理小节只列文化场景库，具体方位/路线/地图感以机理文件为准）。

## 一、妖界（密林 + 会盟 · 起家地）

### 文化基调
**血脉崇拜 + 部族共生**。妖族不修文字，修血脉——天赋神通刻在血脉里，部族以血脉天赋立身。气质：野性、直接、重诺、记仇、热闹。妖族不讲客套，认死理（锤伯"料不能浪费"就是妖族式的认死理）。

### 风物地理
- **妖灵密林**（边缘·人妖交汇·男主转生+建国地）：两界交汇的原始密林，灵气浓郁成雾，古树通灵，兽踪遍地。多族混居的混乱地带——六界大战的传统战场之一，也是逃亡者/流亡者的避难所。
- **妖王会盟深处**（议事场·八妖王领地）：八妖王各带血脉天赋的地盘（白虎族雪原/九尾狐幻境/龙族遗脉深潭等），议事场是议会不是朝廷。
- **地灵族聚居地**（锤伯的炼器铺所在）：地灵族是妖界最"老实"的一脉——匠人，靠炼器立身，不参与妖王博弈，故被厄枭灭族（弱肉强食的牺牲品）。

### 社会结构
**部族制 + 妖王会盟议会**。部族内部讲义气（同族不弃）；妖王会盟是强议会弱（八妖王议而不决，各有心思）。强者为尊但部族内重情。

### 价值观与信仰
- **血脉纯粹 = 高贵；杂血/凡身 = 低贱**（男主凡身最弱 = 血脉论最底层，**最大反差**）
- **记仇**：灭族之仇必报（锤伯↔厄枭、小牙↔周临血仇）
- **部族共生**：同族互助，但跨族戒备

### 内部矛盾（生故事的地方）
1. 八妖王割据无统一顶级 → 人族猎妖取灵石（外部压力的根源）
2. 血脉论歧视：杂血/弱族（地灵族/灵狸族）受压 → 男主凡身崛起打破血脉论
3. 妖王会盟四派博弈：平衡派（昼）/ 野心派（厄枭·外势力潜伏）/ 投机派（紫蘅·弱族生存）/ 潜伏者（戌迦·神族眼线）
4. 部族间旧怨（灵狸族vs牙狼族等的世仇）

### 关键地点（场景库）
妖灵密林边缘（男主转生地）/ 锤伯炼器铺（治愈种子地）/ 妖王会盟议事场 / 白虎族雪原（昼的领地）/ 九尾狐幻境（紫蘅的领地）/ 地灵族遗址（锤伯灭族现场·V4-V5 复仇地）

### 代表 + native 配角
- 代表：锤伯/小牙/小曜/昼/紫蘅/厄枭/戌迦
- native（待 V1-V5 中文化命名）：灵狸族长（小牙父辈）/ 牙狼王 / 猪头大帝 / 大鬼酋长 / 诸部首领 / 八妖王其他成员

### 共存障碍（伤口）
**血脉论 + 对人族的仇恨**（人族猎妖取灵石）→ 妖族不信人族，也跨族戒备。

### 男主的解法（机制）
- 转生妖族（站在妖这边·获得信任前提）
- 灵觉感知听见真心（绕过血脉论看个体——"血脉不重要，你是谁才重要"）
- 建和邦用**地灵族师徒传承模式**（锤伯传匠心给男主）扩展为五族共和——传承不分血脉，认材料/认人
- **打破血脉论**：男主凡身最弱却成妖圣 = 活着的反证

### 可生支线（密度素材）
诸部求存（灵狸族被人族猎·V1-V3 收编线）/ 八妖王博弈（V4-V5）/ 锤伯灭族之谜（V1 埋·V4-V5 回收）/ 血脉论歧视的渐进打破 / 地灵族古法传承（师徒制展开）/ 部族世仇调解（和邦的种田日常）

## 二、人界（正道 + 商修 · 周临场域）

### 文化基调
**秩序 + 信仰 + 利益**。人族修文字、修宗门——传承靠师徒+典籍。气质：讲规矩、重传承、繁华、但伪善（信仰被利用）。城池烟火气 + 宗门清肃 + 商道交错。

### 风物地理
- **凡俗界**：皇朝城池、金银交易、市井烟火（男主前世的现代记忆与此对照）
- **修士界**：太一宗山门（正道第一宗）、正道诸国、灵石商道
- **人妖边城**（V2 舞台）：人妖交汇的边城，正道/商修/妖族混处，最混乱也最自由

### 社会结构
**皇朝 + 宗门（太一宗）+ 商会（跨界商修网络）**。王权 vs 教权（宗门）的张力是人界主线。商修是跨界粘合剂。

### 价值观与信仰
- **灭妖除魔 = 天道**（太一宗旗帜·实为神族意志 F16·讽刺结构）
- **正道传承 = 正统**（师徒/典籍/宗门）
- **商修重利**（但自由商会重人·商离）

### 内部矛盾
1. 太一宗三派：激进派（玄冥·掌异端审问官）/ 温和派（温故被逐）/ 动摇者（周临）
2. 皇朝被仙化（正道诸国盟主被夺舍）
3. 正道伪善（灭妖实为神族意志·人族被当枪使）
4. 商修网络分裂（商会总会中立 vs 自由商会倾向男主）
5. 王权 vs 教权（皇朝与太一宗的权力博弈）

### 关键地点
太一宗山门 / 正道诸国前线（周临战场）/ 人妖边城（V2）/ 商会总会 / 皇朝王城（被仙化的盟主所在）

### 代表 + native 配角
- 代表：周临/陆离/温故/商离/莘奴/玄冥/薛恒
- native：太一宗宗主 / 正道诸国盟主（被仙化）/ 异端审问官群体 / 老猎师（V1 灭妖队相关）/ 商会总会会长 / 皇朝王室温和派

### 共存障碍（伤口）
**"灭妖是天道"信仰 + 猎妖取灵石的经济依赖** → 人族视妖为敌/为资源，"人妖必敌"是刻板信仰。

### 男主的解法
- **温故**（"不杀妖的人族"代表·V1 救男主埋因）打破"人妖必敌"的第一道口子
- 男主救人族（温故/陆离/莘奴转化）→ 和邦人族代表证明人妖可共存
- 终极：揭"灭妖之道实为神族操纵"(F16) 让人族信仰崩塌重建（玄冥塌陷是信号）
- **周临**（人族最强）终局接纳妖圣男主 = 人族对妖族最大的和解象征

### 可生支线
异端审问官黑幕（V2-V3·V8 自爆）/ 商修灵石暗战（陆离/商离线）/ 周临前线苦撑（远方暗线）/ 温故被逐之谜 / 玄冥信念崩塌（V8）/ 王权 vs 教权博弈 / 被仙化盟主之谜

## 三、冥界（冥府渡口 · 鬼族）

### 文化基调
**秩序 + 公平 + 宿命**。鬼族修判官秩序——审亡魂执念。气质：冷静、公正、被动、肃穆、但不堪重负。冥府是六界最"老成"的运转机构，几万年没变过。

### 风物地理
- **冥府渡口**：黄泉路、判官衙门、执念狱、轮回渡口。幽暗、肃穆、无尽亡魂排队。
- **幽冥族故乡**（铁岚出身·已毁）：曾被厄枭势力扫荡，遗民流散。

### 社会结构
**判官秩序**：判官审亡魂（执念重入执念狱反复磨·轻者入轮回）。鬼修（幽冥族一脉）认主本能强（铁岚"两百年见到的第一个不会变的主君"）。

### 价值观与信仰
- **公平**（每个亡魂都要审·不可糊弄）
- **秩序**（轮回不可乱·生死有账）
- **被动中立**（冥府不介入活人世事·几万年的规矩）

### 内部矛盾
1. 六界大战积下海量亡魂·冥府不堪重负（运转过载）
2. 天庭先锋试探/强征亡魂做军力（破坏轮回秩序·V6-V8 升级）
3. 判官秩序被动·无力主动反抗天庭
4. 亡魂账被篡改（天庭掩盖死亡真相·支线13）

### 关键地点
冥府渡口 / 判官衙门（冥所在）/ 执念狱 / 轮回渡口 / 幽冥族故乡遗址 / 亡魂账库

### 代表 + native 配角
- 代表：铁岚/冥
- native：判官群体（冥的同僚）/ 幽冥族遗民 / 亡魂（个别有戏的战死者执念）

### 共存障碍（伤口）
**被动中立 + 轮回秩序封闭** → 鬼族不介入世事、不信活人、不结盟。

### 男主的解法
- **铁岚**（前厄枭副官·弑主·流浪→和邦军事长）打破"鬼族不介入"——她找到"不变形的主君"
- 冥府被天庭逼迫后**主动**站和邦（冥带判官群体·V7）——被动者被逼主动
- 锤伯本源在冥府（情感戏·男主再见锤伯残念·F20）= 鬼族与男主的情感纽带
- 和邦鬼族代表证明：鬼族也能在共和里有一席（冥的判官秩序成为和邦的司法维度）

### 可生支线
冥府亡魂账（V7-V8 揭天庭篡改）/ 铁岚弑主之谜（V3 揭·与锤伯灭族同源）/ 锤伯本源在冥府（情感戏）/ 天庭强征亡魂（V6-V8）/ 判官秩序 vs 天庭越权 / 战死者执念（个别亡魂的小故事）

## 四、魔界（魔宫 · 割据山河）

### 文化基调
**力量 + 野心 + 焦虑**。魔族修魔速成——业力重、天劫先劈。气质：急躁、野心、狼狈、强者为尊、但有自己的荣耀观（力量背后的代价）。魔族活得最焦虑——速成的代价是天天怕天劫。

### 风物地理
- **魔宫**（不是一座宫·是大能割据的山河）：每个魔尊占一座山头，山头间常年打架/合纵/背叛。魔气弥漫（灵气被业力污染的形态），天空常裂（天劫随机劈）。
- 江烬的山头（堕落场域·白金剑气与魔气交缠）/ 阿檀流亡路线（魔界边缘·逃出魔宫的路）

### 社会结构
**魔尊割据（山头制）**：合纵连横，强者为尊，弱肉强食。无统一——每个魔尊是自己的王。

### 价值观与信仰
- **力量 = 一切**（弱者无话语权）
- **业力是代价**（修魔速成但天劫劈·魔族的集体原罪）
- **野心**（怕被支配所以先支配·厄枭逻辑）

### 内部矛盾
1. 魔尊割据内战（合纵连横·V6 江烬登场场域）
2. 业力累积·天劫首当其冲（魔族的生存焦虑）
3. 四条路线拉扯：野心扩张（厄枭·跨界潜伏妖界）/ 堕落报复（江烬）/ 流亡逃避（阿檀·第三条路）/ 少壮继承（墨渊）
4. 魔族被天庭利用（V8 江烬被欺骗·魔宫成天庭棋子）

### 关键地点
魔宫割据山河 / 江烬山头 / 阿檀流亡路线 / 墨渊成长地 / 魔界天劫裂空处

### 代表 + native 配角
- 代表：江烬（主题承载型）/ 厄枭 / 阿檀 / 墨渊
- native：各魔尊（割据者·合纵连横的玩家）/ 魔族流亡者群体

### 共存障碍（伤口）
**只信力量 + 业力重（被天道 reject）** → 魔族不信善意、只信力量，且自认不被天地接纳。

### 男主的解法
- **江烬**（上代人族强者堕落=善被打碎的样本）→ 男主"凭什么不堕落"（治愈 vs 力量的辩论）→ 终幕江烬执念被迪化第四阶段·法则级化解（非杀戮·以善化解力量逻辑）
- **阿檀/墨渊**（魔族流亡+继承善）→ 和邦魔族代表证明：魔族也有第三条路（不野心不堕落·共建）
- 男主不靠力量征服魔族——靠证明"善不被打碎"（江烬镜像的反面例证）

### 可生支线
魔宫割据内战（V6）/ 江烬堕落真相（V6 揭）/ 阿檀流亡（V3-V4）/ 墨渊师徒情悲剧弧（V6-V8）/ 厄枭跨界潜伏妖界 / 魔族天劫焦虑（世界观日常）

## 五、仙界（仙宗联盟 · 飞升所在）

### 文化基调
**清修 + 记录 + 盲从**。仙修飞升所在——讲究清修记录、与天庭关系复杂。气质：清高、记录、高高在上、但盲从（给天庭背书）。仙界是六界最"体面"的，也是最伪善的（清修之名行背书之实）。

### 风物地理
- **云海之上·仙宗连绵山门**：灵气清冽，云海苍茫，仙宗山门隐于云中。
- **飞升台**（失踪发生地·F18 关键）：仙修飞升的圣台，实为天庭吸收仙修的陷阱。
- **灵族聚居地**（砚青故乡）：天地灵气孕育的灵识种族，活得长、看得多、是仙界原生记事者。

### 社会结构
**仙宗联盟**（管仙界但管得松）+ 老成派（跟天庭紧）vs 少壮派（质疑）。灵族是独立的"记事者"群体，不属仙宗。

### 价值观与信仰
- **清修记录 = 使命**（灵族800年记录·砚青流派）
- **代天道清洗 = 背书**（名义替天行道·实给天庭背书·伪善）
- **飞升 = 终极目标**（但飞升失踪是秘密·F18）

### 内部矛盾
1. 老成派 vs 少壮派（对天庭的态度分裂）
2. 飞升失踪真相（天庭吸收仙修用于复活·F18·穿插仙界卷核心）
3. 仙宗"代天道清洗"实为给天庭背书（伪善·与人界太一宗呼应）
4. 灵族800年记录的真相（砚青记了什么·F12 关联）

### 关键地点
仙宗联盟山门 / 飞升台（失踪地）/ 灵族聚居地（砚青故乡）/ 沈砚飞升前师门 / 仙界云海秘境

### 代表 + native 配角
- 代表：砚青/沈砚/青玄
- native：仙宗老成派首领 / 少壮派首领 / 灵族记录者群体 / 飞升台守者

### 共存障碍（伤口）
**清修不介入 + 盲从天庭** → 仙修不质疑秩序、高高在上、不与"下界"共和。

### 男主的解法
- **砚青**（800年记录者·首次干预·和邦史官）打破"仙界不介入"——800年记录者破例下场
- **沈砚**（飞升剑仙·从仙界传信质疑）→ 穿插仙界卷揭飞升失踪真相 → 仙界少壮派觉醒
- 和邦仙族代表 + 仙界少壮派加入 → 证明仙界也能质疑天庭、共建共和
- 砚青成为和邦的"史官+文化长"——仙界的记录使命转化为和邦的文化维度

### 可生支线

## 六、神界（天庭遗址 · 终局对手）

### 文化基调
**永恒 + 执念 + 废墟**。始原仙神居所——天道化身消失后的遗址。气质：古老、不死、执念深重、是废墟不是文明。神界没有"社会"，只剩几个执念不死的始原仙神和他们操纵的棋子。

### 风物地理
- **天外废墟**（不在云端·在天外）：远古法则碎片撑起的废墟，星序像河一样缓慢流转，每颗"星"是一个沉睡的仙神，半毁法则阵纹遍布。
- **不老宫殿**（昊玄殁殃所在）：没有时间的宫殿，两人不老不死，靠"代天道清洗"维持存在意义。
- **复活仪式阵**（终幕舞台）：复活天道化身的阵法。

### 社会结构
**始原仙神（昊玄殁殃为首）+ 天庭先锋（薛恒等被仙化的执行者）+ 潜伏眼线（戌迦）**。无社会——只剩执念链。

### 价值观与信仰
- **完成被中断的创世使命**（复活天道化身·昊玄执念）
- **代天道清洗**（维持存在意义·殁殃复仇式）
- **被舍弃的付出**（执念根源 F18·天道化身消失后他们被舍弃）

### 内部矛盾
1. 昊玄（执念复活·安静）vs 殁殃（更激进·复仇）的路线差
2. 天庭先锋的代理人局限（不能直接下界·靠仙化夺舍）
3. 戌迦万年潜伏的"戏假情真"（任务 vs 情感）
4. 薛恒/天枢的觉醒悬念（被夺舍者残存的人）

### 关键地点
天庭遗址（终幕舞台）/ 星序（昊玄殁殃沉睡处）/ 复活仪式阵 / 仙化之源（制造夺舍的地方）

### 代表 + native 配角
- 代表：昊玄/殁殃/薛恒/戌迦/天枢
- native：始原仙神群体（沉睡者）/ 天庭先锋军

### 共存障碍（伤口）
**执念操盘循环** → 神界是六界大战循环的操盘者，它的存在依赖循环。**不可共存——只能被化解。**

### 男主的解法（终幕）
- **神族除外于和邦**（五族共和·神族除外·不是吸纳）
- 男主终幕用**迪化第四阶段·法则级化解天庭先锋军**（非杀戮·能量循环转化）——不靠力量消灭，靠法则化解
- **昊玄殁殃"被舍弃的付出"被理解**（与男主内核咬合·他们也是"付出善意被辜负"的终极放大版）——不是被杀，是被治愈/被理解后执念消解
- **周临相认**（人族最强接纳妖圣）成为打破循环的象征——循环的本质是"六界互不信任/互杀"，周临的接纳是循环被打破的 key

### 可生支线

## 七、六界和谐共存引擎（建国脊梁 · 用户要的核心）⭐

> 男主建和邦不是"收角色"，是**逐界治愈伤口**。每界有一个"共存障碍"（该界不能与其他界共存的根本原因），男主用治愈模型+能力解开 → 该界加入和邦。**建国 = 治愈的果实**（v3 内核）。

### 共存进度表（V1 → 终幕）

| 卷 | 和邦吸收 | 该界共存障碍（被治愈的伤口） | 男主的解法（机制） | 和邦新增维度 |
|----|---------|---------------------------|-------------------|------------|
| V1-V3 | **妖**（锤伯/小牙/诸部）+ **人**（陆离/温故） | 妖血脉论+人妖仇恨 | 转生妖族+灵觉感知看个体+地灵族师徒传承式共和 | 起家：师徒制→共和雏形 |
| V3 | **+ 鬼**（铁岚/冥） | 鬼族不介入+轮回封闭 | 铁岚找到"不变形的主君"+冥府被逼主动结盟 | 司法维度（判官秩序） |
| V4-V5 | 妖王会盟纳入 | 妖界割据无统一顶级 | 男主虚名最高但建共和（非支配·拒绝捷径） | 妖界统一（非帝国·是共和） |
| V6 | **+ 魔**（阿檀/墨渊） | 魔族只信力量+业力 reject | 江烬镜像（善 vs 力量）→ 流亡派第三条路 | 魔族代表（力量被善化解） |
| 穿插仙 | **+ 仙**（砚青/沈砚/少壮派） | 仙界盲从天庭+不介入 | 砚青首次干预+揭飞升失踪→仙界质疑共建 | 文化维度（800年记录→史官） |
| V8-终幕 | **五族统一**（神除外） | 神界操盘循环 | 迪化第四阶段·法则级化解天庭先锋（非杀戮）+周临相认（人族最强接纳妖圣=循环打破象征） | 五族共和完成·循环打破 |

### 共存引擎的设计原则（写作红线）

1. **不靠力量征服**：男主每界都是用"治愈模型"（被治愈的经历+灵觉感知看真心+迪化塑造本体的具现联结）解开伤口，不是武力收服。武力只护人，不建国。
2. **每界加入绑一个"伤口治愈事件"**：不是"该卷加了"，是"该界的伤口被男主解开了一个具体事件"——铁岚弑主后被接纳（鬼族伤口）、阿檀流亡找到第三条路（魔族伤口）、砚青800年首次干预（仙界伤口）。
3. **共和不是帝国**：和邦是五族共和（有各族的维度——妖的部族/人的宗门商修/鬼的判官/魔的流亡派/仙的记录者），不是男主当皇帝。男主是"联结者"不是"统治者"。
4. **神族除外是设计核心**：五族共和（神除外）——神界是循环操盘者，不被吸纳，终幕被化解。这保证了"打破循环"的结局不是"男主当六界之主"，而是"循环操盘者被化解+五族自治共和"。
5. **周临相认是共存引擎的终局落点**：人族最强剑修接纳妖圣男主 = "人妖必敌"刻板信仰的终极打破 = 循环（六界互杀）被打破的象征。这是共存引擎的句号。

### 共存引擎的反面（防止跑偏）
- ❌ 男主靠碾压收服各界（那是帝国不是共和）
- ❌ 各界加入没有"伤口治愈事件"（那是收小弟不是建国）
- ❌ 和邦只有妖族（那不是五族共和）
- ❌ 神族被吸纳进和邦（神族是循环操盘者·除外是设计核心）
- ❌ 终局男主当六界之主（应是循环打破+五族自治）
