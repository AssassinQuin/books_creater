# 势力设计

> 完整设计见 DB `faction` 分类。本文档为汇总指针，详细数据以 DB 为准。
> 命名风格：欧洲中世纪 + 拉丁语/古诺斯语词根，避免中英混合。

---

## 一、人族国家（5个）

### 1. 瓦尔德帝国（The Empire of Vald）

| 维度 | 内容 |
|------|------|
| **地理** | 中原核心，最富饶、人口最密集 |
| **政体** | 帝国制 |
| **首都** | 瓦尔德城 |
| **统治者** | 瓦尔德家族 |
| **野心** | 统一埃瑟利亚大陆 |
| **军事** | 最强陆军，举兵南下"讨伐"邻国 |
| **经济** | 农业+税收+征召，庞大但脆弱 |
| **徽章** | 铁冠 |
| **格言** | "铁与火，秩序与面包" |
| **核心价值观** | 秩序即仁慈——没有帝国，魔潮来时各自为战 |
| **内部张力** | 北方贵族想扩张 vs 南方派想稳定 |
| **与帝国关系** | 自身 |
| **种族构成** | 人类主导，允许矮人/半精灵入籍（同化政策） |
| **魔法政策** | 觉醒者需登记，发放执照 |

> **写作指南**：帝国不是反派。他们真的在维持秩序，但维持秩序的方式是把所有人都变成帝国的燃料。写帝国时写其效率、冷漠、庞大的官僚机器，不写邪恶。

### 2. 里萨兰提亚（Risarantia）

| 维度 | 内容 |
|------|------|
| **地理** | 西海岸，高原+海岸 |
| **政体** | 城邦联盟制 |
| **首都** | 里萨港 |
| **统治者** | 各城邦执政官 |
| **野心** | 保持独立，联合抗帝 |
| **军事** | 海军最强，陆军分散 |
| **经济** | 商业+以太矿脉+海上贸易 |
| **徽章** | 礁石上的船锚 |
| **格言** | "风浪越大，船越贵" |
| **核心价值观** | 自由航行，自由贸易 |
| **内部张力** | 大城邦想垄断 vs 小城邦想自由竞争 |
| **与帝国关系** | 被帝国讨伐对象 |
| **种族构成** | 人类+矮人+混血 |
| **魔法政策** | 觉醒者可自由执业，需商会担保 |

> **写作指南**：写里萨兰提亚时写其混乱、活力、码头气味、不同语言的叫骂声。城邦之间互相算计，但对外一致。

### 3. 奥伯龙尼亚（Oberonia）

| 维度 | 内容 |
|------|------|
| **地理** | 东境平原，河流纵横 |
| **政体** | 分裂公国制 |
| **首都** | 奥伯龙城（名义上） |
| **统治者** | 多个小领主 |
| **野心** | 各自自保，无力统一 |
| **军事** | 分散弱小 |
| **经济** | 农业为主，河流运输 |
| **徽章** | 分叉的河流 |
| **格言** | "家族、责任、荣誉" |
| **核心价值观** | 各领主自治，名义上联合 |
| **内部张力** | 领主互相征伐 vs 共同抗帝 |
| **与帝国关系** | 被帝国以"保护"名义渗透 |
| **种族构成** | 纯人类 |
| **魔法政策** | 各领主自行决定 |

> **写作指南**：写奥伯龙尼亚时写其分裂、河流、小城堡、领主之间的婚姻和背叛。是帝国最容易吞并但也最耗精力的地方。

### 4. 斯卡迪亚（Skardia）

| 维度 | 内容 |
|------|------|
| **地理** | 北境，霜墙以南 |
| **政体** | 边境伯国 |
| **首都** | 霜壁城 |
| **统治者** | 边境伯爵 |
| **野心** | 守住防线，保持独立 |
| **军事** | 依赖破碎盾誓团 |
| **经济** | 贫瘠，靠帝国补贴（但补贴迟到） |
| **徽章** | 裂开的冰 |
| **格言** | "墙不倒，人不退" |
| **核心价值观** | 生存第一 |
| **内部张力** | 向帝国屈服换粮饷 vs 保持独立冻死 |
| **与帝国关系** | 名义臣服，实际独立 |
| **种族构成** | 人类+少量矮人 |
| **魔法政策** | 觉醒者稀少，不登记 |

> **写作指南**：写斯卡迪亚时写其寒冷、贫瘠、绝望中的坚韧。是主角团可能遇到男二的地方。

### 5. 莫尔登（Morden）

| 维度 | 内容 |
|------|------|
| **地理** | 南方沼泽湿地 |
| **政体** | 王国制 |
| **首都** | 泥沼城 |
| **统治者** | 莫尔登家族 |
| **野心** | 被忽视，只想自保 |
| **军事** | 弱，依赖地形防御 |
| **经济** | 渔业+湿地农业+走私 |
| **徽章** | 沼泽中的灯 |
| **格言** | "沉下去才能浮起来" |
| **核心价值观** | 在夹缝中求生存 |
| **内部张力** | 王室想靠拢帝国 vs 民间支持逆流兄弟会 |
| **与帝国关系** | 暂时未被帝国关注 |
| **种族构成** | 人类+半身人混居 |
| **魔法政策** | 混乱，不执行 |

> **写作指南**：写莫尔登时写其潮湿、疫病、被遗忘的感觉。逆流兄弟会在此活跃，因为帝国管不到。

## 二、跨国/秘密组织（5个）

### 1. 赫斯珀里迪斯（The Hesperides）

| 维度 | 内容 |
|------|------|
| **性质** | 秘密网络，无总部，节点散布各国 |
| **起源** | 几百年前学者从古籍残片拼凑出以太真相，破封想结束战争，却释放灾难 |
| **分裂** | 守烬派（维持封印，做脏活）vs 燃尽派（彻底解封，相信新世界） |
| **核心矛盾** | 真诚的理想→真诚的错误→真诚的罪恶 |
| **格言** | "前面六盏都灭了"（内部暗语） |
| **识别方式** | 右手覆左手，拇指交叉成环 |
| **种族构成** | 人类+精灵+少量矮人+混血 |
| **魔法政策** | 掌握最多真相，但选择隐瞒 |

> **写作指南**：写赫斯珀里迪斯时写其隐秘、历史重量、成员的真诚信念。他们不是反派，是被困住的理想者。关键场景：一个成员在触发兽潮后独自哭泣。

---

### 2. 逆流兄弟会（The Fratres Contrarii）

| 维度 | 内容 |
|------|------|
| **性质** | 流动技术传播网络，无固定领地 |
| **核心** | 让普通人能用魔法物品，知识一旦传播就夺不走 |
| **分裂** | 温和派（只教防御）vs 激进派（教攻击，认为没有攻击的防御是等死） |
| **被通缉** | 帝国、灰烬图书馆、冷炉行都想消灭或利用他们 |
| **格言** | "这次不一样" |
| **种族构成** | 各种被排斥者：混血、变异者、流亡学者 |
| **魔法政策** | 传播魔法物品制作技术，不管觉醒者执照 |

> **写作指南**：写逆流兄弟会时写其理想主义、危险、被追捕的紧张感。他们是唯一真正想打破循环的势力，但作者不给答案——打破后是新世界还是新循环？

---

### 3. 破碎盾誓团（The Broken Shield）

| 维度 | 内容 |
|------|------|
| **性质** | 北方军事同盟，非国家，自治 |
| **成员** | 人类、矮人、混血、甚至变异者——墙前不问出身 |
| **核心** | 不是为国家挡魔潮，是为自己身后的土地挡 |
| **与帝国关系** | 帝国想收编（"给粮饷"），但粮饷永远迟到 |
| **格言** | "盾裂了，还在挡" |
| **徽章** | 裂开的盾牌上插着断箭 |
| **种族构成** | 最混：人类+矮人+混血+变异者 |
| **魔法政策** | 实用主义，谁有用谁上 |

> **写作指南**：写破碎盾誓团时写其粗犷、绝望中的尊严、墙前的平等。男二可能来自这里。

---

### 4. 灰烬图书馆（The Bibliotheca Cinerea）

| 维度 | 内容 |
|------|------|
| **性质** | 学术-宗教混合体，总部在河间地废墟高塔 |
| **功能** | 记录历史、审查出版物、发放觉醒者执照 |
| **核心矛盾** | 学者求真 vs 配合权力删改 vs 私下保留备份 |
| **与帝国关系** | 名义独立，实际与帝国、赫斯珀里迪斯三方勾结 |
| **格言** | "墨水比灰烬持久" |
| **徽章** | 上半截实、下半截虚的塔 |
| **种族构成** | 人类学者为主，少量精灵 |
| **魔法政策** | 控制觉醒者鉴定和执照发放 |

> **写作指南**：写灰烬图书馆时写其矛盾——学者想求真，但必须配合权力。关键场景：一个学者在烧书时偷偷抄录副本。

---

### 5. 冷壁炉商会（The Cold Hearth）

| 维度 | 内容 |
|------|------|
| **性质** | 商业共同体，银湾城邦背后的实际掌控者 |
| **核心** | 以太结晶贸易，不在乎谁统治，只在乎路线畅通 |
| **策略** | 不让任何一方赢——帝国太强就资助逆流兄弟会，逆流兄弟会太盛就泄露给帝国 |
| **格言** | "秤不问你从哪来" |
| **徽章** | 黄铜天平，两边托盘分别是矿石和硬币 |
| **种族构成** | 最杂：人类、矮人、精灵、混血——种族是标签不是身份 |
| **魔法政策** | 不在乎，只在乎结晶产量和价格 |

> **写作指南**：写冷壁炉商会时写其冷漠、效率、没有温度。成员有钱但没有归属，hearth（壁炉/家/心脏）冷了。

## 三、种族领地（3个）

### 1. 埃瑟利亚大陆（Aetheria）

大陆整体框架。从北到南：霜烬荒原→北境→中原→西海岸→东境→南方密林→东南海岸。

### 2. 艾洛萨恩（Aelosain）——精灵领地

| 维度 | 内容 |
|------|------|
| **地理** | 南方密林深处 |
| **现状** | 古老、衰退、分裂 |
| **与帝国关系** | 帝国表面尊重，实际想开垦林地 |
| **内部张力** | 封闭派（自守）vs 参与派（介入世界） |
| **魔法特点** | 记得"上一次循环"的片段，以歌谣和禁忌形式 |

### 3. 卡兹·杜姆（Kazdum）——矮人城邦

| 维度 | 内容 |
|------|------|
| **地理** | 西境高原地下 |
| **现状** | 多个互相独立的地下城邦 |
| **与帝国关系** | 与里萨兰提亚签采矿契约，不臣服帝国 |
| **内部张力** | 传统派（封闭）vs 开放派（与人类贸易） |
| **魔法特点** | 擅长以太结晶开采和锻造 |

## 五、帝国"举事讨伐"的全景

帝国不是打"其他种族"，是打**其他人族国家**：

| 阶段 | 目标 | 理由 | 实际目的 |
|------|------|------|---------|
| 第一阶段 | 河间地诸领 | "结束分裂，统一人族" | 粮仓+兵源 |
| 第二阶段 | 银湾城邦 | "保护贸易路线" | 矿脉+海军+税收 |
| 第三阶段 | 东南自由港 | "打击海盗" | 控制对外航线 |
| 同时 | 渗透暮林 | "开化蛮荒" | 林地资源+以太植物 |

**精灵、矮人不是帝国的"讨伐对象"**——帝国想拉拢或利用他们：
- 矮人：签采矿契约，给武器订单
- 精灵：表面尊重，实际想骗他们让出林地
