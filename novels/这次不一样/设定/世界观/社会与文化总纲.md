# 社会与文化总纲

> **条目名**：社会与文化总纲
> **定位**：本书日常生活、文化体系、经济逻辑的完整设定。所有社会描写、文化冲突、生活细节的呈现必须回归此处校准。

---

## 一、日常生活

### 写作总纲
写日常写感官不写说明。鱼腥味、铁锈味、焚香味。市场叫卖声、军号声、教堂钟声。硬币的重量、干粮的硬度、以太灯的冷光。让读者闻到听到摸到这个世界。不写"经济体系是"——写一个鱼贩子找零时铜币不够用面包凑。

### 日常节律
日出而作，日落而息。没有电灯，照明靠油灯/以太灯（富人）。食物保存：腌制、风干、地窖储存。水源：井水、河水、雨水收集。季节：冬季漫长，北方几乎无法外出。

社交空间：酒馆、市场、教堂/神殿、铁匠铺、码头。
信息流动：告示栏、吟游诗人、商人传闻、教会布道。

### 各地区日常

| 地区 | 日常特征 |
|------|----------|
| 三港 | 贸易繁忙，码头日夜运转，商人阶层富裕，底层聚居区拥挤 |
| 脊堡联盟 | 寒冷坚韧，军民不分，随时可能有魔潮警报 |
| 白廷 | 安静肃穆，教堂钟声定节奏，信徒日常祈祷 |
| 灰石镇 | 大陆十字路口，五方势力交汇，集市最热闹 |
| 拾荒者聚落 | 城墙外的完整社区，种地打猎采集手工，靠三港的边角料生存 |

### 以太物品与平民
以太物品不是人人可用——它是阶层标志。

| 层级 | 物品 | 说明 |
|------|------|------|
| 奢侈品 | 照明/保鲜/取暖/通讯 | 富人专属 |
| 标准品 | 一次性防护符/简易工具强化 | 中产偶尔用 |
| 黑市货 | 不稳定有副作用 | 贫民区流通 |
| 违禁品 | 逆流兄弟会制造 | 效果好但违法 |

能使用以太物品=有地位，不能用=底层。

### 物价与货币
- **三港铸币**：稳定流通货币
- **以太结晶**：真正硬通货
- **以物易物**：底层普遍

参考物价：黑面包1铜币（工人半天工资），治疗药水3颗结晶（只有贵族和士兵用得起），贫民房租每月2银币（占收入一半）。

## 二、文化体系

### 写作总纲
写文化写具体的活法不写抽象的概念。每个势力的文化通过角色的日常行为展现——修女洗脚又举报、老兵偷偷哭又擦干脸、商人说有利的真话。文化在动作里不在旁白里。

### 核心特征
以太觉醒者构成特权阶层，觉醒能力是社会分层的核心维度之一。

信仰与科学对立：白廷教义将以太解释为神赐，民间觉醒者实践则更技术化。

历史以太灾为分水岭——灾前文明、灾后重建。

日常中的世界观：酒馆闲聊、告示栏排名、酒馆物价比设定说明文更能展示世界。

### 文化现象

**吟游诗人**：大陆信息传播的重要媒介，传唱英雄故事、势力丑闻、荒野传说。

**节日与仪式**：
- 白廷的觉醒仪式
- 三港的贸易节
- 脊堡联盟的阵亡纪念
- 灰石镇的全城集市

**禁忌话题**：
- 以太灾的真相（各势力说法不同）
- 复苏的原因（公开讨论可能被视为异端）

**命名习惯**：各地不同——三港用港名、脊堡联盟用军衔、白廷用圣名。

## 三、经济体系

### 核心逻辑
以太结晶是硬通货和权力基础。晶体随阶位生长——阶位越高，晶体越大越纯密度越高。

### 货币与流通

| 货币类型 | 说明 |
|----------|------|
| 三港铸币 | 日常交易货币，稳定但会贬值 |
| 以太结晶 | 真正硬通货，不贬值，全球通用 |
| 以物易物 | 底层和偏远地区普遍 |

### 晶体流通
- **魔晶**：最常见，觉醒者吸收强化自身晶核，多余流通为货币/能源/锻造材料
- **以太晶**：稀有，不限属性，价格极高
- **吸收效率**：吸收外部魔晶是低效的——像用别人的井水浇自己的田。直接从以太吸收最纯但最慢。富人用大量低质魔晶堆量，穷人靠时间慢慢纯吸——穷人花更多时间走更慢的路

### 黑暗规则
觉醒者死后晶核留存。强者猎杀觉醒者取核——给世界一层黑暗底色。

### 各势力经济特征

| 势力 | 经济模式 | 核心资源 |
|------|----------|----------|
| 三港 | 商业寡头，航运+贸易 | 以太富集区群、航运网络 |
| 脊堡联盟 | 军事经济，裂谷开发 | 脊骨裂谷产出（结晶+魔物材料） |
| 白廷 | 神权经济，祭坛控制 | 觉醒祭坛群（觉醒成功率最高） |
| 公会 | 服务收费，情报垄断 | 荒野地图、魔物情报、探索许可证 |
| 窖众 | 地下经济，灰色交易 | 仿刻铭牌、私贩结晶、灰道情报 |

## 四、社会与文化写作总纲

**日常即世界观**。用摊贩闲聊、告示栏排名、酒馆物价展示世界。写具体、感官、不解释。

**文化通过日常细节展示**，不写百科条目。不同势力对同一事件有不同叙事——读者自己判断。

**经济写黑市价格不写面板**。写人们为了晶核做的事，不写价格数字。

**社会分层写待遇不写等级**。觉醒者和未觉醒者的差距在社会资源，不在能力数值。
