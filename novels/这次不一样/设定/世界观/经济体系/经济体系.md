# 经济体系

> 完整设计见 DB `economy` 分类。本文档为汇总指针。
> 核心原则：以太结晶是一切经济活动的底层硬通货。

---

## 一、总体框架：埃瑟利亚经济体系

### 货币系统

| 层级 | 货币 | 说明 |
|------|------|------|
| 第一 | **以太结晶**（按属性/品质分级） | 真正硬通货 |
| 第二 | 各国铸币 | 贬值严重，边境不接受 |
| 第三 | 以物易物 | 边境和底层普遍 |

### 经济层级

```
Layer 1: 原材料 — 以太结晶开采（卡兹·杜姆矮人主导）
    ↓
Layer 2: 制造 — 魔法物品制作（里萨兰提亚城邦 + 逆流兄弟会地下）
    ↓
Layer 3: 贸易 — 跨势力运输（冷壁炉商会垄断）
    ↓
Layer 4: 金融 — 结晶汇兑、期货、保险（冷壁炉商会 + 灰烬图书馆背书）
    ↓
Layer 5: 消费 — 各国贵族、觉醒者、军队
```

### 价格波动

以太浓度波动 → 结晶产量波动 → 价格剧烈波动 → 社会动荡。

> **写作指南**：写经济时写其残酷——结晶是硬通货，穷人没有结晶就没有保护，没有保护就死在魔潮里。经济不是背景，是生死。

## 二、各国/组织经济

### 1. 瓦尔德帝国经济

| 维度 | 内容 |
|------|------|
| **类型** | 农业+征召+税收 |
| **主要产出** | 粮食、纺织品、木材 |
| **贸易地位** | 进口以太结晶（自身产量低），出口粮食和人力 |
| **税收** | 什一税+觉醒者特别税+战争征召（实物代替货币） |
| **财富分配** | 皇室和北方贵族掌握90%财富，底层平民以劳役代税 |
| **脆弱性** | 依赖里萨兰提亚的结晶进口，一旦断供军队和觉醒者系统崩溃 |
| **黑市** | 庞大，底层通过黑市获取低价结晶和未登记魔法物品 |

> **写作指南**：写帝国经济时写其庞大但脆弱——表面强盛，实际命脉捏在商会和城邦手里。征召制让农民变成士兵，士兵变成炮灰。

---

### 2. 里萨兰提亚经济

| 维度 | 内容 |
|------|------|
| **类型** | 商业+矿业+海上贸易 |
| **主要产出** | 以太结晶（核心）、海运服务、奢侈品、情报 |
| **贸易地位** | 出口结晶，进口粮食和原材料 |
| **货币** | 城邦铸币+结晶本位 |
| **金融** | 冷壁炉商会主导，提供汇兑、贷款、保险 |
| **脆弱性** | 依赖卡兹·杜姆的矿脉供应，一旦矿脉枯竭或矮人断约，经济崩溃 |
| **阶级** | 大商人>小商人>工匠>水手>贫民 |
| **行会** | 各行会有严格准入，但黑市工匠（逆流兄弟会）在底层活跃 |

> **写作指南**：写里萨兰提亚经济时写其活力与腐败并存——码头上的叫骂声、商人的算计、黑市交易在光明正大的市场隔壁。

---

### 3. 卡兹·杜姆经济

| 维度 | 内容 |
|------|------|
| **类型** | 矿业+锻造 |
| **主要产出** | 以太结晶原石、精炼金属、魔法武器/防具 |
| **贸易地位** | 出口原石和锻造品，进口粮食和木材（地下无法种植） |
| **契约** | 与里萨兰提亚签长期采矿契约，按年结算 |
| **脆弱性** | 完全依赖地面贸易，一旦通道被封或契约作废，饥荒 |
| **社会结构** | 矿工>锻造师>商人>仆人 |
| **劳动条件** | 矿工寿命短（以太辐射），但收入高，吸引地面贫民冒险 |

> **写作指南**：写卡兹·杜姆经济时写其地下世界的独特逻辑——没有阳光，没有时间感，只有契约和金属敲击声。

---

### 4. 冷壁炉商会经济网络

| 维度 | 内容 |
|------|------|
| **类型** | 跨势力金融+贸易垄断 |
| **主要业务** | 以太结晶汇兑、跨势力贷款、情报、雇佣兵服务 |
| **贸易路线** | 里萨兰提亚-瓦尔德帝国（结晶-粮食）、卡兹·杜姆-里萨兰提亚（原石-精炼）、斯卡迪亚-瓦尔德帝国（情报-补贴）、莫尔登-自由港（走私-避税） |
| **盈利模式** | 低买高卖+信息差+战争期货（在冲突前囤积物资） |
| **操纵手段** | 故意制造短缺→涨价→抛售→再制造短缺 |
| **与战争关系** | 战争=利润。帝国统一=利润下降（垄断无竞争），所以商会暗中资助反抗势力 |

> **写作指南**：写商会经济时写其冰冷计算——人命是数字，战争是机会，忠诚是商品。成员可能在同一笔交易里既卖武器给帝国又卖情报给反抗者。

---

### 5. 逆流兄弟会地下经济

| 维度 | 内容 |
|------|------|
| **类型** | 非正规技术传播+黑市制造 |
| **主要产品** | 低成本魔法物品、未登记觉醒者培训、被禁知识副本 |
| **生产模式** | 分散细胞制，各小组独立运作，互不知晓 |
| **分销** | 通过贫民区网络、走私路线、伪装成普通商品流通 |
| **定价** | 远低于市场价（免费或成本价），破坏正规经济 |
| **资金来源** | 匿名捐赠+成员自筹+偶尔抢劫商会运输队 |
| **经济影响** | 让底层获得自保能力，但也导致正规魔法物品市场萎缩，激怒灰烬图书馆和冷壁炉商会 |

> **写作指南**：写逆流兄弟会经济时写其理想主义与危险的结合——他们在做正确的事，但方式让所有人（包括自己人）都紧张。

---

### 6. 破碎盾誓团经济

| 维度 | 内容 |
|------|------|
| **类型** | 军事补贴+走私+雇佣 |
| **主要产品** | 魔潮情报、护卫服务、黑市以太结晶 |
| **资金来源** | 各国承诺补贴（但永远迟到）、护送商队过危险地带、出售魔潮预警情报、走私战死魔兽的结晶 |
| **经济压力** | 补贴不够买粮食，士兵家属在斯卡迪亚挨饿，迫使前线士兵参与走私 |
| **腐败** | 基层指挥官默许士兵私藏战死魔兽结晶，高层假装不知道 |
| **与商会关系** | 部分指挥官与冷壁炉商会有秘密交易，用情报换物资 |

> **写作指南**：写破碎盾誓团经济时写其屈辱——他们是英雄，但必须靠走私和贿赂才能吃饱。这种屈辱比魔潮更侵蚀人心。

## 四、关键经济冲突

| 冲突 | 双方 | 本质 |
|------|------|------|
| 帝国 vs 银湾 | 瓦尔德帝国 vs 里萨兰提亚 | 统一 vs 独立 = 控制贸易路线 |
| 商会 vs 兄弟会 | 冷壁炉商会 vs 逆流兄弟会 | 垄断利润 vs 免费传播 |
| 正规 vs 黑市 | 灰烬图书馆 vs 逆流兄弟会 | 控制知识流动 |
| 补贴 vs 走私 | 斯卡迪亚 vs 破碎盾誓团 | 尊严 vs 生存 |
