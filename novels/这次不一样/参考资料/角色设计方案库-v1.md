# 角色设计方案库 v1（覆盖完整情感光谱：暖 → 虐 → 悲壮）

> **定位**：本书配角群像设计的「案例 / 模式 / 手法 / 方案」参考库。
> **核心立场**（区别于上一版配角设计的错）：
> 1. **不是禁止虐**——虐、感人、bad end 是强大且必要的情感工具。错的是「所有配角都做成暗黑自残、调性单一压抑」。
> 2. **多样性 > 单一调性**：一个配角群像要混合多种调性（温柔治愈 / 陪伴成长 / 自我救赎 / 感人虐 / 悲壮 bad end / 反差萌），有轻有重、有暖有虐才有层次。
> 3. **正向不等于扁平和稀泥**：温柔治愈型也要有自己的伤口与挣扎；虐心型要有升华不廉价。
>
> 严咬合：`设定/角色/群像.md`（18 人迪化网络）·`设定/角色/男主.md`（错误公式/治愈=击穿公式）·`设定/题材定位.md`（迪化+种田+治愈+仙侠）。

## 一、经典案例库（按作品归类，每案例 3-5 句）

### A. 治愈温暖类（暖光谱）

#### 1. 《夏目友人帐》——夏目贵志 + 猫咪老师
- **角色**：能看见妖怪的孤独少年 + 化身招财猫的强大妖怪「斑」。
- **内核**：夏目「温柔地对待世界，也想被世界温柔以待」——他不是没被伤害，是选择不把伤害传出去；猫咪老师傲娇贪吃，却用「契约」做体面说法，陪夏目一生。
- **感人原因**：每集一个妖怪的执念被看见、被归还名字——「被看见」本身就是治愈。
- **手法**：①单元剧式妖怪故事，每集一颗小温柔；②「喵咪老师」的反差萌（强大本体 ↔ 招财猫形态）让陪伴不沉重；③夏目的温柔是「克制」的——他不抱怨，只在独处时落泪，让暖里带酸。

#### 2. 《国王排名》——波吉 + 卡克
- **角色**：又聋又哑、矮小无力的第一王子 + 影子一族的孤儿刺客。
- **内核**：波吉是「弱小者向上生长」的纯粹模板——他被全城嘲笑，却始终以善回应；卡克是「被王室驱逐的孤儿」，他认波吉是因为「波吉是第一个不嫌弃他出身的人」。
- **感人原因**：两个伤痕累累的灵魂互为解药；波吉流泪的镜头让猛男落泪。
- **手法**：①极简童话画风 ↔ 沉重人性议题的反差；②波吉的「弱」被推到极致（聋哑+无力），让「不放弃」显得尤为厚重；③「后妈」反转——初看恶毒，实则深爱，让扁平反派变立体。

#### 3. 《罗小黑战记》——小黑 + 无限
- **角色**：家园被毁的妖灵猫小黑 + 妖灵会馆最强人类执行者无限。
- **内核**：小黑从「恨人类」到「想成为无限那样的人」——是「被一个好人接住」的治愈；无限收徒不是出于责任，是「偶然在意，进而放不下」。
- **感人原因**：师徒情在不经意细节里累积（无限给小黑买烧鸡、小黑偷偷学他动作）。
- **手法**：①萌宠形态 ↔ 人形形态的反差；②风息（反派）不是恶，是「想给妖族留栖息地」的悲情——让读者两边都心疼；②治愈靠「日常琐碎」累积，不靠大事件。

#### 4. 《间谍过家家》——阿尼亚 / 约尔 / 劳埃德
- **角色**：读心超能力女孩 + 杀手母亲 + 间谍父亲，组成虚假家庭。
- **内核**：阿尼亚是「假家庭里的真感情」——她知道父母身份，父母彼此不知；她用童真把「任务家庭」变成「真家庭」。
- **感人原因**：阿尼亚的童真 vs 间谍世界的冷酷——她不是装傻，是真天真，让大人的伪装一层层瓦解。
- **手法**：①身份错位喜剧（每个成员都以为自己在演戏）；②阿尼亚的「真」是破壁器；③「假家庭变真家庭」的内核是「羁绊不靠血缘」。

#### 5. 《紫罗兰永恒花园》——薇尔莉特
- **角色**：从小被当战争机器养大的少女，战后做「代笔写信」的工作。
- **内核**：「工具 → 人」的弧线——她不懂感情，通过替别人写信学会「我爱你」的意思。
- **感人原因**：每一封信背后是一段人生；薇尔莉特从「无感」到「流泪」的渐变是动画史上最克制的治愈。
- **手法**：①单元剧式情感教育（每集一个委托人的人生）；②薇尔莉特的「不懂」是观众情感投射的容器；③「寻找少佐说的『我爱你』是什么」是贯穿主线——情感追索。

#### 6. 《白兔糖》《狼的孩子雨与雪》——亲情羁绊型
- **角色**：单身汉收养孤儿 / 单身母亲独自养狼孩子。
- **内核**：非血缘的羁绊比血缘更深；「养育」本身就是最深的治愈。
- **感人原因**：日常琐碎里的牺牲——主角放弃了自己的人生可能性，但从未把这当成「牺牲」。
- **手法**：①时间跨度（童年→成年）让成长可见；②主角的牺牲从不被煽情化，只在结尾轻轻一戳。

#### 7. 《哆啦A梦》——哆啦A梦 + 大雄
- **角色**：来自未来的猫型机器人 + 普通软弱的小学生。
- **内核**：陪伴型模板——哆啦A梦不解决大雄的人生，只在每次大雄哭的时候出现；大雄的「软弱但善良」是底色。
- **手法**：①道具的奇幻 vs 大雄的日常；②哆啦A梦「陪伴但不替代」——每次大雄想偷懒，道具就会反噬，逼他自己成长。

### B. 国漫群像类（迪化+温暖典范）

#### 8. 《修真聊天群》——宋书航 + 九洲一号群（重点拆·迪化+温暖群像典范）
- **角色群**：天生好人的普通大学生宋书航，误入修真者聊天群；群里有美貌强大的白前辈、永远在线的北河散人、关心中生代的苏氏阿十六、性格各异的羽柔子/狂刀三浪/铜卦仙子等。
- **内核**：**迪化+温暖群像的范本**——宋书航的「好人属性」是真的（不是装），群友们各有性格、各有伤、各有梗，他们的「脑补」不恶意、不黑暗，是「人情味里的误解」。
- **感人原因**：白前辈对宋书航的护短、北河散人永远第一个回复、阿十六像姐姐一样关心他——温暖不是靠「悲情牺牲」，是靠**日常人情累积**。
- **手法**（核心可借鉴）：
  1. **聊天群机制**——「现代社交形式 × 修真」的反差喜剧外壳，让修真不沉重；
  2. **群友各有完整人生**——北河散人、苏氏阿十六、羽柔子都有自己的支线/伤/执念，不是主角的工具人；
  3. **迪化温度暖**——男主被脑补成「深谋远虑」「气运之子」，但群友的脑补**基于对男主的认可**，不是恐惧；
  4. **群像横向涟漪**——群友之间也有恩怨情仇（铜卦 vs 三浪、阿十六的姐妹关系），让群像立体；
  5. **温暖靠「投喂」「关心」「互相收拾烂摊子」累积**——不是靠宏大牺牲。

#### 9. 《一人之下》——冯宝宝 + 张楚岚 + 王也 + 诸葛青
- **角色**：失忆呆萌的强大女战士 + 表面废柴的大学生 + 武当道士 + 诸葛家天才。
- **内核**：**全员疯批人设的反差萌**——冯宝宝三无+碾压战力，张楚岚「不摇碧莲」+ 深藏不露，王也道长懒散+最强，诸葛青自负+真性情。
- **感人原因**：每个角色都「反差」到位——呆萌 vs 杀手、废柴 vs 隐藏高手、懒散 vs 守道、自负 vs 真。
- **手法**：①反差是基本盘（反差萌=角色设计的乘数）；②每个角色有自己的「异人」立场（哪都通、武当、诸葛家、全性），不是主角阵营的工具；③冯宝宝失忆+寻根的主线，让「呆萌」不沦为搞笑，是「一个失忆者在陌生世界的孤独」。

#### 10. 《狐妖小红娘》——转世续缘的虐
- **角色**：涂山狐妖为转世的人类与妖恢复前世记忆牵红线。
- **内核**：**人妖寿命差的悲剧被「转世续缘」制度化为希望**——虐不在「死」，在「前世记得、今生忘了」。
- **感人原因**：每一对转世续缘都是一段前世的虐恋+今生的重逢；虐得有意义（为爱等待），不廉价。
- **手法**：①单元剧式情感卷（每篇一对情侣）；②「苦情树起誓」的仪式感让虐有制度依托；③前世虐恋 + 今生重逢的双线对照。

#### 11. 《非人哉》——神话人物现代治愈
- **角色**：九月（九尾狐）、敖烈（龙王三太子白龙马）、哪吒、哮天、小玉（玉兔）。
- **内核**：**神话原型 × 现代职场/日常**——把神仙拉下神坛，变成「打卡上班、被领导骂、为房租发愁」的普通人。
- **感人原因**：熟悉的神话人物（哪吒、敖烈）以全新面貌出现，既亲切又新鲜；每个角色保留了原型的一两个特征（哪吒的萝莉正太、敖烈吐水）作为「梗」。
- **手法**：①泡面番式单元剧；②原型 1-2 个核心特征 + 现代角色全重塑；③「神话原型 × 现代生活」的反差喜剧。

### C. 神话新编影视类（重塑手法）

#### 12. 《哪吒之魔童降世》——哪吒 + 敖丙
- **改了什么**：①哪吒从「灵珠转世」改成「魔丸错投」（天选救世主 ↔ 注定成魔的宿命翻转）；②李靖从「冷酷父亲」改成「深爱孩子的父亲」（整部作品的结构性反转）；③敖丙从「反派龙太子」改成「哪吒唯一的朋友」（敌人→朋友）。
- **没改什么**：哪吒的「反抗精神」、混天绫/乾坤圈等符号、亲子冲突的壳。
- **讨喜原因**：「我命由我不由天」击中当代个体反抗宿命的共鸣；父子情重塑让虐不廉价（不是父亲不爱，是宿命逼人）。

#### 13. 《白蛇缘起》《新神榜杨戬》《大圣归来》《姜子牙》
- **共同手法**：①只借原型人物关系，转讲全新故事；②给反派/扁平角色补完整动机（杨戬师父慈父形象崩塌→真相揭晓）；③「觉醒」靠「权威崩塌」（师父/天庭的伪善被揭穿）；④迎合当代审美（果敢有力的少年许宣、帅气杨戬）。
- **讨喜原因**：神话人物是「集体潜意识」，改一个细节就能撬动巨大共鸣；保留符号 + 重塑内核 = 既亲切又新鲜。

### D. 网文群像类

#### 14. 《诡秘之主》——塔罗会
- **角色群**：克莱恩建立的隐秘组织，成员以塔罗牌代号，彼此不知真实身份。
- **内核**：**身份错位 + 共同使命**——成员各有秘密议程（「正义」小姐是亚伯拉罕家族纽带、「倒吊人」是海盗王），他们的合作基于「交易」而非「忠诚」。
- **感人原因**：身份揭晓时的化学反应；陌生人通过网络（塔罗会）建立的真实羁绊。
- **手法**：①代号制让身份悬念持续；②成员各有独立故事线（不只是主角的工具）；③「神弃之地」「末日预演」等大事件让群像共担命运。

#### 15. 《雪中悍刀行》——温华 / 褚禄山 / 徐骁
- **温华**：与主角徐凤年结义的兄弟，知晓徐凤年真实身份后**自断一臂一腿、折剑出江湖**——为不背信义也不害友。
- **褚禄山**：体型壮硕如球、阴狠胖军官，但其「文武第一」「忠诚」反转——恶形外秀其内。
- **徐骁**：人屠，但为子女、为北凉扛下一切。
- **手法**：①「寥寥数笔勾勒一个人物」——白描 + 反转；②每个配角都有「闪光点」（温华的义、褚禄山的忠、徐骁的扛）；③群像调性混合：温华的悲壮（断臂）+ 褚禄山的黑色幽默 + 徐骁的沉重。

### E. 感人虐 / bad end 案例（虐光谱）

#### 16. 《四月是你的谎言》——宫园薰
- **角色**：身患绝症的少女小提琴手，用「谎言」拉男主有马公生走出创伤。
- **虐在哪**：薰知道自己快死了，她让公生重新学会音乐，却没法陪他走下去。
- **为什么不廉价**：①薰的死不是「剧情杀」，是她「最后的礼物」——她用生命把公生从深渊拉出；②她的「谎言」是「我没病」——这谎言本身就是最深沉的爱；③结尾公生收到薰的遗书，虐在「她已经走了，但她的音乐还在」——是升华，不是悲剧。
- **bad end 力量**：肉体的消逝 vs 精神的永存——bad end 反而比 happy ending 更撼人。

#### 17. 《未闻花名》——面码
- **角色**：童年死去的玩伴，以幽灵形态回来，让昔日好友重聚。
- **虐在哪**：面码回来是为了「实现一个愿望」——愿望实现她就得走。
- **为什么不廉价**：每个活着的朋友都因面码的死有创伤；面码的回归让大家和解；最后面码消失——虐在「终于好好道别」，是治愈不是悲剧。

#### 18. 《仙剑奇侠传》——赵灵儿 / 林月如
- **赵灵儿**：女娲后人，与水魔兽同归于尽——宿命论下的悲剧英雄。
- **林月如**：为救赵灵儿和男主死在锁妖塔——「不问你要不要我，我也要救你」。
- **为什么不廉价**：她们的死是基于「自我选择」（女娲使命/爱），不是「剧情杀」；赵灵儿镇压锁妖塔=白蛇雷峰塔的神话原型呼应，悲剧有原型支撑。

#### 19. 《古剑奇谭》——沈夜 / 谢衣
- **沈夜**：流月城大祭司，为护族人甘愿背负一切罪名——是「反派中的悲壮者」。
- **谢衣**：沈夜之徒，被沈夜重伤后成为「破军」，师徒的虐缘。
- **为什么不廉价**：反派的悲壮——他不是坏人，是「为了族人不择手段」的悲剧；bad end 留白「残存的人 vs 夺舍的神」。

#### 20. 《进击的巨人》——调查兵团 + 埃尔文
- **虐在哪**：「为了人类献出心脏」——调查兵团每次出墙都伴随巨大牺牲；埃尔文团长的「放弃梦想，带队赴死」是动画史上最悲壮的演讲之一。
- **为什么不廉价**：牺牲有完整信念支撑（不是无意义的死）；埃尔文死前终于得知「墙外的真相」——梦想与使命的交叠让死有意义。

#### 21. 《钢之炼金术师》——等价交换 + 人造人
- **内核**：「没有牺牲就得不到任何收获」——等价交换原则让一切代价有意义。
- **手法**：①七宗罪人造人（人性阴暗面的具现）；②主角兄弟为复活母亲失去身体——代价贯穿全书；③反派不是纯粹的恶，是「被剥离的情感」。

#### 22. 《大鱼海棠》《时光代理人》《你的名字》——错过 / 代价
- **大鱼海棠**：为救一人牺牲全村——代价的失衡。
- **时光代理人**：每个委托都伴随「无法改变的悲剧」——程小时看到过去却改不了。
- **你的名字**：交换身体 + 错过——「我在找一个人，但我不记得是谁」。

### F. 神话悲剧原型（历久弥新）

#### 23. 精卫填海 / 夸父逐日 / 刑天舞干戚
- **共同内核**：「明知不可为而为之」的悲壮——精卫鸟衔木填海、夸父逐日渴死、刑天被斩首仍以乳为目以脐为口挥舞干戚。
- **为什么永恒感动**：①不是「失败」——是「永不停歇的抗争」本身；②隐喻人类对自然、对宿命、对死亡的反抗；③陶渊明「精卫衔微木，将以填沧海。刑天舞干戚，猛志固常在」——悲壮精神被文化编码。
- **可借鉴内核**：本书的悲壮反派 / bad end 位置可注入这种「永不罢休」——他不是失败，是「注定失败也要做」。

#### 24. 后羿嫦娥 / 白蛇雷峰塔 / 牛郎织女 / 梁祝
- **共同内核**：相爱被宿命拆散；等待、守望、跨不过的银河/雷峰塔。
- **为什么永恒**：①是中国式「离散美学」的原型；②「等待」本身就是最深情的告白；③悲剧的根在「规则」（天规/人妖殊途），不是个人恶意。

## 二、正向治愈角色设计模式分类（暖光谱）

> 每种模式：内核 / 典型剧情手法 / 为什么让人代入感动 / 适合什么样的配角位置。

### 1. 温柔治愈型（夏目型）
- **内核**：温柔地对待世界，也想被世界温柔以待。他/她不是没被伤害，是选择不把伤害传出去。
- **典型手法**：①单元剧式解决他人的执念/伤口；②克制的温柔（不抱怨，独处时才落泪）；③反差萌搭档（傲娇保镖/萌宠）。
- **代入感来源**：每个观众心里都有一个「想成为夏目」的部分——不报复，只是温柔地活下去。
- **适合配角位**：治愈锚点（如本书温故位·反迪化的真人族善意）；男主体力/心力耗尽时的归处。

### 2. 陪伴型 / 帮助型（猫咪老师 / 哆啦A梦型）
- **内核**：陪伴不替代——他/她不解决主角的人生，但每次主角哭的时候都在。
- **典型手法**：①傲娇/贪吃/反差萌（强大本体 ↔ 萌形态）；②「契约」「任务」做体面说法（猫咪老师说是为了友人帐，哆啦A梦说是为了任务）；③关键时刻化身边最强战力。
- **代入感来源**：每个人童年都想要一个哆啦A梦。
- **适合配角位**：贯穿全书的萌宠陪伴（本书缺这个位置）；男主题材外的喜剧调剂。

### 3. 成长型（波吉 / 大雄型）
- **内核**：弱小者向上生长——他/她不强大，但「不放弃」。
- **典型手法**：①把「弱」推到极致（波吉聋哑无力）；②一个坚定的「目标」（波吉要当最伟大的国王）；③每一步前进都伴随眼泪。
- **代入感来源**：弱者的坚持比强者的胜利更动人——读者在波吉身上看见自己。
- **适合配角位**：弟系/被弃者（本书小牙位可深化波吉内核）；弱小妖族的成长线。

### 4. 自我救赎型（哪吒 / 薇尔莉特型）
- **内核**：被命运/偏见/创伤定义的人，选择反抗——「我命由我不由天」。
- **典型手法**：①「魔丸/工具」的宿命设定；②关键人物的爱重塑信念（李靖的父爱、少佐的「我爱你」）；③最终选择（哪吒选择救人、薇尔莉特选择写「我爱你」）。
- **代入感来源**：每个人都有「被定义」的痛——反抗定义是普世爽点。
- **适合配角位**：救赎反转位（本书墨渊位·「继承父亲的善」）；堕落者的回归。

### 5. 感人亲情 / 羁绊型（白兔糖 / 狼的孩子型）
- **内核**：非血缘的羁绊比血缘更深；「养育」本身就是最深的治愈。
- **典型手法**：①时间跨度让成长可见；②主角的牺牲从不被煽情化（不哭天抢地）；③结尾轻轻一戳——多年后孩子叫了一声「爸爸/妈妈」。
- **代入感来源**：家庭温暖的普世向往。
- **适合配角位**：师徒传承（本书锤伯位已是）；男主作为「被养育者」的成长。

### 6. 反差萌 / 笨拙温暖型（阿尼亚 / 冯宝宝型）
- **内核**：呆萌/笨拙的外表下，是最纯粹的真。
- **典型手法**：①身份错位喜剧（阿尼亚知道父母身份、冯宝宝三无+绝世高手）；②「童言无忌」「天然呆」是破壁器；③反差战力（呆萌时被欺负，关键时刻碾压）。
- **代入感来源**：反差是角色设计的乘数；萌即正义。
- **适合配角位**：迪化喜剧型（本书邵半仙位已是）；男主和邦的萌宠/呆萌战力。

### 7. 见证者 / 记录者型（砚青对应型）
- **内核**：「被记录的才存在」——见证者的眼光让主角的存在被永久锚定。
- **典型手法**：①观察者原则（只记录不干预）；②第一次干预是核心转折点；③「几百年的记录」让历史感厚重。
- **代入感来源**：每个人都渴望被看见、被记住。
- **适合配角位**：记录者（本书砚青位已是）；循环见证（本书小曜位已是）。

### 8. 群像环绕主角的中心型（宋书航 / 克莱恩型）
- **内核**：主角不最强、不最深谋，但群像环绕他/她，因为主角是「磁场」。
- **典型手法**：①聊天群/塔罗会的组织形式；②成员各有完整人生；③「迪化」基于对主角的认可，不是恐惧。
- **代入感来源**：主角是普通人，但被一群特别的人环绕——读者代入「普通但不孤独」。
- **适合配角位**：群像中心位的男主本身就是（本书已是）。

## 三、感人虐心 / 悲壮 / bad end 设计模式（虐光谱）

> 虐 ≠ 为虐而虐。虐出升华或救赎，才有力量。

### 1. 转世续缘 / 错过型（狐妖 / 四月谎言 / 你的名字型）
- **内核**：相爱但因寿命/宿命/时间错过；虐在「前世记得、今生忘了」「她已走，但音乐还在」。
- **手法**：①制度化的希望（苦情树起誓）；②前世/今生双线对照；③升华——肉体的消逝 vs 精神的永存。
- **什么角色适合虐**：羁绊极深的主角/挚友；跨越时间的关系。
- **不廉价的关键**：虐的根在「规则」（寿命差/天道），不在个人恶意；虐的果是「升华」不是「绝望」。

### 2. 自我牺牲升华型（锤伯 / 温华断臂 / 林月如型）
- **内核**：为护他人/信念主动选择牺牲；「这次我先把心交出去，至少这次是我自己选的」。
- **手法**：①牺牲要有完整铺垫（不是剧情杀）；②代价形式独特（锤伯失去炼器能力、温华断臂折剑）；③临终释然（「这次没浪费」）。
- **什么角色适合虐**：师徒传承者；忠义两难者；为信念付出一切的人。
- **不廉价的关键**：①他/她有完整人生（不是工具人）；②主动选择（不是被迫）；③临终释然（不是绝望）。

### 3. 命运抗争悲壮型（精卫 / 夸父 / 刑天 / 进巨调查兵团型）
- **内核**：「明知不可为而为之」——注定失败也要做；抗争本身即是意义。
- **手法**：①把「注定失败」摆在台面（精卫填海填不满、调查兵团出墙必死）；②抗争的执念来自原型（女娲后人使命、几千年教化）；③悲壮演讲/仪式（埃尔文「放弃梦想，带人类走进真相」）。
- **什么角色适合虐**：悲壮反派；上代救世失败者；执念型神话原型新编角色。
- **不廉价的关键**：抗争有完整信念支撑；不是「无意义的死」，是「注定失败的坚持」。

### 4. 救赎未竟 / bad end 型（赵灵儿 / 薛恒型）
- **内核**：尽了最大努力，仍未能圆满——但失败本身震撼人心。
- **手法**：①留白结局（薛恒「残存的人 vs 夺舍的神」）；②悲剧有原型支撑（赵灵儿=白蛇雷峰塔）；③失败但不绝望（精神永存）。
- **什么角色适合虐**：被宿命/夺舍/教化困住的囚徒型反派；使命必死的悲剧英雄。
- **不廉价的关键**：bad end 是「最后的礼物」（薰的死是给公生的礼物），不是「剧情杀」。

### 5. 信念崩塌觉醒型（玄冥 / 江烬型）
- **内核**：一生信念被证伪——崩塌本身就是悲剧；觉醒之后是更深的绝望或救赎。
- **手法**：①信念有完整依据（玄冥的千年教义、江烬的「无善意出现」）；②崩塌瞬间的具现（玄冥 V8 揭晓天道=神族操纵）；③不同走向——玄冥凉（不治愈）、江烬嫉妒（待反转）。
- **什么角色适合虐**：反派/反派镜像；信念型角色。
- **不廉价的关键**：信念有血换的依据（不是偏见）；崩塌后的走向不是「千篇一律的洗白」——有的凉、有的救赎。

### 6. 永恒等待 / 守望型（白蛇雷峰塔 / 牛郎织女型）
- **内核**：跨不过的规则拆散的羁绊；等待本身就是最深情的告白。
- **手法**：①「规则」（天规/人妖殊途）作为反派；②时间跨度（二十年、五百年）；③等待者的执念不灭。
- **什么角色适合虐**：双救另一端的远方角色（本书周临位）；分隔两地的挚友。
- **不廉价的关键**：等待不是被动，是「明知你在远方我也守着」的主动选择。

## 四、配角独立设计原则（不依附主角的方法）

> 本书 `群像.md` 已立铁则「每个核心群像把男主从故事里抽走，角色的人生仍成立」。本节展开具体方法。

### 1. 从「是谁」长出，不从「功能位」拼贴
- **做法**：先写角色的完整人生（出身、家庭、伤口、执念、怪癖、语言风格），再把他/她放进剧情。
- **反面**：「我需要一个治愈主角的角色」→ 拼贴出「温柔善良的孤儿」→ 扁平。
- **正例**：锤伯的「不再认活物」从「小徒弟死在怀里」长出——这个伤口让他必然收男主为徒，但收徒不是他的「功能」，是他「卡了八十年的未完成」的释放。

### 2. 世界缩影法——配角是「这个世界某类人的缩影」
- **做法**：每个配角代表一个种族 / 一种立场 / 一类人的生存逻辑。
- **案例**：
  - 锤伯 = 地灵族「认死理·万物皆料」的种族缩影；
  - 玄冥 = 太一宗「灭妖=天道」的激进派缩影；
  - 昼 = 老牌妖王「护均衡」的职责缩影；
  - 商离 = 商修「利得思维」的职业缩影。
- **效果**：配角不依附主角——他/她代表的是「这个世界某类人」，主角只是他/她世界中的一个变量。

### 3. 横向涟漪——配角之间也有关系
- **做法**：群像之间有旧识/仇敌/师承/同门/血仇，不是「都跟主角有关系，彼此无关」。
- **本书已落**：锤伯 vs 陆离（天平旧识）、铁岚 vs 厄枭前任（弑主仇敌）、小牙 vs 周临（隐性涟漪·周临杀过的妖族可能有灵狸族人）。
- **效果**：群像立体，主角不在场时群像也互动。

### 4. 自己的议程——配角「不为男主而动」
- **做法**：配角有自己的目标（玄冥推灭妖战争、昼护均衡、商离做生意、冥守秩序），他们的行动基于自己的议程，主角只是变量之一。
- **反面**：配角「一直在等主角出现」——工具人。

### 5. 把主角抽走，角色的人生仍成立
- **校验问题**：如果主角没出现，这个角色在 10 年后会怎样？
- **正例**：温故——主角没出现，他还是在太一宗外救人，被逐出后做散修；他的人生不依赖主角。
- **反例**：「主角的镜子」「专门考验主角的角色」——抽走主角就空了。

### 6. 反迪化锚点 + 弱迪化调剂
- **做法**：在密集的迪化群像中，留 1-2 个「不迪化」「弱迪化」的角色。
- **本书已落**：温故（反迪化·真人族善意）+ 冥（弱迪化·秩序合作）。
- **效果**：证明「不是所有人都在误读」——让迪化不沦为「男主懵圈被脑补」的廉价套路，调剂节奏。

## 五、多经典角色融合杂糅手法（化学反应 1+1>2）

> 拼凑 1+1<1，化学反应 1+1>2。差别在「内核融合」还是「特质堆砌」。

### 1. 内核融合法（不是特质拼凑）
- **做法**：找几个原型的「内核共性」，融合成一个新内核。
- **案例**：冯宝宝 = 三无（凉）+ 绝世高手（强）+ 呆萌（暖）+ 失忆寻根（悲）——内核是「一个失忆的强大存在在陌生世界的孤独」，四个原型指向同一个内核，不是拼贴。
- **反面**：把「傲娇」+「吃货」+「战力」+「萝莉」堆在一起——没有内核，只是萌点堆砌。

### 2. 反差组合法（萌+战力 / 冷+暖）
- **做法**：用强反差让角色立体。
- **案例**：猫咪老师 = 保护者（强）+ 吃货（弱）；波吉 = 弱者（弱）+ 善良（强）。
- **关键**：反差不是「性格割裂」，是「同一个内核的两面」——猫咪老师的「保护」和「吃货」都是「他在人间找到的锚」。

### 3. 弧线叠加法（多重弧线交织）
- **做法**：让一个角色同时承载 2-3 条弧线。
- **案例**：江烬 = 上代救世失败者（悲壮弧线）+ 嫉妒男主被治愈（嫉妒弧线）+ 救赎反转可能（救赎弧线）——三条弧线交织，让反派立体。
- **关键**：弧线之间要有内在张力（江烬的嫉妒来自「我也想被救但没人救我」）。

### 4. 缺陷互补法
- **做法**：两个角色的缺陷正好互补，他们的羁绊来自「对方有我没有的」。
- **案例**：波吉（弱）+ 卡克（影子刺客）——波吉有善，卡克有力；他们的友谊是「我用我的力护你的善」。

### 5. 原型翻转法（融合后翻转经典预期）
- **做法**：借用经典原型，但翻转一个关键设定。
- **案例**：哪吒从「灵珠转世」翻转为「魔丸错投」——保留反抗精神的内核，但翻转宿命设定。
- **案例**：李靖从「冷酷父亲」翻转为「深爱孩子的父亲」——整部作品结构性反转。

### 6. 「化学反应 vs 拼凑」的检验
- **检验问题**：
  1. 这个角色的几个特质，是不是都指向同一个内核？是→化学反应；不是→拼凑。
  2. 把这个角色放在一个全新场景（非剧情场景），他/她会怎么反应？想得出→立体；想不出→拼贴。
  3. 这个角色有没有「不能被替代」的特质？有→化学反应；没有（换个角色也行）→拼贴。

## 六、多调性搭配原则（核心——暖虐悲壮混搭）

> 一部群像作品的厚度，取决于「调性光谱」的丰富度。全暖显浅，全虐显累。

### 1. 调性比例建议（针对迪化治愈流仙侠）
- **暖 70%（治愈为主调）**：温柔治愈 / 陪伴成长 / 反差萌 / 喜剧调剂
- **酸 15%（微酸·拉锯）**：同病试探 / 见证怀疑 / 信念动摇
- **虐 10%（感人虐·点睛）**：师徒牺牲 / 救赎反转 / 转世续缘
- **悲壮 5%（bad end / 悲壮反派）**：信念崩塌 / 救赎未竟 / 神话悲壮

### 2. 调性按卷分布（本书 12 卷）
- **V1 暖起步**：锤伯治愈种子（暖）+ 男主四层煎熬藏在温馨下（酸）
- **V2 末撕裂**：锤伯护阵牺牲（虐·点睛）+ 灵觉过载首现（酸）
- **V3-V5 暖累积**：铁岚效忠、小曜见证、商离反转、阿檀加入（全暖）
- **V6-V8 拉锯+伏笔**：江烬镜像考验（酸+悲壮）+ 墨渊孝心反转（虐·救赎）
- **V9-V10 摔跟头**：虚名破灭（酸+酸）——此处可加 1 处 bad end（薛恒残存 vs 夺舍）
- **第三幕 巅峰**：周临相认（暖·核弹）+ 玄冥信念崩塌（悲壮·凉）
- **终幕**：打破循环（暖·巅峰）+ 江烬救赎反转（虐·升华）

|------|--------|------------|
| 治愈锚点（暖） | 反迪化·真人族善意 | 温故 |

| 成长陪伴（暖） | 弟系·弱小者向上 | 小牙 |

| 见证者（酸→暖） | 循环活见证·最强战力 | 小曜 |
| 记录者（酸→暖） | 800 年观察者 | 砚青 |
| 喜剧调剂（暖·完全不碰治愈） | 迪化喜剧·乌鸦嘴 | 邵半仙 |

### 4. 经典群像的调性搭配案例
- **《修真聊天群》**：全暖 + 微酸（白前辈的离奇身世之谜做酸）。全群暖色，靠群友的「完整人生」撑厚度，不靠虐。
- **《诡秘之主》**：暖（塔罗会成员羁绊）+ 暗（末日/神降）+ 悲壮（神弃之地）混合。比例约 40/40/20。
- **《一人之下》**：疯批喜剧 + 暖（冯宝宝寻根）+ 悲（各角色的过往创伤）。比例约 50/30/20。
- **《雪中悍刀行》**：暖（兄弟义）+ 悲壮（温华断臂）+ bad end（多位配角的牺牲）。比例约 50/30/20。

### 5. 调性搭配的「三不一必须」
- **不连珠**：暖连暖会腻，虐连虐会累——必须穿插。
- **不孤立**：每个调性角色都要有「牵扯到主线」的关系——纯独立的喜剧角色会沦为工具。
- **不模板化**：同样是「虐」，锤伯的牺牲（升华）vs 玄冥的崩塌（凉）vs 薛恒的留白（bad end）走向不同——同光谱多走向。
- **必须有一个治愈锚点**：再虐的作品，也要有 1 个「不虐」的角色让观众喘息（温故位）。

## 七、针对「仙侠 + 迪化 + 治愈流」网文的推荐设计方向

### 1. 仙侠原生（不照搬日漫设定）
- **核心**：借鉴日漫原型的「内核」，换「仙侠原生外壳」。
- **案例**：夏目的「温柔治愈」内核 → 仙侠外壳可以是「老药师/守林人/茶馆老板娘」（不强大的普通人，男主疲惫时的归处）；猫咪老师的「萌宠陪伴」内核 → 仙侠外壳是「灵兽幼崽/古妖化身」。
- **禁忌**：直接把「哆啦A梦式机器人」「魔法少女」搬到仙侠——出戏。

### 2. 治愈累积 + 反迪化锚点（必须有）
- **核心**：治愈不靠「一个人拯救」，靠群像累积 + 一个真人族善意锚点。
- **本书已落**：温故（反迪化锚点）+ 群像累积善意。
- **建议**：再补 1 个「纯暖」治愈锚点（非锤伯的牺牲型，是夏目式的温柔环绕者，全程不撕）——见方案 1。

### 3. 多种族多调性搭配（六族框架）
- **核心**：六族（人/妖/鬼/魔/仙/灵）框架已天然提供「调性差异化」土壤——每族的生存逻辑不同，自然长出不同调性角色。
- **建议**：
  - 人族 → 镜子拉锯型（陆离·契约）/ 救赎反转（墨渊·孝心）/ 反迪化（温故·善意）
  - 妖族 → 成长陪伴（小牙·弟系）/ 镜像反派（江烬·堕魔）
  - 鬼/冥族 → 秩序合作（冥·清爽）/ 悲壮战将（铁岚·忠义）
  - 魔族 → 霸主反转（阿檀）/ 野心反派（厄枭）
  - 仙/灵族 → 见证记录（砚青·灵族）/ 信仰崩塌（玄冥·太一宗）
  - 地灵族 → 师徒传承（锤伯·牺牲）

### 4. 群像迪化网络的多节点差异化（已有 18 式，需调性平衡）
- **核心**：本书 18 人 18 式迪化模式已差异化（匠人/执念/嫉妒/犬儒/信仰/寄生/任务/制衡/原则/战略/认主/投资/霸主/自我/反迪化/孝心/使命/秩序）。
- **建议**：在此基础上做「调性平衡」——补 1-2 个纯暖节点（治愈锚点 / 萌宠陪伴），让迪化网络不全是「考验/拉锯」型。

### 5. 暖虐比 7:2:1
- 详见 §六·2。本书治愈流定位决定「暖」为主，但「虐」是不可或缺的点睛。

### 6. 迪化的「温度」控制
- **核心**：本书迪化是「治愈内核」的载体——迪化基于「对男主的认可」，不是「对男主的恐惧」。
- **对照《修真聊天群》**：群友的脑补基于宋书航的「好人」属性，不是恶意——这是迪化治愈流的范本。
- **对照《诡秘之主》**：塔罗会的合作基于「交易」，偏冷——不适合本书治愈调性。
- **建议**：本书迪化的「温度」要对齐《修真聊天群》——暖迪化为主，反派迪化（玄冥/江烬/戌迦）做冷色对照。

### 杂糅纪律（取 / 丢 / 配 三步法）

每个角色落地前，**必须明确三步**：

1. **取什么（只取 1-2 个特质）**：从经典角色身上取最打动人的那一点（情感共鸣点），不取外形/职业/情节。
   - 例：取哆啦A梦的「多法宝 + 陪伴解困」，不取机器猫外形。
   - 例：取夏目的「能感受不可见之灵 + 温柔孤独」，不取友人帐/还名字/猫咪老师。
2. **丢什么（明确剥离原角色外壳）**：原角色的标志性外形、职业、情节必须丢掉——否则就是套皮。
   - 反例：把哆啦A梦的「四次元口袋 + 机器猫」直接搬到仙侠 → 出戏。
3. **配什么原生载体（洪荒/修仙原生概念）**：特质配一个六界原生概念做载体，让角色天然属于这个世界。
   - 例：哆啦A梦特质 + 洪荒「多宝道人」（截教收万宝）概念 → 「多宝翁」（收集天下法宝、用法宝帮男主解困 + 陪伴）。
   - 例：夏目特质 + 修仙「阴阳眼/通灵感通/巫族感通」体质 → 通灵茶馆老板娘/老药师。

**校验问题**：这个角色有没有「日漫既视感」？有 → 套皮，重做；没有 → 杂糅成功。

## 九、本书配角设计方案建议（8 个具体方案·特质+原生载体杂糅法）

> **原则**：不新增冗余角色，优先**深化已有位置**（用经典特质照亮还没用足的角度），少量**填补光谱缺失位置**。
> **每个方案严格走「取 / 丢 / 配」三步法**——取 1-2 个打动人的特质 + 丢原角色外壳 + 配洪荒/修仙原生载体 → 杂糅融合。

### 方案 1【新增·纯暖治愈锚点】夏目特质 × 通灵感通体质

- **取什么特质**：夏目贵志（夏目友人帐）——**「能感受不可见之灵 + 温柔孤独」「不把伤害传出去」**。
- **丢什么**：友人帐、还名字情节、猫咪老师、招财猫形态、被欺凌的现代校园童年。
- **配什么原生载体**：**修仙「阴阳眼 / 通灵感通 / 巫族感通」体质 + 洪荒「隐世散仙」原型（济公/鬼谷子式游戏人间者）+「度人」法统**。
- **融合成什么角色**：人界边境或妖灵密林边缘的**通灵茶馆老板娘 / 老药师**（建议人族或地灵族边缘）——她天生阴阳眼能看见游魂/灵气，但**从不干预**，只是给路过的人/妖/鬼一碗茶、一帖药；不参与剧情主线、不知男主身份，把男主当「路过的小妖」款待。
- **撑什么剧情 / 调性**：
  - 纯暖累积（与锤伯的升华虐形成对照——锤伯是深暖，她是一碗茶的轻暖）；
  - 治愈拉锯中的喘息场景（V4-V5 虚名最高点、V9-V10 摔跟头时，男主去她那里坐一会儿）；
  - 终幕「她始终不知道我是谁」——男主建和邦后回茶馆，老板娘还是那句「小妖，又来啦」——**普通人的善意是男主最初的治愈，也是最终的归处**。
- **情感光谱定位**：纯暖（不撕不虐）。
- **与温故的差别**：温故是反迪化的真人族善意（参与剧情、有救人底线）；此角色是**非剧情性的日常善意**（不参与、只提供锚点）。

### 方案 2【新增·萌宠陪伴型·用户示范】哆啦A梦特质 × 多宝道人原型 → 「多宝翁」

- **取什么特质**：哆啦A梦——**「多法宝 + 陪伴解困」「陪伴不替代」**。
- **丢什么**：机器猫外形、四次元口袋、来自未来的机器人设定、大雄的具体情节。
- **配什么原生载体**：**洪荒「多宝道人」（截教收万宝的原型概念，非本人）+「散仙 + 法宝收藏家」流派 +「灵物认主」法统**。
- **融合成什么角色**：**「多宝翁」**——和邦中的一只老灵妖（建议千年蚌精/老灵兽/上古遗种），收藏天下法宝数百件，平时憨态可掬，男主遇困时掏出对应法宝救场；他认男主为「值得托付法宝的人」。
- **撑什么剧情 / 调性**：
  - 陪伴 + 法宝喜剧（每次掏法宝都有反差笑点）；
  - 迪化放大器（「连多宝翁都把法宝托付给他」→ 邵半仙编排成「妖王掌万宝」传说）；
  - **可藏虐线**：多宝翁收藏法宝的执念，是为补某个失去的人（如千年前的徒弟/旧友）——终幕揭晓，轻虐升华。
- **情感光谱定位**：纯暖+喜剧调剂（藏轻虐伏笔）。
- **与方案 7 的差别**：方案 2 是「老灵妖 + 法宝流」陪伴；方案 7 是「古妖 + 战力流」呆萌——避免功能重叠。

### 方案 3【深化·江烬的神话悲壮原型】宫园薰+埃尔文特质 × 蚩尤/刑天原型

- **取什么特质**：宫园薰（四月谎言）——**「用生命拉人出深渊」最后的礼物**；埃尔文（进巨）——**「注定失败的坚持」放弃梦想带人类走进真相**；莱纳——**「身份撕裂」**。
- **丢什么**：薰的小提琴/绝症/公生线；埃尔文的调查兵团/墙外真相/立体机动；莱纳的铠甲巨人/马来战士候补。
- **配什么原生载体**：**上代人族剑修第一人 +「堕魔」仙侠法统 + 洪荒「蚩尤/刑天」原型（被天庭定义为魔的反抗者）+「天劫化魔」机制（走火入魔/天罚）+「度劫未竟」概念**。
- **融合成什么角色**：江烬——上代人族救世剑修，被天庭陷害/同袍被屠/被当叛徒追杀/堕魔。**他的悲壮在「在没有善意的世界里坚持善被碾碎」**——「世界不值得救」是血换的经验，不是偏见。
- **撑什么剧情 / 调性**：
  - V6-V8 镜像考验（「凭什么你被救我没被救」嫉妒弧线）；
  - V8 真相揭晓（天道=神族操纵，信念崩塌——与玄冥呼应但走向不同）；
  - 终幕**两条走向可选**：①救赎反转（看见男主被治愈，「也许这次不一样」）；②bad end（没被治愈，与男主治愈网络擦肩，成为「注定失败的悲剧原型」）。
- **情感光谱定位**：感人虐·悲壮·救赎可能 / bad end（按整体调性定）。

### 方案 4【深化·小牙的「波吉+祢豆子」成长内核】波吉特质 × 妖修进化链

- **取什么特质**：波吉（国王排名）——**「弱小者向光生长」**；祢豆子（鬼灭）——**「家人羁绊 + 被弃恐惧」**。
- **丢什么**：波吉的聋哑王子/王位继承；祢豆子的鬼化/咬竹筒/哥哥依赖。
- **配什么原生载体**：**灵狸族少年 +「妖族血脉觉醒」法统 + 洪荒「灵兽修炼化形」原型（妖修进化链：幼妖→成妖→化形→大妖→妖王→妖神）+「匠心传承」法统（承锤伯）**。
- **融合成什么角色**：小牙（已落·可深化）——他学锤伯**不是「变得像锤伯」，是「长成自己的样子」**；他的目标不是「永远跟着师兄」，是「有一天我能护住别人」（终局灵狸族长老兼匠师）。
- **撑什么剧情 / 调性**：
  - V3-V5：小牙学细活，从「被护者」长成「能护人者」；
  - V9-V10：男主摔跟头时，小牙第一次反过来护男主（用锤伯传的手艺）；
  - 终幕：小牙救下另一个被族里放弃的灵狸幼崽，**「这次轮到我不丢下别人」**（已落，需具现场景）。
- **情感光谱定位**：温暖陪伴+成长型治愈。

### 方案 5【新增·神话悲壮反派/bad end】精卫+夸父+刑天特质 × 忠臣死谏原型 → 「万年神将」

- **取什么特质**：精卫填海——**「永不罢休」**；夸父逐日——**「明知不可为而为之」**；刑天舞干戚——**「注定失败也挥出最后一刀」**。
- **丢什么**：精卫的鸟形/填海动机；夸父的逐日/渴死；刑天的斩首/乳脐为目口。
- **配什么原生载体**：**神族天庭万年神将 +「天道执行者」自我认同 + 洪荒「忠臣死谏/义士」原型（比干剖心/伯邑考）+「天数/劫数」法统 +「天命职司」概念**。
- **融合成什么角色**：**万年神将**——真的信「灭妖是天道」，几千年执行；他的悲壮在「**他不是坏人，他只是被神族教化万年的受害者**」；与戌迦（万年监视者）同源但更老更深——戌迦是「上一代的他」，他是「上上代」。
- **撑什么剧情 / 调性**：
  - V6-V8 或终幕登场——他的存在让「神族不是纯粹的恶」；
  - bad end：终幕信念崩塌但**没有救赎**（与江烬的救赎可能形成对照——同样是「信念崩塌」，江烬被治愈，他没被治愈）；
  - 他的死是神话悲壮型——「明知注定失败，他还是挥出了最后一刀」。
- **情感光谱定位**：悲壮·bad end（凉）。

### 方案 6【深化·陆离的工具化治愈弧线】冈部朋也+薇尔莉特特质 × 散仙商修+天命契

- **取什么特质**：冈部朋也（CLANNAD）——**「用规则替代感情」的契约化防御**；薇尔莉特（紫罗兰）——**「工具 → 人」的渐变**。
- **丢什么**：朋也的时空穿越/中二病；薇尔莉特的代笔职业/机械手臂。
- **配什么原生载体**：**跨界商修 +「契约感知」天赋神通 +「散仙商修」流派（蜀山散仙 + 洪荒游商）+「天命契/因果契约」法统（修真界的因果契约/天道契约概念）**。
- **融合成什么角色**：陆离（已落·可深化）——契约是他用来替代「信任」的工具；他的弧线是从「履约工具」到「愿意停留的人」；与男主同病（错误公式变体：「我履约关系才存在」vs 男主「我有用才被爱」）。
- **撑什么剧情 / 调性**：
  - V3-V5：陆离每次试探男主（「你这么善，迟早被辜负」）→ 男主没变 → 陆离的契约感知一次次失灵；
  - V9-V10：虚名破灭时陆离崩溃「为什么你没变」→ 男主「因为有锤伯、有小牙、有你」；
  - 终幕：陆离把锤伯的天平捐给和邦市集（已落）——「终于愿意停留」的具现。
- **情感光谱定位**：治愈拉锯·暖累积。

### 方案 7【新增·反差萌战力】冯宝宝特质 × 上古大妖原型 → 「上古呆萌大妖」

- **取什么特质**：冯宝宝（一人之下）——**「三无 + 绝世高手」反差**；**「失忆寻根」**。
- **丢什么**：哪都通公司设定、张楚岚线、具体现代背景。
- **配什么原生载体**：**古妖/上古灵兽 +「沉睡千年魂魄不全」仙侠法统 + 洪荒「上古大妖/僵尸/旱魃」原型（将臣/旱魃式的远古存在）+「化形/夺舍/分神」法统**。
- **融合成什么角色**：**上古呆萌大妖**——男主和邦后期唤醒的古妖（建议远妖族血脉，如沉睡千年的妖将）；平时三无+贪吃+学不会人话，战斗时碾压 A 级；她的呆萌是「千年沉睡魂魄不全」的具现，**有恢复记忆的伏笔**——终幕可能反转（恢复记忆后变成另一种人格，或带着前世记忆离开）。
- **撑什么剧情 / 调性**：
  - 喜剧+反差战斗（呆萌时被欺负，战斗时碾压）；
  - 迪化（「连上古大妖都听他号令」→ 邵半仙编排「妖王驭古妖」）；
  - 隐藏虐线：终幕恢复记忆——可能是悲壮（前世记忆让她选择离开/牺牲）或暖（她选择留下，因为「这次有人对我好」）。
- **情感光谱定位**：反差萌+喜剧调剂（藏虐线/反转可能）。
- **与方案 2 的差别**：方案 2 是「老灵妖 + 法宝流」陪伴型；方案 7 是「上古大妖 + 战力流」呆萌型——功能不重叠。

### 方案 8【深化·邵半仙的「银时」底色】银时特质 × 江湖散仙原型

- **取什么特质**：银时（银魂）——**「懒散皮囊下的真心」「关键时刻守底线」**；阿尼亚（间谍过家家）——**「无心之言揭破真相」的破壁萌**。
- **丢什么**：银时的万事屋/武士刀/夜兔神乐组合；阿尼亚的读心超能力/实验体背景。
- **配什么原生载体**：**游方说书人 +「散修 + 江湖术士」传统（已落）+ 洪荒「江湖散仙」原型（济公/吕洞宾游戏人间）+「天机不可泄露/谶纬成真」法统**。
- **融合成什么角色**：邵半仙（已落·可深化）——他半生不得志、被同行排挤、怕自己的嘴，但**关键时刻（终幕）敢跟着男主去天庭**——「懒散皮囊下的大勇气」。
- **撑什么剧情 / 调性**：
  - V1-V8：邵半仙的喜剧外壳（已落）；
  - 第三幕：男主摔跟头时，邵半仙的乌鸦嘴预测了这件事——他**第一次「不想自己的嘴成真」**，他想阻止（但还是阻止不了）——「懒散皮囊」第一次裂开；
  - 终幕：他敢跟着男主去天庭（已落，需具现场景：战战兢兢跟着，嘴里念「贫道不去了不去了」，但脚步没停）。
- **情感光谱定位**：喜剧外壳+终幕英雄色彩（暖+一点点悲壮）。

### 方案备选（按需取用·覆盖剩余光谱）

**多样性纪律**（针对上一版配角设计的错的纠正）：
1. **不是全暖**——治愈流不等于「全员温柔」，要有 1-2 个 bad end 角色做厚度（薛恒、方案 5）。
2. **不是全虐**——不能让所有配角都「自残/暗黑/工具化」（上一版的错），暖仍是主调 70%。
3. **不是全为主角服务**——配角有自己的议程、伤口、世界（详见 §四）。
4. **不是全是镜子**——镜子位只 1-2 个（陆离+江烬），其余各位置独立。
5. **不是全概念**——温暖要落到具体场景（一碗茶、一句「可惜了」、一只萌宠、一次没走），不是冷冰冰的概念。

**最后一条铁律**：本书 `群像.md` 已立「**每个核心群像把男主从故事里抽走，角色的人生仍成立**」——这是配角独立的最高校验。本方案库所有建议都服从这条铁律。

>
> **每个角色落地前，必须走「取 / 丢 / 配」三步法 + 通过四道校验**：
>
> **三步法**：
> 1. **取**：从经典角色身上只取 1-2 个打动人的特质（明确写出取了什么）
> 2. **丢**：明确剥离原角色的外形/职业/情节（明确写出丢了什么）
> 3. **配**：配一个洪荒/修仙原生的概念/法统/原型做载体（让角色天然属于六界）
>
> **四道校验**：
> 1. **校验 1（独立性）**：把男主抽走，这个角色的人生还成立吗？
> 2. **校验 2（杂糅度）**：是「特质 + 原生载体」化学反应，还是「日漫角色套仙侠皮」？**有日漫既视感 = 套皮，重做**。
> 3. **校验 3（调性平衡）**：这个角色在调性地图中是哪个位置？与已有角色是否重叠？
> 4. **校验 4（原生度）**：载体是不是洪荒/修仙原生概念？是否抄了具名角色本人（多宝道人/通天/二郎神等）？**抄概念不抄具名角色本人**（本书是原创仙侠，世界观与人物全部原创）。
