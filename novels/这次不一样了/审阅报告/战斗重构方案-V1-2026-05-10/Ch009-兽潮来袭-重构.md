# Ch009 兽潮来袭 -- 重构方案

## 一、现有诊断

### 问题清单

| # | 严重度 | 描述 |
|---|--------|------|
| 1 | 高 | 兽潮描写缺冲击力。现有描写"荧光像潮水一样铺满了地平线"是远景，但缺从远处到近处的动态过程——读者感受不到"扑面而来"的压力 |

## 二、分镜设计

### 2.1 兽潮远景段（替换L25-L33）

**设计目标**: 从远景到中景的动态推进，制造"从远处到扑面而来"的压迫感。

**分镜序列**:

```
[远景·全景]
地面在抖。不是一下一下——是持续。碎石在脚下滑，管壁的铁皮发出嗡嗡的共振声。
西边。天际线上，灰绿色的荧光在雾气里翻涌。不是一层墙——是无数个点。

[远景→中景·推进]
荧光在移动。从地平线蔓延过来，越来越近。越来越密。
每个荧光点是一只灰蜥。指甲盖大小的灵能结晶嵌在鳞片上，在黑暗中闪着暗绿色的光。
前排的灰蜥已经进了废墟外围。四条腿贴着地面跑，尾巴拖着一串灵能残渣的微光。

[中景·管道区]
聚落西面的管道缝隙里开始传来声音。金属碰撞——灰蜥撞上管壁。爪子刮铁皮的声音。
尖锐。密集。越来越近。像有人在用指甲刮黑板，但不只一个人——是上百个。

[近景·NPC反应]
聚落西边有人尖叫。
阿婆的声音——不是喊叫，是那种老年人特有的、用尽全身力气的嘶哑："堵上！堵上！"
```

### 2.2 T1灰蜥群突入段（替换L31-L43）

**设计目标**: 展示灰蜥的灵能结晶追踪机制、群战波次、个体差异。

**核心新增内容**:

1. **灵能结晶追踪**: 灰蜥不是乱跑——它们的灵能结晶会感应灵能浓度高的物体（活的比死的热、有灵能装备的更热）。聚落里有照明石、灵能陷阱、人的体温，所以聚落比周围废墟更"亮"。

2. **群战波次**: 不是一窝蜂涌入，而是前排先锋→主力跟进→尾波散兵的三波结构。

3. **个体差异**: 第一只灰蜥比其他的小（先锋往往是最快的个体），有只灰蜥的灵能结晶比其他的亮（可能是吃过更多灵能残渣的变异个体）。

**分镜序列**:

```
[中景·灰蜥先锋]
第一批灰蜥不到十只。比后面的都小——腿长，身子窄，灵能结晶特别亮。
它们不绕路。直奔聚落。灵能结晶在鳞片上闪——不是发光，是感应。它们在追灵能浓度最高的方向。聚落里有照明石、有灵能陷阱、有活的体温。在灰蜥的感知里，聚落像暗夜里的一盏灯。

[近景·灰蜥冲管道]
一只灰蜥从管道上方跳下来。不是爬——是跳。后腿蹬了一下的力气，四条腿在空中张开，灵能结晶在鳞片上闪了两下。落地。爪子在碎石上打滑，但它不减速。直线冲最近的热源——老陈。

[特写·灵能结晶]
灰蜥的灵能结晶在鳞片上像一颗暗绿色的玻璃珠。结晶在发热——它在感应前方灵能波动。人的体温、照明石的光、老陈手里铁棍上残留的灵能灼烧痕迹。全部在结晶的感应范围内。
```

### 2.3 沈野碎片感知段（替换L63-L66附近）

**设计目标**: 沈野的拓印能力在战斗中的第一次体现——他通过碎片"读"到灰蜥的灵能频率。

**分镜序列**:

```
[近景·沈野感知]
碎片烫得他后背出了汗。牵引感从碎片里炸开——不只是方向了。他能"读"到东西。
灰蜥的灵能频率。单层回路。简单。像一根绷紧的弦，震了一下就能断。
他闭了一下眼。牵引感网里，灰蜥的灵能频率像萤火虫一样亮着——七个在聚落外围，三个在管道缝隙里，两个在——

[快切]
他的眼睛睁开了。
"右边管道！"他喊。"有东西进来了！"
```

### 2.4 T2出场段（替换L51-L61）

**设计目标**: T2的远景压迫感——不是"缓慢推进"，而是"压迫性的存在"。

**分镜序列**:

```
[远景·T2]
然后他看见了第二波。
灰蜥群的后面。更深处。更大的影子在荧光里移动。
灰白甲壳。灵能纹路在甲壳上发光——不是T1的暗绿色，是更亮的灰白色，像骨头烧了之后的颜色。
第一只T2从废墟管道上方翻过来。四条腿着地，碎石在它脚下崩裂。它比灰蜥大三倍。前肢粗短，像两把铲子。头部突出的灵能结晶镶嵌在甲壳上，在黑暗中闪着冷光。

[特写·T2灵能纹路]
甲壳上的灵能纹路不是画上去的——是甲壳本身的纹理在发光。纹路从头部延伸到背脊，像血管一样在灰白甲壳下流动。每一条纹路都带着微弱的灵能脉冲，让周围的空气都在震。

[慢镜头·T2压迫]
它停了。不是累——是看。头部的灵能结晶缓缓转动，像雷达一样扫过聚落。它没有冲。它不需要冲。灰蜥群在前面开路，它在后面走。
三只T2。灰蜥群的后面排成一条线。像牧羊犬在赶羊。
```

## 三、关键段落改写

### 改写段1: 兽潮到来全景（替换原文L1-L33）

```
地面在抖。

不是地震那种——是一下一下的、有节奏的、从远到近的震动。碎石在管壁上沙沙响。铁皮接缝处发出嗡嗡的共振声。沈野从管道缝隙往外看。天没有全黑——西边的天际线上有一层淡淡的荧光。不是晨光。是灵能。灰绿色的光贴着地面涌过来，像一堵缓慢推进的墙。荧光里能看见雾气在翻涌，雾气里夹着焦糊味。焦糊味很重。比平时重十倍。像有人把一整条灵能管路烧了。

他把手按在背包上。碎片贴着后背——烫。不是微热。是烫。牵引感从碎片里涌出来，像一根绳子往西边拽。

然后他看到了。

荧光不是一层墙。是无数个点。从西边废墟的管道上方涌过来，灰绿色的荧光像潮水一样铺满了地平线。每一个荧光点是一只灰蜥。指甲盖大小的灵能结晶嵌在它们的鳞片上，在黑暗中发出暗绿色的光。前排的灰蜥已经进入废墟外围——四条腿贴着地面跑，尾巴拖着一串灵能残渣的微光。它们跑的方向不是随机的。直线。奔着聚落来的。

灵能结晶追踪。灰蜥的结晶会感应灵能浓度高的物体。聚落里有照明石、有灵能陷阱、有活的体温。在灰蜥的感知里，聚落像暗夜里的一盏灯。

第一批不到十只。先锋。比后面的都小——腿长身子窄，灵能结晶特别亮。它们从管道缝隙里钻进来，爪子刮铁皮的声音尖锐密集。像有人在用指甲刮黑板——但不只一个人。上百个。

然后他看见了第二波。灰蜥群后面。更深处。更大的影子在荧光里移动。灰白甲壳。灵能纹路在甲壳上发光——不是T1的暗绿色，是更亮的灰白色。一只T2从废墟管道上方翻过来。四条腿着地，碎石在脚下崩裂。它比灰蜥大三倍。前肢像铲子，头部突出的灵能结晶镶嵌在甲壳上，闪着冷光。甲壳上的灵能纹路从头部延伸到背脊，像血管一样在灰白色表面下流动。每一条纹路都带着微弱的灵能脉冲，周围的空气在震。它停了。头部的灵能结晶缓缓转动，像雷达扫过聚落。不是冲。不需要冲。灰蜥群在前面开路。它在后面走。三只T2。在灰蜥群后面排成一条线。
```

### 改写段2: 碎片感知增强（替换原文L63-L66）

```
碎片烫得他把背包甩到了胸前。牵引感从碎片里炸开——不是一根绳子了。是一张网。从碎片向四面八方延伸。他的手指能"读"到周围灵能体的轮廓。管道壁上的灵能残渣。地面上散落的碎渣。前方三只灰蜥的灵能频率——单层回路，简单，像一根绷紧的弦。七只在聚落外围。两只在管道缝隙里。更远——T2的巨大灵能频率。灰白色。三层嵌套。像一堵墙。

太密了。太多。信息像洪水灌进手掌，他的手指在发抖。
```

## 四、异兽风格设计

### T1灰蜥（本章）

| 维度 | 设计 |
|------|------|
| 追踪方式 | 灵能结晶感应灵能浓度（追热的），照明石/体温/陷阱都是热源 |
| 群战模式 | 先锋→主力→尾波三波，先锋最快最小，主力数量最多，尾波是掉队的散兵 |
| 个体差异 | 先锋个体比其他小但快；有变异个体结晶更亮；饥饿的灰蜥更凶 |
| 弱点 | 灵能结晶——碎了就失去追踪能力和攻击力；笨——只会直线追 |
| 行为特征 | 进管道后变灵活（管道宽度刚好够转身）；同类尸体前会犹豫（舔空气嗅血） |
