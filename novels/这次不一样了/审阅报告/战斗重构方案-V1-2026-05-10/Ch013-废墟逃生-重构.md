## 二、分镜设计

### 2.1 灰蜥vs鳞兽差异化段

**设计目标**: 沈野在这章先后遇到灰蜥和鳞兽，两者的行为要有明显差异。

**对比设计**:

| 维度 | T1灰蜥 | T1鳞兽 |
|------|--------|--------|
| 追踪 | 灵能结晶感应（追热的） | 视觉+嗅觉（看到就追） |
| 速度 | 快但只能直线 | 比灰蜥快一倍，能微调方向 |
| 身体 | 四条腿，肩宽超过管道口径 | 扁平身体，能压缩挤进窄道 |
| 弱点 | 灵能结晶碎了就废 | 翻过来四脚朝天就翻不了身 |
| 声音 | 爪子刮铁皮的尖锐声 | 背脊灵能线刮管壁的咝咝声 |
| 荧光 | 结晶暗绿色点状 | 背脊一排细线状 |

**灰蜥段（L1-L30附近）**:

```
[中景·灰蜥逼近]
灰蜥蹲了一下后腿。要扑了。
沈野的手摸到了刮刀。他的碎片在背包里发烫——牵引感在灰蜥身上震。他能"读"到灰蜥的灵能结构：单层回路。简单。比管壁上的残渣还简单。但回路里有一股热量——灵能追踪本能。灰蜥的结晶正在锁定他。他的碎片灵能浓度比周围环境高——在灰蜥眼里他是一盏灯。

[快切·逃脱]
灰蜥扑了。
沈野往左滚。碎石打滑。摔倒。肩膀蹭在管道拐角的铁锈上。灰蜥的爪子擦着他的肩膀过去——指甲在碎石上划出火星。肩膀上一道火辣辣的疼。皮划了。不深。
他翻身爬起来。灰蜥也转身了。比他快。蹲后腿。又要扑。
不跟它打。

[中景·引诱]
沈野掏出一块碎片——普通的灵能碎片，不是五层嵌套的。他的手指碰到碎片的一瞬间，拓印本能自动运作：碎片的灵能浓度比灰蜥结晶高一截。扔过去会产生一个灵能脉冲。灰蜥的结晶追踪本能会锁定脉冲源——至少三到五秒。
够了。
他往灰蜥身后扔。碎片砸在碎石上。灵能结晶碎裂——一声脆响，一闪绿光。
灰蜥转头。本能。灵能脉冲吸引了它。它转身往碎片方向窜了一步。
就这一步。
```

**鳞兽段（L56-L78附近）**:

```
[中景·鳞兽出场]
第二只不是灰蜥。是鳞兽。
比灰蜥长。更扁。四条腿贴地跑的时候像一条灰色的蛇。灵能结晶不在鳞片上——在背脊上。一排细细的发光线，像脊椎骨长在外面。荧光不是点状的暗绿色——是线状的灰白色。
鳞兽比灰蜥快。快一倍。
沈野刚从管道里出来。鳞兽就看到了他。它没有蹲下——直接冲。直线。不犹豫。鳞兽不需要灵能追踪——它看到了。

[快切·追击]
沈野转身跑。
鳞兽在身后。十步。八步。五步。碎石在脚下打滑。
前方——废墟夹道。两截断裂管道交叉的窄巷。只够一个人侧身过。
沈野冲进去。
鳞兽也冲进来——但它的身体比夹道宽。背脊上的灵能线刮着管壁。火星四溅。咝咝声。和灰蜥的尖锐爪声不一样——鳞兽的声音是连续的、像蛇吐信。
它还在挤。鳞片叠在一起——像手风琴一样收缩。身体能压缩。它还在往里挤。

[近景·沈野看到陷阱]
沈野看到了脚下的东西。
灵能陷阱。旧的。触发器埋在碎石里。感应线裸露在外。碎渣弹还连着。他不知道还能不能用——灵能被灰蜥吸了一波，浓度下降了。
他的手指碰到感应线的一瞬间——拓印本能。碎渣弹的灵能结构：核心碎了60%，残余灵能不能引爆完整的碎渣弹。但如果有一个外力触发——比如一个足够大的灵能脉冲——也许能引爆残余。
也许。

[快切·引爆]
他没有选择。
弯腰捡起感应线。线头在手里绕了两圈。继续跑——往夹道另一端。感应线从他手里拉出来，在碎石上拖出一条线。
鳞兽在后面挤。背脊灵能线碰到了感应线。
碎渣弹炸了。闪光在夹道里炸开。灰白色的灵能冲击波把鳞兽推了回去。鳞兽的身体在冲击波里翻了个个——四条腿朝天。
它还在动。没死。但翻了。扁平的身体在夹道里翻不了身。四条腿在空中划。背脊上的灵能线一闪一闪——像一排快灭的灯。
```

### 2.2 管道快切段（沈野在管道内逃跑）

**设计目标**: 管道内是沈野的主场——他认识这片废墟比认识自己的手还熟。用快切展示他的逃跑技术。

```
[快切·管道内]
弯腰。半蹲。往前挪。灵能残渣在脚下沙沙响。
前方弯道。左拐。
头顶有滴水。灵能残渣的水。不要碰。
前方截面。碎石堵了一半。侧身。挤过去。背包卡了一下。拽。
管壁上有铁锈。手指摸着走。左边管壁光滑——这段管道以前是灵能输送管，内壁打磨过。右边粗糙——焊接缝。
前方分叉。左边通第二区排水系统。右边是死路。
左拐。
碎片的牵引感在黑暗里延伸——弯道、截面、连接处。管道的路线在他脑海里像一幅画。他闭着眼都能走。
但他在跑。不是走。弯着腰半蹲着跑。膝盖撞在管壁上。疼。不管了。
出口。圆形的。直径比这端大。外面的荧光。
```

## 三、关键段落改写

### 改写段1: 沈野引诱灰蜥（替换原文L18-L25）

核心改动:
- 增加"拓印本能判断碎片灵能浓度"的描写
- 碎片扔出后灰蜥的反应增加细节：灵能脉冲→结晶锁定→转向窜一步
- "就这一步"保持

### 改写段2: 鳞兽出场（替换原文L56-L63）

核心改动:
- 鳞兽和灰蜥的视觉差异：点状暗绿→线状灰白
- 鳞兽行为差异：不蹲下直接冲、能看到就追不需要灵能追踪
- 鳞兽声音差异：咝咝声（像蛇吐信）vs灰蜥的尖锐爪声

### 扩写建议: 沈野救受伤女人段

原文太仓促。建议增加:
- 沈野差点踩到她的快切
- 女人受伤的视觉细节（肩膀上的洞、布条没缠紧、血的颜色）
- 两人无声交流的细节（她看了他一眼，眼睛亮了一下——认出来了。没说话。在废墟里不需要说话。）
- 沈野给布条时手指碰到她手的触感（冰的、在抖）

## 四、异兽风格设计

### T1鳞兽（本章首次出场）

| 维度 | 设计 |
|------|------|
| 外形 | 比灰蜥长更扁，四条腿贴地跑时像灰色蛇。背脊一排细线状灵能结晶 |
