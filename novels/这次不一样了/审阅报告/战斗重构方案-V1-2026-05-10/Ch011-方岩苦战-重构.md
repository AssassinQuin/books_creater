# Ch011 方岩苦战 -- 重构方案

## 一、现有诊断

### 问题清单

| # | 严重度 | 描述 |
|---|--------|------|
| 1 | 高 | T2战斗描写过于概括。"方岩没有退。他冲了上去"→一刀→弹开→受伤→退进管道。全过程不到200字。这是全书第一次正面T2战斗，需要充分展开 |
| 2 | 高 | T2没有主动攻击行为描写。只写"前肢像铲子一样横扫"，缺T2的攻击节奏、攻击范围、和环境互动 |
| 3 | 高 | 方岩体力消耗过程不够细腻。应该有清晰的递进：灵能短刀光变暗→体力下降→判断力开始出错→最后的绝境 |
| 4 | 中 | 夹道死角的描写不够绝望。三只灰蜥+T2前肢夹击，应该是最危险的时刻，但紧张感不够 |
| 5 | 低 | 缺方岩的心理活动。15年前北境也是这样——这段回忆应该更具体 |

## 二、分镜设计

### 2.1 方岩vs T2 完整战斗段

**设计目标**: 这是全卷最重要的战斗段落之一。方岩作为15年老兵，第一次遇到"北境经验不够用"的敌人。战斗要有节奏：试探→发现不对→硬上→失败→受伤→撤退→绝境。

**分镜序列**:

```
[中景·对峙]
方岩和T2隔着碎石地对峙。
T2没有动。头部的灵能结晶缓缓转动，灰白色的光在结晶内部流动。它在扫描方岩——不是看，是读。T2的结晶能感应灵能波动。方岩手里灵能短刀的冷白光在T2的感知里像一盏灯。

[快切·方岩冲锋]
方岩冲了上去。跑的时候右膝弯了一下——旧伤。重心偏左。右脚落地快一点，别让膝盖受太多力。壁盾的斥候没有腿好的。腿好的去了步兵营。跑了十年以上的，没有腿没伤的。
十五步。T2的前肢抬起来了。

[特写·第一刀]
短刀从右上方劈下去。灵能冷白的光划过空气，直奔T2脖子和甲壳的连接处。
北境的经验。四个T2都是这么杀的。脖子和甲壳的连接处——鳞片最薄，灵能纹路最稀疏。一刀下去，甲壳和脖子的灵能结构断裂，头掉了。

[慢镜头·弹刀]
刀刃碰到了甲壳。
碰。
不是切入。不是卡住。是碰。像碰到了一面弹性极强的墙。
甲壳表面的灵能纹路在刀刃接触的瞬间全部亮了——不是被切割的闪，是反击的闪。灵能从纹路里涌出来，沿着刀刃往刀柄灌。方岩的手腕一麻。短刀弹开了。弹开的轨迹在灵能光里画了一道弧线。
甲壳上没有痕迹。灵能纹路恢复流动，像什么都没发生过。

[近景·方岩判断]
不对。
方岩的脑子里只有这两个字。
北境的T2，甲壳能切进去。切开之后有五厘米的灵能结构断裂带。五厘米够让灵能切割渗透进去，震碎颈部灵能回路。
刚才那一刀——零厘米。甲壳表面连白印都没有。灵能纹路把冲击力分散了。
这只T2的甲壳比北境的厚了不止一倍。

[快切·T2反击]
T2的前肢横扫。铲子一样的爪子带着灰白色的灵能光，从左到右，横扫方岩的腰部高度。
方岩往后跳。右膝弯了——不够快。旧伤拖了他零点二秒。
铲子的边缘刮过他的右腿。从膝盖下方到大腿外侧。不是划。是刨。前肢上的灵能结晶带着灵能切割效果——物理切割加灵能切割双重效果。裤子被撕开。皮肉翻开。血涌出来。红的。热的。在T2的灵能光里是灰色的。
方岩闷哼了一声。不是疼——是方岩这种人不会喊疼。是本能的声音，像被人打了一拳从胸腔里挤出来的气。

[中景·退进夹道]
他退。
不是转身跑——是面朝T2后退。壁盾的斥候不把后背留给敌人。
退进废墟夹道。两截断裂管道形成的窄巷。T2的身体比夹道宽。它挤不进来。
方岩知道这个。他在北境用过这种战术。废墟是屏障。管道是城墙。
壁盾的斥候有句话："打不过就跑，跑不了就缩，缩不了就死。"

[近景·T2尝试挤入]
T2站到夹道入口。四条腿撑在碎石上，头探了进来。夹道只够它的头和前肢。前肢伸进来——铲子在管壁上横扫。铁皮被刮下来一片。铁屑在灵能光里飞。
方岩贴着另一侧管壁。肩膀蹭在粗糙的铁皮上。血从肩膀渗出来——不是T2抓的，是管壁上锈蚀的铁刺划的。比右腿的伤少，但疼。
右腿在流血。血顺着裤腿流到碎石上。碎石上的血在灵能光里是灰色的。
短刀的灵能光暗了。杀五只T1的消耗加上一刀劈T2甲壳被弹开的反噬——灵能碎渣仓快空了。

[特写·新威胁]
然后三只新的T1从夹道另一端钻进来。
灰蜥。灵能结晶在鳞片上闪。
它们闻到了血的味道——方岩右腿上的血，肩膀上的血，夹道里全是血的味道。灰蜥的灵能结晶追踪本能比视觉灵敏。它们不需要看到他。闻着血的灵能波动就来了。

[中景·绝境]
方岩退到了夹道的死角。前面是T2的前肢，在管壁上一下一下地横扫。后面是三只灰蜥，蹲下来准备扑。右边是管壁。左边也是管壁。
灵能短刀的灰光微弱得像一根快灭的蜡烛。
他的右腿在流血。短刀快暗了。体力见底。
方岩半跪在夹道里。左手撑着地。右手握着短刀。灰光在刀刃上摇摇欲坠。

[慢镜头·回忆]
三只灰蜥逼近了。它们的动作比前面的五只慢——不是体力差。是谨慎。它们闻到了同类的血。五具灰蜥尸体在夹道外面的碎石上。这三只灰蜥在尸体前面蹲了下来，舌头伸出来舔了一下空气。
血的味道。方岩的血。
它们蹲下后腿。准备扑。

方岩没有闭眼。他抬头。夹道上方——星空被废墟挡了一半，只剩几颗星星。十五年前在北境也是这样。T2围上来，短刀快暗了，腿流着血。那次他倒下了。醒来在医院。八个人没醒过来。
这次没有医院了。也没有队友了。
```

## 三、关键段落改写

### 改写段1: T2弹刀+受伤（替换原文L41-L53）

上面的分镜2.1已经是完整改写。核心改动:
- 原文"刀刃碰到了甲壳。弹开了" → 扩展为完整的弹刀过程：碰→灵能纹路反击闪→刀刃弹开弧线→甲壳无痕迹
- 增加"北境经验不够用"的判断过程：五厘米→零厘米
- T2反击从"前肢横扫→刮过右腿"扩展为完整动作链：横扫→方岩跳→旧伤拖了零点二秒→铲子刨开右腿→双重切割效果

### 改写段2: 绝境段（替换原文L64-L92）

核心改动:
- 增加"面朝T2后退"的壁盾斥候习惯
- 增加灰蜥在同类尸体前犹豫的行为（和Ch010第3只灰蜥一致）
- 方岩回忆从"十二个名字"具体化为一句话："十五年前在北境也是这样。八个人没醒过来。"

## 四、异兽风格设计

### T2锐化体（本章详细战斗）

| 维度 | 具体表现 |
|------|---------|
| 防御 | 甲壳灵能纹路能吸收灵能攻击并反弹，北境一刀能切五厘米，外环这只零厘米 |
| 攻击节奏 | 缓慢但精准。不急躁。前肢横扫范围大（腰部高度），带灵能切割效果 |
| 智能 | 会扫描灵能波动（结晶像雷达）。会在夹道入口用前肢试探而不是硬冲 |
| 追击 | 不追进窄道——身体太大。但会伸前肢进去横扫。管壁被刮得铁屑纷飞 |
| 与T1关系 | T1灰蜥在T2身后更胆大——T2的灵能压制让灰蜥的本能攻击性增强 |

| 角色 | 展示点 | 具体表现 |
