## 二、分镜设计

### 2.1 方岩杀5只T1 -- 逐一分镜

**设计目标**: 5只灰蜥，5种不同的击杀方式，展示壁盾斥候15年经验。

**核心原则**: 不是"一刀一个"的重复，而是每一只都利用不同的环境因素和经验判断。

**分镜序列**:

```
[中景·包抄态势]
五只灰蜥从废墟管道缝隙里钻出来。不是一字排开——是扇形包抄。
左边两只，右边两只，正前方一只。
正前方那只最大。灵能结晶在鳞片上闪着暗绿色的光。
方岩站在碎石地上。灵能短刀握在右手。左手的军用包还背着——里面有碎渣弹和灵能陷阱。但他来不及用。

[第1只·正面硬接]
灰蜥先动了。正前方那只。它蹲了一下后腿，四条腿蹬地。
方岩没有退——他侧身一步。灰蜥的爪子从他左肩旁边划过去，爪尖在棉衣上留下三道口子。方岩等的就是这一下。灰蜥扑完之后有一瞬间的停顿——后腿落地还没发力。壁盾斥候管这个叫"空档"。零点三秒。
短刀从下往上一撩。灵能冷白的光划过灰蜥腹部——鳞片最薄的地方。灵能切割不是物理切割，是灵能频率震碎鳞片的灵能结构。灰蜥的腹部裂开，内脏和灵能残渣一起涌出来。它倒在地上，灵能结晶闪了两下，灭了。

[第2只·地形利用]
右边第一只。它绕了半圈，从一段塌了一半的管道上方扑过来。
方岩没有抬头——他听到了。灵能频率变化在脑海里画了一条线：从高到低，从右到左。从上面来。
他往前跨了一步——不是躲避，是站位。灰蜥从他头顶扑过去的瞬间，方岩的短刀往上反刺。刀刃扎进灰蜥的下颌——鳞片和头骨的连接处。灵能切割从内部震碎了灵能结晶的基座。灰蜥的身体在空中痉挛了一下，落地。灵能结晶碎了，暗绿色的粉末散在碎石上。

[第3只·利用尸体]
左边第一只。它看到同伴的尸体——蹲了一下后腿，舌头伸出来舔了一下空气。血的味道。
犹豫。灰蜥不是完全没脑子。它在判断。
方岩等了它一秒。
然后他踢了第一只灰蜥的尸体。尸体滑过碎石地，撞在左边那只灰蜥的前腿上。灰蜥被撞歪了一步——那一瞬间它的灵能结晶闪了两下，注意力从方岩转移到尸体上。本能。追热的。
方岩三步冲上去。短刀横劈。刀刃从灰蜥的脖子上划过，灵能结晶连着一截颈椎飞出去。

[第4只·转身反击]
右边第二只。从侧后方来。快。它没等同伴死就冲了——年轻的那只，灵能结晶比其他的亮，可能是最近吃了更多灵能残渣。
方岩听到了。灵能频率在他的地形感知里是一条急速上升的线。来不及转身。他用背对着灰蜥——不是失误。是计算。
灰蜥的爪子从背后扑过来。方岩的左手肘往后一撞——撞在灰蜥的下巴上。不重，但够让它偏头。偏了半寸。爪子从他肩膀旁边划过——棉衣撕了一条口子，皮蹭破了一层。
方岩借着这一撞的力转身。短刀从左往右横扫。刀刃砍在灰蜥的前腿关节上——关节处没有鳞片。灵能切割把前腿从关节处整齐地切了下来。灰蜥翻了，三条腿在地上划，灵能结晶在慌乱中闪得像信号灯。方岩走过去。一刀。捅进灵能结晶。灭了。

[第5只·耗死]
最后一只。没有冲。它站在管道缝隙的边缘，灵能结晶在鳞片上闪着不稳定的暗光。它看着地上的四具同类尸体。舌头缩回去了。它的后腿在抖——不是怕，是本能的犹豫。灰蜥群有等级。这只最小。等级最低。前面的都死了，轮到它没有指挥。
方岩喘着粗气。短刀的灵能光暗了——杀四只灰蜥消耗的灵能已经让刀刃上的光从冷白变成灰色。
他没有追。他站在原地。短刀横在身前。看着那只灰蜥。
灰蜥也看着他。灵能结晶闪了两下。然后它转身。钻回了管道缝隙。
方岩没有追。壁盾的斥候有句话——"追穷寇是步兵的事，斥候的命是留着回来的。"
```

### 2.2 T2出场慢镜头段

**设计目标**: T2从"管道上方翻过来"到"方岩的短刀弹开"的过程需要慢镜头展开。

**分镜序列**:

```
[远景→中景·T2翻过管道]
碎石滚落的声音从上方传来。不是碎石——是重量。很重。
方岩抬头。

[慢镜头开始]
一只灰蜥的前肢从管道截面上方伸出来——不对。不是灰蜥。是灰白色的甲壳。甲壳上的灵能纹路在发光，灰白色的光从纹路缝隙里渗出来，像裂开的灯泡。
然后是头。比灰蜥大三倍。头骨上镶嵌着一块突出的灵能结晶——不是灰蜥指甲盖大小的结晶，是拳头大的、灰白色的、内部有纹路在流动的结晶。
前肢。像铲子。不是爪子——是两把铲子。铲子的边缘有灵能切割的微光，像刀刃。
四条腿着地。碎石在它脚下崩裂。它站起来的高度到方岩的胸口。

[特写·方岩判断]
方岩的短刀亮了一下——不是灵能，是刀刃反射了T2甲壳上的灵能光。
他在北境见过T2。杀过四个。但北境的T2——灵能浓度低，甲壳薄，灵能纹路弱。眼前这只的灵能纹路亮得像刻在甲壳上的文字。甲壳的厚度比北境的厚了一倍。灵能结晶的密度——
他心里算了一下。
外环。灵能浓度0.41。还在涨。
外环不该有这种东西。

[快切恢复]
T2的前肢抬起来了。
方岩冲了上去。
```

## 三、关键段落改写

### 改写段1: 方岩杀5只灰蜥（替换原文L13-L27）

这段内容太长，上面的分镜2.1已经是完整改写。直接替换即可。

核心改动:
- 原文"每一刀都精准——不浪费力气，不花哨。壁盾斥候的战斗方式：一刀一个，专打弱点" → 改为5只灰蜥的逐一分镜，每只不同的杀法
- 增加"空档"概念（壁盾斥候的战斗经验术语）
- 增加灰蜥犹豫的行为（舔空气/看到尸体犹豫）
- 增加方岩体力消耗的递进（喘气加重/灵能光变暗）
- 第5只灰蜥逃跑，不杀——体现"追穷寇是步兵的事"的斥候智慧

### 改写段2: T2甲壳弹刀（替换原文L41-L48）

```
[快切]
短刀从右上方劈下去。灵能冷白的光划过空气，直奔T2脖子和甲壳的连接处——北境的经验。T2的弱点。

[特写·碰撞]
刀刃碰到了甲壳。
不是切入。是碰。像刀砍在铁板上——不，像刀砍在弹簧上。甲壳表面的灵能纹路在刀刃接触的瞬间闪了一下——不是被切割的闪，是反击的闪。灵能从甲壳纹路里反扑出来，像电流一样沿着刀刃往刀柄涌。方岩的手腕一麻。短刀差点脱手。

[慢镜头]
刀刃在甲壳上弹开了。弹开的轨迹在灵能光里画了一道弧线。方岩看清了——甲壳没有痕迹。连一道白印都没有。灵能纹路在甲壳上流动着，把冲击力均匀地分散到整个甲壳表面。不是硬——是韧。像水一样吸收了所有力量。

T2反击。前肢像铲子一样横扫。方岩往后跳——右膝弯了一下。旧伤。冷天会犯。来不及了。铲子的边缘刮过他的右腿。不是划——是刨。前肢上的灵能结晶带着灵能切割效果，比物理切割更深。裤子被撕开。血涌出来。
```

## 四、异兽风格设计

### T1灰蜥（本章详细）

| 个体 | 差异 | 行为 |
|------|------|------|
| 第1只 | 最大，正面冲 | 直线扑击，标准攻击模式 |
| 第2只 | 从管道上方绕行 | 利用高度优势，绕后包抄 |
| 第3只 | 看到尸体后犹豫 | 同类尸体前嗅血，被尸体转移注意力 |
| 第4只 | 最年轻，结晶最亮 | 不等同伴就冲，速度快但判断差 |
| 第5只 | 最小，等级最低 | 看到四个同伴死了就跑了，无指挥时本能是逃 |

### T2锐化体（本章首次正面接触）

| 维度 | 设计 |
|------|------|
| 甲壳 | 灰白色，灵能纹路嵌在甲壳表面，能吸收并反弹灵能攻击 |
| 弱点 | 脖子和甲壳连接处（但外环T2甲壳厚，北境经验不适用） |
| 前肢 | 铲状，边缘有灵能切割效果，横扫范围大 |
| 灵能结晶 | 拳头大，镶嵌在头骨上，能转动像雷达 |
| 行为 | 缓慢推进，不主动冲锋，让灰蜥开路 |

| 角色 | 展示点 | 具体表现 |

| 方岩·地形感知 | 战斗中变成雷达 | 灵能频率变化画出灰蜥移动方向的线，不用看就能判断"从上面来" |
