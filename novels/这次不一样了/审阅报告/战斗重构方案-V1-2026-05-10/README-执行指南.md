## 执行注意事项

### 1. 字数控制
- 每章重构后目标: 3000-3500字
- Ch013当前2782字，需要扩写至少200字
- 其他章节在替换过程中注意总字数不超过3800字

### 2. 风格一致性
- 保持"末日基调：黑色、灰暗"——不热血不中二
- 分镜感增强但不要过度使用"慢镜头"——全卷最多5-6个慢镜头（已分配到各章关键节点）
- 快切短句保持节奏感但不滥用——每章1-2个快切段即可

### 3. 角色一致性
- 沈野：沉默寡言，用动作代替语言。不主动帮人。摩挲食指关节是紧张/思考的微动作
- 方岩：短句。壁盾斥候习惯。不回头看队友。判断精准但身体跟不上
- 老陈/阿公等NPC：有性格的普通人。黑色幽默（"七十个铜板"）。不是英雄

### 4. 异兽一致性
- T1灰蜥：追热的、只能直线追、进不了窄管道、灵能结晶是核心弱点
- T1鳞兽：视觉追踪、比灰蜥快一倍、身体能压缩挤窄道、翻过来就翻不了身
- T2锐化体：甲壳灵能纹路吸收反弹攻击、铲状前肢带灵能切割、缓慢推进不急躁

### 5. 能力边界
- 沈野当前是初觉级拓印：只能"读"已存在的灵能结构，不能主动攻击、不能复制活人能力
- 拓印本能（手感好/会挑）：通过触碰感知灵能物品的质量和状态
- 碎片干扰T2是初觉级的偶然事件——频率共振，不是他主动控制的
- 方岩地形感知是极弱初觉：只能感知灵能体的位置和移动方向，不能精细读取
