## 二、重构核心方法论

### 2.1 分镜设计五层体系

```
[远景] → [中景] → [近景] → [特写] → [慢镜头]
  |         |         |         |          |
战场全貌   双方动作   武器碰撞   微表情     时间拉长
环境态势   位置变化   关键动作   关键细节   关键瞬间
敌我分布   配合走位   闪避格挡   灵能反应   碎裂/突破/牺牲
```

### 2.2 句式节奏控制

```
常态叙事: 15-20字混合句式
快切紧张: 3-8字短句密集排列
慢镜头:   30-50字长句+感官细节拉长
燃点高潮: 短句爆发→一声停顿→长句释放
```

### 2.3 异兽行为差异化设计原则

- **T1灰蜥**: 靠灵能结晶追踪（追热的），直线追击，群殴，数量多单体弱，进不了窄管道。不同个体有微小差异（大小/速度/结晶亮度）。
- **T1鳞兽**: 比灰蜥快一倍，扁平身体能压缩挤窄道，背脊灵能线，冲刺+碾压。
- **T2锐化体**: 灵能纹路甲壳（反击式防御），前肢铲状切割，灵能结晶镶嵌头骨，甲壳有灵能切割效果。比北境T2强（0.41灵能浓度）。

### 2.4 能力展示设计

| 角色 | 能力 | 战斗展示方式 |
|------|------|------------|
| 沈野 | 灵能拓印（初觉） | 触碰碎片/灵能物品时"读"到结构信息，在战斗中表现为：判断灵能陷阱能否用、感知异兽灵能弱点位置、找到最佳逃跑路线 |
| 沈野 | 拓印本能（手感好/会挑） | 捡陷阱残骸时一眼判断能否用、选择最优逃跑路线（废墟结构知识+灵能感知）、挑选最佳引诱碎片 |
| 方岩 | 地形感知（极弱初觉） | 战斗中变成"雷达"，感知周围灵能体的距离和移动方向 |
| 方岩 | 壁盾斥候战术 | 陷阱布局、标记撤退路线、地形判断（什么能过什么不能）、指挥协调 |
