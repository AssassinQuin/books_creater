# Ch014 聚落防御战 -- 重构方案

## 一、现有诊断

### 问题清单

| # | 严重度 | 描述 |
|---|--------|------|
| 1 | 高 | 方岩的指挥只有一句话概括（"都别乱。听我说。"），缺具体的调度过程——谁去哪、做什么、怎么配合 |
| 2 | 高 | 灰蜥突入管道区是"最危险的时刻"，但只有一只灰蜥突入。应该有多只、更混乱、快切更密集 |
| 3 | 高 | 老陈杀灰蜥的过程太简单（"侧身躲→等停顿→砸灵能结晶→三下才停"），缺分镜和节奏感 |
| 4 | 中 | 阿公碎渣弹炸灰蜥的段落缺代价感（只写了"七十个铜板"），缺爆炸的视觉效果 |
| 5 | 中 | "战斗结束了"收尾太突兀。应该有余波——检查死角、清点损失、受伤者的处理 |

## 二、分镜设计

### 2.1 方岩指挥调度段

**设计目标**: 展示壁盾斥候15年战场指挥能力。不是下命令，是分配资源。

**分镜序列**:

```
[中景·方岩站出来]
方岩拖着右腿从管道口出来。短刀握在手里——灵能光已经暗到几乎看不见了。但他站得很稳。
他扫了一眼聚落。十二只灰蜥散在外围。没有集中的方向。有人在管道里躲着。有几个在外面——老陈，一个邻居阿公，两个拾荒者。
方岩的脑子在算。十五年的斥候不是白干的。
十二只。散的。没有指挥。有利——散兵比群战好对付。
缺点——他只有五个人。一个瘸子。四个平民。灵能短刀一把。暗的。
够不够？不够。但能打。

"都别乱。"
声音不高。但穿透力很强。废墟里长大的耳朵都灵——谁的声音大谁的声音小不重要，重要的是谁的声音稳。方岩的声音很稳。
"听我说。"

所有人看向他。

[快切·调度]
方岩的手指指了三个方向。每指一个方向就有人动。
"南面三个大口——堵上。石块不够拆铁皮。灰蜥的爪子划不穿双层铁皮。" → 两个拾荒者去搬石块
"东面留一个出口。灵能陷阱设在出口两侧。" → 阿公去搬陷阱
"沈野——"方岩叫他。沈野走过去。
"哪些管道能通到聚落外面。灰蜥可能从哪进来。"

[近景·沈野管道判断]
沈野闭了一下眼。碎片的牵引感在脑海里展开——管道的走向、裂缝的位置、连接处。他记住了所有路线。
"南面三个大口。东面两个。北面一个。西面没有——管道全塌了。"他睁开眼。"但南面第二个管道口旁边有一条裂缝。碎石堵了但灰蜥挤得进去。"
"堵上。"
"裂缝在管道外侧。需要从外面堵。"沈野已经转身了。他用石块和铁皮从外面堵裂缝。

[中景·执行]
拾荒者们动了。没有犹豫——在废墟里活了十几年的人知道什么时候该听话。
邻居阿公去搬石块。老陈把面摊残骸的铁板拖到南面管道口——铁板上有面糊的痕迹，干了一半。两个拾荒者从废墟里搬来灵能陷阱——之前聚落设的还没用完的。碎渣弹的弹壳是铜的，每一个都值钱。阿公数了一下。十二颗。加上他自己攒的六颗。十八颗。
够了。也许。
```

### 2.2 灰蜥突入管道区段（最危险时刻）

**设计目标**: 不是一只灰蜥突入——是两只同时从不同方向突入，制造多线快切的混乱。

**分镜序列**:

```
[中景·突入]
南面第三个管道口的石块被推开了。不是一只灰蜥——是两只。
同时。从同一个管道口。一只在前面挤进去，第二只紧跟着。灵能结晶在鳞片上闪着暗绿色的光。嘴里有血——不是它们的。前面那只的爪子上还挂着一块布——人的衣服。
它们钻进了管道区。管道区。拾荒者住的地方。有人还在里面。

[快切·混乱]
"管道区进来了！"有人喊。声音尖锐。是女人的声音。
沈野和两个拾荒者冲进管道区。瘦高个拿着铁管。矮壮的抱着石块。沈野握着刮刀。碎片的牵引感在管道里展开——他能"读"到灰蜥的位置。
两只。一前一后。前面的已经进了管道深处。后面的在管道口。中间隔了约十步。
管道宽度刚好够一只灰蜥转身。但不够两个人并排。
沈野做了一秒钟的判断。
"堵后面！"他喊。
瘦高个从管道后面推了一块铁皮过来——堵住退路。灰蜥回头。退路没了。
前面那只灰蜥在管道深处——离他们十五步。它听到后面有动静，转头。灵能结晶闪了两下。
两只灰蜥。夹在中间。
"碎渣弹。"沈野从背包侧兜摸出一颗——最后一颗。他把触发器卡在管道壁上。感应线横在管道中间。
"往后退。退到铁皮那里。"

[近景·引爆]
他们退了。灰蜥也追了。后面的那只先踩到感应线。
碎渣弹在管道里炸了。空间太小——灵能冲击波在管道壁上反弹了两三次。灰蜥被冲击波推到管壁上。灵能结晶碎了两个。它还在动——但慢了。前腿拖在地上。
前面那只灰蜥被冲击波的余波掀了一下。没踩到感应线。但它听到了爆炸——灰蜥的本能在爆炸后会犹豫两到三秒。
方岩从管道口外面进来。右腿拖着。短刀握在手里——灵能光只有微弱的一层灰。他把短刀插进后面灰蜥的腹部。灵能切割——最后一刀。灰蜥不动了。
前面那只灰蜥犹豫了三秒。然后它转身——往管道深处跑。它不傻。同类死了。
沈野没有追。管道太窄。追上去就是一对一。他只有一把刮刀。
灰蜥从管道另一端跑了。出去了。

[中景·代价]
"它跑了。"沈野说。
方岩靠在管壁上。短刀彻底暗了。
"它会回来吗？"矮壮的问。
"不会。"方岩说。"灰蜥追热的。聚落的灵能陷阱炸了——热源少了。它去找更热的地方。"
方岩在喘。右腿上的血浸透了三层布条。脸在灵能结晶的微光里发白。
```

### 2.3 战后余波段（替换"战斗结束了"）

**设计目标**: 不是"战斗结束了"一句话收尾。要有检查死角、清点损失、受伤处理的过程。

```
[中景·清点]
方岩没有说"战斗结束了"。他说的是"清死角"。
"沈野，带人把每条管道走一遍。没有灰蜥才算完。"
沈野和瘦高个走了。一根管道一根管道地检查。照明石的光在管道里晃。空了。空了。空了。管道壁上的太阳画还在——两个歪歪扭扭的小人。沈野看了一眼。继续走。
走到最后一根管道——北面的。管道口堵着石块。石块没动过。他侧身钻进去。空的。
"干净了。"他说。

[近景·代价]
聚落清点。几个受伤——
邻居阿公的手被碎渣弹的余波烫了。皮起了三个水泡。他把烫伤的手泡在一桶凉水里，另一只手还在捡碎渣弹的壳——铜的，一个壳值两个铜板。
"七十个铜板的碎渣加六个铜板的壳。"阿公算了算。"亏大了。"
老陈的腰扭了。面摊被砸了。铁锅翻了。面糊洒了一地。他蹲在地上翻面摊的残铁——还能用的捡出来。不能用的放一边。嘴里数着什么——可能是铜板。
两个拾荒者有皮外伤。一处管道被灰蜥撞塌了——南面第三根。不影响整体结构。
但没有死亡。
方岩的指挥救了人。壁盾老兵的战场控制——在废墟里也能用。石块、铁皮、灵能陷阱、管道结构。不是正规军的方式。但有效。
```

## 三、能力展示点

| 角色 | 展示点 | 具体表现 |
|------|--------|---------|
| 方岩·壁盾指挥 | 调度五个人打十二只灰蜥 | 扫一眼→脑子计算→分配任务→留出口设陷阱→堵裂缝。不是蛮干是资源分配 |
| 沈野·拓印 | 管道内定位灰蜥 | 碎片牵引感在管道里展开→读出两只灰蜥的位置和间距 |
| 沈野·废墟知识 | 判断灰蜥去向 | "灰蜥追热的。聚落的灵能陷阱炸了——热源少了。它去找更热的地方。" |

## 四、热血/大场面设计

| 场景 | 设计 |
|------|------|
| 方岩指挥 | 中景→快切调度：每指一个方向就有人动。"够了。也许。"——老兵的精确估算 |
| 管道区突入 | 两只灰蜥同时突入→沈野判断→堵后路→碎渣弹引爆→冲击波管道内反弹→方岩最后一刀。管道窄战的空间感 |
| 阿公碎渣弹 | 灵能冲击波把三只灰蜥掀翻→阿公从碎石后跳出来→石头砸→"七十个铜板的碎渣"。黑色幽默+代价感 |
| 战后清点 | 不是"结束了"——是"清死角"。一根管道一根管道检查。太阳画还在。阿公数铜板。老陈翻残铁。 |
