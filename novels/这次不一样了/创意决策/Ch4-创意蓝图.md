# 创意蓝图：第4章《240%》

## 因果链确认

### 事件1：拾荒中的异常——残片路标
- **因为** Ch1捡到的五层残片手感异常+Ch3管壁规整刮痕，沈野的注意力被牵引到东段深管
- **所以** 他走了一条不常走的路线，发现残片每隔十步出现一次，五层嵌套纹路方向一致，朝向甬道深处
- **逼出** 一个判断：有人在这条甬道里投放过东西——不是自然剥落，不是搬运遗落，是故意放的。路标
- **雪球** 沈野的"手感"在追踪残片时变得更强——他不需要看，手指贴上管壁就能判断残片的位置。这种能力的升级他本人毫无察觉
- **没变** 甬道还是窄的，矿灯还是只照两步，东段比西段更暗

### 事件2：废弃灵站分站——源质分级手写字（F9 planted）
- **因为** 残片路标指向甬道尽头，尽头是一处废弃灵站分站
- **所以** 沈野进入分站，在拆了一半的设备残骸中发现灵能净化阵内壁刻着手写字："源质分级·第三批·标记数17人"。手写比印刷更让他不安——印刷是流程，手写是人
- **逼出** 他不认识这些字的意思，但记下来了。碎渣袋内壁划了三道。他没想过"为什么要记"，记是拾荒者的本能——记住了以后也许用得上
- **雪球** 拆设备的方式太规整：外壳→纹路板→灵枢→底座。知道顺序的人。和管壁上的规整刮痕呼应
- **没变** 分站已经废弃了，门被拆了，灵枢被搬走了，只剩空壳

### 事件3：公告栏240%——黄色警报
- **因为** 回程经过聚落主干道，灵能公告栏换了新纸
- **所以** 沈野看到灵能活动度读数240%——历史最高150%。黄色警报，比蓝色高一级。纸的右下角多了一枚他没见过的新戳文
- **逼出** 一个数字的冲击：240%不是"高了一点"，是"完全超出认知范围"。外围十七年，他见过最高的才132%
- **雪球** 新戳文暗示灵站内部的层级变化——和源质分级编号产生间接联想（沈野不会主动联想，但读者会）
- **没变** 排队的人抬头看了看，低头继续数碎渣。外围人对预警的反应是"看看，然后忘了"

### 事件4：方岩出现在公告栏旁——第一次主动说话
- **因为** 方岩四年修灯，蹲在北段最远的那根灯柱下，看北边甬道看了四年
- **所以** 他在公告栏旁边和沈野站在同一张纸前，开口说了五个字："北边不对劲。"说完就走了
- **逼出** 方岩四年沉默的第一次主动开口——重量不在五个字的内容，在于"方岩开口了"。这个人连修灯时被人递水都不说谢谢
- **雪球** 沈野手里捏着残片。残片指向东段。方岩说北边不对劲。两个方向。他现在还不知道这两个方向意味着什么
- **没变** 方岩还是那个走起路来膝盖响的人。说了五个字，表情没变

### 事件5：沈野让沈念少出门——她没听
- **因为** 残片规律分布+源质分级编号+240%+方岩的话，沈野的警觉拉满了
- **所以** 他回家对沈念说"这两天别出去了"。她说"好"。第二天她又去了灵站——他不知道
- **逼出** 保护机制的反讽：沈野越收缩保护半径，沈念就在保护半径外面走得越远。"好"是他听到的最后一个字
- **雪球** 沈念不是"不听话"——她去灵站不是为了自己，是为了给他攒路费。她的保护和他的保护是反方向的
- **没变** 石屋里碎渣炉的灰烟从门缝往外冒，灰味和暖味挤在一起

**因果链完整性验证**：✅ 全部5事件因果链完整。残片→规律分布→废弃分站→源质分级（F9）// 回程→240%→方岩说话→警觉→收缩保护→沈念出门。两条线在沈野身上交叉：外部威胁升级（240%+北边不对劲）+ 内部发现升级（源质分级+残片路标），但他的应对策略只有一种——让别人少出门。

## 场面设计

### 场面1 | 密度: 中量
- **时间/地点**: D3天没亮→清晨。东段深管——比西段更窄、更潮湿、更暗。矿灯照两步。空气闷，碎渣腐烂的微甜变成衣服捂了两三年的味道
- **核心事件**: 沈野走非常规路线，追踪残片，发现规律分布（每十步一块，方向一致，像路标）
- **人物及目标（角色矩阵）**:
  · 沈野: 想{搞清楚这些残片是不是只有一块} / 障碍{东段深管不熟悉，异兽风险} / 对环境: 谨慎但被好奇心驱动（他自己不承认是好奇心）
- **微事件分配**:
  · 费笔①: 东段深管的环境——管壁上的水渍、空气里的闷味、更暗的光。和西段的区别用感官展示而非说明
  · 日常①: 贴管壁走的动作——在东段更频繁，每隔几步就贴一次，不是找碎渣了，是在找残片
  · 世界呼吸①: 东段管壁上的旧标记——不是碎渣画的，是刀刻的，很规整，但被水渍泡得模糊了。和Ch3的规整刮痕呼应
- **伏笔操作**: 埋设→残片规律分布（路标暗示）；提起→F1五层残片手感升级
- **镜头序列**: {感官入场：东段深管的潮湿和暗} → {主镜头：沈野贴壁行走+每隔十步抠出残片} → {插入镜头：四块残片并排+纹路方向一致} → {收束：他在原地站了一会儿}
- **预计字数**: 900-1100字

### 场面2 | 密度: 中量
- **时间/地点**: D3上午。东段深管尽头废弃灵站分站（灵枢分站·东七）。门被拆，设备被搬空，角落有拆了一半的残骸
- **核心事件**: 发现灵能净化阵内壁手写字"源质分级·第三批·标记数17人"（F9 planted）
- **人物及目标（角色矩阵）**:
  · 沈野: 想{看看分站里还有什么} / 障碍{设备被搬空了，只剩残骸} / 对分站: 拾荒者的本能——进去翻翻
- **微事件分配**:
  · 日常①: 拆设备痕迹的判断——外壳先卸、纹路板第二层、灵枢第三层、底座最后。知道顺序的人。沈野不会拆灵站设备，但他能看出来先后
  · 世界呼吸①: 分站地面净化灵枢底座——四颗螺丝孔，最后一颗螺纹磨平了。反复拆装
  · 费笔②: 手写字的笔触——用刀刻在金属内壁上，笔画歪歪扭扭但每笔用力到底。在金属上刻字需要很硬的刀尖和很大的力气
- **伏笔操作**: 埋设→F9源质分级手写字（高优先级伏笔）；提起→管壁规整刮痕（Ch3种子，此场面呼应——知道顺序的人来过这里）
- **镜头序列**: {环境入场：废墟岔口+碎石堆上的分站标记} → {主镜头：沈野挤进门框+翻残骸} → {插入镜头：内壁手写字的特写——歪歪扭扭但刻得很深} → {收束：碎渣袋内壁划了三道，第三道划歪了}
- **预计字数**: 700-900字

### 场面3+4 | 密度: 轻量→重量突变
- **时间/地点**: D3中午前后。聚落主干道——灵能公告栏前面。面摊在旁边
- **核心事件**: 240%黄色警报 + 方岩第一次主动说话"北边不对劲。"
- **人物及目标（角色矩阵）**:
  · 沈野: 想{消化240%的数字} / 障碍{数字超出认知范围} / 对方岩: 意外——这个人不在灯柱底下
  · 方岩: 想{说一句该说的} / 障碍{他不解释} / 对沈野: 说了五个字就够了
- **微事件分配**:
  · 费笔③: 面摊前两个老人下棋——"收购价下调了""来的人还更多，怪不怪"。纯纹理，用路人对话展示灵站的反常
  · 世界呼吸②: 公告栏的新戳文——比常规戳小一圈，边缘有细密纹路。沈野不认识
  · 日常②: 排队的人抬头看了警报，低头继续数碎渣。外围人的反应模式
- **伏笔操作**: 提起→Ch3方岩沉默的对比（四年第一次主动说话）；埋设→新戳文（灵站内部变化的暗示）
- **镜头序列**: {物件入场：灵能公告栏的黄色纸} → {主镜头：240%数字的冲击} → {插入镜头：方岩出现在旁边+五个字} → {收束：方岩走了，沈野站在原地，手摸到残片}
- **预计字数**: 800-1000字

### 场面5 | 密度: 轻量→切
- **时间/地点**: D3晚上→D4天没亮。石屋——碎渣炉+矮桌+灰味暖味
- **核心事件**: 沈野让沈念少出门，她说好，第二天她又去了
- **人物及目标（角色矩阵）**:
  · 沈野: 想{让她安全} / 障碍{他管不住她出门} / 对沈念: 他不知道她为什么出门
  · 沈念: 想{给哥哥攒路费} / 障碍{他说别出去} / 对沈野: "好"——然后做她觉得该做的事
- **微事件分配**:
  · 日常③: 沈野摆弄四块残片——并排放，纹路方向一致，朝东。他低着头看，沈念没看他
  · 世界呼吸③: 第二天沈野出门时看了一眼沈念——裹着棉被还在睡。门轻轻带上。他没有知道的事正在发生
- **伏笔操作**: 提起→沈念暗格（Ch2种子，她为谁攒钱在这里升级为"他不知道"）
- **镜头序列**: {对话入场："这两天别出去了""好"} → {主镜头：沈野摆残片+沈念码铜板} → {插入镜头：矮桌上铜板少了几枚} → {收束：甬道拐角处沈念的身影被灰绿光吞掉}
- **预计字数**: 600-800字

## 叙事节奏

- **情绪曲线**: 场面1(强度3, 谨慎探索) → 场面2(强度4, 发现异常但不动声色) → 场面3+4(强度6, 240%数字冲击+方岩五字暴击) → 场面5(强度5, 收缩保护→她没听)
- **转场方式**:
  - 场面1→2: **自然延伸**。追踪残片→残片指向尽头→尽头是分站。同一空间连续
  - 场面2→3: **感官硬切**。废弃分站阴暗→聚落主干道的光和面摊的油味。中间回程一句带过
  - 场面3→4: **无缝衔接**。沈野看公告栏→旁边有人→方岩。不换场，空间不变
  - 场面4→5: **时间跳跃+物感过渡**。从公告栏→晚上石屋。过渡靠"碎渣炉的灰味"连接——和Ch1石屋开场呼应
- **节奏断层位置**: 场面4末尾→场面5开头。方岩说"北边不对劲"走了→石屋里沈念在数铜板。外部的暴烈警报和内部的日常平静并置——外面的世界在崩，里面的日子照过
- **刀锋技法**: **保护的反讽**。沈野说"别出去了"，沈念说"好"——两个字很轻，轻到沈野以为这事到此为止。但第二天她走了。保护者的指令和保护对象的选择之间的错位，整个V1的核心矛盾在这里又一次隐现

## 角色行为弧线

### 沈野
- **本章起点**: 带着Ch1残片的好奇心（他不承认是好奇心）和Ch3管壁刮痕的疑虑出门。今天是探索日
- **本章目标**: 搞清楚残片是不是只有一块（显线）；消化240%和方岩的话（潜线）；保护沈念（本能线）
- **关键行为**: ①走非常规路线——说明他被残片牵引了，拾荒者的"手感"在升级；②源质分级手写字——他不认识但记下来，拾荒者本能；③240%面前站了一会儿——数字让他不安，但他不知道不安的边界在哪里；④对沈念说"别出去了"——保护收缩
- **本章终点**: 脑子里堆了四件事——残片路标、源质分级编号、240%、方岩的五个字。他不知道这四件事连在一起，但直觉告诉他不对了
- **失控时刻**: 方岩说完五个字走的时候，沈野伸手摸口袋里的残片——这个动作他没想就做了。残片已经变成他的"安全毯"

### 方岩
- **本章起点**: 在灯柱底下修灯。沉默四年
- **本章目标**: 说一句该说的
- **关键行为**: 站在公告栏前和沈野看同一张纸。开口："北边不对劲。"说完走了
- **本章终点**: 走了。回到灯柱底下继续修灯
- **失控时刻**: 五个字本身——方岩从不解释，从不主动开口。他开了这个口，说明北边的事情已经超过了他"不说"的阈值

### 沈念
- **本章起点**: 在石屋里数铜板
- **本章目标**: 给哥哥攒路费
- **关键行为**: 说了"好"——然后第二天出门了。矮桌上铜板少了几枚
- **本章终点**: 甬道拐角处身影被灰绿光吞掉
- **失控时刻**: 她不是失控——她是在用自己的方式控制。沈野的保护是"不让你出门"，她的保护是"出门帮你攒路费"。两个人的保护逻辑冲突，但动机完全一致

## 声音层适配

本章为transition章（日常→悬念），声音需从Ch1的daily平滑过渡到mystery。

- 场面1-2：daily底色。沈野的拾荒视角，动作驱动，不解释。感官描写为主
- 场面3-4：mystery切入。240%数字的冲击用"站了一会儿"表达，方岩的五个字用"转身走了"收住。不解释恐惧，让沉默说话
- 场面5：daily回落的假象。"好"是平静的，但读者知道第二天她走了。日常的平静是悬念的伪装

## 信息投放技术（悬疑层）
