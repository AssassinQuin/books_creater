# 创意蓝图：第7章《两轮椅子》

## 因果链确认

### 事件1：沈念加倍——两轮引渡椅
- **因为** 灵站贴出"加急采集通告"：灵晶产出配额翻倍、兑换券加价50%、限三日。沈念本来只是去换盐，路过看到了
- **所以** 第一轮正常引渡完毕后，她在灵站门口站了一会儿，转身回去排队坐第二轮
- **逼出** "最后攒一笔"的动机——她不是贪多，是在跟时间赛跑。身体在垮，窗口在关。限三日=三天内尽量多换一点
- **雪球** 两轮之间间隔太短，身体没有恢复。第二轮引渡的凉气走到后背中间停了一下才继续往上——身体在抗议
- **没变** 引渡椅还是硬的，照柱灯还是偏黄的，灵枢嗡嗡声还是那个调子。灵站的日常没有因为她的决定而改变

### 事件2：韩朗标记——高产出源704（F2深化）
- **因为** 沈念第二轮引渡完成后经过灵枢操作台，隔间门没关严
- **所以** 她看到韩朗不在窗口而是在操作台后面，用笔在灵枢面板上写字（不是敲）。嘴角动了一下——对灵册确认的表情，和上次一样
- **逼出** 读者看到面板上的字迹："高产出源704，牒号零三。持续观察。"韩朗不知道自己在杀人——他以为在做灵册采集
- **雪球** "持续观察"三个字暗示韩朗的记录不是一次性的，而是长期追踪。和Ch2韩朗"额外敲四下"呼应——他一直在关注沈念的灵能数据
- **没变** 韩朗还是那个做了十几年轴的人。翻灵册下一页，找下一个牒号

### 事件3：沈念的身体——膝盖响、手抖
- **因为** 两轮引渡之间间隔太短，灵能过度抽取
- **所以** 走出灵站后膝盖响了一声、手微微发抖。她把手揣进口袋攥紧，攥了一会儿，指节发白，松开。不抖了
- **逼出** "她平时不那样"——第一轮之后没有，第二轮之后才酸。身体在用疼痛告诉她什么，但她选择无视
- **雪球** 手抖→攥紧→指节发白→不抖了。这个动作的暴力程度说明她对抗身体反应已经不是第一次了
- **没变** 袖子拉到指尖以下，盖住手背。从Ch2到Ch7，这个动作没有变过

### 事件4：回家路上——灵能浓度+收购价旧纸
- **因为** 经过公告栏，看到灵能浓度又升了。风掀开纸角，露出底下旧收购价单
- **所以** 旧纸上的价格比现在高一倍。两年前的价格。灵站在缩收购价
- **逼出** 一个残酷的对照：她给哥哥攒路费，灵站同时在把路费变薄。一增一减，她的身体在换越来越薄的纸
- **雪球** 灵能浓度又升了（Ch2种子推进，从"高了一格"到"高了将近两格"）。收购价缩→兑换券实际购买力下降
- **没变** 寻狗启事还在。灰灰大概没找到。公告栏上的悲喜没人管

### 事件5：沈野注意到了——先处理"能处理的"
- **因为** 沈野回家看到沈念叠衣服很慢，手指在拉链边缘停了一下
- **所以** 他注意到了。但他脑子里堆着七块残片、方岩的话、源质分级编号、240%、收购价旧纸——先处理"能处理的"
- **逼出** 保护机制的结构性盲点：沈野的处理优先级永远是"外部威胁>内部信号"。他能注意到残片的纹路方向变了半度，但注意不到妹妹的手指抖了一下
- **雪球** "先处理能处理的。他的习惯。"这个习惯在Ch11会被沈念打碎——"你每次都算错了。你算的时候从来不算上我。"
- **没变** 绳子系了三道。和Ch4一样。沈野对残片的在乎超过了对人

**因果链完整性验证**：✅ 全部5事件因果链完整。加急通告→两轮引渡→韩朗确认标记（F2）// 引渡过度→膝盖响+手抖→身体在垮 // 公告栏→灵能升高+收购价缩→路费变薄 // 沈野回家→注意到但先处理外部事→结构性盲点。

## 叙事节奏

- **情绪曲线**: 场面1(强度3, 日常决定) → 场面2(强度4, 第二轮身体+韩朗暗线) → 场面3(强度5, 身体崩溃信号) → 场面4(强度4, 公告栏残酷对照) → 场面5(强度5, 注意到但没处理)
- **转场方式**:
  - 场面1→2: **动作无缝衔接**。第一轮走出门→站了一会儿→转身进门。不换场，空间不变
  - 场面2→3: **时间跳跃+感官过渡**。灵站隔间→走出灵站太阳偏西。光线角度变化连接
  - 场面3→4: **空间延续**。同一条回家路，经过公告栏。不停，停了一步
  - 场面4→5: **时间跳跃+物感过渡**。公告栏→晚上石屋。"帆布袋搁在门边当的一声"切进室内
- **节奏断层位置**: 场面2末尾→场面3开头。韩朗翻盖合上字迹暗了→沈念走在甬道里膝盖响了一声。灵站的冰冷和身体的疼痛之间的硬切
- **刀锋技法**: **"先处理能处理的"**。沈野注意到了沈念的手指停了一下，但他脑子里堆着残片、方岩的话、源质分级、240%。他选择先处理那些东西。这个选择的重量要到Ch10摊牌时才爆炸——到那时候他才知道"先放一放"的东西放不了了

## 角色行为弧线

### 沈念
- **本章起点**: 去杂货摊换盐，路过灵站看到通告。"百分之五十"让她停下了脚步
- **本章目标**: 最后攒一笔路费
- **关键行为**: ①决定第二轮——"她站了一会儿。转身。又走进了灵站。"犹豫存在但被行动盖过；②第二轮引渡时凉气走到后背中间停了一下——身体已经不能像第一轮那么顺畅；③手抖→攥紧→指节发白→不抖了——对抗身体反应的暴力程度说明她经常做这个动作；④看到旧收购价数字——她算了一笔账。没有愤怒，只有数字
- **本章终点**: 躺在门帘后面，灯灭了。外面沈野在摸残片。她的手指今天抖过两次，攥紧过两次，都停了。还能停几次？
- **失控时刻**: 膝盖响了一声。"她平时走路膝盖不响。"一句话的重量比整段心理描写都重

### 沈野
- **本章起点**: 从东段深管回来，帆布袋里多了两块残片
- **本章目标**: 处理外部威胁（残片、方岩的话、源质分级、240%）
- **关键行为**: ①看到了沈念叠衣服很慢，手指在拉链边缘停了一下。②看到了，但脑子里堆了太多东西。③摸残片，一块一块，绳子系了三道
- **本章终点**: "先处理能处理的。他的习惯。"站起来。睡了
- **失控时刻**: 他失控的地方不在于"没看到"，而在于"看到了但选择先放一放"。这个选择的合理性会在Ch11被摧毁

### 韩朗
- **本章起点**: 在操作台后面写字
- **本章目标**: 确认高产出源的灵能等级，记录，归档
- **关键行为**: "高产出源704，牒号零三。持续观察。"字迹方正，笔画匀称
- **本章终点**: 翻开灵册下一页，找下一个牒号
- **失控时刻**: 无。韩朗没有失控——这是最恐怖的部分。他不需要失控。他只需要做他的工作流

## 声音层适配

本章为transition章，声音从daily底色逐渐加入mystery元素。

- 场面1-2：daily底色。灵站排队、引渡椅的日常感。沈念的视角平稳、动作驱动
- 场面3：mystery切入。身体信号的异常不用心理描写，用动作展示——膝盖响一声，手抖，攥紧。读者自己判断这意味着什么
- 场面4：daily+mystery混合。公告栏的灵能读数和旧价格是信息量，但沈念的视角只"看了一眼""记住了""没捡"
- 场面5：daily回落的假象。沈野摸残片是日常动作，但他选择不处理沈念的事是悬念。日常的平静是沈念崩塌的背景音

## 信息投放技术（悬疑层）

本章F2韩朗备注属于"第三层：展示后果，不解释因果"。

- 沈念看到韩朗在写→看不到内容→走出门
- 读者通过视角切换看到字迹内容："高产出源704，牒号零三。持续观察。"
- 读者知道这意味着韩朗在追踪沈念，但不知道"高产出源"的真正含义
- 韩朗"不知道自己在杀人"——这句话告诉读者韩朗的视角，但不解释灵枢司的目的
- 悬念保留到Ch14"可能流失"

## POV特殊处理

- 全章沈念POV。场面2的韩朗备注通过视角切换展示（沈念走出门→叙述视角短暂拉开→字迹内容→回到沈念视角）。这是悬疑小说中常见的"读者知道但角色不知道"技法，不破坏POV契约
- 场面5中沈野的内心活动（残片、方岩的话、源质分级等）通过沈念的观察间接传递——她看到沈野坐下倒水、摸残片、系绳子。她不知道他在想什么，但读者从沈野的动作中可以推断
