## 一、POV声音设计

### 沈念 vs 沈野的声音差异
| 维度 | 沈野（Ch1） | 沈念（Ch2） |
|------|------------|------------|
| 叙事密度 | 极简，动作驱动 | 较密，观察驱动 |
| 内心活动 | 几乎无，用动作暗示 | 有，但不解释，用"注意到"代替"知道" |
| 社交感知 | 透明（路人不存在） | 高（注意到每个人） |
| 对话量 | 极少（"嗯""面"） | 多（闲聊、自言自语、搭话） |
| 感官偏好 | 触觉（手感）→硬 | 视觉+嗅觉→软 |
| 说话风格 | 不开口 | 先笑再开口，话多活泼 |
| 世界态度 | 适应（三步远的光走一辈子） | 审视（看到了不对但不说） |

### 沈念核心声音指纹
- 话多，但不碎——每句话背后有观察
- 注意到别人注意不到的细节（韩朗敲了四下不是三下，不是正常速度）
- 温暖但不天真——她知道兑换券被剥削，只是不说
- 笑是武器——用笑挡住所有不想回答的问题
- 她看到的世界更细腻、更有温度，但温度下面藏着恐惧

## 二、五个场面设计

### 场面1：沈念的早晨
**入场方式**: 感官（嗅觉——碎渣炉灰烟味）
**结构**: 单线推进
**收束**: 环境空镜（矿道口天光）

| 要素 | 内容 |
|------|------|
| 位置 | 石屋→矿道口 |
| 时间 | 清晨（沈野出门后） |
| 感官 | 灰烟+暖味（嗅觉）、碎渣炉噼啪声（听觉）、冷水刺手（触觉） |
| 核心动作 | 热剩面、净囊过滤水、洗碗、晒衣服 |
| 角色状态 | 独处时的沈念——手指灰色又多了一截，她看到了，拉下袖子 |
| 世界展示 | 净囊过滤（水处理）、碎渣炉（取暖/炊事一体）、矿道口晒衣服（聚落生活） |
| 微事件 | 洗碗时手指碰到冷水一阵刺→灰色多了一截→袖子盖住 |
| 费笔 | 矿道口阿婆问灵站人多不多——日常闲聊，展示聚落邻里关系 |

**沈念弧线**: 从日常劳作中透露她知道自己的身体状况在恶化，但选择"先过今天再说"

---

### 场面2：灵站领配给
**入场方式**: 对话（排队中阿婆搭话）
**结构**: 单线聚焦
**收束**: 动作切断（转身走）

| 要素 | 内容 |
|------|------|
| 位置 | 灵站窗口内外 |
| 时间 | 上午 |
| 感官 | 灵枢嗡嗡声（听觉）、窗框磨损（视觉）、稳定剂瓶盖封条触感 |
| 核心动作 | 排队→刷卡领稳定剂→透过窗户看到韩朗额外操作 |
| 角色状态 | 沈念是"等待者"——排队时数门槛磨损、看蹲地画线的男孩 |
| 伏笔操作 | F2 planted：韩朗在灵枢上多敲四下（比正常刻录重）→低头看显纹板右下角→沈念角度看不到内容，但看到"确认"的表情 |

**韩朗表情设计**: 不是对人的笑，是对灵册上某行字的确认——像老陈分完碎渣说"七铜板"那个表情，专业、无情感。沈念看到的是"他在确认什么"这件事本身。

**微事件**: 
- 画线的男孩（世界呼吸——聚落里孩子的日常）
- 引渡椅磨损（远看一眼，为Ch7做铺垫）

---

### 场面3：换粮市集
**入场方式**: 物件（兑换券排在柜台上）
**结构**: 单线
**收束**: 动作（继续走）

| 要素 | 内容 |
|------|------|
| 位置 | 灵站东边岔道·合作商铺 |
| 时间 | 中午 |
| 感官 | 面粉味、指甲缝白粉、铁盒子丢券的声音 |
| 核心动作 | 用兑换券换面→9铜板 vs 现金7铜板→三成加价 |
| 角色状态 | 沈念没抱怨——她知道规则，选择接受。沉默本身就是信息 |
| 世界展示 | 兑换券经济剥削体系——灵站发行券、指定商铺、加价三成 |

**方岩修灯（远距离出现）**:
- 照柱灵灰岩石柱，底座纹结头
- 方岩蹲着拧，拧了半圈灯闪了一下又暗了，拧回去重新来
- 沈念放慢脚步看了几秒，方岩没抬头
- 费笔：他修灯总修不好——不是手艺不行，是在用修灯的时间想别的事（Ch3费笔呼应）

---

### 场面4：公告栏
**入场方式**: 环境（公告栏铁板生锈的视觉）
**结构**: 单线
**收束**: 物件特写（粉笔数字）

| 要素 | 内容 |
|------|------|
| 位置 | 灵站与市集之间 |
| 感官 | 生锈铁板、印刷纸 vs 手写纸的质感对比 |
| 核心动作 | 看灵枢丰收期通知→看寻狗启事→看灵能浓度读数 |
| 费笔（必含）| 寻狗启事"灰灰"——有人用铅笔画箭头指向灵站方向，旁边歪歪扭扭写"最后一次在这看到的" |
| 环境线索 | 灵能浓度读数比上个月高一格——沈念记住了，没说 |
| 微事件 | 两个老人下棋的对话——"收购价下调了""下调了去的人还更多，怪不怪"（世界呼吸+社会信息） |

**沈念弧线**: 她不只在看公告——她在对比。灵能升高+收购价变化=不对。但她"记住了，没说"。

---

### 场面5：暗格
**入场方式**: 动作（回到石屋，确认无人）
**结构**: 缩小聚焦
**收束**: 内心沉默（等他回来）

| 要素 | 内容 |
|------|------|
| 位置 | 石屋北墙 |
| 感官 | 铁皮掀开的金属声、旧布的触感、天光落在手上照出灰色 |
| 核心动作 | 掀铁皮→取兑换券→一张张数→叠好放回→铁皮盖好→碎渣袋挡住 |
| 角色状态 | 读者不知总数——沈念知道，但她不说。这是她的秘密 |
| 章末钩子 | 韩朗多敲了什么？灵能浓度为什么升高？暗格里有多少？ |

**关键细节**: 数券时天光照在手指上——灰色在日光下格外清晰。她没看手，低头数券。这个细节同时展示"身体状况恶化"和"她选择不看"。

## 四、微事件储备

### 费笔（≥2）
1. **寻狗启事**（必含）: "灰灰"，铅笔箭头指向灵站，"最后一次在这看到的"
2. **两个老人下棋**: "收购价下调了""下调了去的人还更多，怪不怪"（世界呼吸+社会信息）

### 日常微事件（≥2）
1. **洗碗时手指灰色**: 沈念看到灰色又多了一截→拉袖子→继续洗碗
2. **矿道口阿婆搭话**: 问灵站人多不多——邻里闲聊

### 世界呼吸（≥2）
1. **碎渣炉灰烟+暖味**: 整个石屋都是灰味和暖味挤在一起
2. **净囊过滤水**: 灰白色囊布磨得发亮，过滤后水还有灰味但好一点
3. **画线男孩**: 蹲在灵站墙根画圈，画完擦掉再画

### 弹性事件（字数不够时展开，3个）
1. **商铺老板多给了一把碎灵晶渣**: "凑个整"——市集里偶尔有的善意
2. **沈念观察排队人的细节**: 瘦高个儿没醒透、年轻女人孩子啃衣角
3. **方岩修灯细节展开**: 纹结头的铜质、磨损的引灵纹、灯柱顶端的闪烁

## 七、情绪曲线

```
场面1: 平稳日常（温暖底色+灰色暗线）
场面2: 微微紧张（韩朗额外操作→沈念注意到不对）
场面3: 日常+克制（剥削但沉默接受）
场面4: 信息密度↑（灵能升高+收购价变化→不对）
场面5: 安静收束（数券→秘密→等他回来）
```

整章情绪基调：表面平静，底层暗涌。沈念视角比沈野视角多了一层"我知道但我不说"的张力。
