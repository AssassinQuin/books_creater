# 创意蓝图：第1章《三堆法》

## 因果链确认

### 事件1：深管拾荒完整流程
- **因为** 外围穷，不捡就断粮；沈野靠"什么都捡"维持生存——碎渣是大头但不是全部
- **所以** 展示了他完整的拾荒技能链：掌贴岩壁感知灵脉走向→定位碎渣层→撬取；拆废弃灵矿石阀门取刻纹残片；塌方区扒铁木；岩壁缝隙抠异灵骨碎片
- **逼出** 三堆法的生存决策——全天收获分成三堆：换粮的/换药的/留自己的。这不是碎渣分拣法，是命的三等分
- **雪球** 三堆法展示了收入结构的脆弱性：沈野一个人撑两份（换粮+换药），"留自己的"永远最少
- **没变** 甬道里的矿灯还是只照三步远，外围人还是一辈子走在这三步里

### 事件2：五层残片（F1埋设）
- **因为** 拾荒路线深，沈野走到一处不常去的岩壁拐角
- **所以** 掌贴岩壁时摸到一块纹路异常的东西——五层嵌套纹路，从没见过
- **逼出** 一个选择：碎渣成色好，揣着没扔。掌贴上去时手指停了一下——不是温度异常，是"感觉不对"，纹路内部有某种结构他"摸"得懂
- **雪球** 他把这个选择当成"今天运气不错"，但读者知道这不是运气——这是他能力的第一道裂缝
- **没变** 矿灯的光还是灰绿的，甬道还是窄的，他还在赶时间

### 事件3：灰蜥追击
- **因为** 深管区域虫豸级灰蜥群行，追振动。沈野的撬取动作制造了微震
- **所以** 三四只灰蜥追来，沈野利用地形脱身——从塌方缝隙抄近道
- **逼出** 本能级空间判断力：他预判了灰蜥的追击路线，选择了正确缝隙。他不知道自己为什么算准，只当"运气好"
- **雪球** 灰蜥爪子划了他棉衣肩膀一口子（设定已有），他不补——实用主义性格具象化
- **没变** 外围人被灰蜥追是常事，没有人为此大惊小怪

### 事件4：老陈面摊碎渣换面
- **因为** 三堆法中"换粮的"那堆需要交易
- **所以** 沈野到老陈面摊，碎渣倒在台面上，老陈刮板一拨分成色："这堆七铜板，这堆五铜板，这堆——你留着铺路吧"
- **逼出** 日常中的温情：油在铁板上嗞一声，老陈多舀半勺汤。"今天碎渣成色好。"沈野把面端回家
- **雪球** 老陈的面摊=情绪锚点，所有温暖围绕热汤展开。但这个场景也暗示铜板经济的精确——七铜板就是七铜板，不多不少
- **没变** 聚落里其他人也在排队换面，铜板在碎渣袋里叮当响

### 事件5：兄妹晚饭
- **因为** 沈野把面端回家，沈念已经摆好碗
- **所以** 两人分一碗面。沈念把仅有的干菜叶夹到他碗里，他把碎渣匀到她汤里（注意：处理为"把一粒碎灵晶渣磨的粉匀进汤里"）。她没发现
- **逼出** 沈念帮他补棉衣裂口——针脚很密，补了三遍。他看她手指——袖口拉到盖住指尖，看不清。他想问，没问
- **雪球** 两个不对：①她补三遍针脚=她也在替他算日子②她想问没问的灰色指尖=灵衰症暗线启动
- **没变** 碎渣炉的灰烟从门缝往外冒，全屋灰味和暖味——日子照常过

**因果链完整性验证**：✅ 全部5事件因果链完整。没有断裂。事件1→2→3→4→5形成完整的一天时间线，逻辑连贯。每一步"因为→所以→逼出→雪球→没变"均可落地。

## 场面设计

### 场面1 | 密度: 轻量
- **时间/地点**: D1天没亮→清晨。深管/甬道，矿灯灰绿光只照三步远。岩壁潮湿，空气里有金属味+残渣微甜刺鼻+烧焦味
- **核心事件**: 沈野拾荒完整流程——从出门到收袋，展示"什么都捡"的外围生存全景
- **人物及目标（角色矩阵）**:
  · 沈野: 想{今天多捡点} / 障碍{深管区域异兽出没} / 对环境: 熟悉到麻木，不用想就能操作
- **微事件分配**:
  · 费笔①: 矿灯灰绿光——甬道里只有三步远的光，外围人一辈子都在三步远的光里走路（章首定调句，感官锚点：灰绿色+三步距离）
  · 费笔②: 沈野的指甲——指节老茧，指甲极短。抠异灵骨碎片时指甲缝塞满灰，他在裤腿上蹭了两下
  · 日常①: 掌贴岩壁感知灵脉走向——这个动作他一天做几十次，像呼吸一样自然。闭上眼指尖贴上去，十秒就够
  · 日常②: 拾荒袋的分类习惯——碎渣一层、骨碎片一层、阀门零件一层。袋子里面的秩序比他住的地方还整齐
  · 世界呼吸①: 风灌进甬道的呜咽声——远处低沉震动（兽潮存在感暗线），沈野没抬头
  · 世界呼吸②: 甬道岩壁上的旧刮痕——前人留的记号，碎渣画的白线过两天就没了
- **伏笔操作**: 埋设→五层残片铺垫（此场面后段，沈野走到深处拐角发现残片）；提起→无
- **镜头序列**: {建立镜头：矿灯照亮甬道三步} → {主镜头：沈野弯腰行走的背影+手的特写} → {插入镜头：掌贴岩壁的指尖+碎渣层的灰绿荧光} → {收束：矿灯灭，画面缩回三步的黑暗}
- **预计字数**: 1000-1200字

### 场面2 | 密度: 中量
- **时间/地点**: D1清晨。深管甬道深处，灰蜥领地边缘
- **核心事件**: 灰蜥追击——沈野利用地形+本能空间判断脱身，棉衣肩膀被划
- **人物及目标（角色矩阵）**:
  · 沈野: 想{脱身} / 障碍{灰蜥群追振动，壳宽不能过窄缝} / 对灰蜥: 虫豸级，不恐惧，纯经验应对
- **微事件分配**:
  · 日常①: 灰蜥追击时沈野的判断链——听到振动→数拍（几只）→看岩壁宽度→选缝隙。这不是英雄式反应，是活下来的人的自动化流程
  · 世界呼吸①: 灰蜥鳞片在矿灯光下闪了一下——大狗大小的东西在甬道里跑起来的声音像石头滚
- **伏笔操作**: 埋设→空间判断力本能（沈野"算准"了灰蜥不会选那条窄缝，他自己不知道为什么）
- **镜头序列**: {建立镜头：甬道深处的黑暗+低沉嘶嘶声} → {主镜头：沈野奔跑+侧身钻入塌方缝隙} → {插入镜头：灰蜥壳宽卡在缝口+沈野肩膀裂口渗出一线红} → {收束：沈野靠着岩壁喘气，棉衣裂口不补，继续走}
- **预计字数**: 600-800字

### 场面3 | 密度: 轻量
- **时间/地点**: D1傍晚前。老陈面摊——被火烧黑的铁锅架在金属板台面上（废弃灵站拆下的外壳），台面被碎渣灰染成灰绿色
- **核心事件**: 碎渣换面——老陈分成色、多舀半勺汤，沈野端面回家
- **人物及目标（角色矩阵）**:
  · 沈野: 想{把"换粮的"那堆换成面} / 障碍{无} / 对老陈: 熟人，不需要社交
  · 老陈: 想{正常做生意+多给点} / 障碍{无} / 对沈野: 看着他长大的，关心藏在"汤还热"里
- **微事件分配**:
  · 日常①: 老陈刮板一拨分了成色——"这堆七铜板，这堆五铜板，这堆——你留着铺路吧。"铜板经济精确到一铜板
  · 日常②: 油在铁板上嗞一声——面摊的嗅觉标记。老陈头都不抬
  · 世界呼吸①: 面摊前排队的几个拾荒者——没人聊天，各自数碎渣袋，铜板响的时候会抬头看一眼对方，然后低下头继续数
  · 世界呼吸②: 远处灵能公告栏上黄色预警灯闪了一下——兽潮预警灵阵的日常维护，没人多看
- **伏笔操作**: 提起→无；回收→无
- **镜头序列**: {建立镜头：面摊全景——铁锅+金属台面+排队的人} → {主镜头：碎渣倒在台面+刮板分堆的特写} → {插入镜头：老陈多舀半勺汤的手+沈野接过碗的手} → {收束：沈野端碗转身，面汤的热气在灰绿光线里散开}
- **预计字数**: 600-800字

### 场面4 | 密度: 重量（≥2人互动，≥800字）
- **时间/地点**: D1傍晚。沈野的家——甬道分支里一条"毛细血管"般的小甬道，石屋矮小需弯腰，碎渣炉铁皮桶里灰烟从门缝冒，全屋灰味和暖味
- **核心事件**: 兄妹分面、补衣服、沈野注意到沈念手指异常但不追问
- **人物及目标（角色矩阵）**:
  · 沈野: 想{把面带回来+确认妹妹状态} / 障碍{他说不出关心的话，只能看} / 对沈念: 唯一例外——他可以不说"嗯"的例外
  · 沈念: 想{照顾哥哥（补衣+分面）+隐藏灰色指尖} / 障碍{灵衰症恶化的体力下降+袖口遮不住全部} / 对沈野: 话多活泼是给他的保护壳——她在他面前笑得最自然
- **微事件分配**:
  · 日常①: 沈念摆碗的动作——两个碗、两双筷子，碗口有个缺口她让他用那个（理由是"那个碗大"）
  · 日常②: 碎渣炉的声音——铁皮桶里的碎渣偶尔噼啪一声，像在跟自己说话。沈野已经听不出这个声音了
  · 世界呼吸①: 净水囊过滤后的水倒进暖壶——水流过净囊还有点灰味，但比直接喝强。暖壶是沈野自己修的，暖纹比标准的多一个控纹节点
  · 费笔①: 补衣针脚——沈念补了三遍。第一遍针脚稀了她不满意，拆了重来。第三遍她把线拉紧，牙齿咬断。线头在灯下一闪
- **伏笔操作**: 埋设→沈念袖口/灵衰症暗线（袖口盖住指尖，沈野视角看不清，他想问没问——读者通过沈野视角意识到异常）
- **镜头序列**: {建立镜头：石屋全貌——碎渣炉+矮桌+两张坐垫} → {主镜头：两人分面+干菜叶的特写} → {插入镜头：沈念补衣的手指+袖口边缘的灰色+沈野视线的停留} → {收束：沈野把碎渣匀进沈念汤里，她没发现。他看她袖口，想问，没问}
- **预计字数**: 1000-1200字

## 叙事节奏

- **情绪曲线**: 场面1(强度3, 平稳日常) → 场面2(强度6, 短促紧张) → 场面3(强度4, 温情日常) → 场面4(强度5, 温暖底色下的裂缝)
- **转场方式**:
  - 场面1→2: **加速过渡**。拾荒流程中段自然切入灰蜥追击，不需要场景切换，是同一空间的情绪突变
  - 场面2→3: **时间跳跃+感官硬切**。从深管喘气→面摊油嗞声。中间的时间（沈野走回聚落）用一句带过
  - 场面3→4: **淡出过渡**。沈野端碗转身→推开家门。热汤的热气连接两个空间
- **节奏断层位置**: 场面2末尾→场面3开头。灰蜥追击的紧张余温还没散（沈野肩膀裂口渗血），下一秒就到了老陈面摊的油嗞声和铜板声。这个断层的核心：**外面追着你的东西，回家不值一提**。不解释恐惧，让断层说话
- **刀锋技法**: **沉默暴击**。用在场面4末尾。沈野看沈念手指→袖口拉到盖住指尖→看不清→想问→没问。整个过程中两人都在做正常的事（补衣服、喝汤），没有一个字提到异常。最大的刀是"他选择了不问"——不是不敢，是还没到必须问的程度。读者比他先意识到不对

## 角色行为弧线

### 沈野
- **本章起点**: 天没亮出门的拾荒者。对他来说这是普通一天——出门、捡东西、换面、回家
- **本章目标**: 拾荒换粮换药维持生存（显线）；让妹妹过得好一点但说不出这个目标（潜线）
- **关键行为**: ①五层残片掌贴上去停了一下——他第一次对一个东西产生了"摸得懂"的感觉，但归为"运气好"；②沈念袖口看不清→想问→没问
- **本章终点**: 表面回到日常。但口袋里多了一块"感觉不对"的残片，眼睛里多了一个"看不清"的袖口。两个不知道叠在一起
- **失控时刻**: 分面时把碎灵晶渣磨的粉匀进沈念汤里——这个动作本身是关爱，但"她没发现"三个字暴露了他的沟通模式：只做不说，做了也不确认对方知不知道。这个模式后面会害他

### 沈念
- **本章起点**: 在家等哥哥回来，摆好碗。正常的一天——给哥哥补衣、分面、笑
- **本章目标**: 照顾哥哥（补衣+分面）+隐藏灰色指尖不让沈野看到
- **关键行为**: ①把干菜叶夹到沈野碗里（分配上永远他优先）；②补了三遍棉衣裂口（针脚里藏着她替他算的日子）；③袖口拉到盖住指尖
- **本章终点**: 表面：正常的一天。暗面：灰色指尖在扩大，补衣三遍的针脚出卖了她的焦虑
- **失控时刻**: 补衣服时第三遍拆线重来——这不是正常补衣服。正常补一遍就够了。三遍不是完美主义，是她需要手里的活计填住脑子里的什么（灵衰症的焦虑？还是替哥哥攒路的焦虑？）。她不会说，但针脚比她的话更诚实

### 老陈
- **本章起点**: 面摊开张，刮板分碎渣的一天
- **本章目标**: 正常做生意，顺手多给沈野半勺汤
- **关键行为**: 分了成色后多舀半勺汤——夸人靠动作不靠词
- **本章终点**: 沈野端碗走了，他继续下一单
- **失控时刻**: 无（本章老陈是稳定锚点，不需要失控）

## 伏笔操作

### 埋设
1. **F1 五层残片**（高）— 沈野在岩壁拐角摸到五层嵌套纹路残片。掌贴上去时"感觉不对"——纹路内部有某种结构他"摸"得懂。读者知道残片特殊+沈野手感异常，但不知道为什么
   - importance: high
   - 计划回收章节: Ch8(本能使用)→Ch9(发热)→Ch15(与残盘共振)

   - importance: medium
   - 计划回收章节: Ch5(方岩搭手→手感框架化)
   - 场面位置: 场面2

   - importance: high
   - 计划回收章节: Ch10(翻背包→摊牌)
   - 场面位置: 场面4末尾

1. **[世界呼吸] 拾荒路上经过废弃矿道口——有个老人蹲在矿道口用石头磨骨扣**
   - 具体内容：沈野走过一条分支甬道时，看到一个不认识的老人蹲在矿道口，面前摆了七八颗骨扣，用石头一颗一颗磨。骨扣磨好了值两铜板一颗，磨坏了一文不值。老人手很稳，磨完一颗吹掉粉末放进口袋，再拿起下一颗。旁边放着一碗水，水面上漂了一层灰。沈野经过时老人抬头看了一眼——不是警惕，是认人的确认。确认不是同行，低头继续磨
   - 感官锚点：石头磨骨头的沙沙声+骨粉在水面上形成的灰色圆圈+老人手背上比沈野还深的裂纹
   - 人物弧线连接：沈野看了一眼，想到"磨骨扣一颗两铜板，一天磨二十颗也不过四十铜板"——和自己的拾荒收入对比。这个念头一闪而过，他没停步
   - 预估字数：400-500字

2. **[人物塑造] 沈野回家路上经过聚落公共区域——看到有人把碎渣炉歪了的炉子扶正继续烧**
   - 具体内容：沈野端面经过一条公共甬道——有人家的碎渣炉被今天的风吹歪了，灰烟往甬道里灌。一个女人弯腰扶炉子，小孩在旁边被呛得咳嗽。沈野经过时把面碗换到左手腾出右手帮了一下——没停步，扶正就走了。女人说了一句"谢了"，他没回头
   - 感官锚点：碎渣炉歪倒时灰烟的角度变化+铁皮桶在地上刮的声音+小孩咳嗽的回声在甬道里被放大

   - 预估字数：300-400字

   - 感官锚点：水入喉时的灰味（不是苦，是干燥的金属感）+暖壶三层旧布的触感+白渍在指甲下的硬度

   - 预估字数：300-400字
