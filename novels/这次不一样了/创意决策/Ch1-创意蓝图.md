# 创意蓝图：第1章《三堆法》

## 因果链确认

### 事件1：深管拾荒完整流程

```
因为 外围穷——拾荒是唯一生计，碎渣就是钱，钱就是沈念的药，药就是她多活一天
→ 所以 沈野每天天没亮进深管，掌贴管壁感受灵脉走向，按三堆法分类碎渣
→ 逼出 三堆法的分类逻辑——换粮的、换药的、留自己的——暴露生存优先级：药钱永远不够
→ 雪球 三堆法暗示"换药堆"永远最小→沈念的药是持续消耗品→稳定剂只是延缓不是治愈
→ 没变 其他拾荒者也在做同样的事，甬道深处偶尔传来敲击声——外围人的日常
```

**因果完整性**：✅ 前因充分（外围经济结构决定拾荒是唯一出路），后果必然（三堆法是拾荒者理性分类），选择有重量（药钱不够但必须持续投入），雪球方向明确（药→稳定剂→耐药→Ch10摊牌）

### 事件2：五层残片发现

```
因为 沈野日常动作——掌贴管壁感受灵脉走向（拾荒者的标准操作）
→ 所以 在管壁拐角摸到纹路异常的东西——五层嵌套残片，从没见过
→ 逼出 手指"摸"得懂纹路内部结构——他的通感天赋第一次被触发，但他只当是"手感好"
→ 雪球 残片收进布袋没扔→这个"手感"到底是什么？→F1埋设→Ch8本能使用→Ch10蓝光泄露→Ch15与残盘同频
→ 没变 管壁其他碎渣照常，五层残片是唯一异常——世界大部分照常运转，异常是局部的
```

**因果完整性**：✅ 前因充分（日常拾荒动作触发），后果必然（通感天赋对灵纹结构有反应），选择有重量（收起来没扔——直觉判断"这东西不一般"），雪球方向明确（F1主线伏笔）

**⚠️ 术语约束**：沈野能力描述禁止使用"灵能解构/铸造"，写作时用"通感""手感""说不清的感觉"替代。叙述中不解释这是天赋，只展示他的手指"停了一下"。

### 事件3：灰蜥追击脱身

```
因为 深管深处有灰蜥出没——甬道生态常态，拾荒者每天和它共处
→ 所以 灰蜥追来，沈野不能跑（灰蜥追振动），只能走
→ 逼出 利用地形记忆+本能级空间判断力，从塌方缝隙脱身——他以为这是经验，实际是天赋的一部分
→ 雪球 空间判断力=通感天赋的另一种表现→Ch3方岩递绳结时进一步展示→Ch8兽潮中本能反应
→ 没变 灰蜥还在甬道里，卡在缝隙里刨了三秒——它还在，危险还在，明天还得进管子
```

**因果完整性**：✅ 前因充分（深管生态），后果必然（灰蜥追振动→不能跑），选择有重量（走而非跑=冷静判断），雪球方向明确（天赋的另一种隐性展示）

**缺口补充**：灰蜥缺少生物细节。建议写作时补充——体型：半人长，灰白壳，四条短粗腿，脑袋楔形；攻击方式：冲撞+壳缘切割；速度：直线快但拐弯笨；感知方式：追振动。

### 事件4：老陈面摊换面

```
因为 拾荒回来需要把碎渣换成食物——碎渣经济是外围的底层循环
→ 所以 碎渣按成色分三堆定价——"这堆七铜板，这堆五铜板，这堆你留着铺路吧"
→ 逼出 老陈多舀半勺汤——外围的善意不说出口，用"今天碎渣成色好"代替"我知道你不容易"
→ 雪球 碎渣成色好=今天运气好→运气不能天天有→药钱缺口持续存在
→ 没变 面摊每天开，铁板嗞嗞响，碎渣经济照常运转——灵枢体系通过碎渣→兑换券→配给间接控制外围
```

**因果完整性**：✅ 前因充分（碎渣经济体系），后果必然（三堆定价是成色决定价格的市场逻辑），选择有重量（老陈的善意用行动不用语言），雪球方向明确（经济压力持续）

### 事件5：兄妹晚饭

```
因为 一天结束，两人分一碗面——这是他们每天的仪式
→ 所以 互相照顾——沈念把干菜叶夹给他，他把碎灵石渣匀到她汤里（她没发现）
→ 逼出 沈野看沈念手指——袖口拉到盖住指尖，灰色斑块只露一瞬→他想问，没问
→ 雪球 他没问→问题还在→沈念的病在恶化但他选择不面对→F4种子（Ch2正式种植，Ch10回收）
→ 没变 甬道壁凿出的洞里，碎渣炉灰烟冒，两个人每天这样吃饭——日常还在继续
```

**因果完整性**：✅ 前因充分（分面是日常仪式），后果必然（互相照顾是本能），选择有重量（想问没问=恐惧驱动的逃避），雪球方向明确（F4→Ch2种植→Ch10回收）

**⚠️ 缺口补充**：
- "家"缺少感官基线——建议补充：碎渣炉铁皮桶里碎渣不完全燃烧的灰烟味、油布挡风时甬道风声变闷、碎灵石渣在汤里化开时微微发热
- 稳定剂缺少物象描述——建议补充：小瓶，玻璃质但磨砂不透明，瓶身有灵站戳文，液体淡青色，开瓶有苦味

## 场面设计

### 场面1 | 密度：中量（偏重）

- **时间/地点**：D1天未亮→午前，深管废弃引流管甬道——灰绿光照三步，管壁灵脉纹路若隐若现，空气凉湿带铁锈味
- **核心事件**：沈野深管拾荒完整流程，发现五层残片，灰蜥追击脱身
- **人物及目标（角色矩阵）**：
  · 沈野：想捡够碎渣换药钱 / 障碍：深管灵息稀薄碎渣少、灰蜥出没 / 对灰蜥：判断→规避→脱身
- **对话指令**：沈野独处，无对话。内心活动通过动作表达——摩挲残片时手指停住、灰蜥刮擦声传来时不回头、侧身过缝隙时吸肚子。沉默是这里的主声部
- **动作指令**（五拍链）：
  1. 掌贴管壁感受灵脉走向——指腹压住冷硬矿脉壁面，像盲人摸字
  2. 定位碎渣层撬取——布袋渐满，按三堆法分堆
  3. 拐角处手指停住——残片五层纹路，"摸"得懂内部结构
  4. 灰蜥刮擦声→不跑→走——追振动，跑等于喊它过来
  5. 塌方缝隙侧身挤过——肩胛刮岩壁，回头看灰蜥卡住三秒，转身走了
- **微事件分配**：
  · 费笔≥2：
    - 矿灯灰绿光照三步——外围人一辈子在三步远的光里走路，再远就是黑
    - 管壁灵脉纹路像老树的年轮，指腹贴上去能感觉到灵息的流向——凉的地方空，温的地方有碎渣
  · 日常≥2：
    - 布袋里碎渣按三堆法分——换粮堆、换药堆、留自己的堆，雷打不动
    - 矿灯额头绑带磨出的凹痕，每天出门前检查一遍矿灯灵石还亮不亮
  · 世界呼吸≥2：
    - 甬道深处偶尔传来其他拾荒者的敲击声——远，像另一个世界
    - 管壁某处灵矿石裸露层被前人撬过，留下一排整齐的凿痕——有人比他先来过
- **伏笔操作**：埋设 → F1五层嵌套残片（手感异常——"摸"得懂纹路内部结构，通感天赋第一次触发）
- **镜头序列**：移动镜头（跟着沈野进甬道，矿灯光圈在前方晃）→ 建立镜头（甬道灰绿光三步，管壁灵脉纹路）→ 插入镜头（残片五层纹路特写——指腹贴上去手指停住）→ 移动镜头（灰蜥追击中穿行——不跑，走）→ 插入镜头（灰蜥脑袋卡在缝隙口，四条腿刨出火星）→ 收束（出甬道，日光刺眼眯眼）
- **预计字数**：1200-1800字

### 场面2 | 密度：轻量

- **时间/地点**：D1午后，深管出口三十步老陈面摊——铁皮棚子三张矮桌，废灵矿石垒灶台，油烟焦香铁板嗞声
- **核心事件**：碎渣换面，三堆定价，老陈多舀半勺汤
- **人物及目标（角色矩阵）**：
  · 沈野：想用碎渣换一碗面 / 障碍：碎渣成色决定价格 / 对老陈：交易关系，不多话
  · 老陈：日常营业 / 障碍：无 / 对沈野：老主顾，多舀半勺汤不说原因
- **对话指令**：极简交易对话。老陈报成色——"这堆七铜板，这堆五铜板，这堆你留着铺路吧"。沈野不还价。老陈多舀汤只说"今天碎渣成色好"，不说真正原因。潜台词密度10-20%（轻松日常场景）。老陈的善意用行动不用语言——外围人的规矩
- **动作指令**：
  1. 碎渣倒案板
  2. 老陈刮板一拨分成色——刮板用了十几年，木柄磨出指形凹槽
  3. 油在铁板上嗞的一声
  4. 面碗搁膝盖，汤糊半张脸
  5. 碗底干净
- **微事件分配**：
  · 费笔≥2：
    - 铁板上油嗞的一声——外围最奢侈的声音
    - 老陈刮板木柄磨出指形凹槽——十几年的东西，手和工具长在一起了
  · 日常≥2：
    - 碎渣按成色分三堆定价——灵枢体系通过碎渣成色间接控制外围物价
    - 面汤热气糊了半张脸——吃面的时候什么都看不见，只有热和咸
  · 世界呼吸≥2：
    - 旁边矮桌两个老人下棋，聊灵站收购价——"我孙子在灵站当差，说最近收购价下调了"
    - 面摊灶台废灵矿石垒的，灵息残渣燃烧时冒灰烟——碎渣经济从灶台开始
- **伏笔操作**：埋设 → F4预热种子（面汤里沈野匀碎灵石渣——为场面3沈念汤里的碎灵石渣铺垫）
- **镜头序列**：建立镜头（铁皮棚子三张矮桌，油烟在日光里散开）→ 插入镜头（刮板分碎渣成色——三堆）→ 插入镜头（油在铁板上嗞）→ 反应镜头（沈野埋头吃面，汤糊脸）→ 收束（碗底干净，起身走）
- **预计字数**：500-800字

### 场面3 | 密度：中量

- **时间/地点**：D1傍晚，家——甬道壁凿出的洞，洞口油布挡风，铺板两个木箱一个灶，碎渣炉灰烟从门缝往外冒
- **核心事件**：两人分一碗面，沈念补棉衣，沈野看手指想问没问
- **人物及目标（角色矩阵）**：
  · 沈野：想确认沈念的手指到底怎么了 / 障碍：问了就是面对，他还没准备好 / 对沈念：唯一例外，但今天选择不问
  · 沈念：想照顾哥哥、隐藏病情 / 障碍：袖口盖不住所有灰色，补衣服时针扎到手会抖 / 对沈野：笑，补衣服，不说疼
- **对话指令**：沈野对沈念稍长句（"先吃，这个凉的"），沈念话多但今天少了一句——"少一句就是信号"。关键沉默：沈野看到手指→想问→没问。用动作填充沉默——摩挲食指关节。潜台词密度40-50%（关系推进场景）。沈念的"没事啊"永远不是没事。沈野的沉默不是不在意，是不敢问
- **动作指令**：
  1. 沈念把仅有的几片干菜叶夹到他碗里
  2. 他把碎灵石渣匀到她汤里——她没发现
  3. 她补棉衣裂口——针脚很密，补了三遍
  4. 他看她手指——袖口拉到盖住指尖，灰色斑块只露一瞬

- **微事件分配**：
  · 费笔≥2：
    - 碎渣炉铁皮桶里碎渣不完全燃烧，灰烟从门缝往外冒——家的气味是灰烟和凉汤
    - 沈念的针线盒——铁皮罐头盒改的，里面三根针一团线，线是拆旧衣服攒的
  · 日常≥2：
    - 面汤里沈念把干菜叶夹给他——"你今天走得多，多吃点"
    - 沈野把碎灵石渣匀到她汤里——碎灵石渣微微发热，在汤里化开她感觉不到
  · 世界呼吸≥2：
    - 甬道外面有人经过的脚步声——邻居，不招呼，外围人各过各的
    - 碎渣炉的火光照在管壁上，灵脉纹路若隐若现——灵息在管壁里流，不管人在不在
- **伏笔操作**：埋设 → F4种子（沈念袖口盖住手指，沈野想问没问——Ch2正式种植F4，Ch1种下种子）
- **镜头序列**：建立镜头（甬道壁洞，油布挡风，碎渣炉灰烟）→ 插入镜头（面汤里的干菜叶——她夹给他）→ 反应镜头（沈念低头补衣服，针脚细密）→ 插入镜头（手指灰色斑块——只露一瞬，袖口拉下）→ 反应镜头（沈野摩挲食指关节，嘴动了一下没出声）→ 收束（沉默。碎渣炉灰烟冒。两个人各干各的）
- **预计字数**：1000-1500字

## 叙事节奏

- **情绪曲线**：场面1(强度4) → 场面2(强度2) → 场面3(强度6)
- **起承转合分配**：
  - 起(12%)：场面1前段——深管拾荒流程建立，三堆法展示生存逻辑（~400字）
  - 承(45%)：场面1中后段（残片发现+灰蜥追击）+ 场面2（面摊换面）（~1500字）
  - 转(28%)：场面3前中段——分面互相照顾，补棉衣，手指灰色斑块露出（~900字）
  - 合(15%)：场面3后段——想问没问，沉默收束（~500字）
- **节奏断层位置**：场面1→场面2之间——从灰蜥追击的紧张（短句密集、动作加速）突然切换到面摊的日常（长句舒缓、油烟焦香）。硬切转场，速度骤降。读者从"他会没事吗"的紧张跌入"这就是他的日常"的平静——紧张感没有释放，只是被日常压住了
- **刀锋技法**：悬而未决——场面3末尾，沈野看到沈念手指灰色斑块，想问没问。章末不解决这个悬念。沉默代替回答，动作代替语言。读者带着三个问题离开：残片是什么？他的"手感"到底是什么？她袖口盖住的是什么？

## 角色行为弧线

### 沈野

- **本章起点**：天没亮出门拾荒，日常生存模式。冷脸，算账优先，拾荒者的全套生存技能在线
- **本章目标**：捡够碎渣换药钱——今天的任务和昨天一样
- **关键行为**：
  1. 发现五层残片——手指"摸"得懂纹路内部结构（通感天赋第一次触发，但他只当是"手感好"）
  2. 看到沈念手指灰色斑块——想问，没问（恐惧驱动的逃避，不是理性选择）
- **本章终点**：回家，沉默。问题没有解决，只是被压下去了。他的保护模式还在旧轨道上——"大概没事"就过去了
- **失控时刻**：看到沈念手指灰色斑块时摩挲食指关节——他几乎要开口了，嘴动了一下，但没出声。这不是理性判断"现在问不合适"，是恐惧让他把话咽回去。他怕问了就不得不面对答案

### 沈念

- **本章起点**：在家等沈野回来，日常照顾模式。阳光，话多，笑起来嘴角先动眼睛后亮
- **本章目标**：照顾哥哥，隐藏病情——袖口盖住手指，不说疼
- **关键行为**：
  1. 补棉衣——针脚很密补了三遍（她在用照顾他来填补自己说不出口的话）
  2. 袖口拉下来盖住手指——灰色斑块蔓延到第一关节，她知道但不能让他知道
- **本章终点**：补完衣服，笑了一下。她的秘密又藏过了一天。但袖口比昨天又拉低了一指宽
- **失控时刻**：补衣服时针扎到手——她没出声，但手指抖了一下。沈野看到了但假装没看到。两个人都在假装——她假装不疼，他假装没看见

### 老陈

- **本章起点**：面摊日常营业，刮板搅锅
- **本章目标**：做生意
- **关键行为**：多舀半勺汤——"今天碎渣成色好"
- **本章终点**：继续搅锅。面摊还在，日子还在过
- **失控时刻**：无（NPC极简，搅锅报价一两个短句）

## 悬念锚点

章末制造三个悬念，形成读者追读动力：

1. **残片悬念**：五层嵌套纹路是什么？为什么他的手指"摸"得懂？（F1主线伏笔入口）
2. **天赋悬念**：沈野的"手感"到底是什么？他以为只是经验，但五层残片的手感不一样——这是天赋的第一次触发（能力线入口）
3. **病情悬念**：沈念袖口盖住的是什么？沈野想问没问——灰色斑块只露一瞬（F4种子入口）

三个悬念的权重：病情 > 天赋 > 残片。读者最先关心的是"她怎么了"，其次是"他到底是什么人"，最后是"那块残片有什么用"。
