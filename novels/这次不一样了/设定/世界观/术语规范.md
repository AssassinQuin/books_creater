# 术语规范

> 写作前必读，写作后逐项检查。这个世界有自己的说话方式——不要用现代术语，要从世界观的根上长出正确的词。

## 一、世界原生命名逻辑

这个世界是**中世纪 + 末世 + 兽潮 + 寡头 + 教会 + 灵能黑科技**。

这里的人不知道什么叫"信息时代"。他们理解世界的方式是三种东西：

- **灵能是自然力**——像水（流动/凝固/蒸发）、像矿脉（沉积/开采/提炼）、像风（波动/感知/回响）
- **技术是器物**——设备是器、纹路是刻痕、记录是册
- **管理是制度**——权力是令、身份是牌、秩序是规

### 遇到现代概念时的思维路径

写作时脑子里冒出一个现代概念，不要查表替换——走下面四步，从世界观的根上想出来：

**第一步：这个概念的本质是什么？**

剥离现代外壳，找到它最底层的功能。比如"数据库"的本质是"存东西的地方，以后能找回来"。"加密"的本质是"让只有特定的人能看懂"。"权限"的本质是"谁被允许做什么"。

**第二步：这个世界的人怎么感知这件事？**

他们看不到"数据流"——他们看到灵册翻页、灵息波动、纹路亮灭。他们不操作"系统"——他们拨灵台、对纹路、翻灵册。他们不"登录"——他们验腰牌、认纹路、出示灵契。

问自己：**一个矿工/猎人/灵站操作员/灵枢文吏，会用什么感官来感知这件事？** 手摸到的？眼睛看到的？耳朵听到的？灵能波动感觉到的？

**第三步：他们日常最熟悉的东西是什么？**

用他们已有的经验来类比。灵枢文吏最熟悉册、档、令、牌。壁盾军人最熟悉阵、垒、锋、盾。猎人最熟悉探、嗅、走、刀。教会祭司最熟悉圣、辉、戒、颂。外围拾荒者最熟悉碎渣、刮刀、甬道、岩壁。

问自己：**这个概念最像他们日常生活中的哪样东西？**

**第四步：用那个东西的说法来说。**

"数据库"→ 存灵册的地方 → 册房/档阁
"加密"→ 让别人看不懂 → 刻密纹
"权限"→ 谁能做什么 → 腰牌等级/令权
"扫描"→ 用眼睛/灵能扫一遍 → 巡纹/探脉
"系统崩溃"→ 整个东西断了/散了 → 枢网断了/规制散了

### 关键原则：不是替换词，是换一种看世界的方式

查表替换是偷懒——遇到"数据"就写"灵册"，遇到"系统"就写"规制"，换汤不换药。

正确的做法是：**先想这个世界的人会怎么理解这件事，再用他们的语言说出来。**

比如"系统崩溃"——这个世界的人不知道什么叫"系统"，更不知道什么叫"崩溃"。但他们知道"枢网断了"（灵枢网散了，灵站之间传不了讯了）、"规制散了"（原来运转的规矩不灵了）、"令出不了枢城"（命令传不下去了）。三种说法对应三种视角——灵枢文吏说"枢网断了"，壁盾军士说"令出不了枢城"，外围猎人说"灵站不动了"。**同一个事，不同的人有不同的说法。**

### 怎么识别现代术语

不需要背列表。现代术语有一个共同特征：**这个世界的人没有对应的感官经验**。

他们摸不到"数据"，看不到"信号"，听不到"频率"，操作不了"系统"。如果一句话里出现了他们**无法用五种感官（手/眼/耳/鼻/灵能感知）去体验**的词，那就是现代术语——走四步思维路径，从世界观的根上重新长出来。

自检方法：写完一句，想象韩朗或方岩站在旁边——他听得懂吗？他会怎么说？

## 二、命名规范（最高优先级）

### 2.1 核心原则：不可什么都加"灵"

"灵"字在这个世界观里是技术前缀——就像现实中我们不说"电路灯泡""电动冰箱""热力灶台"，我们说"灯泡""冰箱""灶台"。灵能已经是这个世界的基础设施，不需要每样东西都标注"灵能驱动"。

**禁止模式**：
- 灵能+名词（灵能短刀、灵能罗盘、灵能碎渣、灵能学院）——功能描述式命名，AI味重
- 纹路+名词（纹路保暖衣、纹路灯柱、纹路灶台、纹路飞舟）——技术原理不该出现在物品名里

**正确做法**：
- 用物品的**特征**命名（赤鳞、铁麦、夜苔、碎渣炉）
- 用**文化根脉**命名（震刃、探脉盘、惊雷阵、枢城）
- 用**口语缩略**命名（暖衣、暖壶、净囊、照柱、铸锤）
- 日常物品直接用**本名**（驮兽、猎鹰、短刀、灶台）

### 2.2 保留"灵"字的术语（已固化，不可改）

| 术语 | 理由 | 别名（仅记有特色的） |
|------|------|----------------------|
| 灵枢 | 文化根脉：枢=枢纽，《庄子·天枢》 | —— |
| 灵晶 | 已固化为货币名 | 石头（外围叫法，带轻蔑——"几块石头换我半天命"） |
| 灵站 | 已固化为设施名 | —— |
| 灵契 | 文化根脉：契=契约 | 卡（中域以下口语，"刷卡"=用灵契） |
| 灵衰症 | 已固化为疾病名 | 灰病（民间）/ 慢慢死（外围底层） |
| 灵灶 | 日常物只需一个字区分普通灶 | —— |
| 异灵 | 物种类名，区分于普通野兽 | —— |

### 2.3 命名方法论（层积命名法）

每个新术语必须通过以下流程：

**Step 1 概念解构**：拆解命名对象的本质要素
**Step 2 文化映射**：从道教/佛教/民俗/历史制度中找对应
**Step 3 组合筛选**：按音韵感、陌生化、体系一致性筛选
**Step 4 验证测试**：角色会怎么说？读者会好奇吗？查文化出处能找到吗？

**命名三层结构**：
- 底层：文化根脉（道教/佛教/民俗/历史出处）
- 中层：专业术语（书面上使用的正式名）
- 表层：口语称呼（角色日常对话中的叫法）

**别名原则**：不是所有东西都需要别名。只有满足以下条件之一才给别名：
1. 阶级差异——同一东西不同阶层叫法不同，反映世界观裂痕
2. 画面感强——别名比正式名更有画面，读者一看就记住
3. 叙事功能——角色会因身份不同用不同名，有剧情作用
4. 文化反差——正式名和民间名之间有有趣落差

纯缩略不算别名（驮兽→兽、暖壶→暖壶）、无信息增量不算（碎渣→渣）、太泛不算（灵灶→灶）

| 南方密林 | 野性、神秘、危险 | 血棘、印藤、地伏花蛇、蚀心蕈 |

### 身份验证

| 术语 | 功能 | 形态 |
|------|------|------|
| 腰牌 | 身份标识 | 灵能物品，记录个人纹路 |
| 手谕 | 临时授权 | 灵能文书，带签发者印记 |
| 誓约 | 契约关系 | 灵能层面绑定 |

**验证机制**：纹路 + 物品 + 灵能 = 效果实现

### 记录体系

| 术语 | 说明 |
|------|------|
| 碑文 | 远古文明记录，自然形成，基本无法解析 |
| 灵册 | 人类从碑文偷学的简化技术，可记录基础灵能信息 |

### 灵枢网

人为建设的灵站网络 + 信息传输系统。

- 灵站：抽取环境灵能的设施 + 信息中转
- 传输：灵站之间的物理通道
- 信息：传讯石 / 灵册 / 腰牌令牌
- 运行：各灵站独立运转，通过传讯石同步，管理员根据灵枢司命令或灵台感知后本地调整

### 灵台

灵能矿石雕刻的石台/祭坛。灵能流过特定纹路产生效果。外观如中世纪星盘、日晷、占星台。

### 灵印

感知型觉醒者可学习的基础追踪技术。在目标身上留下灵能纹路印记，通过感知印记位置追踪。

### 密纹 / 显纹

| 术语 | 说明 |
|------|------|
| 密纹 | 主动遮蔽的灵能纹路，需特定条件读取 |
| 显纹 | 让隐藏纹路显现 |

### 对纹 / 强纹

| 术语 | 说明 |
|------|------|
| 对纹 | 让两个灵能结构的纹路协调一致 |
| 强纹 | 远超安全阈值的深层纹路匹配，研究院实验产物 |

### 传讯石

成对的灵能通讯工具。一对之间以灵能纹路连接，向一块注入灵能，另一块同步显纹。距离有限，需定期充能。

## 十、建筑用语规范

**禁止管道风格**：世界观中不存在"管道"概念——灵能不通过管道输送，而是通过纹路和地脉流动。

| 禁止用语 | 替换用语 | 说明 |
|---------|---------|------|
| 管道 | 甬道/矿道 | 地下通道用甬道，矿工通道用矿道 |
| 管壁 | 岩壁/墙壁 | 地下结构用岩壁，建筑用墙壁 |
| 管路段 | 矿道段 | 仅限矿区语境 |
| 管路 | 矿道/甬道 | 视语境选择 |
| 管道群 | 甬道群 | 废墟地下结构 |
| 管道口 | 矿道口/入口 | 视语境选择 |
| 管道走向 | 矿道走向 | 仅限矿区语境 |
| 管道内 | 矿道内 | 仅限矿区语境 |

**建筑设计原则**：中世纪+灵能黑科技，非蒸汽朋克。灵能通过纹路流动，不通过物理管道。建筑外观以石砌、木构、铸合矿为主，内城白塔群+虹桥，中域砖石城墙+供塔，外围石堡+木栅。拒绝一切"管道输能"概念——灵能在纹路中流动，纹路刻在墙壁、地面、桥面上，不是藏在中空管道里。
