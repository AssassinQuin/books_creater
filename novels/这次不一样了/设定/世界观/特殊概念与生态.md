## 一、特殊概念与设定

### 1. 灵能现象类

#### 1.1 黑月潮涌（灵能潮汐）

| 项目 | 内容 |
|------|------|
| **名称** | 黑月潮涌（俗称"涨潮"） |
| **定义** | 黑月封印裂缝周期性扩大导致的灵能浓度剧烈波动现象。灵能如潮水般从裂缝涌出，向四周扩散又回缩，形成可预测的周期性涨落。 |
| **来源/历史** | 第三纪元末期，初代枢印师发现黑月并非静止天体，其表面封印存在呼吸般的节律。第四纪元元年，枢都建立"潮涌志"记录体系，至今已完成三百余轮完整观测。 |
| **影响范围** | 全球范围，但强度随距离衰减。枢都周围涨落幅度约30%，北方矿区约20%，东部海岸因洋流扰动可达40%，西部荒原不足5%，南方密林则呈现反常的"逆潮"现象。 |
| **相关势力** | 枢都"潮涌司"（专职预测与预警）、北方矿脉"守闸人"（利用低潮期深入矿区）、东部"流韵商会"（潮汐贸易调度） |

#### 1.2 灵脉凝渊

| 项目 | 内容 |
|------|------|
| **名称** | 灵脉凝渊（又称"地窍闭锁"） |
| **定义** | 高密度灵能在地下灵脉节点处过度压缩，形成肉眼不可见但灵纹印可探测的"负压区"。进入者会感到灵能被缓慢抽离，长期滞留将导致灵纹退化。 |
| **来源/历史** | 第三纪元"大刻印时代"遗留问题。当时枢印师为固定灵脉走向，在关键节点打入"锁窍桩"，部分桩体年久失效后形成反向虹吸效应。 |
| **影响范围** | 已知七处，最大者在西部荒原腹地（直径约三里），最小者在南方密林根系层（仅数丈）。枢都地下亦有微型凝渊，被用作"灵狱"关押重犯。 |
| **相关势力** | 枢都"地窍阁"（监测与封印）、西部"荒原巡脉队"（标记危险区域）、黑市"吸灵盗"（非法采集凝渊核心"渊晶"） |

#### 1.3 纹韵共鸣

| 项目 | 内容 |
|------|------|
| **名称** | 纹韵共鸣（又称"同纹相召"） |
| **定义** | 当两个结构高度相似的灵纹印在近距离同时激活时，产生的相互增幅或干涉现象。共鸣可提升能力效果，也可能导致纹路过载崩解。 |
| **来源/历史** | 第三纪元中期偶然发现。两名枢印师在实验中使用了同源纹路，引发小型爆炸。此后"共鸣律"成为灵纹学核心分支，"契纹配对"成为高阶技术。 |
| **影响范围** | 理论上任何灵纹印均可共鸣，但实际需相似度达七成以上。枢都"共鸣院"掌握三百余组稳定共鸣对，民间私传约数十组。 |
| **相关势力** | 枢都"共鸣院"（研究与管制）、军方"双纹营"（配合作战单位）、地下"纹贩"（非法交易稀有共鸣对） |

### 2. 社会制度类

#### 2.1 九窍品阶制

| 项目 | 内容 |
|------|------|
| **名称** | 九窍品阶制（全称"人身九窍灵纳品第"） |
| **定义** | 以人体可承载灵纹印的数量与质量划分社会等级的制度。将人分为"未开窍""一窍通"至"九窍圆"十个品阶，品阶决定职业准入、婚配范围、赋税额度。 |
| **来源/历史** | 第四纪元十五年由枢都"品窍院"制定，取代早期混乱的"能者居之"局面。初衷是标准化人才选拔，后期逐渐僵化，成为阶层固化的工具。 |
| **影响范围** | 枢都及直属领地严格执行，北方矿区以"矿脉贡献"折算品阶，东部海岸实行"流动品阶"（随船队业绩浮动），西部荒原基本无视，南方密林部落有类似但独立的"根脉深度"体系。 |
| **相关势力** | 枢都"品窍院"（评定与仲裁）、各地方"开窍所"（检测与登记）、反对派"平窍社"（主张废除品阶） |

#### 2.2 灵契牒册制

| 项目 | 内容 |
|------|------|
| **名称** | 灵契牒册制（简称"契册制"） |
| **定义** | 所有具有法律效力的灵能契约必须以特定纹路书写于"灵纸"上，经"印关"加盖官印后存入"契阁"备查的制度。涵盖婚契、地契、商契、奴契、死契五大类。 |
| **来源/历史** | 第四纪元三十年，枢都为解决灵能契约纠纷频发而立法。初代"契阁"仅存纸质档案，第五十年引入"灵刻痕"永久备份技术，契约不可伪造、不可抵赖。 |
| **影响范围** | 枢都法律体系核心，北方矿区矿权契约为重点，东部海岸海上贸易契约适用，西部荒原仅口头契约，南方密林以"血纹"替代。 |
| **相关势力** | 枢都"契阁"（档案管理）、"印关署"（官方认证）、商会"契行"（中介与担保）、黑市"伪契坊"（非法仿制） |

#### 2.3 纹传宗法

| 项目 | 内容 |
|------|------|
| **名称** | 纹传宗法（全称"灵纹印世袭传承律"） |
| **定义** | 允许家族将核心灵纹印通过特殊仪式"纹移"传递给血亲的特权制度。被传承者需承受"纹压测试"，失败者将遭受灵脉损伤。 |
| **来源/历史** | 源于第三纪元末期几个大家族为保存研究成果而私设的传承仪式。第四纪元六十年被官方承认并规范化，但限定每代仅可传承一道核心纹路。 |
| **影响范围** | 枢都贵族与世家核心利益，北方矿区三大矿主家族以此垄断"深脉探测纹"，东部海岸船王家族传承"航韵纹"，西部荒原无此传统。 |
| **相关势力** | "纹传世家"（约二十余家掌握特权）、"移纹殿"（官方仪式执行）、反对派"断纹会"（主张纹路公有） |

### 3. 信仰/仪式类

#### 3.1 黑月瞑祭

| 项目 | 内容 |
|------|------|
| **名称** | 黑月瞑祭（又称"关目礼"） |
| **定义** | 每月黑月完全遮蔽（"关目"）时举行的集体冥想仪式。参与者封闭视觉，以灵息感知黑月辐射的"原初韵律"，借此净化纹路、恢复灵能。 |
| **来源/历史** | 起源已不可考，第三纪元已有文字记录。最初是枢印师的研究手段，后演变为全民性宗教活动。第四纪元建立"瞑祭司"统一管理。 |
| **影响范围** | 全球通行，但形式各异。枢都举行万人大祭，北方矿区在矿井深处小型举行，东部海岸在船上面向黑月，西部荒原因黑月稀薄而效果微弱，南方密林与"树瞑"结合。 |
| **相关势力** | 枢都"瞑祭司"（组织与解释权）、"原初道"（将其神圣化的宗教派别）、"瞑盗"（利用仪式期间防御空虚作案的匪帮） |

#### 3.2 开窍典仪

| 项目 | 内容 |
|------|------|
| **名称** | 开窍典仪（全称"人身灵窍启封大典"） |
| **定义** | 儿童年满十二岁时，由"开师"以特定灵纹印刺激体内"隐窍"，测定其灵能亲和度与可承载纹路类型的仪式。结果决定其一生品阶起点。 |
| **来源/历史** | 第四纪元十五年与九窍品阶制同步设立。最初使用粗暴的"强启法"，致死率极高；第四纪元四十年改革为"韵导法"，安全性大幅提升。 |
| **影响范围** | 枢都及直属领地强制举行，北方矿区可延后至十四岁（等待体格发育），东部海岸部分船民子女在海上由随船开师举行，西部荒原与南方密林无此仪式。 |
| **相关势力** | "开师行会"（垄断仪式执行权）、"品窍院"（结果认证）、"替窍门"（非法为富家子弟伪造开窍结果的地下组织） |

#### 3.3 痕葬

| 项目 | 内容 |
|------|------|
| **名称** | 痕葬（全称"灵刻痕归土礼"） |
| **定义** | 高阶灵能者死后，将其遗体置于"痕穴"中，使其一生积累的灵纹印逐渐渗入地质层，形成"道痕"的丧葬仪式。道痕可被后世开采利用。 |
| **来源/历史** | 第三纪元"大刻印时代"发明。最初是枢印师为保存研究数据而设，后演变为荣誉象征。第四纪元立法规定，只有"五窍"以上者方有资格申请痕葬。 |
| **影响范围** | 枢都周边"痕陵"为圣地，北方矿区存在古代痕葬群（重要矿脉来源），东部海岸海下痕穴（潜水采集），西部荒原古代痕葬因灵能稀薄而保存完好，南方密林"根葬"为变体。 |
| **相关势力** | "痕陵司"（管理与维护）、"采痕人"（合法开采道痕）、"盗墓痕者"（非法盗掘古代痕穴）、"归土派"（主张道痕应自然演化，反对开采） |

## 二、动植物设计

### 1. 灵能植物类

#### 1.1 纹纸树

| 项目 | 内容 |
|------|------|
| **名称** | 纹纸树（学名：灵脉桦，俗名：契树、牒木） |
| **外观** | 高可达十丈，树皮呈淡金色，叶片薄如蝉翼且带有天然细密纹路。秋季叶片脱落时，纹路会短暂发光。树干截面可见年轮状"脉轮"，每一轮对应一年的灵能浓度变化。 |
| **生态习性** | 仅生长于枢都周围灵能浓度稳定区域。根系极浅，依赖空气中灵息而非土壤养分。对灵能潮汐敏感，涨潮时叶片直立，退潮时垂落。 |
| **用途/价值** | 叶片经处理后即为"灵纸"，是书写灵契牒册的唯一合法载体。脉轮木材可制作高阶灵纹印的"承纹板"。树皮提炼的"金浆"是上等灵墨原料。 |
| **分布区域** | 枢都周围"金环带"，人工林场为主，野生种群稀少。 |
| **首次出场建议** | 主角在契阁目睹一份古老地契，纸张历经百年仍纹路清晰，引出纹纸树的介绍。 |

#### 1.2 韵丝苔

| 项目 | 内容 |
|------|------|
| **名称** | 韵丝苔（俗名：吟苔、唱绒） |
| **外观** | 附生苔藓，呈银蓝色，丝状分枝可长达数尺。无风时会自发颤动，发出类似低吟的微弱声响。密集生长处会形成"韵场"，声音交织如合唱。 |
| **生态习性** | 东部海岸特有，附生于礁石与船底。依赖海水中的灵能微粒与潮汐节律生长。退潮时休眠，涨潮时活跃。可被特定频率灵纹印"调谐"，改变其发声模式。 |
| **用途/价值** | 调谐后的韵丝苔可作为"活警报器"，感知特定灵息波动。其提取物"韵露"是制作"声纹印"的必需材料。干燥韵丝为高级乐器共鸣材料。 |
| **分布区域** | 东部海岸潮间带，远洋船只底部（随船扩散）。 |
| **首次出场建议** | 海港码头的船底刮削工正在清理船底，刮下的韵丝苔被分类收集，主角注意到不同船只的苔色深浅不一，暗示船只曾到访不同灵能浓度海域。 |

#### 1.3 窍根参

| 项目 | 内容 |
|------|------|
| **名称** | 窍根参（俗名：人形根、九须参） |
| **外观** | 地下块根呈人形，有主根与九条侧根，形似人体九窍。表皮土黄色，切开后断面有星点状灵纹。年限越久，人形越完整，星点越密集。 |
| **生态习性** | 北方矿区深层矿脉缝隙中生长。根系可穿透岩石，追踪灵脉走向。对灵能浓度极度敏感，会在凝渊边缘主动回避。冬季地上部分枯死，块根休眠。 |
| **用途/价值** | 核心药材，可炼制"开窍散"（辅助开窍典仪）、"固窍丹"（稳定品阶）。高年限者可直接研磨为"窍粉"，临时提升灵纹印承载上限。 |
| **分布区域** | 北方矿区深层，野生为主，人工培育困难。 |
| **首次出场建议** | 矿难救援中，老矿工凭窍根参的分布判断灵脉安全走向，救出被困者，同时暗示矿区生态与灵能地质的深层关联。 |

#### 1.4 痕菌

| 项目 | 内容 |
|------|------|
| **名称** | 痕菌（学名：灵刻真菌，俗名：道痕菇、记忆菌） |
| **外观** | 菌丝体在地下蔓延，子实体仅在古代道痕上方冒出地面。子实体形态因所吸收的道痕内容而异：战斗类道痕上长出带刺菌盖，治愈类道痕上长出半透明胶质菌盖，知识类道痕上长出层叠如书页的菌盖。 |
| **生态习性** | 严格依赖道痕中的灵能残留生长。菌丝可解读道痕信息并转化为子实体形态。生命周期与灵能潮汐无关，而与道痕衰减速度相关。 |
| **用途/价值** | 子实体是"读痕"的辅助材料，可帮助灵能者模糊感知道痕原主的情绪与记忆。某些形态稀有者（如"书页菇"）是黑市高价收藏品。过度采集会导致道痕加速衰减。 |
| **分布区域** | 古代痕陵周边，已开采的古代矿区，海下痕穴。 |
| **首次出场建议** | 盗墓痕者的赃物中出现一枚奇特菌菇，契阁调查员通过菌菇形态反推被盗痕穴的类型，引出痕菌与道痕的关系。 |

#### 1.5 契血藤

| 项目 | 内容 |
|------|------|
| **名称** | 契血藤（俗名：盟约藤、血纹蔓） |
| **外观** | 攀援藤本，茎干呈暗红色，表面有凸起纹路，酷似灵契牒册上的契约纹路。叶片对生，触碰后会渗出淡红色汁液。果实为蒴果，成熟爆裂时种子呈"印"状。 |
| **生态习性** | 南方密林特有，与多种树木形成"血契共生"——藤根接入宿主根系，以灵能为媒介交换养分。若宿主死亡，契血藤会在一个潮汐周期内枯死。可被人工嫁接，用于标记边界。 |
| **用途/价值** | 汁液是"血契"仪式的重要材料，可使口头契约产生类似灵契的约束力（但效力较弱且难以解除）。茎干纤维可编织"契绳"，用于临时束缚灵能者。种子"契印"是南方部落交换的通货。 |
| **分布区域** | 南方密林全境，人工嫁接种群见于枢都贵族花园（象征"牢固盟约"）。 |
| **首次出场建议** | 南方部落使者与枢都贵族谈判，以契血藤汁液当场缔结"血契"，主角观察到汁液纹路流动与正式灵契的异同，暗示南方密林存在独立的灵能文明体系。 |

### 2. 异化动物类

#### 2.1 纹瞳鼠

| 项目 | 内容 |
|------|------|
| **名称** | 纹瞳鼠（俗名：窥纹鼠、志录鼠） |
| **外观** | 普通田鼠受灵能影响后的变异种，体型略大，双眼虹膜上生有天然微型纹路。不同个体纹路各异，如同指纹。毛色因所处区域灵能属性而异：枢都周围淡金，北方矿区蓝灰，东部海岸银青，西部荒原土黄，南方密林暗绿。 |
| **生态习性** | 夜行性，以灵纹印残留的能量碎屑为食。会本能地追踪新鲜灵息，因此常出现在灵能者活动区域。繁殖力极强，但变异率仅约一成。 |
| **用途/价值** | 纹瞳可制作"窥纹镜"的辅助镜片，帮助解读复杂纹路。活体可用于探测灵纹印残留（比仪器更灵敏但不可靠）。部分灵能者饲养作为宠物与警报器。 |
| **分布区域** | 全球分布，随人类聚落扩散。 |
| **首次出场建议** | 案发现场发现一只纹瞳鼠，其瞳孔纹路记录了凶手使用灵纹印时的灵光一闪，成为关键物证，引出"生物志录"的概念。 |

#### 2.2 脉息蚕

| 项目 | 内容 |
|------|------|
| **名称** | 脉息蚕（俗名：韵丝蚕、灵络蚕） |
| **外观** | 家蚕变异种，体色半透明，体内可见灵能如血液般流动。吐丝时丝缕带有微弱灵息波动，成品丝线在黑暗中会发出对应区域灵能属性的微光。 |
| **生态习性** | 必须以纹纸树叶片或同类灵能植物为食，普通桑叶无法存活。结茧时会将一生吸收的灵能浓缩于茧壳纹路中。化蛾后灵能尽失，恢复为普通昆虫。 |
| **用途/价值** | 茧丝是"灵织品"原料，可制作承载灵纹印的衣物（如"韵甲""息袍"）。蚕蛹可提炼"脉息油"，用于保养灵纹印器具。蛾翅粉末是某些仪式的催化剂。 |
| **分布区域** | 枢都周围人工养殖为主，东部海岸有小型海养种群（以韵丝苔为食，产"海韵丝"）。 |
| **首次出场建议** | 贵族子弟炫耀其"韵甲"内衬，提及原料脉息蚕的稀有程度，主角注意到甲胄内侧的蚕丝纹路竟与某份古契纹路相似，暗示灵织品与灵契的共同起源。 |

#### 2.3 渊影鸽

| 项目 | 内容 |
|------|------|
| **名称** | 渊影鸽（俗名：黑月鸽、关目鸟） |
| **外观** | 岩鸽变异种，羽毛呈深蓝近黑色，仅在黑月光下会泛出暗金色光泽。双眼可直视黑月而不盲，瞳孔为罕见的竖瞳。飞行时翅膀振动频率与灵能潮汐存在微弱共振。 |
| **生态习性** | 筑巢于高处，偏好灵能浓度变化剧烈的区域。迁徙路线与灵能潮汐方向高度一致。具有群体"共鸣导航"能力，单只迷失后可通过同类共振找回方向。 |
| **用途/价值** | 经过训练的渊影鸽是"灵信"传递的可靠工具，其体内可短暂储存微型灵纹印信息，比纸质密信更难截获。鸽羽可制作"黑月瞳"护具，减轻直视黑月的伤害。 |
| **分布区域** | 枢都周围塔楼、北方矿区井架、东部海岸灯塔、南方密林树冠层。西部荒原因灵能稀薄而罕见。 |
| **首次出场建议** | 密信被截，但截获者发现信鸽体内储存的灵纹印信息已自毁，仅余一片鸽羽。主角通过鸽羽来源追溯至某特定鸽舍，引出灵能信息传递的攻防体系。 |

### 3. 灵能生态类

#### 3.1 灵息藻华

| 项目 | 内容 |
|------|------|
| **名称** | 灵息藻华（俗名：韵潮、光涌） |
| **外观** | 并非单一物种，而是多种灵能微藻在特定条件下爆发性增殖形成的生态现象。海面或湖面被一层发光的藻膜覆盖，颜色从淡蓝到金绿不等，随灵能潮汐节律明暗脉动。 |
| **生态习性** | 触发条件：灵能潮汐峰值+水温适宜+营养盐充足。持续数日至数周，期间下方水体严重缺氧。藻华消退后留下"藻痕"——一层富含灵能的沉积物，可维持数月。某些大型藻华会形成"伪灵脉"，干扰探测。 |
| **用途/价值** | 藻华期可采集"华露"——高纯度液态灵能，是制作高阶灵墨的顶级材料。藻痕沉积物是优质农田肥料。但过度采集会破坏生态，导致后续数年藻华不再发生。 |
| **分布区域** | 东部海岸近海为主，枢都周围湖泊偶有小型藻华，南方密林沼泽存在"腐华"变体（暗红色，有毒）。 |
| **首次出场建议** | 船队为追逐藻华而与另一船队发生冲突，主角目睹海面发光如潮的奇景，同时发现藻华下方隐藏着某古代沉船痕葬的线索。 |

#### 3.2 根脉网络

| 项目 | 内容 |
|------|------|
| **名称** | 根脉网络（南方部落称"大地之息"，枢都学者称"木灵脉"） |
| **外观** | 南方密林特有的生态现象。密林深处，古老树木的根系通过灵能媒介相互连接，形成覆盖整片森林的地下网络。网络节点处（古老巨树根部）会渗出"树液灵息"，在地面形成发光的脉络图案。 |
| **生态习性** | 网络具有信息传递能力——一棵树遭受伤害，远处节点可感知振动。某些学者认为网络存在"群体意识"，但尚未证实。灵能潮汐期间，地面脉络图案会改变，被南方部落用作"自然历法"。 |
| **用途/价值** | 节点树液是"活灵墨"的唯一来源，书写时纹路可随环境微调，适应性极强。网络本身是不可再生的"天然灵脉图"，对研究灵能地理具有无价价值。南方部落通过特定仪式"接入"网络获取信息。 |
| **分布区域** | 南方密林核心区，外围森林仅有零散连接。枢都曾有移植尝试，均告失败。 |
| **首次出场建议** | 南方向导带领队伍穿越密林，刻意避开某些区域。主角夜间观察到地面发光脉络如血管般搏动，追问下得知根脉网络的存在，以及一个禁忌——某些"死脉"区域会吞噬接入者的灵能。 |
