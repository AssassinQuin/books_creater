# 种族体系

## race: 种族体系

> **条目名**：种族体系

## 元数据

- **volume_range**: V1-尾声
- **region**: 全域
- **writing_guide**: 写种族时避免写成'另一个阵营'——种族关系比敌友更复杂。制度性压迫体现在日常细节中。不把任何种族写成全善全恶。灵裔傲慢来自寿命不是天性，地族顺从来自实力不是懦弱，鸦裔中立来自信息优势不是冷血，石裔沉默来自愧疚不是木讷。每个种族背后都藏着未解之谜，主角在故事推进中逐步发现。种族间的冲突不用战争场面体现，用集市价格、执照审批、日常摩擦体现。远古历史通过遗址发现、灵裔口述、鸦裔记忆碎片逐步揭示，不是开篇就倒出来。
- **priority**: 50
- **is_constant**: false
- **status**: active

## 详细内容

- **data**:
    - **races**:
        - **人族**: <!-- name -->
            - **dawn**: 三千年前不过是七族最弱，散落大陆东部河谷给灵裔种地。灰烬纪后在废墟中捡到灵纹批量刻印法，从捷径崛起
            - **glory**: 灰烬纪后靠灵纹商品化建立统治——灵纹变税、变律法、变只有人族能考的官职
            - **fall**: 统治不是因最强，是因最早学会把灵纹变商品。内部撕裂比种族矛盾更深
            - **now**: 占壁城六成人口。住内城石屋也住外围土棚。内城人族看外围拾荒人族比看兽裔还嫌弃。灵纹普及运动是穷人人族先喊的
            - **lingneng**: 灵纹技术主要使用者但非天生灵能种族，通过学习和刻印掌握灵纹。灵纹商品化的始作俑者
            - **friction**: 街角能听到人族小贩用灵裔语骂灵裔，用土话骂官府，转身对兽裔顾客多收两成。人族内部阶级撕裂比种族矛盾深
            - **mystery**: 灰烬纪中批量刻印法从哪来？官方说'先贤独创'，但灰烬纪前遗址从未出现人族灵纹器物。有说法：那个模具从地底挖出
        - **灵裔**: <!-- name -->
            - **dawn**: 精灵基底，寿命200+。灵纹是他们的语言不是工具
            - **glory**: 辉脉王朝横跨大陆中脊，城市从山脉中生长，每条街道是活的灵纹回路
            - **fall**: 灰烬纪中石裔倒戈切断灵脉供给线，辉脉王朝覆灭。灵裔没有忘记——两百年寿命意味着背叛故事鲜活如昨
            - **now**: 不到壁城一成，聚居内城旧脉巷，巷下还埋着辉脉王朝灵纹管（枯了没人敢挖）。垄断高端灵纹技术，壁城首席纹师过半灵裔。但政治被边缘化，军事级灵纹研究禁止灵裔参与——名义安全实则防复国
            - **lingneng**: 天生灵能共振，灵纹刻印像呼吸。看人族用模具压灵纹像书法家看印刷体
            - **friction**: 纹师工价是人族三倍，人族骂宰客灵裔反唇'你那也叫灵纹'。年轻灵裔说人族话比利裔语利索，填种族栏审批多两道
            - **mystery**: 末代王将核心灵纹图谱封入'脉心'器物，从未被找到。灵裔家族暗中角力只为找脉心复国。但长老害怕找到——王朝覆灭真正原因可能不是石裔背叛
        - **石裔**: <!-- name -->
            - **dawn**: 矮人基底，骨密度是其他种族两倍。裂谷城锻造场能把灵纹刻入金属分子结构，成品强十倍且不衰退
            - **glory**: 裂谷城在北部山脉深处，地下锻造场是七族灵器的巅峰
            - **fall**: 灰烬纪倒戈的分支被自己人驱逐。裂谷城三百年前废弃，锻造技术失传，现用简化版灵纹只刻表面用几年就磨没
            - **now**: 不到壁城两成，聚在锻造区和矿场。矿难死亡率是地面八倍。口传'血账'记录每笔亏欠。壁城石裔是叛徒后代——他们自己知道。灵裔提灰烬纪时石裔不反驳，沉默在锻造锤节奏里
            - **lingneng**: 天生感知矿脉灵纹走向，锻造灵纹器物是绝技。不是天赋是骨骼——塌方能扛住别人扛不住
            - **friction**: 锻造技术被征用，器物署名人族工匠。矿难石裔间流传：'塌方时人族跑兽裔挖石裔扛——因为只有我们扛得住'
            - **mystery**: 裂谷城为何废弃？官方说灵脉枯竭，血账记着另一件事：地下最深层封着'原脉'——未经加工的世界初始灵纹。长老禁止接近。然后整座城就空了
        - **地族**: <!-- name -->
            - **dawn**: 霍比特基底。灰烬纪记录里是被战火碾过的地方——不是目标只是刚好在路上
            - **glory**: 没有远古荣光可追忆。活下来的方式只有一个：往下钻
            - **fall**: 打不过就挖洞抢不过就藏粮追不上就堵路。壁城建城时与人族达成协议，但协议内容和人族的理解从来不是同一回事
            - **now**: 聚居壁城地下三到五米的地道网，连城墙根排水沟都能通到菜窖。壁城粮食三成来自地族但没人写在告示栏。种'根薯'不需阳光靠灵能碎屑就能长
            - **lingneng**: 灵能亲和度最低觉醒率极低，但对灵衰症有天然抗性——别人绝症他们咳嗽两周。这让某些势力非常感兴趣，地族非常警惕
            - **friction**: 交的永远比留的多。安分不是善良是打不过。没有人族通行证的地族小贩被城管追着跑
            - **mystery**: 为什么能抗灵衰症？有说法'基因层面灵能排异'，但灵裔纹师酒后说：'地族不是抗灵衰——是灵衰的幸存者。第一次灵衰不是灰烬纪之后才有的。'次日否认
        - **兽裔**: <!-- name -->
            - **dawn**: 半兽人基底。曾控制大陆北部整个草原，灰烬纪里是灵裔王朝最凶猛的先锋
            - **glory**: 灵纹加持下徒手撕开城门。辉脉王朝给每个部落分配一条灵脉——名为'共生契约'实为锁链
            - **fall**: 灵脉在部落领地中心，离开就失去灵纹供给战士衰弱。兽裔后称之为'第一根锁链'
            - **now**: 住城外营地。有通行证可进但营地便宜且人族不放心兽裔聚集。壁盾征召当先锋死亡率最高，阵亡通知连章都不盖。年轻人当兵不为爱国为军饷稳定
            - **lingneng**: 觉醒率低但一旦觉醒爆发力最强。灵纹刻印粗犷如斧劈但灵能密度是灵裔两倍。灵器鉴定所不成文规矩：兽裔灵器不鉴定怕承认比灵裔强
            - **friction**: 被当野蛮人。部落长老想保持独立年轻人被征走。军饷是营地唯一稳定收入
            - **mystery**: 辉脉王朝分配的灵脉覆灭后仍在运行，无人维护自行运转两千年。按现有理论不可能。灵脉位置连起来恰好画出一个圆
        - **灵族**: <!-- name -->
            - **dawn**: 灵能生命体，来源不明——连灵族自己都不记得。半透明体质灵能高处近隐形灵能低处如褪色水渍
            - **glory**: 灵纹是母语不需学习拿起刻刀就会。最接近灵纹本质的种族
            - **fall**: 寿命仅30-40年记忆同样短。离开灵能高浓度区域迅速衰弱，活动范围被物理条件锁死
            - **now**: 壁城不到一百人，聚居在内城灵能浓度最高的区域。离开高灵能区迅速衰弱，活动范围被物理条件锁死。最精密灵纹校准离不开灵族，报酬是灵能供给。死后灵能回归自然不结晶——这让研究灵族的人困惑很久
            - **lingneng**: 本身就是灵能生命形态，灵纹是母语。最顶尖的灵纹师都是灵族
            - **friction**: 从高处看下去看见所有人但不被任何人看见。活得不长但比任何种族都接近灵纹本质
            - **mystery**: 寿命为何如此短？若真是灵能凝聚应和灵能一样长久。有灵族纹师死前留话：'灵纹不是工具是世界的骨骼。灵能是我们的血液。世界在流血。'怀疑短命不是天然——是某种东西在消耗他们，消耗他们的也在消耗世界
        - **鸦裔**: <!-- name -->
            - **dawn**: 群体记忆共享种族，记忆可追溯灰烬纪之前。灰烬纪记录中不参战但每场战争前后都在交战双方间穿行
            - **glory**: 没有远古荣光需要吹嘘——从来不需要。群体记忆让赢家写的史书和输家流的血同时存在，没有矛盾只有真相。真相让他们选择永远中立
            - **fall**: 知道太多的人没有朋友。所有种族的秘密都装在鸦裔记忆里，但没有任何种族真正信任他们
            - **now**: 西墙根集市清晨开日落散，卖的不是货是消息。一个铜片一条当日情报，十个铜片一条只有三人知的事。价格公道也同时卖给对家
            - **lingneng**: 灵能波动的接收器能截获灵纹通讯。群体记忆通过灵能共振传递，个体活六七十年但集体记忆延续千年
            - **friction**: 人族利用灵裔提防兽裔不信石裔地族假装他们不存在。最孤独的种族。不站队不是冷血是看过了所有站队的后果
            - **mystery**: 集体记忆中有不属于任何已知历史时期的片段——画面里大陆灵纹全亮从山脉到海洋整片大陆被灵纹覆盖如发光的网。长老说是'第一次记忆'比灰烬纪还早。但鸦裔也会说这些记忆可能伪造——'没动机骗你，也没动机告诉你哪些是真的'
    - **overview**: 壁城集市上，人族粮饼摊主对地族顾客多看一眼不是嫌弃是确认有没有偷带私粮。灵裔纹师铺子前的人族学徒被骂了不还嘴但出巷子就举报铺子灵纹等级超标。石裔铁匠给兽裔修灵器不掺水因为矿场旁就是兽裔营地今晚铺子可能需要他们帮忙看着。鸦裔信使同一杯茶功夫把三条消息卖给三拨人每条都真但只说三分。灵族纹师在高处看下去看见所有人不被任何人看见。城墙上壁盾兵灵能长矛暗着——充能要钱城墙不会因为矛尖暗了就塌。种族间仇恨不在脸上在价格里在执照里在日常的每一寸空间里。没有人早上起来说'我要压迫其他种族'但每天日落时城里权力格局又往人族这边挪一寸。不是阴谋是惯性。惯性比阴谋可怕因为你可以反抗阴谋但没法反抗昨天。
