# 建筑与聚落

> 核心调性：中世纪 + 兽潮 + 灵能黑科技 + 寡头 + 末世。
> 建筑首先是防御工事，其次才是住所。兽潮是日常威胁，所有建筑都要考虑防兽。
> 你住什么样的房子，就是什么样的人。

## location: 管道聚落

- **keys**: ["管道聚落", "管道", "拾荒者", "灵能烤炉", "蔽息纹", "阿公布"]
- **secondary_keys**: ["地下管道", "帆布隔断", "灵能残渣", "碎渣取暖", "外围住所"]
- **tags**: ["地点", "外围", "聚落", "沈野起点", "建筑"]

- **volume_range**: V1-V2

- **空间结构**：地下废弃管道系统改建。一人半高铁管，帆布和木板隔断，管道平行排列如肠腔
- **灵能状态**：稀薄但不稳定——管壁沉积的灵能残渣时多时少，多的时候指尖碰管壁能觉出微弱刺痛，少的时候跟荒原上没区别
- **感官基线**：
  - 气味：铁锈 + 灵能残渣的酸味 + 灵能烤炉的烟。三种味道混在一起，住久了闻不出来，走出去再回来才呛
  - 声音：管道回声 + 远处异灵嚎叫 + 风灌进管口的呜咽。说话要喊，不然回声把字吞了
  - 温度：冬冷夏闷。冬天铁管冻手，夏天管道里闷得像蒸笼
  - 光照：照明石的暖黄色。碎渣品质差，光也暗，远远看管道口像一排昏黄的眼
- **所属势力**：无——拾荒者自治
- **功能**：外围拾荒者的住所
- **特色**：公共灵能烤炉是聚落核心；入口处有阿公布的灵能陷阱；蔽息纹门帘挡虫豸
- **人口**：约200人
- **安全等级**：高危——兽潮来了只能堵管道口祈祷
- **首次出场**：V1

管道聚落不是"建"出来的，是"占"出来的。

前代城市的地下管道系统废弃之后，拾荒者钻进去搭棚子住。没人知道那些管道最初是做什么的——管壁上刻着看不懂的纹路，有些还微微泛光，大部分已经暗了。拾荒者不管那些，能挡风就行。

管道直径一人半高，成年人弯腰走，抬头磕铁皮。管道之间用帆布和木板隔断——说是隔断，其实就是挂块布、插块板，挡不住声音也挡不住气味，只能挡住视线，给自己圈出一小块"这是我的地方"。管道平行排列，像肠腔一样弯弯绕绕，新来的人走三趟也记不住路。聚落里的人靠管道壁上的刻痕认路——老住户刻的，三角形是往里走，叉号是死路，圆圈是有水渗出来可以接。

管道的铁壁挡风挡雨但挡不住异灵。虫豸能钻进管道，牙能撕开铁皮。聚落的"防御"是入口处的灵能陷阱和蔽息纹门帘，聊胜于无。灵能陷阱是阿公布设的——阿公布是聚落里唯一懂灵能纹路的老人，手抖得厉害但刻纹还准，陷阱能炸虫豸，炸不了牙。蔽息纹门帘挂在管道口，灵能纹路编织的粗布帘子，能遮蔽管道里人的灵息，让虫豸闻不出来。但门帘是旧的，纹路磨损大半，灵能残渣补上去也撑不了几天。兽潮来了，聚落能做的就是堵管道口——推碎石堆、焊铁皮板、把所有能搬的东西堆在管口——然后祈祷。

管道深处有公共灵能烤炉。烧碎渣取暖做饭，碎渣在炉膛里噼啪响，烟散不出去，顺着管道飘，住久了肺都是黑的。灵能烤炉是聚落里唯一的热源，也是唯一能煮热汤的地方。老陈的面摊就搭在烤炉旁边——一口被火烧得发黑的铁锅架在金属板台面上，台面是从废弃灵站拆下来的外壳。面汤没什么油水，但热乎。聚落里的人收工回来，端一碗蹲在管道边上喝，算是这一天里最像"活着"的时刻。

雨季管道积水，没到脚踝，深的地方到小腿。冬天漏风，风从管壁裂缝灌进来，棉衣裹三层还是冷。但比荒原上露天强——至少有个顶。至少不用半夜被虫豸咬醒。

沈野和沈念就住在管道聚落里。他们的"家"是管道末端一个死胡同，帆布隔出两间——外面是沈野的，里面是沈念的。沈野在管壁上刻了一排蔽息纹，手艺粗糙但比没有强。管道口挂着蔽息纹门帘，门帘是沈念缝的，灵能残渣磨成粉掺进线里，缝了三层。

猎人管管道聚落叫"铁肠子"——弯弯绕绕，住里面的人像肠子里的虫。拾荒者自己不这么叫，他们管这叫"家"。虽然这个家随时可能被兽潮碾碎。

外围人怎么说："铁肠子？能住。比荒原上强。至少有个顶。"

## location: 灵站堡垒

- **keys**: ["灵站堡垒", "灵站", "围屋", "引渡椅", "公告栏", "兽潮预警"]
- **secondary_keys**: ["灵晶交易", "灵能引渡", "围屋群", "灵站余热", "外围避难所"]
- **tags**: ["地点", "中域/外围交界", "灵站", "建筑", "过渡地带"]
- **related**: ["三环结构", "灵衰症机制", "征召与内城体系"]
- **volume_range**: V1-V14
- **priority**: 30
- **is_constant**: 否

- **空间结构**：灵站本体（一层石砖建筑 + 引渡椅 + 公告栏 + 感应器）+ 围绕灵站建的围屋群（青砖矮房）
- **灵能状态**：灵站压低周围浓度，比外围稳定。灵站周围百步内灵能波动平缓，像被一只手按住了
- **感官基线**：
  - 气味：灵晶的金属味 + 人群的汗味 + 围屋炊烟。灵站里面更冷更干净，围屋里更暖更呛
  - 声音：灵站设备嗡鸣 + 人群嘈杂 + 围屋里的叫卖。灵站本体嗡嗡响，像一头铁兽趴在那里喘气
  - 温度：比外围暖——灵站运转散出余热，围屋群蹭这个热量
  - 光照：灵站灯光（冷白）+ 围屋窗户的油灯（暖黄）。灵站的光是冷的，围屋的光是暖的，分界线就在灵站围墙门口
- **所属势力**：灵枢司
- **功能**：灵晶交易 + 灵能引渡 + 兽潮预警 + 安全居住
- **特色**：灵站是方圆几里最安全的建筑——墙壁最厚、窗户最小、有灵能预警。围屋群像卫星一样围绕灵站，越近越贵越安全
- **人口**：围屋群约500-800人
- **安全等级**：中风险——灵站能挡虫豸，牙级以上需要猎人/壁盾支援
- **首次出场**：V1

灵站堡垒是外围和中域的过渡地带。从荒原上走过来，远远先看见灵站的灯——冷白色的光在灰蒙蒙的荒原上特别扎眼，像一块钉在地上的铁牌子写着"这里安全"。

灵站本身是一层石砖建筑，比管道聚落强在"有正经墙壁"。石砖砌的，灰白色，墙面刻了灵能防御纹——纹路不复杂，但管用。窗户小得只够伸出一个拳头，门板厚得需要两个人推。灵站里面是引渡椅、读取器、公告栏、感应器——灵枢的触角伸到外围的末端。引渡椅在灵站最里面，隔着一道布帘，坐上去的人能听见灵能流过身体的嗡嗡声。公告栏在灵站门口，铁板焊的，上面贴满纸条和灵枢公告，黄色预警灯在顶上闪。感应器连着灵枢网的灵息感知网，灵能浓度一有异常就亮灯。

围绕灵站建的围屋是中域底层人的住所。青砖矮房，一间挨一间，像蜂巢一样挤在灵站周围。房租比普通砖棚贵三倍但住的人排队——安全比什么都重要。围屋越靠近灵站越贵，最里面一圈围屋的住户大多是灵站员工和小商贩，最外面一圈住的是刚从荒原上搬来的人，房租便宜但兽潮来了最先遭殃。围屋之间的巷道窄得只能侧身走，头顶是邻居搭的晾衣杆，脚下是泥水和碎砖。

灵站堡垒的墙壁更厚，窗户更小，像堡垒多过像家。这不是建筑师的审美——是活下来的经验。壁厚挡牙，窗小挡虫豸，门板厚挡冲撞。灵站围墙上面刻了灵能防御纹，虫豸撞上来会被弹开，但牙级反复冲撞能撞裂。灵站顶上有预警灯和传讯石，兽潮来的时候灯闪三下，传讯石往周围灵站发灵息。

兽潮来了，灵站堡垒是外围人最后的避难所——挤进灵站围墙内，推搡、叫喊、哭，祈祷墙能撑住。墙撑住了，明天继续过日子。墙没撑住，就没有明天了。

灵站经理通常是灵枢派来的执枢级员工，穿灰蓝制服，胸口别齿轮套灵晶徽章。他管灵站运转、灵晶收购、围屋出租、兽潮预警——一个灵站经理就是这方圆几里的土皇帝。好的经理会在兽潮来时开放灵站内堂让人躲，坏的经理锁门只让交了钱的进。

猎人管灵站堡垒叫"铁壳子"——硬但闷，住里面像被壳扣住了。外围人管灵站叫"救命桩"——兽潮来了往灵站跑，跑到了就活，跑不到就死。

外围人怎么说："灵站那堵墙，是我这辈子见过最厚的东西。不是因为建筑好——是因为命薄，墙就显得厚了。"

## location: 中域城镇

- **灵能状态**：稳定，灵站维持浓度在可用范围。灵能波动平缓，像一条流速均匀的河
- **感官基线**：
  - 气味：食物 + 灵能染料 + 铁匠铺的烟。市集上烤肉和灵能染料的味道混在一起，闻着比外围像人住的地方
  - 声音：市集叫卖 + 酒馆喧哗 + 教会钟声。城镇的白天是吵的，晚上也不安静——总有巡逻队的脚步声
  - 温度：四季分明但有灵能供暖。冬天屋里比外围暖，但暖得不均匀——灵站附近暖，边角还是冷
  - 光照：油灯 + 灵能灯 + 枢光纹。灵能灯比照明石亮，照在石砖路上有反光。教会礼拜堂的灵能蜡烛光最暖
- **所属势力**：灵枢司（名义）/ 多势力共存（实际）
- **功能**：交易 + 居住 + 信息交换 + 宗教活动
- **特色**：中域城镇是"正常生活"的极限——有市集、有酒馆、有教会，像中世纪城镇。但城镇外围有厚墙和灵能防御纹，墙外就是荒原和异灵
- **人口**：数千至数万不等
- **安全等级**：低风险——城镇防御能挡大部分兽潮
- **首次出场**：V2

中域城镇是外围人梦想中的"好地方"——有正经房子、有市集、有酒馆、有教会。从管道聚落走出来的人第一次站在城镇街道上，会愣住：脚底下是铺好的石砖，不是泥地；头顶上有屋檐，不是铁皮；窗户上有玻璃——灵能处理过的薄石片，透光但不透风。

街道是石砖铺的，雨天不踩泥。房子是青砖砌的，墙厚门实，窗户有玻璃。灵能灯挂在街角，比照明石亮十倍，照在石砖路上有反光。城镇的灵站比外围大十倍，公告栏上的信息更详细更及时，引渡椅有六把而不是一把。灵站门口永远有人排队——卖灵晶的、引渡的、看公告的、求医的。

城镇外围有厚墙。城墙高三丈，青砖砌成，外面抹了灵能加固层，表面刻满灵能防御纹——虫豸撞上来会被弹开，牙级需要几次冲撞才能破。城墙上有巡逻道，壁盾兵或城镇卫兵24小时轮班。城门是铁皮包木，门洞里有灵能感应器，进出要验牌。城墙外面是荒原和异灵，城墙里面是"正常生活"——这个"正常"是城墙撑起来的，墙倒了正常就没了。

猎人酒馆是城镇的信息中心——墙上贴满手写纸条和灵站公告，猎人在这里交换情报、接任务、买卖装备。酒馆的规矩简单：不问来路，不传闲话，欠债还钱。教会礼拜堂是城镇最高的建筑——尖顶指向黑月，钟声一响全城都听得见。黑月瞑祭在这里举行，信徒闭眼感知黑月的灵能辐射。

市集在城镇中央，摊位挤摊位，卖什么的都有——灵晶、灵能装备、食物、草药、灵能染料、旧衣服。铁匠铺在市集边上，锤声从早响到晚，灵能短刀和灵能陷阱都从这里出。市集的角落有灵枢回收官的摊位，收灵晶打八折，但至少不用跑灵站排队。

中域城镇的"正常"是脆弱的。城墙外面就是荒原，兽潮来了城墙能挡大部分，但挡不住角级以上。城镇的灵站维持灵能浓度在可用范围，但灵站调值偏了浓度就波动，波动了异灵就活跃。城镇的安宁像一层薄冰——踩着没事，碎了就掉下去。

外围人怎么说："进了城才知道，原来人可以住砖房。原来路可以不踩泥。原来灯可以亮到半夜。原来活着可以是这个样子。"

猎人酒馆不是"酒馆"——是猎人生态的核心节点。

从外面看就是一间普通石砖房，门板厚，窗户小，门口挂一块木牌，上面刻了酒杯和短刀交叉的图案。推门进去，热气和噪音一起扑过来。大堂里永远有人在喝酒、吵架、交换情报。长条木桌排成三排，凳子是粗木钉的，坐上去吱呀响。壁炉在大堂最里面，烧一整天，火光把人的影子拉得老长。

墙上贴满手写纸条。白条黄条红条黑条按颜色分区——白条在门口附近，黄条往里，红条在柜台旁边，黑条在角落。灵站公告贴在最显眼的位置，字迹工整，盖了灵枢的印。角落里有"寻人"和"求助"的纸条，字迹潦草，有的被烟熏得看不清。纸条旧了没人撕，新的盖上去，风大的天从窗户灌进来吹走几张，也没人管。墙上有些地方纸条叠了七八层，揭开来能看见几年前写的字。

外围人怎么说："礼拜堂的蜡烛暖，祭司的脸也暖。但暖完了，该干的活还是得干，该吃的苦还是得吃。暖一下，继续熬。"

废墟猎场不是"猎场"——是前代城市死后的尸体。

倒塌的建筑露出钢筋和管道，像肋骨从腐烂的皮肉里戳出来。建筑残骸堆成小山，缝隙里长着灰菌和变异苔藓，灵能残渣沉积在角落里泛着灰绿色的荧光。地下空间被灵能残渣和灰菌覆盖，踩上去软绵绵的，像踩在腐肉上。异灵在深处筑巢——虫豸在浅层，牙在中层，更深处有什么没人知道，因为去过的人没回来。

拾荒者白天在外围刮管壁碎渣。刮刀贴着管壁刮，碎渣落进布袋里，一天刮下来的碎渣能换几个铜板。不敢深入——深处有虫豸群，更深处有牙。偶尔有胆大的拾荒者往深处走，运气好能刮到品质好的碎渣，运气不好就回不来了。拾荒者之间有个不成文的规矩：太阳过午就往回走，天黑之前必须出废墟。废墟的夜不属于人。

猎团偶尔组织废墟清剿，但废墟太大清不完。清了一片区域，过几天异灵又回来了。废墟是异灵的天然巢穴——倒塌的建筑提供遮蔽，灵能残渣提供食物，地下空间提供通道。人类清剿的速度赶不上异灵繁殖的速度。

废墟里最危险的不是异灵——是崩坏纹路。

第三纪元刻的灵能纹路在漫长岁月中逐渐失效，有些纹路突然释放残余灵能，像地雷一样炸。拾荒者管这叫"老古董的屁"——不知道什么时候放，放了就要命。崩坏纹路炸起来威力不等：小的像碎渣弹，炸一片碎石；大的像灵能冲击波，方圆几步内的人直接被灵能震晕。更麻烦的是有些崩坏纹路不炸——它释放灵能冲击，冲击波不伤身体但扰乱灵能回路，觉醒者碰上了灵能乱窜，普通人碰上了头晕呕吐。

废墟地面上有些地方颜色不对——比周围深或者比周围浅，边缘有细密的裂纹。老拾荒者说这是"老古董的屁股"，离远点。但新手分不清，踩上去就炸了。方岩在废墟里走过十几年，他靠的是地形感知——灵能纹路哪怕失效了，残留在石头里的灵能痕迹还是跟周围不一样。他能感觉到"这块石头底下有东西"。但他的感知范围只有十几米，废墟里十几米不够用。

沈野在废墟深处找到五层嵌套碎片那次，就是踩在崩坏纹路的边缘——运气好没炸，运气不好就是碎渣弹的放大版。碎片嵌在一面倒塌的墙壁里，灵能纹路五层嵌套，每一层都不同，像密码一样叠在一起。沈野的手指碰到碎片的时候，灵能拓印自动启动，纹路像水一样流进他的感知里。他蹲在那里看了很久，直到灵能残渣的酸味呛得他咳嗽才回过神来。

废墟猎场是外围人的饭碗也是坟墓。每天有人从这里活着出去，也每天有人留在这里。活着的带走碎渣和灵晶，留下的变成废墟的一部分——骨头和碎渣一起沉积，过几年就分不清哪个是人的哪个是异灵的。

拾荒者怎么说："废墟里有三样东西：碎渣、异灵、老古董的屁。碎渣养人，异灵吃人，屁——看命。"
