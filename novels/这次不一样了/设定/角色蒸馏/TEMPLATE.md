# 角色蒸馏模板

> **用途**: 每章写作后记录角色状态快照
> **命名规则**: `{角色名}-V{卷}CH{章}.md`
> **更新时机**: Step 3 状态同步时

## 使用示例

### 沈野 · V1 CH3 状态快照

```markdown
# 沈野 · V1 CH3 状态快照

## 基础状态
- **位置**: 边境镇外环→中环路上
- **物理状态**: 正常，指尖深红（修灯后更红）
- **物品清单**: 碎罗盘/刮刀/残片/灵能稳定剂/2铜币
- **受伤情况**: 无

## 能力状态
- **当前阶段**: 萌芽（初觉级拓印）
- **能力表现**: 修灵能灯（找堵塞节点+碾残渣），精度极高
- **代价累积**: 无
- **限制条件**: 读不了碑文，复制不了有代价能力

## 心理/态度状态
- **核心情绪**: 焦虑（沈念的病在走）+ 好奇（方岩给路线图）
- **对关键角色的态度**:
  - → 沈念: 10（唯一）
  - → 方岩: 2→3（从利用到可合作）
- **当前谎言/面具**: "我只是拾荒的"
- **内在真相**: 知道自己是能力者潜质，选择不测试

## 本章关键变化
- [x] 态度变化: 对方岩从"利用"→"可合作"（给路线图）
- [ ] 能力变化: 无
- [ ] 受伤/恢复: 无
- [ ] 物品变化: 获得路线图
- [x] 新信息/认知: 知道研究院方向，知道方岩是壁盾老兵

## 下章预示
- **可能的行为倾向**: 按路线图前进，保护沈念
- **待爆发的矛盾**: 沈念卖灵晶的事还没暴露
- **与谁的关系可能变化**: 方岩（如果合作顺利）

---
快照时间: 2026-05-14 10:00
```

---

## 批量创建命令

```bash
# 为主角团创建V1-V3的蒸馏文件模板
for char in 沈野 沈念 方岩 陆沉 汐 蔓; do
  for vol in V1 V2 V3; do
    mkdir -p "设定/角色蒸馏/${char}"
    touch "设定/角色蒸馏/${char}/${char}-${vol}-TEMPLATE.md"
  done
done
```

---

> 每章写作后必须更新对应角色的蒸馏文件。
> 这是 Step 3 状态同步的强制步骤。
