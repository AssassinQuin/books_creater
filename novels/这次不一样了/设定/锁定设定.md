## 二、城市/聚落外部形态（锁定）

### 外围·废墟聚落（沈野起点）

- **外观**：几十截废弃灵能管道拼成的聚落，从外面看像一堆灰色铁管堆在碎石地上
- **材料**：锈蚀灵能管道、旧铁皮、碎石
- **布局**：管道平行排列，缝隙用碎石和铁皮堵着，顶上搭旧布挡雨
- **入口**：管道口用碎石堵半边，留侧身通过的缝
- **围栏**：无城墙，外围散布灵能陷阱
- **高度**：管道直径约1.5-2米，人能在里面弯腰走
- **颜色**：铁锈灰，灵能残渣灰绿色点缀
- **特色**：灵能公告栏（黄色预警灯）、老陈面摊（铁锅+金属板台面）

### 外围·矿工聚落

- **外观**：依矿坑而建的棚屋群，比管道聚落大
- **材料**：矿坑废弃铁架+帆布+木板
- **布局**：围绕矿坑入口呈半圆形分布
- **入口**：矿坑口是天然入口，有简易木门
- **特色**：矿工临时棚（铁皮搭的）、灵能水井

### 中域·边境镇

- **外观**：砖石城墙（矮，约3米），城外散布农田和灵能农场
- **材料**：砖石+灵能加固层
- **布局**：十字主街，内区（研究院分部/灵站/商铺）和外区（住宅/农田）
- **入口**：东西两个城门，铁门包灵能层
- **特色**：灵站比外围大十倍，灵能路灯亮到午夜

### 中域·自由城

- **外观**：高砖石城墙（约5米），灵能加固层在阳光下微微发光
- **材料**：砖石+灵能结构+金属装饰
- **布局**：内区（城墙内）→中区（城墙外围）→外区（城墙外贫民窟）
- **入口**：四门，灵能安检
- **特色**：研究院总部、灵能剧院、灵能中继塔

### 内城·枢都

- **外观**：灵能白金色高墙，从远处看像发光的堡垒
- **材料**：灵能建材（灵晶+金属合金），表面有灵能纹路
- **布局**：同心圆结构，灵枢总部在核心
- **入口**：身份牌+灵能验证
- **特色**：灵能设施全覆盖——路灯、暖气、通讯、净化空气

### 外围→中域·过渡地聚落

- **铁谷镇**：山隘中转站。依山壁而建，半天然洞穴+铁皮棚。矿工/猎人/走私者混居
- **盐碱驿站**：荒漠补给点。几座石头砌的低矮建筑围成院落，中间有灵能水井
- **灯塔港**：南海岸渔港。木质栈桥+石头仓库，灯塔用灵能碎片驱动

## 四、异灵/灵兽详细形态（锁定）

### 虫豸·游荡体（无智慧）

#### 灰蜥（西部荒原·突击型）
- **体型**：大狗大小，四足，贴地
- **外观**：灰绿色鳞片，灵能结晶在头部（暗绿色光）
- **移动**：四条腿弹簧式弹跳，荒原上比废墟里快
- **行为**：群居，靠灵能灵息追踪猎物
- **弱点**：灵能结晶碎了就死；本能优先散后判断，可被灵能脉冲吓散
- **产出**：灵能结晶（碎了不值钱，活的值钱）

#### 沙穴蚁（西部荒原·拟态型）
- **体型**：拳头到巴掌大小
- **外观**：灰褐色，与碎石同色
- **行为**：地下挖巢群居，地面塌陷伏击
- **弱点**：单独不危险，成群致命；火攻有效

### 牙·锐化体（初步智能）

#### 灰蜥锐化体（西部荒原·突击型）
- **体型**：灰蜥的1.5倍
- **外观**：鳞片更硬，灵能结晶更大（亮绿色）
- **新能力**：初步战术——侧面包抄、诱敌
- **弱点**：腹部鳞片薄，灵能脉冲可震裂结晶

#### 矿晶蛛（北方矿区·巢穴型）
- **体型**：半人高
- **外观**：八足，甲壳有灵能矿晶纹路
- **能力**：在灵晶矿脉结网，网丝有灵能传导性
- **弱点**：怕火，网丝可被灵能切割

#### 喷射水母（东部海岸·远程型）
- **体型**：伞面直径约半米
- **外观**：半透明，体内灵能凝液发光
- **能力**：喷射灵能凝液，射程50米
- **弱点**：近身无还手能力

#### 迷雾鳗（东部海岸·拟态型）
- **体型**：两米长蛇形
- **外观**：暗蓝色，可释放灵能迷雾
- **能力**：灵能迷雾遮蔽感知
- **弱点**：灵能感知型可穿透迷雾

### 角·特化体（中等智能）

#### 伪装蜥（西部荒原·拟态型）
- **体型**：成人大小
- **外观**：能模仿岩石和沙丘外形
- **能力**：拟态静止时几乎不可发现，猎物走近才突袭
- **弱点**：灵能感知可识别（灵息不对），移动时拟态失效

#### 岩壳龟兽（北方矿区·重装型）
- **体型**：两米长，一米高
- **外观**：甲壳硬度堪比灵能护盾，灰褐色
- **能力**：在岩壁中穿行，偷袭矿工
- **弱点**：腹部关节薄弱、移动慢

#### 孢子母树（南方密林·巢穴型）
- **体型**：树形，高3-5米
- **外观**：植物异兽，花朵释放灵能孢子
- **能力**：孢子寄生控制人类行为
- **弱点**：高温/灵能净化杀灭孢子

### 鳞·统帅体（高智慧）

#### 灵焰龙蜥（焱的族群精英）
- **体型**：三层楼高
- **外观**：深红鳞片，灵焰在鳞缝中流动
- **能力**：灵焰操控，有战术智慧，可指挥低级异灵
- **弱点**：灵焰核心在胸口，被击中则灵焰失控

#### 锐化体·甲壳型（兽潮中沈野遇到）
- **体型**：比虫豸灰蜥大一圈
- **外观**：灰白甲壳，灵能纹路发光
- **能力**：甲壳可弹开灵能短刀
- **弱点**：甲壳关节处有缝隙

## 五、能力体系核心规则（锁定）

> 注：详细能力体系描述见 `世界观/能力体系.md`，此处仅锁定不可变更的核心规则。

### 七阶体系（锁定）

| 阶位 | 名称 | 核心特征 | 战斗力定位 |
|------|------|---------|-----------|
| 一阶 | 初觉 | 能感觉到灵能存在但控制不了 | 无战斗力 |
| 二阶 | 通感 | 灵能开始回应，可操控做一件事 | 基础战斗力 |
| 三阶 | 凝相 | 灵能有形状和结构 | 核心战力 |
| 四阶 | 回响 | 灵能往外渗透，获得外界回应 | 质变级 |
| 五阶 | 化生 | 能力发生根本性改变 | 极少数 |
| 六阶 | 自成 | 自成一个完整的灵能体系 | 传说级 |
| 七阶 | 归源 | 触及灵能本身的"源" | 理论推测 |

### 能力类型（锁定）

| 类型 | 核心机制 | 代表角色 |
|------|---------|---------|
| 感知型 | 展开灵能触角探查周围 | 方岩（地形感知） |
| 强化型 | 灵能在肌肉里循环提升力量 | 壁盾军团战士 |
| 铸造型 | 用灵能材料拼出/铸造物品 | 沈野（共鸣前） |
| 编织型 | 编织灵能结构 | 蔓、织 |
| 分解型 | 分解灵能/物质结构 | 陆沉 |
| 共鸣型 | 复制他人能力 | 沈野（共鸣后） |

### 核心规则（锁定）

1. **灵能浓度卡脖子**：阶位再高，到了低浓度地区也要打折。外围通感级勉强够用，凝相级只能发挥六七成。
2. **觉醒不可逆**：一旦觉醒，无法"关闭"能力。
3. **自然醒 vs 坐椅子**：两种觉醒方式在能力上无差别，区别在于是否欠灵枢灵晶。
4. **能力进化非线性**：不是简单的"升级"，可能质变（如沈野凝相→共鸣）。

### 6.2 态度量表标准

| 数值 | 含义 | 写作体现 |
|------|------|---------|
| 0 | 无关系/未相遇 | 无互动 |
| 1-2 | 冷漠/利用/敌对 | 保持距离，算计 |
| 3-4 | 观察/戒备/可合作 | 试探性互动 |
| 5-6 | 信任/朋友/关心 | 主动帮助，敞开心扉 |
| 7-8 | 深厚/生死之交/家人 | 托付后背，无条件支持 |
| 9-10 | 唯一/不可分割 | 命运共同体 |

### 6.3 能力阶段定义

| 阶段 | 含义 | 更新时机 |
|------|------|---------|
| **萌芽** | 首次获得能力，不稳定 | 觉醒章节 |
| **发展** | 能力增强，有代价 | 能力提升章节 |
| **成形** | 能力稳定，自主控制 | 质变章节 |
| **突破** | 能力性质改变 | 跨类型/复制活人 |
| **融合** | 创新/熔铸/传承 | 终局章节 |
| **稳定** | 能力成熟，无大变化 | 长期保持 |
| **衰退** | 能力下降/代价累积 | 代价爆发章节 |
| **终局** | 能力最后一次使用 | 死亡/牺牲章节 |
| **无能力** | 无觉醒 | 始终 |

### 6.4 同步规则

1. **DB优先**: 所有状态变化先写入 novel-db，再更新角色深化.md
2. **每章必更**: 每章写作后更新出场角色的 status 字段
3. **蒸馏文件**: 每章写作后创建/更新角色蒸馏文件
4. **冲突检测**: 角色深化.md与DB不一致时，以DB为准
