# 第一幕：裂缝初现（Ch1-Ch5, D1-D5）

## Ch1 废墟猎场（D1）

- **时间**: D1 清晨→下午→黄昏
- **场景**: 外环废墟深管 → 碎石堆 → 聚落入口（教会小堂）→ 沈野家管道
- **核心事件**:
  1. 沈野在深管拾荒，手感指引他挖出一块异常残片（F1:五层嵌套，灵能模式不可识别）
  2. 残片灵能波动引来灰蜥群，追逐战在废墟管道展开——碎渣弹、照明石、灰蜥追踪方式（世界观速览）
  3. 手感两次救他——摸管壁知方向→凭触觉黑暗中找出口（拓印萌芽信号）
  4. 回聚落经过教会小堂，牧师做灵能净化，给沈念多做了3秒——欲言又止
  5. 回家把捡到的按价值分三堆：自己的最少（"只管自己和沈念"哲学展示）
- **出场角色**: 沈野(主视角)、沈念、方岩(远处剪影)、牧师、老陈(面摊)
- **新增微事件**:
  - 聚落入口老头卖旧铁皮，每天喊"好铁皮"，没人买（费笔·纯）
  - 沈野在管道遇到另一个拾荒者，两人点头让路——聚落规矩：不打招呼也不瞪眼，谁先移开眼睛谁示弱（日常·秩序）
  - 远处管道上方岩在修灵能路灯，看不清脸，只看到工具在灵能灯光下反光的轮廓（世界呼吸·陌生人）
  - 沈野在管道拐角看到一个老妇人蹲在地上用刮刀抠墙缝里的碎渣，动作很慢，每抠一下喘一口气（费笔·边缘人）
  - 一只灰蜥的尸体横在管道交汇处——死了有两天了，几只小虫在壳缝里爬进爬出。沈野绕过去，没碰（世界呼吸·废墟常态）
  - 回聚落路上经过一段露天管道，阳光从管道的裂缝里照下来，灰尘在光束里慢慢飘（日常·废墟美学）
- **世界观展示**: 碎渣经济、灵能碎渣弹、拾荒者日常、灵站加量（公告栏）、教会基层净化
- **伏笔**: F1残片异常 + F2沈念手指发麻 + 牧师欲言又止 + 方岩修灯剪影
- **角色状态**: 沈野——拾荒者的精确生存哲学展示，对F1好奇但不懂；沈念——手指间歇发麻，说"站久了"
- **字数**: 4000-4500字

## Ch2 灵站排队（D2·沈念视角）

- **时间**: D2 早晨→午间
- **场景**: 灵站门口排队 → 灵站柜台 → 教会祈祷点 → 回聚落的路
- **核心事件**:
  1. 沈念去灵站卖灵晶——频率不正常（一周三次，已持续大半年），但她觉得"正常"
  2. 排队听到后面两个女人对话："老周家的走了一个月了""他老婆也快了，手都灰了"——她假装没听见
  3. 韩朗在屏幕上多敲了几下——标记"高产出源·稳定·维护优先"
  4. 公告栏"丰收期·灵能浓度连续上升15天"（她看懂了"连续上升"但不知道意味着什么）
  5. 去教会祈祷点安静坐了一会儿——不是信教，是那里没人说话
- **出场角色**: 沈念(主视角)、韩朗、老矿工、猎人(交灵晶闲聊)、牧师(祈祷点)
- **新增微事件**:
  - 韩朗接了一通内线电话，语气从职业微笑变成简短"嗯…嗯…知道了"，挂完电话在原地站了三秒才继续做事（世界呼吸·系统里有人）
  - 灵站门口猎人在交灵晶闲聊："西三区灰蜥群异常""黄条赏金涨了"——中间还夹了一句"老赵昨天被咬了一口，大腿上，不严重"（费笔·猎人的日常风险）
  - 灵站墙上贴着一张手写寻狗启事——"黄狗，左耳缺一块，叫大黄。找到送到老陈面摊。"纸边已经卷了，贴了一段时间了（费笔·谁家丢了狗）
  - 排队时前面一个老矿工咳嗽得很厉害，弯着腰，他老婆在旁边拍他的背——"说了别去了你非去"。老矿工没回话，咳完了直起腰继续排队（日常·灵衰症的生活碎片）
  - 灵站门口地上有半块被踩碎的灵晶——没人捡。沈念看了一眼，心想可惜了但没弯腰（日常·在聚落里灵晶碎了也是常事）
  - 排队快轮到沈念时，她右边一个中年女人被工作人员叫到旁边说了几句话——女人脸上表情从期待变成空白，站了一会儿转身走了。没人知道她听到了什么（世界呼吸·灵站的另一面不止韩朗）
- **关键描写**: 灵站灰白建筑/共振卡读取器滴滴声/韩朗的职业微笑与屏幕操作/灵站门口地面划痕
- **世界观展示**: 灵站运作（灵晶交易/吸收椅/共振卡）、灵能丰收期、教会祈祷点、货币体系（1灵晶≈50铜板）
- **伏笔**: 韩朗标记沈念 + "丰收期"概念 + 灵站地面划痕（大件拖拽）
- **角色状态**: 沈念——表面正常，底下有秘密；韩朗——系统内的螺丝，标记了"好用的设备"
- **字数**: 3500-4000字

## Ch3 聚落·方岩（D3）

- **时间**: D3 上午→黄昏→深夜
- **场景**: 聚落市集 → 灵能路灯旁 → 猎人酒馆门口 → 方岩修灯处

  3. 方岩："你手上的感觉不是手感。去测。"沈野："不感兴趣。"（征召恐惧—隐性）
  4. 猎人酒馆门口情报交换——"西面有牙级的""灰蜥活动范围往东扩"

- **出场角色**: 沈野(主视角)、方岩(正式登场)、沈念(市集同行)、猎人(酒馆)、陷阱匠、老猎人
- **新增微事件**:
  - 两个小孩追一只铁皮甲虫跑过市集，一个摔倒了爬起来继续追，膝盖磕破了一块，他没哭，拍了两下尘土继续追（费笔·童年）
  - 陷阱匠摊位上对年轻猎人说"网编错了，牙级一挣就开，回去重编"——年轻猎人嘟囔了一句走了，走了几步又回头看了一眼陷阱匠的手势（日常·手艺人的传承）
  - 老猎人看到沈野袋子里露出的F1残片角落，视线停了一拍，然后移开——什么都没说（世界呼吸·有些人知道什么事不该问）
  - 市集角落有个女人在卖自己缝的布包——针脚很密，但布料是旧管道布改的，灰扑扑的没什么人看（费笔·手艺人）

- **世界观展示**: 猎人经济链（陷阱匠/取晶师/装备匠）、壁盾痕迹（绳结/疤痕）、灵能路灯结构、聚落市集生态
- **伏笔**: 方岩出身暗示 + 灰蜥往东扩（因果双铺垫） + 罗盘指向东北(禁地方向) + 方岩注意到沈野
- **角色状态**: 沈野——否认能力但有一瞬恐惧；方岩——不是闲逛者，每天都在勘探周边

## Ch4 日常·鸦（D4·沈念视角）

- **时间**: D4 上午→午后→黄昏
- **场景**: 沈野家 → 废墟浅层 → 教会小堂 → 聚落
- **核心事件**:

  2. 在碎石堆下发现受伤的鸦——银蓝色眼睛，微弱的灵能波动，不是攻击性的
  3. 沈念处理伤口、喂干粮。"别怕。疼一会儿就好了。"（她对异类生物的本能善意）
  4. 回来路过教会小堂，牧师叫住沈野："让你妹妹有空来坐坐。"沈野警觉了但没表现
  5. 牧师桌上摊着记录簿——"赵老三·手灰·第三周""李寡妇·咳蓝光·初现"；沈野经过时牧师合上了记录簿
- **出场角色**: 沈念(主视角)、沈野、鸦(初遇)、牧师、邻居阿婆
- **新增微事件**:
  - 邻居阿婆在门口择灰绿色菜念叨"涨价了，什么都涨价了"——不是跟沈念说话，是自言自语，沈念走过时阿婆抬头看了她一眼说"你瘦了"，沈念说"没有啊"，阿婆没接话继续择菜了（费笔·日常）

  - 老陈在面摊说了一句"最近灰蜥比以前多了，昨天老赵家儿子在浅管遇到三只"——他在擦一个已经擦得很干净的碗（日常·面摊老板的信息渠道）

  - 在浅层捡碎渣时遇到另一个拾荒者——一个驼背的中年男人，蹲在一堆碎石前慢慢翻。沈念经过时他抬头看了她一眼，认出了是沈野的妹妹，没说话，低下头继续翻（世界呼吸·聚落里谁都认识谁）
  - 回程时，远处传来三声碎渣弹爆炸的声音——闷响，距离不近。沈念没停脚步，在废墟里听到爆炸声是常事（日常·废墟的声音地图）

# 第二幕：崩塌与揭露（Ch6-Ch12, D6-D8）

## Ch6 深管与警告（D6上午）

- **时间**: D6 上午→午后
- **场景**: 废墟深管 → 聚落入口 → 公告栏前 → 方岩修灯处

## Ch18 荒原第一夜（D14·卷尾）

- **时间**: D10-D14（数天后）→ D14 夜
- **场景**: 外环荒原 → 灰蜥群追逐 → 废弃灵能站
- **核心事件**:
  1. 数天穿越——荒原开阔，沈野靠拾荒者经验判断兽群位置，用方岩路线图确认方向
  2. 灰蜥群追逐战——沈野战术精准（不是英雄是生存专家），但背包被撕裂，干粮损失
  3. 沈念体力明显下降，但不说话，分饼时说"够了，还有老陈的饼"
  4. D14夜 — 找到废弃灵能站过夜，沈念靠墙坐着，手指蓝光在黑暗中一闪一闪
  5. 沈野靠墙坐着看北方天际线——沉默
  6. 碎罗盘在口袋里微微发热——他摸出来看：黑暗中罗盘的针在微弱地发光，指向同一个方向（东北）
  7. 卷尾：沈念睡着，沈野看着她的手指和罗盘，把残片又放回口袋里
- **出场角色**: 沈野(主视角)、沈念、鸦
- **新增微事件**:
  - 鸦在荒原上飞了一圈回来——它出去探路的时间越来越长，回来时羽毛上沾了不同颜色的灰尘（灰的、红的、褐色的），它在沈念肩膀上抖了抖羽毛，灰尘在阳光里散开（费笔·鸦在用自己的方式探索）
  - 沈念在废弃灵能站角落里看到墙上有一段刻字——"走到这里的人，别回头"，字迹很旧，不是最近刻的。下面还有一行更小的字但被灰尘盖住了看不清。她没告诉沈野（世界呼吸·有人在这条路上走过）
  - 沈野把最后一块饼掰成两半——大的给沈念，小的留给自己。沈念接过来没吃，把饼又掰了一半放回沈野手里。沈野看了她一眼，她把视线移开了（日常·妹妹分饼的方式是给哥哥多的，哥哥也是）
  - 荒原的风比废墟的烈——没有管道遮挡，风直接灌过来，带着沙子和草屑。沈念被风呛了一下，咳了几声，用手挡住嘴。咳完之后她的嘴唇上有几粒细小的灰蓝色灵能粉尘——她用手指抹了一下，在裤子上蹭掉了（日常·荒原里没有地方可以好好咳嗽）
  - 废弃灵能站的地面上散落着一些旧文件——被风翻过很多次，纸已经脆了，上面的字迹模糊不清。沈野蹲下来翻了翻，看到一些数据表格和手写笔记，日期是几年前。他看不明白，放了回去（费笔·废弃的地方总有废弃的记录）
  - 傍晚时荒原上出现了另一队人的影子——很远，隔着至少一里地，看不清楚，只能看到几个黑点在移动。他们没有靠近。沈野盯着看了一会儿，确认不是异灵，继续赶路（世界呼吸·荒原里不止他们两个人）
- **关键描写**: 荒原开阔地貌/灰蜥群追逐战术/废弃灵能站内景/沈念手指蓝光在黑暗中的视觉冲击/碎罗盘微热发光/沈野看北方天际线
- **世界观展示**: 荒原生态（虫豸密度比废墟高）、灵能站废弃原因、荒原方向→边境镇
- **伏笔**: 碎罗盘微热（→V4拓印本能联动）+ 荒原虫豸密度比废墟高（→V2边境镇生存压力）+ 墙上刻字（→V10禁地入口呼应）+ 鸦探路行为进化（→V2独立行动）
- **角色状态**: 沈野——沉默中带着决心，临睡前把碎罗盘和F1残片放在一起看了看；沈念——睡着时手指还在闪蓝光，但嘴角没有痛苦；鸦——不再是受伤的小生物了
- **字数**: 4000字
