# 《这次不一样了》设定总索引

> **核心原则**：DB（`novel-db`）是唯一权威源，本目录下所有 `.md` 文件均为人可读副本。
> 通过 `sync_db_to_files()` 从 DB 模板驱动生成；手动编辑仅限标注为「手动维护」的文件。

---

## 子目录说明

| 目录 | 内容 | 文件数 | 说明 |
|------|------|--------|------|
| `人物/` | 角色完整档案（基本信息→外观→背景→弧线→外观描写库→决策引擎→当前状态→关系） | 28 | 每角色一个文件，含关系数据 |
| `世界观/核心设定/` | 世界运行规则：七阶体系、双王体系、灵衰症、循环设定、纹路法则等 | 24 | 世界观骨架，写作前必读 |
| `世界观/能力/` | 能力体系：按角色分组的能力文件 + 通用规则（灵能资源、衍路体系、裔族血继等） | ~24 | 查某角色能力看对应文件 |
| `世界观/地点/` | 地理设定：三环结构、枢都、禁地、各城市聚落 | 17 | 含路线图和区域关系 |
| `世界观/异灵/` | 异灵图鉴：低阶→高阶→功能型→驯化兽 | 4 | 按等级分组 |
| `世界观/物品/` | 物品装备：武器、日用品、交通工具、专业工具 | 4 | 按用途分组 |
| `世界观/势力/` | 势力组织：统治方、反抗方、异族 | 3 | 按阵营分组 |
| `大纲/` | 全书规划：概览、卷级大纲、伏笔清单、支线弧线 | ~22 | 卷级大纲DB优先，其余手动 |
| `锁定/` | 不可变更的设定规则，初始化后极少修改 | 7 | 违反锁定设定需走 C3 级联更新 |
| `参考/` | 辅助参考：快速参考卡、设计方案、追踪规范 | 4 | 不直接参与写作流程 |
| `写作/` | 写作执行规范和作者声音定制 | 2 | 每章写作必读 |
| `灵感库/` | 调研素材、头脑风暴、方法论参考 | ~25 | 不入DB，纯参考 |

## 数据权威源

| 数据类型 | 权威源 | 文件角色 | 写入规则 | 读取规则 |
|---------|--------|---------|---------|---------|
| 角色档案/关系 | **DB** (`characters` + `character_relations`) | 人可读副本 | 只写DB，完事后 `sync_db_to_files()` | MCP `character_detail()` 优先；空时回退读文件 |
| 世界观全部 | **DB** (`world_settings`) | 人可读副本 | 只写DB，完事后 `sync_db_to_files()` | MCP `world_query()` 优先；空时回退读文件 |
| 伏笔 | **DB** (`foreshadows`) | 人可读副本 | 只写DB，完事后 `sync_db_to_files()` | MCP `foreshadow_list()` 优先 |
| 卷级大纲 | **DB** + 文件 | 人可读+git追踪 | DB为主，已有文件不覆盖 | MCP `volume_get()` 获取摘要；空时回退读文件 |
| 锁定设定 | 文件 | 唯一源 | 只写文件 | 只读文件 |
| 参考素材 | 文件 | 唯一源 | 只写文件 | 只读文件 |
| 写作规范 | 文件 | 唯一源 | 只写文件 | 只读文件 |
| 灵感库 | 文件 | 唯一源 | 只写文件 | 只读文件 |

## 快速查询指南

| 我想查…… | → 看这里 |
|-----------|---------|
| 某角色的完整档案 | `人物/{角色名}.md` |
| 某角色的能力/武器/装备 | `世界观/能力/能力_{角色名}.md` |
| 两人的关系 | `人物/{任一方}.md` 中的关系段落 |
| 世界核心规则（七阶/双王/循环/灵衰） | `世界观/核心设定/` 下对应文件 |
| 某地点的详细设定 | `世界观/地点/{地点名}.md` |
| 异灵种类和等级 | `世界观/异灵/` 按等级分组查看 |
| 物品/装备属性 | `世界观/物品/` 按用途分组查看 |
| 势力组织和阵营 | `世界观/势力/` 按阵营分组查看 |
| 经济/物价/货币 | `锁定/货币与物价.md`（不可变更） |
| 全书结构和卷级规划 | `大纲/全书概览.md` + `大纲/V{N}-*.md` |
| 伏笔状态和回收计划 | `大纲/伏笔清单.md` |
| 不可变更的设定底线 | `锁定/锁定设定总索引.md` → 各子文件 |
| 写作时必须遵守的规范 | `写作/写作执行规范.md` |
| 作者声音和文风要求 | `写作/作者声音.md` |
| 角色快速速查（写作时） | `参考/角色快速参考卡.md` |
| 术语用词规范 | `世界观/术语规范.md` |
| 某调研主题的灵感素材 | `灵感库/` 下搜索关键词 |
