# 能力等级与异兽分类体系 — 跨作品调研

> 调研日期：2026-05-14
> 目的：为《这次不一样了》的能力阶位、异兽分级、物品分类提供参考
> 覆盖范围：成熟网文（灵气复苏/异能/修仙）、日本动漫、影视特摄、中国古典志怪

---

## 一、网文中的觉醒者/异能等级体系

### 1.1 字母分级制（最主流）

来源不明，但已被起点、刺猬猫等平台大量异能小说采用。基本框架：

| 等级 | 含义 | 对应阶段 |
|------|------|---------|
| F级 | 刚觉醒，能力有限 | 几乎等同于普通人 |
| E级 | 入门，有一定发展 | 能力初现但控制差 |
| D级 | 正式，可独立行动 | 能稳定使用一种能力 |
| C级 | 熟练，较为成熟 | 能力灵活运用 |
| B级 | 高级，相当强大 | 小队核心战力 |
| A级 | 精英，非常强大 | 军级/组织级骨干 |
| S级 | 超级，战略级存在 | 一人抵一支军队 |
| SS级 | 超越S级 | 传说级 |
| SSS级 | 人类极限 | 历史上有记录的不超过十人 |
| X级 | 不可分类 | 不确定是否存在 |

**优点**：简洁直观，读者秒懂。
**缺点**：太游戏化，像在读游戏攻略而不是小说。完全没有生活气息。

**代表作品**：大量起点都市异能文。是当前网文最烂大街的分级方式。

### 1.2 境界制（修仙传统）

修仙/玄幻小说的经典框架，几经演变形成了几套"公认"体系：

**经典修真体系**（凡界部分）：
炼气 → 筑基 → 结丹 → 元婴 → 化神 → 合道 → 大乘 → 渡劫

每个大境界通常分初期/中期/后期/巅峰（或大圆满）。

**灵气复苏流简化版**（都市背景）：
后天 → 先天 → 宗师 → 大宗师 → 超凡 → 破虚

**武道体系**（低武→高武）：
淬体 → 锻骨 → 通脉 → 凝真 → 抱丹 → 神海 → 法相 → 涅槃

**评价**：
- 优点：每个境界名字自带画面感，读者能想象到对应的力量层次
- 缺点：境界之间的战斗力差距经常写崩——一个元婴到底能打几个金丹？作者自己也说不清
- 灵气复苏流的问题：把修仙境界的名字搬到都市背景里，违和感很强。一个穿校服的高中生说自己是"炼气三层"，总感觉哪里不对

### 1.3 序列制（《诡秘之主》）

乌贼的《诡秘之主》开创了"途径+序列"体系：

- 22条神之途径，每条途径从序列9到序列0
- 序列越低越强，序列0是神
- 同序列不同途径之间有克制关系
- 喝下魔药晋升，有失控风险（扮演法）

**评价**：
- 优点：体系极其精密，逻辑自洽，每条途径有完整的历史和文化背景。序列名称本身就带着世界观信息（如"占卜家""学徒"）
- 缺点：复杂到需要读者做笔记。不适合力量体系不是核心卖点的作品
- 可借鉴点：**能力名称本身就是世界观的一部分**，不是独立于世界之外的分类标签

### 1.4 阶层描述制（较少见但有亮点）

部分作品不使用固定等级名，而是用阶层描述：

《大王饶命》的灵气觉醒：不强调等级划分，而是通过"觉醒者""觉醒精英""觉醒宗师"等称呼暗示层次。

《全球高武》：武道段位制——初级武者→中级武者→高级武者→武师→宗师→大宗师→武神，模仿现实中的段位制。

**评价**：
- 优点：有现实参照物（段位制），读者代入感强
- 缺点：还是偏"游戏化"，只是换了个皮的等级制

## 二、动漫中的异能/能力体系

### 2.1 《我的英雄学院》——个性系统

**核心设定**：世界上80%的人类拥有名为"个性"的超能力。

**分级方式**：没有严格的等级制，而是用"个性"的类型和强度来区分：
- 个性的强弱由先天决定
- 职业英雄按社会认可度和战绩排名（英雄公告牌排名）
- 英雄有不同定位：近战型、辅助型、情报型、治疗型

**可借鉴点**：
- **不按能力本身分级，按社会功能分类**——这个思路比"一二三四五"有趣得多
- 英雄排名是公开的，存在争议和操纵——这给剧情提供了天然冲突

### 2.2 《一拳超人》——英雄分级+灾害分级

**英雄协会分级**：
- S级（至高）：面对灾害级别的怪人
- A级：精英
- B级：正式
- C级：入门

**怪人/灾害分级**（wolf→tiger→demon→dragon→god）：
- 狼：威胁一般市民
- 虎：威胁一群市民
- 鬼：威胁整个城市
- 龙：威胁多个城市
- 神：威胁人类存亡

**可借鉴点**：
- **英雄和怪人的分级是独立的**——英雄是S级不代表能单挑龙级怪人
- 灾害分级用的是"威胁范围"而不是"战斗力数值"——这是更聪明的分类方式
- 分级名称用动物（狼/虎/龙）而非数字——有文化感

### 2.3 《进击的巨人》——无等级制

巨人没有等级分类。不同类型的巨人（无垢巨人/智慧巨人/奇行种/超大型巨人/铠之巨人等）是按**特征**命名而非按强弱排序。

**可借鉴点**：
- **按特征命名而非按等级排序**——读者的记忆点不是"这是T3"，而是"这是铠之巨人"
- 巨人的恐怖不来自等级数字，来自叙事

### 2.4 《咒术回战》——咒力等级

- 四级→三级→二级→一级→特级→准特级（咒术师）
- 四级→三级→二级→一级→特级→准特级（咒灵/咒物，独立体系）

按咒力的量和对身体的适应度分级。考核方式是实战测试。

**评价**：
- 比字母分级稍好，因为有对应的考核制度做支撑
- 但本质上还是数字等级制

## 三、影视/特摄中的怪物分级

### 3.1 哥斯拉系列——怪兽分级

东宝的哥斯拉宇宙有明确的怪兽分级：

- **不明生物（MUTO）**：未分类的新物种
- **普通怪兽**：普通威胁等级
- **王者级（King）**：哥斯拉、王者基多拉等
- **终极级（Titanus）**：远古泰坦级存在

分级标准不是战斗力数值，而是：
- 体型大小
- 辐射/能量等级
- 对人类文明的威胁程度
- 生态位（掠食者/领地守护者/毁灭者）

**可借鉴点**：
- **按生态位分类**而非战斗力排名——这个思路和"猎人怎么看待异兽"天然契合
- 等级名称有世界观感（"泰坦"而不是"T4"）

### 3.2 生化危机系列——B.O.W.分级

安布雷拉公司的生物武器分级：
- **低级B.O.W.**：丧尸、犬型B.O.W.
- **高级B.O.W.**：猎杀者（Hunter）、舔食者（Licker）
- **超级B.O.W.**：暴君（Tyrant）
- **终极B.O.W.**：威斯克等变异体

分级方式是安布雷拉公司内部的产品编号——从商业/军事角度分类，不是从生态角度。

**可借鉴点**：
- **不同势力有不同的分类方式**——猎人的叫法和研究院的叫法不一样，这比全世界统一一套分级更真实

## 四、中国古典志怪传统中的分类

### 4.1 山海经——按形态描述命名

《山海经》不分类，只描述。每条记录的格式基本是：

> "又东三百里，曰XX之山，有兽焉，其状如X，X目X足，其名曰X，其音如X，食之不X。"

**核心特征**：
- 没有等级划分
- 用"其状如X"来做形态参照——你不知道它长什么样，但它像你认识的东西
- 名字本身就是描述（"九尾狐""饕餮""毕方"都是名字即特征）
- 功能性标注——"食之不蛊""见则天下大旱"，记录的是它和人的关系

**可借鉴点**：
- **名字即特征**——比"T2灰蜥锐化体"有记忆点得多
- **功能性记录**——猎人最关心的不是"它几级"，而是"遇到它怎么办"
- **形态参照**——用已知事物描述未知事物，读者能脑补画面

### 4.2 上古十大神兽（民间整理）

排名方式不统一，但常见的"十大"包括：
白泽、夔、凤凰、麒麟、梼杌、獬豸、犼、重明鸟、毕方、饕餮

**分类逻辑**（民间约定俗成）：
- **祥瑞**：凤凰、麒麟、白泽、重明鸟——给人间带来好运的存在
- **凶兽**：饕餮、梼杌、混沌、穷奇（四凶）——代表自然灾害或人性之恶
- **神兽**：夔、犼——力量接近天地的存在

注意：这不是《山海经》本身的分类，是后人整理的。但"祥瑞/凶兽/神兽"这个三分法已经深入人心。

### 4.3 《聊斋志异》《搜神记》《子不语》——按精怪来源分类

志怪小说的分类方式：
- **妖**：动物修炼成精（狐妖、蛇妖、兔妖）
- **鬼**：人死后所化
- **怪**：无法归类的异常存在
- **仙**：修道有成者
- **魔**：走邪路的修行者

**可借鉴点**：
- **按"从什么变来的"分类**，而不是按"能打几个"分类——这是猎人在田野中真正会用的分类方式
- 狐妖和蛇妖的修行方式、弱点、行为模式完全不同——猎人对付它们的方法也不同

### 4.4 中国妖怪学（当代整理）

当代学者张云在《中国妖怪故事（全集）》中的分类：
- **统**（统领类）：龙、凤、麒麟
- **妖**（动物修炼类）：狐、蛇、兔、猫
- **精**（器物成精类）：扫帚精、笔精、灯精
- **鬼**（亡灵类）：吊死鬼、水鬼、无头鬼
- **怪**（异常现象类）：不明生物、地域性怪物

**可借鉴点**：
- "精"和"妖"的区别——一个是从器物变来的，一个是从动物变来的。这种"按来源分"的思路比"按战斗力分"更有故事性

## 五、网文中的物品/装备分级

### 5.1 颜色分级（游戏化，最烂大街）

白→绿→蓝→紫→橙（金）→红

起源于《暗黑破坏神》和WoW，被大量网文和手游 adoption。

**问题**：完全没有文化感，一看到"紫色装备"就出戏。

### 5.2 品阶分级（修仙传统）

修仙武器的经典分级：

**凡器→灵器→宝器→仙器→神器→先天至宝**

每级又分下品/中品/上品/极品。

**变体**：
- 黄阶→玄阶→地阶→天阶（用"天地玄黄"传统排序）
- 凡铁→寒铁→灵铁→玄铁→仙铁（按材质分级）

**评价**：
- 比颜色分级好——至少有文化根基（"天地玄黄"出自《千字文》）
- 但还是偏"系统化"——猎人在路边摊捡到一把刀，他不会想"这是玄阶还是地阶"，他会想"这刀够不够硬"

### 5.3 口语化分级（较少见）

极少有网文用真正的口语来分级物品。大部分所谓的"口语化"只是给系统等级起了个外号。

**可借鉴方向**：猎人怎么评价一把刀？
- "这刀够硬"（质量好）
- "使惯了"（合手）
- "凑合用"（一般但能用）
- "有来头"（来历不凡）
- "邪门"（效果不可预测）

## 六、对本项目的具体启示

### 6.1 觉醒者等级：我们的选择

当前方案（入灵级替代共鸣级后的七阶制）：
初觉→通感→凝相→入灵→蜕变→域场→灵源

**优势**：每个名字都描述了能力的状态而非数值。猎人口中的"菜鸟/老手/硬茬子/怪物"又比研究院七阶更接地气。

**可优化方向**：
- 研究院七阶和猎人黑话之间的"翻译"可以更有趣——不同地区猎人的叫法不一样（北方矿工叫法 vs 东部渔民叫法）
- 不需要改等级本身，但可以在不同角色的嘴里听到不同的叫法

### 6.2 异兽分级：我们的选择

当前方案（猎人黑话）：
虫豸→牙→角→鳞→天灾（对应研究院T1-T5）

**对比其他作品**：
- 一拳超人的"狼虎鬼龙神"和我们的方案最接近——都是用具体意象而非数字
- 山海经的"其状如X"描述方式我们已经加了

**可优化方向**：
- 不同区域的猎人对同一种异兽可能有不同的俗称（北部矿工叫"铁甲虫"的，东部渔民可能叫"石壳子"）
- 异兽的名字可以更山海经化——不是"T2矿晶蛛"，而是直接给它一个名字，猎人之间口口相传

### 6.3 物品分级：我们的选择

当前方案（猎人黑话）：
硬货→合手的→行货→将就

**对比其他作品**：
- 没有任何一部主流作品用这种"经验口语"来分级——这是我们独一份的
- 这恰好是我们的优势

### 6.4 最大的差异化

纵观所有调研，发现一个关键规律：

**好作品的能力体系，名字本身就是世界观。**

- 《诡秘之主》的"占卜家""小丑"——你看到名字就知道这个途径的文化背景
- 山海经的"饕餮""毕方"——名字本身就是故事
- 哥斯拉的"泰坦"——名字带有远古神话感

**烂作品的能力体系，名字是独立于世界的标签。**

- "S级觉醒者"——放到任何一部小说里都能用，没有辨识度
- "紫色装备"——你分不清这是修仙世界还是游戏世界

我们的"虫豸/牙/角/鳞/天灾""硬货/合手的/行货/将就"走的是正确的方向——这些词只有在这个世界里、这群人嘴里才会出现。

## 八、我们不需要的东西

基于调研，以下做法已经被用烂了，我们应当避免：

1. **字母分级**（S/A/B/C）——最烂大街，毫无辨识度
2. **颜色分级**（白绿蓝紫橙）——游戏感太强
3. **纯数字分级**（1-9阶）——太直白，没有故事性
4. **"天地玄黄"四阶**——用了几百年了，读者已经审美疲劳
5. **"炼气筑基金丹元婴"搬到都市**——修仙境界的名字放在现代背景里违和感极强
6. **所有势力使用同一套分级**——不真实，不同势力应该有不同的视角
