# 江屿入队逻辑 + 汐关系网

---

## 一、江屿入队——完整因果链

### 1.1 江屿是谁

灵枢安保部前成员，中层偏低。不是高层，不是核心人物——他在灵枢的定位是"知道一些事但不够格被保护"的级别。

他叛逃的原因不是良心发现——是**怕死**。他执行了一次内部"清理"任务——去处理一个泄露灵站参数的底层灵能工。到了现场发现那个人认识他，小时候住同一个街区。他执行了命令。回去之后他把制服脱了，直接从灵枢后门走了。这不是道德觉醒。是"我下不了第二次手"——他怕自己变成能下第二次手的人。

走的时候他带走了一份数据——不是计划好的，是顺手。灵枢外勤部的行动部署表，他负责的那个片区。他拿它当"保命符"——万一被抓，可以用这个换命。

### 1.2 为什么在边境镇

他从内环一路往外逃。他不敢走大路（灵枢在找他），只能走边境方向的猎人路线——猎人网络不问身份。到了边境镇他走不动了：再往外就是无人区，没有补给、没有路线、没有活路。他在边境镇逗留找补给的时候被灵枢检查站认出了身份。

不是"被抓"——是行政扣留：边境镇的灵枢工作人员核实了他的身份（通缉名单上有个名字），把他关在检查站后面的临时扣留室等总部来人接收。没有镣铐、没有重兵——一间锁了门的屋子，门外一把锁，一把钥匙。

### 1.3 团队如何发现他

兽潮后团队到达边境镇休整。沈念在灵站门口排队时听到两个人在闲聊：
> "检查站后面关了个灵枢叛逃的。偷了什么东西，等车来接。"
> "偷什么了？"
> "谁知道。反正也不关我们的事。"

沈念记住了这个消息。她没有马上告诉沈野——她在想"这个人有没有用"。

当晚，陈启明通过猎人网络传来字条，内容之一：
> "灵枢叛逃者江屿，原安保部，手上可能有外勤部数据。人关在边境镇检查站。三日内必被接走。"

陈启明的字条加速了沈念的决定。她跟沈野说了："有一个灵枢叛逃者在镇上，手里有数据。"

沈野的第一反应："灵枢的人。不管。"沈念说："他手里有灵站的分布数据和巡逻路线。我们接下来要走的路用得上。"沈野沉默了一会儿——他不想跟灵枢的人有任何关系，但他也知道沈念说的对。他最后说了一句："去看一眼。不行就放回去。"

### 1.4 接触和交易

沈念和沈野到检查站。江屿被关在后面的小屋子里——没有虐待，就是关着。他看到有人来的时候第一反应不是求救，是警惕："你们是谁的人？"

沈念说："路过的。听说你有数据。"江屿看着他们——两个外环拾荒者打扮的人，一个女孩脸色不好，一个年轻人手上全是碎渣的痕迹。不是灵枢的人。他稍微放松了一点，但没全信。

他没有交出数据。他给了一句口头信息——他记得灵枢在南三区的一处秘密检查站频率，可以让他们避开灵枢的巡逻。

沈野核实了这条信息的准确性（通过猎人网络问了一下，确实存在）。然后他对江屿说了一句："你可以跟着。但你身上的东西——如果让我发现你藏着对我们不利的，你会比被灵枢带走更惨。"

江屿知道这是实话。他选择了跟——不是信任，是没有别的选择。

### 1.5 入队后的初始状态

| 维度 | 内容 |
|------|------|
| 江屿对团队 | 警惕。不认为他们会保护他，但知道利益一致 |
| 团队对江屿 | 沈野不信任但可用，沈念算过账（数据价值>风险），汐不管他（跟她没关系） |
| 陆沉对江屿 | 无感——管他是谁，不影响我追引导装置就行 |
| 江屿入队条件 | 提供灵枢内部数据+不拖后腿；团队提供保护+补给 |
| V2末状态 | 行政扣留解除→被沈念"买"出来了（她用两份灵能稳定剂+一袋干粮给检查站的人做了交换，没让沈野知道她用了自己的稳定剂配额） |

## 二、汐的关系网

### 2.1 汐是什么人

一个从实验室出来的"非人"。研究院把她当特殊异灵研究——不是人，不是异灵，是"月裔"（他们也不知道月裔是什么，只知道样本稀有）。她从出生就在笼子里，没有名字，只有编号。她不知道"善意"不需要代价，不知道"抚摸"不是实验流程的一部分。她像孩子一样闯进每个人的世界——不知道门关着，不知道有人不欢迎她。她的底色不是恐惧——是**好奇**。实验室没有杀死她的好奇心，这是她最珍贵的东西。

### 2.2 汐 ↔ 沈念："第一个不让她疼的人"

| 阶段 | 关系状态 | 汐的视角 | 叙事功能 |
|------|---------|---------|---------|
| V2初遇 | 沈念给她梳头→她僵住了（不知道被善待该怎么反应） | "这个人的手和实验室的人不一样——她不让我疼" | 建立"暖的频率"概念 |
| V2据点 | 沈念教她做手势→她学得很快。沈念指着水杯说"水"，她模仿发音完全不对，沈念笑着鼓掌 | "做错了也会被夸？"——这是她第一次接触"鼓励" | 从"疼完才有饭吃"到"做错了也有人笑" |
| V3逃亡 | 沈念给她扎头发、塞水壶——不是战前准备，是习惯性照顾 | "有人记得我需要什么" | 她被看见了 |
| V3惨败 | 她过载失去能力，沈念拖着她和陆沉走 | "她没有丢下我" | 信任建立：她不会因为"没用"就被扔掉 |
| V4+V5 | 沈念把她纳入团队日常——不是当"工具"，是当"需要被照顾的人" | "我在这个地方有一个位置" | 归属感萌芽 |
| V6及以后 | 沈念做决策时会看她一眼——确认她的状态。她也会看沈念——确认安全 | 不需要语言——她们之间有了一种同步 | 默契形成 |
| V14 | 沈念走进治疗室前，汐站在门口——她不是来帮忙的，是来确认沈念会出来 | "你也会好。和你说的一样。" | 闭环：第一个给她善意的人，她看着她走到了终点 |

**一句话总结**：沈念是汐的人类锚点。在实验室里汐学到的是"先疼后吃"，沈念教会她的是"可以不疼"。

### 2.3 汐 ↔ 陆沉："天真的孩子闯入冷冰的世界"

这是全书最重要的感情支线之一。不是爱情——是从排斥到接纳到保护到"她是我的人"的完整过程。

| 阶段 | 卷 | 汐做了什么 | 陆沉的反应 | 关系状态 |
|------|----|-----------|-----------|---------|
| 陌生闯入 | V2兽潮 | 汐在废墟里发现力竭的陆沉，不会说话但挡在他和异灵之间 | 他看到她的背影在他面前站着——不是她救了他，是她替他挡了几秒 | 他记住了她的存在，但不想承认 |
| 第一次靠近 | V2逃生路上 | 汐伸手牵他，以为他和她一样需要被拉着走 | 陆沉抽回手——没说话，没看她 | 被拒绝。汐不理解做错了什么 |
| 试探 | V3篝火边 | 汐蹲在陆沉旁边看他拆陷阱，离得很近，眼睛亮晶晶的，比了个大拇指 | "走开。"她说。汐没走。陆沉换了个位置——但他没有推她 | 第二次拒绝，但拒绝力度减弱了——从"滚"到"走开"到换位置 |
| 默默存在 | V4-V5 | 汐不再靠近，但会坐在不远处——不看他，不打扰他，就在那儿 | 他不赶她了。有一次他拆完陷阱抬头看到她坐在几米外，什么都没做——他没说什么 | 从"拒绝"到"不拒绝" |
| 第一次靠近 | V6某个夜晚 | 陆沉坐在营地边缘守夜。汐走过去，在他旁边坐下——没问他能不能坐，直接坐了。他看了她一眼，没说话。 | 他什么都没说。这是他第一次没有做任何拒绝的动作。 | 接纳的开始 |
| 回望 | V7队伍冲突后 | 团队分裂那晚，汐坐在远处翻译碑文。陆沉路过的时候停了一下——不是停下来帮她，是确认她在安全位置。然后走了。 | 陆沉自己可能都没意识到他在确认她的位置。但他确实确认了。 | 不自觉的保护 |
| 站在前面 | V8-V9追杀中 | 异灵追来时陆沉站到了汐前面——不是计划好的，是身体先于脑子动了 | 汐抬头看到他站在自己前面。她不会说"谢谢"，但她的频率变暖了。陆沉感觉到了但这种感觉很陌生 | 身体记忆确认：保护她已经变成本能 |
| 确认 | V10禁地边缘 | 陆沉要去禁地，走之前他看了一眼汐——不是告别，是确认位置。"……你在。"他说。 | 这是他第一次主动对她说话。两个字。 | 主动确认：他知道她在 |
| 默契 | V12渊苏醒时 | 渊苏醒时全场混乱。汐在人群中回头找陆沉——不是害怕，是想确认"他在"。 | 她在人群中找到他的位置时，他也正看着她。不是约好的。 | 双向确认 |
| 完整 | V14治疗成功 | 汐站在门口等沈念出来。陆沉从她身走过去的时候，她碰了一下他的手指——很小心的，像他V2抽回手的时候她没有死心 | 他停了一下。没有抽回。 | 从V2"伸手被抽回"到V14"碰了没抽回"——14卷走完一条弧线 |

**一句话总结**：她不知道门关着，她敲了，他不开，她就坐在门口等。等了14卷，他开门了。

### 2.4 汐 ↔ 沈野："跟着他因为'暖的频率'"

| 维度 | 内容 |
|------|------|
| 为什么跟沈野 | V2兽潮逃生时沈野是第一个伸手拉她的人。汐感知到他身上有一种她没感知过的"暖的频率"——不是温度，是灵能频率的质感。她跟着他，没有理由，就是"暖的" |
| 沈野的态度 | 不排斥不照顾——他连自己妹妹都管不过来。但也不赶她。沈野的"默认接受"对汐来说已经足够——没人把她当异灵赶走 |
| 汐的理解 | "这个人身上暖的。他不会伤害我。"——在她的世界里这是最高评价 |
| 关系性质 | 不是情感依赖——汐依赖沈念（情感）而跟随沈野（安全感）。沈野对她来说是"安全的地方" |

### 2.5 汐 ↔ 方岩："长辈但不知道怎么相处"

方岩是全书最不会和汐相处的人。他习惯了对年轻人吼"别磨叽"——但对汐没办法吼，因为她听不懂。他只好放慢语速、用简单词汇。汐觉得奇怪但不讨厌他。方岩给过她一块干粮——她接了，没吃，放进了口袋。方岩看到了也没问。她后来把那块干粮给了路边一只受伤的鸦——那是她学会"分享"的方式。

### 2.6 汐 ↔ 陈启明："放我出来的人，也是关我的人"

陈启明是研究院里唯一对她做过善意举动的人——在兽潮中打开了她的笼子让她跑。但她也知道他是研究院的人，研究院是关她的地方。她记住了他的灵能频率，但她再也没找到过。她对陈启明的感情不是感谢不是恨——是记住了。记住了一个人做过的事，但不赋予它意义。
