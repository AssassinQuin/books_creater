## 五大灵能区域叠加

灵能区域不受行政区划限制，由禁地灵能扩散自然形成，叠加在三环结构之上。

```
                        北方矿区
                     (强化/感知型)
                    蓝灰色 / 矿晶闪烁
                         |
   西部荒原 -------- 灵枢核心区 -------- 东部海岸
  (编织/结构型)     (同化/控制型)       (波动/传输型)
  土黄色 / 晶体结构  金色光芒           青绿色 / 波纹扩散
                         |
                      南方密林
                    (生命/共生型)
                   翠绿色 / 藤蔓纹路

各区域特征差异：
  浓度：核心区 > 矿区/海岸 > 荒原/密林（自中心向外递减）
  振动频率：每个区域独特的"味道"，决定觉醒倾向
  温度：核心区偏暖，荒原偏冷，海岸多变，密林湿热
  流向：从禁地向外辐射，遇地形改变方向
```

      活动范围：沼泽三角→潮汐镇→灯塔港一线

      种类不定/实力不定

      异灵本能回避禁地区域

    T1（最低）：本能驱动/不具智慧/群体行动

    T3（高级）：高度智慧/可指挥T1/罕见
    T4（传说）：渊/可能存在的其他个体/数量不明

## 通信网络覆盖

```
    灵枢灵能通讯网：
      覆盖：枢都(全覆盖) > 外城环带(全覆盖) > 灵站镇(全覆盖)
            > 中环主干道沿线城镇(部分覆盖) > 边境镇(有节点)
      延迟：内环即时 / 中环数小时 / 外环无覆盖
      方式：灵能共振传输，需灵能共振卡（沈念V1偷取的那种）

    壁盾军团通讯：
      方式：灵能信号弹+骑马传令
      覆盖：北境要塞↔矿山城↔铁谷镇↔冻土哨站
      速度：要塞到铁谷镇约1-2天

    商队带信：
      覆盖：所有有商路连接的城镇
      速度：跟着商队走，数天到数周
      这是中环到外环的主要信息传递方式

    教会通讯：
      方式：密林内的灵能感应+信使
      覆盖：圣城↔密林据点↔藤桥寨
      特点：教会声称"信仰相通"，实际利用密林生命型灵能的共振
      教会通讯同时用于传播统一教义·维持认知控制

    无覆盖区：
      外环大部分区域（废墟聚落/盐碱荒原/冻土前线）
      过渡带（无固定据点的荒野路段）
      禁地周边（灵能异常无法建立通讯）
```
