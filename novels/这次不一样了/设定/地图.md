## 五大灵能区域叠加

灵能区域不受行政区划限制，由禁地灵能扩散自然形成，叠加在三环结构之上。

```
                        北方矿区
                     (强化/感知型)
                    蓝灰色 / 矿晶闪烁
                         |
   西部荒原 -------- 灵枢核心区 -------- 东部海岸
  (编织/结构型)     (同化/控制型)       (波动/传输型)
  土黄色 / 晶体结构  金色光芒           青绿色 / 波纹扩散
                         |
                      南方密林
                    (生命/共生型)
                   翠绿色 / 藤蔓纹路

各区域特征差异：
  浓度：核心区 > 矿区/海岸 > 荒原/密林（自中心向外递减）
  振动频率：每个区域独特的"味道"，决定觉醒倾向
  温度：核心区偏暖，荒原偏冷，海岸多变，密林湿热
  流向：从禁地向外辐射，遇地形改变方向
```

## 贸易路线

### 灵晶主路线（灵枢控制）

```
外环灵站 ===商队===> 中环自由城 ===精炼===> 内环枢都
(收购低纯灵晶)       (中等纯度交易)          (高纯灵晶分配)

灵枢监控所有货物 / 官方商队7-15天一班 / 收费高但安全
```

### 独立商队路线（走私网络）

```
外环聚落 ===走私路线===> 中环边境镇 ===> 自由城
(物种灵晶/违禁品)         (设备零件/情报)

不走灵枢主干道 / 兽潮后地形变化需重新找路 / 外环和中环经济命脉
```

### 猎人队路线

```
兽潮区 <==> 各城镇
(带人穿越 / 猎杀物种取晶 / 采集灵能素材 / 替人带信运货)
最灵活的运输力量 / 收费高但可靠
```

### 黑市网络

```
各城镇地下 <==> 相互连接
交易品：私藏灵晶 / 设备零件 / 灵衰症偏方 / 情报
       物种灵晶 / 灵能装备(沈野铸造品在黑市有市场)
灵能频率黑市：灵站共振变化 / 区域浓度变化 / 物种领地扩张情报
```

### 灵衰症经济闭环

```
普通人 --> 去灵站卖灵晶 --> 得灵衰症 --> 治疗需天价灵晶
   ^                                                 |
   |                    继续卖                        |
   +-------------------------------------------------+
   灵枢定价让大多数人一辈子赚不够治疗费
   偶尔几个"幸运儿"治好 -> 活招牌宣传
   不靠杀人赚钱 -- 靠让你活着继续卖
```
