# 灵衰症与救治逻辑重构

> 核心原则：沈野的动机全程是个人化的——治妹妹。不是革命者。对抗灵枢是被逼的。
> 灵枢不是"邪恶组织故意制造疾病"，是"系统有副作用但选择了隐瞒"。
> 治疗需要三样东西，从V4开始逐步发现，每一样都有独立获取的困难。

---

## 一、灵衰症的真实机制

灵衰症不是"灵枢故意制造的疾病"。它是灵站系统的副作用：

**正常使用灵站**（低频率、短时间）：人体灵能自然恢复，无害。像献血一样。

**灵枢的改动**：为了提高灵晶产量，灵枢在灵站设备中增加了"共振增幅器"——让每次抽取效率更高。参数在安全线附近但没超线。单次使用不会出问题。

**问题在于累积**：高频+长期使用，人体灵能循环系统被反复微损伤——像血管壁被反复磨损。灵能残渣沉积在循环系统的管壁上，越积越多，最终堵塞整个循环。这就是灵衰症。

**灵枢知不知道**：知道。早期数据就显示了沉积现象。但灵枢选择了隐瞒——不是不想治，是公布真相意味着"灵站不安全"→人们不来卖灵晶→灵枢收入断崖→整个灵能供应体系崩溃。所以灵枢的策略是：不承认灵衰症和灵站有关，对外宣称是"灵能时代普遍现象"。

**不是纯粹的恶**：灵枢内部有人（钟衍）知道参数在临界线上，但他只是"执行层"。高层（韩朗）把灵衰症患者当数据管理。没有人坐在会议室里说"让我们制造疾病"。是系统惯性——停下来就崩溃，只能继续。

## 二、沈野的动机链（逐卷演变）

### V1：兽潮夜，活下去
动机：带沈念活下去。没有更大的目标。妹妹有病（以为是体质差），兽潮来了先跑。

### V2：发现灵衰症，去研究院
动机：方岩给路线图→去研究院治沈念的病。纯粹求医。到了发现研究院能压制但不能根治。
转折点：陈启明发现沈念的灵能残渣沉积模式异常——"不像自然暴露，像长期高频"。埋下疑点。

### V3：惨败中分兵
动机：还在求医阶段。惨败让团队受伤，但灵衰症治疗的线索还在追踪中。陆沉追兽潮异常方向，沈野继续保护沈念。

### V4：发现真相，崩溃
动机链关键转折：
1. 江屿发现灵站参数被调高——但不是"故意害人"，是"为了多产灵晶"
2. 沈野潜入灵站看到按产出率分级的名录——沈念是"高产出优质源"
3. 研究院告诉沈野：灵衰症能治，但需要灵能循环修复技术——研究院只有理论没有实物
4. 沈野崩溃不是因为"灵枢是坏人"——是因为**妹妹的病有办法治，但治疗需要的东西在灵枢手里被锁着**

**沈野的反应**：不是"我要推翻灵枢"。是"我需要那个治疗数据。灵枢不给我就去偷。"

### V5：合作是为了偷数据
和星火社合作的原因：星火社有灵枢内部的渗透渠道，能帮沈野接触到灵站系统的核心技术区。不是革命，是交易——帮星火社做任务，换取进入灵枢数据层的机会。

### V6-V7：被迫升级
偷数据的过程中被灵枢发现→追杀→团队被迫反击→从"偷数据"变成"被灵枢追杀必须反击"。V7星火社背叛后，连组织都靠不住了，只能靠自己。

### V8-V12：从自保到理解
在逃跑和反击的过程中，逐步理解灵枢不只是"锁着妹妹的治疗数据"——灵站系统的副作用害了无数人。从"治妹妹"扩展到"那些和沈念一样排队的人"。但核心动机始终是妹妹——扩展是副产品。

### V13-V14：治疗闭环
最终集齐三样东西，治疗灵衰症。

## 三、治疗闭环：三缺一渐进铺垫

灵衰症的本质：灵能循环系统被灵能残渣堵塞（像血管被胆固醇堵塞）。

**治疗需要三样东西**：

### 1. 灵能残渣清除技术（林原的数据）
- **V4铺垫**：林原给沈念检查时说"沉积模式可以压制"。他有一套清除灵能残渣的实验方案，但需要活体实验——"五和一"。他是用这个数据研究清除方法的
- **V8铺垫**：双星城废墟的公式墙包含灵能频率清除方程——许知许行留下的。林原的方案缺的就是这个频率参数
- **V14收集**：林原的数据+许知许行的频率方程=完整的灵能残渣清除方案

### 2. 灵能循环结构修复（蔓的编织）
- **V5铺垫**：蔓的编织不只是编网——她能编织灵能结构。沈念观察蔓编织时发现：编织的灵能线路和灵衰症患者受损的灵能循环路径很像
- **V7铺垫**：蔓编织质变——从编物到编灵能本身。她能直接编织灵能循环的物理结构
- **V10铺垫**：蔓的编织域场前兆——她能在一定范围内修复灵能结构。但只对小范围有效
- **V14应用**：蔓的编织+清除技术配合——先清除残渣（腾出空间），再编织修复受损的循环结构（重建管道）

### 3. 临床经验+患者档案（沈念的贡献）
- **V4铺垫**：沈念偷偷复制灵衰症患者档案——按产出率排序。她开始研究不同患者的沉积模式差异
- **V6铺垫**：沈念用患者档案建立灵衰症传播模式图——她发现了研究院没注意到的规律：沉积速度和灵能亲和度有关。亲和度高的人（沈念）反而沉积更快
- **V9铺垫**：沈念在战斗间隙做紧急处理时，发现自己对不同阶段的灵衰症反应有直觉判断
- **V14应用**：沈念的临床经验告诉她每个患者该先清哪段、再修哪段——她是指挥蔓"往哪编"的人。不是所有灵衰症都一样，需要个体化治疗方案

### 治疗流程（V14）
1. 沈念根据患者档案判断受损位置和严重程度 → 制定个体化方案
2. 林原的频率清除技术（数据）→ 清除灵能残渣，腾出循环通道
3. 蔓的编织 → 按沈念的方案修复受损的灵能循环结构
4. 三者缺一不可：没有清除，编织修不上（残渣挡着）；没有编织，清除了也白搭（循环断了）；没有沈念的方案，不知道该清哪修哪

## 四、关键设定调整

| 原设定 | 调整后 | 原因 |
|--------|--------|------|
| 灵枢故意制造灵衰症 | 灵站系统的副作用，灵枢选择隐瞒 | 更合理：系统惯性而非主观恶意 |
| 沈野要"推翻灵枢" | 沈野要"偷治疗数据"→被迫反击 | 符合人设：务实拾荒者不是革命者 |
| 灵枢压制治疗 | 治疗技术需要灵枢核心数据，灵枢锁着不是不想治是怕暴露 | 避免脸谱化反派 |
| V14治疗突然闭环 | V4开始三线铺垫，每卷推进一项 | 治疗不是天降，是14卷积累 |
| 林原是纯反派 | 林原有治疗数据但用不活人实验方式获取 | 电车难题不是善恶问题 |
| 沈念是纯受害者 | 沈念自己积累的临床经验是治疗关键一环 | 普通人高光，不是被动等救 |
