# 写作执行规范

> **本规范为最高优先级，后续所有章节写作必须严格遵守**
> **通用写作风格标准** →见 [writing-style.md](../../../../.claude/skills/novel-writer/references/writing-style.md)
> **反AI句式系统** →见 [SENTENCE-PATTERNS.md](../../../../SENTENCE-PATTERNS.md)
> **外部Skill参考** →见 [skills仓库](../../../../skills/)（web-novel-writer/novel-framework/storytelling/prose-craft）
> **Memory系统** →见 [memory skill](../../../../skills/memory/SKILL.md)（跨会话记忆持久化）
> 本文件只管**小说特定规则**：字数、流程、人物规则、检查清单、禁止项

---

## 一、字数要求

- **每章目标**：3000字以上
- **允许范围**：3000-5000字
- **最低门槛**：不得低于3000字
- **检查方式**：每章完成后立即用`wc -m`统计字符数

### 偏差处理
- 低于3000字：**必须使用场景深化技法扩写**（→见下方"反注水规则"），禁止注水凑字
- 超过5000字：考虑分章

---

## 二、内容依据（严格执行）

### 大纲对照
- **必须包含大纲规定的所有场景碎片**
- 场景顺序不得擅自改变
- 伏笔埋设点必须对应大纲

### 数据一致性
- **novel-db为准**：角色能力、状态、关系必须与db一致
- 世界观设定：地名、人名、势力、物品名称统一
- 禁止db中不存在的概念或设定

### 技能/能力使用
- **严格按照角色当前能力等级**描写
- 未觉醒/未进阶不得使用超能力
- 能力使用代价必须展现
- 禁止能力膨胀

## 三、小说特定写作规则

> 通用规则（去AI味/画面感/时间表达/感官描述/爽点/章节结构等）见 writing-style.md

### 🔴 角色智能底线（强制）
- [ ] **所有角色都没有蠢人**——错误判断必须基于信息不对称/利益冲突/情绪干扰，不是因为蠢
- [ ] 任何角色的"错误"都必须给出基于角色已知信息+立场的合理推理链
- [ ] 角色智能底线具体到每个角色→见设定/角色深化.md·各角色标注"🔴"的规则

### 🔴 世界势力存在感（强制）
- [ ] 大纲中出现的势力（教会/猎人/灵站/研究院等）在对应场景中必须有自然存在，不能"隐形"
- [ ] 各势力在具体卷中的存在形式→见对应卷大纲·"猎人元素""教会元素"标注，写作前读取大纲获取当前卷的势力密度和角色
- [ ] 三层防御体系在兽潮场景中必须体现→见设定/世界观/能力体系.md·狩猎职业体系+势力.md
- [ ] 灵站必须同时展现正面（稳定收入/预警/安全/净化）和负面（榨取/灵衰症/监控）→见设定/世界观/循环设定.md·灵站的表面与里层
- [ ] 新引入的势力角色必须有存在的理由（利益/职责/信仰），不能出现只为推动剧情的NPC

### 🔴 NPC互动真实性（强制）
- [ ] 陌生人NPC必须有戒备/试探前置，不能一上来就热络帮忙
- [ ] 只有长期熟人（阿婆/老陈/阿铁/阿公/方岩）可直接温情互动
- [ ] 沈念获取情报通过偷听/旁观/熟人转述/观察发现，不用直接对话问出情报
- [ ] 陌生人主动透露敏感信息必须有利益交换或误判前提

### 🔴 角色行为一致性（强制）
- [ ] 角色行为必须与角色蒸馏/人物卡一致（写作前加载角色蒸馏文件）
- [ ] 角色特定习惯（如食物偏好/保护行为/情绪表达方式）从角色蒸馏中读取，不硬编码

### 🔴 微动作泄露内心（强制）
- [ ] 离别/告别场景：角色必须有2-3个不舍微动作（手指多停一秒/回头看一眼/指尖悬在物体上方不碰/脚步慢半拍）
- [ ] 沈念"最后的旅行"心态：首次见新事物时要有短暂珍视感（多看两眼/嘴角轻弯/在心里记下），不是兴奋是"想把这一刻留住"
- [ ] 隐藏情绪通过身体泄露，不用直白词：不说"不舍""留恋""难过"，用"手指蜷了一下""站了一秒才迈步""眼睛在某处多停了一下"
- [ ] 非离别场景也适用：重大心事时日常动作泄露（吃东西变慢/手指无意识摩挲某物/目光偶尔飘向某个方向）
- [ ] 每个情绪转折点至少1个微动作，每个告别场景至少2个微动作

### 🔴 世界观与逻辑审计（强制）
- [ ] 新引入概念是否说清楚——读者能否不依赖外部知识就理解
- [ ] 世界观展开是否自然——通过场景/动作/对话带出，不是角色突然科普
- [ ] 事件因果逻辑是否清晰——角色决策符合已知信息，无逻辑跳跃
- [ ] NPC传授知识途径正确——老猎人教经验✅/路人突然科普❌/有利益交换才透露✅
- [ ] 信息释放节奏合理——不一次性倾倒

### 🔴 时间锚点（强制）
- [ ] 每章开头必须有明确时间标记（天数/时段/相对上章）
- [ ] POV切换时用环境光线/天气/人物作息锚定时段
- [ ] 章节间时间跳跃（>1天）必须明确说明间隔
- [ ] 同一天不同时段用"傍晚""入夜""天亮了"等标记

### 🔴 第三人称叙事一致性（强制）

> 本项目已确认使用**第三人称限制性叙事**原则。

- [ ] **POV锁定**：每场场景锁定一个POV角色，不跳POV。同一场景内不能同时出现两个角色的内心活动
- [ ] **信息边界**：叙述不超出当前POV角色的认知范围。不写"他不知道的事"，不写"没人看到的画面"
- [ ] **观察过滤**：POV角色的观察受其情绪、经验、关注点影响。焦虑时注意到光线太亮、声音太吵；放松时注意到细节与温度
- [ ] **禁止全知评论**：不用叙述者口吻做价值判断（"他不知道，这将是他最后悔的决定"→直接通过行为展示）
- [ ] **POV切换信号**：切换POV时必须有明确信号（空行+场景定位句/角色名先行/光线时段变化），不让读者混淆
- [ ] **视角频率**：每2-3章切换一次视角（降低切换频率，避免读者不适应），单次出场不少于3000字
- [ ] **内心活动限第三人称**：角色内心活动用"他想""她觉得"引导，不切换为第一人称内心独白

### 🔴 反AI指纹消除（强制）
- [ ] **标点多样性**：每段标点类型≥3种（不能只有句号+逗号）→详细规则见 SENTENCE-PATTERNS.md 第一章
- [ ] **破折号使用**：每章8-15次（V1平均4次/章，严重不足）
- [ ] **省略号使用**：每章3-6次
- [ ] **分号使用**：每章1-3次
- [ ] **句号密度**：不超过该段落类型上限（日常/情绪段≤25%，环境段≤20%）
- [ ] **否定转折句式**（"不是X，是Y"）：每章≤1次，全书≤5次→替代方案见 SENTENCE-PATTERNS.md 第四章
- [ ] **所有否定句式合计**：每章≤4次
- [ ] **否定消解**：能用动作替代否定时，不用否定句式
- [ ] **场景结构不重复**：相邻场景不使用相同的（入场+主体+收束）组合→结构零件库见 SENTENCE-PATTERNS.md 第三章
- [ ] **入场方式多样化**：每章至少4种不同入场方式
- [ ] **收束方式多样化**：每章至少3种不同收束方式
- [ ] **段落长度变化**：每章至少3个一句话段落+2个长段落（7+行），相邻段落长度差≥2行
- [ ] **信息三层投放**：新设定出场不紧跟解释，分三层投放（出场→功能→背景）→见 SENTENCE-PATTERNS.md 第二章
- [ ] **意象梯度化**：核心意象有程度变化（不是每次都"烫"），使用替换库避免超频→见 SENTENCE-PATTERNS.md 第五章
- [ ] **环境白噪音控制**：每章≤2次同类环境音效，使用替换库→见 SENTENCE-PATTERNS.md 第六章
- [ ] **意象追踪**：章节末尾填写意象追踪注释
- [ ] **无连续3句句号切割**（"X。Y。Z。"模式）

### 🔴 环境先行设计（强制）
- [ ] 大事件开始前必须先设计所有涉及的环境框架（空间/光线/声音/温湿度/灵能/时间）
- [ ] 同一地点不同章节出现时核心环境特征一致（不能上次窄这次突然宽）
- [ ] 环境变化有因果（天气变了/被破坏了/灵能波动了）
- [ ] 比较有代表性的地点保存环境快照，后续加载保证一致 →见 novel-framework 存储架构指南
- [ ] 环境参与叙事——光线暗示时间、温度暗示危险、声音暗示接近 →见 storytelling 环境暗示系统
- [ ] 详细策略 →见 web-novel-writer 原则二：环境先行设计

### 🔴 事件场面搭建（强制）
- [ ] 每章写正文前完成场面设计清单（时间快照/在场人物及状态/物品清单/各人目的/动作线骨架）
- [ ] 大事件先生成总纲再逐章填充（大事件总纲→逐章骨架→逐章正文）
- [ ] 动作之间有物理连接——上一招收势是下一招起势
- [ ] 战斗有空间感——地面材质/障碍物/高低差/光线影响
- [ ] 详细策略 →见 web-novel-writer 原则三：事件场面搭建

### 🔴 对话个性化（强制）
- [ ] 对话基于角色档案设计，遮住名字能分辨谁在说话 →见 storytelling 声音指纹
- [ ] 同一角色对不同人说话方式不同（亲近者/陌生人/敌人）
- [ ] 同一角色不同场景说话变化（紧张/放松/愤怒/悲伤）
- [ ] 使用弦外之音：不说破、答非所问、话里有话、留白 →见 storytelling 弦外之音系统
- [ ] 使用通感描写增加文字层次 →见 storytelling 通感系统

### 🔴 人物外观一致性（强制）
- [ ] 人物外观/性别/标志性特征与前文一致（不能过几章就变）
- [ ] 写正文前加载人物外观描写库 →见 novel-framework Character-Forge 外观描写库
- [ ] 网文旁白可以细腻但不啰嗦——每个描写细节至少承担两个功能

### 🔴 物品使用一致性（强制）
- [ ] 物品一旦出现过，外观/功能/使用方式即锁定
- [ ] 灵能残渣等关键物品有完整描写（生成/使用/外观/颜色/味道/功效/变化/触感）→见 novel-framework Artifact-Smith
- [ ] 物品状态追踪（谁持有/完好度/位置）

### 🔴 复杂场面生成（强制）
- [ ] 每章至少1个中量以上场面（≥2人互动≥800字）
- [ ] 3+人场景必须使用角色矩阵（目标/障碍/对其他人的态度/信息持有量）
- [ ] 场面密度匹配事件层级（微→轻量/小→中量/中→重量/大→大场面）
- [ ] 多人场景对话不全是"轮流发言"——允许打断/跑题/沉默/子群对话
- [ ] 关键对话有潜台词层——不说白了，用答非所问/过度强调/沉默传递真实意图
- [ ] 场景间过渡优先软过渡/零换行切换，避免全部硬切
- 详细策略 →见 references/scene-composition-guide.md

## 五、禁止事项（违反必须重写）

### 小说特定禁止
- ❌ 角色因为"蠢"做错事——所有误判必须有信息不对称/利益冲突/情绪干扰的前提（→见角色深化·各角色铁律）
- ❌ 大纲中标注的势力在场景中完全隐形——写作前读取大纲获取势力密度
- ❌ 灵站只写负面不写正面——必须同时展示"希望"和"代价"（→见循环设定·灵站的表面与里层）
- ❌ 陌生人NPC主动热情分享信息（必须戒备/试探前置）
- ❌ 角色行为与角色蒸馏/人物卡不一致
- ❌ POV切换无时间锚点
- ❌ 同一场景内切换POV或插入非POV角色内心活动
- ❌ 叙述超出当前POV角色认知范围（全知视角信息泄露）
- ❌ 用全知叙述者口吻做价值判断（"他不知道这是最后一次"等）
- ❌ 内心活动切换为第一人称（必须用"他想""她觉得"引导）
- ❌ POV切换无信号让读者混淆
- ❌ 离别/告别场景无微动作不舍细节（必须2-3个身体泄露）
- ❌ 用"不舍""留恋""难过"等直白情绪词代替微动作
- ❌ 精确时间表达 / 直白时间过渡（见 writing-style.md 第三章）
- ❌ 偏离大纲核心冲突
- ❌ 引入未在世界观中的设定
- ❌ 角色行为不符合人设
- ❌ 能力使用无限制无代价
- ❌ 爽点无铺垫突然打脸
- ❌ 全章场景间只用硬切拼接（必须有软过渡或零换行切换）
- ❌ 多人对话"轮流发言"（必须有打断/跑题/子群对话）
- ❌ 关键对话全说白无潜台词

### 🔴 反注水禁止（强制）
- ❌ 加一句孤立感官描写凑字数（"空气里有消毒水的味道"）——必须用五感递进法：感官→反应→判断→行动
- ❌ 加一句无因果过渡（"他继续走"/"走廊的灵能灯嗡嗡响"）——必须承载信息增量
- ❌ 重复标志性意象凑字数（反复"太阳画""摩挲指关节"）——同章不超过1次，全书不超过5次
- ❌ 形容词堆砌（"很大的很漂亮的"）——用具体细节替代
- ❌ 静态环境罗列（"走廊里有灯。灯是白的。"）——必须有人物与环境互动
- ❌ 角色自言自语式内心独白（"他想：这可怎么办呢"）——用动作和身体反应替代
- ❌ Telling式扩写（"方岩在北境待了十五年"）——必须Showing（"右膝弯得不太自然，北境十五年的旧伤"）

### 🔴 反AI指纹禁止（强制）
- ❌ 连续3句句号切割（"他站了起来。手贴上管壁。指尖微烫。"）——用逗号/破折号连接
- ❌ "不是X，是Y"否定转折句式超过1次/章
- ❌ 所有否定句式合计超过4次/章
- ❌ 新设定出场后紧跟解释句（科普式信息倾倒）——信息分三层投放
- ❌ 相邻场景使用相同的（入场+主体+收束）结构组合
- ❌ 每段只有句号+逗号两种标点（标点类型必须≥3种）
- ❌ 同一意象在同章内重复使用（同章不超过1次）
- ❌ 同类环境白噪音超过2次/章（"碎石沙沙响""灵能路灯一闪一闪"）
- ❌ 段落长度趋于均匀（每段3-5行像尺子量过）——必须有1行段落和7+行段落
- **替代法则**: 每当想加一句话凑字数，先问"这句话是否同时在做两件以上的事？"如果不是，用能做多件事的方式重写
- **字数不足时**: 使用场景深化决策树（→见 references/scene-deepening-guide.md 第五章），不要注水

### 流程禁止
- ❌ 写完不调用`writing_finish`
- ❌ 写完不创建角色蒸馏
- ❌ 不检查字数和规范
- ❌ DB不一致不修正

## 六、重写标准

- 字数低于3000字
- 场景缺失或严重偏离大纲
- 违反禁止事项
- 存在注水段落（孤立感官/无因果过渡/重复意象/形容词堆砌）
- 用户明确要求重写

## 七、执行纪律

1. 读取大纲对应场景
2. 读取writing_start上下文
3. 按**正文生成加载协议**加载：卷级大纲→事件大纲→伏笔线索→世界观→地图→人物快照→环境快照→事件快照→前文回顾 →见 web-novel-writer 正文生成加载协议
4. 读 writing-style.md（通用标准）
5. 读 SENTENCE-PATTERNS.md（**反AI句式系统——必读**）
6. 读 scene-composition-guide.md（复杂场面策略）
7. 读 scene-deepening-guide.md（场景深化/反注水）
8. 加载出场角色的**人物档案**（外观描写库+声音指纹+微表情词典）→见 novel-framework Character-Forge
9. **环境先行设计**：为本章场景搭建环境框架（空间/光线/声音/温湿度/灵能/时间）
10. **事件场面搭建**：完成场面设计清单（时间/人物/物品/目的/动作线骨架）
11. 随机选择本章场景结构组合方案（入场/主体/收束分配）
12. 按本规范的小说特定规则+反AI规则+对话个性化+环境一致性+物品一致性生成内容
13. 自检通用风格 + 小说特定规则 + 反AI指纹检查 + 场面生成规则 + 密度检查 + 反注水检查 + 对话个性化检查 + 外观一致性检查
14. 统计字数
15. 调用writing_finish更新DB
16. 创建角色蒸馏文档（含增量更新）
17. 更新环境快照/物品状态（如有变化）
18. 填写意象追踪注释（章节末尾，注释形式）
19. 检查所有检查清单
20. （推荐）更新Memory：创作决策/写作经验/角色状态 →通过 memory skill 执行
