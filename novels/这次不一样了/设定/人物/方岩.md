## 外观描写库

**性别**: 男

**身高体型**: 四十出头但看着像五十——十五年的边境前线和兽潮在他身上留下了比年龄更深的痕迹。一米七五，壮实但不臃肿——军人的体型，不是健身的体型。肩膀宽厚，手臂有明显的肌肉线条但不是夸张的健美，是长年扛装备爬地形练出来的实用肌肉。脖子粗短，站立时重心略低——这是常年蹲守观察练出来的体态。大腿粗壮有力，适合长途行军和快速短跑。肚子有一点——不是发福，是退伍后运动量下降加上喝闷酒的结果。手指粗短有力，指节全是老茧——不是握笔的茧，是握刀和爬绳的茧。指甲剪得极短极齐（壁盾军规：长指甲在战斗中会卡）。膝盖有旧伤——半蹲久了会痛，走路时右腿有极微的拖（不明显，但他自己知道）。

**面容特征**: 脸型方正粗犷——国字脸，下颌骨硬。皮肤粗糙偏黑——不是天生的黑，是十几年边境紫外线加上灵能辐射浸出来的深色。额头有三道深横纹（常年的皱眉+日晒留下的肌沟），眉心一道竖纹（判断兽潮方向时紧锁的），法令纹深。眉毛浓密灰白杂半——他不修剪，野蛮生长。眼睛不大但目光沉稳锐利——不是年轻人的锐利，是"我见过太多人死了我还在"的沉稳。看人时会先扫全身再对视——斥候本能，先评估威胁再看脸。眼角有鱼尾纹，笑的时候更深（他笑得不多）。鼻梁宽扁，左侧有一处旧骨折痕迹（年轻时被牙异灵撞的）。嘴唇厚而干，常年起皮。下巴有灰白胡茬——刮不干净了也懒得刮了，退伍后更不讲究。左脸颊有一道旧疤——从颧骨斜拉到下颌，约四厘米，已经愈合泛白，是那次任务的纪念品。这道疤让他左侧面部肌肉有点不自然——笑的时候左侧嘴角的弧度比右侧小。左耳有一道旧裂口（兽潮中灵能碎片划的）。

**头发**: 黑灰杂半，剃短——壁盾军规遗留习惯。退伍后不再剃光头但保持极短，短到头皮可见。鬓角有白发——不算多但 noticeable。他不照镜子。偶尔沈念说他"头发该剪了"他会说"嗯"然后又忘了。剃头用的是一把钝了的老式折叠刀，所以头皮上偶尔有划痕——他已经习惯了。不用任何护发品，头皮上有一层薄薄的灰（边境灰尘）。

**肤色**: 偏黑偏粗——边境风霜+灵能残渣日积月累。手臂颜色比脸深一度（常年卷袖子）。脖子和前臂有晒痕分界线——军装的领口和袖口挡住了紫外线，其他地方被晒成了深色。手背上有几道浅色旧疤和几处深色灵能灼痕（战斗遗留），排列密集，像一张粗糙的地图。脖子后面有一大片粗糙皮肤——常年在烈日下行军晒的。

**穿着风格**:
- **日常**: 旧壁盾军装外套改的——深灰色，肩章拆了，胸前的铁质徽章磨损得快看不清。内搭粗布衬衣（领口磨毛了）。裤子是军规长裤改的，膝盖处补了两层（他自己补的，针脚粗糙——和沈念的细密针脚形成对比）。硬底军靴——鞋底磨薄了但他换了两次鞋底。腰间挂一把标准灵能短刀（壁盾制式）和一个小布包（装烟丝和火折子——退伍后学会的坏习惯）。没有披风、没有装饰。整体一看就是"当过兵的"。
- **战斗**: 不换装——他的日常穿着就是战斗穿着。但如果预判有危险，会把布包收紧、短刀换到顺手位置、检查弹药——全是下意识的动作，不需要想。他不需要准备——十五年的身体记忆会自动执行这些动作。
- **穿着逻辑**: 所有衣服都是旧壁盾军装改的——他不买新衣服因为"旧的够穿"。修补都是自己做的——针脚粗糙但结实。口袋永远有旧地图——手绘的边境路线图，标注了据点、水源、危险区、异灵出没频率。用铅笔更新，笔迹潦草但准确。他不选择衣服，只选择能用的。

**标志特征**:
- 粗糙的方脸+深纹+灰白杂半的眉毛=老兵的"身份证"
- 左脸颊旧疤（那次任务的纪念品，全书不变）
- 左耳旧裂口（兽潮中灵能碎片划的）
- 手背密集旧伤疤+深色灵能灼痕（翻废墟十五年的斥候勋章）
- 手指粗短+指节全茧+短指甲=用过刀的手
- 走路总在观察周围——头部微转、眼神扫射、斥候本能停不下来
- 左臂有旧伤（12人小队全军覆没那次留下的）——天冷或下雨时酸痛，他摸左臂的方式不是揉是握一下再松开
- 睡觉时姿势随时能起身——半蜷、一只手在刀旁（真的睁一只眼——沈念第一次看到吓了一跳）
- 骂人时声音反而变小——低沉的威胁
- 站着的时候重心永远在前脚——随时准备冲
- 夸人时用力拍肩——拍得很重，沈念被拍过一次后说"方叔你轻点"，他拍得更重了（他不知道怎么轻）

## 决策引擎（写作时用这个生成他的选择/动作/语言）

### 核心冲突：教人活着 vs 替人死

方岩这辈子只会两件事——教人怎么活，和人怎么死。

```
教人活着：训练、指路、骂人、修装备、把年轻人推到他够得着的高度
替人死：几个月前，12个人在他眼前死了，他活着回来了。这件事是他所有选择的底色
```

**日常状态**：教人活着赢。骂骂咧咧地教年轻人怎么用刀、怎么认路、怎么在废墟里多活一天。

**触发状态**：任何场景让他想起12个人——他会突然沉默，然后做一件具体的事（检查装备/擦刀/看路线图）。他不用语言处理这个，用动作。

**升级状态**：当保护年轻人和追查真相冲突→他会选保护年轻人。然后夜里一个人喝闷酒，喝到第三碗的时候说"12个人不是白死的"。

### 决策规则（按优先级）

```
规则1：年轻人不能死在我前面
  → 表现：把最安全的任务给他们，最危险的路自己走
  → 他骂人越凶→那个人他越担心

规则2：真相可以等，命不能等
  → 表现：查了几个月的真相可以再等一天，但眼前这个人受伤了得先处理
  → 但他的耐心有限——如果年轻人反复犯同样的错，他会爆炸

规则3：不信命令，信自己的判断
  → 表现：别人说"前面安全"他也要自己查一遍
  → 不是不相信那个人，是15年的习惯改不了

规则4：话只说到七分
  → 表现：他不解释前因后果。他说"左边"就是左边，不接"因为右边有坑"
  → 不是不信任，是习惯了战场上没人有时间听前因后果
  → 但他偶尔会多说一句（对沈念/对完全的新人）

规则5：沉默代答案
  → 表现：不想回答→沉默。不知道→沉默。太难过了→沉默
  → 他的沉默有很多种意思，但每一种都是"我不想/不知道怎么用语言处理这个"
```

### 生成他的对话（三步法）

```
第一步：现在他说的话有用吗？
  - 没用的不说——不寒暄、不问好、不夸奖（除非拍肩膀）
  - 有用的最短说——"趴下"不说"你最好趴下因为前面有危险"
  - 例外：喝酒之后话会变多（但全是重复内容）

第二步：他在跟谁说？
  - 沈念 → 声音降半调，句子变长一点点，会重复提醒
  - 沈野 → 命令式短句。认可他最多说一句"手稳"
  - 陆沉/同辈 → 偶尔正常对话，但不会超过三句
  - 年轻人/新手 → 最凶。他的凶=关心，但接收方不一定知道
  - 敌人 → 越危险话越少，最后只剩刀声

第三步：检查——这句话是不是"太像老兵该说的话"？
  - "我经历过更糟的" ❌ → 他不会这么说。他只会沉默。
  - "年轻人不懂" ❌ → "别磨叽" ✅
  - "听我的没错" ❌ → 他会直接说该怎么做，不说"听我的"
```

### 生成他的动作（两步法）

```
第一步：他的身体在什么状态？
  - 清醒状态 → 眼睛不停扫视，站姿重心在前，随时准备冲
  - 放松状态 → 重心后移，眼睛还在扫但频率低了（极少出现）
  - 回忆状态 → 左手摸左臂旧伤。握一下，松开。一秒

第二步：他有没有在刻意避开什么？
  - 避开的动作本身也是信息——他不看某个方向、不碰某样东西、不和某人说话
  - 避开=那件事/那个人让他不舒服
```

### 场景决策速查

| 场景 | 他的默认选择 | 可能的偏移 | 偏移条件 |
|------|------------|-----------|---------|
| 有人问他的过去 | 带过或沉默 | 如果是沈念问→说半句然后转移话题 | 沈念让他想起女儿 |
| 看到年轻人做危险的事 | 大声骂然后帮他检查装备 | 如果那人已经受伤了→先救，不骂了 | 伤重到骂了也没用 |
| 有人质疑他的路线 | "不信你走你的" | 如果质疑的人是对的（他确实错了）→沉默，然后调整路线但不承认 | 他错了但不会道歉 |
| 看到沈念疼/不舒服 | 安静很久，然后把最安全的路线给她 / 把自己的东西给她 | — | — |
| 不确定前面有没有危险 | 自己先走一段确认，让其他人等着 | 如果时间紧迫→"跟紧，我叫停就停" | 不能等的时候 |
| 有人说了让他想起12个人的话 | 沉默，摸左臂，然后转移话题或走开 | — | — |
| 战斗结束后 | 先检查所有人的装备再检查自己的伤 | 如果受伤的人里有沈念→先看她 | — |

**底层驱动**: 12个人不是白死的。打仗他不怕，怕的是打了一场没意义的仗。

**决策逻辑**: 只看实际情况，不听口号。对上级的命令会执行但会保留自己的判断——因为那次延迟增援让他不再信任命令。

**怎么写他**:
- 短句，命令式，偶尔沉默很久。夸人时用力拍肩
- 对年轻人又凶又护——骂完了偷偷把对方的装备修好补好。骂人不是脾气差——是他知道装备不好会死人、训练不够会死人
- 只会打仗，不懂别的。退伍之后不知道干什么——没有家（老婆早离了），没有想做的事。他最想做的事（让年轻人不用打仗）恰好是他唯一能做的事的反面——教打仗
- 对平民没耐心，但对沈念温柔（兽潮中从废墟里把她拖出来+让她想起兽潮中死的4岁女儿）
- 睡觉睁一只眼。身上无数旧伤。走路时总在观察周围——斥候的本能停不下来

**情绪怎么写**:
- 愤怒→不骂人，沉默更久。然后去做事
- 提到12个战友→一句话带过，不展开。但会无意识摸左臂旧伤
- 对年轻人的担心→凶："你手里那玩意儿能杀人吗不能就别举着"
- 唯一的软肋→沈念。看到她疼会安静很久，不会安慰但会把最安全的路线给她

**口头禅**: "别磨叽。""趴下。""枪端稳了没？""……我那边有12个人。"
**他不会说的**: 大道理。他只说具体该做什么

**战斗**: 15年边境斥候。灵能感知地形——在灵能浓度变化中"看到"地形结构。认识路线：知道哪些据点还活着哪些被兽潮吞了。天然侦察兵和向导。

## 对话声音指纹

### 声音特征

**音色**: 沙哑、厚重、粗糙。像砂纸磨铁皮——但比沈野的更粗。声带被十五年的战场喊令磨粗了。说话时胸腔共鸣强——他不用丹田发声，他的身体就是共鸣箱。声音永远比正常人高半拍到一拍——他自己不觉得。安静说话时声音依然"大"。他无法小声说话——不是不会，是十五年喊命令的习惯改不了。

**语速**: 快偏急。短句为主，句子之间没有间隙——像连射。但不是急躁——是军中指令的节奏：信息量大、时间短、没有废话。特别是紧急情况——句子和句子之间没有间隙，像机关枪。但骂人时反而变慢——一字一顿，每个字都像钉子。日常对话时语速中等偏快，不给人思考时间。他觉得犹豫=浪费时间。他的长句只有在解释路线或战术时才会出现，而且会刻意放慢——因为斥候的情报传递规则是"说清楚比说快重要"。

**说话习惯**:
- 短句是母语。长句是需要努力才能说出来的东西。命令式为主——"趴下。""别磨叽。""枪端稳了没？"
- 不说大道理——他只说"该做什么"。"为什么？""因为会死。"这就是他的全部解释
- 骂人是关心方式——"你那玩意儿能杀人吗不能就别举着！"翻译：我担心你会受伤
- 夸人用力拍肩——他不会说"你做得好"，他用物理力度传达认可。拍得很疼
- 骂人时声音反而变小变沉——不是压抑，是"教官模式"。低沉的威胁比大喊大叫有效
- 偶尔冒出长句——通常是回忆12个战友时，但说到一半会突然停住，然后转移话题
- 对沈念说话时声音会降半个调——他自己不知道
- 说话时会不自觉地看左臂旧伤的位置——提到12个人的时候
- 沉默和说话一样有信息量——他沉默的时候通常是在判断。判断完了他会开口，通常是一句话总结

### 口头禅
"别磨叽。""趴下。""枪端稳了没？""……我那边有12个人。"

### 微表情词典

### 弦外之音设计

方岩的核心弦外之音方式：**以吼叫代关心，以沉默代伤痛**。

- 不说破：他知道赵铁山签了协议的事——但不说。不是因为大度，是他理解赵铁山的处境。"不签会死更多人"这个逻辑他反驳不了。他知道12个人的真相但他选择"不知道"。不是不在乎——是知道了但他改变不了任何事。对方岩说"我知道你签了协议"比骂他更残忍——因为他知道。他的"不知道"是给自己的最后一道防线。但他的巡逻日志里记下了每一个异常——这些日志是他给未来的证据。15年斥候训练告诉他：看到的东西写下来，万一有一天需要回头看。每一页都是他对"真相会被埋没"这件事的抵抗。
- 以吼叫代关心：他只会打仗，只会教打仗。关心人的方式是军事化训练——"枪端稳了"="我担心你"。他不是温柔的人也变不成温柔的人——他能做的就是让身边的人不要死。他恨打仗因为他见过太多死人，但他只会打仗所以他继续打。他不是在恨和爱之间纠结——是只有一种语言的人用这种语言说所有的话。
- 以沉默代伤痛：12个人死了他只字不提。不是不想念——是怕提了就停不下来。他把所有的悲伤压缩成了一个动作：左手握一下左臂旧伤。这是他允许自己悲伤的全部时间——一秒钟。然后继续走。他说"12个人"这四个字的时候声音会变——只变一瞬，然后他转移话题。那一瞬是他在把一整个坟场吞回去。

## 能力体系：灵能感知地形（通感级）

### 核心：斥候直觉

方岩的能力不是战斗型——是情报型。他能感知灵能浓度在空间中的变化，并用这种变化在大脑中"看到"地形结构。

```
感知逻辑：
地形结构 → 灵能浓度分布 → 他的感知器官（皮肤/内耳）捕捉浓度差异 → 大脑自动建模
→ 输出：一张实时更新的3D地形图

具体表现：
- 在未知环境中行走时，他能感知前方50米内的地形起伏、管道走向、灵能浓度异常区
- 灵能浓度高的地方（异灵聚集区/灵站/禁地边缘）在他"感知"中会"亮"
- 灵能浓度低的地方（安全通道/旧据点）在他"感知"中会"暗"
- 地下结构（管道/地下室/矿脉）他也能感知——因为地下灵能流动方式不同

限制条件：
- 精度有限：能感知"大致结构"但不能感知"细节"——知道前面有管道但不知道管道里有什么
- 灵能干扰区失效：灵枢的干扰装置、高浓度灵能区域会淹没他的感知
- 等级极低：通感级勉强——放在觉醒者里几乎是最低档。他的真正能力是15年经验
- 几乎不成长：通感级已经是他能达到的上限

经验才是核心能力：
他认路不是靠灵能——是靠15年走过的每一条路线
他知道哪些据点还活着、哪些被兽潮吞了、哪里有水源、哪里有异灵巢穴
他的路线图是手绘的、铅笔更新的、笔迹潦草但比任何灵能地图都准确
这是时间堆出来的数据库——不是天赋
```

### 斥候附加技能

| 技能 | 来源 | 表现 |
|------|------|------|
| 生存判断 | 15年边境经验 | 闻空气里的灵能味道判断兽潮是否将至；听地面震动判断异灵数量和类型 |
| 急救 | 军队基础训练 | 止血、固定骨折、处理灵能灼伤——不够专业但够用 |
| 路线规划 | 斥候本职 | 能在复杂地形中找到最快最安全的路径。他的路线图是团队的生命线 |
| 轻武器 | 军队标配 | 灵能步枪、灵能短刀——中规中矩的军事训练水平，没有特长 |
| 夜间行动 | 斥候训练 | 全黑暗环境中保持行动能力。睡觉半醒——有动静秒起 |

### 能力的叙事意义

方岩是"普通人靠经验碾压觉醒者"的活例子。他的灵能等级几乎是最低的（通感级勉强），但他的价值远超大部分凝相级觉醒者——因为15年的经验数据库比任何能力都可靠。他的存在说明：在这个世界里，能力不是唯一的价值，经验、判断力、生存本能同样重要。也正因为如此，他退役的原因不是能力不够——是"初觉级太弱不够当军官"。但一个能画出最准确的边境路线图的老兵，比任何军官都有用。

## 不完美维度（必须遵守）

### ① 执行偏差
- **偶尔幽默**：平时凶巴巴的，偶尔会说一句特别冷的笑话——冷到全场沉默的那种，他自己不觉得好笑。沈念第一次听到的时候愣了三秒才笑
- **偶尔优柔寡断**：面对跟12个战友无关的决定时反而犹豫——吃面还是吃馍、走左边还是走右边（两条路都一样）、要不要多带一壶水。小事上他会反复纠结
- **偶尔脆弱**：不是戏剧化的崩溃——是某一天他什么都没做，坐在那里发了很久的呆。问他他说"没事"，是真的没事，就是累了

### ② 无意义细节
- 会不自觉地哼跑调的军歌——哼到一半发现自己在哼就停了，但过一会儿又哼起来。他不知道自己哼的是什么曲子
- 喝热水的时候一定要吹一下——不管烫不烫
- 口袋里永远有不知道用来干什么的小东西——一颗特别圆的石头、一段铁丝、一片干树叶。他也不知道为什么留着，就是捡了就放口袋里了
- 刮胡子总会漏掉同一处——左边下颌角那里。不是故意的，就是那个角度他刮不到

### ③ 认知偏差
- 他对外环的判断基于15年前的经验——那时候没有灵站加量、没有这么多虫豸、没有聚落人口膨胀。他还用老办法判断新情况，有时候对有时候错
- 他觉得年轻人都不行——不是真的，是他的偏见。他觉得新一代的拾荒者"不够硬"，其实只是他自己老了
- 他以为他的路线图是唯一的正确答案——其实有些路他太久没走了，状况已经变了，但他不信别人说的

### ④ 表达失败
- 想安慰人的时候变成训人——"别哭了，哭有什么用"（其实他想说的是"我理解你难受"）
- 想道谢的时候变成了一句"嗯"——对方等了半天以为他没反应
- 想说"我担心你"的时候变成了一句"你那个装备不行"——他所有的关心都需要通过"挑毛病"这个通道才能出来

### ⑤ 非线性情绪
- 在战场上他不紧张——回到营地休息的时候反而开始手抖
- 聊到开心的事（沈念讲了个笑话）他沉默了很久——不是在生气，是他太久没开心过了，不知道怎么回应
- 看到沈念疼的时候他发了火——不是对她，是对旁边的人。他自己也不知道为什么生气

## 核心定位

**方岩**——做错了的事能不能原谅自己？不是原谅，是承认，然后继续走。

打了十五年仗的老兵。只会打仗，不懂别的。对年轻人又凶又护。

退伍之后不知道干什么。没有家，没有老婆（早离了，受不了他常年不在），没有想做的事。他的全部技能就是认路、判断兽群、带新人活下来。所以他留在边境——不是因为使命感，是因为他去别的地方没用。

不久前那场兽潮，他的斥候小队在边境执行侦察任务时遭遇异常兽群，12人全军覆没。他以为是自己判断失误——没有跑快，没有早半秒下令撤退。后来发现不是：军团高层延迟了增援，因为灵枢要求控制兽潮信息传播。那12个人不是被兽群杀的，是被信息差杀的。方岩要的不是正义——他要的是那12个人不是白死的证明。

兽潮过后他没有回壁盾。他带着那12个人的名字一路追踪灵能异常，沿着兽潮路径查灵站参数偏差、查灵枢对边境信息的管控节点。几个月了，每一条线索都断在"需要更高权限"的墙前。他在这个聚落停下来，是因为灵站异常模式和灵枢介入程度跟他追踪的方向吻合。他需要在这里找到最后一块拼图。

在这个聚落他碰到了沈野和沈念。认识，但不熟——壁盾外围偶尔碰到过那个拾荒者，冷冷的人，不搭理谁。兽潮那天方岩在废墟里把沈念从碎石下拉出来，后来他自己被兽潮余波困在坍塌区，沈野用拾荒者的直觉找到他的位置把他捞了出来。三个人之间的债算不清，也不需要算清。方岩画了路线图给沈野，告诉他去研究院。沈念给他包扎、给他吃的、不问他为什么在废墟里。方岩后来知道沈念偷偷卖灵晶攒路费得灵衰症，他说不出"别卖了"——因为他也知道不卖就没钱。他没跟他们走，因为那12个战死的弟兄的事他还没查清楚。

他没有觉醒能力（地形感知是通感级不是战斗级），但他的判断力比任何觉醒者都强。不是超能力——是15年用命换来的经验数据库。"兽潮不正常"不需要灵能检测，他闻到了空气里灵能味道不对。

他教新斥候的时候最凶，因为他知道训练不够会死人。他的"凶"是用唯一会的方式（军事化）表达关心。他恨打仗因为他见过太多死人，但他只会打仗所以他继续打。他不是在恨和爱之间纠结——是只有一种语言的人用这种语言说所有的话。

他对平民没耐心。和沈念相处时温柔是因为她救过他，也因为她让他想起自己的女儿——兽潮中死的，4岁。但他对沈念的关心不全是投射——沈念是真的让他想保护。投射给了开始的动机，真实关心让这个动机持续。当投射消退之后，关心还在。

他写下每个观察不是习惯——是证据。15年斥候训练告诉他：看到的东西写下来，万一有一天需要回头看。日志是他给未来的自己留的线索。每一页都是他对"真相会被埋没"这件事的抵抗。

他说话短不是因为不会说长句——是因为长句让他有时间想到不该想的东西。"趴下"比"快趴下来，有东西过来了"快0.3秒。0.3秒在战场上决定生死。他的简洁不是风格，是伤疤。
