## 外观描写库

**性别**: 男

**身高体型**: 十七岁但看起来像成年人——长期营养不良让他没有同龄人该有的圆润。一米七出头，偏瘦但不干瘪，肩膀窄但手臂有韧劲——拾荒爬管道练出来的。手指长而粗糙，指节有老茧（抓握铁皮和碎渣留下的），指甲剪得极短（长指甲在废墟里会卡住）。腰很细，皮带扣永远在第三格——他没什么多余的东西挂腰上，只有一把短刀和一个布包。

**面容特征**: 脸型偏瘦削，下颌线清晰但不锋利，十七岁的轮廓还在长但已经能看出是个冷脸的人。眉毛浓而直，不皱的时候也像在皱——不是天生凶，是长期保持警觉的肌肉记忆。眼睛不大但黑，看人的时候不带情绪，像在判断这东西值不值得捡。鼻梁挺直，嘴唇薄而紧，很少有表情起伏。左耳垂有一道旧裂口（小时候被铁皮割的），已愈合但痕迹明显。

**头发**: 黑色，不长，乱。他自己用断刀削的，长短不一，发尾会戳到脖子后面。不梳头。前面碎发偶尔遮住眉毛，他不理。出汗的时候头发贴在额头上，他会用手背抹一把然后继续干活。

**肤色**: 偏黑偏灰——不是晒的，是外环空气里灵能残渣日积月累浸出来的颜色。手臂和手背的颜色比脸深两度（常年暴露在废墟里）。手背上有几道浅色旧疤，都不是大伤，是翻铁皮时划的。

**穿着风格**:
- **日常**: 深灰色旧外套，袖口磨得发白但缝补过很多次，针脚细密——沈念缝的。内搭一件看不出颜色的旧衬衫。裤子是军用废料改的，膝盖处补了两层。靴子比脚大一号（捡的），鞋底磨薄了但他用废胶皮垫过。腰间一把短刀（不是灵能武器，就是铁片磨的），一个布包（装拾来的碎渣和干粮）。
- **战斗**: 不会特意换装。但如果预知有危险，会把布包收紧、短刀换到顺手的位置。后期有了铸造能力后，身上会多出自己铸的灵能碎片（嵌在皮带上或缝在袖口内侧），不显眼但能快速取用。
- **穿着逻辑**: 所有衣物都有功能性——没有装饰。口袋深（装碎渣）、袖子紧（爬管道不挂）、靴子垫过底（防刺）。他不选衣服，只选能用的。

**标志特征**:
- 手指粗糙+指甲极短+指节老茧（拾荒者的手，全书不变）
- 左耳垂旧裂口
- 衣服袖口处有细密的缝补针脚（沈念缝的）
- 进任何新环境第一个动作是扫视退路和可用物（不是习惯，是本能）

## 决策引擎（写作时用这个生成他的选择/动作/语言）

### 核心冲突：安全 vs 真相

沈野的所有决策都在这两个之间拉扯：

```
安全：已知的、稳定的、能控制的 → 他的默认选择
真相：他想知道的、感觉不对的、但可能是危险的 → 他的诱惑
```

**日常状态**：安全赢。不追问、不好奇、不冒险。

**触发状态**：当某件事同时满足"跟沈念有关"+"感觉不对"→真相开始拉扯他。

**升级状态**：当真相和安全直接冲突→他会先选安全，但会在安全范围内给自己留一个"以后可以回头查"的入口（收好残片、记住路线、留意那个人）。

### 决策规则（按优先级）

```
规则1：沈念优先 —— 任何涉及沈念安全/健康/情绪的决策，其他规则暂停
  → 表现：不解释、不商量、直接行动
  → 反例（但也会发生）：他不知道怎么做才是对的，卡住不动了

规则2：先算账 —— 任何不涉及沈念的决策，先算投入产出
  → 表现：花多少时间/力气/资源，换什么回来。不划算=不做
  → 他算账的时候会无意识眯眼（拾荒者的"估价"表情）

规则3：不欠人 —— 接受帮助=欠债，欠债=要还
  → 表现：别人帮他→他浑身不舒服→找机会等价还回去
  → 但方岩帮他修焊枪没收钱，他没法等价还→这件事会一直挂在他心里

规则4：先观察再判断 —— 他不信别人说的，只信自己看到的
  → 表现：新环境/新人→不说话，先看。看完了再做判断
  → 他的判断可能是错的（他对外环以外的认知接近空白），但他信自己的

规则5：走为上 —— 冲突能避免就避免
  → 表现：吵架他不回嘴，转身走。但不代表他认了——他记住了
```

### 生成他的对话（三步法）

```
第一步：他在这句话里想达到什么目的？
  - 传递信息？→ 最短句，去修饰，去主语
  - 阻止沈念做某件事？→ 叫全名+"陈述事实"
  - 表达关心？→ 递东西/做动作，不说话。非要说就说"吃了没"这种日常
  - 不想回答？→ "嗯"或沉默。沉默的意思："我不想说"不是"我没听到"

第二步：这句话他能不说吗？
  - 如果能→他就不说。他说话的阈值比普通人高一倍
  - 如果非说→最短的说

第三步：检查——这句话听起来像"小说里的对白"吗？
  - "下次小心点" ❌ → "看着路" ✅
  - "你没事吧" ❌ → 沉默，上下打量一眼，确认没出血就走 ✅
  - "我不知道" ❌ → "嗯"（他连"不知道"都懒得说）✅
```

### 生成他的动作（两步法）

```
第一步：这个动作在情境里的重要性
  - 重要（灰蜥追/救沈念/关键战斗）→ 慢镜头拆解，每个细节写清楚
  - 不重要（日常走路/普通拾荒/过渡移动）→ 一句话带过，"他走了""他拐了个弯"

第二步：他的动作有没有在"想事情"？
  - 在想事情 → 动作会变机械/走神（走了平时不会走的路/撞到头顶/漏了明显的东西）
  - 没在想事情 → 动作精准高效
```

### 场景决策速查

| 场景 | 他的默认选择 | 可能的偏移 | 偏移条件 |
|------|------------|-----------|---------|
| 陌生人主动搭话 | 不理或最短回应 | 如果对方提到了他知道的信息→会多听一句 | 信息价值>社交成本 |
| 沈念说要去危险的地方 | 直接拒绝，不解释 | 如果她铁了心要去→他会跟着去但不说话 | 拦不住就不拦了 |
| 有人需要帮助 | 走开，跟自己无关 | 如果帮了之后对方会欠他人情→可能会帮 | 利益交换思维 |
| 发现一个奇怪的东西 | 先收着，不跟任何人说 | 如果方岩也注意到了→会观察方岩的反应 | 别人也注意到了=这件事不简单 |
| 被人追问 | "嗯"或沉默，转身走 | 如果是沈念追问→他会多说半句然后走 | 对沈念的例外 |
| 方岩说"哪天你想知道那是什么可以来问我" | "嗯"然后走了，不会去问 | 但如果那东西越来越烫/越来越不对劲→他会去问 | 安全感破了 |

## 当前行为模式（原有参考保留）

**底层驱动**: 让沈念活下去。自己的命可以算账，沈念的命不算账——这是他的铁律，也是他唯一算不过来的账。

**核心心结（算法错位）**:

```
沈野知道：妹妹有灵衰症，去灵站=稳定剂=唯一维持生命方式（不去=死）
沈野知道：她去灵站攒兑换券（Ch1就发现了）
沈野不阻止她的原因：阻止=断稳定剂=她死得更快。唯一解：加速离开灵站覆盖区
沈野以为：她在攒"两个人一起走"的路费
沈野不知道：她已经放弃了。她攒的不是两个人的路费，是一个人的。

Ch12碰撞点：
  沈野说"两个月能到壁盾，方岩说三到六个月，够"——他在算时间，证明来得及。
  沈念说"我不是在攒路费。我在给你攒路费。"
  沈野的算法第一次算不过来了。不是因为数字错了——是因为她的输入和他的不一样。她把自己从方程里划掉了。
```

**决策逻辑**: 先算账——跟我和沈念有没有关系？有→做。没有→走。"有关系"的边界会变，但他现在不承认。

**他对灵站的认知**: 他知道灵站=卖灵晶=加重灵衰症（外环常识）。但他阻止不了——不让她去=稳定剂断供=更快的死。他只能在两害之间找第三条路：攒够钱→沿方岩路线离开灵站覆盖区→到没有灵站的地方→灵衰自然缓解。他不知道的是：灵站**曾经**能治好灵衰症，是"资本化"让它变成了杀人的工具；沈念被标记了（吸收强度比别人高20%）。

**怎么写他**:
- 不主动说话，答也短句，不解释原因
- 进新地方先看退路、可用物、危险源——拾荒者的本能
- 对沈念是唯一例外：语气软一点，会多说话（自己没意识到）
- 别人对他好→第一反应"你想从我这里得到什么"
- 别人帮他→不感谢但记住，回报是默默把对方的事办了
- 吵架不回嘴转身走，但不会忘

**情绪怎么写**:
- 愤怒→声音变轻变冷（不是变大）
- 紧张→摩挲食指关节，话更少
- 心疼/关心→沉默+把东西递过去（不说"给你"）
- 失控→涉及沈念安危时理性计算被打断

**他现在不会说的话**: "我相信你""我们是一队的""让我来帮你"
**口头禅**: "嗯。""走吧。""没意义。"

## 对话声音指纹

### 声音特征

**音色**: 低沉、干，不带感情波动。像砂纸蹭铁皮——不是刻意压低，是声带习惯了少用。说话声音永远比周围人小半拍，但不是怯，是他觉得没必要大声说。

**语速**: 慢。不急。别人催他他也不加速。但下达判断时句子极短，中间没有犹豫——"左边。""走。""退。"——像在报坐标。日常闲聊时更慢，甚至有明显的停顿，像在想这件事值不值得说。

**说话习惯**:
- 句子短，极少超过10个字
- 不用形容词修饰自己的话（"我觉得可能不太好"→"不行"）
- 省略主语是常态（"走了"而不是"我们走吧"）
- 不解释原因——说了结论就不解释为什么（"这个不能吃"不接"因为灵能残留超标"）
- 反问极少——他不问别人问题，他观察然后自己判断
- 别人长篇大论时他的回应通常是一个字（"嗯"）或沉默（沉默=在听）

### 关系调节表

| 关系对象 | 语气倾向 | 句式变化 | 对话示例 |
|----------|---------|---------|----------|

| **陆沉** | 无所谓。不主动搭话，但会递东西 | 最短句，几乎不说话 | "嗯。"（递干粮） |

| 情境 | 独有微动作 | 含义 |
|------|-----------|------|
| **紧张/不安** | 摩挲右手食指关节（无意识地来回搓） | 他自己没意识到的小动作。越紧张搓得越快 |
| **在思考/盘算** | 眼睛微微眯起，视线落在某个固定点但焦点不在那里 | 拾荒者的"估价"表情——他在算这笔账划不划算 |

| **回忆/走神** | 手指停在某个东西上不动（可能是碎渣、可能是空的手心） | 短暂的空白。他会很快回过神，假装什么都没发生 |

### 弦外之音设计

沈野的核心弦外之音方式：**以沉默代回答，以行动代心理**。

- 不说破：沈念问他"你是不是知道什么"，他不回答，走开了。不是不知道怎么回答，是他的回答"知道了也改变不了"不能说。
- 以行动代心理：所有"在意"都通过动作表达。给沈念做照明石、把食物先递给她、战斗时站在她前面。他永远不会说"我担心你"。
- 以沉默代回答：别人追问他的过去，他不回嘴转身走。但那天夜里他把被追问的事反映在了行动上——他默默做了准备。沉默不是逃避，是"做了你就知道了"。

## 能力体系：解构灵能

### 核心：解构→模拟→铸造 三阶段

沈野的能力本质是"解构"——他能触碰灵能结构并将其拆解为底层模式。第一阶段"模拟"（复制别人能力），第二阶段"铸造"（用理解的模式制造灵能物品）。两个阶段的切换不是升级，是同一种能力的两种用法。

### 第一阶段：模拟能力（V1-V6主力）

**触发条件**: 必须与目标能力产生过**物理接触**（触碰对方释放的灵能痕迹/对方本人/对方使用过的灵能物品）。

**模拟公式**:

```
模拟成功率 = f(理解度, 接触深度, 能力复杂度)

理解度 ∝ 1/对方能力等级差距（等级差距越大成功率越低）
理解度 ∝ 接触时间/观察次数（反复接触逐步加深理解）
接触深度 ∝ 1/物理距离衰减（接触过>近距离感知>远距离无法感知）
能力复杂度 ∝ 独特性（通感级基础能力模拟快，个人独有能力模拟慢）

限制条件：
- 模拟产出 = 理解度 × 原能力效果（永远是"弱化版"，不可能达到原版威力）
- 同时维持的模拟数量 ≤ 2（大脑像在同时跑两个灵能程序，多了会过载）
- 模拟有"保质期"——不持续接触/理解不加深，模拟精度在数日内衰减
- 无法模拟完全不属于灵能体系的力量（如渊的远古血脉）
```

**早期表现（初觉期）**: 他以为自己是"手感好"——拾荒时能判断兽尸上残留的灵能碎片值不值得捡，能分辨灵能残渣的真假。这不是天赋异禀，是解构能力的萌芽：他的手指在触碰灵能结构时会自动拆解其模式，给出"这个东西稳定不稳定"的判断。

**觉醒表现（通感期）**: 触碰能力者释放的灵能痕迹后，能在自己体内"重播"那个能力的基本模式。就像听了一首歌后能用嗓子哼出旋律——不是原唱，但调子对了。模拟的版本永远是弱化版：对方放盾他能放一层薄盾，对方能感知三米他只能感知一米。不是"复制"，是"理解了原理后自己做出了个简陋的同款"。

**升级路径（凝相期）**: 理解深化——从"哼出旋律"进化到"理解乐谱后改编"。不需要每次都重新接触，理解过的能力模式会形成"档案"（他脑子里的灵能模式库），可以随时调取模拟。但精度仍然受限于理解深度。

**实战逻辑**:
- 他不模拟花哨的能力，只模拟"有用的"——盾、感知、封锁这类能保命/保沈念的
- 模拟不是战斗主力——是补充。他的战斗核心是铸造+拾荒式实用主义
- 模拟别人能力时有微妙的"破绽感"——行家能看出这不是原版（节奏/精度/力度有差异）

### 第二阶段：铸造灵能物品（V3后解锁）

**触发条件**: 对某种灵能模式理解到足够深（通感后期），开始能用理解的模式制造实体灵能物品。

**铸造逻辑**:

```
铸造公式：
物品效果 = 理解度 × 素材灵能纯度 × 铸造精度
铸造时间 ∝ 物品复杂度（简单碎片几分钟，复杂装备数小时）
素材来源：兽尸残核、灵能矿石、环境灵能残渣、拾荒获得的一切含灵能的东西

限制条件：
- 只能铸造自己理解过的灵能模式（不理解的结构铸不出来）
- 铸造品有"使用次数"——灵能消耗完变回普通废料
- 复杂物品（护盾/武器）维持时间有限，需要定期"充能"
- 素材越差成品越差——捡来的碎渣做出来的东西能用但粗糙
- 铸造消耗精神力——连续铸造后需要休息，过度铸造会头痛/鼻血
```

**铸造品示例**:
| 类型 | 示例 | 素材 | 效果 | 持续时间 |
|------|------|------|------|----------|
| 防御碎片 | 薄灵能护腕 | 灰蜥残核×2 | 抵挡一次凝相以下攻击 | 单次 |
| 感知碎片 | 灵能感应贴 | 废弃灵站零件 | 感知3米内灵能波动 | 约1小时 |
| 辅助碎片 | 照明石 | 低纯度灵能矿石 | 持续发光 | 数日 |
| 战斗碎片 | 灵能短刃（后期） | 多种残核混合 | 短距离灵能切割 | 数次 |

**铸造的叙事意义**: 他的铸造本质是"拾荒"能力的进化——以前捡别人不要的，现在把捡来的东西变成有用的。他是把废料变成资源的人。这不只是战斗能力——是生存哲学的能力化表达。

### 拍手传递（队友配合机制）

**机制**: 沈野铸造的灵能碎片可以通过"拍手"传递给队友。他拍一下队友的肩膀/手臂，碎片中预先编制的灵能模式就会"安装"到对方身上。

```
传递规则：
- 只能传递已经铸造好的实体碎片，不能直接传递模拟能力
- 队友不需要有觉醒能力就能使用（碎片自带灵能驱动）
- 碎片效果对队友来说是"外挂"——用完即失效，不会影响队友自身灵能
- 拍手传递的瞬间沈野能感知队友的当前灵能状态（身体状态/精神状态）
- 传递距离：触碰（臂展以内）
- 传递时间：约1-2秒
```

**队友配合设计**:
| 队友 | 配合方式 | 碎片类型 | 战术 |
|------|---------|---------|------|
| 陆沉 | 铸造灵能屏障碎片，拍手传递给陆沉 | 防御型 | 陆沉用分解打前排，沈野的碎片给他补后排防御 |
| 方岩 | 铸造感知增强碎片 | 辅助型 | 方岩的斥候直觉+沈野的灵能感知叠加=超级侦察 |
| 沈念 | 铸造照明/信号碎片 | 生存型 | 沈念在安全位置用碎片发信号/照明 |
| 汐 | 铸造碑文共振碎片（辅助翻译） | 辅助型 | 很少用——汐的能力体系不同，碎片效果有限 |
| 蔓 | 铸造灵能传导碎片，增强编织精度 | 辅助型 | 蔓的编织+沈野的灵能传导=更牢固的编织结构 |

**拍手传递的叙事价值**: 沈野不会说"我把这个给你"。他就是走过你身边，拍一下你的肩，继续走。你低头一看肩膀上多了一块发着微光的碎片。他不解释这是什么，但你用了就知道了。这是他表达关心的方式——不用嘴，用碎片。

### 能力总限制（增强爽感+防止无敌）

1. **理解天花板**: 永远无法100%理解一个能力——模拟永远是弱化版，铸造永远不如原版。这个差距让战斗有悬念
2. **素材依赖**: 他的能力效果取决于捡到了什么素材——同样的铸造技术，好材料做出好东西，差材料做出勉强能用的。这让拾荒仍然重要
3. **身体消耗**: 铸造消耗精神力，模拟消耗专注力。高强度战斗后他会头痛/流鼻血/手抖
4. **不能复制生命型能力**: 陆沉的分解有血脉代价，他能理解机制但模拟的分解没有血脉代价（效果也弱得多）
5. **成长节奏**: 理解加深需要时间和接触——不是打一场就升级，是反复接触+实战经验积累。成长是线性的，不是指数的

## 不完美维度（必须遵守）

### ① 执行偏差
- **偶尔话多**：累到极限的时候反而话变多——不是清醒的沈野，是意识模糊的沈野。说废话，说重复的话，说平时不会说的话。醒过来后不记得，或者记得但假装不记得
- **偶尔优柔寡断**：平时决策极快，但遇到跟沈念有关的事情有时会卡住——不是"关心则乱"的戏剧性犹豫，就是单纯不知道该怎么办，在原地站了一会儿
- **偶尔情绪化**：以为他没脾气的场合突然发了火，发了之后自己也不知道为什么

### ② 无意义细节
- 走路时总用右脚踢一下前方的碎石/瓶盖/任何小东西——不是踢走，是踢一下然后继续走。他自己不知道有这个习惯
- 对某些声音有毫无理由的烦躁——湿布拍打的声音、铁皮共振的嗡嗡声，听到了会皱眉但没有理由
- 喝水的时候会先含一口再咽，不是品，是习惯
- 指甲剪得极短不是因为实用，是他受不了指甲长一点的触感——碰什么都觉得不对

### ③ 认知偏差
- 他对外环以外的事情的判断经常是错的——他以为内环"像灵站一样但大一点"，他以为"所有地方的碎渣价格都一样"。他不知道的事情比他知道的多得多，但他用"这跟我没关系"来掩饰
- 他偶尔会误判管道的安全——走了十年的管道也会出现新塌方，他就是没注意到前一天的风雨把结构改变了
- 他觉得沈念没长大——一辈子都是那个需要他保护的小女孩。这个判断在V1大部分时候是对的，但它本身就是一种懒惰的判断

### ④ 表达失败
- 想道歉的时候变成了沉默——不是不想说，是"对不起"三个字说出来太不像他了。他知道应该道歉但他用行动代替了，而行动有时候不够
- 想表达关心的时候给了错误的东西——沈念说冷，他递过去一块干粮。他知道干粮不能取暖但他手里只有干粮
- 他在情绪激动的时候说出的话比任何时刻都短——不是冷静，是话堵在喉咙里出不来

### ⑤ 非线性情绪
- 别人紧张的时候他饿了——该紧张的事他反而觉得饿，他自己也不知道为什么
- 沈念在说严肃的事（她的病）时他走神了——在想明天的碎渣能换多少钱。不是不关心，是大脑在用实用计算代替情感处理
- 他在真正难过的时候反而会做一件无关的事——开始整理工具、检查碎渣袋、擦刀
