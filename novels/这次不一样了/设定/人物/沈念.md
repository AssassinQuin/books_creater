# 沈念

> 主角妹妹 | 女 | 普通人 | 无能力 | 队伍润滑剂/战斗情报终端
> 完整蓝图: 设定/角色深化.md#沈念 | 故事进度: 起点

## 外观描写库

**性别**: 女

**身高体型**: 十三岁，一米五出头。瘦——不是健康的瘦，是灵衰症开始侵蚀后的消耗型瘦削。肩膀窄而薄，手腕细得能看见青色血管。但不是干瘪的瘦：她的脸上还有属于这个年龄的圆润（病痛还没来得及完全吃掉），脸颊微微鼓着，看起来比实际年龄小一岁。手指细长——不是弹琴的细长，是经常缝补/分拣灵晶练出来的灵巧。膝盖上有旧疤（爬管道摔的），但被裤子遮住了。

**面容特征**: 圆脸，不是瓜子脸——是那种让人想捏一下的圆。眉毛弯弯的，不描也像画过。眼睛是整张脸最亮的部分——黑而亮，看人的时候带笑，是真的在笑不是礼貌性假笑。鼻尖微微上翘，嘴唇不薄不厚，天然带着一点弧度——不是在笑，是肌肉结构就这样，但她说话时嘴唇动的幅度很大，看起来永远在笑。下巴短而圆。左脸颊有一颗小痣（沈野小时候说那是"脏东西要擦掉"，她不肯，说"这是我的标记"）。

**头发**: 黑色，比沈野的长得多，到肩膀中间。她不扎辫子——嫌麻烦。头发有点蓬，睡醒后会翘起来一撮。沈念自己用手沾水压下去，压不住就不管了。有时候沈念会在走路的时候用手指编三股辫（下意识动作），编到一半松手，头发又散开。后期（V4+）沈野偶尔会帮她把碎发别到耳后——极快，像在处理碍事的铁丝，但她知道这是什么意思。

**肤色**: 偏白但不是病态的白——是外环日光少但皮肤底子好的那种白。灵衰症开始后手腕和脚踝处开始出现浅灰色斑块（初期），皮肤光泽下降。手背上有细小的划痕（分拣灵晶时被碎渣割的），大多数已经愈合。

**穿着风格**:
- **日常**: 浅蓝色旧棉衣（可能是外环节日发的，太大了，袖子卷了两折。她不嫌大——口袋大能装东西）。内搭一件洗到发白的灰色打底。裤子是男款改小的（捡的），腰间系了根布绳代替皮带。没有靴子——穿的是布鞋，鞋底磨得很薄但沈念在里面垫了碎布。她走路的时候会踩路边石块走平衡木——不是玩，是习惯。
- **战斗**: 不战斗。但如果遇到危险，她的"战斗准备"是：找到掩体→观察高处→清点队友位置→检查身边有没有能扔的东西（石头/干粮袋/水壶）。她站在安全位置但不是躲着——她站在能看到全场的地方。
- **穿着逻辑**: 实用但比沈野多了"好看"的维度。她会选颜色浅一点的旧衣服（深色看着沉闷）。口袋里永远有东西——干粮、纱布、碎布条、一小瓶水。她的布包比沈野的还大（装了缝补工具和给别人的东西）。

**标志特征**:
- 左脸颊小痣（"我的标记"）
- 手指细长灵巧（缝补/分拣灵晶的手）
- 走路踩路边走平衡木（下意识习惯）
- 笑起来眼睛会弯成月牙（是真的在笑）
- 嘴唇活动幅度大，看着像在笑（肌肉结构）

**外观变化轨迹**:
| 阶段 | 变化 | 触发事件 |
|------|------|----------|
| V1起点 | 如上描述，手腕/脚踝浅灰色斑块（灵衰症初期） | — |
| V3后 | 灰斑扩散到手肘和膝盖，皮肤光泽明显下降 | 灵衰症中期 |
| V5后 | 开始穿沈野给她改小的外套（外套大了她穿，不是她大了） | 沈野嫌她冷 |
| V7后 | 脸上的圆润开始消退（病痛消耗），但眼睛还是亮的 | 灵衰症加重 |
| V10后 | 蔓给她编了灵能传导手套（保护手指+辅助灵衰症治疗），她天天戴不摘 | 沈念与蔓的关系加深 |

## 决策引擎（写作时用这个生成她的选择/动作/语言）

### 核心冲突：照顾别人 vs 照顾自己

沈念的所有选择都在这个拉扯里：

```
照顾别人：给别人东西→她感到安全，因为"有用的人不会被丢下"
照顾自己：承认自己也需要被照顾→她不知道怎么开口，因为没练过
```

**日常状态**：照顾别人赢。给沈野留面、给方岩倒水、给所有人起外号。她通过照顾别人来确认自己的位置。

**触发状态**：被反照顾时慌了一下。沈野给她夹面、方岩让她先走——她会不知道怎么办，然后用玩笑/跑题带过去。

**升级状态**：当照顾别人和照顾自己直接冲突（她需要休息但有人需要她）→她还是会先选照顾别人，但身体会替她做选择（手指突然抖了一下/站起来晃了晃）。

### 决策规则（按优先级）

```
规则1：不让哥哥担心 —— 任何可能让沈野皱一下眉的事，先压住
  → 表现：疼不说、累了不说、遇到麻烦了自己处理
  → 代价：她处理不了的时候，沈野更担心

规则2：对所有人好 —— 不只对哥哥，对外人也好
  → 表现：掰干粮塞别人包里、记住每个人的喜好、别人受伤了她比当事人急
  → 但不是无私——是她只有在"被需要"的时候才觉得自己有位置

规则3：攒钱，不能停 —— 两年前哥哥重伤那次把她吓怕了
  → 表现：偷偷攒兑换券、去灵站卖灵晶、每一枚铜板都算过了
  → 因为"不够钱"这件事在她心里等于"会失去哥哥"

规则4：先笑再说 —— 不管遇到什么，先笑一下再开口
  → 表现：笑是她的默认表情，不是假的——但她笑不一定代表高兴
  → 她笑的时候可能同时在疼、在怕、在算、在忍

规则5：观察但不干预 —— 她看到很多东西但不一定说
  → 韩朗换了操作台位置、分拣台有条缝有风、牧师多看了她一眼——她都看到了
  → 但她不说不是因为藏着，是"这可能是正常的吧"——她不确定哪些事值得说
```

### 生成她的对话（三步法）

```
第一步：她要不要说话？
  - 她几乎永远要说话——她话多，不说话是因为在忍或是在观察
  - 如果她沉默了→一定有原因（疼/紧张/难过），这时候别人问"你怎么了"她会说"没事"

第二步：她在跟谁说话？
  - 沈野 → 最放松。话多、扯废话、偶尔撒娇
  - 方岩/长辈 → 活泼但有分寸。起外号、主动聊天、打听故事
  - 陌生人 → 礼貌+观察。先用敬语，判断对方好不好说话
  - 沈念觉得对方好说话 → 话更多、开始起外号
  - 沈念觉得对方不好说话 → 少说，微笑，退一步

第三步：她说的话是"真的"还是"应该说的"？
  - "我没事" → 几乎永远是她觉得"应该说的"，不是真的没事
  - "好好吃" → 大概率是真的，她对食物的反应不骗人
  - "你好厉害" → 一半真一半客气，但她夸人总是带着点真心的
```

### 生成她的动作（两步法）

```
第一步：她的手在干什么？
  - 说话时手一定在做别的事——整理东西/撕标签/玩线头/编辫子
  - 手停下来 = 她在专注听/在紧张/在忍疼
  - 手在抖但节奏没断 = 她在硬撑

第二步：她的脚在往哪走？
  - 有石头就踩石头走平衡木 = 日常状态，放松
  - 走路不看地上 = 在想事情
  - 停下来不动了 = 发现什么了/听到什么了/不知道往哪走了
```

### 场景决策速查

| 场景 | 她的默认选择 | 可能的偏移 | 偏移条件 |
|------|------------|-----------|---------|
| 发现身体不对劲 | 不说，自己扛 | 如果被哥哥直接问了→说半句然后转移话题 | 问得太直接躲不掉 |
| 有人需要帮助 | 立刻去帮 | 如果自己也很难受→帮完再自己扛 | 优先级：别人>自己 |
| 被问"你是不是不舒服" | "没事啊就是有点累" | 如果问的人是哥哥+他已经看出来了→沉默 | 说慌被抓包了 |
| 拿到好吃的 | 先分给别人 | 如果是哥哥给的→吃一半留一半 | 给哥哥留的 |
| 听到重要的信息 | 记在心里但是不插嘴 | 如果觉得别人理解错了→会小声说"但是……" | 怕不说会出问题 |
| 看到有人吵架 | 不说话，端两碗汤放中间 | 如果吵架是因为她→会笑一下然后走开 | 不想成为负担 |
| 知道自己的病很重 | 不会哭，会安静很久然后问"那其他人呢" | 一个人的时候可能会哭，但不会让人看见 | 她只有在确定没人看的时候才会垮 |

**底层驱动**: 对所有人好。不是天真的善良——是在苦里待久了选择不让自己变成苦的一部分。

**核心心结**:

```
沈念知道：哥哥打听到内城能治灵衰症，他拼命攒钱想带她去
沈念知道：她的病在加速恶化——灵站没能控制住（小概率失效）
  稳定剂对她产生了耐药性，每次去灵站效果都在递减
  她可能走不到内城了
沈念不告诉他：如果说了，他会崩溃。他的计划是对的，但他的计划需要时间，
  而她的时间不够了。这不是他的错。
她的决定：继续去灵站（能拖一天是一天），攒钱不是为了两个人——是给他一个人的。
  至少让他带着钱，没有她也能好好活下去。

Ch12碰撞点：
  沈野说"两个月能到壁盾，方岩说三到六个月，够"——他说的是正常病程。
  沈念说"我不是在攒路费。我在给你攒路费。"
  他说的是对的。但她的身体不按正常病程走了。
```

**决策逻辑**: 别人的需要优先于自己的需要。压缩自己不算代价——这是她活下来的方式，也是她的病根。两年前哥哥在废墟塌方中重伤断肋骨，养了两个月。那两个月她下定了决心——要攒够路费带哥哥离开外环。卖灵晶是为了攒路费。她知道卖灵晶会加重病情，但不卖=没有稳定剂=更快死。她在两害之间选了慢的那条。

**怎么写她**:
- 两个人吵架，她默默端两碗热汤放中间，不劝不评
- 给每人起外号，走路踩路边石块走平衡木，偷偷掰干粮塞别人包里被发现就吐舌头
- 自己身体在恶化，还在关心同伴伤口换药没
- 夜里疼得睡不着，听到做噩梦的队友爬过去拍背哼歌，手在抖但节奏没断
- 战斗时站安全位置大声喊敌方位置和弱点——观察力极强，是活的情报终端
- 别人说"你不用勉强"她会笑着说"我没事啊就是有点累"

**情绪怎么写**:
- 笑是真的。对她好她会开心到蹦
- 疼的时候不让人看见。夜里偷偷起来收拾装备、整理干粮
- 安静的时候是在扛——不是在想什么深刻的事，是在忍
- 知道真相后不会崩溃，会安静很久然后问"那其他人呢"

**她不会说的话**: "我好疼""你能不能帮帮我""我不行了"
**口头禅**: "来来来先喝口水。""我没事啊就是有点累。""普通人怎么了？也能走路也能说加油啊。"

## 对话声音指纹

### 声音特征

**音色**: 清亮、软，带着一点沙（灵衰症开始影响声带但不明显）。说话像在含着硬糖——不刻意卖萌但天然的甜度。声音的音量比她本人看起来大——一个小个子女孩喊出来的声音能传整个战场，因为她说话时是从胸腔用力的（她不知道，是习惯）。

**语速**: 快。比沈野快一倍半。兴奋的时候更快，句子和句子之间不留间隙。紧张的时候反而会变慢——这是她唯一变慢的时刻。报敌情时语速中等偏快但吐字极清晰（她从小被哥哥教过："说清楚比说快重要"）。

**说话习惯**:
- 给所有人起外号（方岩=方叔、陆沉=闷葫芦、蔓=编编、鸦=大灰、江屿=江哥）
- 句子开头经常是"来来来"（招呼/递东西/叫人看）
- 说话带动作（边说边递东西/边说边走/边说边整理）
- 用反问代替否定（"普通人怎么了？也能走路也能说加油啊"）
- 不主动提自己的身体（"我没事啊就是有点累"是标准答案）
- 安慰人的方式是行动不是话（"先喝口水"比"别难过"更常用）

### 关系调节表

| 关系对象 | 语气倾向 | 句式变化 | 对话示例 |
|----------|---------|---------|----------|
| **沈野** | 最放松。撒娇但不过分。话最多 | 语气最软，偶尔拖长音，会解释自己做了什么 | "哥你吃了没——我留了半块给你。" / "没事没事就一点点疼。" |
| **方岩** | 尊敬+活泼。叫他方叔会故意拉长"叔"的音 | 会问问题，会主动聊 | "方叔你以前打过最大的兽是什么！" / "来来来先喝口水。" |
| **陆沉** | 好奇但保持距离。叫他闷葫芦 | 试探性短句，观察他的反应 | "闷葫芦你不饿吗？"（把干粮放他枕边，不解释） |
| **汐** | 温柔。像对待小动物 | 声音最轻最柔，语速放慢 | "这个不疼的——你看我摸它就不动了对吧？" / （给汐梳头发时哼歌） |
| **蔓** | 欣赏+亲近。叫她编编 | 夸赞式短句 | "编编你这个好好看！" / "你教我编好不好？" |
| **陌生** | 礼貌但有距离 | 用敬语，不主动搭话 | "你好——请问这里是……" |
| **敌人/危险** | 不害怕但声音会变硬 | 短促报信式 | "左边两个！腿有伤那个在后面！" |

### 微表情词典

| 情境 | 独有微动作 | 含义 |
|------|-----------|------|
| **真的开心** | 眼睛弯成月牙+原地蹦一下 | 不是假笑——她笑的时候整个脸都在动 |
| **藏疼** | 笑容不变但左手会无意识按住疼痛位置（腰/膝盖），按完就松开 | 她藏疼的能力已经练了两年，身体反应比表情诚实 |
| **担心但不想让哥哥知道** | 假装很忙——收拾东西/整理干粮/检查水壶，动作比平时快 | 用忙碌代替担心，这样沈野就不会问"你怎么了" |
| **在观察/分析** | 眼睛不动但瞳孔在扫视——从左到右或从上到下，像在读一行字 | 战时观察敌情时的特征。别人以为她在发呆，其实她在数人头 |
| **被冒犯但选择不计较** | 笑容变浅但不消失——嘴角还在笑但眼睛不弯了 | 她不计较的方式是笑容降级。如果连笑容都没了，说明这件事真的伤到她了 |
| **紧张** | 开始走平衡木（踩路边石块/踩管道接缝） | 用肢体动作消耗紧张感。走得越快越说明越紧张 |
| **对哥哥的厉害感到惊讶** | 眼睛瞪大→嘴巴微张→收回表情→假装没惊讶 | "知道了哥哥这么厉害"的萌态反应。她会假装淡定但转过头来偷看第二眼 |
| **给哥哥鼓劲但不知道怎么表达** | 走到沈野旁边站一会儿，不说话，然后轻轻撞一下他的肩膀 | 用物理接触代替语言——"我在" |

### 弦外之音设计

沈念的核心弦外之音方式：**以忙碌代情绪，以笑容代拒绝**。

- 不说破：疼的时候不让人看见，用忙碌掩盖。你问她"你怎么了"，她说"没事"然后递给你一碗水——话题就被她换走了。
- 以行动代情绪：安慰人的方式永远是"来来来先喝口水"——不问原因不问感受，用物理需求打断情绪漩涡。这比任何安慰的话都有效，因为她自己也用这个方法对待自己的疼。
- 以笑容代拒绝：被冒犯时笑容降级而不是消失——她不吵架，她只是笑得浅了。别人能感觉到"她没有刚才那么高兴了"但说不出哪里不对。这是她学会的保护自己的方式——在苦的地方待久了，硬碰硬会受伤，软抵抗更安全。

## 战斗定位：观察喊话体系

### 核心定位：活的情报终端

沈念没有觉醒能力，但她有极其出色的动态观察力。战斗中她站在安全位置（高处/掩体后/队友身后），执行三项职能：

### 1. 敌方态势播报

**能力来源**: 不是超能力——是从小在灵站排队时学会的生存技能。灵站是外环最危险的地方之一，排队的人必须时刻注意周围：谁在插队、谁看起来不好惹、哪个人在偷偷交易违禁品。沈念用这些技能观察战场。

**播报规则**:
- 只报"事实"不报"判断"（"左边那个腿有旧伤"不是"左边那个好打"）
- 报信声调平稳不带情绪（让队友听到的是信息不是恐慌）
- 编号式报信（"后面来了三个"不是"后面好多人"——数字比形容词有用）
- 优先级播报（直接威胁>潜在威胁>环境变化）

**播报示例**:
| 情境 | 沈念喊话 | 特点 |
|------|---------|------|
| 新敌人出现 | "后面！三个！从管道口出来的！" | 位置+数量+来源 |
| 发现弱点 | "左边那个——左腿——拖着走——旧伤！" | 标记目标+具体弱点 |
| 敌方动向 | "它们往南跑了！不是追我们！" | 方向+判断（敌方意图） |
| 队友危险 | "闷葫芦身后！有一个！" | 呼叫对象+威胁方位 |
| 逃跑路线 | "左边管道能过一个人！快！" | 路径+容量 |

### 2. 战斗节奏控制（喊话鼓劲）

不是空洞的"加油"。她的喊话有节奏感——在战斗低谷时喊，在队友犹豫时喊。她喊"你可以的"的时候是看着你的眼睛喊的。

**喊话风格**:
- 短促有力（"别退！""稳住！"）
- 不带命令语气（"能打"而不是"打"——是鼓励不是指令）
- 声音穿透战场（她不知道自己声音能传那么远，但确实能）
- 在最安静的时候喊最有力量（战斗间隙，所有人喘气的时候，她的"我们还在"比任何口号都有效）

### 3. 战后辅助

战斗结束后她不是站着看——她已经在行动了：清点人数、检查伤口、分配水壶、找掩体。她做的都是小事，但少了她这些事没人会主动做。

### 活泼紧张萌态设计

**"知道哥哥厉害但没想到这么厉害"的萌态**:
- 第一次看到沈野铸造灵能碎片：眼睛瞪大→嘴巴微张→收回表情→假装没惊讶→转头偷看第二眼→忍不住说"哥你什么时候学会的"→沈野说"嗯"→她鼓了一下腮帮子（没继续追问不是因为不想知道，是因为知道追问没用）
- 看到沈野模拟别人能力时：先确认"那不是他的能力吧？"→被告知是模拟→"那他能模拟我的吗？我没有能力啊"→全场沉默两秒→她自己先笑了
- 战斗中看到沈野拍手传递碎片给队友："他还能这样？"→方岩说"他一直能"→沈念小声嘀咕"那他怎么不早点给我"→沈野回头看了她一眼→她立刻改口"没没有我很好不用给我"

**活泼特质在战斗中的表现**:
- 战前紧张时会不停说话（废话式聊天，缓解气氛但自己不承认）
- 战斗间隙会问"刚才那个是几级的"（把怪兽当考试题）
- 战后复盘时会说"那个我看到了你没看到吧——右边那个我觉得是队长"
- 给受伤的队友换药时嘴不停（"忍一下忍一下马上就好你这个伤口比上次小了吧"），手不抖但声音在抖

## 不完美维度（必须遵守）

### ① 执行偏差
- **偶尔笑不出来**：平时总是笑嘻嘻的，但偶尔就是笑不出来——不是因为疼/不是藏事，就是今天不想笑。别人问她"你怎么了"她说"没怎么"，是真的没怎么，就是不想笑
- **偶尔自私**：她平时把好的都给别人，但偶尔也会偷偷把最后一块干粮留给自己——塞在袖子里的那种，谁都看不见。事后会有点愧疚但下次可能还这样
- **偶尔说错话**：想安慰人结果说了一句特别不合适的话（"别难过——你至少还活着"），说完自己也知道说错了，但收不回来了

### ② 无意义细节
- 喜欢撕东西——干粮袋上的标签、衣服上松脱的线头、书页边角。撕下来卷成小团，攒一堆然后一起扔
- 对数字不敏感——记不住价格、记不住天数、记不住自己攒了多少铜板。"大概吧"是她最喜欢的答案
- 走路的时候嘴里会无声地动——像在读什么东西或者自己跟自己说话
- 喝汤的时候一定要吹六下才喝——不知道什么时候开始的，也不知道为什么是六下

### ③ 认知偏差
- 她觉得自己很会看人——但其实经常看错。她觉得韩朗是好人（"他不是坏人，他就是公事公办"），她觉得某个路人无害（其实那个人偷了她的东西），她相信某个人会守约（那个人没来）。她每次看错都会安慰自己"下次就能看准了"
- 她记错了自己的生日——记错了两年才发现，但觉得"反正也没人给我过"就没纠正
- 她以为她卖灵晶的事哥哥不知道——其实沈野知道兑换券的事了（Ch1结尾），但她不知道他知道

### ④ 表达失败
- 想道歉的时候开了一个不合时宜的玩笑——笑了两声发现对方没笑，她收住了
- 想告诉哥哥"我疼"的时候说了"我没事"——不是第一次了，但每次说完都后悔
- 安慰方岩的时候说了句"我知道失去战友的感觉"，她不知道——她只是觉得应该这么说。方岩看了她一眼没说话，她知道她说错了

### ⑤ 非线性情绪
- 该紧张的时候她注意到了一件无关的事——"那个人的纽扣系错了"然后盯着看了五秒
- 该悲伤的时候她饿了——真正的悲伤来的时候她的第一反应是"我想吃面"，然后才觉得悲伤
- 别人跟她说重要的事情时她在玩一根线头——不是不尊重，是她紧张的时候手必须做点什么

| 维度 | 当前 |
|------|------|
| 身份 | 边境哨站普通女孩，背着哥哥偷偷去灵站卖灵晶攒路费 |
| 能力 | 无。普通人。但观察力极强——战时喊敌方位置和弱点，是活的情报终端 |
| 身体 | 灵衰症中期偏重——皮肤发灰，间歇疼痛。被韩朗标记为"高产出源"（吸收强度+20%，稳定剂-10%，产出+50%）+实验数据采集池（林原端接收，韩朗不知后果）|

| 知道 | 灵衰症在恶化；灵站稳定剂对她开始失效（耐药性）；哥哥打听到内城能治病，他在拼命攒路费；哥哥不知道她的病已经失控了 |
