# 方岩 完整人物档案

## 一、人物设定

### 1.1 身份与背景

**壁盾军团15年斥候**——不是普通士兵，是军团的"眼睛"。十五年间绘制了边境最准确的手绘路线图，标记了每一个据点、水源、危险区、异灵出没频率。

**V1状态**：刚退役不久，在外环聚落附近混日子——修灵能路灯（手艺人身份做掩护），实际在暗中调查几个月前那件事。他沿着线索一路追过来的，每个遇到相似条件的地方就停下来查，发现这个聚落有相似条件，于是驻留下来暗中调查。

**几个月前**：他的斥候小队12人全军覆没。他一直以为是自己的判断失误。后来查出真相——军团高层延迟了增援，因为灵枢要求控制兽潮信息。**那12个人不是被兽群杀的，是被信息差杀的。** 这条线从V1贯穿到V9。

**核心驱动**："12个人不是白死的。打仗他不怕，怕的是打了一场没意义的仗。"

### 1.2 外貌特征

四十一二岁看着像五十。国字脸、粗糙偏黑、深纹、灰白杂半的粗眉。左脸颊一道四厘米旧疤（那次任务的纪念品），左耳有一道旧裂口（灵能碎片划的）。手指粗短，指节全茧——握刀的痕迹。膝盖有旧伤，走路时右腿有极微的拖。

穿着总是一身旧壁盾军装改的——肩章拆了，徽章磨得快看不清。腰间一把标准灵能短刀（壁盾制式）。口袋永远有手绘的边境路线图，用铅笔更新，笔迹潦草但精确。

### 1.3 性格内核

**核心冲突**：教人活着 vs 替人死

```
教人活着：训练、指路、骂人、修装备、把年轻人推到他够得着的高度
替人死：几个月前，12个人在他眼前死了，他活着回来了。这件事是他所有选择的底色
```

**决策规则（按优先级）**：
1. **年轻人不能死在我前面** → 骂得越凶＝越担心
2. **真相可以等，命不能等** → 查了几个月的真相可以再等一天，但眼前这个人受伤了得先处理
3. **不信命令，信自己的判断** → 别人说"前面安全"他也要自己查一遍
4. **话只说到七分** → 不说"因为右边有坑"，只说"左边"
5. **沉默代答案** → 不想回答→沉默。不知道→沉默。太难过了→沉默

**底层逻辑**：他不是不会社交——是只用一种语言活着：**以吼叫代关心，以沉默代伤痛**。

他只会打仗，不懂别的。退伍之后不知道干什么——没有家（老婆早离了），没有想做的事。他最想做的事（让年轻人不用打仗）恰好是他唯一能做的事的反面——教打仗。他恨打仗因为他见过太多死人，但他只会打仗所以他继续打。他不是在恨和爱之间纠结——是只有一种语言的人用这种语言说所有的话。

**与沈念的关系底色**：沈念让他想起兽潮中死的4岁女儿。他照顾沈念不全是投射——投射给了开始的动机，真实关心让动机持续。当投射消退之后，关心还在。

## 二、能力体系

### 2.1 核心能力：灵能感知地形（通感级）

| 维度 | 内容 |
|------|------|
| **感知逻辑** | 地形结构 → 灵能浓度分布 → 感官捕捉浓度差异 → 大脑自动建模 → 实时3D地形图 |
| **范围** | 常态50米，壁盾领地高浓度环境可扩至500步 |
| **限制** | 精度有限（知道大致结构但不知细节）；灵能干扰区失效；通感级无法突破 |
| **本质** | 不是战斗型能力，是情报型——15年经验数据库比能力本身可靠百倍 |

### 2.2 斥候附加技能

| 技能 | 表现 |
|------|------|
| 生存判断 | 闻灵能味道判断兽潮将至、听地面震动判断异灵数量和类型 |
| 急救 | 止血、固定骨折、处理灵能灼伤——够用 |
| 路线规划 | **全书最强**——能在复杂地形中找到最快最安全的路径 |
| 轻武器 | 灵能短刀——中规中矩，没有特长 |
| 夜间行动 | 全黑暗保持行动能力。睡觉半醒 |

### 2.3 能力弧线

| 阶段 | 卷 | 能力状态 | 关键事件 | 心理变化 |
|------|-----|---------|---------|---------|
| **起点** | V1 | 通感级地形感知+15年经验 | 兽潮中救沈念、被沈野救 | "能力不重要，经验才重要" |
| **稳定** | V1-V9 | 感知范围10-30米，逐步适应外环低浓度 | 追牙→归队→壁盾领地感知倍增 | "老办法最可靠" |
| **过载** | V6 | 高浓度区短暂"瞎了"三秒 | 北境追异灵进化异常时 | 第一次发现能力有天花板 |
| **禁用** | V10 | 禁地边缘感知完全失效 | 尝试追踪陆沉时 | "这地方不对" |
| **收束** | V14 | 感知衰退但经验更丰富 | 退役——巡逻日志留在了壁盾旧据点 | "12个人不是白死的" |

**方岩的核心叙事意义**："普通人靠经验碾压觉醒者"的活例子。通感级最低档，但价值远超凝相级——15年的经验数据库比任何能力都可靠。说明在这个世界里，能力不是唯一的价值。

## 三、全卷剧情线

### V1 兽潮——出场与动机建立

**出场**：外环聚落修路灯的老兵。方岩和沈野之前就有过一些交集——认识但不熟。方岩知道沈野有个妹妹在生病，沈野知道方岩是壁盾退役的（从他绳结手法和走路习惯猜的）。

**关键场景**：
- 修灯时递新绳给沈野（注意到他的旧绳磨毛了）
- 兽潮中方岩在废墟里把被砸到的沈念拖出来——沈野看到了这一幕
- 方岩被异灵逼到死角时，沈野用残片扔出去停住异灵——救了方岩
- 只有在这之后，方岩才画路线图给他们："你救了我妹妹，我救了你——这路你自己走比我带着走有用。"
- 兽潮中迎着方向走（不是跑，是在看）→发现牙级甲壳
- 出示十二张壁盾标记纸——兽潮方向与灵站共振设备角度完全对应。"终于来了"
- 碎罗盘残块放在石头上："有些事没做完"
- 老猎人之死后，方岩说"到了"
- 画一整夜路线图：十六站，从外环到边境镇。训练指南写在背面
- ***碎裂*\*：给沈野碎罗盘最大块残片："到边境镇找陈启明。壁盾的旧人。说我的名字。"
- 选择不走——"你的路跟我的路不一样"
- 远处山坡上送行

**卷末状态**：从旁观者变成"带路的人"。给出路线图和线索，选择留下查12人真相。与沈野沈念的关系从"认识但不熟"变成"互相救过命的交情"。

### V2 边城——归队与推理成型

**关键事件**：
- D9离开去追踪牙的灵能回路（旅途不全在场）
- 铁谷镇补给点留壁盾暗号（猎人网络15天传递）
- **冻湖归队**（Ch029）：带回两个关键证据——牙体内有引导装置残留纹路；外环灵站共振设备换过核心部件
- 教沈野标记系统和战斗基础
- **方岩推理**（Ch064）："灵站管网弧形排列以禁地方向为焦点——灵站在'收走'环境中的灵能，弧形聚焦=指向禁地方向。有人活了几个世纪=灵枢特殊能力。"**部分正确（确实有焦点），但关键错误（以为是一群人，非一个人）**

**卷末状态**："灵枢创始人四百年没换过"的推理成型。调查线正式启动。

### V3 惨败——第一次正面冲突

**关键事件**：
- 柳陌追杀时做仲裁收江屿入队（"用他。用完再说。"）
- 找废弃研究所路线（发现第二块碑文）
- 三银币付猎人报酬
- 绝境中找到教会驿站做紧急治疗
- **分兵决策**（全书最关键的结构性决定）：
  - 方岩+陆沉：留边境线，方岩走壁盾军团线联系旧部
  - 沈野队+沈念+汐+江屿：向自由城
- 分兵告别："别死。""你也是。"——他们说过的最长一段话
- 外环追踪牙来源→发现灵能驱赶装置残骸→判断"灵枢不可能在外环部署精英"
  - **这个判断让他低估了灵枢渗透深度**（V7认知推翻的前置条件）
- 走访老猎手收集兽潮路径口传记录
- 发现赵铁山签了灵枢秘密协议——对壁盾的感情开始复杂化

**卷末状态**：双线叙事建立。方岩从"追线索"变成"主动调查"。对壁盾的信任出现裂痕。

### V4 灵站——内线网络建立

**关键事件**：
- 铁谷镇中转，与陈启明会合
- 陈启明认出驱赶装置残骸频率模式——"和灵站共振密纹同源，但更复杂。像是共振密纹的'父版本'。"
- **内线正式建立**：方岩提供外环数据，陈启明提供研究院内部数据
- 用地形感知精确定位铁谷镇灵能管线盲区，建立安全通讯路径
- 用教会数据做灵衰症分布热力图（V12证据）

**卷末状态**：从"单人调查"到"数据内应网络"的构建者。陈启明成为V2-V7最重要的内部情报源。

### V5 星火——壁盾情报网

**关键事件**：
- 走壁盾内部快速通道提前抵达自由城（D2）
- 通过壁盾情报网定位星火社据点
- 外围观察一天确认不是灵枢钓鱼
- **确认装备序列号LC-NX开头＝灵枢技术部内部批次**
- 参与A线（灵枢中继站潜入）——"灵枢拼命护着的地方更值得看"
- 发现中继站地下管线通道作为撤退路线
- 发现异灵从禁地方向**逃跑**（不是攻击）
- "他是拿命在传这些东西"（陈启明的解密数据）

**卷末状态**：从"被动追线索"到"主动预判方向"。壁盾情报网成为团队最重要的外部信息源。

### V6 多线——壁盾线主视角（全书方岩最重要的个人卷）

**关键事件**：
- 带蔓走壁盾内部快速通道到北境要塞
- 蔓沿途修复两处灵能路标——方岩在巡逻日志记"编织者修复效率：常规修理的十倍"
- **见赵铁山**——签了协议的老人
- **12人照片墙**：第三排第五张到第十六张。几个月前刚死的人。一个一个念名字，念到第十六张时停了。
- **地形感知倍增**（回到壁盾领地高浓度环境）：范围百步扩到五百步，帮壁盾重绘灵能地图
- **发现异灵进化异常**：靠近禁地方向三个月扩大40%，个体平均体积增大——自然进化需要几十年，这不是自然
- D9地形感知短暂过载：高浓度区"瞎了"三秒
- **巡逻队长者闲聊**——"灵枢那个创始人据说四百年没换过"
  - 来源：壁盾初创时期一个斥候追踪"灰袍人"到灵枢核心区外围，二十年后在同样年会上看到同一个人没有变老
- 与焱交手（D13）：险些被杀，确认焱有"指挥能力"——不是普通角
- **D10信息交叉①**：向自由城传异灵进化数据

**卷末状态**："最重要错误结论"的参与推导者。手上有"四百年没换过"的证据但不够完整。对赵铁山的感情开始复杂化。

### V7 灰色——暗线确认 + 体系崩塌

**方岩最重要的暗线**——与江屿的侦探调查：

1. **D2屋顶谈话**：方岩找江屿拿出V6巡逻日志——"灵枢创始人四百年没换过"
2. **D3巡逻路线对比**：外环正常轮换，内环七年一字不差
3. **D6年报笔迹对比**：三年年报签名叠在一起完美重合。把四百年前的创建者笔记签名影印件叠上去——四个签名重合。"一个人的写字习惯能四百年不变吗？"
4. **约定暂不公开**——证据链不够完整，且暴露可能触发不可预测反应

**其他关键**：
- D5凌晨地面低频振动——"不是地震，是从更远的地方传过来的，像什么巨大的东西翻了个身"
- 方岩把D5异常记入巡逻日志备注——"兽潮频率对不上灵枢触发器"
- 废弃传教站发现教会比灵枢早12小时到达（教会一直在监控）
- 蔓编织丝线桥——方岩踩上时发现脚下纹路在微调自适："这不是桥，是活的网"
- 对比蔓的编织和装备匠的灵能装备："一个是活的，一个是死的"——灵能本质认知萌芽
- D15冲突：认为"应该把星火社真相公布"
- D16屋顶与沈念夜话——"不是做。是还没做完。"
- D17握住蔓编织的短刃——丝线根据握力、角度、手温自动调整。劈了一刀切穿两层护甲

**卷末状态**：暗线证据到手但不公开。开始理解"灵能不是工具，是某种有意愿的东西"。

### V8 双星——废墟调查

**关键事件**：
- 穿越兽潮区时注意向导异常：不踩碎石、不流汗、不怕兽潮声（实际是渊本人，B2不写明）
- 通过壁盾旧战友确认双星城废墟低频灵能脉动振幅增大15%
- 21天周期——灵枢灵能循环完整周期
- 参与公式墙解读（三方协作）
- 联系壁盾情报部预警"不止一方在查你们位置"

**卷末状态**：壁盾情报网做后盾。路线图和经验救了全队。

### V9 断裂——V1-V9最长配角弧线收束

**方岩的弧线收束卷**：

- "做完这件事我就不欠了。"——12人召回壁盾北境

- 认出墙上两个名字是壁盾军团曾经救过的人（韩朗留下的"高产出源"名单）
- 废弃中转站反击战：预判敌人进攻路线（老兵经验指挥战斗）
- **目睹沈野做第五版灵能压制器全碎**，捡碎片掂了掂：**"你确定这是压制器不是加压器？"**
  - 这个瞬间：沈野突然意识到方岩不是"他雇来的老兵"，是"会帮他捡碎片的人"
- 全程不说话把灵枢巡逻路线图递给江屿（江屿被召回灵枢前）
- 做鸦中继通讯的节点（地形感知做接力）
- 与赵铁山对话揭示壁盾与灵枢"合作协议"的隐藏条款

> **V1-V9弧线收束**：从V1兽潮中救沈念、被沈野救的外环老兵，到V9用路线图和经验救全队的守护者。12个人几个月前刚死——他的每一次选择都在证明"不是白死的"。

### V10 血脉——守边境抉择

- 焱的脉冲攻势下选择守边境（陆沉v.s.边境）——"陆沉有能力照顾自己，但如果边境防线崩溃所有人都会死。"

## 五、与其他角色的镜像设计

方岩没有直接的跨代镜像（陆沉↔封绝、沈野↔虞渊那种），但他作为"普通人靠经验碾压觉醒者"的定位，是全书最反"能力至上"的角色。他的存在证明了：

> **能力不是唯一的价值，经验、判断力、生存本能同样重要。**

他的"12人真相"线是全书最朴素的弧线——没有血脉觉醒、没有超级事件，只有一个老兵沿着线索一个城一个城查过来，花了9卷时间查清楚几个月前战友为什么死，然后安静地接受了"知道了也改变不了什么"，继续保护活着的人。

## 六、写作约束（不做的）

- ❌ **不做方岩的煽情独白**——他的弧线收束用行为和一句话完成（"做完这件事我就不欠了"），不铺开回忆杀
- ❌ **不做方岩线的独立章节**——他的暗线在主线事件的缝隙中推进（D2屋顶谈话、D3巡逻路线对比、D6年报笔迹），不单独割裂成"侦探篇"
- ❌ **不做方岩的内心独白**——他的心理通过行为传达（沉默、摸左臂、做具体的事），不直接写"他在想什么"
- ❌ **不做方岩的大道理**——他只说该做什么，不说为什么该做。"为什么？因为会死。"这就是他的全部解释
- ❌ **不做"老兵经典台词"**——"我经历过更糟的"他不会说。他只会沉默。"听我的没错"他不会说。他会直接说该怎么做
