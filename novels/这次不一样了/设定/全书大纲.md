# 《这次不一样了》全书大纲

> **版本**: v2.0 — 基于 novel-planner v2 方法论重设计
> **核心公式**: 因为世界观规则压迫 → 所以角色被迫选择 → 逼出不可逆后果 → 留下的定时炸弹
> **主题**: 小人物的选择能不能打破400年循环？"这次不一样了"=终极反讽

---

## 一、全书核心设计

### 1.1 核心冲突

```
世界观刑具: 灵能吸收器→灵衰症→灵枢垄断治疗→穷人在循环中等死
角色两难:   沈野"只护妹妹"的哲学 vs 世界比他想的复杂
终极悬念:  兽潮为什么不正常？妹妹的病到底是什么？
```

**终极方向**: 沈野从"只管自己和沈念"到"算不过来的事，就一起扛"——不是英雄觉醒，是被现实一步步逼出来的范围扩大。

### 1.2 主角成长弧线（5个阶段）

| 阶段 | 卷 | 沈野状态 | 关键变化 | 对应的世界认知 |
|------|----|---------|---------|-------------|
| **1.拾荒者** | V1 | 只算自己→算不过来了 | 妹妹发病暴露了他的计算盲区 | 外环=全部世界 |
| **2.队员** | V2-V4 | 被迫接受队友→开始信任 | 第一次被人救、第一次信任陌生人 | 世界比外环大 |
| **3.反抗者** | V5-V7 | 相信反抗→反抗也是假的 | 星火社崩塌=第二次被世界骗 | 没有正义的一方 |
| **4.独立者** | V8-V11 | 自己做决定→扛别人的决定 | 禁地之路、F1真相、纪元揭示 | 历史是循环的 |
| **5.选择者** | V12-V14 | 理解虞渊→走自己的路 | 第三次认知推翻→终局选择 | 循环可以打破 |

### 1.3 明暗双线全局规划

**明线**: 沈野团队从外环出发→求医→发现真相→反抗→禁地→打破循环

```
V1            V2-V3          V4             V5-V7           V8-V11         V12-V14
出发求医 ─→ 组队+第一块碑 → 灵衰症真相 → 加入反抗失败 → 禁地+纪元   → 终局+打破
```

**暗线**: 四条贯穿全书的隐藏线索

| 暗线 | 起点 | 终点 | 推进方式 |
|------|------|------|---------|
| **D1 虞渊七重铺陈** | V2(封绝记忆闪过) | V13(逐一收束) | 每1-2卷揭示一层 |
| **D2 四纪元闭环** | V2(第一块碑) | V12(最后一块碑) | 每卷1块碑文碎片 |
| **D3 三次认知推翻** | V4 | V12 | 推翻不=补充信息=推翻旧理解 |
| **D4 鸦的进化** | V1(受伤弱小) | V14(叫沈念名字) | V1-V14全程渐进 |
