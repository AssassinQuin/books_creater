# 人物能力设定方案 v2

> 基于v3.2 Phase 3验证 + 特异能力盘点调研库
> 设计原则：能力强≠权力大≠有用；壁盾=普通人+装备；不是都和灵能挂钩
> 调研来源仅做设计参考，能力名称和机制按灵能世界观独立设计

---

## 一、能力体系二层结构

| 层级 | 描述 | 代表 |
|------|------|------|
| **觉醒层** | 灵能七级（初觉→通感→凝相→共鸣→蜕变→域场→灵源）。普通能力者 | 沈野、陆沉、汐、蔓等 |
| **普通层** | 无觉醒。靠灵能装备/武器/工具参与战斗。壁盾军团的主力 | 大部分人 |

**例外**：虞渊和渊的能力远超七级上限，但不单独分类——他们就是极少数站在这套体系最顶端的强者。虞渊的灵能同化让他和灵能本身融为一体，渊的血脉比灵能更古老。他们不是"超越灵能"的存在，而是灵能七级体系无法量化的极端个体。

**壁盾军团战斗体系**：
- 普通士兵 + 灵能武器 = 统一灵能状态（不是觉醒但能用）
- 能力者军官 = 战术核心（不是神，是厉害一点的队友）
- 团队作战 > 个人能力
- 方岩退役原因：初觉级太弱，不够当军官，但斥候经验让他比军官更有用

## 三、新增能力设定

### 3.1 灵枢高层

**钟衍 — 灵枢技术总监**
- **能力**：灵能共振解析（共鸣干涉）
- **体系**：觉醒层，共鸣级
- **机制**：他的感知方式是"共振"——接触任何灵能结构，能在自己体内复现其振动模式。不是复制能力（那是沈野的拓印），而是"听到"灵能的"声音"。灵能设备运转正常不正常，他摸一下就知道。灵枢的灵能共振协议参数，他能"听"出哪些超了安全阈值。这种感知让他在灵枢内部像活体检测仪——谁在调参数、谁的灵能波动异常、谁在隐瞒什么，他都不需要刻意探查，站在旁边就"听到"了
- **上位逻辑**：他是技术总监不是因为战斗能力强，是因为没有人比他更懂灵能设备的"声音"。虞渊需要这种人维护灵站网络——但钟衍能"听"到的东西比虞渊希望他知道的多得多
- **性格匹配**："我只是执行层"——他的能力也是被动的。他不主动探查，但无法关闭感知。就像他在密钥和作业之间无缝切换，他的能力也在"系统正常"和"系统在杀人"之间无缝切换。两种声音同时存在，他选择只听一种
- **灵感来源**：被动式全时感知 + 灵能结构解析 + 无意识最优解计算
- **弱点**：零战斗能力。纯粹感知/解析型。"听到"敌人来了不等于能打
- **视觉锚点**：解析时手指不自觉地在桌面上敲击——频率和他感知到的灵能共振一致

**柳陌 — 灵枢安保精锐**
- **能力**：灵能印记刻录
- **体系**：觉醒层，凝相级
- **机制**：她能将自己的灵能"刻"进目标体内——像打烙印。被刻印的人，她永远能感知位置和状态（活着/受伤/灵能波动）。印记不会消失，距离没有上限。进阶用法：她能在自己身体上刻录多种印记模板，临时调取某个被刻印者的灵能波动特征来伪装自己——骗过灵能检测门、混进不同的灵能区域。本质上是"记录+追踪+伪装"三位一体
- **性格匹配**：她的能力就是"不会忘记"——刻过的印记永远在。和她对灵枢的忠诚一样不会改变。江屿叛逃那天，她在他身上刻的印记到现在还在。她能感觉到江屿在哪个方向、心跳快不快。这是她追杀的动力也是她的折磨——她无法停止感知一个她认为"不够强"的人活得好好的
- **上位逻辑**：灵枢最完美的追杀工具——被她刻过的人永远跑不掉。但这也是虞渊控制她的锁链——她自己身上也有虞渊的印记（她不知道），所以虞渊随时知道她在哪
- **灵感来源**：灵能信息记录+调取 + 精神标记永久追踪 + 锁定而非隐藏
- **弱点**：刻印需要近身接触（臂展距离内），刻录过程约3秒，实战中很难对高手完成。只能追踪不能战斗——遇到凝相以上能力者打不过，只能跑和跟踪
- **视觉锚点**：刻印时掌心浮现和目标灵能同色的纹路；追踪时瞳孔变成被追踪者的灵能颜色

**韩朗 — 灵枢战斗高层**
- **能力**：灵能固化（灵能锚定）
- **体系**：觉醒层，共鸣级
- **机制**：他能让灵能"凝固"——不再流动，变成实体。自己的灵能可以固化为盔甲/盾牌/台阶（攻防一体）。别人的灵能一旦被他的灵能触碰，也会凝固——能力者发现自己"放不出技能"因为灵能被冻住了。不是"无效化"（灵能还在），而是"锁住了"（灵能出不来）。他自己的灵能不受影响——他是唯一能在自己固化场内自由行动的人
- **上位逻辑**：灵枢需要"定海神针"——战场上他往那一站，周围灵能变成他的地盘。能力者在他面前全部降级。不是因为打不过，是因为"动不了"。这种人在灵枢内部政治中也一样——不是最有野心的，是最难被搬动的
- **灵感来源**："归零"弱化为"凝固"（不是消除灵能而是锁住）+ 灵能实体化攻防 + 触碰范围内的绝对主场
- **弱点**：固化场范围有限（约10米半径），无法同时保护多人。对物理攻击无效——灵能被冻住的人照样能拿刀砍你。纯粹力量型对手是他的天敌
- **视觉锚点**：固化场内空气像凝固的琥珀，灵能变成半透明晶体

### 3.2 教会

**沈鹤 — 教会年轻祭司**
- **能力**：灵能回响感知
- **体系**：觉醒层，通感级（但在教会体系内已经是高层潜力）
- **机制**：他能听到灵能的"回响"——灵能经过的地方会留下残余波动，像声音的回音。碑文存在了几百年，每一代接触碑文的人都留下了情感波动的残余——恐惧、虔诚、怀疑、绝望。沈鹤能听到这些回响。碑文对他来说不是冰冷的石头，是几百年来无数人情感的"录音机"。这让他能判断碑文上哪些部分被人为打磨过（回响断层）、哪些部分是原始的（回响连续）
- **性格匹配**："用科学方法验证信仰"——他的能力就是听到"真实"。碑文的回响不会说谎——它记录了每一个接触者的真实情感。教会打磨碑文的文字层可以骗过普通人，但骗不过回响——沈鹤能听出"这段碑文的文字和回响不匹配"，说明文字被改过。这就是他质疑的起源：信仰告诉他碑文是神圣的，回响告诉他碑文被改过
- **V6帮助汐的原因**：他的回响感知告诉他碑文有"更深层的东西"——不只是被改过的文字，还有一层他听不到的频率（碑文的灵能层，超出了他的感知范围）。汐能翻译碑文，沈鹤希望汐翻译时他能在旁边听回响，拼出完整的真相
- **灵感来源**：预感真伪 + 读取灵能残留情感 + 探测灵能遗迹而非活人
- **弱点**：离开灵能遗迹（碑文/古战场/旧灵站）能力几乎没用。战斗能力为零。回响信息是情感的，不是事实的——他能听出"有人恐惧过"，但不知道"恐惧什么"
- **视觉锚点**：接触碑文时手掌微颤，像在抚摸琴弦感受余震

### 3.3 壁盾军团

**赵铁山 — 壁盾军团长**
- **能力**：灵能共鸣·体魄共振
- **体系**：觉醒层，凝相级
- **机制**：他的灵能不外放——全部内循环。灵能在体内走经脉，和肌肉骨骼产生共振，让身体本身的物理性能超越常人极限。不是"灵能覆盖在拳头上"（那是灵能武器的用法），是灵能从内部改造了身体的物质结构。他的拳头打出去没有灵能波纹、没有特效，但力量和速度是普通人的十倍。壁盾的灵能武器体系他最熟——他能用最朴素的灵能步枪打出共鸣级的效果，因为他的身体和武器之间形成了共振回路
- **叙事逻辑**：壁盾"能力者只是厉害点的普通人"——赵铁山就是活例子。他的能力没有特效、没有花样，没有肉眼可见的"超自然"。打起来就是又快又硬又持久。壁盾新兵看到军团长用的武器和他们一模一样，但赵铁山能用同一把枪打出他们十倍的效果。不是因为武器不同，是因为人和武器之间的共鸣不同
- **"不知道"的悲剧性**：他有能力也有权力知道真相，但选择了不知道。方岩（弱能力者）反而追查了。强能力+大权力+零贡献。他的身体改造能力让他能活过无数次兽潮——活得越久，不知道的事情越多
- **灵感来源**：力之奥义的朴素版（身体本身的力而非外放力场）+ 看似最弱实则最扎实 + 持续性身体解锁
- **弱点**：纯近战，无法应对远程灵能攻击。灵能内循环有时间限制——持续战斗4小时后身体开始排斥自身灵能（过载）。他没有远程手段，没有特效，没有领域
- **视觉锚点**：激活时皮肤下出现淡金色纹路——不是灵能外放的光，是灵能改造身体结构的痕迹，像肌肉纤维被重新编织

### 3.4 研究院

**林原 — 研究院激进派首席**
- **能力**：灵能结构透视（解剖之眼）
- **体系**：觉醒层，通感级
- **机制**：他的视觉和常人不同——他看到的不只是物体表面，而是灵能结构。活人在他眼里是一套灵能循环系统（经脉走向/灵能沉积/灵衰症侵蚀位置）。灵能设备在他眼里是透明的——每个零件的灵能传导效率、哪里磨损、哪里过载，一目了然。让他极度擅长设计实验——他直接"看到"灵衰症在血管壁上的沉积模式，然后精确计算"五和一"的数据
- **叙事逻辑**：他的能力让他极度擅长数据分析——也让他把人当数据。"五和一"不是冷血，是他真的只看到数字。他看到的是灵能循环系统、沉积曲线、效率参数——不是一个人在痛苦。他的能力在感知层面就过滤掉了"人的属性"，只留下"数据属性"。这是他的悲剧：不是选择冷血，是他的世界真的只有数据
- **不碰孩子**：孩子身上没有灵能沉积——干净的灵能循环系统。这是他唯一看到"不是数据"的东西。他自己的孩子死时他还不会这个能力——如果他当时会，他会在孩子身上看到什么？他不敢想
- **灵感来源**：看穿本质（灵能结构而非生死线）+ 透视灵能经络 + 自动计算最优实验方案
- **弱点**：零战斗能力。他看到的灵能结构是静态的解剖图，不能帮他在战斗中预判动态攻击。离开数据/研究环境毫无用处
- **视觉锚点**：分析时瞳孔收缩到极小——他在"调焦"看灵能结构层，物理视觉几乎关闭

**陈启明 — 研究院内线**
- **能力**：灵能异常预警（危险直觉）
- **体系**：觉醒层，初觉
- **机制**：不是主动感知——是被动触发的直觉。当附近的灵能出现"不该出现的波动"（数据篡改/灵能设备被动过手脚/有人在撒谎时灵能波动异常），他的后颈会发凉。就像动物在地震前的焦躁不安。他无法定位、无法量化、无法解释——就是"不对劲"。刚好够他发现"兽潮预警数据不对"和"灵站参数被篡改"
- **叙事逻辑**：他是最弱的能力者，但他的直觉救了方岩无数次。V7暴露后他失去了一切——但他传的数据一直用到V14。他的能力不来自训练、不来自知识、不来自灵能等级——来自他十二岁被从废墟刨出来时的生存本能。灵能给了他一个"活体地震仪"
- **灵感来源**：预感危险（只有直觉这一层）+ 灵能微弱激活的生存本能
- **弱点**：初觉级，几乎不成长。感知范围很小（同一房间）。只有"不对劲"，没有"什么不对劲"。无法区分威胁等级——灵站参数被改0.1%和兽潮来袭的预警感受差不多
- **视觉锚点**：无——他甚至不知道自己有能力的特征表现。以为"后颈发凉"是普通人都会有的直觉

## 四、无能力者设计

| 人物 | 为什么无能力 | 高光来源 |
|------|-------------|---------|
| 沈念 | 纯粹无觉醒 | 医疗知识+灵衰症诊断+患者档案+撤离组织+治疗发现 |
| 江屿 | 纯粹无觉醒 | 社交工程+通道记忆+编号识别+勇气（V13三次折返） |
| 周远 | 灵衰症患者（灵能系统已损） | 组织信念+V7之死 |

### 普通人高光分布（V1-V14全书）

**V1**：沈念在兽潮夜用医疗知识稳定三个伤员（没有灵能，只有纱布和经验）
**V2**：陈启明凭分析师直觉发现数据异常（初觉≈无能力，靠的是脑子不是灵能）
**V3**：江屿叛逃灵枢——靠的不是能力是通道编号记忆和社交工程
**V4**：沈念诊断灵衰症被沈野发现卖灵晶——"你让我卖我还卖吗？"（V4暴露）
**V5**：周远组织星火社基层的情报网——凭的是人脉不是能力
**V6**：沈念用患者档案建立灵衰症传播模式图——比研究院的数据还准确（她做过田野调查）
**V7**：周远发现核心层要夺权后去找沈野——被灭口。普通人知道的代价
**V8**：江屿凭灵枢内部工作经验判断灵站异常——"这种波动模式我见过，是人为调参"
**V9**：沈念在战斗间隙给汐做紧急处理——没有灵能治疗术，只有绷带、止血粉和冷静的手
**V10**：陈启明V7暴露后失联但传的数据还在用——他的分析报告一直指导到V14
**V11**：江屿在灵枢核心区密室沉默——不是能力不是战斗，是一个人在最恐怖的地方选择不说话
**V12**：沈念用患者档案反向推导灵衰症压制方案——林原的数据+沈念的档案=突破
**V13**：江屿三次折返灵枢废墟救人+抢救数据晶片（灵衰症压制方案全部技术档案）+抢救灵能清洗装置原型机。没有灵能，只有对通道的记忆和三次"再进去一次"
**V14**：江屿终于做了他一直念叨的事。战乱中他反复说过"要是没这些破事，我一定要去南边海边开个小修理铺，修灵能收音机"。V14尾声，他真的去了。在南边小镇海边支了个铺面，招牌是他自己刻的，歪歪扭扭。灵能收音机堆了一桌子，大部分是他从灵枢废墟里捡回来的零件拼的。沈念带沈野来过一次，江屿正蹲在地上修一台老式收音机，抬头说了一句"来了啊"，然后继续修。收音机放着歌。海风吹进来。他没再提过灵枢、没再提过通道编号、没再提过三次折返。他手上全是机油，但手没抖过。——和他在灵枢内部精确冷酷地执行任务形成最大反差：同一个手，掐过人脖子、按过紧急按钮、从废墟里刨出过数据箱，现在拧着螺丝听收音机。沈念+蔓配合实现灵衰症治疗——沈念的临床经验+蔓的编织+林原的数据=治疗不是灵能奇迹，是三种不同人的配合

### 沈念灵晶线
- V1：偷卖灵晶（暗线）
- V4：诊断暴露 → 沈野发现 → 双重打击（灵衰症+妹妹卖灵晶）→ 沈念反问"你让我卖我还卖吗？"
- V5-V14：灵晶线转暗线
- V14尾声："我一直知道。"沈野第一次哭

## 五、双王设定

**虞渊 — 灵能同化**
- 不是"使用"灵能，是"成为"灵能。他和灵枢体系物理绑定——体系在他在，体系亡他亡。这解释了V13为什么他必须死（不是良心发现，是物理必然）
- 他的灵能等级远超灵源级，但不是"超越体系"——他就是体系的终点。灵能七级量到顶就到这里了
- 灵感来源：万法归一 + 因果逆转（虞渊的存在本身就是对灵能因果的逆转）

**渊 — 远古血脉**
- 不是灵能，是血脉——比灵能更古老的力量。汐和蔓是渊血脉在不同环境中的自然分化，不是"灵能觉醒"而是"基因表达"
- 这解释了为什么汐的波动感知和蔓的编织不完全符合灵能七级——它们的源头不在灵能体系内
- 灵感来源：吞噬同化生命本源 + 比灵能体系更古老的存在层级
