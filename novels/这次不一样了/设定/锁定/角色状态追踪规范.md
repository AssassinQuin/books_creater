# 角色状态追踪规范

> 锁定设定，不可变更。见 [锁定设定总索引](锁定设定总索引.md)

## 六、角色状态追踪规范（锁定）

> 所有角色状态变化必须同步到 novel-db character.status 字段和角色蒸馏文件。
> 本规范定义状态追踪的强制字段和格式。

### 6.1 强制字段

每个角色的 `character.status` JSONB 必须包含以下字段：

```json
{
  "ability_arc": {
    "current_stage": 1,
    "stage_name": "萌芽",
    "description": "基础拓印/简单铸造",
    "volume_range": "V1-V3"
  },
  "attitude_matrix": {
    "角色A": {"V1": 2, "V3": 5, "V6": 7, "V9": 8, "V14": 9},
    "角色B": {"V1": 1, "V3": 3, "V6": 5, "V9": 7, "V14": 8}
  },
  "key_turning_points": [
    {"chapter": 3, "event": "方岩给路线图", "attitude_change": "沈野→方岩: 利用→可合作"}
  ],
  "injuries": [
    {"id": "SY-INJ001", "type": "灵能切割伤", "location": "右腿", "severity": "中", "source_chapter": 11, "healing_status": "恢复中"}
  ],
  "ability_changes": [
    {"id": "SY-ABI001", "type": "觉醒", "source_chapter": 5, "description": "首次触发拓印"}
  ],
  "inventory": "碎罗盘/刮刀/残片/稳定剂/2铜币"
}
```

### 6.2 态度量表标准

| 数值 | 含义 | 写作体现 |
|------|------|---------|
| 0 | 无关系/未相遇 | 无互动 |
| 1-2 | 冷漠/利用/敌对 | 保持距离，算计 |
| 3-4 | 观察/戒备/可合作 | 试探性互动 |
| 5-6 | 信任/朋友/关心 | 主动帮助，敞开心扉 |
| 7-8 | 深厚/生死之交/家人 | 托付后背，无条件支持 |
| 9-10 | 唯一/不可分割 | 命运共同体 |

### 6.3 能力阶段定义

| 阶段 | 含义 | 更新时机 |
|------|------|---------|
| **萌芽** | 首次获得能力，不稳定 | 觉醒章节 |
| **发展** | 能力增强，有代价 | 能力提升章节 |
| **成形** | 能力稳定，自主控制 | 质变章节 |
| **突破** | 能力性质改变 | 跨类型/复制活人 |
| **融合** | 创新/熔铸/传承 | 终局章节 |
| **稳定** | 能力成熟，无大变化 | 长期保持 |
| **衰退** | 能力下降/代价累积 | 代价爆发章节 |
| **终局** | 能力最后一次使用 | 死亡/牺牲章节 |
| **无能力** | 无觉醒 | 始终 |

### 6.4 同步规则

1. **DB优先**: 所有状态变化先写入 novel-db，再更新角色深化.md
2. **每章必更**: 每章写作后更新出场角色的 status 字段
3. **蒸馏文件**: 每章写作后创建/更新角色蒸馏文件
4. **冲突检测**: 角色深化.md与DB不一致时，以DB为准

### 6.5 状态检查清单

每章写作后检查：
- [ ] 出场角色的 injuries 是否有新增/恢复？
- [ ] 出场角色的 inventory 是否有变化？
- [ ] 出场角色的 attitude_matrix 是否有变化？
- [ ] 出场角色的 ability_arc 是否有变化？
- [ ] 关键转折事件是否记录到 key_turning_points？

> 生效日期：2026-05-10。后续写作必须严格对照执行，不得随意变更。
