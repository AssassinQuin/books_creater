# 日常危险清单

> 写作参考：正文写作时按区域检查，确保场景有足够的"活着就有代价"感。不是每章都要命悬一线——是每章都有"代价在累积"的感觉。

## 使用方式

正文写完一个场景后，对照当前区域的危险清单，检查：
1. 这个场景至少命中**1项**危险吗？
2. 命中的危险是**场景的背景**还是**被角色感知到了**？（背景也算，但不能总是背景）
3. 有没有场景**完全没有**命中任何危险？（不能有——每个场景都该有代价感）

## 外围：每天都是赌命

外围的危险不需要"发生"——外围的危险是**背景噪音**，一直都在，偶尔放大。

### 天气与灵能

- [ ] 灵能风暴：灵能浓度骤变。体质弱的当场晕厥，灵衰症患者症状加剧。不是每天都有，但每个月来一两次。外围人能闻到——空气里有一股铁锈味，指甲发灰的人会先感到后颈发凉。
- [ ] 灵能残渣沉降：风大的日子，灵能残渣像灰尘一样从天上落。落在皮肤上痒，吸进去咳。拾荒者用布蒙口鼻，但布也会被浸透。
- [ ] 冷季提前/延长：每年不一样，但总有外围聚落准备不足。冷季多一天就多一天消耗，消耗不够就是死人。

### 水与食物

- [ ] 水源污染：灵能残渣渗入地下水。水不是脏——是微甜。甜是因为灵能残渣溶进去了。喝完短期没事，长期指甲发灰。
- [ ] 水霸涨价/断水：水霸控制水井是外围常态。兽潮后水源被污染→净水稀缺→水霸涨价。涨价不是"贪婪"——是他也要花更多成本过滤。但结果一样：穷人的水被截了。
- [ ] 碎渣粉掺太多：碎渣粉糊是外围主食。碎渣比例超过一半→长期吃的人指甲发灰。分不清是灵衰症还是碎渣毒。有人两种都有。
- [ ] 冷季断粮：每年冷季都有聚落断粮。断粮后的选择：饿死、出去找吃的（异灵风险）、抢别的聚落（人杀人的风险）。

### 灵衰症阴影

- [ ] 身边有人指甲发灰：不是新闻，是日常。但每次看到都让人心里一紧——下一个是我吗？
- [ ] 灵药断供：灵药堂免费发药，但药量时多时少。少了的时候患者偷偷减量——效果差但还能撑。完全断了就撑不住了。
- [ ] 送灰讨论：聚落里有人到了晚期，聚落头人在讨论要不要"送走"。当事人可能还不知道。家属在哭。没人想动手但没人敢不动手。
- [ ] 灵能污染扩散：灵衰症晚期患者周围灵能残渣浓度升高→邻居也开始出现早期症状。一个人晚期→整条街危险。

### 异灵与安全

- [ ] 低级异灵闯入：不是兽潮——是虫豸或牙级异灵误入聚落边缘。壁盾不管（太小了），猎手不在（去出任务了），聚落自己处理。处理不好就有人受伤，受伤就需要药，药要钱，钱要卖灵晶，卖灵晶就是灵衰症。
- [ ] 兽潮预警紧张：兽潮来之前的3-5天，外围人闻到空气变了——灵能浓度微微波动，异灵活动增加，斥候带回来的消息一次比一次急。聚落进入"备战"：囤水、修栅栏、检查碎渣弹。备战本身消耗资源。
- [ ] 道路危险：聚落之间的道路不安全。单独行走等于送死——至少3人结伴，最好有猎手。拾荒者在外围边缘作业本身就是冒险。
- [ ] 碎渣弹过期：碎渣弹放久了灵能衰减→打出去不炸/炸力不够→遇到异灵时才发现→死。

### 人际暴力

- [ ] 灵晶抢劫：碎渣交易是现金交易，在野外做。有人盯梢拾荒者的路线，趁交易时抢劫。
- [ ] 黑市纠纷：碎渣黑市没有法律保护。纠纷自己解决——解决方式通常是暴力。
- [ ] 聚落内部矛盾：资源紧张时，聚落内部矛盾加剧。"谁多拿了配给""谁家的病人传染了隔壁"——小的摩擦在日常中累积。
- [ ] 灵站巡查：灵站的人定期来外围聚落"登记""体检"。实际上是筛查高产出源。有潜质的年轻人躲起来——躲不过就被征召。

### 角色日常的危险感写法

不是每章都写"今天差点死了"。外围的危险感来自：
- **累积感**：指甲又灰了一点。水又涨了两个铜板。碎渣袋轻了。
- **无力感**：看到邻居被送灰，什么也做不了。帮了也改变不了什么。
- **随时感**：出门刮管子可能回不来。兽潮可能今晚就来。灵衰症可能在身体里慢慢长。

## 中域：安全的牢笼

中域的危险不是"你会死"——是"你不能问""你不能选""你不能走"。

### 信息管控

- [ ] 教会巡逻：巡礼祭司定期巡视中域社区。检查有没有"违禁碑文抄本""异端言论"。被查到的东西没收，人被"约谈"。约谈后的人变了——不怎么说话了，眼神躲闪。
- [ ] 灵枢新闻管控：中域人看到的"新闻"是灵枢审核过的。外围的混乱被描述成"局部兽潮""例行征召"。灵衰症被描述成"灵能时代普遍现象"。没人提灵站调值。
- [ ] 邻居消失：中域偶尔有人"被教会带走"。第二天那个人家就空了。没人问为什么——问了你也可能空。
- [ ] 研究院传闻：研究院偶尔传出消息——"又有一个实验体跑了""林原的研究出了事故"。消息被灵枢快速压制，但地下室里传得很快。

### 经济窒息

- [ ] 灵晶供应不稳：灵晶价格波动。今天是这个价明天是那个价。中域人的收入是外围的10倍，但灵能设备用不起也等于没有。
- [ ] 阶级固化：觉醒者和非觉醒者之间有一道看不见的墙。觉醒者的灵能设备优先供电，纹路净水池优先供水。非觉醒者排队等剩下的。
- [ ] 灵站合同陷阱：灵站员工待遇好，但合同里有"竞业禁止""信息保密""服务年限"。签了就走不了。想走？违约金你付不起。

### 灵能隐患

- [ ] 纹路设备故障：中域的纹路基础设施比外围密10倍，出故障的概率也高。灵能泄漏、传导石板碎裂、净水池纹路失效——这些"小事故"在灵晶供应充足时不算事，供应不稳时就是灾难。
- [ ] 觉醒者能力波动：灵能浓度变化时觉醒者的能力跟着波动。稳定期无所谓，衰退期可能关键时刻掉链子。
- [ ] 非觉醒者灵衰症：以前只有外围才有的病，现在中域也开始出现。灵枢的解释是"人口流动带入"，但患者分布和灵站位置高度相关。

### 日常恐惧

- [ ] 盯梢感：中域人总觉得有人在看。教会裁判官、灵枢安保、壁盾巡逻——三套监控体系。大部分时候它们不管你，但你不知道什么时候轮到你。
- [ ] 选择萎缩：在中域，你的选择越来越少。不能说、不能问、不能查、不能走。安全是用自由换的，但没有人跟你签合同——你是被动同意的。
- [ ] 道德负担：中域人知道外围在死人。他们在灵站买的外围灵晶，每一颗都可能是一个灵衰症患者的命。但你不买你也没别的选择——灵能设备要灵晶才能转。

### 中域的危险感写法

中域的恐怖不是暴力——是**安静的窒息**。
- **邻居效应**：隔壁的人不见了。没人提。你假装没注意到。
- **代价转移**：中域的安全是建在外围的苦难上的。角色知道这一点但不能说。
- **制度暴力**：不是某个人打你——是制度让你付不起违约金走不了灵站，是制度让灵药堂的药永远不够，是制度让你的孩子因为是"非觉醒者"排在净水队伍最后面。

## 内城：金丝笼

内城的危险最隐蔽——因为表面上看，内城是这个世界最安全的地方。

### 能力绑架

- [ ] 觉醒者义务：内城觉醒者享有最好的一切——但代价是"随时可以被征召"。灵枢需要你的时候，你不能拒绝。
- [ ] 灵能依赖：内城的每一个便利都依赖灵能供应。灵能稳定时是天堂，灵能波动时所有设备同时出问题。
- [ ] 信息茧房：内城人看到的世界是被过滤过的。外围的惨状、中域的动荡都被弱化。灵枢不是在说谎——是在选择性报道。

### 内部裂痕

- [ ] 阶层分化：觉醒者之间也有等级。高阶灵能者住核心区，低阶住外围环。内城的"外围"不比外围的"中域"好多少。
- [ ] 灵枢高层博弈：保守派和改革派的斗争波及普通人。今天这个政策明天那个政策——普通内城人只是棋子。
- [ ] 灵能事故掩盖：内城的灵能事故比公开的多。每次事故都被灵枢快速处理、封锁消息。但当事人知道，当事人的家属知道。

## 北境/禁地边缘：活着就是奇迹

这些地方不需要危险清单——整个地方就是危险。在这里的人不是"过日子"，是"还能撑多久"。

- [ ] 灵能浓度异常区：方向感失灵、时间感错乱、灵能回路被干扰。老手靠地标而不是感知判断方向。
- [ ] 高阶异灵出没：角级和鳞级是常态。不是"可能遇到"——是"一定能遇到，问题是什么时候"。
- [ ] 遗迹辐射：第三纪元遗迹的灵能残留可能激活体内的灵能回路（好的）也可能摧毁它（坏的）。完全看运气。
- [ ] 补给线脆弱：从聚落到这里需要武装护送。补给线断了就是断粮断水断药。
- [ ] 同伴就是威胁：在高危区域，同伴的能力波动可能比异灵更致命。信任是奢侈品。

## 危险级联速查

一个危险触发下一个的常见链条。写作时可以用来给场景加深度。

**经济级联**：灵晶减产 → 灵站收购价暗降 → 拾荒者收入减少 → 买不起碎渣弹 → 遇到异灵无防护 → 死/伤

**健康级联**：灵药断供 → 患者减量 → 症状反弹 → 需要更多药 → 但药更少了 → 加速恶化 → 送灰

**安全级联**：壁盾兵力不足 → 防线缺口 → 异灵渗入 → 外围聚落遭袭 → 幸存者涌入其他聚落 → 资源更紧张 → 聚落冲突

**信息级联**：碑文碎片流出 → 有人质疑教会 → 教会镇压 → 更多质疑 → 教会加大镇压 → 镇压本身成为新问题

**灵枢级联**：灵站维护不足 → 调值偏差 → 灵能事故 → 公众信任下降 → 灵晶交易量减少 → 维护预算更少
