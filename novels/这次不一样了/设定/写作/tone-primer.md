# 世界观基调向量词典

> 给 novel-planner-volume / novel-chapter-writer 中所有 Agent 使用。
> 每章/每场面**强制选择1个主向量**，可叠加1个辅助向量。
> 不是描述性说明——是 Agent 必须填写的输出字段的枚举值来源。

---

## 一、5种基调向量（必选其一）

### 1. 冷漠克制
**核心感**：废土日常，一切如常，没有热血。动作先行，感受留白。

- 角色做事不解释为什么做
- 感情通过身体动作/环境传达，不写"他感到悲伤"
- 节奏匀速，不刻意渲染
- **典型场景**：沈野出门拾荒 / 换碎渣 / 走过灵站不停下

### 2. 突然暴力
**核心感**：无预警。像现实——走着走着就出事了，没有铺垫。

- 不写"他感到一丝不安"这种预兆
- 暴力来了就是来了，叙事不减速，不煽情
- 读完要有"怎么突然"的瞬间停顿
- **典型场景**：拾荒者之间的抢夺 / 异灵突袭 / 被灵站保安当场制住

### 3. 短暂温暖
**核心感**：冰冷废土里的一个小善意。暖一下就收，不恋战，不抒情。

- 善意是动作不是语言——老陈多给一块碎渣不收钱，不说话就走开
- 温暖后立刻回到冷漠/日常，不过渡不解释
- 读完留下一口气，不是热泪盈眶
- **典型场景**：有人多给了什么 / 沈念把东西分给别人 / 沈野沉默后的保护行为

### 4. 荒诞笑点
**核心感**：正经场面来一句不对劲的。读者嘴角动一下就够了，不是笑话。

- 角色一本正经说荒谬的话
- 危险过后有人说了一句特别不搭的话
- 严肃场合里来一个无关紧要的执念
- **典型场景**：谈价格谈得特别认真的小事 / 沈念在不合时机说废话 / 异灵追击时有人在意鞋子

### 5. 兄妹张力
**核心感**：两个人在穷里互相撑着，又不让对方知道自己在撑。

- 不是感人的大场面，是微动作和沉默的积累
- 沈野不说"我在保护你"，他多走两步挡在她前面
- 沈念不说"我很难受"，她笑着把碗推过去
- **典型场景**：分配食物 / 沈野跟着但装作没在跟 / 一方受伤另一方装没看见

## 二、废墟秩序锚点库（每章必选1个）

> 每章必须展现废墟秩序的1个具体细节，让读者感受到"这个世界在正常运转"。

| 类型 | 具体细节选项（任选1） |
|------|---------------------|
| **规矩** | 拾荒者领地划分惯例 / 先到先得的默契 / 碎渣分成的行规 / 不抢老人摊位的不成文规定 |
| **价格** | 今天灵碎涨了多少 / 某东西贵了一个铜板的原因 / 灵站压价了 / 兑换比例变了 |
| **公告** | 灵站新禁令 / 配额调整 / 失踪者名单 / 奖惩公告 |
| **剥削** | 灵站克扣碎渣的方式 / 保安巡逻的时间规律 / 谁在吃谁的差价 |
| **互助** | 拾荒者之间的情报共享 / 有人帮扛了东西 / 不问理由的搭手 |

## 三、微动作特征库（不可压缩，Agent 必须保留）

> 当场面有情绪时刻时，**从这里选微动作**，不要凭空发明。

### 沈野
| 情绪时刻 | 微动作 |
|---------|--------|
| 担忧/压力 | 摩挲食指关节（反复、无意识） |
| 保护本能触发 | 沉默后多走两步，挡在前面 |
| 体贴（不想说出口） | 把吃的给沈念，不说话，看别处 |
| 认可（罕见） | 停顿两秒，继续走，什么都没说 |
| 愤怒/不满 | 话更短，甚至只剩一个字 |

### 沈念
| 情绪时刻 | 微动作 |
|---------|--------|
| 疼痛/压抑 | 一声不吭，反而笑着帮别人做事 |
| 夜里失眠 | 给旁边的人拍背，哼歌 |
| 心情好 | 踩石头走平衡 |
| 把东西分给人 | 碗推过去，不等对方说谢谢 |
| 察觉到沈野在管自己 | 装没发现，但走路跟上了 |

### 通用微动作（次要角色）
| 情绪时刻 | 微动作 |
|---------|--------|
| 紧张 | 手放在腰间的武器/工具上，没动，只是放着 |
| 不信任 | 答话但眼睛没看对方 |
| 疲惫 | 坐下来先放工具，后放人 |
| 警戒 | 说话时背对墙 |

## 四、克制美学量化基准

> 写透与粗放的配额，与 writing-constraints.md 中的硬约束对应。

| 约束 | 基准 | 说明 |
|------|------|------|
| **写透配额** | ≤1场面/章 | 每章只有1个场面感官全开（视觉+听觉+触觉+嗅觉+节奏），其余粗放 |
| **解释句上限** | ≤5句/章 | 设定说明、内心OS、情感解释，合计不超过5句 |
| **核心意象频次** | ≤2次/章 | 同一微动作（如"摩挲关节"）每章不超过2次 |
| **温暖段收束** | 出现后立刻回到主基调 | 温暖场面≤3句，之后立刻硬切 |
| **暴力预兆** | 禁止 | 不写"他感到不安/危险"，暴力直接到来 |

---

## 五、基调组合规则

| 主向量 | 允许叠加 | 禁止叠加 |
|--------|---------|---------|
| 冷漠克制 | 荒诞笑点、兄妹张力 | 突然温暖（克制与温暖对立，全章不同时用） |
| 突然暴力 | 短暂温暖（暴力后的温暖） | 荒诞笑点（暴力中不插笑点，之后可以） |
| 短暂温暖 | 冷漠克制（温暖前/后的冷漠） | 突然暴力（同场面） |
| 荒诞笑点 | 冷漠克制 | 兄妹张力（兄妹的微妙感不配荒诞） |
| 兄妹张力 | 冷漠克制、短暂温暖 | 荒诞笑点 |
