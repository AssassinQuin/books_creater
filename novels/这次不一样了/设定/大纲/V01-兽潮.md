# V1 兽潮

## 卷级因果链

因为沈念灵衰症中晚期（稳定剂耐药·小概率失效）→ 所以沈野按正常病程攒钱的盘算正在失效 → 沈念加倍去灵站卖灵晶攒"给哥哥的路费"（而非"一起去的路费"）→ 韩朗标记"高产出源" → 兽潮来袭（方向异常·牙级甲壳"不是外围的东西"）→ 方岩在兽潮中本能找沈念（不是巧合·是父亲找女儿的本能）→ 沈野发现方岩不是普通修灯人 → 逼出壁盾身份暴露+残盘指向东北+路线图 → 翻背包发现兑换券数量异常 → 摊牌："稳定剂没用了""我在给你攒路费" → 时间线错位炸裂 → 方岩确诊"三到六个月" → 沈野矿道口画四条线抹掉三条 → 第一次冲突"你不去""我去" → 夜谈揭露两年前根因（沈野瞒着找路→沈念追出去→甬道塌→灵息外泄加速病情）→ 第二次冲突 → 妥协："如果走不到，我至少在路上看了" → 方岩画十六站路线图 → 出发前夜互相塞药 → 雪球：两个人带着各自的秘密上路，保护模式都没改 → 到达荒原第一夜，残盘指向东北

没变的是：他还是在替她多走一步（加倍拾荒、浓缩稳定剂藏包底），她还是在替他把痛苦藏好（止痛呼吸法、把所有东西带上像不打算回来、出发前夜用眼睛刻下）。

本卷只有一件事：从"日子还能过"到"日子过不下去了必须走"。

## 起


### 起

沈野的日常是钻进深矿道掏碎渣。他有一种说不清的手感——手贴上灵脉内壁就知道哪个方向碎渣多，像灵脉内壁在跟他说话。他把拾荒收获分成三堆：好的给沈念换粮，中等的存着，最次的留自己。这套分堆法雷打不动。深矿道里他摸到一块五层纹路的残片，从没见过这种纹路，碎渣成色好，揣着没扔。一只虫豸级灰蜥从甬道深处追来，沈野没有正面迎战——他利用地形和本能级的空间判断力预判异兽路线，从塌方缝隙中抄近道脱身。不是战斗，是逃亡中的本能反应，他不知道自己为什么能算准，只当是"运气好"。
回家的路上经过教会小堂，牧师在里面给沈念做净化——多停了好几秒。沈野站在门口等着，他注意到牧师的表情不是"关心"，更像"确定"。但他没追问。他一直这样：注意到了，记住了，判断"大概没事"就过去了。
沈念每隔几天去灵站卖灵晶，领一小瓶免费配给的稳定剂。沈野在外面等她，靠墙看公告栏。透过窗户他看到灵站司册员韩朗在灵枢上多敲了几下——不是正常刻录速度，是额外敲了什么。沈野的角度看不到显纹板内容，但他看到了韩朗低头看了一眼显纹板右下角。公告栏贴着两张纸：一张是灵枢的丰收期官方通知，印刷精美；旁边一张手写寻狗启事，纸边已经卷了。沈念出来的时候说"还行"，但她把手揣进口袋——她平时不那样。沈野数了数她兜里的稳定剂瓶子，配额还够。他没追问。
市集上有个修路灯的人叫方岩。沈野经过时点了个头，方岩回了一个"嗯"。方岩低头干活，忽然说了句"你这根绳不行"，把手里新打的绳结解下来递过去——绳结是壁盾斥候的双环扣，比他自己的结实三倍。沈野认出标记但没问。沈念去市集换粮时经过方岩修灯的地方，她给所有人递水——自己的水壶小，只有半壶，但倒的时候不犹豫。第一次方岩没接，第二次她把水壶放灯柱底座上就走了。方岩喝了一口。她笑起来眼睛眯成一条缝，手指上有一层淡淡的灰色，用袖口遮。方岩没问。他见过那种灰色。他女儿手指也是这样开始发灰的。
支线在此阶段的苗头：兄妹心结——沈野三次"注意到了但没追问"，保护本能把"变化"翻译成"不需要追问的事"；灵站暗线——韩朗额外操作、沈念频繁去灵站，碎片化灵息动静让读者觉得"灵站有问题"；方岩线——壁盾绳结暴露身份，沈念递水送饼，她不知道他女儿也是灵衰症走的；残片线——五层纹路残片，手感异常，拓印能力萌芽的第一次触发；教会线——牧师表情"确定"而非"关心"。

## 承


### 承

事情开始不对了。沈野去平时不去的深矿道，在甬道上方发现了同样的残片——不是偶然掉落，是规律分布。有人在这条甬道里投放过什么东西。公告栏更新了数字。"灵息强度升至二倍半——预警灵阵·橙级。"沈野盯着看了好一会儿。外围最高的丰收期也就150%。240%不对。他让沈念少出门，她说好，第二天她又去了——他不知道。沈念加倍去灵站不是为了治病，是为了多攒一份路费给哥哥。她的盘算和他不同：他在算"两个人到内城要多少钱"，她在算"他一个人到内城要多少钱"。
然后是那个女孩。隔壁几条甬道外住着一家三口，最小的女孩七八岁，扎两根小辫子。沈野以前见过她在灵站门口等母亲——靠墙蹲着，小二郎腿，手指在墙上画画，等多久都不闹。那天傍晚沈野经过她家矿道口，里面比平时安静。女孩蜷在母亲怀里，皮肤从手指开始发灰，蔓延到手腕，再到小臂。灰斑爬过肘关节的时候她母亲没有哭，只是把她的辫子拆了重新编了一次。动作很慢，很稳。入夜前女孩走了。沈野站在甬道外待了一会儿，转身走了。他没去看沈念——怕看到她的时候脑子里会浮现那个女孩的脸。那天晚上他把拾荒时间从12小时拉到了14小时。不是多了一个目标，是怕停下来就会想起那双辫子。
然后兽潮来了。深夜，地面在震。沈野的第一反应是经验判断："三小时就散。"但这一次方向不对——以往兽潮是横向扫过，这一次直冲聚落。沈野这辈子第一次在废墟里掉头跑。聚落被冲击时甬道塌了一截，沈念被碎石和甬道碎石压住。方岩不是"正好在附近"——他在找她。兽潮来的时候他第一反应不是跑，是往沈念平时的方向走。他把甬道碎石扛起来，把沈念拖出来，先托后脑勺。不是士兵救人那种职业反应，是一个父亲抱起孩子的方式。沈念疼得叫了一声，他说了句"没事"——他跟女儿说过同样的话，同样的语气，同样的谎。天亮后聚落毁了三分之一。方岩从废墟里捡起一块甲壳对着光看——牙级的，碎片边缘在晨光里泛着微光。"不是外围的东西。"他没再说。沈野站在旁边等他继续说。方岩站起来，膝盖响了一声，走了。
同一时间另一条线在暗处推进。沈念在灵站坐了两轮引渡椅——平时只坐一轮。灵站刚发了灾后重建激励：卖灵晶配额翻倍，兑换券+50%，限三日。她决定最后攒一笔路费。第二轮吸收时韩朗在灵枢上做了标记，嘴角动了一下——不是对她的笑，是对灵册的确认。他不知道自己在杀人，他以为在做"灵册采集"。沈野回家的时候天已经黑了。沈念整理背包的动作变慢了。他注意到了。但他脑子里全是兽潮方向不对、牙级甲壳、方岩的话——他不是没看见她的异常，是两件事压在一起，先处理了"能处理的"。
支线在此阶段的推进：灵站暗线——收购价下调→灾后激励翻倍→韩朗"确认"标记，读者逐渐拼出"这个灵枢体系在收割"；方岩线——兽潮中主动找沈念（不是巧合，是本能）→救出来后说"没事"（跟女儿说过一样的话）→发现牙级甲壳，他的行为已经出卖了他；兄妹心结——沈野"注意到了但先处理能处理的"，保护模式的代价开始显现，沈念加倍坐引渡椅他不知道。

事件清单：
- E1：沈野在深矿道上方发现同样残片——规律分布，不是偶然掉落→有人在这条甬道里投放过什么东西
- E2：公告栏"灵息强度升至二倍半——预警灵阵·橙级"→外围最高150%，沈野判断"不对"
- E3：沈野让沈念少出门，她说好但第二天又去了→兄妹信息差第一次显式扩大
- E4：隔壁甬道女孩灵衰症发作，灰斑从手指爬到手腕→母亲拆辫子重新编→入夜前走了
- E5：沈野没去看沈念，怕辫子和她的脸重叠→拾荒时间从12小时拉到14小时
- E6：兽潮深夜来袭，方向异常——直冲聚落而非横向扫过→沈野第一次在废墟里掉头跑
- E7：方岩在兽潮中找沈念，先托后脑勺拖出来→说"没事"（跟女儿说过同样的谎）
- E8：方岩捡起牙级甲壳"不是外围的东西"→站起来走了
- E9：沈念坐两轮引渡椅+灾后激励翻倍→韩朗做"确认"标记（平庸之恶）
- E10：沈野回家注意到沈念整理背包变慢→但先处理"能处理的"

费笔清单：
- 费笔1：面摊前两个老人下棋——"我孙子在灵站当差，说最近收购价下调了""下调了去的人还更多，怪不怪"（融入Ch004日常场景）
- 费笔2：远处有人吹口琴，调子不太准，过了一会儿停了——沈野数碎渣时听到，没抬头（融入Ch005女孩走后的沉默场景）
- 费笔3：兽潮过后一只灰蜥卡在甬道缝隙里，还活着，一只眼睛看着沈野——沈野没救也没杀，绕过去了（融入Ch006兽潮废墟场景）
- 费笔4：灾后捡兽骨——"这次不一样，牙级的"（融入Ch007灾后场景，标题呼应"这次不一样了"的第一次出现——反讽）

## 转


### 转

沈野主动去找方岩。不是修灯。兽潮后方岩救过沈念——一个修灯人不会在兽潮里精准找到某个特定的人。方岩没等他问，卷起袖子，小臂上有一条整齐的刀疤——不是异灵抓的，是刀划的。"壁盾18年。退役了。"残盘的残块放在旁边的石头上，针不指向北，指向东北。"有些事没做完。"方岩没说为什么帮沈念。不是客气，是说不出口。他女儿十二岁走的，灵衰症，手指也是从指尖开始发灰。沈念给他递水的时候笑眯眯的样子和他女儿一模一样——不是长得像，是那种"自己没多少日子了还在给别人倒水"的样子像。他在兽潮里找她不是军人本能，是害怕——害怕再看到一个小女孩的手指发灰，而他连水都来不及接。
沈野经过那个女孩的矿道口，她母亲坐在外面，辫子拆了一半，手里握着旧发绳。抬头看了沈野一眼——那个眼神他后来想了很久。不是恨，不是怨，是"你也在数日子吧"。沈野没有停下来。
透过窗户看到韩朗在某个页面停留过久——沈野记住了这个画面，但他不知道它意味着什么。沈念出灵站的时候脚步比以前慢，攥兑换券的手指在抖——两轮引渡椅的代价已经扎根在她身体里。沈野看到了。那个女孩的影子又闪了一下。他甩开。继续翻背包。
然后所有线在翻背包这一刻炸了。沈野翻背包找干粮，发现一沓兑换券，数量远超预期。他数了三遍——确认"你又去了"。他一直以为她在为"一起去内城"攒钱。他算了一下："两个月能到壁盾。方岩说三到六个月。够。"——他的盘算是对的，如果病情按正常速度。他说服的不是她，是他自己。
沈念说："哥，我不是在攒路费。""我在给你攒路费。"五个字落地的时候，她的手指痉挛，蓝光从指缝泄出来，皮肤从指尖开始发灰蔓延到整个手背。身体替她确认了：她说的是真的。他第一次看到她的秘密小金库——几枚铜板、几张兑换券、一小袋碎灵晶，全在背包最底层暗格，衬布下面。每一样都是她忍着两轮引渡椅副作用换来的。她在替他存"活路"。
方岩确诊，声音很平："不是正常的灵衰症进展。稳定剂耐药。三到六个月——但可能更快。"沈野在矿道口坐了一整夜，手指在灵脉内壁的灰上画了四条线：留在外围、去灵站求医、找教会、走方岩的路。他抹掉了三条。第四条线的位置留下了一个模糊的手印。他回去说："你不去。"她说："我去。"——第一次冲突。她的反驳不针对他的理由，她说的是另一件事："你一个人去，谁给你数碎渣。"
那天夜里沈念一边缝他裂开的袖口一边说出了两年前的事。他偷偷去北边废墟找内城方向的路，骗她说去东边捡碎渣。她追出去那天西段甬道塌了，她被埋了半截，他拖她出来的时候断了两根半肋骨。甬道灵息外泄，她吸入高浓度残气，灵衰症从初期加速到中期。他一直以为她的病是自然发展的。她说："你每次都算错了。你算的时候从来不算上我。""这不是你的错。但你不能因为怕我担心就自己扛。我不是你的行李。"他听到了。但保护本能不会因为听到就改变。
第二天他又找了三个理由，她一个一个打断。"我的身体我比你清楚。""那就多带碎渣弹。"她站起来走到门口转回来："方岩的图我记了七成"——实际记了九成，连补给站之间的距离都记了。她说如果他不带她，她自己走。上一次他就没拦住她。傍晚她坐在甬道中间数铜板，阳光从缝隙照在钱上。"差一个人的路费。"她抬头看他："哥，我想跟你走。不是为了帮你数碎渣——是因为这条路我想自己走一遍。"停了一下。"如果走不到，我至少在路上看了。"他什么都没说。走过去在她旁边坐下，帮她一起数。这是他的妥协——不是"同意你去"，是"我们一起数"。
支线在此阶段的爆发：兄妹心结（核心段）——兑换券摊牌→秘密小金库→"稳定剂没用了"→四条线→冲突→夜谈揭露两年前根因→第二次冲突→妥协，嘴上约定达成，行为模式未改；方岩线（交汇）——壁盾身份暴露+残盘指向东北+方岩确诊，他从旁观者变成不可替代的盟友，他画的不是路线图，是"不想再看到同样的结局"；灵站暗线（暗涌）——韩朗停留过久，读者此时拼出"灵站有问题"的完整图，但沈野还在处理妹妹的事，顾不上深究。
关键对话/核心句：
> "我在给你攒路费。"
> "我不是你的行李。"
> "如果走不到，我至少在路上看了。"

## 合


### 合

方岩画了一整夜路线图，十六站，从外围到边境镇。笔法粗犷但标注极细——哪里地形窄兽群过不去，哪里有废弃矿洞可以藏身。画到第7站停了一下："废弃净房，路过别吸气。"沈念笑了一下。路线图背面写着训练指南。方岩把残盘最大块的残片擦了两遍递给沈野："到边境镇找陈启明。壁盾的旧人。说我的名字。"然后他说他不走。"你的路跟我的路不一样。"他没说为什么给路线——不是因为欠了什么，是因为他女儿没等到有人给她画一张这样的图。他画不了给自己女儿的，就画给这个像她的人。
出发前夜，沈野收拾行李时在沈念背包里摸到一个小包——稳定剂、止血绷带、几枚兑换券，全是她用自己的钱换的。她知道路上他更危险。他拿着小包站了一会儿，放回原处，把搭扣扣好。没拿出来。没问她。然后他出门，用多捡的碎渣换了一瓶浓缩稳定剂——比常规强三倍——塞进自己包的最底层。她不知道。两个人都在用对方不知道的方式保护对方。沈念睡不着，不是因为害怕——是因为她在记。记甬道里光线的角度，记哥哥收东西的习惯，记最后一眼聚落的样子。她打算记住这一切，因为"这可能是最后一次"。她没有哭。她在用眼睛刻下。老陈烙了两张饼，油比平时多放了一块。"等你回来给我。"
清晨。沈野背着包站在聚落出口，沈念跟在后面，鸦站在她肩膀上。远处山坡上有一个人影——沈野知道那是方岩。方岩站了一会儿，转身朝另一个方向走了。沈念回头看了一眼聚落，只看了一眼。然后没再回头。几天后。荒原第一夜。沈念靠墙睡着了，手指在黑暗里闪了一下蓝光——身体在泄灵能。沈野坐在对面看着她。残盘在发热，针在微光中指向东北。他又摸到口袋里那块残片，在手里转了两圈。放回去了。抬起头看北方天际线。
支线在此阶段的状态：兄妹心结——约定达成了但行为没改，互相塞药是保护模式的镜像，她还在记最后一眼，他还在加倍拾荒；方岩线（收束）——画完路线图+送行，弧光完成，残盘和陈启明名字是留给V2的伏笔；灵站暗线（悬着）——沈念取走和鸣灵契，但灵站追踪机制读者已经知道了，留给V4；残片线（悬着）——残片+残盘共鸣，留给后续卷。
