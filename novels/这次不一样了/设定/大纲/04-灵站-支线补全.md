# V4 支线补全：灵站

> V4 是全书的第一次认知推翻——灵衰症是系统副作用。支线密度应高于 V3。

---

## 一、韩朗线·V4：悬停三秒——全书最关键的三秒

### 事件完整展开

韩朗被调到自由城灵站。他不再是外环管理员了——自由城灵站比外环大十倍，人手多，系统更复杂。他的工位在二楼数据分析组，不再是直接面对顾客的柜台。

D8-D9 江屿潜入自由城灵站内层时——韩朗正在二楼处理数据。

他处理的不是沈念的档案——是一批从外环灵站系统同步过来的旧档案，编号NX-4400到NX-4450。NX-4421。沈念的名字。

他看到了。

**三秒里他在想什么**：

**第一秒**：认出编号。他记过这个编号。外环，高产来源，维护优先。

**第二秒**：看到状态标记——「观察中」。不是他改的。不是外环灵站改的。标记状态被更高级的权限修改过了。他不知道是谁。

**第三秒**：手指悬在键盘上方——他没有动。他在想一件事：如果连状态标记都能被人从更高级改掉，那他每天提交的数据到底在被谁看？

然后他关掉了窗口。

### 三秒之后的连锁反应

- 他没升级标记（系统要求他看到异常的标记状态时应该升级为"重点关注"）
- 他没汇报（发现标记状态异常应该向安全部报告）
- 他没删除（他也没保护数据——他只是什么都没做）

这个"什么都没做"比V3的"没上报"更重——V3他只涉及自己的信息，V4他涉及了系统的信息异常。他在V3已经跨过了"不作为"的门槛，V4跨过了"明知系统有异常但不报告"的门槛。

他的叛逃在V7发生时——读者回头看他V3→V4→V5→V6→V7的路径：
- V3：看到了晚期名单→没上报
- V4：看到了标记异常→没报告
- V5：收到了截获的灵枢通讯→改了一个字的报告（"确认"改为"待核实"）
- V6：收到了边境镇数据异常的警报→模糊化处理了日志
- V7：叛逃

没有一步是突然的。

## 二、教会·善终所线：V4 的核心副线——"一个杀人一个埋人"

### 善终所的全景

自由城的教会善终所——不是"灵衰症患者等死的地方"。是一个没有灵能灯、没有共振设备、只有床、药和人的地方。

老修女在这里工作了33年。她看到的每一个患者都不是"编号"，都记得名字。

**老修女告诉沈野的事**：

> "你知道我在这里33年看到什么吗？
> 我看到的不是灵衰症越来越多了——我看到的是灵站附近的灵衰症患者越来越多。
> 外环的、这个区的、那个区的——我把地址标在地图上，发现了一个规律。
> 不用猜：灵站密集的区域，病例密度就高。灵站离得远的地方，病例就少。
> 教堂里的其他人都说——灵能浓度高的地方自然病人多。
> 我想说的是——我们做了33年临终关怀。33年。如果这33年不是在治病，是在收治被同一种原因致病的人——
> 那这个房间的意义是什么？"

**沈野没有回答。老修女也没有等他回答。**

沈野站了几分钟，然后走出了房间。他在走廊上站了一会儿，看着善终所门口排队的人——脸色发灰、咳嗽、有人需要扶着墙才能站直。这不是第一次认知推翻的终点——而是沈野第一次问自己这个问题时的起点。

### 善终所数据的作用

老修女在33年里积累了灵站附近灵衰症发病率的民间数据——不是官方数据，是她在善终所的地图上手动标记的。这份地图在V4末尾被方岩拿到了。方岩后来用它做了灵衰症分布热力图——和官方数据对比之后发现：官方数据低估了实际发病率的40%。

方岩保留这份对比图——V7韩朗叛逃时带来的灵枢内部数据，和方岩的热力图可以互证。

### 善终所数据V4→V12的路径

```
V4 老修女给沈野看标记地图→沈野转给方岩→方岩做热力图
→V7 韩朗叛逃带来灵枢内部发病率数据→与热力图对比→确认官方数据低估了40%
→V12 沈鹤发现教会高层知道这份数据但选择沉默
→V14 治疗闭环的基础——所有数据最终汇总为治疗方案
```

## 三、沈野铸造学习·凝相突破的因果链

### V4 前三天：全部失败

沈野从V3本能铸造的经验出发，V4第一天就开始尝试复现。他找了一堆兽尸灵能残留、碎渣、灵能残片——用V3同样的方法，试图"把一块碎片拼回去"。

前三天全部失败。

失败的不是他的能力——是他的意识。他在有意识的状态下无法进入V3那种"本能模式"。他的脑子在路上，他一直在想自由城还有多远、沈念的病情、方岩传信的内容——他的注意力是分散的。

他的能力需要「聚焦」（他在极端压力下自动聚焦了），而他在有选择的时候反而做不到。

### D4：方法的转变

第四天，他停下来。他找了路边的一块灵能残骸，不试图"铸造"它——只是把它放在手里，感受它的灵能结构。用手感受。不是用脑子分析。

他发现了一个关键区别：
- 以前他"摸"灵能物品时——他在"识别"（这是什么品质的碎渣？值多少钱？）
- 现在他"摸"灵能结构时——他在"读取"（回路怎么走的？它想做什么？）

转变不是方法的改变——是目标的改变。以前他在用拾荒者的技能分辨灵能物品的价值。现在他在用拓印本能理解灵能结构的意图。

### D5：第一次成功

他成功的原因不是"更努力了"——是他不再试图"做"什么。他把灵能残留放在手心，让它自然凝聚。他只做了一个动作：给它一个方向——"亮"。

残渣绕着他的手指凝聚成了一块粗陋的灵能碎片。光照亮了他的手掌。

沈念在旁边看着——她说了一句话："好看。比灵站的灯暖。"

这块碎片就是他在自由城给沈念的第一件装备——一块亮度比灵能照明石高三倍但持续时间差不多的碎片。他不是"做"出来的——是灵能残渣在他的引导下"自己"凝成的。

### 铸造哲学的形成（V4→V8→V14）

```
V4：灵能可以在引导下自行凝聚。不是"我做"——是"我引导"。
V6：给每个队友做装备——理解每个人缺什么比造最强的装备更重要。
V8：第一件真正的定制装备（给方岩的罗盘）——他把人的灵能频率编进了装备。
V14：封印修复——不是"一个人做了一个最强的铸造"，是"一群人引导灵能自行修复"。
```

## 四、陆沉线·V4：禁地阈值——他看到了别人没看到的数据

### 发现过程

陆沉用陈启明提供的权限潜入了研究院自由城分部的灵能监测室。他不是在找"证据"——他是在找一个具体的频率模式：他在V3救汐战斗中感知到的那种"有人在400年前做过同样的事"的灵能回响。他想知道这种频率是否被记录过。

监测室的终端里存着过去十年的全量数据。他花了半天时间搜索——不是找关键词，是用他的分解能力感知终端中储存的灵能数据流。他可以"感觉到"数据中灵能频率的分布。

他发现了一个异常模式。

### 禁地阈值数据

在监测室的隐藏目录中（不是公开目录，是系统自动存储未分类数据时创建的"垃圾目录"），他找到了一份从未被分类的连续监测数据——从大约400年前开始的灵能浓度监测记录。数据不是在研究院生成的，是从一个外部来源持续同步过来的。

数据内容：禁地及其周边的灵能浓度日变化。

每一条记录都有标注：「阈值·接近」或「阈值·正常」。在最近十几年的记录中，"接近"的出现频率越来越高。

数据末尾有一条批注，不是管理员写的，是系统自动生成的：「临近阈值。建议提高南三区灵站提取率。」

**陆沉看到这个注释时的反应**：

他站在这行字前站了片刻。灵站提取率和禁地阈值之间有关联——不是随机建议，是系统在"推荐"一种压制机制。提高灵站的灵能提取率→从环境中抽取更多灵能→禁地方向的灵能浓度上升被压制。

这不是经济效益问题——是在用灵能回收技术压制禁地方向的灵能泄漏。

**他没有把这个发现告诉其他人**。不是因为不信任——是他需要先验证。

他用自己的方法验证：他去了自由城的几个不同区域，用分解能力感知地下的灵能管线走向——所有的灵站主管线都指向同一个方向：东北。禁地方向。

他确认了。然后他告诉了方岩。

### 这个数据在V4→V12中的路径

```
V4 陆沉发现→告诉方岩→方岩用铁谷镇数据交叉验证
→V7 韩朗叛逃带来灵枢内部文件→确认"南三区提取率提高"是系统指令不是经济决策
→V9 封绝坐标确认→禁地的物理位置确认
→V12 禁地真相揭示→"收走全部灵能"=四百年前的封印方案
```

## 五、自由城势力的日常痕迹——不是"入城检查需要身份牌"，是"前面的人被拦下来了"

### 自由城的白天和晚上

自由城比沈野去过的任何地方都大——也比他去过的任何地方都冷。不是温度，是人与人之间的距离。

| 场景 | 展示内容 |
|:----:|---------|
| 入城检查站 | 灵枢的检查站，进出需要身份牌。沈野没有——江屿用旧身份帮他混过去的。排队时前面的人因为身份牌过期被拦下来了。那个人站在栏杆外，看着队伍往里走。沈野排队时经过他时没看他。 |
| 灵站大楼 | 八层。外环灵站只有一层。自由城灵站的门口有一个巨大的灵枢标志——不是贴在墙上的，是嵌在建筑立面上的。发光的。白天看不太明显，晚上亮的时候半个街区都能看到。 |
| 教会总部 | 不是外环的小堂，不是边境镇的驻点——是一整座石砌的教堂，有尖顶、彩绘玻璃、管风琴。教堂门口有一块铜板，上写着：「感谢灵枢能源对本堂的资助·纪元第397年」。比边境镇的那块大。 |
| 研究院分部 | 灵能监测设备全天候运行。门口有一块电子屏，滚动着灵能浓度的实时数据。有人路过时会看一眼。大部分人不看。 |
| 地下酒馆 | 自由城的酒馆不是"猎人酒馆"——是"什么人都去"的地方。猎人在角落喝酒、工人在吧台喝便宜的酒、偶尔有一个穿着灵枢制服的人坐在最里面。(没有人坐在他旁边。) |

### 星火社的影子（自由城·V4）

V4 星火社不是"一个组织"，在自由城的日常中是看不见的痕迹：

- 公告栏上有时会出现半张被撕掉的传单——不是贴在灵站公告栏上的，是贴在外围居民区的墙上的。内容看不全，但不多的字出现「以……抗……」和「自……城……组……」。没人承认贴了。
- 酒馆里偶尔有人说一句"自由城有人在组织"，声音不大。说话的人说完后继续喝酒。周围没人接话。
- 老陈(如果他在自由城)会说"别信那些传单，也别不信"——但老陈不在自由城。这句话因此缺失了。沈野在自由城听到的只有传言，没有老陈那样能帮他把信息放在"可以信也不可以信"的框架里的人。
