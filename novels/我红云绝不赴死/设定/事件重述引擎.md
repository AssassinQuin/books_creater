# 事件重述引擎（全书叙事哲学）

> **权威**：2026-08-14 新建（用户裁定·最高创作原则之一）。与《对标/卷级大事件设计模板与细纲新标准.md》并列——那个管"事件怎么写好看"，本文件管"事件与原著的关系怎么处理"。写任何涉及 canon 事件的卷纲/细纲前必读。
>
> **一句话定调**：本书不是洪荒设定小说。**本书的核心是每个事件的因果质量**——为什么发生、谁推动、谁的因果被改变：命运的结构 + 每个角色的经历 + 主角团事件的推动。canon 事件（后羿射日、不周山、封神……）只是**默认稿**：它们提供读者识别的快感和"知果"策略的知识底座，但**任何一层都可以改——动机、执行者、乃至结局——只要新版本的因果链比原著更合理、更有力**。判据永远是"为什么"，不是"原著如此"。

---

## 一、canon 是默认稿，不是圣旨（决策原则）

1. **默认保留 canon 的理由**：读者识别快感（"这是我知道的那个洪荒"）+ 主角"知果"策略需要知识底座 + 洪荒情怀。这是惯性收益，不是义务。
2. **改写的许可**：任何 canon 事件都可以在任意层改（动机/执行者/结局）——**判据是因果质量**：新版的三源传导链（命运结构性+人物不可逆选择+主角团推动）是否比原著的笼统因果更合理、更贴本书主题。更合理就改。
3. **改动成本意识**（不是禁区，是工程账）：量劫级事件的结局改动有**下游连锁**——十日不凌空，后羿的弓就没了意义，嫦娥的月就空了，巫妖的账就平不了。**改一个要看三个**：动结局前先盘下游 canon 链条，决定是"链式重构"（连带改下游）还是"局部改写"（结局微调但链条兼容）。个人级命运（红云不死/太一假死/通天免贬）已大量改写，证明本书从不以 canon 为上限。
4. **两级表从"能改/不能改"改为"默认锚定/可论证改写"**：骨架事件默认保留（惯性收益+连锁成本），但持有论证即可改；血肉层（个人命运）默认自由改。**两者的边界是成本，不是教条。**

## 二、四种重述模式（每个 canon 事件选一种或组合）

### 模式 A · 动机重写（执行者不变，因果链重写）
canon 的人物做了 canon 的事，但**为什么做**完全是我们给的。后羿仍射日——但他的弓为什么举起来，是我们的因果链（他的经历、他的性格、主角团在他生命里留下的东西）。
- 风险：不能只是给原著动机换个说法——重写的动机必须**只能长在本书的土壤里**（拔掉主角团的影响，这个动机就不成立）。
- 判据：读者读完应该觉得"原著那个笼统的动机，原来可以是这一整条人生"。

### 模式 B · 执行者置换（事件同名，扣弦的换了人）
"后羿射日"之名下，是另一个人（或几个人）完成的——因为主角团改变了原执行者的因果：他的性格被经历重塑、他的时机被推移、他的手被换掉。历史记下的名字没变，**真相里换过人**。
- 风险：置换不能是猎奇换皮——换的人必须比原执行者"更该"做这件事（因果链更顺、人物弧更完整）。
- 判据：揭晓时读者回看要能对上——"原来前面那些铺垫都是在换这根弦"。

### 模式 C · 历史吸收（主角团推动，传说记错功劳）
主角团（红云+邻居网+镇元子+各位善缘）的推动真实发生在事件里，但**传说把他们的活记成了 canon 的注脚或别人的功劳**——他们成了历史无名的手。
- 这是"迪化"的历史学放大版：散修迪化云鹤，历史迪化所有人。
- 判据：主角团的 fingerprints 必须可回溯（读者看得见），但世界看不见——**知情的只有读者**，这是本书读者独享的爽。

### 模式 D · 结局改写（canon 事件走向新的结局）
事件名还在（十日凌空/封神），但**结局本身被改写**——因为主角团的推动或因果链的重构，历史在这里拐弯。本书已有先例：太一假死（"陨落"没发生）、通天免贬、孔宣隐退——都是结局级改写。
- 风险：读者预期落差（洪荒情怀党可能抵触"标志性结局没了"）——对冲办法：**改写的结局要给"更疼或更爽的补偿"**（太一没死→帝俊装不知道的独裁悲剧——比原结局更疼）。
- 判据：改写后的结局必须比 canon 版**更贴本书主题**（人心 vs 天道），否则只是为改而改。
- 工程账：动结局前盘下游链条（§一.3），决定链式重构还是局部改写。

## 三、推动力三源（每个重述事件的"为什么会这样"必须落在其中至少两源）

1. **命运的结构性**：量劫守恒——劫力找因果最薄弱处落，事件"必须发生"是因为账必须平（机制基础=因果调度机制的守恒律）。
2. **人物的不可逆选择**：性格即命运——每个角色走到那一步，是他全部经历的必然（canon 内核锚定底色 + 本书经历重塑路径）。
3. **主角团事件的具体传导**：主角团做过的某件事，改变某人某物的状态，该状态在事件里起作用。**传导链必须具体可指**（哪件事→改变了谁→在事件的哪一环起了什么作用），禁止"大势所趋"式含糊。

**禁止偷懒解释**："历史惯性""天数使然""冥冥之中"——这些词在正文和细纲里禁止作为因果交代（幕后纪律的禁词也适用）。"天数"只能作为角色的**主观感叹**，不能作为叙事的客观解释。

## 五、写作纪律

1. 每个卷纲大事件条目必须标注：**【重述模式 A/B/C/D】+【推动力三源命中哪几源】+【传导链】**——三缺一的按未完成设计处理。
2. 人物底层设定可适配本书（"更符合我们的小说"），但 **canon 内核优先原则**不变：读者要认得出"这是后羿/这是共工"，认出的那一刻才会在"原来他为什么这么做"上被击中。
3. 重述的自检问题（每个事件问一遍）：
   - **canon 版与本书版的因果对比**：原著给的"为什么"是什么？我们给的"为什么"是否更合理/更贴主题？——**选因果更好的那版**，这是所有决策的最终判据。
   - 拔掉主角团的影响，这个事件的 canon 版还成立吗？（成立=canon 本来就有；不成立=我们的重写真正参与了因果——**两种都可以，但要自知**）
   - 读者知道真相而世界不知道的部分（模式 B/C）在哪一章兑现"原来如此"？
   - 有没有撞车？（调研表：已见过的重写版本——撞车即换方向）
4. 与导航失效引擎联动：主角知道 canon 结局（骨架），但每次过程重写都在制造他的知识盲区（血肉）——**骨架锚定恰恰是悬念的来源**：读者知道"后羿射日会发生"，不知道"我们这个故事里它是怎么被推动成这样的"。
