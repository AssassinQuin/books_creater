## 一、知果改因 · 四步详解

### 一句话

红云知结局→寻因→改因→结果变不变取决于**有没有圣人把这个结局当棋子**。

### Step 1 · 知果

红云前世读过洪荒小说，知道著名事件的结局：
- 红云被围杀身死
- 太一帝俊巫妖战陨
- 后土化轮回
- 通天封神被贬
- 截教封神败

**局限**：小说只给结局大纲，不给过程细节；干预后世界偏离小说→结局知识逐渐失效。

### Step 2 · 寻因

从结局倒推：是什么**因**导致了这个**果**？
- 太一死 ← 因：巫妖决战，太一持混沌钟参战
- 夸父死 ← 因：十日凌空（帝俊十子恃权巡天），夸父追日
- 后土化轮回 ← 因：天道需六道轮回 + 后土慈悲不忍心

### Step 3 · 改因

在因果链关键节点**行动**——改变/阻断/推迟"因"的发生：

| 手法 | 说明 | 例 |
|------|------|----|
| **间接影响** | 通过信息/建议/布局影响关键角色决策 | 提醒帝俊管束十子→十日不凌空→夸父不追日 |
| **精准缺席** | 自己不在某事件现场 | 不让座→不结鲲鹏怨 |
| **机缘利用** | 利用洪荒散落的灵宝/功德/遗泽增强行动能力 | 散敌人魂魄→让特定角色无法参与某事件→间接影响走向 |
| **因果转嫁** | 祸水引向该承之人（核心调度操作） | 接紫气但布局转嫁→鲲鹏/冥河自相残杀 |

### Step 4 · 应对涟漪

这是最关键的部分。红云改了因，结果**不一定**变——取决于圣人棋局：

| 情况 | 结果 | 原因 |
|------|------|------|
| 这个结局**不是**任何圣人的棋子 | **改变** | 没人会出手维持→因果链断了→结果变了 |
| 这个结局**是**某圣人的重要棋子 | **不变**（圣人出手维持） | 圣人发现因果链被改→通过其他手段推动→让结果仍然发生 |
| 这个结局**牵涉多个圣人**的博弈 | **部分改变** | 圣人之间也在博弈→红云的干预成为新变量→各方重新布局 |

**例子**：
- 红云阻止赵公明一次下山（卷四·灵脉冲突化解）→ 赵公明没下山 → 但赵公明下山有**多层因果**（截教弟子被杀的不忿+通天面子+同门义气）→ 红云只断了第一层 → 赵公明仍因其他因果下山 → **改因有极限：你断一条因果链，其他因果链补上**
- 红云救太一假死（卷三）→ 太一不死 → 但太一是巫妖量劫的应劫者 → 天道需要有人应劫 → 劫力转移 → **后果落到了后土身上**

## 二、不是什么（4条否定）

| 否定 | 说明 |
|------|------|
| **不是超能力** | 他不能"看到因果链"或"切断因果线"——只是凭前世记忆推理 |
| **不是新规则** | 他没有创造"因果调度"这个系统——他只是一个知道未来的人试图改变未来 |
| **不是全知** | 小说只给结局大纲，不给过程；现实可能与小说有差异；干预后世界偏离小说→结局知识逐渐失效 |
| **不是万能** | 个人力量有限（金仙~准圣级），不能强行改变大势；圣人比他聪明比他强，他们的棋局他看不穿 |

## 三、两条地基法则（不可魔改）

> 这两条是洪荒世界的底层物理定律。红云不能违反，只能利用。

### 3.1 因果守恒律

**一笔命债/劫数不灭不消，只流转。救A免死，死果必落B。**

- 你救了一个人 → 死果不会消失 → 它会沿因果链找下一个薄弱点落下
- 红云救太一不死 → 劫力转移 → 后土承劫
- **推论**：改因不是免费的——每改一次，代价以某种形式转嫁

### 3.2 劫力趋同律

**劫力沿因果链找最薄弱/欠账最多的点落点。**

- 因果债越多的人/族群，越容易被天道选为应劫者
- 截教"有教无类"→ 门下杂 → 招业多 → 因果积累远超阐教 → 封神量劫清算时截教承受的清算量也远超阐教
- **推论**：善良本身就是一种因果负债（通天的悲剧=善念导致因果积累）

> 详见 [世界观总纲 §1.3](世界观总纲.md#13-因果守恒律不可魔改地基) · [参考资料20 第四层](../../../参考资料/洪荒流/20-完整因果链总工程图.md)

## 四、改因的极限

### 4.1 断一条链，其他链补上

因果不是单线，是**网**。红云断了一个节点，其他因果链会绕过来补上。

```
赵公明下山因果链（多层）：
  ① 截教弟子被杀的不忿
  ② 通天的面子
  ③ 同门义气
  ④ 申公豹挑拨

红云断① → ②③④仍在 → 赵公明仍下山
```

### 4.2 守恒反弹

改因产生的代价以三种形式反弹（不是红云创造的规则——是世界既有的因果/量劫/守恒法则在自然运转）：

| 反弹类型 | 机制 | 例 |
|---------|------|----|
| **劫力转移** | 量劫需要应劫者，A不死了，劫力落向别处 | 救太一→后土承劫 |
| **蝴蝶效应** | 干预创造新变量，产生无法预判的连锁反应 | 改因后世界偏离小说→结局知识失效 |
| **圣人反制** | 如果这个结局是圣人的棋子，圣人会出手维持 | 红云帮通天→元始联合准提→四圣围通天 |

## 五、圣人博弈表

> 红云不是唯一的玩家。圣人各自有利益/算计/棋局。
> 详见 [世界观总纲 §7.3](世界观总纲.md) · [参考资料22 主题二](../../../参考资料/洪荒流/22-圣人博弈与算计深度拆解.md)

| 圣人 | 棋局 | 红云改因时的对抗 |
|------|------|----------------|
| **鸿钧** | 以紫气养红云作应劫靶子→借红云身死拿人道规则 | 红云改因逃离死局→鸿钧通过天道系统追踪/布局→杀棋针对"高深版红云"布→卷五落空 |
| **元始** | 打压截教→封神清账→阐教胜利 | 红云帮通天→元始联合准提→四圣围通天 |
| **准提** | 西方贫瘠→扩张→收截教残余→佛教大兴 | 红云改因影响封神格局→准提用元始给的凭证穿战线收人 |
| **女娲** | 造人→护人族→等有人替她护人族 | 红云改因影响人族→女娲暗中观察→终局给红云后手 |
| **通天** | 有教无类→万仙来朝→但门下招业→封神应劫 | 红云帮通天→通天免贬 |
| **老子** | 无为中深谋→化胡为佛分佛教气运 | 红云发现化胡暗线→"人道版化胡"层次更高 |

> **核心张力**：红云在改因，圣人也在布局。他改了一个因，圣人可能通过其他手段让结果不变。这是一场**信息不对称的博弈**——红云知道结局（信息优势），但圣人比他强比他聪明（力量/算计优势）。

## 六、红云策略5阶段

| 卷 | 策略阶段 | 特征 | 关键事件 |
|----|---------|------|---------|
| 一 | **盲目改因** | 只知结局，试粗暴回避（缺席/不沾/藏），不懂守恒 | 让座/不让座的纠结→改了一个因后果乱落→越避越深 |
| 二 | **领悟代价** | 真死被救→切身体会"改因有代价" | 从"盲目改因"到"知道改因有后果" |
| 三 | **试手改因** | 主动寻因改因。发现蝴蝶效应不可控 | 救太一→劫力溢出→后土承劫。改因的道德代价 |
| 四 | **多步布局** | 更精准地寻因改因，多步布局。但发现圣人也在布局 | 他的暗子被鸿钧破了 |
| 五 | **终极改因** | 不是改某个事件的因，是**改变整个棋局的结构** | 立人道=给天道体系加了新变量→所有圣人的棋局都被打乱 |

## 七、canon 边界（哪些可改·哪些不可改）

### 不可改（硬法则·天道既有）

- 因果/量劫/功德/业力/气运（洪荒原生法则）
- 圣人不可硬刚（红云天花板=准圣）
- 量劫因果根（龙凤争霸/巫妖世仇/阐截道统争）
- 因果守恒律 + 劫力趋同律

### 可改（命运细节·人物意志·紫气性质）

> 详见 [魔改决策记录](魔改决策记录.md) · 13项魔改清单

| 可改类型 | 例 |
|---------|----|
| 人物命运细节 | 太一假死隐存/通天免贬/后土被动承劫 |
| 紫气性质 | 紫气=应劫标记（非单纯成圣机缘） |
| 人物意志 | 鲲鹏复杂化（怨中有苦）/后土被动化 |
| 穿越机制 | 穿越成普通散修云鹤/云道苦练成长/知果改因（2026-08-10 重构：旧版"化形=穿越触发/力量封印"已废弃） |
| 结构概念 | 火云洞人道规则=遁去的一（合一） |
