## 一、基底：因果与守恒律（不可动）

- **因果**：每果必有因，每因必结果；因果成链，跨量劫不灭。
- **因果守恒律（★第一硬法则）**：一笔命债/劫数**不灭不消，只流转**。救 A 免死，其死果不消失，只转移——必落 somewhere/someone。
- **量劫 = 天道调度因果**：众生因果积累到临界，天道降量劫清账。天道是因果的"总调度"，红云要抢在天道之前，**自己手动调度**。

> 这三层是洪荒原生（量劫清算）+ 本书强化（守恒），**不可魔改**，是地基。

## 三、因果调度三步

### Step 1 · 识链（认人 + 观察 + 逆向推断 + 试错）
只知结局 / 不认人，识链极艰辛（**拼图，非看穿**）：
- **认人对号**（谨慎试探，认错风险——信息差体系，见第四节）。
- **观察**（亲身经历，补全细节）。
- **逆向推断**（从结局倒推因）。
- **试错**（谨慎干预验证，但守恒反噬 / 蝴蝶效应令推断失效，反复修正）。

### Step 2 · 断链（断因）
在因果链关键节点缺席 / 不参与 / 布局阻断，使死果不落本该死的人头上。
> 红云的"苟 / 不沾"即此步原始形态——盲目断链致守恒死果乱落（早期绝望之因）。

### Step 3 · 调度（转嫁 / 化解）★核心
断链后守恒死果仍要落，红云须调度：
- **转嫁**：把死果引向**该承之人**（罪人 / 敌人 / 注定死者 / 自愿者），不害无辜。
- **化解**：以功德 / 布局令死果消解（功德抵业 / 令天道账平），无人需承。最难，后期方成。**终极化解 = 借火云洞人道规则化劫**（见第六节）。

### 推导链路
```
① 知结局：大能 X 命定死于劫 A，因因果链 C。
② 识链：拆 C 节点（认人对号→观察→推断→试错，拼图式）。
③ 断链：于某节点缺席/阻断，X 不死。
④ 守恒警报：X 不死→劫 A 因果未足→死果转移。
⑤ 调度决策：有该承之人→转嫁；功德/布局足→化解；两者皆无→不敢动（或硬动害无辜）。
⑥ 执行布局。
⑦ 蝴蝶效应：改 X→剧本飘移→结局知识失效→重新识链。
⑧ 守恒反噬：改命招天道反推→新麻烦。
```
> **成熟标志**：从"只会断链（盲目苟）"→"断链+转嫁该承之人"→"断链+化解（不累一人）"。

## 四、信息差体系（认人悬念 ⊃ 迪化，合一）

> 机制减法：迪化与认人悬念都是信息差装置，**合为一套**。

- **认人悬念（主装置）**：红云知结局但不认人——谨慎对号 + **认错风险**（把好人当坏人防 / 坏人当好人近）。认错 = 被自己的结局知识误导。
- **迪化（认人悬念的衍生）**：红云的谨慎试探 / 藏拙，被别人误读成"高深"——本质也是信息差（别人不知道他真不懂）。**后期他识破别人脑补后，会故意演**（夺回主动权）。
- **一套信息差体系**：认错人（他被自己误导）+ 迪化（别人被他误导）= 双向信息差，不再分两套装置。
> 认错人反转全书只用 2 次，但必须有**严重后果**（付出代价），落到具体剧情单元。

## 五、canon 边界

### 使用（保持 canon，作约束素材）
- 因果守恒 / 量劫清算（洪荒原生，本书强化为硬法则）。
- 圣人不可硬刚（红云战力天花板远低于圣人；人道规则是规则制衡，非战力）。
- 量劫因果根（龙凤争霸杀业 / 巫妖世仇 / 阐截道统争）。
- 主要人物命运骨架（谁死于何劫）= 红云要改的对象。

### 魔改（为机制与戏剧）
- **应劫者可调度**：canon 应劫者命运指定；本书改为劫的因果债需有人承，但承者可调度（红云操作空间）。
- **紫气 = 应劫标记**：canon 紫气是成圣机缘；本书改为紫气同时是天道标定的应劫靶子（得紫气 = 被天道盯上作消耗品）= 红云必死机制解释。
- **化形 = 穿越触发**（canon 无）。
- **各必死角色命运改写**（太一假死隐存 / 后土被动承劫 / 通天免贬 / 夸父仍死 / 孔宣沦坐骑等）。
- **金蝉脱壳两层**（见六）：canon 红云真死；本书改为应劫假死 → 反算鸿钧。
- **后土被动承劫**：canon 后土化轮回是命运/大爱；本书改为她**因不忍心救小人物 → 破因果 → 反噬被动承劫**（A+B 被动版，**非主动赴死**）。详见 [深度关系弧线.md](深度关系弧线.md)。
- **鲲鹏复杂化**（怨中有苦，可救赎 / 可利用，终成棋子）。
- **鸿钧封印约束**（见六，修 bug）：canon 鸿钧合道超然；本书改为鸿钧**不能直接动火云洞**（规则层封印），只能借应劫者身死间融合——绕路有硬约束。
> 原则：硬法则（守恒 / 圣人 / 量劫根）不魔改；命运细节 / 人物意志 / 紫气性质 / 金蝉脱壳可魔改。魔改服务因果逻辑，不破坏洪荒框架。

## 六、核心设定（机制减法后）

### 金蝉脱壳 · 两层（砍自四层）
原四层（应劫 → 云中子归位 → 本体化劫 → 反算鸿钧）**砍为两层**：
1. **应劫假死**：红云 seemingly 死于必死劫——众人 + 鸿钧以为棋成。
2. **反算鸿钧**：红云没死——借火云洞人道规则化死劫（劫力润人族）+ 云中子福报面归位（黄河阵引爆身份）+ 本体升格人道圣者 + 反手用火云洞（鸿钧真目标）制衡天道。**云中子归位与人道化劫并入"反算"的组成部分，不再各占独立反转层。**
> 两层反转更酣畅、不堆叠；机制根：**人道高于因果**（人心高于账本），故能化天道死劫。

### 火云洞人道规则 = 遁去的一（合一）= 鸿钧真目标 = 红云抗天筹码
> 机制减法：人道规则与遁去的一都是"天道算不尽的变数"，**合一**。
- **遁去的一 = 人道规则**：天道算不尽的变数，其本质是人道规则（人族气运 / 人心是天道也要让步的底层规则）。不再分设两套。
- 火云洞下蕴人道规则 / 崆峒印。鸿钧以紫气饵养红云的真目标 = 火云洞人道规则（借红云身死融合紫气与人族气运）。
- **伏笔前移**：卷一火云洞初探就埋（红云察觉异常但不懂），卷二/三逐步显化，卷四识破——读者跟红云一起摸出来，非结局临时救兵。
- 本书红云没死，火云洞在手 → 反成抗天筹码。终局借人道规则化死劫、立人道制衡天道。
- 人道规则**高于因果**（人心高于账本），故克冥河杀剑、化天道死劫。

### 鸿钧封印约束（修 bug）
- 鸿钧合道，但**不能直接动火云洞人道规则**（规则层封印——天道与人道是制衡的两层，天道不能单方面改人道）。
- 所以鸿钧只能绕路：以紫气饵养应劫者（红云），借红云身死瞬间融合紫气与人族气运、间接掌控火云洞。
- 这个硬约束让鸿钧的绕路（养红云）**逻辑自洽**（非随意），也解释了他为何不直接动手。

### 云中子 = 红云命数化人（独立的人）
- 卷二红云被救，代价是一段命数 / 劫数溢出化成**独立灵魂**（非分身 / 转世，是全新的人）。
- **命数分裂**：福报面 / 善因面 → 云中子（→阐教福德之仙）；劫数面 / 死劫面 → 红云本体（倒霉不断紫气招祸）。
- 云中子是独立的人，有自己的意志与弧，非红云工具。封神反算的关键组成（福报面归位）。

### 紫气部分被夺 + 守恒顺延
- 卷二围杀，红云紫气**部分被夺**：本体留部分（祸根兼筹码），被夺部分落鲲鹏 / 冥河（反派起变化）。
- 红云没死 → 必死劫**顺延**成封神必死劫（守恒），贯穿卷三~五，是金蝉脱壳的硬必然。

### 冥河 = 因果调度天敌
- 冥河元屠阿鼻双剑"**杀不沾因果**"——红云能转嫁因果，冥河能杀不沾因果，二者天然互克。
- 机制意义：给因果调度设天敌，避免无敌化。终局被人道规则（高于因果）所破。
- **机制反衬（藏在剧情，叙事不 judge）**：冥河逃账（杀不沾因果）vs 后土认账（被动承劫化轮回）——认账的反而是超越。

## 七、支线因 + 人物改变因（要点）

因果调度的每步操作荡开**支线因**（下游因果），并**改人物**（内在弧光）。下表精简，详细弧光见 [深度关系弧线.md](深度关系弧线.md) + [人物与关系.md](人物与关系.md)。

| 操作 | 支线因（荡开） | 人物弧光 |
|---|---|---|
| 断链（救太一） | 太一隐存→妖族残部连锁 | 太一：张扬天帝→蛰伏隐者 |
| 守恒转移（救太一→劫落后土） | 后土被动承劫→化轮回 | 后土：悲剧镜像（红云照见自己） |

## 八、成熟度曲线（v2.3 对齐红云成长流）

- **卷一（盲目断链）**：只会断链原始形态（缺席 / 不沾），不懂守恒，死果乱落、越避越深。
- **卷二（窥隙萌芽）**：真死被救，初窥因果缝隙（意识守恒律）——从"盲目断链"到"知道死果要落"。悟法萌芽。
- **卷三（试手转嫁）**：悟三步链路，试"断链+转嫁"，时有失败或道德崩塌。**后土被动承劫 = 红云照镜**（不走硬救路）。
- **卷四（布局成熟）**：稳定"断链+转嫁该承之人"；化解未成。同期识破火云洞人道规则（伏笔前移到此显化）。
- **卷五（化解 · 金蝉脱壳两层）**：悟"化解至无人受损"——借火云洞人道规则化顺延死劫（劫力润人族）、反算鸿钧、立人道。
