> 目的：给配角更鲜活的人设质感（表现层），让他们与原典洪荒故事、与红云碰撞，产生迪化 + 喜剧火花。

## 一、重构纪律（边界·必读）

1. **内核不改，只改人设**（★第一准则）：
   - **内核（不改）**：动机、道德底色、能力、命运骨架、核心关系——来自原典，是辨识度。
   - **人设（改）**：表现层——行为风格质感、说话腔调、反差、梗、喜剧节奏。
2. **人设质感用"经典小说/动漫角色原型类型"锚定，不用现代职场/社会身份类比**（★第二准则）：
   - 用动漫/小说里被验证过"好看"的**原型类型**（如悲情宿敌、佛系老头、幕后棋手、没落贵族主母、天选福将……）来定型质感。
   - 用原型描述**行为特征与画面感**，不绑死某个具体角色（避免缝合/出戏），也不写"高管/CEO/打工人/内卷"这类现代职场词进设定与正文。
3. **服务剧情**：碰撞火花要产因果 / 推关系 / 兑论点，不是纯段子。
4. **与迪化咬合**：配角的人设质感让他们更易迪化红云（双向喜剧）。
5. **悲剧底色不被淹没**：喜剧是调剂，红云的宿命孤独感是主轴；喜悲同源，梗来自信息差/错位/人设固有反应，不靠降智。

---

## 二、碰撞机制（火花怎么产生）

- **双向迪化**：红云真茫然（试探/藏拙），配角用自己的人设逻辑解读成"高深"。
- **信息差喜剧**：红云知结局，配角不知；配角的意气风发/认真较真反衬红云"知命却不能说"的憋悲——喜悲同源。
- **人设 vs 原典事件**：配角的固有质感撞进原典大事件（让座/量劫/封神），固有反应被放大，出火花。
- **错位博弈**：两角色各用各的逻辑误读对方（红云怂 vs 鲲鹏觉他在演），怨/缘越结越深。

## 三、配角人设重构（按戏份/卷排）

> 格式：**内核（不改）** / **人设原型（小说·动漫类型）** / **碰撞火花** / **功能**。

### 镇元子（卷一主场 · 红云挚友）
- **内核不改**：地仙之祖 / 人参果树主人 / 厚重沉稳 / 红云挚友 / 卷二被调虎离山愧疚成共谋者。
- **人设原型**：**【守园人型 · 不敢拥有的佛系老头】**——表面万事慢三拍、与世无争、什么都有所以什么都不急；内核是"拥有=靶子"的恐惧让他活成孤岛。不投入就不怕失去，是几万个元会看太多陨落淬出来的生存哲学。触他底线（动树/碰红云）时暴起，用最温和语气说最狠的话，打完坐回去继续喝茶——不可预测才是他真正的威慑力。
- **碰撞火花**：红云的认人试探被他当"论道考校"认真点评半天（表层喜感）；深层碰撞是**镇元子"不敢拥有"被红云逼到面对——他最怕的事（在乎的东西被夺走）在卷二应验，此后每一步陪红云都是在赌自己敢不敢继续在乎**。喜转悲的根不是"他没救成朋友"，是他的人生哲学碎了。
- **独立焦虑**：人参果树/地仙界安危（龙凤/巫妖/封神量劫波及先天灵根）。表面不在乎，实际独自巡山、加固地脉、计算量劫余波对万寿山的影响——不说、不做声、不让任何人知道他在怕。
- **语言指纹**：自称"老朽"（红云面前偶尔滑成"我"）；好说"倒也""却也""倒罢了"三字缓冲；紧张时反而丢口癖变短变硬；愤怒时一个字一个字说，越怒越慢。对话样本——*"老朽这万寿山啊，别的没有，清静倒还剩些。你那火云洞与我这儿相邻，倒也好。红云，你若又要往巫妖那边去，趁早别告诉我。告诉了我也拦不住，反倒让我这几天茶喝不踏实。"*

### 鲲鹏（贯穿 · 对手/棋子）
- **内核不改**：妖师 / 能力强有抱负 / 让座结怨 / 背叛 / 怨中有苦 / 终成棋子。
- **人设原型**：**【悲情宿敌型 · 执着努力家】**——动漫经典的"能力极强却总差一步、较真记仇、有苦衷的宿敌/追赶者"。拼命追、永远差临门一脚、怨气滚雪球、胜负心极重；不滑稽到崩，是又惨又拧。
- **碰撞火花**：红云真怂想避让座（缩后/推托），鲲鹏解读成"他在演我 / 以退为进"——**双向误会**，鲲鹏越较真，红云越懵，怨越结越深。卷二围杀他紫气只夺到部分（红云没死透）——"连怨都没报痛快"的悲情宿敌崩溃。
- **功能**：错位博弈对手 / 认人悬念最大陷阱（红云知他会害，认不全他各阶段形态）/ 棋子反转的悲喜。

### 鸿钧（幕后 · 卷五正面）
- **内核不改**：合天道 / 算计 / 紫气饵养红云 / 真目标火云洞人道规则。
- **人设原型**：**【幕后棋手型 · 高维乐子人】**——动漫/小说的"把众生当棋、永远从容算计、偶露冷幽默的幕后掌控 BOSS"。不怒不笑、话留半句、一句轻描淡写定全局；幽默是细思极恐的冷幽默。
- **碰撞火花**：算尽一切，唯独算不准"遁去的一"（红云变数）。红云在他面前如芒在背却不知为何（只知"鸿钧合道"结局）。**卷五红云反将一军**——掌控者的翻车预告。
- **功能**：压迫感来源 / 终局反转对手 / 红云弧线"抗天"的靶子。

### 元凤（卷一种因 · 卷二兑 · 孔宣线）
- **内核不改**：凤族之主 / 族责族傲 / 被救 / 凤族仍衰（守恒）/ 牵挂孔宣。
- **人设原型**：**【没落贵族主母型 · 骄傲慈母】**——动漫的"落难也端着、恩怨分明、为族为子的亡国公主/贵族主母"。架子不倒、重体面、恩必报；重伤坠逃也是骄傲的。
- **碰撞火花**：红云当她无名伤者草草救（没问姓名），她却把红云当"看穿她身份仍平等相救、不居功的大慈悲者"——**她越郑重报恩，红云越心虚**（我真是顺手）。卷二她循因果溯源来救红云，红云方知当年无名伤者是凤族之主。
- **功能**：端着 vs "我真是顺手"的反差 / 救命网主环① / 孔宣母子线的母。

### 后土（卷三主场 · 悲剧镜像 · 同路人）
- **内核不改**：慈悲祖巫 / 化轮回（被动承劫·非主动选择）/ 全书唯一不迪化红云的人。
- **人设原型**：**【清醒的无力者型 · 走在前面的人】**——看透一切却挡不住不忍心的祖巫。巫族里的异类（以战为荣的巫族中，她的力量是"承载"非"破坏"）。安静不是因为超脱，是已经看透结局，沉默里全是压抑的不甘。蹲下来救护是本能，起身就走不接受感谢是克制。
- **碰撞火花**：全书唯一不迪化红云的人——别人看到"高深大能"，她看到"一个想活的人在恐惧"。她不说破、不揭穿，只在只有红云能听到时轻描淡写一句"你在算自己会不会死吧"——太准了，被理解的震颤。红云失去她=失去洪荒唯一不用演戏面对的人。
- **语言指纹**：短句+沉默（一句不超过十个字）；对红云专用"你啊——"起手没说完就停住；安慰只说"我在"两个字；叫红云从不加"道兄"。离别时说出全书最长的话（也才两句）：*"你啊，明明怕死怕得要命。偏偏每一次，都跑回来。"*
- **功能**：红云的悲剧镜像（同一种善良不忍心→破因果→反噬，她走在前面）/ 全书最重离别 / 不迪化的独特视角。

### 云中子（卷二诞生 · 卷四显 · 卷五引爆）
- **内核不改**：红云命数化人（承福报面）/ 独立的人 / 阐教福德之仙 / 不知来历到独立成道。
- **人设原型**：**【天选福将型 · 好运憨憨】**——动漫的"运气逆天到自己都懵、憨厚本分、身世成谜的天选队友"。总"这次怎么又没事？"、爱琢磨、憨厚；不知来历的困惑是成长钩。
- **碰撞火花**：他躺赢（福报面）vs 红云本体倒霉——**一体两面，命运天差地别**。红云远观这个"自己命数化出的人"风生水起，欣慰又荒诞。卷五黄河阵他身份引爆，福将才知自己"从哪来"。
- **功能**：福报面 vs 劫数面的命运对比 / 封神脱壳钩子 / "独立的人"弧光。

### 太一 / 帝俊（卷三主场 · 巫妖）
- **内核不改**：太阳星先天神祇 / 建妖族天庭 / 兄弟 / 有妻有子 / 会陨。
- **人设原型**：**【热血兄弟档型 · 巅峰搭档】**——动漫的"一热一稳、拌嘴互怼、感情深、走向悲剧的热血兄弟/搭档"。太一热血爱放豪言，帝俊稳重像操心的老妈子；巅峰期的张扬热闹。
- **碰撞火花**：红云知他们结局（妖庭崩/身死），看他们意气风发拌嘴放豪言，**内心"你们快完了"却不能说**——他们的热闹反衬红云的知命孤独。红云断链救太一（假死隐存）→ 太一从张扬天帝变蛰伏隐者。
- **功能**：热血兄弟的热闹群像 / 红云"知坏结局憋悲"的载体 / 救太一的形态转变。

### 通天（卷四~五 · 封神）
- **内核不改**：截教主 / 有教无类 / 重情义护短 / 被贬。
- **人设原型**：**【义气大哥型 · 护短掌门】**——动漫的"重情重义、护短到傻、明知坑也跳的豪爽领袖/掌门"。广收徒、有教无类、不耍心眼；义气到让人又敬又急。
- **碰撞火花**：红云想断链救他（免贬），他重义气明知坑也替徒弟扛——**红云的"算计"遇到通天的"义气"，救不动**。红云救通天=截教不全灭=孔宣取舍沦坐骑（元凤之子的网荡回红云）。
- **功能**：护短大哥的热血 / 截教群仙热闹群像 / 红云"断链也有救不了的"之痛。

### 冥河（贯穿 · 因果克星）
- **内核不改**：血海之主 / 元屠阿鼻杀不沾因果 / 谋成圣 / 因果调度天敌。
- **人设原型**：**【阴魂不散型 · 偏执复仇者】**——动漫的"记仇到偏执、打不死甩不脱、死缠烂打的宿敌/复仇鬼"。阴魂不散、"又来了"、死守老巢；执念深到变态。
- **碰撞火花**：他追红云（因果克星），红云躲；"**又来了**"的执念喜感。他杀不沾因果 vs 红云调度因果——两个"因果漏洞利用者"互克。终被人道规则（高于因果）破——**偏执复仇者的终极翻车**。
- **功能**：持续威胁 / 认人悬念紧张源（他来要命）/ 终局克星被破的爽点。

### 伏羲 / 女娲（背景→卷四暗线 · 人族/火云洞）
- **内核不改**：人族始祖 / 女娲造人补天 / 伏羲演八卦 / 勾连火云洞人道气运。
- **人设原型**：**【创世神祇型 · 互补夫妻】**——神话/动漫的"高维造物主、一冷神性一温理性、俯瞰众生的夫妻档"。女娲冷疏离+对自己造的人母亲式操心，伏羲温润理性爱推演；一冷一温。
- **碰撞火花**：红云凶兽期救伏羲（不认得，善缘②），伏羲欠恩。女娲补天/造人红云知结局。**火云洞（三皇居所）= 鸿钧真目标**，伏羲女娲一脉是人族气运关键——卷四红云渐察、卷五握成抗天筹码。
- **功能**：造物主夫妻反差萌 / 善缘② / 人族气运暗线 / 火云洞抗天筹码来源。

## 四、喜剧节奏控制（不淹没悲剧底色）

- **红云是悲喜的锚**：他茫然、孤独、知自己必死——无论配角多热闹，主视角的宿命感始终在。配角的喜是"红云眼里的洪荒众生相"。
- **喜悲同源**：太一帝俊的热闹 → 因红云知他们必陨，热闹才悲；镇元子的吐槽 → 因卷二他会愧疚，喜才转悲。**喜剧是悲剧的铺垫，不是逃逸。**
- **密度分层**：卷一（自保期）迪化反差喜剧最密，给读者入口；卷二（死而复生）喜剧收、悲起；卷三（后土拒救）悲核；卷四（抗天）紧张；卷五（立道）悲壮升华。**喜感随弧线递减，厚重感递增。**
- **梗的来源**：信息差（红云知结局）/ 错位误会（双向迪化）/ 人设固有质感撞事件——不靠降智、不靠现代网络流行语/职场黑话出戏（洪荒语境内的梗）。
