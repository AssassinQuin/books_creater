## 一、红云的性格与知识（v2.3 地基）

### 性格：谨慎 + 苟 + 底牌多 + 倒霉（实力不弱，非弱鸡）
- **谨慎（核心）+ 苟**：凡事谋而后动；藏拙、留后路、不沾因果、避死劫。行动准则：不算清楚不动 → 动前算尽后路 → 动后清理不沾因果。**但不代表被动——算准了就出手，且干脆利落。**
- **有实力但不熟悉（成长流，非一上来碾压）**：准圣修为 + 九九散魄葫芦（先天灵宝）是这具身体本有的，但**穿越者红云不会用 / 不知全貌**——他不熟悉这具准圣身体的实力、不知道葫芦的全部能力。**慢慢摸索、学习、解锁自己的力量**（从不会用到会用、从用不好到精通）。爽点 = **解锁 / 精通**（每次新掌握一种力量、解锁葫芦新用法 = 成长进阶的爽，**不重复套路**）。
- **底牌是"摸索出来的"**：他的多个后手 / 手段 / 法宝，是**边摸索边积累**的（不是开局全有）。谨慎让他慢慢把"不会用的力量"变成"底牌"，越往后底牌越多、手段越多样。
- **成长线总览（每卷解锁节点 · 战力天花板=准圣，始终打不过圣人，靠因果调度+人道规则补）**：
  - **卷一·基础**：化形即有准圣+葫芦但**不会用**；摸索出基础准圣力量运转 + 葫芦第一层（散魂）。**首解锁爽点 = 第一次笨拙催动葫芦散凶兽**。
  - **卷二·进阶**：围杀实战逼出葫芦进阶（红霞威压 / 护体）。从"会基础"→"会进阶"。
  - **卷三·精通**：巫妖大战 + 因果调度中，解锁葫芦精准用法（锁定 / 定向）+ 准圣神通（祥云防御 / 转移），精通配合因果调度。
  - **卷四·上限**：沉淀深研，触及葫芦隐藏上限 / 先天灵宝级威能，准圣力量磨到极致。
  - **卷五·质变**：借人道规则，准圣+葫芦+人道产生质变（人道圣者，规则级非战力级），终局碾压 / 反算。
  - **天花板约束**：再怎么成长，圣人层面（鸿钧 / 三清）仍碾压他——所以他必须靠因果调度 + 人道规则，不是战力硬刚（保留"倒霉 / 被圣人碾压"的张力）。
- **倒霉（核心张力）**：紫气招祸 / 必死劫 / 被天道盯上作应劫棋。**他的困境不是实力不够，是命数太差**——明明不弱、底牌多、谨慎，却处处遭灾。**"有实力却被命运针对"是红云的核心张力与共情点**（区别李长寿的稳健+好运，红云是稳健+底牌多+倒霉）。
- **老好人善良（张力）**：谨慎/苟说"别沾"，善良说"救/让"。两股博弈——有时谨慎胜（避掉），有时善良胜（救了/让了，但用谨慎的方式：草草救、不问名、匆匆走）。
- **迪化（升级：被迪化 → 故意演）**：早期谨慎的藏/避/布被脑补"高深"（被动）；**后期他识破别人脑补后，会故意演**（夺回主动权，从"被误读"升级为"利用误读"）。

### 知识层：只前世记忆（近乎无金手指）
- **蓝星普通人**，读过洪荒流小说 / 神话。
- **无洪荒本体记忆**：不记得自己是"红云老祖"，没有红云的任何记忆。
- **不认识人**：见到镇元子/三清/鲲鹏，**根本不认识**（小说里是名字，现实是真人，对不上号）。
- **不知现实**：不知洪荒规则/时局/时间/过程/细节。
- **知小说结局**：红云身死（围杀）/ 太一帝俊陨 / 后土化轮回 / 通天被贬 / 鲲鹏背叛落魄 / 截教封神败 / 女娲补天造人 / 共工触不周山 / 三族龙凤初劫退场 / 罗睺被鸿钧灭 / 鸿钧合道。
- **金手指**：极弱（小说结局 + 可能记错 + 现实与小说有差异），近乎无。
- **靠谨慎**：辨认人、核实现实、防备、试错。

### 亲身经历、谨慎推动（参与者，非旁观）
- **不是上帝视角旁观者**（知剧本操作），是**第一视角参与者**。
- 亲身经历洪荒（从零认人 / 搞清现实 / 应对量劫）。
- 谨慎推动：基于"知结局"想避 / 改命，但**不知过程**，一边摸索一边推——**经历→觉悟→谨慎升级**。

### 与李长寿（《我师兄》）区隔
- 李长寿：纯谨慎 + 多底牌战力（纸人/毒/遁术），轻喜剧调，主动系统化布局。
- **红云：谨慎 + 善良张力（李长寿没有）+ 陌生穿越不认人不知现实**（悲剧底色，茫然艰辛，亲历者）。红云的谨慎是"茫然中的自我保护"，不是李长寿的"系统化控场"。

## 三、认人悬念（★ v2.3 戏剧装置）

红云知结局（谁害他/谁陨/谁叛），但**不认识现实的人**——必须谨慎试探、对号，**且可能认错**。

- **认人对号**：知"鲲鹏会害我"，见到北冥来的大妖，不确定是不是鲲鹏（小说是文字，现实是真人），谨慎试探。
- **认错风险**：可能把好人当坏人防、把坏人当好人近——制造悬念与反转。
- **迪化**：他谨慎试探对方身份时，对方脑补"红云道兄高深莫测，在试探我的道心"（他真不懂，是真茫然被误读）。
- **认知累积**：从"只知结局"→慢慢把小说名字和现实人对上→搞清现实→谨慎布局。认知从零累积，读者跟红云一起拼图。

## 五、配角立体度（各有性格 + 弧线 + 挣扎，与红云谨慎碰撞）

> 配角不知红云穿越，把他当洪荒红云，迪化他的谨慎。每个角色先是一个完整的人。
> **人设原型质感 + 碰撞火花**见 [配角人设重构.md](配角人设重构.md)（内核不改·用小说/动漫原型类型定型，不用职场类比）。本节是性格/弧线骨架，重构档是表现层质感。

- **镇元子**：沉稳厚重的地仙之祖，有自己执念（人参果/地仙界）。首位深度迪化者（红云的谨慎被他读成"造化"）。他也在变：旁观→入局→兜底（卷二被调虎离山的愧疚是转折）。
- **鲲鹏**：让座怨，但有抱负（谋圣位/妖族前途），**怨中有苦**。每阶段动机/挣扎要写——他不是纯反派，是红云"认人"最大的陷阱与对手。
- **元凤**：凤族之主，有族责。被救后凤族仍衰（守恒），她的恩情 + 族衰之痛 + 对孔宣的牵挂。
- **后土**：慈悲祖巫，化轮回是**主动抉择**（非被迫）。拒救是她的觉悟，也是对红云的点化——红云精神上的导师。
- **云中子**：独立的人，承红云福报面。自己成长：不知来历→福德之仙→知承福报面→独立成道。
- **鸿钧**：合天道运转洪荒。以紫气饵养红云，**真目标是火云洞人道规则**（红云起初不知，只知"鸿钧合道"结局，慢慢识破）。
- **太一/帝俊**：太阳星先天神祇，建妖族天庭，有妻有子有事业。红云知他们"会陨"，但要认人对号、谨慎斡旋。
- **通天**：截教主，重情义。红云知他"会被贬"，谨慎接近/布局救。
- **冥河**：血海之主，谋成圣。持元屠阿鼻"杀不沾因果"=红云因果调度天敌。

## 七、涟漪机制（保留 v2 + v2.3 认人/亲历调整）

红云投入石子，涟漪沿人物网多层荡开：
- **认人涟漪**：他谨慎试探某人身份，不只改两人关系，更震响对方所在的那张网（试探鲲鹏→妖族圈震荡）。
- **救命网（卷一种→卷二兑）**：救元凤/伏羲/让座西方/镇元子挚友→卷二多角色合力救红云。
- **救太一→守恒转移**→劫落后土→拒救→点化红云。
- **解十日（迟）**：夸父死/后羿活→夸父后羿的网震荡。
- **救通天**：截教不全灭→孔宣取舍沦坐骑（元凤之子的网荡回红云）。
- **紫气部分被夺**：鲲鹏/冥河各得部分→势力变化→追杀升级+冥河克星显化。
- **必死劫顺延**：卷二没死→封神必死劫→卷五金蝉脱壳化债。

> **涟漪原则**：红云的每次谨慎干预，不只改一个人的命，更震响他所在的那张网。事件永不独立，皆连锁。读者跟红云（第一视角）一起经历涟漪荡开。

## 八、总纪律
1. **性格先行**：剧情从红云的"谨慎 vs 善良/大势"博弈推导，不是事件摆弄人物。
2. **亲身经历**：红云是第一视角参与者，不是上帝视角旁观。经历→觉悟→谨慎升级。
3. **谨慎统摄**：谨慎是红云唯一依靠（近乎无金手指）；主动=谨慎地主动，迪化=谨慎被误读，战力=谨慎保命，弧线=谨慎对象升级。
4. **认人悬念**：知结局但不认人，谨慎对号+认错风险，是新戏剧装置。
5. **人物独立**：每个角色先问"去掉红云他在过什么日子"。
6. **关系是网（多对多）**：人物之间有不经红云的关联，红云是网中一节点。
7. **事件涟漪**：每件事后果沿网荡开，不独立。
8. **因果调度有克星**：冥河杀不沾因果/鸿钧天道/蝴蝶效应/认人错误——因果调度非无敌。
