# 调研报告 · 市井小人物群像技法（反哺火枣墟邻居群）

> 2026-08-14 · B3 调研产出。调研源：凡人修仙传（厉飞雨/张铁/墨大夫）、放开那个女巫（铁斧/巴罗夫/镇民集体）、转生史莱姆（哥布林村命名场景）、洪荒关系户（关系网十大手法）、sitcom ensemble 方法论。
> 用途：火枣墟 5 邻居的**运营机制层**——已织入 设定/火枣墟与散修生态.md §四；写日常戏/善后章时召回本文件。

## 一、十二条操作清单（带书证）

1. **出场即人生切片**——配角登场前已预载几十年人生（厉飞雨出场自带抽髓丸死限+堂主身份）。
2. **人情设账期，交易不结清**——能一次给完的偏分期，强制未来场景（韩立只配一年药"让他不会慢慢遗忘这份人情"·凡人L804）。
3. **弱点即功能**——缺陷当机制用（姜老左耳背=保密机制）。
4. **标签+一个反差瞬间**——一个怪癖比三段描写更让人记住；反差="他还有另一面"（紫苑能干但做饭杀人）。
5. **岗位信息具体到数字**——功能配角首场戏要有可核对的处境细节（哥布林村"一百只、能战六十、敌百余"）。
6. **情感爆发=仪式性动作，不用心理描写**——史莱姆命名场景：把死去儿子的名字托付恩人，付出可见代价（魔素少一半）。
7. **名声先行，借他人视角出场**——铁斧"住在老街的人没几个不认识"（女巫L1062）。
8. **给工具人一段自利逻辑的POV**——留下/帮忙的理由必须对他自己有利（巴罗夫"这就是权力的滋味"·女巫L2905）。
9. **每个配角有产能上限**——约束反造真实（铁匠铺月产枪管三四根）。
10. **集体记忆做道德坐标**——镇民对比新旧领主；集体情绪出口场面。
11. **保留节目+变奏**——重复戏码形成期待契约，关键时刻变奏（缺席/输一次/数字变化）制造信号。
12. **长尾回收**——配角离开后仍在世界惯性运转：后代/名字被冒用/心魔幻化/旧物空位（厉飞雨三重回收·凡人L3533/37548/55337/141802）。
13. **关系网自运转**——配角之间要有不经过主角的债务/恩怨/默契（洪荒关系户手法9）。

## 二、逐角色优化（已织入生态文件§四）

**姜老**：半杯茶账期（"剩下半杯，下回带消息来续"）；名声先行（柳货郎嘴里先立"耳朵背得比谁的嘴都严"）；柱子内侧爪痕（土行鼠天性·紧张就挠·不用介绍出身）；茶渣分两份（"留一半。闻着，也是喝。"）；卷二空碗（案上多摆一只，不明说给谁）。
**石蛮**：话的专属语法（"名词+嗯"=最高认可；拒绝是长嗯）；冲火场事后溪边发抖半日（英勇不补话，代价看得见）；切磋配"现场直播员"（墟市传言版本自动升级到"一根手指都没动过"）；猎人语法证词（"往常熊瞎子过溪先停了听水。今年没停"）；伤疤按需发放（只肯讲三道=三个事件钥匙）。
**枣大娘**：小本本升级"墟市账本"（一半记偷枣一半记赊账=墟市户口与信用体系）；行为对偶（拒收白送、自己塞枣只说"拿去，核还我"）；讨价还价有输有赢（第四次被凤族反将·认亏·记本子）；开仓放枣的代价POV（"仓里是三年的底。开了仓，明年墟价压不住"）；林孙树长尾（卷二照常抽芽，她每天看一眼不说破）。
**柳货郎**：报价=伸手指仪式（某天伸出没用过的七根指头=全场都知道出大事）；底线一句话预载（"我爹就是叫消息害死的"）；被怀疑时自利自证（当众倒扣货担"我全部家当在这儿，我跑得掉吗"）；消息准确率记账（"柳货郎十中几"口碑）；"顺路"的缺席变奏（卷二开场没来——空的一次比满的十次重）。
**乌巢**：37道安魂符可见生产（画完一道低声说一个名字再收匣——数到三十七停笔，匣满了人还没埋完）；数息法的暗偿（云鹤的符比市面好用三成——掺了手艺，不收钱不提）；右臂黑纹=墟市体温计（阴雨爬一寸，常客看袖口猜天气）；茶棚传承（姜老教的第一件事是左耳背的秘密——保密制度代际交接）；留下来的自利语法（"黑水墟的事，如今只有我还记得。我得活着，当块活地图"）。

## 三、关系排列组合运营表（sitcom 技法）

固定场景=朔望开墟。每对二元组一条专属戏路，日常戏不依赖新事件：

| 关系 | 专属戏路 |
|---|---|
| 姜老×枣大娘 | 税债双人舞（讨税—抵账—假装没看见，每墟变奏） |
| 姜老×柳货郎 | 消息定价权之争（茶换 vs 枣卖，互相拆台又串货） |
| 姜老×石蛮 | 话痨独角戏（对石蛮说半天得一声"嗯"，墟市最佳听众） |
| 枣大娘×柳货郎 | 账本对决（他永远欠她两颗枣，永远下周还——永续债务=永续戏） |
| 枣大娘×石蛮 | 核还林联盟（沉默的规矩同盟，不靠对话） |
| 石蛮×乌巢 | 嗯嗯对坐组（与云鹤的嗯嗯二人组可互换成三人组） |
| 柳货郎×石蛮 | 皮货砍价（收皮压价，石蛮不会还嘴只把兽皮抱回一寸——肢体谈判学） |
| 乌巢×柳货郎 | 北方消息对质（乌巢是唯一能证伪的人——每次对质都是质检直播） |
| 乌巢×枣大娘 | 收留者的暗账（她没把他记进税本，他看穿不说——被接纳而不点破） |
| 姜老×乌巢 | 茶棚交接线（长线） |

云鹤在场五回路轮转（半杯茶账期/嗯嗯二人组/还核默契/散财传说/数息之夜），每个朔望换主视角。

## 四、三条最重要提醒

1. **配角间不经过主角的债务关系是关系网自运转的核心**（姜老欠税×枣大娘装不知——放大它）。
2. **每个配角的"最后一次出场"要提前设计**——卷二"云道友身死"=五人组的峰顶时刻：空碗、不来的货郎、照常发芽的林孙树、数息的失眠者、半杯没人续的茶——**五个空位就是五个钩子**。
3. **迪化系统的基层生产线在墟市**——切磋直播/散财传说/茶棚以讹传讹，给传言留"版本升级"的可见轨迹。
