# 卷级大事件设计模板与细纲新标准（2026-08-14）

> 本文件是 2026-08-14 全盘重造的**方法论权威**。依据：诡秘之主卷一/卷六深度拆解（拆文库）+ 洪荒关系户/我师兄开局节奏解剖 + 两次诊断结论。此后所有卷纲、细纲、正文的生成与审查均以本文件为准；与旧文档冲突处以本文件为准。

---

## 〇、病根诊断（为什么重造）

旧设计的病：**工艺层硬、素材层空**。

| # | 病 | 证据 |
|---|---|---|
| 1 | **无具名大事件**：三个四拍弧全是"无名天灾+路过善举"，核心事件实际戏量仅2-5章 | 凶兽潮=天气不是案件；"罗睺杀伐之气滋养凶兽"的谜题引子只当一句传闻；救元凤60章单元实际戏量2-4章 |
| 2 | **无人的荒野**：散修全是无名NPC，零坊市零集市零营生零物价 | 细纲ch18自认"无名NPC"；日常池7个场景6个单人可完成 |
| 3 | **社交网一根线**：唯一常驻关系镇元子，每次出场=功能节点（教学/预警/协防） | 档案里的平视互动事件（凶兽攻万寿山红云帮守）没编进卷纲 |
| 4 | **主角不想知道**：所有疑问被"先活下来/以后再说"纪律性搁置 | 诡秘驱动力是"主角想知道"；红云的追查动作=全卷看一眼刻痕2次 |
| 5 | **量劫是地图配色**：三族战火零侵入日常 | 前35章三族命中3章且全是传闻 |
| 6 | **世界一成不变**：府邸/地点/法宝/规则无动态演变 | 火云洞从ch4起是永久布景 |

**保留资产**（重造不扔）：F00-F26伏笔系统、六步线+赐号认知暴击、迪化引擎+信息差铁律、千层饼五层、大神角色档案（语言指纹/行为重复点/独立弧线）、善后章哲学、吃货低线、幕后永不揭示纪律、细纲执行工艺。

## 一、卷级大事件设计模板（诡秘式）

每个剧情单元（弧）必须有一个**有名字、有对手、有谜团、可追踪15-25章的大事件**。按此卡填写，字段不全不许开细纲。

```
【卷级大事件卡】事件名：____（必须有专名，如"兽潮案·黑水兽祸"）
一、规模
- 章数：15-25章（复合事件上限34章）｜字数预算：5-9万
- 卷内位置：第__段（高潮后必须接3-5章善后才进下一事件）
- 与前后事件的嵌套关系：上一事件的哪个线头孵化本事件？本事件收网时埋什么下一案的名字？

二、阶段划分（四拍+缓冲带，章数按20章标准配置）
- 日常缓冲带（前置4-6章）：过日子+凶兆一点点埋（诡秘ch56-69式）
- 铺垫（4-6章）：受害者/异象具象化→主角被动卷入→官方或势力接手→第一次擦肩错过
- 升级（2-3章）：官方行动失败——借强者之败写敌之强，不靠正面打斗
- 高潮（3-5章）：初战→真身反转→主角绝境自救→收网
- 善后（3-5章）：抖完+复盘／立一个配角／补偿或葬礼／埋下一案的名字

三、人物配置表（岗位字段，缺一不开工）
- 受害者（具名，能画出长相）：__｜死法/惨状有专属性细节
- 证人/报案人：__｜通过他立主角能力（应验式）
- 嫌疑人（含误导层）：表层嫌疑__→真凶__（"英雄人设"式误导）
- 线人×3（不同渠道）：__／__／__（信息永远通过人物抵达，不用旁白）
- 队友（每人一个不可替代岗位）：破局技__／承伤位__／收尸善后位__／疑心暗线位__
- 幕后黑手（本层）：组织名__（有体系有行事风格，非散兵）
- 更大真相（下层）：__（本事件只揭一角，名字留到下案引爆——"霍纳奇斯"式）

四、线索链（可追踪三件套）
- 主角手段：__（占卜四板斧的对应物：推演/感知/八卦/法宝异动）
- 物证链：物证A→地点B→人物C→记录D（≥4环，收网时由主角当面串讲）
- 利害刻度：__（赏格/功德/灵物估值/物价，让读者可感）

五、反转点（至少两层）
- 案中反转：真凶/真目标不是表面那位
- 案后更大真相：本事件只是更大棋局一角，收网章末尾留下一案名字
- 校验：揭穿后读者回看前文能否"原来如此"？答不上=假反转

六、善后章配置（每章必做三件事之一，三件全无=水章，删）
- ①主角复盘（消化情绪+得出新认知）②立配角/新关系/因果债 ③抛新悬念钩子
- 情感善后选项：庆功宴／补偿受害方／葬礼（配墓志铭级金句）／悼念者独场
- 跨事件义务：本事件配角至少1人后续卷回流（援军/情报/因果债）

七、状态变化（动态维度，必填）
- 本事件结束时：主角居所/持有物/能力/名声 各是什么状态，较事件前变了什么？
- 本事件对世界造成什么可留存改变？（地点损毁/聚落兴衰/物价/势力渗透）
```

## 二、细纲新标准

### 2.1 写法纪律（针对"工程规格书"病）

1. **场景化写作**：细纲主体用"画面+动作+台词"的白描，不用功能标签堆砌。【功能标签】【契约风险】等工程字段压缩到章尾一个"工程注记"小块，正文写作时不读。
2. **过日子配比**：每章 6-7 成日常外壳（请安/吃饭/赶集/斗嘴/手艺）裹 3-4 成硬核内容（设定/关系/信条/机缘/案件推进）。纯单人整章戏原则上不允许（必须至少一个活人接触点）。
3. **期待钩为主**：章尾钩子类型配比——期待钩（下一关系对象/他又备了什么/他打的什么算盘）+好奇钩 ≥ 危机钩。危机钩连续不得超过2章。
4. **每章一件具体增量**：每章让读者多知道一件**具体的事**（新规则/新人物/新物证/新地名/新物价），写不出具体增量的章并入邻章。
5. **章驱动问题**：不问"这章发生什么冲突"，问"这章读者开始期待什么"。
6. **对话样例**：关键场景在细纲里直接写 2-4 句台词原样（尤其配角口癖首次亮相、迪化现场、教学场景），正文直接可用。
7. **禁止"赶"的三个表现**：①砍掉章末"合"段（温馨/余味收束）直接跳下一冲突；②过程戏压缩成一句"整备完毕"；③每章新地图新人物。

### 2.2 细纲模板（字段）

```
# 细纲 · 单元 · 第N章 · 章名
## 一、本章内容（场景化白描，500-800字）
按2-4个场景写：地点/在场人物/发生什么/关键台词2-4句/章尾画面。
## 二、结构
- 字数目标 3000±300｜场景切镜：A→B→C
- 情绪流向：起→承→转→合（合=温馨/余味/吐槽收束，必填）
- 章尾钩子：类型+内容（期待/好奇/危机）
## 三、增量清单
- 读者本章新知道：1件具体的事（人/物/规则/地点/物价）
- 伏笔触点：F编号+触碰方式（故事化小场景，非callback）
- 关系温度：与__的关系变化（具体事件，非标签）
- 状态变化：主角居所/持有物/能力/名声 的增量（无则写"无"）
## 四、工程注记（正文写作时不读）
- 禁止提前释放清单
- 称呼纪律：赐号前对外名=云鹤；叙述层同
- 对齐检查：与卷纲单元卡/前后章的衔接点
```

## 三、状态动态维度规范（世界不是布景）

**总表权威**：`设定/时空与状态动态总表.md`（居所迁移线/地点生命周期/法宝成长线/能力里程碑/世界规则演变五张表）。

**纪律**：
1. 每个剧情单元卡必填"状态变化"字段：单元结束时主角的居所、持有物、能力、名声、身边人物，以及世界（地点/聚落/物价/势力）的可留存变化。
2. **地点有生命周期**：每个重要地点（火云洞/不周山/聚集地/万寿山…）在总表中有"兴—用—变—废/转生"的轨迹。量劫必须改变地貌（资料库canon：罗睺自爆毁西方祖脉、不周山断、葫芦藤陨灭等）。
3. **府邸会迁移**：主角居所按卷演化（游走→火云洞→…），每次迁移有剧情理由（事件驱动，不是随机换地图）。
4. **法宝会成长**：散魂葫芦按"禁制重数逐步祭炼"写可见成长线（canon机制），且有灵智（看心情/闹脾气/护主）——它是"第十一个角色"。
5. **规则会演变**：天道初现→合道→圣位体系→人道补全→地道立→绝地天通→封神收编，按总表节点在正文中以"生活口径"可感（不旁白说教）。
6. **时间流逝实感**：用"过日子"跳时间（迷路一个月/闭关一甲子），纪年用元会/万年（canon计量），不用"年"。

## 四、人物深度配方

**岗位先行，血肉跟上**：
1. 每个事件配角先回答"他在这个事件里担哪个不可替代的岗位"（线索递送/技能破局/承伤/善后/疑心暗线），岗位确立后再堆生活细节。
2. **一个弱点反复使用**（邓恩健忘式）——弱点比优点更像人。
3. **一个钱的问题**（老尼尔欠债30镑式）——购买力即人物；洪荒对应：灵石/灵草/口粮/人情债。
4. **一个未完成的梦想**——善后章顺手揭开，不占正章。
5. **一个职业性小动作/口头禅**（语言指纹7维已有，落到台词）。
6. **死亡或离别的位置设计**——提前铺垫足够的关系重量再动手。
7. **平视关系网**：主角身边长期维持 2-3 条平视线（邻居/损友/买卖对手），大神线另计。所有常驻配角进 `设定/角色/` 建档（名字/营生/欲望/弱点/口癖/与主角关系温度曲线）。

## 五、洪荒味公式与日常配方

1. **大设定×小口径**：圣人=会偷笑的家长；量劫=别族的酒桌牢骚；时间制度=迷路的吐槽。零旁白说教。
2. **洪荒元素接入营生才活**：地脉=镇元子的职业日常（已验证20章命中）；三族战火=流民/物价/征调；紫霄宫消息=散修圈的头条八卦。
3. **生活道具清单**（每单元至少5件，可复用）：食物（烤兽腿/灵果/茶）、住所物件、营生工具、人情硬通货（灵草/符箓/消息）。
4. **闲聊"废笔"**：每章允许1段不推剧情的斗嘴/忽悠，专负责人味。
5. **权威人物生活化**：大神要有小动作、会别扭、会护短（档案已有语言指纹，给场地）。
