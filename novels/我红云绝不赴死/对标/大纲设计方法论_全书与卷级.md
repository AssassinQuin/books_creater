# 全书与卷级大纲设计方法论 · 诡秘案例示范 + 红云诊断

> **关系声明**：本文件是 [诡秘机制设计方法论_总纲.md](诡秘机制设计方法论_总纲.md) **维度一（大纲结构设计）的展开深化**——总纲讲原则 R1.x，本纲讲**怎么写**全书大纲和卷级大纲，用诡秘第一卷+第六卷做案例示范，对红云全书骨架 + 五卷各卷做大纲层诊断。
> **应用对象**：[红云全书大纲](../大纲/大纲.md) + [五卷卷纲](../大纲/)。
> **使用场景**：开新书 / 改全书结构 / 写新卷纲 / 审卷纲时套用本纲的字段模板、设计步骤、checklist。

---

## 序 · 大纲设计的两个层级

长篇网文大纲分两层，必须分开维护、不能混写：

| 层级 | 文件 | 内容 | 字数 | 维护频率 |
|---|---|---|---|---|
| **全书大纲** | `大纲.md` | 指针 + 全书骨架（卷功能分配 + 跨卷曲线 + 主题闭环 + 设定索引） | 短（1-2 千字） | 极少改（定了就不动） |
| **卷级大纲**（卷纲） | `卷纲_第X卷.md` | 单卷完整设计（12 节范本，见 Part 2） | 中（5-10 千字） | 写该卷前定版，写后不改 |

**纪律**：全书大纲不堆细节（细节在各卷卷纲），卷纲不越界碰跨卷结构（跨卷结构在全书大纲）。两层各自单源维护，互不污染。

# Part 1 · 全书大纲设计

## 1.1 全书大纲的字段模板

一份合格的全书大纲应包含以下 6 块（[红云大纲.md](../大纲/大纲.md) 已对齐）：

```
# 大纲总览 · 《书名》

## 一句话主线
（一句话：主角是谁 + 靠什么 + 从起点到终点）

## 全书主题（背景色，非统帅）
（一句话主题 + 详见主题纲领文件指针）

## N 卷骨架表
| 卷 | 卷名 | 主角弧线 | 核心事件 | 千层饼主梗 | 核心情感 | 卷纲指针 |

## 主角人设（一句话）
（一句话内核 + 详见人物与关系文件指针）

## 设定档索引
（指针清单：主题 / 人物 / 机制 / 配角 / 关系 / 文风）

## 关键设定锚点
（切入时间点 / 终局 / 不写什么 / 核心机制）
```

**纪律**：
- 全书大纲不超过 2 千字——它是"地图索引"，不是"地图本身"
- 每一块都用**指针**指向详细文件（单源维护）
- 改全书大纲 = 改全书结构，必须全链路同步（各卷卷纲 + 设定 + 伏笔追踪）

## 1.2 全书骨架设计七步法

**开新书时按这七步排全书骨架**（不要一上来就写卷一卷纲）：

### Step 1 · 定主线（一句话）
主角是谁 + 靠什么 + 从起点到终点。**红云示例**：蓝星普通人穿越成洪荒必死红云，靠谨慎 + 因果调度 + 人道规则，从想苟命到立人道抗天。

> **诡秘对照**：现代人克莱恩穿越蒸汽朋克 + 克苏鲁世界，靠序列升级 + 塔罗会 + 愚者伪装，从值夜者小队员到愚者（旧日之神）。

### Step 2 · 定主题（背景色，非统帅）
一句话主题——**主题是背景色，不是统帅**（[全书主题纲领.md](../设定/全书主题纲领.md)）。主题不能当口号喊，要通过角色弧线和事件兑现。

> **诡秘对照**：主题是"守护与牺牲"——通过邓恩之死、塔罗会成员的成长、克莱恩一次次为守护而冒险兑现，从不喊口号。

### Step 3 · 定卷数 + 卷功能分配
长篇网文卷数建议 4-7 卷（少于 4 卷单卷过厚难支撑，多于 7 卷难收束）。**每卷功能必须递进，不能平行重复**：

| 功能 | 含义 | 典型位置 |
|---|---|---|
| 铺垫卷 | 立人设 + 立世界 + 种因 | 卷一 |
| 反转卷 | 第一次大反转 + 兑现部分因 | 卷二 |
| 情感核心卷 | 最重情感 + 主角弧线跃迁 | 卷三（中段） |
| 觉醒卷 | 主题觉醒 + 主角从被动转主动 | 卷四 |
| 升华卷 | 主题兑现 + 终局 + 全员闭环 | 卷末卷 |

> **红云五卷分配**（健康）：避祸种因（铺垫）→ 死而复生（反转）→ 试手守恒（情感核心）→ 沉淀布暗（觉醒）→ 封神脱壳（升华）。**完全对齐典型功能分配，且每卷递进不重复。**

> **诡秘对照**：6 卷 = 小丑（铺垫）/ 无面人（反转 + 身份探索）/ 旅行家（探索 + 扩张）/ 不死者（反转 + 揭示）/ 红祭司（战争 + 群像）/ 逐光者（收束 + 巅峰）。**卷名 = 途径名 = 该卷主角状态**——结构化升级流的巅峰设计。

### Step 4 · 定主角弧线（跨卷递进）
主角的性格 / 责任 / 觉悟跨卷递进，不能"卷一卷五一个样"。**红云示例**：自保 → 牵挂 → 责任 → 抗天 → 立道。

> **诡秘对照**：克莱恩从"想回家"→"想守护兄妹"→"想守护值夜者/塔罗会"→"想守护这个世界"→"承担愚者的责任"。**每卷扩一圈，越扩越大但内核不变（守护）。**

### Step 5 · 定跨卷曲线（见 1.3）
全书必须编目五条跨卷曲线：认知颠覆 / 伏笔回收 / 能力成长 / 情绪基调 / 关系深度。**每条曲线在全书大纲里有一行总览，详细落表在 [伏笔.md](../追踪/伏笔.md) / [人物与关系.md](../设定/人物与关系.md)**。

### Step 6 · 定全书高潮点
长篇必须有可编号的高潮点（中点 / 3/4 / 终局），不是只有结尾：

- **中点高潮**（50% 位置）：主角第一次大反转 / 大低谷——全书"上下半场"的分界
- **3/4 高潮**（75% 位置）：主角弧线的关键跃迁 / 觉醒——为终局蓄力
- **终局高潮**（95% 位置）：主题兑现 + 全员闭环

> **红云示例**：中点 = 卷二围杀真死（大低谷）+ 救命网兑现（反转）/ 3/4 = 卷四识破鸿钧主题觉醒 / 终局 = 卷五立人道抗天。

> **诡秘对照**：中点 = 第三卷末邓恩之死（全书最重离别之一）/ 3/4 = 第六卷阿蒙本体揭晓（认知颠覆）/ 终局 = 第七卷克莱恩成为愚者（主题兑现）。

### Step 7 · 定主题闭环
全书主题必须在主角弧线上**兑现**，不是结尾喊出来。**红云主题闭环**（已有，[大纲.md](../大纲/大纲.md)）：
- 卷一芽（能避却救）
- 卷二根（善因回响）
- 卷三点化（能救却赴死）
- 卷四觉醒（能苟却抗）
- 卷五升华（能独活却立道）

> **诡秘主题闭环**：守护与牺牲。卷一邓恩之死（牺牲的种子）→ 卷二-三 克莱恩为守护而冒险 → 卷四-五 为守护而布局 → 卷六 在天使级碾压下保住性命和核心资产（配得上不输的守护）→ 卷七 终局承担愚者责任（守护的升华）。

## 1.3 跨卷叙事曲线编目（★全书大纲的核心）

**这是全书大纲最重要的部分**——五条跨卷曲线必须显式编目，不能藏在各卷卷纲里：

### 曲线 ① · 认知颠覆曲线
每卷一次"重写读者认知"的爆点（R1.4）。**红云编目表**（[总纲维度一指导①](诡秘机制设计方法论_总纲.md)）：

| 卷 | 认知颠覆点 | 重写的认知 |
|---|---|---|
| 一 | 身份揭晓 + 让座 | "原来这就是死局，越避越深" |
| 二 | 围杀真死 → 救命网兑现 | "原来种因有回响，他不是一个人" |
| 三 | 后土被动承劫 = 红云照镜 | "原来救人也会害人，因果有代价" |
| 四 | 识破鸿钧真目标 = 火云洞 | "原来他从一开始就被算计" |
| 五 | 迪化层崩塌 + 金蝉脱壳 | "原来真人一直在茫然挣扎" |

> **诡秘对照**：6 卷 = 序列 9 占卜家（认知颠覆①：穿越+克苏鲁）/ 序列 8-7（认知颠覆②：塔罗会 + 多身份）/ 序列 6-5（认知颠覆③：罗塞尔穿越者真相）/ 序列 4（认知颠覆④：阿蒙 + 神弃之地）/ 序列 3-2（认知颠覆⑤：地球+旧日外神）/ 序列 1（认知颠覆⑥：宇宙终极真相）。**每卷一次，递进不重复。**

### 曲线 ② · 伏笔回收曲线
种因→兑现→新种的接力（R5.x）。**红云已有 [伏笔.md](../追踪/伏笔.md) 第四"因果链传导"图**——卷一种因 → 卷二兑现 → 卷三因果转移 → 卷四五终局。

> **关键纪律**：每卷必须有"本卷兑现 / 本卷新埋 / 解锁里程碑 / 禁碰底牌"四栏（见卷纲字段 2.2）。

### 曲线 ③ · 能力成长曲线
能力阶梯命名化 + 每次代价（R4.1-2）。**红云编目表**：

| 卷 | 阶段 | 命名（建议） | 代价 |
|---|---|---|---|
| 一 | 觉醒 | 散魄·初悟 / 半圣 | 赤云相暴露位置（卷一末身份坐实） |
| 二 | 进阶 | 散魄·红霞威压 / 护体 | 紫气招祸（克星闻味而来） |
| 三 | 精通 | 散魄·精准配合因果调度 | 触及人道规则初察（开始被鸿钧注意） |
| 四 | 上限 | 散魄·葫芦隐藏威能 | 主题觉醒后被动布暗（被鸿钧反算破暗子） |
| 五 | 质变 | 人道圣者（规则级非战力级） | 必须以本体应劫（金蝉脱壳代价） |

> **诡秘对照**：22 途径 × 序列 9→0，每个序列命名化（占卜家/小丑/无面人/旅行家/不死者/红祭司/逐光者）+ 每个序列有扮演法消化 + 失控风险。**命名 + 代价 + 消化机制 = 三位一体**（R4.1-3）。

### 曲线 ④ · 情绪基调曲线
全书情绪基调跨卷递进，不能"卷一卷五一个调"。**红云编目表**：

| 卷 | 主导情绪 | 喜悲比 |
|---|---|---|
| 一 | 茫然 + 警觉 + 迪化喜剧（轻底色） | 喜 > 悲 |
| 二 | 紧张 + 绝境 + 救命网反转 | 喜悲反转（喜转悲→悲转喜） |
| 三 | 温暖（共同经历）→ 毁灭性离别 | 悲 > 喜（前半喜后半悲） |
| 四 | 沉淀 + 觉醒 + 燃 | 燃 > 悲 > 喜 |
| 五 | 终局爆点 + 升华 + 余韵 | 升华 > 燃 > 悲 |

> **诡秘对照**：日常奠基（卷一）→ 悬疑加重（卷二-三）→ 战争 + 揭秘（卷四-五）→ 巅峰压抑 + 智力高潮（卷六）→ 终局升华（卷七）。**日常密度单调下降，悬念强度单调下降（被冲突替代），压抑中段最重——典型延迟储蓄曲线。**

### 曲线 ⑤ · 关系深度曲线
深度关系跨卷累积（红云已有 [深度关系弧线.md](../设定/深度关系弧线.md) "3 核心 + 2 次厚"）。**红云编目表**：

| 关系 | 卷一 | 卷二 | 卷三 | 卷四 | 卷五 |
|---|---|---|---|---|---|
| ① 镇元子（挚友） | 起 | 裂痕（迪化破灭） | 弥合（陪伴） | 升华（共谋） | 闭环（并肩立道） |
| ② 后土（知己） | 起（映照） | 持续 | **高潮·赴死** | 精神回响 | 精神闭环 |
| ③ 伏羲（道引） | 起（欠恩） | 深化（合力救） | 护人族共事 | **主场·找道** | 闭环（共立人道） |
| ④ 太一（兄弟） | — | — | 起（共事）→ 假死兄弟 | 隐存秘密 | 余韵 |
| ⑤ 鲲鹏（宿敌） | 起（让座怨） | 兑现（围杀） | 追杀 | 追杀 | **闭环·决裂** |

> **诡秘对照**：克莱恩 × 塔罗会成员（最厚关系网）——奥黛丽/阿尔杰/戴里克/佛尔思/埃姆林/嘉德丽雅/休，每人一条独立成长线，跨卷累积温度，终局全员闭环。

# Part 2 · 卷级大纲（卷纲）设计

## 2.1 卷纲字段模板（12 节范本）

每卷卷纲必须包含 12 节（[story-outline 规则 R1](../../../.claude/rules/story-outline.md) + 红云范本）：

### 首卷范本（12 节）

```
# 卷纲 · 第X卷 · 卷名 · 《书名>

## 一、卷定位
### 核心信息（章节范围 / 字数目标 / 本卷定位 / 蓝星本名 / 力量体系）
### 核心矛盾（一句话：本卷要解决什么）
### 卷契约与终局储备（卷契约 / 本卷主推线 / 本卷战果 / 解锁里程碑 / 禁碰底牌 / 契约风险）
### 情绪弧线（本卷整体情绪走向）

## 二、结构骨架
### 主角本卷 N 阶段认知（每段认知状态）
### 多线交织矩阵（每段 × 多线，每章至少推进 2 条）
### 交织纪律
### N 段详述（每段核心事件 / 战果 / 多线推进 / 对标）
### 节奏目标（基调比例）
### 对标坐标（1/4 · 中点 · 3/4 · 卷尾）

## 三、核心引擎（认人悬念 / 迪化 / 赐号揭晓 / 双向启发 / 葫芦灵智 / 千层饼 / 日常层）

## 四、执行锚点
### 人物弧线（本卷主要角色弧线）
### 本卷伏笔（埋 / 兑现 / 回收计划）
### 本卷反转（类型 / 重写的认知 / 涉及角色）
### 黄金三章专门设计（仅首卷）
```

### 非首卷范本（12 节，替代黄金三章为开篇衔接）

红云卷二-五已用此范本：核心信息 / 卷契约与终局储备 / 认人悬念+迪化层 / 剧情单元卡 / 对标坐标 / 核心矛盾 / 情绪弧线 / 人物弧线 / 本卷伏笔 / 本卷反转 / 日常层 / **本卷开篇衔接** / 正文夯实指引。

## 2.2 卷定位设计（最关键的 3 块）

### ① 本卷定位（一句话）
**先回答"这一卷在全书担什么功能"**（R1.1），再排事件。红云五卷定位：

- 卷一：全书铺垫卷——立红云人设 + 立"越谨慎越深陷"论点 + 埋全书因果伏笔
- 卷二：全书第一个大反转卷——红云真死被救 / 云中子诞生 / 因果调度萌芽 / 救命网兑现
- 卷三：情感核心卷 + 因果调度试手卷
- 卷四：主题觉醒卷 + 沉淀布暗卷
- 卷五：终局卷——必死劫兑现 → 两层反转金蝉脱壳 → 立人道抗天 → 全员关系闭环

> **诡秘对照**：卷一（小丑）= 日常奠基卷 / 卷六（逐光者）= 收账之卷（铺设:揭示 = 1:14）。**每卷功能单一明确。**

### ② 卷契约与终局储备（6 栏，不可省）

| 栏 | 含义 | 红云卷二示例 |
|---|---|---|
| 卷契约 | 读者快感来源（多个引擎） | 死而复生震撼 + 救命网回响爽 + 云中子奇观 + 鲲鹏怨兑现 |
| 本卷主推线 | 本卷最重要的 1-2 条线 | 死而复生·悟法萌芽 + 救命网兑现 |
| 本卷战果 | 本卷结束时达成什么 | 红云悟"死果要落" / 云中子诞生 / 紫气部分被夺 / 必死劫顺延 |
| 解锁的终局里程碑 | 为后续卷解锁什么 | 云中子线（封神脱壳钩子）/ 必死劫顺延（卷五硬必然）/ 紫气分裂 |
| **禁碰的终局底牌** | 本卷不能碰什么（留后续卷） | 火云洞人道规则真相、鸿钧真目标、立人道抗天（卷四五揭） |
| **契约风险** | 本卷最容易让读者弃书的风险点 | **红云"真死"段不能让读者以为主角真没了——须铺垫救命网兑现预告** |

**纪律**：
- "禁碰底牌"是**卷级安全阀**——防止提前消耗终局爆点
- "契约风险"必须显式写出，且给出**对冲方案**——这是防弃书的核心

### ③ 核心矛盾（一句话）
本卷要解决什么问题 / 达到什么目标。**红云示例**：
- 卷一：红云谨慎自保 vs 越谨慎越被卷入
- 卷二：红云谨慎算尽 vs 大势 / 克星碾压；但善良（救命网）这次救了他
- 卷三：红云试手救 vs 救人有代价；改命的极限——不忍心反而害了自己
- 卷四：红云识破自己是棋子，本可苟却选择抗
- 卷五：红云必死劫兑现，本可独活却选择立人道抗天

## 2.3 卷内结构骨架

### ① 阶段划分（每段 10-30 章，单一功能）

### ② 多线交织矩阵（每章至少推进 2 条）

**纪律**：每章至少推进 2 条线（日常练功章 = A+D；社交章 = B+A+D；事件章 = C 是 A/B/D 三线积累后的交汇爆发）。

### ④ 对标坐标（1/4 · 中点 · 3/4 · 卷尾）
每卷用 4 个结构点锚定节奏（R1.5 + 已有 [总纲维度一](诡秘机制设计方法论_总纲.md)）：

## 2.4 剧情单元卡设计

每个剧情单元（约 10-25 章，3-6 万字）必须有完整字段（[story-outline 规则 R1](../../../.claude/rules/story-outline.md)）：

```
### 单元 LX-Y：单元名（阶段·功能）
- 单元 ID：LX-Y
- 主推线：本单元最重要的 1-2 条线
- 核心事件：本单元发生什么（一句话）
- 主角目标 / 关键选择
- 共同经历（深度关系）：堆温度的具体场景
- 非主角关系线：让世界活起来
- 因果链埋因 / 兑现：暗线落点
- 战果线：本单元结束时达成什么
```

**关键纪律**（R2.3 + 总纲维度二指导①）：
- 每个事件弧必须**四拍齐全**（日常缓冲 / 铺垫 / 升级+高潮 / **善后**）
- **善后章不可省**——3-5 章让主角抖完 + 复盘 + 埋新悬念
- 单元之间用日常缓冲带过渡（剪刀差，R1.3）

> **诡秘对照**：第一卷教唆者案（ch56-79）= 铺垫 14 章 → 升级 3 章 → 高潮 4 章 → 善后 3 章。**善后章是诡秘"像小说而非 A 接 B"的关键**（[第一卷拆解 原理4](诡秘第一卷拆解与重构指导.md)）。

## 2.5 卷核心引擎演化（★卷纲设计的灵魂）

**核心引擎每卷必须演化，不能平行重复**。红云双核心引擎（认人悬念 + 迪化）的跨卷演化：

### 认人悬念演化（卷一→卷五）

| 卷 | 演化 | 红云认知 |
|---|---|---|
| 一 | **起**：认人装置立 | 不识 → 谨慎试探对号 → 紫霄宫认全人 |
| 二 | **进阶**：认全名字 ≠ 看透手段 | 冥河首次正面·认出已晚的碾压感 |

| 四 | **识局**：从识人到识局 | 终于看穿鸿钧棋局 |
| 五 | **破局**：识人→识局→破局 | 反算鸿钧 |

### 迪化演化（卷一→卷五）

| 卷 | 演化 | 迪化内容 | 累积效果 |
|---|---|---|---|
| 一 | 起：迪化机制立 | 谨慎试探被脑补"高深" | 名声雪球第一推 |
| 二 | 升级 + 破灭 | "连死都没死透，深不可测" / **镇元子迪化破灭喜转悲** | 鸿钧记账：红云有德，可用 |
| 三 | 加深 + 例外 | "在下一盘大棋" / **后土不迪化（唯一真懂他）** | 鸿钧警觉：他在布局 |
| 四 | 歪打正着 | "韬光养晦"（红云真在布暗） | 鸿钧确认：他在经营火云洞 |
| 五 | **崩塌 + 与真相重合** | 所有迪化层崩塌 → 真人一直在茫然挣扎 → 鸿钧杀局打在幻影上 | **跨卷迪化层总兑现** |

### 千层饼引擎演化（专用纪律）

- **每卷只用一个核心大事件**（[feedback-selective-reversal-character-trait](../../../C:/Users/Administrator/.claude/projects/d--code-books-creater/memory/feedback-selective-reversal-character-trait.md)）

- **卷四五不用新造千层饼**——卷五是前四卷迪化层的总兑现

> **诡秘对照**：诡秘的"反转"不是千层饼，而是**认知颠覆型反转**（R8.1）——每卷一次"重写读者认知"的爆点。红云的千层饼是**信息差型反转**（主角算 N 层，实际发展到 N+2 层），二者机制不同但都是"反转 = 认知颠覆"。
