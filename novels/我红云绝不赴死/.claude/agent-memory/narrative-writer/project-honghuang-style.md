《洪荒：我红云绝不赴死》正文写作核心纪律（2026-08-10 新设定重写后）。

**Why:** 用户废弃旧设（化形=穿越/赤发赤肤/封印祥云之力），改为"读者穿越成衣着整洁的普通散修"。文风审美来自 `设定/作者心声.md`：细腻/人物丰富/多事件衬托/内心吐槽是核心喜剧引擎/动作升格/环境衬托情感/留白不点破。

**How to apply:**

七条铁律（不得违反）：
1. 穿越成平平无奇的普通散修（衣着整洁亚裔），本名云鹤；非化形、非先天大能
2. 第一卷姿态：以读者参与感走进洪荒，不代入角色、不对标红云
3. **幕后设定永不揭示（最高纪律）**：他本是先天云化形，故灵力底子好——正文绝不表达/解释/暗示。禁用词：先天/本体/云化形/跟脚/之所以…是因为/冥冥中/仿佛/与生俱来/似乎。台前只是普通散修，体内有点微弱灵力但不会用（只呈现"推不动"，不解释为什么）
4. 能力是云道法则/云遁（后期），起步普通散修低修为
5. 读者知识与自我认知分离——他读过洪荒小说，但只是模糊觉得"草发光像小说里写的"
6. 无系统/老爷爷/金手指弹窗
7. 内心是沈云鹤

文风审美（作者心声.md）：
- 细节集中：一个场景只给 1 个核心特写
- 留白不点破：动作先上，解释后补，永不当场回答读者疑问
- 动作升格：电影慢镜头，把一个瞬间拉长
- 环境衬托情感：不写"他很恐惧"，让环境替角色感受
- 禁AI腔：禁升华/禁"他感到"直述/禁万能比喻/禁章末总结
- 疯劲：每章至少 1 段写完觉得"这会不会太过"——不要删

禁止的精确数字 → 见 [[feedback-no-precise-numbers]]

ch1 已完成（2026-08-10），ch2-3 旧版仍含旧设（赤发赤肤/封印/化形波动），待按新设定重写。
