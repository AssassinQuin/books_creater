写正文时禁止用精确数字表示大小、长度、时间、次数、数量。改用当前世界物品类比 + 文字描述词。

**Why:** 用户 2026-08-10 新增文风纪律（最高优先级）。精确数字（两下/三步/二十多年/凌晨两点/三颗/第二颗）读感像现代人计量，破坏洪荒古代世界的沉浸感。模糊词（片刻/几晃/许多年/深夜/几颗/又一颗）更贴合限知视角的角色主观感受，也更自然。

**How to apply:**

时间类：
- "两息" → "片刻" / "一刹"
- "两个月" → "好些日子"
- "二十多年" → "许多年"
- "凌晨两点" → "深夜"
- "三千年" → "几千年"

长度/距离类：
- "走了不到二十步" → "走了没多远"
- "每走两步" → "走不几步"

次数类：
- "眼皮跳了两下" → "跳了几下"
- "晃了两下" → "晃了几晃" / "晃了晃"
- "推了三下" → "推了几下"
- "看了两眼" → "看了看"

数量类（精确→模糊）：
- "三颗果核" → "几颗果核"
- "第二颗。第三颗。" → "又一颗。再一颗。"
- "四个字" → "几个字"
- "半颗果肉" → "果肉"

**保留的合理用法**：
- 世界物品类比：巴掌宽 / 核桃大小 / 半人高（用当前世界物品做参照，好）
- 自然量词：一片 / 一口 / 一声 / 一张脸 / 一圈 / 一层 / 一手（中文固有无计数量词）
- 已模糊词：片刻 / 一会儿 / 几步 / 几颗 / 几重 / 半天
- 身体部位固定词：两手空空 / 四肢 / 五官（不是计数）
- 泛指：每一口 / 一件事
