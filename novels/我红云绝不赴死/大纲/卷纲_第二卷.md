## 二、卷契约与终局储备
- **卷契约**：红云真死又生 + 救命网回响 + 云中子诞生奇观 + 因果调度萌芽 + 鲲鹏怨兑现（部分）。
  - 读者快感：① 死而复生震撼 ② **救命网回响爽**（卷一种的因卷二兑现）③ 云中子诞生奇观 ④ 镇元子迪化破灭·喜转悲
- **本卷主推线**：死而复生·悟法萌芽 + **救命网兑现**（卷一善因的果）
- **本卷战果**：红云悟"死果要落"（萌芽）/ 云中子诞生（福报面独立）/ 紫气部分被夺（筹码+祸根）/ 鲲鹏冥河各得部分紫气（势力变化）/ 必死劫顺延（封神悬剑起）
- **本卷解锁的终局里程碑**：云中子线（封神脱壳钩子之源）、必死劫顺延（卷五金蝉脱壳硬必然）、紫气分裂（鲲鹏冥河势力变化）
- **本卷禁碰的终局底牌**：火云洞人道规则真相、鸿钧真目标、立人道抗天（卷四~五揭）
- **契约风险**：**需补强**——红云"真死"段不能让读者以为主角真没了/弃书。须在死前铺垫救命网即将兑现的预告（元凤循因果溯源的伏笔、镇元子赶来的紧迫），把"真死"写成"绝境反转的倒计时"而非"主角没了"。死要死得震撼，但不能破坏"主角会回来"的读者契约。

## 三、认人悬念 + 迪化层（卷二演化）

### 认人悬念（进阶：认全名字 ≠ 看透手段）
- 卷一紫霄宫红云"认全了人"，卷二他进入"识人布局"——但围杀来得太快，他对鲲鹏、冥河的**各阶段形态/手段**仍认不全。
- **冥河首次正面**：红云知小说结局里"有个杀不沾因果的人"，但围杀中才认出眼前血海之主就是冥河——**克星正面碾压**，认人悬念的反面（认出了，但已经晚了）。
- 鲲鹏：红云知他会害，但鲲鹏联合冥河的时机/手段超出他的结局知识（小说只写结局，不写过程）。

### 迪化（"连死都没死透"被脑补）
- 红云死而复生后，"连死都没死透"被大能迪化成"红云道兄深不可测/有大后手"（实为救命网+命数分裂）——**他越茫然（我怎么活的？），越被脑补成深谋远虑**。
- **镇元子迪化破灭（喜转悲）**：镇元子（佛系老头）被调虎离山，本以为红云"自有后手"（迪化），结果红云真差点死——**迪化破灭，他从吐槽役坠入愧疚**，喜转悲，挚友质感落地。

### 千层饼引擎（卷二·围杀与死而复生）
> 本卷千层饼用于**围杀→死而复生**这一核心大事件（跨 L2-2/L2-3/L2-4），不在紫气招祸等次要事件上使用。

**围杀五层：**
1. **谋定（层 1）**：红云知"鲲鹏会联合围杀"→谋定多条退路（① 提前布隐匿阵 ② 留葫芦护体后手 ③ 暗中知会镇元子接应方位）→推理：三条退路，鲲鹏一条也堵不死。
2. **跑偏（层 2）**：冥河——他没预料的变量（小说只写结局，不写冥河参与围杀的时机）→阴魂不散的克星堵死两条退路+鲲鹏正面碾压。
3. **迪化（层 3）**：镇元子被调虎离山后，其他大能以为"红云自有后手"（迪化惯性），**没人第一时间来救**——迪化的惯性害了他。
4. **后果（层 4）**：他真死了。紫气被夺走部分。读者震撼：**千层饼的层 3 把救命的人吓退了。**
5. **反弹（层 5）**：救命网（卷一种的善因）在他死后才启动——元凤循因果溯源率凤族来救。**死过一次反而激活了另一层因果链**（救命网→守恒反噬→命数分裂→云中子诞生）。

**跨卷接口**：围杀千层饼的"层 5"（死而复生→迪化更深"连死都没死透"）直接喂给卷三——大能更确信他"深谋远虑"，迪化雪球越滚越大，为终局金蝉脱壳的"终生迪化层兑现"蓄力。

## 四、剧情单元卡（相对体量，字数开放）

### 单元 L2-1：紫霄宫分宝·得紫气·招祸悬剑升（卷二开篇·衔接卷一）
- **单元 ID**：L2-1
- **主推线**：分宝得紫气（招祸标记）+ 鲲鹏怨深化
- **红云（谨慎 vs 大势）**：知"紫气=招祸"（小说结局），想推/避，却被大势 + 迪化推到得紫气（**A 被动卷入**）。得紫气 = 被天道盯上作应劫靶子（魔改：紫气=应劫标记）。
- **鲲鹏碰撞（悲情宿敌）**：让座怨未消（卷一）+ 分宝又失机缘 → "又是他！"的怨气滚雪球，较真记仇升级。他越较真，红云越想避，错位加深。
- **冥河远观**：血海之主首次远观觊觎紫气（伏笔）。
- **共同经历（深度关系①②）**：紫气招祸，**镇元子与红云共对**（劝他推、谋划避祸——深度关系①深化，共同应对危机，为 L2-2 被调虎离山的裂痕埋前因）；紫霄宫大能齐聚，红云再见**后土**（卷一共同救护的映照者），两人持续交集（深度关系②延续，为卷三深交铺垫）。
- **战果线**：紫气得（招祸）/ 鲲鹏怨深化 / 冥河觊觎伏笔 / **深度关系①②深化**

### 单元 L2-2：围杀·真死（卷中大低谷·爆点·六线交织）
- **单元 ID**：L2-2
- **主推线**：鲲鹏 + 冥河围杀 → 红云真死
- **红云（谨慎的极限）**：谨慎防备（布三条退路：隐匿阵/葫芦护体/镇元子接应），但冥河是未知变量→克星堵死两条+鲲鹏正面碾压→**算尽仍真死**。谋定链没问题，是信息差杀了him。
- **【镇元子支线·牺牲时刻】被调虎离山→地书稳真灵**：
  - 围杀发起前，有人制造"万寿山遇袭"假象lure镇元子。他面临选择：守万寿山（自己的）还是接应红云（朋友）。他选了红云——但万寿山方向也有"动静"（调虎离山的陷阱）。他两头跑，两头都没赶上。
  - 赶回时红云真灵将散→**牺牲时刻**：镇元子用"地书"强行稳住红云散落真灵——等于把万寿山地脉对火云洞洞开，人参果树暂时暴露无防护。**他用人参果（最怕失去的东西）换红云的真灵。**
  - 事后他不提这件事。补了火云洞防御，回万寿山巡了三遍山。
- **【鲲鹏支线·讨债式围杀】先要承认→冥河抢先→账对不上**：
  - 鲲鹏在围杀中不直接下杀手→先把红云逼到死角→**要红云亲口承认"让座是算计"**（他的记账文化：账目对齐才能销）。他甚至用当年红云在同行路上替他补漏洞的同一种手法反过来困住红云——"你当年替我补的那道破绽，今天原样还给你"。
  - **冥河不等他逼问完→直接打散红云真灵**→红云先倒了。鲲鹏的"讨债仪式"被冥河从中间撕碎。
  - 紫气只夺到部分（冥河分走一半）→鲲鹏攥着那点紫气指节发白→"他承认了？没有？"→账永远对不上→**执念种下**：从此追杀不是为了杀，是为了对账。
- **【鲲鹏×冥河·非主角关系线】围杀搭档互看不顺眼**：
  - 鲲鹏是精密军师型，围杀要有计划有步骤有仪式（先逼承认再杀）。冥河是阴魂不散型，不管仪式直接抢紫气。两人在围杀中**因节奏不合产生摩擦**：鲲鹏布的局被冥河的暴力冲散，冥河嫌鲲鹏"磨叽"。他们不是盟友——是**各怀目的临时搭伙**，围杀一结束立刻分道扬镳。这条关系让围杀不是"两个反派联手"那么简单——他们内部也在博弈。
- **【冥河支线·首次正面】克星碾压**：红云围杀中才认出"杀不沾因果的人"→认出已晚。冥河**是闻着紫气自己来的**（紫气对成圣有用），不是鲲鹏邀请的——鲲鹏以为自己联络了冥河，实际冥河是被紫气吸引自发前来。冥河不等鲲鹏的仪式→暴露了他根本不在乎鲲鹏的"账"。鸿钧没有邀请冥河——但天道系统的因果废料流向变化（鸿钧可操控）让冥河"恰好"在这个时间闻到了紫气。鸿钧默许，没干预。
- **【鸿钧暗线·调虎离山的暗手·天道信号事件】**：围杀发起前，**天道地脉监测系统在万寿山北方生成了一个凶兽级能量波动报告**。镇元子的地书系统接收到——数据精确到不像凶兽（真实凶兽能量有杂波波动，这个信号太"干净"了，像天道系统直接生成的标准信号）。镇元子不敢赌（万寿山是他命根子），rush去查看→空无一人→信号在他到达后消散。他赶不回来了。**事后镇元子复盘：真实凶兽的能量信号不会这么"干净"——这个信号是被制造出来的。他不知道是谁有本事让天道系统生成假信号。** 鸿钧不需要亲自动手——他是天道的运维者，让系统生成一个假报告比亲自出手简单得多。
- **【后土支线·涟漪】**：红云濒死震动洪荒→后土有所感（她不知发生了什么，但感应到"那个人"快没了→为卷三深交埋线）。
- **战果线**：红云真死 / 紫气部分被夺 / 镇元子牺牲时刻（地书稳真灵）/ 鲲鹏账对不上（执念种下）/ 冥河紫气到手 / 鸿钧暗手（调虎离山）/ 后土感应

### 单元 L2-3：救命网兑现·被救（反转）
- **单元 ID**：L2-3
- **主推线**：救命网兑现（元凤①+伏羲②+让座西方③合力救）
- **红云**：真死、走投无路、真灵将散——**救命网回响**：元凤循因果溯源率凤族来救（主环①），伏羲（②）、西方（③，让座欠人情）合力，把红云真灵从将散中拉回。
- **元凤碰撞（没落贵族主母）**：郑重报恩——"当年无名救命之恩，今日还"。红云方知当年"无名伤者"是凤族之主，**震撼 → 悟因果回响**（卷二悟法催化）。
- **伏羲深化（深度关系③起）**：伏羲合力救红云，红云与他进一步交集、识破当年凶兽期救的就是他——结缘深化（伏羲的人族背景进入红云视野，"找道"埋种）。
- **后土感应（深度关系②延续）**：红云真死震动洪荒，卷一共同救护的后土亦有所感（为卷三主场深交埋线）。
- **代价**：救命网合力救 = 动用大因果，**守恒反噬 → 命数分裂**（→ L2-4）。
- **战果线**：救命网兑现 / 红云被救 / 因果回响悟

### 单元 L2-4：命数化云中子·悟法萌芽（卷尾·新主线）
- **单元 ID**：L2-4
- **主推线**：命数分裂化云中子（福报面）+ 红云悟法萌芽 + 镇元子愧疚闭环
- **红云**：被救的代价 = 一段命数/劫数溢出化成**独立灵魂**（云中子，承福报面）；本体残存（劫数面，倒霉不断紫气招祸）。
- **云中子碰撞（天选福将）**：一化形就福气满满（福报面），自己都懵（"我怎么了？"）。红云远观这个"自己命数化出的人"，心情复杂（**他这么顺，我这么衰——一体两面**）。
- **悟法萌芽**：死过一次，初窥因果缝隙——"死果要落"（从卷一"盲目断链"到"知道死果要落"）。**只是萌芽**，未成熟（卷三才试手）。
  - **【因果调度能力的物质载体】**：红云凭什么能调度因果？三结合：①**九九散魄葫芦的散魂属性**——散魂=可切断魂与因果链的连接（先天灵宝级能力）；②**蓝星现代人思维**——把因果链当系统/算法来推演分析（洪荒大能不会用这种思维方式）；③**死过一次的真灵损伤体感**——他真灵散过一次，对因果链的"断点"有物理层面的体感（能"摸到"因果链）。三者结合才能调度因果。能力上限：葫芦是先天灵宝级→能断准圣级因果；天道级/圣人级因果（封神榜）最多扰动不能改。
- **镇元子愧疚闭环（深层）**：镇元子赶来见红云残存，迪化破灭只是表层——深层是**"我在乎的东西果然被夺走了"**，他的人生哲学（不拥有就不怕失去）在卷二被击碎。他的选择不是"弥补愧疚"，是在恐惧被印证之后仍然选择继续在乎。从"守园人"到"赌徒"的转变起点在此。
- **卷尾大钩子**：必死劫顺延成封神必死劫（守恒，贯穿卷三~五的悬剑）+ 云中子独立成长线开启 + 紫气分裂招新祸
- **战果线**：云中子诞生 / 悟法萌芽 / 镇元子共谋 / 必死劫顺延悬剑

## 六、核心矛盾
红云谨慎算尽（布后手/留退路），仍真死——**谨慎有极限，大势/克星碾压**；但卷一种的善因（救命网）在绝境兑现——**善良这次救了他**。论点：**死过一次才知"死果要落、命可改"**，从被动避祸→主动识链。

**★主动出击燃点（配合进阶解锁）**：围杀中红云**进阶红霞威压·主动震退追兵**（寡不敌众仍真死=倒霉，但有反杀瞬间，不憋屈——读者看到他不是被动挨打）。

## 七、情绪弧线
紫气招祸的紧张（悬剑升）→ 围杀的绝境恐惧（**大低谷**）→ 救命网兑现的震撼感动（**反转·善有善报**）→ 云中子诞生的奇观（荒诞+希望）→ 悟法萌芽的沉重觉悟（新主线·责任初萌）。

**喜悲反转**：卷一喜剧调剂收，卷二悲起；镇元子迪化破灭喜转悲；元凤郑重报恩的端庄 vs 红云"我真是顺手"保留一点轻喜；云中子诞生的"天选福将"荒诞调剂悲。

## 八、人物弧线
- **红云**：谨慎自保者 → **死而复生者**（弧线对象升级到「牵挂」——救命网让他有了不愿连累的人）。**战力成长·进阶**：围杀实战逼出葫芦进阶（红霞威压 / 护体），从"会基础"→"会进阶"。
- **镇元子**：佛系挚友 → **恐惧被印证的守园人**（迪化破灭不是表层喜转悲，是内核"拥有=靶子"被应验，人生哲学碎了）→ **选择继续在乎的赌徒**（明知在乎=风险仍然重修那座桥）→ 共谋者。
- **后土**：卷一映照者 → **持续交集**（紫霄宫再见 + 死劫感应，深度关系②延续，为卷三主场深交埋线）。
- **伏羲**：被救者 → **结缘深化**（合力救红云，红云识破当年所救，深度关系③"找道"萌芽）。
- **鲲鹏**：悲情宿敌（怨兑现但没痛快，执念加深；紫气只夺到部分）。
- **元凤**：没落贵族主母（报恩兑现，红云方知救的是她）。
- **云中子**：**诞生**（天选福将，独立的人，成长线起）。
- **冥河**：阴魂不散克星（首次正面，追杀执念起）。

## 九、本卷伏笔
- **埋**：云中子独立成长线（→卷四阐教/卷五黄河阵）；必死劫顺延（→卷五金蝉脱壳）；紫气分裂（鲲鹏冥河各得部分，势力变化→追杀升级）；冥河克星（→卷五被破）；红云悟法（→卷三试手）；镇元子共谋（→贯穿）；**深度关系线**（镇元子裂痕① / 后土持续② / 伏羲找道萌芽③）。
- **本卷兑现**：救命网①②③（卷一种→卷二兑）；让座结怨（卷一→卷二鲲鹏围杀）；**镇元子共同经历①深化（共对紫气 → 裂痕）**。
- **回收计划**：云中子线→卷四五；必死劫→卷五；紫气分裂→卷五；冥河→卷五；**后土线→卷三主场；伏羲线→卷四五立道；镇元子裂痕→卷三~五弥合**。

## 十、本卷反转
- **救命网反转**：卷一"无名伤者随手救" → 卷二"凤族之主循因果来救"（最无意的善举结救命的果）。
- **迪化破灭反转**：镇元子以为红云"自有后手" → 红云真差点死（迪化破灭，喜转悲）。
- **鲲鹏反转**：以为报了怨 → 紫气只夺到部分、红云没死透（悲情宿敌连怨都没报痛快）。
- **云中子反转**：红云死劫的"代价"竟化成一个独立的人（奇观反转，福报面独立）。

## 十一、日常层结构（占比降·悲起）
- **形态**：紫霄宫分宝间隙社交（最后一次大能群像日常，之后红云"死"退场）→ 死后/被救后的火云洞残破日常（红云残存调养，镇元子常来探望愧疚——挚友戏主场 / **人族药膳——红云重伤调养期间，伏羲带来人族采集熬煮的药膳汤，红云第一次尝到洪荒"烟火气"，馋哭了——这碗汤让他第一次对人族有了具体的好感**）→ 云中子独立成长的远观碎片（红云远观自己命数化出的人——荒诞调剂）
- **驱动循环**：因果回响悬念 + 镇元子愧疚温度 + 云中子成长钩子 + **吃货种子**（药膳汤→人族烟火的初印象，为卷三吃货觉醒蓄力）
- **占比**：卷二日常占比比卷一**降**（悲起，喜剧收），但仍要有（红云调养+镇元子探望的挚友戏承载喜悲反差，云中子远观的荒诞戏调剂）。

## 十二、本卷开篇衔接（替代黄金三章）
- **衔接卷一卷尾**（让座结怨 + 分宝将至）：卷二开篇 = 紫霄宫分宝现场，红云知"紫气招祸"想避，却被推到得紫气。**开篇钩子 = 招祸悬剑升（倒计时感）。**
