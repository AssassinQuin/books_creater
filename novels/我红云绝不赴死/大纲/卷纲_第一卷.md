> v2.3（2026-08-06）：**红云人设根本重构**——蓝星普通人穿越（化形即穿越·茫然）/ 只前世记忆（知小说结局，不知过程/时间/细节）/ **不认人**（认人悬念·认错风险）/ **亲身经历**（第一视角参与者，非上帝旁观）/ 谨慎为核心 / 战力=谨慎保命。替 v2.1 的"知剧本+上帝视角操控"。

## 二、卷契约与终局储备

  - 读者快感三引擎：① **认人悬念**（知结局但认不出人——紧张反转，认错风险）② **迪化反差爽**（真茫然被脑补成大佬）③ **谨慎战斗爽**（算准才出手，干脆利落保命）

- **本卷战果**：立红云人设（谨慎 + 只知结局 + 亲历者）/ 镇元子挚友 / 火云洞道场 / **认人拼图初成**（化形时谁都不认 → 紫霄宫大致认全洪荒主要玩家）/ 救命网种子（5 善缘）+ 第一大因（让座结怨）

- **契约风险**：**契约安全**。避祸段靠认人悬念 + 迪化反差喜剧 + 谨慎战斗场面提亮，不憋屈；红云虽茫然，但**靠谨慎始终有主动性**（谋而后动、算准才出手），不是被动挨推。

## 三、认人悬念 + 迪化层（★ v2.3 双核心引擎）

### 红云的双面
- **内心**：蓝星普通人 + 只记得读过的洪荒小说结局 + **茫然恐惧**（这是哪？我是谁？这些都是谁？）+ 谨慎自保
- **外表（被脑补）**：高深莫测的红云道兄 / 洪荒老好人 / 慈悲大能 / 深谋远虑 / 暗合天道

### 认人悬念机制（v2.3 新核心装置）
- 红云**知结局**（鲲鹏会害我围杀我 / 太一帝俊会陨 / 后土化轮回 / 通天被贬 / 截教封神败），但见到现实的人**根本认不出**——小说是文字名字，现实是真人，对不上号。
- 他必须**谨慎试探 / 对号**：通过言行、修为、来历、法宝、旁人称呼，慢慢把名字和人配上。且**可能认错**——把好人当坏人防、把坏人当好人近。
- **认错风险制造悬念与反转**：他知道"鲲鹏会害我"，但北冥来的大妖是不是鲲鹏？他不确定，于是谨慎防备了一个可能无辜的人，或错信了一个真正危险的人。
- **认知从零累积**读者跟红云一起拼图——化形时谁都不认 → 游历中逐渐对号 → 紫霄宫讲道（大能齐聚）才大致认全。认知是本卷的一条暗线进度。

### 迪化机制（v2.3 升级：真茫然被误读，不是装的）
- 红云的**谨慎摸索**（试探对方身份 / 藏拙避祸 / 谨慎救人 / 算准才出手）被大能脑补成"高深"——**他真不懂、真茫然，是被误读**（比 v2.1"装的"更深一层，也更心酸）。
- 他谨慎试探某人身份时，对方脑补"红云道兄在试探我的道心"；他谨慎藏拙时，对方脑补"深不可测"。
- 迪化是红云"种因"的**加速器**——快速织网；也种恶因（被脑补成威胁，招忌惮/觊觎，如鲲鹏冥河因红云"深不可测"而警惕）。
- **与论点咬合**：红云越谨慎（藏/试/避），越被脑补，越结因果，越陷深——越想藏越显眼。

### 迪化喜剧写法
- 内心 OS（茫然苟命）vs 外界脑补（大佬）的反差；但**穿插动作/对话**，不连续心理独白（story-narrative 规则 6）。
- 每个脑补落到具体角色的具体反应（镇元子抚掌/三清互视/鲲鹏阴鸷/伏羲动容），禁"众人都震惊"。

## 四、剧情单元卡（相对体量，字数开放）

### 单元 L1-1：化形即穿越·茫然知死局·立足火云洞·认人悬念+迪化初显（开篇·黄金三章主场）
- **单元 ID**：L1-1
- **主推线**：立红云人设 + 火云洞道场 + **镇元子同行扎根（深度关系①起）** + **认人悬念立** + **迪化机制立**
- **红云（v2.3 亲历者）**：蓝星意识突然降临洪荒一朵刚化形的红云体内——**茫然**（这是哪？我是谁？这是什么世界？），逐渐反应过来（我穿越成红云了？那个让座结怨、紫气招祸、被围杀身死的倒霉红云？），只记得读过的小说结局，**不知过程/时间/细节/不认人**。**有准圣修为 + 葫芦但不会用**（成长流起点）。第一反应：**极度谨慎**（先藏、先搞清现实、不算清楚不动）。
- **认人悬念**：火云洞是"家"但他毫无记忆；第一个撞见的大能（镇元子）他**根本不认识**，谨慎试探（这人是敌是友？是小说里的谁？我该套什么话？）。
- **迪化**：他谨慎试探 / 布避祸隐匿阵（自保）被镇元子脑补"红云道兄此阵暗合造化 / 在点拨于我"（他真只是在藏）。迪化初显，镇元子评价↑。
- **共同经历（[魔改]·深度关系①）**：五庄观与火云洞**地理相邻**，镇元子是红云穿越后最早的同行者；红云不认人、不知现实，镇元子无意中成了他的"**洪荒向导**"（带他认地理、识风俗、辨大能），试探套话被迪化成"论道"——**红云在洪荒的"扎根"从镇元子开始**。
- **火云洞异常（人道规则伏笔前移·机制减法）**：红云立足火云洞，**察觉此地有异常**（洞天福地之首，似有更深的东西），但**不懂是什么**——埋人道规则伏笔（卷二/三显化，卷四识破），读者跟红云一起摸出来，非结局临时救兵。
- **战果线**：人设立 / 道场立 / **挚友立（深度关系①起）** / **认人悬念立** / 迪化立 / **火云洞伏笔（异常·人道规则前移）**
- **对标参照**：我师兄 ch1-3（黄金三章立人设）+ 洪荒关系户 ch1（策略立）

### 单元 L1-2：凶兽量劫·谨慎战斗救伏羲·认人悬念加深
- **单元 ID**：L1-2
- **主推线**：A 被动卷入凶兽量劫 → 红云**谨慎战斗** + 救伏羲（善缘②）+ **后土初遇·善良映照（深度关系②起）**
- **认人悬念**：凶兽潮波及火云洞/游历路线，红云远遁避祸（知凶兽量劫结局，但**不认得**凶兽、不认得参与的大能）。撞见一受伤的先天神祇（伏羲），**不认得他是伏羲**，但谨慎善良相救；又遇**一名救护弱者的慈悲女子（后土）**，不认得，却被她的温柔震撼（对号悬念：这是小说里的谁？）。
- **战斗（谨慎保命式）**：先观察凶兽弱点、算准才出手、九九散魄葫芦散凶兽魂魄 + 祥云之力 + 避其锋芒护伏羲脱身、不恋战。展现准圣 + 先天灵宝战力，但**策略性、不硬刚、不碾压**。
- **共同经历（[魔改]·深度关系①②）**：红云与镇元子**同行抗凶兽**（深度关系①深化）；遇后土救护众生（人族弱者），红云加入**共同救护**——红云的善良**第一次被"高维的善"映照**，震撼（后土卷一早出场，深度关系②起，浅识深印象）。
- **迪化**：凶兽期大能见红云出手，脑补"红云道兄威能深不可测/一葫散凶兽"（实为保命+善良）；伏羲被救欠恩。迪化加深，名声传。
- **远观罗睺鸿钧**（天道之威远因）；**诛仙剑落通天**伏笔
- **战果线**：善缘②种 / 战斗场面立 / 迪化名声起 / 罗睺线
- **对标参照**：我师兄 ch7-13（进险地 + 铺底牌 + 反杀战斗——被动入局后主动出手）

### 单元 L1-3：龙凤初劫·谨慎战斗救元凤·善良双刃（卷一中段情感高点）
- **单元 ID**：L1-3
- **主推线**：B 逃避反触发 + C 巧合 → 红云**谨慎战斗**救元凤（善缘①）
- **认人悬念**：避凤族战火途中撞见一名浑身浴血、坠逃的女修（实为元凤），**不认得她是凤族之主**，混沌中来不及问，谨慎善良相救（止血/隐匿气息引走追兵/指条逃路），救完匆匆离去。
- **战斗**：红云 vs 三族追兵——葫芦 + 准圣威压打退，**一击震慑 + 护元凤脱身 + 不恋战**。干脆利落不拖沓。
- **迪化**：三族脑补"红云以一己之力威慑三族/深不可测"（实为善良+避祸）；元凤欠恩。
- **善良双刃**：L1-4 让座（恶因）vs L1-3 救元凤（善因），同一种善良两种果——深化红云挣扎。
- **战果线**：善缘①种 / 元凤-孔宣线 / 守恒初见（凤族衰）/ 战斗情感高点
- **对标参照**：洪荒关系户 ch3（偶遇后土善缘）+ 我师兄 ch13-17（反杀/夺草小高潮）

### 单元 L1-4：紫霄宫听道·认全人·建大能圈·让座（卷尾大钩子）
- **单元 ID**：L1-4
- **主推线**：**认人拼图收口** + 建大能圈关系网 + 让座（D 主动选择）
- **认人悬念收口**：紫霄宫讲道，洪荒主要大能齐聚——红云**终于把小说名字和现实人大致对上号**（这是三清、这是接引准提、这是女娲伏羲、这是鲲鹏、这是帝俊太一……）。认人暗线进度收束。但让座当口，他对鲲鹏的怨意、紫气之争的大势尚看不透——**认全人 ≠ 看透局**。
- **鲲鹏短暂同行→破裂（[魔改]·深度关系⑤起）**：紫霄宫路上 / 讲道间隙，红云与鲲鹏有过**短暂同行 / 小合作**，两人本有"成友"可能（鲲鹏抱负 vs 红云谨慎，初印象不差）。让座令这层潜在友情**破裂**——怨因此有重量（"我们本可以不是敌人"）。
- **让座（谨慎 vs 善良/大势博弈）**：知"让座种祸"，他尝试避（推托/迟到/缩在后），却因老好人本性 + 大势 + 迪化（被推到前台脑补成高风亮节）最终仍让座。**他想主动避让座，却仍陷进去**（论点）。气运流转西方（善缘③）/ 西方欠人情。
- **迪化**：让座被大能脑补"红云道兄高风亮节让圣位"或"暗藏玄机"（实为老好人本性与避祸失败的叠加）。
- **卷尾大钩子**：让座结怨鲲鹏（多因：让座+卷一错位）+ 分宝将至（紫气招祸）
- **对标参照**：洪荒关系户黄金三章（三套话术三圣人）+ 我师兄 ch22-30（算计升级转折）

## 六、核心矛盾
红云**谨慎自保**（藏拙/试探/避祸/算准才动），却越谨慎越被卷入——被迪化推上神坛、被善良拉扯、被大势裹挟。**越想藏越显眼，越谨慎越深陷。**

**★主动出击燃点（冲突强化·配合成长解锁）**：凶兽威胁火云洞 / 镇元子，红云**首解锁葫芦·主动散凶兽碾压**（建立"红云一出手就解决"的预期，不是逃跑学，是反杀学）。

## 八、人物弧线
- **红云**：茫然穿越的蓝星倒霉蛋 → **谨慎求生者**（认人拼图初成，谨慎对象 = 自保）。**在洪荒扎下第一根**（镇元子同行 + 后土善良映照）。

- **后土**：**卷一早出场** → 共同救护中初遇（善良映照，深度关系②起，浅识深印象；→ 卷三主场拒救、卷五闭环）。
- **元凤/伏羲**：被红云谨慎救（善缘种，欠恩；红云起初不认得他们）。
- **鲲鹏**：短暂同行（本可成友）→ **让座破裂结怨**（怨起有重量，深度关系⑤起；迪化让鲲鹏对红云"深不可测"更忌惮）。

## 十、本卷反转
- **认人反转**：知"此人会害我/会陨"却认错人——把好人当坏人防、把坏人当好人近（认人悬念首次兑现，为全书反转装置奠基）。
- **让座反转**：让座的「善举」反成悲剧之因（论点首次显现）。
- **善良双刃**：L1-4 让座（恶因）vs L1-3 救元凤（善因）——同一种善良两种果。
- **迪化反转**：红云越想藏/越茫然，越被脑补成高深，名声越大，因果越缠。

## 十二、黄金三章专门设计（L1-1 前段）

- **第 1 章 · 化形即穿越·死局倒计时·首解锁**
  - 钩子：**外部撞击 + 倒计时 + 成长首解锁**（不茫然内向）。化形瞬间准圣气息波动 / 祥云异象**立刻引来附近威胁**（凶兽 / 觊觎者 / 路过大能）——红云（蓝星意识刚降临）还没搞清"我是谁"，威胁已到。
  - 倒计时：他反应过来自己是必死的红云，且**第一个威胁已经上门**——死局不是抽象的，是"我现在连怎么用这具身体都不会，就要被打死了"。
  - 成长首解锁：被迫应对，**第一次笨拙地摸索催动葫芦 / 准圣力量**（不确定、试错、勉强催动）——勉强化解威胁。展示"有力量但不会用"的成长流起点（**爽点 = 首次催动葫芦**）。
  - 交付：人设（蓝星穿越 + 倒霉 + 有力量不会用 + 谨慎）+ 世界 + 钩子（死局倒计时 + "我连自己的力量都不会用，必须尽快摸索"的紧迫）

- **第 2 章 · 谨慎的第一步 · 认人悬念 + 迪化初显**
  - 探查火云洞 + 布避祸阵 + 初探洪荒散修圈
  - **认人悬念立**：第一个撞见的大能，红云**不认识**，谨慎试探套话（这是谁？敌友？）
  - **迪化初显**：对方脑补红云的谨慎试探/避祸动作"暗合天道 / 在考校道心"（他真不懂）
  - 交付：策略立 + 世界展开 + **认人悬念立 + 迪化机制立**

- **第 3 章 · 结识镇元子**
  - 挚友线起 + 大能圈入口；镇元子是首位**深度认人试探对象 + 深度迪化者 + 洪荒向导**（红云谨慎试探他身份 / 套洪荒常识，他抚掌赞叹红云"造化"——实则是红云在认世界）。**深度关系①（扎根）起**。
  - 交付：第一个深度关系建立（镇元子同行扎根）+ 善缘种子（镇元子枢纽）+ 章尾钩子（镇元子提及紫霄宫讲道 / 凶兽阴影）

## 十三、正文夯实指引（本卷）

| 维度 | 要求 |
|---|---|
| **认人悬念写法** | 红云知结局但不认人——每次接触新角色都写他的"对号试探"（从言行/修为/法宝/旁人称呼推断这是谁）+ 认错的可能；读者跟红云一起拼图。落到具体动作（套话/观察/印证），禁"他一眼认出这是XX" |
| **迪化写法** | 内心 OS（茫然苟命）vs 外界脑补（大佬）反差；**真茫然被误读**（不是装的）；脑补落到具体角色的具体反应（镇元子抚掌/三清互视/鲲鹏阴鸷/伏羲动容），禁"众人震惊"；穿插动作对话不连续独白 |
| **战斗写法** | 谨慎保命式（先观察/算准才出手/法宝+借势脱身/不恋战），不硬刚顶级、不碾压；九九散魄葫芦的具体威力（散魂/红霞/威压）；战前铺危机、战中写策略反转、战后留迪化脑补 |
| **场景颗粒** | 感官锚点（火云洞云气/万寿山人参果香/洪荒混沌天象/紫霄宫紫气威压/战场血霞）+ 动作 + 对话 |
| **情绪节拍** | 卷级弧线落到每场戏 show don't tell——谨慎通过具体试探/算计动作、认人悬念通过对号与认错、迪化通过反差、战斗通过策略，禁"他很恐惧/他感到" |
| **钩子链** | 章首 7 式 / 章尾 13 式；黄金三章强钩子；日常章弱钩子或情绪钩子 |
| **对话潜台词** | 角色语言档案：镇元子沉稳厚重/红云温润避世（内里茫然算计）/鲲鹏阴鸷/元凤端庄/伏羲温润。对话三功能 |
| **四型姿态** | 每事件标 A/B/C/D 型，不连续两件大事同型 |
| **禁用词前置** | 按 [文风.md](../设定/文风.md) + narrative-writer 规范；否定翻转/总结收尾/堆叠比喻前置规避 |
