## 三、认人悬念 + 迪化层（★ v2.3 双核心引擎）

### 红云的双面
- **内心**：蓝星普通人 + 只记得读过的洪荒小说结局 + **茫然恐惧**（这是哪？我是谁？这些都是谁？）+ 谨慎自保
- **外表（被脑补）**：高深莫测的红云道兄 / 洪荒老好人 / 慈悲大能 / 深谋远虑 / 暗合天道

### 认人悬念机制（v2.3 新核心装置）
- 红云**知结局**（鲲鹏会害我围杀我 / 太一帝俊会陨 / 后土化轮回 / 通天被贬 / 截教封神败），但见到现实的人**根本认不出**——小说是文字名字，现实是真人，对不上号。
- 他必须**谨慎试探 / 对号**：通过言行、修为、来历、法宝、旁人称呼，慢慢把名字和人配上。且**可能认错**——把好人当坏人防、把坏人当好人近。
- **认错风险制造悬念与反转**：他知道"鲲鹏会害我"，但北冥来的大妖是不是鲲鹏？他不确定，于是谨慎防备了一个可能无辜的人，或错信了一个真正危险的人。
- **认知从零累积**读者跟红云一起拼图——化形时谁都不认 → 游历中逐渐对号 → 紫霄宫讲道（大能齐聚）才大致认全。认知是本卷的一条暗线进度。

### 迪化机制（v2.3 升级：真茫然被误读，不是装的）
- 红云的**谨慎摸索**（试探对方身份 / 藏拙避祸 / 谨慎救人 / 算准才出手）被大能脑补成"高深"——**他真不懂、真茫然，是被误读**（比 v2.1"装的"更深一层，也更心酸）。
- 他谨慎试探某人身份时，对方脑补"红云道兄在试探我的道心"；他谨慎藏拙时，对方脑补"深不可测"。
- 迪化是红云"种因"的**加速器**——快速织网；也种恶因（被脑补成威胁，招忌惮/觊觎，如鲲鹏冥河因红云"深不可测"而警惕）。
- **与论点咬合**：红云越谨慎（藏/试/避），越被脑补，越结因果，越陷深——越想藏越显眼。

### 千层饼引擎（卷一首建·贯穿全书）
> 红云专属反转引擎：**他算到第二层，实际发展到第四层。** 每件事比他设计的多绕 1-2 圈。

**卷一示范千层饼——让座五层（L1-4 核心）：**
1. **谋定（层 1）**：红云知"让座种祸"→谋定"降低存在感"（迟到/缩后排/不与鲲鹏对视/不接话头）。
2. **跑偏（层 2）**：他的"低调"被大能读成"高风亮节不争"→反而被推向前排。
3. **迪化（层 3）**：到了前排他试图推托→推托被脑补"谦德/暗藏玄机"→关注度更高。
4. **后果（层 4）**：鲲鹏的怨气因"红云虚伪谦让"更深（本就因短暂同行破裂而怨，现在更觉得红云做作）→ 紫气招祸的因果比原著更早结下。
5. **宿命（层 5）**：他什么招都使了，还是被大势推到让座——**读者：他真的尽力了。**

**写法纪律**：千层饼**不是万能套路**，只用于每卷 1 个核心大事件（本卷=让座）。其余事件用简单迪化（1 层误读）即可。千层饼一旦使用，每组 3-5 层，层层有因果支撑（不是硬扭）。层 1 必须有谋定链（展示"因为 X，他选 Y"），层 2-3 靠倒霉/信息差/迪化推动，层 4-5 是后果+可能被下一轮谋定利用。**跨卷的大事件**（如必死劫顺延→金蝉脱壳）可用跨卷千层饼——层跨卷累积，终卷一次性兑现。

### 迪化喜剧写法
- 内心 OS（茫然苟命）vs 外界脑补（大佬）的反差；但**穿插动作/对话**，不连续心理独白（story-narrative 规则 6）。
- 每个脑补落到具体角色的具体反应（镇元子抚掌/三清互视/鲲鹏阴鸷/伏羲动容），禁"众人都震惊"。

### 单元 L1-1：渐入式荒诞开场·金山乞丐·立足火云洞（开篇弧·约6章）
> **详细设计见 [L1-1开篇弧线重构.md](L1-1开篇弧线重构.md)**。本节是单元卡概要。

- **单元 ID**：L1-1
- **主推线**：立红云人设（蓝星穿越/不知道自己是谁/有力量不会用/金山乞丐/谨慎为核心/吃货）+ 火云洞道场 + **镇元子关系起（深度关系①）** + **认人悬念渐起** + **迪化机制起**
- **★身份揭晓推迟**：红云化形时不知道自己是谁——蓝星记忆因化形冲击碎片化，只有模糊不安。**身份在第3章被别人告知**（"你叫红云"→记忆雪崩→"我应该写遗书？"），不是自己想起来。
- **★金山乞丐喜剧引擎**：准圣修为+先天灵宝但完全不会用——核心喜剧。葫芦"看心情"触发、飞行撞洞顶、感知炸脑子、布阵画歪线。喜剧密度在开篇弧最高，随弧线递减。
- **章节结构（6章·每章多阶段交叉）**：
  - **ch1**（①不知道在哪 + ②外面太可怕）：化形→茫然→蓝星人本能→翻找食物(F05)→发现刻痕(F01)→踏出洞口→远观洪荒恐怖→缩回→测试灵草没味道→发现非灵物野草→刻天数

  - **ch4**（⑥金山深化 + ⑦来邻居）：继续解锁失败→地脉品灵力(F01因果推进：波动传万寿山)→**镇元子上门投诉噪音**→教力量控制→探地脉发现异常脉络→果茶事件→力量可控

  - **ch6**（⑩赶鸭子上架）：紧急备战→歪阵/半吊子飞法/对葫芦战前动员→镇元子协调防御→走向战场→**L1-2凶兽量劫开始**

### 单元 L1-2：凶兽量劫·谨慎战斗救伏羲·认人悬念加深
- **单元 ID**：L1-2
- **主推线**：A 被动卷入凶兽量劫 → 红云**谨慎战斗** + 救伏羲（善缘②）+ **后土初遇·善良映照（深度关系②起）**
- **认人悬念**：凶兽潮波及火云洞/游历路线，红云远遁避祸（知凶兽量劫结局，但**不认得**凶兽、不认得参与的大能）。撞见一受伤的先天神祇（伏羲），**不认得他是伏羲**，但谨慎善良相救；又遇**一名救护弱者的慈悲女子（后土）**，不认得，却被她的温柔震撼（对号悬念：这是小说里的谁？）。
- **战斗（谨慎保命式）**：先观察凶兽弱点、算准才出手、九九散魄葫芦散凶兽魂魄 + 祥云之力 + 避其锋芒护伏羲脱身、不恋战。展现准圣 + 先天灵宝战力，但**策略性、不硬刚、不碾压**。
- **共同经历（[魔改]·深度关系①深化·凶兽被迫协防）**：
  - **镇元子线·被迫协防**：凶兽潮波及火云洞-万寿山交界地脉。镇元子**不能只守万寿山**——凶兽从交界处涌入，如果火云洞方向的凶兽不清掉，万寿山侧翼暴露。他**不得不**跟红云协调防御。
  - **战斗中的自然深化**：镇元子第一次看到红云在实战中用他教的的力量控制——笨拙但管用。他发现红云在战斗中**听进了他教的东西**（不像其他大能学了就走/偷师/转手卖人情）。打完之后镇元子不用吩咐，红云主动清理了交界处残存的凶兽（不是帮镇元子——是帮自己，交界处不安宁火云洞也不安全）。**两个自私的理由碰巧指向同一个方向——各自守各自的，但守住各自等于守住共同**。
  - **关系状态**：扛过命了——朋友。不是"发现合作效率高的邻居"，是**一起打过仗的人**。不需要确认，扛过命就是。
  - **专属暗号建立**：镇元子进火云洞从此不敲门直接进；红云布阵时镇元子在旁边喝茶挑漏洞不帮忙但会指出哪里歪了。这是只有他们两人之间的交流方式。
- **后土支线（同一战场另一角落·深度关系②起）**：
  - 后土在凶兽潮波及的人族聚落废墟中救护弱者（她的日常）。红云也在同一片战场——他撞见受伤的伏羲（不识），谨慎善良相救。
  - 后土在旁边看到了红云救人的全过程：他手抖着催动葫芦（笨拙），救完转身就走（谨慎/不沾因果），走了两步又**回头看了一眼**——确认那人活下来了。
  - 后土认出这个矛盾：**想跑但跑不了，怕死但还是伸手了**——她自己就是这样（巫族以战为荣，她的力量是"承载"非"破坏"，每次救护也是"我也不想但忍不住"）。她不是觉得红云"好"——是**认出同类**。
  - 红云灵力消耗大，下意识问"你身上带吃的了吗"——后土没迪化。她是全书第一个没把红云当"高深大能"的人。递过巫族干粮，说了半句"你啊——"没说完。暗号种子：红云在后土面前不用装。
- **伏羲支线（被救·善缘②·因果种因）**：
  - 红云在凶兽潮中救了一个受伤的先天神祇——不认得他是伏羲。混沌中来不及问，止血/隐匿/指路，救完匆匆离去。
  - 伏羲欠恩但不识救命者（为卷三"吃货觉醒"后两人交集埋因——到卷三共同护人族时，伏羲才逐渐对上号）。
- **多线交织点**：一场凶兽量劫，同时推了三条关系线（镇元子扛命→朋友 / 后土认出同类 / 伏羲欠恩种因），且都与"红云的善良+谨慎"这一个核心行为相关——他救人时既善良（伸手）又谨慎（想跑），这个矛盾同时被镇元子（看到笨拙但管用）、后土（看到想跑又回头）、伏羲（感受到救命之恩）各自捕捉到不同的面向。
- **迪化**：凶兽期大能见红云出手，脑补"红云道兄威能深不可测/一葫散凶兽"（实为保命+善良）；伏羲被救欠恩。迪化加深，名声传。
- **远观罗睺鸿钧**（天道之威远因）；**诛仙剑落通天**伏笔
- **战果线**：善缘②种 / 战斗场面立 / 迪化名声起 / 罗睺线
- **对标参照**：我师兄 ch7-13（进险地 + 铺底牌 + 反杀战斗——被动入局后主动出手）

### 单元 L1-4：紫霄宫听道·认全人·建大能圈·让座（卷尾大钩子）
- **单元 ID**：L1-4
- **主推线**：**认人拼图收口** + 建大能圈关系网 + 让座（D 主动选择）
- **认人悬念收口**：紫霄宫讲道，洪荒主要大能齐聚——红云**终于把小说名字和现实人大致对上号**。认人暗线进度收束。但让座当口，他对鲲鹏的怨意、紫气之争的大势尚看不透——**认全人 ≠ 看透局**。
- **【圣人博弈·紫霄宫座位暗战】**：紫霄宫座位=势力地位。三清前排（老子居中不争/元始端坐/通天大大咧咧）；女娲伏羲一排（女娲冷疏离/伏羲温润观察）；接引准提在角落（准提四处递话拉关系/接引沉默）；帝俊太一张扬（太一声大/帝俊周旋）；鲲鹏在太一身后半步（妖师的身份=不是主人是军师）；镇元子靠前但不争（散修领袖自有位置）。**红云一个刚化形的准圣，在这些人里格格不入**——座位安排的社交暗战是世界观的第一印象。
- **鲲鹏短暂同行→破裂（[魔改]·深度关系⑤起）**：
  - **★关系建立事件——"谋而后动，总比莽撞强"**：紫霄宫路上，红云与北冥来的较强大妖（不知是鲲鹏）短暂同行。途中太一无心刺了鲲鹏一句（"你这般辛苦谋划，天赋一道顶你百年苦修"），戳了鲲鹏"努力被天赋碾压"最痛的疤。红云——自己就是蓝星穿越的"努力苟命的普通人"——在旁边下意识嘟囔一句：**"谋而后动，总比莽撞强。"**（其实是说给自己听的座右铭。）鲲鹏猛地侧目——他是第一次听到一个大能认同"努力谋划 > 天赋莽撞"。他以为红云懂他——红云确实懂，因为他是同类。**这一瞬"这个人，和别人不一样"的错觉种下。**
  - **让座粉碎**：让座时，鲲鹏把红云的"谦让"解读成"虚伪/以退为进的算计"——**"你明明和我一样是努力谋划的人，为什么也用这种虚伪的谦让手段？你也在演！"** 被同类背叛的恨比被敌人打败深十倍。怨因此有重量：**"我以为你懂我，原来你和其他人一样。"**
- **让座（谨慎 vs 善良/大势博弈 · 千层饼主场）**：
  - **谋定链**：知"让座种祸"→谋定"降低存在感"（① 迟到错过选座 ② 缩后排不与鲲鹏对视 ③ 不接话头不引起注意）→ 推理：只要没人注意到我，让座就不会落到我头上。
  - **千层饼执行**（详见三节千层饼引擎）：越低调越被推前→越推托越被迪化"高风亮节"→最终仍被大势推到让座。**他什么招都使了，还是输了——读者：他真尽力了。**
  - **因果流转**：气运流转西方（善缘③）/ 西方欠人情。
- **迪化**：让座被大能脑补"红云道兄高风亮节让圣位"或"暗藏玄机"（实为老好人本性与避祸失败的叠加）。
- **卷尾大钩子**：让座结怨鲲鹏（多因：让座+卷一错位）+ 分宝将至（紫气招祸）
- **对标参照**：洪荒关系户黄金三章（三套话术三圣人）+ 我师兄 ch22-30（算计升级转折）

## 十二、黄金三章专门设计（L1-1 前段）

- **第 1 章 · 化形即穿越·死局倒计时·首解锁**
  - 钩子：**外部撞击 + 倒计时 + 成长首解锁**（不茫然内向）。化形瞬间准圣气息波动 / 祥云异象**立刻引来附近威胁**（凶兽 / 觊觎者 / 路过大能）——红云（蓝星意识刚降临）还没搞清"我是谁"，威胁已到。
  - 倒计时：他反应过来自己是必死的红云，且**第一个威胁已经上门**——死局不是抽象的，是"我现在连怎么用这具身体都不会，就要被打死了"。
  - 成长首解锁：被迫应对，**第一次摸索催动葫芦**——不确定、试错、手忙脚乱。但葫芦一旦催动→**一击震慑**：散魄之力将威胁直接轰散（凶兽魂魄散尽/觊觎者被准圣威压逼退），威力远超红云自己的预期。**红云被自己这具身体的力量吓了一跳——"这……这么强？"** 展示"有力量但不会用"的成长流起点，同时给读者一个**"卧槽这主角有点东西"的瞬间**（爽点 = 首次催动葫芦一击震慑，不是勉强化解）。力量展示后红云立刻收敛（谨慎人设），但那一击的余威让附近的散修/凶兽暂时不敢靠近火云洞——给红云争取了立足的缓冲期。
  - 交付：人设（蓝星穿越 + 倒霉 + 有力量不会用 + 谨慎）+ 世界 + 钩子（死局倒计时 + "我连自己的力量都不会用，必须尽快摸索"的紧迫）
  - **★鸿钧伏笔前移——账外的灵魂**：化形波动被合天道的鸿钧感知——但鸿钧感知到的不是"一个新大能出世"，而是**洪荒因果账上多了一笔对不上的账**。红云的真灵是蓝星穿越来的，不在天道因果网内——他是"账外灵魂"，又恰好落在火云洞（人道规则锚点）。鸿钧合道后一直在找机会堵火云洞漏洞，但规则需要一个"因果网外的灵魂"来撬动——本源大能都在账内撬不动。一笔带过（红云感到一阵莫名寒意但不知来源），到卷二 L2-1 分宝时鸿钧赐紫气才显化。**读者回看时发现：鸿钧从第一章就在。**

- **第 2 章 · 谨慎的第一步 · 认人悬念 + 迪化初显**
  - 探查火云洞 + 布避祸阵 + 初探洪荒散修圈
  - **认人悬念立**：第一个撞见的大能，红云**不认识**，谨慎试探套话（这是谁？敌友？）
  - **迪化初显**：对方脑补红云的谨慎试探/避祸动作"暗合天道 / 在考校道心"（他真不懂）
  - **小爽点闭环**：红云布避祸阵时歪打正着解决了一个小麻烦（如阵法意外困住了一只在附近窥探的低阶凶兽/散修探子）→旁边看到的散修脑补"红云道友布阵杀鸡儆猴，深不可测"→红云内心"我只是在藏自己啊"。**一个完整的"歪打正着→被迪化→读者爽"的小闭环**。
  - **吃货铺垫（轻笔）**：红云摸索这具准圣身体时，发现"不用吃饭也能活"——但灵魂深处一个蓝星人在哀嚎：**我想吃顿好的**。一笔带过，不展开。
  - 交付：策略立 + 世界展开 + **认人悬念立 + 迪化机制立 + 小爽点闭环 + 吃货人设一笔**

- **第 3 章 · 结识镇元子**
  - 挚友线起 + 大能圈入口；镇元子是首位**深度认人试探对象 + 深度迪化者 + 洪荒向导**（红云谨慎试探他身份 / 套洪荒常识，他抚掌赞叹红云"造化"——实则是红云在认世界）。**深度关系①（扎根）起**。
  - 交付：第一个深度关系建立（镇元子同行扎根）+ 善缘种子（镇元子枢纽）+ 章尾钩子（镇元子提及紫霄宫讲道 / 凶兽阴影）

## 十三、正文夯实指引（本卷）

| 维度 | 要求 |
|---|---|
| **认人悬念写法** | 红云知结局但不认人——每次接触新角色都写他的"对号试探"（从言行/修为/法宝/旁人称呼推断这是谁）+ 认错的可能；读者跟红云一起拼图。落到具体动作（套话/观察/印证），禁"他一眼认出这是XX" |
| **迪化写法** | 内心 OS（茫然苟命）vs 外界脑补（大佬）反差；**真茫然被误读**（不是装的）；脑补落到具体角色的具体反应（镇元子抚掌/三清互视/鲲鹏阴鸷/伏羲动容），禁"众人震惊"；穿插动作对话不连续独白 |
| **战斗写法** | 谨慎保命式（先观察/算准才出手/法宝+借势脱身/不恋战），不硬刚顶级、不碾压；九九散魄葫芦的具体威力（散魂/红霞/威压）；战前铺危机、战中写策略反转、战后留迪化脑补 |
| **场景颗粒** | 感官锚点（火云洞云气/万寿山人参果香/洪荒混沌天象/紫霄宫紫气威压/战场血霞）+ 动作 + 对话 |
| **情绪节拍** | 卷级弧线落到每场戏 show don't tell——谨慎通过具体试探/算计动作、认人悬念通过对号与认错、迪化通过反差、战斗通过策略，禁"他很恐惧/他感到" |
| **钩子链** | 章首 7 式 / 章尾 13 式；黄金三章强钩子；日常章弱钩子或情绪钩子 |
| **对话潜台词** | 角色语言档案：镇元子沉稳厚重/红云温润避世（内里茫然算计）/鲲鹏阴鸷/元凤端庄/伏羲温润。对话三功能 |
| **四型姿态** | 每事件标 A/B/C/D 型，不连续两件大事同型 |
| **吃货写法** | 卷一是铺垫期：轻笔带过（嚼灵草不是味/蹭人参果/想念蓝星食物），不展开，不硬塞。吃货暗线是"藏着的钩子"，读者到卷三才恍然"原来他一直在馋" |
| **谋定链写法** | 关键决策展示"因为 X，所以我选 Y"（1-3 句），不展示结果。穿插动作落地，禁止长段内心独白推演 |
| **千层饼写法** | 仅让座用千层饼（5 层）。其余事件用简单迪化（1 层误读）。千层饼层层有因果支撑，不是硬扭 |
| **禁用词前置** | 按 [文风.md](../设定/文风.md) + narrative-writer 规范；否定翻转/总结收尾/堆叠比喻前置规避 |
