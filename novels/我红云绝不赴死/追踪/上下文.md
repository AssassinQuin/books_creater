## 锁定的核心（恢复时必读）
- **书名**：洪荒：我红云绝不赴死
- **主角**：红云老祖（蓝星魂穿；化形=穿越触发）。蓝星本名 **沈云鹤**（父母望闲云野鹤），化形后用本名自称，散修/镇元子叫他"云鹤道友"；L1-4 紫霄宫赐号"红云"
- **切入时间点**：紫霄宫讲道前·红云化形（鸿钧已合道，大能已出世，讲道未开）
- **主线五折**：避祸种因 → 死而复生·顿悟 → 试手守恒 → 沉淀布暗 → 封神脱壳·立人道抗天（详见 [大纲/大纲.md](../大纲/大纲.md)）
- **全书主题（背景色·非统帅）**：**天道算得尽因果，算不尽人心**——"能活却选择不独活"（后土能救却赴死 / 红云能苟却立道）= 遁去的一 = 人道高于因果。详见 [设定/全书主题纲领.md](../设定/全书主题纲领.md)
- **核心机制**：因果守恒 + 因果调度（识链-断链-转嫁该承之人／化解）；红云只前世记忆（知小说结局/不认人/不知现实），近乎无金手指，靠谨慎
- **力量体系（v3.0 定版）**：本命神通散魄为根，**从零修炼到半圣**（非化形即准圣）。化形时只有散魄雏形 + 先天灵宝葫芦（有灵智），修为低。靠修炼散魄提升，**自认天才**（实为火云洞真身先天加成，他不知）。葫芦 = 有灵智的伙伴（看心情触发 + 闹脾气）
- **身份揭晓**：**L1-4 紫霄宫赐号"红云"→激活蓝星记忆→无人点破自己想起**（非 ch3 被告知、非 L1-2 善后）
- **终局反转**：四层反转"应劫"大戏；死劫导入火云洞人道规则化劫润人族；揭破鸿钧真目标反算；立人道制衡天道
- **无西游**（到封神终局即止）
- **文风**：现代白话 + 古典神话韵味，不文言

## 卷一 v3.0 定版决策

> 卷纲 v3.0 只记录当前状态。以下是不可再改的定版锚点（改动需全链路同步）。

1. **蓝星本名沈云鹤**：全程用本名自称直到 L1-4 赐号。反衬主题：求闲云野鹤，得红云死局；鹤飞走，云染红
2. **力量从零自修**：散魄雏形起步（非化形即准圣），自认天才（实为火云洞真身先天加成），能力线拉长全书
3. **葫芦有灵智**：有灵智的伙伴（不是工具），看心情触发 + 闹脾气（喜剧源）。情感弧线：建立感情 → L1-4 揭晓后想丢/委屈 → 后续和解
4. **身份揭晓在 L1-4**：自修赤云相显化 → 众大能赐号"红云" → 激活蓝星记忆 → 无人点破自己想起。反讽：越强越坐实死局
5. **不知是洪荒→慢慢得知**：化形时不知是谁、不知在哪、不知是洪荒 → L1-1 通过交流 + 发现世界特征慢慢得知
6. **鸿钧/圣人无剧本**：只能因果推测 + 主动布局，非执行原著。F02 = 鸿钧感知账外灵魂 + 火云洞异常 → 布局纳入
7. **让座 = 红云 vs 鸿钧因果博弈（千层饼）**：红云算二层（躲），鸿钧算四层（布局纳入天道账），输在对手更高层的局，非巧合
8. **镇元子协防 = 红云主动求助**：F01 地脉异常引来凶兽 → 红云盘算搞不定 → 破例示弱求助镇元子（朋友契约起点）
9. **迪化三层节制**：日常小误会（不推名声）/ 事件中迪化（名声跃升）/ 里程碑大迪化（名声定格+招祸）
10. **双向启发互动**：沈云鹤真诚求教 → 对方莫名其妙 → 反启发对方悟道/突破（与单向迪化并存）
11. **多线同步交织（非单元接力）**：四线（A成长/B社交/C事件交汇/D暗线）每章至少推进 2 条，事件是交汇爆发点不是独立阶段
12. **日常层七类**：火云洞练功 / 镇元子串门 / 吃货乡愁 / 洪荒游历 / 日记遗书 / 囤货收集 / 修仙工艺偏执
