# 将夜


> **条目名**：将夜

## 概览

- **region**: 全域

## 详细设定

### foreshadowing

    - **planted**: 第零章蚂蚁寓言——蚂蚁搬回龙的尸骨，有人在世界最高处杀了一条龙
    - **recalled**: 卷5昊天降临——她从世界最北端雪峰醒来，踏莲而行
    - **span**: ~500章
    - **planted**: 桑桑常年体寒、小脚冰凉、需要宁缺暖脚
    - **recalled**: 卷4桑桑被确认为冥王之女——体寒是冥界气息的表征
    - **span**: ~300章
    - **planted**: 宁缺名字出现在天书第一卷（旁白透露，宁缺本人不知）
    - **recalled**: 荒原争夺天书明字卷——宁缺发现自己的名字早已被昊天记录
    - **span**: ~150章
    - **planted**: 夫子崖洞藏书、书院不器意
    - **recalled**: 宁缺闭关读书三本——崖洞是夫子为他设的修行关隘
    - **span**: ~50章
    - **planted**: 吕清臣老人他是念师
    - **recalled**: 后续揭示吕清臣是书院大先生的化身/关联
    - **span**: ~100章
    - **planted**: 七枚内心独白冥王之女是一碗粥我悬空寺便是那把勺子
    - **recalled**: 勺子隐喻贯穿——各方势力都想做勺子借他人之手达成目的
    - **span**: ~100章
    - **planted**: 书院登山考验——宁缺看到君子不器四字
    - **recalled**: 崖洞闭关时领悟书院不器意
    - **span**: ~40章
    - **planted**: 明字卷预言日月轮回夜临月现
    - **recalled**: 结局——新世界有了月亮宁缺指着月亮说因为有月亮啊
    - **span**: ~600章
    - **planted**: 陈皮皮提到调羹——宁缺说给我一个调羹我就能挖地道回人间
    - **recalled**: 七枚的勺子隐喻与此呼应——调羹/勺子成为全书反复出现的工具意象
    - **span**: ~300章
    - **planted**: 桑桑的丰腴体型反复描写
    - **recalled**: 昊天降临人间时她的身躯很特别身体很丰满——桑桑即昊天
    - **span**: ~400章

### hook_types

    - **effect**: 建立小人物仰望大事件的核心叙事姿态暗示全书主题
    - **examples**: 第零章蚂蚁寓言
    - **type**: 开篇寓言钩
    - **effect**: 用新空间+新规则+新对手制造换地图兴奋感
    - **examples**: 卷1末书院二层楼开启→登山考验
    - **type**: 空间悬念钩
    - **effect**: 身份不确定性让读者持续猜测每次揭露都反转前一次认知
    - **examples**: 宁缺曾被判定不能修行却考入书院桑桑体寒
    - **type**: 身份悬念钩
    - **effect**: 用未知+截止日期制造紧迫感
    - **examples**: 陈皮皮如果三本书都看完了你还不能出来
    - **type**: 章节末悬念钩
    - **effect**: 回看时才惊觉的暗钩鼓励读者重读建立细读习惯
    - **examples**: 桑桑小脚冰的像两根冰树枝般——实则是冥王之女的身体异象
    - **type**: 日常中的暗流钩

### info_delivery

三层信息投放：(1)表层即时——战斗/对话/冲突细节全部即时呈现。(2)深层延迟碎片化——世界观核心设定通过碎片化线索跨卷揭露，每次只给一个碎片，同一悬念至少3次不同角度暗示后才正式揭露。(3)视角信息差——旁白透露给读者但角色不知道的信息，制造上帝视角的紧张感。

### pacing_pattern

六卷三组升降弧：卷1-2上升弧卷3-4下降+逃亡弧卷5-6终局弧。每卷内部日常蓄水→冲突爆发→余波沉淀三段式。卷间以空间转换硬切割，空间即节奏。荒原卷最长~340章用公路文结构维持长弧张力。

### pov

宁缺第三人称有限视角为主轴+全知叙述者冷眼旁观（世人以为/殊不知句式）+特殊场景切换至桑桑/昊天/七枚等非主角视角制造信息不对称。昊天降临段使用纯客观描写无心理活动，制造神明非人感。

### unique_techniques

- **蚂蚁视角寓言框架**
  - **概述**: 以最低微生物视角描写最高层级事件建立凡人对不可知之事的仰望
  - **示例**: 第零章蚂蚁搬回龙的尸骨
- **神明降临的纯客观描写**
  - **概述**: 昊天描写完全不写心理活动只用视觉描写制造非人冷漠感
  - **示例**: 卷5第一章：她闭着眼睛容颜普通寻常眼眸里没有任何杂质也没有任何情绪
- **勺子工具隐喻系统**
  - **概述**: 用日常器具隐喻各方势力政治博弈转化为具象的厨房场景
  - **示例**: 七枚：冥王之女如果是一碗粥我悬空寺便是那把勺子
- **信息不对称叙事**
  - **概述**: 读者通过旁白知道信息但角色不知道持续制造紧张
  - **示例**: 此时的他并不知道自己的名字已经出现在天书的第一卷里
- **日常对话中的世界观投放**
  - **概述**: 通过角色闲聊/争吵自然透露世界观不用设定说明文
  - **示例**: 陈皮皮扔书：这本书讲的是书院不器意
- **回看型暗钩**
  - **概述**: 前文埋入看似无关日常细节后文揭晓身份后读者主动回溯
  - **示例**: 桑桑小脚冰→数百章后确认冥王之女体寒是冥界气息
- **反高潮日常收束**
  - **概述**: 历经神明降临天地大战后结局回到最琐碎日常用不变日常强调生活继续
  - **示例**: 结局：世界上切牡丹鱼最好的是两个人大师兄和桑桑
- **空间即节奏的公路文骨架**
  - **概述**: 以行走为骨架串联独立叙事单元用地理移动维持长弧张力
  - **示例**: 卷2结构：长安出发→各势力领地→争夺天书→遭遇魔宗
- **章标题叙事功能化**
  - **概述**: 章标题不是概括而是情绪锚点或悬念设置
  - **示例**: 第一百六十一章：自今日始你我不再命如纸
