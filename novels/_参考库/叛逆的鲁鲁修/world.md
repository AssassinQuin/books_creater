# 叛逆的鲁鲁修 — 世界观分析

## 1. 不列颠帝国殖民体系

### 1.1 Numbers等级制度

**核心机制**：被征服地区的原住民被贬为"Numbers"（数字），丧失公民权。

**社会分层**：
| 等级 | 身份 | 权利 |
|------|------|------|
| 皇族 | 不列颠皇室成员 | 绝对权力 |
| 贵族 | 不列颠贵族/骑士 | 特权阶层 |
| 荣誉不列颠人 | 效忠帝国的原住民 | 有限权利 |
| Numbers | 被征服地区居民 | 无公民权 |

**文本证据**（Stage3-SWORD）：
> 一个殖民地的原住民，一个日本人，居然加入了不列颠贵族行列...这在一部分种族歧视主义根深蒂固的不列颠人眼中简直如同噩梦。

### 1.2 11区（日本）的社会结构

**占领后的变化**：
- 国名被剥夺，改为数字"11区"
- 原日本首相枢木玄武死亡（朱雀弑父）
- 抵抗组织持续活动（华莲等人）
- 不列颠移民享有特权

**双重生活**：
- 表面：不列颠统治下的"和平"
- 地下：抵抗运动、恐怖袭击、情报战

## 2. Knightmare机甲系统

### 2.1 军事地位

Knightmare是不列颠军事优势的核心：
- 人形机动兵器，高度约4-5米
- 高机动性，可在城市战和野战中使用
- 驾驶员（Knight）的社会地位高

**型号体系**：
| 型号 | 特点 | 使用者 |
|------|------|--------|
| Lancelot | 白色，第七代，实验机 | 朱雀 |
| Guren Mk-II | 红色，中华联邦技术 | 华莲 |
| Mordred | 重型，圆桌骑士专用 | 阿妮亚 |

### 2.2 战术逻辑

- Knightmare不是无敌的，有能量限制（Energy Filler）
- 驾驶员技术决定战斗力
- 特种机型改变战局平衡

**文本证据**（圆桌骑士）：
> Knightmare的必要条件之一是被搭乘者之存在...没有搭乘者的实战从一开始就是错误的。

## 3. Geass系统

### 3.1 Geass的本质

- 源自"C的世界"（集体潜意识）
- 由Code持有者赋予
- 反映获得者的内心愿望/欲望

### 3.2 已知Geass能力

| 持有者 | 能力 | 代价/限制 |
|--------|------|----------|
| 鲁路修 | 绝对服从（对视时） | 无法关闭，最终双眼 |
| 朱雀 | 活下去（被动） | 强制生存本能 |
| 毛 | 读心 | 范围过大，无法关闭 |
| 洛洛 | 时间停止（感知层面） | 心脏负担 |
| 查尔斯 | 记忆篡改 | — |
| 玛丽安娜 | 灵魂转移 | 需要阿妮亚作为容器 |

### 3.3 Code系统

- Code = 永生 + Geass赋予能力
- 从Geass进化而来（双眼Geass者可能获得Code）
- C.C.和V.V.是已知Code持有者
- Code可以封印，但无法真正摧毁

## 4. 神秘组织

### 4.1 Geass教团
- 研究Geass的秘密组织
- 培养Geass能力者
- 被查尔斯皇帝利用

### 4.2 阿卡夏之剑
- 查尔斯和V.V.的计划
- 意图消灭人类的"谎言"（停止时间/意识统一）
- 最终鲁路修阻止了这一计划

## 5. 国际格局

**世界三分**：
1. **不列颠帝国**：控制美洲、日本、部分欧洲
2. **中华联邦**：亚洲大陆，内部不稳
3. **EU（欧洲联盟）**：欧洲大陆，与不列颠对抗
