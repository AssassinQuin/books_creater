# 叛逆的鲁鲁修 — 能力体系分析

## 1. Geass系统核心机制

### 1.1 本质
- 源自"C的世界"（集体潜意识/阿卡夏记录）
- 由Code持有者赋予
- 反映获得者的**内心最深愿望**

### 1.2 获得条件
- 与Code持有者签订契约
- 契约内容通常是"实现愿望"的交换
- 愿望决定Geass的形态

### 1.3 进化与失控

**进化路径**：
- 初始：单眼Geass，有限能力
- 进化：双眼Geass，能力增强
- 终点：可能获得Code（永生+赋予能力）

**失控机制**：
- 使用频率越高，失控风险越大
- 失控时Geass持续发动，无法关闭
- 鲁路修的双眼Geass就是失控的表现

## 3. Code系统

### 3.1 Code持有者
- **C.C.**：最古老的Code持有者之一
- **V.V.**：查尔斯的哥哥
- **查尔斯**：从V.V.处获得，后被鲁路修夺取
- **鲁路修**：最终成为Code持有者（争议）

### 3.2 Code特性
- **永生**：不老不死，伤口愈合
- **赋予Geass**：可与他人签订契约
- **免疫Geass**：不受其他Geass影响
- **可封印**：C.C.曾封印自己的Code，但无法摧毁

### 3.3 Geass与Code的关系
```
普通人 → 签订契约 → Geass持有者 → 双眼Geass → 可能获得Code
```

**关键规则**：
- 只有双眼Geass者可能获得Code
- 获得Code后失去Geass能力
- Code可以转让，但转让条件不明

## 4. 能力体系的叙事功能

### 4.1 愿望具现化
- 每个人的Geass反映其内心最深欲望
- 鲁路修：控制欲 → 绝对服从
- 朱雀：求生欲/赎罪 → 活下去
- C.C.：渴望被爱 → 被所有人爱

### 4.2 代价机制
- 能力越强，代价越大
- 失控是能力的必然终点
- 没有"免费"的力量

### 4.3 叙事扳机
- Geass不是战斗技能
- 每次使用都推动关键剧情
- 尤菲米亚大屠杀：Geass失控作为叙事转折点
