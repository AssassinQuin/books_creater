# 叛逆的鲁鲁修 -- 可借鉴能力体系

## 模式1：Code永生契约系统（adapt）

**核心**：赋予者与持有者的永生契约

**操作要点**：


**操作要点**：
- 永生者可以与他人签订契约
- 契约内容：赋予力量，交换条件（通常是实现愿望）
- 契约关系不是主仆，而是互相依赖
- 契约可以解除，但代价巨大

**C.C.的契约模式**：
- 给予Geass
- 见证契约者的结局
- 孤独地继续永生
- 与鲁路修的关系打破这一模式

**改编方向**：以太赋予者与觉醒者的契约关系

**适用场景**：奇幻/史诗/言情

---

## 模式2：愿望具现化能力（adapt）

**核心**：能力形态反映内心最深欲望

**操作要点**：


**操作要点**：
- 能力不是随机赋予，而是反映获得者的愿望
- 鲁路修：控制欲 → 绝对服从
- 朱雀：求生欲/赎罪 → 活下去
- C.C.：渴望被爱 → 被所有人爱
- 毛：理解他人 → 读心

**叙事功能**：
- 能力揭示角色内心
- 能力的代价与愿望的强度成正比
- 愿望的扭曲导致能力的扭曲

**改编方向**：觉醒者的能力反映其灵魂纹路/内心渴望

**适用场景**：超能力/奇幻/心理

---

## 模式3：能力失控与进化（direct）

**核心**：力量增长伴随失控风险

**操作要点**：


**操作要点**：
- 能力随使用频率增强
- 增强伴随失控风险
- 失控时能力持续发动，无法关闭
- 最终可能失去人性或获得更高层次的力量

**Geass进化路径**：
```
单眼Geass → 频繁使用 → 双眼Geass → 失控 → 可能获得Code
```

**关键规则**：
- 没有"免费"的力量
- 能力越强，代价越大
- 失控是能力的必然终点

**改编方向**：以太能力的侵蚀与失控机制

**适用场景**：超能力/暗黑/惊悚
