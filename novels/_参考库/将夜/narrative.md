## 视角策略

宁缺第三人称有限视角为主轴 + 全知叙述者冷眼旁观（"世人以为/殊不知"句式） + 特殊场景切换桑桑/昊天/七枚等非主角视角制造信息不对称。昊天降临段使用纯客观描写无心理活动，制造神明非人感。

## 信息投放

**三层信息投放**：
1. **表层即时**：战斗/对话/冲突细节全部即时呈现
2. **深层延迟碎片化**：核心设定通过碎片化线索跨卷揭露，同一悬念至少3次不同角度暗示后才正式揭露
3. **视角信息差**：旁白透露给读者但角色不知道的信息，制造上帝视角紧张感

## 钩子类型（5种）

| 类型 | 示例 | 效果 |
|------|------|------|
| 开篇寓言钩 | 第零章蚂蚁寓言 | 建立小人物仰望大事件的核心叙事姿态 |
| 空间悬念钩 | 书院二层楼开启→登山考验 | 用新空间+新规则制造换地图兴奋感 |
| 身份悬念钩 | 宁缺被判定不能修行却考入书院 | 身份不确定性让读者持续猜测 |
| 章节末悬念钩 | "如果三本书都看完了你还不能出来" | 未知+截止日期制造紧迫感 |
| 日常中的暗流钩 | 桑桑"小脚冰的像两根冰树枝" | 回看时才惊觉的暗钩 |

## 独特技法（9种）

| 技法 | 说明 |
|------|------|
| 蚂蚁视角寓言框架 | 以最低微生物视角描写最高层级事件 |
| 神明降临的纯客观描写 | 昊天不写心理只用视觉，制造非人冷漠 |
| 勺子工具隐喻系统 | 日常器具隐喻各方势力政治博弈 |
| 信息不对称叙事 | 旁白给读者信息但角色不知，持续紧张 |
| 日常对话中的世界观投放 | 角色闲聊/争吵自然透露世界观 |
| 回看型暗钩 | 前文日常细节后文揭晓后读者主动回溯 |
| 反高潮日常收束 | 神明降临后结局回到琐碎日常 |
