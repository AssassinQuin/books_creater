## 体系：元素觉醒体系

**分类**：元素分类 + 等级分层

### 境界（5级，7^n指数增长）

| 境界 | 星子数量 | 描述 | 晋升条件 |
|------|---------|------|---------|
| 初阶（星尘） | 7颗 | 7颗星子组成星尘，对应一个基础魔法技能 | 16岁觉醒仪式 |
| 中阶（星云） | 49颗 | 49颗星子组成星云，对应中级技能 | 星尘满 → 星尘化星云 |
| 高阶（星座） | 343颗 | 343颗星子组成星座，对应高级技能 | 中阶满 → 星云化星座 |
| 超阶（星海） | 2401颗 | 2401颗星子组成星海 | 高阶满 + 资源突破 |
| 禁咒 | — | 最高等级，受国际公约限制 | 极少数人达到 |

### 元素类型

22+ 种：火/冰/雷/风/土/水/光/暗影/召唤/治愈/心灵/空间/混沌/恶魔/诅咒/植物/亡灵/毒/岩/音等

### 战斗体系

**战斗风格**：元素对抗 + 装备强化 + 多系组合

**关键技法**：
- 星子排列施法
- 灵种/魂种/天种强化
- 同系差异化开发
- 恶魔系代价爆发

**天花板控制**：
- 禁咒级受国际公约限制，公开身份 = 失去自由
- 修炼资源被世家垄断（星尘魔器/灵种/地圣泉）

### 独特性

1. 7^n 指数级星子数量增长，数学严谨 + 宇宙意象美感
2. 与斗破苍穹（斗气单一升级）、斗罗大陆（武魂固定）不同，核心创新是多系觉醒 + 视觉化修炼
3. 天生双系每次等级突破可觉醒2系，指数级累积优势（2→3→5→8系）
4. 三级种子强化线（灵种→魂种→天种）独立装备体系
5. 恶魔系：灵魂抽取 + 精魄抵消 + 社会追杀三重代价
6. 同系差异化开发——技能路线 + 灵种品质 + 超阶个性化（三生万象）

### 社会影响

修炼资源被世家垄断，阶层固化严重。能力等级直接决定社会地位——魔法师 = 上等阶层。禁咒法师虽是天花板但受国际公约监管。
