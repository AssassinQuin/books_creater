# 金手指 · 鉴定/感知弱法宝
> 对标凡人修仙传"小绿瓶"——辅助型、不逆天、慢慢摸索

## 形态
一枚不起眼的小物件（建议：古朴残玉 / 蒙尘石珠 / 暗纹铜瞳，待定）。主角偶然得到（凡流被动触发）。

## 能力（鉴定/感知）
- 物品：看穿真伪、灵草药性年份、法器品级与暗病、阵法破绽、矿石成色
- 人：感知他人修为深浅、杀意/敌意、是否说谎（心跳/气息）、虚实
- 危险：模糊的危险征兆预感（"被盯上了""这里有陷阱"）

## 限制（弱、不逆天）
1. **只"看"不给力**：鉴定/感知只提供信息，不给修为/力量/直接战力。看穿危险 ≠ 能打过。
2. **消耗与冷却**：使用消耗神识/精力，过度使用头痛流鼻血；有冷却（不能无限看）。
3. **早期模糊，成长性**：初期只能看穿浅层（低阶物品/明显杀意），随修为提升 + 熟练度才能看更深（高阶/隐蔽）。对标小绿瓶"慢慢摸索规律"。
4. **看穿有代价**：盯着高阶强者看太久会被察觉（暴露）；某些至宝/大能看不穿。

## 配稳健（核心咬合）
**看穿 → 提前察觉危险 → 布局避险 → 稳健**。这金手指是稳健的"眼睛"——韩立靠谨慎猜危险，陈安靠金手指看危险，但看穿后仍要靠稳健布局才能活（看穿不等于能对付）。这让陈安比韩立更能提前避险，但仍不无敌（信息优势 ≠ 实力优势）。

## 成长曲线
随修为/熟练度：浅层鉴定 → 深层鉴定 → 感知杀意 → 危险预兆 → 看破阵法/伪装。每阶段对应一个升级台阶，慢慢解锁（防写无可写）。
