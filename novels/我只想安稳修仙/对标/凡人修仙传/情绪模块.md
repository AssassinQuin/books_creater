# 剧情/情绪模块.md · 凡人流情绪引擎
> 主对标《凡人修仙传》前30章提炼 · 服务《我只想安稳修仙》

## 读者需求
看一个**资质平庸、没背景、没靠山**的普通人,在残酷冰冷的修仙世界,靠**谨慎、算计、藏拙、积累**,一步步活下来、变强、求长生。代入感来自"他和我一样普通",爽感来自"他靠脑子活下来了"。

## 情绪引擎(四核)
1. **求生欲**:主角始终在求生(底层→苦修→被算计→化险),紧迫感贯穿
2. **谨慎的回报**:藏拙/低调/留底牌 → 关键时刻被瞧不出深浅、表面镇定 → 赢。爽点在"藏了这么久终于见效"
3. **积累的爽**:金手指/修炼都不立刻逆天,慢慢试错、摸规律、苦修 → 终于突破。爽在"熬出来了"
4. **化险为夷**:每段危机(阴谋/试药/强敌)靠谨慎+底牌+镇定熬过。爽在"差点死了,但他早就料到"

## 可复现模块卡(7 张)

### M1 底层平庸开局模块
触发:开篇。动作:贫寒日常白描 + 外表平庸 + 聪明藏拙。情绪:代入(我和他一样普通)。凡人1-3章。

### M2 藏拙回报模块 ★稳健流核心
触发:被强敌/师兄/对手打量时。动作:主角缩/低调/不显实力 → 对方"瞧不出深浅" → 主角表面平淡。情绪:暗爽(藏拙见效)。凡人15章(小算盘瞧不出韩立)、30章(墨大夫称奇)。

### M3 弱金手指谨慎试用模块
触发:得金手指。动作:不立刻用,先试(砸/稀释/小批量) → 摸规律 → 才正式用。情绪:好奇+谨慎(凡流金手指不逆天)。凡人10-14章(砸瓶子)、25章(稀释绿液试规律)。

### M4 暗流阴谋推进模块
触发:主线反派布局。动作:反派病重/布局/试药 → 主角察觉异样 → 暗流逼近。情绪:紧张(被算计的危机感)。凡人15-24章(墨大夫病重→抽髓丸)。

### M5 积累突破模块
触发:苦修/试金手指到临界。动作:慢慢积累 → 终于小成/成功。情绪:积累的爽(熬出来了)。凡人25章(催熟成功)、口诀第四层。

### M6 化险为夷模块 ★
触发:危机爆发/反派摊牌。动作:主角表面镇定内心翻涌 → 靠底牌/算计/早预料 → 化解。情绪:险中求生的爽。凡人30章(墨大夫摊牌,韩立早预料)。

### M7 情感代价模块
触发:修炼/求生间隙。动作:思乡/亲情疏离/孤独。情绪:厚度(求生的代价)。凡人20章(家人态度越来越客气)。防主角成无情机器。
