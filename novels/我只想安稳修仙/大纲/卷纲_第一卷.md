# 卷纲 · 第一卷 落霞微末
> 凡流开局 · 对标凡人修仙传七玄门段(1-30章) + 稳健流加码

## 卷信息
- 卷名：落霞微末（落霞宗 + 微末底层）
- 约莫章数：30 章 / ~10 万字
- 所属阶段：开篇期（全书第 1-30 章）
- 功能：立人设 + 立世界 + 得金手指 + 第一次化险为夷（凡流黄金三章范式 + 稳健流底牌雏形）

## 卷契约（承诺读者的快感）
- 凡流爽：底层平庸少年的代入感 + 藏拙回报（被瞧不出深浅）+ 弱金手指谨慎试用的好奇
- 稳健流爽：谋定后动雏形（看穿危险→布局）+ 第一次底牌揭晓的爽
- 期待债：陈安怎么在残酷宗门活下来？鉴定法宝能看穿什么？第一个阴谋是什么？

## 终局储备（本卷解锁/禁碰）
- 解锁：金手指（鉴定法宝）登场定型；陈安藏拙/稳健的人设立住；第一个小阴谋化解
- 禁碰：长生真相、金手指本源、终极宿敌、陈安身世之谜（开篇期不释放）

## 剧情单元（3 个）

### 单元 A：底层入局 + 藏拙苦修（第 1-9 章）
- 主推线：陈安被动入落霞宗 → 藏拙观察 → 拜师苦修
- 战果线：立人设（平庸/藏拙/求生）、立世界（落霞宗/修仙界残酷）、修炼起步（资质平庸的苦）
- 对标：凡人 1-9 章（山村→七玄门→拜墨大夫→修炼难）

### 单元 B：得金手指 + 暗流阴谋（第 10-16 章）
- 主推线：陈安偶然得鉴定法宝 → 谨慎试用摸能力 → 察觉师傅/同门的异样（阴谋逼近）
- 战果线：金手指定型（鉴定/感知，限制+成长性）、第一个阴谋种子埋下
- 对标：凡人 10-19 章（神秘瓶子→试用→墨大夫病重暗流）

### 单元 C：布局化险 + 站稳脚跟（第 17-30 章）
- 主推线：陈安靠金手指看穿阴谋 → 谋定后动留后手 → 危机爆发化险为夷 → 站稳（修为小进/底牌初成）
- 战果线：稳健流首次大兑现（看穿+布局+化险）、陈安从被动求生到主动稳健的转变起点
- 对标：凡人 20-30 章（抽髓丸→试药→配灵药→枭雄末路墨大夫摊牌化险）

## 阶段边界
- 本卷可释放：陈安人设、落霞宗格局、鉴定金手指、第一个阴谋、练气期起步
- 本卷禁止释放：筑基以上境界细节、宗门背后的更大势力、金手指本源、长生真相

## 核心事件
陈安从贫寒少年被动入落霞宗，靠藏拙与苦修熬过底层，偶然得一枚鉴定法宝，看穿师傅的算计，谋定后动留后手，化解第一次杀身之祸，站稳脚跟。

## 起始状态 → 结束状态
陈安：贫寒无依的凡人少年（资质平庸/三重垫底）→ 落霞宗练气期弟子（藏拙立住/金手指在手/第一次化险/稳健雏形成型）
