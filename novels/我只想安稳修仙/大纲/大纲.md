# 大纲 · 我只想安稳修仙（全书体量与阶段总览）

## 全书体量
- 总章节数：长篇马拉松（凡流体量，目标 300+ 章 / 数百万字，按节奏滚）
- 目标字数：百万字+
- 全书情绪曲线：压抑求生（起步）→ 期待积累（苦修）→ 爽感爆发（化险/底牌）→ 圆满长生（收尾）

## 阶段划分
1. **开篇期（第一卷，约 30 章，~10%）**：立人设（平庸/藏拙/求生）+ 立世界（修仙界黑暗森林）+ 得金手指（鉴定法宝）+ 第一次化险为夷。读者建立：对陈安的认同 + 对凡流稳健爽的期待。
2. **发展期（第二-N卷，~60%）**：苦修积累 + 多次阴谋/强敌化险 + 底牌逐步建立 + 修真百艺精进 + 境界逐级突破（练气→筑基→金丹→元婴）。读者建立：对稳健流爽点（谋定后动/底牌）的持续期待 + 对终局长生的迫切。
3. **高潮期（~20%）**：核心冲突爆发（终极宿敌/长生真相/金手指本源）+ 多线收束 + 连续化险/底牌大揭晓。
4. **收尾期（~10%）**：伏笔回收 + 长生达成 + 结局余韵。

## 核心情绪引擎（贯穿）
求生欲 + 谨慎回报（藏拙见效）+ 积累爽（熬出来）+ 化险为夷 + 谋定后动 + 底牌感。
**爽点不在力量碾压，在弱者靠稳健/金手指/积累活下来、赢下去。**

## 关键节点约束（防写无可写）
- 终局底牌（一次性）：长生真相 / 金手指本源 / 终极宿敌 / 陈安身份终点——逐卷解锁，不提前打光
- 升级台阶：练气→筑基→金丹→元婴→化神→渡劫→仙，按剩余档数逐级，不越级
- 金手指（鉴定/感知）随修为/熟练度逐步解锁能力（浅层→深层→杀意→预兆→阵法），不一次性给满
