# 诡秘之主-ability-失控=具体精神异变（非走火入魔）


> **条目名**：诡秘之主-ability-失控=具体精神异变（非走火入魔）

## 概览

- **region**: 全域

## 详细设定

### source_work

诡秘之主

### source_dimension

ability

### pattern_name

失控=具体精神异变（非走火入魔）

### pattern_detail

失控不是抽象的'走火入魔'，而是有具体可观察的精神和行为异变：躁狂、幻听、幻视、心情烦躁、听见疯狂耳语、看到虚幻事物、梦呓、梦游、人格变异。老尼尔因妻子之死的精神创伤叠加魔药负面影响而失控，邓恩被0-08污染也是具体过程。

### source_context

非凡者服用魔药后会持续受到'引人堕落让人疯狂的低语呢喃和虚幻诱惑'，消化不良时表现为躁狂/幻听/幻视/心情烦躁。老尼尔序列7'通灵者'失控：因妻子之死的精神创伤叠加魔药负面影响，最终异变为怪物被邓恩击杀。失控不是瞬间发生而是渐进过程——克莱恩选择'占卜家'时已将'引人堕落的虚幻耳语'列为必须面对的风险之一。

### elements

    - **component**: 失控征兆
    - **value_range**: 初期：心情烦躁、间歇性幻听；中期：持续性躁狂、幻视、梦呓梦游；晚期：人格变异、记忆混乱、行为不可控、彻底异变为怪物
    - **constraint**: 失控征兆是渐进的，有明确的时间窗口（三年观察期）但没有精确的临界点；'自身消耗到极限'状态下最容易暴露
    - **progression**: 渐进式恶化，速度与魔药消化程度负相关
    - **component**: 失控诱因
    - **value_range**: 消化不良（未用扮演法）、精神创伤叠加（老尼尔丧妻）、超量服食（阿尔杰'超量服食接近失控'）、外部污染（0-08对邓恩）、高序列神性侵蚀
    - **constraint**: 失控通常是多重因素叠加，单一因素不一定导致失控；精神状态直接影响消化进度
    - **progression**: 低序列主要风险是消化不良+外部污染，高序列主要风险是神性侵蚀
    - **component**: 失控后果
    - **value_range**: 异变为怪物（老尼尔）→ 成为其他非凡者的猎物/材料来源 → 可能被更高维存在注意利用
    - **constraint**: 失控不可逆——克莱恩选择魔药时已知'一旦服用了魔药，就没有后悔的机会'；失控者会被自己人击杀（邓恩杀老尼尔）
    - **progression**: 固定——失控后只有死亡一条路

### adaptation_map

    - **aspect**: 失控表现
    - **original**: 躁狂/幻听/幻视/心情烦躁/梦呓梦游/人格变异/异变为怪物
    - **abstract_role**: 失控有具体的、可观察的、渐进的行为和精神症状，不是抽象的'走火入魔'
    - **replacement_guide**: 设计3-5个具体的渐进失控症状（听觉异常→视觉异常→行为异常→人格变异→彻底异变），每个症状都有可描写的日常场景，需满足：症状在日常中可观察到、渐进过程有时间窗口
    - **aspect**: 失控诱因
    - **original**: 消化不良+精神创伤+外部污染+超量服食的多因素叠加
    - **abstract_role**: 失控不是'修为不够'而是'心理状态+外部因素+体系特性'的综合结果
    - **replacement_guide**: 设计多种独立的风险因素（心理创伤/体系本身副作用/外部污染源/过度使用），让失控有叙事深度——不是'不够努力'而是'这个世界本身就危险'，需满足：每种因素都能独立展开为剧情
    - **aspect**: 失控叙事
    - **original**: 老尼尔失控被队友击杀，建立'这个世界的规则是认真的'的基调
    - **abstract_role**: 用重要角色的失控事件建立能力体系危险的具象认知
    - **replacement_guide**: 在故事前期安排一个重要配角的失控事件，通过渐进铺垫（提前多次提及风险/状态不稳定）→爆发→不可逆后果，建立读者对能力体系危险的具象恐惧

### applicability

适用于任何有'修炼风险'的能力体系，需要避免'走火入魔'这种模糊表述

### 示例

奥黛丽询问消化征兆时提到'我几乎没有再出现心情烦躁、听见呓语等情况了'。阿尔杰解释传统判定法：'确认完全没有躁狂、幻听、幻视等情况后，让自身消耗到极限，在这种状态下，如果依旧没听见疯狂的耳语，没看到奇怪的事物，那就表明可以晋升。'值夜者规定'至少等三年'才能晋升。伦纳德'从午夜诗人到梦魇用了九年'。
