## 体系：昊天道修行体系

**分类**：五段式境界划分 + 职业分流 + 品级细分

### 境界（7级）

| 境界 | 描述 | 晋升条件 |
|------|------|---------|
| 初境（初识） | 意念自气海雪山外放，明悟天地之息 | 雪山气海十七窍需开通足够数量（万中无一） |
| 感知 | 触碰天地元气并能和谐相处，通过元气感知事物 | 从初识进阶需与天地元气往返交流 |
| 不惑 | 初步明白元气流动规律并加以利用 | 从感知进阶（谢承运年方二十入不惑实属不易） |
| 洞玄 | 意识与天地元气融为一体，可分中上品 | 从不惑进阶极为困难 |
| 知命 | 从本质上掌握元气运行规律，明悟世界本原 | 从洞玄进阶，已有上品之分 |
| 天启（传说） | 聆听昊天启示，暂借昊天威势光明 | 传说境界，人间已不知多少年无圣人 |
| 无距（传说） | 从心所欲而无距，意念所至能抵万里之外 | 传说境界，具体不可考 |

### 战斗体系

**职业分流（同源 → 五职业分化）**：
- 剑师：凝元气于剑
- 符师：封元气于符纸
- 念师：直接调动元气
- 阵师：封元气于阵法
- 武者：布元气于全身

**天花板控制**：
- 境界天花板：五境之上仅传说有天启和无距
- 肉体天花板：修行者长年冥想身体反而孱弱
- 代价天花板：越强代价越大，无代价的全力输出不存在

### 独特性

1. 五境名具哲学深意（初识→感知→不惑→洞玄→知命），与儒家认知暗合
2. 同源分流产生五职业差异化战斗
3. 武道纳入修行体系打破武道修行二元对立
4. 魔宗异端路线提供理念冲突
5. 元十三箭体现技术突破完整路径（跨领域合作模式）
6. 书院二层楼超越世俗等级

### 社会影响

能力等级直接映射社会阶层：洞玄境界在任何国家受到极大尊重；修行者是帝国战略资源；平民与修行者差距极大。
