# 第一序列 - 能力体系维度

## 基础信息
- 类型：都市异能/废土末世
- 优先级：★★★

## 体系概览
- **体系名**：超凡者体系（基因锁/骑士/巫师/纳米机器人）
- **分类**：按觉醒方式与能力来源分类——精神意志具现型、基因改造型、外物接驳型、信仰传承型

## 等级体系
| 等级 | 描述 | 晋升条件 |
|------|------|---------|
| 觉醒者（初阶超凡者） | 因精神意志或基因突变获得超凡能力，表现随机 | 精神意志极度凝聚或遭遇生死危机 |
| 骑士（传承型） | 通过九死一生考验获得资格，能力偏向身体强化 | 完成骑士组织生死试炼 |
| T序列（基因改造战士） | 火种公司基因药剂改造，T1-T5分级 | 注射基因药剂，受个体基因上限限制 |
| 基因锁（超凡者进阶） | 任小粟通过宫殿系统解锁，属性点提升 | 获得感谢币→兑换技能学习图谱 |
| 纳米战士（外物接驳型） | 纳米机器人植入人体，形成外覆式装甲 | 手术植入，同步协调率达标 |
| 巫师（异域能力者） | 通过实验体转化与药物注射 | 注射巫师药物，丧失人类情感 |

## 战斗风格
- 个体能力差异化极大，团战依赖配合
- 关键技法：能力封印、外覆式装甲、空气炮、暗影之门、蒸汽列车、黑刀/黑狙、摧城
- 力量上限控制：基因上限、能力封印、数量压制、代价设计

## 社会影响
超凡者成为各财团争夺的战略资源，能力等级直接对应社会地位。流民中的超凡者被抓捕研究，财团垄断高端力量。

## 独特性
与传统修仙/魔法体系不同：能力来源多元、无统一等级标准、觉醒随机性强、代价设计真实（T5癌症、纳米机器人被控制、巫师丧失人性）。
