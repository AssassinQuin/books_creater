# 借鉴库（borrowable 蒸馏）

恢复自 git 提交 `9f2fd6a`（2026-06-12 诡秘之主 v6.0 深度蒸馏），原路径 `novels/_参考库/`。
12 部成熟作品共 587 个 md 文件的可借鉴模式蒸馏——**网文作者思路的直接素材**。

## 作品清单

全职法师、将夜、诡秘之主、指环王、权游、第一序列、神墓、放开那个女巫、叛逆的鲁鲁修、故障乌托邦、设定（公共）等。

## 文件类型

| 文件 | 内容 |
|---|---|
| `borrowable-highlight.md` | 高光段落摘录 |
| `borrowable-世界观.md` | 世界观构建模式 |
| `borrowable-人物.md` | 人物塑造模式 |
| `borrowable-叙事手法.md` | 叙事技巧（双线/留白/切换等） |
| `borrowable-能力体系.md` | 力量体系设计模式 |
| `borrowable-节奏结构.md` | 节奏与结构模式 |
| `ability/characters/highlight.md` 等 | 原始结构化数据 |

## 使用方式

- 检索：`mcp__story-flow__ref_search(query, scope="borrow")`
- 路由：「借鉴/作者思路/拆书」主题会指向本库
- 原则：借鉴**模式**不抄**内容**；写进正文的具体表达必须重铸
