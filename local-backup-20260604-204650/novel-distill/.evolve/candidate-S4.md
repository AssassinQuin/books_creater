# 参考作品蒸馏引擎

## 触发

用户说"蒸馏XX""分析小说""拆解小说""参考分析""蒸馏参考"。

## 核心概念

**`_参考库`**：novel-db 中的特殊小说名，存储所有参考作品的蒸馏数据。不绑定任何具体小说，全局共享。

**两阶段流程**：Phase 1 粗提取（快速扫描）→ 用户选维度 → Phase 2 细蒸馏（深入提取）

## 作品类型→维度权重映射

Phase 1 粗提取完成后，根据作品类型推荐维度权重，辅助用户选择。

| 作品类型 | 必选维度 | 推荐维度 | 低优先级 |
|---------|---------|---------|---------|
| 纯西幻 | 世界观, 能力体系 | 人物, 节奏 | 叙事手法, 亮点 |
| 仙侠/修仙 | 能力体系, 世界观 | 节奏, 亮点 | 叙事手法 |
| 都市异能 | 能力体系, 人物 | 叙事手法, 亮点 | 世界观 |
| 硬科幻 | 世界观, 叙事手法 | 能力体系, 亮点 | 节奏 |
| 历史/架空 | 世界观, 人物 | 叙事手法, 节奏 | 能力体系 |
| 悬疑/推理 | 叙事手法, 人物 | 节奏, 亮点 | 世界观, 能力体系 |
| 公路/冒险 | 世界观, 节奏 | 人物, 叙事手法 | 能力体系 |
| 通用（无法判断） | — | 全部等权重 | — |

## 执行流程

### Phase 0：输入确认

```
1. 获取文件路径（用户直接给，或追问）
2. 验证文件存在：ls {path}
3. IF 文件不存在 → 追问正确路径
4. 统计文件大小和章节数：
   - wc -l {path}（行数）
   - grep -c "^第.*章\|^Chapter\|^\*\*\*" {path}（章节数估计）
5. 输出概要："文件 {name}，{lines} 行，约 {chapters} 章，预计 Phase 1 耗时 {est}"
6. IF 文件 > 2000 行 → 提示将分段读取
```

### Phase 1：粗提取（全量扫描）

**目标**：快速识别作品骨架和类型，输出带权重推荐的维度菜单。

#### Step 1.1：结构识别

```
分段读取文件（每段 500-800 行，重叠 50 行）：
1. 识别卷/章结构（正则：第X卷/第X章/Chapter X）
2. 记录每个分段的起止位置和标题
3. 输出结构摘要
```

#### Step 1.2：逐卷快速摘要

对每个卷/大段，提取（每卷限 200 字）：

```
- 核心事件（1-2 句）
- 出现人物（名字列表）
- 关键设定（地名/能力/势力名）
- 情绪基调（1 个词）
```

#### Step 1.3：维度覆盖检测

基于摘要，判断 6 个维度中哪些有实质内容：

| 维度 | 检测信号 |
|------|---------|
| 世界观 | 出现地理描述/历史事件/种族/文化 |
| 能力体系 | 出现等级/技能/修炼/战斗描述 |
| 人物 | 出现多人物互动/关系变化/成长 |
| 叙事手法 | 出现伏笔/悬念/视角切换/非线性叙事 |
| 节奏结构 | 可识别弧段/高潮/日常/转折 |
| 核心亮点 | 独特设定/创新手法/高口碑要素 |

#### Step 1.4：作品类型判定 + 存储元数据

根据 Step 1.2 的内容信号判定作品类型，查"作品类型→维度权重映射"表生成推荐。

```
# 存储 meta 概览
world_upsert(
  novel_name="_参考库",
  category="ref_meta",
  name="{作品名}",
  data={
    "title": "{作品名}",
    "author": "{作者}",
    "genre": "{类型}",
    "volumes": [...],
    "dimensions_available": [1,2,3,4,5,6],
    "genre_weights": {"1": 0.9, "2": 0.8, ...},  # 基于类型映射的维度权重
    "volume_summaries": {...}
  }
)

# 存储卷摘要（每个卷一条）
world_upsert(
  novel_name="_参考库",
  category="ref_volume",
  name="{作品名}-卷{N}",
  data={...摘要数据...}
)
```

输出给用户（带权重推荐）：
```
{作品名} 粗提取完成：
- 类型判定：{genre}，{N} 卷，{M} 章
- 推荐蒸馏维度（按相关性排序）：
  [1]世界观 ★★★  [2]能力体系 ★★★  [3]人物 ★★☆  [4]叙事手法 ★☆☆  [5]节奏 ★★☆  [6]亮点 ★★☆
- 必选维度已标 ★★★，推荐 ★★☆
选择要深入蒸馏的维度（可多选，如 1,2,4）：
```

### Phase 2：细蒸馏（用户选维度后）

用户选择维度后，逐维度深入提取。完整 schema 见 `references/distill-schemas.md`。

#### 通用流程

```
1. 根据维度定位相关章节（用 Phase 1 的卷摘要）
2. 读取相关章节全文（分段读取，避免爆 context）
3. 按"蒸馏检查清单"逐条提取
4. 每个维度独立写入 _参考库（支持下游 skill 精准检索）
5. 提取 borrowable 模式，独立写入并交叉引用维度
6. 输出维度蒸馏报告
```

#### 维度 1：世界观

蒸馏检查清单：
- [ ] 有哪些主要地理区域？各自叙事功能是什么？
- [ ] 有哪些关键历史事件？如何影响当前故事？
- [ ] 有哪些种族/势力？关系如何？
- [ ] 有哪些文化特征？在故事中如何呈现？
- [ ] 有哪些世界规则（物理/魔法/社会）？如何展现给读者？

存储：`world_upsert(novel_name="_参考库", category="ref_world", name="{作品名}", data={...}, tags=["{作品名}", "world", "{genre}"])`

Borrowable 提取：
```
从世界观数据中提取可独立使用的模式，按 Borrowable 模板格式写入。
示例：某个地理区域的设计模式（如"北境蛮荒-文明边界"模式）可被其他作品直接借用。
```

#### 维度 2：能力体系

蒸馏检查清单：
- [ ] 体系名称和分类方式是什么？（元素/流派/属性/其他）
- [ ] 有几个等级？晋升条件是什么？
- [ ] 战斗风格和代表性技法有哪些？
- [ ] 力量上限如何控制？对社会结构有何影响？
- [ ] 与其他作品的能力体系有什么本质区别？

存储：`world_upsert(novel_name="_参考库", category="ref_ability", name="{作品名}")`

Borrowable 提取：
```
从能力体系中提取可独立使用的模式，按 Borrowable 模板格式写入。
示例：某个等级晋升机制的设计（如"洞见-需要实战中顿悟而非死磕"）可被借用。
```

#### 维度 3：人物

蒸馏检查清单：
- [ ] 核心人物有谁？各自角色原型是什么？
- [ ] 主角的成长轨迹是什么？触发事件是什么？
- [ ] 配角的功能性分配是否合理？（每个人都有自己的故事线）
- [ ] 反派的立场和逻辑是什么？（不是"坏"，是"被困住"）
- [ ] 人物关系网的模式是什么？

存储：
- 单人：`character_create(novel_name="_参考库", name="{人物名}@{作品名}", ...)`
- 关系：`relation_create(novel_name="_参考库", from_name="{A}@{作品名}", to_name="{B}@{作品名}", ...)`
- 总体：`world_upsert(novel_name="_参考库", category="ref_characters", name="{作品名}")`

Borrowable 提取：
```
从人物模式中提取可独立使用的设计模式。
示例：某种反派设计模式（如"被困在系统中的执行者"）可被借用。
```

#### 维度 4：叙事手法

蒸馏检查清单：
- [ ] 视角方式是什么？（第一人称/第三人称限知/全知/多视角切换）
- [ ] 整体节奏模式是什么？（快慢交替/持续加速/张弛有度）
- [ ] 用了哪些钩子类型？（悬念/冲突/异常/情感共鸣）
- [ ] 有哪些伏笔？跨度多长？如何回收？
- [ ] 有哪些独有技法？（标注原文片段作为示例）

存储：`world_upsert(novel_name="_参考库", category="ref_narrative", name="{作品名}")`

Borrowable 提取：
```
从叙事手法中提取可独立使用的模式。
示例：某种信息投放方式（如"通过摊贩闲聊展示世界观"）可被借用。
```

#### 维度 5：节奏结构

蒸馏检查清单：
- [ ] 整体弧段结构是什么？（暖色弧→冷色弧→小胜利→新暖色弧）
- [ ] 暖色弧的设计：温暖是真的暖，还是暗藏威胁？
- [ ] 冷色弧的设计：如何兑现暖色弧的伏笔？
- [ ] 高潮的蓄力和释放方式是什么？
- [ ] 日常与推进的占比和交替模式是什么？

存储：`world_upsert(novel_name="_参考库", category="ref_rhythm", name="{作品名}")`

Borrowable 提取：
```
从节奏结构中提取可独立使用的模式。
示例：某种弧段交替节奏（如"5章暖弧+3章冷弧"）可被借用。
```

#### 维度 6：核心亮点

蒸馏检查清单：
- [ ] 核心卖点是什么？为什么有效？
- [ ] 读者留存的要素是什么？
- [ ] 有哪些创新之处？
- [ ] 有哪些可能的失败点或风险？（作为反面参考也有价值）
- [ ] 综合评价？适合借鉴的小说类型？

存储：`world_upsert(novel_name="_参考库", category="ref_highlight", name="{作品名}")`

Borrowable 提取：
```
从亮点中提取可独立使用的模式。
示例：某种核心设定（如"封印→复苏→混乱→再封印的历史循环"）可被借用。
```

### Borrowable 模式独立存储

每个维度蒸馏时提取的 borrowable 模式，独立写入 _参考库，支持精准检索。

#### Borrowable 模板

```json
{
  "name": "模式名称",
  "description": "一句话描述这个模式是什么",
  "source_work": "{作品名}",
  "source_dimension": "来自哪个维度（1-6）",
  "applicability": {
    "genres": ["适用的作品类型"],
    "scenarios": ["适用的创作场景"]
  },
  "difficulty": "easy | medium | hard",
  "adaptation_needed": false | "需要什么改编",
  "example": {
    "original": "在原作中的具体表现（简述+章节范围）",
    "adapted": "如何在其他作品中使用（简要说明）"
  },
  "cross_ref": {
    "category": "ref_{维度}",
    "name": "{作品名}"
  }
}
```

#### Borrowable 存储

```bash
world_upsert(
  novel_name="_参考库",
  category="ref_borrowable",
  name="{作品名}-{模式名}",
  data={...Borrowable模板内容...},
  tags=["borrowable", "{作品名}", "{genre}", "easy|medium|hard"]
)
```

检索示例：
```
vector_search(novel_name="_参考库", query_text="等级晋升 顿悟 机制", category="ref_borrowable")
→ 返回所有匹配的 borrowable 模式，包含适用范围和改编说明
```

## 检索接口（其他 skill 使用）

### 在 novel-setup 中使用（PP-3 协议）

当用户说"参考XX小说的YY"时：

```
1. vector_search(novel_name="_参考库", query_text="{作品名} {维度}")
2. IF 结果为空 → db_search(novel_name="_参考库", keyword="{作品名}")
3. IF 仍为空 → 提示该作品尚未蒸馏，是否现在蒸馏？
4. 返回蒸馏数据，PP-3 协议执行适配验证
```

### Borrowable 精准检索

下游 skill 可按需精准检索 borrowable 模式，不必获取整个维度：

```
# 按类型检索
vector_search(novel_name="_参考库", category="ref_borrowable", query_text="{创作场景}")

# 按难度检索
db_search(novel_name="_参考库", category="ref_borrowable", keyword="easy")

# 按作品检索
db_search(novel_name="_参考库", category="ref_borrowable", keyword="{作品名}")
```

### 直接查询

用户可随时查询已蒸馏的参考数据：

```
"无职转生的能力体系怎么样" →
  vector_search(novel_name="_参考库", query_text="无职转生 能力体系")

"有什么 easy 难度的等级晋升模式可以借鉴" →
  vector_search(novel_name="_参考库", category="ref_borrowable", query_text="等级晋升")
```

## 大文件处理策略

详细分段读取实现见 `references/file-handling.md`。核心规则：

| 文件大小 | 策略 |
|---------|------|
| < 2000 行 | 一次读取 |
| 2000-10000 行 | 分段读取（每段 800 行，重叠 50 行） |
| > 10000 行 | Phase 1 仅读首尾+每卷首章，Phase 2 按维度精准读取相关卷 |

## 质量保障

1. **交叉验证**：人物关系与世界观设定交叉检查一致性
2. **引用溯源**：每条提取数据标注来源章节范围
3. **避免过度解读**：只提取文本中明确存在的内容，不推测作者意图
4. **借鉴定级**：每个 borrowable 模式标注难度（easy/medium/hard）和适用范围

## 禁止

- 不编造原文没有的内容
- 不做主观价值判断（不说"写得好/写得差"，只描述"怎么写的"）
- 不存储完整原文段落（只存结构化提取结果）
- 不跳过 Phase 1 直接进入 Phase 2
