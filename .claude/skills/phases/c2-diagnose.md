# C2 健康诊断阶段指令

> 本文件只包含健康诊断阶段的执行指令。
> 需要时加载：engines/review-checklist.md

## 输入

- `health_check(novel_name="这次不一样了")` 返回的健康指标
- 状态总线全部数据

## 执行步骤

### Step 1: 指标采集

调用 `health_check(novel_name="这次不一样了")` 获取：
- 伏笔积压率
- 配角活跃度
- 升级节奏
- 日常密度
- 暗线推进
- 卷完成度

### Step 2: 指标对比

与目标值对比：

| 指标 | 健康值 | 当前值 | 状态 |
|------|--------|--------|------|
| 伏笔积压率 | ≤30% | | |
| 配角出场 | ≥1次/3章 | | |
| 升级节奏 | 每卷1级 | | |
| 日常密度 | 20-30% | | |
| 暗线推进 | 每卷1层 | | |
| 卷完成度 | 按规划 | | |

### Step 3: 破局策略

对异常指标生成破局策略：

| 问题 | 策略 |
|------|------|
| 伏笔积压 | 安排回收章节/减少新埋伏笔 |
| 配角沉寂 | 插入支线节点/他人观察 |
| 升级过快 | 增加阻碍/能力副作用 |
| 日常不足 | 插入费笔/世界呼吸 |
| 暗线停滞 | 安排揭示节点/信息投放 |
| 卷进度滞后 | 压缩事件/合并章节 |

## 输出

- 状态总线.thread.health 更新
- 文件: `审阅报告/健康诊断-{日期}.md`
