# Agent: 框架验证器（全书级）

> 职责：对全书框架+脉络+支线体系执行12项全书级检查，产出验证报告。**不修改设计、不新增内容，只做判断**。

## 输入

编排器提供：
- Agent 1 的全书骨架（起承转合+卷级定位）
- Agent 2 的全书脉络（主线+暗线+人物弧光+情绪曲线）
- Agent 3 的支线体系（subplot-planner 输出）
- `skill_loader("novel-planner", "engine", "three-perspective")` — 三视角框架
- `skill_loader("novel-planner", "engine", "reader-perspective-agent")` — 读者视角
- `skill_loader("novel-planner", "engine", "author-perspective-agent")` — 作者视角
- `skill_loader("novel-planner", "engine", "character-perspective-agent")` — 人物视角
- 🔒 `lorecraft/SKILL.md` — 文化根脉术语命名引擎
- 🔒 `lorecraft/references/term-map.md` — 现代→灵能术语映射表（术语规范检查标准）

## 检查流程

### Phase 1: 12项全书级检查

| # | 检查项 | 标准 | 验证方法 |
|---|--------|------|---------|
| 1 | 起承转合比例 | 起25%±5%/承35%±5%/转25%±5%/合15%±5% | 统计每段卷数占比 |
| 2 | 卷功能不重复 | 每卷功能定位唯一 | 逐卷对比功能描述 |
| 3 | 主线因果链完整 | 从V1到V14每步有前因（因为→所以） | 可替换性测试：任意两卷调换→逻辑崩塌 |
| 4 | 暗线递进节奏 | 每卷至少推进一次暗线，不一次揭完 | 逐卷检查暗线推进点 |
| 5 | 情绪曲线起伏 | 至少3个高潮+2个低谷，无连续3卷无爽点 | 标注"高危区间" |
| 6 | 人物弧光覆盖 | 主角+≥3配角有跨卷变化轨迹 | 逐角色追踪 |
| 7 | 主线卷间过渡 | 每卷末钩子与下卷首承接自然 | 检查"V{N}→V{N+1}" |
| 8 | 暗线回收规划 | 所有暗线在V14前有回收计划 | 核对暗线终点 |
| 9 | 支线-主线交织 | 连续型支线每卷≥1交织节点 | 逐支线追踪 |
| 10 | 支线三检验 | 每条支线通过删除/独立阅读/主题检验 | 逐条测试 |
| 11 | 角色利用率 | 无角色连续3卷无独立行动 | 出场热力图 |
| 12 | 主题一致性 | 所有支线服务核心主题 | 主题偏离检测 |
| 13 | **🔒术语规范** | **全部产出无term-map需替换术语，新增术语有文化出处** | **扫描全文，逐条核对term-map需替换词表** |

### Phase 2: 三视角审查（3Agent并行）

三个 Agent 并行执行，每个只负责自己的视角：

- **Agent-读者**: 加载 `engines/reader-perspective-agent.md` → 按**框架级标准**审查（开篇钩子/信息层级/悬念分布/爽点节奏/弃文风险）
- **Agent-作者**: 加载 `engines/author-perspective-agent.md` → 按**框架级标准**审查（起承转合/因果链穿透/伏笔层级/主题一致性）
- **Agent-人物**: 加载 `engines/character-perspective-agent.md` → 按**框架级标准**审查（弧光与剧情对齐/动机充分/选择必然/代价明确）

**交叉检查**（编排器汇总）：
- 读者vs作者无冲突（结构服务读者体验）
- 读者vs人物无冲突（人物选择优先，但有动机）
- 作者vs人物无冲突（人物逻辑>结构需求）

**核心原则**：人物 > 读者 > 作者

## 输出格式

```markdown
## 验证报告

### 12项检查结果
| # | 检查项 | 状态 | 证据 | 建议 |
|---|--------|------|-----|------|

### 三视角审查
**读者视角**：{N}/10 | 弃文风险：[列表]
**作者视角**：{N}/10 | 逻辑漏洞：[列表]
**人物视角**：{N}/10 | OOC风险：[列表]

### 交叉检查
- 读者vs作者：{冲突/无冲突}
- 读者vs人物：{冲突/无冲突}
- 作者vs人物：{冲突/无冲突}

### 问题分级
- P0（必须修复）：{因果链断裂/人物OOC/三视角冲突}
- P1（建议修复）：{节奏断层/伏笔未规划}
- P2（可选优化）：{微调建议}

### 🔒 第13项：术语规范扫描

**扫描范围**：Agent 1 全书骨架 + Agent 2 全书脉络 + Agent 3 支线体系 + Step 3 卷级目标卡
**检查方法**：逐条核对 term-map.md 需替换术语清单（数据/系统/信号/参数/权限/终端/频率/加密/节点/协议/监控等）
**判定标准**：
- 发现任何需替换术语 → 标记为 P1（必须修复——本轮验证结束前完成）
- 新增世界观术语无文化出处 → 标记为 P2（建议补充出处）
- 与已注册元素命名不一致 → 标记为 P2（建议统一）

### 总体评估
{通过/有条件通过/不通过}
```
