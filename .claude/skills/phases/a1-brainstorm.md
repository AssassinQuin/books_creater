# A1 头脑风暴阶段指令

> 本文件只包含头脑风暴阶段的执行指令。
> 需要时加载：engines/brainstorm.md, engines/book-analysis.md

## 输入

- 用户提供的灵感片段（画面/主角/情绪/对立面/独特规则）
- 可选：参考作品（用于拆书分析）

## 执行步骤

### Step 1: 灵感收集

加载 `engines/brainstorm.md` → 逐问深挖：
1. 画面：你最先想到的是什么画面？
2. 主角：这个画面里谁在做什么？
3. 情绪：看完这个画面，读者应该感到什么？
4. 对立面：谁/什么在阻止主角？
5. 独特规则：这个世界有什么不同寻常的规则？

每次只问一个问题，深入追问直到用户说"够了"。

### Step 2: 拆书分析（如提供参考作品）

加载 `engines/book-analysis.md` → 分析参考作品：
- 核心冲突结构
- 人物关系网
- 世界观展示方式
- 节奏控制手法
- 可迁移到自己的项目

### Step 3: 输出决策卡

整合所有信息，产出决策卡：

```
决策卡:
- 核心冲突: {一句话}
- 主线方向: {起点→终点}
- 读者情绪: {目标情绪曲线}
- 亮点场景: {3-5个必写场景}
- 品类节奏: {对应品类的时间线}
- 预计卷数: {8-15}
```

## 输出

- 状态总线.creative.decision_card 更新
- 文件: `docs/decisions/ADR-{日期}-{主题}.md`
- DB: `novel_create` + `novel_update(genre, status)`
