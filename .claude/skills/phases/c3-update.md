# C3 级联更新阶段指令

> 本文件只包含级联更新阶段的执行指令。
> 需要时加载：engines/causality.md

## 输入

- 用户指定的修改内容（改设定/改人物/改能力）
- 状态总线全部数据

## 执行步骤

### Step 1: 更新数据

执行用户指定的修改：
- 改世界观 → `world(action="upsert")`
- 改人物 → `character_update`
- 改能力 → `character_update` + `world(action="upsert")`

### Step 2: 影响范围分析

加载 `engines/causality.md` → 调用 `search(action="keyword")` 扫描全部影响：

| 修改类型 | 可能影响 |
|---------|---------|
| 世界观规则 | 所有涉及该规则的章节/事件/人物能力 |
| 人物属性 | 所有涉及该人物的章节/关系/事件 |
| 能力设定 | 所有战斗场景/升级节点/物品效果 |
| 势力关系 | 所有涉及该势力的章节/人物立场 |

### Step 3: 确认修改清单

产出修改清单，用户确认：

```
修改清单:
- 直接修改: {N} 处
- 级联影响: {N} 处
- 需要人工判断: {N} 处

确认后执行级联同步。
```

### Step 4: 级联执行

按依赖顺序执行修改：
1. 先改底层设定（世界观/能力规则）
2. 再改人物状态
3. 最后改章节内容（如有）

### Step 5: 验证

重新运行相关审计：
- 改世界观 → 运行 C4 设定审查
- 改人物 → 检查 OOC 风险
- 改能力 → 检查战斗场景一致性

## 输出

- 状态总线全部更新
- 文件: `docs/decisions/ADR-{日期}-级联更新.md`
- DB: 全部相关表更新
