# A2 世界观建模阶段指令

> 本文件只包含世界观建模阶段的执行指令。
> 需要时加载：engines/worldbuilding.md, engines/causality.md

## 输入

- 决策卡（来自 A1）
- 已有世界观数据（`world_query`）

## 执行步骤

### Step 1: 确立双锚点

加载 `engines/worldbuilding.md` → 设计：
- **危机锚**: 世界面临的核心危机是什么？
- **变量锚**: 什么变量让这个世界与众不同？

### Step 2: 核心稀缺资源

确定驱动冲突的稀缺资源：
- 是什么让人们争夺/合作？
- 资源分布如何影响势力格局？

### Step 3: 世界观刑具化

将世界观规则转化为对角色的压力：
- 每条规则必须能"压"到角色身上
- 规则不是背景板，是推动力

### Step 4: 涟漪效应

修改一条规则 → 追踪对其它维度的影响：
- 经济变化 → 社会结构变化 → 日常生活变化

### Step 5: 逐维度展开

6维度建模：
1. 种族/物种
2. 势力/组织
3. 地理/地图
4. 能力/等级体系
5. 经济/货币
6. 日常生活

每维度完成 → `world_upsert` → 🔒确认

### Step 6: 交叉验证

加载 `engines/causality.md` → 验证：
- 锚点稳固？
- 稀缺真实？
- 涟漪完整？
- 价值一致性？
- 跨维度无矛盾？

## 输出

- 状态总线.setting.world 更新
- 文件: `设定/世界观.md`
- DB: `world_upsert` ×6
