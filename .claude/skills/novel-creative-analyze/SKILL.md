> **替代方案**: `novel-review`（选择"创意评估"模式）
> **迁移**: 创意分析/评好/惊喜度/创意评估 → 触发 `novel-review` 并选择"创意评估"

> 评估"好不好"而非"有没有错"。与 novel-qa 互补：qa 找硬伤，creative-analyze 找软肋。
> qa 回答"这章OOC了吗？"，creative-analyze 回答"这章读者会惊喜吗？"

## 流程

```
Step 0: 确定分析范围+数据采集
Step 1: Agent—惊喜度分析师 → 意外性评估
Step 2: Agent—情感工程师 → 情感冲击评估

Step 4: 汇总+创意优化建议 → 🔒检查点A
```

## Step 0: 确定分析范围+数据采集

### 分析范围

| 输入 | 分析维度 | 数据源 |
|------|---------|--------|
| 卷级大纲 | 悬念设计/反转意外性/卷间节奏 | volume_get + 大纲文件 |
| 章节大纲 | 爽点密度/信息层级/伏笔节奏 | chapter_plan + 卷纲 |
| 正文 | 对话弦外之音/环境情绪服务/角色选择意外性 | Read正文 + get_chapter_context |
| 人物 | 决策独特性/弧线意外性/差异化 | character_detail + distillation_timeline |

### 数据采集

```python
# 按分析范围采集
if scope == "卷级":
    volume_get(novel_name="NOVEL_NAME", volume_number=N)
```

## Step 1: Agent—惊喜度分析师

评估内容的**意外性**——读者能猜到吗？

### 评估维度

| 维度 | 问题 | 评分(1-5) |
|------|------|-----------|
| 反转意外性 | 核心反转读者能提前猜到吗？ | 1=一眼看穿 5=完全意外但合理 |
| 伏笔隐蔽性 | 伏笔回收时读者是"果然如此"还是"原来如此"？ | 1=明牌 5=深藏 |
| 角色选择意外性 | 角色的关键选择让读者意外吗？ | 1=套路 5=出人意料但符合人设 |
| 信息投放节奏 | 关键信息在读者最想知道时释放吗？ | 1=过早/过晚 5=恰到好处 |

### 硬约束
- 每个维度必须给出具体文本证据（不能只打分不举例）
- "意外但合理" > "意外但不合理" > "不意外"
- 反转必须有伏笔支撑（无伏笔的意外=突兀）

## Step 2: Agent—情感工程师

评估内容的**情感冲击力**——读者会动容吗？

### 评估维度

| 维度 | 问题 | 评分(1-5) |
|------|------|-----------|
| 情感峰值 | 全卷/章最高潮的情感冲击有多强？ | 1=无感 5=心跳加速 |
| 情感转折 | 情感方向转换是否自然有力？ | 1=生硬 5=丝滑且有力 |
| 留白效果 | 不说破的情感比说破的更有力吗？ | 1=全说破 5=恰到好处的沉默 |
| 共情深度 | 读者能代入角色的处境吗？ | 1=旁观者 5=感同身受 |

### 硬约束
- 必须区分"作者想传达的情感"和"读者实际感受到的情感"
- 情感冲击 ≠ 情感密度（1个精准的高峰 > 10个平均的波动）
- 检查是否存在"情感通货膨胀"（连续高潮导致读者脱敏）

## Step 3: Agent—节奏设计师

评估内容的**节奏感**——读者会无聊吗？

### 评估维度

| 维度 | 问题 | 评分(1-5) |
|------|------|-----------|
| 爽点间隔 | 两个爽点之间的"干旱期"有多长？ | 1=超过3章无爽点 5=节奏紧凑 |
| 张弛有度 | 高潮和日常的交替是否自然？ | 1=全程高压/全程平淡 5=呼吸感 |
| 信息密度 | 每段文字的信息投放是否均匀？ | 1=信息堆砌/空洞 5=均匀流动 |
| 弃文风险点 | 哪些位置读者最可能弃文？ | 1=多处高危 5=无弃文风险 |

### 硬约束
- 必须标注具体的弃文风险位置（章号+段落）
- 爽点间隔 >3章 = 高危弃文区间
- 检查是否存在"信息沙漠"（连续2+段无新信息）

## Step 4: 汇总+创意优化建议

### 创意评分卡

```
【创意评分卡】{范围}
惊喜度: {均分}/5  ← {最强维度}({分}) / {最弱维度}({分})
情感冲击: {均分}/5  ← {最强维度}({分}) / {最弱维度}({分})
节奏感: {均分}/5  ← {最强维度}({分}) / {最弱维度}({分})
综合: {均分}/5

🔴 创意软肋（最需改进的3项）：
1. {维度}: {具体问题} → {优化建议}
2. ...
3. ...

🟢 创意亮点（最值得保持的3项）：
1. {维度}: {具体表现} → {为什么好}
2. ...
3. ...
```

### 🔒检查点A

展示创意评分卡 + 优化建议。用户确认后，建议可选择性应用到对应内容。

## 与 novel-qa 的关系

| 维度 | novel-qa | novel-creative-analyze |
|------|----------|----------------------|
| 目标 | 找错（OOC/因果断裂/术语违规） | 评好（惊喜度/情感/节奏） |
| 标准 | 硬约束（违反=拒绝） | 软指标（1-5评分） |
| 输出 | P0/P1/P2问题清单 | 创意评分卡+优化建议 |
| 时机 | 写完后 | 写前（评估蓝图）+ 写后（评估效果） |
| 优先级 | P0 > 创意建议 | 创意建议不覆盖硬约束 |

**原则**：先过 qa（无P0），再过 creative-analyze（提升质量）。硬约束是底线，创意是天花板。

## 异常处理

| 场景 | 处理 |
|------|------|
| 分析范围为空 | 阻断，提示指定卷/章/人物 |
| 正文不存在 | 只分析大纲层级 |
| 角色无蒸馏数据 | 跳过人物分析，提示先完成写作 |

## 分析模式

| 模式 | 触发 | 范围 |
|------|------|------|
| 全卷 | "分析V1" | 整卷大纲+全部章节 |
| 单章 | "分析Ch5" | 单章正文+大纲 |
| 人物 | "分析{角色名}" | 角色蒸馏+出场章节 |
| 对比 | "对比V1和V2" | 两卷创意评分对比 |
