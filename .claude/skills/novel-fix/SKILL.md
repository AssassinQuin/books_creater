# 文本修复与润色

## 触发
用户说"修复""润色""改文""去重"。

## 模式（问用户）
1. **修复** — 针对审阅报告中的 P0/P1 问题逐项修复
2. **润色** — 提升文笔质量（不改变情节）
3. **术语修复** — 批量替换违规术语
4. **标记返修** — 用户在正文中标记（**加粗**=扩写 / ~~删除线~~=简写 / *斜体*=润色），为每个标记生成 3 种候选方案
5. **戏剧增强** — 用户说"太平了""加戏""剧情爆破"时触发，加载 `engines/drama-boost.md`

## 标记返修执行
1. 读取用户标记的正文文件
2. 提取标记：`**...**`（扩写）/ `~~...~~`（简写）/ `*...*`（润色）
3. 逐标记生成 3 种候选（扩写：感官/因果/潜台词三方向；简写：保留不同信息的压缩；润色：不同风格改写）
4. 展示候选 → 用户选择 → 替换
5. `validate_chapter` 重新校验

## 戏剧增强执行
1. 加载 `engines/drama-boost.md`
2. 分析当前章节的场面结构和冲突强度
3. 选择匹配的爆破方案（不改终点只加过程，或提出终点修改建议）
4. 输出加戏方案 → 用户确认 → 修改正文
5. `validate_chapter` 重新校验

## 通用执行
1. 定位问题段落
2. 修复
3. `validate_chapter` 重新校验
4. 用户确认 → 更新文件 + DB

## 完成后
问用户：继续修复 / 写正文 / 其他。
