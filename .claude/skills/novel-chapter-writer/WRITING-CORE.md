# WRITING-CORE.md — 章节结构模板

> 本文档是 novel-chapter-writer Step 2.1 的详细指令。

## 章节结构模板

**起承转合是参考骨架，不是模具。**

| 段落 | 占比 | 字数    | 内容                        |
| ---- | ---- | ------- | --------------------------- |
| 起   | ~17% | ~500字  | 收束上章+引入核心冲突       |
| 承   | ~40% | ~1200字 | 2-3事件推进+日常/NPC/世界观 |
| 转   | ~27% | ~800字  | 转折/冲突升级               |
| 合   | ~17% | ~500字  | 情绪峰值+章末钩子           |

---

## 反AI结构僵化（强制）— 每5章至少2种变体

| 变体   | 适用     | 结构                        |
| ------ | -------- | --------------------------- |
| 标准型 | 常规推进 | 起→承→转→合                 |
| 突入型 | 延续高潮 | 直接从转开始→合留悬念       |
| 日常型 | 过渡铺垫 | 起→长段日常承→安静收束      |
| 倒叙型 | 揭露回忆 | 合段开头→倒回起→承→解释     |
| 碎片型 | 多线切换 | 3-4个短场景碎片拼接         |
| 螺旋型 | 高潮核心 | 起极短→承极长→转爆发→合极短 |

## 章末钩子4种（不是每章都要）

悬念式 / 反转式 / 情绪炸弹 / 信息投放

## 4层内容模型（每章配比）

| 层      | 内容            | 占比   | 质量要求                                                 |
| ------- | --------------- | ------ | -------------------------------------------------------- |
| A推进层 | 主线/冲突/升级  | 40-50% | **信息推进率控制**: 每一段必须有新信息，拒绝原地踏步。   |
| B人物层 | 对话/心理/关系  | 25-30% | **主观镜头偏心**: 只写角色关心的，拒绝全知视角平均用力。 |
| C世界层 | 环境/NPC/世界观 | 15-20% | **感官尺度引擎**: 严禁精确数字，用身体和环境做度量衡。   |
| D氛围层 | 感官/节奏/伏笔  | 5-10%  | **锯齿状叙事**: 拒绝意象回环，用行动切断抒情。           |

## 人类化写作自检清单 (Anti-AI Checklist)

1. **[ ] 拒绝回环**：检查是否有“意象->解释->升华”的工整段落？若有，删掉解释，直接接行动。
2. **[ ] 拒绝精确**：文中是否出现了“米/厘米/秒/分钟”？全部替换为感官词（如“一盏茶”“两个指节”“一箭之地”）。
3. **[ ] 拒绝平权**：是否每个角色都有详细描写？删掉路人的描写，只保留主角主观感受到的那个“点”。
4. **[ ] 拒绝过度伏笔**：是否在反复强调“他不说”“假装不存在”？删掉这些，通过动作表现他的隐忍。
5. **[ ] 拒绝均匀**：段落长度是否都差不多？制造至少3个一句话段落，1个超长叙事段。
