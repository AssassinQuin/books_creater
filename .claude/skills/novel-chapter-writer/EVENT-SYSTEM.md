> 本文档是 novel-chapter-writer Step 2.2 的详细指令。

## 按事件序列写作

从事件序列表逐一展开：

1. **环境搭建** → 参照 `references/engine-environment.md` 的5要素，首次完整、再访只写变化
2. **人物对话** → 参照 `references/engine-dialogue.md` 的关系差异化+弦外之音+微表情
3. **动作场景** → 参照 `references/engine-action.md` 的5拍+空间感知+具体化
4. **物品使用** → 参照 `references/engine-item.md`，加载档案保持一致
5. **过渡到下一事件** → 空行+过渡句

**变速原则**: 关键情节慢写（多感官多细节）、过渡情节快写（长句概述）

**战斗场景** → 使用 `/novel-battle` 独立skill处理（分镜→写正文→审计），再整合回本章

## 场景搭建规则（强制）

每个场景100-200字五感铺垫（参照 `references/engine-environment.md` 感官层）：

| 感官 | 内容 | 示例 |
|------|------|------|
| 视觉 | 光影/色彩/细节 | 晨光照亮浮尘 |
| 听觉 | 环境音/远声 | 矿坑轰鸣像地底呼吸 |
| 嗅觉 | 气味 | 铁锈味混冷气 |
| 触觉 | 温度/质感 | 冷风冻得手麻 |
| 氛围 | 2-3感官综合 | 晨雾贴地涌，压得人喘不过气 |
