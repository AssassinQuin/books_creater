> **本文件职责**：章节结构、事件序列、世界知识注入、字数控制。

## 一、前置检查（Step 2.0）

读 `设定/写作执行规范.md` 获取小说特定规则。

### 事件分类

| 类型 | 作用 | 特征 |
|------|------|------|
| 线索推动型 | 推动线索进展 | 有线索标记（F1/F2...） |
| 人物关系型 | 推动关系变化 | 互动后信任/怀疑/依赖变化 |
| 场景铺垫型 | 为高潮铺垫 | 不直接推进，让后续更有冲击力 |
| 人物展示型 | 自然展现人物 | 通过对话/行动体现，禁评价词 |
| 伏笔埋设型 | 长线回收准备 | 必须填foreshadow_plant |

### 事件层级

| 层级 | 粒度 | 爽点要求 |
|------|------|---------|
| 超级 | 卷级 | 卷终决战/命运转折 |
| 大 | 弧级(8-12章) | Boss战/重大转折 |
| 中 | 段级(3-5章) | 阶段胜利/关系突破 |
| 小 | 章级 | 小胜利/小揭露/角色高光 |
| 微 | 场景级 | 对话钩子/信息投放 |

### 爽点密度

- 微/小爽点：每章至少1个
- 中爽点：每3-5章
- 大高潮：每8-12章
- 超级高潮：每卷1-2次
- **平路不超过3章**

### 升级周期

铺垫→积累→突破→展示（V1-4: 每5-8万字; V5-10: 每10-15万字; V11-14: 每15-20万字）

## 二、章节结构（Step 2.1）

### 结构模板

| 段落 | 占比 | 字数 | 内容 |
|------|------|------|------|
| 起 | ~17% | ~500字 | 收束上章+引入核心冲突 |
| 承 | ~40% | ~1200字 | 2-3事件推进+日常/NPC/世界观 |
| 转 | ~27% | ~800字 | 转折/冲突升级 |
| 合 | ~17% | ~500字 | 情绪峰值+章末钩子 |

### 变体（每5章至少2种）

| 变体 | 适用 | 结构 |
|------|------|------|
| 标准型 | 常规推进 | 起→承→转→合 |
| 突入型 | 延续高潮 | 直接从转开始→合留悬念 |
| 日常型 | 过渡铺垫 | 起→长段日常承→安静收束 |
| 倒叙型 | 揭露回忆 | 合段开头→倒回起→承→解释 |
| 碎片型 | 多线切换 | 3-4个短场景碎片拼接 |
| 螺旋型 | 高潮核心 | 起极短→承极长→转爆发→合极短 |

### 4层内容模型

| 层 | 内容 | 占比 | 要求 |
|----|------|------|------|
| A推进层 | 主线/冲突/升级 | 40-50% | 每段必须有新信息 |
| B人物层 | 对话/心理/关系 | 25-30% | 主观镜头偏心 |
| C世界层 | 环境/NPC/世界观 | 15-20% | 用身体感受替代精确数字 |
| D氛围层 | 感官/节奏/伏笔 | 5-10% | 锯齿状叙事 |

## 三、世界知识注入（Step 2.1 按需）

参照 `设定/lorebook/` 目录下的YAML条目。写作时按以下流程加载：

1. **常驻条目**：从 `设定/lorebook/entries/` 读取所有 `constant: true` 的YAML，按 priority 排序
2. **关键词匹配**：遍历按需条目，检查 keys 是否在章节大纲/角色名/场景地点中命中
3. **时序过滤**：检查 delay/cooldown/sticky 条件
4. **Token预算**：Lorebook总量不超过上下文的20%，常驻占40%（永不裁剪），按需按priority裁剪

### 设定一致性

- 一致性：正文与已激活Lorebook保持一致
- 范围控制：只使用已激活条目中的设定
- 物品闭环：使用灵能物品必须有对应Lorebook条目
- 经济一致：交易/物价参考灵晶+货币体系数值

## 四、事件序列写作（Step 2.2）

从事件序列表逐一展开：

1. **环境搭建** → 首次完整描写，再访只写变化
2. **人物对话** → 关系差异化+弦外之音+微表情（→见`engines/dialogue.md`）
3. **动作场景** → 5拍+空间感知+具体化（→见`engines/scene-composition.md`）
4. **物品使用** → 加载档案保持一致
5. **过渡到下一事件** → 空行+过渡句（→见`engines/scene-composition.md`·缝合技术）

**变速原则**：关键情节慢写（多感官多细节）、过渡情节快写（长句概述）

### 场景搭建规则

每个场景100-200字五感铺垫：

| 感官 | 内容 | 示例 |
|------|------|------|
| 视觉 | 光影/色彩/细节 | 晨光照亮浮尘 |
| 听觉 | 环境音/远声 | 矿坑轰鸣像地底呼吸 |
| 嗅觉 | 气味 | 铁锈味混冷气 |
| 触觉 | 温度/质感 | 冷风冻得手麻 |
| 氛围 | 2-3感官综合 | 晨雾贴地涌 |

### 复杂场面（3+人）→ 角色矩阵

→ 见 `engines/scene-composition.md`·角色矩阵

### 场景缝合

→ 见 `engines/scene-composition.md`·缝合技术

### NPC互动规则（每章至少2个有动机NPC）

| 类型 | 动机 | 对话特点 |
|------|------|---------|
| 商贩 | 利益驱动 | 价格变动/供需/行情 |
| 居民 | 地区文化 | 生活态度/舆论/流言 |
| 军人 | 专业背景 | 术语/经验/立场 |
| 逃亡者 | 创伤求生 | 谨慎/回避/试探 |

NPC必须有：姓名/绰号 + 背景暗示 + 可见动机 + 与主角的互动痕迹。

## 六、分支事件（Step 2.5）

- 分支事件占每章 **15%-25%** 字数
- 类型：日常闲聊/世界观观察/环境细节/人物小冲突/过渡填充
- 分支必须涉及人物互动或世界观展示
- 分支与主线自然过渡

## 七、质量检查（Step 2.6-2.7）

### 内容丰富度检查（14项）

| 检查项 | 要求 |
|--------|------|
| 章节结构 | 使用合适变体，近5章至少2种不同变体 |
| 章末钩子 | 有钩子或确认是日常型 |
| 爽点密度 | 本章至少1个微/小爽点 |
| 信息缺口 | 至少1个 |
| 日常事件 | 2-3个日常场景 |
| NPC出场 | 至少2个有动机NPC |
| 场景搭建 | 每场景五感氛围铺垫 |
| 世界观展示 | 至少3个元素自然融入 |
| 人物性格 | 微表情/动作展示（禁直白词） |
| 分支事件 | 占15%-25%字数 |
| 4层内容 | A40-50%+B25-30%+C15-20%+D5-10% |
| 反注水 | 无孤立感官/无因果过渡/无重复意象 |
| 场景密度 | 每3段至少1段"同时做2+件事" |
| 伏笔处理 | 伏笔已标记并填写foreshadow_plant |

### AI指纹检查（强制，不通过=拒绝存盘）

→ 见 `engines/anti-ai-patterns.md` 完整检测规则和修复方案

快速检查项：

| 检查项 | 拒绝阈值 |
|--------|---------|
| FP-1 句号切割法 | >20% 或存在3+连续短句 |
| FP-2 解释式展示 | >5次 |
| FP-3 结构对称 | 方差<15% |
| FP-4 否定转折 | >4次 |
| FP-5 质量均匀 | 全章每段都"认真写"=均匀=AI |
| FP-6 废笔缺失 | 每个细节都服务结构=AI |
| FP-7 人物太干净 | 所有人都维持人设=AI |
| FP-8 无作者声音 | 全章"稳顺好读"但无个性=AI |
| FP-9 全程匀速 | 全章节奏平稳无断裂=AI |
| FP-10 伏笔太密 | 每个细节都回收=AI |
| FP-11 太安全 | 全章无刺无炸=AI |
| FP-12 人物均等 | 每个角色都有可爱标签=AI |

### 字数控制

- **最低**: 3000字（不含标点）
- **目标**: 3000-5000字
- 每500字暂停检查字数
- 不足3000时**按优先级展开事件**，用新内容填充：
  1. 先展开蓝图的弹性事件储备（世界呼吸/人物塑造/费笔纹理/人物互动）
  2. 再扩展现有场面的感官维度（嗅觉/触觉/温度/环境音）
  3. 再加入角色微动作/微表情/习惯细节
  4. **填充标准**：每次填充引入新内容（新动作/新对话/新冲突/新事件），不重复已有内容
- 超过5000时考虑拆章
