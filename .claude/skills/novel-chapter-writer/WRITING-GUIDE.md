## 一、前置检查（Step 2.0）

读 `设定/写作执行规范.md` 获取小说特定规则。

### 事件分类

| 类型 | 作用 | 特征 |
|------|------|------|
| 线索推动型 | 推动线索进展 | 有线索标记（F1/F2...） |
| 人物关系型 | 推动关系变化 | 互动后信任/怀疑/依赖变化 |
| 场景铺垫型 | 为高潮铺垫 | 不直接推进，让后续更有冲击力 |
| 人物展示型 | 自然展现人物 | 通过对话/行动体现，禁评价词 |
| 伏笔埋设型 | 长线回收准备 | 必须填foreshadow_plant |

### 事件层级

| 层级 | 粒度 | 爽点要求 |
|------|------|---------|
| 超级 | 卷级 | 卷终决战/命运转折 |
| 大 | 弧级(8-12章) | Boss战/重大转折 |
| 中 | 段级(3-5章) | 阶段胜利/关系突破 |
| 小 | 章级 | 小胜利/小揭露/角色高光 |
| 微 | 场景级 | 对话钩子/信息投放 |

### 爽点密度

- 微/小爽点：每章至少1个
- 中爽点：每3-5章
- 大高潮：每8-12章
- 超级高潮：每卷1-2次
- **平路不超过3章**

### 事件设计思维模型

1. **碰撞引擎**：因果链+信息不对称碰撞+空间共置碰撞
2. **信息缺口张力**：每章至少1个信息缺口
3. **自信犯错**：合理决策+信息不完整→出错→共情

### 升级周期

铺垫→积累→突破→展示（V1-4: 每5-8万字; V5-10: 每10-15万字; V11-14: 每15-20万字）

## 二、章节结构（Step 2.1）

### 结构模板

| 段落 | 占比 | 字数 | 内容 |
|------|------|------|------|
| 起 | ~17% | ~500字 | 收束上章+引入核心冲突 |
| 承 | ~40% | ~1200字 | 2-3事件推进+日常/NPC/世界观 |
| 转 | ~27% | ~800字 | 转折/冲突升级 |
| 合 | ~17% | ~500字 | 情绪峰值+章末钩子 |

### 变体（每5章至少2种）

| 变体 | 适用 | 结构 |
|------|------|------|
| 标准型 | 常规推进 | 起→承→转→合 |
| 突入型 | 延续高潮 | 直接从转开始→合留悬念 |
| 日常型 | 过渡铺垫 | 起→长段日常承→安静收束 |
| 倒叙型 | 揭露回忆 | 合段开头→倒回起→承→解释 |
| 碎片型 | 多线切换 | 3-4个短场景碎片拼接 |
| 螺旋型 | 高潮核心 | 起极短→承极长→转爆发→合极短 |

### 4层内容模型

| 层 | 内容 | 占比 | 要求 |
|----|------|------|------|
| A推进层 | 主线/冲突/升级 | 40-50% | 每段必须有新信息 |
| B人物层 | 对话/心理/关系 | 25-30% | 主观镜头偏心 |
| C世界层 | 环境/NPC/世界观 | 15-20% | 严禁精确数字 |
| D氛围层 | 感官/节奏/伏笔 | 5-10% | 锯齿状叙事 |

## 三、世界知识注入（Step 2.1 按需）

参照 `设定/lorebook/` 目录下的YAML条目。写作时按以下流程加载：

1. **常驻条目**：从 `设定/lorebook/entries/` 读取所有 `constant: true` 的YAML，按 priority 排序
2. **关键词匹配**：遍历按需条目，检查 keys 是否在章节大纲/角色名/场景地点中命中
3. **时序过滤**：检查 delay/cooldown/sticky 条件
4. **Token预算**：Lorebook总量不超过上下文的20%，常驻占40%（永不裁剪），按需按priority裁剪

### 设定一致性

- 禁止矛盾：正文必须与已激活Lorebook一致
- 禁止超范围：不能使用未激活条目中的设定
- 物品闭环：使用灵能物品必须有对应Lorebook条目
- 经济一致：交易/物价参考灵晶+货币体系数值

## 四、事件序列写作（Step 2.2）

从事件序列表逐一展开：

1. **环境搭建** → 首次完整描写，再访只写变化
2. **人物对话** → 关系差异化+弦外之音+微表情
3. **动作场景** → 5拍+空间感知+具体化
4. **物品使用** → 加载档案保持一致
5. **过渡到下一事件** → 空行+过渡句

**变速原则**：关键情节慢写（多感官多细节）、过渡情节快写（长句概述）

### 场景搭建规则

每个场景100-200字五感铺垫：

| 感官 | 内容 | 示例 |
|------|------|------|
| 视觉 | 光影/色彩/细节 | 晨光照亮浮尘 |
| 听觉 | 环境音/远声 | 矿坑轰鸣像地底呼吸 |
| 嗅觉 | 气味 | 铁锈味混冷气 |
| 触觉 | 温度/质感 | 冷风冻得手麻 |
| 氛围 | 2-3感官综合 | 晨雾贴地涌 |

### 复杂场面（3+人）→ 角色矩阵

| 角色 | 目标 | 障碍 | 对他人态度 | 信息持有 |
|------|------|------|-----------|---------|

### 场景缝合

优先软过渡和零换行，避免全部硬切。

## 五、人物鲜活化（Step 2.3-2.4）

### 微表情与动作细节（禁止直白情绪词）

- 禁止："他惊讶""愤怒地说""悲伤地说"
- 正确：手停在半空/指节敲桌/喉结动了动/嘴角压紧
- 每段对话至少1个微表情/动作细节

### 说话风格差异化

从 character_get 的 speech_style/catchphrase 提取，按关系调节语气。

### 口头禅自然融入

首次建立2-3次，后续每3-5次对话出现一次。

### NPC互动规则（每章至少2个有动机NPC）

| 类型 | 动机 | 对话特点 |
|------|------|---------|
| 商贩 | 利益驱动 | 价格变动/供需/行情 |
| 居民 | 地区文化 | 生活态度/舆论/流言 |
| 军人 | 专业背景 | 术语/经验/立场 |
| 逃亡者 | 创伤求生 | 谨慎/回避/试探 |

NPC必须有：姓名/绰号 + 背景暗示 + 可见动机 + 与主角的互动痕迹。

## 六、分支事件（Step 2.5）

- 分支事件占每章 **15%-25%** 字数
- 类型：日常闲聊/世界观观察/环境细节/人物小冲突/过渡填充
- 分支必须涉及人物互动或世界观展示
- 分支与主线自然过渡

---

## 七、质量检查（Step 2.6-2.7）

### 内容丰富度检查（14项）

| 检查项 | 要求 |
|--------|------|
| 章节结构 | 使用合适变体，近5章至少2种不同变体 |
| 章末钩子 | 有钩子或确认是日常型 |
| 爽点密度 | 本章至少1个微/小爽点 |
| 信息缺口 | 至少1个 |
| 日常事件 | 2-3个日常场景 |
| NPC出场 | 至少2个有动机NPC |
| 场景搭建 | 每场景五感氛围铺垫 |
| 世界观展示 | 至少3个元素自然融入 |
| 人物性格 | 微表情/动作展示（禁直白词） |
| 分支事件 | 占15%-25%字数 |
| 4层内容 | A40-50%+B25-30%+C15-20%+D5-10% |
| 反注水 | 无孤立感官/无因果过渡/无重复意象 |
| 场景密度 | 每3段至少1段"同时做2+件事" |
| 伏笔处理 | 伏笔已标记并填写foreshadow_plant |

### AI指纹检查（强制，不通过=拒绝存盘）

| 检查项 | 要求 | 拒绝阈值 |
|--------|------|---------|
| FP-1 句号切割法 | 连续独立短句≤2个，全章占比≤15% | >20% 或存在3+连续短句 |
| FP-2 解释式展示 | 设定首次出现不紧跟解释，全章≤3次 | >5次 |
| FP-3 结构对称 | 场景间段落长度方差>20% | 方差<15% |
| FP-4 否定转折 | "不是X，是Y"全章≤2次 | >4次 |
| FP-5 质量均匀 | 有2-3个粗糙段（无感官/无比喻/纯动作），相邻段落质量差≥20分 | 全章每段都"认真写"=均匀=AI |
| FP-6 废笔缺失 | 有3种废笔（角色废话/环境废笔/生活碎片/假伏笔/跑题对话），占5-10%字数 | 每个细节都服务结构=AI |
| FP-7 人物太干净 | 至少1个角色失控时刻（说蠢话/情绪过头/oversharing/跑题） | 所有人都维持人设=AI |
| FP-8 无作者声音 | 至少1个声音注入点（读设定/作者声音.md），禁用安全牌比喻 | 全章"稳顺好读"但无个性=AI |
| FP-9 全程匀速 | 至少1处节奏断层（突然加速/停滞/切走/时间塌缩） | 全章节奏平稳无断裂=AI |
| FP-10 伏笔太密 | 废线和真伏笔混合穿插，真废笔按需使用 | 每个细节都回收=AI |
| FP-11 太安全 | 大纲有爆炸事件的章节必须让读者感受到爆炸力度 | 全章无刺无炸=AI |
| FP-12 人物均等 | 主角超饱和，NPC极简（1特征），路人透明 | 每个角色都有可爱标签=AI |

### 深层AI指纹（十九至二十二节）

详见 SENTENCE-PATTERNS.md 第十九至二十二节：
- 十九·质量方差引擎：消灭"每段80分"
- 二十·废笔配额系统：消灭"每段都服务结构"
- 二十一·作者声音系统：消灭"工业化无个性"
- 二十二·叙事意识层反AI系统：消灭"太稳定/太安全/太工整"（节奏失控/真废笔/废线/饱和度不均/爆炸点/作者失控升级）

### 字数控制

- **最低**: 3000字（不含标点）
- **目标**: 3000-5000字
- 每500字暂停检查字数
- 不足3000时用场景深化技法，禁止注水
- 超过5000时考虑拆章
