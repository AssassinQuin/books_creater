# 逐章写作引擎（优化版）

> 共享约定：读 `.claude/skills/novel-writer/references/shared-conventions.md`（含流程纪律）

---

## 强制流程

```
Step 1 注入全量上下文 → Step 2 写正文 → Step 3 🔒状态同步 → Step 4 存盘
```

**Step 3 是不可跳过的强制步骤**。每章写完后必须执行质量检查，未完成则拒绝存盘。

---

## Step 1: 注入全量上下文

```
writing_start(novel_id, chapter_number)
→ 基础信息（前3章摘要+活跃人物+未回收伏笔）
```

**跨大纲全量加载（强制）：**

```
1. world_query(category="faction") → 势力范围、当前势力关系
2. world_query(category="location") → 区域设定、本章涉及地点详情
3. world_query(category="ability") | world_query(category="economy") → 物品/资源体系
4. character_get(character_id) → 章节涉及人物最新状态(status含position/inventory/mental_state)
5. relation_list() → 人物关系网，判断对话立场/冲突来源
6. timeline_query(from_chapter=1, to_chapter=当前章) → 全卷时间线，避免矛盾
7. volume_get(volume_id) → 当前卷完整规划，理解本章在卷中位置
```

## Step 2: 写正文

### 2.0 前置检查（强制）

```
读 设定/写作执行规范.md
```

**字数分段控制（🔴 强制执行）：**

| 检查节点 | 目标字数 | 检查动作 | 未达标处理 |
|----------|----------|----------|----------|
| 写作开始前 | 0字 | 确认目标2800-3500字 | 调整目标 |
| 写作500字后 | ≥500字 | 暂停检查字数+进度 | 继续写作 |
| 写作1000字后 | ≥1000字 | 暂停检查字数+进度 | 继续写作 |
| 写作1500字后 | ≥1500字 | 暂停检查字数+进度 | 继续写作 |
| 写作2000字后 | ≥2000字 | 暂停检查字数+进度 | 继续写作 |
| 写作2500字后 | ≥2500字 | 暂停检查是否完成大纲 | 继续/收尾 |
| 写作3000字后 | ≥3000字 | 暂停评估是否需拆章 | 继续/拆分 |

**🔴 执行规则：**
- 每个检查节点必须暂停，统计当前字数
- 如字数<2500且大纲未完：强制扩展日常场景，不得直接收尾
- 如字数>3500且大纲未完：警告"考虑拆分为第X章上+第X章下"
- 最终字数必须≥2500，否则拒绝存盘

**强制遵守：**
- 最低字数：2500字（不含标点）
- 目标字数：2800-3500字
- 内容依据：本章大纲为纲，世界观/人物状态为准
- 检查清单：逐项勾选，写后逐项确认

**内容丰富度强制检查（9项）：**

| 检查项 | 强制要求 | 未达标处理 |
|--------|----------|----------|
| ✅ 日常事件 | 至少2-3个日常场景（衣食住行/闲聊/观察/训练） | 扩展日常场景 |
| ✅ NPC出场 | 至少1-2个新NPC出场（非路人甲乙） | 补充NPC互动 |
| ✅ 场景搭建 | 每个场景必须有环境描写+氛围铺垫（100-200字） | 补充场景描写 |
| ✅ 世界观展示 | 至少1个世界观元素自然融入（货币/宗教/服饰/俚语/食物） | 自然植入设定 |
| ✅ 人物性格 | 通过行动/话语/微表情展示人物（不用"他惊讶"） | 增加细节动作 |
| ✅ 分支事件 | 至少1个非大纲的枝干事件 | 补充支线内容 |
| ✅ 人口密度 | 村/镇等生活场景暗示"几十人"活跃 | 增加背景人物 |
| ✅ 口头禅/梗 | 主要角色1-2个口头禅或习惯动作 | 增加人物特色 |
| ✅ 短章舒适 | 字数过多可拆分章节，保证阅读节奏 | 分章节 |
| ⚠️ 分割符 | 禁用 `---` 过度使用场景分隔 | 用空行或过渡句 |

**字数分段控制：**
- 预估目标：2800-3500字
- 写作中每约500字暂停一次，检查当前字数：
   - 如当前字数 < 2500 且接近大纲结尾：警告"字数不足，需扩展日常场景"
   - 如当前字数 > 3500 且大纲未完：警告"大纲未完但字数已超，考虑拆分为第X章上+第X章下"
- 字数强制：最终字数必须 ≥ 2500，否则拒绝存盘

### 2.1 角色分析指导（让人物活过来）

**目标**：基于novel-character技能的完整人物档案，使用角色蒸馏法分析当前剧情人物，推理反应/行为、话语，指导写作。

**世界观一致约束（新增）：**
- **人物离开地区后返回**：人物离开某地区后"后面回来"期间，当地情况、人物、饮食、物价等保持不变
- **人物重逢记忆一致**：人物再次到曾经到过的地区或场景，记忆中的人物关系、当地习俗、地理认知要一致
- **多人物同地场景**：不同人物去同一个地方，可能是偶然相遇，但要通过对话说明当地特色、人物、饮食等
- **时间线连贯**：人物离开A地，去B地办事，"后面回来"——这段时间内B地的剧情不能推进到"前面"

**执行流程：**

```
1. character_get(character_id) × N → 获取所有涉及人物的完整档案
2. 角色蒸馏分析（7步）：
	   a. 萃取：从档案中提取外貌、身份、关键行为
	   b. 深度：Ghost→Lie因果链 + Want/Need矛盾 + 弧线类型判定
	   c. 洋葱三层：社交面具 + 自我认知 + 真实内核
	   d. 矛盾注入：主气质 × 矛盾特质 = 化学反应
	3. 剧情推理：
	   a. 当前处境：人物在哪？什么环境？谁在场？
	   b. 压力源：Ghost（创伤）？Lie（谎言）？Want（欲望）？Need（需求）？
	   c. 冲突分析：与谁对立？谁是盟友？谁是敌对？
	   d. 关系网络：与其他人物的关系强度
	4. 行为指导生成：
	   a. 说话风格：紧张/放松/愤怒时的用词、句式节奏
	   b. 行动倾向：主动/被动/犹豫/果断
	   c. 对话立场：对每个角色的具体态度
	   d. 情绪反应：遇到冲突时的真实反应（不"震惊""难以置信"）

5. **口头禅预定义**：
   - character_get 提取每个角色的 `catchphrase` 字段
   - 写作时自动将口头禅融入对话（如"那倒是...""嗯..."等）
   - 如角色无预设口头禅，根据性格特点在首次登场时临时生成（"那个...""嗯..."等）

**输出：写作指导卡片**

```

[人物分析指导 - 第{章节号}章]

涉及人物：
| 姓名 | 当前处境 | 压力源 | 冲突对象 | 说话风格 | 行动倾向 | 对话立场 | 口头禅 | 离开地区 | 目的地 |
|------|----------|---------|----------|----------|----------|----------|
| {A} | {描述} | {Ghost/Lie/Want/Need} | {人物名} | {具体描述} | {具体描述} | {从档案提取} | {原地点} | {B地目的} |
```
