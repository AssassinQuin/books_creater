# 逐章写作引擎（优化版）

> 共享约定：读 `.claude/skills/novel-writer/references/shared-conventions.md`（含流程纪律）

---

## 强制流程

```
Step 1 注入全量上下文 → Step 2 写正文 → Step 3 质量检查 → Step 4 存盘
```

**Step 3 是不可跳过的强制步骤**。每章写完后必须执行质量检查，未完成则拒绝存盘。

---

## Step 1: 注入全量上下文

```
writing_start(novel_id, chapter_number)
→ 基础信息（前3章摘要+活跃人物+未回收伏笔）
```

**跨大纲全量加载（强制）：**

```
1. world_query(category="faction") → 势力范围、当前势力关系
2. world_query(category="location") → 区域设定、本章涉及地点详情
3. world_query(category="ability") | world_query(category="economy") → 物品/资源体系
4. character_get(character_id) × N → 章节涉及人物最新状态(status含position/inventory/mental_state)
5. relation_list() → 人物关系网，判断对话立场/冲突来源
6. timeline_query(from_chapter=1, to_chapter=当前章) → 全卷时间线，避免矛盾
7. volume_get(volume_id) → 当前卷完整规划，理解本章在卷中位置
```

## Step 2: 写正文

### 2.0 前置检查（强制）

```
读 设定/写作执行规范.md
```

**强制遵守：**
- 最低字数：2500字（不含标点）
- 目标字数：2800-3500字
- 内容依据：本章大纲为纲，世界观/人物状态为准
- 检查清单：逐项勾选，写后逐项确认

**内容丰富度强制检查（9项）：**

| 检查项 | 强制要求 | 未达标处理 |
|--------|----------|----------|
| ✅ 日常事件 | 至少2-3个日常场景（衣食住行/闲聊/观察/训练） | 扩展日常场景 |
| ✅ NPC出场 | 至少1-2个新NPC出场（非路人甲乙） | 补充NPC互动 |
| ✅ 场景搭建 | 每个场景100-200字环境描写+氛围铺垫 | 补充场景描写 |
| ✅ 世界观展示 | 至少1个世界观元素自然融入（货币/宗教/服饰/俚语/食物） | 自然植入设定 |
| ✅ 人物性格 | 通过行动/话语/微表情展示人物（不用"他惊讶"） | 增加细节动作 |
| ✅ 分支事件 | 至少1个非大纲的枝干事件 | 补充支线内容 |
| ✅ 人口密度 | 村/镇等生活场景暗示"几十人"活跃 | 增加背景人物 |
| ✅ 口头禅/梗 | 主要角色1-2个口头禅或习惯动作 | 增加人物特色 |
| ✅ 短章舒适 | 字数过多可拆分章节，保证阅读节奏 | 分章节 |
| ⚠️ 分割符 | 禁用 `---` 过度使用场景分隔 | 用空行或过渡句 |

**字数分段控制：**
- 预估目标：2800-3500字
- 写作中每约500字检查一次
- 如当前字数 < 2500 且接近大纲结尾：警告"字数不足，需扩展日常场景"
- 如当前字数 > 3500 且大纲未完：警告"大纲未完但字数已超，考虑拆分为第X章上+第X章下"
- 字数强制：最终字数必须 ≥ 2500，否则拒绝存盘

### 2.1 角色分析指导（让人物活过来）

**目标**：基于novel-character技能的完整人物档案，使用角色蒸馏法分析当前剧情人物，推理反应/行为、话语，指导写作。

**执行流程：**

```
1. character_get(character_id) × N → 获取所有涉及人物的完整档案
2. 角色蒸馏分析（7步）：
	   a. 萃取：从档案中提取外貌、身份、关键行为
	   b. 深度：Ghost→Lie因果链 + Want/Need矛盾 + 弧线类型判定
	   c. 洋葱三层：社交面具 + 自我认知 + 真实内核
	   d. 矛盾注入：主气质 × 矛盾特质 = 化学反应
	3. 剧情推理：
	   a. 当前处境：人物在哪？什么环境？谁在场？
	   b. 压力源：Ghost（创伤）？Lie（谎言）？Want（欲望）？Need（需求）？
	   c. 冲突分析：与谁对立？谁是盟友？谁是敌对？
	   d. 关系网络：与其他人物的关系强度
	4. 行为指导生成：
	   a. 说话风格：紧张/放松/愤怒时的用词、句式节奏
	   b. 行动倾向：主动/被动/犹豫/果断
	   c. 对话立场：对每个角色的具体态度
	   d. 情绪反应：遇到冲突时的真实反应（不"震惊""难以置信"）

5. **口头禅预定义：**
   - character_get 提取每个角色的 `catchphrase` 字段
   - 写作时自动将口头禅融入对话（如"那倒是...""嗯..."等）
   - 如角色无预设口头禅，根据性格特点在首次登场时临时生成（"那个...""嗯..."等）

**输出：写作指导卡片**

```
[人物分析指导 - 第{章节号}章]

涉及人物：
| 姓名 | 当前处境 | 压力源 | 冲突对象 | 说话风格 | 行动倾向 | 对话立场 | 口头禅 |
|------|----------|---------|----------|----------|----------|----------|
| {A} | {描述} | {Ghost/Lie/Want/Need} | {人物名} | {具体描述} | {具体描述} | {具体描述} | {从档案提取} |

[场景级指导]
- {人物A}遇到{场景}时：会{具体反应}，说话{风格}，动作{具体}
- {人物B}与{人物A}互动：考虑{关系}，对话体现{立场}
```

**写作时参考此卡片，确保人物反应符合档案设定。**

### 2.2 设定冲突检测与整改

写作过程中持续检查，发现冲突立即处理：

**检测维度：**
| 冲突类型 | 检测方法 |
|-----------|---------|
| 世界观冲突 | 是否与world_query返回的设定矛盾？ |
| 人物冲突 | 是否与character_get返回的status/背景矛盾？ |
| 时间线冲突 | 是否与timeline_query返回的历史事件矛盾？ |
| 大纲冲突 | 是否偏离writing_start返回的outline逻辑？ |
| 前文冲突 | 是否与前3章摘要中的关键事实矛盾？ |

**整改流程（用户确认）：**
1. 暂停写作，明确列出冲突点
2. 展示选项给用户：
	   - 选项1：整改设定（调用world_upsert/character_update）
	   - 选项2：整改大纲（更新outline）
	   - 选项3：重构正文（重写当前段落）
3. ⚠️ **等待用户确认**，收到选择后执行修复
4. 修复后继续写作

### 2.3 写作执行

读 `.claude/skills/novel-writer/references/writing-style.md` + `anti-ai-patterns.md`

#### 内容丰富度章节设计策略（基于诡秘之主/权力游戏/经典网文调研）

**核心原则**：
- **诡秘之主**：前期慢热，大量笔墨描写日常生活，营造异世界质感；塔罗会群像，每个成员完整人设
- **权力游戏**：POV角色密度控制，涟漪效应（不同故事线相互影响）
- **经典网文**：主角300字内登场，性格突显；动作-反应模式推动剧情

---

##### 场景1：开篇慢热（第1章示例）

**设计目标**：通过日常细节营造真实生活感，引入NPC，世界观自然展示

| 元素 | 设计要求 | 第1章示例 |
|------|---------|-----------|
| **主角登场（300字内）** | 性格突显：通过具体行动/对话展示主角性格 | 沈念推开木门，手指在衣角搓了搓。外头是灰的，像块脏布…… |
| **日常场景（1-5个）** | 衣食住行细节：物价/食物/出行/住宿/闲聊 | 街面铺着石板，几个摊贩在卖东西。沈念走到一个面摊前，老板娘抬头看了他一眼……「沈念，今天灵石又涨了啊……那倒是，老板娘的包子倒是一如既往，热气腾腾。」 |
| **环境描写（100-200字）** | 五感+氛围+地理位置暗示 | 天空灰得像块发霉的抹布。风从街道尽头吹过来，带着远处的哭嚎和铁器撞击的杂音…… |
| **新NPC登场（1-2个）** | 每人三要素：独特性格+口头禅+习惯动作+高光时刻 | 老头：「喂，小哥，借个火……」沈念看了他一眼，那双眼睛很小，像两颗浑浊的黑玻璃珠，眼角堆满了细纹，一看就上了年纪。 |
| **世界观展示（1-2个）** | 通过对话/物品/观察自然融入设定 | 沈念摸出两个铜板，递给老头。「行，二十铜。」「谢了，叔。」 |
| **支线涟漪效应** | 配角的行动要影响主线 | 老头把油条往灶膛一塞，蓝色的火苗窜上来。老头回头看了他一眼：「年轻人，我看你面相不差，但命有点硬啊……」 |

**场景1效果**：
- ✅ 主角登场：搓手+深呼吸，体现谨慎
- ✅ 日常细节：包子热气+物价上涨
- ✅ 环境描写：五感完整，营造压抑氛围
- ✅ NPC登场：老头+中年妇女，两人有独特性格
- ✅ 世界观展示：物价上涨+城里不太平
- ✅ 涟漪效应：老头的信息影响后续

---

##### 场景2：剧情推进中段（第2-4章示例）

**设计目标**：主线推进与支线交织

| 元素 | 设计要求 | 示例 |
|------|---------|-----|
| **主线事件** | 明确目标+具体行动+结果 | 沈念走进灵站大厅…… |
| **支线涟漪** | 配角的行动/选择要回响主线，形成闭合 | 沈念刚排到位置，一个穿灰袍的中年男人从旁边走过来：「小六，到了？」那人笑了笑…… |
| **NPC群像** | 配角有完整人设，在主场景有高光时刻 | 中年男人压低声音继续说…… |
| **世界观细节** | 货币体系+守夜者制度+地理形势 | 检石表面泛着暗淡的光，但今天的光明显更暗…… |

**场景2效果**：
- ✅ 主线清晰：沈念进站+与NPC对话
- ✅ 涟漪效应：中年男人的情报影响后续
- ✅ 配角丰满：中年男人有谨慎性格
- ✅ 世界观细节：兽潮预告+守夜者撤离

---

##### 场景3：高潮/冲突（第5-8章示例）

**设计目标**：动作密集+多线交织

| 元素 | 设计要求 | 示例 |
|------|---------|-----|
| **动作密集** | 短句密集+动词驱动，对话≤20% | 剑光一闪，沈念的剑已经出鞘。他脚尖一点，整个人像离弦的箭一样射出去…… |
| **多线交织** | 主角+配角的冲突同步进行 | 沈念冲到那人面前，那人还没反应过来。沈念一剑劈下，那人惨叫一声，半边身子都炸开了…… |
| **人物冲突** | 通过具体冲突展示人物立场/能力 | 老头提着油条冲过来：「小六！你疯了？这可是灵站的守夜者……」沈念皱眉：「叔，你别管我，让我处理。」 |
| **涟漪效应** | 冲突结果影响后续多章剧情 | 中年男人捂着胸口倒在地上，脸却没什么表情。他死死盯着沈念，嘴角突然咧开一丝诡异的笑…… |

**场景3效果**：
- ✅ 动作密集：剑光一闪+劈下
- ✅ 多线交织：沈念+老头同时参与
- ✅ 人物冲突：立场清晰
- ✅ 涟漪预告：中年男人临死的话

---

##### 场景4：收尾/过渡（第9-12章示例）

**设计目标**：总结本章+钩子悬念

| 元素 | 设计要求 | 示例 |
|------|---------|-----|
| **事件总结** | 梳理本章发生的关键事件 | 沈念看着地上中年男人的尸体，心里一阵发冷。他蹲下来，在那人怀里翻了翻——只有几个铜板，一张身份符。 |
| **钩子悬念** | 为下章埋下钩子，引出读者好奇心 | 沈念站起身，看向灵站外。天色越来越暗了，兽潮前的宁静正在一点点消失……远处，第一声兽嚎已经隐约传来…… |

#### 场景类型策略

| emotion_type | 核心策略 | 占比 | 具体写法 |
|-----------|---------|------|----------|
| dialogue | 潜台词+废话+抢话 | 对话≥60% | 「那个...你说呢」+打断+省略号 |
| action | 短句密集+动词驱动 | 动作≥50%，对话≤20% | 「剑气一闪""他冲出去""手掌按住地面」 |
| atmosphere | 五感铺陈+环境暗示情绪 | 环境≥40%，内心≥30% | 视觉+听觉+触觉 |
| psychology | 情绪分层+回忆碎片 | 内心独白≥40% | 三层：当前感受+过去联想+本能反应 |
| daily | 闲聊带设定+毛边细节 | 闲聊+侧面≥60% | 「这批灵石是北境运来的吧？""那倒是...」 |

**说明**：根据大纲关键词判断场景类型，同一章场景类型≤2种。

#### 多线交织策略

**主线判断：**
1. 查volume_get返回的main_plotlines → 本章属于哪条线节点
2. 对比timeline_query → 本章在时间线位置

**伏笔操作：**
1. 查foreshadow_list → 计划回收的伏笔
2. 暗线埋设：非暗线章节用日常不经意带过
3. 伏笔回收：暗线章节在高潮前3-5章回收

**配角控制：**
1. 检查哪些配角最近5章没出场
2. 避免堆砌：同章配角≤3人，每人出场≥200字

**场景切换：**
1. 同一场景切换≤2次
2. 用动作/环境过渡，不用"与此同时""另一边"等显式连接

---

#### 去AI味要点

| 避免 | 示例 |
|------|------|
| 均匀句式 | 「他看着她，她看着你。」 |
| "然而""于是""随后"堆砌 | 手一松，剑落地。他冲了出去。 |
| 完美逻辑对话 | 「那个...你说呢？」「啊...我...」+打断+省略号 |
| 过度规整 | 桌角翘一块皮，桌面有茶渍，窗户缝塞着传单 |
| 情绪词堆砌 | 指尖在抖。他的瞳孔放大。 |
| **错别字** | 不使用"于是""随后""接着""因此""然而"等过渡连接词；不使用"基线""简短""核心配角""主要情节""简短"等AI特有词汇 |

---

#### 节奏控制

**字数约束（强制）：**
- 最低字数：2500字
- 目标字数：2800-3500字
- 检测：如<2500字，必须扩展而非拖沓

**章节标题设计规范（重要）：**

| 要求 | 说明 |
|------|------|
| 有意义 | 章节标题要独立设计，反映本章核心内容，不能直接复用大纲小标题 |
| 不巨头 | 避免使用几万字的大纲小标题作为章节标题（大纲小标题是场景梗概） |
| 简洁 | 标题控制在15字以内 |
| 一致性 | 与本章内容、卷级主题保持一致 |

**节奏分布：**
- 开头10%承接铺垫 → 发展40%核心推进 → 高潮30%最紧张 → 收尾20%钩子悬念

**防拖沓原则（不要特异凑字数）：**
| 禁止 | 替代 | 动作接动作，不写连接词 |
| 无意义长心理描写 | 用具体行为展示情绪 |
| 重复相同动作 | 合并或一次概括 |
| 环境描写填充 | 用环境暗示情绪，不单独堆砌 |
| 章节末无推进 | 每段至少一个推进点

**爽点密度：**每3-5章一个（打脸/逆袭/获得/展示/复仇）

## Step 3: 质量检查（强制）

```
每章写完后立即执行，未完成则拒绝存盘。

**质量检查维度（6项）：**

| 检查项 | 强制要求 | 检查方式 | 未达标处理 |
|--------|----------|----------|----------|
| ✅ 9项内容丰富度 | 对照2.0前置检查清单逐项确认 | 补充缺失场景 |
| ✅ 大纲内容标记 | 检查[大纲内容] vs [支线事件]标注是否明确 | 修正错误标记 |
| ✅ 口头禅应用 | 检查对话中口头禅是否自然融入 | 优化不自然处 |
| ✅ 字数达标 | 统计字数，确认≥2500字 | 拒绝短章 |
| ⚠️ POV控制 | 检查同一场景POV是否切换>2次 | 优化或拆分章节 |
| ⚠️ 人物性格一致 | 检查人物行为是否符合档案设定 | 修正OOC |
| ⚠️ 去AI味 | 检查是否存在禁用词汇 | 修正 |

**检查流程：**
