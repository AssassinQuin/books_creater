# 逐章写作引擎（优化版）

> 共享约定：读 `.claude/skills/novel-writer/references/shared-conventions.md`（含流程纪律）

---

## 强制流程

```
Step 0 断点检测 → Step 1 注入全量上下文 → Step 2 写正文 → Step 3 🔒状态同步 → Step 4 存盘
```

**Step 3 是不可跳过的强制步骤**。每章写完后必须执行质量检查，未完成则拒绝存盘。

---

## Step 0: 断点检测（续写场景必执行）

当用户说"继续写"/"接着写"时，在Step 1之前执行断点检测：

```
1. 检查目标章节文件是否存在：glob("novels/{小说名}/正文/第{NNN}章-*.md")
2. 检查novel-db中该章节是否有writing_finish记录
3. 三态分支：

   (a) 文件不存在 → 正常从Step 1开始
   (b) 文件存在但字数<2500 且 无writing_finish → 🔒提示用户：
       "检测到未完成的第N章({当前字数}字)，从断点继续还是重写？"
       - 用户选"继续" → 读已有正文，定位最后一个完整事件，从下一事件续写
       - 用户选"重写" → 删除旧文件，从Step 1重新开始
   (c) 文件存在且字数≥2500 → 提示用户：
       "第N章已完成({字数}字)，是否覆盖重写？"
       - 用户确认"是" → 备份旧文件(.bak)，从Step 1重新开始
       - 用户确认"否" → 提示下一章号，询问是否写下一章
```

**新章节（非续写）跳过此步骤。**

---

## Step 1: 注入全量上下文

```
writing_start(novel_id, chapter_number)
→ 基础信息（前3章摘要+活跃人物+未回收伏笔）
```

**跨大纲全量加载（强制）：**

```
1. world_query(category="faction") → 势力范围、当前势力关系
2. world_query(category="location") → 区域设定、本章涉及地点详情（含食物/天气/文明/文化）
3. world_query(category="ability") | world_query(category="economy") → 物品/资源体系
4. character_get(character_id) → 章节涉及人物最新状态(status含position/inventory/mental_state)
5. relation_list() → 人物关系网，判断对话立场/冲突来源
6. timeline_query(from_chapter=1, to_chapter=当前章) → 全卷时间线，避免矛盾
7. volume_get(volume_id) → 当前卷完整规划，理解本章在卷中位置
8. foreshadow_list(status="planted") → 未回收伏笔清单
```

## Step 2: 写正文

### 2.0 前置检查（强制）

```
读 设定/写作执行规范.md
```

**大纲事件拆解与分类（🔴 强制）：**

```
从 chapter.outline 中提取所有事件（用 + 分割），按逻辑顺序排序：
1. 事件优先级：核心主线 > 支线 > 填充
2. 时间顺序：前序事件在前，后序事件在后
3. 因果连贯：每个事件必须推动剧情/人物关系/埋设线索
4. 缺失补充：大纲未列出的必要过渡事件（如时间过渡、空间移动）
```

**事件分类体系（强制执行）：**

大纲是主干，事件是枝干。每章生成时需明确每个事件的**类型与作用**：

| 事件类型 | 作用 | 特征 | 示例 |
|---------|------|------|------|
| **线索推动型** | 为后续事件/章节铺垫，推动各种线索进展 | 有明确线索标记（F1/F2...），为后续回收做准备 | 方岩给路线图→后续路线异常事件（V2） |
| **人物关系型** | 推动人物情感/立场变化，建立或改变关系 | 互动后人物间信任/怀疑/依赖关系发生变化 | 沈念发病→沈野焦虑加深；蔓给沈念编手套→关系突破 |
| **场景铺垫型** | 为高潮/转折做准备，营造氛围、展示世界观、引入关键元素 | 不直接推进剧情，但让后续高潮更有冲击力 | 兽潮夜日常→沈野创伤回忆铺垫；自由城地下探索→V5铺垫 |
| **人物展示型** | 自然展现人物特点（性格/能力/口头禅），不直白描述 | 通过对话/行动体现，禁用"他善良""她坚强"等评价词 | 沈野用冷漠边界保护沈念，细节动作体现关心 |
| **伏笔埋设型** | 为长线回收做准备，必须有明确回收规划 | 填写foreshadow_plant，必须planned_recall_chapter | 碎罗盘→F5伏笔，V5回收；鸦的干粮→V7回收 |

**事件层级体系（🔴 强制）：**

| 层级 | 粒度 | 字数范围 | 爽点要求 |
|------|------|---------|---------|
| **超级** | 卷级 | 每卷1-2个 | 卷终决战/命运转折/真相揭露 |
| **大** | 弧级 | 2400-3600字(8-12章跨度) | Boss战/重大转折/认知推翻 |
| **中** | 段级 | 900-1500字(3-5章跨度) | 阶段胜利/关系突破/能力跃升 |
| **小** | 章级 | 3000字(1章) | 小胜利/小揭露/角色高光 |
| **微** | 场景级 | 500-1000字 | 对话钩子/信息投放/情绪波动 |

**爽点密度（🔴 强制执行）：**

| 爽点级别 | 间隔 | 必须包含 |
|----------|------|---------|
| 微/小爽点 | 每1章 | 至少1个小胜利/小揭露/角色高光 |
| 中爽点 | 每3-5章 | 阶段性胜利/关系突破/能力展示 |
| 大高潮 | 每8-12章 | 卷内高潮/Boss战/重大转折 |
| 超级高潮 | 每卷1-2次 | 卷终决战/命运转折/真相揭露 |

**平路不超过3章**：连续3章无爽点，追读率开始下降，必须在第4章补一个中爽点。

**卷级事件侧重（根据当前卷类型调整事件比例）：**

查 volume_get 判断当前卷类型，按以下比例分配事件：

| 卷类型 | 冲突事件 | 揭露/关系 | 成长/日常 | 伏笔 |
|--------|---------|----------|----------|------|
| 开篇卷 | 20% | 35% | 30% | 15% |
| 成长卷 | 20% | 35% | 30% | 15% |
| 高潮卷 | 35% | 25% | 25% | 15% |
| 过渡卷 | 15% | 30% | 40% | 15% |
| 终卷 | 30% | 25% | 25% | 20%(回收为主) |

**事件设计三大思维模型（🔴 强制融入）：**

1. **碰撞引擎**（来源: 低智商犯罪蒸馏）
   - 用因果链而非巧合连接事件
   - 信息不对称碰撞：读者知道角色不知道 / 角色知道读者不知道 / 双方不知但读者猜到
   - 空间共置碰撞：不同线索的人物在同一空间相遇
2. **信息缺口张力**
   - 每章至少投放1个信息缺口（谁/为什么/怎么/什么时候/会怎样）
   - 缺口必须在后续章节有补上
3. **自信犯错**
   - 主角做合理决策但因信息不完整而出错
   - 读者能理解主角的选择，看到后果时产生共情

**升级周期事件结构（适用于成长/高潮卷）：**

```
铺垫(升级线索) → 积累(获取资源/领悟) → 突破(战斗/危机触发) → 展示(新能力实战验证)
```
- 前期卷(V1-4): 每5-8万字一次升级，铺垫3万→积累4万→突破1万→展示2万
- 中期卷(V5-10): 每10-15万字一次，重心转关系/阴谋
- 后期卷(V11-14): 每15-20万字一次，质变为主

**生成原则：**
- 事件不能堆砌，要有因果推进（碰撞引擎驱动）
- 每类事件合理混合，避免单类型重复
- **分支事件占每章15%-25%字数（强制）**
- 分支事件类型：日常闲聊/世界观观察/环境细节/人物小冲突/过渡填充
- 大纲事件是主线必须完成，分支事件可增删

**输出：事件序列表**

| 序号 | 事件内容 | 事件类型 | 事件层级 | 涉及人物 | 爽点级别 | 预期目标 | 线索/缺口 |
|------|----------|---------|---------|----------|---------|----------|----------|
| E1 | {事件1} | {类型} | {大/中/小/微} | {人物} | {微/小/中} | {目标} | {线索或信息缺口} |
| E2 | {事件2} | {类型} | {大/中/小/微} | {人物} | {微/小/中} | {目标} | {线索或信息缺口} |
| ... | | | | | | | |

**强制规则：**
- 事件必须按顺序展开，不可跳跃或合并
- 每个事件必须含至少1个人物互动或世界观展示
- 主线事件不得少于1000字
- 支线事件用于铺垫人物关系/世界观，不得偏离主线
- **每章至少1个微/小爽点，每3-5章追踪中爽点进度**
- **每章至少投放1个信息缺口（5W: 谁/为什么/怎么/什么时候/会怎样）**

### 2.1 章节结构模板

**起承转合是参考骨架，不是模具。** 每章的实际结构应根据事件类型灵活调整：

| 段落 | 占比 | 字数 | 内容要求 | 爽点/钩子 |
|------|------|------|---------|----------|
| **起** | ~17% | ~500字 | 收束上章钩子 + 引入本章核心冲突 | 回顾→悬念延续 |
| **承** | ~40% | ~1200字 | 2-3个事件推进 + 日常/NPC/世界观穿插 | 小爽点/信息缺口 |
| **转** | ~27% | ~800字 | 转折/意外/冲突升级 | 转折性爽点 |
| **合** | ~17% | ~500字 | 情绪峰值 + 章末钩子 | 钩子4型之一 |

**🔴 反AI结构僵化规则（强制）：**

不要每章都按 起→承→转→合 展开。根据事件内容和在卷中的位置，灵活选择结构变体：

| 变体 | 适用场景 | 结构 |
|------|---------|------|
| **标准型** | 常规推进章 | 起→承→转→合 |
| **突入型** | 延续上章高潮/紧急场景 | 直接从转开始（无起段），急促推进→合段留悬念 |
| **日常型** | 过渡/铺垫章 | 起→长段日常承（无明确转），结尾安静收束（无钩子也行） |
| **倒叙型** | 揭露/回忆章 | 合段开头（先给结果/悬念），倒回起→承→解释 |
| **碎片型** | 多线切换/快速推进 | 3-4个短场景碎片拼接，无完整起承转合 |
| **螺旋型** | 高潮卷核心章 | 起极短→承极长（持续升级）→转爆发→合极短（留大悬念） |

**每5章内至少使用2种不同变体**，避免连续出现相同结构。

**结构选择决策：**
1. 看上章结尾：上章是高潮结尾→这章用突入型或日常型消化；上章安静→这章可标准型推进
2. 看卷中位置：卷初→标准/日常；卷中→标准/碎片；卷末高潮→螺旋/突入
3. 看事件类型：战斗/升级→螺旋/突入；日常/NPC→日常型；揭露/反转→倒叙型
4. **随机因素**：偶尔让结构"跑偏"——安静的日常章突然出意外、紧张战斗章突然插入冷幽默。真实生活不按模板来

**章末钩子4种类型（不是每章都必须有钩子）：**

| 类型 | 示例 | 适用场景 |
|------|------|---------|
| 悬念式 | "他推开门，看到的不是..." | 信息揭露前 |
| 反转式 | 读者以为A结果B | 认知颠覆时 |
| 情绪炸弹 | 角色做出意外选择 | 关系转折时 |
| 信息投放 | 新线索/新威胁出现 | 伏笔提起时 |

**4层内容模型（🔴 每章配比）：**

| 层次 | 内容 | 占比 | 来源 |
|------|------|------|------|
| **A: 推进层** | 主线事件/冲突/升级 | 40-50% | 大纲事件序列 |
| **B: 人物层** | 对话/心理/关系变化 | 25-30% | 角色深化+关系网 |
| **C: 世界层** | 环境描写/NPC/世界观展示 | 15-20% | world_query |
| **D: 氛围层** | 感官细节/节奏调节/伏笔 | 5-10% | 五感描写 |

### 2.2 按事件序列写作

```
从事件序列表中选择下一个事件E，按以下结构展开：
1. 场景搭建（100-200字五感氛围 → C/D层）
2. 人物互动（基于关系网和人物档案 → B层）
3. 剧情推进（完成事件目标 → A层）
4. 线索埋设（自然融入世界观 → C/D层）
5. 过渡到下一事件（空行+过渡句）

每个事件完成后，标记E为已完成，继续下一事件。
章节完成后对照"起承转合"模板检查整体结构。
```

**事件→正文转化节奏（变速原则）：**
- 关键情节（高潮/转折）→ 慢写：多细节、多感官、短句密集
- 过渡情节（移动/准备）→ 快写：长句、概述、快速推进
- 变速是防疲劳核心：不改变事件本身，只改变叙述速度

**场景搭建规则（🔴 强制执行）：**

每个场景必须用**五感描写**建立氛围，100-200字铺垫：

| 感官 | 描写内容 | 示例 |
|------|---------|------|
| **视觉** | 光影、色彩、物体细节、建筑特色 | 晨光穿过窗缝照亮浮尘；灵能路灯的金色光芒在雾中晕开 |
| **听觉** | 环境音、远处的谈话、机械运转声 | 远处矿坑传来机械轰鸣，像地底的呼吸；风撕扯废墟的吱嘎声 |
| **嗅觉** | 气味（饭菜/金属/雨后泥土/灵能残渣） | 铁锈味混着隔夜的冷气；灵能站门口的苦味飘过街道 |
| **触觉** | 温度、质感、重力感 | 沈野的手被冷风冻得发麻；灵能烤炉的热浪扑面而来 |
| **氛围** | 用2-3个感官细节建立场景基调 | 废墟的晨雾贴着地面涌，压得人喘不过气 |

**示例**："废墟的晨雾贴着地面涌，铁锈味混着隔夜的冷气。远处矿坑传来机械轰鸣，像地底的呼吸。沈野的手被冷风冻得发麻，抓紧了背包带。"

**场景构建清单（每个场景必查）：**
- [ ] **地点**: 具体空间（不只"一个房间"，而是"灵站地下二层的储物间"）
- [ ] **感官**: 至少2种感官描写
- [ ] **角色**: 有动作/对话的角色（不静态站立）
- [ ] **信息增量**: 这个场景让读者知道了什么新东西？
- [ ] **推进**: 场景结束后，什么改变了？

**高燃场面五原则（适用于战斗/升级/觉醒场景）：**
1. 铺垫>爆发：爆发前至少2章铺垫，积累越久越燃
2. 代价感：每次强必有代价（体力/精神/关系牺牲）
3. 视觉化：用具体意象而非抽象描述（"灵能在指尖裂成蓝色闪电"优于"灵能暴涨"）
4. 节奏控制：爆发段短句密集，恢复段长句舒缓
5. 情感钩子：高燃不只炫技，必须绑定角色情感/关系/目标

**人物互动规则：**
- 查阅relation_list，判断人物间立场（盟友/敌对/中立）
- 参考人物档案中的speech_style/catchphrase/behavioral_flags
- **NPC对话需体现背景和动机（非路人甲乙）**：每章至少2个有背景的新NPC

**世界观自然植入规则（🔴 强制执行）：**

每章至少3个世界观元素，自然融入对话/动作，避免说明：

| 元素类型 | 具体内容 | 植入方式 |
|---------|---------|---------|
| **货币体系** | 铜币/银币/金币/灵晶的使用场景 | "三个铜币一碗杂粮""这袋灵晶能换半年饭钱" |
| **宗教元素** | 教会的仪式/教义/祭司的日常 | "祭司路过时居民低头致敬""黑月前夜守夜的人" |
| **俚语/黑话** | 特定群体的语言习惯 | 觉醒者称普通人"市民"的轻蔑语调 |
| **食物/生活** | 具体食物名称+制作方式 | "杂粮饼""灵能烤炉热饼""老陈面馆" |
| **服饰/器具** | 灵能驱动的日常用品 | 灵能照明石/通讯石/检测器/灵能公告栏 |

**植入原则：**
- 不堆砌：通过人物对话或动作自然带出
- 语境契合：世界观元素必须贴合场景和人物身份
- 避免说明：用"展示"而非"告诉"

**示例**："三十五个铜币。"沈野数出钱，压在柜台上。"昨天两碗。""够了。"老板收起硬币，扔来一个布包。"黑月节要到了，这布染过。"

### 2.3 人物鲜活化规则（🔴 强制执行）

**微表情与动作细节（禁止直白情绪词）：**

- ❌ 禁用："他惊讶""难以置信""愤怒地说""悲伤地说"
- ✅ 用动作体现情绪：
  - 惊讶：手停在半空、眼睛微微睁大、呼吸停了一拍
  - 愤怒：指节敲桌、嘴角压紧、身体前倾
  - 紧张：喉结动了动、手不自觉摸向装备、眼神游移
  - 不屑：嘴角撇一下、目光移开、手指轻敲桌面

**每段对话至少1个微表情/动作细节。**

**说话风格差异化：**
- 冷漠角色（沈野）：短句、少标点、被动语态、"嗯"结尾
- 阳光角色（沈念）：口语化、感叹词、主动语态、"那个..."
- 压抑角色（方岩）：慢节奏、停顿、省略号
- 专业角色（灵站员工）：术语+礼貌、公式化

**口头禅自然融入：**
- 从character_get提取catchphrase字段
- 首次登场时建立：用2-3次对话自然植入
- 后续使用频率：每3-5次对话出现一次
- 如角色无预设口头禅：根据性格特点在首次登场时临时生成

**示例**：
```
沈野："嗯。"（看窗外）"雾太厚。"
沈念："哥哥，你又不说话..."（低头折衣角）"那个...方叔是不是又要来？"
```

### 2.4 NPC互动规则（🔴 强制执行）

**每章至少2个新NPC出场（非路人甲乙）：**

- **NPC命名**：有姓名/绰号/职业标识
- **背景暗示**：通过对话/动作透露NPC身份（如"老陈面馆的老板"不是"店主"）
- **动机可见**：NPC有明确目标/立场，不是工具人
  - 商贩：利益驱动+本地物价+市场动态
  - 居民：地区文化+生活态度+对势力看法
  - 雇佣/军人：专业背景+任务经验+世界观立场
  - 逃亡者/流浪者：创伤+求生状态+信息价值
- **记忆点**：NPC与主角的互动留下痕迹（后续可呼应）

**NPC类型与执行示例：**

| 类型 | 动机 | 对话特点 | 示例 |
|------|------|---------|------|
| 商贩 | 利益驱动，反映市场动态 | 价格变动、供需关系、行情传闻 | "上周三十，这周五十。老欠那边也不容易，他涨价了。" |
| 居民 | 体现地区文化+对势力看法 | 生活态度、舆论、流言 | "祭司今天又来巡逻了，有人见到他盯着灵站。" |
| 军人 | 专业背景+任务经验 | 术语、经验分享、世界观立场 | "兽潮的频率不对，这次是冲着灵站来的。" |
| 逃亡者 | 创伤+求生+信息价值 | 谨慎、回避、试探 | "我不问你从哪来，你也别问我去哪。" |

**示例**：
```
"陈三，又来？"老欠的店主抬头，手还擦着台面。"灵站又加量了？"
"嗯。"沈野把袋子放地上。
"上周三十，这周五十。"店主摇头，从架下摸出一份清单。"老欠那边也不容易，他涨价了。"
```

### 2.5 分支事件触发（🔴 强制执行）

**大纲是主干，必须扩展枝干：**

- **分支事件字数占每章15%-25%（强制）**
- **分支类型**：
  - 日常闲聊：路人谈话/邻里互动/集市偶遇
  - 世界观观察：看到灵能公告栏/集团巡逻队/异灵传闻
  - 环境细节：天气变化/动物行为/建筑特色
  - 人物小冲突：误会/争执/合作解决
  - 过渡填充：空间移动/时间流逝/准备动作
  - 支线目的：不推动主线，但丰富世界、铺垫人物、建立氛围

**分支事件示例（以第1章为例）：**
- 路边偶遇其他拾荒者交换情报
- 灵站公告栏看到兽潮预警
- 集市角落黑市交易灵晶的对话
- 观察矿工排队领装备的场景
- 沈念和邻居小孩玩闹的片段

**执行原则：**
- 分支与主线自然过渡，不突兀切入
- 分支必须涉及人物互动或世界观展示
- 分支事件要体现生活质感，不能只是填充

### 2.7 字数分段控制（🔴 强制）

- **最低字数**：2500字（不含标点）
- **目标字数**：2800-3500字
- **写作中每约500字暂停一次**，检查当前字数：
  - 如当前字数 < 2500 且接近大纲结尾：警告"字数不足，需扩展日常场景/NPC互动"
  - 如当前字数 > 3500 且大纲未完：警告"大纲未完但字数已超，考虑拆分为第X章上+第X章下"
- **字数强制**：最终字数必须 ≥ 2500，否则拒绝存盘

## Step 3: 🔒 状态同步（强制执行）

**写作完成后必须执行质量检查，未完成则拒绝存盘。**

### 3.1 质量检查清单

| 检查项 | 标准 | 未达标处理 |
|--------|------|----------|
| ✅ 事件完整性 | 大纲列出的所有事件是否全部展开 | 补充未完成事件 |
| ✅ 事件类型 | 5种事件类型是否合理混合 | 调整事件类型分布 |
| ✅ 分支事件 | 是否有1-2个大纲外的分支事件，占15%-25% | 增补分支内容 |
| ✅ 场景搭建 | 每个场景是否有100-200字五感铺垫 | 补充感官描写 |
| ✅ 世界观植入 | 至少3个世界观元素自然融入 | 自然植入设定 |
| ✅ NPC出场 | 至少2个新NPC有动机背景 | 增强NPC深度 |
| ✅ 人物鲜活 | 主要角色是否有微表情/动作细节，禁用直白情绪词 | 修改描写方式 |
| ✅ 口头禅 | 主要角色是否有1-2个口头禅自然出现 | 植入口头禅 |
| ✅ 字数达标 | 总字数是否 ≥ 2500字 | 扩展内容或拆章 |
| ✅ 线索埋设 | 伏笔是否标记（F1/F2...），是否填写foreshadow_plant | 补充伏笔标记 |
| ✅ 人物关系 | 互动是否体现关系变化（信任/怀疑/依赖） | 调整互动细节 |

### 3.2 数据库同步

```
1. writing_finish(chapter_id, summary, key_events, characters_involved, new_foreshadows, resolved_foreshadows, ability_level, location, timeline_events)
2. timeline_add() → 添加本章时间线事件
3. character_update() → 更新人物状态（位置/装备/心理状态）
4. relation_create/update() → 更新人物关系
5. foreshadow_plant() → 埋设新伏笔
6. foreshadow_recall() → 回收已埋伏笔
7. dimension_log() → 记录维度变化
8. 角色蒸馏 → 为本章出场的主要角色创建蒸馏文件：
   ```
   novels/{小说名}/设定/角色蒸馏/{角色名}-V{卷号}CH{章号}.md
   ```
   内容：本章中该角色的行为变化/关系变化/新信息/下章状态预判（3-5行即可，用于下章写作速查）
```

**输出格式：**
- **summary**：本章摘要（300-500字）
- **key_events**：关键事件列表（3-5条）
- **characters_involved**：出场人物列表
- **new_foreshadows**：新埋设伏笔（F编号+描述+计划回收章节）
- **resolved_foreshadows**：已回收伏笔（F编号+回收方式）
- **timeline_events**：时间线事件（event_time/event_order/event_description）

### 3.3 拒绝存盘条件

出现以下任一情况，拒绝存盘：
- 总字数 < 2500字
- 大纲事件未完成且无合理拆分方案
- 缺少世界观植入（少于3个元素）
- 缺少NPC出场（少于2个有动机的NPC）
- 场景搭建缺失（五感描写不足）
- 人物描写直白（使用"惊讶""愤怒地说"等直白情绪词）
- 分支事件缺失（字数占比<15%）
