# 状态追踪引擎（受伤 + 物品 + 能力变化）

> **用途**: 定义写作时角色状态变化的标准规则
> **触发时机**: Step 2 写正文时参考（受伤/物品变化场景）、Step 3 状态同步时强制执行
> **数据来源**: novel-db character.status JSONB 字段
> **归属**: novel-chapter-writer skill 系统（写作执行规范）

---

## 一、受伤追踪

### 1.1 数据结构（character.status.injuries数组）

```json
{
  "id": "{角色缩写}-INJ{N}",
  "type": "切割伤/抓伤/灵能灼烧/灵能过载/骨折/淤青/扭伤/内伤/...",
  "location": "具体部位",
  "severity": "轻/中/重/危",
  "source_chapter": 12,
  "source_event": "T2灵能爪擦过",
  "description": "棉衣从胸口到右肩被撕开，红色痕迹，血珠冒出",
  "healing_status": "新伤/恢复中/基本恢复/已痊愈",
  "healing_timeline": "3-5天结痂/7-10天恢复",
  "expected_full_recovery_chapter": 18,
  "affects": ["右臂活动受限", "穿衣不便"],
  "resolved": false
}
```

### 1.2 严重度→恢复时间线标准

| 严重度 | 类型示例 | 自然恢复时间 | 后续表现要求 | 章节体现 |
|--------|---------|------------|------------|---------|
| **轻** | 皮外伤/擦伤/轻度淤青/轻微灵能灼烧 | 1-3天 | 短期疼痛/不影响行动 | 下1-2章有疼痛提及→之后消退 |
| **中** | 深度切割/灵能灼烧(面积<手掌)/扭伤/轻度骨折 | 5-10天 | 行动受限/需包扎/疼痛持续 | 2-3章内行动受限→逐步好转→结痂 |
| **重** | 骨折/大面积灵能灼烧/内伤/深度撕裂/关节损伤 | 15-30天 | 需专业治疗/明显跛行 | 4-6章持续影响→需治疗场景才能好转 |
| **危** | 致命伤/灵能侵蚀内脏/断肢/大量失血 | 需灵能修复 | 无法行动/不治疗会死 | 直到获得专业治疗前持续严重 |

### 1.3 灵能相关特殊伤

| 伤型 | 来源 | 特点 | 恢复方式 |
|------|------|------|---------|
| 灵能灼烧 | T2+灵能爪/灵能冲击 | 灰色伤痕/边缘发黑/不易结痂 | 比普通切割慢1.5-2倍 |
| 灵能过载 | 共振超限/碎片信息冲击 | 神经性（手抖/头痛/感知过敏） | 数小时到2天自然消退 |
| 灵衰症恶化 | 灵能沉积加速 | 系统性（指尖灰扩大/体力下降） | 不可逆/只能延缓/需灵能修复治疗 |

### 1.4 外环医疗条件

- **聚落急救**：草药+布条包扎+碎灵晶止血（只能处理轻伤）
- **灵站医务**：灵能绷带+基础灵能修复（可处理中度伤，收费）
- **镇医院**：正规灵能医疗设备（可处理重伤，需身份牌或高额费用）
- **内环集团医院**：灵能修复完整治疗（需三级身份牌）

## 二、物品/装备追踪

### 2.1 数据结构（character.status.inventory字段）

```
"inventory": "刮刀(完好)/碎渣弹(剩余3颗)/灵能短刀(灵能耗尽)/碎罗盘(已碎,保留碎片)/背包(被划破)/干粮(2天份)/五层嵌套碎片(发热中)"
```

### 2.2 消耗品追踪

| 物品 | 典型携带量 | 消耗速率 | 补充来源 |
|------|-----------|---------|---------|
| 碎渣弹 | 5-10颗 | 每次战斗1-3颗 | 市集购买/拾荒获取 |
| 灵能碎渣仓 | 1仓 | 持续消耗/可充能 | 灵站充能(收费) |
| 干粮 | 3-5天份 | 每天消耗 | 市集/聚落补给 |
| 碎灵晶 | 拾荒随机 | 按需使用 | 拾荒/战斗获取 |
| 照明石 | 1-2块 | 缓慢消耗灵能 | 市集购买 |

### 2.3 装备损毁追踪

| 状态 | 含义 | 后续处理 |
|------|------|---------|
| 完好 | 正常使用 | 无 |
| 磨损 | 功能正常但有损耗描写 | 可继续用/需要维护 |
| 损坏 | 功能受损但仍可用 | 需要修复/性能降低 |
| 碎裂 | 不可使用 | 可保留碎片(情感价值)/需替换 |
| 丢失 | 不在角色身上 | 后续能否找回/需替换 |

## 三、能力变化追踪

> **注意**: 能力变化由大纲剧情确定，人物系统记录。此处仅定义追踪格式。

### 3.1 数据结构（character.status.ability_changes数组）

```json
{
  "id": "{角色缩写}-ABI{N}",
  "type": "觉醒/提升/质变/削弱/封印",
  "source_chapter": 25,
  "source_event": "禁地核心共鸣",
  "description": "灵能铸造从'模拟'进入'设计'阶段",
  "before": "只能模拟已有灵能结构",
  "after": "能自主设计新灵能回路",
  "affects_combat": true,
  "affects_crafting": true,
  "permanent": true
}
```

### 3.2 变化类型定义

| 类型 | 含义 | 示例 |
|------|------|------|
| **觉醒** | 首次获得能力 | 沈野V1首次触发拓印 |
| **提升** | 能力等级/范围增强 | 方岩感知范围从10米扩到30米 |
| **质变** | 能力性质改变 | 蔓V7从编物理结构变为编灵能本身 |
| **削弱** | 能力下降 | 陆沉过度使用分解导致生命力损耗 |
| **封印** | 能力暂时/永久失效 | 灵枢震域内能力被压制 |

## 四、写作时状态检查清单

### 4.1 受伤一致性检查

- [ ] 新伤是否标记了 source_chapter 和 source_event？
- [ ] 严重度是否符合恢复时间线？
- [ ] 旧伤在后续章节是否有合理体现（疼痛/行动不便）？
- [ ] 医疗条件是否符合当前地点？
- [ ] 灵能特殊伤是否有对应描写（灰痕/手抖等）？

### 4.2 物品一致性检查

- [ ] 消耗品数量是否随使用递减？
- [ ] 装备损毁是否有前置事件？
- [ ] 新物品获取是否有来源说明？
- [ ] 物品状态是否影响角色行动？

### 4.3 能力变化检查

- [ ] 变化是否有充分前因？（禁止"因为剧情需要"）
- [ ] 变化是否符合锁定设定中的能力体系规则？
- [ ] 变化后是否有适应期/副作用描写？
- [ ] 变化是否同步更新到 character.status？

## 五、Step 3 同步规则

### 5.1 同步到 DB

```python
# 受伤同步
character_update(
    character_id=id,
    status={
        "injuries": [...],  # 完整数组，包含新旧伤
        "inventory": "...",  # 更新后的物品清单
        "ability_changes": [...]  # 新增变化追加到数组
    }
)
```

### 5.2 同步到角色蒸馏文件

```
novels/{小说名}/设定/角色蒸馏/{角色}-V{卷}CH{章}.md
```

记录本章该角色的状态变化快照。
