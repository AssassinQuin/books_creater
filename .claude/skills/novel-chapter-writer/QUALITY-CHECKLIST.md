# QUALITY-CHECKLIST.md — 内容丰富度检查 + 字数控制

> 本文档是 novel-chapter-writer Step 2.6-2.7 的详细指令。

## 2.6 内容丰富度检查（18项强制）

### 基础丰富度（14项）

| 检查项 | 要求 |
|--------|------|
| 章节结构 | 使用了合适变体（非全部标准起承转合） |
| 结构变化 | 近5章至少2种不同变体 |
| 章末钩子 | 有钩子或确认是日常型 |
| 爽点密度 | 本章至少1个微/小爽点 |
| 信息缺口 | 至少1个（5W） |
| 日常事件 | 2-3个日常场景 |
| NPC出场 | 至少2个有动机的新NPC |
| 场景搭建 | 每场景五感氛围铺垫 |
| 世界观展示 | 至少3个元素自然融入 |
| 人物性格 | 微表情/动作展示（禁直白词） |
| 分支事件 | 占15%-25%字数 |
| 4层内容 | A40-50%+B25-30%+C15-20%+D5-10% |
| 反注水 | 无孤立感官/无因果过渡/无重复意象（→见 references/scene-deepening-guide.md） |
| 场景密度 | 每3段至少1段"同时做2+件事" |

### 🔴 AI指纹检查（4项强制，V2.0 新增）

> 详细检测规则见 `references/ai-fingerprint-detection.md`

| 检查项 | 要求 | 拒绝存盘阈值 |
|--------|------|-------------|
| FP-1 句号切割法 | 连续独立短句≤2个，全章占比≤15% | >20% 或存在3+连续短句段落 |
| FP-2 解释式展示 | 设定首次出现不紧跟解释，全章≤3次 | >5次 或设定出现即解释 |
| FP-3 结构对称 | 场景间段落长度方差>20%，切入方式轮换 | 方差<15% 或连续3场景同模板 |
| FP-4 否定转折 | "不是X，是Y"全章≤2次 | >4次 或连续段落重复 |

**AI指纹不通过 = 拒绝存盘**，必须修改后重新检查。

## 2.7 字数分段控制（强制）

- **最低**: 3000字（不含标点）
- **目标**: 3000-5000字
- 每500字暂停检查字数
- 不足3000时用场景深化技法（→见 `references/scene-deepening-guide.md`），禁止注水
- 超过5000时考虑拆章
