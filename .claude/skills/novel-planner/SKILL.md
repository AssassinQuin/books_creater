## 强制流程

```
Step 0: 断点检测 → volume_list + chapter_list，避免重复设计
Step 1: 全书总纲（首卷必做）→ 🔒确认

Step 5: 双通道保存（DB + 文件）+ 跨卷伏笔对齐

## Step 0: 断点检测

调用 `volume_list(novel_id)` + `chapter_list(novel_id, status='planned')` 检查已有数据，避免重复设计。

## 调研注入：大纲级方法论（强制）

以下方法论来自 2026-05-15 大纲剧情设计深度调研，全书规划必须遵守。

### 起承转合循环嵌套（强制）

全书结构必须按起承转合四段设计，每卷内部同样嵌套四段：

```
全书: 起(V1-V2) → 承(V3-V6) → 转(V7-V10) → 合(V11-V14+尾声)
每卷: 起(10-15%) → 承(40-50%) → 转(20-25%) → 合(10-15%)
每章: 起(开篇钩子) → 承(发展) → 转(小反转) → 合(收束+下章钩子)
```

Step 2 逐卷规划时，必须将事件分配到四段中，标注每段占比。

### 伏笔五级分类（强制）

| 级别 | 回收周期 | 管理方式 |
|------|---------|---------|
| 章级 | 同章内 | 写作时自觉 |
| 卷级 | 同卷内 | 细纲标注 |
| 跨卷 | 1-3卷后 | 伏笔登记表 |
| 全书 | 5卷+后 | 大纲固定 |
| 烟雾弹 | 故意不回收 | 登记表标注"烟雾弹" |

**积压上限**: 未回收伏笔不超过总埋设量的 30%。每卷至少埋 2 个新伏笔 + 回收 1 个旧伏笔。
Step 5 伏笔对齐时，必须检查积压率。

### 支线三检验（强制）

每条支线加入大纲前，必须通过三个检验：

1. **删除检验**: 删除这条支线，主线还能成立吗？（能=支线，不能=这是主线一部分）
2. **独立阅读检验**: 只看这条支线，读者能获得完整叙事满足吗？（能=好支线）
3. **主题检验**: 这条支线是否呼应全书主题？（是=好支线，否=噪音）

Step 2.5 支线设计时，每条支线标注三检验结果。

### 人物弧光对齐（强制）

| 弧类型 | 适用角色 | 与剧情对齐规则 |
|--------|---------|---------------|
| 变化弧 | 主角/重要配角 | 催化事件=激励事件同侧面，蜕变点=剧情高潮同步，挣扎期=全书40-60% |
| 扁平弧 | 导师/精神支柱 | 角色不变但改变周围世界 |
| 幻灭弧 | 悲剧角色/反派 | 相信→怀疑→否定，用于反派深度 |

Step 1 全书总纲中，为每个核心角色标注弧类型和蜕变点所在卷。
群像角色的蜕变点必须分散在不同卷，避免同卷多角色同时质变。

### 悬念五种"未知"轮换（强制）

每卷至少维持 1 个信息缺口，五种类型卷间轮换：谁/为什么/怎么/什么时候/会怎样。
回答旧"未知"的同时必须提出新"未知"。

## Step 2: 逐卷规划

### 2.1 环境先行

识别本卷主要场景(2-5个) → `engine_detail('environment')` 查看5要素 → `world_upsert(category='location')` → 再规划事件。

### 2.2 事件设计：四大要素

每设计一个事件（无论大小），必须同时回答四个问题：

```
1. 因为什么？（前因）
   ├─ 上一事件的后果 → 因果链传递
   ├─ 世界观规则压迫 → 系统施加压力
   └─ 角色内在动机 → 性格驱动的选择

2. 所以什么？（后果——必须留下未闭合尾巴）
   ├─ 信息增量 | 状态改变 | 关系变化
   ├─ 物资消耗 | 定时炸弹
   └─ 不能解决问题，只能转移/升级问题

3. 逼出什么？（角色选择——没有完美选项）
   ├─ 轻: 选A或B差别不大
   ├─ 中: 各有代价
   ├─ 重: 无论选什么都没好结果
   └─ 不可逆: 选了就回不了头

4. 什么没变？（世界呼吸）
   └─ 事件发生时，世界大部分仍在正常运转
```

因果链连接格式：
```
D{N}: {事件名}
- 因为: {前因}
- 所以: {直接后果}
- 逼出: {角色被迫做的选择}
- 雪球: {这个选择将引发的下一个后果}
- 没变: {此时世界正常运转的一个细节}
```

### 2.3 微事件设计（每章 ≥6 条）

**费笔(≥2条/章)**: 不回收·不解释·不呼应·一次性。类型: 边缘人/环境细部/声音碎片/动物/日常故障。每个 ≤2 句。

**日常(≥2条/章)**: 三层递进——表层(展示生活环境) → 中层(暗示社会规则) → 深层(透露系统压力)。植入优先级: 角色动作 > 对话 > 环境描写 > 内心独白。

**世界呼吸(≥2条/章)**: 展示世界独立运转——系统运作/远处活动/他人生活/历史痕迹/自然力量。

### 2.4 超级事件设计

超级事件 = 3-5 个大事件因果链锁在一起，缺一环不成立。

**何时该有**: 认知推翻卷(必出) / 团队转折卷(必出) / 揭示卷(推荐) / 普通推进卷(不必)。

**三步因果链熔合法**:
1. 识别叙事核心——读者读完这卷会记住的一件事
2. 拆解为[触发→升级→高潮→后果]四个阶段
3. 检查因果锁链——每个阶段是上一个的"所以"，不能只是"然后"

超级事件占全卷 40-50%。检查: 因果锁链 ✅ / 节奏梯度 ✅ / ≥3角色独立行动 ✅ / 不可逆后果 ✅。

### 2.5 支线设计

支线类型: 连续支线(≥3卷) / 独立章(1章) / 世界呼吸(散落) / 跨卷慢线(全书)。

每卷安排 1-2 个支线节点。不在 POV 内的支线角色每卷至少出现 1 次。不出场角色每卷留 1 个"他在那"的痕迹。

### 2.6 事件层级与章节组合

| 章类型 | 事件占比 | 适用位置 |
|--------|---------|---------|
| 推进章 | 线索推动40%+人物关系30%+展示20%+伏笔10% | 主线推进点 |
| 日常章 | 场景铺垫30%+人物展示30%+线索推动20%+费笔20% | 建立期 |
| 过渡章 | 人物关系40%+线索推动30%+展示20%+费笔10% | 消化/准备期 |
| 高潮章 | 线索推动50%+人物关系30%+伏笔10%+世界呼吸10% | 卷内高潮 |

每卷规划确认后，逐章设计。对每章产出：

```

  - 时间: D{N} 时间段
  - 场景: 地点1 → 地点2 → 地点3
  - 核心事件(因果链): 因为{前因} → 所以{后果} → 逼出{角色选择}
  - 出场角色: 主视角、角色A(初遇)、角色B(背景)
  - 新增微事件(≥6条，分类标注):
    · 费笔(≥2): 不回收不解释的纯世界纹理
    · 日常(≥2): 日常生活细节/习惯/物价/饮食
    · 世界呼吸(≥2): 势力痕迹/独立运转/他人生活
  - 关键描写: 需要重点描写的画面
  - 世界观展示(刑具化): 本世界观规则如何对角色施压

## Step 4: 卷级检查清单（10项）

| # | 检查项 | 通过标准 |
|---|--------|---------|
| 1 | 因果密度 | 每章 ≥1 个"因为…所以…逼出…"因果链 |
| 2 | 可替换性测试 | 任意两个相邻事件不能调换顺序 |
| 3 | 可删减性测试 | 删除任意事件会导致逻辑链断裂 |
| 4 | 雪球累积 | 后果强度逐章递增 |
| 5 | 世界观刑具化 | 每章 ≥1 次世界观规则对角色施压 |
| 6 | 微事件多样性 | 每章 ≥6 条，费笔/日常/世界呼吸各 ≥2 |
| 7 | 伏笔间距 | 埋设→提起 ≤3 卷，提起→回收 ≤3 卷 |
| 8 | 不出场痕迹 | 无角色超过 2 卷无任何痕迹 |
| 9 | 追读钩子 | 卷尾有未解决的悬念驱动下一卷 |
| 10 | 选择重量 | 重大选择有不可逆后果 |

## 读者体验设计（全卷总纲）

> 这是与"因果链/事件层级"并列的核心维度。结构正确但读得难受=失败。

### POV锚点原则（铁律）

**默认视角**: 第三人称·主角限知视角（全书以沈野为POV锚点），读者知道的不超过沈野知道的。

**他人视角的允许条件**（以下三者缺一不可）：
1. **该事件无法通过主线传递**（即沈野不可能知道/看到/推理出）
2. **该事件本身极其精彩**，读者错过会后悔
3. **该事件对全书情绪弧线至关重要**

**他人视角的数量上限**：全书中他人视角独立场景 ≤ 5 处，每处 ≤ 500字。

**允许的切视角场景**（本书）：
| 卷 | 切谁 | 为什么切 | 字数 |
|----|------|---------|:----:|
| V3 | 韩朗·47天 | 不切则全书最长支线失去因果 | ≤300字 |
| V7 | 韩朗·叛逃 | 这是V1-V7弧线收束瞬间 | ≤500字 |
| V12 | 虞渊·第一次正面出现 | 400年沉默结束，必须从虞渊视角写 | 整段 |

**禁止的切视角模式**：
- ❌ V6三线并行（每线独立章节）→ 应改为沈野收到方岩来信/听说汐的消息
- ❌ V8主视角切汐 → 应沈野视角，汐的觉醒通过沈野观察展现
- ❌ V10主视角切陆沉 → 应沈野视角，陆沉禁地经历通过回归后讲述展现

### 主线承载所有（铁律）

所有支线/他人故事通过以下方式融入主线：

| 方式 | 例子 | 适用 |
|------|------|------|
| 传信/对话中提及 | "方岩托人带话，说他在北境见到了赵铁山" | 日常信息传递 |
| 沈野主动打听 | 沈野问江屿"你以前在灵枢做什么的" | 关系推进型 |
| 环境痕迹 | 灵站墙上有韩朗的签名,旁边有项目编号 | 暗线暗示 |
| 事后讲述 | 陆沉回来后说"禁地里七座塔，每一座都是一个人" | 重要事件回顾 |

**绝对禁止**：为展示世界观而切视角（世界观通过主线动作展示）。

### 每卷情绪锚点

每卷必须定义 **一个核心情绪**（且只一个），全卷所有事件服务于这个情绪：

| 卷 | 核心情绪 | 读者在读什么 |
|----|---------|-------------|
| V1 | **紧迫** | 妹妹要死了，必须走 |
| V2 | **扩展** | 世界比想象中大，有人可以信任 |
| V3 | **痛** | 第一次正面打，输了，要分开 |
| V4 | **崩塌** | "我信的一切都是假的" |
| V5 | **怀疑** | 这个组织能信吗？ |
| V6 | **焦灼** | 答案在靠近，但怎么都对不上 |
| V7 | **绝望** | 没有好人。没有正义的一方。 |
| V8 | **悲伤→决心** | 有人没回来，但必须继续走 |
| V9 | **分离** | 团队散了，各自的路 |
| V10 | **和解** | 不是复仇，是理解 |
| V11 | **愤怒→沉默** | "一个人可以被用到什么程度" |
| V12 | **震撼→理解** | 不是一个人在操控，是两个人在下棋 |
| V13 | **告别** | 虞渊走了，旧时代结束了 |
| V14 | **温暖** | 不是更强，是不孤独 |

**检查规则**：如果一盖章的第 3 节和第 7 节让读者产生不同的核心情绪，说明这章塞了太多东西。

### 节奏控制

每卷必须有明确的"呼吸空间"——连续高压的章节数 ≤ 3 章，之后必须接 1-2 章慢节奏（日常/旅途/对话/心理）。

| 节奏模式 | 适用 | 示例 |
|---------|------|------|
| 紧→松→紧→松（交替） | 大部分卷 | 战斗→休整对话→追逃→营地夜话 |
| 松→紧（铺垫到高潮） | 收束卷 | V8前期重建关系→后期影牺牲 |
| 紧→松（高潮到余韵） | 情感卷 | V7星火社崩塌→蔓离开/韩朗融入 |

**禁止**: 连续 3 章以上高强度事件而不给读者消化时间。

### 信息投放节奏

读者对重要信息的承受节奏：
- 每卷 **核心新信息** ≤ 3 条（指"改变读者世界观认知"的信息）
- 超过 3 条 → 读者信息过载，记不住，也感受不到每条的分量

示例(V4)：核心信息只有 2 条——①灵衰症是系统副作用（认知推翻）②沈念"那其他人呢"（弧线转折）。其他都是这两条的铺垫和后果。

**检查规则**: 列出一卷中"如果没有这一条信息，读者对世界的理解不受影响"的信息。抹掉它们。那是噪音。

## 环境先行设计
