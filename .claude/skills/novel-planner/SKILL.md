## 章节大纲设计

每卷规划**确认后**，进入章节大纲设计，按以下4步执行：

### Step 1: 逐章设计（循环所有章节）

对本章每个章节，设计完整信息：

```
章节概览: Ch{N} {标题}（{第几幕}·{章节类型}）
  - 时间: D{N} 时间段
  - 场景: 地点1 → 地点2 → 地点3
  - 核心事件(因果链): 因为{前因} → 所以{后果} → 逼出{角色选择}
  - 出场角色: 主视角、角色A(初遇)、角色B(背景)
  - 新增微事件(≥6条，分类标注):
    · 费笔(≥2): 不回收不解释的纯世界纹理
    · 日常(≥2): 日常生活细节/习惯/物价/饮食
    · 世界呼吸(≥2): 势力痕迹/独立运转/他人生活
  - 关键描写: 需要重点描写的画面
  - 世界观展示(刑具化): 本世界观规则如何对角色施压
  - 伏笔: F{N}+F{N+1}（埋设+回收）
  - 角色状态: 各角色起止状态
  - 字数: 预估字数范围
```

### Step 2: 保存到 DB

```
# 先创建/更新章节
chapter_plan(novel_id, number=N, title="标题", outline="核心事件摘要", chapter_type="normal", volume_id=V)

# 再创建场景清单（每章1-5个场景）
scene_create(chapter_id, scene_number=1, location="地点", characters_involved=["角色"], conflict="冲突描述", emotion_type="紧张/舒缓/悲伤", key_beats=["拍1", "拍2"], notes="备注")
```

**注意**：`chapter_plan` 返回 `id` → 用此 `id` 调 `scene_create`

### Step 3: 🔒 用户确认全部章节后 → 文件落盘

将所有章节组装为一个 Markdown 文件，写入：

```
novels/{小说名}/设定/章节大纲/V{卷号}-{卷名}-事件大纲.md
```

文件格式见下方模板。**不输出文件 = 流程未完成。**

### Step 4: git commit

```
B1: {卷名} 事件大纲完成
```

### 新增: 支线设计四步法

**第一步: 确定支线类型**
| 类型 | 定义 | 跨度 |
|------|------|------|
| 连续支线 | 跨越多卷的配角弧线 | ≥3卷 |
| 独立章 | 单章完成的配角时刻 | 1章 |
| 世界呼吸 | 势力痕迹/日常/费笔 | 散落各章 |
| 跨卷慢线 | 每卷1-2次但跨度极长 | 全书 |

**第二步: 每卷安排1-2个支线节点**
- 不在POV内的支线角色（韩朗/牧师/陈启明），每卷至少出现1次
- 出现方式: 正章 / 他人观察 / 传信 / 系统日志 / 环境痕迹

**第三步: 每个支线节点记录**
```
角色: 韩朗 | V1节点 | 方式: 沈念视角
做了什么: 标记"高产出源·稳定·维护优先"
隐性影响: 灵站监控系统开始运作
留下什么: 系统语言定义的关系模式
```

**第四步: 不出场角色痕迹**
- 不出场≠不存在。每卷至少留1个"他在那"的痕迹
- 痕迹要有推进——不是重复同一状态
- 痕迹要服务于主线的隐性因果

### 环境先行: 识别本卷主要场景(2-5个) → `engine_detail('environment')` 查看5要素 → `world_upsert(category='location')` → 再规划事件

### 因果逻辑: `engine_detail('causality')` 查看因果大纲法 → 每事件必须有前因后果

## 事件设计核心: 四大要素

每设计一个事件（无论大小），必须同时回答四个问题：

```
1. 因为什么？（前因）
   ├─ 上一事件的后果 → 因果链传递
   ├─ 世界观规则压迫 → 系统施加压力
   └─ 角色内在动机 → 性格驱动的选择

2. 所以什么？（后果——必须留下未闭合尾巴）
   ├─ 信息增量 | 状态改变 | 关系变化
   ├─ 物资消耗 | 定时炸弹
   └─ 不能解决问题，只能转移/升级问题

3. 逼出什么？（角色选择——没有完美选项）
   ├─ 轻: 选A或B差别不大
   ├─ 中: 各有代价
   ├─ 重: 无论选什么都没好结果
   └─ 不可逆: 选了就回不了头

4. 什么没变？（世界呼吸）
   └─ 事件发生时，世界大部分仍在正常运转
```

**因果链连接格式**:
```
D{N}: {事件名}
- 因为: {前因}
- 所以: {直接后果}
- 逼出: {角色被迫做的选择}
- 雪球: {这个选择将引发的下一个后果}
- 没变: {此时世界正常运转的一个细节}
```

## 微事件设计: 费笔/日常/世界呼吸

### 费笔(≥2条/章)
**四特征**: 不回收·不解释·不呼应·一次性
**常用类型**: 边缘人 / 环境细部 / 声音碎片 / 动物 / 日常故障
**铁律**: 每个不超过1-2句，不承载信息增量

### 日常(≥2条/章)
**三层递进**:
- 表层: 展示生活环境（动作/物品/话）
- 中层: 暗示社会规则（习惯/默契/潜规则）
- 深层: 透露系统压力（物价/表情/传言）

**植入优先级**: 角色动作 > 对话 > 环境描写 > 内心独白

### 世界呼吸(≥2条/章)
**展示世界独立运转**: 系统运作 / 远处活动 / 他人生活 / 历史痕迹 / 自然力量
**与费笔区别**: 费笔是纯纹理，世界呼吸暗示结构

### 伏笔间距规则
| 规则 | 标准 |
|------|------|
| 埋设→提起 | ≤3卷 |
| 提起→回收 | ≤3卷 |
| 长跨卷伏笔(6卷+) | 中间卷至少2次"提起"节点 |
| 提起方式 | 角色回忆/环境触发/外部事件/别人提起 |

## 卷级检查清单（10项）

设计完成后逐项检查：

| # | 检查项 | 通过标准 |
|---|--------|---------|
| 1 | **因果密度** | 每章≥1个"因为…所以…逼出…"因果链 |
| 2 | **可替换性测试** | 任意两个相邻事件不能调换顺序 |
| 3 | **可删减性测试** | 删除任意事件会导致逻辑链断裂 |
| 4 | **雪球累积** | 后果强度逐章递增，不匀速 |
| 5 | **世界观刑具化** | 每章至少1次世界观规则对角色施压 |
| 6 | **微事件多样性** | 每章≥6条微事件，费笔/日常/世界呼吸各≥2 |
| 7 | **伏笔间距** | 埋设→提起≤3卷，提起→回收≤3卷 |
| 8 | **不出场痕迹** | 无角色超过2卷无任何痕迹 |
| 9 | **追读钩子** | 卷尾有未解决的悬念驱动下一卷 |
| 10 | **选择重量** | 重大选择有不可逆后果 |
