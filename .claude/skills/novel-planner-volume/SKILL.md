# 卷级章节设计

> 根据 novel-planner 确定的"每卷做什么"，设计"每章发生什么"。包含事件设计、世界元素注册、声音适配。

<what-to-do>

## 强制流程

```
Step 0: 加载全书框架 → 加载本卷目标 → MCP数据采集
  ↓
Step 1: Agent 1 — 场景设计师 → 环境先行+场景清单+感官分配
  ↓
Step 2: Agent 2 — 事件架构师 → 因果链+超级事件+支线+人物弧光
  ↓  🔒检查点A: 确认事件架构
Step 3: Agent 3 — 章节设计师 → 逐章大纲+微事件+伏笔分配+声音适配
  ↓
Step 4: Agent 4 — 世界元素注册师 → 注册新元素(地点/NPC/物品/能力/概念)
  ↓  🔒检查点B: 确认元素注册
Step 5: Agent 5 — 卷级验证器 → 10项卷级检查
  ↓  🔒检查点C: 确认验证通过(P0必须修复)
Step 6: 双通道保存(DB+文件) + 更新世界元素索引
Step 7: 🔒用户确认 → git commit
```

## 编排器职责

只负责：**MCP调用 + Agent启动 + 检查点确认 + 保存 + 世界元素注册**。不直接设计事件。

## Step 1: Agent 1 — 场景设计师

### 输入
- 本卷目标+核心事件类型
- 世界观数据（能力体系/势力分布/经济系统）
- 已有场景列表（world_query）

### 指令文件
`agents/scene-designer.md`

### 输出
- **场景清单**（2-5个）：
  - 每个场景含环境5要素（视觉/听觉/嗅觉/触觉/温度）
  - 场景与卷目标的关联
  - 场景间的空间关系
- **感官分配表**：每章主导感官（避免单一感官疲劳）
- **新场景需求**：需要创建的新地点列表

### 输出验证
- [ ] 场景数量2-5个，不重复
- [ ] 每个场景有完整5要素
- [ ] 场景与卷目标直接相关

## Step 2: Agent 2 — 事件架构师

### 输入
- Agent 1 的场景清单
- **本卷角色完整档案**（character_get 批量，含外观/性格/说话风格/能力/状态/关系/物品/恐惧/目标）
- **角色关系网**（relation_list）
- **世界观约束**（能力体系/经济系统/社会规则）
- **作者声音定义**（叙事声音指纹）
- 卷定位（起/承/转/合，由卷号判断）

### 指令文件
`agents/event-architect.md`

### 核心职责

**融入世界观设计事件**：
- 事件必须**从世界观中生长出来**，不是"剧情需要"
- 每个事件问："这个世界里，什么规则/势力/经济关系导致了这个事件？"
- 事件的结果必须**反作用于世界观**（改变势力格局/经济关系/社会规则）

**融入人物设定设计事件**：
- 事件必须**从人物性格中生长出来**
- 每个事件问："以这个角色的性格/能力/恐惧，他会怎么做？"
- 事件的结果必须**推动人物弧光**（变化/选择/代价）

### 输出
- **卷级起承转合**：
  - 起（10-15%）：建立场景+引入冲突
  - 承（40-50%）：事件推进+角色互动
  - 转（20-25%）：超级事件（如有）+转折点
  - 合（10-15%）：收尾+下卷钩子
- **因果链**（每事件）：
  - 因为：[前因，必须关联世界观规则或人物性格]
  - 所以：[直接后果]
  - 逼出：[迫使角色做出的选择，必须符合其性格]
  - 雪球：[连锁反应，必须关联世界观机制]
  - 没变：[什么没有改变，留下遗憾]
- **世界观互动表**（新增）：
  - 每个事件涉及的世界观规则
  - 事件对世界观的改变（如有）
  - 新暴露的世界观信息（如有）
- **人物弧光对齐**：本卷内角色的变化节点
  - 每个变化节点关联具体事件
  - 变化必须符合角色性格逻辑
- **悬念锚点**：旧未知回答+新未知提出

### 输出验证
- [ ] 起承转合四段完整
- [ ] 每事件有因果链5要素
- [ ] **每事件关联至少1条世界观规则**
- [ ] **每事件关联至少1个人物性格特征**
- [ ] 支线通过三检验
- [ ] 人物弧光有具体节点

## 🔒检查点A: 确认事件架构

编排器展示：

```
【本卷事件架构】V{卷号}《{卷名}》

起(Ch1-Ch2): {事件1} → {事件2}
承(Ch3-Ch7): {事件3} → ... → {事件N}
转(Ch8-Ch10): {超级事件(如适用)} → {事件N+1}
合(Ch11-Ch12): {事件N+2} → 下卷钩子: {悬念类型}

【支线】（三检验结果）
{支线1}: 删除✅ 独立✅ 主题✅
{支线2}: 删除✅ 独立✅ 主题❌ → 建议删除或合并

【人物弧光】
{角色A}: {本卷变化节点}
...

确认后进入章节设计。输入"OK"或修改意见。
```

## Step 3: Agent 3 — 章节设计师

### 输入
- 确认后的事件架构
- 预估章数（本卷字数÷3500-5000字/章）
- 上一卷末角色状态
- 声音适配要求（从卷目标推断：战斗卷→author-voice-battle，情感卷→author-voice-emotion）

### 指令文件
`agents/chapter-designer.md`

### 输出
- **章节映射表**：起/承/转/合 → 章节范围
- **逐章大纲**（每章）：
  - 时间/地点
  - 核心事件
  - 参与角色
  - 微事件（费笔/日常/世界呼吸）
  - 伏笔操作（埋/提/收）
  - 角色状态变化
  - 预估字数
  - **声音适配标记**：该章加载的剧情层声音（battle/emotion/daily/mystery）
- **微事件多样性检查表**：
  - 费笔场景≥2
  - 日常场景≥2
  - 世界呼吸场景≥2
  - 荒诞笑点≥1
  - 突然温暖≥1
- **伏笔分配表**：
  - 新埋伏笔≤2个/章
  - 提起旧伏笔≥1个/章
  - 回收伏笔≥1个/章（本卷内）
- **角色状态追踪表**：每章开始/结束时的角色状态

### 输出验证
- [ ] 每章有明确核心事件
- [ ] 微事件多样性达标
- [ ] 伏笔分配合理（不积压）
- [ ] 声音适配标记与事件类型匹配

## Step 4: Agent 4 — 世界元素注册师

### 输入
- Agent 3 的逐章大纲
- 已有世界元素索引
- 世界观约束

### 指令文件
`agents/world-element-registrar.md`

### 职责
遍历逐章大纲，识别需要注册的新元素：

**新地点**：
- 首次出现的场景
- 有独特感官特征的环境
- 对剧情有重要影响的地点

**新NPC**：
- 有名字且有对话的角色
- 有独特行为模式的角色
- 对主线或支线有推动作用的角色

**新物品**：
- 首次出现的道具
- 有独特功能或来源的物品
- 对剧情有关键作用的物品

**新概念**：
- 首次提及的规则/制度/信仰
- 对世界运转有影响的设定
- 需要后续解释或回收的概念

### 输出
- **新元素清单**（每元素）：
  - 名称
  - 类型（地点/NPC/物品/概念）
  - 首次出现章节
  - 基本定义
  - 感官特征（如有）
  - 比喻可用性（初步）

### 注册流程
编排器根据清单创建文件：
```
novels/{小说名}/设定/世界元素/{类型}/{元素名}.md
```

并更新索引：
```
novels/{小说名}/设定/世界元素/索引.md
```

## Step 5: Agent 5 — 卷级验证器

### 输入
- Agent 3 的逐章大纲
- Agent 2 的事件架构
- Agent 4 的新元素清单

### 指令文件
`agents/volume-validator.md`

### 10项卷级检查

| # | 检查项 | 标准 |
|---|--------|------|
| 1 | 卷目标达成 | 所有章节合力达成卷目标 |
| 2 | 起承转合比例 | 起15%/承50%/转25%/合10% |
| 3 | 因果链完整 | 每章核心事件有前因后果 |
| 4 | 微事件多样性 | 费笔≥2/日常≥2/世界呼吸≥2 |
| 5 | 伏笔节奏 | 新埋≤2/章，提起≥1/章，回收≥1/章 |
| 6 | 人物弧光推进 | 至少1个角色有明显变化 |
| 7 | 声音适配 | 每章有明确的声音层标记 |
| 8 | 世界元素一致性 | 新元素与已有设定不矛盾 |
| 9 | 卷首/卷末钩子 | 承接上卷+引出下卷 |
| 10 | 字数预估合理 | 每章3500-5000字，总字数符合规划 |

### 输出
- 逐项结果（通过/警告/失败）
- 问题分级（P0/P1）
- 总体评估

## 🔒检查点C: 确认验证通过

P0问题→必须修复。修复方式：
- 事件架构层→回到Agent 2修复→重新走Step 3-5
- 章节设计层→回到Agent 3修复→重新走Step 4-5
- 元素注册层→回到Agent 4修复→重新走Step 5

无P0→进入保存。

## 与上下层的关系

- **上层：novel-planner**：提供"每卷做什么"（卷目标/核心事件类型/钩子设计）
- **本层：novel-planner-volume**：根据上层输入，设计"每章发生什么"+注册世界元素
- **下层：novel-chapter-writer**：根据本层输出，生成"正文怎么写"

## 世界元素注册规则

### 注册时机
只在 **novel-planner-volume** 阶段注册，不在 novel-planner 或 novel-chapter-writer 注册。

原因：
- novel-planner 阶段太抽象，无法确定具体元素
- novel-chapter-writer 阶段太具体，容易过度注册
- novel-planner-volume 阶段刚刚好：事件已确定，元素有具体用途

### 注册标准
满足以下任一条件：
- 在事件大纲中被具体描写（有感官细节）
- 被角色提及或使用过（有互动记录）
- 对世界运转有实际影响（经济/生态/社会）
- 有独特的感官特征（气味/声音/触感/视觉）

### 不注册的标准
- 只在对话中提及，无具体描写
- 一次性道具，无后续影响
- 通用概念，无独特设定

## 声音适配规则

### 适配时机
Agent 3（章节设计师）为每章标记声音层。

### 适配逻辑
| 章节事件类型 | 加载声音层 |
|-------------|-----------|
| 战斗/动作 | author-voice-battle |
| 情感高潮/离别/重逢 | author-voice-emotion |
| 日常/世界呼吸/荒诞 | author-voice-daily |
| 悬疑/揭秘/伏笔回收 | author-voice-mystery |
| 混合类型 | 主类型声音层+辅助声音层 |

### 适配输出
声音适配标记写入逐章大纲，novel-chapter-writer 在 Step 3 加载。
