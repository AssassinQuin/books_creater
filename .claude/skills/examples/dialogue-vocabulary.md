## 一、动作卡位词库（按身体部位分类）

**使用原则**：同一角色同一章内，同一动作不得重复两次；优先使用手部+头部组合。

| 部位 | 动作示例 | 变体表达（至少5种） |
|------|---------|-------------------|
| **手部** | 伸手、按住 | 手指点了点、手掌覆上、指尖划过、手指蜷起、手背蹭了蹭、拇指摩挲、手指关节轻叩、手掌摊开、手指交叉、指尖轻触 |
| **头部** | 挑眉、低头、抬头 | 头偏了偏、脑袋微侧、下巴抬了抬、额头抵住、后脑勺靠在、头发晃了晃、眉毛皱起、眉心微蹙、眼角微眯 |
| **身体** | 转身、后退一步、上前一步 | 身体前倾、后背挺直、肩膀耸了耸、腰弯了弯、膝盖微屈、脚尖转向、脚跟碾了碾、身体晃了晃、重心前移 |
| **面部** | 喉结滚动、嘴角抽动 | 脸颊肌肉绷紧、下颌线收紧、嘴唇抿了抿、舌尖抵住上颚、鼻孔微张、眼角抽了抽、额头青筋微跳、太阳穴突突直跳 |
| **腿部** | 脚步骤停、蹲着、站着 | 脚尖点了点地面、脚跟抬起、膝盖碰了碰、腿交叉、腿微微发抖、脚无意义地踢了踢、鞋底蹭了蹭地面 |
| **综合** | 倚着、砸 | 身体斜靠、肩膀撞了一下、手肘撑在、手掌拍在、拳头捶在、手指掐进、手背青筋暴起、整个人僵住 |

## 二、神态词库（按情绪分类）

**使用原则**：同一角色同一章内，同一情绪不得使用相同神态两次；优先眼部+嘴部组合；避免过度使用"眼神"，可换成目光、视线、眼角、瞳孔。

| 情绪 | 核心神态 | 变体表达（至少5种） |
|------|---------|-------------------|
| **委屈** | 眼眶泛红 | 睫毛湿润但无泪、眼角微红、嘴唇微微发抖、下巴收紧（克制不哭）、声音带鼻音、眼神躲闪 |
| **嘲讽** | 嘴角勾起一抹嘲讽的笑 | 眼角微眯、眉毛轻挑、嘴角一侧上扬、眼神斜睨、冷笑一声、鼻腔发出轻哼 |
| **冷漠** | 眼神一暗 | 目光冰冷、眼皮半垂、面无表情、嘴角拉平、眼神没有焦点、脸部肌肉不动 |
| **惊讶** | 眼睛睁大 | 瞳孔收缩、眉毛扬起、嘴巴微张、表情僵住、眼皮快速眨动、身体微微后仰 |
| **愤怒** | 脸色一沉 | 下颌线绷紧、额头青筋微跳、鼻孔微张、眼神锐利、嘴角下拉、脸颊肌肉抽搐 |
| **心疼** | 眼神软下来 | 目光柔和、眉心微蹙、嘴角动了动（想说没说）、眼神在对方身上多停了一瞬、表情复杂 |
| **警惕** | 眼神锐利 | 瞳孔微缩、眼角余光扫视、目光定在某处、眼皮微抬、眼神从散漫变聚焦 |
| **疲惫** | 表情僵住 | 眼神空洞、眼皮沉重、肩膀塌下、脸色苍白、嘴角下垂、目光没有焦点 |
| **害羞** | 垂下眼帘 | 脸颊微红、眼神躲闪、嘴角不自觉上扬、手指无意义地动作、声音变小 |
| **得意** | 挑眉 | 眼角微弯、嘴角上扬、眼神明亮、下巴微抬、表情放松、身体微微前倾 |
| **恐惧** | 表情僵住 | 瞳孔放大、脸色发白、嘴唇发抖、身体微微发抖、眼神飘忽、呼吸急促 |
| **厌恶** | 眉头皱起 | 嘴角下拉、眼神避开、鼻孔微张、表情扭曲、身体微微后仰、声音变冷 |
| **期待** | 眼神亮了一下 | 嘴角不自觉上扬、身体前倾、手指无意义地动作、眼神聚焦、表情柔和 |
| **失望** | 眼神暗了下去 | 嘴角下垂、表情垮下来、眼神空洞、肩膀塌下、笑容消失、目光移开 |
| **倔强** | 咬了咬唇 | 下巴抬起、眼神坚定、嘴角抿紧、拳头攥紧、身体挺直、目光直视对方 |
| **温柔** | 笑了一下（不是笑） | 眼神柔和、嘴角微弯、表情放松、目光在对方身上停留、声音变轻 |
| **尴尬** | 表情僵住 | 嘴角抽搐、眼神飘忽、脸颊微红、手指无意义地动作、声音发干、挠了挠头 |
| **专注** | 眼神聚焦 | 眉头微蹙、身体前倾、手指停在半空、呼吸变浅、表情严肃、目光不动 |
| **释然** | 表情柔和下来 | 眉心舒展、嘴角自然上扬、眼神温和、肩膀放松、脸部肌肉不再紧绷 |
| **困惑** | 眉头皱起 | 眼神迷茫、嘴角微张、头偏了偏、眼睛眨了眨、表情茫然、声音发虚 |

## 三、环境描写词库（按场景分类）

**使用原则**：同一章内，同一环境元素不得重复描写两次；优先使用听觉+嗅觉，比视觉更有代入感；1-2句即可，不宜过长。

| 场景 | 环境元素 | 变体表达（至少5种） |
|------|---------|-------------------|
| **雨天** | 雨滴、雷声 | 雨丝斜斜地飘进来、雨点砸在铁皮屋顶上噼啪作响、窗外的雨幕模糊了视线、雨水顺着窗框淌下来、雷声在远处滚动、雨声盖过了说话声、地面溅起泥点、空气中弥漫着潮湿的泥土味 |
| **夜晚** | 月光、星光 | 月光透过窗棂洒进来、星光稀疏得像撒了一把盐、夜色浓得化不开、远处的灯火忽明忽暗、月亮被云遮住了一半、路灯在雨雾中晕开一圈光、黑暗中传来不知名的声响 |
| **废墟/管道** | 铁锈、灰尘 | 风从破损的窗框灌进来、管道里传来滴水的声音、墙角的灰尘被脚步声扬起、铁锈味混着潮湿的气息、碎石从头顶落下来、远处的嘶鸣声在管道里回荡、照明石的光芒在墙上投下摇晃的影子 |
| **集市/聚落** | 人声、烟火 | 远处传来讨价还价的声音、炊烟从屋顶飘起来、空气中弥漫着烤食物的香味、人群的嘈杂声忽远忽近、摊位上的照明石发出暖黄色的光、小孩的笑声从巷子里传出来、铁器碰撞的声音清脆响亮 |
| **荒原** | 风、沙石 | 风卷着沙石打在脸上、远处的地平线在热浪中扭曲、枯草在风中摇晃、天空灰蒙蒙的像一块旧布、脚下的碎石咯吱作响、风从西边吹过来带着焦糊味、远处的异灵嘶鸣声若隐若现 |
| **室内/住所** | 光线、温度 | 屋里的光线暗了下来、火堆噼啪作响、墙上的影子随着火光摇晃、空气里弥漫着一股霉味、角落里传来老鼠跑动的声音、门缝透进一丝冷风、桌上的茶已经凉了 |
| **战斗/紧张** | 声音、动静 | 远处传来脚步声、兵器碰撞的声音清脆刺耳、呼吸声在寂静中格外明显、心跳声像擂鼓、风突然停了、空气中的灵能波动让皮肤发麻、地面微微震动 |
| **温情/暧昧** | 光线、气息 | 烛光摇曳、两人的影子在墙上交叠、空气中弥漫着淡淡的草药香、他的呼吸拂过她的耳际、指尖相触的温度、月光洒在他的发梢、她的头发蹭过他的肩膀 |

## 四、微表情库 V2.0（按情绪分类）

**核心原则**：微表情必须多样化，同一情绪在同一章内不得重复相同动作。每个情绪提供至少5种不同表达方式，写作时轮换使用。

### 1. 隐藏不安/紧张

| 部位 | 微表情示例 | 变体表达 |
|------|-----------|---------|
| 手部 | 手指蜷了一下 | 指尖无意识摩挲衣角、手背青筋微凸、拳头攥紧又松开、手指关节发白、拇指掐进掌心 |
| 眼部 | 眼神飘忽不定 | 睫毛快速颤动、眼皮跳了一下、目光游移又强行定住、瞳孔微缩、不敢直视对方眼睛 |
| 身体 | 肩膀微不可察地绷紧 | 后背挺直了一瞬、脚尖不自觉转向门口、喉结上下滚动、呼吸一滞、身体微微前倾又缩回 |
| 面部 | 嘴角抽动 | 脸颊肌肉紧绷、下颌线收紧、眉心微蹙又舒展、额头渗出细汗、脸色发白 |

**频率控制**：每角色每章≤2次，且两次必须使用不同部位/动作。

### 2. 压抑情绪/强忍

| 部位 | 微表情示例 | 变体表达 |
|------|-----------|---------|
| 嘴部 | 嘴唇抿成一条线 | 嘴角下撇又强行拉平、牙齿咬住下唇内侧、舌尖抵住上颚、嘴唇微微发抖、深吸一口气 |
| 眼部 | 眼眶泛红但无泪 | 眼角肌肉紧绷、眼皮低垂遮住情绪、睫毛上沾了湿气但没眨眼、目光空洞一瞬、眼神暗了一下 |
| 面部 | 表情僵住 | 脸部肌肉抽搐了一下、笑容凝固在脸上、眉头皱起又强行舒展、脸色变了一瞬又恢复、太阳穴青筋微跳 |
| 身体 | 胸口起伏了一下 | 肩膀微微耸起又放下、手指掐进掌心、身体僵硬了一瞬、深呼吸但声音很轻、脚步顿了一下 |

**频率控制**：每章≤1次，优先使用嘴部+眼部组合。

### 3. 警觉/戒备

| 部位 | 微表情示例 | 变体表达 |
|------|-----------|---------|
| 眼部 | 眼神锐利了一瞬 | 瞳孔微缩、眼角余光扫视、目光定在某处不动、眼皮微抬、眼神从散漫变聚焦 |
| 身体 | 脚步慢了半拍 | 身体重心微移、肩膀不自觉绷紧、脚尖转向有利方向、手指自然垂落但随时准备抬起、呼吸变浅 |
| 头部 | 头微侧 | 耳朵动了一下（像听声音）、下巴微收、脖颈线条绷紧、头低了一瞬又抬起、偏头角度变小 |
| 手部 | 手指无意识抽动 | 手背青筋微凸、手腕转了一下、手指张开又握拳、手自然下垂但肌肉紧绷、指尖轻敲大腿（克制） |

**频率控制**：适度，紧张场景可增加，日常场景减少。

### 4. 不想多说/回避

| 部位 | 微表情示例 | 变体表达 |
|------|-----------|---------|
| 嘴部 | 没接话 | 嗯了一声（敷衍）、嘴唇动了动但没出声、话到嘴边又咽回去、咳嗽一声转移话题、声音低下去 |
| 眼部 | 没回头 | 目光移开、垂下眼帘、看向别处、眼神放空、眨眼频率变快 |
| 身体 | 转身/背对 | 脚步后退半步、身体侧过去、肩膀微微耸起、手指无意义地比划了一下、挠了挠头 |
| 面部 | 表情淡下去 | 笑容收了、脸色平静得像没听见、眉心舒展（假装不在意）、嘴角拉平、脸部肌肉放松（伪装） |

**频率控制**：适度，根据角色性格调整频率。

### 5. 松了口气/放松

| 部位 | 微表情示例 | 变体表达 |
|------|-----------|---------|
| 身体 | 肩膀塌下来 | 后背靠向椅背/墙壁、身体重心从脚尖移回脚跟、手指松开、深呼吸（胸口起伏明显）、身体晃了一下（脱力） |
| 面部 | 表情柔和下来 | 眉心舒展、嘴角自然上扬（不是笑）、眼神温和了一瞬、下颌线放松、脸部肌肉不再紧绷 |
| 手部 | 手指松开 | 手掌摊开、手指无意识舒展、手自然垂落、指尖不再发白、手背青筋消退 |
| 呼吸 | 呼吸变深 | 吐出一口长气、呼吸声变重、胸口起伏变大、鼻尖呼出的气变热、喉咙发出轻微的叹息声 |

**频率控制**：适度，用动作暗示而非直接写"松了口气"。

### 6. 心疼/怜惜

| 部位 | 微表情示例 | 变体表达 |
|------|-----------|---------|
| 眼部 | 看了一眼XX→XX（瘦了/灰了） | 目光在XX身上多停了一瞬、眼神软下来、眼角余光一直跟着XX、视线落在XX的伤口/疲惫处、目光闪烁了一下 |
| 面部 | 表情复杂 | 嘴角动了动（想说又没说）、眉心微蹙又舒展、笑容带着苦涩、脸色变柔、脸部肌肉放松但眼神沉重 |
| 身体 | 身体倾向XX | 脚步不自觉向XX靠近、肩膀微微侧向XX、手指伸向XX又缩回、身体前倾、站姿从戒备变放松 |
| 手部 | 手伸向XX | 手指轻触XX的肩膀/手臂、手掌悬在XX上方没落下、手指蜷缩了一下（克制）、手背擦过XX的手、指尖轻轻点了点XX |

**频率控制**：每章≤1次，避免过度使用"看了一眼"。

### 7. 愤怒/克制怒火

| 部位 | 微表情示例 | 变体表达 |
|------|-----------|---------|
| 眼部 | 眼神变冷 | 瞳孔收缩、目光锐利如刀、眼角微眯、眼神中闪过一丝戾气、目光死死盯着对方 |
| 面部 | 脸色沉下来 | 下颌线绷紧、嘴角下拉、脸颊肌肉抽搐、额头青筋微跳、表情凝固 |
| 手部 | 拳头攥紧 | 手指关节发白、手背青筋暴起、手掌拍在桌上、手指掐进掌心、手微微发抖（克制） |
| 身体 | 身体前倾 | 肩膀耸起、胸口起伏变大、呼吸变重、站姿从放松变紧绷、脚尖转向对方 |

**频率控制**：每章≤2次，愤怒升级时动作幅度加大。

### 8. 惊讶/意外

| 部位 | 微表情示例 | 变体表达 |
|------|-----------|---------|
| 眼部 | 眼睛睁大 | 瞳孔放大、眼皮抬起、睫毛颤动、眼神中闪过一丝不可置信、目光定住 |
| 面部 | 表情僵住 | 嘴巴微张、嘴角抽动、脸色变了一瞬、眉心皱起又舒展、脸部肌肉松弛（没反应过来） |
| 身体 | 身体僵住 | 脚步顿住、肩膀耸起、手停在半空、身体微微后仰、头向后缩了一下 |
| 嘴部 | 话到嘴边停住 | 发出一声短促的气音、嘴唇动了动没出声、咳嗽一声掩饰、声音卡住、无意识地说出"啊" |

**频率控制**：每章≤2次，避免过度使用"瞪大眼睛"。

### 9. 悲伤/难过

| 部位 | 微表情示例 | 变体表达 |
|------|-----------|---------|
| 眼部 | 眼眶泛红 | 睫毛湿润、眼角有泪但没落下、眼神空洞、眼皮低垂、目光没有焦点 |
| 面部 | 表情垮下来 | 嘴角下拉、眉心皱起、脸部肌肉松弛（无力）、笑容勉强又消失、脸色苍白 |
| 身体 | 身体缩起来 | 肩膀塌下、背微微驼、头低下去、双手抱臂（自我保护）、身体轻轻发抖 |
| 嘴部 | 声音发紧 | 嘴唇发抖、话说到一半停住、声音变低、喉咙发出哽咽声、深呼吸压住情绪 |

**频率控制**：每章≤1次，克制表达比直接哭泣更有力量。

### 10. 喜悦/开心（克制版）

| 部位 | 微表情示例 | 变体表达 |
|------|-----------|---------|
| 眼部 | 眼神亮了一下 | 眼角微弯、瞳孔放大、目光变得柔和、眼神中闪过一丝光彩、睫毛颤动（笑意） |
| 面部 | 嘴角不自觉上扬 | 笑容从眼底溢出、眉心舒展、脸颊微微泛红、表情柔和、脸部肌肉放松 |
| 身体 | 身体放松 | 肩膀放下、站姿变随意、手指无意义地摆动、脚步变轻快、身体微微晃动 |
| 手部 | 手指无意义地动作 | 手指轻敲桌面（节奏轻快）、手掌摊开、手指互相摩挲、手背擦过嘴角（掩饰笑意）、指尖轻点 |

**频率控制**：适度，克制表达比大笑更符合末日基调。

## 五、标点使用速查

| 标点 | 用法 | 示例 |
|------|------|------|
| **破折号——** | 语气转折、声音拖长、思绪中断 | "不是怕——是跑太急了" / "你——" |
| **省略号……** | 欲言又止、沉默延续、声音渐弱 | "我……"她低下头。/ 远处传来嘶鸣，越来越近…… |
| **感叹号！** | 情绪爆发、短促命令、惊呼 | "跑！" / "别碰！" |
| **问号？** | 质疑、反问、不可置信 | "就凭你？" / "这……怎么可能？" |
| **冒号：** | 引出具体动作/神态，替代"说" | 他伸手按住她肩膀，语气软下来："别闹了。" |
| **分号；** | 并列对比、节奏停顿 | 他动了；她没动。 |
| **引号嵌套** | 内心独白、特殊含义 | 他所谓的"帮忙"，不过是添乱。 |
| **无标点短句** | 极度紧张时的快切 | 他跑。管道在抖。碎石落。 |
| **括号（）** | 极短补充说明，慎用 | 他喊了一声（其实更像呜咽）。 |
