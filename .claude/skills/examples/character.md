## 一、完整蒸馏模板

```
角色: {名字}
来源: {参考素材}

【萃取】
外貌: (从素材提取的具体描写)
身份: (社会角色/职业/地位)
能力: (已知的技能和水平)
关键行为: (3个最能代表这个人的行为)
他人评价: (其他角色怎么说他/她)

【深度 — Ghost→Lie + Want/Need】
Ghost: (故事开始前的创伤事件)
Wound: (创伤让他变成了什么样的人)
Lie: (他告诉自己什么错误信念来保护自己)
Truth: (故事最终揭示的正确信念，或"不揭示")
Want: (他以为自己想要什么，外在具体的)
Need: (他真正需要什么，内在抽象的)
矛盾验证: (越追求Want是否越远离Need？)

【弧线】
弧线类型: (正面变化/负面变化/正面平坦/负面平坦/不改变)
起点状态: (A)
终点状态: (B，平坦弧写"不变")
改变节点: (至少3个，每个需要触发事件+痛苦)
倒退: (A→A'→退回A→A''→B)

【原型】
原型: (5选1或2)
模板: (45选1或2)
矛盾特质: (主气质×矛盾特质=化学反应)

【洋葱三层】
社会面具: (别人看到他是什么样的)
自我认知: (他以为自己是怎样的)
真实内核: (压力下暴露的本能)

【定标 — 用行为定义】
性格: (不用形容词，写3个具体行为)
弱点: (最致命的缺陷是什么，不是"太善良")
习惯: (口头禅/小动作/偏好)

【共情细节】
共情技法: (从6种中选2-3种)
反差感: (与主气质矛盾的特质)
标志性习惯: (去掉就不像他的动作)
不完美时刻: (最该坚强时的软弱瞬间)
普遍性翻译: (去掉类型元素后的普遍困境)

【语音锻造】
句式偏好: (长/短/省略/反问/排比...)
词汇特征: (书面/口语/方言/术语...)
情绪变化: (高兴时→/生气时→/紧张时→)
示例对话:
  日常: "..."
  愤怒: "..."
  紧张: "..."
  安慰别人: "..."
```

## 二、45角色模板速查

### 主角成长型（12种）

1. **被迫上路者** — 不想卷入，但被事件推着走
2. **边界扩展者** — 从熟悉世界踏入未知，每一步都在重新定义自己
3. **沉默的守护者** — 不说话，但用行动保护特定的人或信念
4. **赎罪行者** — 过去犯了错，用整个故事偿还
5. **真相追寻者** — 为了某个答案不惜一切，答案本身可能毁灭他
6. **身份迷失者** — 不知道自己是谁，在寻找身份的过程中成长
7. **能力觉醒者** — 原本普通，突然获得力量，学习如何驾驭
8. **规则打破者** — 发现世界运行的规则是错的，决定改变它
9. **代际传承者** — 继承前辈的遗志/能力/债务，在传承中找到自己
10. **双重生活者** — 表面一种身份，实际另一种，两边都在拉扯
11. **逆向成长者** — 从成熟/强大状态开始，逐渐暴露脆弱/学习柔软
12. **集体代表者** — 代表某个群体（种族/阶级/职业），个人成长即群体缩影

### 反派深度型（10种）

1. **系统的维护者** — 不是坏，是相信现有秩序比混乱好
2. **恐惧先手者** — 因为害怕被伤害，所以先伤害别人
3. **疲劳的创造者** — 曾经相信，现在累了，用破坏表达绝望
4. **被背叛的理想主义者** — 曾经比主角还正义，被现实碾碎后黑化
5. **爱的独占者** — 为了一个人/一件事，可以毁灭世界
6. **代际复仇者** — 继承上一代的仇恨，其实自己没直接受伤
7. **秩序狂** — 混乱让他生理不适，为了秩序可以牺牲一切
8. **镜像主角** — 和主角起点相同，选择不同，每一步都对照
9. **被利用的棋子** — 以为自己是大BOSS，实际是更大棋局的棋子
10. **末日准备者** — 真的相信末日要来，所有"恶行"都是准备

### 配角点睛型（13种）

1. **做了一件好事的普通人** — 平时自私/冷漠，关键时刻意外善良
2. **信仰碎了的执行者** — 曾经忠诚，发现真相后内心崩塌
3. **知道太多的人** — 掌握关键信息，但不敢说/不能说/说了一半死了
4. **过气英雄** — 曾经辉煌，现在落魄，用回忆反衬时代变迁
5. **孩子的眼睛** — 用孩子的视角看世界，说出大人不敢说的真相
6. **沉默的见证者** — 全程在场，不说话，但最后一句证词改变一切
7. **反复横跳者** — 立场不固定，每次出现都在不同阵营
8. **时间胶囊** — 代表过去某个时代/事件，出场即触发回忆
9. **喜剧面具** — 用幽默掩盖最深的痛，笑越大声伤越重
10. **功能型贵人** — 出场只为帮主角一次，但这一次改变主线
11. **警告者** — 提前说出预言/警告，没人信，最后应验
12. **影子角色** — 主角的反面/补充，两人合在一起才完整
13. **牺牲铺垫者** — 出场就是为了在某一刻牺牲，但牺牲要有重量

### 特质融合型（10种）

1. **温柔的暴力** — 用最温柔的方式做最残忍的事
2. **精确的疯狂** — 疯子，但每一步都逻辑自洽
3. **阳光的伤痕** — 最开朗的人，藏着最深的伤
4. **冷漠的热忱** — 表面不关心，实际比谁都投入
5. **懦弱的勇敢** — 害怕得要死，但还是做了
6. **聪明的愚蠢** — 智商极高，情商为零
7. **强大的脆弱** — 力量最强，内心最脆
8. **诚实的欺骗** — 说的每句话都是真的，但组合起来是谎言
9. **自由的枷锁** — 追求自由，却被自由本身束缚
10. **爱的毁灭** — 因为爱，所以毁灭

## 三、示例对话（语音锻造参考）

### 街头混混
```
日常: "去去去，别挡老子的路，再烦老子收拾你！"
愤怒: "你他妈找死是吧？"
紧张: "……走。"
```

### 豪门千金
```
日常: "麻烦你帮我拿一下那本书，谢谢。"
愤怒: "我想，你可能不太清楚自己在和谁说话。"
紧张: "……我知道了。"
```

### 老兵（{配角B}式）
```
日常: "堵上。""别废话。走。"
愤怒: （不说话，直接动手）
紧张: "嗯。"
```
