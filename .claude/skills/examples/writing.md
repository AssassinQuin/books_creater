## 一、对话案例

**反面（AI味）**:
> "林兄，你的实力确实令人钦佩，但此事恐怕没有那么简单，我建议我们还是从长计议。"

**正面（白话）**:
> "我说老林，你这身手是没话说，但这事没那么简单，别冲动。"

## 二、叙述画面感案例

**反面（空洞）**:
> 他展现出了强大的实力，令在场的所有人都感到震惊。

**正面（画面感）**:
> 他一拳砸在石墙上，碎石飞溅。旁边蹲着抽烟的两个散工同时站起来，烟都忘了掐。

---

## 三、侧面描写案例

**反面（直白设定）**:
> 潜龙城的修行者等级分为九级，主角目前是三级。

**正面（侧面展示）**:
> 街边的告示栏前围了一群人，最新贴出的潜龙榜上，三级觉醒者的名字密密麻麻排了两页，二级的只有十七个。旁边一个卖包子的婶子探着脖子看了看："哟，今年二级的又少了两个。"

## 四、句号切割法案例

```
❌ "{主角}在跑。管道在脚下延伸。{本地生物}在身后。"
✓ "{主角}在跑，管道在脚下延伸——身后{本地生物}的嘶鸣越来越近。"
```

## 五、解释式展示案例

**设定展示**:

❌ 说明式："灵能结晶在{本地生物}鳞片上发暗绿色的光，这是因为灵能浓度达到0.41时会产生荧光反应。"

✅ 呈现式："灵能结晶在{本地生物}鳞片上发暗绿色的光。"——到这里就停

**动机展示**:

❌ "不是因为怕，是因为跑太急了。"
✅ "不是怕——是跑太急了。"

| "他不是不想走" | "他站在原地没动" |

## 七、节奏模式案例

**加速模式**（日常→紧张）:
```
中速段落 → 中速段落 → 快速段落 → 快速段落 → 极快单句独立成段 → 停
```

**减速模式**（紧张→释放）:
```
快速段落 → 快速段落 → 中速段落（喘息） → 慢速段落（情感沉淀） → 静止
```

**心跳模式**（紧张中的短暂平静）:
```
快速 → 快速 → 慢速（突然安静） → 快速 → 快速 → 慢速 → 爆发
```

## 八、Telling → Showing 案例

| Telling | Showing |
|---------|---------|
| "{配角B}在北境待了十五年。" | "{配角B}的右膝偶尔弯得不太自然。北境十五年的旧伤。冬天会更僵。" |
| "他很紧张。" | "他的拇指在刮刀柄上画圈。食指关节摩挲了两下。呼吸没变，但手指的动作比平时快了一倍。" |
| "这里很穷。" | "三十五个铜币。老板用袖子擦了一下柜台，把铜板一个一个翻过来看，像每个都可能假。" |
