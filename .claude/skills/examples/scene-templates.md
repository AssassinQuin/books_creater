## 模板A：三人对话（信息交换+立场博弈）

**示例骨架**：

```
[建立] {资源站}地下室的灯忽明忽暗，{配角B}靠着门框，{主角}坐在箱子上，{主角妹妹}蹲在角落翻布包。

[对话] {配角B}说："路线图上标了三个中转站。"
{主角}看了一眼："第二个画了叉。"
"那是旧路，兽潮之后断了。"[{配角B}的语气像在说天气预报]
{主角妹妹}没抬头，但翻布包的手停了一下。

[插入] 地图上第二个叉旁边，有人用炭笔补了一行小字。{主角}眯着眼辨认。

[对话+C介入] "绕路要多走四天。"{主角}说。
{主角妹妹}终于抬头："四天的话干粮不够。"
{配角B}看了{主角妹妹}一眼——不是看小孩子的眼神，是看同伴。
"走旧路。"{配角B}说。"我认识那条路的另一头。"

[切换] {主角}没说话，手指在地图边缘摩挲。{主角妹妹}又低下头翻布包了。{配角B}转身推门出去的时候，走廊里的风灌进来，灯又暗了一下。
```

## 模板B：人群中的私密对话

**软过渡示例**：

```
[场景A] {主角}把{道具}装进腰包。
[场景B] 腰包里的{道具}硌着腰，他换了个坐姿。{场所}大厅排了十几个人。
```

**感官桥示例**：

```
[场景A] 铁锈味越来越重。
[场景B] 铁锈味里混上了别的东西——烧焦的灵能。{资源站}门口围了一圈人。
```

**动作桥示例**：

```
[场景A] {主角}背起{主角妹妹}往{资源站}走。
[场景B] 走到{资源站}门口，背上的人动了动。"哥，到了？"
```

## 模板C：多事件并发

**平行剪辑示例**：

```
[场景A - {主角}线] 3-5句推进
[场景B - {主角妹妹}线] 3-5句推进
[场景A - {主角}线] 继续
[场景B - {主角妹妹}线] 继续
[交汇] 两条线在同一空间相遇
```

## 模板D：安静场面下的暗涌

**暗涌层级示例**：

- **级1**：角色有一个秘密没说出来 → 通过回避某些话题/动作体现
- **级2**：角色做了一个决定但还没执行 → 通过准备工作/凝视某个方向体现
- **级3**：角色在压抑情绪 → 通过僵硬的动作/过度的控制体现

## 模板E：日常中的世界观展开

**植入方式对比**：

| 设定 | ❌ 说明式 | ✅ 动作/对话式 |
|------|---------|--------------|
| 货币体系 | "灵晶是通用货币" | "三个铜币一碗。"{主角}数出钱压在柜台上。 |
| {世界特有疾病} | "{世界特有疾病}是灵能侵蚀" | {主角妹妹}把袖子往下拽了拽，遮住手腕上的灰斑。 |
| 兽潮周期 | "兽潮每三个月一次" | 墙上的公告栏贴着新告示，"距下次黑月还有十一天"。 |
| 势力关系 | "灵枢和教会不和" | "祭司今天又来{资源站}了。"老板压低声音，"上周那个检修的也是他们的人吧？" |

## 零换行切换示例

```
他说完那句话的时候，{资源站}大厅的灯暗了一下。
```
（既是对话的反应，又暗示{资源站}异常）

```
第二天，{主角}在{资源站}排队时又见到了那个断臂的散工。
```
（一句话完成：时间跳跃+地点转换+人物引入）
