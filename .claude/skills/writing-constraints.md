# 写作约束配置

本文件是 MCP 校验工具的约束来源。修改后 MCP 自动生效。
格式为 Markdown 表格，MCP 用正则解析。

## 硬约束（百分比密度）

基于占章节总字数的千分比(‰)计算。

| key | 标签 | min‰ | max‰ | 说明 |
|-----|------|------|------|------|
| em_dash | 破折号密度 | 2.0 | 4.0 | —— 占千分比 |
| ellipsis | 省略号密度 | 0.8 | 1.5 | …… 占千分比 |
| semicolon | 分号密度 | 0.3 | 0.8 | ；占千分比 |
| exclamation | 感叹号密度 | 0.3 | 1.0 | ！占千分比 |

| key | 标签 | min | max | 说明 |
|-----|------|-----|------|------|
| avg_punct_types | 平均每段标点类型数 | 2.5 | - | 句逗破省分叹问冒顿 |
| dialogue_breaks | 对话打断/转折 | 4 | - | ——开头行 |

## 违禁词

以下词出现在正文中直接拦截：

- 可能吧
- 事情没那么简单
- 你不懂
- 你不明白
- 听我说

## 创作原则

| key | 规则 | 参考 |
|-----|------|------|
| small_event_first | 字数不够时禁止扩句，必须加一个真正的事件 | 铁律1 |
| author_voice | 审美偏执/比喻体系/不点破留白/细节集中——DNA始终在线 | 铁律2 |
| foreshadow_moderation | 核心异常≤2个/章，禁持续轻度异常模式 | 铁律3 |
| density_sawtooth | 1-2段写透其余推进，禁每段70分，连续精写≤3段 | 铁律4 |
| dialogue_waste | 对话废笔率≥40%：打断/半句/重复/情绪不一致 | 铁律5 |
| element_exclusion | 排除1-2个可用世界元素故意不写 | 铁律6 |
| character_imperfect | 执行偏差/无意义细节/认知错误/表达失败/非线性情绪 | 铁律7 |
| imbalance | 每章≥2种失衡（情绪/节奏/人物/事件/质量/对话） | 铁律8 |
| pure_text | 正文文件禁止含注释/统计/审计备注等非正文内容 | - |
| scene_world_breathing | 每章至少1个分支小事件（打断/路人/偶发） | - |
| causal_chain | 每个关键事件必须有充分前因，禁因为剧情需要 | - |
