# 战斗场面引擎

> 共享约定：读 `references/shared-conventions.md`
> 动作引擎：读 `references/engine-action.md`（动作链5拍+空间感知+具体化）

## 核心公式

```
短动作句(快) → 慢镜头长句(关键击) → 反馈/后果 → 下一循环
铺垫(70%) → 转折(5%) → 爆发(15%) → 余波/代价(10%)
```

## 强制4步流程

```
Step 1 战斗设计(设计层) → Step 2 分镜脚本(导演层) → Step 3 写正文(执行层) → Step 4 审计(验证层)
```

---

## Step 1: 战斗设计

### 1.1 战况分析

读取角色状态（体力/装备/位置/心理/身体）：
- 前一章角色蒸馏文件
- 角色深化.md（能力+战斗风格+行为基线）
- novel-db character_get（最新状态）
- 确定POV角色（一场战斗一个POV）

### 1.2 战场环境设计

参照 `engine-environment.md`，具体位置+可用元素+5感：

- 地点：具体位置（"第三区管道拐角，左断裂管，右碎石墙"）
- 可用元素：管道/碎石/灵能残渣/铁皮/陷阱/灵能回路
- 5感：光(结晶闪)/声(金属碰)/嗅(锈+焦)/温(冷风+灵能热)/地(碎石/滑/残渣)

### 1.3 异兽行为设计

每种异兽必须有：≥1独特行为 + ≥1独特弱点 + ≥1独特攻击方式

| 等级 | 行为模式 | 关键差异 |
|------|---------|---------|
| T1灰蜥 | 群猎/灵能追踪 | 独特围猎策略/攻击节奏/受伤反应 |
| T1变种 | 独居/守地盘 | 独特攻击方式/固定行为模式 |
| T2 | 智能狩猎/碾压 | 独特试探/伏击/压迫战术；多核灵能结晶 |
| T3+ | 按设定 | 突出"和之前的完全不同" |

同场多只同等级异兽必须有行为差异：先锋冲/侧翼围/后队犹豫

### 1.4 战斗弧线

```
铺垫(70%) → 转折(5%) → 爆发(15%) → 代价(10%)
```

- 铺垫：敌压力↑ → 资源↓ → 情绪积累
- 转折：发现弱点/能力触发/环境利用/团队配合
- 爆发：短句密集+慢镜头交替 → 击杀/驱逐
- 代价：体力/资源/身体/精神代价结算

### 1.5 燃点设计（每场≥1个）

| 类型 | 公式 | 检查点 |
|------|------|--------|
| 绝地反击 | 资源耗尽→近身→受伤→找弱点反 | 反击前后都有代价 |
| 团队配合 | 队友引开→主角绕背→同时出手 | 配合有因果，不是突然默契 |
| 能力觉醒 | 本能触发→发现新能力→压制 | 首次展示，不能太强 |
| 代价高光 | 伤/旧伤复发→不退→咬牙干 | 燃后必须躺/付代价 |
| 环境杀 | 引敌入陷阱/利用地形 | 环境元素在铺垫阶段已展示 |

燃点必须绑定角色情感/关系/目标。不绑定情感的燃点只是炫技。

## Step 2: 分镜脚本

先想镜头序列，再转文字。

### 2.1 分镜表

| # | 机位 | 时长 | 内容 | 字数 | 节奏 |
|---|------|------|------|------|------|
| 1 | 远景 | 3s | 全战场/态势/紧迫 | 100-150 | 慢 |
| 2 | 中景 | 2s | 对峙/试探/首次交锋 | 80-120 | 中 |
| 3 | 快切 | 0.3s×N | 密集战斗/被压制 | ≤15字/句 | 快 |
| 4 | 慢镜头 | 5s | 转折/致命击/死亡 | 200-300 | 极慢 |
| 5 | 特写 | 1s | 微表情/碰撞/关键细节 | 50-80 | 定格 |
| 6 | 中景 | 2s | 喘息/代价/收束 | 80-120 | 慢 |

### 2.2 机位切换节奏

```
远景(开场) → 中景(试探) → 快切(危机) → 慢镜头/爆发 → 快切(反击) → 中/远(余波)
```

### 2.3 时长→字数映射

| 时长 | 字数 | 句式 |
|------|------|------|
| 0.3s | ≤15字/句 | 动词开头，无主语 |
| 1s | 50-80字 | 1-2动作+反馈 |
| 3s | 100-150字 | 动作+环境+反馈 |
| 5s慢 | 200-300字 | 极致细节+感官+时间拉伸 |

### 2.4 节奏控制

| 节奏 | 段落长度 | 句式 | 内容 |
|------|---------|------|------|
| 快 | 1-2行 | 短句密集动词 | 密集战斗，无心理 |
| 中 | 2-3行 | 长短交替 | 战术动作+环境 |
| 慢 | 4-6行 | 长句密集感官 | 慢镜头/特写/余波 |

**段落长度 = 时间流速** — 战斗节奏的核心技法。

## Step 3: 写正文

按分镜表逐镜写作，每段标注机位类型。

### 3.1 强制规则

**1. POV锁定**：一场战斗一个POV，读者只能看到POV角色所见/所闻/所感。

**2. 动作-反馈链**：每一击必须有结果。
- ✅ "刮刀扎进鳞缝→阻力→刀尖滑→拧刀柄→绿光溅"
- ❌ "他砍了一下，灰蜥死了"

**3. 动词>形容词**：精准动词胜过十个形容词。消除所有"副词+动词"组合。

**4. 辅助描写≤10字**：战斗中压缩心理/环境，环境信息在远景/中景中已铺垫。

**5. 五感反馈**：触(冲击/热/痛)/声(金属/骨/呼吸)/嗅(血/灵能灼烧/焦)/味(血/锈/灵能苦)

**6. 实时代价**：持续展示体力消耗/受伤/资源减少，不是最后总结"他受伤了"。

**7. 受伤+物品记录（战后强制）**：

每个参战角色生成：
- **受伤数组** (character.status.injuries)：ID/类型/部位/严重度/来源/描述/恢复时间/行为影响/痊愈状态
- **物品/装备变化** (character.status.inventory)：消耗品使用/装备损毁/新物品/状态变化

必须写入角色蒸馏文件。

**8. 20%细节法则**：只给关键细节，让读者想象80%。选择1-2个最有力的细节放大。

### 3.2 快切模板

```
{动词}。{名词}。{动词}。{方向}。{动作+反馈}。
```

### 3.3 慢镜头模板

```
{时间拉伸开场} → {极致感官细节} → {内心独白(≤1句)} → {关键动作} → {反馈/后果}
```

### 3.4 同章多场战斗

- 不同战斗可用不同POV
- 每场独立执行分镜脚本
- 场景间空行+过渡句
- 同场战斗中途不切POV

---

## Step 4: 八维度审计

### 4.1 分镜完整性

≥3种机位切换。输出分镜图谱。

### 4.2 POV一致性

一场战斗中途不可切POV。禁止全知叙述。禁止POV角色无法感知的信息。

### 4.3 动作-反馈链

每次攻击有具体结果。受伤描写具体（部位/程度/后续影响）。无悬空动作。反馈符合物理/灵能逻辑。

### 4.4 异兽差异化

每种异兽≥1独特行为/攻击方式。不同等级风格明确区分。禁止"通用异兽模板"。

### 4.5 代价系统

每场战斗≥3种代价（体力/资源/身体/精神）。

**受伤DB审计**：
- 正文受伤但DB无记录 = P0
- DB严重度与正文不符 = P1
- 后续章未体现受伤影响 = P0

**恢复时间线标准**：轻1-3天/中5-10天/重15-30天/危需灵能修复

**物品/装备DB审计**：消耗/损毁/战利品必须更新DB。

### 4.6 燃点审计

≥1个燃点 + 类型明确 + 充分铺垫 + 绑定角色情感 + 使用慢镜头/特写 + 燃后有代价 + 推动剧情

### 4.7 节奏审计

存在节奏变化 + 快慢交替合理 + 段落长度匹配节奏 + 连续快切≤5段

### 4.8 精准动词审计

问题模式：副词+动词/形容词+名词/重复动词(>3次)/模糊动词("攻击/防御/战斗")

### 问题分级

| 级别 | 定义 | 处理 |
|------|------|------|
| P0 | POV切换/无代价/异兽通用模板/动作悬空 | 必须重写 |
| P1 | 缺少机位/燃点无铺垫/全程匀速/代价不连贯 | 必须修改 |
| P2 | 精准动词不足/环境缺失/感官单一 | 建议修改 |
| P3 | 重复动词/副词堆砌/过渡粗糙 | 批量修复 |

### 评分

- **A**: 全标准满足，分镜丰富，节奏好，燃点到位
- **B**: 1-2处小不足
- **C**: 3+处不足，需部分修改
- **D**: 核心规则违反（无代价/POV切/异兽模板），需重写

C级以下必须修改才能合并入章节正文。

## 批量执行

- 支持逐章或并行Agent执行（>3章时）
- 每章独立报告，最后总览

## 修复模式

读取问题清单 → 生成P0/P1修复方案 → 用户确认 → Edit修改 → 重新审计确认解决

## 协作模式

- 与chapter-writer协作：写完→有战斗→调本skill→整合→全章检查
- 与novel-qa协作：正文扫描时战斗维度→调本skill审计
