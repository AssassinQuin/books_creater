# 能力设计案例库

> 展示六步法在完整角色设计中的实际应用。每个案例展示从经历回溯到命名的完整决策链。

---

## 案例1：{守卫势力}退役斥候→修理铺老板娘

### 角色档案

- 身份：{主角势力}退役女斥候，在中域开灵能装备修理铺
- 年龄：40+，服役约二十年
- 性格：务实、寡言、手比嘴快、不愿意惹麻烦
- 关键背景：未注册觉醒者（怕征召令）

### Step 1-2: 经历回溯 + 能力来源

**经历节点**：深夜潜伏在敌方壁垒外，手掌贴着冷石判断墙厚，忽然"看见"了石料内部的纹路、应力线、灵路管道走向。那是第一次觉醒，但她没报告。

**能力来源**：二十年斥候生涯反复做同一件事——接近敌人阵地，判断：哪面墙薄、哪根柱子承重、哪段灵路节点松了。能力不是"觉醒了才有的"，是二十年的手艺活把灵能感知通道磨了出来。

**一句话**："她的能力来自二十年在壁缝里摸墙的手。"

### Step 3: 机制定义

| 维度 | 定义 |
|------|------|
| 核心机制 | 将灵能感知沿接触面压入固体内部，以"剖面图"方式感知内部结构 |
| 触媒 | 必须物理接触（手掌），来自斥候时期"永远用手掌贴墙"的肌肉记忆 |
| 对象限制 | 只对无机物生效（活体组织灵能场太混乱读不进去） |
| 深度分层 | 被动（结构直觉预警）→ 浅层（结构轮廓）→ 深层（损伤历史+残留灵能签名） |
| 团队定位 | 诊断/法证型，非战斗 |

### Step 4: 代价设计

| 代价 | 表现 | 影响 |
|------|------|------|
| 触觉侵蚀（物理） | 手指触觉永久性减退，右手中指+无名指分辨不出丝绸和粗布 | 修理工失去触觉的悖论 |
| 不可关闭的预警（精神） | 被动感知无法关闭，睡不好觉 | 选了个建筑够老够稳的城市才能勉强睡 |
| 知己之眼（心理） | 深层透察时看见自己的身体内部结构——骨骼纹路、血管走向、衰老痕迹 | 每次使用都要承受"看见自己正在老去" |

### Step 5: 三视角命名

| 视角 | 名称 | 文化根脉 |
|------|------|---------|
| 自述名 | **摸骨** | 中域民间"摸骨算命"传统，修理行当的自嘲称呼 |
| 登记名 | **裂隙共感** | 研究院分类命名——感知完整之物中的裂隙 |
| 外号 | **壁缝眼** | {主角势力}斥候时期的浑名，"壁"+"缝"+"眼"三层意象 |

### Step 6: 多样性检查

- 前缀碰撞：无"灵"字 ✅
- 构词模式："摸+骨"（动词+名词），与已有能力名不同 ✅
- 机制差异化：核心动词"摸/读/看"，与拓印（复制）不同 ✅
- 代价差异化：三维度独立代价，与{主角}/钟衍不重复 ✅
- 字数检查：正式名≤4字 ✅

## 案例2：渊的"震域"能力——旧能力名修复

### 原命名诊断

**灵能震域** — AI味问题：
- "灵能"万能前缀
- "震+域"是AI最爱的"效果+范围后缀"组合（域/场/波/罩四选一）
- 无人格痕迹、无文化锚点

### 经历回溯（渊是沉睡者/远古存在）

渊不是"觉醒"的——他是{反派}的一部分，能力来源是远古记忆散逸前留下的残响。他的意识在远古时代曾是封印的一部分，所以他的能力天然带"范围/边界"属性——不是学的，是"记得"。

### Step 5: 三视角命名

| 视角 | 名称 | 逻辑 |
|------|------|------|
| 自述名 | **翻地** | 渊自己的叫法。粗暴、直接——像农人翻地一样平常化，用在灵能上就是灭世级轻描淡写 |
| 登记名 | **荡灵** | 研究院分类："荡"有摆动/冲刷/扫荡三重含义 |
| 外号 | **地龙翻身** | 民间用地震俗语形容，带着对自然灾害的敬畏 |

**修复后**：主线用"翻地"，对话中"地龙翻身"出现，登记名仅出现在研究院档案场景。

## 案例3：教会执事——重能力角色设计

### 角色档案

- 身份：教会底层执事，负责维护圣城外围的辉戒阵
- 年龄：30+，从小被教会收养
- 性格：虔诚但动摇，信仰是他唯一知道的坐标系

### Step 1: 经历回溯

**经历节点**：十岁时在圣城辉殿做杂役，不小心打破了封印圣器的一枚辉戒。戒面碎裂时，他看到了一幅不属于这个世界的画面——那是上一任圣器主人临死前留在辉戒里的记忆：一个人在灵能洪流中站起来，身边的一切在解体。

他昏了过去，醒来后发现自己"看得到"器物里残留的记忆——不是完整的影像，是碎片：一截断掉的对话、一片烧焦的衣角、一只紧握又松开的手。

**一句话**："他的能力来自打碎一枚辉戒时被圣器记忆'溅'到了。"

### Step 3: 机制定义

| 维度 | 定义 |
|------|------|
| 核心机制 | 触碰有灵能残留的物品时，"读到"物品经历过的情感性记忆碎片 |
| 触媒 | 指尖接触，灵能越强/历史越久的物品"读"到的越多 |
| 限制 | 不是完整回放，只有情感浓度最高的碎片（恐惧、狂喜、绝望） |
| 不可控 | "读"到记忆时读不到现实——使用中对外界完全失明 |

### Step 4: 代价设计

| 代价 | 表现 |
|------|------|
| 记忆混淆（精神） | 读到太多别人的记忆后，不确定那段记忆是自己的还是在辉戒里看到的 |
| 画面残留（心理） | 越恐怖的记忆碎片残留越久，有时半夜醒来眼前还浮现读到的东西 |
| 信仰动摇（精神） | 读到圣器前主人的恐惧和怀疑后，开始怀疑"辉的指引"是否真的存在 |

### Step 5: 三视角命名

| 视角 | 名称 | 逻辑 |
|------|------|------|
| 自述名 | **触忆** | 教会执事自己的叫法。克制、中性——触碰即可唤起的记忆 |
| 登记名 | **遗触感** | 教会分类："遗"=圣器遗留，"触"=接触，"感"=感知。学术仪轨命名 |
| 外号 | **翻旧账** | 底层教徒私下议论——"那个能翻旧账的执事" |

## 案例4：猎人向导——无觉醒但有不可替代价值

### 角色档案

- 身份：猎人小队向导，在中域和北境之间走了三十年
- 年龄：50+
- 觉醒状态：无觉醒

### Step 0: 前置判断 → 无觉醒

跳过 Step 1-6，直接进入"无能力者的不可替代价值"。

### 不可替代价值

| 维度 | 描述 |
|------|------|
| 知识 | 知道哪条路的灵能波动稳定、哪段废墟有旧灵路陷阱、哪个小镇的井水安全 |
| 人脉 | 沿路每个哨站都有他认识的老人，"欠他一个人情"覆盖了方圆三百里 |
| 判断 | 看了一眼云就知道风暴什么时候到——不是能力，是三十年野外经验的直觉 |
| 角色 | 觉醒者需要他的时候，他总在最意想不到的地方出现，递一壶热水 |

**核心设计原则**：没有能力的角色，反而承担了"让能力者能够运转"的支撑性功能。他的价值不在战斗中体现，而是在每次转折、每次补给、每次信息差中浮现。
