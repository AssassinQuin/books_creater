# 战斗场面写作引擎

> 基于22源调研方法论。每场战斗都是小型高潮，必须体现分镜感、能力展示、代价系统。

## 核心公式

```
动作短句（快）→ 慢镜头长句（关键一击）→ 反馈/后果 → 下一个循环
```

```
铺垫期(70%) → 转折点(5%) → 爆发期(15%) → 余波/代价(10%)
```

## 强制流程

```
Step 1 战斗设计（设计层）→ Step 2 分镜脚本（调度层）→ Step 3 写正文（执行层）→ Step 4 自检（验证层）
```

---

## Step 1: 战斗设计

输入：章节大纲中的战斗事件 + 角色蒸馏文件 + 角色深化·能力字段

### 1.1 参战分析

```
1. 读取角色蒸馏文件（前一章）→ 参战角色的当前状态（体力/装备/位置/心理/身体）
2. 读取角色深化.md → 能力字段 + 战斗风格 + 行为基线
3. 确定本场战斗的POV角色（一场战斗只跟一个视角）
4. 读取 novel-db character_get → 最新人物状态
```

### 1.2 战场环境设计

具体到"站在哪，左边是什么，右边是什么"：

- **地点**：不只"废墟"，而是"第三区管道拐角，左边断裂管道，右边碎石墙"
- **可利用元素**：管道缝隙/碎石堆/灵能残渣/铁皮/陷阱位置/灵能纹路
- **环境五感**：光线（灵能结晶闪/路灯灭/荧光）+ 声音（金属碰撞/碎石响/风声）+ 气味（铁锈/焦糊/灵能灼烧）+ 温度（冷风/灵能热度）+ 地面（碎石/湿滑/灵能残渣）

### 1.3 异兽行为设计

🔴 禁止"扑过来→打一下→死了"。每种异兽至少1个独特行为+1个独特弱点+1个独特攻击方式。

| 等级 | 行为模式 | 独特化要点 |
|------|---------|-----------|
| T1灰蜥 | 群殴围猎，灵能追踪 | 每群有独特的包围策略/攻击节奏/受伤反应 |
| T1变种 | 独居领地 | 独特的攻击方式/固定的行为模式（可预判）|
| T2 | 智能狩猎，碾压级 | 独特的试探/设伏/压制战术；多核灵能结晶 |
| T3+ | 按设定 | 突出"和之前见过的都不一样" |

**同场多只同等级异兽必须有行为差异**：先锋的冲、侧翼的包抄、掉队的犹豫。

### 1.4 战斗弧线设计

```
铺垫(70%) → 转折(5%) → 爆发(15%) → 代价(10%)
```

- **铺垫**：敌方压力递增 → 我方资源递减 → 情绪暗流蓄水
- **转折**：发现弱点 / 能力触发 / 环境利用 / 团队配合
- **爆发**：短句密集 + 慢镜头交替 → 击杀/驱逐
- **代价**：体力/资源/身体/精神代价清点

### 1.5 燃点设计（每场至少1个）

| 燃点类型 | 公式 | 检查要点 |
|---------|------|---------|
| 绝地反击 | 资源耗尽→近身搏斗→受伤→找到弱点反击 | 反击前有代价，反击后有新代价 |
| 团队配合 | 队友引开→主角绕背→同时出手 | 配合有前因，不是突然默契 |
| 能力觉醒 | 本能触发→发现新能力→压制 | 第一次能力展示，不能太强 |
| 代价高光 | 受伤/老伤复发→不退→咬牙干 | 燃点后必须躺/付出代价 |
| 环境杀 | 引敌进陷阱/利用地形 | 环境元素在铺垫阶段已展示 |

🔴 燃点必须绑定角色情感/关系/目标。不绑定情感的燃点只是炫技。

### 输出：战斗设计表

| 项目 | 内容 |
|------|------|
| POV角色 | {角色名} |
| 参战方 | {我方} vs {敌方} |
| 战场 | {具体地点+环境元素} |
| 异兽 | {类型+独特行为+独特弱点} |
| 弧线 | {铺垫事件}→{转折事件}→{爆发事件}→{代价} |
| 燃点 | {类型+绑定情感} |
| 预期字数 | {匹配事件层级} |

## Step 2: 分镜脚本

**逆向工作流**：先想镜头序列，再翻译成文字。

### 2.1 分镜表

| 序号 | 机位 | 时长 | 内容 | 字数 | 节奏 |
|------|------|------|------|------|------|
| 1 | 远景 | 3秒 | 战场全貌/敌情/紧迫感 | 100-150字 | 慢 |
| 2 | 中景 | 2秒 | 对峙/试探/第一轮交手 | 80-120字 | 中 |
| 3 | 快切 | 0.3秒×N | 密集交手/被压制 | 每句≤15字 | 快 |
| 4 | 慢镜头 | 5秒 | 转折/关键一击/致命瞬间 | 200-300字 | 极慢 |
| 5 | 特写 | 1秒 | 微表情/武器碰撞/关键细节 | 50-80字 | 定格 |
| 6 | 中景 | 2秒 | 喘息/代价/收束 | 80-120字 | 慢 |

### 2.2 机位切换节奏

```
远景(开场定位) → 中景(试探交手) → 快切(危机被压) → 慢镜头/特写(转折爆发) → 快切(反击收割) → 中景/远景(余波代价)
```

### 2.3 镜头时长→字数映射

| 镜头时长 | 字数 | 句式 |
|---------|------|------|
| 0.3秒 | ≤15字，一句话 | 动词开头，无主语 |
| 1秒 | 50-80字 | 1-2个动作+反馈 |
| 3秒 | 100-150字 | 动作+环境+反馈 |
| 5秒(慢镜头) | 200-300字 | 极度细节+感官+时间拉长 |

### 2.4 节奏控制

| 节奏 | 段落长度 | 句式 | 内容 |
|------|---------|------|------|
| 快 | 1-2行 | 短句，动词密集 | 密集交手，无心理描写 |
| 中 | 2-3行 | 长短交替 | 战术动作+环境 |
| 慢 | 4-6行 | 长句，感官密集 | 慢镜头/特写/余波 |

🔴 **段落长度=时间流速**。这是战斗节奏的核心技术。

### 输出：完整分镜表（填充实际内容）

## Step 3: 写正文

按分镜表逐镜头写作。每写完一个镜头，标注机位类型。

### 3.1 强制规则

**1. POV锁定**：
- 一场战斗只跟一个视角
- 读者只能看到POV角色能看到/听到/感觉到的
- 🔴 不能出现"他不知道""另一个方向传来"等全知叙述
- 🔴 一场战斗中途不可切换POV（不同场景可切不同POV）

**2. 动作-反馈链**：
- 每一击必须有结果，不能悬空
- ✅ "刮刀扎进鳞片缝→阻力→刀尖滑→拧刀柄→绿光溅出"
- ❌ "他砍了一下，灰蜥死了"

**3. 动词>形容词**：
- 精准动词一个顶十个形容词
- ✅ 翻滚/蹲/横刀/砍/劈/扎/拧/挡/弹
- ❌ 猛烈地攻击/快速地躲避/狠狠地砍
- 🔴 扫描并消除所有"副词+动词"组合

**4. 辅助描写≤10字**：
- 战斗中的心理/环境描写极度压缩
- 环境信息在前面的远景/中景已经铺好
- 战斗中只给关键细节

**5. 五感反馈**：
- 触觉：冲击力/热度/疼痛质感（"刀柄震得虎口发麻"）
- 听觉：金属声/骨头声/呼吸声/心跳（"鳞片和铁管撞出脆响"）
- 嗅觉：血腥/灵能灼烧/焦糊（"焦糊味更浓了——是他背包被划了"）
- 味觉：血/铁锈/灵能苦味（"嘴里有铁锈味——咬破嘴唇了"）

**6. 代价实时**：
- 战斗过程中持续体现体力消耗/受伤/资源减少
- 不是最后总结"他受伤了"，而是过程中每一段都有代价痕迹
- 伤情必须具体到部位+程度（"右臂三道抓痕，棉衣破了，血从袖口渗出来"）

**7. 🔴 受伤+物品状态记录（战斗完成后强制执行）**：

战斗场景写完后，必须为每个参战角色生成以下数据并更新到novel-db：

**受伤记录（injuries数组 → character.status.injuries）**：
```
{
  "id": "{角色缩写}-INJ{N}",
  "type": "切割伤/抓伤/灵能灼烧/灵能过载/骨折/淤青/...",
  "location": "具体部位",
  "severity": "轻/中/重/危",
  "source_chapter": {章号},
  "source_event": "{什么导致的}",
  "description": "{伤情具体描述}",
  "healing_status": "新伤/恢复中/基本恢复/已痊愈",
  "healing_timeline": "{预计多久能好，参考下表}",
  "expected_full_recovery_chapter": {预计哪章能完全恢复},
  "affects": ["{对角色行为的影响}"],
  "resolved": false
}
```

**受伤严重度→恢复时间线标准**：

| 严重度 | 类型示例 | 恢复时间 | 后续表现 |
|--------|---------|---------|---------|
| 轻 | 皮外伤/擦伤/轻度淤青/轻度灵能灼烧 | 1-3天 | 短期疼痛/不影响行动/下章基本消退 |
| 中 | 深度切割/灵能灼烧(面积<手掌)/扭伤 | 5-10天 | 行动受限/需包扎/疼痛持续/2-3章后明显好转 |
| 重 | 骨折/大面积灵能灼烧/内伤/深度撕裂 | 15-30天 | 需专业治疗/明显跛行/持续影响4-6章 |
| 危 | 致命伤/灵能侵蚀内脏/断肢 | 需专业治疗(灵能修复) | 无法行动/危及生命/不治疗会死 |

**物品/装备状态记录（inventory_changes数组 → character.status.inventory）**：
```
战斗后必须检查并更新：
- 消耗品：碎渣弹用了几个/灵能碎渣仓剩余/干粮剩余
- 装备损毁：武器/护具/工具是否损坏/丢失
- 新获取：战利品/拾取的物品
- 状态变化：灵能耗尽/需要充能/已损坏但仍可用

更新character.status.inventory字段，格式：
"inventory": "刮刀(完好)/碎渣弹(剩余3颗)/背包(被划破)/..."
```

🔴 **受伤+物品追踪必须写入角色蒸馏文件**（chapter-writer Step 3.2）：
```
蒸馏文件新增字段：
- 身体·受伤: {列出当前所有未痊愈的伤，含部位/严重度/恢复进度}
- 装备·消耗: {列出战斗中的装备/消耗品变化}
```

**7. 20%细节法则**：
- 只给关键细节，让读者脑补80%
- 不要面面俱到——选最有力量的1-2个细节放大

### 3.2 快切写作模板

快切段（密集交手）的句式模板：

```
{动词}。{名词}。{动词}。{方位}。{动作+反馈}。
```

示例：
```
翻滚。碎石硌背。站起来。刀横。左边一只扑过来——蹲。它从头顶飞过。转身。砍。鳞片裂了。绿光溅出来。疼。右臂。又一只是从右边来的。
```

### 3.3 慢镜头写作模板

慢镜头段（关键转折/致命一击）的句式模板：

```
{时间拉长的开头} → {极度细节的感官描写} → {内心独白（≤1句）} → {关键动作} → {反馈/后果}
```

示例：
```
碎渣弹脱手的那一刻时间变慢了。灰蜥张嘴——嘴里两排锯齿形的牙，灵能结晶在下颚闪着暗绿的光。弹在空中翻了一圈。半圈。它的嘴合上——弹从齿缝穿过去。炸。
```

### 3.4 多场战斗同章

同一章包含多场战斗时：
- 不同战斗场景可以用不同POV（如沈野vs灰蜥用沈野POV，方岩vs T2用方岩POV）
- 每场战斗独立执行分镜脚本
- 场景间用空行+过渡句衔接
- 🔴 不可在同一场战斗中途切POV

## Step 4: 自检清单

写完战斗场景后，逐项检查：

| # | 检查项 | 标准 | 未达标处理 |
|---|--------|------|-----------|
| 1 | 分镜完整 | 有≥3种机位切换 | 补充缺失机位 |
| 2 | POV锁定 | 全程同一视角，无全知叙述 | 移除非POV信息 |
| 3 | 动作反馈 | 每次攻击/防御有具体结果 | 补充反馈 |
| 4 | 异兽差异 | 每种异兽≥1个独特行为/弱点 | 设计独特细节 |
| 5 | 代价系统 | ≥3种代价类型（体力/资源/身体/精神）| 补充代价 |
| 6 | 燃点 | ≥1个燃点，绑定角色情感 | 设计燃点 |
| 7 | 节奏变化 | 快慢交替，非匀速 | 调整段落长度 |
| 8 | 精准动词 | 无"副词+动词"堆砌 | 替换为精准动词 |
| 9 | 环境利用 | 角色≥1次利用环境 | 加入环境互动 |
| 10 | 字数匹配 | 战斗字数与事件层级匹配 | 扩展或压缩 |
| 11 | 🔴 受伤记录 | 每个参战角色受伤已写入status.injuries | 补充受伤记录 |
| 12 | 🔴 物品追踪 | 消耗品/装备损毁已更新status.inventory | 补充物品变化 |

### 评分标准

- **A**：全部达标，分镜丰富，节奏好，燃点到位
- **B**：1-2项轻微不足，不影响阅读
- **C**：3项以上不足，需局部修改
- **D**：核心规则违反（无代价/POV切换/异兽模板），需重写

🔴 评分C以下必须修改后才能合并到章节正文中。

| 场景 | 流程 |
|------|------|
| 章节含战斗 | chapter-writer → 识别战斗事件 → 调用本skill → 整合回章节 → chapter-writer Step 3全章检查 |

| 战斗审计 | 写完后调用 novel-battle-auditor 进行专项审计 |
