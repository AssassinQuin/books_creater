# 方法论/内容分离守则

本文件定义 wuzhei-perspective skill 的方法论白名单和内容黑名单，由 `scripts/auto-reject-content-pollution.sh` 强制审计。

## 核心原则

> 输出**抽象创作方法论**，不输出**具体作品元素**。

具体作品元素仅在 `[案例：禁止搬运]` 标注下作为说明使用。

## 方法论白名单（普适，可输出）

### 7 个核心心智模型

1. 世界观优先（Worldview First）
2. 故事基调决定论（Tone Decides Everything）
3. 代价法则（Cost Principle）
4. 配角非道具（Supporting Characters Are Not Props）
5. 角色完整性 > 读者意愿（Character Arc Self-Determination）
6. 现实参照（Reality Anchor）
7. 玩家视角的世界感（World Feel Over Immersion）

### 12 条决策启发式

1. 创作流程顺序：风格→世界→故事
2. 设定优先于灵感
3. 改造而非照搬
4. 命名三标准：有格调 + 可理解 + 超现实
5. 现实参照
6. 配角三问：他下班后做什么、他想要什么、他的逻辑是什么
7. 角色弧线自决
8. 代价前置
9. 场景独立性测试
10. 每本书反思前作
11. 读者作为校对
12. 不同题材 = 有意识挑战舒适区

### 表达 DNA

句式 / 词汇高频 / 禁忌词 / 节奏 / 幽默 / 确定性 / 引用习惯

## 引用规则

### 1. `[案例]` 标注（必须）

引用《诡秘之主》或其他具体作品元素时，必须加 `[案例：禁止搬运]` 标注：

```
- 作品层面 `[案例：禁止搬运]`：《诡秘之主》22 途径 × 10 序列体系——这是"世界观优先"的实例，不要照搬到你的作品
```

### 2. 抽象优先（必须）

引用案例后，必须抽象为可迁移的方法：

| 案例（具体） | 抽象方法（普适） |
|------------|----------------|
| 22 途径 × 10 序列 | 能力体系先行于剧情 + 力量分级 + 进阶有代价 |
| 塔罗会群像 | 制度化场景作为配角收束机制 |
| 扮演法 | 能力消化靠持续行为而非打坐 |
| 鲁恩王国=维多利亚英国 | 架空元素必须有现实锚点（但锚点要自己选） |
| 切尔诺贝利命名 | 命名要承载象征意义 |

### 3. 世界观基调检测（必做）

分析用户问题前，扫描用户作品的世界观元素：

- **含克苏鲁/蒸汽朋克/西幻基调** → 可以引用相关案例（仍需 `[案例]` 标注）
- **不含**（纯东方仙侠/武侠/末世/都市/科幻）→ **禁止输出**黑名单元素

## V3 关键词检测

`scripts/auto-reject-content-pollution.sh` 检测目标文件：

1. 扫描黑名单关键词
2. 检查关键词所在行是否有 `[案例]` 标注
3. 有标注 → 通过
4. 无标注 → 违规，exit 1

### 调用方法

```bash
# 检测 SKILL.md
bash scripts/auto-reject-content-pollution.sh SKILL.md

# 检测任意 skill 输出文件
bash scripts/auto-reject-content-pollution.sh <target.md>
```

### 返回值

- `exit 0`：通过（无违规）
- `exit 1`：失败（有违规，输出违规列表）
- `exit 2`：参数错误或文件不可读

## 误报防护

以下情况**不应**视为违规：

1. 关键词在 `[案例：禁止搬运]` 标注同行
2. 关键词在反模式说明中（如"❌ 不要输出克苏鲁"）
3. 关键词在引用规则表中（如本文件）

脚本的 `CASE_MARKERS` 字段已包含这些标注，会自动豁免。
