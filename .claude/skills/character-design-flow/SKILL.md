# 人物设计科学流程 (Character Design Flow)

> 本 skill 是项目级硬流程。设计/审视任何角色时**必须按此走**，避免反复踩坑（套皮 / 概念噱头 / 抽象标签 / 不感人 / 硬套剧情 / 依附主角 / 拼凑）。

## R — 原文（方法论根基）

> "打动人的是**人性**，不是**设定**。经典角色之所以经典，是他们的**具体情境和情感**让人共鸣——不是他们的能力/数字/标签。新编哪吒打动人的是'一个被偏见的小孩渴望被爱'，不是'魔丸'这个设定。设定只是壳，壳再精巧也是空的。"
>
> "好的杂糅是化学反应 1+1>2：**经典动人特质（人性骨头）+ 世界观原生载体（不违和）→ 融合**。坏的杂糅是拼凑 1+1<1：堆砌原型/概念噱头，方向各指一边。"

## I — 核心闭环（一句话）

**经典动人特质（人性骨头）→ 取/丢/配杂糅 → 世界观原生身份（从简）→ 本书核心机制承载（如迪化）→ 咬合主线（合理）→ 精彩 + 感人 + 合理**

## II — 10 条铁律

1. **人性骨头在前，设定从简在后**。先立"他怕什么/要什么/什么让人心疼"，设定（能力/身份/数字）服务人性、从简。**检验：拿掉设定噱头，角色还打动人吗？空了=没骨头=牵强。**
2. **经典动人特质做基底**。用经过验证的经典角色（日漫/神话新编/网文/影视）的动人机制做灵感，**不自编冷僻概念**。经典自带打动人的力量。
3. **取/丢/配，不套皮**。只取 1-2 个动人**特质**（具体情境+情感+关系时刻，**不是抽象标签**），丢掉原角色外壳（名字/外形/职业/情节），配世界观原生载体。**整体映射经典角色=套皮，违和，重做。**
4. **配世界观原生载体**。用项目世界观**已有的**种族/职业/法统/概念（**先 grep 查证，不假设、不编**）。抄概念不抄具名角色本人。设定要"天然属于这个世界"。
5. **化学反应，不拼凑**。多个特质必须指向**同一内核**。检验：①特质是否都指向同一内核？②放新场景角色会怎么反应（想得出=立体）？③角色有不可替代的特质吗？
6. **用本书核心机制承载**。角色通过本书的核心机制（如迪化流=用迪化承载）参与故事，不另搞一套。
7. **独立于主角**。配角是"这个世界某类人的缩影"，有自己的议程/伤口/关系。**把主角抽走，角色的人生仍成立。** 不做主角的工具人/纯镜子。
8. **多调性混合**。暖/酸/虐/悲壮光谱搭配（参考比例 暖70/酸15/虐10/悲壮5，按题材调）。不要全暗黑自残，也不要全暖扁平。
9. **具体情境动人，非抽象标签**。动人靠"娜美画海图8年赎村子+用刀划阿龙标记+路飞把草帽扣她头上"这种**具体细节**，不是"用交易隔开感情"这种**抽象概念**。
10. **剧情从人设+主线自然生长，不硬编硬套**。先立人设，剧情在和主线交汇的点自然长出，**不先编剧情再套到卷纲上**。

## A1 — 书中应用（《这次不一样》·陆离案例）

### 失败版（概念噱头 · 不打动人 · 必须重做）
- "契约感知天赋"（能感知违约）+ "用交易隔开一切感情" + "账本空页崩溃"——全是抽象概念/噱头。
- **诊断**：
  - "用交易隔开一切"是抽象心理学标签，**无经典人物背书**。
  - "契约感知"是冷僻天赋噱头，抢戏且不自然。
  - "账本空页"建在不打动人的骨头上，套了"感人表象"（空页+台词），里面是空的。

### 正确流程示范
1. **选经典基底**：娜美（《海贼王》）——动人机制是"独自扛太久+装不在乎+不敢求救+被无条件接住"。
2. **吃透动人机制（具体 · 非抽象）**：娜美独自画海图8年赎被统治的村子、对外装爱钱、撑不住时用刀划阿龙标记、哭着喊"救救我"、路飞没问一句把草帽扣她头上——打动人的是这些**具体情境**，不是任何抽象标签。
3. **取/丢/配**：取"扛太久+装不在乎+不敢求救+被接住"的动人机制；丢鱼人/海图/草帽；配六界原生载体（**商修——grep 查证是《仙侠世界观基底.md》确立概念，人族修士的一类**，不是编的）。
4. **迁移到本书+迪化**：陆离作为商修，**独自扛什么具体的东西、装作不在乎什么、什么时刻壳破求救、被男主怎样接住**——必须落到具体情境（像娜美的"8年/划标记/扣草帽"级别），不是抽象标签。
5. **感人检验**：能向别人讲清"这个角色哪里让人哭"吗？讲不清=没真懂，重做。

## A2 — 触发场景

- 设计新角色/配角
- 审视已有角色"不打动人/没特点/概念化/牵强"
- 用户反馈"角色奇怪/套皮/不感人/硬套剧情"
- 审查人物设定是否合理

**语言信号**："角色没特点""不打动人""套皮""概念化""奇怪的设定""硬套剧情""为什么觉得这个能感人""设定牵强"

## E — 可执行步骤（设计/审视一个角色）

1. **选经典基底**：明确借哪个经典角色的动人机制（必须有名有姓的经典角色，**不能"我自己编"**）。
2. **吃透动人机制**：写下这个经典角色**到底哪里打动人**——具体到情境/情感/关系时刻，**不要抽象标签**。
3. **取/丢/配**：
   - **取**：只取 1-2 个动人特质（明确写出）
   - **丢**：明确剥离原角色外壳（名字/外形/职业/情节）
   - **配**：配一个**世界观原生载体**（先 grep 查证世界观已有，不假设/不编）
4. **用本书核心机制承载**：角色如何通过本书机制（如迪化）参与故事。
5. **咬合主线**：角色和主线的关系（同病/对照/独立支线），剧情从交汇点自然生长，**不硬套**。
6. **落到具体感人锚点**：写出 1-2 个**具体**的动人情境/时刻（不是抽象标签）。
7. **过六道校验**（下方）。

## B — 失败模式（红线 · 出现即重做）

1. **套皮**：整体映射经典角色（连名字/外形/情节一起搬）→ 违和。校验：有"日漫既视感"=套皮。
2. **概念噱头当骨头**：用"契约感知/800年记录/因果账/斩三尸/补天残石"这种冷僻概念当角色核心 → 不打动人。骨头必须是人性。
3. **抽象标签代替动人**：用"用交易隔开感情/自我工具化/记忆重负"这种抽象心理学标签 → 没经典背书、不具体、不感人。
4. **硬套剧情**：先编一段支线剧情再套到卷纲上 → 不合理。剧情从人设+主线生长。
5. **全暗黑自残 / 全暖扁平**：调性单一 → 前者压抑不讨喜，后者没厚度。
6. **拼凑（1+1<1）**：堆砌多个方向不一的原型/特质 → 互相矛盾。
7. **依附主角**：把男主抽走角色就空了 → 工具人。
8. **凭空编**：不借经典、自己拍脑袋 → 大概率重蹈"概念噱头"覆辙。

## 六道校验清单（每个角色落地前必须全过）

1. **骨头校验**：拿掉所有设定噱头，角色的"人性"还打动人吗？
2. **经典背书校验**：核心动人特质来自哪个经典角色？能说清它**为什么打动人**吗（具体情境，非标签）？
3. **套皮校验**：有"日漫/经典既视感"吗？有=重做。
4. **原生度校验**：载体是 grep 查证过的世界观概念吗？抄概念不抄具名角色本人？
5. **独立性校验**：把主角抽走，角色的人生还成立吗？
6. **感人校验**：能向别人讲清楚"这个角色哪里会让人哭/代入"吗？讲不清=没真懂，重做。

## 相关 skills / 资料

- **experience-depth**：诊断人物弧线"真变了还是表面变了"（纵向深度），与本 skill 互补。
- **inner-conflict**：制造"知道该做却做不到"的横向内心张力。
- **interpretive-space**：让作品经得起反复阅读（留白 / Show don't Tell）。
- **`novels/这次不一样/参考资料/角色设计方案库-v1.md`**：经典案例库 + 设计模式 + 特质+原生载体杂糅表（本书专用参考层）。

---

> **使用纪律**：本 skill 是硬流程，不是参考。每次设计/审视角色，**必须走 E 步骤 + 过六道校验**。校验不过 → 不落地，重做。尤其是**校验 6（感人校验）**：讲不清"为什么打动人"，就是没真懂，停下来吃透经典再动手，不要凭概念硬编。
