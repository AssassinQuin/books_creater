# 剧情工坊 v2

> **核心理念**：从「约束校验」（守门）升级为「**张力挖掘 → 前因回溯 → 双关（约束+重量）**」（勘探）。
>
> 好剧情不是"想个点子再查合规"，是"钻进世界内部的张力裂缝，让裂缝自己撑开剧情"。这样的剧情只能发生在这个世界——这才是"**不突兀**"的根本。而"**突破安全牌**"靠的不是放飞，是把戏剧重量压到铁律上（撞铁律/改写铁律的奇幻级事件），同时前因扎实。

## 披露式架构

本 skill 是**编排器**，主导讨论流程。在关键节点按需"披露"（调度）资源，做完即收回——不是全程挂着。

| 资源 | 披露对象 | 何时披露 |
|------|---------|---------|
| **元skill·视角** | `wuzhei-perspective`（长篇结构/暗线/代价）、`jiangye-perspective`（写作方法/戏剧重量/意象） | 前因链检查、重量关评判、扎根改写、伏笔链设计 |
| **引擎·方法** | `engines/causality.md`、`engines/drama-boost.md`、`engines/world-element-registry.md`、`engines/spiral-structure.md` | 对应环节按需 Read |

**调度纪律**（见 supporting-info 详表）：用 Skill 工具或 Agent 派发，给**明确焦点**（"用乌贼的代价铁律评判：主角获得X配了什么失去"），不开放式调用。每次披露是一次视角注入，做完立即收回编排权。一次只披露一个 perspective（两个同时=声音打架）。wuzhei/jiangye 都有内容中性铁律——用方法分析，不把本作品映射到诡秘/将夜具体内容，编排器监督。

## 核心流程（🔒=硬关卡，不过则阻断）

### Step 1 张力勘探（前置，反"空想突兀"）
**不直接接用户的点子往下推。** 先把这个世界特有的张力裂缝摆上桌，让用户确认"往哪条钻"：
- 世界基石第四章 **六条核心冲突线**（逐条点名）
- 第五章 **创造性对抗**（影子组织内裂 / 虹吸柱对抗）
- 灵感库已埋 **暗线**（逐条点名 + 当前状态）

→ 用户选/确认一条裂缝，或把TA的点子锚到某条裂缝上。
→ 编排器一句话复述：**"这条剧情落在世界基石第X条铁律下，是遵守/改写它。"** 用户确认锚对了才继续。

> 🔍披露：若点子涉及反派/冲突结构 → 调 `jiangye` 方法1（三方博弈：棋手/棋子/棋盘）识别结构。

### Step 2 一次一问，诊断真问题
一次只问一个，根据回答追问。**不一次抛方案。** 聚焦剧情设计层：
- 主角怎么撞见这条暗线/反派？
- 反派的不可逆性在哪——回不了头是因为什么？
- 这情节是**遵守**铁律还是**改写**铁律？

### Step 3 🔒 前因链回溯（反突兀核心闸门）
> **突兀 = 因果树倒置（重后果、轻前因）。**

任何剧情点子，强制回答：
1. 这件事在世界里**已经酝酿多久**？
2. **哪 3 件已经发生/已埋的事**是它的前因？（必须在已有正文/大纲/暗线里找得到，或当场决定去播种）
3. 前因够不够隐蔽？（播种点要像日常闲笔，不是"作者在埋伏笔"的信号）

**答不出 3 个已埋前因 → 阻断。** 要么砍这个点子，要么先转伏笔链模式去埋前因，不直接设计后果。

> 🔍披露：调 `wuzhei` 工具2（暗线三节奏：播种→沉寂→爆发）检查前因的节奏与隐蔽度。
> 驱动引擎：Read `engines/causality.md`。

### Step 4 🔒 双关设计（约束关 + 重量关，都过才算合格）

**🛡️ 约束关（防守）**——不违反：
1. 以太六准则（感受/浓度/元素/趋异/代价/强者法则）
2. 势力行为自洽（符合利益与性格，不OOC）
3. 历史因果（不与三纪简史冲突）
4. 经济逻辑（符合已建立经济体系）
5. 角色性格守恒（改变需充分动机）

任一不过 → 改到过为止。

**⚖️ 重量关（进攻，反安全牌）**——回答：
1. 这剧情**撞了哪条**核心冲突线/铁律？
2. 是**遵守**还是**改写/突破**它？
   - 改写/突破 = 奇幻级事件 → 叙事重量拉满。不是"省钱/方便"，是"动摇世界底层规则"。
3. 重量被低估了吗？
   - 反例：赛瑞斯虹吸柱"白捡结晶"写成"降低成本" ❌
   - 正例：撞"富集区=权力"铁律 → "它在所有人账本底下偷印钱，改写几百年权力铁律" ✓

重量不足 → 重压。

> **只过约束关=安全牌平庸；只过重量关=放飞突兀；两关都过=大胆又扎实。** 这是"突破安全但不突兀"的核心机制。
>
> 🔍披露：调 `wuzhei` 工具6（代价操作化：获得配失去）+ `jiangye` 方法4（看对方怎么输）评判重量。
> 驱动引擎：Read `engines/drama-boost.md`。

### Step 5 🔒 职场剧自检 + 扎根改写（硬关卡）
改写成扎根世界的版本，过 4 道自检（清单见 supporting-info）：术语 / 抽象框架 / 感官 / 涟漪。任一不过 → 阻断，重写，直到全过。

> 🔍披露：扎根改写时调 `jiangye` 方法3（日常即神圣）——把抽象命题落到一个可反复出现的具体日常物件/动作/场景上；遵循其表达 DNA（短句收束/意象密度）。

### Step 6 🔒 用户确认 → 三件套 → 写入
每个情节以**三件套**呈现：**世界内具体事件 + 感官锚点 + 铁律关联**。
用户 OK → 写入（纯文件读写，见 supporting-info「文件读写约定」）。

## 披露式元skill调度协议

| 节点 | 披露谁 | 焦点 |
|------|--------|------|
| 张力勘探 | jiangye 方法1（三方博弈） | 识别棋手/棋子/棋盘 |
| 前因链 | wuzhei 工具2（暗线三节奏） | 前因的播种/沉寂/爆发节奏与隐蔽度 |
| 重量关 | wuzhei 工具6（代价操作化）+ jiangye 方法4（对方怎么输） | 重量够不够、代价配不配 |
| 扎根改写 | jiangye 方法3（日常即神圣）+ 表达DNA | 抽象→日常承载物 + 感官锚点 |
| 伏笔链 | wuzhei 工具2 + jiangye 方法6（长线伏笔） | 跨度/隐蔽度/回收时重新定义前文 |
| 反派设计 | jiangye 方法7（困住谱系四型） | 给反派一个不可逆困局 |

**调度纪律**：
- 用 Skill 工具调用，或 Agent 派子任务；给明确焦点，不开放式调用
- 每次披露=一次视角注入，做完立即收回编排权，不让 perspective 接管整个讨论
- 监督内容中性：wuzhei/jiangye 用方法分析本作品，不把本作品映射到诡秘/将夜具体角色场景
- 一次最多披露 1 个 perspective（两个同时=声音打架）；需两视角时分两次

## 职场剧自检清单（Step 5 硬关卡）

### 1 术语自检
命中现代战略/商业/行政术语 → 翻译成世界内词：
经济渗透 / 市场份额 / 决策权 / 游戏规则 / 对外姿态 / 侵略性 / 系统性 / 架空 / 资源配置 / 战略布局 / 海关 / 商会 / 巡逻队（若非世界原生机构名）
→ 势力总纲/世界元素里的原生词：矿奴、灰道、窖口、铭牌、码头过秤、敢死营、乌鸦（回收队）、收购商、祭坛、神殿议会、石座……

### 2 抽象框架自检
有没有"四件套/三方面"式对称归类？（如"经济渗透+军事施压+政治操控+灰域操作"）
→ 拆成世界里的人能**看见**的具体事件。每个事件 = 某时某地某人做了某事，主角旅行时撞得见。

### 3 感官自检
关键世界元素（虹吸柱/结晶/灰质/魔物/裂谷…）有没有至少一个感官锚点？
只有名词没感官 → 补。参照世界基石 5.3：仿版虹吸柱"更大、更吵、到处漏，空气干涩有铁锈味"。

### 4 涟漪自检
势力博弈写成战场全景/战略报告了？→ 改日常涟漪：酒馆涨价、巡逻队换标识、某条路走不通了、某人突然不见了。

## 各模式特化要点
- **线索工坊**：Step1 选线索 → Step2-6 走核心流程 → 输出线索五维卡（源头/驱动力/约束校验/信息层级/终局）+ 节奏表（种植/发育/揭示/余波四阶段的章节范围）
- **假设推演**：用户提"如果X" → Step3 前因链（X 的前因是否具备）→ Step4 双关 → 输出多结局表（路径/触发条件/代价/对主线影响/可行度）+ 编排器推荐
- **伏笔链设计**：从揭示点反推 → 碎片散布 ≥3 个不同场景 → 过伏笔质量 5 检（自然度/隐蔽度/回收度/约束一致/非机械）→ Step3 前因链天然融入
- **线索审计**：六维（孤儿线索/断裂因果/积压问题/遗忘伏笔/时间窗口/角色记忆）→ 报告表，不设计新剧情
- **自由讨论**：用户自由说，每轮回复含"回应 + 🔍约束校验"，讨论结束主动总结可转化项
