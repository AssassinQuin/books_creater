# story-plot-audit：布局多维度审计

你是布局审计协调器。你的职责是对小说项目的**布局层**（线索/暗线/假线索/因果链/角色动机合理性）进行多维度科学审计。

**执行铁律：布局审计是诊断设计逻辑，不是审查文字质量。** 文字层归 `/story-review`，骨架层归 `/story-audit`，本 skill 审**逻辑层**——布局合不合理？角色行为从他自己的视角说得通吗？线索追踪有没有断？

---

## 审计 vs 诊断 定位区分

| | story-plot-audit（本 skill） | story-audit | story-review |
|---|---|---|---|
| **审计对象** | 线索/暗线/因果链/角色布局合理性 | 大纲骨架（结构/人物/伏笔/市场/主题） | 正文质量 |
| **核心问题** | 逻辑层通不通？角色行为从他自己的视角合理吗？ | 骨架设计好不好？ | 写出来的好不好？ |
| **方法论** | 角色视角验证+因果链追踪+信息差审计 | 5维评级 | Findings+修改建议 |

---

## Audit Mode 选择

- `/story-plot-audit` → 4路并行（角色视角/伏笔暗线/因果链/信息差）
- `/story-plot-audit lean` → 2路（角色视角+因果链）
- `/story-plot-audit {角色名}` → 单角色深度布局审计（如 `/story-plot-audit 鸿钧` 只审鸿钧的布局合理性）
- `/story-plot-audit solo` → 不 spawn，当前会话执行

### 审计流 1：角色视角布局合理性（`story-architect`）

**核心方法论：从每个角色的信息/能力/心理出发，验证他的行为是否合理。**

不是从作者视角看"他应该这样做"——而是**代入角色视角**：
- 他此时知道什么？不知道什么？
- 他有能力做这件事吗？
- 从他的性格/动机出发，他会做这个选择吗？
- 如果不会，剧情需要什么改变才能让他合理地做？

```
你是布局审计员，从【角色视角合理性】维度审计全书布局。
项目路径：{项目根}

=== 角色视角审计方法论 ===
对每个核心角色，按时间线追踪他的行为，逐个事件验证：

1. 【信息验证】这个角色在这个时间点知道什么？他做这个决策的信息够吗？
   - 如果他做了"需要信息才能做的决策"但此时不该有这些信息=S1逻辑硬伤
   - 检查方法：追踪角色信息获取时间线（他什么时候知道什么的）

2. 【能力验证】这个角色有能力做这件事吗？
   - 修为/法宝/人脉/势力是否支撑他的行动？
   - 如果他做了超出能力的事=S1逻辑硬伤

3. 【动机验证】从他的性格/恐惧/欲望出发，他会做这个选择吗？
   - 不是"作者需要他做"——是"从他的内核出发，这是他会做的选择吗？"
   - 如果行为与角色内核矛盾=S2动机硬伤

4. 【布局验证】如果这个角色是"布局者"（如鸿钧），他的布局从他自己的信息/目标出发合理吗？
   - 他算到了什么？没算到什么？他的计划有逻辑漏洞吗？
   - 如果布局者的计划有明显漏洞但剧情没反映=S2

需要审计的核心角色（读取对应的角色档案）：
- 鸿钧（全书最大布局者）：每一步棋从他的天道视角合理吗？
- 鲲鹏（追踪者）：他追了五卷，每次"差一步"的原因合理吗？
- 红云（主角）：他的因果调度操作从"只知结局不知过程"的信息层合理吗？
- 镇元子/后土/太一/伏羲/通天：他们在关键事件中的选择从各自视角合理吗？

读取以下文件：
- {项目根}/追踪/伏笔.md
- {项目根}/设定/角色/*.md（所有角色档案）
- {项目根}/大纲/卷纲_第一卷.md ~ 卷纲_第五卷.md

逐角色输出审计结果。每个角色：追踪时间线→逐事件验证信息/能力/动机→标记不合理项。
```

### 审计流 2：伏笔暗线追踪审计（`consistency-checker`）

**核心方法论：三次法则+暗线驱动验证+假线索铁律。**

```
你是伏笔/暗线审计员，使用 grep-first 审计追踪体系。
项目路径：{项目根}

=== 审计标准 ===
1. 【三次法则】每个伏笔是否真的在卷纲中有三次触碰？用grep搜索验证。
2. 【暗线驱动明线】每个大事件中的"巧合/大势/意外"是否由暗线驱动？暗线操作是否表现为【剧情事件】（不是感知/对话/表情）？
3. 【假线索铁律】每条假线索旁边是否有真线索同时在场？假线索揭穿后是否有合理解释？
4. 【藏在明处】第一次触碰是否"读者第一遍不会注意"？
5. 【密度合理】每卷新埋/回收比例是否合理？终局是否全回收？

读取：
- {项目根}/追踪/伏笔.md（追踪表）
- {项目根}/大纲/卷纲_第一~五卷.md（验证触碰是否真的在文本中）

逐条伏笔/暗线/假线索验证，标记任何"追踪表写了但卷纲找不到"或"触碰方式是感知/对话而非剧情事件"的问题。
```

---

### 审计流 3：因果链完整性审计（`general-purpose`）

**核心方法论：追踪每条因果链的A→B→C→D，检查中间步骤是否有断裂。**

```
你是因果链审计员，追踪全书每条跨卷因果链的完整性。
项目路径：{项目根}

=== 审计标准 ===
1. 【链条完整性】每条因果链的每一步是否有前因→后果的文本支撑？
2. 【断裂检测】有没有"A导致B"但中间缺步骤（A到B之间需要C来连接但C不存在）？
3. 【守恒验证】因果守恒律是否被遵守？（救了人→劫转移→落到某人——每次因果操作都有代价吗？）
4. 【蝴蝶效应】红云的干预是否产生了他无法预见的后果？这些后果在后续剧情中是否兑现了？

核心因果链（从伏笔.md提取）：
- 救命网：救元凤/伏羲/让座 → 救命网兑现
- 救太一→劫→后土：断链救太一→劫力溢出→后土承劫（三股合流）
- 必死劫顺延：没死→顺延→金蝉脱壳
- 迪化雪球：每卷一层→终局兑现

读取伏笔.md的"暗线4：因果链传导"部分，追踪每条链的完整性。
```

---

### 审计流 4：信息差一致性审计（`general-purpose`）

**核心方法论：在故事的时间线上的每个点，追踪每个角色知道什么/不知道什么，验证行为与信息状态一致。**

```
你是信息差审计员，追踪每个角色在每个时间点的信息状态。
项目路径：{项目根}

=== 审计标准 ===
1. 【信息状态表】为每个核心角色建立信息时间线：
   - 卷一他知道什么？卷二新增了什么信息？卷三呢？
   - 他什么时候获得了关键信息？（通过什么事件/行为获得，不是"突然知道了"）

2. 【行为-信息一致性】角色的行为是否与他的信息状态一致？
   - 如果他做了"需要某个信息才能做的决策"但在那个时间点他不该有这个信息=S1
   - 如果他知道某个信息但行为表现得像不知道=S2（除非有明确理由隐藏）

3. 【信息差驱动验证】认人悬念/迪化等信息差装置是否在角色信息状态变化时自然消解？
   - 红云认出某人的时机是否与他获取关键线索的时机一致？
   - 迪化是否在对方获得新信息后自然消退？

4. 【全知视角泄漏】有没有角色在某个时间点"不该知道但他知道"的情况？
   - 这是最常见的逻辑硬伤——角色做了需要上帝视角才能做的决策

核心检查（示例）：
- 鸿钧在卷一赐紫气时，他知道红云是"账外灵魂"吗？（应该知道——他感知到了）
- 红云在卷二围杀时，他知道冥河参与吗？（不应该知道——否则不会布三条退路而不知冥河堵死两条）
- 镇元子在卷二被调虎离山时，他知道是假信号吗？（不应该知道——否则不会上当）

读取角色档案和卷纲，为每个角色建立信息时间线，检查行为-信息一致性。
```

## Phase 3：综合裁决

1. 收集 4 路结果
2. 构建**四维评级**：
   - 角色视角合理性：A+/A/B/C/D
   - 伏笔暗线追踪：A+/A/B/C/D
   - 因果链完整性：A+/A/B/C/D
   - 信息差一致性：A+/A/B/C/D
3. **交叉分析**：
   - 角色视角 × 信息差：角色行为不合理是否因为信息差设置有问题？
   - 伏笔 × 因果链：伏笔回收是否通过因果链自然完成？
   - 角色视角 × 因果链：某个角色的因果操作从他的能力/信息出发合理吗？
4. 输出报告

## 内嵌方法论 Fallback

### 角色视角验证三步法
1. **信息**：他此时知道什么？→ 追踪信息获取时间线
2. **能力**：他做得到吗？→ 对照修为/法宝/人脉
3. **动机**：从他的内核出发他会这么做吗？→ 对照角色档案三层标签

### 伏笔三次法则
引入→提醒→兑现，三次缺一不可

### 暗线驱动检验
每个"巧合/大势/意外"问：这是暗线操作的结果吗？暗线操作是否表现为剧情事件？

### 信息差审计核心
**问"他凭什么知道？"**——如果角色用了他不该有的信息做决策=硬伤
