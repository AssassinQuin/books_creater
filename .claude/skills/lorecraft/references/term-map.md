# 术语规范

> 西幻世界术语映射。写作前加载，写作后对照检查。

## 一、现代术语替换指南

现代科技术语会瞬间破坏西幻沉浸感。以下术语禁止出现在叙事中：

**禁用词表**：数据、参数、系统、信号、密钥、权限、终端、频率、追踪标记、加密、解密、节点（地脉节点除外）、协议、芯片、监控、扫描、验证（验牌/验照除外）、认证、授权、升级、通信、传输、接收、广播、频道、中继、签名、识别、访问、登录、日志、备份、恢复、版本、配置、部署、程序、代码、编码、解码、指令、操作台、面板、检测器、传感器、屏幕、模块、接口、数据库、脚本、校准、频谱、共振

**替换思路**：用魔法世界的逻辑替代工业逻辑。不是"监测"是"感知"。不是"传输"是"传递"。不是"系统"是"体系/网络"。不是"加密"是"隐藏/遮掩"。

## 二、核心术语

### 能量体系

| 术语 | 说明 |
|------|------|
| 以太 | 弥漫于地脉中的原始魔力。无色，高浓度偏蓝白 |
| 地脉 | 地下以太流动的通道网络 |
| 以太泉 | 地脉节点涌出地表的以太源 |
| 以太结晶 | 以太凝结的半透明蓝白棱柱体 |
| 碎晶 | 指甲盖大，日常用 |
| 整晶 | 拳头大，交易硬通货 |
| 核心晶 | 人头大，战略资源，仅迷宫深层产出 |
| 魔核 | 魔物死后凝结的低品质结晶 |

### 觉醒与魔法

| 术语 | 说明 |
|------|------|
| 点火 | 觉醒那一刻，体内以太回路贯通的瞬间 |
| 觉醒者 | 被以太选中、能使用元素魔法的人 |
| 元素亲和 | 觉醒者获得的元素属性（火/水/风/土/光/暗） |
| 稀有亲和 | 极少数人觉醒的变异元素（雷/冰/木/铁） |
| 回路 | 觉醒者体内引导以太的通道 |
| 引导 | 用意志控制以太流动施放魔法 |

### 社会制度

| 术语 | 说明 |
|------|------|
| 执照 | 觉醒者合法使用魔法的许可 |
| 魔力税 | 觉醒者每年缴纳的以太使用税 |
| 征召 | 城邦强制征用觉醒者的制度 |
| 黑户 | 未注册/未缴税的觉醒者 |

### 种族

| 术语 | 说明 |
|------|------|
| 异族 | 人类对精灵/矮人/兽血者的统称 |
| 兽血者 | 长期以太暴露导致血脉变异的人类，有动物特征 |
| 隐居族 | 躲在深山密林中的纯血精灵社区 |
| 矿镇矮人 | 在人类城镇边缘建立社区的矮人 |

### 迷宫与魔物

| 术语 | 说明 |
|------|------|
| 迷宫 | 灾变留下的地下空间扭曲，地脉交汇处的异空间 |
| 尘级 | 虫鼠大小的低等魔物，单个不危险但成群致命 |
| 铁级 | 狼/熊大小的中型魔物，有战术意识 |
| 渊级 | 人形或更大的高等魔物，有明确智力 |
| 灾级 | 传说级超大型魔物，可改变地形 |
| 迷宫许可证 | 公会发放的迷宫进入资格 |

### 设施与物品

| 术语 | 说明 |
|------|------|
| 觉醒祭坛 | 古代遗迹中的觉醒仪式设施 |
| 回收队/乌鸦 | 公会专门回收迷宫中死者装备的精锐队伍 |
| 灰路 | 灰烬的走私路线+情报传递链 |
| 以太灯 | 用碎晶驱动的照明装置 |
| 魔力药剂 | 以太结晶粉末制成的治疗药物 |

## 三、势力名称

银港同盟、铁脊、圣廷、冒险者公会、灰烬

**银港内部**：赫尔曼家族、科瓦奇家族、赛勒斯家族、三人议事会
**铁脊内部**：七将军议会、以太师团、敢死营
**圣廷内部**：大主教、十二神殿议会、异端审判庭、圣骑士团
**公会内部**：石座（分部长）、回收队（乌鸦）、评级（铜→银→金→白金→秘银）

## 四、地点名称

灰石镇（公会总部）、脊骨深渊（铁脊迷宫）、三泉城（银港首府）、白塔（圣廷圣殿）、碎口（灰烬西部枢纽）

## 五、区域名称

北部脊骨山脉、东部海岸（银港领地）、南方内陆（圣廷领地）、西部荒原（无人区）、中心低地（灰石镇周边）
