## 三、五步命名法速查

```
Step 1 概念具象化 → "这东西长什么样？使用有啥身体感受？"
Step 2 三视角命名 → 学者 / 劳动者 / 黑话各一个候选
  → ⚠️ 视角D 势力语境约束（全局，见下方）
Step 3 文化根脉锚定 → 冲突？隐喻？出处？
Step 4 🔒 多样性检查 → 5条全部通过才能入库
Step 5 最终筛选 → 自然度/范畴差异/独特性
输出: 1正式名 + 1口语名 + ≥1别称
```

### 视角D 检查要点（全局约束，贯穿Step 2）

- ❌ 不是"给同一事物起不同名字"
- ✅ 不同势力关注的事物本就不同，用各自母体造词
- 归属优先级：首次出现场景 > 最高频使用角色 > 概念最贴近的势力
- 冲突消歧：管理/记录/准入→灵枢；分析/检测/论证→研究院
- 核心约束：同一概念在全书中只保留一个主流名称

## 四、🔒 多样性检查清单（5条，全部强制）

| # | 检查项 | 硬性约束 |
|---|--------|---------|
| a | **前缀碰撞** | "灵"前缀占比>40%时停用，优先用气/韵/真/道/法/玄等 |
| b | **构词模式** | 连续3个术语不能相同构词模式 |
| c | **地层分布** | 不能全是同一地层（须有口语/学者混合） |
| d | **字数** | 正式名≤4字，超长必须有口语简称 |
| e | **字根碰撞** | "韵"≤20%、"息"≤15%，韵+息>30%停用2批次 |

**不通过处理**：回到Step 2重生成 → 连续2次不通过 → 走最低接受方案

## 五、结构型AI指纹（命名层面）

## 六、术语淘汰生命周期速查

```
Phase 1 标记 → term-map 标「待淘汰」
Phase 2 轮换 → 每章前选1-3个，新正文用新名，同步改设定文件
Phase 3 封存 → term-map 标「已淘汰」
```

**迁移节奏**：前10章优先"灵能XX"系列（~15个），11-30章处理中优先级（~20个），31+章低频术语。目标：全书~40章内旧批从97%降到40%以下。
