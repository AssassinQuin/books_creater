# Lorecraft 术语生成指南（Tier 1 — 写前加载）

> 本文件是 lorecraft 的精简版。完整参考表（根隐喻字根、文化根脉映射、替代策略、批量修复）见 `SKILL.md` 的 supporting-info。

## 设计直觉

术语不是标签——是读者进入世界观的入口。

好的术语自带画面感："道痕"让读者联想到石板上被灵能刻出的纹路；"灵契"让人想到两人交换信物时的仪式感。差的术语只是精确的信息搬运："频率签名""权限等级""终端接入"——精确，但和这个灵能世界毫无关系。

根本区别：**AI术语压缩信息（精确+透明+去文化），人类术语展开体验（隐喻+陌生化+文化根脉）**。小说追求审美体验最大化，不是信息效率最大化。

## 加载协议

写前加载 `references/term-map.md` 全量内容，生成中随时参考。

命名流程：遇到概念 → 先查 term-map 有无映射 → 有则直接用 → 无则走四步法生成新术语 → 展示用户确认 → 写入。

## 术语生成四步法

### Step 1 概念解构

把需要命名的概念拆解为2-4个本质要素。例如"频率签名"→ 独特性 + 可识别性 + 灵能属性 + 痕迹性。

### Step 2 文化映射

为每个本质要素从5大文化根脉寻找对应：道教/佛教/中医/历史/民俗。例如：独特性→道教"本命"/佛教"业力"；痕迹性→道教"道痕"/佛教"法印"。

### Step 3 组合筛选

从文化映射中组合候选，按三个标准筛选：
1. **音韵感**：读起来顺口有力量，双字词通常优于四字描述
2. **陌生化**：似懂非懂，有想象空间——"气印"比"频率签名"更能激发好奇
3. **体系一致性**：与世界观已有术语在同一根隐喻下自洽

### Step 4 验证测试

1. 角色在对话中会说这个词吗？（还是像说明书？）
2. 读者第一次看到会好奇而不是困惑吗？
3. 能在典籍/历史/民俗中找到根脉吗？

## 六个生成方向

遇到现代概念时，不要简单查找替换，而是从概念本质出发重新生成：

| 概念域 | 生成方向 | 思路引导 |
|--------|---------|---------|
| 量化/测量 | 感知描述 + 痕迹隐喻 | 灵能者怎么**感知**到它？灵能留下了什么**痕迹**？→ "灵息""道痕""灵纹" |
| 权限/控制 | 契约关系 + 身份凭证 | 谁**和谁**之间有什么**约定**？什么**信物**能证明身份？→ "灵契""灵牒""封印" |
| 数据/存储 | 典籍隐喻 + 人工编撰 | 谁**用手写**的？用什么**材质**记录？→ "灵册""灵录""道志" |
| 信号/通信 | 灵能流动 + 感知共鸣 | 灵能怎么**在人与人之间流动**？→ "灵枢网""灵能动静""传音" |
| 设备/工具 | 身体隐喻 + 天然材料 | 身体的**哪个部位**在做这件事？→ "灵窍""灵枢""道眼" |
| 加密/安全 | 纹路遮蔽 + 印记检验 | 灵能痕迹怎么被**掩盖**？→ "密纹""隐印""灵钥" |

> 完整映射见 `references/term-map.md`。

## 术语分层

同一个概念在不同语境有不同的表达——正式文献用底层词，专业交流用中层词，日常对话用表层词。这避免了所有角色都像念说明书。

- 底层（文化根脉）：道痕、灵契、灵枢
- 中层（专业术语）：道痕辨识、灵契准入、灵枢规程
- 表层（口语称呼）："他的印子""{资源站}那把锁""名册"

## 根隐喻字根

术语字根与世界观根隐喻保持一致：灵能→气/脉/韵/息/纹/痕，{资源站}→枢/窍/眼/门/关，控制→契/约/令/牒/印，记录→册/录/牒/档/志。

## 生成后自评

新术语完成后，用以下问题评估质量：

- [ ] 这个术语能让读者联想到一个画面或感觉吗？
- [ ] 它和世界观已有术语的字根家族一致吗？
- [ ] 不同势力的角色会用不同的方式称呼它吗？
- [ ] 它有文化根脉（典籍/历史/民俗出处）吗？
