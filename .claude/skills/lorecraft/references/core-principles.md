# Lorecraft 核心原则（Tier 1 — 全程强制加载）

> 本文件是 lorecraft 的精简版，用于其他 skill 的"全程强制加载"场景。
> 完整规则（四步法详解、势力字根、替代策略表、批量修复指南）见 `SKILL.md` 的 supporting-info。

## 核心原则

AI术语 = 语义压缩（精确+透明+去文化），人类术语 = 语义展开（隐喻+陌生化+文化根脉）。
小说术语追求审美体验最大化，不是信息效率最大化。

## 🔒 强制加载协议

写作/设定/大纲生成前必须执行：
1. **加载 term-map.md**：读 `references/term-map.md` 全量内容
2. **建立术语对照**：生成中随时参考映射表，避免现代术语
3. **角色/场景/物品命名时**：先查映射表 → 有映射直接替换 → 无映射走四步法
4. **写后自检**：逐项检查术语合规性

## 术语四规则（精简）

| # | 规则 | 一句话 |
|---|------|--------|
| 1 | 携带文化根脉 | 术语能在道教/佛教/中医/历史/民俗典籍中找到影子，角色对话中自然使用 |
| 2 | 服务世界观根隐喻 | 字根与根隐喻一致（灵能→气/脉/韵，灵站→枢/窍/门，控制→契/约/印，记录→册/录/志） |
| 3 | 分层（避免全员NPC） | 同一概念有底层（正式）、中层（专业）、表层（口语）三种表达 |
| 4 | 现代术语替代 | 不做简单查找替换，按概念类型（量化测量/层级控制/信息存储/通信传输/设备工具/安全保密）重新生成 |

## 四步法（精简）

1. **概念解构**：拆为2-4个本质要素
2. **文化映射**：从道教/佛教/中医/历史/民俗5大根脉找对应
3. **组合筛选**：按音韵感+陌生化+体系一致性筛选
4. **验证测试**：自然度？陌生化平衡？文化深度？

## 禁止术语速查

以下6类现代术语禁止出现在世界观设定和正文中：
- **量化测量**：频率、参数、数值、数据 → 感知描述或痕迹隐喻
- **层级控制**：权限、认证、授权 → 契约关系或身份凭证
- **信息存储**：数据、数据库、记录 → 典籍或人工编撰
- **通信传输**：信号、协议、网络 → 灵能流动或契约连接
- **设备工具**：终端、传感器、屏幕 → 身体隐喻或天然材料
- **安全保密**：加密、密钥、验证 → 纹路遮蔽或印记检验

> 完整映射表见 `references/term-map.md`。
