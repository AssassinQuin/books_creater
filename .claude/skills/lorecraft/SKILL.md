# Lorecraft — 文化根脉术语命名引擎

> ⚠️ **强制规范**：本 skill 所有规则均为硬约束。写作/生成/设定前必须加载 [references/term-map.md](references/term-map.md)，生成后必须逐条检查术语合规性。

## 核心原则

AI术语 = 语义压缩（精确+透明+去文化），人类术语 = 语义展开（隐喻+陌生化+文化根脉）。
小说术语追求审美体验最大化，不是信息效率最大化。

## 🔒 强制加载协议

**写作/设定/大纲生成前必须执行以下步骤：**

1. **加载 term-map.md**：先读 `references/term-map.md` 全量内容
2. **建立术语对照**：在生成中随时参考映射表，避免写出现代术语
3. **角色/场景/物品命名时**：先查映射表 → 有映射直接替换 → 无映射走四步法
4. **写后自检**：逐项检查术语合规性，发现违规必须修复后才能提交

## 术语生成规则（原则式，非枚举式）

### 规则1：术语必须携带文化根脉

**为什么**：现代科技术语（如"数据""权限""信号"）携带了工业时代的信息效率逻辑：精确、透明、去语境化。当它们出现在一个以"灵能""契约""痕迹"为根隐喻的世界中时，会产生认知错位——读者会瞬间从"灵气流转的古老世界"被拉回"机房和办公楼"。术语不仅是信息载体，更是世界观氛围的调音器。

**如何判断一个术语是否有文化根脉**：
- 能在道教/佛教/中医/历史/民俗典籍中找到影子吗？
- 角色在对话中会说这个词吗？（还是像说明书？）
- 读者第一次看到会好奇而不是困惑吗？

**如何生成有文化根脉的术语**：
1. **概念解构**：把需要命名的概念拆解为2-4个本质要素
2. **文化映射**：为每个本质要素从5大文化根脉寻找对应
3. **组合筛选**：按音韵感、陌生化、体系一致性三标准筛选
4. **验证测试**：自然度、陌生化平衡、文化深度

### 规则2：术语必须服务于世界观根隐喻

**当前世界观的根隐喻**：
**灵能是活的力量，灵站是恒温器，虞渊是控制者，渊是沉睡者**

**术语选择在这个根隐喻下寻找对应字根**：
- 灵能相关 → "气/脉/韵/息/纹/痕"等有生命感的字，呼应"灵能是活的力量"
- 灵站相关 → "枢/窍/眼/门/关"等有枢纽感的字，呼应"灵站是恒温器/控制节点"
- 控制/准入 → "契/约/令/牒/印"等有契约感的字，呼应"虞渊是控制者"的约束主题
- 记录/信息 → "册/录/牒/档/志"等有典籍感的字，暗示信息是稀缺的人工记录
- 追踪/标记 → "印/痕/纹/记/识"等有痕迹感的字，呼应灵能活动会留下物理痕迹的设定

**为什么这个规则重要**：如果术语字根与根隐喻不一致，世界观会出现"拼凑感"。例如：用"数据"描述灵能信息（工业时代逻辑）与用"灵册"描述（典籍记录逻辑），后者与"灵能是活的力量"这一根隐喻自洽，前者则产生认知冲突。

### 规则3：术语必须分层（避免所有角色都像念说明书）

| 层级 | 命名策略 | 示例 |
|------|---------|------|
| 底层（文化根脉） | 古语/文言，从原典蒸馏双字词 | 道痕、灵契、灵枢、灵册 |
| 中层（专业术语） | 底层词+修行体系化 | 道痕辨识、灵契准入、灵枢规程 |
| 表层（口语称呼） | 角色日常叫法 | "他的印子""灵站那把锁""名册" |

**为什么分层**：同一概念在不同语境中需要不同的语体。正式文献用底层词，专业交流用中层词，日常对话用表层词。如果所有角色在所有场合都用同一套术语，会产生"全员NPC"的违和感。

### 规则4：现代术语的替代原则（非枚举式替换表）

**核心原则**：当遇到现代科技术语时，不要简单查找替换表，而是回到"四步法"重新生成。

**现代术语的识别特征**（帮助判断一个词是否属于"现代术语"）：
- 是否来自工业/信息时代（20世纪后）？
- 是否暗示精确量化、标准化、去人格化？
- 是否在现实世界中有明确的技术定义？
- 是否在世界观的根隐喻中找不到对应字根？

**替代策略**（按概念类型分类，非按具体词汇枚举）：

| 概念类型 | 替代方向 | 示例 |
|----------|---------|------|
| **量化测量类**（频率、参数、数值） | 转向感知描述或痕迹隐喻 | "频率"→"灵息/道痕"（感知）或"灵纹图"（痕迹） |
| **层级控制类**（权限、认证、授权） | 转向契约关系或身份凭证 | "权限"→"灵契"（契约）或"灵牒"（凭证） |
| **信息存储类**（数据、数据库、记录） | 转向典籍或人工编撰 | "数据"→"灵册"（典籍）或"灵录"（记录） |
| **通信传输类**（信号、协议、网络） | 转向灵能流动或契约连接 | "信号"→"灵能动静"（感知）或"灵枢网"（枢纽连接） |
| **设备工具类**（终端、传感器、屏幕） | 转向身体隐喻或天然材料 | "终端"→"灵枢"（身体枢纽）或"灵窍"（孔窍） |
| **安全保密类**（加密、密钥、验证） | 转向纹路遮蔽或印记检验 | "加密"→"密纹"（纹路遮蔽）或"灵钥"（钥匙隐喻） |

**为什么用概念类型而非具体词汇**：模型看到具体词汇替换表时，倾向于做简单的查找替换（路径最优），而不理解背后的文化逻辑。用概念类型引导模型回到"四步法"，强迫它思考"这个概念的本质是什么→在世界观根隐喻下应该如何表达"。

## 文化根脉提取四步法

### Step 1 概念解构

把需要命名的概念拆解为2-4个本质要素。

```
例："频率签名" → 本质要素：
  1) 独特性（每个都不同）
  2) 可识别性（能被辨认）
  3) 灵能属性（与灵气/灵能相关）
  4) 痕迹性（是留下的印记）
```

### Step 2 文化映射

为每个本质要素从5大文化根脉寻找对应：

| 文化根脉 | 核心典籍/领域 | 典型术语风格 |
|---------|-------------|------------|
| 道教 | 道德经/庄子/周易/道藏 | 玄奥、自然、气韵 |
| 佛教 | 法华经/楞严经/禅宗 | 因果、空性、超脱 |
| 中医 | 黄帝内经/脉学/经络 | 脉象、气血、经络 |
| 历史 | 官制/科举/军事/礼制 | 制度感、等级感 |
| 民俗 | 风水/占卜/巫术/传说 | 日常、神秘、接地气 |

```
例：独特性 → 道教：本命/元神/命格；佛教：业力/因果
    可识别性 → 道教：符箓/法印/道纹；中医：脉象/气色
    灵能属性 → 道教：灵气/真气/道韵；民俗：灵光/气运
    痕迹性 → 道教：道痕/仙迹；佛教：法印/业痕
```

### Step 3 组合筛选

从文化映射中组合候选术语，按三标准筛选：

1. **音韵感**：读起来顺口、有力量。例如"道痕"比"灵能痕迹"更凝练，双字词通常优于四字描述。
2. **陌生化**：似懂非懂，有想象空间。例如"气印"比"频率签名"更能激发读者对"这是什么"的好奇。
3. **体系一致性**：与世界观其他术语风格统一，在同一根隐喻下自洽。如果世界用"纹/痕"描述灵能痕迹，新术语也应优先考虑这类字根而非另起炉灶。

### Step 4 验证测试

三个问题帮助判断术语是否合适：

1. **自然度**：角色在对话中会说这个词吗？如果听起来像说明书而非人话，说明还需要口语化变体。
2. **陌生化平衡**：读者第一次看到会好奇而不是困惑吗？过于生僻会导致理解门槛过高，过于直白则失去神秘感。理想的术语是"好像懂，但想继续读下去"。
3. **文化深度**：查文化出处能找到根脉吗？术语最好能从典籍、历史或民俗中找到影子，而非凭空造字。有根脉的术语经得起反复使用，无根脉的术语容易显得廉价。

## 层积命名法

术语分三层，各层命名策略不同。这种分层设计的目的是：让术语在正式文献、专业交流和日常对话中呈现自然的语体差异，避免"所有角色都像是念说明书"。

| 层级 | 命名策略 | 示例 |
|------|---------|------|
| 底层（文化根脉） | 古语/文言，从原典蒸馏双字词 | 道痕、灵契、灵枢、灵册 |
| 中层（专业术语） | 底层词+修行体系化 | 道痕辨识、灵契准入、灵枢规程 |
| 表层（口语称呼） | 角色日常叫法 | "他的印子""灵站那把锁""名册" |

## 根隐喻约束

术语体系服务于统一的根隐喻，这是保证世界观内在一致性的核心机制。当前世界观的根隐喻：

**灵能是活的力量，灵站是恒温器，虞渊是控制者，渊是沉睡者**

术语选择在这个根隐喻下寻找对应字根：
- 灵能相关 → "气/脉/韵/息/纹/痕"等有生命感的字，呼应"灵能是活的力量"
- 灵站相关 → "枢/窍/眼/门/关"等有枢纽感的字，呼应"灵站是恒温器/控制节点"
- 控制/准入 → "契/约/令/牒/印"等有契约感的字，呼应"虞渊是控制者"的约束主题

## 命名工作流

1. 发现现代术语 → 判断概念类型（量化测量/层级控制/信息存储/通信传输/设备工具/安全保密）→ 按对应替代方向重新生成
2. 无明确概念类型 → 执行四步法 → 生成新术语 → 写入映射表
3. 新术语需同时更新：DB(world_upsert) + 文件(设定/*.md) + 大纲(V*.md)
4. **生成后建议自检**：扫描全文有无现代术语残留

## 写后检查建议

每章/每份设定写完后，建议逐项检查以下内容。现代术语残留率控制在 5% 以下时，世界观沉浸感基本不受影响；超过 15% 时，读者容易频繁"出戏"。

- [ ] **量化测量类术语**：是否用感知描述替代了精确量化？（如"灵息波动"替代"频率变化"）
- [ ] **层级控制类术语**：是否用契约关系替代了行政层级？（如"灵契"替代"权限"）
- [ ] **信息存储类术语**：是否用典籍隐喻替代了数据库概念？（如"灵册"替代"数据"）
- [ ] **通信传输类术语**：是否用灵能流动替代了网络协议？（如"灵能传讯"替代"通信"）
- [ ] **设备工具类术语**：是否用身体隐喻替代了电子设备？（如"灵枢"替代"终端"）
- [ ] **安全保密类术语**：是否用纹路遮蔽替代了加密算法？（如"密纹"替代"加密"）
- [ ] **文化根脉**：新术语是否有典籍、历史或民俗出处？
- [ ] **体系一致性**：术语是否与根隐喻下的字根家族一致？
- [ ] **势力区分**：不同势力/体系的术语风格是否有差异化？

**发现违规必须修复，不可跳过。** 修复优先级：对话中的现代术语 > 叙述中的现代术语 > 仅出现在设定文档中的现代术语。

## 批量修复指南

当发现既有文件存在现代术语残留时（如重写的人物档案）：

1. 确定术语类型（按概念类型分类：量化测量/层级控制/信息存储/通信传输/设备工具/安全保密）
2. 按对应替代方向重新生成，而非简单查找替换
3. 替换后重新检查：被替换的术语是否有语境歧义（同一词在不同语境可能有不同映射）
4. 特殊处理：角色口头禅/特征用语中的现代词→按角色口语替换为表层称呼，保留角色语言个性
