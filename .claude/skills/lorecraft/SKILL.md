# Lorecraft — 文化根脉术语命名引擎

> ⚠️ **强制规范**：本 skill 所有规则均为硬约束。写作/生成/设定前必须加载 [references/term-map.md](references/term-map.md)，生成后必须逐条检查禁止术语残留。

## 核心原则

AI术语 = 语义压缩（精确+透明+去文化），人类术语 = 语义展开（隐喻+陌生化+文化根脉）。
小说术语追求审美体验最大化，不是信息效率最大化。

## 🔒 强制加载协议

**写作/设定/大纲生成前必须执行以下步骤：**

1. **加载 term-map.md**：先读 `references/term-map.md` 全量内容

3. **角色/场景/物品命名时**：先查映射表 → 有映射直接替换 → 无映射走四步法
4. **写后自检**：逐项检查禁止术语清单，发现违规必须修复后才能提交

## 文化根脉提取四步法

### Step 1 概念解构

把需要命名的概念拆解为2-4个本质要素。

```
例："频率签名" → 本质要素：
  1) 独特性（每个都不同）
  2) 可识别性（能被辨认）
  3) 灵能属性（与灵气/灵能相关）
  4) 痕迹性（是留下的印记）
```

### Step 2 文化映射

为每个本质要素从5大文化根脉寻找对应：

| 文化根脉 | 核心典籍/领域 | 典型术语风格 |
|---------|-------------|------------|
| 道教 | 道德经/庄子/周易/道藏 | 玄奥、自然、气韵 |
| 佛教 | 法华经/楞严经/禅宗 | 因果、空性、超脱 |
| 中医 | 黄帝内经/脉学/经络 | 脉象、气血、经络 |
| 历史 | 官制/科举/军事/礼制 | 制度感、等级感 |
| 民俗 | 风水/占卜/巫术/传说 | 日常、神秘、接地气 |

```
例：独特性 → 道教：本命/元神/命格；佛教：业力/因果
    可识别性 → 道教：符箓/法印/道纹；中医：脉象/气色
    灵能属性 → 道教：灵气/真气/道韵；民俗：灵光/气运
    痕迹性 → 道教：道痕/仙迹；佛教：法印/业痕
```

### Step 3 组合筛选

从文化映射中组合候选术语，按三标准筛选：

1. **音韵感**：读起来顺口、有力量（"道痕" > "灵能痕迹"）
2. **陌生化**：似懂非懂，有想象空间（"气印" > "频率签名"）
3. **体系一致性**：与世界观其他术语风格统一（同一根隐喻下）

### Step 4 验证测试

三个问题：
1. 角色在对话中会说这个词吗？（自然度）
2. 读者第一次看到会好奇而不是困惑吗？（陌生化平衡）
3. 查文化出处能找到根脉吗？（文化深度）

## 层积命名法

术语分三层，各层命名策略不同：

| 层级 | 命名策略 | 示例 |
|------|---------|------|
| 底层（文化根脉） | 古语/文言，从原典蒸馏双字词 | 道痕、灵契、灵枢、灵册 |
| 中层（专业术语） | 底层词+修行体系化 | 道痕辨识、灵契准入、灵枢规程 |
| 表层（口语称呼） | 角色日常叫法 | "他的印子""灵站那把锁""名册" |

## 根隐喻约束

术语体系必须服务于统一的根隐喻。当前世界观的根隐喻：

**灵能是活的力量，灵站是恒温器，虞渊是控制者，渊是沉睡者**

所有术语必须在这个根隐喻下自洽：
- 灵能相关 → 用"气/脉/韵/息/纹/痕"等有生命感的字
- 灵站相关 → 用"枢/窍/眼/门/关"等有枢纽感的字
- 控制/准入 → 用"契/约/令/牒/印"等有契约感的字
- 记录/信息 → 用"册/录/牒/档/志"等有典籍感的字
- 追踪/标记 → 用"印/痕/纹/记/识"等有痕迹感的字
