# Lorecraft — 文化根脉术语命名引擎

> 写作/生成/设定前加载 [references/term-map.md](references/term-map.md)，生成后评估术语质量。精简版指南见 [references/core-principles.md](references/core-principles.md)。

## 设计直觉

术语不是标签——是读者进入世界观的入口。好的术语自带画面感："道痕"让人联想到灵能刻出的纹路；"灵契"唤起交换信物的仪式感。差的术语只是精确的信息搬运："频率签名""权限等级"——精确，但和灵能世界毫无关系。

**AI术语压缩信息（精确+透明+去文化），人类术语展开体验（隐喻+陌生化+文化根脉）。**

## 推荐流程

**加载参考 → 四步法 → 用户确认 → 写入**

写作/设定/大纲生成前，先加载 `references/term-map.md` 全量内容，生成中随时参考。命名时先查映射表，有映射直接用，无映射走四步法。

## 术语生成四规则

### 规则1：术语携带文化根脉

现代科技术语（如"数据""权限""信号"）携带工业时代的信息效率逻辑：精确、透明、去语境化。当它们出现在以"灵能""契约""痕迹"为根隐喻的世界中，会产生认知错位——读者瞬间从"灵气流转的古老世界"被拉回"机房和办公楼"。术语是信息载体，更是世界观氛围的调音器。

判断方法：
- 能在道教/佛教/中医/历史/民俗典籍中找到影子吗？
- 角色在对话中会说这个词吗？（还是像说明书？）
- 读者第一次看到会好奇而不是困惑吗？

### 规则2：术语服务于世界观根隐喻

**当前世界观的根隐喻：灵能是活的力量，{资源站}是恒温器，{反派}是控制者，渊是沉睡者。**

术语字根在这个根隐喻下生长：灵能相关用气/脉/韵/息/纹/痕（有生命感），{资源站}相关用枢/窍/眼/门/关（有枢纽感），控制相关用契/约/令/牒/印（有契约感）。详细的根隐喻字根映射表详见 supporting-info §根隐喻字根表。

### 规则3：术语分层（不同角色不同说法）

同一概念在不同语境中用不同的语体：正式文献用底层词，专业交流用中层词，日常对话用表层词。所有角色所有场合都用同一套术语，会产生"全员NPC"的违和感。

分层定义与示例详见 supporting-info §命名分层表。

### 规则4：遇到现代术语时，走四步法重新生成

核心思路：不要简单查找替换表，而是回到"这个概念的本质是什么→在世界观根隐喻下应该如何表达"。模型看到具体词汇替换表时，倾向于做简单查找替换（路径最优），而不是理解背后的文化逻辑。用概念类型引导模型回到四步法，思考"概念本质→根隐喻表达"。

现代术语的识别特征（帮助判断一个词是否属于"现代术语"）：
- 是否来自工业/信息时代（20世纪后）？
- 是否暗示精确量化、标准化、去人格化？
- 是否在现实世界中有明确的技术定义？
- 是否在世界观的根隐喻中找不到对应字根？

按概念类型分类的替代策略详见 supporting-info §现代术语替代策略表。

## 文化根脉提取四步法

### Step 1 概念解构

把需要命名的概念拆解为2-4个本质要素。

### Step 2 文化映射

为每个本质要素从5大文化根脉寻找对应。5大文化根脉表详见 supporting-info §文化根脉映射表。

### Step 3 组合筛选

从文化映射中组合候选术语，按三标准筛选：

1. **音韵感**：读起来顺口、有力量。双字词通常优于四字描述。
2. **陌生化**：似懂非懂，有想象空间。
3. **体系一致性**：与世界观其他术语风格统一，在同一根隐喻下自洽。

### Step 4 验证测试

三个问题帮助判断术语是否合适：

1. **自然度**：角色在对话中会说这个词吗？
2. **陌生化平衡**：读者第一次看到会好奇而不是困惑吗？
3. **文化深度**：查文化出处能找到根脉吗？

## 命名工作流

1. 发现现代术语 → 判断概念类型（量化测量/层级控制/信息存储/通信传输/设备工具/安全保密）→ 按对应替代方向重新生成
2. 无明确概念类型 → 执行四步法 → 生成新术语 → 🔒展示给用户确认
3. 用户确认后 → 写入 DB(`world_upsert`) + 更新 term-map.md + 更新相关设定文件
4. **生成后建议自检**：扫描全文有无现代术语残留

## 根隐喻字根表

**当前世界观的根隐喻**：灵能是活的力量，{资源站}是恒温器，{反派}是控制者，渊是沉睡者。

| 根隐喻 | 对应字根 | 说明 |
|--------|---------|------|
| 灵能相关（活的力量） | 气/脉/韵/息/纹/痕 | 有生命感的字，呼应"灵能是活的力量" |
| {资源站}相关（恒温器/控制节点） | 枢/窍/眼/门/关 | 有枢纽感的字，呼应"{资源站}是恒温器/控制节点" |
| 控制/准入（{反派}是控制者） | 契/约/令/牒/印 | 有契约感的字，呼应"{反派}是控制者"的约束主题 |
| 记录/信息（稀缺人工记录） | 册/录/牒/档/志 | 有典籍感的字，暗示信息是稀缺的人工记录 |
| 追踪/标记（灵能物理痕迹） | 印/痕/纹/记/识 | 有痕迹感的字，呼应灵能活动会留下物理痕迹的设定 |

**为什么这个规则重要**：如果术语字根与根隐喻不一致，世界观会出现"拼凑感"。例如：用"数据"描述灵能信息（工业时代逻辑）与用"灵册"描述（典籍记录逻辑），后者与"灵能是活的力量"这一根隐喻自洽，前者则产生认知冲突。

```
Step 1 概念解构："频率签名" → 本质要素：
  1) 独特性（每个都不同）
  2) 可识别性（能被辨认）
  3) 灵能属性（与灵气/灵能相关）
  4) 痕迹性（是留下的印记）

Step 2 文化映射：
    独特性 → 道教：本命/元神/命格；佛教：业力/因果

    灵能属性 → 道教：灵气/真气/道韵；民俗：灵光/气运
```

## 边界条件

| 场景 | 处理方式 |
|------|---------|
| 首次使用（空映射表） | 首次设计世界观时 term-map 为空，跳过碰撞检查，标注'首次设计'，后续新增时补查 |
| 术语冲突消歧 | 当 lorecraft 建议的术语与 abilitycraft 已有能力名冲突时，保留已注册名，lorecraft 提供替代方案 |
| 文化根脉不适用 | 当概念域无合适的文化根脉时（如外星科技元素），允许使用中性描述词，但标注'非灵能术语'并在 term-map 中注册 |
| 用户对术语不满意 | 重新执行四步法，提供2-3个候选术语供选择 |
| term-map 文件损坏/缺失 | 从 DB `world_query(category='terminology')` 恢复，DB 也为空则提示用户手动重建 |
| 写后检查发现大量现代术语(>15%) | 批量修复模式：按概念类型分组→逐组走四步法→验证→确认→入库 |

## 术语质量评估

每章/每份设定写完后，用以下问题评估术语质量。现代术语残留率控制在5%以下时世界观沉浸感基本不受影响；超过15%时读者容易频繁"出戏"。

- [ ] **量化测量类**：量化概念是否用感知描述表达了？（如"灵息波动"而非"频率变化"）
- [ ] **层级控制类**：控制关系是否用契约/身份表达了？（如"灵契"而非"权限"）
- [ ] **信息存储类**：存储概念是否用典籍隐喻表达了？（如"灵册"而非"数据"）
- [ ] **通信传输类**：传递概念是否用灵能流动表达了？（如"灵能传讯"而非"通信"）
- [ ] **设备工具类**：工具概念是否用身体/天然隐喻表达了？（如"灵枢"而非"终端"）
- [ ] **安全保密类**：安全概念是否用纹路/印记隐喻表达了？（如"密纹"而非"加密"）
- [ ] **文化根脉**：新术语有典籍/历史/民俗出处吗？
- [ ] **体系一致性**：术语与根隐喻下的字根家族一致吗？
- [ ] **势力区分**：不同势力的术语风格有差异化吗？

修复优先级：对话中的现代术语 > 叙述中的现代术语 > 仅出现在设定文档中的现代术语。

## 批量修复指南

当发现既有文件存在现代术语残留时（如重写的人物档案）：

1. 确定术语类型（按概念类型分类：量化测量/层级控制/信息存储/通信传输/设备工具/安全保密）
2. 按对应替代方向走四步法重新生成，而非简单查找替换
3. 替换后重新检查：被替换的术语是否有语境歧义（同一词在不同语境可能有不同映射）
4. 特殊处理：角色口头禅/特征用语中的现代词→按角色口语替换为表层称呼，保留角色语言个性
