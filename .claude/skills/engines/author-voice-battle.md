# 作者声音 — 战斗剧情层

> 加载时机：战斗/动作场面。在通用层基础上叠加。

## 战斗声音指纹

### 节奏控制
- **危险逼近**：句子越来越短，段落越来越碎。像心跳加速
- **动作爆发**：一个长句不喘气，动词连发（劈/削/斩/扫/蹬/跃）
- **后果停顿**：动作结束后突然慢下来，写生理细节（血滴落的速度、呼吸的节奏）

### 感官优先级
1. **听觉**（碰撞、断裂、刮擦——与世界观匹配的战斗声响）
2. **触觉**（震动从武器传到手、血黏在手指上）
3. **视觉**（最后才写，因为战斗中视觉是模糊的）

### 比喻库（战斗专用）
> ⚠️ 以下为示例格式。每部小说应从自己的世界观中提炼比喻。

| 概念 | 比喻思路 |
|------|---------|
| 速度快 | 用世界观内最快的现象类比 |
| 力量大 | 用世界观内最强冲击的声响类比 |
| 疼痛 | 用角色熟悉的灼烧/撕裂感类比 |
| 恐惧 | 用世界观内的危险信号类比（突然安静=危险来了） |
| 死亡 | 用世界观内的消逝方式类比（光熄灭/声音消失） |

### 禁忌
- 不写"他感到愤怒/恐惧"——写身体反应（后颈汗毛竖起、手指自动摸向武器）
- 不写战斗中的心理活动——战斗中没时间想，只有本能
- 不总结战斗意义——战斗结束就是结束，意义在读者心里

### 战后声音切换
战斗结束后的3-5句内，声音必须从"快"切换到"慢"：
- 第一句：动作停止（他放下了刀）
- 第二句：环境重新出现（管道里的回声停了）
- 第三句：身体感知恢复（他才发现手指在抖）
- 第四句：世界继续（远处有人在喊什么）
