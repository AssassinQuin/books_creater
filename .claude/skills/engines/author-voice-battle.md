# 作者声音 — 战斗剧情层

> 加载时机：战斗/动作场面。在通用层基础上叠加。

## 战斗声音指纹

### 节奏控制
- **危险逼近**：句子越来越短，段落越来越碎。像心跳加速
- **动作爆发**：一个长句不喘气，动词连发（劈/削/斩/扫/蹬/跃）
- **后果停顿**：动作结束后突然慢下来，写生理细节（血滴落的速度、呼吸的节奏）

### 感官优先级
1. **听觉**（金属碰撞、骨头断裂、灰蜥爪子刮管壁）
2. **触觉**（震动从刀柄传到虎口、血黏在手指上）
3. **视觉**（最后才写，因为战斗中视觉是模糊的）

### 比喻库（战斗专用）
| 概念 | 世界观内比喻 |
|------|-------------|
| 速度快 | 像碎渣弹爆炸瞬间的闪光 |
| 力量大 | 像牙级冲撞管道的闷响 |
| 疼痛 | 像徒手抓烧红的碎渣 |
| 恐惧 | 像管道深处突然安静——灰蜥来了 |
| 死亡 | 像照明石耗尽，光一点一点暗下去 |

### 禁忌
- 不写"他感到愤怒/恐惧"——写身体反应（后颈汗毛竖起、手指自动摸向碎渣弹）
- 不写战斗中的心理活动——战斗中没时间想，只有本能
- 不总结战斗意义——战斗结束就是结束，意义在读者心里

### 战后声音切换
战斗结束后的3-5句内，声音必须从"快"切换到"慢"：
- 第一句：动作停止（他放下了刀）
- 第二句：环境重新出现（管道里的回声停了）
- 第三句：身体感知恢复（他才发现手指在抖）
- 第四句：世界继续（远处有人在喊什么）
