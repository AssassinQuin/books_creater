# AI味黑名单 V2.0

> **本文件是AI指纹的唯一权威定义**。其他文件引用不重复，只指向本文件。
> **本文件功能**: AI 写作中常见的套路、用词、句式、节奏黑名单。写作时实时对照检查，发现新的 AI 味模式时追加到 Memory。
>
> **定位**: AI味模式清单（每种模式的长什么样子+示例+自查方法）。
> **配合文件**: `anti-ai.md` 是正式检测标准（评分/阈值/分级），正式审计时用它打分的依据。

## 第一层：词汇级 AI 味（表层）

### 1.1 高频AI副词替换清单

每个词都有具体替代写法，遇到时直接替换：

| AI副词 | 替代方式 |
|--------|---------|
| 不禁 | 直接写动作（"他笑了"而非"他不禁笑了"） |
| 缓缓 | 写具体速度（"用了一拍才走完三步"） |
| 淡淡 | 写具体质感（"笑了一下，嘴角没到眼睛"） |
| 微微 | 写可观察的变化（"手指弯了一下"） |
| 轻轻/默默/静静/悄悄 | 写具体的轻/静是什么感觉 |
| 渐渐/悄然 | 写具体的变化过程 |
| 陡然/猛然/蓦然/骤然 | 写具体的突然感（"手一顿"→"还没反应过来"） |

### 1.2 限制使用的形容词（每章≤1次）

深邃、冰冷、炽热、苍茫、浩瀚、恢弘、磅礴、诡异、阴冷、森然、空灵、悠远

### 1.3 动词替换清单

凝视→盯着/看了一眼 | 感受→觉得/感觉 | 萦绕→绕着/转 | 沉浸→埋头/投入 | 彷徨→犹豫/拿不定主意

### 1.4 减少使用的过渡词（每章≤3次）

然而、但是、不过、于是、随后、接着、终于、突然、忽然、此刻、刹那间、一瞬间

### 1.5 情绪描写标准

用动作替代表述：
- "他心中涌起一股莫名的感动" → 用动作表现（攥紧拳头/咬了一下嘴唇/别过头去）
- "所有人都被深深震撼了" → 用具体反应（有人退了一步/没人说话/旁边的人互相看了一眼）

### 1.6 设定套路替换方案

| 套路 | 问题 | 替代方案 |
|------|------|---------|
| 使用能力的"代价""反噬" | AI最爱编，9成网文都有 | 用资源不足/对手更强/时机不对制造困难 |
| "寿命折损" | 廉价戏剧性 | 直接让后果是具体的（受伤/失去东西/被人追杀） |
| "精神崩溃/失控暴走" | 太常见 | 用具体的情绪反应（发抖/沉默/咬牙/冷笑） |
| "觉醒隐藏血脉" | 毫无铺垫的即兴设定 | 事先埋伏笔，让读者能回溯 |
| "天道/命运选中之人" | 太空 | 用具体事件驱动（被某个人选中/被某件事卷入） |
| "一步登天的机缘" | 跳过成长过程 | 每次升级都有铺垫和努力 |

## 第二层：句式级 AI 味（深层）⭐ V2.0 新增

### 2.1 🔴 AI指纹 #1：句号切割法（最大破绽）

**症状**: 通篇大量使用句号+短句的"呼吸式断句"，每个信息点都独立成句。

```
❌ AI典型句号切割法（每句独立，节奏机械）：
"不大。比鸡蛋小一点。灰白色的灵能碎片。"
"沈野在跑。管道在脚下延伸。灰蜥在身后。"
"他停下。回头看。什么都没有。"

✓ 人类写法（逗号串联，节奏像呼吸）：
"不大，比鸡蛋小一点，灰白色的灵能碎片。"
"沈野在跑，管道在脚下延伸——身后灰蜥的嘶鸣越来越近。"
"他停了下来，回头看了一眼，什么都没有。"
```

**检测规则**:
- 连续3个以上"XX。XX。XX。"结构的独立短句（每句≤8字）→ 必须改
- 单段内句号断句超过5个独立短句 → 必须改
- 全章"主语+谓语"结构的独立短句超过8次 → 需要压缩合并

**修复方案**:
- 用逗号串联相关信息点：`"不大，比鸡蛋小一点"`
- 用破折号连接转折：`"不是怕——是跑太急了"`
- 合并相关动作：`"他停了下来回头看"` 而非 `"他停下。回头看。"`
- 长短句交替：短句后紧跟一个长句，打破节奏惯性

**适用场景**: 句号切割法在紧张场景可以**有限使用**（快切战斗），但日常/铺垫场景连续超过2个短句就需要用逗号/破折号串联。

### 2.2 🔴 AI指纹 #2：解释式展示（最隐蔽的AI味）

**症状**: 每出现一个设定/物品/行为，立刻跟一句解释或说明。AI 害怕读者不理解。

```
❌ AI解释式展示（设定自带注释）：
"灵能结晶在灰蜥鳞片上发出暗绿色的光。荧光映在管壁上，把锈迹都照出来了。"
——"荧光映在管壁上"是对前一句的多余解释，读者已经能想象到发光效果

"不是普通的——普通碎片是单层结构，像一张纸。"
——刚展示完就直接解释区别，不给读者自己感受的空间

"灵能残渣不清理会影响睡眠。"
——对设定的功能做直接说明，应该通过角色失眠来展示而非直接告诉读者

"不是为了信仰——是为了黑月节那晚灵站免费发一碗灵能汤，热的。"
——动机解释句式，AI特别喜欢"不是X——是因为Y"来解释角色行为

✓ 人类写法（让读者自己感受到，而非被告诉）：
"灵能结晶在灰蜥鳞片上发暗绿色的光。"（就到这里，不解释光照效果）

"碎片？不是普通的。"他翻过来看了看背面，沉默了一会儿。（展示而非解释区别）

（不写"灵能残渣影响睡眠"，而是下一章角色失眠、烦躁、做噩梦，读者自己会联想）
```

**检测规则**:
- 设定/物品首次出现后，同一段内紧跟功能性说明 → 删除或延后到另一个场景展示
- "不是X——是因为/是为了Y" 解释动机的句式，每章≤1次
- 括号注释式说明（如补充设定细节）→ 用行动展示代替

**修复方案**:
- **延迟展示**: 设定出现时不解释，让读者好奇；3-5章后通过角色体验自然揭示
- **行动替代说明**: 不写"残渣影响睡眠"，写角色连续三天没睡好，脾气变差
- **对话替代旁白**: 通过NPC的闲聊带出设定，而非旁白直接科普
- **留白**: 有些设定不需要解释"为什么"，让读者自己推理

### 2.3 🔴 AI指纹 #3：结构工整对称（叙事模板感）

**症状**: 每个场景都遵循相同的叙事模板：动作描写 → 环境补充 → 感官细节 → 角色反应 → 转场。

```
❌ AI工整结构（每个场景同一节奏）：
场景1（管道逃亡）：动作→环境→感官→反应→转场
场景2（聚落生活）：动作→环境→感官→反应→转场
场景3（老陈面摊）：动作→环境→感官→反应→转场
场景4（回到管道）：动作→环境→感官→反应→转场
——四个不同性质的场景，叙事结构完全一样

✓ 人类写法（场景间节奏差异）：
场景1（管道逃亡）：短句快切→动作密集→几乎无环境描写→直接跳切
场景2（聚落生活）：长句铺开→环境细节丰富→NPC对话穿插→慢节奏
场景3（老陈面摊）：从对话切入→动作和对话交织→感官描写融在对话里
场景4（回到管道）：一个画面开头→直接进事件→不铺垫
```

**检测规则**:
- 连续3个场景使用相同的"5段式"结构 → 至少2个场景需要打破模板
- 紧张场景（逃亡/战斗/对峙）和日常场景的段落长度分布相似 → 紧张场景需要更短段落
- 每个场景都以"环境铺陈"开头 → 至少1/3的场景从动作/对话/内心独白直接切入

**修复方案**:
- **变速**: 紧张场景用短句+快切（≤15字/句），日常场景允许长句铺开
- **切入方式轮换**: 环境→动作→对话→内心→悬念→声音，六种开头轮换
- **非对称结构**: 有些场景可以只有2段（极度聚焦），有些场景可以8段（充分展开）
- **省略**: 不是每个场景都需要环境铺垫。连续场景（同一地点）只在第一次做环境描写

### 2.4 🔴 AI指纹 #4："不是X，是Y"否定转折句式模式化

**症状**: 同一种否定-转折句式高频出现，AI 学到了"否定+转折=有深度"然后反复使用。

```
❌ AI高频否定转折（同一句式反复出现）：
"不是直线跑——管道不是直的"
"不是经验"
"不是怕，是跑太急了"
"不是痛叫，是灵能结晶被震裂后追踪信号紊乱的嘶鸣"
"不是信仰，是实用"
"不是为了信仰——是为了黑月节那晚灵站免费发一碗灵能汤"
——6次同类句式在3000字内，读者会感到模式化

✓ 人类写法（否定转折只是工具之一，不滥用）：
"管道不是直的。"（就这一句，后面用动作展示而非继续解释）
"他摇头。不是因为怕。是因为这条路跑多了，知道前面有什么。"
（每次否定转折都用不同的结构，且配合具体的角色行为）
```

**检测规则**:
- 全章"不是X，是/因为/为了Y"句式超过2次 → 必须改掉多余的
- 连续两个段落使用否定转折 → 后一个改用其他句式
- 否定转折后紧跟解释性从句（"是因为……"超过10字）→ 缩短或改用行动展示

**修复方案**:
- **保留最好的1个**，其余改掉
- 改为肯定式表达：`"管道拐了好几个弯"` 而非 `"管道不是直的"`
- 改为行动展示：`"他跑了几步猛地拐弯——前面是堵死的"`
- 改为内心独白：`"又是弯道。他甚至不用看。"`
- 改为零解释：只呈现事实，让读者自己判断

### 2.5 🔴 AI指纹 #5：精确度偏见 (New)
**症状**: 使用不符合角色视角的精确数字（寸/秒/米/克）。
**检测规则**: 搜索“寸”“秒”“米”“克”等词，除非是精密仪器场景。
**修复方案**: 替换为感官尺度（指节/呼吸/跨步/一盏茶）。

### 2.6 🔴 AI指纹 #6：节奏回环 (New)
**症状**: [意象] -> [解释] -> [升华] 的工整循环。
**检测规则**: 检查段落末尾是否总是以“这意味着……”或“就像……”结尾。
**修复方案**: 锯齿状叙事。切断升华，直接跳转到下一个物理动作。

### 2.7 🔴 AI指纹 #7：刻意伏笔 (New)
**症状**: 伏笔感太重，像是在大声告诉读者“这里有秘密”。
**检测规则**: 搜索“不说”“假装不存在”“默契”等词。
**修复方案**: 事件嵌入。将线索藏在真正的冲突或动作反馈中。

### 2.8 🔴 AI指纹 #8：作者替角色下结论（New - 借鉴humanize"假设共鸣"）

**症状**: AI 用旁白直接总结角色的心理状态，而非让读者通过动作/反应自己感受。这是 AI "害怕读者不理解"的安全本能。

```
❌ AI替角色下结论（旁白式心理总结）：
"他知道这意味着危险。"
"她明白这是最后一次机会。"
"他们都清楚后果有多严重。"
"沈野意识到方岩在隐瞒什么。"

✓ 人类写法（用动作/反应替代旁白总结）：
"他往后退了半步。"
"她把东西攥得更紧了，指节发白。"
"没人说话。"
"沈野看了方岩一眼，没问。"
```

**检测规则**:
- 搜索 "他知道/她明白/他们都清楚/意识到/发现" 等旁白式心理动词 → 每章≤2次
- 心理总结后没有紧跟具体动作 → 必须改为动作展示
- 连续两个段落以心理总结开头 → 后一个必须改写

**修复方案**:
- **动作替代**: "他知道危险" → "他往后退了半步"
- **反应替代**: "她明白这是最后一次" → "她把东西攥得更紧了"
- **沉默替代**: "他们都清楚后果" → "没人说话"
- **留白替代**: 删掉心理总结，让读者自己从上下文推断

### 2.9 🔴 AI指纹 #9：段落长度均匀（New - 借鉴humanize"语气均匀"）

**症状**: 连续段落的字数/句数几乎一致，像一台"情绪稳定的播音机"。人类写作的段落长度天然有起伏。

```
❌ AI均匀段落（每段4句，约80字，节奏机械）：
[段落1] 沈野在管壁上刮着碎渣。灰绿色的残渣落在袋子里，发出轻微的沙沙声。他的手指被管壁的锈迹划了一下，没出血，只是有点疼。他继续刮。
[段落2] 方岩坐在旁边，看着沈野的动作。他的腿伤还没好，走路一瘸一拐。但他没抱怨，只是静静地等着。沈野的袋子快满了。
[段落3] 远处传来灰蜥的嘶鸣，声音不大，但两个人都听见了。沈野停下手，侧耳听了一会儿。方岩握紧了短刀。嘶鸣声渐渐远了。
——三段都是4句，都是"动作→细节→反应→收尾"，像复制粘贴

✓ 人类写法（段落长度有起伏，节奏自然）：
[段落1] 沈野在管壁上刮着碎渣。灰绿色的残渣落在袋子里，沙沙响。手指被锈迹划了一下——没出血，只是疼。他继续刮，没停。
[段落2] 方岩坐在旁边看着，腿伤没好，走路一瘸一拐。他没抱怨。
[段落3] 远处传来灰蜥的嘶鸣。

两个人都听见了。沈野停下手，侧耳听——方岩握紧短刀。嘶鸣声渐远，没再回来。
——第一段5句详细，第二段2句极简，第三段打破句式，有急有缓
```

**检测规则**:
- 连续5个段落，长度差异<20% → 触发警报
- 紧张场景和日常场景的段落长度分布相似 → 紧张场景需要更短段落
- 全章无"急刹车"（1句话独立成段）→ 至少1处

**修复方案**:
- **拆分**: 将1个长段落拆成2个短段落（制造节奏突变）
- **合并**: 将2个短段落合并（制造语流绵长感）
- **急刹车**: 在关键情绪点用1句话独立成段
- **长短交替**: 长段（5-8句）后紧跟短段（1-2句）

### 2.10 🔴 AI指纹 #10：情绪安全区（New - 借鉴humanize"观点太安全"）

**症状**: AI 让角色永远保持"理性分析"状态，即使在极端压力下也不失控。真人会犯错、会慌乱、会说错话。

```
❌ AI情绪安全区（角色永远从容）：
"沈野冷静地分析了局势，决定从左侧绕过去。"
"面对牙的攻击，方岩沉着地拔出短刀，迎了上去。"
"沈念虽然害怕，但还是镇定地处理着伤口。"
——所有角色都像训练有素的特种兵，没有慌乱，没有失误

✓ 人类写法（角色会慌、会错、会失控）：
"沈野想从左侧绕——脚下一滑，差点摔倒。他骂了一句，扶住管壁。"
"方岩拔出短刀，手在抖。不是怕，是肾上腺素。他深吸一口气，迎上去。"
"沈念处理伤口，手在抖。绷带缠了两圈才缠对。她没说话，怕一说话就哭出来。"
——角色有失误、有生理反应、有情绪边缘
```

**检测规则**:
- 高压场景（战斗/生死/背叛）中角色无失误/无慌乱 → 必须添加
- 角色永远"冷静分析"而非"本能反应" → 改为本能优先
- 冲突场景双方都像在下棋 → 至少一方要"打错"或"失控"

**修复方案**:
- **添加失误**: 角色在紧张时犯错（滑倒/说错话/判断错误）
- **生理反应**: 手抖/心跳/出汗/呼吸急促——不是"怕"，是身体本能
- **情绪边缘**: 角色在临界点"差点崩溃但没崩溃"，而非"始终镇定"
- **本能优先**: 紧急情况下角色先行动后思考，而非"冷静分析"

## 第三层：结构级 AI 味（深层）

### 3.1 禁止：过度均匀的信息密度
**症状**: 每一段的字数、信息量几乎一致，缺乏详略得当。
**修复方案**: 信息推进率控制。有些段落极简（1句话推进），有些段落极详（长段铺陈环境带出新设定）。

### 3.2 🔴 AI指纹 #8：均等观察 (New)
**症状**: 对所有角色和环境细节进行平均权重的描写（全知摄影机）。
**修复方案**: 主观镜头偏心。只写角色当前最关心的1个细节，其余模糊处理。

### 3.3 🔴 AI指纹 #9：情绪过稳 (New)
**症状**: 即使在极度压力下，语言结构依然工整、文学化。
**修复方案**: 语言解构。使用碎片化、崩坏的语法来表现极端情绪。

## 第四层：角色设计级 AI 味（最隐蔽）

| AI味模式 | 为什么是AI味 | 替代方案 |
|---------|------------|---------|
| 每人恰好一个标签、一个缺陷、一个秘密、一个弧线 | 太整齐了，真人不是这样 | 有的人有多个互相矛盾的缺陷；有的人没有秘密；有的人弧线走到一半就停了 |
| 缺陷是"太善良""太执着""太认真" | 自我表扬，不是缺陷 | 缺陷要让读者不舒服："她无法拒绝需要帮助的人，即使这些人在利用她" |
| 弧线是直线（从A直接到B） | 真人成长有倒退有反复 | A→A'→退回A→A''→B。至少一次"差一点做到了但没做到" |
| 好人做好事理由全干净 | 太圣人了 | 做好事的理由里混着私心。江屿帮沈野也帮自己确认罪行 |
| 坏人做坏事全因为坏 | 懒惰的恶 | 坏人有信念。虞渊真信自己能替所有人做决定。焱真信先动手才能活 |
| 所有人都在关键时刻"做出正确选择" | 假 | 有人做了错选择。有人做了错选择还不后悔。有人想改来不及 |
| 所有问题都有答案 | 太完满了 | 有人到结局还在挣扎。柳陌的信仰碎了没重建 |
| 反派的恶突然"顿悟"被感化 | 廉价的救赎 | 改变是渐进的，需要多次触发+痛苦。或者不改 |
| "觉醒了"然后突然变成好人 | 一句话改变人生 | 每一步微变化需要触发事件。没有触发事件的变化不可信 |
| 配角围着主角转 | 主角光环太重 | 配角有自己的生活、目标、时间线。主角不在时他们在做自己的事 |
| 顿悟式成长（某人一句话就"想通了"） | 舒适不会让人改变 | 改变的催化剂必须是痛苦的。旧应对机制彻底失效时人才会改变 |

## AI味检测方法 V2.0

### 写完每章后自查（4层检测）

**第一层：词汇扫描（快速）**
1. 搜索高频AI副词（不禁/缓缓/淡淡/微微……），出现超过 1 次就改
2. 搜索"震惊""难以置信""倒吸一口凉气"，每章合计不超过 1 次
3. 检查对话——如果不像真人说话就改

**第二层：句式扫描（重点）**
4. 🔴 搜索连续3个以上独立短句（句号切割法）→ 合并或用逗号/破折号串联
5. 🔴 统计"不是X，是/因为/为了Y"句式次数，超过2次必须改
6. 🔴 检查设定首次出现后是否紧跟解释 → 删除解释，延后到另一场景用行动展示
7. 检查是否有超过 3 句连续的心理描写或环境描写

**第三层：结构扫描（深层）**
8. 🔴 检查各场景是否使用相同的叙事模板 → 至少2/5的场景打破模板
9. 🔴 检查段落长度分布——如果每段都是3-4句/15-20字 → 需要变速
10. 检查紧张场景和日常场景的句式长度是否有明显差异 → 无差异就改

**第四层：角色扫描**
11. 检查角色行为是否符合蒸馏文件中的人设
12. 检查是否有角色突然"顿悟"而没有触发事件
13. 检查配角是否有独立的行动和动机

## 第五层：AI的安全本能（最深层）

AI写作最根本的问题不是词汇、句式、结构——是AI**本能地追求安全**。

AI的训练目标让它在写作时默认选择：
- 读者能理解的（牺牲含蓄）
- 读者能接受的（牺牲冒犯）
- 读者能消化的（牺牲留白）
- 读者能预期的（牺牲意外）
- 读者能满意的（牺牲刺痛）

这五个"安全选择"构成了AI写作最深的指纹——**它永远不会让读者不舒服**。

### 安全本能的五种表现

| 表现 | AI默认行为 | 破解方法 |
|------|-----------|---------|
| **怕读者不懂** | 每个暗示都要解释，每个伏笔都要回收确认 | 砍掉50%的解释。读者比AI以为的聪明得多 |
| **怕读者难受** | 角色受苦时总有补偿，失去后总有获得 | 不补偿。失去就是失去。不公就是不公 |
| **怕读者无聊** | 每段都塞信息，每章都有转折，不给喘息 | 敢于无聊。真正的无聊段落让后面的爆发更猛 |
| **怕读者意外** | 所有转折都有铺垫，所有反转都有线索 | 允许无预警的事件。真实世界没有伏笔 |
| **怕读者不满** | 结局总让主角得到某种胜利或成长 | 允许失败。允许倒退。允许没有意义 |

### 深层破解原则

1. **不舒服的地方正是好文字所在** —— 如果写完一段觉得"这会不会太狠了"，保留它
2. **未消化的情绪最有力量** —— 不用帮读者处理情绪，留给他们在心里自己发酵
3. **真正的残忍是轻描淡写** —— 不用渲染苦难，用平静的语气写残酷的事
4. **读者记住的永远不是解释，是画面** —— 一个画面顶一百句"他明白了"
5. **最好的结尾不是闭环，是缺口** —— 读者带着那个缺口离开，然后想了一整夜

## 第六层：借鉴 Humanizer-zh 的补充模式（网文适配版）

> 来源：[Humanizer-zh](https://github.com/op7418/Humanizer-zh)（7.5k Star），基于维基百科 AI 写作特征指南。
> 以下为我们的前5层未覆盖、但网文写作中同样高发的 AI 指纹模式。

### 6.1 🔴 AI指纹 #11：系动词回避（用复杂结构替代"是/有"）

**症状**: AI 用"作为/充当/标志着/拥有/设有/提供"替代简单的"是/有"。

```
❌ AI系动词回避（绕弯子说简单的事）：
"灵站作为地下聚落的能源中枢，充当着所有人的生命线。"
"这把刀拥有三层灵纹结构，提供远超普通武器的切割力。"

✓ 人类写法（直接说）：
"灵站是地下聚落的能源中枢，所有人都靠它活。"
"这把刀有三层灵纹，比普通武器锋利得多。"
```

**检测规则**:
- 搜索"作为/充当/标志着/拥有/设有/提供"替代"是/有"的用法 → 每章≤2次
- 名词+是+名词 的简单句被改写为复杂结构 → 改回简单句

**网文警示词表**:
| AI绕弯 | 直接替代 |
|--------|---------|
| 作为…… | 是…… |
| 充当着…… | 是…… |
| 标志着…… | 是…… / 意味着…… |
| 拥有……（指属性） | 有…… |
| 设有…… | 有…… |
| 提供了……（指功能） | 能…… |

---

### 6.2 🔴 AI指纹 #12：三段式法则过度使用

**症状**: AI 强行将想法分成三组以显得全面。"A、B和C"三段式排比。

```
❌ AI三段式排比（强行凑三）：
"他感到了恐惧、愤怒和绝望。"
"灵能体系分为感知、操控和共鸣三个阶段。"
"这座城市充满了活力、希望和机遇。"

✓ 人类写法（两项或四项，不刻意凑三）：
"他怕。也怒。"（两项，短促有力）
"灵能体系分感知和操控两个阶段，共鸣是极少数人才能触及的。"（两项+补充）
"街上人多了，摊贩也多了，偶尔能看见几个穿灵纹服的，还有人在巷口卖灵能汤。"（多项自然罗列）
```

**检测规则**:
- "A、B和C"三段式排比每章≤3次
- 连续2个三段式排比 → 后一个必须改为两项或四项
- 三段式排比中三项都是抽象名词 → 必须改（恐惧/愤怒/绝望 → 具体反应）

---

### 6.3 🔴 AI指纹 #13：同义词循环（刻意换词）

**症状**: AI 有重复惩罚机制，导致同一事物用不同词反复指代，读起来像在绕圈。

```
❌ AI同义词循环（同一事物换三个词说）：
"沈野握紧了短刀。少年深吸一口气。这个年轻人知道不能犹豫。"
——"沈野""少年""这个年轻人"是同一个人，刻意换词反而突兀

"灵能在管道中流淌，灵波沿着管壁扩散，灵力充盈了整个空间。"
——"灵能""灵波""灵力"是同一概念，换词不换意

✓ 人类写法（同一事物用同一个词，或用代词）：
"沈野握紧短刀，深吸一口气。他知道不能犹豫。"
"灵能在管道中流淌，沿着管壁扩散，充盈了整个空间。"
```

**检测规则**:
- 同一段内对同一人/物使用3+个不同称呼 → 统一为1个称呼+代词
- 连续3句用3个不同词指代同一概念 → 保留最常用的1个词
- 角色称呼在对话中可以变化（对方叫"小沈"vs自称"我"），但旁白中应统一

---

### 6.4 🔴 AI指纹 #14：过度限定（层层削弱）

**症状**: AI 在陈述前加大量限定词，生怕说错。"可能""也许""某种程度上""似乎"堆叠。

```
❌ AI过度限定（层层削弱，不敢说死）：
"这可能在某种程度上意味着灵能体系或许正在发生某种变化。"
"他似乎隐约感觉到可能有什么不对。"
"可以说，这也许算是一种进步。"

✓ 人类写法（敢说，错了再修正）：
"灵能体系在变。"
"他感觉不对。"
"这是进步。"
```

**检测规则**:
- 一句内出现2+个限定词（可能/也许/似乎/某种程度上/或许/大概/可以说）→ 只保留1个或全删
- "可能……或许……"双重限定 → 必须删到只剩1个
- 陈述事实时用限定词 → 删掉限定词，直接陈述

---

### 6.5 🔴 AI指纹 #15：夸大象征意义（万物皆象征）

**症状**: AI 喜欢把任何细节都拔高到象征层面，赋予"更深层含义"。

```
❌ AI夸大象征（万物皆隐喻）：
"裂缝在管壁上蔓延，象征着地下世界正在崩塌的秩序。"
"灰蜥的嘶鸣回荡在管道中，仿佛是这片废墟最后的叹息。"
"他握紧的拳头，是对命运无声的抗争。"

✓ 人类写法（物就是物，不必升华）：
"管壁上的裂缝又多了几条。"
"灰蜥的嘶鸣在管道里回荡。"
"他握紧了拳头。"
```

**检测规则**:
- 搜索"象征着/仿佛是/是对……的抗争/代表了/意味着更深的" → 每章≤1次
- 物理描写后紧跟象征解读 → 删掉象征解读，让读者自己感受
- "仿佛"用于比喻可以（每章≤3次），但用于象征性升华必须删

**网文警示词表**:
| AI夸大象征 | 替代 |
|-----------|------|
| 象征着 | 删掉，或改为角色视角（"他觉得这像是在……"） |
| 仿佛是……的叹息/哀鸣/低语 | 删掉拟人化，只写声音 |
| 是对……的无声抗争 | 删掉升华，只写动作 |
| 代表了更深的 | 删掉，让读者自己悟 |
| 这不仅仅是X，更是Y | 改为"这是X"或"这是X，也是Y" |

---

### 6.6 🔴 AI指纹 #16：通用积极结论（强行升华）

**症状**: 每个段落/场景/章节都以"积极展望"或"意义升华"收尾。

```
❌ AI强行升华（每段都正能量收尾）：
"尽管前路未卜，但沈野知道，只要不放弃，总会找到出路。"
"这一夜虽然艰难，却让他们的关系更近了一步。"
"灵能的奥秘还有很长的路要探索，但每一步都值得。"

✓ 人类写法（不升华，停在当下）：
"沈野没想那么远。先活过今晚再说。"
"那一夜谁都没睡好。"
"灵能的奥秘？他现在只想搞清楚怎么不把自己炸了。"
```

**检测规则**:
- 段落/场景末尾出现"尽管……但……总会/终将/值得" → 必须改
- 章节末尾出现意义升华 → 改为悬念/画面/动作/对话收尾
- "这一X虽然Y，却让Z更W" 强行找积极面 → 删掉积极面，停在负面或中性

**网文特有变体**:
| AI强行升华 | 替代 |
|-----------|------|
| "虽然艰难，但他变得更强大了" | "他没变强。只是更会忍了。" |
| "这次失败让他看清了方向" | "他没看清方向。只是知道这条路走不通。" |
| "失去的终将以另一种方式归来" | "失去的就是失去了。" |
| "痛苦让他成长" | "痛苦就是痛苦。成长是后来的事，也可能不来。" |
