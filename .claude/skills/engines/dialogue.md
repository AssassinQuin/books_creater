## 对话生成协议

### Step 1: 加载说话人档案

写对话前，对每个开口的角色执行：

```
1. character_get_by_name(novel_name="这次不一样了", character_name={character_name}) → 提取:
   - speech_style: 句式节奏(短句/长句/碎句/正式)
   - catchphrase: 口头禅
   - personality: 核心性格（影响语气）
   - background: 出身（影响用词层次）

2. relation_list → 查说话人对听话人的关系:
   - relation_type: ally/family/rival/subordinate...
   - intensity: 1-10（影响亲密度）
   - description: 关系描述（影响说话方式）
```

### Step 2: 关系调节语气

同一人物对不同对象语气不同：

| 关系类型 | 语气倾向 | 示例(方岩) |
|----------|---------|-----------|
| 对战友 | 简短直接/暗含信任 | "堵上。""别废话。走。" |
| 对晚辈 | 克制关心/不多说 | "你的碎片，注意控制。" |
| 对陌生人 | 警惕/沉默/单字 | "嗯。""不进去。" |
| 对敌人 | 冷/不加修饰 | (方岩不废话，直接动手) |
| 对弱者 | 不刻意温柔但会给 | (把短刀借给沈野) |

### Step 3: "说"字替代四法

**核心原则**：别把"说"字当成必需品。用动作、神态、环境、语感替代"他说/她说"。

| 方法 | 核心思路 | 关键提示 |
|------|---------|---------|
| **动作卡位法** | 用动作代替"说"，让人物边做动作边说话 | 同一角色同一章内，同一动作只用一次；优先手部+头部组合 |
| **神态神韵法** | 用表情、神态代替"说"，情绪直接透出来 | 同一角色同一章内，同一情绪用不同神态表达；优先眼部+嘴部组合 |
| **情境穿插法** | 在对话中间插一句环境描写，自然打断"说"字 | 情绪转折处、对话停顿处插入；1-2句即可 |
| **语感辨识法** | 靠角色语言特色直接省略"说"字 | 每个主要角色的句式节奏、口头禅、用词层次必须有明显差异 |

**动作/神态/环境使用铁律**：
1. 服务于情绪，每处动作/神态都有对应的情绪来源
2. 克制表达：末日基调下，幅度要小，点到即止
3. 环境描写优先使用听觉+嗅觉，比视觉更有代入感
4. 避免过度使用"眼神"，可换成目光、视线、眼角、瞳孔

### Step 4: 弦外之音

中国文学意境——说出来的话≠真实意图：

```yaml
表达层次:
  表层台词: "没事。就是脏了。"  (沈念对阿婆说手指发灰)
  真实意图: 我知道这是灵衰症，我不想让你担心
  暗示手段:
    - 动作: 手指蜷了一下（下意识隐藏）
    - 微表情: 笑了一下（硬撑）
    - 环境呼应: 阿婆的沉默（老人看穿但不说破）

常用技法:
  - 以动作代心理: "攥紧了。攥了又松。" → 不写"他很紧张"
  - 以环境代情绪: "风从西边吹过来，焦糊味比昨天淡了一点" → 不写"他松了口气"
  - 以沉默代回答: 方岩没接话 → 不写"方岩不想谈这个"
  - 以重复代执念: "碎罗盘不在手里了——手空了" → 不写"他很不舍"
```

## 标点符号规范

AI写作的标点使用往往单调（逗号+句号为主），丰富标点能打破机械感。

**核心规则**：
- 对话中每3-5句至少使用1次破折号、省略号或感叹号
- 紧张场景多用短句+句号快切，情感场景多用省略号+破折号
- 避免连续5句以上只用逗号和句号
- 问号不仅用于疑问，也可表不可置信、反问

## 对话结构规则

### 对话节奏标准
超过3句纯对话必须插入动作/微表情/环境——让读者"看到"说话的人。

### 微表情使用原则
- 同一角色同一章内，同一情绪用不同动作表达
- 优先使用组合：眼部+手部、面部+身体，比单一部位更生动
- 每次紧张换不同部位：攥拳/咬唇/后颈发凉/眼神移开/手指敲桌面
- 微表情是"微"的，动作幅度要小，点到即止
- 与对话紧密相连：出现在对话前后，服务于当下的对话情绪

### 通感技巧
跨感官描写，增加文学意境：
```
视觉→触觉: "他的目光像砂纸蹭过手背"
听觉→温度: "声音凉下来。管道里的风也凉了"
情绪→环境: "话说到一半，外面的风停了"
```

## 对话差异化示例

### 沈野 (主角·拾荒者)
- **基础语气**: 极少说话，多为短句/单字回应
- **对沈念**: 话比平时多一点，但从不解释为什么做某事（用行动代替）
- **对陌生人**: 沉默观察，只说必要的
- **紧张时**: 不说话，手攥紧

### 沈念 (妹妹·13岁)
- **基础语气**: 比哥哥话多，但不说多余的话
- **对小孩**: 自然变软，"念姐"的语气
- **对灵站员工**: 礼貌但防备，不暴露太多
- **隐藏病情时**: 语气正常，但会突然停顿/换手做事

### 方岩 (老兵·壁盾斥候)
- **基础语气**: 像读报告，没有波动
- **回忆战友时**: 嘴角动一下（不是笑），语气不变但内容变
- **教沈野时**: 简短指令式，不解释原理只说方法
- **痛苦时**: 也不说，腿弯了一下，继续走

## 动作代情绪法（核心写作技法）

> 原则：**不直接说"他难过"，而是写"他做了什么"**。情感在动作里自己显形。

### 两步操作法

1. **停下"他觉得/他感到"** → 问：此刻，他的身体哪个部位最诚实？是手在抖，还是喉咙发紧，还是眼睛不知道该看哪里？
2. **诚实部位+日常动作** → 不是"他焦虑"，而是"他不停地用指甲去抠茶杯上那个掉漆的豁口，直到指尖发白"

### 情绪→动作替换表

| 情绪词 | ❌ AI写法 | ✅ 动作代情绪 |
|--------|---------|-------------|
| 紧张 | "他非常紧张，心跳加速" | "他接过纸，看了三遍。第一遍很快，第二遍很慢，第三遍目光停在某个字上，像被钉住了。然后他把纸对折，再对折，折成一个再也打不开的硬块" |
| 悲伤 | "他感到无比悲伤" | "他站在那里，把口袋里的钥匙翻出来又放回去，翻出来又放回去" |
| 愤怒 | "他怒火中烧" | "他咬了一下后槽牙，没说话，把筷子放下了" |
| 焦虑 | "他焦虑不安" | "他不停地用指甲抠茶杯上那个掉漆的豁口，直到指尖发白" |
| 委屈 | "他心里很委屈" | "他低头把鞋带系了又解，解了又系" |
| 恐惧 | "他恐惧万分" | "他的手在桌下攥成拳，指甲掐进掌心，但他脸上什么都没有" |
| 心动 | "他心跳加速" | "他端起杯子喝了一口，发现是空的，又放下了" |

### 检测规则

- 搜索"他感到/他觉得/他心中/他内心/他不禁" → 每处必须替换为动作或删除
- 每章直接情绪词 ≤5个（"他害怕""他高兴"等）
- 高压场景（战斗/对峙/告白）中直接情绪词 = 0
- 例外：内心独白可用情绪词，但旁白中必须用动作替代

## QA校验规则

检查对话时验证：
1. **语气匹配**: 说话人的用词/句式是否符合character档案
2. **关系匹配**: 对不同对象的语气是否有差异（如果对所有人都一样→OOC）
3. **知识边界**: 角色说的信息是否超出了他"应该知道"的范围
4. **伴随动作**: 纯对话堆叠是否超过3句
5. **微表情重复**: 同一微表情是否在同一章出现超过2次
6. **"说"字冗余**: 是否过度使用"他说/她说"，优先用动作/神态/环境替代
7. **标点丰富度**: 对话中是否每3-5句至少使用1次破折号、省略号或感叹号
8. **标点单调**: 是否连续5句以上只用逗号和句号
9. **动作多样性**: 同一角色同一章内，同一动作只用一次，每次用不同身体部位
10. **神态多样性**: 同一角色同一章内，同一情绪用不同神态表达
11. **环境多样性**: 同一章内，同一环境元素只深入描写一次
12. **微表情组合**: 优先使用眼部+手部、面部+身体组合
13. **情绪表达轮换**: 紧张时轮换身体部位（手/嘴/眼/颈/肩/脚），每次用不同方式
14. **克制表达**: 微表情是"微"的，动作幅度要小，点到即止
