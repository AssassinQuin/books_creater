# 场景深化指南（反注水）

> 核心原则：扩写≠加字数。扩写=给已有内容加更多层次和意义（deepening），不是停留在表面重复（padding）。
> 具体案例见 `reference-deepening-examples.md`

---

## 一、密度原则（最高法则）

**每句话做多件事。** 如果一句话只做一件事，它就缺乏密度。

| 层压（错误） | 融合（正确） |
|-------------|------------|
| 描写+对话+动作简单叠加，各层可删 | 描写同时暗示情绪、对话同时展示关系、动作同时推进情节 |

**反密度信号**: 一个段落只展示角色一个面、只推进一步情节、只揭示一个设定 → 天然薄，需要深化。

---

## 二、深化 vs 注水判别

| 维度 | 深化（Deepening） | 注水（Padding） |
|------|-----------------|----------------|
| 信息密度 | 每句有新信息 | 重复说同一件事 |
| 感官 | 五感交织有主次，基于角色兴趣 | 机械罗列 / 只加一句"有X味" |
| 细节 | 选取有意味的（象征/暗示） | 无差别罗列 / 加形容词 |
| 人物关联 | 细节反映性格/状态/关系 | 细节与人物无关 |
| 因果 | 每个扩展有因果必然性 | 随机插入无因果内容 |
| 潜台词 | 表面之下有未说出的东西 | 表面即全部 |
| 服务于 | 人物/情节/主题/伏笔 | 字数 |

## 三、六大扩写技法

### 3.1 五感递进法

**不用清单式罗列。用递进公式：**

```
感官刺激 → 生理反应 → 认知判断 → 行动决策
```

**2+1法则**: 视觉+听觉为基线，加一种第三感制造"兴趣钩子"。

**角色兴趣原则**: 角色注意到的 = 角色关心的 + 异常的。不是打勾清单。

### 3.2 动作分解法

**把"做了什么"变成"怎么做的"。** 每个微动作传递不同信息。

每步同时传递: 温度(触觉) + 声音(听觉) + 光线(视觉) + 身体反应 — 一句话做多件事。

### 3.3 环境交互法

**角色与环境的互动自然带出世界观，不是静态罗列。**

**微展开原则**: 角色每次回到同一场景，暴露1-2个新细节，保留锚点物件。不要一次性描写完。

### 3.4 对话扩展法

**对话中同时发生的4件事**: 传达信息 + 展示性格 + 推进关系 + 潜台词。

### 3.5 因果链展开法

**从结果反推因果链，每步都是一个场景。**

**Yes-but / No-and 技巧**:
- 找线索A → 没找到（No） → 但发现线索B（and）
- 争赢了议题A（Yes） → 但暴露了隐藏的议题B（but）

**感情反复法**: 想做 → 折回 → 又想 → 又折回 → 终于爆发。犹豫和反复天然产生篇幅+心理张力。

### 3.6 摘要戏剧化（Telling → Showing）

**把"告诉"变成"展示"。**

## 四、场景分层模型

每个完整场景需要五层元素交织:

| 层次 | 内容 | 扩展方式 |
|------|------|---------|
| **对话层** | 角色说出的话 | 加潜台词/话中话/打断/沉默 |
| **内心层** | POV角色没说出口的 | 加判断/回忆/算计/犹豫 |
| **描写层** | 可感知的一切 | 五感递进/微展开/环境变化 |
| **动作层** | 物理发生的事 | 动作分解/因果链/微动作 |
| **情感层** | 身体泄露的情绪 | 微表情/本能反应/矛盾信号 |

不用等量，但全部要出现。缺失任何一层，场景感觉"薄"。

## 五、字数不足时的扩写决策树

```
字数不足？
├─ 是否有"一次只做一件事"的段落？ → 加层（描写+情绪 / 对话+关系）
├─ 关键动作是否分解了？ → 动作分解法
├─ 感官是否只用了一种？ → 五感递进法（基于角色兴趣加第二第三种）
├─ 对话是否只有信息交换？ → 加潜台词/动作打断/环境反应
├─ 世界观是否通过互动展示？ → 环境交互法
├─ 是否有可以展开的因果链？ → 因果链展开法
├─ 是否有Telling可以变Showing？ → 摘要戏剧化
├─ 是否可以加一个小冲突/障碍？ → Yes-but / No-and
└─ 以上都不适用 → 加一个有因果的分支事件（日常/NPC/世界观观察）
```

**绝对不要**: 加一句孤立感官描写/加一句无因果过渡/重复标志性意象/加形容词堆砌。

## 六、禁止的注水模式

| 模式 | 示例 | 为什么错 |
|------|------|---------|
| 孤立感官 | 原文 + "空气里有消毒水的味道" | 只做1件事，无因果无人物关联 |
| 无信息过渡 | 原文 + "他继续走" | 零信息量 |
| 重复意象 | 每章都提"太阳画""摩挲指关节" | 不是深化是重复，读者审美疲劳 |
| 形容词堆砌 | "很大的很漂亮的很宽敞的" | 不增加任何具体信息 |
| 环境静态罗列 | "走廊里有灯。灯是白的。" | 无人物交互，无因果推进 |
| 角色自言自语 | "他想：这可怎么办呢" | 低于该角色水平的思考 |

**替代法则**: 每当想加一句话凑字数，先问"这句话是否同时在做两件以上的事？" 如果不是，用能做多件事的方式重写。
