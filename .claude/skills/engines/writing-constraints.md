# 写作约束配置

本文件是 MCP 校验工具的约束来源。修改后 MCP 自动生效。
格式为 Markdown 表格，MCP 用正则解析。

## 硬约束（百分比密度）

基于占章节总字数的千分比(‰)计算。

| key | 标签 | min‰ | max‰ | 说明 |
|-----|------|------|------|------|
| em_dash | 破折号密度 | 2.0 | 4.0 | —— 占千分比 |
| ellipsis | 省略号密度 | 0.8 | 1.5 | …… 占千分比 |
| semicolon | 分号密度 | 0.3 | 0.8 | ；占千分比 |
| exclamation | 感叹号密度 | 0.3 | 1.0 | ！占千分比 |

## 违禁词

以下词出现在正文中直接拦截，必须替换为具体动作/感官描写：

- 可能吧 → 删掉或换成具体动作（"他搓了搓手指"）
- 事情没那么简单 → 删掉或换成角色具体推理
- 你不懂 → 换成角色具体解释或沉默
- 你不明白 → 同上
- 听我说 → 删掉或换成角色拉住对方/压低声音等动作

> AI副词替换清单→见`engines/anti-ai-patterns.md`·第一层词汇级

## 创作原则（7条核心+4条补充）

### 7条核心——写中强制检查

| key | label | 规则 | 参考 |
|-----|-------|------|------|
| 刀锋技法 | 刀锋技法(至少1种) | 至少1种：沉默暴击/暴力插入/不回头/尺度崩塌/反高潮/情绪断层/悬而未决。使用后禁止解释/升华/角色自我剖析。先沉默，再断裂，不留注解。 | 铁律8衍生 |
| 质量方差 | 质量方差(粗糙段2-3个) | 2-3个粗糙段/章（无感官/无比喻/纯动作），相邻段落质量差≥20分。连续精写≤3段。不能每段都"认真写"——要让读者感受到"这段作者没用力"。 | 铁律4衍生 |
| 废笔配额 | 废笔配额(3种/章) | 3种废笔/章(角色废话/环境废笔/生活碎片/假伏笔/跑题对话)，真废笔和废线按需使用。每章至少3处看似"没用"的内容——它们的作用是让读者相信世界在正常运转。 | 铁律5衍生 |
| 角色失控 | 角色失控(1+次/章) | 1+次/章角色"不对"(说蠢话/情绪过头/oversharing/跑题/不理性决定)。不是OOC——是不太理智但符合人物逻辑框架的偏离行为。不是为了制造戏剧冲突而写的。 | 铁律7衍生 |
| 饱和度不均 | 饱和度不均(主角>NPC>路人) | 主角超饱和(过量细节)，NPC极简(1个特征反复用)，路人透明。不撒匀。不是"这句给主角、那句给NPC"的均匀分配，是主角的细节密度远高于其他人。 | - |
| 留白不点破 | 留白不点破(禁止升华) | 禁止金句总结主题/象征。主题通过人物行为传达，不用叙事者评论。不解释角色的情感——通过动作、环境、他人的反应展现。写了"他觉得温暖"就失败。 | - |
| 节奏断层 | 节奏断层(1+处/章) | 1+处/章叙事节奏真的断了(突然加速/停滞/切走/时间塌缩)。不是所有章节都匀速——让读者偶尔感到"这里节奏不对"或是"这段咋回事"。爆炸事件的章节必须让人感觉到爆炸的分量，日常章节用断层替代爆炸。 | - |
