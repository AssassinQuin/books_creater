## 动作链5拍

每个完整动作遵循：预备→启动→接触→反馈→转换

### 1. 预备
身体姿态+环境条件+心理一瞬：
```
灰蜥蹲了一下后腿。（预备——它在蓄力）
沈野的手指碰到碎渣弹的瞬间就知道是弹不是石。（预备——手指的感知）
```

### 2. 启动
肌肉发力+方向+速度：
```
他往左滚——碎石在脚下打滑。（启动+阻碍）
灰蜥从管道上方跳下来。（启动——垂直方向）
```

### 3. 接触/释放
力量传递+灵能反应：
```
老陈一铁棍砸在灰蜥的灵能结晶上。铁棍碰到灵能结晶的时候发出一声脆响。（接触+声音反馈）
碎渣弹在管道里炸了。灵能冲击波在管道壁上反弹了两三次。（释放+空间效果）
```

### 4. 反馈
目标反应+环境变化+自身体感：
```
灰蜥歪了一下，但没倒。（目标反应）
铁锅翻了，面糊洒了一地，已经干了。（环境变化）
肩膀上一道火辣辣的疼——皮划了，不深。（自身体感）
```

### 5. 转换
回位或进入下一个动作的预备：
```
沈野翻身爬起来。灰蜥也转身了，比他快。（转换——新态势）
他蹲了一下后腿，又准备扑。（进入下一次循环的预备）
```

## 空间感知

### 动作前建立空间参照
```
管道宽度刚好够一只灰蜥转身。但不够两个人并排。
——这为后面的"堵后面"战术提供空间依据。

断裂口在第三区和第二区交界的地方。
——这为"绕路半圈多走百步"提供距离感。
```

### 动作中标注位置变化
```
沈野在前面探路。方岩在后面拖着右腿。→（两人间距）
前面那只灰蜥在管道深处——离他们十五步。→（与威胁的距离）
他往西走。→（方向明确）
```

### 动作后更新空间关系
```
铁皮被撞弯了但没破。→（空间结构变化）
灰蜥的爪子在铁皮上划了三道。→（环境痕迹）
碎石堆从管道口移到了管道里面。→（位置变化）
```

## 具体化规则

### 禁止模糊动作
```
❌ "打了"        → ✅ "拳头砸在颧骨上"
❌ "躲开了"      → ✅ "腰往右拧了半寸，爪子擦着棉衣过去"
❌ "受伤了"      → ✅ "肩膀上渗出一道红线，布料黏在皮肤上"
❌ "跑得很快"    → ✅ "他的脚步在碎石上嘎吱嘎吱响"
❌ "很疼"        → ✅ "膝盖弯了一下，吸了口气"
❌ "用力了"      → ✅ "铁棍碰到灵能结晶的时候发出一声脆响，结晶裂了"
```

### 身体部位具体化
```
不用"身体"→ 拆成具体部位:
- 手部: 指尖/指节/手掌/手腕/手背/指甲
- 腿部: 膝盖/脚踝/脚底/小腿/大腿
- 躯干: 肩膀/后背/肋骨/腰/胸口
- 头部: 下巴/嘴角/眼角/额头/太阳穴
```

### 灵能交互具体化
```
灵能不是抽象的"能量"——它有物理表现:
- 接触: 麻/刺/烫/凉/微弱的针扎感
- 视觉: 灰白/暗绿/蓝光/结晶闪光
- 听觉: 嗡嗡声/脆响/闷响/水声
- 嗅觉: 焦糊味/金属味/苦味
- 反应: 白烟/灰白痕迹/结晶碎裂/灼烧痕迹
```

## 动作节奏

### 快节奏（紧张/战斗）
- 短句为主，每句一个动作
- 少用修饰，多用动词
- 省略过渡，直接跳到下一个动作
```
灰蜥扑了。沈野往左滚。碎石打滑。他摔倒在阴影里。
爪子擦着肩膀过去。疼。皮划了。不深。他翻身爬起来。
```

### 慢节奏（日常/回忆/等待）
- 长句，有修饰，有感官细节
- 一个动作展开多角度描写
- 用动作节奏暗示心理节奏
```
方岩用旧布沿着刀刃从根部到刀尖擦了一遍，动作很慢，像在摸一道旧疤。
短刀翻过来，看了看刀背。刀背上有一道刻痕——细细的一条线。
```

### 节奏切换
动作场景中穿插一个慢拍=强调点（燃点设计）：
```
快快快快——停。
"灰蜥翻的一瞬间——腹部白。没有鳞片。灵能结晶全在背脊上，腹部的灵能回路裸露在外面。他看到了。"
——快快快快。
```
