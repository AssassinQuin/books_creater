# 三视角大纲分析

> 从读者、作者、人物、编辑四个角色同时审视大纲框架，多维度发现可优化点。
> 适用时机：卷级大纲完成后、章节规划前，或大纲重大修改后。

---

## 前置条件

| 条件 | 说明 | 不满足时的fallback |
|------|------|-------------------|
| 至少3卷大纲 | 需要3卷以上才能分析节奏曲线 | 2卷时只做"开篇分析"，1卷只做单卷检查 |
| 角色深化文档 | 非必须，有则分析人物弧光更准确 | 跳过弧光验证，标注"缺角色数据" |
| 世界观设定 | 非必须，有则分析逻辑一致性更准确 | 跳过世界观交叉验证 |
| 全部卷级大纲 | 理想情况全有 | 缺卷标注"未分析"，只评已有卷 |

## 执行流程

```
Step 1 召回材料 → Step 2 🔒确认范围 → Step 3 四视角并行分析 → Step 4 🔒审阅报告 → Step 5 汇总优化计划 → Step 6 🔒确认计划 → Step 7 保存
```

### Step 1: 召回材料

读取以下文件（如存在）：
- `novels/{小说名}/设定/大纲/*.md` — 全部卷级大纲
- `novels/{小说名}/设定/角色总览.md` — 角色文档
- `novels/{小说名}/设定/世界观.md` — 世界观设定

### Step 2: 🔒确认分析范围

**等用户确认后才继续。** 用户可选：
- "全部分析" → 四视角并行
- "只看读者视角" → 只启动Reader agent
- "只分析V1-V5" → 限定范围

### Step 3: 四视角并行分析

四个子agent并行执行。每个agent读取全部大纲材料后按各自维度分析：

| Agent | 核心问题 | 审查引擎 | 详细清单 |
|-------|---------|---------|---------|
| **读者** | "我会不会追更？" | `reader-perspective-agent.md` | 钩子/爽点/弃文风险/情感共鸣/信息层级 |
| **作者** | "这个故事讲得通吗？" | `author-perspective-agent.md` | 因果链/起承转合/伏笔/节奏/主题一致性 |
| **人物** | "角色这样行动合理吗？" | `character-perspective-agent.md` | 性格一致/动机充分/选择必然/代价明确 |
| **编辑** | "这本书能卖吗？" | （见下方编辑视角） | 品类/开篇/商业节奏/差异化/完结风险 |

### 四视角审查标准

> **各视角的详细审查维度和评分标准见 `three-perspective-review.md`**。本文件只列出核心问题。

**读者**（核心："我会不会追更？"）：
- 钩子强度（每卷开头3行能否抓住注意力）
- 爽点节奏（每2-3卷小爽点/4-5卷大爽点，无连续3卷无爽点）
- 弃文风险（哪些卷最可能流失读者）
- 情感共鸣/代入感/信息过载/伏笔疲劳

**作者**（核心："这个故事讲得通吗？"）：
- 因果链穿透（每个"因为"追溯到"所以"，拒绝"剧情需要"）
- 关键动作动机充分性（救/帮/信任动作需要具体压力/事件/信息驱动，仅"善良"不够）
- Weiland弧线框架（Ghost→Lie→Want→Need）
- 结构力度/主题一致性/角色利用率/冲突密度
- "作者方便"检测（标记所有"读者问为什么答案只有剧情需要"的节点）

**人物**（核心："角色这样行动合理吗？"）：
- 行为逻辑/性格一致性/能力边界/知识边界
- 动机充分/动机层次/动机变化
- 选择必然性（别无选择+代价明确+后悔空间+连锁反应）

**编辑**（核心："这本书能卖吗？"）：
| 维度 | 标准 |
|------|------|
| 品类匹配 | 核心爽点是否符合目标品类 |
| 开篇质量 | 黄金三章：前3章金手指/前3卷1胜 |
| 人物商业性 | 主角一句话能描述=及格 |
| 差异化 | 至少1个独特卖点 |
| 长篇可持续性 | 14卷体量能否撑住 |
| 完结风险 | 哪些设定可能导致后期崩盘 |

### Step 4-6: 审阅报告 → 汇总 → 确认

**交叉检查**（编排器汇总，详情见 `three-perspective-review.md`）：
- 读者vs作者：结构服务读者体验，不是反过来
- 读者vs人物：人物选择优先，需有充分动机
- 作者vs人物：人物性格优先，作者调整结构
- **核心原则**：人物 > 读者 > 作者

**问题分级**：P0(三视角冲突/必须修复) → P1(单视角严重/必须修复) → P2(建议修复) → P3(可选)

**优化计划**：按重叠度排序（三视角重叠→双视角重叠→单视角独有）

### Step 7: 保存

保存到 `novels/{小说名}/docs/三视角分析-{日期}.md`。

## 异常处理

| 场景 | 处理 |
|------|------|
| 大纲只有1-2卷 | 只做开篇分析 |
| 用户只要1个视角 | 只启动对应agent |
| 缺角色文档 | 弧光分析降级 |
| 中途材料更新 | 从Step 1重来 |
