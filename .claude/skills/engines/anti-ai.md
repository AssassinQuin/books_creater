# AI指纹专项检测指南

> **用途**: novel-qa 正文审阅时，Agent C 质量维度新增 AI 指纹检测子维度。
> **定位**: 检测标准（如何发现+评分+分级）。
> **配合文件**: `anti-ai-patterns.md` 是模式清单（每种AI味的模式描述+示例+自我检测方法），本文档是打分标准。
> **关系**: 写作自查用 patterns.md；正式审阅 scoring 用本文件。

---

## 检测维度（4项核心指纹）

### FP-1：句号切割法检测

**检测方法**:
1. 统计全章独立短句数量（句号断开，≤8字，不含对话）
2. 计算独立短句占全章总句数的比例

**评分标准**:

| 独立短句比例 | 评分 | 处理 |
|-------------|------|------|
| ≤5% | 10/10 | 通过 |
| 5-10% | 7/10 | 可接受，标注位置 |
| 10-15% | 4/10 | 需要合并，标注所有位置 |
| >15% | 1/10 | 严重AI味，必须重写 |

**额外检查**:
- 是否存在连续3+独立短句的段落 → 每处扣2分
- 紧张场景中句号切割是否合理（允许，但每章≤2处）→ 不合理使用扣3分

---

### FP-2：解释式展示检测

**检测方法**:
1. 搜索设定/物品/概念首次出现的位置
2. 检查同一段或紧邻段落是否有功能性解释
3. 搜索"不是X——是因为/为了Y"动机解释句式

**评分标准**:

| 解释式展示次数 | 评分 | 处理 |
|--------------|------|------|
| 0-1次 | 10/10 | 通过 |
| 2-3次 | 6/10 | 需要改为行动展示 |
| 4-5次 | 3/10 | 严重AI味 |
| >5次 | 0/10 | 必须重写 |

**额外检查**:
- 设定首次出现后紧跟"解释段"（功能性说明而非角色体验）→ 每处扣3分
- 动机通过旁白解释而非行动展示 → 每处扣2分
- 括号注释式设定补充 → 每处扣1分

---

### FP-3：结构对称检测

**检测方法**:
1. 将全章按场景分段
2. 统计每个场景的段落数、平均句长、叙事模板类型
3. 计算场景间段落长度分布的方差

**评分标准**:

| 场景节奏差异 | 评分 | 处理 |
|------------|------|------|
| 方差>40% | 10/10 | 节奏差异明显，通过 |
| 方差30-40% | 7/10 | 可接受 |
| 方差20-30% | 4/10 | 节奏过于均匀 |
| 方差<20% | 1/10 | 严重工整，必须打破 |

**额外检查**:
- 连续3个场景使用相同叙事模板（如都从环境切入）→ 扣4分
- 紧张场景和日常场景句长分布相似 → 扣3分
- 每个场景都以环境铺陈开头 → 扣2分
- 无"急刹车"（极短句独立成段）→ 扣1分

---

### FP-4：否定转折模式化检测

**检测方法**:
1. 搜索全章"不是"出现次数
2. 分析每次否定转折的句式结构是否雷同
3. 检查否定转折后是否紧跟长解释从句

**评分标准**:

| "不是X，是Y"次数 | 评分 | 处理 |
|-----------------|------|------|
| 0-1次 | 10/10 | 通过 |
| 2次 | 7/10 | 可接受 |
| 3次 | 4/10 | 需要改掉多余的 |
| 4-5次 | 2/10 | 明显模式化 |
| >5次 | 0/10 | 严重AI味，必须重写 |

**额外检查**:
- 连续2个段落使用否定转折 → 扣3分
- 否定转折后紧跟>10字解释从句 → 每处扣2分
- 所有否定转折句式结构相同（都是"不是X——是Y"）→ 额外扣2分

---

### FP-5：作者替角色下结论检测（New - 借鉴humanize）

**检测方法**:
1. 搜索旁白式心理动词："他知道/她明白/他们都清楚/意识到/发现"
2. 检查心理总结后是否紧跟具体动作
3. 统计连续段落以心理总结开头的次数

**评分标准**:

| 旁白式心理动词次数 | 评分 | 处理 |
|------------------|------|------|
| 0-1次 | 10/10 | 通过 |
| 2次 | 7/10 | 可接受，确保有动作跟进 |
| 3次 | 4/10 | 需要改为动作展示 |
| 4-5次 | 2/10 | 明显AI味 |
| >5次 | 0/10 | 严重AI味，必须重写 |

**额外检查**:
- 心理总结后无具体动作 → 每处扣3分
- 连续2个段落以心理总结开头 → 扣4分
- "意识到"后紧跟长解释（>15字）→ 每处扣2分

---

### FP-6：段落长度均匀检测（New - 借鉴humanize）

**检测方法**:
1. 统计连续5个段落的字数/句数
2. 计算长度差异百分比
3. 检查是否有"急刹车"（1句话独立成段）

**评分标准**:

| 段落长度差异 | 评分 | 处理 |
|------------|------|------|
| >40% | 10/10 | 节奏差异明显，通过 |
| 30-40% | 7/10 | 可接受 |
| 20-30% | 4/10 | 过于均匀，需要变速 |
| <20% | 1/10 | 严重均匀，必须打破 |

**额外检查**:
- 全章无"急刹车"（1句话独立成段）→ 扣3分
- 紧张场景和日常场景段落长度分布相似 → 扣4分
- 连续3个段落都是4句 → 每处扣2分

---

### FP-7：情绪安全区检测（New - 借鉴humanize）

**检测方法**:
1. 识别高压场景（战斗/生死/背叛/重大决策）
2. 检查角色是否有失误、慌乱、生理反应
3. 检查角色是否永远"冷静分析"而非"本能反应"

**评分标准**:

| 高压场景角色反应 | 评分 | 处理 |
|----------------|------|------|
| 有失误+有生理反应+有情绪边缘 | 10/10 | 真实人类反应，通过 |
| 有2项 | 7/10 | 可接受，建议增加第3项 |
| 有1项 | 4/10 | 过于安全，需要添加 |
| 无（永远从容镇定） | 0/10 | 严重AI味，必须重写 |

**额外检查**:
- 角色"冷静分析"而非"本能反应"→ 每处扣3分
- 冲突场景双方都像在下棋（无失误）→ 扣4分
- 角色情绪始终平稳（无峰值/无低谷）→ 扣3分

---

### FP-8：系动词回避检测（New - 借鉴Humanizer-zh）

**检测方法**:
1. 搜索"作为/充当/标志着/拥有/设有/提供"替代"是/有"的用法
2. 检查简单句是否被不必要地复杂化

**评分标准**:

| 系动词回避次数 | 评分 | 处理 |
|--------------|------|------|
| 0-2次 | 10/10 | 通过 |
| 3-4次 | 6/10 | 需要简化 |
| 5-6次 | 3/10 | 明显AI味 |
| >6次 | 0/10 | 严重AI味 |

---

### FP-9：三段式法则检测（New - 借鉴Humanizer-zh）

**检测方法**:
1. 搜索"A、B和C"三段式排比
2. 检查三项是否都是抽象名词

**评分标准**:

| 三段式排比次数 | 评分 | 处理 |
|--------------|------|------|
| 0-3次 | 10/10 | 通过 |
| 4-5次 | 6/10 | 需要改为两项或四项 |
| 6-7次 | 3/10 | 明显凑三 |
| >7次 | 0/10 | 严重AI味 |

---

### FP-10：同义词循环检测（New - 借鉴Humanizer-zh）

**检测方法**:
1. 检查同一段内对同一人/物是否有3+个不同称呼
2. 检查连续3句是否用3个不同词指代同一概念

**评分标准**:

| 同义词循环次数 | 评分 | 处理 |
|--------------|------|------|
| 0次 | 10/10 | 通过 |
| 1-2次 | 6/10 | 统一称呼 |
| 3-4次 | 3/10 | 明显绕圈 |
| >4次 | 0/10 | 严重AI味 |

---

### FP-11：过度限定检测（New - 借鉴Humanizer-zh）

**检测方法**:
1. 搜索一句内出现2+个限定词（可能/也许/似乎/某种程度上/或许/大概/可以说）
2. 检查陈述事实时是否加了不必要的限定词

**评分标准**:

| 过度限定次数 | 评分 | 处理 |
|------------|------|------|
| 0-1次 | 10/10 | 通过 |
| 2-3次 | 6/10 | 删减限定词 |
| 4-5次 | 3/10 | 明显不敢说死 |
| >5次 | 0/10 | 严重AI味 |

---

### FP-12：夸大象征意义检测（New - 借鉴Humanizer-zh）

**检测方法**:
1. 搜索"象征着/仿佛是/是对……的抗争/代表了/意味着更深的"
2. 检查物理描写后是否紧跟象征解读

**评分标准**:

| 夸大象征次数 | 评分 | 处理 |
|------------|------|------|
| 0-1次 | 10/10 | 通过 |
| 2次 | 6/10 | 需要删减 |
| 3-4次 | 3/10 | 万物皆象征 |
| >4次 | 0/10 | 严重AI味 |

---

### FP-13：通用积极结论检测（New - 借鉴Humanizer-zh）

**检测方法**:
1. 搜索段落/场景末尾的"尽管……但……总会/终将/值得"
2. 检查章节末尾是否有意义升华

**评分标准**:

| 强行升华次数 | 评分 | 处理 |
|------------|------|------|
| 0次 | 10/10 | 通过 |
| 1次 | 7/10 | 可接受，建议修改 |
| 2-3次 | 3/10 | 明显正能量强迫症 |
| >3次 | 0/10 | 严重AI味 |

## 综合评分

### 计算方式

```
AI指纹综合分 = (FP-1 + FP-2 + FP-3 + FP-4 + FP-5 + FP-6 + FP-7 + FP-8 + FP-9 + FP-10 + FP-11 + FP-12 + FP-13) / 13
```

### 分级

| 综合分 | 等级 | 处理 |
|--------|------|------|
| 8.0-10.0 | A | 通过，无明显AI指纹 |
| 6.0-7.9 | B | 轻微AI味，标注位置供作者参考 |
| 4.0-5.9 | C | 明显AI味，建议修改后重新检测 |
| 0-3.9 | D | 严重AI味，必须重写 |

### 与现有15维度扫描的集成

AI指纹检测作为 **Agent C（质量维度）** 的子项 `2.15b` 执行，与 `2.15 写作风格` 并列。

在正文审阅报告中增加独立章节：

## 修复优先级

| 优先级 | 指纹 | 原因 |
|--------|------|------|
| P0 | FP-1 句号切割法 | 最容易被人类读者识别的AI特征 |
| P0 | FP-4 否定转折模式化 | 模式化感极强，读者会感到重复 |
| P0 | FP-7 情绪安全区 | 角色不真实是最致命的 immersion break |
| P0 | FP-13 通用积极结论 | 强行升华是网文最致命的AI味，读者一眼看穿 |
| P1 | FP-2 解释式展示 | 隐蔽但破坏沉浸感 |
| P1 | FP-5 替角色下结论 | 让读者感到"被告诉"而非"自己感受" |
| P1 | FP-8 系动词回避 | 绕弯子说话，网文读者最不耐烦 |
| P1 | FP-12 夸大象征意义 | 万物皆象征=万物皆假 |
| P1 | FP-3 结构对称 | 需要全文分析才能发现 |
| P1 | FP-6 段落长度均匀 | 节奏机械，但相对隐蔽 |
| P2 | FP-9 三段式法则 | 网文中偶有排比可接受 |
| P2 | FP-10 同义词循环 | 部分场景换词有合理性 |
| P2 | FP-11 过度限定 | 限定词在内心独白中可接受 |
