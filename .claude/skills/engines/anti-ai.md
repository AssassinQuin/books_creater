# AI指纹专项检测指南

> **用途**: novel-qa 正文审阅时，Agent C 质量维度新增 AI 指纹检测子维度。
> 本文档是检测的完整规则和评分标准，与 `anti-ai-patterns.md` 配合使用。

---

## 检测维度（4项核心指纹）

### FP-1：句号切割法检测

**检测方法**:
1. 统计全章独立短句数量（句号断开，≤8字，不含对话）
2. 计算独立短句占全章总句数的比例

**评分标准**:

| 独立短句比例 | 评分 | 处理 |
|-------------|------|------|
| ≤5% | 10/10 | 通过 |
| 5-10% | 7/10 | 可接受，标注位置 |
| 10-15% | 4/10 | 需要合并，标注所有位置 |
| >15% | 1/10 | 严重AI味，必须重写 |

**额外检查**:
- 是否存在连续3+独立短句的段落 → 每处扣2分
- 紧张场景中句号切割是否合理（允许，但每章≤2处）→ 不合理使用扣3分

---

### FP-2：解释式展示检测

**检测方法**:
1. 搜索设定/物品/概念首次出现的位置
2. 检查同一段或紧邻段落是否有功能性解释
3. 搜索"不是X——是因为/为了Y"动机解释句式

**评分标准**:

| 解释式展示次数 | 评分 | 处理 |
|--------------|------|------|
| 0-1次 | 10/10 | 通过 |
| 2-3次 | 6/10 | 需要改为行动展示 |
| 4-5次 | 3/10 | 严重AI味 |
| >5次 | 0/10 | 必须重写 |

**额外检查**:
- 设定首次出现后紧跟"解释段"（功能性说明而非角色体验）→ 每处扣3分
- 动机通过旁白解释而非行动展示 → 每处扣2分
- 括号注释式设定补充 → 每处扣1分

---

### FP-3：结构对称检测

**检测方法**:
1. 将全章按场景分段
2. 统计每个场景的段落数、平均句长、叙事模板类型
3. 计算场景间段落长度分布的方差

**评分标准**:

| 场景节奏差异 | 评分 | 处理 |
|------------|------|------|
| 方差>40% | 10/10 | 节奏差异明显，通过 |
| 方差30-40% | 7/10 | 可接受 |
| 方差20-30% | 4/10 | 节奏过于均匀 |
| 方差<20% | 1/10 | 严重工整，必须打破 |

**额外检查**:
- 连续3个场景使用相同叙事模板（如都从环境切入）→ 扣4分
- 紧张场景和日常场景句长分布相似 → 扣3分
- 每个场景都以环境铺陈开头 → 扣2分
- 无"急刹车"（极短句独立成段）→ 扣1分

---

### FP-4：否定转折模式化检测

**检测方法**:
1. 搜索全章"不是"出现次数
2. 分析每次否定转折的句式结构是否雷同
3. 检查否定转折后是否紧跟长解释从句

**评分标准**:

| "不是X，是Y"次数 | 评分 | 处理 |
|-----------------|------|------|
| 0-1次 | 10/10 | 通过 |
| 2次 | 7/10 | 可接受 |
| 3次 | 4/10 | 需要改掉多余的 |
| 4-5次 | 2/10 | 明显模式化 |
| >5次 | 0/10 | 严重AI味，必须重写 |

**额外检查**:
- 连续2个段落使用否定转折 → 扣3分
- 否定转折后紧跟>10字解释从句 → 每处扣2分
- 所有否定转折句式结构相同（都是"不是X——是Y"）→ 额外扣2分

## 综合评分

### 计算方式

```
AI指纹综合分 = (FP-1 + FP-2 + FP-3 + FP-4) / 4
```

### 分级

| 综合分 | 等级 | 处理 |
|--------|------|------|
| 8.0-10.0 | A | 通过，无明显AI指纹 |
| 6.0-7.9 | B | 轻微AI味，标注位置供作者参考 |
| 4.0-5.9 | C | 明显AI味，建议修改后重新检测 |
| 0-3.9 | D | 严重AI味，必须重写 |

### 与现有15维度扫描的集成

AI指纹检测作为 **Agent C（质量维度）** 的子项 `2.15b` 执行，与 `2.15 写作风格` 并列。

在正文审阅报告中增加独立章节：

```
## AI指纹检测

| 指纹 | 检测结果 | 评分 | 问题位置 |
|------|---------|------|---------|
| FP-1 句号切割法 | 独立短句占比X% | X/10 | 第X段/第X段 |
| FP-2 解释式展示 | 发现X处 | X/10 | 第X段/第X段 |
| FP-3 结构对称 | 场景方差X% | X/10 | — |
| FP-4 否定转折 | "不是"出现X次 | X/10 | 第X段/第X段 |
| **综合** | — | **X/10** | **等级X** |
```

## 修复优先级

| 优先级 | 指纹 | 原因 |
|--------|------|------|
| P0 | FP-1 句号切割法 | 最容易被人类读者识别的AI特征 |
| P0 | FP-4 否定转折模式化 | 模式化感极强，读者会感到重复 |
| P1 | FP-2 解释式展示 | 隐蔽但破坏沉浸感 |
| P1 | FP-3 结构对称 | 需要全文分析才能发现 |
