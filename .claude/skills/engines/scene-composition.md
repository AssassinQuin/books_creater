# 场面生成引擎 — 复杂场面写作策略

> **本文件职责**：场面怎么搭——密度分级、角色矩阵、镜头语言、潜台词与张力、有机场景流、缝合技术。
> **不在本文件中的**：场景怎么深→`engines/scene-deepening.md`｜对话规则→`engines/dialogue.md`｜风格节奏→`engines/writing-style.md`
> **定位**：场面密度分级（轻/中/重/大场面）+ 多人场景动力学 + 注意力分配规则。
> 解决的核心问题：多人物同场、多事件并发、对话/日常/心理场景的镜头语言、有机场景流。
> **配合文件**: 场景类型基础 →见 [scene-type.md](./scene-type.md)；场景深化 →见 [scene-deepening.md](./scene-deepening.md)
> 通用写作风格标准 →见 [writing-style.md](./writing-style.md)

## 一、场面密度分级

每章由 2-4 个场面组成。根据大纲事件自动规划场面密度：

| 密度 | 人物数 | 事件数 | 字数 | 适用场景 | 章内占比 |
|------|--------|--------|------|---------|---------|
| **轻量** | 1-2人 | 1事件 | 500-800字 | 过渡/独处/心理/信息投放 | 15-20% |
| **中量** | 2-3人 | 2事件交织 | 800-1500字 | 对话博弈/关系推进/日常互动 | 30-40% |
| **重量** | 3-5人 | 多线程并发 | 1500-2500字 | 团队互动/多立场碰撞/暗线爆发 | 30-40% |
| **大场面** | 5+人 | 多线高潮 | 2500-3500字 | 群像戏/会议/战斗/社会事件 | 可占整章 |

**密度规划原则**：
- 每章至少1个中量以上场面（≥2人互动≥800字）
- 连续2个轻量场面后必须接中量或重量
- 大场面每卷不超过3次，用于关键节点
- 卷初/卷末多用中量+重量，卷中可穿插轻量调节

**密度→字数分配示例（3000字/章）**：

```
方案A（推进章）：轻量600 + 重量1800 + 轻量600
方案B（日常章）：中量1000 + 中量1200 + 轻量800
方案C（高潮章）：重量2200 + 中量800
方案D（群像章）：大场面3000（整章一个场面）
```

## 二、多人场景动力学

### 2.1 角色矩阵（3+人场景强制使用）

写多人场景前，先建立在场角色矩阵：

| 角色 | 场景目标 | 当前障碍 | 对其他人的态度 | 信息持有量 |
|------|---------|---------|--------------|-----------|
| 角色A | {想得到什么/想做什么} | {什么阻止TA} | 对B:?/对C:? | 知道?/不知道? |
| 角色B | ... | ... | ... | ... |
| 角色C | ... | ... | ... | ... |

**矩阵决定对话走向**：目标冲突的人会争吵，目标一致但信息不对称的人会产生误解，目标无关的人会跑题。

### 2.2 注意力分配（POV角色视角）

POV角色不是摄像头，是有偏好的观察者：

| 规则 | 说明 | 示例 |
|------|------|------|
| **关系亲近者先注意** | 最关心的人最先进入视野 | {主角}进门先找{主角妹妹}在哪 |
| **威胁源高优先** | 潜在危险吸引注意力 | 有陌生人在场，{主角}会留意对方手的位置 |
| **忽略不关心的人** | 不重要的人被一笔带过 | {主角}对陌生NPC只给一个动作标签 |
| **情绪滤镜** | POV角色的情绪影响观察 | 焦虑时觉得灯光太亮、声音太吵 |

### 2.3 群体化学反应

**2人对话**：对抗或合作，一对一交锋，有来有回。

**3人对话**：三角关系——总有一个是"第三方"。
- A和B争论，C在旁边观察/插嘴/拉偏架
- A和C密谋，B不知道但在场（信息差张力）
- 三人各有立场，形成制衡

**4+人对话**：自然分裂为子群。
- 不是所有人都参与同一个话题
- 有人走神、有人和旁边人低声说话
- 主要争论发生在2-3人之间，其他人做反应
- 写法：主对话线占70%，副线（旁人反应/小动作/低声对话）占30%

**社会层级渗透**：
- 地位高的人先说话、被倾听、很少被打断
- 地位低的人少发言、被打断、用提问代替陈述
- 亲近关系打破层级（{主角}对熟人说话比对陌生人随意）
- 年龄/性别/职业暗示说话方式差异

### 2.4 信息不对称管理

同一场戏中，不同角色知道不同事：

| 信息差类型 | 张力来源 | 写法 |
|-----------|---------|------|
| **读者知道，角色不知道** | 戏剧反讽 | 暗示线索让读者发现，角色错过 |
| **A知道，B不知道** | 角色间博弈 | A的措辞小心避免泄露，B追问 |
| **A以为B知道，其实B不知道** | 误解升级 | A说了半句就停，B理解成另一个意思 |
| **所有人都不知道** | 共同悬念 | 所有人面对同一个未知，反应不同 |

## 三、全域镜头语言

> 战斗场景的多机位系统见 battle-writer。本章覆盖**非战斗场景**的镜头技术。

### 3.1 五种基础镜头

| 镜头 | 作用 | 非战斗场景用法 | 字数映射 |
|------|------|--------------|---------|
| **建立镜头** | 定位空间、时间、人物位置 | 任何新场景开头100-200字 | 100-200字 |
| **反应镜头** | 捕捉听者/旁观者的反应 | 关键对话后，给1-2句描写听者的微表情/动作 | 1-2句 |
| **插入镜头** | 特写关键物件/细节 | 强调某个道具/文件/标记/伤痕 | 1-3句 |
| **移动镜头** | 跟随角色穿过空间 | 赶路/探索/从室外进室内 | 3-5句 |
| **切换镜头** | 多角度展现同一时刻 | 群体反应——"A皱眉，B低头，C装没听见" | 1-2句 |

### 3.2 各场景类型的推荐镜头组合

**对话型**：建立镜头 → 对话（A说/B反应）→ 插入镜头（关键物件）→ 对话继续 → 反应镜头 → 结束
- 每5轮对话插入1次反应镜头或插入镜头
- 三人以上对话用切换镜头展示群体反应

**日常型**：移动镜头（跟着角色走）→ 建立镜头（新空间）→ 插入镜头（食物/物品/公告栏）→ 对话（短）→ 移动镜头（离开）
- 日常场景的核心是移动和观察，不是对话

**心理型**：建立镜头（安静空间）→ 插入镜头（触发回忆的物件）→ 内心独白 → 反应镜头（角色自己的身体反应）→ 结束
- 心理场景用身体反应代替情绪词

**氛围型**：建立镜头（长段环境描写）→ 移动镜头（角色穿过空间）→ 插入镜头（异常细节）→ 建立镜头（环境变化暗示时间流逝）
- 氛围场景是环境主导，人物只是穿行者

### 3.3 镜头切换禁忌

- ❌ 同一段内切换超过3种镜头（读者会晕）
- ❌ 建立镜头超过300字（铺垫太久）
- ❌ 连续3段对话没有镜头插入（纯对话无画面）
- ❌ 反应镜头只写一个人（3+人场景要覆盖多人反应）

## 四、潜台词与张力注入

### 4.1 对话三层结构

每一句重要对话都有三层：

| 层次 | 内容 | 读者感知 |
|------|------|---------|
| **表层** | 角色说了什么 | 直接读到 |
| **潜台词** | 角色真正想表达什么 | 从语境/关系/前文推断 |
| **未说层** | 角色绝不会说出口的东西 | 从身体反应/沉默/回避推测 |

**潜台词植入技法**：
- **答非所问**：问"你还好吗"，答"天快黑了"→ 潜台词：我不想谈这个
- **过度强调**："我真的没事"→ 潜台词：有事，但我不想让你知道
- **沉默替代**：问了一个敏感问题，对方没有回答，直接做另一个动作 → 未说层满满
- **话题偏移**：从A话题突然跳到B话题 → A话题触碰到了不想面对的东西

**潜台词密度**：
- 轻松日常场景：10-20%的对话有潜台词
- 关系推进场景：40-50%的对话有潜台词
- 冲突/谈判场景：60-80%的对话有潜台词
- 陌生人间：潜台词极少，表面客套（戒备感）

### 4.2 身体泄露

嘴上说A，身体在说B。矛盾信号制造张力：

| 嘴上说 | 身体在做 | 传递的信息 |
|--------|---------|-----------|
| "没事" | 手指在搓衣角 | 不安 |
| "我没生气" | 牙关紧咬，筷子用力放下 | 很生气 |
| "随便你" | 身体转向对方，没有转身走 | 还想继续 |
| "不用管我" | 眼睛跟着对方移动 | 希望你管 |
| "我知道了" | 点头但眼神飘向别处 | 其实没在听 |

**规则**：每个情绪转折点至少1个身体泄露。不说"不舍""留恋""难过"，用动作代替。

### 4.3 环境回声

空间细节映射在场角色的情绪状态：

- 角色焦虑 → 描写环境的紧迫感（空间逼仄、空气闷热、声音嘈杂）
- 角色平静 → 描写环境的安宁（光线柔和、声音遥远、空气清凉）
- 角色不安 → 环境中出现"不对劲"的细节（灯闪了一下、远处有异响）

**不是每次都要环境回声**。重要场景用，过渡场景不用。

### 4.4 沉默的力量

有时最有力的是不说话：

| 沉默类型 | 用法 | 效果 |
|---------|------|------|
| **问后沉默** | 问了关键问题，对方不回答 | 比任何回答都有冲击力 |
| **中段沉默** | 对话进行中突然安静 | 所有人的注意力集中 |
| **行动中沉默** | 角色在做某件事时一言不发 | 专注/决心/压抑 |
| **分别沉默** | 离别时不说再见，只是做动作 | 不舍、珍重、说不出口 |

**沉默规则**：每章最多2次"有意义的沉默"。用多了就没力量了。

## 五、有机场景流（反模板僵硬）

> 场景不应该是"事件A → 过渡 → 事件B → 过渡 → 事件C"的流水线。
> 好的场景像水——有主流，也有漩涡和分支，但总在流动。

### 5.1 五种自然驱动模式

| 模式 | 机制 | 适用场景 |
|------|------|---------|
| **中断驱动** | 外部事件打断当前方向 | 任何场景 |
| **发现驱动** | 角色发现新信息改变行为 | 探索/对话 |
| **升级驱动** | 小事滚成大事 | 日常/关系 |
| **跑题-回归** | 对话短暂跑偏再拉回 | 日常对话 |
| **拖延-爆发** | 角色回避问题→积累→爆发 | 心理/关系 |

### 5.2 反僵硬核心原则

1. **允许跑题**：真人聊天不会永远在正题上，允许角色说两句废话再拉回来
2. **允许被打断**：对话不一定是你说完我说，可以抢话、被打断、同时说话
3. **允许停顿**：不是每时每刻都有事件发生，角色可以发呆、沉默、做无意义的事
4. **允许意外**：计划好的事可以出错，预想的方向可以偏离（像真实生活）
5. **允许不完整**：场景不需要每次都有完整的开头和结尾，可以半途进入、半途退出

### 5.3 场景内部节奏

不是匀速推进。场景内部也需要节奏变化：

```
[慢] 进入场景，建立氛围
[中] 人物互动，信息交换
[快] 冲突/意外/转折（短句密集）
[慢] 反应/消化/调整（长句舒缓）
[中] 新方向/收束/过渡
```

**快慢交替是核心**：连续3段相同节奏就会显得僵硬。

## 六、跨场面信息差追踪

### 现有：场面内信息差（§2.4）

同一场戏中，不同角色知道不同事——这是**场面级**的信息不对称。

### 新增：场面间信息差累积

信息差不是只在一个场面内存在就消失的。一个场面留下"未闭合的信息差"，应该在后续场面中闭合、深化或翻新。

### 信息差生命周期

```
开启（埋设）→ 深化（新的角度看到）→ 闭合（揭示）→ 翻新（揭示改变了对之前事件的理解）
```

- 开启→闭合是**最小生命周期**（信息差必须闭合，不能遗忘）
- 翻新是**可选的高级操作**（但每卷至少 1 次，详见 spiral-structure.md）

### 跨场面追踪方法

每个场面设计时，除了记录当前场面内的信息差，还需检查：

```
1. 之前的场面留下了什么"未闭合的信息差"？
   → 本场面是否应该让某个信息差闭合或深化？

2. 本场面新开了什么信息差？
   → 计划在哪个场面闭合？（标注预计闭合章节）

3. 本场面的信息差和卷级信息矩阵（spiral-structure §一）的哪个层级对应？
```

### 追踪模板

```markdown
| 信息差 | 开启场面 | 类型 | 计划闭合 | 实际闭合 | 是否翻新 |
|--------|---------|------|---------|---------|---------|
| {描述} | Ch{N} 场面{M} | L1/L2/L3 | Ch{K} | Ch{J} | {是/否→Ch翻新} |
```

### 规则

1. 一个信息差至少经过 **"开启→深化→闭合"三步**（不能开启后下一场就闭合）
2. **深化**：新场面从不同角度展示了同一个信息（读者意识到"之前那个细节原来和这个有关"）
3. 未闭合的信息差在 QA 时检查——超过 5 章未闭合的信息差需要提醒
4. 与 `spiral-structure.md` 的三层信息矩阵联动——场面级信息差服务于卷级信息矩阵的释放计划

## 七、场景缝合技术

场景之间的连接方式决定了阅读流畅度：

### 6.1 五种缝合方式

| 方式 | 做法 | 流畅度 | 适用 |
|------|------|--------|------|
| **硬切** | 空行 + 新时间/地点标记 | 中 | 场景跨度大（不同地点/不同时间） |
| **软过渡** | 同一物件/感官/动作在两个场景间延续 | 高 | 同一天不同场景（如出门→路上） |
| **平行剪辑** | 两个同时发生的场景交替切换 | 高 | 多线叙事（A线+B线交替推进） |
| **嵌套场景** | 当前场景中插入闪回/回忆碎片 | 中 | 心理场景/揭露场景 |
| **零换行切换** | 用一句话完成时空转换 | 极高 | 熟练后使用（最自然） |

### 6.2 软过渡技法

**物件桥**：同一个物件出现在两个场景中
**感官桥**：同一种感官体验延续
**动作桥**：角色在做同一个动作时场景变了

### 6.3 平行剪辑技法

两个同时发生的场景，交替推进：

```
[场景A - {主角}线] 3-5句推进
[场景B - {主角妹妹}线] 3-5句推进
[场景A - {主角}线] 继续
[场景B - {主角妹妹}线] 继续
[交汇] 两条线在同一空间相遇
```

**规则**：
- 每段不超过5句（长了读者会忘另一条线）
- 两条线必须有因果/时间/空间关联
- 交汇点必须有戏剧性（不是简单的"然后他们见面了"）

### 6.4 零换行切换

最难但最流畅的方式——用一句话同时完成两个功能：

```
他说完那句话的时候，{资源站}大厅的灯暗了一下。
```
（既是对话的反应，又暗示{资源站}异常）

**规则**：零换行切换不超过全章过渡的30%，用多了会显得花哨。

## 八、复杂场面写作模板

> 每个模板含：密度级别/角色配置/镜头序列/张力类型/写作要点/示例片段。
> 完整示例见 `reference-scene-templates.md`

### 模板A：三人对话（信息交换+立场博弈）

**密度**：中量（800-1500字）
**角色**：3人（A主导/B追问/C旁观或插嘴）
**镜头序列**：建立→对话→反应→插入→对话→切换→结束
**张力类型**：信息不对称+立场冲突

**写作要点**：
1. 建立镜头：描写三人所在空间和相对位置
2. A提出话题，B追问细节，C在旁边有反应但暂时不发言
3. A和B的对话交锋中插入C的微表情/动作（为C后面介入铺垫）
4. 关键信息点用插入镜头（A拿出地图/C注意到某物）
5. C介入后三角关系形成，对话进入新一轮博弈
6. 结束时用切换镜头展示三人各自的反应

### 模板B：人群中的私密对话

**密度**：重量（1500-2500字）
**角色**：2人主对话+周围人群做环境
**镜头序列**：建立（全景人群）→拉近（两人）→对话→切换（人群反应）→对话→结束
**张力类型**：公开空间×私密话题的矛盾

**写作要点清单**：
- [ ] 开头有3-5句环境描写建立"公共空间"
- [ ] 对话中至少2次被环境打断/干扰
- [ ] 至少1次"有人走近→压低声音/换话题"的节奏
- [ ] 周围人群不是背景板——至少1个NPC有独立动作/对话
- [ ] 对话结束时，环境照常运转（没有人注意到他们说了什么）

### 模板C：多事件并发

**密度**：重量（1500-2500字）
**角色**：3-5人，每人有独立目标
**镜头序列**：建立→主线推进→支线插入→主线继续→支线再次插入→交汇
**张力类型**：多线交织+碰撞

**写作要点**：
1. 确定主线事件（本章核心）和支线事件（同时发生的另一件事）
2. 主线占70%篇幅，支线占30%
3. 支线不是完全独立——必须和主线有因果或空间关联
4. 使用平行剪辑在主线和支线间切换
5. 两线最终交汇——交汇点产生新的张力

**交汇方式**：
- 空间交汇：两条线的人在同一地点碰面
- 信息交汇：一条线的信息影响另一条线的决策
- 因果交汇：一条线的事件成为另一条线的起因

### 模板D：安静场面下的暗涌

**密度**：中量（800-1500字）
**角色**：1-2人表面互动，内心各有心事
**镜头序列**：建立（安静环境）→日常动作→插入（触发点）→微动作泄露→结束
**张力类型**：表面平静+内心翻涌的对比

**写作要点**：
1. 场景表面极其日常（吃饭/走路/休息/干活）
2. 角色在做日常动作时，微小细节泄露内心（手抖/走神/动作变慢/多看两眼）
3. 不直接写"TA在想XX"，通过动作让读者自己推断
4. 环境细节映射角色情绪（环境回声）
5. 结尾用一个微小但意味深长的动作收束

**暗涌层级**：
- **级1**：角色有一个秘密没说出来 → 通过回避某些话题/动作体现
- **级2**：角色做了一个决定但还没执行 → 通过准备工作/凝视某个方向体现
- **级3**：角色在压抑情绪 → 通过僵硬的动作/过度的控制体现

### 模板E：日常中的世界观展开

**密度**：中量（800-1500字）
**角色**：2-3人，通过日常互动带出设定
**镜头序列**：移动镜头→建立→插入（世界观物件）→对话（自然带出设定）→移动
**张力类型**：信息投放（低张力，自然渗透）

**写作要点**：
1. 世界观通过角色的**使用/观察/反应**展现，不是角色**解释**
2. 每个场景最多植入2个世界观元素（多了就是设定科普）
3. 植入方式优先级：角色动作 > 角色对话 > 环境描写 > 内心独白
4. 不同身份角色对同一设定的反应不同（商贩关心价格，军人关心威胁，平民关心影响）

## 附：复杂场面自检清单

每个中量以上场面完成后检查：

- [ ] **密度匹配**：场面字数是否符合密度级别要求
- [ ] **角色矩阵**：3+人场景是否使用了角色矩阵（目标/障碍/关系）
- [ ] **注意力分配**：POV角色的观察是否符合其关注偏好
- [ ] **镜头组合**：是否使用了≥2种镜头（不全是纯对话/纯叙述）
- [ ] **潜台词层**：关键对话是否有潜台词（不是每句话都说白了）

- [ ] **节奏变化**：场景内部是否有快慢交替（不是匀速）
- [ ] **缝合方式**：场景之间是否用了合适的过渡方式
- [ ] **信息增量**：这个场面让读者知道了什么新东西
- [ ] **推进**：场面结束后什么改变了（关系/信息/目标/位置）
