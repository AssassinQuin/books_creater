# 大纲审查引擎 v3.2

> **本文件功能**: 卷级大纲的5层21项审计+修复闭环。针对"大纲"阶段最容易出的问题设计：故事逻辑bug、因果牵强、人物设定矛盾、故事线断裂、叙事动力不足。
> **触发时机**: novel-planner 每卷大纲创建后/全书大纲完成后/重大修改后。
> **执行方式**: Phase 1 达尔文评估（5层Agent并行，结果写文件）→ Phase 2 女娲修复（多Agent并行修复）→ Phase 3 验证评分（迭代直到达标）。
> **评分方式**: 每层0-10分独立评分，综合分=五层均分×10。公式评分作辅助参考。
> **v3.2变更**: 新增第五层"叙事动力"(6项)；L2新增2.6"人物关系动态"；L4.3加强"高潮递进"判定；总计21项(原15+6新增)。
> **v3.3变更**: 整合「因果逻辑大纲法」，L1增加因果密度/雪球累积/可替换性/可删减性检查；L3增加不可逆节点分布；L5增加认知推翻因果链。详见 `references/causal-outline-method.md`。

## 审计框架：5层21项

### 第一层：故事逻辑（结构骨架）

> 检查故事本身的因果和合理性。这是最底层的——如果因果链断了，其他都白搭。
> **与L2去重**: L1.4信息对称性关注"信息获取时序"（角色间传递），L2.3知识边界关注"角色认知范围"（单个角色知不知道）。不重叠。

| # | 检查项 | 判定标准 | P级 | Agent专注点 |
|---|--------|---------|-----|------------|
| 1.1 | 因果链完整性 | 每个事件有cause→无因果断裂→无"因为剧情需要" | P0 | 逐卷追踪每个关键事件的因果链：A→B→C是否成立。标记无因之果和无果之因。 |
| 1.2 | 动机合理性 | 角色的每个关键选择有铺垫的动机→反派的每步行动符合其目标和智商→无"反派降智" | P0/P1 | 检查每个角色的关键决定：是否在之前有动机铺垫？反派行动是否符合已建立的智商和目标？ |
| 1.3 | 巧合密度 | 关键转折≤2次巧合→主角胜利靠主动选择不靠运气→无"恰好"解决问题 | P1 | 统计所有关键转折点，标记哪些靠巧合哪些靠角色主动选择。巧合>2次=P1。 |
| 1.4 | 信息对称性 | 角色只使用已获取的信息→无"突然知道"→团队信息共享有时序逻辑→无信息泄漏 | P0 | 追踪每卷角色知道了什么、从哪知道的、何时告诉团队的。标记信息来源不明的使用。 |

### 第二层：人物一致性（行为校验）

> 检查角色是否"按人设行事"。大纲阶段最容易出现"为了剧情需要让角色做人设外的事"。
> **与L1去重**: L2.3关注单个角色"该不该知道"（认知边界），L1.4关注"信息在角色间如何传递"（时序逻辑）。

| # | 检查项 | 判定标准 | P级 | Agent专注点 |
|---|--------|---------|-----|------------|
| 2.1 | 行为-设定匹配 | 角色行为不违背已建立的personality/speech_style/decision_mode | P1 | 对比角色深化.md中每个角色的设定，检查大纲中的行为是否匹配。标记"不像他会做的事"。 |
| 2.2 | 能力边界守恒 | 角色只使用已建立等级的能力→升级有触发节点→不突然变强→无"超常发挥"→金手指有使用限制/代价 | P1 | 追踪每卷的能力等级，标记无触发节点的升级和超出已建立边界的能力使用。额外检查金手指是否有明确的限制条件和每次使用的代价。 |
| 2.3 | 知识边界守恒 | 角色只使用已获取的知识→无"他怎么可能知道这个"→无未铺垫的专业知识 | P0 | 追踪每卷角色知道了什么。标记知识来源不明的使用。检查是否有角色"不该知道但知道了"的情况。 |
| 2.4 | 情绪连续性 | 角色的emotional_state在场景间有过渡→不突然切换→创伤有持续影响 | P2 | 检查角色在连续场景中的情绪状态是否合理过渡。标记"突然好了"或"突然崩了"的情况。 |
| 2.5 | 角色出现密度 | 核心角色每卷至少1个关键行为→配角不超过3卷无出场→无角色蒸发 | P2 | 统计每个角色在各卷的出场情况。标记超过3卷无关键行为的角色。 |
| 2.6 | 人物关系动态 | 核心关系对有变化弧线→不冻结在初始状态→有合作/冲突/信任变化的节奏→无"关系化石" | P1 | 追踪每对核心关系（主角-搭档/主角-反派/主角-导师等）在各卷的状态变化。标记全程无变化的关系对。检查关系变化是否有触发事件而非凭空转变。 |

### 第三层：故事线管理（线索工程）

> 检查故事线的铺陈和收束。大纲阶段最容易出现"引了线索忘了收"或"间距太长读者忘了"。

| # | 检查项 | 判定标准 | P级 | Agent专注点 |
|---|--------|---------|-----|------------|
| 3.1 | 主线推进密度 | 每卷至少1个主线推进节点→无连续2卷主线停滞 | P1 | 逐卷标记主线推进节点。检查是否有连续2卷主线无进展。 |
| 3.2 | 伏笔回收率 | planned伏笔100%有回收节点→无遗漏→回收有满足感 | P1 | 检查线索追踪.md中所有planned伏笔是否都有明确的回收卷。标记无回收节点的伏笔。 |
| 3.3 | 伏笔间距风险 | 埋设→提起≤3卷→提起→回收≤3卷→超过=间距风险→读者可能遗忘 | P2 | 计算每个伏笔的埋设-提起-回收间距。超过3卷=间距风险。 |
| 3.4 | 线索公平性 | 本格推理的反转有≥3条公平线索→读者可以提前推导→无"天降真相" | P1 | 检查每个重大反转是否有≥3条提前铺设的公平线索。 |
| 3.5 | 副线独立性 | 副线有独立价值→不只是主线的工具→有自洽的开头结尾→无工具人副线 | P2 | 检查每条副线是否有独立于主线的价值和弧线。 |

### 第四层：世界观+商业（设定+体验）

> 检查设定是否自洽、时空是否合理、读者体验是否流畅。

| # | 检查项 | 判定标准 | P级 | Agent专注点 |
|---|--------|---------|-----|------------|
| 4.1 | 设定自洽 | 同一设定在不同卷描述一致→无矛盾→新设定不推翻旧设定 | P0 | 对比各卷对同一设定的描述。检查新加入的设定是否和已有设定兼容。 |
| 4.2 | 时空一致性 | 季节/移动时间/距离/地理关系一致→无瞬移→无不可能的旅程 | P1 | 追踪每卷的季节、角色位置、移动距离和时间。标记不可能的移动。 |
| 4.3 | 爽点分布与高潮递进 | 每卷≥1个爽点→无连续2卷无爽点→每次高潮强度/规模/影响范围>前一次→整体呈上升趋势 | P1 | 逐卷标记爽点并评估强度(1-5级)。检查连续无爽点卷段。额外比较各卷高潮的规模：对手强度、战力展示、影响范围是否逐次递增。标记"比上次弱"的高潮。 |
| 4.4 | 弃文风险点 | 无连续2卷低谷→V3/V4无弃文风险→Phase过渡点有钩子 | P1 | 评估每卷的弃文风险。标记高弃文风险的卷段。 |
| 4.5 | 终卷回报 | 主线收束+角色弧线完成+伏笔回收+情感满足→读者觉得"值了" | P1 | 检查V14+尾声是否完成了所有承诺：主线、角色弧线、伏笔、情感回报。 |

### 第五层：叙事动力（驱动力引擎）

> 检查故事是否"有话要说、有劲往前推"。百万字长篇最容易"写着写着不知道为什么要写了"——这一层专查这个问题。
> **核心逻辑**: 前四层查"故事对不对"，第五层查"故事值不值得读"。没有叙事动力的故事，逻辑再完美也是死水。

| # | 检查项 | 判定标准 | P级 | Agent专注点 |
|---|--------|---------|-----|------------|
| 5.1 | 主题/立意一致性 | 全书有统一的核心主题→各卷服务于同一主题的不同面→无卷偏题→主题不是口号而是通过故事自然传达 | P1 | 提取各卷大纲的隐含主题，检查是否统一。标记与核心主题无关的卷。检查主题是"演出来的"还是"说出来的"。 |
| 5.2 | 中点转折 | V7(全书50%位置)有重大方向改变→颠覆前半段建立的认知/格局/阵营→前后半段有明显不同的叙事重心 | P1 | 检查V7大纲是否有足以改变故事走向的重大事件。对比V1-V6和V8-V14的叙事重心是否不同。标记"V7只是普通一卷"的情况。 |
| 5.3 | 追读钩子 | 每卷结尾有未解决的悬念/威胁/谜题→驱动读者打开下一卷→无卷以"一切圆满"结尾(终卷除外) | P0 | 逐卷检查结尾状态：是否有明确的未解决张力？标记以"安定"结尾的非终卷。检查钩子是否与下一卷开头形成因果衔接。 |
| 5.4 | 反派层次感 | 反派有鲜明个性(不只是"坏")→行动出人意料但合理→有多阶段递进(认识→对抗→理解/超越)→无"工具人反派" | P1 | 追踪主要反派的个性标签、行动逻辑、与主角关系的阶段变化。标记"只会变强没有维度变化"的反派。检查反派是否有独立于主角的目标和故事。 |
| 5.5 | 弧光完整性 | 主角有明确的初始缺陷→通过事件逐步领悟→缺陷和领悟形成对照→不是"开挂升级"而是"人的成长" | P1 | 提取主角的初始缺陷和终局状态，追踪中间领悟节点。标记"只是变强没有成长"的弧线。检查缺陷是否在关键时刻发挥作用（而非只在开头提一次）。 |
| 5.6 | 世界层层递进 | 世界观随主角成长逐步扩展→每2-3卷揭示新层级/新规则→不一开始全倒出来→也不后半段没有新发现 | P2 | 追踪每卷揭示的世界观新层级。标记连续3卷无新世界观揭示的区段。检查世界观扩展是否与主角能力/地位提升同步。 |

## 执行流程

```
Phase 1 达尔文评估:
  1. 主对话用ctx_batch_execute索引全部大纲+设定到FTS5
  2. 5层Agent并行（每Agent负责1层），结果写入 审阅报告/ 目录
  3. 主对话用ctx_execute_file提取各Agent报告摘要

Phase 2 女娲修复:
  P0/P1自动进入修复 → 每问题3方案 → 交叉验证 → 写入大纲文件

Phase 3 验证迭代:
  修复后重评 → 对比前后分 → 达标通过 / 不达标回Phase 2
```

### Agent执行规范

**必须**:
1. Agent结果写入 `审阅报告/达尔文v3.x/{层级名}.md`
2. 每个Agent只负责1层（4-6个检查项），不读其他层的资料
3. Agent用ctx_batch_execute索引大纲，用ctx_search查询，不直接Read全文
4. Agent报告末尾附：评分 + 问题清单(P0-P3) + 修复建议

**Scope控制**:
- 单Agent处理14卷大纲不会爆context → 但如果爆了，分V1-V7/V8-V14两段
- 优先用ctx工具在sandbox处理大文件，不把原始内容拉进Agent context

### Phase 2 修复流程

每个P0/P1问题生成3个修复方案，交叉验证后执行最优方案。

### 达标标准

- 综合分≥85: 通过
- 无P0: 强制条件
- P1≤3: 强制条件
- L5(叙事动力)≥7: 新增强制条件（叙事动力不足的长篇注定弃文）
