# 创意方法论引擎

> **用途**: 世界观/势力/力量体系/反派/剧情设计时的结构化思考框架。
> **加载时机**: novel-setup (A2), novel-character (A3), novel-planner (B1) 阶段。
> **使用原则**: 不是 checklist，是杠杆点。一部中长篇只需 1个核心设定Skill + 2个剧情Skill + 1个角色Skill + 1个文本Skill。

---

## 一、世界观设计框架

### 冰山模型（乌贼 2025）

读者看到 10%，作者必须构建 100%。**世界先行，角色后置。**

操作方法：
1. 先写出完整的世界规则（哪怕读者永远不会看到全部）
2. 决定每卷暴露多少（信息投放节奏）
3. 通过日常场景和事件侧面传达设定，禁止 exposition 大段倾倒

### 核心意象衍生法

从一个具体意象出发，像涟漪一样扩展整个世界。

操作步骤：
1. 找到世界最核心的一个意象/机制（例：冰原狼 → 北境 → 守夜人 → 异鬼）
2. 从核心意象推导第二层影响（社会/经济/政治）
3. 从第二层推导第三层（文化/禁忌/日常）
4. 每层问："这个设定会导致什么现实后果？"

### 代价守恒律

任何超能力、魔法或黑科技必须有**等价且被社会接受的代价**。

验证问题：
- 这个能力的代价是什么？谁承受？
- 如果代价太小 → 增大直到让使用者犹豫
- 如果代价是抽象的 → 转化为具体的身体/社会/心理后果
- 代价和收益之间有没有社会化的"交易"机制？

### 感官地图绘制

为关键场景建立五感档案，确保与情绪基调**相反或错位**。

操作：屠杀后弥漫烤面包香 / 恐怖地下室有干净消毒水味 / 奢华宴会角落有腐烂味

### 极端化推演

从核心设定出发，推演第二层、第三层的社会影响。

操作：
- 第一层：直接后果（有记忆交易 → 富人买记忆体验）
- 第二层：制度反应（产生"记忆版权法"和"记忆鉴定师"职业）
- 第三层：深层异化（国家用虚假记忆进行意识形态植入）

## 二、多势力冲突框架

### 博弈局面法（最少三方）

**两方是对抗，三方以上才有博弈。**

操作步骤：
1. 列出所有势力（至少 3 个）
2. 为每个势力定义：
   - 核心资源（它掌握什么别人没有的？）
   - 核心恐惧（它最怕失去什么？）
   - 核心目标（它的终极议程是什么？）
   - 时间线（它不以主角为中心运转，有自己的节奏）
3. 画出势力关系图：同盟 / 敌对 / 暗中交易 / 表面和平
4. 找到资源交叉点：A 手上的废品是 B 的神级宝物

### 阵营差异化四要素

| 维度 | 设计要点 | 检验标准 |
|------|---------|---------|
| **信仰原则** | 每个势力有独特价值观体系 | 如果把势力名遮住，能不能通过行为认出它？ |
| **行事方法** | 战斗风格 + 日常谈吐 | 同一个目标，不同势力用完全不同的手段 |
| **习俗** | 节日 / 礼仪 / 禁忌 | 禁忌可直接触发剧情冲突 |
| **语言** | 专有术语 / 表达习惯 | 不同势力的人说话方式不同 |

**Monolith 警告**：真实势力内部一定有派系分歧。分歧比一致更有戏剧性。如果所有成员说一样的话、做一样的事，世界"没有灵魂"。

### 信息不对称引擎

每个势力掌握不同信息 → 误解 / 误判 / 意外联盟。

操作：在每个关键冲突点，列出各方"知道什么"和"不知道什么"，用信息差制造戏剧性。

### 冲突个人化

冲突不能只是概念/视角差异，必须有**血和伤疤**。

验证：如果删掉一个冲突，读者能感受到"少了一个人在流血"吗？
- 矿奴咳灵晶碎片（不是"被剥削"，是具体的肺在碎裂）
- 韩朗亲手按沈念在提取椅上（不是"势力对立"，是具体的暴力动作）

## 三、力量体系设计框架

### Sanderson 三定律

| 定律 | 操作 | 反模式 |
|------|------|--------|
| 局限 > 能力 | 一个角色的限制比能力更有趣 | 无限升级，越来越强 |
| 局限 > 创新 | 在现有能力的限制上做文章，而非发明新能力 | 遇到新情况就加新规则 |
| 先扩展后增加 | 先用好已有元素，再添加新元素 | 每次打不开局面就引入新设定 |

### 资源稀缺 + 晋升代价模型（诡秘之主）

- 力量体系的资源总量固定 → 升级必须争夺 → 天然冲突引擎
- 晋升越高，代价越大（失去人性/失去选择/失去自我）
- 途径不可逆 → 每次选择都有永久后果

### 性格决定能力 + 制约创造力量（HxH）

- 角色的能力是其性格的延伸 → 能力反映内心
- 自我施加的限制 = 叙事杠杆（束缚越紧，突破越燃）
- 角色选择制约条件本身就揭示其价值观

### 力量体系 = 冲突引擎

力量体系不是升级表。验证：
1. 删掉升级机制，故事还有张力吗？如果没有 → 体系设计失败
2. 不同等级之间的社会地位差异大吗？这是日常冲突的来源
3. 力量的获取途径和代价是什么？谁在控制这些途径？

## 四、角色驱动剧情框架

### 欲望三角（Want / Need / Fear）

每个核心角色三层动机：
- **Want（表面欲望）**：他声称要什么（复仇、金钱、安全）
- **Need（深层需求）**：他实际缺什么（被接纳、停止内疚、被认可）
- **Fear（无意识恐惧）**：如果得到 Need，他会失去什么身份认同

**所有关键选择都在这三者间撕裂。**

操作：设计每个关键场景时，问"这个场景中 Want/Need/Fear 分别在拉扯什么？"

### 角色决策驱动

剧情不是"发生什么事"，而是"角色在压力下做什么选择"。

验证：如果换一个人做主角，故事走向会不同吗？如果不会 → 剧情不是角色驱动的。

### 虚假胜利 / 虚假失败陷阱

在转折点设计一个**看似达成目标实则埋下更大危机**的事件。

操作：主角以为杀死了反派，实则帮其完成了仪式；以为救出了人质，实则带回了间谍。

### 多米诺骨牌因果链

不先想"发生什么"，而先想"因为前一件事，所以不可避免地发生了后一件事"。

操作：每一步因果之间不能有"巧合"缝隙。如果需要巧合 → 回到上一步重新设计前因。

### 限制爆破法

给主角施加一条**极端且不可违背的限制**，然后在限制内寻找解。限制越荒谬，创意越锋利。

## 五、反派设计框架

### 六维度模型

| 维度 | 设计问题 | 操作 |
|------|---------|------|
| **情感锚定** | 反派失去了什么？动机溯源到失去/恐惧/执念 | 写一段反派的"失去"场景 |
| **行为反差** | 对不同对象展示不同面向 | 对敌人残酷 vs 对弱者关怀 |
| **价值观平行** | 和主角追求同一目标但路径不同 | "换位思考"的张力 |
| **脆弱性场景** | 什么时候会动摇？ | 通过具体场景（非旁白）展示软肋 |
| **情感梯度** | 与主角关系随剧情有曲线变化 | 从厌恶到理解？从恐惧到同情？ |
| **结局留白** | 读者应该"恨不起来" | 结局引发复杂情感而非简单痛快 |

### 反派合理化辩护

在动笔前，用**反派的逻辑写一段能说服自己的演讲**。不用任何"疯狂""邪恶""天生坏种"的词。

验证标准：如果你自己被这段话说服了 → 反派设计成功。

### "在自己框架里做正确之事的人"（乌贼）

反派有完整的逻辑链：从 A → B → C，每一步合理，只是起点和主角不同。

操作：列出反派的逻辑链，检查每一步是否都能独立成立。

## 六、思维工具箱（打破创意枯竭）

### 「如果相反」反转术

将故事中最理所当然的设定直接反转，检验其戏剧性。

### 陌生化组合

将两个**熟悉但从未被并置**的元素强行组合，然后合理化其共存逻辑。

### 契诃夫之枪变体：延迟引爆

在第一章放置一个看似无关的道具/细节/角色，直到读者几乎忘记时，以变形后的方式回收。

### 随机刺激法

从无关领域随机抽取一个概念，强制嫁接到当前故事中。

### POV 透镜过滤

同一场景换三个视角写，每个版本的偏见/秘密/感官缺陷扭曲事实。

### 潜台词冰山

对话三层：字面意思（10%）→ 社交意图（30%）→ 真实情感（60%，未说出）。只写水面上的 10%。

### 主题物化法

将抽象主题转化为一个具体物品、一种身体疾病或一个重复动作。

## 七、跨领域核心原则

以下原则在任何设计任务中都适用：

1. **差异化 = 张力 = 戏剧性** — 无论设计势力还是角色，第一步是"它和别人有什么本质不同"
2. **信息管理 = 叙事引擎** — 什么时候让读者知道什么
3. **自洽 = 最高原则** — 自洽产生必然感，必然感 = 读者信服的基础
4. **限制 > 能力** — 角色的限制比能力更有趣，系统的稀缺性比丰富性更有张力
5. **世界观-势力-反派三位一体** — 三者不能分开设计，互相验证
6. **势力有自己的时间线** — 不以主角为中心运转
