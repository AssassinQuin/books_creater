# 作者声音引擎

> 《这次不一样了》叙事声音指纹。所有章节必须遵循。

## 一、叙事视角

- **第三人称有限视角**，严格锁定当前POV人物
- 不进入非POV人物的内心（除非有明确的心灵感应设定）
- 叙述者知道POV人物知道的一切，不超越其认知边界
- POV切换必须有明确过渡（场景切换或章节切换）

## 二、句式节奏

- **短句为主**（≤25字），用于动作、对话、紧张时刻
- **长句用于**：环境描写、内心活动、时间流逝感
- **段落长度不均**：
  - 动作段落：2-4句，快节奏
  - 环境段落：5-8句，慢节奏
  - 对话段落：1-3句，碎片化
- **禁止连续3个段落以相同句式开头**（如连续以"他"开头）

## 三、比喻体系

- **偏好意象**：金属（刀刃/锁链/铠甲）、火焰（燃烧/灰烬/余温）、水流（暗涌/漩涡/干涸）、阴影（遮蔽/吞噬/缝隙）
- **禁止**：现代物品比喻（如"像电梯一样快""像手机一样亮"）
- **每个比喻只出现一次**，全文不重复
- 比喻后不加解释（如"像刀锋一样锐利——那是他多年磨砺的结果"→删除解释）

## 四、信息投放

- **环境信息通过动作带出**，不单独描写
  - ❌ "房间很暗，只有一盏油灯"
  - ✅ "他摸黑找到油灯，火石擦了三下才点燃"
- **人物背景通过对话碎片透露**，不直接叙述
  - ❌ "他从小在孤儿院长大，所以性格孤僻"
  - ✅ "孤儿院那套，你还没玩够？"（通过对话暗示）
- **情感通过生理反应展现**，不直接说"他感到..."
  - ❌ "他感到一阵恐惧"
  - ✅ "后颈的汗毛竖了起来"

## 五、留白规则

- **不解释角色的动机**（让读者自己推断）
- **不总结场面的意义**（不写"这一刻，他明白了..."）
- **关键情感时刻后沉默1-2句**，不立即转场
- **对话中的沉默用动作填充**，不用省略号
  - ❌ "你走吧。……"
  - ✅ "你走吧。"他转过身，开始收拾桌上的图纸。

## 六、词汇指纹

- **动词优先于形容词**：不说"锋利的刀"，说"刀切开了空气"
- **具体名词优先于抽象名词**：不说"力量"，说"拳头的重量"
- **禁用词**：缓缓、淡淡、微微、不禁、代价、反噬、寿命折损、精神崩溃
- **句式偏好**：
  - 用"把"字句替代"被"字句（主动态）
  - 用短促的祈使句替代长句请求
  - 环境描写用拟人化动词（"风挤进门缝"而非"风从门缝吹进来"）

## 七、章节节奏签名

- **开篇**：直接进入动作或对话，不铺垫环境
- **中段**：信息密度递增，每200字检查一次"这句话做了几件事"
- **结尾**：停在动作或对话上，不总结、不升华
- **转场**：用感官细节过渡（气味/声音/温度变化），不用"与此同时"

## 八、独立校验标准

作者声音不纳入 `writing-constraints.md`，使用本引擎独立校验。

### 校验项（逐章）

| 校验项 | 标准 | 检测方法 |
|--------|------|---------|
| POV锁定 | 非POV人物内心活动 = 0 处 | grep "想/觉得/意识到" 且主语非POV |
| 句式多样性 | 连续3段首句结构不同 | 抽样检查段落首句 |
| 比喻唯一性 | 同一比喻全文只出现1次 | 比喻提取后全局比对 |
| 展示非叙述 | "他感到/觉得/意识到" ≤ 1 处/章 | grep 统计 |
| 环境动作化 | 独立环境描写段落 ≤ 2 处/章 | 检查无动作动词的环境段 |
| 开篇直入 | 首段必须含动作或对话 | 首段检查 |
| 结尾留白 | 末段不含总结/升华/金句 | 末段检查 |
| 禁用词 | 缓缓/淡淡/微微/不禁/代价/反噬/寿命折损/精神崩溃 = 0 | grep 统计 |

### 评分

- A(≥90)：8项全达标
- B(≥80)：7项达标
- C(≥70)：6项达标
- D(<70)：≤5项达标 → 必须修改

### 执行检查清单（写作中）

每写完3个段落，检查：
- [ ] 当前POV是谁？叙述者是否超越了POV的认知？
- [ ] 这3个段落的首句结构是否不同？
- [ ] 是否有比喻？是否与前文重复？
- [ ] 是否有"他感到/他觉得/他意识到"？→改为生理反应或动作
- [ ] 是否有环境单独描写？→改为动作中带出
