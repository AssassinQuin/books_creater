# 因果逻辑大纲法（Causal Outline Method）

> **核心原则**：新手问"接下来发生什么"，大神问"因为发生了什么，所以接下来必然发生什么"
> **本文件功能**: 将"时间驱动型大纲"升级为"因果逻辑网型大纲"的方法论+检查清单
> **触发时机**: novel-planner 生成/优化大纲时，novel-qa 审计大纲时

---

## 一、理论框架：新手 vs 大神的6个维度

| 维度 | 新手写法 | 大神写法 |
|------|---------|---------|
| **世界观** | 舞台背景——有趣但无关压力 | 刑具——精密运转、自带压迫感的规则 |
| **情节推进** | 时间顺序："第一天…第二天…" | 因果逻辑："因为A，所以必然B→导致C" |
| **事件关系** | 珠子+串绳，可调换顺序 | 逻辑网，环环相扣，抽掉一环就崩塌 |
| **驱动力** | "该发生新事了" | "上一个后果逼着下一个必须发生" |
| **读者效果** | 连续发生的事 | 步步紧逼、雪球滚大的压迫感 |
| **核心命名** | 世界观即背景 | **世界观即刑具** + **情节即逻辑** |

## 二、因果逻辑网的构建方法

### 2.1 核心公式

```
事件N = f(事件N-1的 consequences, 角色 choices, 世界观 rules)
```

**不是**："第N天，主角去了X地方，遇到了Y"
**而是**："因为事件N-1导致了Z后果，主角被迫做出A选择，而世界观规则B使得这个选择必然引发C"

### 2.2 四步构建法

#### Step 1: 世界观刑具化

将世界观从"背景设定"转化为"压迫角色的规则系统"

**新手写法**：
> 这个世界有灵能，灵能可以觉醒，觉醒者很强

**大神写法**：
> 灵能觉醒的代价是寿命折损（规则1）→ 觉醒者越强，死得越快（规则2）→ 所以最强的人不会随便出手（规则3）→ 主角必须在"变强保命"和"隐藏实力"之间做选择（压迫感）

**刑具化检查清单**：
- [ ] 世界观规则是否对角色产生**持续压力**？
- [ ] 规则之间是否有**连锁反应**？（规则A触发规则B）
- [ ] 角色是否有**绕过规则**的动机？（绕过=剧情推进点）
- [ ] 规则是否有**代价**？（无代价=无张力）

#### Step 2: 因果链编织

每个事件必须回答三个问题：

```
1. 因为什么？（前因）
2. 所以什么？（后果）
3. 逼出什么？（角色被迫做的选择）
```

**示例对比**：

| | 新手（时间驱动） | 大神（因果驱动） |
|---|---|---|
| 事件 | 第3天，主角遇到反派 | 因为主角第2天暴露了身份（前因），所以反派追踪到了他的位置（后果），主角被迫在"逃跑"和"设伏反杀"之间选择（逼出选择） |
| 可替换性 | 可以改成"第5天遇到反派" | 不能替换——必须在身份暴露后立即发生 |
| 删减影响 | 删掉只是少一个事件 | 删掉则身份暴露的后果悬空，逻辑链断裂 |

#### Step 3: 雪球效应设计

让后果不断累积，形成"越滚越大"的压迫感

**雪球结构**：
```
初始事件 → 小后果 → 角色应对 → 应对产生新后果 → 更大后果 → 角色再应对 → ... → 终极危机
```

**关键原则**：
- 每个"应对"不能彻底解决问题，只能**转移或升级**问题
- 后果的累积速度要**加快**（不是匀速）
- 角色在应对中**暴露更多弱点**，为下一个后果埋下伏笔

#### Step 4: 不可逆节点设置

在因果链中设置"一旦触发就无法回头"的不可逆节点

**不可逆节点的特征**：
- 角色做出了**无法撤销的选择**（杀了人、背叛了信任、暴露了秘密）
- 世界观规则被**永久改变**（封印解除、真相公开、势力格局重组）
- 角色能力/状态发生**质变**（觉醒、黑化、失去重要之人）

**不可逆节点的作用**：
- 防止剧情"倒带"（读者不会觉得"反正可以重来"）
- 增加选择的重量（每个选择都有代价）
- 推动角色成长（无法回头=必须前进）

## 三、因果链的螺旋升级

### 线性因果链（现有）

```
A → B → C（后果递增，雪球效应）
```

这是 `causality.md` 的核心，解决"后果不断累积"的问题。

### 螺旋因果链（升级）

```
A → B → C → 回到A（但读者现在对A有了新理解）
```

螺旋层解决的不是"后果更大"，而是"理解更深"。

### 设计方法

在编织因果链时，对每个关键节点追加两个问题：

```
现有三问（线性层）：
1. 因为什么？（前因）
2. 所以什么？（后果）
3. 逼出什么？（角色选择）

新增两问（螺旋层）：
4. 这个事件有没有"隐藏的第二层后果"？
5. 第二层后果在何时揭示能翻新读者对当前事件的理解？
```

### 螺旋密度验证

- 每 **3 章**至少 1 个"回到前面事件但翻新理解"的节点
- 全卷的因果链图上，至少有 **2 条"回旋箭头"**（从后面的节点连回前面的节点）
- 回旋箭头不要求标注在因果链图上——在 `spiral-structure.md` 的回旋镖追踪表中体现

### 与 spiral-structure.md 的分工

| 问题 | 谁解决 |
|------|--------|
| 事件之间因果链怎么编？ | 本文件（causality.md） |
| 因果链中哪些事件有隐藏的第二层含义？ | spiral-structure.md |
| 什么时候揭示第二层含义来翻新理解？ | spiral-structure.md |
| 如何确保有足够的事件可以翻新？ | plot-density.md |

## 四、大纲格式：因果逻辑网模板

### 4.1 单卷大纲格式

```markdown
## 卷N：{卷名}

### 卷级因果链
- **触发事件**：因为{前卷遗留后果}，所以{本卷初始状态}
- **核心冲突**：{世界观规则} × {角色选择} = {必然冲突}
- **不可逆节点**：{角色做出的无法回头的选择}
- **遗留后果**：{本卷结束时留给下卷的定时炸弹}

### 逐日因果网（不是时间线！）

**D1：{事件名}**
- 因为：{前因}
- 所以：{直接后果}
- 逼出：{角色被迫做的选择}
- 雪球：{这个选择将引发的下一个后果}

**D2：{事件名}**
- 因为：{D1选择的后果}
- 所以：{新后果}
- 逼出：{新选择}
- 雪球：{下一个定时炸弹}

...（以此类推）

### 世界观刑具在本卷的压迫
- {规则1} → 导致{角色困境}
- {规则2} → 导致{角色两难选择}
- {规则3} → 导致{不可逆节点}
```

### 4.2 全书大纲格式

```markdown
## 全书因果逻辑网

### 主线因果链
初始状态 → 触发事件 → 第一次选择 → 第一次不可逆 → 第一次认知推翻 → 第二次选择 → ... → 终局

### 暗线因果链（与主线交织）
暗线初始 → 暗线触发 → 暗线第一次暴露 → 暗线与主线碰撞 → ... → 暗线收束

### 世界观刑具的全书压迫曲线
- V1-V3：规则初现（角色感知到压力）
- V4-V6：规则收紧（压力升级，角色被迫适应）
- V7-V9：规则反噬（角色的应对引发更大危机）
- V10-V12：规则真相（角色理解规则的本质）
- V13-V14：规则破局（角色打破或重构规则）

### 不可逆节点分布
- V{X}：{不可逆事件1} → 影响{后续哪些卷}
- V{Y}：{不可逆事件2} → 影响{后续哪些卷}
```

## 五、因果逻辑审计清单

### 5.1 单卷审计

| 检查项 | 通过标准 | 失败示例 |
|--------|---------|---------|
| **因果密度** | 每章≥1个"因为…所以…逼出…"链 | "主角去了X地方"（无前因后果） |
| **可替换性测试** | 任意两个相邻事件不能调换顺序 | "D3遇到反派"和"D5遇到盟友"调换后不影响逻辑 |
| **可删减性测试** | 删除任意事件会导致逻辑链断裂 | 删除"探索"章节后主线不受影响 |
| **雪球累积** | 后果强度逐章递增 | 每章后果强度相同（匀速推进） |
| **世界观压迫** | 每章至少1次世界观规则对角色施压 | 角色行动不受世界观限制 |
| **选择重量** | 每个重大选择都有不可逆后果 | 选择后可以轻松反悔 |

### 5.2 全书审计

| 检查项 | 通过标准 | 失败示例 |
|--------|---------|---------|
| **主线因果完整性** | 从初始状态到终局，每步都有因果 | 中间有"时间跳跃"填充的空白 |
| **暗线-主线交织** | 暗线不是独立故事，是主线的"隐藏因果" | 暗线和主线直到最后才强行交汇 |
| **世界观刑具一致性** | 世界观规则在全书中持续施压，不中途失效 | 前半段规则很严，后半段规则消失 |
| **不可逆节点分布** | 每2-3卷至少1个不可逆节点 | 前5卷都可以"倒带重来" |
| **终局因果收束** | 终局的每个元素都能在前文找到因果 | 终局出现"天降神兵"解决一切 |

## 六、正反示例对照

### 6.1 反面示例（时间驱动型）

```markdown
**D1**：林夜在迷雾监狱醒来，发现墙上规则。他觉得挺有意思，到处探索。
**D2**：遇到女警苏沐，触发解谜关卡，勉强通关，惹上灰狼帮。
**D3**：灰狼帮堵人，发生冲突，林夜用规则耍花招脱身。
```

**问题**：
- 每一天独立成段，事件之间无不可替代的因果关系
- D2的解谜和D3的冲突可以调换顺序
- 删掉"探索"直接打架，对主线影响差不多
- 推动力是"时间到了"，不是"逻辑逼迫"

### 6.2 正面示例（因果逻辑网型）

```markdown
**D1**：林夜醒来，发现规则"每说一次谎，心跳加快10下"。
- 因为：他对镜子说"我是无辜的"（其实是卧底，这句话是假的）
- 所以：心跳飙到110，监狱系统记录了他的异常
- 逼出：必须在系统锁定前找到上线接头
- 雪球：接头的唯一线索在"惩戒室"，而进入惩戒室需要触犯规则

**D2**：林夜故意对守卫说假信息，触发规则，被丢进惩戒室。
- 因为：D1的系统异常正在累积，时间紧迫
- 所以：心跳飙到140，成功进入惩戒室
- 逼出：在惩戒室里没找到接头人，但发现血写暗语
- 雪球：暗语要求"两个心跳超过150的人同时推门"→需要另一个人也被惩罚到濒死

**D3**：林夜骗灰狼帮老大说"我知道逃生通道"。
- 因为：D2的暗语需要第二个人
- 所以：老大信了（也说了谎，打算拿到通道后杀林夜）
- 逼出：两人心跳同时飙到160，隐藏门裂开
- 雪球：门后不是出口，是终极规则"开门者中，只能活一个"
```

**优势**：
- D1的身份暴露→迫使D2进惩戒室→D2的暗语→迫使D3找第二个人→D3的双人触发→引出终极选择
- 事件不可调换、不可删减，逻辑链环环相扣
- 读者感受到的不是作者在安排，是故事自己在滚动碾压角色

## 七、与现有工具的整合

### 7.1 与 novel-planner 的整合

**卷规划阶段**：
1. 先用`因果逻辑网模板`替代传统时间线
2. 每卷必须明确：触发事件→核心冲突→不可逆节点→遗留后果
3. 环境先行设计后，用`世界观刑具化检查清单`验证环境是否产生压迫

**全书总纲阶段**：
1. 用`全书因果逻辑网`替代传统"起承转合"
2. 明确主线因果链+暗线因果链+世界观压迫曲线
3. 不可逆节点分布必须提前规划

### 7.2 与 novel-qa 的整合

**大纲审计阶段**：
1. 在现有5层21项审计基础上，增加`因果逻辑审计清单`
2. 重点检查：因果密度、可替换性、可删减性、雪球累积
3. 因果链断裂=自动P0（致命）

**修复阶段**：
1. 发现"时间驱动"写法→转换为"因果驱动"
2. 修复公式：找到无因果的事件→补上前因/后果/逼出的选择
3. 验证：修复后事件不可调换、不可删减

### 7.3 与 outline-review-checklist 的整合

现有5层21项中，以下检查项与因果逻辑法直接对应：

| 现有检查项 | 因果逻辑法增强 |
|-----------|--------------|
| L1.1 因果链完整性 | 增加"因果密度"和"雪球累积"检查 |
| L1.3 巧合密度 | 增加"可替换性测试"和"可删减性测试" |
| L3.1 主线推进密度 | 增加"不可逆节点分布"检查 |
| L5.2 中点转折 | 增加"认知推翻的因果链"检查 |
| L5.3 追读钩子 | 增加"遗留后果=定时炸弹"检查 |

## 八、快速自检口诀

```
因果密度够不够？每章要有因为所以逼出
可不可换顺序？能换=因果弱，不能换=因果强
删了会不会塌？会塌=核心链，不塌=可删
雪球滚没滚？后果要越来越大
世界观压没压？规则要持续施压角色
选择重不重？不可逆=重，可回头=轻
```
