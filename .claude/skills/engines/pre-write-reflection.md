# 写作前强制反思引擎（Pre-Write Reflection）

> **本文件职责**：写正文前的最后一道检查——定情绪、预翻车、锁瞬间、禁句式。
> **触发时机**：novel-write Step 2.5（创意蓝图确认前）。
> **定位**：写前预防，不是写后检查。validate_chapter 是写后，本引擎是写前。两层配合。
> **配合文件**: AI味清单→`anti-ai-patterns.md`｜场景类型→`scene-type.md`｜卷级情绪→`get_chapter_context`返回的`core_emotion`

---

## 反思流程（四维度，必须逐项输出）

### 一、情绪定调

从 `get_chapter_context` 返回的卷级 `core_emotion` 推导本章情绪走向。

```
卷级核心情绪: {从上下文包获取}
本章前序情绪: {前一章结尾情绪状态}
本章目标情绪: {延续 / 升级 / 反转 / 降维}
```

**决策规则**：
- 连续 2 章同情绪 → 本章必须反转或降维
- 前一章高潮 → 本章必须降维（不能一直高潮）
- 卷级转折章 → 情绪必须反转

**输出**：一句话描述本章读者读完后应该**感到什么**。不是"紧张"，是"紧绷到不敢呼吸然后突然松掉"。

---

### 二、预判翻车点

基于本章场面类型（从 `scene-type.md` 获取），列出 3-5 个**最容易犯的错**。

#### 按场面类型的翻车清单

| 场面类型 | 高频翻车点 | 预防方式 |
|---------|-----------|---------|
| **战斗** | 招式解说（"他用X能力做了Y"）、无敌推进、疼痛免疫 | 每次攻击必须带代价/失误；用感官替代说明；战后必有余波 |
| **对话** | 信息倾泻（一人说清所有设定）、全员理性、没有潜台词 | 每人说的话 ≠ 真实意图；打断、回避、跑题；加身体语言 |
| **日常** | 无事发生、纯填充、世界观展览 | 日常中埋冲突种子；NPC 有自己的事在做；用物价/闲聊/告示栏传信息 |
| **心理** | 内心独白过长、自我分析太清晰、情绪词堆砌 | 用动作/环境替代"他感到"；情绪是模糊的不是清晰的；打断内心流 |
| **氛围** | 描写堆砌、五感清单化、与角色无关 | 每个描写必须通过角色注意力的筛选；角色只注意到他关心的+异常的 |
| **蒙太奇** | 跳跃无锚点、节奏失控、信息过载 | 每个切点有因果/时间/空间锚点；信息量递减不是递增 |

**输出**：列出本章的 3-5 个翻车点，每个写一句**具体避免方式**。

---

### 三、核心瞬间

本章必须有 **1 个读者会记住的画面/台词/决定**。

**核心瞬间的标准**：
- 视觉化（读者能在脑海中"看到"这个画面）
- 不可预测（但事后看来必然）
- 有情感冲击（不是信息冲击）

**不是核心瞬间的**：
- "主角终于学会了X能力" — 这是剧情推进，不是瞬间
- "NPC说了一句重要的话" — 除非这句话本身让人记住
- "打了一场精彩的仗" — 仗是过程，瞬间是一个画面

**输出**：用一句话描述本章的核心瞬间。如果写不出来，说明本章缺少锚点，需要回到 Step 2 补充。

---

### 四、禁用句式

从 `anti-ai-patterns.md` 提取与本章场面类型相关的 **5 个高频 AI 味句式**，写作时主动避开。

#### 按严重度排序的通用禁令

| # | 句式 | 替代方式 |
|---|------|---------|
| 1 | `不禁` + 动作 | 直接写动作本身，删掉"不禁" |
| 2 | `缓缓/淡淡/微微/轻轻` + 动作 | 换成具体速度/力度/方式 |
| 3 | `不是X，而是Y` 否定转折 | 直接写Y，跳过否定 |
| 4 | `他的眼中闪过一丝X` | 用动作/环境替代眼部描写 |
| 5 | `空气仿佛凝固了` | 换成具体感知（声音消失/人停止动作） |

#### 按场面类型的专项禁令

| 场面 | 禁令 | 替代 |
|------|------|------|
| 战斗 | 禁用"一道X光/一股X力" | 写具体物理效果（地面裂开/空气变形/温度变化） |
| 对话 | 禁用"他说完，全场沉默" | 写在场人的具体反应（有人放下杯子/有人看向窗外） |
| 日常 | 禁用"平凡的X" / "日常的X" | 直接写具体事物，不贴标签 |
| 心理 | 禁用"他意识到" / "他突然明白" | 用行为变化展示领悟（停下手里的动作/改变路线） |

**输出**：列出本章适用的 5 条禁用句式 + 替代写法。

## 输出格式

```
## 写作前反思

**情绪定调**: {一句话}
**前序状态**: {前一章结尾} → 本章: {目标情绪}（{延续/升级/反转/降维}）

**翻车预警**:
1. {翻车点1} → {避免方式}
2. {翻车点2} → {避免方式}
3. {翻车点3} → {避免方式}

**核心瞬间**: {一句话描述}

**禁用句式**:
1. ❌ {句式} → ✅ {替代}
2. ❌ {句式} → ✅ {替代}
3. ❌ {句式} → ✅ {替代}
4. ❌ {句式} → ✅ {替代}
5. ❌ {句式} → ✅ {替代}
```

## 与现有系统的分工

| 阶段 | 工具 | 职责 |
|------|------|------|
| 写前 | **本引擎** | 预防：定情绪、预翻车、锁瞬间、禁句式 |
| 写中 | anti-ai-patterns.md | 实时参考：AI味黑名单 |
| 写后 | validate_chapter | 检查：硬约束校验 + writing_rules 规则 |
| 审后 | novel-review | 诊断：三视角审查 |

预防（本引擎）+ 实时参考（anti-ai）+ 检查（validate）+ 诊断（review），四层防护。
