## 物品全生命周期模板

新物品首次出现时，按此模板建立档案：

```yaml
物品名: {中文名}
别名/俗称: {俗称/正式名称/外号}

# 来源
生成方式: {如何产生/采集/制造}
产地: {哪里有/哪里多/哪里没有}
稀缺度: {随处可见/常见/稀少/极稀有}

# 外观
形态: {固体薄片/结晶/液体/粉末/工具}
颜色: {灰绿/暗白/金色/透明/随浓度变化}
质感: {凉/麻/涩/黏/脆/硬}
光泽: {微荧光/哑光/金属光泽/结晶闪光}
大小: {指甲盖/掌心/拳头/手臂长}
结构: {单层/双层嵌套/三层/回路纹路}

# 感官
触感: {碰到的感觉/长时间接触的后果}
气味: {自然状态/燃烧时/研磨时}
味道: {如果入口}
声音: {碰撞/踩踏/研磨时的声音}

# 功能
主要用途: {列出1-5个}
使用方式: {怎么用/需要工具吗/有门槛吗}
生效条件: {需要灵能激活/直接使用/需要研磨}
持续时间: {一次性/持续多久/消耗速度}

# 等级/类型差异
类型1: {名称} - {与基础型的区别} - {价格/稀有度}
类型2: {名称} - {区别} - {价格}
...

# 变化与衰减
自然衰减: {暴露空气多久失效/灵能散逸速度}
受激发: {接触灵能/高温/撞击时反应}
用后变化: {变成什么/残留什么/消失无踪}

# 使用禁忌与代价
直接接触: {高浓度灼手/粉末吸入咳血/长期接触{世界特有疾病}}
误用后果: {灵能爆炸/中毒/吸引异灵}

# 经济
价格: {铜板/兑换券/以物易物比}
获取成本: {时间/体力/风险}
存储条件: {干燥处/避灵能/密封}

# 在故事中的使用记录
ch{N}: {怎么用的，状态变化}
```

## 使用规则

### 首次使用新物品
1. 按模板建立完整档案
2. 存储到 `world(action="upsert", novel_name="{小说名}", category="ability"/"economy", name="{物品名}", data={档案}})`
3. 正文中只展示与当前场景相关的属性（不全量罗列）

### 后续使用
1. 从 `world(action="query", novel_name="{小说名}", name="{物品名}")` 加载档案
2. 正文描写必须与档案一致
3. 如果本章有新的属性发现，更新档案

### 消耗品追踪
- 每章写完后在 `writing_finish` 的 key_events 中标注物品消耗
- 下章加载时通过人物状态快照确认剩余量

## 一致性校验规则

QA检查时：
- **外观矛盾**: 档案写"灰绿色"→正文写"蓝色" → 报错
- **功能矛盾**: 档案写"止血"→正文写"没有效果" → 报错
- **价格矛盾**: 档案写"2铜板"→正文写"50铜板" → 报错（除非有通货膨胀原因）
- **使用矛盾**: 档案写"需要研磨"→正文直接抓了用 → 报错
- **消耗矛盾**: 上章用完了→本章还在用 → 报错
