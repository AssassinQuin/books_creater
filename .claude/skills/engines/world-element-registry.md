# 世界观元素注册机制

> 写作中遇到新的世界观元素（物品/活动/生物/地点/概念），即时注册保存，后续可引用。
> 注册路径：`novels/{小说名}/设定/世界元素/{类型}/{元素名}.md`

---

## 注册流程

```
发现新元素 → 判断类型 → 创建文件 → 写入定义 → 标记可引用
```

### 发现时机

- 写正文时需要一个新比喻/类比 → 检查是否已有世界观内元素可用
- 写场景时需要新道具/生物/地点 → 先查注册库，没有再创建
- 灵感突发想到一个有趣的设定 → 立即注册，后续可能用到

### 注册标准

满足以下任一条件即可注册：
- 在正文中被具体描写过（有感官细节）
- 被角色提及或使用过（有互动记录）
- 对世界运转有实际影响（经济/生态/社会）
- 有独特的感官特征（气味/声音/触感/视觉）

## 元素类型

### 1. 物品（items/）

| 属性 | 说明 |
|------|------|
| 名称 | 通用名+俗称 |
| 外观 | 材质、颜色、形状、磨损痕迹 |
| 功能 | 实际用途+衍生用途 |
| 来源 | 自然产出/人工制造/其他 |
| 价值 | 在经济体系中的位置 |
| 感官 | 摸起来/闻起来/听起来像什么 |
| 比喻可用性 | 可用来比喻什么概念 |

### 2. 活动（activities/）

| 属性 | 说明 |
|------|------|
| 名称 | 通用名+俗称 |
| 参与者 | 谁做这件事 |
| 流程 | 具体步骤 |
| 地点 | 在哪里做 |
| 时间 | 什么时候做/频率 |
| 经济关系 | 涉及的交易/交换 |
| 社交功能 | 除了实际用途，还承载什么社会关系 |

### 3. 生物（creatures/）

| 属性 | 说明 |
|------|------|
| 名称 | 学名+俗称 |
| 分类 | 按世界观分类 |
| 外观 | 体型、颜色、特征部位 |
| 行为 | 攻击方式、移动模式、感知方式 |
| 生态 | 栖息地、食物链位置 |
| 威胁等级 | 对人类的危险程度 |
| 可利用部分 | 猎人取什么材料/值多少钱 |

### 4. 地点（locations/）

| 属性 | 说明 |
|------|------|
| 名称 | 官方名+俗称 |
| 位置 | 在世界中的方位 |
| 功能 | 实际用途+衍生用途 |
| 人群 | 谁在这里/什么时候来 |
| 感官特征 | 温度/气味/声音/光线 |
| 历史 | 怎么变成现在这样的 |

### 5. 概念（concepts/）

| 属性 | 说明 |
|------|------|
| 名称 | 术语+俗称 |
| 定义 | 在这个世界里是什么意思 |
| 来源 | 谁提出的/怎么流传开的 |
| 影响 | 对什么人/什么事有影响 |
| 争议 | 有没有不同理解 |

## 使用规则

### 比喻引用

注册后的元素可用于比喻/类比，使比喻扎根于世界观而非现实世界。

### 一致性检查

使用已注册元素时，必须与其定义一致——声音、触感、功能不能前后矛盾。

### 扩展注册

已注册元素可在后续章节中补充新属性：
- 首次出现：注册基本属性
- 第二次出现：补充感官细节
- 第三次出现：补充比喻可用性
- 以此类推...
