# 世界观元素注册机制

> 写作中遇到新的世界观元素（物品/活动/生物/地点/概念），即时注册保存，后续可引用。
> 注册路径：`novels/这次不一样了/设定/世界元素/{类型}/{元素名}.md`

---

## 注册流程

```
发现新元素 → 判断类型 → 创建文件 → 写入定义 → 标记可引用
```

### 发现时机

- 写正文时需要一个新比喻/类比 → 检查是否已有世界观内元素可用
- 写场景时需要新道具/生物/地点 → 先查注册库，没有再创建
- 灵感突发想到一个有趣的设定 → 立即注册，后续可能用到

### 注册标准

满足以下任一条件即可注册：
- 在正文中被具体描写过（有感官细节）
- 被角色提及或使用过（有互动记录）
- 对世界运转有实际影响（经济/生态/社会）
- 有独特的感官特征（气味/声音/触感/视觉）

---

## 元素类型

### 1. 物品（items/）

| 属性 | 说明 |
|------|------|
| 名称 | 通用名+俗称 |
| 外观 | 材质、颜色、形状、磨损痕迹 |
| 功能 | 实际用途+衍生用途 |
| 来源 | 自然产出/人工制造/灵能变异 |
| 价值 | 在废墟经济中的位置 |
| 感官 | 摸起来/闻起来/听起来像什么 |
| 比喻可用性 | 可用来比喻什么概念 |

**示例**：
```markdown
# 碎渣弹

## 基本属性
- 名称：碎渣弹（俗称：渣子雷/响儿）
- 外观：拳头大小，碎渣外壳+火药芯，表面有指甲刻的记号
- 功能：爆炸驱赶异兽/炸开碎石/信号标记
- 来源：拾荒者自制，碎渣外壳+市集换的火药
- 价值：1颗≈5铜板（材料费），熟练工一天做3-4颗

## 感官特征
- 摸起来：粗糙，有碎渣的颗粒感，好的弹壳密度高
- 闻起来：火药味+铁锈味
- 听起来：引线燃烧嘶嘶声→爆炸闷响（管道里回声大）
- 看起来：深灰色，表面有使用者的私人记号

## 使用场景
- 深管拾荒时驱赶灰蜥
- 炸开堵住的管道口
- 紧急信号（三声短响=求救）

## 比喻可用性
- 速度快：像碎渣弹爆炸瞬间的闪光
- 突然性：像口袋里摸到的碎渣弹——不知道什么时候会炸
- 危险中的安全感：像刻了记号的碎渣弹——知道哪颗深哪颗浅
```

### 2. 活动（activities/）

| 属性 | 说明 |
|------|------|
| 名称 | 通用名+俗称 |
| 参与者 | 谁做这件事 |
| 流程 | 具体步骤 |
| 地点 | 在哪里做 |
| 时间 | 什么时候做/频率 |
| 经济关系 | 涉及的交易/交换 |
| 社交功能 | 除了实际用途，还承载什么社会关系 |

**示例**：
```markdown
# 分堆

## 基本属性
- 名称：分堆（拾荒者术语）
- 参与者：拾荒者（通常是一家之主）
- 流程：倒在地上→按品质分三堆→好的换粮/中的存着/次的自用
- 地点：家里/临时营地
- 时间：每次拾荒回来必做

## 经济关系
- 好堆→灵站/市集换粮或兑换券
- 中堆→存着换碎渣弹材料
- 次堆→自用或应急

## 社交功能
- 展示拾荒成果（邻里会看分堆判断收成）
- 家庭责任分配（好堆给谁=谁被优先照顾）
- 沈野的分堆：好堆给沈念，中堆存着，次堆自己——不用说话，堆的大小就是态度

## 比喻可用性
- 优先级：像分堆——好的给重要的人，次的留自己
- 隐藏信息：分堆时手抖不抖、分得细不细——暴露拾荒者的心理状态
```

### 3. 生物（creatures/）

| 属性 | 说明 |
|------|------|
| 名称 | 学名+俗称 |
| 分类 | 虫豸/牙级/异变体/其他 |
| 外观 | 体型、颜色、特征部位 |
| 行为 | 攻击方式、移动模式、感知方式 |
| 生态 | 栖息地、食物链位置、与灵能关系 |
| 威胁等级 | 对人类的危险程度 |
| 可利用部分 | 猎人取什么材料/值多少钱 |

**示例**：
```markdown
# 灰蜥

## 基本属性
- 名称：灰蜥（学名：管道岩蜥）
- 分类：虫豸（低级异兽）
- 外观：30-50cm，灰色鳞片，爪子适合攀爬金属管壁

## 行为特征
- 感知：追振动，不追视觉/气味
- 攻击：群体出动，爪子刮管壁发出警告声
- 移动：管道内快速爬行，直线追击

## 生态
- 栖息地：深管、废弃灵能站
- 食物：碎渣残渣、小型生物
- 与灵能关系：灵能浓度高时更活跃（丰收期危险）

## 威胁与价值
- 威胁：单只不可怕，群体危险；追振动意味着跑动=吸引
- 猎人价值：白条30铜板/只，鳞片可做低级护甲
- 拾荒者应对：碎渣弹驱赶、不跑动、靠墙走

## 比喻可用性
- 恐惧：像管道深处突然安静——灰蜥来了
- 群体压力：像灰蜥群——一只不可怕，但你知道后面还有更多
- 本能反应：像灰蜥追振动——身体比脑子快
```

### 4. 地点（locations/）

| 属性 | 说明 |
|------|------|
| 名称 | 官方名+俗称 |
| 位置 | 在外环/内环/深层/地表 |
| 功能 | 实际用途+衍生用途 |
| 人群 | 谁在这里/什么时候来 |
| 感官特征 | 温度/气味/声音/光线 |
| 历史 | 怎么变成现在这样的 |

### 5. 概念（concepts/）

| 属性 | 说明 |
|------|------|
| 名称 | 术语+俗称 |
| 定义 | 在这个世界里是什么意思 |
| 来源 | 谁提出的/怎么流传开的 |
| 影响 | 对什么人/什么事有影响 |
| 争议 | 有没有不同理解 |

## 使用规则

### 比喻引用

注册后的元素可用于比喻/类比：
- ✅ "像碎渣弹爆炸瞬间的闪光"（速度快）
- ✅ "像分堆时的手抖"（暴露内心）
- ✅ "像灰蜥追振动"（本能反应）
- ✅ "像老陈的饼——油多但不说"（沉默的善意）

### 一致性检查

使用已注册元素时，必须与其定义一致：
- 碎渣弹是"闷响"不是"巨响"
- 灰蜥"追振动"不追气味
- 分堆"三堆"不是"两堆"

### 扩展注册

已注册元素可在后续章节中补充新属性：
- 首次出现：注册基本属性
- 第二次出现：补充感官细节
- 第三次出现：补充比喻可用性
- 以此类推...
