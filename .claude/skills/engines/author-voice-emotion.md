# 作者声音 — 情感高潮剧情层

> 加载时机：情感高潮/离别/重逢/真相揭露。在通用层基础上叠加。

## 情感声音指纹

### 核心原则
- **情感越重，描写越轻**。最重的情感用最小的动作传达
- 不写"他很难过"——写他做了什么（小动作、反常行为、下意识的动作）
- 情感场面里的环境描写必须**反向**：悲伤时写温暖，温暖时写寒冷

### 节奏控制
- **铺垫段**：正常节奏，甚至稍快（让读者没准备好）
- **情感爆发前1句**：突然停顿（一个短句，一个动作）
- **情感爆发**：不直接写情感，写环境对这个情感的"反应"（环境突然变化）
- **爆发后**：留白。1-2句什么都不说，然后转场

### 比喻库（情感专用）
> ⚠️ 以下为示例格式。每部小说应从自己的世界观中提炼比喻。

| 概念 | 比喻思路 |
|------|---------|
| 心痛 | 用角色熟悉的身体疼痛类比（看不见的伤） |
| 温暖 | 用食物/身体接触的感官细节 |
| 孤独 | 用环境中的声音消失表达 |
| 希望 | 用微弱但存在的光亮/信号类比 |
| 绝望 | 用资源/力气耗尽但路还远的状态类比 |
| 牵挂 | 用随身携带的小物件/下意识的动作表达 |

### 对话规则
- 情感高潮时，角色说的话比平时**更短**
- 寡言角色可能只说一个字或不说
- 多话角色可能突然停住，或者说的全是废话
- **最重的情感永远不是用说的**——是用做的

### 禁忌
- 禁止"他明白了/他懂了/他意识到了"——读者自己明白
- 禁止回忆杀插入——情感在当下，不在过去
- 禁止金句总结——情感不需要总结，只需要存在
