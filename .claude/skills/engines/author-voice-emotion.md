# 作者声音 — 情感高潮剧情层

> 加载时机：情感高潮/离别/重逢/真相揭露。在通用层基础上叠加。

## 情感声音指纹

### 核心原则
- **情感越重，描写越轻**。最重的情感用最小的动作传达
- 不写"他很难过"——写他做了什么（沈野摩挲食指关节、沈念笑着把碗推过去）
- 情感场面里的环境描写必须**反向**：悲伤时写温暖，温暖时写寒冷

### 节奏控制
- **铺垫段**：正常节奏，甚至稍快（让读者没准备好）
- **情感爆发前1句**：突然停顿（一个短句，一个动作）
- **情感爆发**：不直接写情感，写环境对这个情感的"反应"（照明石闪了一下、面汤的热气突然散了）
- **爆发后**：留白。1-2句什么都不说，然后转场

### 比喻库（情感专用）
| 概念 | 世界观内比喻 |
|------|-------------|
| 心痛 | 像碎渣弹在胸口炸开，但外面看不见伤 |
| 温暖 | 像面汤的热气糊了半张脸，烫但舍不得吹凉 |
| 孤独 | 像管道深处只剩自己的脚步声，连回声都没有 |
| 希望 | 像照明石快耗尽时突然闪了一下——不知道是真的还是看错了 |
| 绝望 | 像碎渣袋越来越轻，但还要走很远的路 |
| 牵挂 | 像口袋里那颗刻了记号的碎渣弹，时刻摸得到 |

### 对话规则
- 情感高潮时，角色说的话比平时**更短**
- 沈野平时就短，情感高潮时可能只说一个字或不说
- 沈念平时话多，情感高潮时可能突然停住，或者说的全是废话
- **最重的情感永远不是用说的**——是用做的（沈野多放了一包干粮到沈念背包里）

### 禁忌
- 禁止"他明白了/他懂了/他意识到了"——读者自己明白
- 禁止回忆杀插入——情感在当下，不在过去
- 禁止金句总结——情感不需要总结，只需要存在
