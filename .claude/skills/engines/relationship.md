# 人物关系与态度变化追踪规范

> **用途**: 定义人物关系变化、态度变化的记录和追踪规则
> **触发时机**: 
> - 大纲规划时（确定关系/能力变化节点）
> - 写作时（Step 3 状态同步）
> - 人物修改时（检查受影响关系）
> **归属**: novel-character skill 系统
> **核心原则**: 关系变化由大纲剧情确定，态度变化在人物系统中完善

---

## 一、数据来源分工

| 内容 | 确定位置 | 记录位置 | 说明 |
|------|---------|---------|------|
| **关系变化** | 大纲（卷/章节） | novel-db relation表 | 大纲确定"谁和谁的关系变了" |
| **态度变化** | 人物系统 | 角色总览.md | 人物系统完善"怎么变的" |
| **能力变化** | 大纲（卷/章节） | character.status + 角色总览.md | 大纲确定变化节点，人物系统完善描写 |
| **关系细节** | 人物系统 | 角色总览.md | 对话语气、微动作、弦外之音 |

## 二、关系变化追踪

### 2.1 关系类型定义

```
ally（盟友）    enemy（敌人）    mentor（导师）
lover（恋人）   family（家人）   rival（对手）
subordinate（下属）
```

### 2.2 关系强度量表

| 强度 | 含义 | 示例 |
|------|------|------|
| 1-2 | 点头之交/表面关系 | 市集摊贩和顾客 |
| 3-4 | 普通关系/同事 | {主角势力}战友 |
| 5-6 | 信任/朋友 | {主角}和{配角B}初期 |
| 7-8 | 深厚感情/生死之交 | {主角}和{配角C}后期 |
| 9-10 | 不可分割/命运共同体 | {主角}和{主角妹妹} |

### 2.3 关系变化记录格式（novel-db）

```json
{
  "from_character_id": 1,
  "to_character_id": 2,
  "relation_type": "ally",
  "intensity": 6,
  "chapter_established": 15,
  "description": "V3并肩战斗后，从雇佣关系转为真正的信任",
  "history": [
    {"chapter": 1, "event": "初次相遇", "intensity_change": 0},
    {"chapter": 5, "event": "共同突围", "intensity_change": +2},
    {"chapter": 12, "event": "{主角}为{配角B}铸造装备", "intensity_change": +1},
    {"chapter": 15, "event": "{配角B}坦白12个弟兄的事", "intensity_change": +2}
  ]
}
```

## 三、态度变化追踪

### 3.1 态度维度

每个角色对其他关键角色的态度，按以下维度追踪：

| 维度 | 含义 | 变化示例 |
|------|------|---------|
| **信任** | 是否相信对方 | 从"利用"到"可以托付后背" |
| **亲近** | 情感距离 | 从"保持距离"到"主动关心" |
| **尊重** | 认可程度 | 从"看不起"到"承认价值" |
| **戒备** | 防御程度 | 从"完全开放"到"有所保留" |
| **依赖** | 依靠程度 | 从"独立行动"到"需要对方" |

### 3.2 态度变化记录格式（角色总览.md）

在角色总览.md中，每个角色章节增加「态度追踪」小节：

```markdown
### {主角} → {配角B}

| 维度 | V1初遇 | V3并肩 | V6真相 | V9抉择 |
|------|--------|--------|--------|--------|
| 信任 | 2（利用） | 5（可合作） | 7（信任） | 8（生死之交） |
| 亲近 | 1（冷漠） | 3（偶尔交流） | 5（会担心） | 7（主动关心） |
| 尊重 | 3（认可经验） | 5（承认价值） | 7（敬佩） | 8（不可替代） |

**关键转折**:
- V1CH3: {配角B}给路线图，{主角}态度从"利用"变为"可合作"
- V3CH15: {配角B}坦白12弟兄的事，{主角}第一次"心疼"这个老兵
- V6CH28: {配角B}为{主角}挡伤，信任突破到"可以托付后背"
```

### 3.3 态度变化写作规范

1. **用行为体现态度变化**: "他开始信任{配角B}了"→写出信任的行为（递东西/靠得更近/主动说情报）
2. **微动作泄露**: 从"站在三米外"到"递东西时手会停一下"
3. **对话变化**: 从"嗯"到"你小心点"
4. **决策影响**: 从"不管他死活"到"先确认他安全"

## 四、能力变化追踪

### 4.1 能力变化由大纲确定

大纲中必须明确标注：

```markdown
### V4 卷大纲

**{主角}能力变化**:
- V4CH20: 首次"模拟"他人能力（{配角C}分解的弱化版）
- 触发条件: 禁地核心共鸣，灵能浓度骤升
- 代价: 模拟后头痛三天，鼻血
- 后续影响: 开始理解"灵能路数"的概念
```

### 4.2 能力变化在人物系统中完善

在角色总览.md中增加「能力弧线」小节：

```markdown
### {主角} · 能力弧线

| 阶段 | 卷 | 能力状态 | 关键事件 | 心理变化 |
|------|-----|---------|---------|---------|
| 萌芽 | V1-V3 | 基础拓印 | 拾荒时触发 | "手感好而已" |
| 发展 | V4-V6 | 模拟他人 | 禁地共鸣 | "原来我能做到这个" |
| 成形 | V7-V9 | 自主设计 | 给队友造装备 | "你缺什么，我补什么" |
| 突破 | V10-V12 | 复制活人 | 从柳陌身上读路数 | "理解一个人比理解结构难" |
| 融合 | V13-V14 | 熔铸新路数 | 两种结构合二为一 | "两只手合到了一起" |

**能力代价累积**:
- V4: 头痛三天
- V7: 鼻血+手抖一周
- V10: 严重到一天只能铸一件
- V13: 铸造后需要人扶才能站稳
```

## 五、变化一致性检查清单

### 5.1 大纲层面检查

- [ ] 每卷是否有明确的关系变化节点？
- [ ] 能力变化是否有充分前因？（每次变化追溯到具体事件/压力/资源）
- [ ] 变化节奏是否合理？（同一卷内多人突破需要间隔和差异化触发）
- [ ] 变化是否有代价？

### 5.2 人物系统层面检查

- [ ] 态度变化是否有微动作/对话支撑？
- [ ] 关系变化是否符合双方性格？
- [ ] 能力变化后是否有适应期描写？
- [ ] 变化是否同步到角色总览.md？

### 5.3 DB同步检查

- [ ] relation(action="create")/update 是否执行？
- [ ] character.status.ability_changes 是否更新？
- [ ] 变化是否有 source_chapter 记录？

## 六、关系动力学（剧情发动机）

> 核心原则：**人物推事件，非事件推人物**。关系张力驱动剧情，而非外部事件堆砌。

### 6.1 关系是活火山（岩浆积累→喷发）

每段重要关系都是一座活火山。平时埋岩浆（未解决的冲突/未说出口的话/未还清的债务），关键时刻喷发。

**岩浆积累规则**:
| 操作 | 效果 | 示例 |
|------|------|------|
| 未解决的误会 | 高压储存 | 两人绝交三年，偶尔碰面客气点头——客气本身就是岩浆 |
| 未说出口的话 | 等待触发 | 喝醉后敲开门说"当年那件事，我其实是……" |
| 未还清的债务 | 权力倾斜 | "你欠我一条命"→每次需要帮忙时翻出来 |
| 未承认的情感 | 累积到临界 | 每次见面多看一眼，直到某天忍不住 |

**喷发节奏**:
- 每卷至少1次小规模喷发（关系微变）
- 每3卷1次中规模喷发（关系质变）
- 关键卷末大规模喷发（关系彻底重组）
- 喷发后必须有余震（后续影响2-3章）

### 6.2 权力倾斜是发动机

所有关系里都藏着权力：谁更在乎谁？谁欠谁更多？谁离开谁活不下去？

**权力不对等类型**:
| 类型 | 表现 | 剧情驱动 |
|------|------|---------|
| 情感不对等 | A爱得深，B爱得浅 | 读者想知道A什么时候受不了 |
| 信息不对等 | A知道B的秘密 | 读者想知道A什么时候用这张牌 |
| 技能不对等 | 师父的绝学全在徒弟手里 | 权力反转后的道德困境 |
| 生存不对等 | A离开B活不下去 | B的每一个决定都牵动A的命 |

**权力反转规则**:
- 每段重要关系至少经历1次权力反转
- 反转必须有触发事件（不能凭空反转）
- 反转后双方行为必须改变（不能嘴上说变了实际没变）

**每场戏的权力检查**:
```
这场戏开始时，谁在这段关系里占上风？
这场戏结束时，权力有没有变化？
如果没有变化 → 这场戏大概率是废的
```

### 6.3 关系长出关系（网状连锁）

单线关系（A认识B，B认识C，C认识A）没有张力。高明的关系网是：A和B的秘密，变成A和C的筹码。

**关系网编织规则**:
| 操作 | 效果 |
|------|------|
| A和B的秘密 → A和C的筹码 | 信息跨关系流动 |
| B对C的恩情 → B要挟D的工具 | 恩情变成权力 |
| C和D的恋情 → A刺激E的武器 | 感情变成武器 |
| 反派用男二的父亲威胁男二背叛主角 | 外部压力撕裂内部关系 |

**关系网密度检查**:
- 每个重要角色至少和3个其他角色有非表面关系（秘密/债务/误会/暗恋/亏欠/仇恨）
- 如果角色只和主角有关系，和其他人都是点头之交 → 关系网太稀，剧情会断

### 6.4 关系驱动剧情的写作检查

每写一个场景，必须回答：
1. 这场戏里，哪段关系在变化？
2. 变化的方向是什么？（靠近/疏远/反转/破裂）
3. 变化的触发是什么？（事件/信息/选择/意外）
4. 变化后，权力倾斜了吗？

如果4个问题都答不上 → 这场戏没有关系推进，需要加料。

## 七、快速参考

### 写作时以哪个为准？

| 问题 | 答案 |
|------|------|
| 谁和谁的关系变了？ | **大纲**（剧情节点） |

| 能力什么时候变？ | **大纲**（卷/章节标注） |
| 能力变化怎么描写？ | **角色总览.md**（能力弧线） |
| 对话语气怎么变？ | **角色总览.md**（关系调节表） |
| 变化是否合规？ | **锁定设定.md**（能力体系规则） |
