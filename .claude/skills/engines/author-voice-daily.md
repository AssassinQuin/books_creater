# 作者声音 — 日常/世界呼吸剧情层

> 加载时机：日常场景、世界呼吸片段、荒诞笑点。在通用层基础上叠加。

## 日常声音指纹

### 核心原则
- **日常不是 filler，是 world-building**。每个日常片段都在展示世界怎么运转
- 节奏比主线慢，信息密度低，但**每句话都在做至少两件事**
- 让读者觉得"这些人真的在生活"，而不是"这些人在等剧情发生"

### 节奏控制
- **日常段落**：句子可以长一点，允许废话和跑偏
- **荒诞插入**：正经对话中突然来一句荒谬的，节奏瞬间断裂
- **温暖瞬间**：短，快，不收尾。像现实生活中美好的瞬间——来了就走

### 世界呼吸四元素

#### 1. 荒诞笑点
- 正经场面里来一句不对劲的
- 角色一本正经说蠢话
- 危险过去后有人说了一句特别不搭的话
- **原则**：不是笑话，是"这也行？"的那种笑

#### 2. 突然温暖
- 与当前基调形成反差的善意瞬间
- **原则**：暖一下就收，别恋战。不超过3句

#### 3. 突然暴力
- 不需要铺垫的极端暴力瞬间
- 像现实一样——你走在路上，下一秒可能出事
- **原则**：不预告，来了就来了。写后果不写过程

#### 4. 短暂快乐
- 角色有他们自己的快乐时光，跟主线无关
- **原则**：这些瞬间不服务结构——它们服务世界

### 比喻库（日常专用）
> ⚠️ 以下为示例格式。每部小说应从自己的世界观中提炼比喻，不照搬。

| 概念 | 比喻思路 |
|------|---------|
| 忙碌 | 用世界观内的繁忙场景类比 |
| 无聊 | 用角色在等待中的小动作表达 |
| 满足 | 用食物/温暖/安全的感官细节 |
| 尴尬 | 用社交场景中的沉默和不自在 |
| 期待 | 用不确定但有希望的状态 |

### 对话规则
- 日常对话**允许不推进剧情**
- 允许闲聊、废话、跑题、重复
- 允许两个人说不到一起去（体现性格差异）
- **正面标准**：读完日常对话，读者应该更了解这个世界，而不是更了解剧情

### 日常节奏标准
- 设定通过日常自然流露：角色在做自己的事时，世界自然暴露——不是角色充当讲解员
- 日常段落结尾留给读者自己感受：写完日常动作就收，让画面停在读者脑子里
- 日常是呼吸，长度以一个完整动作为单位（搅锅/买药/走路），做完就切
