# 拆书分析指南

> 从优秀作品中系统提取可借鉴的技巧和风格特征。

---

## 分析流程

### 第一步：文本导入

用户通过以下方式提供文本：
- 直接粘贴文本
- 提供文件路径（`.txt` / `.md`）
- 粘贴关键章节（不需要全书）

最少需要 **2000字** 才能做有意义的分析。

### 第二步：段落类型标注

逐段分类：

| 类型 | 识别标准 | 统计维度 |
|------|---------|---------|
| **对话** | 引号内内容 / 一人说一句的模式 | 对话占比、人均句长 |
| **动作** | 短句+动词密集 | 动作段落占比 |
| **描写** | 环境/外貌/物品的感官描写 | 五感分布 |
| **心理** | 内心独白/情绪词/回忆 | 心理描写深度 |
| **叙述** | 交代背景/时间跳跃/总结 | 信息密度 |
| **日常** | 吃饭/购物/闲聊 | 侧面设定密度 |

输出：各类型占比 + 雷达图描述

### 第三步：技巧提取

#### 节奏分析
- 统计每段句数和句长分布
- 找出节奏变化点（长→短的切换位置）
- 统计每千字的节奏切换次数

#### 对话分析
- 对话占比（全书中对话字数 / 总字数）
- 潜台词密度（说话人真实意图≠字面意思的比例）
- 废话/语气词使用频率
- 是否有抢话/打断

#### 描写分析
- 五感使用频率（视觉/听觉/嗅觉/触觉/味觉各多少次）
- 侧面描写占比（通过NPC/环境间接展示 vs 直接描述）
- 设定融入密度（世界观信息通过日常场景自然带出的比例）

#### 伏笔分析
- 标记前置线索出现位置
- 标记揭示/回收位置
- 计算前置→揭示的章距
- 分析线索的隐蔽程度（是否容易被读者猜到）

### 第四步：风格建档

将提取的特征存入 Memory，供后续写作参考：

```
memory_store(
  content="《{书名}》风格特征：句式{短/中/长}为主（占比{x}%/{y}%/{z}%），对话占比{d}%，描写密度每千字{n}段，五感偏好{视觉+听觉}，独特用词：{词1、词2}",
  metadata={tags: "shared,style-profile", type: "reference"}
)
```

### 第五步：技巧提炼

提取可复用的具体手法：

```
memory_store(
  content="《{书名}》技巧：{具体手法描述}，示例：{原文片段}，适用场景：{什么时候用}",
  metadata={tags: "shared,technique", type: "reference"}
)
```

## 输出模板

```markdown
# 《{书名}》拆书分析

## 基础数据
- 分析字数：{N}字
- 段落类型分布：对话{d}% | 动作{a}% | 描写{w}% | 心理{p}% | 叙述{n}% | 日常{l}%

## 节奏特征
- 平均句长：{N}字
- 句长分布：短句(<10字){x}% | 中句(10-20){y}% | 长句(>20){z}%
- 节奏切换频率：每千字{N}次

## 对话特征
- 对话占比：{d}%
- 潜台词密度：{高/中/低}
- 废话/语气词：{有/无}，示例：{...}
- 抢话/打断：{有/无}

## 描写特征
- 五感分布：视觉{N} | 听觉{N} | 嗅觉{N} | 触觉{N} | 味觉{N}
- 侧面描写占比：{N}%
- 设定融入密度：每千字{N}处

## 伏笔特征
- 发现伏笔：{N}条
- 平均回收章距：{N}章
- 隐蔽程度：{高/中/低}

## 可借鉴技巧
1. {技巧1}：{描述} — 适用：{场景}
2. {技巧2}：{描述} — 适用：{场景}
3. {技巧3}：{描述} — 适用：{场景}

## 风格标签
{标签1} | {标签2} | {标签3}
```
