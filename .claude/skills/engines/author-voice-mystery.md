# 作者声音 — 悬疑/揭秘剧情层

> 加载时机：悬疑铺设、真相揭露、伏笔回收。在通用层基础上叠加。

## 悬疑声音指纹

### 核心原则
- **信息控制是唯一的节奏**。给多少、什么时候给、以什么方式给——决定悬疑感
- 叙述者知道答案，但**假装不知道**。让读者和POV人物同步困惑
- 真相揭露时，声音必须从"模糊"瞬间切换到"清晰"——这种切换本身就是冲击

### 节奏控制

#### 铺垫阶段（读者不知道有问题）
- 正常叙事，但**埋入异常细节**
- 异常细节不解释，像日常一样带过去
- 让读者事后回想才意识到"原来那时候就有问题了"

#### 暗示阶段（读者觉得不对劲）
- 异常细节开始**重复出现**
- 每次出现多一点点信息，但还不够拼出全貌
- POV人物开始注意到，但还没重视

#### 揭示阶段（真相揭露）
- **先给画面，后给解释**
- 让读者看到真相的画面1-2秒，POV人物才反应过来
- 揭示后的3-5句内，声音变冷、变快——信息密度突然爆增

### 信息投放技术

| 层级 | 技术 | 示例 |
|------|------|------|
| 第一层 | 异常细节当日常写 | 某个角色做了件不太对的事——像日常一样带过去 |
| 第二层 | 异常重复但不解释 | 同一个异常反复出现，每次都像巧合 |
| 第三层 | POV人物开始注意 | POV角色"多看了一眼"——但他没追问 |
| 第四层 | 异常与其他异常连接 | 多个独立异常突然指向同一个答案 |
| 第五层 | 真相画面先给 | 关键证据/画面先呈现，角色的反应后给 |

### 比喻库（悬疑专用）
> ⚠️ 以下为示例格式。每部小说应从自己的世界观中提炼比喻。

| 概念 | 比喻思路 |
|------|---------|
| 不对劲 | 用感官上的微妙异常（手感/气味/声音不对） |
| 隐藏真相 | 需要额外动作才能发现的东西 |
| 真相逼近 | 用越来越强的危险信号类比 |
| 恍然大悟 | 用突然的光亮/清晰类比（不是渐变，是瞬间） |
| 真相的代价 | 用揭示本身带来的伤害类比 |

### 悬疑节奏标准
- 叙述者只呈现事实，让读者自己发现"这里有问题"——读者比你早一步发现异常 = 最佳悬疑
- POV人物的推理必须慢读者半步：他能注意到不对劲，但拼不出完整真相——信息差制造悬念
- 真相揭露后用画面收束：一个画面就够了（表情/动作/环境变化），大段解释会破坏悬疑张力
- 伏笔分批回收，每次只亮一盏灯——读者消化一个真相后，再给下一个

### 揭示后的声音切换
真相揭露后，必须在5句内完成声音切换：
1. 真相画面（客观描述，不带情感）
2. POV人物的生理反应（手抖、呼吸停、后颈发凉）
3. 环境的"反应"（环境突然变化、远处有{本地生物}叫）
4. POV人物的第一个动作（把东西塞进口袋、转身、走）
5. 下一场景的第一个画面（转场，不停留）
