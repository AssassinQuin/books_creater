# 作者声音 — 悬疑/揭秘剧情层

> 加载时机：悬疑铺设、真相揭露、伏笔回收。在通用层基础上叠加。

## 悬疑声音指纹

### 核心原则
- **信息控制是唯一的节奏**。给多少、什么时候给、以什么方式给——决定悬疑感
- 叙述者知道答案，但**假装不知道**。让读者和POV人物同步困惑
- 真相揭露时，声音必须从"模糊"瞬间切换到"清晰"——这种切换本身就是冲击

### 节奏控制

#### 铺垫阶段（读者不知道有问题）
- 正常叙事，但**埋入异常细节**
- 异常细节不解释，像日常一样带过去
- 让读者事后回想才意识到"原来那时候就有问题了"

#### 暗示阶段（读者觉得不对劲）
- 异常细节开始**重复出现**
- 每次出现多一点点信息，但还不够拼出全貌
- POV人物开始注意到，但还没重视

#### 揭示阶段（真相揭露）
- **先给画面，后给解释**
- 让读者看到真相的画面1-2秒，POV人物才反应过来
- 揭示后的3-5句内，声音变冷、变快——信息密度突然爆增

### 信息投放技术

| 层级 | 技术 | 示例 |
|------|------|------|
| 第一层 | 异常细节当日常写 | "牧师多做了几秒净化"——像日常一样带过去 |
| 第二层 | 异常重复但不解释 | 每次见到牧师，净化时间都多几秒 |
| 第三层 | POV人物开始注意 | 沈野"多看了一眼"——但他没问 |
| 第四层 | 异常与其他异常连接 | 净化时间+沈念揉手指+兑换券——三个异常指向同一个答案 |
| 第五层 | 真相画面先给 | 沈野翻到兑换券——画面先给，他的反应后给 |

### 比喻库（悬疑专用）
| 概念 | 世界观内比喻 |
|------|-------------|
| 不对劲 | 像碎渣的手感不对——不是石头，不是普通碎渣 |
| 隐藏真相 | 像管道深处的碎渣，需要摸才能发现 |
| 真相逼近 | 像灰蜥的脚步声从管道另一头传来，越来越近 |
| 恍然大悟 | 像照明石突然亮了——不是 gradual，是 snap |
| 真相的代价 | 像碎渣弹爆炸——亮了，但碎片会伤到自己 |

### 禁忌
- 禁止叙述者提前暗示"这里有问题"——让读者自己发现
- 禁止POV人物过早推理出真相——他的推理必须慢读者半步
- 禁止真相揭露后用大段解释——真相的画面够了，解释破坏悬疑
- 禁止所有伏笔同时回收——分批回收，每次只亮一盏灯

### 揭示后的声音切换
真相揭露后，必须在5句内完成声音切换：
1. 真相画面（客观描述，不带情感）
2. POV人物的生理反应（手抖、呼吸停、后颈发凉）
3. 环境的"反应"（照明石闪了一下、远处有灰蜥叫）
4. POV人物的第一个动作（把东西塞进口袋、转身、走）
5. 下一场景的第一个画面（转场，不停留）
