# 三视角剧情审查引擎

> 所有剧情必须从读者、作者、人物三个视角审视。
> 加载时机：novel-planner-volume 验证阶段 + novel-qa 审计阶段。

---

## 一、读者视角

> 读者知道什么？期待什么？感到困惑还是兴奋？

### 1.1 理解度检查

| 检查项 | 标准 | 问题示例 |
|--------|------|---------|
| 信息层级 | 第一层（动作/对话）→第二层（暗示）→第三层（解释），不跳级 | 直接给第三层解释，读者失去探索乐趣 |
| 悬念管理 | 每个悬念有明确的"未知类型"（谁/为什么/怎么/什么时候/会怎样） | 读者不知道自己在等什么 |
| 伏笔可见度 | 伏笔在首次出现时像日常细节，不标红 | 伏笔太明显=剧透，太隐藏=遗忘 |
| 角色识别 | 新角色首次出场有明确标识（外貌/动作/对话风格） | 读者分不清谁是谁 |
| 场景定位 | 每个场景开头明确时间/地点/人物 | 读者不知道现在在哪里 |

### 1.2 吸引力检查

| 检查项 | 标准 | 问题示例 |
|--------|------|---------|
| 钩子强度 | 每章开头有冲突/悬念/异常信号 | 开头铺垫环境，读者弃文 |
| 节奏变化 | 紧张→松弛→紧张，不是单调 | 全程高潮=全程无高潮 |
| 情感共鸣 | 有至少1个让读者"代入"的瞬间 | 角色全是工具人，无情感连接 |
| 期待感 | 读者想知道"接下来会发生什么" | 剧情可预测，无悬念 |
| 爽点分布 | 承转段有升级/收获/打脸，起合段有悬念/危机 | 爽点太密或太疏 |

### 1.3 困惑点检查

| 检查项 | 标准 | 问题示例 |
|--------|------|---------|
| 逻辑跳跃 | 事件A到事件B有明确因果 | 读者觉得"这怎么突然..." |
| 设定突兀 | 新规则提前铺垫，不突然抛出 | 突然冒出一个没提过的能力 |
| 人物行为 | 角色行为符合其已知性格 | "他怎么会这么做？" |
| 时间线 | 时间顺序清晰，不混乱 | 回忆/现实切换无标识 |

## 二、作者视角

> 结构是否完整？伏笔是否合理？节奏是否恰当？

### 2.1 结构检查

| 检查项 | 标准 | 问题示例 |
|--------|------|---------|
| 起承转合 | 每卷/每章有明确的起承转合 | 只有"起"没有"转"，平铺直叙 |
| 因果链 | 每个关键事件有充分前因 | "因为剧情需要"不是答案 |
| 伏笔回收 | 埋下的伏笔有回收计划，不烂尾 | 伏笔太多，回收不过来 |
| 支线管理 | 支线有独立价值，不拖累主线 | 支线太长，主线被遗忘 |
| 节奏控制 | 高潮/低谷/平台期分布合理 | 前紧后松或前松后紧 |

### 2.2 伏笔检查

| 检查项 | 标准 | 问题示例 |
|--------|------|---------|
| 伏笔密度 | 每章≤2个新埋伏笔，≥1个提起旧伏笔 | 伏笔太少=无深度，太多=混乱 |
| 伏笔层级 | 章级/卷级/跨卷/全书/烟雾弹，层级清晰 | 所有伏笔都是"全书级"，无层次 |
| 回收时机 | 伏笔回收时读者有"原来如此"感 | 回收太早=无惊喜，太晚=被遗忘 |
| 烟雾弹 | 有故意误导的烟雾弹，增加悬疑 | 所有线索都指向同一答案 |

### 2.3 主题检查

| 检查项 | 标准 | 问题示例 |
|--------|------|---------|
| 主题一致性 | 所有事件指向同一核心主题 | 事件各自为政，无统一主题 |
| 象征系统 | 核心意象反复出现，形成象征 | 意象用过即弃，无积累 |
| 价值观 | 作者价值观通过人物行为传达，不直接说教 | 叙事者突然评论"这就是人性" |

## 三、人物视角

> 角色行为是否符合性格？动机是否充分？选择是否必然？

### 3.1 行为逻辑检查

| 检查项 | 标准 | 问题示例 |
|--------|------|---------|
| 性格一致性 | 角色行为符合其性格档案 | 胆小的角色突然勇敢，无铺垫 |
| 能力边界 | 角色不超越其能力范围解决问题 | 突然觉醒新能力脱困 |
| 知识边界 | 角色不做超越其认知的决定 | 角色知道不该知道的信息 |
| 情感真实性 | 角色的情感反应符合其经历 | 亲人死亡只难过一页 |

### 3.2 动机检查

| 检查项 | 标准 | 问题示例 |
|--------|------|---------|
| 动机充分 | 每个关键选择有明确的内在动机 | "因为剧情需要"不是动机 |
| 动机层次 | 表面动机→深层动机→隐藏动机 | 只有表面动机，角色扁平 |
| 动机冲突 | 角色有相互矛盾的动机（想要A但害怕B） | 角色只有一个目标，无内心冲突 |
| 动机变化 | 动机随经历合理变化 | 动机突然改变，无过渡 |

### 3.3 选择必然性检查

| 检查项 | 标准 | 问题示例 |
|--------|------|---------|
| 别无选择 | 角色在当时的处境下，这个选择是最合理的 | 明明有更简单的选择，角色选最难的 |
| 代价明确 | 每个选择有明确的代价 | 选择无代价，无张力 |
| 后悔空间 | 选择后角色有"如果当时..."的后悔 | 角色从不后悔，不像真人 |
| 连锁反应 | 选择引发一系列后果，不是孤立事件 | 选择后无事发生 |

## 四、三视角交叉检查

### 4.1 读者 vs 作者

| 冲突 | 解决原则 |
|------|---------|
| 读者觉得无聊，作者觉得结构完整 | 结构服务读者体验，不是反过来 |
| 读者觉得困惑，作者觉得伏笔巧妙 | 伏笔的可见度需要调整 |
| 读者觉得角色蠢，作者觉得符合逻辑 | 角色的知识边界需要明确 |

### 4.2 读者 vs 人物

| 冲突 | 解决原则 |
|------|---------|
| 读者期待角色A赢，角色A选择输 | 人物选择优先，但需要有充分动机 |
| 读者觉得角色B该死，角色B活着 | 人物生存逻辑优先，但需要有代价 |
| 读者喜欢角色C，角色C戏份少 | 人物服务于故事，不是服务于人气 |

### 4.3 作者 vs 人物

| 冲突 | 解决原则 |
|------|---------|
| 作者需要角色D死，角色D不想死 | 人物选择优先，作者调整结构 |
| 作者需要角色E背叛，角色E性格忠诚 | 人物性格优先，作者找其他角色 |
| 作者需要高潮场面，角色F选择逃避 | 人物选择优先，高潮从其他角色来 |

**核心原则**：人物 > 读者 > 作者
- 人物的行为逻辑是第一位的
- 读者的体验是第二位的
- 作者的结构需求是第三位的

## 五、检查流程

### 5.1 卷级检查（novel-planner-volume 阶段）

对每个事件，过三视角清单：

```
事件: {事件名}

读者视角:
- [ ] 信息层级正确（不跳级）
- [ ] 悬念类型明确
- [ ] 角色可识别
- [ ] 场景可定位
- [ ] 钩子强度足够
- [ ] 无逻辑跳跃

作者视角:
- [ ] 因果链完整
- [ ] 伏笔密度合理
- [ ] 主题一致
- [ ] 节奏恰当

人物视角:
- [ ] 行为符合性格
- [ ] 动机充分
- [ ] 选择必然（无更简单选择）
- [ ] 代价明确

交叉检查:
- [ ] 读者vs作者无冲突
- [ ] 读者vs人物无冲突
- [ ] 作者vs人物无冲突
```

### 5.2 章级检查（novel-qa 阶段）

对每章正文，过三视角清单：

```
第{N}章

读者视角:
- [ ] 开头有钩子
- [ ] 信息不跳级
- [ ] 悬念管理清晰
- [ ] 情感有共鸣点
- [ ] 结尾有期待感

作者视角:
- [ ] 起承转合完整
- [ ] 伏笔操作正确（埋/提/收）
- [ ] 节奏变化明显
- [ ] 主题传达有效

人物视角:
- [ ] POV人物行为符合性格
- [ ] 对话符合说话风格
- [ ] 选择有充分动机
- [ ] 情感反应真实

交叉检查:
- [ ] 三视角无冲突
```

## 六、问题分级

| 级别 | 定义 | 处理 |
|------|------|------|
| P0 | 三视角冲突（人物逻辑 vs 作者结构） | 必须修复，调整结构或人物 |
| P1 | 单视角严重问题（读者完全困惑） | 必须修复，调整信息投放 |
| P2 | 单视角中等问题（读者部分困惑） | 建议修复，优化细节 |
| P3 | 单视角轻微问题（可优化） | 可选修复，批量处理 |
