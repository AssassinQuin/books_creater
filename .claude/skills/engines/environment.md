## 环境5要素

每个环境首次出现时必须完整设计：

### 1. 空间结构
- 建筑类型（管道/废墟/灵站/教会/矿坑）
- 地形（高低/宽窄/出入口/死角/遮挡物）
- 可利用元素（可攀爬的/可推倒的/可躲藏的）
- 灵能基础设施（管道走向/阀门/接口/照明位置）

### 2. 灵能维度
- 灵能浓度（外环低→内环高，影响人物感知和异灵出没）
- 灵能类型（残渣/结晶/流动灵能/污染区）
- 灵能残留（兽潮后/战斗后/日常状态）
- 结晶分布（壁面/地面/空气中）

### 3. 感官层
- **视觉**: 光源+色温+亮度+可见距离+雾/烟/尘
- **触觉**: 温度+湿度+风感+地面质感+灵能刺感
- **嗅觉**: 主气味+次要气味+异常气味（血/焦糊/灵能灼烧）
- **听觉**: 环境底噪+远近声源+异常安静/异响
- **味觉**: 空气味道/食物/灵能水的口感（偶尔）

### 4. 时间维度
- 时段（晨/午/暮/夜/深夜）
- 季节（秋季开头→冬季推进→时间线相关）
- 天气（雾/雨/风/晴/灵能风暴）
- 时间流逝感（"天快亮了"/"又过了一刻钟"）

### 5. 情绪映射
环境暗示人物状态，不直说：
- 紧张 → 风停了，安静得不正常
- 孤独 → 灵能路灯一盏一盏灭
- 希望 → 暖光从管壁缝隙里透出来
- 危险 → 焦糊味比昨天重了一点

## 描写规则

### 首次出现：完整5要素
至少覆盖3个感官+空间结构+时间。不需要罗列，融入叙事：
```
✅ 管道更粗更深，有些地方头顶看不到管壁。灵能残渣厚得像一层壳。
   空气比外环稠，呼吸的时候能感觉到灵能粒子贴着喉咙。(空间+触觉+灵能)

❌ 管道很粗。空气中有灵能残渣。温度适中。没有风。很安静。(罗列式)
```

### 再次出现：只写变化
锚定首次描写的基线，只描写与基线不同的部分：
```
✅ 今天的废墟比昨天安静。连灵能路灯的嗡嗡声都小了。(变化)
❌ 废墟还是那个废墟。管道还在。灵能路灯还在闪。(无信息量重复)
```

### 跨章同场景：一致性锚点
- 温度不能忽冷忽热（同一场景同一时段内）
- 光照来源不能变（管道里没有太阳）
- 气味只能渐变不能突变（除非有原因）

## 环境与事件的关系

### 设计顺序：环境→事件
规划事件时，先回答：
1. 这个事件发生在什么环境？（空间/灵能/感官）
2. 环境如何影响事件？（狭窄空间→追逐战/开阔地带→大规模冲突）
3. 事件如何改变环境？（战斗→灵能残留/塌方→封闭道路）
4. 环境中有哪些可利用元素？（可触发的陷阱/可攀爬的结构）

### 多环境切换
一个大事件可能跨越多个环境：
```
事件: 兽潮来袭
├── 环境1: 聚落管道区 (防御战)
├── 环境2: 第三区管道裂缝 (逃生通道)
├── 环境3: 排水口 (方岩负伤)
└── 环境4: 矿工聚落方向 (沈念逃跑)

每个环境独立建立快照，切换时明确过渡描写。
```
