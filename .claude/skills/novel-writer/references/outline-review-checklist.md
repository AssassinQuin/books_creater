# 大纲审查检查清单

> **本文件功能**: 卷级大纲完成后、章节规划前的强制验证。防止基础叙事逻辑问题流入正文。
> **触发时机**: novel-planner 每卷大纲创建后、🔒确认前。重大修改后也必须重新执行。
> **执行方式**: 4个Agent并行，每个Agent负责一个维度群。
> **核心原则**: 不只查当前卷——必须与前后卷大纲、角色蓝图交叉比对。当前卷没问题但前后全是问题=审查失败。

---

## Agent A: 因果链 + 叙事结构 + 前后一致性

### 开篇验证（V1必须通过，其他卷参考）

- [ ] 开篇前3000字是否有冲突/悬念/异常信号（三选一至少一个）
- [ ] 开篇是否展示了主角的核心特质（不是说明，是行为展示）
- [ ] 金手指/特殊能力在前3章是否至少有一次暗示或展示
- [ ] 读者读前3章后能否回答："主角是谁？他想要什么？什么挡着他？"

### 因果链完整性

- [ ] **每个关键事件有充分前因**：逐个检查大纲中的转折点，每个转折点是否能回答"为什么会发生这件事？"
- [ ] **无"作者方便"事件**：逐个检查——如果读者问"为什么恰好是这样"，有没有比"剧情需要"更好的答案
- [ ] **触发条件检查**：角色做出重大行动（出发/救人/信任/背叛）前，是否有足够的信息/动机/压力支撑
- [ ] **巧合检查**：大纲中的巧合是否有"因为XXX才碰巧"的前因铺垫，而非纯粹的"偶遇"

### 前后卷交叉验证（核心新增）

- [ ] **角色状态连续性**：上一卷结尾的角色（位置/能力/关系/知识/目标）→ 本卷开头是否一致？逐角色对比
- [ ] **承诺追踪**：上一卷结尾留下的悬念/承诺/未完成的目标，本卷是否有回应？不能"忘了"
- [ ] **伏笔接力**：上一卷埋的伏笔，本卷是否有推进（不一定要回收，但不能完全沉默）
- [ ] **信息差守恒**：角色在上一卷知道的信息，本卷不能"忘记知道"。角色在上一卷不知道的，本卷不能"突然知道"（除非有新的获取途径）
- [ ] **能力连续性**：角色在上一卷展现的能力等级，本卷不能突然变弱（无理由）或突然变强（无铺垫）
- [ ] **关系连续性**：上一卷建立的角色关系（信任/敌对/暧昧），本卷开头必须延续，不能"重置"
- [ ] **下一卷可衔接**：本卷结尾的状态，能否自然过渡到下一卷（如果下一卷已规划，直接比对）

### 场景过渡逻辑

- [ ] **卷间过渡**：上一卷结尾的角色位置/目标/状态，是否与下一卷开头一致
- [ ] **角色去向清晰**：上一卷出场的角色，下一卷在做什么？不能"消失"（除非死亡/离队有交代）
- [ ] **时间线衔接**：两卷之间的时间间隔是否合理，角色状态变化是否有时间支撑
- [ ] **地点移动合理**：角色从A到B有没有交代路径/耗时/途中事件

### 节奏结构

- [ ] 本卷开头是否有钩子（让读者想继续的理由）
- [ ] 本卷是否有至少一个高潮场景（角色在压力下做出艰难选择）
- [ ] 本卷结尾是否留了下一卷的钩子
- [ ] 有无连续3段以上慢节奏无冲突段落（标记为"拖沓风险"）
- [ ] 爽点间隔是否合理（网文标准：每2-3卷至少一个小爽点）

## Agent B: 角色动机 + 行为逻辑 + 蓝图比对

### 关键动作动机检查

逐个检查大纲中角色的**关键动作**（每个角色每卷不超过5个关键动作）：

- [ ] **动作→动机匹配**：角色做这件事，读者能理解为什么吗？如果答案是"因为剧情需要"，标记为问题
- [ ] **角色知不知道该做**：角色掌握的信息足以支撑他的决定吗？不能让角色基于他不知道的信息行动
- [ ] **符合性格设定**：这个动作和角色的Ghost/Lie/Want是否自洽？如果矛盾，矛盾是否有铺垫
- [ ] **代价/收益合理**：角色付出这个代价换来的东西，从他的价值观看值得吗？

### 角色蓝图交叉比对（核心新增）

读取 `设定/角色深化.md` + `设定/人物/*.md`，逐角色比对：

- [ ] **Ghost一致性**：本卷角色的行为能从他/她的Ghost（创伤）推导吗？有没有"明明有这个创伤但表现得像没有"的地方
- [ ] **Lie→Want推导链**：本卷角色的Want（外在目标）是否被Lie（错误信念）驱动？Want变了但Lie没变=不合理
- [ ] **弧线进度匹配**：角色的成长轨迹表与本卷大纲是否一致？跳跃或回弹都需要解释
- [ ] **能力等级匹配**：本卷角色的能力使用是否在角色卡标注的等级范围内？不能用超出等级的能力
- [ ] **知识范围守恒**：本卷角色展示的"知道的信息"是否在角色卡的knowledge_scope内？超出=需要新增获取途径
- [ ] **关系网匹配**：本卷角色间的互动是否符合 `relation_list` 中记录的关系类型和强度
- [ ] **未覆盖角色检查**：角色深化文档中列出的角色，是否在本卷有合理的出场/缺席？重要角色连续2卷无独立行动=问题

### 特别检查项（从V1V2教训提取）

- [ ] **"救/帮/信任"动机充分性**：主角/配角为什么要救/帮/信任一个陌生人？仅"善良"不够，需要具体压力或利益
- [ ] **"给/送/牺牲"动机充分性**：角色把珍贵之物给别人，有充分理由吗？仅"好心"不够
- [ ] **"隐瞒/不告诉"动机充分性**：角色为什么要隐瞒信息？隐瞒对自己有利还是有弊？如果不利还隐瞒，恐惧必须具体
- [ ] **"突然出现"合理性**：新角色/旧角色在某个场景突然出现，有足够的前因（为什么在这里/为什么是这个时间）吗
- [ ] **"不去做某事"合理性**：角色明明应该做某事却没做，理由充分吗？不能靠"角色智商不够"来解释

### 角色并行线逻辑

- [ ] 如果A线（角色A的行动）和B线（角色B的行动）是并行的，时间线是否对齐
- [ ] A线中角色A不知道B线发生的事，是否一致（不能让A对B的行为了如指掌）
- [ ] 两条并行线汇合时，各自的状态是否自洽（A经历了X，B经历了Y，汇合时两人各带着X和Y的后果）

---

## Agent C: 商业性 + 信息密度 + 立意检查

### 商业节奏

- [ ] 本卷有几个爽点？（0个=致命，1个=危险，2+个=合格）
- [ ] 爽点类型是否多样？（全是"逃跑成功"不够，需要"赢了/发现了/被认可了"等正向爽点）
- [ ] 本卷是否有让读者"想骂人/想哭/想拍桌"的情感爆发点
- [ ] 弃文风险预测：读者最可能在哪里弃文？标出位置和原因

### 立意与核心主题（核心新增）

- [ ] **本卷的核心冲突是否清晰**：用一句话能说清楚"这卷在讲什么"吗？说不清=立意模糊
- [ ] **主题站得住脚**：本卷表达的观点/态度，读者会反驳吗？"牺牲是值得的""真相必须公开"——站得住吗？
- [ ] **明暗双线清晰**：明线（角色看的到的）和暗线（读者能猜到的）分别是什么？暗线推进了多少？
- [ ] **核心价值观一致**：本卷传递的价值观和全书核心主题一致吗？不能V1说"个人活命重要"V2突然变"牺牲精神"
- [ ] **不教条**：有没有"讲道理"的段落？角色用行为传递主题，不是用台词

### 信息密度

- [ ] 本卷引入了几个新概念？（超过5个标记为"过载风险"）
- [ ] 本卷引入了几个新角色？（超过4个标记为"角色过载"）
- [ ] 新概念/新角色是否分层释放（而非集中在一个段落全部抛出）
- [ ] 有无"教科书段落"——用叙述句直接解释设定而非通过角色行为展示

### 伏笔管理

- [ ] 本卷新埋伏笔数量 vs 回收旧伏笔数量（净增加>5条=伏笔积压）
- [ ] 每条新伏笔是否标注了计划回收点
- [ ] 跨卷未回收伏笔是否超过30章（标记为"伏笔疲劳风险"）

## Agent D: 重大问题头脑风暴 + 外部调研

> **触发条件**：Agent A/B/C发现P0或P1问题时自动启动。不启动=跳过此Agent。

### 问题分类与处理策略

| 问题类型 | 处理方式 | 目的 |
|---------|---------|------|
| 简单修复（补前因/加过渡） | 直接给出修复方案 | 快速解决 |
| 角色动机不足 | 头脑风暴3种以上动机方案，选最优 | 不闭门造车 |
| 重大人设/能力/剧情问题 | **启动外部调研**：搜索同类作品的处理方式、分析优缺点 | 参考成熟方案 |
| 前后卷矛盾 | 回溯到问题源头，评估从哪一卷改代价最小 | 最小改动原则 |

### 头脑风暴流程（P0/P1问题必执行）

对每个P0/P1问题：
1. **明确问题**：一句话说清"哪里不对"
2. **生成方案**：至少3种不同方向的修复方案
3. **评估代价**：每种方案对前后卷的影响（改一卷vs改多卷）
4. **推荐最优**：选代价最小、效果最好的方案
5. **如果涉及重要人设/能力/剧情设计**：启动外部调研（见下方）

### 外部调研触发条件

满足以下任一条件时，必须启动调研（不能闭门造车）：

- [ ] 新设计核心能力体系（灵能/异能/魔法等）
- [ ] 新设计重要角色原型（反派/导师/竞争对手等）
- [ ] 核心剧情反转（认知推翻/真相揭示等）
- [ ] 涉及现实领域知识（军事战术/医学/政治博弈/经济学等）
- [ ] 读者可能质疑"为什么是这样"的世界观设定

### 调研方法

1. **同类作品参考**：搜索3-5部同类题材作品（网文/小说/影视），看它们怎么处理类似问题
2. **现实逻辑验证**：如果是现实领域问题（军事/医学等），搜索该领域的基础知识验证合理性
3. **读者反馈预判**：搜索平台（起点/番茄/贴吧）的读者讨论，看同类设定的读者接受度
4. **输出调研摘要**：每个调研点输出3-5条可落地的设计建议，标注来源

## 问题分级标准

| 级别 | 定义 | 处理方式 |
|------|------|---------|
| **P0-致命** | 因果链断裂、开篇无钩子、关键动作动机缺失、前后卷矛盾 | 必须修复后才能确认大纲 |
| **P1-严重** | 角色行为不合理、节奏拖沓、信息过载、立意模糊 | 建议修复+头脑风暴，用户确认可降级 |
| **P2-中等** | 伏笔悬空、配角工具人化、爽点不足 | 标记后待优化 |
| **P3-轻微** | 命名/措辞/细节 | 可选修改 |

## 审查报告格式

```markdown
# 大纲审查: 第{N}卷 {卷名}

**日期**: {日期}
**审查范围**: 全卷大纲 + 前后卷交叉验证 + 角色蓝图比对
**前卷状态**: 第{N-1}卷结尾→本卷开头，{一致/不一致项}
**角色蓝图**: 已比对/{N}个角色，{M}个一致/{K}个问题

## P0-致命问题 ({N}个)
### 1. {问题标题}
- 位置: {大纲中的哪个段落}
- 类型: {因果链断裂/动机缺失/开篇无钩子/前后矛盾/蓝图不符}
- 问题: {具体描述——读者会怎么说}
- 修复方案: {头脑风暴/调研后的推荐方案，附2-3个备选}

## P1-严重问题 ({N}个)
{同上格式}

## P2-中等问题 ({N}个)
{同上格式}

## 外部调研记录（如有）
### {调研主题}
- 参考来源: {列出参考的作品/资料}
- 可落地建议: {3-5条具体设计建议}
- 采纳状态: {已采纳/备选/暂缓}

## 亮点
- {大纲中设计得好的地方}

## 前后卷交叉验证结果
- 角色状态连续性: {通过/N处不一致}
- 伏笔接力: {通过/N条未推进}
- 信息差守恒: {通过/N处违规}
- 能力连续性: {通过/N处跳跃}
- 关系连续性: {通过/N处重置}

## 总评
- 爽点数: {N}个（{类型列表}）
- 弃文风险: {高/中/低}，风险点: {位置}
- 因果链完整度: {N}%
- 蓝图符合度: {N}%
- 立意清晰度: {清晰/模糊/站不住}
- 建议动作: {通过/修复后通过/重写}
```

## 大文件拆分规则

- 单卷大纲文件 > 3000字时，拆分为 `大纲/{NN}-{卷名}.md`（主文件）+ `大纲/{NN}-{卷名}-场景.md`（场景细节）+ `大纲/{NN}-{卷名}-伏笔.md`（伏笔清单）
- 角色深化文档按角色数拆分：`人物/{角色名}.md`（单人卡）+ `角色深化.md`（汇总索引）
- 审查报告独立文件：`审阅报告/大纲审查-V{N}-{日期}.md`
