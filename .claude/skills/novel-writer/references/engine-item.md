## 物品全生命周期模板

新物品首次出现时，按此模板建立档案：

```yaml
物品名: {中文名}
别名/俗称: {拾荒者叫法/正式名称/外号}

# 来源
生成方式: {如何产生/采集/制造}
产地: {哪里有/哪里多/哪里没有}
稀缺度: {随处可见/常见/稀少/极稀有}

# 外观
形态: {固体薄片/结晶/液体/粉末/工具}
颜色: {灰绿/暗白/金色/透明/随浓度变化}
质感: {凉/麻/涩/黏/脆/硬}
光泽: {微荧光/哑光/金属光泽/结晶闪光}
大小: {指甲盖/掌心/拳头/手臂长}
结构: {单层/双层嵌套/三层/回路纹路}

# 感官
触感: {碰到的感觉/长时间接触的后果}
气味: {自然状态/燃烧时/研磨时}
味道: {如果入口}
声音: {碰撞/踩踏/研磨时的声音}

# 功能
主要用途: {列出1-5个}
使用方式: {怎么用/需要工具吗/有门槛吗}
生效条件: {需要灵能激活/直接使用/需要研磨}
持续时间: {一次性/持续多久/消耗速度}

# 等级/类型差异
类型1: {名称} - {与基础型的区别} - {价格/稀有度}
类型2: {名称} - {区别} - {价格}
...

# 变化与衰减
自然衰减: {暴露空气多久失效/灵能散逸速度}
受激发: {接触灵能/高温/撞击时反应}
用后变化: {变成什么/残留什么/消失无踪}

# 使用禁忌与代价
直接接触: {高浓度灼手/粉末吸入咳血/长期接触灵衰症}
误用后果: {灵能爆炸/中毒/吸引异灵}

# 经济
价格: {铜板/兑换券/以物易物比}
获取成本: {时间/体力/风险}
存储条件: {干燥处/避灵能/密封}

# 在故事中的使用记录
ch{N}: {怎么用的，状态变化}
```

## 使用规则

### 首次使用新物品
1. 按模板建立完整档案
2. 存储到 `world_upsert(category="ability"/"economy"/自定义, name="{物品名}", data={档案}})`
3. 正文中只展示与当前场景相关的属性（不全量罗列）

### 后续使用
1. 从 `world_query(name="{物品名}")` 加载档案
2. 正文描写必须与档案一致
3. 如果本章有新的属性发现，更新档案

### 消耗品追踪
- 每章写完后在 `writing_finish` 的 key_events 中标注物品消耗
- 下章加载时通过人物状态快照确认剩余量

## 一致性校验规则

QA检查时：
- **外观矛盾**: 档案写"灰绿色"→正文写"蓝色" → 报错
- **功能矛盾**: 档案写"止血"→正文写"没有效果" → 报错
- **价格矛盾**: 档案写"2铜板"→正文写"50铜板" → 报错（除非有通货膨胀原因）
- **使用矛盾**: 档案写"需要研磨"→正文直接抓了用 → 报错
- **消耗矛盾**: 上章用完了→本章还在用 → 报错

## 常见物品档案示例（灵能残渣）

```yaml
物品名: 灵能残渣
别名: 碎渣/残渣/灰绿片子

来源: 灵能设备耗损自然脱落/异灵遗骸析出/矿脉自然析出
产地: 废墟管道内壁(外环薄→内环厚)/异灵尸体附近/灵能矿脉
稀缺度: 随处可见(外环)/常见(内环)

形态: 薄片状固体
颜色: 灰绿色(单层外环)/暗绿偏蓝(高浓度)/发金(特殊残片)
质感: 凉/微麻(正常)/烫(高浓度或共振时)
光泽: 边缘微荧光
大小: 指甲盖到掌心不等
结构: 单层回路(外环)/双层嵌套(第四区)/三层(内环)

触感: 正常碎渣凉/高浓度灼手/研磨后有粉感
气味: 淡苦/金属味/不完全燃烧时焦苦
声音: 踩上去沙沙响/碰撞轻脆/研磨闷响

主要用途: 燃烧发热(穷人取暖)/填充管路(修照明石)/触发陷阱/研磨止血(微弱)
使用方式: 直接使用(燃/填)/用刮刀采集/研磨成粉
持续时间: 燃烧约1时辰/止血效果2-3时辰/填充后长期有效

类型1: 灰绿单层残渣 - 外环常见 - 2铜板/片
类型2: 双层嵌套残渣 - 第四区 - 10铜板/片
类型3: 灵能碎片(残片) - 极稀有 - 无定价/无市

变化: 暴露空气缓慢失能(数日)/接触灵能共振发热/不完全燃烧冒白烟
禁忌: 直接抓高浓度灼手/吸入粉末咳血/长期接触手指发灰(灵衰症诱因之一)
```
