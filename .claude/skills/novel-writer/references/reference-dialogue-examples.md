## 动作卡位法案例

用动作代替"说"，让人物边做动作边说话，画面感立现。

```
❌ "你别闹了。"他说。
✅ 他伸手按住她的肩膀，手指轻轻蹭了蹭她的胳膊，语气软下来："你别闹了。"

❌ "你必死无疑。"反派说。
✅ 反派攥紧拳头，手背青筋暴起，狠狠砸在桌子上："你必死无疑。"
```

## 神态神韵法案例

用表情、神态代替"说"，情绪直接透出来。

```
❌ "我没有做错。"她说。
✅ 她眼眶泛红，睫毛轻轻颤动着，声音带着哭腔："我没有做错。"

❌ "就凭你？"大佬说。
✅ 大佬挑眉，嘴角勾起一抹嘲讽的笑，眼神斜睨着他："就凭你？"
```

## 情境穿插法案例

在对话中间插一句环境描写，自然打断"说"字，烘托气氛。

```
❌ "你根本不懂我！"她说。"我怎么不懂？"他说。
✅ "你根本不懂我！"她猛地转身。窗外的雷雨砸在玻璃上，噼啪作响。
  "我怎么不懂？"他追上去，声音被风声盖得发闷。

❌ "其实我早就注意你了。"他说。"我也是。"她说。
✅ "其实我早就注意你了。"他声音很轻。月光透过窗棂，洒在他的发梢。
  "我也是。"她低头，指尖蹭着衣角。
```

**情境穿插时机**：情绪转折处、对话停顿处、气氛切换处。环境描写1-2句即可，不宜过长。

## 语感辨识法案例

靠角色的语言特色直接省略"说"字。前提是人物说话有自己的风格，不能所有人一个味儿。

```
街头混混："去去去，别挡老子的路，再烦老子收拾你！"
→ 不用写"混混说"，语气自带身份标签。

豪门千金："麻烦你帮我拿一下那本书，谢谢。"
→ 不用写"千金说"，礼貌疏离感就是标签。

夫妻对话："饭好了吗？""快了，再等五分钟。"
→ 不用加任何提示语，自然分清谁是谁。
```

**语感辨识前提**：每个主要角色的句式节奏、口头禅、用词层次必须有明显差异。

## 标点组合技巧案例

```
❌ AI单调标点：
"你没事吧。"她说。"我没事。"他说。"真的吗。"她问。

✅ 丰富标点：
"你没事吧？"她声音发紧。
他摇头，没说话。
"……真的？"
"嗯。"他顿了顿，"……真的。"
```

## 对话节奏案例（超过3句纯对话需插入动作/微表情/环境）

超过3句纯对话必须插入动作/微表情/环境：

```
✅
"几时了？"沈念揉了揉眼睛。
"辰时过了。"沈野把糊糊盛了两碗。
"照明石你动过？"
"填了点碎渣。"他没抬头。

❌ (纯对话堆叠)
"几时了？"
"辰时过了。"
"照明石你动过？"
"填了点碎渣。"
"好看。"她说。
沈野没接话。
```
