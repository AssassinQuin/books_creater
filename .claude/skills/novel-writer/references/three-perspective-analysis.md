# 三视角大纲分析

> 从读者、作者、编辑三个角色同时审视大纲框架，多维度发现可优化点。适用于卷级大纲完成后、章节规划前的整体审查。

---

## 触发条件

- 用户说"分析大纲"/"三视角"/"审查框架"
- B1卷规划完成后、B2章节规划前
- 大纲重大修改后

## 输入要求

- 全部卷级大纲文件
- 角色深化文档（如有）
- 世界观设定（如有）

## 三个分析角色

### 角色1：读者（Reader）

**核心问题**："我会不会追更？"

| 分析维度 | 检查项 | 输出格式 |
|---------|--------|---------|
| 钩子强度 | 每卷开头3行能否抓住注意力 | 钩子评分表（1-10） |
| 爽点节奏 | 升级节点/反转/高潮的间隔是否合理（每2-3卷必须有爽点） | 节奏曲线图 |
| 弃文风险 | 哪些卷最可能让读者流失？为什么？ | 风险点列表+严重度 |
| 情感共鸣 | 读者最可能在哪些场景哭/燃/怒？ | 情感高光点列表 |
| 代入感 | 主角的行为逻辑读者能理解吗？有没有"为什么要这样做"的断裂？ | 代入断裂点 |
| 信息过载 | 设定信息是否自然融入？有没有"教科书段落"？ | 过载段落标记 |
| 期待管理 | 伏笔埋下后回收间隔是否太长/太短？读者会不会忘了？ | 伏笔回收时间表 |

**输出模板**：
```markdown
# 读者视角分析

## 追更欲望评分：{N}/10
## 弃文风险点（按严重度排序）
## 爽点节奏曲线
## 情感高光Top5
## 代入断裂点
## 伏笔疲劳风险
## 优化建议（优先级排序）
```

### 角色2：作者（Author）

**核心问题**："这个故事讲得通吗？"

| 分析维度 | 检查项 | 输出格式 |
|---------|--------|---------|
| 故事逻辑 | 因果链是否完整？每个事件是否有充分的前因？ | 逻辑链图 |
| 人物弧光 | 每个核心角色是否有完整的变化曲线？弧光是否有"回弹"（不是直线）？ | 弧光完成度表 |
| 结构对称 | 三次认知推翻的力度是否递增？高潮是否有足够铺垫？ | 结构分析 |
| 主题一致性 | 所有支线是否都在服务核心主题？有没有偏题的线？ | 主题偏离检测 |
| 角色利用率 | 每个角色在各卷是否有存在感？有没有"隐形角色"？ | 角色出场热力图 |
| 矛盾冲突 | 每卷是否有足够的冲突驱动？有没有"无事发生"的段落？ | 冲突密度图 |
| 信息差管理 | 读者知道vs角色知道vs作者知道——信息差是否被有效利用？ | 信息差矩阵 |
| 写作难度 | 哪些段落写起来会特别难？需要什么准备？ | 写作难度预警 |

**输出模板**：
```markdown
# 作者视角分析

## 故事逻辑完整度：{N}%
## 人物弧光完成度（每人评分）
## 核心结构分析
## 角色出场热力图
## 主题偏离检测
## 写作难度预警
## 优化建议（优先级排序）
```

### 角色3：编辑（Editor）

**核心问题**："这本书能卖吗？"

| 分析维度 | 检查项 | 输出格式 |
|---------|--------|---------|
| 品类匹配 | 是否符合目标品类（网文玄幻/都市/科幻）的核心爽点？ | 品类符合度 |
| 开篇质量 | 前3章（V1-V2）是否足够强？黄金三章法则 | 开篇评分 |
| 节奏商业性 | 爽点间隔是否符合平台节奏（每N章一个小高潮）？ | 商业节奏分析 |
| 人物商业性 | 主角是否有"标签化记忆点"？读者能否用一句话描述？ | 人物记忆点检测 |
| 差异化 | 与同类作品的差异化是否足够？读者为什么要看这本？ | 差异化分析 |
| 长篇可持续性 | 14卷的体量能否撑住？有没有注水风险？ | 可持续性评估 |
| 完结风险 | 哪些设定/伏笔可能导致后期崩盘？ | 完结风险预警 |
| 跨卷连贯性 | 卷与卷之间的衔接是否顺畅？有没有"断层"？ | 衔接检查 |

**输出模板**：
```markdown
# 编辑视角分析

## 商业潜力评分：{N}/10
## 品类符合度
## 开篇黄金三章评分
## 差异化卖点
## 节奏商业性分析
## 完结风险预警
## 优化建议（优先级排序）
```

## 执行方式

三个角色用三个并行子agent执行，每个agent：
1. 读取全部卷级大纲+角色深化+世界观设定
2. 按对应角色的分析维度逐一检查
3. 输出标准格式分析报告
4. 最后给出优先级排序的优化建议

## 结果汇总

三个agent完成后，人工或自动汇总：
1. 三个视角的重叠建议（高优先级）
2. 仅单视角提出的建议（中优先级）
3. 汇总为「优化计划」文档
4. 保存到 `novels/{小说名}/docs/三视角分析-{日期}.md`
