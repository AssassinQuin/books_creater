# 三视角大纲分析

> 从读者、作者、编辑三个角色同时审视大纲框架，多维度发现可优化点。
> 适用时机：卷级大纲完成后、章节规划前，或大纲重大修改后。

---

## 前置条件

| 条件 | 说明 | 不满足时的fallback |
|------|------|-------------------|
| 至少3卷大纲 | 需要3卷以上才能分析节奏曲线 | 2卷时只做"开篇分析"，1卷只做单卷检查 |
| 角色深化文档 | 非必须，有则分析人物弧光更准确 | 跳过弧光验证，标注"缺角色数据" |
| 世界观设定 | 非必须，有则分析逻辑一致性更准确 | 跳过世界观交叉验证 |
| 全部卷级大纲 | 理想情况14卷全有 | 缺卷标注"未分析"，只评已有卷 |

## 执行流程

```
Step 1 召回材料 → Step 2 🔒确认范围 → Step 3 三视角并行分析 → Step 4 🔒审阅报告 → Step 5 汇总优化计划 → Step 6 🔒确认计划 → Step 7 保存
```

### Step 1: 召回材料

读取以下文件（如存在）：
- `novels/{小说名}/设定/大纲/*.md` — 全部卷级大纲
- `novels/{小说名}/设定/角色深化.md` — 角色文档（如有）
- `novels/{小说名}/设定/世界观.md` — 世界观设定（如有）

### Step 2: 🔒确认分析范围

向用户展示：
- 检测到N卷大纲（列出卷名）
- 有/无角色深化文档
- 有/无世界观设定
- 是否全部卷还是部分卷（缺哪几卷）

**等用户确认后才继续。** 用户可选：
- "全部分析" → 三视角并行
- "只看读者视角" → 只启动Reader agent
- "只分析V1-V5" → 限定范围
- "先不跑，我补充材料" → 暂停

### Step 3: 三视角并行分析

三个子agent并行执行。每个agent读取全部大纲材料后按各自维度分析。

**可选触发**：用户指定只跑1-2个视角时，跳过未选的。

---

### 角色1：读者（Reader）

**核心问题**："我会不会追更？"

| 分析维度 | 检查方法 | 评分标准 | 输出 |
|---------|---------|---------|------|
| 钩子强度 | 每卷开头3行能否抓住注意力 | 1-10（≤4为高危弃文） | 每卷钩子评分 |
| 爽点节奏 | 升级/反转/高潮间隔是否≤3卷 | 无爽点间隔>3卷=高危；>4卷=极危 | 节奏曲线图（ASCII bar） |
| 弃文风险 | 哪些卷最可能流失读者 | 按严重度排序（高/中/低） | 风险点列表 |
| 情感共鸣 | 预测读者哭/燃/怒的场景 | 高光Top5+理由 | 情感高光列表 |
| 代入感 | 主角行为逻辑读者能理解吗 | "为什么要这样做"=断裂点 | 代入断裂点 |
| 信息过载 | 设定信息是否自然融入 | "教科书段落"=过载 | 过载段落标记 |
| 伏笔疲劳 | 埋下→回收间隔是否合理 | >5卷未回收=高风险 | 伏笔回收时间表 |

**爽点节奏标准**（网文黄金法则）：
- 每2-3卷必须有小爽点（小胜/升级/真相揭露）
- 每4-5卷必须有大爽点（认知推翻/大战/命运转折）
- 连续3卷无爽点=弃文高危区

**输出字段**：追更欲望N/10、弃文风险点(严重度排序)、爽点节奏曲线(ASCII bar)、情感高光Top5、代入断裂点、伏笔疲劳风险、优化建议(优先级排序)

---

### 角色2：作者（Author）

**核心问题**："这个故事讲得通吗？"

| 分析维度 | 检查方法 | 评分标准 | 输出 |
|---------|---------|---------|------|
| 故事逻辑 | 因果链是否完整？每个事件有充分前因？ | 逻辑漏洞数=扣分项 | 逻辑完整度百分比 |
| 人物弧光 | 每角色是否有完整变化曲线？有无回弹？ | 用Weiland框架：Ghost→Lie→Want→Need→弧线类型 | 每人弧光评分表 |
| 结构力度 | 高潮是否有足够铺垫？认知推翻力度是否递增？ | 三次推翻需递增（如7→8.5→9.5） | 结构分析 |
| 主题一致性 | 所有支线是否服务核心主题？ | 偏离主线=标记 | 主题偏离检测 |
| 角色利用率 | 每角色各卷是否有存在感？ | 连续3卷无独立行动=隐形 | 出场热力图 |
| 冲突密度 | 每卷是否有足够冲突驱动？ | 无冲突卷=标记 | 冲突密度图 |
| 写作难度 | 哪些段落写起来特别难？ | 1-10难度评分 | 写作难度预警 |

**Weiland弧线框架**：Ghost(创伤)→Lie(错误信念)→Want(外在目标,被Lie驱动)→Need(内在成长,与Lie矛盾)→弧线类型(正向/平坦/负面)→健康弧线=有回弹+Want/Need有张力

**输出字段**：逻辑完整度N%、弧光完成度(每人评分+Weiland检查)、结构分析(推翻力度递增)、出场热力图、主题偏离检测、写作难度预警(1-10)、优化建议(优先级)

---

### 角色3：编辑（Editor）

**核心问题**："这本书能卖吗？"

| 分析维度 | 检查方法 | 评分标准 | 输出 |
|---------|---------|---------|------|
| 品类匹配 | 核心爽点是否符合目标品类？ | 品类TOP3爽点覆盖率 | 品类符合度 |
| 开篇质量 | 前三卷是否足够强？ | 黄金三章法则：前3章出金手指/前21万字有胜利 | 开篇评分（1-10） |
| 节奏商业性 | 爽点间隔是否符合平台节奏？ | 每2-3卷小高潮/每4-5卷大高潮 | 商业节奏分析 |
| 人物商业性 | 主角是否有标签化记忆点？ | 一句话能描述=及格 | 人物记忆点检测 |
| 差异化 | 与同类作品的差异化足够？ | 至少1个独特卖点 | 差异化分析 |
| 长篇可持续性 | 14卷体量能否撑住？ | 注水风险段落=标记 | 可持续性评估 |
| 完结风险 | 哪些设定可能导致后期崩盘？ | 按严重度排序 | 完结风险预警 |

**黄金三章标准**（网文）：前5000字核心设定露出→前3章金手指初现→前3卷(21万字)至少1胜→留存率目标>30%

**输出字段**：商业潜力N/10、品类符合度、开篇评分1-10、差异化卖点、节奏分析、完结风险、平台推荐(含理由)、优化建议(商业优先级)

---

### Step 4: 🔒审阅三视角报告

三视角分析完成后，**先展示报告给用户审阅**。用户可选：
- "没问题，继续汇总" → 进入Step 5
- "某个视角要修改" → 调整后重新展示
- "补充材料后重跑" → 回到Step 1

### Step 5: 汇总优化计划

自动交叉对比三个视角的建议：

| 重叠度 | 条件 | 优先级 |
|--------|------|--------|
| 三视角重叠 | 2-3个视角同时提出 | **高** |
| 双视角重叠 | 2个视角提出 | **中** |
| 单视角独有 | 仅1个视角提出 | 按来源分列 |

**优化计划格式**：标题(日期+来源) → 高优先级(多视角重叠) → 中优先级(双视角) → 单视角建议(按来源分表) → 执行路线图(分批) → 风险矩阵(严重度×概率)

### Step 6: 🔒确认优化计划

展示优化计划，等用户确认。用户可选：
- "按计划执行" → 修改大纲
- "调整优先级" → 修改后重新确认
- "先记下来，以后再说" → 只保存计划

### Step 7: 保存

保存到 `novels/{小说名}/docs/三视角分析-{日期}.md`（含四个文件：读者/作者/编辑/优化计划）。

---

## 异常处理

| 场景 | 处理 |
|------|------|
| 大纲只有1-2卷 | 只做开篇分析，标注"材料不足" |
| 用户只要1个视角 | 只启动对应agent，汇总时跳过重叠对比 |
| 缺角色文档 | 弧光分析降级为"基于大纲推断"，标注不确定 |
| 缺世界观文档 | 跳过世界观交叉验证 |
| 中途材料更新 | 用户说"重跑"→ 从Step 1重新开始 |

## 与其他skill的集成

- **前置**：`novel-planner` B1卷规划完成后触发
- **后置**：优化计划→ 回到 `novel-planner` 修改大纲
- **数据源**：读取 `novels/{小说名}/设定/` 下的所有文件
- **不依赖novel-db MCP**：纯文件分析，不读写数据库
