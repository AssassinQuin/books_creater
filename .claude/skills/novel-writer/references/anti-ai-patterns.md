# AI味黑名单 V2.0

> **本文件功能**: AI 写作中常见的套路、用词、句式、节奏黑名单。写作时实时对照检查，发现新的 AI 味模式时追加到 Memory。
>
> **V2.0 更新**: 基于专业 AI 文风诊断，新增四大深层 AI 指纹检测体系。

---

## 第一层：词汇级 AI 味（表层）

### 1.1 禁止的高频AI副词（一个都不要用）

不禁、缓缓、淡淡、微微、轻轻、默默、静静、悄悄、渐渐、悄然、陡然、猛然、蓦然、骤然

### 1.2 限制使用的形容词（每章≤1次）

深邃、冰冷、炽热、苍茫、浩瀚、恢弘、磅礴、诡异、阴冷、森然、空灵、悠远

### 1.3 禁止的动词（找替代）

凝视→盯着/看了一眼 | 感受→觉得/感觉 | 萦绕→绕着/转 | 沉浸→埋头/投入 | 彷徨→犹豫/拿不定主意

### 1.4 减少使用的过渡词（每章≤3次）

然而、但是、不过、于是、随后、接着、终于、突然、忽然、此刻、刹那间、一瞬间

### 1.5 情绪描写禁用词

不要: "他心中涌起一股莫名的感动"
换成: 用动作表现（攥紧拳头/咬了一下嘴唇/别过头去）

不要: "所有人都被深深震撼了"
换成: 用具体反应（有人退了一步/没人说话/旁边的人互相看了一眼）

### 1.6 禁止的设定套路

| 套路 | 为什么禁止 | 替代方案 |
|------|----------|---------|
| 使用能力的"代价""反噬" | AI最爱编，9成网文都有 | 用资源不足/对手更强/时机不对制造困难 |
| "寿命折损" | 廉价戏剧性 | 直接让后果是具体的（受伤/失去东西/被人追杀） |
| "精神崩溃/失控暴走" | 太常见 | 用具体的情绪反应（发抖/沉默/咬牙/冷笑） |
| "觉醒隐藏血脉" | 毫无铺垫的即兴设定 | 事先埋伏笔，让读者能回溯 |
| "天道/命运选中之人" | 太空 | 用具体事件驱动（被某个人选中/被某件事卷入） |
| "一步登天的机缘" | 跳过成长过程 | 每次升级都有铺垫和努力 |

## 第二层：句式级 AI 味（深层）⭐ V2.0 新增

### 2.1 🔴 AI指纹 #1：句号切割法（最大破绽）

**症状**: 通篇大量使用句号+短句的"呼吸式断句"，每个信息点都独立成句。

```
❌ AI典型句号切割法（每句独立，节奏机械）：
"不大。比鸡蛋小一点。灰白色的灵能碎片。"
"沈野在跑。管道在脚下延伸。灰蜥在身后。"
"他停下。回头看。什么都没有。"

✓ 人类写法（逗号串联，节奏像呼吸）：
"不大，比鸡蛋小一点，灰白色的灵能碎片。"
"沈野在跑，管道在脚下延伸——身后灰蜥的嘶鸣越来越近。"
"他停了下来，回头看了一眼，什么都没有。"
```

**检测规则**:
- 连续3个以上"XX。XX。XX。"结构的独立短句（每句≤8字）→ 必须改
- 单段内句号断句超过5个独立短句 → 必须改
- 全章"主语+谓语"结构的独立短句超过8次 → 需要压缩合并

**修复方案**:
- 用逗号串联相关信息点：`"不大，比鸡蛋小一点"`
- 用破折号连接转折：`"不是怕——是跑太急了"`
- 合并相关动作：`"他停了下来回头看"` 而非 `"他停下。回头看。"`
- 长短句交替：短句后紧跟一个长句，打破节奏惯性

**适用场景**: 句号切割法在紧张场景可以**有限使用**（快切战斗），但日常/铺垫场景**禁止连续超过2个**。

### 2.2 🔴 AI指纹 #2：解释式展示（最隐蔽的AI味）

**症状**: 每出现一个设定/物品/行为，立刻跟一句解释或说明。AI 害怕读者不理解。

```
❌ AI解释式展示（设定自带注释）：
"灵能结晶在灰蜥鳞片上发出暗绿色的光。荧光映在管壁上，把锈迹都照出来了。"
——"荧光映在管壁上"是对前一句的多余解释，读者已经能想象到发光效果

"不是普通的——普通碎片是单层结构，像一张纸。"
——刚展示完就直接解释区别，不给读者自己感受的空间

"灵能残渣不清理会影响睡眠。"
——对设定的功能做直接说明，应该通过角色失眠来展示而非直接告诉读者

"不是为了信仰——是为了黑月节那晚灵站免费发一碗灵能汤，热的。"
——动机解释句式，AI特别喜欢"不是X——是因为Y"来解释角色行为

✓ 人类写法（让读者自己感受到，而非被告诉）：
"灵能结晶在灰蜥鳞片上发暗绿色的光。"（就到这里，不解释光照效果）

"碎片？不是普通的。"他翻过来看了看背面，沉默了一会儿。（展示而非解释区别）

（不写"灵能残渣影响睡眠"，而是下一章角色失眠、烦躁、做噩梦，读者自己会联想）
```

**检测规则**:
- 设定/物品首次出现后，同一段内紧跟功能性说明 → 删除或延后到另一个场景展示
- "不是X——是因为/是为了Y" 解释动机的句式，每章≤1次
- 括号注释式说明（如补充设定细节）→ 用行动展示代替

**修复方案**:
- **延迟展示**: 设定出现时不解释，让读者好奇；3-5章后通过角色体验自然揭示
- **行动替代说明**: 不写"残渣影响睡眠"，写角色连续三天没睡好，脾气变差
- **对话替代旁白**: 通过NPC的闲聊带出设定，而非旁白直接科普
- **留白**: 有些设定不需要解释"为什么"，让读者自己推理

### 2.3 🔴 AI指纹 #3：结构工整对称（叙事模板感）

**症状**: 每个场景都遵循相同的叙事模板：动作描写 → 环境补充 → 感官细节 → 角色反应 → 转场。

```
❌ AI工整结构（每个场景同一节奏）：
场景1（管道逃亡）：动作→环境→感官→反应→转场
场景2（聚落生活）：动作→环境→感官→反应→转场
场景3（老陈面摊）：动作→环境→感官→反应→转场
场景4（回到管道）：动作→环境→感官→反应→转场
——四个不同性质的场景，叙事结构完全一样

✓ 人类写法（场景间节奏差异）：
场景1（管道逃亡）：短句快切→动作密集→几乎无环境描写→直接跳切
场景2（聚落生活）：长句铺开→环境细节丰富→NPC对话穿插→慢节奏
场景3（老陈面摊）：从对话切入→动作和对话交织→感官描写融在对话里
场景4（回到管道）：一个画面开头→直接进事件→不铺垫
```

**检测规则**:
- 连续3个场景使用相同的"5段式"结构 → 至少2个场景需要打破模板
- 紧张场景（逃亡/战斗/对峙）和日常场景的段落长度分布相似 → 紧张场景需要更短段落
- 每个场景都以"环境铺陈"开头 → 至少1/3的场景从动作/对话/内心独白直接切入

**修复方案**:
- **变速**: 紧张场景用短句+快切（≤15字/句），日常场景允许长句铺开
- **切入方式轮换**: 环境→动作→对话→内心→悬念→声音，六种开头轮换
- **非对称结构**: 有些场景可以只有2段（极度聚焦），有些场景可以8段（充分展开）
- **省略**: 不是每个场景都需要环境铺垫。连续场景（同一地点）只在第一次做环境描写

### 2.4 🔴 AI指纹 #4："不是X，是Y"否定转折句式模式化

**症状**: 同一种否定-转折句式高频出现，AI 学到了"否定+转折=有深度"然后反复使用。

```
❌ AI高频否定转折（同一句式反复出现）：
"不是直线跑——管道不是直的"
"不是经验"
"不是怕，是跑太急了"
"不是痛叫，是灵能结晶被震裂后追踪信号紊乱的嘶鸣"
"不是信仰，是实用"
"不是为了信仰——是为了黑月节那晚灵站免费发一碗灵能汤"
——6次同类句式在3000字内，读者会感到模式化

✓ 人类写法（否定转折只是工具之一，不滥用）：
"管道不是直的。"（就这一句，后面用动作展示而非继续解释）
"他摇头。不是因为怕。是因为这条路跑多了，知道前面有什么。"
（每次否定转折都用不同的结构，且配合具体的角色行为）
```

**检测规则**:
- 全章"不是X，是/因为/为了Y"句式超过2次 → 必须改掉多余的
- 连续两个段落使用否定转折 → 后一个改用其他句式
- 否定转折后紧跟解释性从句（"是因为……"超过10字）→ 缩短或改用行动展示

**修复方案**:
- **保留最好的1个**，其余改掉
- 改为肯定式表达：`"管道拐了好几个弯"` 而非 `"管道不是直的"`
- 改为行动展示：`"他跑了几步猛地拐弯——前面是堵死的"`
- 改为内心独白：`"又是弯道。他甚至不用看。"`
- 改为零解释：只呈现事实，让读者自己判断

## 第三层：结构级 AI 味（深层）

### 3.1 禁止：过度均匀的信息密度

```
❌ 他走进了房间。房间很大，有五十平方米。墙上挂着一幅画，画的是山水。
   桌上放着一杯茶，茶还冒着热气。窗户开着，微风轻轻吹进来。

✓ 他推门进去。屋里大得有点浪费，就一张桌子一把椅子。桌上那杯茶还冒
   着热气——说明不久前有人来过。窗户开着，风把桌上那张纸吹得哗哗响。
```

### 3.2 禁止：排比句/三连击

```
❌ 他不会放弃，不会屈服，不会退缩。

✓ 他没打算退缩。从来就没有。
```

### 3.3 禁止：过度修饰

```
❌ 他的眼中闪烁着坚定而不屈的光芒，仿佛在黑暗中燃烧的火焰。

✓ 他眯了眯眼。"来吧。"
```

### 3.4 禁止：译制片式对话

```
❌ "我必须告诉你，这件事比你想象的要复杂得多。"

✓ "这事没那么简单。"
```

### 3.5 🔴 新增：禁止段落节奏匀速

```
❌ AI匀速节奏（每段长度相似，句式结构相同）：
每段3-4句，每句15-20字，均匀分布。
读起来像节拍器：哒-哒-哒-哒-哒-哒-哒-哒。

✓ 人类变速节奏（段落长短参差，句式结构多变）：
短段（1-2句）→ 长段（5-6句）→ 极短段（1句独立成段）→ 中段
像心电图：有波峰波谷，不是一条直线。
```

## 第四层：角色设计级 AI 味（最隐蔽）

| AI味模式 | 为什么是AI味 | 替代方案 |
|---------|------------|---------|
| 每人恰好一个标签、一个缺陷、一个秘密、一个弧线 | 太整齐了，真人不是这样 | 有的人有多个互相矛盾的缺陷；有的人没有秘密；有的人弧线走到一半就停了 |
| 缺陷是"太善良""太执着""太认真" | 自我表扬，不是缺陷 | 缺陷要让读者不舒服："她无法拒绝需要帮助的人，即使这些人在利用她" |
| 弧线是直线（从A直接到B） | 真人成长有倒退有反复 | A→A'→退回A→A''→B。至少一次"差一点做到了但没做到" |
| 好人做好事理由全干净 | 太圣人了 | 做好事的理由里混着私心。江屿帮沈野也帮自己确认罪行 |
| 坏人做坏事全因为坏 | 懒惰的恶 | 坏人有信念。虞渊真信自己能替所有人做决定。焱真信先动手才能活 |
| 所有人都在关键时刻"做出正确选择" | 假 | 有人做了错选择。有人做了错选择还不后悔。有人想改来不及 |
| 所有问题都有答案 | 太完满了 | 有人到结局还在挣扎。柳陌的信仰碎了没重建 |
| 反派的恶突然"顿悟"被感化 | 廉价的救赎 | 改变是渐进的，需要多次触发+痛苦。或者不改 |
| "觉醒了"然后突然变成好人 | 一句话改变人生 | 每一步微变化需要触发事件。没有触发事件的变化不可信 |
| 配角围着主角转 | 主角光环太重 | 配角有自己的生活、目标、时间线。主角不在时他们在做自己的事 |
| 顿悟式成长（某人一句话就"想通了"） | 舒适不会让人改变 | 改变的催化剂必须是痛苦的。旧应对机制彻底失效时人才会改变 |

## AI味检测方法 V2.0

### 写完每章后自查（4层检测）

**第一层：词汇扫描（快速）**
1. 搜索高频AI副词（不禁/缓缓/淡淡/微微……），出现超过 1 次就改
2. 搜索"震惊""难以置信""倒吸一口凉气"，每章合计不超过 1 次
3. 检查对话——如果不像真人说话就改

**第二层：句式扫描（重点）**
4. 🔴 搜索连续3个以上独立短句（句号切割法）→ 合并或用逗号/破折号串联
5. 🔴 统计"不是X，是/因为/为了Y"句式次数，超过2次必须改
6. 🔴 检查设定首次出现后是否紧跟解释 → 删除解释，延后到另一场景用行动展示
7. 检查是否有超过 3 句连续的心理描写或环境描写

**第三层：结构扫描（深层）**
8. 🔴 检查各场景是否使用相同的叙事模板 → 至少2/5的场景打破模板
9. 🔴 检查段落长度分布——如果每段都是3-4句/15-20字 → 需要变速
10. 检查紧张场景和日常场景的句式长度是否有明显差异 → 无差异就改

**第四层：角色扫描**
11. 检查角色行为是否符合蒸馏文件中的人设
12. 检查是否有角色突然"顿悟"而没有触发事件
13. 检查配角是否有独立的行动和动机

### AI指纹快速检测命令

每章写完后，用以下命令快速扫描四大AI指纹：

```bash
# 指纹1：句号切割法 — 统计独立短句（≤8字）占比
# 如果独立短句占比 > 15%，需要合并

# 指纹2：解释式展示 — 搜索设定紧跟解释的模式
# 检查是否有"名词+描写。补充说明。"的连续模式

# 指纹3：结构工整 — 统计各场景段落数和句式长度
# 如果方差 < 20%，说明节奏过于匀速

# 指纹4：否定转折 — 搜索"不是"出现次数
# 如果"不是"出现 > 2次/章，多余的必须改掉
```
