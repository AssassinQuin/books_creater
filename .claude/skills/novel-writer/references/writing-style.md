# 写作通用标准

> **本文件为写作风格的唯一标准源**。所有 skill（生成/检查/审计）统一引用本文件。
> 小说特定规则（字数/流程/人物规则/检查清单）见各小说 `设定/写作执行规范.md`。
> 需要具体案例时，按需加载 `reference-writing-examples.md`。

---

## 一、对话：像真人说话

**规则**:

- 短句为主，长句拆开
- 能用一个字不用两个字
- 省略主语（真说话时谁整天"我""你"的）
- 口语化用词（"行""成""没门""少来"）
- 不同身份的人说话方式不同（粗人不说文话，书生不说糙话）
- 对话有废话（"嗯""啊""那个"有跑题有废话）

---

## 二、叙述：有画面感

**规则**:

- 用动作和反应替代形容词
- 用感官类比替代模糊描述（"比人还高的石墙" > "很高的墙"）——不用精确数字，用身体感受和类比传递信息
- 用感官替代判断（声音/气味/温度/触感）
- 一个场景最多 3 个感官细节，不要贪多

---

## 三、时间表达文学化（强制）

- **禁止精确时间**：不写"看了两秒""愣了三秒""等了五分钟"→ 改用"愣了愣神""怔了怔""一时没反应过来""半晌"
- **过渡用文学化表述**：不写"天没亮就醒了""过了一小时"→ 改用"翌日""次日清晨""第二天""入夜后""天蒙蒙亮"
- **长度用感受替代**：不写"走了两个小时"→ 改用"走了很久""太阳偏西才到""走到腿发酸"
- **时间感靠环境和身体传递**：用光线变化、体力消耗、肚子饿、天色渐暗等侧面展示时间流逝

---

## 四、描述感官化（强制）

- 距离/大小/程度用感官类比：不写"三米高""五米远"→ 写"比人还高的石墙""扔都扔不到对面"
- 用身体感受替代精确数字：不写"温度到了四十度"→ 写"烫得不敢碰""热得头发晕"
- 用参照物替代测量值：不写"重五十斤"→ 写"单手提不起来""压得肩膀往下沉"

---

## 五、侧面描写：用路人展示世界

**常用侧面手法**:

- 榜单排名（展示主角位置和成长）
- 物价（展示经济体系）
- 路人闲聊（展示世界观和近期事件）
- 摊贩商品（展示科技/修炼水平）
- 建筑和街道（展示城市特点）
- 告示/传单（展示社会秩序和热点）

---

## 六、日常充实

### 日常场景的作用

1. **展示世界观**: 通过细节让读者"住"在这个世界
2. **调节节奏**: 不能一直打，日常场景让读者喘口气
3. **侧面描写**: 通过日常中的小细节展示主角的实力变化
4. **伏笔载体**: 日常中不经意提到的东西可能是后面的关键

### 每 5-8 章安排一段日常，包含至少 2 个：

- 吃饭场景（食物描写 + 对话 + 信息交换）
- 逛街/集市（物价 + 社会风貌 + 偶遇）
- 住宿/休息（居住条件 + 思考/规划 + 梦境回忆）
- 交通/赶路（沿途风景 + 同行对话 + 突发事件）
- 训练/修炼（能力展示 + 难点突破 + 旁人反应）

---

## 七、章节结构

```
开头（10%）: 承接上文 + 本章场景铺垫
发展（40%）: 核心事件推进，冲突升级
高潮（30%）: 本章最紧张/最燃/最爽的时刻
收尾（20%）: 解决或留悬念 + 章末钩子
```

### 章末钩子类型

| 类型   | 示例                                               |
| ------ | -------------------------------------------------- |
| 悬念   | "门被推开的那一刻，他愣住了。"                     |
| 反转   | "他以为的死局，原来是别人布的棋。"                 |
| 新信息 | "榜单刷新了，第一名的名字让所有人倒吸一口凉气。"   |
| 威胁   | "远处的天空裂开了一条缝，里面有什么东西在往外涌。" |
| 承诺   | "'三天后，我会在擂台上等着你。'"                   |

## 八、爽点设计

### 爽点类型

| 类型 | 说明                    |
| ---- | ----------------------- |
| 打脸 | 质疑者被啪啪打脸        |
| 逆袭 | 绝境翻盘                |
| 获得 | 重要资源/能力/信息/盟友 |
| 展示 | 实力暴露，震惊全场      |
| 复仇 | 对之前的压迫者还击      |

### 爽点分层

- **基础爽**：战斗胜利/获得资源/解决困境
- **高级爽**：解开世界观谜题/发现历史真相/角色认知突破/团队关系重大进展

### 爽点三阶段

1. **期待** — 铺垫线索、设置目标
2. **验证** — 角色努力、过程展示
3. **满足** — 达成目标、揭示真相

每 3-5 章必须有一个爽点，爽点要有铺垫不是突然打脸。

## 九、去AI味核心要点

1. **句式长短交替**: 不要每句都是 15-20 字，偶尔来个 5 字短句
2. **省略过渡**: 不要每段都用"然而""但是""于是""随后"开头
3. **减少修饰**: 一个名词前最多一个形容词，不要"幽暗深邃的古老而神秘的地下洞穴"
4. **对话要有废话**: 真人说话有"嗯""啊""那个"有跑题有废话
5. **场景要有毛边**: 不要完美描述，留点不规整的细节
6. **情绪要克制**: 不要每段都"震惊""难以置信""倒吸一口凉气"，真实情感是失望/愤怒/无奈/释然

### 🔴 七大AI指纹对抗（与 anti-ai-patterns.md 配合使用）

#### 指纹1：句号切割法对抗

**核心原则**: 逗号串联相关信息，句号只用于真正的语义断点。

#### 指纹2：解释式展示对抗

**核心原则**: 展示而非解释。让读者自己感受到，而非被告诉。

#### 指纹3：结构对称对抗

**核心原则**: 场景间节奏差异是活人的标志。

#### 指纹4：否定转折对抗

**核心原则**: "不是X，是Y"是工具之一，不是万能钥匙。

#### 指纹5：精确度偏见对抗 (New)

**核心原则**: 禁止出现数字化的精确测量（寸/秒/米），改用身体感官尺度（指节/呼吸/跨步）。

#### 指纹6：节奏回环对抗 (New)

**核心原则**: 打破 [意象→解释→升华] 的工整循环，使用 [意象→行动→感官残留] 的锯齿状叙事。

#### 指纹7：均等观察对抗 (New)

**核心原则**: 拒绝全知摄影机。使用“偏心”的主观镜头，只聚焦角色当前最关心的1个细节，其余模糊化。

## 十、句式呼吸节奏系统

> AI写作最致命的不是用词，而是**节奏**。人类写作的节奏像呼吸，有深有浅有停顿；AI写作的节奏像节拍器，均匀、稳定、可预测。

### 三速节奏体系

| 速度   | 句长    | 段落  | 用途           |
| ------ | ------- | ----- | -------------- |
| **快** | 5-12字  | 1-2行 | 战斗/逃亡/危机 |
| **中** | 12-25字 | 3-4行 | 日常/对话/过渡 |
| **慢** | 25-50字 | 5-8行 | 情感/回忆/氛围 |

### 节奏组合模式

**加速模式**（日常→紧张）: 中速 → 中速 → 快速 → 快速 → 极快单句独立成段 → 停

**减速模式**（紧张→释放）: 快速 → 快速 → 中速（喘息） → 慢速（情感沉淀） → 静止

**心跳模式**（紧张中的短暂平静）: 快速 → 快速 → 慢速（突然安静） → 快速 → 快速 → 慢速 → 爆发

### 节奏铁律

1. **连续同速不超过3段** — 超过就必须变速
2. **每章至少1次急刹车** — 快速段落突然接一个极短句（1-5字）独立成段
3. **每章至少1次长呼吸** — 慢速段落中插入一个超长句（40+字），然后短句收尾
4. **段落长度参差** — 同一场景内段落长度方差>30%

## 十一、叙事节奏：信息释放控制

### 信息缺口设计

每章设置 1-2 个"信息缺口"，让读者有推理空间：

- 缺口不是"不知道"，而是"部分知道"或"误解"
- 缺口要在后续章节有补上，避免烂尾

### 悬念分层揭示

- **碎片线索**（早期）—— 给读者碎片化信息
- **拼图整合**（中期）—— 角色开始拼图，可能推理错误
- **真相揭示**（后期）—— 完整揭示，伴随认知冲击

---

## 十二、人物心理活动：外化决策过程

- **选择前置描写**：重要决策前描述角色心理活动，展示权衡过程
- **具体化心理描写**：避免抽象的"陷入沉思"，用具体画面和记忆代替
- **心理与行动关联**：心理活动要直接关联后续行动，不要过长拖慢节奏

---

## 十三、对话场景化

### 三要素

- **环境描写**（服务于对话氛围）
- **人物动作/神态**（展示关系）
- **对话内容**（推动情节）

重大对话前设置场景，不要突然进入对话。每句对话都踩在剧情上。

---

## 十四、七大写作心智模型

| 模型           | 核心                                                             |
| -------------- | ---------------------------------------------------------------- |
| **碰撞引擎**   | 多线的价值在线与线的碰撞。碰撞目标物必须是物理的、可流转的       |
| **信息差张力** | 张力 = 读者知道的 + 角色不知道的。三层：戏剧反讽/单向差/认知翻转 |
| **自信犯错**   | 让聪明角色在信息不完整时做自信推理→错误结论。不是"蠢"，是"盲"    |
| **小人物驱动** | 小人物不是 NPC，是推动剧情的主动力。给每个小人物 1 个明确动机    |
| **喜剧缓冲器** | 在紧张中提供释放。比例目标：喜剧:紧张 = 1:6 到 1:8               |
| **阴谋永动机** | 所有行动由强动机驱动。三层：表层/深层/极层                       |
| **双重叙事**   | 同时讲两条时间线。类型：并行双线 / 前后双线                      |

---

## 十五、基调控制

- 末日基调：破败、匮乏、惶惶是主基调
- 不华丽、不热血、不中二
- 角色情绪要真实：疲惫、麻木、绝望中的微小温暖
- 黑色幽默在残酷中发光

---

## 十六、世界观渐进展示

- 前期：循序渐进展示体系基础
- 中期：补充世界观细节
- 后期：揭示历史真相
- 通过角色日常体验自然认知，不一次性倾倒
- 新引入概念必须说清楚，读者不依赖外部知识就能理解
- 通过场景/动作/对话带出，不是角色突然科普
