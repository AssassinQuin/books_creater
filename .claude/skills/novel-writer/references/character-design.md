# 人物设计指南

> **核心原则**: 人物丰满多样，不全围着主角转。每个人物都是一个完整的"人"——有状态、有触发器、有语音指纹、有认知边界。

---

## 设计原则

1. **每个人物都有自己的生活在过** — 不出场的时候他们也在做自己的事
2. **每个人都有目标** — 不只是服务于主角剧情的工具人
3. **每个人都有弱点** — 完美的人物不真实
4. **每个人的说话方式不同** — 同一句话 5 个人有 5 种说法
5. **NPC 也要有个性** — 路边摊贩、酒馆老板、巡逻兵，每个人都有独特之处
6. **人物是活的** — 状态会变、关系会动、认知会扩展

---

## 角色深度设计方法论

> 来源：经典人物塑造方法论调研（12经典案例 + 5大方法论 + 45模板 + 5原型）
> 以下方法在设计角色时按需使用，不要求每个角色全用，但主角和核心配角至少覆盖方法1+2+7+质量检查。

### 方法1：Ghost→Lie 因果链

> 角色行为可信度的根基。Ghost是事件，Wound是后果，Lie是应对机制。三者因果链越清晰，行为越可信。

```
执行步骤:
1. Ghost："故事开始前，他身上发生过什么创伤性事件？"
2. Wound："这件事让他变成了什么样的人？"
3. Lie："他告诉自己什么错误信念来保护自己？"
4. Truth："故事最终要揭示的正确信念是什么？"（可能不揭示——不是所有角色都痊愈）
5. 验证：Ghost→Wound→Lie 是否因果清晰？中间断一环就补上
```

### 方法2：Want/Need 矛盾设计

> 推动情节的是Want，打动读者的是Want和Need的矛盾。

```
执行步骤:
1. Want：他以为自己想要什么？（具体、外在、推动情节）
2. Need：他真正需要什么？（抽象、内在、他自己不知道）
3. 验证矛盾：越追求Want是否越远离Need？否→改Want或Need
4. 设计"镜像时刻"：故事中段一个场景，逼他直面这个矛盾
```

### 方法3：弧线类型判定

> 不是所有角色都要改变。不变的代价有时比改变更动人。

```
执行步骤:
1. 这个角色在故事中会不会改变？
   - 会变好 → 正面变化弧
   - 会变坏 → 负面变化弧
   - 不变（持真理） → 正面平坦弧。需定义他持有什么"真理"，世界是真理的反面
   - 不变（持谎言） → 负面平坦弧。需定义他坚持什么错误信念
2. 不改变的角色：不变的代价是什么？没代价=固执，有代价=伟大/悲剧
3. 不改变 ≠ 不成长：可能是"想改来不及""不改不后悔""处境变了人没变"
```

### 方法4：原型匹配

> 从5大原型中选骨架，再从45模板中选具体型。避免从零开始造角色。

**5大原型**（每个含正面/负面变体 + 红线）：

| 原型 | 核心公式 | 红线 |
|------|---------|------|
| 凡人守护者 | 没有特殊 × 坚定守着什么 | 不能变强到超越"凡人"边界 |
| 创伤重构者 | 被伤害 × 用伤害学到的逻辑应对 | 创伤不能被"爱"治好 |
| 理念殉道者 | 真心信 × 信仰被现实碾压 | 信仰必须经历"代价测试" |
| 忠诚偏执者 | 绝对忠诚 × 忠诚对象有问题 | 忠诚必须有"自我保护"成分 |
| 混沌自由者 | 不属于体系 × 按自己规则活 | "自由"必须有代价 |

**45模板速查**（详见灵感库/经典人物塑造方法论-调研.md 第七节）：
- 主角成长型12种（被迫上路者/边界扩展者/沉默的守护者/...）
- 反派深度型10种（系统的维护者/恐惧先手者/疲劳的创造者/...）
- 配角点睛型13种（做了一件好事的普通人/信仰碎了的执行者/...）
- 特质融合型10种（温柔的暴力/精确的疯狂/阳光的伤痕/...）

```
执行步骤:
1. 先定原型（5选1或2）
2. 再选模板（45选1或2）
3. 对照"负面变体"检查是否踩坑
4. 对照"红线"检查是否越界
```

### 方法5：洋葱三层

> 共情的关键：读者一层一层剥开时，每层有意外但回头看都合理。

```
执行步骤:
1. 第一层·社会面具：别人看到他是什么样的？（一句话）
2. 第二层·自我认知：他以为自己是怎样的？（一句话）
3. 第三层·真实内核：压力下暴露的本能是什么？（一句话）
4. 验证：三层之间有"意外但合理"的差距？三层一样=太浅，跳跃太大=不合理
```

### 方法6：矛盾特质注入

> 矛盾本身就是故事。给角色一个与主气质矛盾的特质。

```
执行步骤:
1. 写下角色主气质（一个词）
2. 给一个矛盾特质（一个词）
3. 写"化学反应"——两个特质碰到一起产生什么独特行为？
4. 验证：化学反应是否自然产生了独特行为？矛盾但没反应=无效
```

常用矛盾组合参考：
- 温柔×反叛 / 理性×自毁 / 强大×脆弱 / 天真×残忍
- 阳光×伤痛 / 自私×善意 / 忠诚×背叛对象 / 清醒×无力

### 方法7：共情注入

> 角色不需要"可爱"，但必须"可理解"。

**6种共情技术**（选2-3种组合使用）：

| 技法 | 做法 | 适用 |
|------|------|------|
| 隐藏的伤口 | 独处时暴露的缺陷/创伤 | 所有角色 |
| 不期而遇的善意 | 最不像做好事时的微小善举 | 冷漠/自私型 |
| 保护弱者的本能 | 对特定弱者有保护欲 | 反派/强硬型 |
| 自嘲的幽默 | 能笑自己 | 严肃/高冷型 |
| 不公的遭遇 | 不配承受的不幸（不卖惨） | 所有角色 |
| 关键时刻牺牲 | 平时自私，关键时刻付出 | 自私/实用型 |

**3种矛盾制造法**：
- 环境矛盾：不同环境表现不同人格
- 道德矛盾：同一事对不同对象相反标准
- 秘密矛盾：外在行为和内在秘密形成张力

### 方法8："活过来"三细节

> 没有这三个细节，角色是"设定"。有了，角色是"人"。

```
1. 反差感：给角色一个与主流气质矛盾的特质（必须三种以上气质共存）
2. 标志性习惯：一个他无意识会做的事，暗示最深层心理状态
   - 检验：去掉这个习惯，角色是否"不像他了"？是→通过
3. 不完美时刻：在最该"坚强"的时刻给一个软弱瞬间
   - 检验：这个软弱是"意料之外但合理"的吗？
```

### 方法9：普遍性翻译

> 代入感的核心：把具体困境翻译成人类普遍困境。

```
执行步骤:
1. 写下角色的具体困境（含世界观/类型元素）
2. 去掉类型元素，翻译成一句话人类普遍困境
3. 翻译不出来 → 困境太特殊，读者代入不了 → 重写困境
4. 翻译出来了 → 验证：这个普遍困境是否"谁都可能遇到"？
```

示例：
- "灵衰症被灵枢人为制造" → "被信任的系统伤害"
- "血脉诅咒只能活到四十" → "知道时间不多了要怎么活"
- "实验室出生以为痛苦是正常的" → "不知道自己值得更好的"

### 方法10：反派共情三技法

> 反派成功的标准：读者能说"我理解他为什么这样，虽然我不认同"。

```
1. 给反派一个"对得起他的动机"：他不觉得自己是坏人
2. 给反派一块柔软的地方：对某个特定对象有温度
3. 反派的逻辑链必须自洽：用反派的视角复述故事，是否像一个"主角"？
```

### 方法11：渐进改变设计

> 改变必须是渐进的，不是顿悟式。最可信的轨迹不是A→B，是A→A'→退回A→A''→B。

```
执行步骤:
1. 写出起点状态A和终点状态B
2. 中间拆成至少3个微小变化节点
3. 每个节点需要：一个具体触发事件 + 一次痛苦
4. 加倒退：A→A'→退回A→A''→退回A'→最终到B
5. 验证：有没有哪个变化是"突然顿悟"的？有→拆成渐进
```

### 质量验证清单

每个角色设计完成后，逐条过检：

**检查清单（8条）**:
- [ ] 一句话能说清核心渴望？
- [ ] 渴望背后有创伤/缺失驱动？
- [ ] 有一个让人不舒服的内在缺陷（不是"太善良"）？
- [ ] 在不同人面前展现不同的面？
- [ ] 有一个标志性反差？
- [ ] 成长/堕落路径每一步合理？
- [ ] 有一个意想不到但回想合理的深层动机？
- [ ] 有一个代表内心状态的标志性习惯？

**AI味红线（踩中任何一条=重做）**:
- [ ] 弧线是直线（从A到B没有倒退）？
- [ ] 缺陷是萌点（"太执着""太善良"）？
- [ ] 好人做好事理由全干净？
- [ ] 坏人做坏事全因为坏？
- [ ] 所有人都在关键时刻"做出正确选择"？
- [ ] 每人恰好一个标签、一个缺陷、一个秘密、一个弧线？
- [ ] 所有人都改变了？没有人"不改""想改来不及"？
- [ ] 所有问题都有答案？没有人到结局还在挣扎？

## 角色蒸馏法（Character Distillation）

> 灵感来源：tavern-card-distiller 的角色卡蒸馏流程。从参考素材中系统提取人物核心，确保不遗漏关键维度。

### 蒸馏步骤

**第一步：信息萃取** — 从素材中提取原始信息
- 直接描写：外貌、身份、能力
- 间接描写：他人评价、环境暗示、历史记载
- 行为证据：关键决策、压力反应、日常习惯

**第二步：内核提炼** — 从原始信息提炼角色内核
- 核心矛盾：内心最深的冲突是什么？
- 行为驱动：什么情况下会做出反常举动？
- 情感锚点：最在意的人/事/信念是什么？

**第三步：维度定标** — 每个维度用具体行为定义，不用形容词
- ❌ "性格坚毅" → ✅ "连续三天不睡觉追查线索，手指磨破也不吭声"
- ❌ "善良温柔" → ✅ "打架时避开要害，但嘴上骂得最难听"
- ❌ "聪明狡猾" → ✅ "每次谈判前都准备三套方案，永远不第一个报价"

**第四步：语音锻造** — 确保一读对话就知道是谁说的
- 提取参考素材中的原话
- 总结句式偏好（长句/短句/省略/反问）
- 定义情绪变化时的语言特征
- 写 3-5 句示例对话作为标定

### 蒸馏模板

```
角色: {名字}
来源: {参考素材}

【萃取】
外貌: (从素材提取的具体描写)
身份: (社会角色/职业/地位)
能力: (已知的技能和水平)
关键行为: (3个最能代表这个人的行为)
他人评价: (其他角色怎么说他/她)

【深度 — Ghost→Lie + Want/Need】
Ghost: (故事开始前的创伤事件)
Wound: (创伤让他变成了什么样的人)
Lie: (他告诉自己什么错误信念来保护自己)
Truth: (故事最终揭示的正确信念，或"不揭示")
Want: (他以为自己想要什么，外在具体的)
Need: (他真正需要什么，内在抽象的)
矛盾验证: (越追求Want是否越远离Need？)

【弧线】
弧线类型: (正面变化/负面变化/正面平坦/负面平坦/不改变)
起点状态: (A)
终点状态: (B，平坦弧写"不变")
改变节点: (至少3个，每个需要触发事件+痛苦)
倒退: (A→A'→退回A→A''→B)

【原型】
原型: (5选1或2)
模板: (45选1或2)
矛盾特质: (主气质×矛盾特质=化学反应)

【洋葱三层】
社会面具: (别人看到他是什么样的)
自我认知: (他以为自己是怎样的)
真实内核: (压力下暴露的本能)

【定标 — 用行为定义】
性格: (不用形容词，写3个具体行为)
弱点: (最致命的缺陷是什么，不是"太善良")
习惯: (口头禅/小动作/偏好)

【共情细节】
共情技法: (从6种中选2-3种)
反差感: (与主气质矛盾的特质)
标志性习惯: (去掉就不像他的动作)
不完美时刻: (最该坚强时的软弱瞬间)
普遍性翻译: (去掉类型元素后的普遍困境)

【语音锻造】
句式偏好: (长/短/省略/反问/排比...)
词汇特征: (书面/口语/方言/术语...)
情绪变化: (高兴时→/生气时→/紧张时→)
示例对话:
  日常: "..."
  愤怒: "..."
  紧张: "..."
  安慰别人: "..."
```

## 主角设计

### 必须定义

| 维度 | 问题 | novel-db 字段 |
|------|------|--------------|
| 出身 | 从哪来？家庭背景？ | `background` |
| 外部目标 | 具体要做什么？（活下去/报仇/找到XX） | `goals` |
| 内部渴望 | 深层想要什么？（自由/被认可/安全感） | `goals`（后半段） |
| 性格 | 用 3 个具体行为定义，不用形容词 | `personality` |
| 缺陷 | 最大毛病是什么？推动弧光的核心 | `weaknesses` |
| 习惯 | 口头禅/小动作/偏好 | `speech_style` + `catchphrase` |
| 底线 | 绝对不会做什么？ | `personality`（后半段） |
| 禁忌 | 一碰就炸的点？ | `personality`（后半段） |

### 语音画像（Speech Profile）

> 参照 tavern-card-distiller 的语音定标机制，每个角色必须有完整的语音指纹。

定义内容：
- **句式节奏**: 长句型/短句型/长短交替/省略型
- **词汇层**: 书面词汇/口语/方言/专业术语/粗话频率
- **语气特征**: 反问多/感叹多/陈述为主/爱用比喻
- **情绪变化时的语言偏移**:
  - 轻松时：句式变短，爱开玩笑
  - 紧张时：话变少，用陈述句
  - 愤怒时：嗓门大/冷声线（二选一，符合人设）
  - 受伤时：嘴硬/沉默/转移话题

存入 `speech_style` 字段，格式示例：
```
短句为主，爱用反问。粗话频率中，急了骂娘。轻松时话多带调侃，紧张时变沉默只剩单字。
```

`catchphrase` 存口头禅，如："麻烦死了" / "有意思" / "这不废话吗"

### 动态状态（Dynamic State）

> 借鉴 tavern-card-distiller 的状态追踪系统。长篇连载中人物状态必须可追踪、可演进。

用 `character_update(_status_json=...)` 维护 JSON 状态，结构如下：

```json
{
  "emotional_state": "压抑",
  "emotional_trend": "持续恶化",
  "key_possessions": ["父亲遗留的剑", "一枚不知来历的令牌"],
  "secrets": ["隐藏的血脉", "曾经背叛过师父"],
  "knowledge_scope": ["了解东城势力格局", "不知道师父的真实身份"],
  "current_arc": "从逃避到面对",
  "arc_progress": 0.3,
  "last_major_event": "发现师父的密信",
  "behavioral_flags": {
    "trust_level": "低 — 刚被背叛",
    "combat_style": "保守防守型",
    "social_mode": "警惕，不主动接触"
  }
}
```

**状态更新时机**：
- 每卷结束时更新 `arc_progress`
- 重大剧情后更新 `emotional_state` + `behavioral_flags`
- 获得新物品/信息时更新 `key_possessions` / `knowledge_scope`
- `writing_finish` 后检查是否需要更新

### 主角不能做的事

- ❌ 开始就无敌（没成长空间）
- ❌ 毫无理由地圣母（帮助陌生人不需要理由）
- ❌ 女性角色倒贴（不需要理由就喜欢主角）
- ❌ 所有人都喜欢他（不真实）
- ❌ 永远正确不犯错（无聊）

## 核心配角设计（至少 3 人）

### 配角类型

| 类型 | 功能 | 设计要点 |
|------|------|---------|
| **导师/引路人** | 带主角入门，传授知识 | 有自己的过去和遗憾，不是专职解说员 |
| **搭档/兄弟** | 陪伴主角，制造互动 | 有自己的目标和故事线，不只是附庸 |
| **对手/竞争者** | 激发主角成长 | 有自己的理由，可能最后成为盟友 |
| **羁绊/恋人** | 情感支点 | 有自己的生活，不是等待主角拯救的公主 |
| **信息源** | 提供消息和情报 | 有自己的立场和目的，不是免费百科 |

### 配角独立性检查

每个配角回答以下问题（答不上来说明是工具人）：
1. 他/她自己的目标是什么？（与主角无关的目标）
2. 如果主角不出现，他/她会在做什么？
3. 他/她有什么不为人知的秘密？
4. 他/她最害怕什么？
5. 他/她和主角有利益冲突吗？

### 配角专属：出场节拍器

> 百万字长跑中配角容易"消失"。用状态追踪防止遗忘。

```json
{
  "last_appear_chapter": 45,
  "appear_count_in_volume": 3,
  "current_whereabouts": "在南域执行家族任务",
  "pending_plot_threads": ["与三皇子的秘密交易尚未揭穿"],
  "next_scheduled": "卷四中期回归，带来南域情报"
}
```

**出场间隔规则**：
- 核心配角：不超过 8 章需要出场或侧面提及
- 重要配角：不超过 15 章需要出场或侧面提及
- 超过间隔 → `health_check` 标黄 → 安排侧面提及（路人转述/书信/回忆）

## 反派设计

### 反派不是"坏人"，是"对手"

好的反派要让读者觉得"如果我是他，我也可能这么做"。

### 必须定义

| 维度 | 问题 | novel-db 字段 |
|------|------|--------------|
| 目标 | 他想要什么？ | `goals` |
| 理由 | 为什么这个目标对他很重要？ | `background` |
| 手段 | 他用什么手段？为什么选这种？ | `personality` |
| 底线 | 他绝对不会做什么？ | `personality` |
| 弱点 | 他有什么致命缺陷？ | `weaknesses` |
| 视角 | 站在他的角度，他是对的吗？ | `arc_notes` |

### 反派层级

| 层级 | 出现时机 | 特点 |
|------|---------|------|
| 小BOSS | 前10章 | 展示主角实力的垫脚石，但要有自己的故事 |
| 中BOSS | 第一卷中后期 | 有自己的势力，对主角构成真正威胁 |
| 大BOSS | 贯穿全书 | 隐藏在幕后，逐渐揭示其全貌 |
| 隐藏BOSS | 后期反转 | 可能是主角身边的人，颠覆读者认知 |

### 反派状态追踪

```json
{
  "threat_level": "区域级",
  "current_scheme": "暗中控制东城商会",
  "known_by_protagonist": ["知道他是商会背后的手"],
  "unknown_by_protagonist": ["真实身份是前朝遗族", "与师父有旧"],
  "next_move": "在主角突破金丹前完成布局",
  "relationship_to_protagonist": "尚未正面接触，仅通过代理人交锋"
}
```

## NPC/路人设计

### 为什么 NPC 很重要

路人的一句话可以比作者写三段设定更有用：

**反面**（空洞）:
> 这座城市是大陆上最繁华的商贸中心，汇聚了来自各地的商人和冒险者。

**正面**（侧面描写）:
> 街边卖烤肉串的大爷看了他一眼："小伙子外地来的吧？看你这身行头，刚到潜龙城？告诉你，晚上别往南区走，最近那边不太平。对了，你要是手头紧，东城的佣兵公会正在招人。"

### NPC 设计模板

```
角色: {名字或描述}
出场: 在哪一章/什么场景
功能: 提供信息/制造氛围/侧面展示世界
特点: 一句话概括他的独特之处
说话风格: {方言/口头禅/语气}
世界观触发: 他能自然带出什么设定信息
```

> 世界观触发（World-Book Trigger）：借鉴 tavern-card-distiller 的 lorebook 触发机制。每个 NPC 关联 1-2 条世界观信息，出场时自然带出，而非硬性科普。

### 常用 NPC 场景

- **摊贩/店主**: 用物价和商品展示经济体系
- **酒馆常客**: 用八卦和传闻展示世界观
- **巡逻兵/守卫**: 用规矩和检查展示社会秩序
- **同行/竞争对手**: 用对比展示主角的水平和特点
- **老前辈/退休强者**: 用回忆展示历史和传说

## 认知地图（Knowledge Map）

> 每个人物的知识边界不同。信息差是制造张力和悬念的利器。

### 知识维度

| 类型 | 说明 | 存储位置 |
|------|------|---------|
| 已知事实 | 角色确定知道的信息 | `status.knowledge_scope` |
| 未知但相关 | 角色不知道但与己相关的信息 | `status.secrets`（别人的视角） |
| 错误认知 | 角色以为对但其实错的信息 | `arc_notes` 标注 |
| 信息差冲突 | 两个角色对同一件事知道的不同版本 | 关系描述中标注 |

### 信息差运用

- **读者知道，角色不知道** → 悬念/紧张
- **角色知道，读者不知道** → 伏笔/揭秘
- **角色A知道，角色B不知道** → 误会/戏剧性
- **所有人都以为对但其实错** → 反转

## 人物关系管理

### 关系类型

```
师徒/师生  —  传承、期望、叛逆
兄弟/战友  —  信任、牺牲、分歧
恋人/暧昧  —  障碍、误解、成长
敌对/竞争  —  动机、升级、转化
利用/交易  —  利益、背叛、反转
亲属/血缘  —  羁绊、责任、冲突
```

### 关系动态追踪

> 关系不是静态的。`relation_create` 的 `intensity` (1-10) 和 `description` 应随剧情更新。

关系演进路径（示例）：
```
陌生人 → 熟人 → 信任 → 背叛 → ？
敌人 → 对手 → 尊重 → ？
利用 → 习惯 → 依赖 → ？
```

每卷结束时检查：哪些关系需要更新 `intensity` 和 `description`？

### 关系图使用

用 `memory_graph` 工具：
- `memory_graph(action="subgraph", hash={主角hash}, radius=2)` 查看主角的二度关系
- 发现孤立的角色（没关系的NPC需要补充关联）
- 发现关系过密的区域（是否所有角色都只围着主角转？）

## 设计流程总览

```
A3 人物设计
│
├── 1. 读 world_query 召回世界观设定
│
├── 2. 角色蒸馏（每个角色走一遍）
│   ├── 萃取：从灵感/参考素材提取原始信息
│   ├── 深度：Ghost→Lie因果链 + Want/Need矛盾 + 弧线判定 + 原型匹配
│   ├── 洋葱三层：社会面具 + 自我认知 + 真实内核
│   ├── 矛盾注入：主气质×矛盾特质 + 化学反应
│   ├── 共情细节：6技法选2-3 + 反差 + 标志习惯 + 不完美时刻 + 普遍性翻译
│   ├── 定标：用行为定义各维度
│   └── 锻造：语音画像 + 示例对话
│
├── 3. 写入 novel-db
│   ├── character_create(name, role, personality, speech_style, ...)
│   ├── character_update(_status_json={动态状态JSON})
│   └── relation_create(from, to, type, intensity, description)
│
├── 4. 质量验证
│   ├── 质量检查清单（8条）
│   ├── AI味红线（8条）
│   └── 群像独立检查（每人5问）
│
├── 5. 交叉验证
│   ├── 知识地图交叉（谁知道什么、信息差在哪）
│   ├── 世界观触发映射（NPC 关联哪些设定）
│   └── 关系网完整性（无孤立节点、非星型拓扑）
│
└── 6. git commit -m "A3: 人物完成 - {小说名}"
```
