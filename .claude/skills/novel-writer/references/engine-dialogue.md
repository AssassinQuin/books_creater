## 对话生成协议

### Step 1: 加载说话人档案

写对话前，对每个开口的角色执行：

```
1. character_get({character_id}) → 提取:
   - speech_style: 句式节奏(短句/长句/碎句/正式)
   - catchphrase: 口头禅
   - personality: 核心性格（影响语气）
   - background: 出身（影响用词层次）

2. relation_list → 查说话人对听话人的关系:
   - relation_type: ally/family/rival/subordinate...
   - intensity: 1-10（影响亲密度）
   - description: 关系描述（影响说话方式）
```

### Step 2: 关系调节语气

同一人物对不同对象语气不同：

| 关系类型 | 语气倾向 | 示例(方岩) |
|----------|---------|-----------|
| 对战友 | 简短直接/暗含信任 | "堵上。""别废话。走。" |
| 对晚辈 | 克制关心/不多说 | "你的碎片，注意控制。" |
| 对陌生人 | 警惕/沉默/单字 | "嗯。""不进去。" |
| 对敌人 | 冷/不加修饰 | (方岩不废话，直接动手) |
| 对弱者 | 不刻意温柔但会给 | (把短刀借给沈野) |

### Step 3: "说"字替代四法（核心升级）

**核心原则**：别把"说"字当成必需品。用动作、神态、环境、语感替代"他说/她说"，让对话更生动高级。

#### 方法一：动作卡位法
用动作代替"说"，让人物边做动作边说话，画面感立现。

```
❌ "你别闹了。"他说。
✅ 他伸手按住她的肩膀，手指轻轻蹭了蹭她的胳膊，语气软下来："你别闹了。"

❌ "你必死无疑。"反派说。
✅ 反派攥紧拳头，手背青筋暴起，狠狠砸在桌子上："你必死无疑。"
```

**常用动作卡位词**：伸手、按住、攥紧、砸、挑眉、转身、低头、抬头、后退一步、上前一步、倚着、蹲着、站着、手指蹭、手背擦、指尖捏、肩膀抖、喉结滚动、脚步骤停。

#### 方法二：神态神韵法
用表情、神态代替"说"，情绪直接透出来。

```
❌ "我没有做错。"她说。
✅ 她眼眶泛红，睫毛轻轻颤动着，声音带着哭腔："我没有做错。"

❌ "就凭你？"大佬说。
✅ 大佬挑眉，嘴角勾起一抹嘲讽的笑，眼神斜睨着他："就凭你？"
```

**常用神态词**：眼眶泛红、睫毛颤动、嘴角抽了一下、眼神一暗、眉头皱起、眉心微蹙、眼神闪躲、目光一滞、脸色一沉、表情僵住、笑了一下（不是笑）、咬了咬唇、喉结滚动、眼神斜睨、挑眉、眯眼、瞪大眼睛、垂下眼帘。

#### 方法三：情境穿插法
在对话中间插一句环境描写，自然打断"说"字，烘托气氛。

```
❌ "你根本不懂我！"她说。"我怎么不懂？"他说。
✅ "你根本不懂我！"她猛地转身。窗外的雷雨砸在玻璃上，噼啪作响。
  "我怎么不懂？"他追上去，声音被风声盖得发闷。

❌ "其实我早就注意你了。"他说。"我也是。"她说。
✅ "其实我早就注意你了。"他声音很轻。月光透过窗棂，洒在他的发梢。
  "我也是。"她低头，指尖蹭着衣角。
```

**情境穿插时机**：情绪转折处、对话停顿处、气氛切换处。环境描写1-2句即可，不宜过长。

#### 方法四：语感辨识法
靠角色的语言特色直接省略"说"字。前提是人物说话有自己的风格，不能所有人一个味儿。

```
街头混混："去去去，别挡老子的路，再烦老子收拾你！"
→ 不用写"混混说"，语气自带身份标签。

豪门千金："麻烦你帮我拿一下那本书，谢谢。"
→ 不用写"千金说"，礼貌疏离感就是标签。

夫妻对话："饭好了吗？""快了，再等五分钟。"
→ 不用加任何提示语，自然分清谁是谁。
```

**语感辨识前提**：每个主要角色的句式节奏、口头禅、用词层次必须有明显差异。见下文"对话差异化示例"。

### Step 4: 弦外之音

中国文学意境——说出来的话≠真实意图：

```yaml
表达层次:
  表层台词: "没事。就是脏了。"  (沈念对阿婆说手指发灰)
  真实意图: 我知道这是灵衰症，我不想让你担心
  暗示手段:
    - 动作: 手指蜷了一下（下意识隐藏）
    - 微表情: 笑了一下（硬撑）
    - 环境呼应: 阿婆的沉默（老人看穿但不说破）

常用技法:
  - 以动作代心理: "攥紧了。攥了又松。" → 不写"他很紧张"
  - 以环境代情绪: "风从西边吹过来，焦糊味比昨天淡了一点" → 不写"他松了口气"
  - 以沉默代回答: 方岩没接话 → 不写"方岩不想谈这个"
  - 以重复代执念: "碎罗盘不在手里了——手空了" → 不写"他很不舍"
```

## 标点符号丰富化规范（对抗AI声纹）

AI写作的标点使用往往单调（逗号+句号为主），丰富标点能打破机械感，让文字有呼吸和情绪。

### 标点使用指南

| 标点 | 用法 | 示例 |
|------|------|------|
| **破折号——** | 语气转折、声音拖长、思绪中断 | "不是怕——是跑太急了" / "你——" |
| **省略号……** | 欲言又止、沉默延续、声音渐弱 | "我……"她低下头。/ 远处传来嘶鸣，越来越近…… |
| **感叹号！** | 情绪爆发、短促命令、惊呼 | "跑！" / "别碰！" |
| **问号？** | 质疑、反问、不可置信 | "就凭你？" / "这……怎么可能？" |
| **冒号：** | 引出具体动作/神态，替代"说" | 他伸手按住她肩膀，语气软下来："别闹了。" |
| **分号；** | 并列对比、节奏停顿 | 他动了；她没动。 |
| **引号嵌套** | 内心独白、特殊含义 | 他所谓的"帮忙"，不过是添乱。 |
| **无标点短句** | 极度紧张时的快切 | 他跑。管道在抖。碎石落。 |
| **括号（）** | 极短补充说明，慎用 | 他喊了一声（其实更像呜咽）。 |

### 标点组合技巧

```
❌ AI单调标点：
"你没事吧。"她说。"我没事。"他说。"真的吗。"她问。

✅ 丰富标点：
"你没事吧？"她声音发紧。
他摇头，没说话。
"……真的？"
"嗯。"他顿了顿，"……真的。"
```

**规则**：
- 对话中每3-5句至少使用1次破折号、省略号或感叹号
- 紧张场景多用短句+句号快切，情感场景多用省略号+破折号
- 避免连续5句以上只用逗号和句号
- 问号不仅用于疑问，也可表不可置信、反问

## 对话结构规则

### 禁止连续纯对话
超过3句纯对话必须插入动作/微表情/环境：

```
✅
"几时了？"沈念揉了揉眼睛。
"辰时过了。"沈野把糊糊盛了两碗。
"照明石你动过？"
"填了点碎渣。"他没抬头。

❌ (纯对话堆叠)
"几时了？"
"辰时过了。"
"照明石你动过？"
"填了点碎渣。"
"好看。"她说。
沈野没接话。
```

### 微表情库

| 情绪 | 微表情 | 频率控制 |
|------|--------|---------|
| 隐藏不安 | 手指蜷了一下/攥紧了又松 | 每角色每章≤2次 |
| 压抑情绪 | 嘴角动了一下/嘴唇抿了一下 | 每章≤1次 |
| 警觉 | 眼神停了一下/脚步慢了半拍 | 适度 |
| 不想多说 | 没接话/没回头/嗯了一声 | 适度 |
| 松了口气 | 没有直接描写→用动作暗示 | 适度 |
| 心疼 | 看了一眼XX→XX（瘦了/灰了） | 每章≤1次 |

**注意**: 微表情不能模板化重复。同一情绪用不同动作：
- 紧张: 攥紧/攥刮刀柄/攥膝盖上的布/攥背包带/攥碎罗盘（每处不同）

### 通感技巧

跨感官描写，增加文学意境：
```
视觉→触觉: "他的目光像砂纸蹭过手背"
听觉→温度: "声音凉下来。管道里的风也凉了"
情绪→环境: "话说到一半，外面的风停了"
视觉→嗅觉: "灯光照着的不是铁锈，是焦糊味留下的痕迹"
触觉→情绪: "掌心微微出了汗，但手指是凉的"
```

## 对话差异化示例

### 沈野 (主角·拾荒者)
- **基础语气**: 极少说话，多为短句/单字回应
- **对沈念**: 话比平时多一点，但从不解释为什么做某事（用行动代替）
- **对陌生人**: 沉默观察，只说必要的
- **紧张时**: 不说话，手攥紧

### 沈念 (妹妹·13岁)
- **基础语气**: 比哥哥话多，但不说多余的话
- **对小孩**: 自然变软，"念姐"的语气
- **对灵站员工**: 礼貌但防备，不暴露太多
- **隐藏病情时**: 语气正常，但会突然停顿/换手做事

### 方岩 (老兵·壁盾斥候)
- **基础语气**: 像读报告，没有波动
- **回忆战友时**: 嘴角动一下（不是笑），语气不变但内容变
- **教沈野时**: 简短指令式，不解释原理只说方法
- **痛苦时**: 也不说，腿弯了一下，继续走

## QA校验规则

检查对话时验证：
1. **语气匹配**: 说话人的用词/句式是否符合character档案
2. **关系匹配**: 对不同对象的语气是否有差异（如果对所有人都一样→OOC）
3. **知识边界**: 角色说的信息是否超出了他"应该知道"的范围
4. **伴随动作**: 纯对话堆叠是否超过3句
5. **微表情重复**: 同一微表情是否在同一章出现超过2次
6. **"说"字冗余**: 是否过度使用"他说/她说"，优先用动作/神态/环境替代
7. **标点丰富度**: 对话中是否每3-5句至少使用1次破折号、省略号或感叹号
8. **标点单调**: 是否连续5句以上只用逗号和句号，需引入其他标点打破节奏
