## 对话生成协议

### Step 1: 加载说话人档案

写对话前，对每个开口的角色执行：

```
1. character_get({character_id}) → 提取:
   - speech_style: 句式节奏(短句/长句/碎句/正式)
   - catchphrase: 口头禅
   - personality: 核心性格（影响语气）
   - background: 出身（影响用词层次）

2. relation_list → 查说话人对听话人的关系:
   - relation_type: ally/family/rival/subordinate...
   - intensity: 1-10（影响亲密度）
   - description: 关系描述（影响说话方式）
```

### Step 2: 关系调节语气

同一人物对不同对象语气不同：

| 关系类型 | 语气倾向 | 示例(方岩) |
|----------|---------|-----------|
| 对战友 | 简短直接/暗含信任 | "堵上。""别废话。走。" |
| 对晚辈 | 克制关心/不多说 | "你的碎片，注意控制。" |
| 对陌生人 | 警惕/沉默/单字 | "嗯。""不进去。" |
| 对敌人 | 冷/不加修饰 | (方岩不废话，直接动手) |
| 对弱者 | 不刻意温柔但会给 | (把短刀借给沈野) |

### Step 3: "说"字替代四法（核心升级）

**核心原则**：别把"说"字当成必需品。用动作、神态、环境、语感替代"他说/她说"，让对话更生动高级。

#### 方法一：动作卡位法
用动作代替"说"，让人物边做动作边说话，画面感立现。

```
❌ "你别闹了。"他说。
✅ 他伸手按住她的肩膀，手指轻轻蹭了蹭她的胳膊，语气软下来："你别闹了。"

❌ "你必死无疑。"反派说。
✅ 反派攥紧拳头，手背青筋暴起，狠狠砸在桌子上："你必死无疑。"
```

**常用动作卡位词库（按身体部位分类，写作时轮换使用）**：

| 部位 | 动作示例 | 变体表达（至少5种） |
|------|---------|-------------------|
| **手部** | 伸手、按住 | 手指点了点、手掌覆上、指尖划过、手指蜷起、手背蹭了蹭、拇指摩挲、手指关节轻叩、手掌摊开、手指交叉、指尖轻触 |
| **头部** | 挑眉、低头、抬头 | 头偏了偏、脑袋微侧、下巴抬了抬、额头抵住、后脑勺靠在、头发晃了晃、眉毛皱起、眉心微蹙、眼角微眯 |
| **身体** | 转身、后退一步、上前一步 | 身体前倾、后背挺直、肩膀耸了耸、腰弯了弯、膝盖微屈、脚尖转向、脚跟碾了碾、身体晃了晃、重心前移 |
| **面部** | 喉结滚动、嘴角抽动 | 脸颊肌肉绷紧、下颌线收紧、嘴唇抿了抿、舌尖抵住上颚、鼻孔微张、眼角抽了抽、额头青筋微跳、太阳穴突突直跳 |
| **腿部** | 脚步骤停、蹲着、站着 | 脚尖点了点地面、脚跟抬起、膝盖碰了碰、腿交叉、腿微微发抖、脚无意义地踢了踢、鞋底蹭了蹭地面 |
| **综合** | 倚着、砸 | 身体斜靠、肩膀撞了一下、手肘撑在、手掌拍在、拳头捶在、手指掐进、手背青筋暴起、整个人僵住 |

**动作卡位铁律**：
1. 同一角色同一章内，同一动作不得重复两次
2. 优先使用手部+头部组合，比单一动作更生动
3. 动作要服务于情绪，不要为了加动作而加动作
4. 动作幅度与情绪强度匹配：克制情绪用小动作，爆发情绪用大动作

#### 方法二：神态神韵法
用表情、神态代替"说"，情绪直接透出来。

```
❌ "我没有做错。"她说。
✅ 她眼眶泛红，睫毛轻轻颤动着，声音带着哭腔："我没有做错。"

❌ "就凭你？"大佬说。
✅ 大佬挑眉，嘴角勾起一抹嘲讽的笑，眼神斜睨着他："就凭你？"
```

**常用神态词库（按情绪分类，写作时轮换使用）**：

| 情绪 | 核心神态 | 变体表达（至少5种） |
|------|---------|-------------------|
| **委屈** | 眼眶泛红 | 睫毛湿润但无泪、眼角微红、嘴唇微微发抖、下巴收紧（克制不哭）、声音带鼻音、眼神躲闪 |
| **嘲讽** | 嘴角勾起一抹嘲讽的笑 | 眼角微眯、眉毛轻挑、嘴角一侧上扬、眼神斜睨、冷笑一声、鼻腔发出轻哼 |
| **冷漠** | 眼神一暗 | 目光冰冷、眼皮半垂、面无表情、嘴角拉平、眼神没有焦点、脸部肌肉不动 |
| **惊讶** | 眼睛睁大 | 瞳孔收缩、眉毛扬起、嘴巴微张、表情僵住、眼皮快速眨动、身体微微后仰 |
| **愤怒** | 脸色一沉 | 下颌线绷紧、额头青筋微跳、鼻孔微张、眼神锐利、嘴角下拉、脸颊肌肉抽搐 |
| **心疼** | 眼神软下来 | 目光柔和、眉心微蹙、嘴角动了动（想说没说）、眼神在对方身上多停了一瞬、表情复杂 |
| **警惕** | 眼神锐利 | 瞳孔微缩、眼角余光扫视、目光定在某处、眼皮微抬、眼神从散漫变聚焦 |
| **疲惫** | 表情僵住 | 眼神空洞、眼皮沉重、肩膀塌下、脸色苍白、嘴角下垂、目光没有焦点 |
| **害羞** | 垂下眼帘 | 脸颊微红、眼神躲闪、嘴角不自觉上扬、手指无意义地动作、声音变小 |
| **得意** | 挑眉 | 眼角微弯、嘴角上扬、眼神明亮、下巴微抬、表情放松、身体微微前倾 |
| **恐惧** | 表情僵住 | 瞳孔放大、脸色发白、嘴唇发抖、身体微微发抖、眼神飘忽、呼吸急促 |
| **厌恶** | 眉头皱起 | 嘴角下拉、眼神避开、鼻孔微张、表情扭曲、身体微微后仰、声音变冷 |
| **期待** | 眼神亮了一下 | 嘴角不自觉上扬、身体前倾、手指无意义地动作、眼神聚焦、表情柔和 |
| **失望** | 眼神暗了下去 | 嘴角下垂、表情垮下来、眼神空洞、肩膀塌下、笑容消失、目光移开 |
| **倔强** | 咬了咬唇 | 下巴抬起、眼神坚定、嘴角抿紧、拳头攥紧、身体挺直、目光直视对方 |
| **温柔** | 笑了一下（不是笑） | 眼神柔和、嘴角微弯、表情放松、目光在对方身上停留、声音变轻 |
| **尴尬** | 表情僵住 | 嘴角抽搐、眼神飘忽、脸颊微红、手指无意义地动作、声音发干、挠了挠头 |
| **专注** | 眼神聚焦 | 眉头微蹙、身体前倾、手指停在半空、呼吸变浅、表情严肃、目光不动 |
| **释然** | 表情柔和下来 | 眉心舒展、嘴角自然上扬、眼神温和、肩膀放松、脸部肌肉不再紧绷 |
| **困惑** | 眉头皱起 | 眼神迷茫、嘴角微张、头偏了偏、眼睛眨了眨、表情茫然、声音发虚 |

**神态使用铁律**：
1. 同一角色同一章内，同一情绪不得使用相同神态两次
2. 优先使用眼部+嘴部组合，比单一神态更生动
3. 神态要服务于对话内容，不要为了加神态而加神态
4. 克制表达：末日基调下，神态幅度要小，点到即止
5. 避免过度使用"眼神"：可以换成目光、视线、眼角、瞳孔等替代

#### 方法三：情境穿插法
在对话中间插一句环境描写，自然打断"说"字，烘托气氛。

```
❌ "你根本不懂我！"她说。"我怎么不懂？"他说。
✅ "你根本不懂我！"她猛地转身。窗外的雷雨砸在玻璃上，噼啪作响。
  "我怎么不懂？"他追上去，声音被风声盖得发闷。

❌ "其实我早就注意你了。"他说。"我也是。"她说。
✅ "其实我早就注意你了。"他声音很轻。月光透过窗棂，洒在他的发梢。
  "我也是。"她低头，指尖蹭着衣角。
```

**情境穿插时机**：情绪转折处、对话停顿处、气氛切换处。环境描写1-2句即可，不宜过长。

#### 环境描写词库（按场景分类，写作时轮换使用）

| 场景 | 环境元素 | 变体表达（至少5种） |
|------|---------|-------------------|
| **雨天** | 雨滴、雷声 | 雨丝斜斜地飘进来、雨点砸在铁皮屋顶上噼啪作响、窗外的雨幕模糊了视线、雨水顺着窗框淌下来、雷声在远处滚动、雨声盖过了说话声、地面溅起泥点、空气中弥漫着潮湿的泥土味 |
| **夜晚** | 月光、星光 | 月光透过窗棂洒进来、星光稀疏得像撒了一把盐、夜色浓得化不开、远处的灯火忽明忽暗、月亮被云遮住了一半、路灯在雨雾中晕开一圈光、黑暗中传来不知名的声响 |
| **废墟/管道** | 铁锈、灰尘 | 风从破损的窗框灌进来、管道里传来滴水的声音、墙角的灰尘被脚步声扬起、铁锈味混着潮湿的气息、碎石从头顶落下来、远处的嘶鸣声在管道里回荡、照明石的光芒在墙上投下摇晃的影子 |
| **集市/聚落** | 人声、烟火 | 远处传来讨价还价的声音、炊烟从屋顶飘起来、空气中弥漫着烤食物的香味、人群的嘈杂声忽远忽近、摊位上的照明石发出暖黄色的光、小孩的笑声从巷子里传出来、铁器碰撞的声音清脆响亮 |
| **荒原** | 风、沙石 | 风卷着沙石打在脸上、远处的地平线在热浪中扭曲、枯草在风中摇晃、天空灰蒙蒙的像一块旧布、脚下的碎石咯吱作响、风从西边吹过来带着焦糊味、远处的异灵嘶鸣声若隐若现 |
| **室内/住所** | 光线、温度 | 屋里的光线暗了下来、火堆噼啪作响、墙上的影子随着火光摇晃、空气里弥漫着一股霉味、角落里传来老鼠跑动的声音、门缝透进一丝冷风、桌上的茶已经凉了 |
| **战斗/紧张** | 声音、动静 | 远处传来脚步声、兵器碰撞的声音清脆刺耳、呼吸声在寂静中格外明显、心跳声像擂鼓、风突然停了、空气中的灵能波动让皮肤发麻、地面微微震动 |
| **温情/暧昧** | 光线、气息 | 烛光摇曳、两人的影子在墙上交叠、空气中弥漫着淡淡的草药香、他的呼吸拂过她的耳际、指尖相触的温度、月光洒在他的发梢、她的头发蹭过他的肩膀 |

**环境描写铁律**：
1. 同一章内，同一环境元素不得重复描写两次
2. 环境描写要服务于情绪，不要为了加环境而加环境
3. 优先使用听觉+嗅觉，比视觉更有代入感
4. 克制表达：1-2句即可，不宜过长
5. 环境描写要自然融入对话，不要生硬打断

#### 方法四：语感辨识法
靠角色的语言特色直接省略"说"字。前提是人物说话有自己的风格，不能所有人一个味儿。

```
街头混混："去去去，别挡老子的路，再烦老子收拾你！"
→ 不用写"混混说"，语气自带身份标签。

豪门千金："麻烦你帮我拿一下那本书，谢谢。"
→ 不用写"千金说"，礼貌疏离感就是标签。

夫妻对话："饭好了吗？""快了，再等五分钟。"
→ 不用加任何提示语，自然分清谁是谁。
```

**语感辨识前提**：每个主要角色的句式节奏、口头禅、用词层次必须有明显差异。见下文"对话差异化示例"。

### Step 4: 弦外之音

中国文学意境——说出来的话≠真实意图：

```yaml
表达层次:
  表层台词: "没事。就是脏了。"  (沈念对阿婆说手指发灰)
  真实意图: 我知道这是灵衰症，我不想让你担心
  暗示手段:
    - 动作: 手指蜷了一下（下意识隐藏）
    - 微表情: 笑了一下（硬撑）
    - 环境呼应: 阿婆的沉默（老人看穿但不说破）

常用技法:
  - 以动作代心理: "攥紧了。攥了又松。" → 不写"他很紧张"
  - 以环境代情绪: "风从西边吹过来，焦糊味比昨天淡了一点" → 不写"他松了口气"
  - 以沉默代回答: 方岩没接话 → 不写"方岩不想谈这个"
  - 以重复代执念: "碎罗盘不在手里了——手空了" → 不写"他很不舍"
```

## 标点符号丰富化规范（对抗AI声纹）

AI写作的标点使用往往单调（逗号+句号为主），丰富标点能打破机械感，让文字有呼吸和情绪。

### 标点使用指南

| 标点 | 用法 | 示例 |
|------|------|------|
| **破折号——** | 语气转折、声音拖长、思绪中断 | "不是怕——是跑太急了" / "你——" |
| **省略号……** | 欲言又止、沉默延续、声音渐弱 | "我……"她低下头。/ 远处传来嘶鸣，越来越近…… |
| **感叹号！** | 情绪爆发、短促命令、惊呼 | "跑！" / "别碰！" |
| **问号？** | 质疑、反问、不可置信 | "就凭你？" / "这……怎么可能？" |
| **冒号：** | 引出具体动作/神态，替代"说" | 他伸手按住她肩膀，语气软下来："别闹了。" |
| **分号；** | 并列对比、节奏停顿 | 他动了；她没动。 |
| **引号嵌套** | 内心独白、特殊含义 | 他所谓的"帮忙"，不过是添乱。 |
| **无标点短句** | 极度紧张时的快切 | 他跑。管道在抖。碎石落。 |
| **括号（）** | 极短补充说明，慎用 | 他喊了一声（其实更像呜咽）。 |

### 标点组合技巧

```
❌ AI单调标点：
"你没事吧。"她说。"我没事。"他说。"真的吗。"她问。

✅ 丰富标点：
"你没事吧？"她声音发紧。
他摇头，没说话。
"……真的？"
"嗯。"他顿了顿，"……真的。"
```

**规则**：
- 对话中每3-5句至少使用1次破折号、省略号或感叹号
- 紧张场景多用短句+句号快切，情感场景多用省略号+破折号
- 避免连续5句以上只用逗号和句号
- 问号不仅用于疑问，也可表不可置信、反问

## 对话结构规则

### 禁止连续纯对话
超过3句纯对话必须插入动作/微表情/环境：

```
✅
"几时了？"沈念揉了揉眼睛。
"辰时过了。"沈野把糊糊盛了两碗。
"照明石你动过？"
"填了点碎渣。"他没抬头。

❌ (纯对话堆叠)
"几时了？"
"辰时过了。"
"照明石你动过？"
"填了点碎渣。"
"好看。"她说。
沈野没接话。
```

### 微表情库（V2.0 扩展版）

**核心原则**：微表情必须多样化，同一情绪在同一章内不得重复相同动作。每个情绪提供至少5种不同表达方式，写作时轮换使用。

#### 1. 隐藏不安/紧张

| 部位 | 微表情示例 | 变体表达 |
|------|-----------|---------|
| 手部 | 手指蜷了一下 | 指尖无意识摩挲衣角、手背青筋微凸、拳头攥紧又松开、手指关节发白、拇指掐进掌心 |
| 眼部 | 眼神飘忽不定 | 睫毛快速颤动、眼皮跳了一下、目光游移又强行定住、瞳孔微缩、不敢直视对方眼睛 |
| 身体 | 肩膀微不可察地绷紧 | 后背挺直了一瞬、脚尖不自觉转向门口、喉结上下滚动、呼吸一滞、身体微微前倾又缩回 |
| 面部 | 嘴角抽动 | 脸颊肌肉紧绷、下颌线收紧、眉心微蹙又舒展、额头渗出细汗、脸色发白 |

**频率控制**：每角色每章≤2次，且两次必须使用不同部位/动作。

#### 2. 压抑情绪/强忍

| 部位 | 微表情示例 | 变体表达 |
|------|-----------|---------|
| 嘴部 | 嘴唇抿成一条线 | 嘴角下撇又强行拉平、牙齿咬住下唇内侧、舌尖抵住上颚、嘴唇微微发抖、深吸一口气 |

**微表情使用铁律**：
1. **同一角色同一章内**，同一情绪不得使用相同动作两次
2. **优先使用组合**：眼部+手部、面部+身体，比单一部位更生动
3. **避免模板化**：不要每次紧张都写"攥紧拳头"，轮换使用不同部位
4. **克制为美**：微表情是"微"的，动作幅度要小，点到即止
5. **服务于对话**：微表情出现在对话前后，不要脱离对话单独存在

### 通感技巧

跨感官描写，增加文学意境：
```
视觉→触觉: "他的目光像砂纸蹭过手背"
听觉→温度: "声音凉下来。管道里的风也凉了"
情绪→环境: "话说到一半，外面的风停了"
视觉→嗅觉: "灯光照着的不是铁锈，是焦糊味留下的痕迹"
触觉→情绪: "掌心微微出了汗，但手指是凉的"
```

## 对话差异化示例

### 沈野 (主角·拾荒者)
- **基础语气**: 极少说话，多为短句/单字回应
- **对沈念**: 话比平时多一点，但从不解释为什么做某事（用行动代替）
- **对陌生人**: 沉默观察，只说必要的
- **紧张时**: 不说话，手攥紧

### 沈念 (妹妹·13岁)
- **基础语气**: 比哥哥话多，但不说多余的话
- **对小孩**: 自然变软，"念姐"的语气
- **对灵站员工**: 礼貌但防备，不暴露太多
- **隐藏病情时**: 语气正常，但会突然停顿/换手做事

### 方岩 (老兵·壁盾斥候)
- **基础语气**: 像读报告，没有波动
- **回忆战友时**: 嘴角动一下（不是笑），语气不变但内容变
- **教沈野时**: 简短指令式，不解释原理只说方法
- **痛苦时**: 也不说，腿弯了一下，继续走

## QA校验规则

检查对话时验证：
1. **语气匹配**: 说话人的用词/句式是否符合character档案
2. **关系匹配**: 对不同对象的语气是否有差异（如果对所有人都一样→OOC）
3. **知识边界**: 角色说的信息是否超出了他"应该知道"的范围
4. **伴随动作**: 纯对话堆叠是否超过3句
5. **微表情重复**: 同一微表情是否在同一章出现超过2次
6. **"说"字冗余**: 是否过度使用"他说/她说"，优先用动作/神态/环境替代
7. **标点丰富度**: 对话中是否每3-5句至少使用1次破折号、省略号或感叹号
8. **标点单调**: 是否连续5句以上只用逗号和句号，需引入其他标点打破节奏
9. **动作多样性**: 同一角色同一章内，同一动作不得重复两次
10. **神态多样性**: 同一角色同一章内，同一情绪不得使用相同神态两次
11. **环境多样性**: 同一章内，同一环境元素不得重复描写两次
12. **微表情组合**: 优先使用眼部+手部、面部+身体组合，比单一部位更生动
13. **避免模板化**: 不要每次紧张都写"攥紧拳头"，轮换使用不同部位和动作
14. **克制表达**: 微表情是"微"的，动作幅度要小，点到即止
