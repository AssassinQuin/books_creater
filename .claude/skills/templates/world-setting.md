# 世界观模板

> 权威源：DB `world_settings` 表。文件为可读副本。
> 本模板定义所有世界观分类的完整维度和字段规范。所有 skill 创建/修改世界观时必须遵守。

## 通用元数据（所有分类共享）

| MD字段 | DB列 | 类型 | 必填 | 说明 |
|--------|------|------|------|------|
| keys | keys | TEXT[] | ✅ | 触发关键词（出现这些词时激活此条目） |
| secondary_keys | secondary_keys | TEXT[] | 可选 | 次要触发词 |
| tags | tags | TEXT[] | ✅ | 分类标签（至少含category名+1个特征标签） |
| related | related_ids | TEXT[] | 可选 | 关联条目名（用名称而非ID） |
| volume_range | volume_range | TEXT | 可选 | 出现卷范围（如 V1-V3） |
| writing_guide | writing_guide | TEXT | 可选 | 写作指导（如何描写/展现） |
| priority | priority | INT | 可选 | 优先级（默认30，越低越优先） |
| is_constant | is_constant | BOOL | 可选 | 是否常驻条目（默认false） |

> `lorebook_id` 列保留作为历史数据映射参考，新条目无需填写。关联条目统一用名称引用，不再使用 LB-XXX 编号。

## 分类专属模板

### faction（势力）

```json
{
  "定位": "一句话描述势力本质",
  "规模": "小型/中型/大型/超大型",
  "与主角关系": "敌对/友好/中立/雇佣/交易/复杂",
  "核心理念": "势力信条/原则",
  "内部结构": "组织架构描述",
  "标志特征": "视觉标志/行为特征/口号/服装",
  "叙事定位": "在故事中的角色（如：前/中期boss·认知垄断·信仰崩塌）",
  "关键人物": ["人物1", "人物2"],
  "核心矛盾": "势力内部或对外的核心矛盾",
  "写作要点": "写这个势力场景时必须记住什么",
  "首次出场": "Ch{N}",
  "content": "完整详细描述（叙事风格，非设定堆砌）"
}
```

**势力必须包含**：
- 叙事定位（在故事中扮演什么角色）
- 核心矛盾（内部撕裂/外部冲突）
- 写作要点（写场景时的质感/氛围/禁忌）

## 文件格式

### 单分类文件（`设定/世界观/{分类名}.md`）

```markdown
# {分类中文名}

## {category}: {条目名}
- **keys**: ["关键词1", "关键词2"]
- **secondary_keys**: ["次要词1"]
- **tags**: ["{category}", "标签1", "标签2"]
- **related**: ["关联条目名1", "关联条目名2"]
- **volume_range**: V{N}-V{M}
- **writing_guide**: 写作指导文本
- **priority**: 30
- **is_constant**: false
{条目完整内容}

## {category}: {下一个条目名}
...
```

### 汇总文件（`设定/世界观.md`）

```markdown
# 世界观

> 各分类详细内容见 `设定/世界观/{分类名}.md`，本文件为索引。

## 种族
- {种族名} → 见 `世界观/纪元与种族.md`

## 势力
- {势力名} → 见 `世界观/势力.md`

## 地点
- {地点名} → 见 `世界观/地图.md`

## 能力/物品
- {条目名} → 见 `世界观/物品.md` 或 `世界观/能力体系.md`

## 经济
- {条目名} → 见 `世界观/货币与日常生活.md`

## 日常
- {条目名} → 见 `世界观/货币与日常生活.md`
```

## 扩展机制

新增分类时：
1. 在 DB `world_settings` 表的 `category` 列使用新值（已有索引，无需DDL）
2. 在本模板 `## 分类专属模板` 部分追加新分类的 JSON 结构
3. 在 `world_upsert` MCP 工具中无需修改（category 是动态参数）
4. 在 `get_chapter_context(novel_name, chapter_number, categories="新分类名")` 的 `categories` 参数中传入即可过滤；`load_mode="full"` 自动包含所有分类（无需修改代码）
5. 创建对应的 `设定/世界观/{新分类名}.md` 文件
