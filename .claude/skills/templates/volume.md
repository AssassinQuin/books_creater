# 卷级大纲模板

> 权威源：文件 `设定/大纲/V{N}-{卷名}.md`。DB `volumes` 表存摘要。
> 本模板基于 V01 兽潮实际产出优化，所有模块均来自已验证的创作实践。

## DB 字段映射

| MD字段 | DB列 | 类型 | 必填 | 说明 |
|--------|------|------|------|------|
| number | number | INT | ✅ | 卷号 |
| title | title | TEXT | ✅ | 卷名 |
| main_plotlines | main_plotlines | JSON | ✅ | 主线脉络数组 |
| notes | notes | TEXT | 可选 | 卷级备注 |

## 回响清单（Echo — 大事件余波的自然回溯）

> 密度规则：普通回响≤2次/卷，强相关不限，跨卷≤1次/间隔。
> 融入方式：必须融入世界呼吸或角色日常动作，不能是独立段落。

| # | 回响事件 | 源章节 | 出现章节 | 类型 | 强相关 | 写法 |

## 模板使用说明

### 必填模块（🔒 检查点）

| 模块 | 检查标准 | 不通过后果 |
|------|---------|-----------|
| 卷级因果链 | 能用"因为...所以..."完整串联 | 卷结构松散 |
| 每章场景序列 | ≥3个场景，有动作细节 | 章节空洞 |
| 每段费笔清单 | 起/合≥段章数个，承/转≥段章数÷2向上取整 | 日常呼吸缺失 |
| 每段读者感受 | 明确标注情绪起止状态 | 情绪追踪断链 |
| 每段支线融入 | 起段有苗头，承段有推进，转段有爆发，合段有状态 | 支线与主线割裂 |
| 每章因果链 | 场景间有明确因果 | 叙事断裂 |
| 章末钩子 | 每章结尾有悬念 | 追读动力不足 |
| 人物弧光 | 主角有变化，配角有功能 | 角色扁平 |
| 伏笔清单 | 埋设/展示/回收路径清晰 | 前后矛盾 |
| 回响密度 | 普通回响≤2次/卷，跨卷≤1次/间隔 | 回响泛滥 |
| 节奏分配 | 连续高压≤3章 | 读者疲劳 |
| 不做的 | ≥5条明确边界 | 过度展开 |

### 可选模块

- **关键对话保留区**：仅在对话质量达到"全文保留"标准时填写
- **信息投放节奏**：复杂信息结构时必填
- **下卷衔接**：非末卷时必填

### 扩展机制

新增维度时：
1. 在文件格式中追加新节
2. 如需 DB 支持，在 `volumes` 表新增列
3. 在 `volume_update` MCP 工具中新增对应参数
