# 人物关系与态度变化追踪规范

> **用途**: 定义人物关系变化、态度变化的记录和追踪规则
> **触发时机**: 
> - 大纲规划时（确定关系/能力变化节点）
> - 写作时（Step 3 状态同步）
> - 人物修改时（检查受影响关系）
> **归属**: novel-character skill 系统
> **核心原则**: 关系变化由大纲剧情确定，态度变化在人物系统中完善

---

## 一、数据来源分工

| 内容 | 确定位置 | 记录位置 | 说明 |
|------|---------|---------|------|
| **关系变化** | 大纲（卷/章节） | novel-db relation表 | 大纲确定"谁和谁的关系变了" |
| **态度变化** | 人物系统 | 角色深化.md | 人物系统完善"怎么变的" |
| **能力变化** | 大纲（卷/章节） | character.status + 角色深化.md | 大纲确定变化节点，人物系统完善描写 |
| **关系细节** | 人物系统 | 角色深化.md | 对话语气、微动作、弦外之音 |

## 二、关系变化追踪

### 2.1 关系类型定义

```
ally（盟友）    enemy（敌人）    mentor（导师）
lover（恋人）   family（家人）   rival（对手）
subordinate（下属）
```

### 2.2 关系强度量表

| 强度 | 含义 | 示例 |
|------|------|------|
| 1-2 | 点头之交/表面关系 | 市集摊贩和顾客 |
| 3-4 | 普通关系/同事 | 壁盾军团战友 |
| 5-6 | 信任/朋友 | 沈野和方岩初期 |
| 7-8 | 深厚感情/生死之交 | 沈野和陆沉后期 |
| 9-10 | 不可分割/命运共同体 | 沈野和沈念 |

### 2.3 关系变化记录格式（novel-db）

```json
{
  "from_character_id": 1,
  "to_character_id": 2,
  "relation_type": "ally",
  "intensity": 6,
  "chapter_established": 15,
  "description": "V3并肩战斗后，从雇佣关系转为真正的信任",
  "history": [
    {"chapter": 1, "event": "初次相遇", "intensity_change": 0},
    {"chapter": 5, "event": "共同突围", "intensity_change": +2},
    {"chapter": 12, "event": "沈野为方岩铸造装备", "intensity_change": +1},
    {"chapter": 15, "event": "方岩坦白12个弟兄的事", "intensity_change": +2}
  ]
}
```

## 三、态度变化追踪

### 3.1 态度维度

每个角色对其他关键角色的态度，按以下维度追踪：

| 维度 | 含义 | 变化示例 |
|------|------|---------|
| **信任** | 是否相信对方 | 从"利用"到"可以托付后背" |
| **亲近** | 情感距离 | 从"保持距离"到"主动关心" |
| **尊重** | 认可程度 | 从"看不起"到"承认价值" |
| **戒备** | 防御程度 | 从"完全开放"到"有所保留" |
| **依赖** | 依靠程度 | 从"独立行动"到"需要对方" |

### 3.2 态度变化记录格式（角色深化.md）

在角色深化.md中，每个角色章节增加「态度追踪」小节，按时间线记录关键转折：

```markdown
### 沈野 → 方岩

- V1CH3: 方岩给路线图，信任从"利用"→"可合作"
- V3CH15: 方岩坦白12弟兄的事，第一次"心疼"这个老兵
- V6CH28: 方岩为沈野挡伤，信任突破到"可以托付后背"

| 维度 | V1初遇 | V3并肩 | V6真相 | V9抉择 |
|------|--------|--------|--------|--------|
| 信任 | 2 | 5 | 7 | 8 |
| 亲近 | 1 | 3 | 5 | 7 |
| 尊重 | 3 | 5 | 7 | 8 |
```

### 3.3 态度变化写作规范

1. **禁止直白表述**: 不用"他开始信任方岩了"，用行为体现
2. **微动作泄露**: 从"站在三米外"到"递东西时手会停一下"
3. **对话变化**: 从"嗯"到"你小心点"
4. **决策影响**: 从"不管他死活"到"先确认他安全"

## 四、能力变化追踪

### 4.1 能力变化由大纲确定

大纲中必须明确标注：

```markdown
### V4 卷大纲

**沈野能力变化**:
- V4CH20: 首次"模拟"他人能力（陆沉分解的弱化版）
- 触发条件: 禁地核心共鸣，灵能浓度骤升
- 代价: 模拟后头痛三天，鼻血
- 后续影响: 开始理解"灵能路数"的概念
```

### 4.2 能力变化在人物系统中完善

在角色深化.md中增加「能力弧线」小节，按阶段记录：

```markdown
### 沈野 · 能力弧线

- 萌芽 V1-V3: 基础拓印，拾荒时触发，"手感好而已"
- 发展 V4-V6: 模拟他人，禁地共鸣，"原来我能做到这个"
- 成形 V7-V9: 自主设计，给队友造装备，"你缺什么，我补什么"
- 突破 V10-V12: 复制活人，从柳陌身上读路数，"理解一个人比理解结构难"
- 融合 V13-V14: 熔铸新路数，两种结构合二为一，"两只手合到了一起"

**代价累积**: V4头痛三天 → V7鼻血+手抖一周 → V10一天只能铸一件 → V13铸造后需人扶
```

## 五、变化一致性检查清单

### 5.1 大纲层面检查

- [ ] 每卷是否有明确的关系变化节点？
- [ ] 能力变化是否有充分前因？（禁止"因为剧情需要"）
- [ ] 变化节奏是否合理？（禁止同一卷内多人同时突破）
- [ ] 变化是否有代价？

### 5.2 人物系统层面检查

- [ ] 态度变化是否有微动作/对话支撑？
- [ ] 关系变化是否符合双方性格？
- [ ] 能力变化后是否有适应期描写？
- [ ] 变化是否同步到角色深化.md？

### 5.3 DB同步检查

- [ ] relation_create/update 是否执行？
- [ ] character.status.ability_changes 是否更新？
- [ ] 变化是否有 source_chapter 记录？

## 六、快速参考

### 写作时以哪个为准？

| 问题 | 答案 |
|------|------|
| 谁和谁的关系变了？ | **大纲**（剧情节点） |
| 关系怎么变的？ | **角色深化.md**（态度追踪） |
| 能力什么时候变？ | **大纲**（卷/章节标注） |
| 能力变化怎么描写？ | **角色深化.md**（能力弧线） |
| 对话语气怎么变？ | **角色深化.md**（关系调节表） |
| 变化是否合规？ | **锁定设定.md**（能力体系规则） |
