用户是网文创作者，正在 books_creater 项目下用自定义 skill 体系（story-long-write / story-setup / story-architect 等）写一本仙侠网文《这次不一样》（12 卷·迪化喜剧外壳+治愈内核+种田共和）。

工作方式：用结构化任务简报驱动 agent——简报通常含**必读**（文件路径列表）/ **输出**（目标产出格式）/ **纪律**（不可违背的红线）三段式。期望 agent：① 严格按必读列表顺序读文件，不跳级；② 严咬合规范 schema（Beat 字段、伏笔 F 编号、角色档案动机链）；③ 不擅自编造无证据的细节，无证据写 `[待补充]`；④ 写完直接 Write 落盘到指定路径，不输出 report/summary/findings 的 .md 文件到额外位置。

写作纪律偏好（项目级·CLAUDE.md + 各卷纲已固化）：refactor-over-patch（v4 独立设计·不打 v3 补丁·不写变更日志）/ 禁锁章节数字数（Beat 跨 2-N 章）/ 禁通灵玉鉴术语（男主=灵觉敏锐极简）/ 经典内核中西方融合不做套皮。相关：[[storyline-buildout-status]]
