# ADR 模板 — 创作决策记录

> **路径**: `docs/decisions/{编号}-{标题}.md`
> **用途**: 记录小说创作中不可逆的决策及其理由，防止未来重复讨论。

---

## 格式模板

```markdown
# ADR-{编号}: {标题}

- **状态**: 已接受 | 已废弃 | 已替代（被 ADR-{X} 替代）
- **日期**: {YYYY-MM-DD}
- **关联技能**: {novel-setup / novel-planner / novel-chapter-writer 等}

## 背景

{为什么需要做这个决策？遇到了什么问题或选择？}

## 决策

{最终选择了什么？用1-2句话概括。}

## 替代方案

| 方案 | 优点 | 缺点 | 放弃原因 |
|------|------|------|---------|
| {方案A} | ... | ... | ... |
| {方案B} | ... | ... | ... |
| **选定方案** | ... | ... | — |

## 理由

{为什么选择当前方案？考虑了哪些因素？}

## 影响

{这个决策影响哪些设定/人物/卷/章节？}

## 创建条件检查（三条件门控）

- [ ] **不可逆**: 这个决策一旦执行，难以撤销或修改（不会影响已写正文）
- [ ] **不显而易见**: 存在多个合理选项，需要权衡取舍
- [ ] **真实取舍**: 每个方案都有明确的优缺点

> 如果以上三项不全部满足，不应创建 ADR。

---

## 示例

# ADR-0001: 金手指选择 — 时间回溯

- **状态**: 已接受
- **日期**: 2026-05-10
- **关联技能**: novel-setup

## 背景

主角需要一个核心能力作为故事的驱动力。候选方案包括时间回溯、预知未来、空间传送和灵能复制。

## 决策

主角的金手指为"时间回溯"，可回溯最近30秒内的行为。

## 替代方案

| 方案 | 优点 | 缺点 | 放弃原因 |
|------|------|------|---------|
| 时间回溯 | 紧张感强/代价明确/成长空间大 | 需要精确的规则限制 | — |
| 预知未来 | 信息差爽点 | 容易变成全知视角/战斗张力弱 | 战斗场景失去悬念 |
| 空间传送 | 机动性强 | 破坏距离感/逃跑太容易 | 降低危险感 |
| 灵能复制 | 学能力强 | 成长线模糊/能力太多难管理 | 角色能力膨胀 |

## 理由

时间回溯能制造最强的时间紧迫感和"正确答案"的幻觉——主角以为回溯到正确选择，但每次回溯都有代价（体力消耗/精神损伤），形成"代价螺旋"。这比单纯的"变强"更有叙事张力。

## 影响

- 世界观：需要定义时间回溯的灵能原理
- 角色属性：沈野的初始能力 = 时间回溯
- 卷规划：V1展示回溯能力，V3-V4扩展回溯范围
- 战斗设计：回溯是最后手段，不能每场都用
```
