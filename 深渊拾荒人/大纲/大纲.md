- **题材**：玄幻（末世废土 + 魔法 + 悬疑 + 身份反转）

## 主线一句话

苏行作为 300 年前主动改造的"完整以太适应体"，苏醒后以拾荒者身份生活 7 年，靠衍算金手指在装弱状态下建立公路组织"衍社"，逐步揭开裂天日真相、对抗最终 Boss 铭刻者（同源理念对决），最终选择放弃力量成为锚定塔活体核心——从"被迫装弱"到"主动装弱"到"选择变弱"。

## 核心情绪弧线（延迟满足型）

```
卷 1：压抑 → 第一次被动暴露（小爆发）
卷 2：组织建立的成就感 → 学院追查的紧迫感
卷 3：势力争霸的爽感 → 叛徒+真相的情感冲击（最低谷）
卷 4：身份揭穿的爽感爆发 → 同伴震惊+心疼
卷 5：理念对决+第三条路的悲壮升华
```
