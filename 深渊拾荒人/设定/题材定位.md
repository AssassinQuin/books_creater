# 题材定位

## 基本信息

- **书名**：深渊拾荒人
- **题材类型**：玄幻（末世废土 + 魔法 + 悬疑 + 身份反转）
- **核心梗**：废土最底层的拾荒者，实则是 300 年前主动改造的"完整以太适应体"——装弱拾荒者→隐藏觉醒者→公路组织幕后操盘手→推翻晶石阶层。
- **微创新点**：
  1. 力量代价是"累积型"非"跳跃型"——每次用法术都留以太印记，印记累积导致晶化症恶化。装弱不是选择，是生死攸关的世界规则。
  2. 组织形态是"流亡者结社"非"塔罗会式神秘组织"——靠公路旅行中的恩情+利益+共同秘密绑定，移动而非固定。
  3. 终极危机有"倒计时"——锚定塔 3 年后全部失效，制造全书紧迫感。
- **目标平台**：起点中文网（男频主站）
- **预计字数**：300 万字+ 长架构（4-6 卷）
- **目标读者**：起点男频核心读者，偏好诡秘之主/烂柯棋缘/超神机械师一类有质感、有脑洞、有节奏的精品长篇。
- **主对标书**：诡秘之主（拆文库/诡秘之主/，legacy 拆文库，80 章摘要可用，v12 权威模块缺失）

## 核心梗三分法

- **表层卖点**：废土拾荒者 + 隐藏觉醒者身份反差。读者一眼看到"扮猪吃虎"的爽点预期。
- **深层爽点**：延迟满足型弧线——前 70-80% 持续装弱、持续布局、持续收获小爽点，最终大爆发时身份全面揭晓。读者代入"我心里已经把你们算穿了，但你们看我就是个怂货"的全知爽感。
- **长线钩子**：
  1. 苏行真实身份（300 年前主动改造的志愿者）何时揭穿
  2. 装弱主轴的三段升级（被迫装弱 → 主动装弱 → 选择变弱）
  3. 锚定塔 3 年倒计时——世界毁灭的时间锁
  4. 与最终 Boss"铭刻者"的同源关系——他到底是同伴还是实验品

## 题材框架

- **八节点位置**：开篇，处于"日常世界 + 触发事件"之间——苏行作为拾晶人在灰区挣扎，第一次被迫暴露觉醒者能力。
- **关键转折节点**：
  1. 卷 1 末（约 15-20%）：第一次被动暴露身份（救拾晶同伴）
  2. 卷 2 中（约 30-35%）：组织第一位核心成员通过反转加入
  3. 卷 3 末（约 50-55%）：第一个组织"叛徒"的动机反转
  4. 卷 3-4 交界（约 60-65%）：苏行记忆碎片真相——主动改造的志愿者
  5. 卷 4 中（约 75-80%）：铭刻者真实身份揭穿
  6. 卷 4-5 交界（约 85%）：组织成员发现苏行身份（核心爆发点）
  7. 终卷（约 95%）：苏行选择"放弃力量"作为第三条路

## 五项驱动检查

- **压迫感**：三重锁链（地理/知识/经济）+ 晶化症死循环 + 锚定塔倒计时
- **实力感**：法师五阶体系 + 苏行远超表面的真实实力（300 年前的完整以太适应体）
- **认知颠覆**：4 个核心谜团 + 7 个反转节点
- **资源升值**：晶体 = 货币/修炼资源/战略物资，随组织壮大需求升级
- **悬念增殖**：每解开一个谜团就暴露更深一层真相
